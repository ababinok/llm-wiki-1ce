## Свойства

### Основная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Основная
```

Кнопка первого уровня важности. Предназначена для отображения главного действия пользователя. В группе кнопок всегда является первой слева направо. Рекомендуется использовать только одну основую кнопку в рамках группы кнопок. Свойство [ОпасностьДействия](button-ru-d0cdd9e186f7.md) не влияет на отображение данной кнопки.

---

### Обычная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Обычная
```

Кнопка второго уровня важности. Предназначена для действий любого типа. Располагается, как правило, после основной кнопки. При применении опасности действия будет менять цвет в зависимости от того, какая опасность действия была применена.

---

### Дополнительная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Дополнительная
```

Кнопка третьего уровня важности, вызывает действия любого типа. Располагается после основной или обычной кнопки, если они имеются. При применении опасности действия будет менять цвет в зависимости от того, какая опасность действия была применена.

---

### ИконкаДействия

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ИконкаДействия
```

Кнопка выглядит как иконка действия. Опасность действия не влияет на отображение. Полезно для использования, например, с переключаемыми командами.

---

### Компактная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Компактная
```

Кнопка выглядит более компактной и имеет скругленные углы, рекомендуется для использования в заголовках.
