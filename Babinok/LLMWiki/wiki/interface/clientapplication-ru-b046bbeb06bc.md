## Обзор

Базовый абстрактный тип клиентского приложения.

## Документированный контракт и примеры

`Стд::Интерфейс::КлиентскоеПриложение::КлиентскоеПриложение` `Доступность: Клиент`

Базовый абстрактный тип клиентского приложения. Реализует логику приложения в целом, например, обработку события при запуске приложения.

## Свойства

### SeoОписание

`Доступность: Клиент`

```
SeoОписание: Авто|Строка
```

Задает произвольное описание для приложения, которое будет применено для мета-тега description страницы. Используется для оптимизации поисковой выдачи в сети Интернет.

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) зависит от базового компонента – если это [СтандартноеКлиентскоеПриложениеСРазделами](standardclientapplicationwithsections-ru-2bf3e285c484.md) – будет взято свойство у активной формы [SeoОписание](form-ru-89fb5e7eaeb3.md). Иначе – пустая строка.

### ПараметрыКаноническогоUrl

`Доступность: Клиент`

```
ПараметрыКаноническогоUrl: Авто|Массив<Строка>
```

Указывает какие дополнительные параметры URL (при их наличии) будут использоваться для составления канонической ссылки. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md) – отбрасывает все дополнительные параметры.

Параметры регистрозависимые.

Вне зависимости от заданного значения, state и navLink (только для приложения типа [СтандартноеКлиентскоеПриложениеСРазделами](standardclientapplicationwithsections-ru-2bf3e285c484.md)) считаются параметрами, которые всегда присутствуют в канонической ссылке (при их наличии).

### Путь

`Доступность: Клиент` `ТолькоЧтение`

```
Путь: Строка
```

Путь публикации данного приложения. Должен содержать один сегмент пути, или пустую строку. Не должен содержать следующие зарезервированные пути:

- api
- stdapi
- sys
- ui Если содержит пустую строку, то вход в приложение является точкой публикации приложения. Если путь указан, то путь публикации приложения плюс указанный путь.

---

### РежимАутентификации

`Доступность: Клиент` `ТолькоЧтение`

```
РежимАутентификации: РежимАутентификации
```

Указывает нужна ли аутентификация при входе в приложение. Если аутентификация нужна, то пользователь автоматически будет перенаправлен на страницу аутентификации. Если указан режим без аутентификации, то это означает что может работать и анонимный пользователь.

## Методы

### ДобавитьВИсториюПереходов

`Доступность: Клиент`

```
ДобавитьВИсториюПереходов(СостояниеПерехода: Строка)
```

Добавляет в историю переходов состояние при переходе на другой экран. На текущий момент делается запись в историю браузера, и переданное значение добавляется в параметр браузерной строки.

`СостояниеПерехода`

- некоторая строка, идентифицирующая состояние перехода.

---

### ЗаменитьВИсторииПереходов

`Доступность: Клиент`

```
ЗаменитьВИсторииПереходов(СостояниеПерехода: Строка)
```

Замещает текущее состояние без создания новой записи в истории переходов.

`СостояниеПерехода`

- некоторая строка, идентифицирующая состояние перехода.

---

### ПолучитьОтносительныйПуть

`Доступность: Клиент`

```
ПолучитьОтносительныйПуть(Ссылка: Строка): Строка?
```

Принимает ссылку в виде строки, удаляет из нее адрес приложения и возвращает относительный путь. Например, для строки

`http://localhost:9090/applications/TestApp/SomeUrl`

вернет

`SomeUrl`

. Если ссылка не является ссылкой на приложение, то метод вернет

`Неопределенно`

.

---

### ПолучитьСостояниеПерехода

`Доступность: Клиент`

```
ПолучитьСостояниеПерехода(): Строка
```

Возвращает текущее состояние перехода.

---

### ПолучитьТекущуюЦветовуюСхему

`Доступность: Клиент`

```
ПолучитьТекущуюЦветовуюСхему(): ЦветоваяСхема
```

Возвращает текущую цветовую схему приложения. Возвращаемое значение может отличаться от заданного в свойстве

[ЦветоваяСхема](designtheme-ru-fd772ce038a8.md)

: если значение равно Авто, то цветовая схема пытается определиться автоматически в зависимости от настроек устройства.
