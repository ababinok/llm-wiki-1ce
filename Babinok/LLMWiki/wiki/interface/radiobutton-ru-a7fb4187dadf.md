## Обзор

ТипДанных: Тип значения радиокнопки.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::РадиоКнопка<ТипДанных>` `Доступность: Клиент`

ТипДанных: Тип значения радиокнопки. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент предназначен для реализации сценария выбора из двух и более различных значений. Каждый компонент радиокнопки представляет отдельный пункт выбора. Для обеспечения множественности значений необходимо использовать два или более компонента радиокнопки, у которых значения свойства [ЗначениеВыбора](radiobutton-ru-a7fb4187dadf.md) различны, а свойство [Значение](radiobutton-ru-a7fb4187dadf.md) привязано к одним и тем же данным. Для того чтобы объединить несколько радиокнопок в одну группу выбора, необходимо указать каждой радиокнопке такой группы одинаковое значение свойства [РадиоГруппа](radiobutton-ru-a7fb4187dadf.md).

---

### ЗначениеВыбора

`Доступность: Клиент`

```
ЗначениеВыбора: ТипДанных
```

Значение, связанное с данной радиокнопкой. При выборе радиокнопки пользователем оно будет записано в данные, на которые указывает свойство [Значение](radiobutton-ru-a7fb4187dadf.md). Таким образом, если [Значение](radiobutton-ru-a7fb4187dadf.md) = [ЗначениеВыбора](radiobutton-ru-a7fb4187dadf.md), то радиокнопка является выбранной.
