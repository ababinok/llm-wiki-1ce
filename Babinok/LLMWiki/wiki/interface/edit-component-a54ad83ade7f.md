## Примеры

### Создание поля ввода со множественным выбором

Поле ввода со множественным выбором представляет собой прокручиваемый список вариантов с флажками. Пользователь делает выбор, устанавливая или снимая флажки для нужных элементов списка. В начале списка отображается поле для поиска и фильтрации значений списка.

Поле множественного выбора: сверху поиск, ниже варианты с флажками; выбранные значения отображаются в поле как отдельные элементы. [Описание иллюстрации](../../raw/figures/33b33ddd5bf4ed1d217ca2995a698f86c69f386bcf6cd868170cb1a00ed0e625-a568bf895de2ee17.md)

Для включения режима множественного выбора задайте тип данных для поля ввода как `Массив<Тип>`, например `ПолеВвода<Массив<Строка>>`.

Множественный выбор также поддерживается для следующих типов и их объединений:

- `{ИмяСущности}.Ссылка`
  
  ;
- `{ИмяКонтрактаСущности}.Ссылка`
  
  ;
- `Перечисление`
  
  .

#### Использование элементов «Перечисление» и «Справочник»

Чтобы использовать [перечисление](../project/fixed-set-of-values-8517518057de.md) и/или [справочник](../data/catalog-project-element-b6ca52d114d4.md) в качестве источников данных для элементов списка, задайте свойство **Тип** для поля ввода следующим образом:

- для справочника —
  
  `ПолеВвода<ИмяСправочника.Ссылка?>`
  
  ,
- для перечисления —
  
  `ПолеВвода<ИмяПеречисления?>`
  
  ,
- для справочника и перечисления —
  
  `ПолеВвода<ИмяПеречисления|ИмяСправочника.Ссылка|?>`
  
  .

В примере ниже показано, как может выглядеть описание формы с полем выбора языков программирования, изображенным на рисунке выше.

### Использование маски

Частой задачей при работе с полем ввода является необходимость ограничить формат вводимых данных. Например, номер телефона должен соответствовать определенному шаблону, а код подтверждения — содержать только допустимые символы и быть строго определенной длины. Для решения таких задач применяются маски ввода, которые позволяют задать требуемый формат и упростить ввод данных для пользователя.

Маски могут быть двух типов: фиксированные и динамические.

- Фиксированные маски имеют определенную длину строки и могут быть однозначно разделены на символы.
- Динамические маски имеют неопределенную длину строки или не могут быть однозначно разделены на символы.

| Маска | Тип маски | Описание |
| --- | --- | --- |
| `\ц{2}:\ц{2}` | Фиксированная | Фиксированная длина, маска может быть однозначно разделена на символы |
| `\ц{1,}` | Динамическая | Неопределенная длина не менее 1 символа |
| `\ц{1,2}` | Динамическая | Неопределенная длина от 1 до 2 символов |
| `\ц-\ц` | Фиксированная | Фиксированная длина, маска может быть однозначно разделена на символы |
| `(\ц-)?\ц` | Динамическая | Неопределенная длина в 1 или 3 символа |
| `(\+7\|8)\(\ц{3}\)\ц{3}(-\ц{2}){2}` | Динамическая | Неопределенная длина из-за выбора первой части маски: `+7` или `8` |
| `\+7\(\ц{3}\)\ц{3}-\ц{2}-\ц{2}` | Фиксированная | Фиксированная длина, маска может быть однозначно разделена на символы |

Маски всегда интерпретируются с учетом якорей начала и конца строки (символы `^` и `$`). Если якоря не указаны явно, они будут добавлены автоматически. Например, все перечисленные маски эквиваленты: `\ц+`, `^\ц+`, `\ц+$`, `^\ц+$`.

> [!NOTE] дополнительно
> В текущей версии использование масок доступно только для полей ввода, принимающих тип `Строка`.

Для настройки маски вы можете использовать свойства **Маска** и **ЗамещающийСимволМаски** из группы свойств [НастройкиВводаСтроки](edit-ru-4027d1cb7b27.md):

- Маска
  
  задается типом
  
  [`Образец`](../stdlib/pattern-ru-4e0ef31a791c.md)
  
  и определяет формат вводимой строки.
- ЗамещающийСимволМаски
  
  задается типом
  
  [`Строка`](../stdlib/string-ru-1bac645acacf.md)
  
  и устанавливает символ, которым заполняются пустые места в маске до ввода пользователем значения. Свойство применяется только к фиксированным маскам.

В примере ниже показано, как может выглядеть описание формы с полем ввода номера телефона, использующим маску `\+7\(\ц{3}\)\ц{3}-\ц{2}-\ц{2}`.

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: b8d5bdf5-7efe-4d2f-92c3-e1cfb9ead423
Имя: ФормаСПолемВводаТелефона
ОбластьВидимости: ВПодсистеме
Наследует:
    Тип: Форма
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Имя: ШаблонФормы
        Содержимое:
            Тип: Группа
            Имя: Группа
            Содержимое:
                -
                    Тип: ПолеВвода<Строка?>
                    Имя: ПолеВводаТелефона
                    Заголовок: Телефон
                    НастройкиВводаСтроки:
                        Маска: ='\+7\(\ц{3}\)\ц{3}-\ц{2}-\ц{2}'
```

Данная маска является фиксированной и для нее не установлено значение свойства **ЗамещающийСимволМаски** — пустые части маски будут заполнены символом подчеркивания `_`. В интерфейсе приложения такое поле ввода будет выглядеть следующим образом:

Поле номера телефона с фиксированной маской +7: незаполненные позиции внутри скобок и после разделителей показаны подчёркиваниями. [Описание иллюстрации](../../raw/figures/3ffad78ea92db7b2f5b80a7e049876c798356fed95d1a47209e314e9917be50c-63bb7d3058f281c2.md)

Вы можете задать значение свойства **ЗамещающийСимволМаски** в панели свойств, чтобы определить свой формат замещающего символа. Например, так будет выглядеть поле ввода из примера выше, если задать значение свойства символом `Х`:

Поле телефона с маской показывает +7(XXX)XXX-XX-XX: незаполненные позиции маски заменены заданным символом X. [Описание иллюстрации](../../raw/figures/e88445af71ca5c02c006e8278bf039359d6db9aec3a06621d980b26ca7f65223-36cec13b66f688dc.md)
