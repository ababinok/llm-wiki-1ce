## Обзор

## Документированный контракт и примеры

Компонент интерфейса **КанбанДоска** — это визуальный инструмент представления данных, который помогает организовать работу с информацией. Доска состоит из *колонок*, представляющих состояния, этапы или любые другие категории, по которым распределяются данные, и *свимлайнов* — горизонтальных секций, разделяющих колонки по дополнительным признакам: направлениям, приоритетам, ответственным и т. д. Данные отображаются в виде карточек, которые перемещаются между колонками при изменении их состояния.

Канбан-доска упрощает работу с большими объемами информации за счет следующих возможностей:

- визуальное представление процесса работы,
- группировка связанных данных,
- быстрая идентификация приоритетных элементов,
- выявление блокирующих элементов,
- отображение агрегированной статистики по группам.

Канбан-доска содержит три колонки «Новые» (9), «В работе» (10), «Готово» (5), сверху каждой — агрегаты количества и трудоемкости. [Описание иллюстрации](../../raw/figures/68486823e86412f2f70c51c05efa272499f15b91d2579d30d359e54b75d1b3e4-c0a6dc8d19914341.md)

## Добавление канбан-доски

Рассмотрим пример использования канбан-доски для управления задачами в интерфейсе приложения. Аналогичным образом канбан-доска может использоваться для работы с любыми данными, которые удобно представить в виде набора состояний: заявками, этапами сделок, карточками товаров и т. д.

  - Блокер
    
    — элемент блокирует работу других элементов,
  - Критический
    
    — наивысший приоритет,
  - Серьезный
    
    — высокий приоритет,
  - Незначительный
    
    — низкий приоритет,
  - Тривиальный
    
    — минимальный приоритет.

1. Создайте [форму](form-component-975c31cd89e9.md) с именем **ФормаДоскиЗадач**, которая будет отображать данные о задачах с помощью канбан-доски.
2. В [редакторе компонентов интерфейса](ide-overview-and-basic-actions-969a6e6501a6.md) формы добавьте шаблон формы и поместите в него компонент **КанбанДоска** с именем **КанбанДоскаЗадач**.

В редакторе формы через поиск компонентов выбран «КанбанДоска»; рядом доступны стандартная и произвольная канбан-карточки. [Описание иллюстрации](../../raw/figures/f72b7b05829dd8c1a4aae608036ee74e344e1a53229ab1342026380cf346a9aa-40ad77ab16c825fd.md)

1. В свойствах компонента установите в качестве источника данных таблицу документа **Задачи**. Имя типа данных строки — **ДанныеСтрокиКанбанДоскаЗадач**. Добавьте в динамический список все поля документа, которые должны быть доступны в карточке: **Дата**, **Номер**, **Статус**, **Приоритет**, **Исполнитель**, **Трудоемкость**, **Наименование**, **Код**, **Исполнитель.Аватар**.
2. Задайте параметры обобщенного типа `КанбанДоска`. Канбан-доска параметризуется тремя типами, которые задаются в свойствах компонента:
  
  - `ТипЗначенияКолонки = СтатусыЗадач.Ссылка?`
    
    — по статусу задачи карточка автоматически распределяется по колонкам.
  - `ТипЗначенияСвимлайна = Приоритет?`
    
    — по приоритету задачи карточка автоматически распределяется по свимлайнам.
  - `ТипИсточника`
    
    — задается автоматически на основе указанного источника данных. В качестве аргументов могут быть использованы типы
    
    [`ДинамическийСписок`](dynamiclist-ru-ab61b0be4de4.md)
    
    или
    
    [`ИсточникДанныхМассив`](arraydatasource-ru-2842d399ff6f.md)
    
    .
3. Добавьте [колонки](kanbanboard-ru-b1a0abc5e350.md) с заголовками (**Новые**, **В работе**, **Готово**) и изображениями. Одна колонка может объединять несколько статусов. Соответствие колонки конкретным статусам настраивается через свойство **Значения** колонки.
4. Настройте распределение карточек по колонкам. Свойство **ЗначениеКолонки** определяет, по какому полю карточка попадает в ту или иную колонку. Установите значение `=ДанныеСтроки.Данные.Статус` — тогда карточки автоматически распределяются по колонкам в зависимости от статуса задачи.
5. В [редакторе компонентов интерфейса](ide-overview-and-basic-actions-969a6e6501a6.md) добавьте для канбан-доски компонент **СтандартнаяКанбанКарточка** — он будет использоваться как шаблон для отображения информации о задаче. Настройка свойств карточки описана в разделе [Отображение информации в стандартной канбан-карточке](kanban-board-e9a1a24f61cd.md).

### Заполнение канбан-доски данными

Чтобы на канбан-доске появились карточки, нужно заполнить справочники **СтатусыЗадач** и **Исполнители**, а также создать задачи. Это можно сделать двумя способами — вручную через интерфейс приложения или с помощью программного заполнения демо-данными.

## Отображение информации в стандартной канбан-карточке

**СтандартнаяКанбанКарточка** — это шаблон отображения одной записи на канбан-доске. Свойства компонента задают, какая информация показывается на карточке.

Пример стандартной канбан-карточки [Описание иллюстрации](../../raw/figures/963c4543d343323b566819f54040db9f7068e3f359bb782c080308cbd3cde3d2-df0d9aaeb7688cf7.md)

Можно не задавать часть свойств — карточка все равно будет отображаться. Для удобной работы рекомендуется настроить хотя бы заголовок и код.

### Свойства карточки

Свойства карточки, которые будут заполнены в примере, представлены в таблице:

| Свойство | Выражение | Что отображает |
| --- | --- | --- |
| **Заголовок** | `=ДанныеСтроки.Данные.Наименование` | Описание задачи. |
| **Изображение заголовка** | `=ПолучитьИконкуЗадачи(ДанныеСтроки)` | Иконка в зависимости от приоритета. |
| **Код** | `=ДанныеСтроки.Данные.Код` | Уникальный идентификатор задачи. |
| **Исполнитель** | `=ПолучитьИсполнителя(ДанныеСтроки)` | Сотрудник с аватаром. |
| **Счетчики** | `=ПолучитьСчетчикиКарточки(ДанныеСтроки)` | Метрики задачи. |
| **Теги** | `=ПолучитьТеги(ДанныеСтроки)` | Специальные отметки. |

Методы, используемые в вычисляемых выражениях, реализуются в модуле формы **ФормаДоскиЗадач**.

[Список всех свойств компонента «СтандартнаяКанбанКарточка»](standardkanbancard-ru-06d7324bf021.md)

### Заголовок

Свойство **Заголовок** используется для отображения названия задачи. Значение берется из реквизита **Наименование** документа **Задачи**. Заголовок — основной идентификатор карточки, по которому пользователь быстро находит нужную задачу.

Карточка задачи на канбан-доске: заголовок содержит название задачи; рядом находятся дополнительные признаки, метки и приоритет. [Описание иллюстрации](../../raw/figures/3a5d1396e731eddabb5082df9ab3102344cb0756f4a2f7b5762ab5a11a486fea-4fea665c7532a90f.md)

### Изображение заголовка

Свойство **Изображение заголовка** используется для отображения иконки в верхней части карточки. Иконка зависит от приоритета задачи: для каждого значения приоритета возвращается свое изображение из ресурсов проекта. Это позволяет пользователю быстро определить важность задачи, не читая заголовок.

Слева от заголовка канбан-карточки выделен красный треугольник с восклицательным знаком. [Описание иллюстрации](../../raw/figures/6b1dc439b2956f966358d9f2c4bd08cfc559638d50622ad0376e93aaabcdca49-b2a2c7d50b38926b.md)

Метод `ПолучитьИконкуЗадачи()` возвращает изображение из ресурсов проекта в зависимости от приоритета задачи. Для каждого известного приоритета возвращается своя иконка.

```xbsl
метод ПолучитьИконкуЗадачи(
        ДанныеСтроки: СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>): Url|ДвоичныйОбъект.Ссылка|?
    
    если ДанныеСтроки.Данные.Приоритет == Неопределено 
        возврат Ресурс{БезПриоритета.png}.Ссылка
    ;
        
    выбор ДанныеСтроки.Данные.Приоритет.Представление()
    когда "Блокер"
        возврат Ресурс{Блокер.png}.Ссылка
    когда "Критический"
        возврат Ресурс{Критический.png}.Ссылка
    когда "Серьезный"
        возврат Ресурс{Серьезный.png}.Ссылка
    когда "Незначительный"
        возврат Ресурс{Незначительный.png}.Ссылка
    иначе
        возврат Ресурс{Тривиальный.png}.Ссылка
    ;
;
```

### Код

Свойство **Код** используется для отображения уникального идентификатора задачи. Значение берется из реквизита **Код** документа **Задачи**. Код применяется, когда нужно однозначно сослаться на задачу — например, при обсуждении в команде или поиске.

В канбан-карточке рядом с пиктограммой приоритета показан уникальный код задачи DEV-AUTH-043; ниже расположены заголовок, метки и дополнительная информация карточки. [Описание иллюстрации](../../raw/figures/f79c7476bc854b381bd5befa118b7b9f1ce63570a268d75eb45a1ff2275e326b-96c6e68a3af428fe.md)

### Исполнитель

Свойство **Исполнитель** используется для отображения сотрудника, ответственного за задачу.

Область исполнителя с аватаром и именем [Описание иллюстрации](../../raw/figures/93de672215fa9a3fe3de92f2df042f6532e5942c77351cd2503cfe1df5c88848-f5b6fb1a8c47dff3.md)

Метод `ПолучитьИсполнителя()` возвращает элемент списка значений с именем и аватаром сотрудника. Если исполнитель не назначен, возвращается `Неопределено`.

```xbsl
метод ПолучитьИсполнителя(
        ДанныеСтроки: СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>): ЭлементСпискаЗначений<Строка>?

        ДанныеСтроки.Данные.АватарИсполнителя как ДвоичныйОбъект.Ссылка?
    )
;
```

### Счетчики

Свойство **Счетчики** используется для отображения метрик задачи. В примере на карточке показывается срок давности задачи — сколько времени прошло с момента ее создания.

Канбан-карточка задачи показывает ключ DEV-AUTH-043, название, теги DEV и AUTH, аватар и счётчик времени «24д 19ч 07м» со значком календаря. [Описание иллюстрации](../../raw/figures/0b7a32d4a177eb4f370d02f9ae9475028c20df53b8dbd43bf358a55b03a4fc42-fb06c57339148d0f.md)

Метод `ПолучитьСчетчикиКарточки()` вычисляет срок давности задачи — разницу между текущим моментом и датой создания задачи — и возвращает ее в виде массива с одним элементом. Формат меняется автоматически: меньше суток — `ЧЧ'ч 'мм'м'`, от суток и больше — `д'д 'ЧЧ'ч 'мм'м'`. Дополнительно передается иконка календаря и описание `В работе`.

```xbsl
метод ПолучитьСчетчикиКарточки(
        ДанныеСтроки: СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>): Массив<ЭлементСпискаЗначений<Строка>>?

    знч Сейчас = ДатаВремя.Сейчас()
    знч Длительность = Сейчас - ДанныеСтроки.Данные.Дата

    // Округляем вниз до дней — чтобы выбрать формат
    знч Дней = Длительность.Дни

    пер Формат: Строка
    если Дней >= 1
        Формат = "д'д 'ЧЧ'ч 'мм'м'" // 5д 12ч 30м
    иначе
        Формат = "ЧЧ'ч 'мм'м'"      // 12ч 30м
     
    ;
    знч Результат: Массив<ЭлементСпискаЗначений<Строка>> = [новый ЭлементСпискаЗначений<Строка>(
                Значение = Длительность.Представление(Формат),
                Описание = "В работе",
                ИзображениеНеактивного = Ресурс{Календарь.svg}.Ссылка)]
    возврат Результат
;
```

### Теги

Свойство **Теги** используется для отображения категорий задач.

Теги задачи [Описание иллюстрации](../../raw/figures/b29c685d9f9f9ff55e61bf9c8c488e2b96c8747bbb7353bf9a822b42dae275ab-67255eb1dbfe6a80.md)

Метод `ПолучитьТеги()` извлекает теги из кода задачи. Префикс до первого дефиса становится тегом категории (`UI`, `DEV`), а часть между первым и вторым дефисом — тегом компонента (`ADAPT`, `API`, `AUTH`). Так задачи автоматически категоризируются по структуре их кода.

Каждый тег возвращается как элемент типа [`ЭлементСпискаЗначений`](valuelistitem-ru-c68a213e54f6.md), у которого задается **цвет** — это позволяет визуально различать категории задач прямо на карточке без дополнительной стилизации в шаблоне.

```xbsl
метод ПолучитьТеги(
        ДанныеСтроки: СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>): Массив<ЭлементСпискаЗначений<Строка>>?

    знч Теги: Массив<ЭлементСпискаЗначений<Строка>> = []
    знч Код = ДанныеСтроки.Данные.Код
    если Код.НачинаетсяС("UI-")
        Теги.Добавить(новый ЭлементСпискаЗначений<Строка>(
                Значение = "UI",
                Представление = "UI",
                Цвет = Цвета.Фиолетовый))
    иначе если Код.НачинаетсяС("DEV-")
        Теги.Добавить(новый ЭлементСпискаЗначений<Строка>(
                Значение = "DEV",
                Представление = "DEV",
                Цвет = Цвета.Зеленый))
    ;
    знч Части = Код.Разделить("-")
    если Части.Размер() >= 2
        Теги.Добавить(новый ЭлементСпискаЗначений<Строка>(
                Значение = Части[1],
                Представление = Части[1],
                Цвет = Цвета.Голубой))
    ;
    если Теги.Размер() == 0
        возврат Неопределено
    ;
    возврат Теги
;
```

## Добавление свимлайнов

Свимлайны используются для дополнительного разделения канбан-доски на горизонтальные области: по функциональным зонам, приоритетам, командам или любому другому признаку.

Канбан-доска со свимлайнами: колонки состояний сохраняются, а карточки дополнительно разделены горизонтальными секциями с отдельными заголовками и счётчиками. [Описание иллюстрации](../../raw/figures/51c8c9880d9f610b5dae709ae1f63962109fe66d2c5f363be3dec441f81ac22a-bbf2df3145e55270.md)

Свимлайны в примере группируют задачи по приоритету:

- Критические и важные задачи
  
  — задачи с приоритетом
  
  `Критический`
  
  или
  
  `Серьезный`
  
  . Лимит — 10 карточек.
- Блокирующие задачи
  
  — задачи с приоритетом
  
  `Блокер`
  
  . Лимит — 5 карточек.
- Остальные задачи
  
  — задачи с приоритетом
  
  `Незначительный`
  
  или
  
  `Тривиальный`
  
  . Лимит не задан.

Чтобы настроить свимлайны:

1. Задайте свойство **ЗначениеСвимлайна** с помощью вычисляемого выражения `ДанныеСтроки.Данные.Приоритет`.
2. Добавьте элемент в группу свойств **Свимлайны**.
3. Задайте свойство **Заголовок** — текст, который отображается в интерфейсе.
4. Задайте свойство **Значение** — массив значений, по которым фильтруются задачи в данном свимлайне.
5. Задайте свойство **ЛимитКарточек** — счетчик, который отображается справа от заголовка.
  
  

Выполните настройку для каждой группы задач, или задайте свимлайны с помощью программного кода:

1. Задайте свойство **ЗначениеСвимлайна** с помощью вычисляемого выражения `ДанныеСтроки.Данные.Приоритет`.
2. Задайте свойство **Свимлайны** канбан-доски с помощью вычисляемого выражения `ПолучитьСвимлайны()`.
3. В модуле формы добавьте реализацию метода:
  
  ```xbsl
  метод ПолучитьСвимлайны(): Массив<КанбанСвимлайн<Приоритет?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>>
      знч Свимлайны = новый Массив<КанбанСвимлайн<Приоритет?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>>()
      
      пер Свимлайн = новый КанбанСвимлайн<Приоритет?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>()
      // Текст, который отображается в интерфейсе
      Свимлайн.Заголовок = "Критические и важные задачи"
      // Свойство, которое фильтрует задачи по значениям параметра ТипЗначенияСвимлайна
      Свимлайн.Значения = [Приоритет.Критический, Приоритет.Серьезный]
      // Счетчик, который отображается справа от заголовка
      Свимлайн.ЛимитКарточек = 10
      Свимлайны.Добавить(Свимлайн)
      
      Свимлайн = новый КанбанСвимлайн<Приоритет?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>()
      Свимлайн.Заголовок = "Блокирующие задачи"
      Свимлайн.Значения = [Приоритет.Блокер]
      Свимлайн.ЛимитКарточек = 5
      Свимлайны.Добавить(Свимлайн)
      
      Свимлайн = новый КанбанСвимлайн<Приоритет?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>()
      Свимлайн.Заголовок = "Остальные задачи"
      Свимлайн.Значения = []
      Свимлайны.Добавить(Свимлайн)
      
      возврат Свимлайны
  ;
  ```
  
  Обратите внимание, объект `КанбанСвимлайн` доступен только в окружении **Клиент**, поэтому метод `ПолучитьСвимлайны` должен быть клиентским методом формы. У типа `КанбанСвимлайн` нет конструктора с параметрами — для задания свойств свимлайна нужно использовать присваивание свойствам созданного объекта, как в примере выше.

Такая настройка свимлайнов позволяет визуально разделить задачи по их приоритету, а лимиты карточек помогают контролировать загрузку команды — например, чтобы блокирующих задач накапливалось не больше пяти, и команда могла вовремя среагировать на блокеры.

## Сбор статистики по задачам

В заголовках канбан-доски доступно отображение статистики для каждой колонки. Для этого предназначено свойство **СтатистикаКолонки**. Рассмотрим, как добавить сбор и отображение статистики.

1. Задайте свойство **СтатистикаКолонки** в панели свойств, добавив в него три дочерних элемента.
2. Настройте получение статистики по количеству задач в колонке, установив свойства:
  
  - Значение
    
    как вычисляемое выражение
    
    `Колонка.ПолучитьКарточки().Размер().Представление()`
    
    ,
  - Представление
    
    —
    
    `Задачи`
    
    ,
  - Описание
    
    —
    
    `Количество задач`
    
    .
  
  Свойство «СтатистикаКолонки»: вычисляемое значение подсчитывает размер коллекции карточек колонки и получает его представление; представление статистики — «Задачи», описание — «Количество задач». [Описание иллюстрации](../../raw/figures/530fc45b57172413a85efc68e5a9deeffbd3ff610cd66fdcdadb2783661410aa-4f08280b118c241c.md)
3. Для получения трудоемкости задайте свойства:
  
  - Значение
    
    как вычисляемое выражение
    
    `ПолучитьТрудоемкость(Колонка)`
    
    ,
  - Представление
    
    —
    
    `Трудоемкость`
    
    ,
  - Описание
    
    —
    
    `Общая трудоемкость задач`
    
    .
4. Для определения количества блокирующих задач:
  
  - Значение
    
    как вычисляемое выражение
    
    `ПолучитьБлокеры(Колонка)`
    
    ,
  - Представление
    
    —
    
    `Блокеров`
    
    ,
  - Описание
    
    —
    
    `Количество блокирующих работу задач`
    
    .
5. Добавьте реализацию методов получения статистики в модуль формы:
  
  ```xbsl
  метод ПолучитьТрудоемкость(
          Колонка: КанбанКолонка<СтатусыЗадач.Ссылка?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>): Строка
  
      возврат Колонка.ПолучитьКарточки()
          .Преобразовать(Карточка -> Карточка.ДанныеСтроки.Данные.Трудоемкость)
          .Свернуть((А, Б) -> А + Б)
          .Представление()
  ;
  
  метод ПолучитьБлокеры(
          Колонка: КанбанКолонка<СтатусыЗадач.Ссылка?, СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>>): Строка
  
      возврат Колонка.ПолучитьКарточки()
          .Фильтровать(Карточка -> Карточка.ДанныеСтроки.Данные.Приоритет == Приоритет.Блокер)
          .Размер()
          .Представление()
  ;
  ```

Вверху каждой колонки канбан-доски показана статистика: количество карточек и количество вложенных задач; счётчики относятся к соответствующему состоянию колонки. [Описание иллюстрации](../../raw/figures/dca61a0730c8864ba590d6293d0ca1e860a376d1f0b7c6f968d520fb3e45f36f-8ce7db3a313bc3f2.md)

## Обработка перетаскивания

Канбан-доска позволяет перетаскивать карточки между колонками и свимлайнами для быстрого изменения статуса и приоритета задачи прямо в интерфейсе. При перетаскивании карточки вызывается событие `ПриОкончанииПеретаскивания()`, в обработчике которого реализуется логика обновления данных и синхронизация интерфейса с актуальным состоянием задач.

Для реализации перетаскивания и изменения статуса выполните следующие действия:

1. Добавьте код в модуль документа **Задачи** для обработки изменений статуса и приоритета:
  
  ```xbsl
  @ВПодсистеме
  @НаСервере @ДоступноСКлиента
  метод Изменить(Задача: Задачи.Ссылка, НовыйСтатус: СтатусыЗадач.Ссылка, НовыйПриоритет: Приоритет?)
      исп Транзакции.Начать()
      знч ЗадачаОбъект = Задача.ЗагрузитьОбъект(Заблокировать = Истина)
      если ЗадачаОбъект == Неопределено
          выбросить новый ИсключениеНедопустимоеСостояние("Задача уже удалена.")
      ;
      
      ЗадачаОбъект.Статус = НовыйСтатус
      если НовыйПриоритет != Неопределено
          ЗадачаОбъект.Приоритет = НовыйПриоритет
      ;
  
      ЗадачаОбъект.Записать()
  ;
  ```
2. Добавьте обработчик события **ПриОкончанииПеретаскивания** компонента **КанбанДоскаЗадач** в панели свойств.
3. Реализуйте добавленный обработчик в модуле формы:
  
  ```xbsl
  метод КанбанДоскаЗадачПриОкончанииПеретаскивания(
          Источник: КанбанДоска<ДинамическийСписок<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>, СтатусыЗадач.Ссылка?, Приоритет?>,
          Событие: СобытиеПриОкончанииПеретаскиванияКанбана<СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>, СтатусыЗадач.Ссылка?, Приоритет?>)
  
      знч ДанныеПеретаскивания = Событие.ДанныеПеретаскивания.Первый()
      знч Задача = (ДанныеПеретаскивания как СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиКанбанДоскаЗадач>).Ключ
      знч НовыйСтатус = Событие.Колонка.Значения.Первый()
  
      пер НовыйПриоритет: Приоритет?
      если Событие.Свимлайн != Неопределено и не Событие.Свимлайн.Значения.Пусто()
          НовыйПриоритет = Событие.Свимлайн.Значения.Первый()
      ;
  
      попытка
          Задачи.Изменить(Задача, НовыйСтатус, НовыйПриоритет)
      поймать Исключение: Исключение
          Источник.Обновить()
          выбросить Исключение
      ;
  ;
  ```
