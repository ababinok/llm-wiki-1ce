## Свойства

### Иконка

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Иконка
```

Отображает заголовок в виде иконки (картинки). Если иконка не задана – отображается системная иконка.

---

### ИконкаИТекст

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ИконкаИТекст
```

Отображает заголовок в виде текста и иконки (картинки). Если иконка не задана – будет отображен только заголовок. Если заголовок не задан – будет отрисована только иконка. Если не задано ни то, ни другое – стандартная иконка.

---

### Текст

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Текст
```

Отображает заголовок в виде текста.
