## Обзор

Специальный тип, который генерируется для каждого пользовательского компонента, содержит только контекстные свойства.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяКомпонента}.Контекст` `Доступность: Сервер`

Специальный тип, который генерируется для каждого пользовательского компонента, содержит только контекстные свойства. Тип генерируется всегда, безусловно, независимо от того есть ли у него контекстные свойства или нет. В описании свойства компонента интерфейса существует признак Контекстное, тип [Булево](../stdlib/boolean-ru-7823d4239bcc.md), значение по умолчанию `Ложь`. Свойство помеченное как Контекстное, обязано иметь тип доступный на клиенте и сервере. У пользовательского компонента появляется возможность описывать собственные серверные нестатические методы, помеченные аннотацией [Контекстный](../stdlib/contextual-ru-468258bf9c74.md). Эта возможность доступна только в модулях пользовательских компонентов. В теле серверного метода, помеченного аннотацией [Контекстный](../stdlib/contextual-ru-468258bf9c74.md), тип объекта этот будет заменен с [ИмяКомпонента](componentname-ru-ca3fcf138ae8.md) на [ИмяКомпонента.Контекст](componentname-context-ru-e40a3f370a75.md). Состояние этого объекта будет передаваться с клиента на сервер при каждом вызове этого метода с клиента. На сервере, в теле метода, можно изменять состояние этого объекта, затем оно автоматически будет доставлено на клиент и клиенсткий компонент, для которого был вызван этот метод; будет переинициализирован из этого состояния.

## Примеры

**Общие примеры**

```yaml
Имя: ИмяКомпонента 
Свойства:       
    -
        Имя: КонтекстноеСвойство
        Тип: Строка
        Контекстное: Истина
```

```xbsl
@НаСервере @ДоступноСКлиента @Контекстный
метод КонтекстныйМетодДоступныйСКлиента()
    этот.ПолучитьТип()          // ИмяКомпонента.Контекст
    КонтекстноеСвойство = "123" // Контекстное свойство доступно в серверном окружении
    СерверныйКонтекстныйМетод() // из контекстного метода можно вызвать другой контекстный метод. 
;

@НаСервере @Контекстный
метод СерверныйКонтекстныйМетод()
    этот.ПолучитьТип()          // ИмяКомпонента.Контекст
    КонтекстноеСвойство = "456" // Контекстное свойство доступно в серверном окружении
;
```
