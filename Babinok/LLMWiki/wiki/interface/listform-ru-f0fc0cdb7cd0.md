Имена для поиска: `ФормаСписка`, `ListForm`, `Стд::Интерфейс::Формы::ФормаСписка<ТипРезультата>`, `Std::Interface::Forms::ListForm`.

## Обзор

ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне.

## Документированный контракт и примеры

`Стд::Интерфейс::Формы::ФормаСписка<ТипРезультата>` `Доступность: Клиент`

ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](form-ru-89fb5e7eaeb3.md) без передачи аргумента, в качестве результата открытия возвращается `Неопределено`.

Форма списка. Содержит стандартные функции для работы со списками сущностей. Тип сущности определяется по значению свойства [ОсновнаяТаблица](dynamiclist-ru-ab61b0be4de4.md) источника данных динамического списка основной таблицы формы.

**Сравнение**

Ссылочное
