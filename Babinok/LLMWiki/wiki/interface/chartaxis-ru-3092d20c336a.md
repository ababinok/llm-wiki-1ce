## Обзор

Описывает модель оси для XY-диаграмм.

## Документированный контракт и примеры

`Стд::Интерфейс::Диаграммы::ОсьДиаграммы` `Доступность: КлиентИСервер`

Описывает модель оси для XY-диаграмм.

## Свойства

### Заголовок

`Доступность: КлиентИСервер`

```
Заголовок: Строка
```

Задает заголовок оси.

---

### ИнвертироватьРасположение

`Доступность: КлиентИСервер`

```
ИнвертироватьРасположение: Авто|Булево
```

Определяет, следует ли отображать ось на противоположной стороне области графика.

Прошлые имена: ИнвертироватьРасположение

---

### Отображать

`Доступность: КлиентИСервер`

```
Отображать: Авто|Булево
```

Определяет, отображается ли ось на диаграмме.
