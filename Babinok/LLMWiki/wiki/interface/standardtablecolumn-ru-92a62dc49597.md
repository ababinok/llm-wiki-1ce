## Обзор

ТипДанных: тип данных строки колонки таблицы ТипЗначения: тип значения непосредственно колонки таблицы

## Документированный контракт и примеры

`Стд::Интерфейс::Списки::СтандартнаяКолонкаТаблицы<ТипДанных,ТипЗначения>` `Доступность: Клиент`

ТипДанных: тип данных строки колонки таблицы ТипЗначения: тип значения непосредственно колонки таблицы

Используется для описания колонок таблицы, отображающих стандартные типы данных.

## Свойства

### Вид

`Доступность: Клиент`

```
Вид: Авто|ВидКолонкиТаблицы
```

Задает вид отображения данных ячейки. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - вид зависит от типа данных, отображаемых колонкой:

- [ДвоичныйОбъект.Ссылка](../data/binaryobject-reference-ru-295ba5edda1a.md)
  
  - используется вид
  
  [Картинка](tablecolumnkind-ru-ce1102fede2f.md)
  
  ,
- [Булево](../stdlib/boolean-ru-7823d4239bcc.md)
  
  - используется вид компонента
  
  [Флажок](checkbox-ru-2596f521fb30.md)
  
  вида
  
  [Переключатель](checkboxkind-ru-34ba79b88af9.md)
  
  ,
- Массив, перечисление - используется вид
  
  [Теги](tablecolumnkind-ru-ce1102fede2f.md)
- Остальное - используется вид
  
  [Текст](tablecolumnkind-ru-ce1102fede2f.md)
  
  .

### Значение

`Доступность: Клиент`

```
Значение: ТипЗначения
```

Задаёт значение, отображаемое колонкой таблицы.

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Задает картинку в ячейке. Если не указано, но при этом [Вид](standardtablecolumn-ru-92a62dc49597.md) = [Картинка](tablecolumnkind-ru-ce1102fede2f.md), то будет отображаться картинка из данных, заданных в свойстве [ПолеЗначения](tablecolumn-ru-90496d65cde5.md).

---

### Изображение

`Версия 8.0 и ниже`

> **Исторический контракт:** верхняя граница версии 8.0; не используйте этот член для 10.0.


`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](standardtablecolumn-ru-92a62dc49597.md).

### МаксимальнаяВысотаВСтроках

`Доступность: Клиент`

```
МаксимальнаяВысотаВСтроках: Авто|Число
```

Задает максимальную высоту в строках текста. Применяется, когда [Вид](standardtablecolumn-ru-92a62dc49597.md) = [Текст](tablecolumnkind-ru-ce1102fede2f.md). 0 - не ограничено. [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - наследуется значение свойства [МаксимальнаяВысотаСтроки](table-ru-ccc43dec1ca9.md) из таблицы.

---

### ОбрабатыватьНажатие

`Доступность: Клиент`

```
ОбрабатыватьНажатие: Авто|Булево
```

Управляет наличием гиперссылки в ячейке таблицы. При значении [Авто](../stdlib/auto-ru-1b14ed166f8e.md), гиперссылка используется, если задан обработчик [ПриНажатии](standardtablecolumn-ru-92a62dc49597.md) или в данных ячейки находится ссылочный тип.

---

### ОценкаИнформации

`Доступность: Клиент`

```
ОценкаИнформации: Авто|ОценкаИнформации
```

Оценка информации. Влияет на отображение элементов данной колонки.

---

### Представление

`Доступность: Клиент`

```
Представление: Авто|Строка
```

Задает представление значения, отображаемое в ячейке таблицы. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md), а [Вид](standardtablecolumn-ru-92a62dc49597.md) = [Текст](tablecolumnkind-ru-ce1102fede2f.md), то используется представление значения, полученное через свойство [ПолеЗначения](tablecolumn-ru-90496d65cde5.md): `ДанныеСтроки[ПолеЗначения].Представление()`.

---

### Ссылка

`Доступность: Клиент`

```
Ссылка: Сущность.Ключ|Строка|?
```

Задает ссылку. Если задано, то текст и/или картинка отображаются как гиперссылка, нажатие на которую вызывает событие [ПриНажатии](standardtablecolumn-ru-92a62dc49597.md).

---

### ФигураКартинки

`Доступность: Клиент`

```
ФигураКартинки: Авто|Фигура
```

Определяет фигуру картинки.

---

### Цвет

`Доступность: Клиент`

```
Цвет: Авто|Цвет
```

Задает основной цвет содержимого колонки таблицы. Используется для цвета текста или значка.

---

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  СтандартнаяКолонкаТаблицы<ТипДанных, ТипЗначения>,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на ссылку (текст или картинку) в ячейке таблицы. Если разработчик не установил свойство [СтандартнаяОбработка](onclickevent-ru-15fc28e42f99.md) в `Ложь`, то происходит стандартная обработка нажатия на ссылку - ссылка открывается. Если гиперссылка выключена, то обработчик не вызовется.
