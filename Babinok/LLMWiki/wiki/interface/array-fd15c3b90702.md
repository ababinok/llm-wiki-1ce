# Типы

## [ИсточникДанныхМассив](arraydatasource-ru-2842d399ff6f.md)

`Стд::Интерфейс::ИсточникиДанных::Массив::ИсточникДанныхМассив<ТипДанных>` `Доступность: Клиент`

ТипДанных: тип данных элементов источника

Источник данных для списков и таблиц на основании массива. Данные автоматически обновляются при изменении состава массива. Элементами массива могут быть любые объекты, допускающие обращения к свойствам либо по индексу либо по имени, например:

- [Массив](../stdlib/array-ru-f0659b9628e1.md)
  
  - путем к данным колонки является индекс в этом массиве,
- [Соответствие](../stdlib/map-ru-075f0ef55c6b.md)
  
  - путем к данным колонки является ключ соответствия,
- Структура, описанная на встроенном языке - путем к данным колонки является имя свойства структуры,
- и другие В общем случае:
- если объект поддерживает доступ по индексу, то путем к данным колонки таблицы должен являться индекс,
- если объект не поддерживает доступ по индексу, то имя свойства.

## [НастройкаПоляИсточникаДанныхМассив](arraydatasourcefieldsetting-ru-ee785e7b7013.md)

`Стд::Интерфейс::ИсточникиДанных::Массив::НастройкаПоляИсточникаДанныхМассив` `Доступность: КлиентИСервер`

Настройка поля объекта [ИсточникДанныхМассив](arraydatasource-ru-2842d399ff6f.md). Уточняет поведение того или иного поля в системе. Настраиваемое поле источника данных может не отображаться в компоненте [Таблица](table-ru-ccc43dec1ca9.md) или [Список](list-ru-58c40755a735.md). Например, оно может участвовать в поиске, но при этом не отображаться пользователю.
