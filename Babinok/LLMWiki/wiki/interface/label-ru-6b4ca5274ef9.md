## Обзор

Компонент для вывода надписей в виде текста или гиперссылки.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::Надпись` `Доступность: Клиент`

Компонент для вывода надписей в виде текста или гиперссылки. Может иметь заголовок, изображение и дополнительное значение.

**Сравнение**

Ссылочное

### МаксимальнаяВысотаВСтроках

`Доступность: Клиент`

```
МаксимальнаяВысотаВСтроках: Авто|Число
```

Максимальная высота надписи в строках. Значение 0 снимает ограничение на расширение по высоте. Если текст не влезает в заданное количество строк, то в месте обрезки текста добавляется многоточие. Свойство [МинимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md) является более приоритетным, [МаксимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md) будет увеличена, если значение меньше, чем [МинимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md).

### МинимальнаяВысотаВСтроках

`Доступность: Клиент`

```
МинимальнаяВысотаВСтроках: Авто|Число
```

Минимальная высота надписи в строках. Вертикальный размер надписи не станет меньше ограничения, несмотря на содержимое текста. Может использоваться для выравнивания высоты строк в таблицах или других компонентах. Свойство [МинимальнаяВысота](component-ru-bad1c84be995.md) имеет больший приоритет. Свойство [МаксимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md) является менее приоритетным. Значение свойства [МаксимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md) будет увеличено, если его значение меньше, чем у свойства [МинимальнаяВысотаВСтроках](label-ru-6b4ca5274ef9.md).

### ОбрабатыватьНажатие

`Доступность: Клиент`

```
ОбрабатыватьНажатие: Авто|Булево
```

Управляет отображением надписи в виде гиперссылки.

- `Авто`
  
  - определяется системой автоматически, будет равно
  
  `Истина`
  
  , если выполнено одно из условий:
  
  - свойство
    
    [Значение](label-ru-6b4ca5274ef9.md)
    
    имеет ссылочный тип
  - свойство
    
    [Ссылка](label-ru-6b4ca5274ef9.md)
    
    заполнено
  - задан обработчик события
    
    [ПриНажатии](label-ru-6b4ca5274ef9.md)
- `Истина`
  
  - компонент принимает внешний вид гиперссылки. Обрабатывает нажатие (позволяет обработать событие
  
  [ПриНажатии](label-ru-6b4ca5274ef9.md)
  
  и стандартную обработку перехода по ссылке), может принимать фокус.
- `Ложь`
  
  - обычная надпись. Не обрабатывает нажатие, не принимает фокус. Событие нажатия передается родительским компонентам.

Управляет сжимаемостью надписи по горизонтали. Если `Истина`, то надписи разрешено сжиматься.

---

### РастягиватьРодителя

`Доступность: Клиент`

```
РастягиватьРодителя: Авто|Булево
```

Управляет тем, растягивает ли надпись родительский компонент. При значении `Ложь` надпись не будет влиять на размеры родительского контейнера. т.е. размер родительского контейнера, например, группы, будет определяться другими содержащимися в нем компонентами.

### УровеньЗаголовка

УровеньЗаголовка: Авто|УровеньЗаголовка

Определяет только ее семантический заголовок в разметке страницы. Используется для оптимизации SEO. Не влияет и не переопределяет другие свойства компонента.

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) – [НеИспользовать](headerlevel-ru-323f5f8c91e3.md).

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  Надпись,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на значение надписи, если свойство [ОбрабатыватьНажатие](label-ru-6b4ca5274ef9.md) равно `Истина`. Если разработчик установил свойство события [СтандартнаяОбработка](onclickevent-ru-15fc28e42f99.md) в `Ложь`, то стандартной обработки нажатия на ссылку не происходит. Иначе после завершения обработчика вызывается стандартная обработка нажатия на ссылку.
