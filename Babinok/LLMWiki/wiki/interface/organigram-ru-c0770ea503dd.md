Органиграмма(
  Видимость: Авто|Булево,
  Доступность: Авто|Булево,
  ТолькоЧтение: Авто|Булево,

  ВыравниваниеВГруппеПоГоризонтали: Авто|ВыравниваниеПоГоризонтали,
  ВесПриРастягивании: Авто|Число,
  Высота: Авто|Число,
  Ширина: Авто|Число,
  ШиринаВКолонках: Авто|ШиринаВКолонках,
  МаксимальнаяВысота: Авто|Число,
  МаксимальнаяШирина: Авто|Число,
  МинимальнаяВысота: Авто|Число,
  МинимальнаяШирина: Авто|Число,
  РастягиватьПоВертикали: Авто|Булево,
  РастягиватьПоГоризонтали: Авто|Булево,
  ПриПеретаскивании: (Компонент, СобытиеПриПеретаскивании)->ничто,
  ПриНаведении: (Компонент, СобытиеКомпонента)->ничто,
  ПриПотереНаведения: (Компонент, СобытиеКомпонента)->ничто,
  Приблизить: Команда,
  Отдалить: Команда,
  ПодогнатьКОбластиПросмотра: Команда,

  НастройкиИсточника: НастройкиИсточникаДревовиднойСхемы<ТипИсточника.ItemDataType|ТипИсточника.NodesDataType>?,

  РазмерЭлементов: Авто|РазмерЭлементовОрганиграммы,

Создает компонент органиграммы.

## Свойства

### АльтернативнаяОриентацияПоследнегоУровня

`Доступность: Клиент`

```
АльтернативнаяОриентацияПоследнегоУровня: Авто|Булево
```

Если равно `Истина`, то последний уровень элементов (когда ни один из них не имеет дочерних элементов) будет отображаться перпендикулярно родительскому уровню.

Прошлые имена: АльтернативнаяОриентацияПоследнегоУровня

---

### Источник

`Доступность: Клиент`

```
Источник: ТипИсточника
```

Задаёт источник данных для органиграммы

---

### КомандыЭлемента

`Доступность: Клиент`

```
КомандыЭлемента: ФрагментКомандногоИнтерфейса<КомандаСПараметром<ЭлементОрганиграммы>>?
```

Определяет команды, выполняемые над элементом органиграммы. Каждый конкретный элемент может переопределить команды в своем свойстве [Команды](organigramitem-ru-7daa0e5e236a.md)

---

### НастройкиИсточника

`Доступность: Клиент`

```
НастройкиИсточника: НастройкиИсточникаДревовиднойСхемы<ТипИсточника.ItemDataType|ТипИсточника.NodesDataType>?
```

Описание настроек автоматического заполнения органиграммы по источнику данных.

---

### РазмерЭлементов

`Доступность: Клиент`

```
РазмерЭлементов: Авто|РазмерЭлементовОрганиграммы
```

Определяет размер элементов органиграммы, см. перечисление [РазмерЭлементовОрганиграммы](organigramitemsize-ru-496bc9ae453f.md)

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  ГрафическаяСхема,
  СобытиеСДанными<ЭлементОрганиграммы?>)->ничто
```

Возникает при нажатии на графическую схему. При нажатии на элемент, он передается в данных события. При нажатии в пустую область, в данных события передается [Неопределено](../stdlib/undefined-ru-bad7e9ef4c2b.md).

## Методы

### ПолучитьРодительскийЭлемент

`Доступность: Клиент`

```
ПолучитьРодительскийЭлемент(Элемент: ЭлементОрганиграммы): ЭлементОрганиграммы?
```

Возвращает родительский элемент.

**Перегрузка** [ДревовиднаяСхема::ПолучитьРодительскийЭлемент(Элемент: ЭлементДревовиднойСхемы): ЭлементДревовиднойСхемы?](treeschema-ru-44f073705d32.md)

---

### ПолучитьСоседниеЭлементы

`Доступность: Клиент`

```
ПолучитьСоседниеЭлементы(Элемент: ЭлементОрганиграммы): Массив<ЭлементОрганиграммы>
```

Возвращает соседние элементы - дочерние элементы родителя, за исключением самого элемента.

**Перегрузка** [ДревовиднаяСхема::ПолучитьСоседниеЭлементы(Элемент: ЭлементДревовиднойСхемы): Массив<ЭлементДревовиднойСхемы>](treeschema-ru-44f073705d32.md)

---

### ЦентрироватьПоЭлементу

`Доступность: Клиент`

```
ЦентрироватьПоЭлементу(
  Элемент: ЭлементОрганиграммы,
  СброситьМасштабирование: Булево = Ложь)
```

Центрирует и масштабирует область просмотра на указанном элементе. Если параметр

`СброситьМасштабирование`

равен

`Истина`

, то масштабирование будет сброшено в 1 к 1.

**Перегрузка** [ДревовиднаяСхема::ЦентрироватьПоЭлементу(Элемент: ЭлементДревовиднойСхемы, СброситьМасштабирование: Булево = Ложь)](treeschema-ru-44f073705d32.md) [ГрафическаяСхема::ЦентрироватьПоЭлементу(Элемент: ЭлементГрафическойСхемы, СброситьМасштабирование: Булево = Ложь)](graphicalschema-ru-af7746d2c203.md)
