# ЭлементСпискаЗначений

> Updated: 2026-10-05

Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / Interface.

Имена для поиска: `ЭлементСпискаЗначений`, `ValueListItem`, `Стд::Интерфейс::ЭлементСпискаЗначений<ТипДанных>`, `Std::Interface::ValueListItem`.

## Обзор

ТипДанных: тип свойства Значение.

## Документированный контракт и примеры

`Стд::Интерфейс::ЭлементСпискаЗначений<ТипДанных>` `Доступность: КлиентИСервер`

ТипДанных: тип свойства Значение. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Описывает один элемент списка значений. Используется, например, для описания списка значений переключателя.

**Сравнение**

Структурное
