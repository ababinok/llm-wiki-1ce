## Конструкторы

### НастройкиКарусели

`Доступность: Клиент`

```
НастройкиКарусели(
  РежимШириныЭлемента: Авто|РежимШириныЭлементаКарусели,
  ШиринаЭлемента: Авто|Число,
  ВидОтображенияКнопок: Авто|ВидОтображенияКнопокКарусели,
  ВидНавигации: Авто|ВидНавигацииКарусели,
  РасположениеПанелиНавигации: Авто|РасположениеПанелиНавигацииКарусели,
  ИнтервалВоспроизведения: Авто|Длительность,
  ОтображатьИндикаторы: Авто|Булево,
  ЦиклическаяНавигация: Авто|Булево)
```

Создает объект со значениями свойств, соответствующими параметрам конструктора.

## Свойства

### ВидНавигации

`Доступность: Клиент`

```
ВидНавигации: Авто|ВидНавигацииКарусели
```

Определяет вид навигации Карусели. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - [ПоВидимойОбласти](carouselnavigationkind-ru-9949a7cb768c.md).

---

### ВидОтображенияКнопок

`Доступность: Клиент`

```
ВидОтображенияКнопок: Авто|ВидОтображенияКнопокКарусели
```

Определяет вид отображения кнопок навигации. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - [ПриНаведении](carouselbuttonsdisplaykind-ru-b27a555aad98.md).

---

### ИнтервалВоспроизведения

`Доступность: Клиент`

```
ИнтервалВоспроизведения: Авто|Длительность
```

Интервал, через который будет происходить автоматическое воспроизведение (перелистывание). По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - 0, автоматическое воспроизведение (перелистывание) выключено.

---

### ОтображатьИндикаторы

`Доступность: Клиент`

```
ОтображатьИндикаторы: Авто|Булево
```

Отображает индикаторы навигации. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - `Истина`.

---

### РасположениеПанелиНавигации

`Доступность: Клиент`

```
РасположениеПанелиНавигации: Авто|РасположениеПанелиНавигацииКарусели
```

Определяет расположение панели навигации Карусели. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - [Снизу](carouselnavigationpanellocation-ru-67ec6f81fe77.md).

---

### РежимШириныЭлемента

`Доступность: Клиент`

```
РежимШириныЭлемента: Авто|РежимШириныЭлементаКарусели
```

Включает режим указания ширины элемента внутри Карусели. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - трактуется как [Колонки](carouselitemwidthmode-ru-ece9760b4268.md).

---

### ЦиклическаяНавигация

`Доступность: Клиент`

```
ЦиклическаяНавигация: Авто|Булево
```

Зацикливать ли навигацию - при достижении последнего элемента есть возможность листать дальше, начиная с первого. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - `Ложь`.

---

### ШиринаЭлемента

`Доступность: Клиент`

```
ШиринаЭлемента: Авто|Число
```

Занимаемая элементом Содержимого ширина в соответствующем [РежимШириныЭлементаКарусели](carouselitemwidthmode-ru-ece9760b4268.md):

1. [Колонки](carouselitemwidthmode-ru-ece9760b4268.md)
  
  - значение ширины в колонках должно быть больше нуля.
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  - каждый элемент имеет ширину в 1 колонку.
2. [ПроцентШириныКонтейнера](carouselitemwidthmode-ru-ece9760b4268.md)
  
  - значение в процентах ширины Карусели должно быть задано в интервале от 5 до 100 включительно. При указании выходящих за эти границы диапазона система автоматически приведёт их к значениям по границам.
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  - каждый элемент имеет размер 100% (растягивается на всю ширину).
3. [Пиксели](carouselitemwidthmode-ru-ece9760b4268.md)
  
  - значение задаётся в пикселях.
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  равен 300px.
4. [СобственнаяШирина](carouselitemwidthmode-ru-ece9760b4268.md)
  
  - в этом режиме Карусель не управляет шириной её элементов, используется их собственная ширина.
