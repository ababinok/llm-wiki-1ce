## Обзор

Компонент пользовательского интерфейса [КомпонентСамостоятельнойРегистрации](selfregistrationcomponent-ru-0c366f494356.md) позволяет перед началом самостоятельной регистрации пользователя ввести дополнительные данные, которые будут использованы в процессе регистрации.

## Документированный контракт и примеры

`Стд::Пользователи::Самообслуживание::Интерфейс::ФормаРедактированияПользовательскихДанных` `Доступность: Клиент`

Компонент пользовательского интерфейса [КомпонентСамостоятельнойРегистрации](selfregistrationcomponent-ru-0c366f494356.md) позволяет перед началом самостоятельной регистрации пользователя ввести дополнительные данные, которые будут использованы в процессе регистрации.

Для этого необходимо создать компонент для ввода дополнительных данных, который будет реализовывать данный контракт, и указать его в качестве свойства [ФормаРедактированияПользовательскихДанных](selfregistrationcomponent-ru-0c366f494356.md).

## Методы

### ПолучитьДанныеПользователя

`Доступность: Клиент`

```
ПолучитьДанныеПользователя(): ПараметрСамостоятельнойРегистрацииПользователя
```

Возвращает данные, заполненные пользователем, в виде

[ПараметрСамостоятельнойРегистрацииПользователя](../data/userselfregistrationparameter-ru-68a6041d2f1e.md)

. Параметр будет использован при регистрации, см.

[Начать](../data/userselfregistrationoperation-ru-91f95749933e.md)

и

[УстановитьПараметр](../data/stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)

.

---

### ПользовательскиеДанныеВалидны

`Доступность: Клиент`

```
ПользовательскиеДанныеВалидны(): Булево
```

Правильно или нет пользователь заполнил данные формы. Влияет на доступность кнопки "Далее" на стартовой странице регистрации (кнопка недоступна, если метод вернул

`Ложь`

).
