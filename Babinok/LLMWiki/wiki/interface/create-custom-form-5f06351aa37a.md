## Обзор

В данном примере вы добавите в проект [форму](form-component-975c31cd89e9.md) для ввода, редактирования и форматирования заметок.

## Документированный контракт и примеры

> [!NOTE] примечание
> Этот пример использует [приложение «Демо CRM»](../project/demo-app-3768685a4428.md).

В данном примере вы добавите в проект [форму](form-component-975c31cd89e9.md) для ввода, редактирования и форматирования заметок. Пользователь может сохранить заметку в файл либо очистить содержимое поля ввода. Новая форма будет доступна в разделе **Администрирование** демонстрационного приложения.

Пример пользовательской формы «Заметки» в разделе Администрирование: над большим полем текста расположена панель форматирования (выбор Заголовок, оформление текста и списков). [Описание иллюстрации](../../raw/figures/218d6ffb18e54bde6e78f6304a42ad2cbfa3ab1e870dbd8220cde1cd1204afe6-f608ca4f28012d51.md)

## Создание формы

[Откройте](../project/open-app-in-ide-2c0162ac1160.md) демо-приложение в среде разработки и выполните следующие действия:

1. Добавьте новую форму в [подсистему](../project/hierarchical-project-structure-397ba5e7f9df.md) **Основное**. Для этого наведите мышку на имя подсистемы и нажмите на знак плюса.
2. В открывшемся окне выберите компонент интерфейса **Форма**.
  
  В окне добавления элемента выбран компонент интерфейса «Форма». [Описание иллюстрации](../../raw/figures/425bdee7be9e419ff44d578a3a893ef477bca36c61624ac2c8f766c088e561ba-39e273b52b0a8a0d.md)
3. Задайте имя формы — **Заметки**.
4. Выделите форму в навигаторе проекта, чтобы открыть ее в [редакторе компонентов интерфейса](ide-overview-and-basic-actions-969a6e6501a6.md).
5. Нажмите на знак плюса для узла **Форма**, чтобы добавить новый компонент. В открывшемся окне выберите **ПроизвольныйШаблонФормы**.
  
  В узле «Форма» открыт выбор нового компонента; выбран «ПроизвольныйШаблонФормы». [Описание иллюстрации](../../raw/figures/55edff53b623438272418a417278324403be69af3331f0e8587979af445c76b9-97d7ab3aaf25ff3a.md)
6. К шаблону формы добавьте компонент интерфейса [ФорматированныйДокумент](formatted-document-component-adfc034f4ad2.md), который будет использоваться для ввода и редактирования заметок. Введите имя компонента — **ЗаметкиДокумент**.
  
  Добавление форматированного документа [Описание иллюстрации](../../raw/figures/cb7f55fcd19f683db9f5a90b8bd64e3eaf53ce0e47ab243e4ce8c21f8feea44d-aa8efc6c1573cf12.md)
7. Добавьте [основную команду](form-component-975c31cd89e9.md) для сохранения заметок. Для этого нажмите на знак плюса для узла **Форма** и выберите **Новые команды** ⟶ **ОбычнаяКоманда**.
  
  Добавление команды «Сохранить» [Описание иллюстрации](../../raw/figures/b5f7e902c23c0a0500861531a1b586d830025c8764081069bcafe565af83a339-0ef9a7d4815df465.md)
8. В качестве раздела формы, в который нужно поместить новую команду, выберите **ОсновнаяКоманда**.
  
  
9. В панели свойств команды задайте следующие свойства:
  
  - Представление
    
    — Сохранить,
  - Изображение
    
    — Сохранить.svg.
  
  В свойствах команды заданы представление «Сохранить» и изображение «Сохранить.svg». [Описание иллюстрации](../../raw/figures/4fe51c0606137743778fa248417d06fb3f1ada319f4ca9d4c58617bf339af0b8-eaa65475a522f38b.md)
10. Создайте [обычную команду](form-component-975c31cd89e9.md) для очистки содержимого заметки. Для этого нажмите на знак плюса для узла **Форма** и выберите **Новые команды** ⟶ **ОбычнаяКоманда**.
  
  В редакторе формы раскрыта группа «Новые команды» и выбран тип «ОбычнаяКоманда» для создания команды «Очистить». [Описание иллюстрации](../../raw/figures/3acbfad852ed89005cd89a7aa84544ce1728c70e6a54f17122a1113b011dbc80-5352aedf45fdc408.md)
11. В качестве раздела формы, в который нужно поместить новую команду, выберите **ОбычныеКоманды**. «1С:Предприятие.Элемент» автоматически создаст [фрагмент командного интерфейса](command-interface-fragment-f742e5d6797f.md), к которому добавит созданную команду.
  
  При добавлении команды в форму раскрыт выбор раздела: «КомандыСоздания», «ОбычныеКоманды», «ДополнительныеКоманды»; выбран «ОбычныеКоманды». [Описание иллюстрации](../../raw/figures/f9b37341b04fef0b909bde2bf32d637a49d5a040eb1768a9087b005649e6320c-7e8dfab449159b8e.md)
12. В панели свойств команды задайте следующие свойства:
  
  - Представление
    
    — Очистить,
  - Изображение
    
    — МусорнаяКорзина.svg.

В окне предпросмотра вы можете увидеть, как будет выглядеть форма в приложении.

Макет формы [Описание иллюстрации](../../raw/figures/9a9776d69e1c0d0a2299ff1f54d30e1afcbdee9e3e216efba6f57bc57aa174fc-7de5c9ea7eba4de5.md)

## Создание обработчиков команд

Задайте действия, которые будут выполняться при нажатии на команды **Сохранить** и **Очистить**:

1. В дереве компонентов выделите команду **Сохранить**. В панели свойств команды перейдите к свойству **Обработчик** и нажмите на знак плюса, чтобы автоматически сгенерировать обработчик команды.
  
  Генерация обработчика события «ПриНажатии» [Описание иллюстрации](../../raw/figures/8b941f8836e7dd751217bc70dd6bc8fcb58313fca023cfd76148dd7be24a1520-c872cbae30361456.md)
2. Добавьте к обработчику код для сохранения содержимого заметки в текстовый файл:
  
  Модуль формы «Заметки»
  
  ```xbsl
  метод СохранитьОбработчик(Команда: ОбычнаяКоманда)
      знч Заметка = Компоненты.ЗаметкиДокумент.Значение
      если не Заметка.Пусто()
          ЗаписатьВФайл(Заметка)
          ПоказатьУведомление()
      ;
  ;
  
  @НаСервере @ДоступноСКлиента
  статический метод ЗаписатьВФайл(Заметка: Строка)
      // Создание каталога для хранения заметок
      знч Каталог = Файлы.СоздатьКаталог("C:\\Notes")
      // Запись содержимого заметки в файл
      знч ФайлЗаметки = новый Файл("note_" + ДатаВремя.Сейчас().Представление("гггг-дд-MM-ЧЧ-мм-сс") + ".txt",
                                  Каталог)
      исп ПотокЗаписи = ФайлЗаметки.ОткрытьПотокЗаписи()
      ПотокЗаписи.Записать(Заметка)
  ;
  
  метод ПоказатьУведомление()
      // Уведомление об успешном сохранении заметки в файл
      знч Уведомление = новый Уведомление("", "Заметка сохранена в файл")
      Уведомление.Вид = ВидУведомления.Всплывающее
      Уведомление.ОценкаИнформации = ОценкаИнформации.Положительная
      Уведомление.Показать()
  ;
  ```
3. Аналогичным образом создайте обработчик команды **Очистить**.
4. Добавьте к обработчику следующий код:
  
  Модуль формы «Заметки»
  
  ```xbsl
  метод ОчиститьОбработчик(Команда: ОбычнаяКоманда)
      если не Компоненты.ЗаметкиДокумент.Значение.Пусто()
          Компоненты.ЗаметкиДокумент.Значение = ""
      ;
  ;
  ```

## Добавление формы в интерфейс приложения

Теперь осталось последнее действие — включить в интерфейс команду открытия новой формы. Из предыдущих примеров вы уже знаете, [где находится командный интерфейс приложения](locate-command-interface-7543048d998d.md). Чтобы изменить его, выполните следующие действия:

1. В навигаторе проекта перейдите к элементу **Приложение**, перейдите в дерево объектов в раздел **КомандныйИнтерфейсПанелиНавигации**.
2. Выделите компонент [ГруппаКомандногоИнтерфейса](command-interface-group-52b75d5d03e9.md), представляющий раздел **Администрирование** демо-приложения. Нажмите на знак плюса, чтобы добавить к нему новую команду, и выберите пункт **Вычисляемое выражение** в открывшемся окне.
  
  Добавление вычисляемого выражения [Описание иллюстрации](../../raw/figures/b2fb6376a3dc6595e4880525fd4aeba07f0f3a9193a0e93559d41ef377788479-638ee33e332e40e9.md)
3. В панели свойств выражения выберите команду `Заметки.ОткрытьФорму`.
  
  Добавление команды открытия формы [Описание иллюстрации](../../raw/figures/9ee765b4d44dfba6b84a168cde7abe3783f5a8b7ed2e9ec152a913e5208b88e6-48e02cf1da238e02.md)

Новая команда появится в конце раздела **Администрирование**.

## Запуск приложения

[Опубликуйте](../project/publish-project-on-server-dade1898bf5e.md) проект на сервере и перезапустите приложение. Нажмите **Администрирование** ⟶ **Заметки**, чтобы открыть форму для создания и сохранения заметок.
