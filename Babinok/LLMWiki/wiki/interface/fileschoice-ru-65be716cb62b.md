## Свойства

### ВыбранныеФайлы

`Доступность: Клиент` `ТолькоЧтение`

```
ВыбранныеФайлы: ЧитаемыйМассив<ВыбранныйФайл>
```

Содержит массив выбранных файлов. Если пользователь еще ничего не выбирал, массив пустой. Не образует параметр конструктора.

---

### МножественныйВыбор

`Доступность: Клиент`

```
МножественныйВыбор: Авто|Булево
```

Включает возможность выбора нескольких файлов.

---

### Описание

`Доступность: Клиент`

```
Описание: Авто|Строка
```

Задает текст надписи, показываемой как предложение выбрать файл. Если не указан, то показывается надпись "Выберите файл" или "Выберите файлы".

---

### ОтображатьИконку

`Доступность: Клиент`

```
ОтображатьИконку: Авто|Булево
```

Включает отображение дополнительной декоративной иконки.

---

### Фильтр

`Доступность: Клиент`

```
Фильтр: Авто|Строка
```

Задает допустимые типы файлов при выборе. По умолчанию пустая строка, т.е. фильтр не задан.

Варианты указания:

- audio/* - все аудио-файлы
- video/* - все видео-файлы
- image/* - все картинки
- <MIME-Type> - файлы с этим типом
- .<расширение> - файлы с этим расширением

Допусимо указывать несколько вариантов через запятую, например: `.doc, .docx, .xml, application/msword`
