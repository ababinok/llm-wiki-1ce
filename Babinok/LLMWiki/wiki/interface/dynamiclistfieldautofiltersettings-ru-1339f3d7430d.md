## Конструкторы

### НастройкиАвтоматическогоФильтраПоляДинамическогоСписка

`Доступность: КлиентИСервер`

```
НастройкиАвтоматическогоФильтраПоляДинамическогоСписка(
  ПредставлениеСортировкиПоВозрастанию: Авто|Строка,
  ПредставлениеСортировкиПоУбыванию: Авто|Строка,
  НастройкиВводаСсылок: Авто|НастройкиВводаСсылок,
  НастройкиВводаЧисла: Авто|НастройкиВводаЧисла,
  НастройкиВводаДлительности: Авто|НастройкиВводаДлительности,
  ЗначениеФильтраПоУмолчанию: Объект?)
```

Создает настройки по умолчанию.

---

## Свойства

### ЗначениеФильтраПоУмолчанию

`Доступность: КлиентИСервер`

```
ЗначениеФильтраПоУмолчанию: Объект?
```

Задает значение по умолчанию для автоматического фильтра. Такое значение будет подставлено в фильтр сразу после создания компонента [Список](list-ru-58c40755a735.md), если ему не задано ранее сохраненное значение (см. [Список](list-ru-58c40755a735.md).[ПриЧтенииНастроек](list-ru-58c40755a735.md)).

---

### НастройкиВводаДлительности

`Доступность: КлиентИСервер`

```
НастройкиВводаДлительности: Авто|НастройкиВводаДлительности
```

### ПредставлениеСортировкиПоВозрастанию

`Доступность: КлиентИСервер`

```
ПредставлениеСортировкиПоВозрастанию: Авто|Строка
```

Определяет представление автоматической сортировки по возрастанию. [Авто](../stdlib/auto-ru-1b14ed166f8e.md) использует наиболее понятное представление направления в зависимости от типа поля.
