## Свойства

### Активность

`Доступность: Клиент`

```
Активность: Булево
```

Признак активности. Если `Истина`, то компонент отображается в нажатом состоянии. Имеет смысл только при [Переключаемость](button-ru-d0cdd9e186f7.md) = `Истина`. Если кнопке назначена переключаемая команда, значение этого свойства игнорируется, активность определяется активностью переключаемой команды.

---

### Вид

`Доступность: Клиент`

```
Вид: Авто|ВидКнопки
```

Вид отображения кнопки

### Картинка

`Доступность: Клиент`

```
Картинка: Картинка
```

Указывает на внутренний компонент [Картинка](picture-ru-efed61d49ad9.md). Может использоваться для дополнительного ее оформления.

---

### КартинкаАктивного

`Доступность: Клиент`

```
КартинкаАктивного: Картинка
```

Ссылка на внутренний компонент [Картинка](picture-ru-efed61d49ad9.md), отображаемый в активном состоянии. Может использоваться для дополнительного оформления картинки.

---

### Команды

`Доступность: Клиент`

```
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или группа команд, назначенных кнопке. Если указана группа команд, то команды группы будут размещены в меню кнопки, а в качестве заголовка кнопки будет использован заголовок группы команд.

---

### ОпасностьДействия

`Доступность: Клиент`

```
ОпасностьДействия: Авто|ОпасностьДействия
```

Опасность действия кнопки

---

### Переключаемость

`Доступность: Клиент`

```
Переключаемость: Авто|Булево
```

Признак переключаемости кнопки. Если равен `Истина`, то при нажатии на кнопку, компонент инвертирует флаг [Активность](button-ru-d0cdd9e186f7.md). Если кнопке назначена переключаемая команда, то значение свойства игнорируется, кнопка будет переключаемой.
