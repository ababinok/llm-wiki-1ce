## Свойства

### ЗначенияАвтоПодбора

`Доступность: КлиентИСервер`

```
ЗначенияАвтоПодбора: Массив<ЭлементСпискаЗначений<Объект?>>
```

Массив элементов списка значений, которые будут отображены в списке выбора. Если массив пустой, отображается текст "Ничего не найдено", как при стандартном поиске.

---

### СтандартнаяОбработка

`Доступность: КлиентИСервер`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной (системной) обработки события. Если установить данному свойству значение `Ложь`, то стандартная обработка события производиться не будет. Отказ от стандартной обработки не отменяет действие.

---

### Текст

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Текст: Строка
```

Текст поиска.
