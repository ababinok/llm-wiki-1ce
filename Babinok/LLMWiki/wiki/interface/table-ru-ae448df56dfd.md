## Обзор

Набор записей в виде строк и колонок.

## Документированный контракт и примеры

Набор записей в виде строк и колонок. Необходимо задать **Колонки** (колонки таблицы) и **Источник** (источник данных, которые будут показаны в таблице).

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Источник

```yaml
Источник: ВычисляемоеВыражение|неизвестно
```

Источник данных списка. Экземпляр типа [ДинамическийСписок](dynamiclist-ru-ab61b0be4de4.md) или [ИсточникДанныхМассив](arraydatasource-ru-2842d399ff6f.md).

---

#### ИспользованиеПоиска

```yaml
ИспользованиеПоиска: ВычисляемоеВыражение|Авто|Булево
```

Управляет отображением поисковой строки. Возможные значения:

- Авто
  
  — строка поиска отображается и задействована при наличии данных, по которым можно выполнять поиск;
- Истина
  
  — строка поиска отображается и задействована вне зависимости от наличия данных, по которым можно выполнять поиск;
- Ложь
  
  — строка поиска не отображается и не задействована.

---

#### ОтображатьНастройки

```yaml
ОтображатьНастройки: ВычисляемоеВыражение|Авто|Булево
```

Если установлено значение **Истина** и [Источник](table-ru-ae448df56dfd.md) — [ДинамическийСписок](dynamiclist-ru-ab61b0be4de4.md), то у таблицы включается механизм настройки. Включает в себя настройки двух видов: простые и продвинутые. Пользователь сможет переключаться между ними самостоятельно. Изначальный вид зависит от свойства [ИспользоватьРасширенныеНастройки](table-ru-ae448df56dfd.md) и состава предопределенных (описанных разработчиком фильтров у источника данных) или сохраненных настроек таблицы.

---

#### АвтоВыделениеСтроки

```yaml
АвтоВыделениеСтроки: ВычисляемоеВыражение|Авто|АвтоВыделениеСтроки
```

Режим автоматической установки текущей строки: [ВыделятьПервый](rowautoselection-ru-e2fbed1c50a8.md) и [Выключено](rowautoselection-ru-e2fbed1c50a8.md). При значении **ВыделятьПервый** и если [ИспользоватьВыделениеСтроки](table-ru-ae448df56dfd.md) равно **Истина**, то при первом отображении списка текущей строкой устанавливается первая строка и вызывается событие [ПриВыделенииСтроки](table-ru-ae448df56dfd.md). Событие [ПриНажатииСтроки](table-ru-ae448df56dfd.md) в этом случае не вызывается.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](table-ru-ae448df56dfd.md) = 1, а у другого [ВесПриРастягивании](table-ru-ae448df56dfd.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../../raw/figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../../raw/figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Доступность

```yaml

```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](table-ru-ae448df56dfd.md).


  всегда равно
  
  `Неопределено`

#### НачальныйУровеньРазворачивания

```yaml

```

Устанавливает начальное отображение списка с иерархическим источником данных относительно корня.

Если [Источник](table-ru-ae448df56dfd.md) — это [ИсточникДанныхДеревоПодгружаемый](loadabletreedatasource-ru-feb2e5334aa8.md), то раскрывается [УзелДереваСДаннымиПодгружаемый](loadabletreenodewithdata-ru-99f8911a6722.md) и для него инициируется событие [ПриЗаполненииДочернихЭлементов](loadabletreedatasource-ru-feb2e5334aa8.md).

Игнорируется в мобильной версии.

#### ОбрабатыватьНажатие

- Ложь

#### ОтмечатьГруппыСДочерними

```yaml
ОтмечатьГруппыСДочерними: ВычисляемоеВыражение|Авто|Булево
```

Используется только с иерархическими источниками данных.

- Истина

- Ложь

Для древовидного источника типа [ДинамическийСписок](dynamiclist-ru-ab61b0be4de4.md) выделение потомков системно не осуществляется.

### События

#### ПослеСозданияСтроки

```yaml
ПослеСозданияСтроки: Строка
```

Вызывается после создания экземпляра компонента элемента списка системой. Позволяет донастроить созданный компонент или подписаться на его события. Новый элемент списка в данном событии полностью сконструирован: заполнено свойство **ДанныеСтроки**, по описанию компонента созданы его внутренние компоненты и установлены значения их свойств.

---

#### ПриНажатииСтроки

```yaml
ПриНажатииСтроки: Строка
```

Вызывается при нажатии на элемент списка: либо на пустую область, либо на компонент в этом элементе, который сам не обрабатывает событие **ПриНажатии**.

---

#### ПриВыделенииСтроки

```yaml
ПриВыделенииСтроки: Строка
```

Вызывается при изменении выделенного элемента, если [ИспользоватьВыделениеСтроки](table-ru-ae448df56dfd.md) равно **Истина**.

---

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

---

#### ПриРедактированииСтроки

```yaml
ПриРедактированииСтроки: Строка
```

Вызывается при редактировании строки, процесс которого вызывается системным механизмом.

Если событие определено разработчиком, то команда редактирования строки показывается вне зависимости от возможности отредактировать такую строку системно.

---

#### ПриСозданииСтроки

```yaml
ПриСозданииСтроки: Строка
```

Вызывается при создании строки предопределенной командой создания.

Если событие определено разработчиком, то команда создания строки показывается вне зависимости от возможности сконструировать такую строку автоматически.

---

#### ПриСохраненииНастроек

```yaml
ПриСохраненииНастроек: Строка
```

Событие, вызываемое для сохранения настроек списка. Параметр **Событие** содержит текущие настройки списка. Событие вызывается:

- при сохранении пользователем новой настройки;
- при обновлении пользователем существующей настройки;
- при удалении пользователем настройки.

---

#### ПриЧтенииНастроек

```yaml
ПриЧтенииНастроек: Строка
```

Событие, вызываемое сразу после создания списка для получения сохраненных настроек: фильтров и сортировок.

## Дочерние элеметы

#### КомандыСтроки

```yaml
КомандыСтроки: неизвестно
```

Команды, которые будут доступны для конкретной строки списка. Параметр обработчика команды — идентификатор строки списка, который зависит от типа источника:

- в случае
  
  [динамического списка](../project/dynamic-list-560b781f9b9f.md)
  
  — это ссылка на экземпляр
  
  [сущности](../data/entity-cfb31c8b7cbd.md)
  
  ;
- в случае
  
  [источника данных на основе массива](../project/array-data-source-cc44dedf47c8.md)
  
  — это данные строки.

Получить доступ к идентификатору строки можно через параметр **ДанныеСтроки**. Параметр имеет тип `ТипИсточника.ТипДанных` и содержит данные строки, для которой формируется команда.

---

#### КомандыСтрокиГруппы

```yaml
КомандыСтрокиГруппы: неизвестно
```

Команды, которые будут доступны для групповой строки.

Параметр обработчика команды — данные групповой строки списка.

---

#### КомандыОтмеченныхСтрок

```yaml
КомандыОтмеченныхСтрок: неизвестно
```

Описание команд действий выпадающей панели над множеством отмеченных строк. Параметр обработчика команды — массив идентификаторов строк списка. Идентификаторы строк списка зависят от типа источника:

- в случае
  
  [динамического списка](../project/dynamic-list-560b781f9b9f.md)
  
  — это ссылка на экземпляр
  
  [сущности](../data/entity-cfb31c8b7cbd.md)
  
  ;
- в случае
  
  [источника данных на основе массива](../project/array-data-source-cc44dedf47c8.md)
  
  — это данные строки.

Получить доступ к массиву идентификаторов отмеченных строк списка можно через параметр **ОтмеченныеСтроки**. Параметр имеет тип `Массив<ТипИсточника.ТипИдентификатора>` и содержит массив идентификаторов отмеченных строк.

---

#### Команды

```yaml
Команды: ФрагментКомандногоИнтерфейса?
```

Данное свойство позволяет задать команды, отображаемые в командной панели списка. Командная панель располагается над основным компонентом. Команды, которые не уместились в командной панели на форме, переносятся в меню **Еще**, отображаемое в правой части командной панели. Если значение свойства `Неопределено`, командная панель не отображается. По умолчанию — `Неопределено`.

---

#### Колонки

```yaml
Колонки: неизвестно
```

Массив экземпляров компонента [ПроизвольнаяКолонкаТаблицы](customtablecolumn-ru-51fab442bbf8.md) или компонента [СтандартнаяКолонкаТаблицы](standardtablecolumn-ru-0b1e3e80ca73.md).
