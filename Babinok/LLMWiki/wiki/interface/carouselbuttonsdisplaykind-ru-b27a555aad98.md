## Свойства

### ПриНаведении

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПриНаведении
```

Кнопки навигации отображаются слева и справа в Карусели только при наведении на область Карусели.

---

### Внутри

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Внутри
```

Кнопки навигации отображаются слева и справа в Карусели.

---

### ВПанели

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВПанели
```

Кнопки навигации отображаются в панели навигации Карусели справа рядом друг с другом.

---

### НеОтображать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеОтображать
```

Скрывает кнопки навигации.
