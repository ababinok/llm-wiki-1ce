# Типы

## [ВажностьКоманды](commandimportance-ru-986d64839edb.md)

`Стд::Интерфейс::Команды::ВажностьКоманды` `Доступность: КлиентИСервер`

Определяет важность команды. Важность может использоваться при отображении команды. Например, все команды с важностью [Низкая](commandimportance-ru-986d64839edb.md) из свойства формы [ДополнительныеКоманды](form-ru-89fb5e7eaeb3.md) будут отображены в выпадающем меню "Еще"

---

## [ВидОтображенияГруппыКомандногоИнтерфейса](commandinterfacegroupdisplaykind-ru-41b09fc7443a.md)

`Стд::Интерфейс::Команды::ВидОтображенияГруппыКомандногоИнтерфейса` `Доступность: КлиентИСервер`

Содержит виды отображения групп командного интерфейса. Конкретное отображение группы зависит от места ее размещения, обычно группа команд отделяется разделителями.

---

## [ГруппаКомандногоИнтерфейса](commandinterfacegroup-ru-f89eb5a6f7da.md)

`Стд::Интерфейс::Команды::ГруппаКомандногоИнтерфейса<ТипКоманды>` `Доступность: Клиент`

ТипКоманды: тип команды группы. По умолчанию [Команда](command-ru-ad3bc8ea1407.md). Ограничения параметра типа: Стд::Интерфейс::Команды::Команда, Стд::Интерфейс::Команды::КомандаСПараметром<неизвестно>.

Логическое объединение команд в некоторую группу. Имеет текстовое представление и картинку. В пользовательском интерфейсе может быть представлена в виде группы меню, выпадающего списка и т.д.

---

## [Команда](command-ru-ad3bc8ea1407.md)

`Стд::Интерфейс::Команды::Команда` `Доступность: Клиент`

Команда представляет некоторую функцию приложения доступную пользователю для выполнения. В команде задается текстовое представление и/или картинка, идентифицирующие функцию для пользователя приложения. В пользовательском интерфейсе может отображаться различными компонентами. Абстрактный базовый тип для всех команд.

---

## [КомандаСКомпонентом](commandwithcomponent-ru-4b1e72350e5a.md)

`Стд::Интерфейс::Команды::КомандаСКомпонентом<ТипКомпонента>` `Доступность: Клиент`

ТипКомпонента: Тип компонента, над экземпляром которого будет выполняться команда. Ограничения параметра типа: Стд::Интерфейс::Компонент.

Команда с компонентом - позволяет описать команду привязанную к конкретному компоненту. Например, команду закрытия формы.

---

## [КомандаСПараметром](commandwithparameter-ru-4a1123ae43c7.md)

`Стд::Интерфейс::Команды::КомандаСПараметром<ТипПараметра>` `Доступность: Клиент`

ТипПараметра: тип параметра команды.

Команда с дополнительным параметром. При выполнении команды в ее обработчик передается дополнительный параметр.

---

## [НавигационнаяКоманда](navigationcommand-ru-8290d7424fc8.md)

`Стд::Интерфейс::Команды::НавигационнаяКоманда` `Доступность: Клиент`

Навигационная команда. Результатом выполнения является открытая форма.

---

## [ОбычнаяКоманда](usualcommand-ru-43da648bf5af.md)

`Стд::Интерфейс::Команды::ОбычнаяКоманда` `Доступность: Клиент`

Обычная команда. Используется для создания экземпляра обычной команды непосредственно в компоненте, группе или фрагменте командного интерфейса. Обработчик задается методом модуля где задан экземпляр команды.

---

## [ПереключаемаяКоманда](switchablecommand-ru-154df28f2101.md)

`Стд::Интерфейс::Команды::ПереключаемаяКоманда` `Доступность: Клиент`

Переключаемая команда - это команда имеющая два состояния и переключающаяся между ними при исполнении команды.

---

## [ФрагментКомандногоИнтерфейса](commandinterfacefragment-ru-70af6e9ace5a.md)

`Стд::Интерфейс::Команды::ФрагментКомандногоИнтерфейса<ТипКоманды>` `Доступность: Клиент`

ТипКоманды: тип команды фрагмента командного интерфейса. По умолчанию [Команда](command-ru-ad3bc8ea1407.md). Ограничения параметра типа: Стд::Интерфейс::Команды::Команда, Стд::Интерфейс::Команды::КомандаСПараметром<неизвестно>.

Фрагмент командного интерфейса. Используется для модульной разработки командного интерфейса. Также используется для автоматически создаваемого командного интерфейса.
