## Свойства

### Низкая

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Низкая
```

Уведомление не отображается, но может быть сохранено в центре уведомлений.

---

### Обычная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Обычная
```

Уведомление, которое отображается внутри окна приложения. Рекомендуется использовать в сценариях, когда нужно уведомить пользователя о событии, которое инициировал он сам, в качестве дополнительного подтверждения.

---

### Высокая

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Высокая
```

Уведомление, которое отображается как уведомление браузера. Пользователь увидит данное уведомление даже если он находится в другой вкладке браузера или если окно браузера свернуто.
