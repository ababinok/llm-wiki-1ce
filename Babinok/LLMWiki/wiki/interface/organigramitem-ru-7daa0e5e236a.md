## Конструкторы

### ЭлементОрганиграммы

`Версия 9.0 и выше`

`Доступность: КлиентИСервер`

```
ЭлементОрганиграммы(
  Данные: Объект?,
  ДочерниеЭлементы: Массив<ЭлементОрганиграммы>?,
  Наименование: Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?,
  Пояснение: Строка,
  Описание: Строка,
  КонтактнаяИнформация: Соответствие<ВидКонтактнойИнформации, Массив<Строка>>,
  Статус: Строка,
  ЦветСтатуса: Авто|Цвет,
  Цвет: Авто|Цвет,
  Свернут: Булево,
  Команды: ФрагментКомандногоИнтерфейса<КомандаСПараметром<ЭлементОрганиграммы>>?)
```

Создает элемент органиграммы.

Пояснение: Строка

---

### Свернут

`Доступность: КлиентИСервер`

```
Свернут: Булево
```

Признак того, что элемент свернут. В свернутом состоянии не отображаются его дочерние элементы.

---

### Статус

`Доступность: КлиентИСервер`

```
Статус: Строка
```

Дополнительный статус, например, "Недоступен", "В отпуске" и т.д. Отображается в компоненте [Надпись](label-ru-6b4ca5274ef9.md) с видом значка.

---

### Цвет

`Доступность: КлиентИСервер`

```
Цвет: Авто|Цвет
```

Задает основной цвет элемента. Этот цвет используется на элементе и для цвета соединяющих линий от элемента к его дочерним. Если равен [Авто](../stdlib/auto-ru-1b14ed166f8e.md), цвет рассчитывается автоматически:

- либо от родителя
- либо цвет задается системой (для элементов первого и второго уровней)

---

### ЦветСтатуса

`Доступность: КлиентИСервер`

```
ЦветСтатуса: Авто|Цвет
```

Цвет статуса, например, [Красный](../stdlib/colors-ru-a841affb57c9.md) для "Недоступен". Задает цвет значка.
