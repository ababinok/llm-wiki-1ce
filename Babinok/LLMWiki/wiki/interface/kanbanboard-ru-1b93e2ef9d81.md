## Обзор

ТипИсточника: Источник данных для карточек канбан-доски.

## Документированный контракт и примеры

`Стд::Интерфейс::КанбанДоска::КанбанДоска<ТипИсточника,ТипЗначенияКолонки,ТипЗначенияСвимлайна>` `Доступность: Клиент`

ТипИсточника: Источник данных для карточек канбан-доски. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов. ТипЗначенияКолонки: Тип значения карточки, по которому определяется принадлежность к колонке. Ограничения параметра типа: Стд::Объект, Стд::Неопределено. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов. ТипЗначенияСвимлайна: Тип значения карточки, по которому определяется принадлежность к свимлайну. Ограничения параметра типа: Стд::Объект, Стд::Неопределено. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент, позволяющий отображать данные в виде канбан-доски.

`Доступность: Клиент`

```
Свимлайны: Массив<КанбанСвимлайн<ТипЗначенияСвимлайна, ТипИсточника.ItemDataType>>
```

### СтатистикаКолонки

`Доступность: Клиент`

```

```

Дополнительные элементы, отображаемые в шапке колонки (не больше трех). В элементе отображается [Представление](valuelistitem-ru-c68a213e54f6.md) или, если оно не задано, то [Значение](valuelistitem-ru-c68a213e54f6.md). Описание задается через [Описание](valuelistitem-ru-c68a213e54f6.md).

---

### ЯвляетсяИсточникомПеретаскивания

`Доступность: Клиент`

```
ЯвляетсяИсточникомПеретаскивания: Авто|Булево
```

Доступен ли режим перетаскивания [Авто](../stdlib/auto-ru-1b14ed166f8e.md) разрешается, как `Истина`.

---

### ЯвляетсяПриемникомПеретаскивания

`Доступность: Клиент`

```
ЯвляетсяПриемникомПеретаскивания: Авто|Булево
```

Можно ли над канбан-доской успешно закончить перетаскивание [Авто](../stdlib/auto-ru-1b14ed166f8e.md) разрешается, как `Истина`.

## События

### ПриНажатииНаКарточку

`Доступность: Клиент`

```
ПриНажатииНаКарточку: (
  КанбанДоска<ТипИсточника, ТипЗначенияКолонки, ТипЗначенияСвимлайна>,
  СобытиеСДанными<КанбанКарточка<ТипИсточника.ItemDataType>>)->ничто
```

Событие вызывается при клике на карточку. СтандартнаяОбработка открывает форму редактирования объекта сущности (для источника ДинамическийСписок) или автоматическую форму редактирования объекта (для источника ИсточникДанныхМассив)

---

### ПриОкончанииПеретаскивания

`Доступность: Клиент`

```
ПриОкончанииПеретаскивания: (
  КанбанДоска<ТипИсточника, ТипЗначенияКолонки, ТипЗначенияСвимлайна>,
  СобытиеПриОкончанииПеретаскиванияКанбана<ТипИсточника.ItemDataType, ТипЗначенияКолонки, ТипЗначенияСвимлайна>)->ничто
```

Событие вызывается при завершении перетаскивания

---

### ПриПроверкеОкончанияПеретаскивания

`Доступность: Клиент`

```
ПриПроверкеОкончанияПеретаскивания: (
  КанбанДоска<ТипИсточника, ТипЗначенияКолонки, ТипЗначенияСвимлайна>,
  СобытиеПриПроверкеОкончанияПеретаскиванияКанбана<ТипИсточника.ItemDataType, ТипЗначенияКолонки, ТипЗначенияСвимлайна>)->ничто
```

Событие вызывается, когда при перетаскивании курсор находится над колонкой канбан-доски

---

### ПриПроверкеНачалаПеретаскивания

`Доступность: Клиент`

```
ПриПроверкеНачалаПеретаскивания: (
  КанбанДоска<ТипИсточника, ТипЗначенияКолонки, ТипЗначенияСвимлайна>,
  СобытиеПриПроверкеНачалаПеретаскиванияКанбана<ТипИсточника.ItemDataType, ТипЗначенияКолонки, ТипЗначенияСвимлайна>)->ничто
```

Событие вызывается при наведении курсора на карточку
