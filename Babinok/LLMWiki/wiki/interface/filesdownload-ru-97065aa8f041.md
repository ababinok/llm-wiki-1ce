## Методы

### НачатьВыгрузку

`Доступность: Клиент`

```
НачатьВыгрузку(
  Ссылка: ДвоичныйОбъект.Ссылка,
  ИмяФайла: Строка? = Неопределено)
```

Параметры:

- `Ссылка`
  
  - ссылка на двоичные данные в хранилище,
- `ИмяФайла`
  
  - задает имя файла, с которым он будет предложен к сохранению. Если не указано - будет использовано
  
  [ИмяФайла](../data/binaryobject-ru-a65f10db6bb3.md)
  
  . Если имя файла двоичного объекта не задано, будет использовано "data.ext", где.ext - расширение, подобранное на основе
  
  [ТипСодержимого](../data/binaryobject-ru-a65f10db6bb3.md)
  
  , или "data" без расширения, если оно не может быть определено по заданному типу содержимого.

Получает двоичные данные с сервера. Пользователю будет показан стандартный диалог сохранения файла. Если браузер настроен на автоматическое сохранение файлов данного типа, то загрузка начнется автоматически.
