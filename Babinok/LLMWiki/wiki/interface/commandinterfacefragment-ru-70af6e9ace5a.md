## Обзор

ТипКоманды: тип команды фрагмента командного интерфейса.

## Документированный контракт и примеры

`Стд::Интерфейс::Команды::ФрагментКомандногоИнтерфейса<ТипКоманды>` `Доступность: Клиент`

ТипКоманды: тип команды фрагмента командного интерфейса. По умолчанию [Команда](command-ru-ad3bc8ea1407.md). Ограничения параметра типа: Стд::Интерфейс::Команды::Команда, Стд::Интерфейс::Команды::КомандаСПараметром<неизвестно>.

Фрагмент командного интерфейса. Используется для модульной разработки командного интерфейса. Также используется для автоматически создаваемого командного интерфейса.
