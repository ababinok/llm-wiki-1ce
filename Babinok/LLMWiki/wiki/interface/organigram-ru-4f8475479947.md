## Обзор

Компонент, описывающий [организационную диаграмму](../project/create-organigram-80333421f9d9.md).

## Документированный контракт и примеры

Компонент, описывающий [организационную диаграмму](../project/create-organigram-80333421f9d9.md).

Органиграмма показывает древовидную структуру компании: верхняя карточка организации соединена с пятью подразделениями — Доставка, Бухгалтерия, Офис, Отдел продаж, Отдел закупок. [Описание иллюстрации](../../raw/figures/239e6af30b2acc77dffb2a3a6191438dcdf16cd2b00a0c9121b80b7dca50fb97-e778421f023267ab.md)

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### НастройкиИсточника

```yaml
НастройкиИсточника: ВычисляемоеВыражение|неизвестно
```

Задает настройки для автоматического заполнения органиграммы по данным в источнике.

---

#### АльтернативнаяОриентацияПоследнегоУровня

```yaml
АльтернативнаяОриентацияПоследнегоУровня: ВычисляемоеВыражение|Авто|Булево
```

Если **Истина**, последний уровень элементов (когда ни один из них не имеет дочерних элементов) отображается перпендикулярно родительскому уровню.

Пример альтернативной ориентации последнего уровня органиграммы: у «Дочерний элемент 1» есть дочерние «1.1» и «1.2», расположенные вертикально справа от него; последний уровень ориентирован перпендикулярно родительскому. [Описание иллюстрации](../../raw/figures/490dde586f894a99240459736c233a602e9e4de9f10aa7da3a4be749b5f94242-4bf7bb49b67a45f0.md)

#### РазмерЭлементов

```yaml
РазмерЭлементов: ВычисляемоеВыражение|Авто|РазмерЭлементовОрганиграммы
```

Определяет размер элементов органиграммы: **Обычный**/**Компактный**.

---

#### ВидМакета

```yaml
ВидМакета: ВычисляемоеВыражение|Авто|ВидМакетаДревовиднойСхемы
```

Определяет вид макета древовидной графической схемы:

- СНачалаВКонец
  
  — элементы располагаются горизонтально с начала в конец,
- СверхуВниз
  
  — элементы располагаются вертикально сверху вниз,
- СКонцаВНачало
  
  — элементы располагаются горизонтально с конца в начало,
- СнизуВверх
  
  — элементы располагаются вертикально снизу вверх.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](organigram-ru-4f8475479947.md) = 1, а у другого [ВесПриРастягивании](organigram-ru-4f8475479947.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../../raw/figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../../raw/figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Доступность

```yaml

```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](organigram-ru-4f8475479947.md).

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](organigram-ru-4f8475479947.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](organigram-ru-4f8475479947.md).

### События

#### ПриНажатии

```yaml
ПриНажатии: Строка
```

Событие, которое возникает при нажатии на графическую схему. При нажатии на элемент в свойстве `Данные` события передается этот элемент. При нажатии на пустую область в свойстве `Данные` события передается `Неопределено`.

---

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
