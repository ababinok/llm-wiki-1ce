## Обзор

ТипДанныхСтроки: тип данных строки динамического списка.

## Документированный контракт и примеры

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::СтрокаДинамическогоСписка<ТипДанныхСтроки>` `Доступность: КлиентИСервер`

ТипДанныхСтроки: тип данных строки динамического списка. По умолчанию [ПроизвольныеДанныеСтрокиДинамическогоСписка](customdynamiclistrowdata-ru-4053fd705a34.md). Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ДанныеСтрокиДинамическогоСписка<неизвестно>.

Содержит ключ и значения полей одной записи динамического списка. Состав полей задается свойством [Поля](dynamiclist-ru-ab61b0be4de4.md). Данный объект создается системой автоматически для каждой записи динамического списка, полученной с сервера.
