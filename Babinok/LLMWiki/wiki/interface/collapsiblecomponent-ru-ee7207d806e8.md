## Обзор

Представляет собой компонент, позволяющий скрывать (сворачивать) и показывать (разворачивать) свое содержимое.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::СворачиваемыйКомпонент` `Доступность: Клиент`

Представляет собой компонент, позволяющий скрывать (сворачивать) и показывать (разворачивать) свое содержимое. Сворачивание и разворачивание осуществляется нажатием на заголовок компонента, который включает в себя:

- Кнопку сворачивания (обязательная)
- Заголовок (обязательный)
- Второстепенный заголовок (необязательный)
- Кнопка действия (необязательная)
- Содержимое (обязательное)

## Свойства

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Основной заголовок сворачиваемого компонента.

---

### Команды

`Доступность: Клиент`

```
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или группа команд, связанных с данным компонентом. Если указаны, то выводятся в конце области заголовка.

---

### ОтступПоВертикали

`Доступность: Клиент`

```
ОтступПоВертикали: Авто|РазмерОтступа
```

Определяет вертикальный отступ от границ сворачиваемого компонента до его содержимого.

---

### ОтступПоГоризонтали

`Доступность: Клиент`

```
ОтступПоГоризонтали: Авто|РазмерОтступа
```

Определяет горизонтальный отступ от границ сворачиваемого компонента до его содержимого.

---

### Подзаголовок

`Доступность: Клиент`

```
Подзаголовок: Строка
```

Дополнительный подзаголовок - выводится под основным заголовком.

---

### Свернут

`Доступность: Клиент`

```
Свернут: Булево
```

Указывает состояние компонента. Если `Истина` - свернут.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент?
```

Компонент, являющийся содержимым сворачиваемого компонента. Как правило один из компонентов [Группа](group-ru-9e7fcb6be273.md).
