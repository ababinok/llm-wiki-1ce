## [ПроизвольныйСписок](customlist-ru-858edf1f6219.md)

`Стд::Интерфейс::Списки::ПроизвольныйСписок<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>.

Компонент списка, который использует [ПроизвольнаяСтрокаСписка](customlistrow-ru-a113b0497543.md) для вывода его записей. При наличии обработчика [ПриНажатииСтроки](list-ru-58c40755a735.md) список устанавливает обработчик события `ПриНажатии` у [Содержимое](customlistrow-ru-a113b0497543.md) каждой строки списка, если обработчик не был установлен разработчиком.

## [Список](list-ru-58c40755a735.md)

`Стд::Интерфейс::Списки::Список<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Базовый тип для компонентов-списков. Компонент-список отображает набор записей данных, например: таблица, список карточек.

---

`Стд::Интерфейс::Списки::СтандартнаяКолонкаТаблицы<ТипДанных,ТипЗначения>` `Доступность: Клиент`

ТипДанных: тип данных строки колонки таблицы ТипЗначения: тип значения непосредственно колонки таблицы

Используется для описания колонок таблицы, отображающих стандартные типы данных.

---

## [СтандартныйСписок](standardlist-ru-8843e0eed4c7.md)

`Стд::Интерфейс::Списки::СтандартныйСписок<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>.

Стандартный список. Позволяет отобразить набор данных в виде списка с элементами стандартной структуры. Описание данных строки задаются через свойства списка с использованием вычисляемых выражений.
