## Обзор

Информационный блок, состоящий из изображения, заголовка и описания без возможности редактирования.

## Документированный контракт и примеры

Информационный блок, состоящий из изображения, заголовка и описания без возможности редактирования. Он может:

- отображаться в виде текста или значка (
  
  [ВидОтображенияЗначения](label-component-975bcb38121f.md)
  
  );
- содержать дополнительное значение, отображаемое в виде значка (
  
  [ДополнительноеЗначение](label-component-975bcb38121f.md)
  
  );
- выполнять переход по указанной гиперссылке (
  
  [Ссылка](label-component-975bcb38121f.md)
  
  ,
  
  [ОбрабатыватьНажатие](label-component-975bcb38121f.md)
  
  ,
  
  [ОткрыватьВНовомОкне](label-component-975bcb38121f.md)
  
  );
- иметь подсказку (
  
  [Подсказка](label-component-975bcb38121f.md)
  
  ,
  
  [ОтображатьПодсказку](label-component-975bcb38121f.md)
  
  ).

## Свойства

### Важность

`Авто|ВажностьКомпонента`. Важность надписи.

Сравнение важности надписи: «Низкая» показана светлее, «Обычная» — обычным тоном, «Высокая» — более контрастным и выраженным текстом. [Описание иллюстрации](../../raw/figures/551c89543e4869638ac9f8c946ca4b4eff06dc0f84bb22c348c661e5dcaddbaa-8f584f8f9a1fa9cf.md)

### ВидОтображенияЗначения

`Авто|ВидОтображенияНадписи`. Способ отображения значения надписи:

- `Авто`
  
  — если тип значения равен
  
  `Перечисление`
  
  , вид отображения равен
  
  `ВидОтображенияНадписи.Значок`
  
  , в остальных случаях —
  
  `ВидОтображенияНадписи.Текст`
  
  ;
- `ВидОтображенияНадписи.Текст`
  
  —
  
  «Элемент»
  
  отображает надпись в виде обычного текста;
- `ВидОтображенияНадписи.Значок`
  
  —
  
  «Элемент»
  
  отображает надпись в виде значка.

Сравнение двух вариантов надписи: слева «Надпись в виде текста» со значением «Текст», справа «Надпись в виде значка» со значением «Значок», оформленным как зелёный значок.. [Описание иллюстрации](../../raw/figures/020e6c41d12c9c22f4c3eea95d6669d5385cf6ce3b2990454233d67874a27792-d72859015dd93b64.md)

### ОтображатьПодсказку

`Авто|ОтображениеПодсказки`. Видимость подсказки:

- `Авто`
  
  — если подсказка не задана или равна пустой строке,
  
  «Элемент»
  
  показывает текст заголовка;
- `ОтображениеПодсказки.НеОтображать`
  
  —
  
  «Элемент»
  
  никогда не показывает подсказку;
- `ОтображениеПодсказки.Всегда`
  
  —
  
  «Элемент»
  
  всегда показывает подсказку при наведении на этот компонент.

### ВыделенныйТекст

Надпись содержит текст «Это надпись вида Текст, в которой выделяется слово “текст”». [Описание иллюстрации](../../raw/figures/c0f4f8ee85067dace601ce005e92db08f1519d1453fea19f972e83c722991ba5-7b313798012f66dc.md)

### Значение

### Изображение

`Url|ДвоичныйОбъект.Ссылка|?`. Ссылка на изображение, которое показывается рядом с заголовком.

### МаксимальнаяВысотаВСтроках

`Авто|Число`. Максимальная высота надписи в строках. Значение `0` означает, что высота не ограничена.

### МинимальнаяВысотаВСтроках

`Авто|Число`. Минимальная высота надписи в строках. Вертикальный размер надписи не станет меньше этого значения, несмотря на содержимое текста. Это свойство можно использовать для выравнивания высоты строк в таблицах или в других компонентах.

### ОбрабатыватьНажатие

`Авто|Булево`. Отображение надписи в виде гиперссылки.

- `Авто`
  
  —
  
  `Истина`
  
  , если свойство
  
  Значение
  
  имеет ссылочный тип, заполнено свойство
  
  Ссылка
  
  или задан обработчик события
  
  ПриНажатии
  
  ;
- `Истина`
  
  — компонент имеет вид гиперссылки, может принимать фокус и вызывает событие
  
  ПриНажатии
  
  ;
- `Ложь`
  
  — компонент имеет вид обычной надписи, не может принимать фокус, а нажатие обрабатывают родительские компоненты.

Надпись, обрабатывающая нажатие, имеет вид синей гиперссылки; наведённый курсор показан в форме руки, над ссылкой расположен заголовок надписи. [Описание иллюстрации](../../raw/figures/e15a96acd9178f3c24e25e4d16ccbf37cd8fb28c009393d5b8eb183897a73472-95adad0a4aaba672.md)

### ОписаниеЗначкаДополнительногоЗначения

`Авто|ОписаниеЗначка`. Описание значка дополнительного значения.

### ОписаниеЗначкаОсновногоЗначения

`Авто|ОписаниеЗначка`. Описание значка основного значения надписи, если свойство **ВидОтображенияЗначения** равно **Значок**.

### ОткрыватьВНовомОкне

`Авто|Булево`. Признак того, что ссылка, указанная в свойстве **Ссылка**, будет открыта в новом окне (вкладке) браузера.

### ОценкаИнформации

`Авто|ОценкаИнформации`. Оформление надписи. Возможные значения: `Положительная`, `Предупреждающая`, `Отрицательная`, `Обычная`.

Сравнение оценки информации в надписи: положительная — зелёное оформление, отрицательная — красное, предупреждающая — жёлтое, обычная — нейтральное оформление зелёного оттенка в примере. [Описание иллюстрации](../../raw/figures/da8ae7eb31fe50dae0cd78f39531fea2e63a746fa2262ed5bf9f3a52a9ab5c60-ca4843ef654f2d4a.md)

### Подсказка

`Авто|Строка`. Текст подсказки, который «Элемент» покажет при наведении на надпись.

Пример надписи с подсказкой: при наведении указателя на «Значение надписи» ниже появляется тёмная плашка с текстом «Это подсказка для надписи». [Описание иллюстрации](../../raw/figures/1f85fc53a25d738992311ba1230d26aa0e6f1d1352489332863e94f99efef47d-5901788ee8c14196.md)

### РазрешитьСжатие

`Авто|Булево`. Признак того, что «Элемент» может сжать надпись.

### РастягиватьРодителя

`Авто|Булево`. Признак того, что «Элементу» нужно растянуть родительский компонент. Если равно `Ложь`, то надпись не будет влиять на размеры родительского компонента.

### Ссылка

`Сущность.Ключ|Строка|?`. Ссылка, которую откроет «Элемент» при нажатии на компонент.

### УровеньЗаголовка

`УровеньЗаголовка|Авто`. Уровень заголовка обычной надписи (для которой заполнено только свойство [Значение](label-component-975bcb38121f.md)). Задается с помощью значения перечисления [`УровеньЗаголовка`](headerlevel-ru-323f5f8c91e3.md). Для автоматического определения уровня заголовка используйте значение [`РассчитыватьАвтоматически`](headerlevel-ru-323f5f8c91e3.md).

`Авто` равно [`УровеньЗаголовка.НеИспользовать`](headerlevel-ru-323f5f8c91e3.md).

Данное свойство определяет только семантический заголовок надписи в HTML-разметке страницы и используется для [SEO-оптимизации приложения](../project/seo-optimization-27876869518e.md). Оно не влияет на отображение надписи и не переопределяет другие свойства компонента.

### Цвет

`Авто|Цвет`. Цвет текста надписи. Итоговый цвет надписи определяется исходя из значений следующих свойств:

- [ОценкаИнформации](label-component-975bcb38121f.md)
  
  , если отличается от
  
  `Авто`
  
  и
  
  `Обычная`
  
  ;
- `Цвет`
  
  , если отличается от
  
  `Авто`
  
  ;
- цвет по умолчанию.

### Шрифт

`Авто|Шрифт`. Шрифт надписи. Свойство игнорируется, если надпись отображается как **Значок** или для нее определены **Заголовок**, **Изображение** или **ДополнительноеЗначение**.

### ВыравниваниеВГруппеПоВертикали

Способ вертикального выравнивания этого компонента внутри родительской группы:

- `Авто`
  
  — значение
  
  `ВыравниваниеПоВертикали.ПоБазовойЛинии`
  
  ;
- элементы перечисления
  
  `ВыравниваниеПоВертикали`
  
  —
  
  `Верх`
  
  ,
  
  `Центр`
  
  ,
  
  `Низ`
  
  ,
  
  `ПоБазовойЛинии`
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../../raw/figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение `Низ`, а у второго — `Верх`, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../../raw/figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

Позволяет управлять индивидуальным положением компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри горизонтальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены в начале, то последний компонент можно расположить в конце.

Пример горизонтального выравнивания: первые два компонента расположены в начале горизонтальной группы, последний — у противоположного края. [Описание иллюстрации](../../raw/figures/847e0f298697131e0fbd9b50b89d51e41a8dfd698a7ee3cc05b3b09baa35ad3c-8b1963441d35a227.md)

Если у компонентов внутри группы указаны разные способы горизонтального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение `Конец`, а у второго — `Начало`, то оба компонента окажутся в конце группы.

Пример конфликта горизонтального выравнивания: у второго компонента задано «Конец», у третьего — «Начало». [Описание иллюстрации](../../raw/figures/b99103f735cf8368faa3abd48f5cc63c3afc8224aa3de6451a1d06812af2d2ba-56a203a23c12d5d9.md)

### Высота

`Авто|Число`. Высота компонента в пикселях ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

Если `Авто`, то рассчитывается автоматически. Явно заданное значение высоты применяется, только если оно отлично от 0 и [РастягиватьПоВертикали](label-component-975bcb38121f.md) равно `Ложь`.

### Доступность

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством `ТолькоЧтение`.

### МинимальнаяВысота

### ТолькоЧтение

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние `ТолькоЧтение` распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство `Доступность`.

### Ширина

`Авто|Число`. Ширина компонента в пикселях ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

Если `Авто`, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](label-component-975bcb38121f.md) равно `Ложь`.

### ШиринаВКолонках

`Авто|ШиринаВКолонках`. Ширина компонента в [колонках](widthincolumns-ru-f14525640914.md). Если `Авто`, то рассчитывается автоматически.

### <Свойство разработчика>

Собственное свойство компонента, добавленное разработчиком. Описывается следующими свойствами:

#### ЗначениеПоУмолчанию

Стандартное значение свойства. Значение можно не указывать, если у его типа/типов есть значение по умолчанию (в частности, если его тип включает `Неопределено` или `Null`). Если тип свойства составной (включает несколько типов), необходимо указать тип значения. Иначе просто само значение.

В [описании экземпляра](system-and-interface-components-18287074edda.md) этого компонента вы можете установить другое значение этому свойству.

#### Имя

Имя свойства.

#### Контекстное

`Булево`. Признак доступности значения свойства на клиенте и сервере. Значение по умолчанию — `Ложь`. Если `Истина`, то поле **Тип** свойства должно содержать тип, доступный на клиенте и сервере.

«1С:Предприятие.Элемент» генерирует структурный тип [`{ИмяКомпонента}.Контекст`](componentname-context-ru-e40a3f370a75.md), который содержит как собственные контекстные свойства, так и контекстные свойства, наследуемые от базовых системных типов. Этот тип генерируется всегда, даже если контекстные свойства отсутствуют.

Пример:

```yaml
Имя: МойКомпонент
Свойства:
    -
        Имя: КонтекстноеСвойство
        Тип: Строка
        Контекстное: Истина
```

Для работы с контекстными свойствами на сервере вы можете использовать *контекстные серверные методы*. Эти методы должны располагаться в модуле компонента интерфейса и содержать аннотации [`@Контекстный`](../stdlib/contextual-ru-468258bf9c74.md) и [`@НаСервере`](../stdlib/onserver-ru-ff4072dae1ed.md). В теле метода тип объекта `этот` заменяется на [`{ИмяКомпонента}.Контекст`](componentname-context-ru-e40a3f370a75.md). Состояние этого объекта передается с клиента на сервер при каждом вызове метода. На сервере в теле метода вы можете изменить состояние объекта. Измененное состояние будет автоматически передано на клиент, и компонент будет инициализирован заново с учетом внесенных изменений.

Пример изменения значения контекстного свойства на сервере:

```xbsl
@НаСервере @ДоступноСКлиента
@Контекстный
метод КонтекстныйМетод()
    этот.ПолучитьТип() // Вернет "ИмяКомпонента.Контекст"
    // Задание значения контекстного свойства на сервере
    КонтекстноеСвойство = "Значение"
;
```

#### СохраняемыеДанные

`Истина` — при изменении значения этого свойства «Элемент» установит свойство `СобственнаяМодифицированность` компонента в значение `Истина`. После записи данных вы должны самостоятельно присвоить свойству `СобственнаяМодифицированность` значение `Ложь`.

#### Тип

Тип свойства.

### <Событие разработчика>

Собственное событие компонента, добавленное разработчиком. Здесь вы описываете только само событие, обработчик этого события необходимо назначить при [описании экземпляра](system-and-interface-components-18287074edda.md) этого компонента. О вызове и назначении обработчиков собственных событий компонента можно прочитать [здесь](component-example-077c0c8b7fb0.md). Каждое событие описывается следующими свойствами:

- Имя
  
  — имя события.
- Тип
  
  — тип объекта события:
  
  - тип должен быть наследником типа
    
    `СобытиеКомпонента`
    
    ;
  - если значение не указано, то тип события —
    
    `СобытиеКомпонента`
    
    .

## События

### ПриНажатии

«Элемент» вызывает это событие при нажатии на надпись, если свойство **Гиперссылка** равно **Истина**.

Пример YAML-файла:

```yaml
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: ВПодсистеме
Ид: e424be94-aa77-4808-9d52-f51aebe6182a
Имя: МояНадпись
Наследует:
    Тип: Надпись
    ПриНажатии: ОбработчикПриНажатии
```

Сигнатура обработчика события:

```xbsl
метод ОбработчикПриНажатии(Источник: Надпись, Событие: СобытиеПриНажатии)
    // Обработка события...
;
```

### ПослеСоздания

Переопределяемый обработчик. Предназначен для дополнительной инициализации свойств экземпляра компонента на клиенте и вызова прикладной логики инициализации экземпляра компонента. Выполняется после полного конструирования экземпляра компонента, т. е. когда:

- установлены значения свойств экземпляра компонента, указанные при
  
  [описании экземпляра](system-and-interface-components-18287074edda.md)
  
  ;
- созданы свои компоненты данного экземпляра;
- значения свойств своих компонентов установлены из описаний их экземпляров;
- подключены обработчики событий в экземпляре компонента и в экземплярах его внутренних компонентов.

Сигнатура обработчика:

```xbsl
@Обработчик
метод ПослеСоздания()
// Обработка события...
;
```

### ПриНаведении

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

Когда указатель мыши покидает область компонента, вызывается событие **ПриПотереНаведения**.

### ПриПеретаскивании

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство `СобытиеПриПеретаскивании.СтандартнаяОбработка` не равно `Ложь`, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от `КлиентскоеПриложение`. На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

### ПриПотереНаведения

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

При наведении указателя мыши на область компонента вызывается событие **ПриНаведении**.
