## Обзор

Компонент интерфейса **ПанельЭтапов** используется для отображения последовательности этапов.

## Документированный контракт и примеры

Компонент интерфейса **ПанельЭтапов** используется для отображения последовательности этапов. Этапы могут представлять собой последовательность событий во времени или любые последовательные действия.

Панель этапов с пиктограммами: «Оформлен», «Сборка», «В пути», «Доставлен». Пройденные связи сплошные и синие, будущий переход к доставке показан серым пунктиром. [Описание иллюстрации](../../raw/figures/fc03c79158620ae39207e922d692be0dd670276672f282187816862b7fba031f-fabcbace8171cd3d.md)

Панель этапов может располагаться как вертикально, так и горизонтально (согласно значению свойства [Ориентация](stagespanel-ru-f1ef84720ca1.md)). Если в горизонтальной панели этапы не вмещаются в отведенную ширину, появляется кнопка, при нажатии на которую отображается окно с оставшимися этапами. В мобильной версии вместо кнопки показывается горизонтальная полоса прокрутки. Этапы вертикальной панели могут быть свернуты в соответствии с настройкой [РежимСворачивания](stagespanel-ru-f1ef84720ca1.md).

Каждый этап может отображаться как пройденный или непройденный. Соблюдается следующий порядок следования: от пройденных этапов к непройденным сверху вниз или слева направо.

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Этапы

```yaml
Этапы: ВычисляемоеВыражение|неизвестно
```

Задает список этапов.

Для полноценной настройки отображения этапов используйте массив объектов типа [ЭлементПанелиЭтапов](stagespanelitem-ru-f2f5b69d14f9.md).

В качестве списка этапов можно использовать массив элементов любого типа. Строковое представление этих элементов будет использоваться в качестве значений свойства [Заголовок](stagespanelitem-ru-f2f5b69d14f9.md).

Если в качестве типа данных используется [Перечисление](../stdlib/enum-ru-a7a357b96b4c.md), список этапов можно не указывать. «1С:Предприятие.Элемент» автоматически создаст панель этапов на основании элементов перечисления.

---

#### ТекущийЭтап

```yaml
ТекущийЭтап: ВычисляемоеВыражение|неизвестно
```

Определяет значение текущего этапа. Соответствует свойству [Значение](stagespanelitem-ru-f2f5b69d14f9.md), если в свойстве [Этапы](stagespanel-ru-f1ef84720ca1.md) используется массив объектов [ЭлементПанелиЭтапов](stagespanelitem-ru-f2f5b69d14f9.md).

Разделяет визуальное отображение списка на пройденные и непройденные этапы.

---

#### Ориентация

```yaml
Ориентация: ВычисляемоеВыражение|Авто|ОриентацияСодержимого
```

Указывает расположение этапов в компоненте: по горизонтали или по вертикали. Не рекомендуется использовать горизонтальную ориентацию в процессах, которые имеют более 6 этапов.

При **Авто** используется вертикальная ориентация.

---

#### РежимСворачивания

```yaml
РежимСворачивания: ВычисляемоеВыражение|Авто|РежимСворачиванияПанелиЭтапов
```

Режим сворачивания этапов компонента в вертикальной ориентации. Определяет, какая часть компонента до и/или после текущего этапа должна быть свернута. Согласно правилам сворачивания всегда раскрыты текущий этап и следующий за ним, а также последний.

Если панель содержит большое количество этапов, вы можете использовать это свойство, чтобы скрыть часть из них.

Возможные значения:

- **Авто** равно **Не сворачивать**.
- **Не сворачивать** — отображает все этапы.
- **Сворачивать в начале** — сворачивает все этапы до текущего и отображает кнопку для их разворачивания. Используйте эту опцию, когда текущий этап уже приближается к последнему и требуется скрыть все этапы до него.
  
  Вертикальная панель «Этапы разработки проекта» начинается с кнопки «Развернуть (3)», которая обозначает три скрытых ранних этапа. [Описание иллюстрации](../../raw/figures/bc1151688c7fbeb67009e572ceeb023f70dbe50d4cf9b0aaf9d4df0513cc2216-4f51ae87eaa0bafc.md)
- **Сворачивать в конце** — сворачивает все этапы после следующего за текущим и до последнего (последний этап раскрыт). Для скрытых этапов отображается кнопка разворачивания. Используйте эту опцию, когда текущий этап находится в начале и требуется скрыть все этапы до последнего.
  
  Пример режима «Сворачивать в конце» у панели этапов: сначала показаны несколько начальных этапов; перед последним этапом «Ретроспектива и поддержка» находится кнопка «Развернуть (8)» для скрытых промежуточных этапов. [Описание иллюстрации](../../raw/figures/29eb093588eaa172de60a422a565c1b5bc8a8bc841f5bb743cca79507ccf10ca-3b5aedca6703d0f9.md)
- **Сворачивать полностью** — одновременно применяет режимы **Сворачивать в начале** и **Сворачивать в конце**. Используйте эту опцию, когда требуется компактное отображение панели этапов вне зависимости от положения текущего этапа.
  
  Пример полностью свёрнутой панели этапов: текущий этап «2: Бизнес-логика» выбран сверху. [Описание иллюстрации](../../raw/figures/25447bba1a73aac95a7331cb6dc16526273f61f40022c7d9db317f0d8a9864cd-aa8b847bdeb33015.md)

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](stagespanel-ru-f1ef84720ca1.md) = 1, а у другого [ВесПриРастягивании](stagespanel-ru-f1ef84720ca1.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../../raw/figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../../raw/figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](stagespanel-ru-f1ef84720ca1.md).

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](stagespanel-ru-f1ef84720ca1.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](stagespanel-ru-f1ef84720ca1.md).

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](stagespanel-ru-f1ef84720ca1.md) равно **Ложь**.

---

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
