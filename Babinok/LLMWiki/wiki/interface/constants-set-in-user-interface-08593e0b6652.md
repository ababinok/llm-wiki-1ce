## Документированный контракт и примеры

Во время работы приложения «1С:Предприятие.Элемент» автоматически генерирует формы списка и записи для набора констант. Вы не можете изменить внешний вид или логику работы этих форм.

> Форма списка доступна только для [периодических наборов](../project/constants-set-element-3c8e873b235a.md).

## Создание собственных форм

Вы можете создать собственные формы, а затем указать, что набор констант должен использовать именно их, с помощью свойств **Интерфейс.Список.Форма** и **Интерфейс.Запись.Форма**.

Чтобы создать формы в коде, используйте методы [`СоздатьФормуСписка()`](../stdlib/constantssetname-ru-10721a2e334f.md) и [`СоздатьФормуЗаписи()`](../stdlib/constantssetname-ru-10721a2e334f.md) типа [`{ИмяНабораКонстант}`](../stdlib/constantssetname-ru-10721a2e334f.md).

Например:

```xbsl
ДанныеОрганизации.СоздатьФормуЗаписи()
```

Если для набора констант задана соответствующая форма, то создается форма этого типа. Иначе создается автоматическая форма.

## Команды открытия форм

При добавлении элемента проекта **НаборКонстант** «1С:Предприятие.Элемент» порождает типы для работы с автоматическими формами: [`{ИмяНабораКонстант}.АвтоматическаяФормаЗаписи`](../stdlib/constantssetname-automaticrecordform-ru-61f6e8bd7e14.md) и [`{ИмяНабораКонстант}.АвтоматическаяФормаСписка`](../stdlib/constantssetname-automaticlistform-ru-ba52b8f6bda1.md) и добавляет в автоматический интерфейс приложения команды их открытия.

Добавление форм в автоматический интерфейс приложения настраивается в группе свойств [Интерфейс](../project/constantsset-bae2805eef0b.md).

По умолчанию команды, которые «1С:Предприятие.Элемент» добавляет в интерфейс приложения, в качестве своего представления используют имя набора констант в проекте. Вы можете изменить представление команд с помощью свойств **Интерфейс.Список.Представление** и **Интерфейс.Запись.Представление**. Указанное представление будет также использоваться в качестве представления команд `{ИмяНабораКонстант}.АвтоматическаяФормаСписка.Открыть()` и `{ИмяНабораКонстант}.АвтоматическаяФормаЗаписи.Открыть()`.
