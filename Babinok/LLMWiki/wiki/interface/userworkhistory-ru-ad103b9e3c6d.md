## Обзор

Позволяет записывать объекты в Историю работы Пользователя, а так же загружать историю для последующих взаимодействий.

## Документированный контракт и примеры

`Стд::Интерфейс::История::ИсторияРаботыПользователя` `Тип-одиночка` `Доступность: Клиент`

Позволяет записывать объекты в Историю работы Пользователя, а так же загружать историю для последующих взаимодействий. История Работы Пользователя ведется в разрезе конкретного клиентского приложения. Для клиентских приложений с режимом без аутентификации запись не производится, а загрузка всегда возвращает пустой массив.

### Записать

`Доступность: Клиент` `Статический`

```
Записать(Объект: Сущность.Ключ)
```

Записывает сущность в Историю Работы Пользователя

**Перегрузка** [Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка)](userworkhistory-ru-ad103b9e3c6d.md) [Записать(Ссылка: Строка, Представление: Строка)](userworkhistory-ru-ad103b9e3c6d.md)

#### Примеры

```xbsl
метод ЗаписатьВИсториюДоговор(ДоговорСсылка: Договоры.Ссылка?)
    // Запишет в Историю Работы Пользователя элемент справочника "Договоры", например "Договор-0001" 
    // с представлением "Договор-0001"
    ИсторияРаботыПользователя.Записать(ДоговорСсылка)
;
```

### Записать

`Доступность: Клиент` `Статический`

```
Записать(
  Ссылка: Строка,
  Представление: Строка)
```

Записывает произвольную ссылку в Историю работы пользователя с указанным представлением.

**Перегрузка** [Записать(Объект: Сущность.Ключ)](userworkhistory-ru-ad103b9e3c6d.md) [Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка)](userworkhistory-ru-ad103b9e3c6d.md)

#### Примеры

```xbsl
метод ЗаписатьСсылку()
    // Запишет в Историю Работы Пользователя ссылку "https://1cmycloud.com/welcome/" с 
    // представлением "1С:Предприятие.Элемент"
    ИсторияРаботыПользователя.Записать("https://1cmycloud.com/welcome/", "1С:Предприятие.Элемент")
;
```

### Записать

`Доступность: Клиент` `Статический`

```
Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка)
```

Записывает форму в Историю работы пользователя с указанным представлением.

**Перегрузка** [Записать(Объект: Сущность.Ключ)](userworkhistory-ru-ad103b9e3c6d.md) [Записать(Ссылка: Строка, Представление: Строка)](userworkhistory-ru-ad103b9e3c6d.md)

#### Примеры

```xbsl
метод ЗаписатьФорму()
    // Внутри формы ГруппаЗаказовФорма
    // Запишет в Историю Работы Пользователя форму ГруппаЗаказовФорма с представлением "Группа заказов"
    ИсторияРаботыПользователя.Записать(этот, "Группа заказов")
;
```
