## Обзор

ТипДанных: Тип значения компонента **ПанельЭтапов**.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::ПанельЭтапов<ТипДанных>` `Доступность: Клиент`

ТипДанных: Тип значения компонента **ПанельЭтапов**. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент **ПанельЭтапов** отображает последовательность этапов в заданном порядке. Этапы могут представлять собой последовательность событий во времени или любые другие последовательные события.

Для компонента **ПанельЭтапов** поддерживается вертикальная и горизонтальная ориентация.

Если **ПанельЭтапов** имеет горизонтальную ориентацию и ее этапы не вмещаются в отведенную ширину, появляется кнопка, при нажатии на которую отображается окно с оставшимися этапами. В мобильной версии вместо кнопки показывается горизонтальная полоса прокрутки.

В вертикальном виде **ПанельЭтапов** может отображаться в свернутом состоянии, в развернутом виде этапы отображаются на всю высоту. При сворачивании этапов соблюдаются следующие правила:

- текущий (действующий) этап всегда раскрыт,
- этап после текущего всегда раскрыт,
- последний этап всегда раскрыт.

Остальные этапы могут сворачиваться согласно свойству [РежимСворачивания](stagespanel-ru-b1a7361a0cec.md). Для скрытых этапов отображается кнопка разворачивания. Панель может содержать одну или две кнопки разворачивания. После нажатия на кнопку скрытые этапы разворачиваются без возможности свернуть их обратно (после разворачивания кнопка пропадает).

Каждый этап может быть пройденным или непройденным. Соблюдается следующий порядок следования: от пройденных этапов к непройденным сверху вниз или слева направо.

## Свойства

### Ориентация

`Доступность: Клиент`

```
Ориентация: Авто|ОриентацияСодержимого
```

Указывает расположение этапов в компоненте: по горизонтали или вертикали.

Не рекомендуется использовать горизонтальную ориентацию в процессах, которые имеют более 6 этапов.

При [Авто](../stdlib/auto-ru-1b14ed166f8e.md) используется вертикальная ориентация.

---

### РежимСворачивания

`Доступность: Клиент`

```
РежимСворачивания: Авто|РежимСворачиванияПанелиЭтапов
```

Режим сворачивания компонента в вертикальной ориентации. Определяет, какая часть компонента до и/или после текущего этапа будет свернута. Согласно правилам сворачивания всегда раскрыты текущий этап и следующий за ним, а также последний.

Вы можете использовать данное свойство для обеспечения компактного вида панели, когда количество этапов достаточно большое и необходимо частично их скрыть. Не используйте это свойство в сценариях, когда пользователь должен видеть все этапы сразу.

- [СворачиватьВНачале](stagespanelcollapsingmode-ru-40bf70b70d64.md) — этапы до текущего сворачиваются, и для них отображается кнопка разворачивания. Рекомендуем использовать эту опцию, когда текущий этап уже приближается к последнему и требуется скрыть все этапы до него.
- [СворачиватьВКонце](stagespanelcollapsingmode-ru-40bf70b70d64.md) — этапы между следующим за текущим и последним сворачиваются (последний этап остается раскрыт). Для скрытых этапов отображается кнопка разворачивания. Рекомендуем использовать эту опцию, когда текущий этап находится в начале и требуется скрыть все этапы до последнего.
- [СворачиватьПолностью](stagespanelcollapsingmode-ru-40bf70b70d64.md) — одновременно включены [СворачиватьВНачале](stagespanelcollapsingmode-ru-40bf70b70d64.md) и [СворачиватьВКонце](stagespanelcollapsingmode-ru-40bf70b70d64.md). Рекомендуем использовать эту опцию, когда требуется компактный вид панели вне зависимости от положения текущего этапа.
- [Авто](../stdlib/auto-ru-1b14ed166f8e.md) = [НеСворачивать](stagespanelcollapsingmode-ru-40bf70b70d64.md)

### ТекущийЭтап

`Доступность: Клиент`

```
ТекущийЭтап: ТипДанных
```

Определяет значение текущего (действующего) этапа. Соответствует свойству [Значение](stagespanelitem-ru-f2f5b69d14f9.md), если в свойстве [Этапы](stagespanel-ru-b1a7361a0cec.md) используются объекты [ЭлементПанелиЭтапов](stagespanelitem-ru-f2f5b69d14f9.md).

Фактически разделяет визуальное отображение списка на пройденные и непройденные этапы.

---

### Этапы

`Доступность: Клиент`

```
Этапы: Авто|ЧитаемыйМассив<ТипДанных|ЭлементПанелиЭтапов<ТипДанных>>
```

Устанавливает список этапов.

Полноценное задание этапа возможно при использовании специализированного типа [ЭлементПанелиЭтапов](stagespanelitem-ru-f2f5b69d14f9.md).

В качестве списка можно использовать массив элементов любого типа, указанного в параметре `ТипДанных`. В этом случае используется строковое представление элементов этого типа, которое будет соответствовать свойству [Заголовок](stagespanelitem-ru-f2f5b69d14f9.md).

При [Авто](../stdlib/auto-ru-1b14ed166f8e.md) для параметра `ТипДанных`, наследуемого от типа [Перечисление](../stdlib/enum-ru-a7a357b96b4c.md), список этапов указывать необязательно. Система сама построит интерфейс на основании элементов перечисления.
