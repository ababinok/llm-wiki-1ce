## Свойства

### Выравнивание

`Доступность: Клиент`

```
Выравнивание: Авто|ВыравниваниеПоГоризонтали
```

Выравнивание воронкообразной диаграммы. Значение [ПоШирине](horizontalalign-ru-31ae73a95403.md) эквивалентно значению [Центр](horizontalalign-ru-31ae73a95403.md).

---

### ОтображатьАбсолютныеДоли

`Доступность: Клиент`

```
ОтображатьАбсолютныеДоли: Авто|Булево
```

Отображать ли проценты относительно первого этапа воронки. Проценты отображаются рядом с маркером вне воронки (либо вместо маркера при его отсутствии).

---

### ОтображатьВнешниеМаркеры

`Доступность: Клиент`

```
ОтображатьВнешниеМаркеры: Авто|Булево
```

Отображать ли названия этапов снаружи воронки.

---

### ОтображатьВнутренниеМаркеры

`Доступность: Клиент`

```
ОтображатьВнутренниеМаркеры: Авто|Булево
```

Отображать ли числовые значения этапов внутри воронки.

---

### ОтображатьОтносительныеДоли

`Доступность: Клиент`

```
ОтображатьОтносительныеДоли: Авто|Булево
```

Отображать ли проценты относительно предыдущего этапа воронки. Проценты отображаются в переходе между этапами.

---
