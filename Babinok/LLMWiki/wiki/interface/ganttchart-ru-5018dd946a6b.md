## Свойства

### ВидОтображенияКомандСтроки

`Доступность: Клиент`

```
ВидОтображенияКомандСтроки: Авто|ВидОтображения
```

Задает вид отображения команд строки. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md), то вид отображения команд определяется системой.

---

### ДопустимыеМасштабы

`Доступность: Клиент`

```
ДопустимыеМасштабы: Авто|Множество<Авто|МасштабДиаграммыГанта>
```

Множество доступных масштабов. Пустое множество - разрешены все.

---

### Источник

`Доступность: Клиент`

```
Источник: ТипИсточника
```

Задаёт источник данных для диаграммы ганта

---

### Колонки

`Доступность: Клиент`

```
Колонки: Массив<КолонкаТаблицы<ТипИсточника.NodesDataType>>
```

Описание колонок таблицы диаграммы Ганта. Если свойство колонки задается вычисляемым выражением, то в него передается параметр `ДанныеСтроки`(`RowData`) с типом [ЭлементДиаграммыГанта](ganttchartitem-ru-952871018e2b.md).

---

### КомандыСтроки

`Доступность: Клиент`

```
КомандыСтроки: ФрагментКомандногоИнтерфейса<КомандаСПараметром<ТипИсточника.NodesDataType>>?
```

Команды над строкой. В качестве параметров команд передается объект [ЭлементДиаграммыГанта](ganttchartitem-ru-952871018e2b.md).

---

### Масштаб

`Доступность: Клиент`

```
Масштаб: Авто|МасштабДиаграммыГанта
```

Масштаб диаграммы ганта. По умолчанию равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md) - определяется автоматически, исходя из данных диаграммы (ее интервалов).

---

### ОтображаемыйДиапазон

`Доступность: Клиент`

```
ОтображаемыйДиапазон: Авто|Диапазон<Момент>
```

Задает диапазон, отображаемый на диаграмме Ганта. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md), диапазон определяется автоматически

---

### ПрокруткаПоВертикали

`Доступность: Клиент`

```
ПрокруткаПоВертикали: Авто|Булево
```

Включает вертикальную прокрутку диаграммы.

---

### ПрокруткаПоГоризонтали

`Доступность: Клиент`

```
ПрокруткаПоГоризонтали: Авто|Булево
```

Разрешает или запрещает диаграмме Ганта прокрутку по горизонтали для сохранения размера интервалов. Если значение равно `Ложь`, диаграмма будет помещать всю необходимую область (заданную явно свойством [ОтображаемыйДиапазон](ganttchart-ru-5018dd946a6b.md), или определенную автоматически) в свой размер. Если значение равно `Истина`, то при уменьшении размеров родительской группы возможно появления полосы прокрутки для сохранения комфортного размера интервалов. При увеличении размеров контейнера диаграмма будет автоматически расширять отображаемый диапазон.

---

### РасположениеТаблицы

`Доступность: Клиент`

```
РасположениеТаблицы: Авто|РасположениеТаблицыДиаграммыГанта
```

Определяет положение таблицы диаграммы Ганта. Если [Авто](../stdlib/auto-ru-1b14ed166f8e.md), то в мобильной версии - [Переключатель](ganttcharttablelocation-ru-42fb4f5e5d21.md), в веб-версии - [ВНачале](ganttcharttablelocation-ru-42fb4f5e5d21.md).

---

## События

### ПриВыделенииЭлемента

`Доступность: Клиент`

```
ПриВыделенииЭлемента: (
  ДиаграммаГанта<ТипИсточника>,
  СобытиеПриНажатииНаДиаграммуГанта<ТипИсточника.NodesDataType>)->ничто
```

Возникает при выделении элемента диаграммы Ганта. В событие передается объект типа [ИнтервалДиаграммыГанта](ganttchartinterval-ru-e3894735472b.md), на котором произведено нажатие, или `Неопределено`, если нажатие произошло мимо элемента. В свойстве `СобытиеПриВыделенииЭлементаДиаграммыГанта.Элемент` передается элемент, внутри которого было нажатие.

---

### ПриИзмененииМасштаба

`Доступность: Клиент`

```
ПриИзмененииМасштаба: (
  ДиаграммаГанта<ТипИсточника>,
  СобытиеПриИзмененииМасштабаДиаграммыГанта)->ничто
```

Возникает при интерактивном изменении масштаба диаграммы Ганта пользователем.
