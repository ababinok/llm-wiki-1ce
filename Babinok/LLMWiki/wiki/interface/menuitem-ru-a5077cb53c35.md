Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / Interface.

Имена для поиска: `ЭлементМеню`, `MenuItem`, `Стд::Интерфейс::ЭлементМеню`, `Std::Interface::MenuItem`.

## Обзор

Описывает элемент (пункт) меню.

## Документированный контракт и примеры

`Стд::Интерфейс::ЭлементМеню` `Доступность: КлиентИСервер`

Описывает элемент (пункт) меню. Может содержать внутренние пункты.

**Сравнение**

Структурное

## Свойства

### ДополнительныеПараметры

`Доступность: КлиентИСервер`

```
ДополнительныеПараметры: Объект?
```

Любые дополнительные данные, связанные с этим пунктом меню. Могут использоваться в обработке события выбора из меню.

---

### Заголовок

`Доступность: КлиентИСервер`

```
Заголовок: Строка
```

Заголовок пункта меню.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: КлиентИСервер`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Картинка пункта меню. Рекомендуется использовать картинки размером 24х24 пикселя.

---
