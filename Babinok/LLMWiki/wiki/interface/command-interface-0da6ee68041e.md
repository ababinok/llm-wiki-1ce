## Обзор

Часть пользовательского интерфейса, предназначенная для выполнения команд и навигации по приложению.

## Документированный контракт и примеры

Часть пользовательского интерфейса, предназначенная для выполнения команд и навигации по приложению. Включает в себя кнопки, ссылки, команды, которые позволяют пользователю перемещаться по разделам приложения, открывать формы, выполнять те или иные действия.
