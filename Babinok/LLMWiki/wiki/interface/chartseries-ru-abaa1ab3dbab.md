## Обзор

Описывает серию данных диаграммы с сериями.

## Документированный контракт и примеры

`Стд::Интерфейс::Диаграммы::СерияДиаграммы<ТипПолейДанных>` `Доступность: КлиентИСервер`

Описывает серию данных диаграммы с сериями.

## Свойства

### Имя

`Доступность: КлиентИСервер`

```
Имя: Строка
```

Имя серии, которое будет отображаться в легенде диаграммы.

---

### ОтображатьВЛегенде

`Доступность: КлиентИСервер`

```
ОтображатьВЛегенде: Авто|Булево
```

Признак того, что серия отображается в легенде.

---

### ПоляДанных

`Доступность: КлиентИСервер`

```
ПоляДанных: ТипПолейДанных
```

Определяет отображение данных на серию.
