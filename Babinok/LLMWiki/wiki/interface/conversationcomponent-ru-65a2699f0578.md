## Обзор

Компонент обсуждения Системы Взаимодействия.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::КомпонентОбсуждения` `Доступность: Клиент`

Компонент обсуждения Системы Взаимодействия. Позволяет общаться с другими пользователями в рамках заданного обсуждения. Идентификатор обсуждения устанавливается при помощи соответствующего метода. Для корректной работы компонента необходимо предварительно зарегистрировать приложение на сервере Системы Взаимодействия.

## Методы

### УстановитьИдОбсуждения

`Доступность: Клиент`

```
УстановитьИдОбсуждения(ИдОбсуждения: Ууид)
```

Устанавливает идентификатор текущего обсуждения

---

### УстановитьКонтекстОбсуждения

`Доступность: Клиент`

```
УстановитьКонтекстОбсуждения(КонтекстОбсуждения: Сущность.Ключ|Строка)
```

Устанавливает контекст обсуждения. Если обсуждения с таким контекстом еще нет, оно будет создано.
