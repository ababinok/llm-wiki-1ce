## Обзор

Компоненты интерфейса позволяют описать [пользовательский интерфейс](all-project-elements-5977d6a645f5.md) приложения.

## Документированный контракт и примеры

Компоненты интерфейса позволяют описать [пользовательский интерфейс](all-project-elements-5977d6a645f5.md) приложения. Чтобы добавить компонент интерфейса, выполните следующие действия:

1. Откройте представление
  
  Проект
  
  .
2. Наведите мышку на подсистему, пакет, элемент проекта или компонент интерфейса и нажмите на знак плюса.
3. В открывшемся окне перейдите в группу
  
  Компоненты интерфейса
  
  . Выберите системный компонент, от которого будет унаследован добавляемый компонент интерфейса.
4. Введите имя компонента и нажмите
  
  Enter
  
  .

## Модули

Чтобы добавить модуль компонента интерфейса, в представлении **Проект** нажмите на знак плюса рядом с именем нужного компонента. В открывшемся окне выберите пункт **Модуль**.

## Редактирование

Вы можете изменить свойства компонента интерфейса в панели **Свойства**. Чтобы открыть ее, выделите нужный компонент в [редакторе компонентов интерфейса](ide-overview-and-basic-actions-969a6e6501a6.md).
