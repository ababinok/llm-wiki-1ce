## Документированный контракт и примеры

Во время работы приложения «1С:Предприятие.Элемент» автоматически генерирует форму списка записей для регистра накопления.

Пример формы записи регистра накопления [ОстаткиНоменклатуры](../data/accumulation-register-example-08cac330ee7d.md):

Вы также можете создать собственную форму списка записей. Для этого используйте группу свойств регистра накопления — [Интерфейс](../data/accumulationregister-c199835a97cc.md).

```yaml

```

## Команда открытия формы списка

«1С:Предприятие.Элемент» добавляет в [автоматический интерфейс](auto-generated-ui-7150689c0714.md) приложения команду открытия списка записей регистра накопления. Например, для регистра **ОстаткиНоменклатуры** команда будет иметь вид `ОстаткиНоменклатуры.ОткрытьСписок`.

Если вы не хотите, чтобы пользователь мог работать с данными регистра, вы можете отключить добавление этой команды в автоматический интерфейс. Для этого используйте свойство регистра накопления [ВключатьВАвтоИнтерфейс](../data/accumulationregister-c199835a97cc.md).

В свойствах регистра накопления выделено ВключатьВАвтоИнтерфейс и установлено «Ложь», чтобы команда списка регистра не добавлялась в автоматический интерфейс. [Описание иллюстрации](../../raw/figures/da1a86c4c11cba05657a4537cb1841b9225a154b73f67e92091130193ad58ee3-541b5d88e98cc330.md)

По умолчанию команда, которую «1С:Предприятие.Элемент» добавляет в интерфейс приложения, в качестве своего представления использует имя регистра в проекте. Вы можете изменить представление команды с помощью свойства **Интерфейс.Список.Представление**. Указанное представление будет также использоваться в качестве представления команды `<ИмяРегистраНакопления>.ОткрытьСписок`.

## Создание формы списка регистра накопления

Во время работы приложения «Элемент» автоматически сгенерирует форму списка для работы с записями регистра. Вы не можете изменить внешний вид или логику работы этой формы. Однако вы можете создать собственную форму, а затем указать, что регистр должен использовать именно ее. Для этого используйте свойство **Интерфейс.Список.Форма**.

### Создание формы в коде

Вы можете создать форму списка в коде с помощью метода [`СоздатьФормуСписка()`](../data/accumulationregistername-ru-ca3f7a553094.md) типа [`{ИмяРегистраНакопления}`](../data/accumulationregistername-ru-ca3f7a553094.md).

Например:

```xbsl
ОстаткиНоменклатуры.СоздатьФормуСписка().Открыть()
```

Если для регистра накопления задана форма списка, то будет создана форма этого типа. Иначе будет создана автоматическая форма типа [`<ИмяРегистраНакопления>.АвтоматическаяФормаСписка`](../data/accumulationregistername-automaticlistform-ru-b58cdbecf7fa.md).
