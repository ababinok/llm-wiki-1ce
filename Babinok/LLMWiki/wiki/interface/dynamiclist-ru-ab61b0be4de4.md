## Свойства

### ИспользоватьПолнотекстовыйПоиск

`Доступность: Клиент`

```
ИспользоватьПолнотекстовыйПоиск: Авто|Булево
```

Истина, если требуется делать отбор данных через полнотекстовый поиск. Ложь, если требуется делать отбор данных через поиск подстроки средствами СУБД. Авто, если сущность (таблица) индексируется, полнотекстовый поиск будет использоваться. Значение по умолчанию - Авто.

---

### ИспользуемаяИерархия

`Доступность: Клиент`

```
ИспользуемаяИерархия: Авто|РежимИерархии|Строка
```

Задает группировку для построения иерархического представления динамического списка.

Если [ПоУмолчанию](hierarchymode-ru-f095f6cbddef.md) или пустая строка – будет отображена иерархия, которая указана как иерархия по-умолчанию в справочнике. Если [Выключено](hierarchymode-ru-f095f6cbddef.md) – динамический список вернет свое плоское представление.

[Строка](../stdlib/string-ru-1bac645acacf.md) заполняется указанной иерархией, что отобразит список гетерогенным видом. Например, если в свойстве [ОсновнаяТаблица](dynamiclist-ru-ab61b0be4de4.md) задан иерархический справочник, содержащий реквизиты, которые тоже являются иерархическими сущностями - указав имя такого реквизита в данном свойстве, он перестроится относительно указанной иерархии. Например, справочник Сотрудники имеет базовую иерархию Сотрудник ->... -> Сотрудник. В нем есть реквизит Отдел. Если указать свойству данный реквизит, иерархия перестроится на: Отдел ->... Отдел -> Сотрудник.

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) интерпретирует запрос к динамическому списку в зависимости от того – поддерживается в нем иерархичность или нет. Если да – [ПоУмолчанию](hierarchymode-ru-f095f6cbddef.md).

---

### ОсновнаяТаблица

`Доступность: Клиент`

```
ОсновнаяТаблица: ТаблицаДинамическогоСписка
```

Основная таблица выборки данных динамического списка. Основная таблица определяет не только выборку данных, но и поведение интерфейсных компонент, которые используют динамический список в качестве источника данных. Влияет на открываемую форму при редактировании данных в таблице, на команду добавления нового элемента, на упорядочивание данных по умолчанию.

---

### ОтображатьФильтрПометкиНаУдаление

`Версия 10.0 и выше`

`Доступность: Клиент`

```
ОтображатьФильтрПометкиНаУдаление: Авто|Булево
```

Включает или отключает из состава отображаемых в интерфейсе фильтров фильтр показа отмеченных на удаление записей.

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) – `Истина`.

В случае, если сущность не поддерживает пометки на удаление – всегда `Ложь`.

### Поля

`Доступность: Клиент`

```
Поля: Массив<ПолеКоллекцияДинамическогоСписка|ПолеДинамическогоСписка>
```

Коллекция полей динамического списка. Задает набор колонок, которые могут быть отображены пользователю в таблице. В выражении полей могут использоваться поля основной и присоединенных таблиц.

---

### ПрисоединенныеТаблицы

`Доступность: Клиент`

```
ПрисоединенныеТаблицы: Массив<ПрисоединеннаяТаблица>
```

В выборке данных могут описаны присоединенные таблицы. Таблицы присоединятся к основной как Внешнее Левое Соединение. В условии присоединения могут использоваться поля основной и присоединенной таблицы. Данные из присоединенной таблицы могут использоваться для получения данных, и фильтрации выборки.

---

### Сортировка

`Доступность: Клиент`

```
Сортировка: Массив<ЭлементСортировки>
```

Описание упорядочивания данных выборки динамического списка. Если упорядочивание не задано, используется упорядочивание по умолчанию от основной таблицы.

---

### Фильтр

`Доступность: Клиент`

```
Фильтр: ГруппаЭлементовФильтра
```

Описание фильтрации выборки данных. В описании фильтрации могут использоваться поля основной и присоединенных таблиц.
