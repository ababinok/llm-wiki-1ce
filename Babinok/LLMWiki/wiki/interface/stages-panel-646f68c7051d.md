## Документированный контракт и примеры

Компонент интерфейса **ПанельЭтапов** используется для отображения последовательности этапов. Этапы могут представлять собой последовательность событий во времени или любые последовательные действия.

Панель этапов с пиктограммами: «Оформлен», «Сборка», «В пути», «Доставлен». Пройденные связи сплошные и синие, будущий переход к доставке показан серым пунктиром. [Описание иллюстрации](../../raw/figures/fc03c79158620ae39207e922d692be0dd670276672f282187816862b7fba031f-fabcbace8171cd3d.md)

В данной статье рассматриваются два примера добавления панели этапов в интерфейс приложения. В [первом примере](stages-panel-646f68c7051d.md) панель этапов строится автоматически на базе элементов перечисления. Во [втором примере](stages-panel-646f68c7051d.md) показывается, как настроить отображение этапов с помощью свойств объекта [`ЭлементПанелиЭтапов`](stagespanelitem-ru-f2f5b69d14f9.md).

## Ориентация панели этапов

Панель этапов может располагаться как вертикально, так и горизонтально (в соответствии со значением свойства [Ориентация](stagespanel-ru-f1ef84720ca1.md)).

Если в горизонтальной панели этапы не вмещаются в отведенную ширину, появляется кнопка, при нажатии на которую отображается окно с оставшимися этапами. В мобильной версии вместо кнопки показывается горизонтальная полоса прокрутки.

Горизонтальная панель этапов: завершенные этапы слева соединены голубыми линиями, текущий «Дизайн-спринт» отмечен отдельным значком; справа пунктир ведет к скрытым этапам. [Описание иллюстрации](../../raw/figures/71e0ccda752ede3cdd26f6eeb3cb958d5d45abe88646fb4fbd299cfd37daafa8-2e6994ac83b15b56.md)

Этапы вертикальной панели могут быть свернуты в соответствии с настройкой [РежимСворачивания](stagespanel-ru-f1ef84720ca1.md). При этом соблюдаются следующие правила:

- текущий этап всегда раскрыт,
- следующий этап после текущего всегда раскрыт,
- последний этап всегда раскрыт.

Вертикальная панель «Этапы разработки проекта» начинается с кнопки «Развернуть (3)», которая обозначает три скрытых ранних этапа. [Описание иллюстрации](../../raw/figures/bc1151688c7fbeb67009e572ceeb023f70dbe50d4cf9b0aaf9d4df0513cc2216-4f51ae87eaa0bafc.md)

Каждый этап может отображаться как пройденный или непройденный. Соблюдается следующий порядок следования: от пройденных этапов к непройденным сверху вниз или слева направо.

## Пример создания панели этапов с настройками по умолчанию

Покажем, как добавить панель этапов в форму объекта справочника. В данном примере панель этапов используется для отображения статуса заказа. Интерфейс панели строится автоматически на базе элементов перечисления **СтатусЗаказа**.

В форме заказа справа расположена вертикальная панель этапов: Оформлен → Сборка → В пути → Доставлен. [Описание иллюстрации](../../raw/figures/c0b1c4087965de44dee1c53839dc5c59f023d650fe0649302f2c00860b1b52fe-d32ba22f1ca055a2.md)

### Создание справочника для хранения данных

1. Добавьте [перечисление](../project/fixed-set-of-values-8517518057de.md) **СтатусЗаказа** со следующими элементами:
  
  - Оформлен
    
    — выберите как значение по умолчанию,
  - Сборка
    
    ,
  - ВПути
    
    ,
  - Доставлен
    
    .
2. Создайте [справочник](../data/catalog-project-element-b6ca52d114d4.md) **Заказы** для хранения информации о доставке заказов. Добавьте указанные ниже реквизиты:
  
  - Код
    
    типа
    
    `Строка`
    
    ,
  - Наименование
    
    типа
    
    `Строка`
    
    ,
  - АдресДоставки
    
    типа
    
    `Строка`
    
    ,
  - ДатаДоставки
    
    типа
    
    `Дата`
    
    ,
  - Статус
    
    типа
    
    `СтатусЗаказа`
    
    .

### Добавление формы объекта справочника

1. [Создайте для справочника форму объекта](add-project-element-forms-2ae9079946eb.md) с именем **ЗаказыФормаОбъекта**.
2. Выделите [группу](group-component-982f449c1db4.md) основного раздела формы и измените значение свойства [Компоновка](group-ru-ac8d45ab0db2.md) на **Горизонтальная**.
3. Поместите сгенерированные поля ввода в отдельную группу. Для этого в [редакторе компонентов интерфейса](ide-overview-and-basic-actions-969a6e6501a6.md) выделите все поля, нажмите по ним правой кнопкой мыши и выберите **Рефакторинг** ⟶ **Обернуть в группу**. Введите имя группы — **ПоляЗаказа**. Для свойства [Компоновка](group-ru-ac8d45ab0db2.md) группы задайте значение **Вертикальная**.
  
  Добавление полей в группу [Описание иллюстрации](../../raw/figures/a18b9575b934e5261df46a0f7baa2aaae6628b8f687cb6efaf77619b509815d7-eef01ab7dd58f367.md)
4. Аналогичным образом объедините поля **Статус** и **ДатаДоставки** в отдельную горизонтальную группу.
5. Добавьте панель этапов на форму объекта. Для этого выделите **ОсновнойРаздел** формы и нажмите на знак плюса. В открывшемся окне выберите **ПанельЭтапов**. Задайте имя панели — **ПанельЭтаповДоставкиЗаказа**. В панели свойств укажите тип компонента — `ПанельЭтапов<СтатусЗаказа>`.
  
  Добавление панели этапов [Описание иллюстрации](../../raw/figures/b80613e3d3775917374e8dd962a4327f59253db5b22f95d37efa11822e0a2751-1ddbcc707594ee34.md)
6. Для свойства [ТекущийЭтап](stagespanel-ru-f1ef84720ca1.md) настройте привязку к значению поля ввода **Статус**. Свойство [Этапы](stagespanel-ru-f1ef84720ca1.md) заполнять не нужно, «1С:Предприятие.Элемент» автоматически создаст панель этапов на основе элементов перечисления.

### Создание поля ввода для выбора текущего этапа

1. Добавьте в группу поле ввода. Задайте имя поля — **ТекущийЭтап**, а также укажите его тип — `ПолеВвода<ЭтапыПроекта?>`.
2. В модуле формы создайте метод для заполнения поля ввода данными — названиями этапов разработки.
  
  ```xbsl
  метод СписокЭтаповДляВыбора(): Массив<ЭлементСпискаЗначений<ЭтапыПроекта?>>
      пер Этапы = новый Массив<ЭлементСпискаЗначений<ЭтапыПроекта?>>()
  
      для Этап из ЭтапыПроекта.ПолучитьМассивЭтапов()
          Этапы.Добавить(
              новый ЭлементСпискаЗначений<ЭтапыПроекта?>(
                  Значение = Этап,
                  Представление = Этап.Наименование))
      ;
  
      возврат Этапы
  ;
  ```
3. Укажите данный метод в качестве значения свойства [СписокВыбора](edit-ru-4027d1cb7b27.md). Для свойства [РежимВыбораИзСписка](edit-ru-4027d1cb7b27.md) задайте значение **Только значения из списка**.
  
  Свойства поля ввода: СписокВыбора задан вычисляемым методом, а режим выбора установлен в «Только значения из списка». [Описание иллюстрации](../../raw/figures/317f353ba44c3cdfed5d80c91216c92e4928b4adb6089f76a0ecc0310605e44c-3a5b7cd3531f10c1.md)

### Создание и настройка панели этапов

1. Добавьте в группу панель этапов. Задайте имя панели — **ПанельЭтаповРазработки**, а также укажите ее тип — `ПанельЭтапов<ЭтапыПроекта?>`.
2. В модуле формы создайте метод `СписокЭтапов()` для заполнения массива этапов, которые будут отображаться на панели. Каждый этап описывается с помощью свойств экземпляра типа [`ЭлементПанелиЭтапов`](stagespanelitem-ru-f2f5b69d14f9.md).
  
  ```xbsl
  метод СписокЭтапов(): Массив<ЭлементПанелиЭтапов<ЭтапыПроекта?> | ЭтапыПроекта?>
      знч Этапы = новый Массив<ЭлементПанелиЭтапов<ЭтапыПроекта?> | ЭтапыПроекта?>()
  
      для Этап из ЭтапыПроекта.ПолучитьМассивЭтапов()
          пер ЭтоТекущий = Компоненты.ТекущийЭтап.Значение == Этап
          Этапы.Добавить(
              новый ЭлементПанелиЭтапов<ЭтапыПроекта?>(
                  Значение = Этап,
                  // Добавление заголовка этапа
                  Заголовок =  Этап.Наименование,
                  // Добавление подзаголовка этапа
                  Подзаголовок = Этап.ДатаНачала.ВСтроку(),
                  // Добавление описания этапа
                  Описание = Этап.Описание,
                  // Добавление метки этапа в виде значка
                  ДополнительноеЗначение = Этап.Метка,
                  // Значок текущего этапа имеет зеленый цвет, остальные — синий
                  ОписаниеЗначкаДополнительногоЗначения = новый ОписаниеЗначка(
                      Цвет = (ЭтоТекущий ? Цвета.Зеленый : Цвета.Синий)
                  ),
                  // Задание изображения для индикатора этапа
                  Изображение = Этап.Иконка
              )
          )
      ;
  
      возврат Этапы
  ;
  ```
3. Укажите данный метод в качестве значения свойства [Этапы](stagespanel-ru-f1ef84720ca1.md). Для свойства [ТекущийЭтап](stagespanel-ru-f1ef84720ca1.md) настройте привязку к значению поля ввода **ТекущийЭтап**.
  
  Свойства панели этапов: Этапы задано вычисляемым методом СписокЭтапов(), ТекущийЭтап привязан к значению компонента поля ввода текущего этапа. [Описание иллюстрации](../../raw/figures/e7ce525e94711085c7635af2fe2cf42f5140c4a8b490a1300a6139f505e37100-f0f02439251d3cd8.md)
