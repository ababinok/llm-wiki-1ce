## Задача

Нужно показать выборку прикладных данных в форме. Руководство «Динамический список» описывает `ДинамическийСписок` как источник данных таблиц большинства форм списков. Таблица и её источник решают разные задачи: контракт `Таблица` задаёт отображение, контракт `ДинамическийСписок` — получение данных.

## Порядок настройки

1. В руководстве «Динамический список» найдите декларацию `Таблица<ДинамическийСписок>`. У `Источник` задаются `ОсновнаяТаблица`, `Поля`, при необходимости `Сортировка`, присоединённые таблицы, аргументы и параметры.
2. Для каждого `ПолеДинамическогоСписка` сверяйте `Выражение` и `Псевдоним`. В исходном примере выражение `Владелец.Клиент` получает псевдоним `Владелец_Клиент`. Прикладные таблицы и реквизиты должны существовать в проекте.
3. В декларативном справочнике `Таблица` сверяйте `Колонки` и выбранный тип колонки. В примере с реквизитом-коллекцией `СтандартнаяКолонкаТаблицы<СтрокаДинамическогоСписка>` указывает `ПолеЗначения`. Не считайте поле источника автоматически настроенной колонкой произвольного вида.
4. Параметры динамического списка задаются через `ПараметрДинамическогоСписка`. В выражениях фильтра пример использует `&ПараметрЧисло`, а значение параметра может быть выражением свойства компонента. Это отдельный контекст от `%Возраст` в XBSL-литерале запроса.
5. Для изменения списка программно откройте тип `Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ДинамическийСписок` и сверяйте нужный член, его параметры и клиентское окружение. После этого сверяйте программный тип таблицы и обработчик события; декларативный YAML не заменяет их сигнатуры.

## Пример источника из руководства

В этом примере используются прикладная таблица `Задачи` и её реквизиты. Сохранён исходный YAML; перенос в другой проект требует их адаптации.

```yaml
Тип: Таблица<ДинамическийСписок>
Имя: ТаблицаСписка
Источник:
    ОсновнаяТаблица:
        Таблица: Задачи
    Поля:
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Код
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Наименование
        -
            Тип: ПолеДинамическогоСписка
            Выражение: ДатаСоздания
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Владелец.Клиент
            Псевдоним: Владелец_Клиент
            Представление: Клиент
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
    Сортировка:
        -
            Поле: ДатаСоздания
            НаправлениеСортировки: ПоУбыванию
```

## Проверка решения

Различите тип таблицы, тип источника, поля выборки и колонки отображения; проверьте каждое прикладное имя и контекст синтаксиса параметра. Для реквизитов-коллекций руководство даёт отдельные примеры полей и фильтров.
