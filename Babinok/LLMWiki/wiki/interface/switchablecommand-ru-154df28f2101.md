## Обзор

Переключаемая команда - это команда имеющая два состояния и переключающаяся между ними при исполнении команды.

## Документированный контракт и примеры

`Стд::Интерфейс::Команды::ПереключаемаяКоманда` `Доступность: Клиент`

## Конструкторы

### ПереключаемаяКоманда

`Версия 9.0 и выше`

`Доступность: Клиент`

```
ПереключаемаяКоманда(
  Обработчик: (ПереключаемаяКоманда)->ничто,
  ПредставлениеАктивного: Строка,
  ИзображениеАктивного: Url|ДвоичныйОбъект.Ссылка|? = Неопределено,
  ПредставлениеНеактивного: Строка,
  ИзображениеНеактивного: Url|ДвоичныйОбъект.Ссылка|? = Неопределено,
  Активна: Булево,
  Важность: ВажностьКоманды = ВажностьКоманды.Обычная,
  Доступность: Булево = Истина,
  Видимость: Булево = Истина,
  ОпасностьДействия: ОпасностьДействия = ОпасностьДействия.Отсутствует)
```

Создает переключаемую команду с заданными полями и обработчиком.
