## Методы

### Открыть

`Версия 10.0 и выше`

`Доступность: Клиент` `Статический`

```
@ИменованныеПараметры
Открыть(
  СвойствоФормы1: ТипСвойстваФормы1,
  СвойствоФормы2: ТипСвойстваФормы2,
  СвойствоФормыN: ТипСвойстваФормыN
): ТипРезультата?
```

>

Вызов возможен только с именованными параметрами

Открывает форму данного типа. Допускает только именованную форму вызова. Открывает форму по-разному и возвращает разные результаты в зависимости от свойства [СпособОткрытия](form-ru-89fb5e7eaeb3.md).

- Если
  
  [СпособОткрытия](form-ru-89fb5e7eaeb3.md)
  
  =
  
  [ВМодальномОкне](formopenmethod-ru-9ca1bcb027a4.md)
  
  или
  
  [ВоВсплывающемОкне](formopenmethod-ru-9ca1bcb027a4.md)
  
  , то возвращает значение, переданное в метод
  
  [Закрыть](form-ru-89fb5e7eaeb3.md)
  
  или
  
  `Неопределено`
  
  , если форма была закрыта через "крестик". Метод не вернет управление вызывающему коду, пока окно не закроется.
- Иначе, возвращает
  
  `Неопределено`
  
  . Метод вернет управление вызывающему коду, как только окно откроется.

Параметры:

- `СвойстваФормы`
  
  - дополнительные свойства формы, которые будут установлены при ее открытии.

**Перегрузка** [Форма::Открыть(): ТипРезультата?](form-ru-89fb5e7eaeb3.md)

#### Примеры

```xbsl
метод ОткрытьМояФорма()
   МояФорма.Открыть(СвойствоФормы1 = "Значение свойства")
;
```

Откроет форму `МояФорма`, согласно ее свойству [СпособОткрытия](form-ru-89fb5e7eaeb3.md), при открытии будет установлено ее свойство `СвойствоФормы1`. Можно переопределить способ открытия формы, передав в параметры новое значение для свойства [СпособОткрытия](form-ru-89fb5e7eaeb3.md).

### ОткрытьВМодальномОкне

`Версия 10.0 и выше`

`Доступность: Клиент` `Статический`

```
@ИменованныеПараметры
ОткрытьВМодальномОкне(
  ОжидатьЗакрытия: Булево = Истина,
  СвойствоФормы1: ТипСвойстваФормы1,
  СвойствоФормы2: ТипСвойстваФормы2,
  СвойствоФормыN: ТипСвойстваФормыN
): ТипРезультата?
```

>

Вызов возможен только с именованными параметрами

Открывает форму данного типа в модальном окне. Допускает только именованную форму вызова. Может возвращать значение типа `ТипРезультата`, см. [Закрыть](form-ru-89fb5e7eaeb3.md)

Параметры:

- `ОжидатьЗакрытия`
  
  - если
  
  `Истина`
  
  , то метод не вернет управление, пока окно не закроется,
- `СвойстваФормы`
  
  - дополнительные свойства формы, которые будут ей установлены при ее открытии.

**Перегрузка** [Форма::ОткрытьВМодальномОкне(ОжидатьЗакрытия: Булево = Истина): ТипРезультата?](form-ru-89fb5e7eaeb3.md)

#### Примеры

```xbsl
метод ОткрытьМояФормаВМодальномОкне()
    МояФорма.ОткрытьВМодальномОкне(СвойствоФормы1 = "Значение свойства")
;
```

Откроет форму `МояФорма` в модальном окне, при открытии будет установлено ее свойство `СвойствоФормы1` Метод будет ожидать закрытия окна, после чего продолжится выполнение кода.

## Обработчики

### ПослеСоздания

```
ПослеСоздания()
```

Вызывается после создания UI-компонента системой:

- установлены значения свойств самого компонента, указанные в описании,
- созданы внутренние компоненты данного компонента, значения их свойств установлены из описаний их экземпляров,
- обработчики событий подписаны на события самого компонента и его внутренних компонентов. Предназначено для дополнительной инициализации свойств компонента на клиенте и вызова прикладной логики инициализации компонента.

---

### ПриОбновлении

```
ПриОбновлении()
```

Событие возникает при инициации обновления данных формы с использованием команды

[Обновить](form-ru-89fb5e7eaeb3.md)

или с помощью жеста

`Pull-To-Refresh`

на мобильных устройствах. При этом в

[ФормаОбъекта](objectform-ru-b5cec9fb1ea3.md)

это происходит после обновления данных объекта. В

[ФормаСписка](listform-ru-f0fc0cdb7cd0.md)

- после обновления данных списка системой.

---

### ПослеЗакрытия

```
ПослеЗакрытия()
```

Событие возникающие после закрытия формы, означающее что форма уже закрыта и процесс закрытия нельзя отменить или прервать.

---

### ПередЗакрытием

```
ПередЗакрытием(Событие: ПараметрыЗакрытияФормы)
```

Событие возникающие перед закрытием формы. Параметр

`Событие`

типа

[ПараметрыЗакрытияФормы](formcloseparams-ru-b4203dc56e56.md)

содержит свойство

[РежимЗакрытияФормы](formcloseparams-ru-b4203dc56e56.md)

, которое может принять следующие значения:

- [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  - Закрывает форму и выполняет стандартную обработку.
- [Закрыть](formclosemode-ru-03d39171d2f5.md)
  
  - Закрывает форму без выполнения стандартной обработки.
- [НеЗакрывать](formclosemode-ru-03d39171d2f5.md)
  
  - Не закрывает форму, стандартная обработка не выполняется.
