## Обзор

Компонент в виде плашки с текстом и, опционально, картинкой, крестиком и возможностью нажатия.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::КомпонентВыбора` `Доступность: Клиент`

Компонент в виде плашки с текстом и, опционально, картинкой, крестиком и возможностью нажатия. Обычно используется для индикации и отключения установленных параметров фильтра.

**Сравнение**

Ссылочное

## Свойства

### Активность

`Доступность: Клиент`

```
Активность: Булево
```

Флаг активности компонента (выделение акцентным цветом).

---

### ДополнительныеДанные

`Доступность: Клиент`

```
ДополнительныеДанные: Объект?
```

Дополнительные данные, связанные с компонентом.

---

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Текст заголовка, располагаемый внутри компонента выбора.

---

### Закрываемый

`Доступность: Клиент`

```
Закрываемый: Булево
```

`Истина` – компонент может быть "закрыт" пользователем. В этом случае у компонента появляется крестик закрытия, при нажатии на который вызывается событие [ПриНажатииЗакрытия](choicecomponent-ru-3c84c24a3f44.md).

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Адрес дополнительного изображения компонента.

---

### Изображение

`Версия 8.0 и ниже`

> **Исторический контракт:** верхняя граница версии 8.0; не используйте этот член для 10.0.


`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](choicecomponent-ru-3c84c24a3f44.md).

---

### Картинка

`Доступность: Клиент`

```
Картинка: Картинка
```

Указывает на внутренний компонент [Картинка](picture-ru-efed61d49ad9.md). Может использоваться для ее дополнительного оформления.

---

### Команды

`Доступность: Клиент`

```
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или группа команд, назначенных компоненту выбора. Если указана группа команд, то команды группы будут размещены в меню компонента.

---

### РазрешитьСжатие

`Доступность: Клиент`

```
РазрешитьСжатие: Авто|Булево
```

Управляет сжимаемостью компонента по горизонтали. Если `Истина`, то компоненту разрешено сжиматься.

  КомпонентВыбора,
