> Updated: 2026-10-05

Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / Interface / CommonComponents.

Имена для поиска: `ЭлементПанелиЭтапов`, `StagesPanelItem`, `Стд::Интерфейс::ОбщиеКомпоненты::ЭлементПанелиЭтапов<ТипДанных>`, `Std::Interface::CommonComponents::StagesPanelItem`.

## Обзор

ТипДанных: тип свойства [Значение](stagespanelitem-ru-f2f5b69d14f9.md).

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::ЭлементПанелиЭтапов<ТипДанных>` `Доступность: КлиентИСервер`

ТипДанных: тип свойства [Значение](stagespanelitem-ru-f2f5b69d14f9.md). Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Описывает отдельный этап компонента [ПанельЭтапов](stagespanel-ru-b1a7361a0cec.md).

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../stdlib/object-ru-9e351f286699.md)

## Конструкторы

### ЭлементПанелиЭтапов

`Доступность: КлиентИСервер`

```
ЭлементПанелиЭтапов(
  Значение: ТипДанных,
  Заголовок: Строка,
  Подзаголовок: Строка,
  Описание: Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?,
  ОценкаИнформации: Авто|ОценкаИнформации,
  ДополнительноеЗначение: Объект?,
  ОписаниеЗначкаДополнительногоЗначения: Авто|ОписаниеЗначка)
```

Создает новый объект

ЭлементПанелиЭтапов

с указанными значениями свойств.

---

## Свойства

### ДополнительноеЗначение

`Доступность: КлиентИСервер`

```
ДополнительноеЗначение: Объект?
```

Дополнительное значение этапа, отображаемое в виде значка. Для отображения используется представление переданного объекта.

---

### Заголовок

`Доступность: КлиентИСервер`

```
Заголовок: Строка
```

Заголовок этапа, который отображается ниже подзаголовка.

Если **Заголовок** не задан, а также не заданы [Подзаголовок](stagespanelitem-ru-f2f5b69d14f9.md) и [Описание](stagespanelitem-ru-f2f5b69d14f9.md), то в качестве заголовка отображается текстовое представление свойства [Значение](stagespanelitem-ru-f2f5b69d14f9.md).

Заголовок всегда однострочный.

---

### Значение

`Доступность: КлиентИСервер`

```
Значение: ТипДанных
```

Значение, хранящееся в данном этапе.

---

### Изображение

`Доступность: КлиентИСервер`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Задает изображение (декорацию) индикатора этапа.

---

### Описание

`Доступность: КлиентИСервер`

```
Описание: Строка
```

Описание этапа, которое отображается ниже заголовка.

В горизонтальной ориентации описание всегда двустрочное. В вертикальной ориентации описание не имеет ограничения по количеству строк.

---

### ОписаниеЗначкаДополнительногоЗначения

`Доступность: КлиентИСервер`

```
ОписаниеЗначкаДополнительногоЗначения: Авто|ОписаниеЗначка
```

Описание значка дополнительного значения.

---

### ОценкаИнформации

`Доступность: КлиентИСервер`

```
ОценкаИнформации: Авто|ОценкаИнформации
```

Оценка информации этапа. Может влиять на окрашивание индикатора этапа.

---

### Подзаголовок

`Доступность: КлиентИСервер`

```
Подзаголовок: Строка
```

Подзаголовок этапа, который отображается в самой верхней области этапа. Если его нет, то пустое место не образуется, так как нижние элементы этапа сдвигаются вверх.

Подзаголовок всегда однострочный.

---
