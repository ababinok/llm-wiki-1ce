## Документированный контракт и примеры

`Стд::Интерфейс::ВидУведомления` `Доступность: КлиентИСервер`

Определяет вид отображения уведомления.

## Свойства

### Системное

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Системное
```

Уведомление, которое отображается как уведомление браузера. Пользователь увидит данное уведомление даже если он находится в другой вкладке браузера или если окно браузера свернуто.

---

### Обычное

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Обычное
```

Уведомление, которое отображается внутри окна приложения. Рекомендуется использовать в сценариях, когда нужно уведомить пользователя о завершении выполнения длительного события.

---

### Всплывающее

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Всплывающее
```

Всплывающее уведомление, отображаемое внизу экрана. Рекомендуется использовать в сценариях, когда нужно уведомить пользователя о действии, которое инициировал он сам, в качестве дополнительного подтверждения.

---

### Невидимое

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Невидимое
```

Уведомление не отображается, но может быть сохранено в центре уведомлений.
