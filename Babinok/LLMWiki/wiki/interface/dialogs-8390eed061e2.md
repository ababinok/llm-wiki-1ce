# Типы

## [Диалог](dialog-ru-c77b85fd9948.md)

`Стд::Интерфейс::Диалоги::Диалог` `Тип-одиночка` `Доступность: Клиент`

Содержит методы для открытия предупреждающих окон.

---

## [КнопкаДиалога](dialogbutton-ru-c1e27b012450.md)

`Стд::Интерфейс::Диалоги::КнопкаДиалога<ТипДанных>` `Доступность: Клиент`

ТипДанных: тип свойства Значение. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Описывает одну кнопку предупреждающего окна. Используется, для описания кнопок в предупреждающем окне.

---

## [СтандартнаяКнопкаДиалога](standarddialogbutton-ru-bf2aadb813bf.md)

`Стд::Интерфейс::Диалоги::СтандартнаяКнопкаДиалога` `Доступность: КлиентИСервер`

Содержит стандартные кнопки для типовых диалогов.
