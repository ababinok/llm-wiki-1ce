## Свойства

### БезопасныйРежим

`Доступность: Клиент`

```
БезопасныйРежим: Авто|Булево
```

Режим работы с контейнером, в котором запрещается запуск скриптов и другие потенциально опасные взаимодействия с содержимым контейнера. Выключайте, только если доверяете источнику, от которого поступило содержимое.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Строка
```

Любой html-код, который будет выведен внутри компонента.

## Методы

### ВызватьМетод

`Доступность: Клиент`

```
ВызватьМетод(
  Имя: Строка,
  Параметры: Массив<Булево|ОбъектJs|Число|Строка|?>? = Неопределено
): Булево|ОбъектJs|Число|Строка|?
```

Вызывает функцию скрипта и возвращает результат выполнения. Если идет обращение к процедуре, возвращается

`Неопределено`

. В качестве результата выполнения функции может быть возвращен объект

[ОбъектJs](jsobject-ru-3b7864d1402d.md)

, описывающий объект JavaScript. Параметры:

- `Имя`
  
  - Имя вызываемой функции. Допустима передача составных имен, разделенных точкой, например "Address.GetStreet"
- `Аргументы`
  
  - Массив передаваемых в функцию аргументов. В качестве аргумента допустимо использование JsObject.

---

### ПолучитьПеременную

`Доступность: Клиент`

```
ПолучитьПеременную(Имя: Строка): Булево|ОбъектJs|Число|Строка|?
```

Возвращает значение переменной. В качестве результата обращения к переменной может быть возвращен объект

[ОбъектJs](jsobject-ru-3b7864d1402d.md)

, описывающий объект JavaScript. Параметры:

- `Имя`
  
  - Имя переменной. Допустима передача комплексных имен, разделенных точкой, например "Person.Name"

---

### СоздатьОбъектJs

`Доступность: Клиент`

```
СоздатьОбъектJs(
  Имя: Строка,
  Параметры: Массив<Булево|ОбъектJs|Число|Строка|?>? = Неопределено
): ОбъектJs
```

Создает и возвращает объект

[ОбъектJs](jsobject-ru-3b7864d1402d.md)

, описывающий объект JavaScript. Параметры:

- `Имя`
  
  - Имя типа в JS.
- `Аргументы`
  
  - Массив передаваемых в функцию аргументов. В качестве аргумента допустимо использование другого
  
  [ОбъектJs](jsobject-ru-3b7864d1402d.md)
  
  .

---

### УстановитьПеременную

`Доступность: Клиент`

```
УстановитьПеременную(
  Имя: Строка,
  Значение: Булево|ОбъектJs|Число|Строка|?)
```

Присваивает переменной значение. Параметры:

- `Имя`
  
  - Имя присваиваемой переменной. Допустима передача комплексных имен, разделенных точкой, например "Person.Name"
- `Значение`
  
  - Новое значение переменной. Допустимо использование
  
  [ОбъектJs](jsobject-ru-3b7864d1402d.md)
  
  в качестве присваиваемого значения.
