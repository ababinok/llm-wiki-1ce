## Обзор

Предназначен для объединения команд с целью их совместного отображения в пользовательском интерфейсе.

## Документированный контракт и примеры

Предназначен для объединения команд с целью их совместного отображения в пользовательском интерфейсе. Основное назначение — переиспользование единого набора командных элементов в различных частях интерфейса приложения (например, в различных формах, в панелях навигации или действий в компоненте [СтандартноеКлиентскоеПриложениеСРазделами](standardclientapplicationwithsections-fd5fbdc63cd1.md)).

Пример фрагмента командного интерфейса в панели навигации: группы и команды «Главная», «Продажи», «Отчёты», «Мероприятия», «Настройки», «Сервис», «Путеводитель». [Описание иллюстрации](../../raw/figures/4c4f58e96798cf7fcb99ec2e7773939599e4a30d67b3536640ea93de36f7c3b1-4761f2f745db6e9d.md)

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../language/modular-development-80166cfecf93.md).

## Дочерние элеметы

#### Элементы

```yaml
Элементы: Массив<Команда|ФрагментКомандногоИнтерфейса|ГруппаКомандногоИнтерфейса>
```

Команда или список команд, которые будут содержаться во фрагменте. Все команды и группы команд внутри фрагмента должны иметь имена, уникальные в рамках одного элемента.
