## Свойства

### СтандартнаяОбработка

`Доступность: Клиент`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной обработки.

При стандартной обработке вызывает процесс редактирования строки по умолчанию, если возможно.

В случае, если тип строки является <ТипДанныхУзлов> [ИсточникДанных](datasource-ru-000e18be8897.md) и не входит в список <ТипДанныхЭлемента> [ИсточникДанных](datasource-ru-000e18be8897.md), стандартная обработка откроет форму для редактирования. Возможность открытия формы определяется следующими факторами:

- Тип данных узла не составной
- Тип данных узла можно воссоздать в виде формы с типами
  
  [ПолеВвода](edit-ru-cde85140b31e.md)
  
  (все поддерживаемые в нем типы) и
  
  [Флажок](checkbox-ru-2596f521fb30.md)
  
  (тип
  
  [Булево](../stdlib/boolean-ru-7823d4239bcc.md)
  
  ). Если DataType является, например, Структурой, все поля такого типа должны уметь отображаться в виде вышеописанных интерфейсных типах

Для типа [Таблица](table-ru-ccc43dec1ca9.md) событие может вызываться только для типа DataType <ТипДанныхУзлов> [ИсточникДанных](datasource-ru-000e18be8897.md), который не входит в список типов <ТипДанныхЭлемента> [ИсточникДанных](datasource-ru-000e18be8897.md).
