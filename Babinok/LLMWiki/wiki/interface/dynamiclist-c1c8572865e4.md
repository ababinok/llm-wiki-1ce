## [СтрокаДинамическогоСписка](dynamiclistrow-ru-f0049a8b2f38.md)

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::СтрокаДинамическогоСписка<ТипДанныхСтроки>` `Доступность: КлиентИСервер`

ТипДанныхСтроки: тип данных строки динамического списка. По умолчанию [ПроизвольныеДанныеСтрокиДинамическогоСписка](customdynamiclistrowdata-ru-4053fd705a34.md). Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ДанныеСтрокиДинамическогоСписка<неизвестно>.

Содержит ключ и значения полей одной записи динамического списка. Состав полей задается свойством [Поля](dynamiclist-ru-ab61b0be4de4.md). Данный объект создается системой автоматически для каждой записи динамического списка, полученной с сервера.

---

## [СтрокаУзлаДинамическогоСписка](dynamiclistnoderow-ru-ec60c33112b7.md)

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::СтрокаУзлаДинамическогоСписка<ТипДанныхСтроки,ТипДанныхУзла>` `Доступность: КлиентИСервер`

Тип используемый для строк-узлов динамического списка в режиме иерархии. Содержит ключ записи группы динамического списка.

---

## [ТаблицаДинамическогоСписка](dynamiclisttable-ru-12e94095d9b5.md)

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ТаблицаДинамическогоСписка` `Доступность: КлиентИСервер`

Основная таблица выборки динамического списка. Определяет не только выборку данных, но и поведение интерфейсных компонентов, использующих динамический список в качестве источника данных.
