`Стд::Интерфейс::ИсточникиДанных::ПрисоединеннаяТаблица` `Доступность: КлиентИСервер`

Описание присоединенной таблицы выборки. Задается собственно таблица и условие присоединения.

## Конструкторы

### ПрисоединеннаяТаблица

`Доступность: КлиентИСервер`

```
ПрисоединеннаяТаблица(
  Таблица: Строка,
  Псевдоним: Строка,
  Фильтр: ГруппаЭлементовФильтра,
  Аргументы: Массив<АргументТаблицы|АргументТаблицыВыражение>)
```

Создает присоединенную таблицу со значениями полей по умолчанию.

## Свойства

### Аргументы

`Доступность: КлиентИСервер`

```
Аргументы: Массив<АргументТаблицы|АргументТаблицыВыражение>
```

Аргументы присоедененной таблицы, неименованные аргументы указываются в соответствии с объявленным порядком. Именованные параметры указываются после позиционных.
