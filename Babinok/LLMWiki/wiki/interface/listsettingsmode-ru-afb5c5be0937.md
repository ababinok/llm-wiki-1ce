## Свойства

### Простой

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Простой
```

Упрощенный режим настроек: нет выбора условий, фильтры можно выбирать только из списка доступных, нельзя группировать.

---

### Расширенный

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Расширенный
```

Расширенный режим настроек: есть выбор частотных условий, фильтры можно выбирать только из списка доступных, нельзя группировать.

---

### Произвольный

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Произвольный
```

Произвольный режим настроек: фильтры можно добавлять и удалять по своему усмотрению, выбирать условия, группировать.
