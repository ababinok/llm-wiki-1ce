Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / Interface / Lists.

Имена для поиска: `ПроизвольныйСписок`, `CustomList`, `Стд::Интерфейс::Списки::ПроизвольныйСписок<ТипИсточника>`, `Std::Interface::Lists::CustomList`.

## Обзор

ТипИсточника: Тип источника данных списка.

## Документированный контракт и примеры

`Стд::Интерфейс::Списки::ПроизвольныйСписок<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>.

Компонент списка, который использует [ПроизвольнаяСтрокаСписка](customlistrow-ru-a113b0497543.md) для вывода его записей. При наличии обработчика [ПриНажатииСтроки](list-ru-58c40755a735.md) список устанавливает обработчик события `ПриНажатии` у [Содержимое](customlistrow-ru-a113b0497543.md) каждой строки списка, если обработчик не был установлен разработчиком.

**Сравнение**

Ссылочное

## Свойства

### КонтейнерСтрок

`Доступность: Клиент`

```
КонтейнерСтрок: Авто|Группа
```

Задает контейнер, в котором список размещает свои элементы.

#### Примеры

Например, можно указать матричную группу с шириной колонок от 100 до 200 пикселей

```yaml
Тип: Список<ИсточникДанныхМассив<Строка>>
ТипКомпонентаСтроки: СтрокаСписка
КонтейнерСтрок:
    Тип: Группа
    Компоновка: Матричная
    НастройкиМатричнойКомпоновки:
        ОписаниеАвтоматическихКолонок:
            Ширина: 200
            МинимальнаяШирина: 100
        АвтоЗаполнение: ДобавлятьКолонкиИСтроки
```

Или горизонтальную группу вместо вертикальной:

```yaml
Тип: Список<ИсточникДанныхМассив<Строка>>
ТипКомпонентаСтроки: СтрокаСписка
КонтейнерСтрок:
    Тип: Группа
    Компоновка: Горизонтальная
```

Если указано [Авто](../stdlib/auto-ru-1b14ed166f8e.md), то используется вертикальная [Группа](group-ru-9e7fcb6be273.md).

### ТипКомпонентаСтроки

`Доступность: Клиент`

```
ТипКомпонентаСтроки: Тип<ПроизвольнаяСтрокаСписка<ТипИсточника.ItemDataType|ТипИсточника.NodesDataType>>?
```

Тип пользовательского компонента, наследующего компонент [ПроизвольнаяСтрокаСписка](customlistrow-ru-a113b0497543.md), который будет использоваться для вывода элемента списка.
