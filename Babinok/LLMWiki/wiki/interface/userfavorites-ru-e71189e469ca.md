## Обзор

Позволяет добавлять объекты в **Избранное** пользователя, а также загружать избранные объекты для последующих взаимодействий.

## Документированный контракт и примеры

`Стд::Интерфейс::Избранное::ИзбранноеПользователя` `Тип-одиночка` `Доступность: Клиент`

Позволяет добавлять объекты в **Избранное** пользователя, а также загружать избранные объекты для последующих взаимодействий.

**Избранное** ведется в разрезе конкретного клиентского приложения. Для клиентских приложений, не требующих аутентификации, операции работы с **Избранным** не выполняются, а загрузка всегда возвращает пустой массив.

Доступно в режиме совместимости 10.0 и выше.

**Сравнение**

## Методы

### ЗагрузитьВсе

`Доступность: Клиент` `Статический`

```
ЗагрузитьВсе(): Массив<ПапкаИзбранногоПользователя|ЭлементИзбранногоПользователя>
```

Получает все записи и папки Избранного пользователя, отсортированные по порядку. Первыми идут закрепленные, затем остальные. Внутри папок элементы также отсортированы по порядку

#### Примеры

```xbsl
метод ПолучитьИзбранное(): Массив<ЭлементИзбранногоПользователя | ПапкаИзбранногоПользователя>
    возврат ИзбранноеПользователя.ЗагрузитьВсе()
;
```

### Записать

`Доступность: Клиент` `Статический`

```
Записать(Объект: Сущность.Ключ)
```

Добавляет сущность в

Избранное

пользователя с представлением, равным пустой строке. Запись добавляется в начало избранного, сразу после закрепленных элементов. Если данная сущность уже присутствует в

Избранном

пользователя, выбрасывается

`ИсключениеЭлементИзбранногоПользователяНеУникален`

.

**Перегрузка** [Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка = "")](userfavorites-ru-e71189e469ca.md) [Записать(Ссылка: Строка, Представление: Строка = "")](userfavorites-ru-e71189e469ca.md)

#### Примеры

```xbsl
метод ДобавитьДоговорВИзбранное(ДоговорСсылка: Договоры.Ссылка)
    // Добавит в Избранное элемент справочника "Договоры"
    ИзбранноеПользователя.Записать(ДоговорСсылка)
;
```

### Записать

`Доступность: Клиент` `Статический`

```
Записать(
  Ссылка: Строка,
  Представление: Строка = "")
```

Добавляет произвольную ссылку в Избранное. Если представление не указано, в качестве него используется сама ссылка. Запись добавляется в начало избранного, сразу после закрепленных элементов. Если данная ссылка уже присутствует в избранном у пользователя, выбрасывается ИсключениеЭлементИзбранногоПользователяНеУникален

**Перегрузка** [Записать(Объект: Сущность.Ключ)](userfavorites-ru-e71189e469ca.md) [Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка = "")](userfavorites-ru-e71189e469ca.md)

#### Примеры

```xbsl
метод ДобавитьСсылкуВИзбранное()
    // Добавит ссылку "https://1cmycloud.com/welcome" в Избранное
    ИзбранноеПользователя.Записать("https://1cmycloud.com/welcome", "1С:Предприятие.Элемент")
;
```

### Записать

`Доступность: Клиент` `Статический`

```
Записать(Объект: Форма<неизвестно>|Тип<Форма<неизвестно>>, Представление: Строка = "")
```

Добавляет форму в Избранное с указанным представлением. Пользователь вычисляется автоматически. Запись добавляется в начало избранного, сразу после закрепленных элементов. Если данная форма уже присутствует в избранном у пользователя, выбрасывается ИсключениеЭлементИзбранногоПользователяНеУникален

**Перегрузка** [Записать(Объект: Сущность.Ключ)](userfavorites-ru-e71189e469ca.md) [Записать(Ссылка: Строка, Представление: Строка = "")](userfavorites-ru-e71189e469ca.md)

#### Примеры

```xbsl
метод ДобавитьФормуВИзбранное(ГруппаЗаказовФорма: Форма)
    // Внутри формы ГруппаЗаказовФорма
    // Добавит форму ГруппаЗаказовФорма в Избранное с представлением "Группа заказов"
    ИзбранноеПользователя.Записать(ГруппаЗаказовФорма, "Группа заказов")
;
```

### ЗаписатьВсе

`Доступность: Клиент` `Статический`

```
ЗаписатьВсе(Элементы: Массив<ПапкаИзбранногоПользователя|ЭлементИзбранногоПользователя>)
```

Перезаписывает всё избранное для пользователя и клиентского приложения. Порядок элементов определяется порядком в массиве. Если папка неуникальна, выбрасывается ИсключениеПапкаИзбранногоПользователяНеУникальна Если элемент неуникален по полю Ид или по полям Ссылка, Пользователь, выбрасывается ИсключениеЭлементИзбранногоПользователяНеУникален

#### Примеры

```xbsl
метод ОбновитьИзбранное(Избранное: Массив<ЭлементИзбранногоПользователя | ПапкаИзбранногоПользователя>)
    // Перезаписывает всё избранное указанными элементами
    ИзбранноеПользователя.ЗаписатьВсе(Избранное)
;
```

### Удалить

`Доступность: Клиент` `Статический`

```
Удалить(Ссылка: Строка)
```

Удаляет запись из Избранного, содержащую произвольную ссылку. Пользователь вычисляется автоматически. Если ссылки не существует в избранном, выбрасывается ИсключениеЭлементИзбранногоПользователяНеСуществует

**Перегрузка** [Удалить(Объект: Сущность.Ключ|Ууид|Форма<неизвестно>|Тип<Форма<неизвестно>>)](userfavorites-ru-e71189e469ca.md)

#### Примеры

```xbsl
    ИзбранноеПользователя.Удалить("https://1cmycloud.com/welcome/")

```
