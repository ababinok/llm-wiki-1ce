## Свойства

### ВерсияОс

`Доступность: Клиент` `ТолькоЧтение`

```
ВерсияОс: Строка
```

Содержит версию операционной системы устройства. Доступно при работе только на мобильном клиенте (приложении). В остальных случаях содержит пустую строку.

---

### ВидИнтерфейса

`Доступность: Клиент` `ТолькоЧтение`

```
ВидИнтерфейса: ВидИнтерфейса
```

Вид интерфейса приложения. Определяется при запуске приложения и в процессе дальнейшей работы не изменяется.

---

### ВидПлатформы

`Доступность: Клиент` `ТолькоЧтение`

```
ВидПлатформы: ВидПлатформыКлиента
```

Содержит вид платформы устройства.

---

### ВысотаОкнаПриложения

`Доступность: Клиент` `ТолькоЧтение`

```
ВысотаОкнаПриложения: Число
```

Содержит текущую высоту окна приложения.

---

### ДоступнаБиометрия

`Доступность: Клиент` `ТолькоЧтение`

```
ДоступнаБиометрия: Булево
```

Возвращает Истина, если на устройстве поддерживается биометрия, или Ложь, если не поддерживается. Доступно при работе только на мобильном клиенте (приложении). В остальных случаях Ложь.

---

### ИдКлиента

`Доступность: Клиент` `ТолькоЧтение`

```
ИдКлиента: Строка
```

Содержит идентификатор, уникальный для данного клиентского устройства.

Для всех приложений на данном сервере этот идентификатор будет одинаковый. Идентификатор создается системой и хранится в браузере пользователя. Если пользователь пользуется несколькими браузерами, то для каждого используемого браузера идентификатор будет свой. Идентификатор будет сборшен при полной очистки данных браузера для страницы приложения. В приватном режиме браузера идентификатор не сохраняется при закрытии окна браузера.

## Методы

### ВерифицироватьПользователя

`Доступность: Клиент`

```
ВерифицироватьПользователя(
  Сообщение: Строка,
  СпособВерификации: СпособВерификацииПользователя
): Булево
```

Показывает диалог верификации пользователя и возвращает результат проверки. Если при верификации произошла ошибка, выбрасывается исключение ИсключениеВерификацииПользователя.

---

### ПоддерживаетсяСпособВерификации

`Доступность: Клиент`

```
ПоддерживаетсяСпособВерификации(СпособВерификации: СпособВерификацииПользователя): Булево
```

Проверяет поддерживаемый способ верификации пользователя.

---

### УстановитьБлокировкуЗасыпания

`Доступность: Клиент`

```
УстановитьБлокировкуЗасыпания(): КонтекстБлокировкиЗасыпания
```

Возвращает контекст запрета засыпания, в котором засыпание устройства полностью отключено. Если метод вызвать несколько раз, то запрет будет действовать пока не будут закрыты все контексты.
