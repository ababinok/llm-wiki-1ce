## Обзор

Отобразить отчет либо панель отчетов в пользовательском интерфейсе приложения можно двумя способами:

## Документированный контракт и примеры

Отобразить отчет либо панель отчетов в пользовательском интерфейсе приложения можно двумя способами:

- с использованием формы отчетов,
- посредством встраивания отчета (панели отчетов) в пользовательскую форму или компонент.

Отчеты и панели отчетов отображаются в приложении только в режиме чтения.

## Форма отчета

У каждого отчета (панели отчетов) есть форма, которая открывается с помощью навигационной команды [`{ИмяОтчета}.Открыть`](../stdlib/reportname-open-ru-7450dfd3a8ce.md). По умолчанию используется автоматически сгенерированная форма, которая может быть переопределена в элементе проекта. Для переопределения формы создайте компонент интерфейса вида **ФормаОтчета**:

## Отображение отчетов в пользовательских формах

Для отображения отчета (панели отчетов) на форме используется компонент интерфейса **ПросмотрОтчета**. Чтобы отобразить отчет в компоненте, присвойте объект типа `Отчет` (`ПанельОтчетов`) свойству [Отчет](reportviewer-ru-c2fcfa1af193.md) компонента **ПросмотрОтчета** или настройте привязку данных к свойству [Отчет](reportform-ru-76807d946a52.md) формы отчета.

- Использование механизма привязки данных для отображения отчета
- Указание экземпляра отчета для отображения

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: e34e340e-87d8-4b4a-b673-f2f60ba730f4
Имя: ФормаОтчетаОСотрудниках
ОбластьВидимости: ВПодсистеме
Наследует:
    Тип: ФормаОтчета<ОтчетОСотрудниках>
    Отчет:
        Тип: ОтчетОСотрудниках
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: ПросмотрОтчета<ОтчетОСотрудниках>
            РастягиватьПоВертикали: Истина
            РастягиватьПоГоризонтали: Истина
            Отчет: =Отчет
```
