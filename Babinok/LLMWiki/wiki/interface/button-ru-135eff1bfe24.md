## Обзор

Прямоугольная область, выделенная фоном, с картинкой и заголовком.

## Документированный контракт и примеры

Прямоугольная область, выделенная фоном, с картинкой и заголовком. При нажатии на кнопку выполняется определенное действие, например: отправка данных, переход на страницу, сохранение изменений, закрытие формы.

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Заголовок

```yaml
Заголовок: Авто|Строка
```

Текст, отображаемый в кнопке.

---

#### Вид

```yaml
Вид: ВычисляемоеВыражение|Авто|ВидКнопки
```

Вид отображения кнопки.

---

#### ЗаголовокАктивного

```yaml
ЗаголовокАктивного: Авто|Строка
```

Текст, отображаемый в кнопке в активном состоянии. Имеет смысл, только если свойство [Переключаемость](button-ru-135eff1bfe24.md) равно **Истина**. Если свойство **ЗаголовокАктивного** неопределено, то используется значение свойства [Заголовок](button-ru-135eff1bfe24.md).

---

#### Активность

```yaml
Активность: ВычисляемоеВыражение|Булево
```

Признак активности. Если **Истина**, то компонент отображается с соответствующим состоянием. Имеет смысл, только если свойство [Переключаемость](button-ru-135eff1bfe24.md) равно **Истина**. Если кнопке назначена переключаемая команда, значение этого свойства игнорируется: активность определяется активностью переключаемой команды.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](button-ru-135eff1bfe24.md) = 1, а у другого [ВесПриРастягивании](button-ru-135eff1bfe24.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

---

#### ВидОтображенияЗаголовка

```yaml
ВидОтображенияЗаголовка: ВычисляемоеВыражение|Авто|ВидОтображенияЗаголовка
```

Вид отображения заголовка и изображения кнопки. Значение **Авто** интерпретируется как **ИконкаИТекст**.

Три режима заголовка кнопки: первый показывает только значок ключа; второй — значок ключа слева и текст «Иконка и текст»; третий — только «Текст». [Описание иллюстрации](../../raw/figures/bbf28c5ee97bbb9774eb720e283047f570055fed6250ada84d5f223dc04e2543-12e545d5a24b4b10.md)

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../../raw/figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../../raw/figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Высота

```yaml
Высота: ВычисляемоеВыражение|Авто|Число
```

Высота компонента в пикселях ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение высоты применяется, только если оно отлично от 0 и [РастягиватьПоВертикали](button-ru-135eff1bfe24.md) равно **Ложь**.

---

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](button-ru-135eff1bfe24.md).

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](button-ru-135eff1bfe24.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](button-ru-135eff1bfe24.md).

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](button-ru-135eff1bfe24.md) равно **Ложь**.

---

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриНажатии

```yaml
ПриНажатии: Строка
```

Вызывается при нажатии кнопки. Стандартная обработка события **ПриНажатии** выполняется, только если для свойства `СтандартнаяОбработка` установлено значение `Истина`.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

## Дочерние элеметы

#### Картинка

```yaml
Картинка: Картинка
```

Ссылка на внутренний компонент [Картинка](picture-ru-b53534fbcf55.md), который отображается в кнопке. Может использоваться для дополнительного оформления картинки.

---

#### КартинкаАктивного

```yaml
КартинкаАктивного: Картинка
```

Ссылка на внутренний компонент [Картинка](picture-ru-b53534fbcf55.md), который отображается в кнопке в активном состоянии. Может использоваться для дополнительного оформления картинки. Имеет смысл, только если свойство [Переключаемость](button-ru-135eff1bfe24.md) равно **Истина**. Если свойство **КартинкаАктивного** неопределено, то используется значение свойства [Картинка](button-ru-135eff1bfe24.md).

---

#### Команды

```yaml
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или массив команд, назначенных кнопке. Если указан массив команд, то они размещаются в меню кнопки.
