Элемент списка выбора значения.

## Документированный контракт и примеры

`Стд::Интерфейс::ВводДанных::ЭлементСпискаВыбора` `Доступность: КлиентИСервер`

Элемент списка выбора значения. Описывает одно найденное значение механизмом поиска по подстроке.

## Свойства

### ДиапазонВыделения

`Доступность: КлиентИСервер`

```
ДиапазонВыделения: Массив<ЗакрытыйДиапазон<Число>>
```

Содержит список выделенных фрагментов строки. Таким образом указывается в каких местах строки найдена искомая подстрока.

---

### Значение

`Доступность: КлиентИСервер`

```
Значение: неизвестно
```

Найденное значение. Обычно ссылка или ключ на найденные данные.

---

### Представление

`Доступность: КлиентИСервер`

```
Представление: Строка
```

Представление найденного значения. Может содержать не только значение поля представления, но и значения полей, в которых была найдена подстрока.
