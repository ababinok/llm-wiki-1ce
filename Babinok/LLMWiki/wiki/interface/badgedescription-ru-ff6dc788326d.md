## Обзор

Описание значка, отображающего, как правило, какое-либо дополнительное значение.

## Документированный контракт и примеры

`Стд::Интерфейс::ОписаниеЗначка` `Доступность: КлиентИСервер`

Описание значка, отображающего, как правило, какое-либо дополнительное значение. См. [ОписаниеЗначкаДополнительногоЗначения](picture-ru-efed61d49ad9.md)

**Сравнение**

Структурное

## Конструкторы

### ОписаниеЗначка

`Доступность: КлиентИСервер`

```
ОписаниеЗначка(
  МаксимальноеЗначение: Авто|Число,
  ОтображатьКакТочку: Авто|Булево,
  ВыравниваниеПоВертикали: Авто|ВыравниваниеПоВертикали,
  ВыравниваниеПоГоризонтали: Авто|ВыравниваниеПоГоризонтали,
  Смещение: Авто|Число,
  ОценкаИнформации: Авто|ОценкаИнформации,
  ОтображатьНоль: Авто|Булево,
  Цвет: Авто|Цвет)
```

Создает описание значка со значениями свойств, соответствующими параметрам конструктора.

## Свойства

### ВыравниваниеПоВертикали

`Доступность: КлиентИСервер`

```
ВыравниваниеПоВертикали: Авто|ВыравниваниеПоВертикали
```

Вертикальное положение значка относительно содержимого.

---

### ВыравниваниеПоГоризонтали

`Доступность: КлиентИСервер`

```
ВыравниваниеПоГоризонтали: Авто|ВыравниваниеПоГоризонтали
```

Горизонтальное положение значка относительно содержимого.

---

### МаксимальноеЗначение

`Доступность: КлиентИСервер`

```
МаксимальноеЗначение: Авто|Число
```

Максимальное значение, после которого значок содержит это значение и символ "+". Например, если [МаксимальноеЗначение](badgedescription-ru-ff6dc788326d.md) равно 99, а значение равно или больше 100 - на значке отобразится "99+".

---

### ОтображатьКакТочку

`Доступность: КлиентИСервер`

```
ОтображатьКакТочку: Авто|Булево
```

Показывать ли значок в виде небольшого кружочка без текста.

---

### ОтображатьНоль

`Доступность: КлиентИСервер`

```
ОтображатьНоль: Авто|Булево
```

Показывать ли значок, если отображаемое значение связанного компонента равно 0.

---

### ОценкаИнформации

`Доступность: КлиентИСервер`

```
ОценкаИнформации: Авто|ОценкаИнформации
```

Оценка информации значка

---

### Смещение

`Доступность: КлиентИСервер`

```
Смещение: Авто|Число
```

Смещение в пикселах от угла, задаваемого параметрами положения значка.

---

### Цвет

`Доступность: КлиентИСервер`

```
Цвет: Авто|Цвет
```

Задает основной цвет значка. Цвет фона и цвет текста определяются автоматически
