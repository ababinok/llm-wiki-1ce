## Свойства

### Видимость

`Доступность: Клиент`

```
Видимость: Авто|Булево
```

Определяет, будет ли в приложении отображаться интерфейс для встроенных веб-страниц: панель, меню и т.д. По умолчанию интерфейс показывается, если в [СтандартноеКлиентскоеПриложениеСРазделами](standardclientapplicationwithsections-ru-2bf3e285c484.md) добавлена хотя бы одна встроенная веб-страница.

---

### ДополнительныеКомандыМеню

`Доступность: Клиент`

```
ДополнительныеКомандыМеню: ФрагментКомандногоИнтерфейса?
```

Задает дополнительные команды в меню встроенных веб-страниц.

---

### КомандыПанели

`Доступность: Клиент`

```
КомандыПанели: ФрагментКомандногоИнтерфейса?
```

Содержит описание командного интерфейса панели встроенных веб-страниц.

---

### КомпонентМеню

`Доступность: Клиент`

```
КомпонентМеню: ВсплывающийКомпонент?
```

Компонент для представления меню встроенных веб-страниц. Если не задан, используется встроенный компонент.

---

### Логотип

`Доступность: Клиент`

```
Логотип: Авто|Url|ДвоичныйОбъект.Ссылка
```

Логотип интерфейса встроенных веб-страниц. При значении [Авто](../stdlib/auto-ru-1b14ed166f8e.md) в интерфейсе встроенных веб-страниц будут задействованы картинки по умолчанию, в зависимости от контекста.

---

### ЛоготипКрупный

`Доступность: Клиент`

```
ЛоготипКрупный: Авто|Url|ДвоичныйОбъект.Ссылка
```

Крупный логотип интерфейса встроенных веб-страниц. Если изображение выставлено в [Авто](../stdlib/auto-ru-1b14ed166f8e.md), оно берется из свойства [Логотип](embeddedwebpagesinterface-ru-42e56c8809d2.md)

---

### ОсновнаяКомандаМеню

`Доступность: Клиент`

```
ОсновнаяКомандаМеню: Команда?
```

Задает команду, которая определяет основное действие в меню встроенных веб-страниц.

---

### ЦветПанели

`Доступность: Клиент`

```
ЦветПанели: Авто|Цвет
```

Цвет панели.
