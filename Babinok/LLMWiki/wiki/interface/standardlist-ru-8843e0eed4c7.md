## Обзор

ТипИсточника: Тип источника данных списка.

## Документированный контракт и примеры

`Стд::Интерфейс::Списки::СтандартныйСписок<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>.

Стандартный список. Позволяет отобразить набор данных в виде списка с элементами стандартной структуры. Описание данных строки задаются через свойства списка с использованием вычисляемых выражений.

**Особенности привязки данных в списке**

При описании свойств элементов списка допустимо использовать привязку к данным строки. В отличие от обычной привязки, вычисляемой без аргумента, в привязке данных свойств элементов списка доступен дополнительный параметр:

- ДанныеСтроки(RowData): SourceType.ItemDataType - данные строки таблицы.

**Сравнение**

Ссылочное

### МаксимальнаяВысотаОписанияВСтроках

`Доступность: Клиент`

```
МаксимальнаяВысотаОписанияВСтроках: Авто|Число
```

Максимальная высота свойства [ОписаниеСтроки](standardlist-ru-8843e0eed4c7.md) в строках. Значение 0 снимает ограничение по высоте.

По достижению указанного значения высота текста в строках не сможет стать больше, и все что не вместилось - уйдет в многоточие.

Авто разрешается, как 2

### ОбрезатьЗначение

`Доступность: Клиент`

```

```

Определяет возможность строке из свойства [ЗначениеСтроки](standardlist-ru-8843e0eed4c7.md) элемента обрезаться, уходя в многоточие.

Если Ложь – строка будет всегда показываться в развернутом виде, а при нехватке места, для списка будет показан горизонтальный скролл
