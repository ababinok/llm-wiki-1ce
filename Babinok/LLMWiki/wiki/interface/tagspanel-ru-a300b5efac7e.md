## Обзор

ТипДанных: тип значения компонента **ПанельТегов**.

## Документированный контракт и примеры

`Стд::Интерфейс::ОбщиеКомпоненты::ПанельТегов<ТипДанных>` `Доступность: Клиент`

ТипДанных: тип значения компонента **ПанельТегов**.

Компонент **ПанельТегов** отображает указанные данные в виде области с тегами, которые расположены по всей ширине. Отдельные теги содержат текст и картинку с возможностью обработки нажатия. Область с тегами может быть свернута по высоте до одной строки или развернута на всю высоту.

Тег может быть информационным (неинтерактивным) и интерактивным. Тег становится интерактивным, если компонент **ПанельТегов** содержит обработчик события [ПриНажатииНаТег](tagspanel-ru-a300b5efac7e.md). Интерактивные теги с заданным [Цвет](valuelistitem-ru-c68a213e54f6.md) имеют опцию управления заливкой фона [ОкрашиватьФонТегов](tagspanel-ru-a300b5efac7e.md).

Если компонент **ПанельТегов** находится в составе компонентов [Таблица](table-ru-ccc43dec1ca9.md) (т. е. в колонках таблицы [СтандартнаяКолонкаТаблицы](standardtablecolumn-ru-92a62dc49597.md) или [ПроизвольнаяКолонкаТаблицы](customtablecolumn-ru-7dccdc7e94af.md)), [ПроизвольныйСписок](customlist-ru-858edf1f6219.md) (т. е. в строке [ПроизвольнаяСтрокаСписка](customlistrow-ru-a113b0497543.md)), [Карточка](card-ru-236110dd3bc1.md) ([СтандартнаяКарточка](standardcard-ru-cc5dce54db7d.md), [ПроизвольнаяКарточка](customcard-ru-90894d213430.md)) или [ПроизвольноеОкноМаркераГеографическойКарты](geographicmapmarkercustomwindow-ru-80ef2d2e6c01.md) (или в любых других компонентах, содержащихся в них), то он отображается в более компактном виде: в частности, у него отсутствует [Заголовок](tagspanel-ru-a300b5efac7e.md) и [Изображение](tagspanel-ru-a300b5efac7e.md).

## Свойства

### Заголовок

`Доступность: Клиент`

```
Заголовок: Авто|Строка
```

Заголовок, отображаемый над областью с тегами.

---

### Изображение

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Изображение (декорация) слева от области тегов и заголовка компонента.

---

### ОкрашиватьФонТегов

`Доступность: Клиент`

```
ОкрашиватьФонТегов: Авто|Булево
```

Указывает, заполнять ли фон интерактивных (кликабельных) тегов выбранным [ЦветТегов](tagspanel-ru-a300b5efac7e.md). Значение свойства игнорируется при [ЦветТегов](tagspanel-ru-a300b5efac7e.md) = [Авто](../stdlib/auto-ru-1b14ed166f8e.md).

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) = `Истина`

---

### ОтображатьКнопкуСворачивания

`Доступность: Клиент`

```
ОтображатьКнопкуСворачивания: Авто|Булево
```

Указывает, отображать ли кнопку сворачивания/разворачивания. При скрытии кнопки компонент всегда развернут.

Независимо от значения данного свойства, кнопка сворачивания/разворачивания автоматически скрывается, если теги вмещаются в одну строку.

Свойство [Свернут](tagspanel-ru-a300b5efac7e.md) неактуально, когда [ОтображатьКнопкуСворачивания](tagspanel-ru-a300b5efac7e.md) = `Ложь`, то есть теги всегда развернуты, если кнопка сворачивания скрыта.

[Авто](../stdlib/auto-ru-1b14ed166f8e.md) = `Истина`

---

### Свернут

`Доступность: Клиент`

```
Свернут: Булево
```

Указывает состояние компонента. Свойство требует двунаправленной связи с данными.

`Ложь` — отображается весь набор тегов. `Истина` — набор тегов свернут в одну строку. Кнопка сворачивания/разворачивания показывается, если теги не вмещаются в одну строку.

[Свернут](tagspanel-ru-a300b5efac7e.md) неактуально, когда:

- [ОтображатьКнопкуСворачивания](tagspanel-ru-a300b5efac7e.md)
  
  =
  
  `Ложь`
  
  , то есть теги всегда развернуты, если кнопка сворачивания скрыта;
- компонент отображается в компактном виде.

По умолчанию = `Истина`

---

### СписокЗначений

`Доступность: Клиент`

```
СписокЗначений: ЧитаемыйМассив<ТипДанных|ЭлементСпискаЗначений<ТипДанных>>
```

Устанавливает список значений.

В простых случаях в качестве списка значений можно использовать массив элементов любого типа, переданного в параметре `ТипДанных`. Тогда будет использовано строковое представление элементов этого типа.

В качестве списка можно использовать массив объектов типа [ЭлементСпискаЗначений](valuelistitem-ru-c68a213e54f6.md), где в качестве представления элементов используется соответствующее свойство [Представление](valuelistitem-ru-c68a213e54f6.md). Если оно не задано, то используется строковое представление свойства [Значение](valuelistitem-ru-c68a213e54f6.md).

---

### ЦветТегов

`Доступность: Клиент`

```
ЦветТегов: Авто|Цвет
```

Устанавливает цвет окрашивания тегов.

Если в качестве [СписокЗначений](tagspanel-ru-a300b5efac7e.md) используется массив [ЭлементСпискаЗначений](valuelistitem-ru-c68a213e54f6.md), то при окрашивании тега берется [Цвет](valuelistitem-ru-c68a213e54f6.md) соответствующего элемента, если [Цвет](valuelistitem-ru-c68a213e54f6.md) задан.

При [Авто](../stdlib/auto-ru-1b14ed166f8e.md) используется окрашивание по умолчанию.
