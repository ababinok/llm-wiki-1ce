## Примеры

В примере ниже показано, как выбрать поля **Ссылка**, **Представление** и **Администратор** из таблицы **Пользователи**:

```xbql
ВЫБРАТЬ 
    Ссылка КАК Ссылка,
    Представление КАК Представление,
    Администратор КАК Администратор
ИЗ 
    Пользователи
```

## Поля

### Администратор

```
Администратор: Булево
```

Флаг, который указывает, что пользователь является администратором.

---

### БылУспешныйВход

```
БылУспешныйВход: Булево
```

Флаг, который указывает, что пользователь осуществлял вход в приложение.

---

### ЗапрещенВход

```
ЗапрещенВход: Булево
```

Флаг, который указывает, что пользователь заблокирован.

---

### РазрешенДоступПоТокену

```
РазрешенДоступПоТокену: Булево
```

Флаг, который указывает, что пользователю разрешен доступ к HTTP-сервисам приложения.

---

### Ссылка

`Ключевое поле`

```
Ссылка: Пользователи.Ссылка
```

Ссылка на пользователя.

---

### Представление

```
Представление: Строка
```

Строковое представление пользователя в приложении.

---

### ЛокальОтображения

`Версия 8.0 и выше`

```
ЛокальОтображения: Локаль?
```

Локаль отображения. Влияет на язык интерфейса, форм, сообщений. Необязательное поле.

---

### ЛокальФорматирования

`Версия 8.0 и выше`

```
ЛокальФорматирования: Локаль?
```

Локаль форматирования. Влияет на способ представления дат и чисел в виде строки. Необязательное поле.
