## Задача

Нужно отобрать записи по значению, полученному в коде, и обработать результат. Руководство рекомендует литерал запроса, когда текст известен при компиляции; произвольный запрос используется при динамическом тексте. Типы колонок литерала проверяются при компиляции, а динамического текста — во время работы.

## Порядок реализации

1. Сверьте источник данных и прикладные реквизиты. Исходный пример предполагает справочник `Сотрудники` с `Ссылка`, `ФИО` и `Возраст`; эти имена не являются гарантированным контрактом любого проекта.
2. В XBSL используйте литерал `Запрос{...}`. В исходном примере локальное значение `Возраст` подставляется через `%Возраст`.
3. При работе с текстом языка запросов отдельно сверяйте `&имя-параметра`. Его нельзя механически подставить вместо `%Возраст` в литерале. Для произвольного запроса способ передачи параметров сверяйте в статье «Использование конструктора произвольного запроса».
4. Откройте программный контракт `ТипизированныйЗапрос`: он доступен в окружении `Сервер`, его `Выполнить()` возвращает `РезультатЗапроса<ТипСтрокиРезультатаЗапроса>`. Результат обходится через `для ... из`. Запрос без выборки имеет другой контракт.
5. Если вызов нужен из формы, сначала сверяйте передачу исполнения с клиента на сервер; не считайте наличие XBSL-примера разрешением исполнять запрос на клиенте.

## Пример из руководства

```xbsl
// Установить значения параметров запроса.
знч Возраст = 40

// Задать текст запроса.
знч Запрос = Запрос{ВЫБРАТЬ
                        Сотрудники.Ссылка КАК Ссылка,
                        Сотрудники.ФИО КАК ФИО
                     ИЗ
                        Сотрудники КАК Сотрудники
                     ГДЕ
                        Сотрудники.Возраст < %Возраст}

// Обойти результат запроса и обработать его.
для СтрокаРезультата из Запрос.Выполнить()
    пер СотрудникСсылка = СтрокаРезультата.Ссылка
    пер СотрудникФИО    = СтрокаРезультата.ФИО
;
```

## Ограничения

Руководство отдельно запрещает в литерале форму `ВЫБРАТЬ * ИЗ ЖурналСобытий`. Для динамического текста проверьте отдельные типы результата и документированные исключения. Этот маршрут не заменяет контракт операций записи или изменения данных.
