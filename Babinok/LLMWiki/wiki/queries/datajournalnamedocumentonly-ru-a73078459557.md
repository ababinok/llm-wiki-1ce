## Обзор

Таблица [журнала данных](../project/data-journal-project-element-7531ea42bb4a.md), в состав которого входят только документы.

## Документированный контракт и примеры

`Версия 10.0 и выше`

Таблица [журнала данных](../project/data-journal-project-element-7531ea42bb4a.md), в состав которого входят только документы. Таблица содержит записи, соответствующие данным документов входящих в состав журнала. Одна запись таблицы — один документ.

---

## Примеры

Пример запроса к таблице журнала данных **ЖурналТорговыхДокументов**:

```xbql
ВЫБРАТЬ
    Журнал.Дата КАК Дата,
    Журнал.Номер КАК Номер,
    Журнал.КлючЗаписи КАК КлючЗаписи,
    Журнал.Тип КАК Тип,
    Журнал.Информация КАК Информация
ИЗ
    ЖурналТорговыхДокументов КАК Журнал
```

---

## Поля

### {ИмяКолонки}

```
{ИмяКолонки}: ТипКолонки
```

Значение реквизита документа, соответствующего колонке журнала.

Может принимать значение `Неопределено`, если для документа, входящего в журнал, не указан соответствующий колонке реквизит.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяДокумента.Ссылка
```

Ссылка на документ, входящий в журнал.

---

### ПометкаУдаления

```
ПометкаУдаления: Булево
```

Пометка удаления документ, входящего в журнал.

---

### Дата

```
Дата: ДатаВремя
```

Дата документа. Необязательное поле.

В журнале поле **Дата** будет существовать по умолчанию, только если дата всех документов приводима к одному типу. Тип поля определяется следующим образом:

- `Дата`
  
  , если у всех документов тип реквизита —
  
  `Дата`
  
  .
- `ДатаВремя`
  
  , если у всех документов тип реквизита —
  
  `ДатаВремя`
  
  , либо если документы имеют различные типы реквизитов:
  
  `Дата`
  
  и
  
  `ДатаВремя`
  
  .
- `Момент`
  
  , если у всех документов тип даты —
  
  `Момент`
  
  .

Если в журнале есть документы с типами дат `Дата`/`ДатаВремя` и `Момент`, то поле **Дата** в журнале создано не будет.

---

### Номер

```
Номер: Строка
```

Номер документа. Необязательное поле.

В журнале поле **Номер** будет существовать по умолчанию, только если хотя бы у одного из документов есть реквизит **Номер**. Номер может быть числом, строкой или отсутствовать. Длина числа выбирается как максимальная из входящих (число может быть только целым положительным). Длина строки выбирается как максимальная из входящих.

---

### Тип

`Вычисляемое поле`

```
Тип: Тип
```

Тип ссылки на документ, входящий в журнал.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяЖурналаДокументов.КлючЗаписи
```

Структура с одним полем **Ссылка**, которое содержит ссылку на документ, входящий в журнал.
