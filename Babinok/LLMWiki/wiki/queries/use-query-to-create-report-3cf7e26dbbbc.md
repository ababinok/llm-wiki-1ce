## Обзор

«1С:Предприятие.Элемент» позволяет использовать произвольный запрос в качестве источника данных для отчета.

## Документированный контракт и примеры

«1С:Предприятие.Элемент» позволяет использовать произвольный запрос в качестве источника данных для отчета.

## Ограничения и особенности запроса

Текст запроса должен располагаться в отдельном xbql-файле с тем же именем, что и имя элемента проекта **Отчет**. Запрос не может быть пустым и должен удовлетворять следующим требованиям:

- Быть валидным и соответствовать ограничениям для подзапросов:
  
  - это должен быть запрос на выборку данных;
  - предложение
    
    `УПОРЯДОЧИТЬ ПО`
    
    можно использовать только с предложениями
    
    `ПЕРВЫЕ`
    
    или
    
    `ПОЛУЧИТЬ`
    
    /
    
    `СО СМЕЩЕНИЕМ`
    
    и наоборот.
- В запросе запрещено использовать конструкцию
  
  `ВЫБРАТЬ *`
  
  .
- Для всех выражений в списке выборки должны быть указаны псевдонимы, или это должны быть просто выражения выборки поля. При этом использовать два и более выражения выборки поля с одинаковым именем поля (не важно из одной таблицы или разных) без псевдонима не допускается.
- В запросе используется синтаксис параметров аналогично произвольным запросам:
  
  `&ИмяПараметра`
  
  .
- Не поддерживается использование источников данных на основе коллекций.

## Параметры запроса

Если запрос содержит параметры, их необходимо указать в свойстве отчета **ПараметрыЗапроса**. В свойстве должны быть перечислены все параметры, имеющиеся в запросе. Недопустимо указывать параметры, которые отсутствуют в тексте запроса.

Каждый параметр описывается следующими свойствами:

- **Имя** — `Строка`. Имя параметра. Должно быть корректным идентификатором с точки зрения языка «1С:Элемент».
- **Тип** — `Множество<Тип>`. Тип параметра. Не может быть пустым. В качестве значения:
  
  - допускается использование типов, поддерживаемых в языке запросов, кроме типа
    
    `Байты`
    
    ;
  - разрешено использование коллекций (
    
    `Массив<ТипЭлемента>`
    
    );
  - допускается использование составных типов, однако в состав не может входить коллекция. Например, тип
    
    `Массив<Строка>|Число`
    
    является недопустимым.
  
  Для некоторых типов необходимо указать ограничения:
  
  - `Строка`
    
    —
    
    `МаксимальнаяДлина`
    
    ,
  - `Число`
    
    —
    
    `ДлинаЦелойЧасти`
    
    и
    
    `ДлинаДробнойЧасти`
    
    ,
  - другие ограничения не поддерживаются.
- **ЗначениеПоУмолчанию** — `Объект?`. Значение параметра по умолчанию. Определяется следующим образом:
  
  - если у типа параметра есть значение по умолчанию, используется оно;
  - если параметр имеет составной тип, включающий
    
    `Неопределено`
    
    , значение по умолчанию равно
    
    `Неопределено`
    
    ;
  - в остальных случаях значение по умолчанию необходимо указать явно.

## Пример создания отчета на основе запроса

> [!NOTE] примечание
> Этот пример использует [приложение «Демо CRM»](../project/demo-app-3768685a4428.md).

Чтобы создать отчет на основе запроса, выполните следующие действия:

1. Создайте элемент проекта **Отчет**. Для свойства **ВидИсточникаДанных** выберите значение **Запрос**. Свойство **ИсточникДанных** оставьте пустым.
  
  В свойствах отчёта ВидИсточникаДанных установлен в «Запрос», ИсточникДанных оставлен пустым для программной подготовки запроса. [Описание иллюстрации](../../raw/figures/ec85ae9064fa57a8e63b72c9838e13c0414b43d65ed86cea97838684ed449db1-3b6c6bd11595555a.md)
2. Для отчета автоматически генерируется пустой файл **ИмяОтчета.xbql**. Откройте данный файл и добавьте в него текст запроса.
  
  В данном примере файл **ОтчетОСотрудниках.xbql** содержит запрос, который возвращает поля **Наименование**, **Пользователь**, **БизнесРегион** и **Роль** сотрудников, для которых **Роль** соответствует значению параметра **Должность**.
  
  ОтчетОСотрудниках.xbql
  
  ```xbql
  ВЫБРАТЬ
      Наименование КАК Наименование,
      Пользователь КАК Пользователь,
      БизнесРегион КАК БизнесРегион,
      Роль КАК Роль
  ИЗ
      Сотрудники
  ГДЕ
      Роль == &Должность
  ```
3. Так как запрос содержит параметр, для него необходимо создать соответствующий параметр отчета. Для этого в навигаторе проекта перейдите к вашему отчету и в разделе **Параметры запроса** создайте новый параметр со следующими свойствами:
  
  - Имя
    
    : Должность;
  - Тип
    
    : перечисление
    
    `РольСотрудника`
    
    ;
  - ЗначениеПоУмолчанию
    
    :
    
    `МенеджерПоПродажам`
    
    .
  
  В настройках параметра отчёта указаны: Имя — Должность; Тип — РольСотрудника; ТипЗначенияПоУмолчанию — РольСотрудника; ЗначениеПоУмолчанию — МенеджерПоПродажам; НезаполненноеЗначение — Разрешить. [Описание иллюстрации](../../raw/figures/7449bda2419112310d9afe27e855c1a97f07232b5beafc5766e7913cf2bcc8f2-5206e10aa35d0298.md)
4. В конструкторе добавьте поля, которые нужно отобразить в отчете. Для этого выберите нужные поля на панели слева, и они отобразятся на панели отчета справа.
  
  В данном примере добавляются поля **Наименование**, **Пользователь**, **Бизнес регион**, **Роль**.
  
  Добавление полей к отчету [Описание иллюстрации](../../raw/figures/89d0821d3c6f827e0c16c92489fabf2b81a89935f11e8246e73713cf8a1df41b-bf1f2488b97e4176.md)
  
  <details>
  <summary>Пример YAML-файла отчета «ОтчетОСотрудниках»</summary>
  
  ```yaml
  ВидЭлемента: Отчет
  ОбластьВидимости: ВПодсистеме
  Ид: 89a906b7-0ba9-48d4-ae14-2b1d0b90cb89
  Имя: ОтчетОСотрудниках
  ВидИсточникаДанных: Запрос
  Интерфейс:
      ВключатьВАвтоИнтерфейс: Истина
      Форма: ФормаОтчетаОСотрудниках
  Макет:
      ВидОтображения: СводнаяТаблица
      Поля:
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Наименование
              Ид: e979397c7dc44adaa2013c4aed796c0a
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Пользователь
              Ид: a1a12fbb25ef4e6dbf2718a901cbca1e
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: БизнесРегион
              Ид: c5cbc71708ca4b0d860c6ed7829e6172
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Роль
              Ид: ec6e2459e38940f9957d64a255f657d3
              Использовать: Истина
  ПараметрыЗапроса:
      -
          Имя: Должность
          Тип: РольСотрудника
          ЗначениеПоУмолчанию: МенеджерПоПродажам
  ```
  
  </details>
5. Создайте форму отчета и добавьте поле ввода для выбора должности сотрудника. В свойстве **Значение** поля ввода настройте привязку к значениям параметра отчета.
  
  В редакторе формы отчёта добавлено поле выбора должности сотрудника; его значение привязывается к параметру отчёта, рядом расположен компонент просмотра результата. [Описание иллюстрации](../../raw/figures/e581693a2b8b1a17aa72ed6c3b14ebae3a74ef51f44bf14e6566205359175254-b309f6274ee142f7.md)
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: e3da7c3a-fdd5-4be8-bfdc-35c077c48260
  Имя: ФормаОтчетаОСотрудниках
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: ФормаОтчета<ОтчетОСотрудниках>
      ВключатьВАвтоИнтерфейс: Ложь
      Отчет:
          Тип: ОтчетОСотрудниках
      Содержимое:
          Тип: ПроизвольныйШаблонФормы
          Содержимое:
              Тип: Группа
              Содержимое:
                  -
                      Тип: ПолеВвода<РольСотрудника?>
                      Имя: Должность
                      Значение: =Отчет.Параметры.Должность
                  -
                      Тип: ПросмотрОтчета<ОтчетОСотрудниках>
                      РастягиватьПоВертикали: Истина
                      РастягиватьПоГоризонтали: Истина
                      Отчет: =Отчет
  ```
6. Включите в интерфейс команду открытия формы отчета. Нажмите на элемент проекта **Приложение** и перейдите к элементу **ГруппаКомандногоИнтерфейса** раздела **Анализ**. Добавьте [навигационную команду](../project/navigation-command-e62fae29cc19.md), которая открывает форму отчета.
  
  [Подробнее о том, где находится командный интерфейс](../interface/locate-command-interface-7543048d998d.md)
  
  Приложение.yaml
  
  ```yaml
  # Элементы раздела «Анализ»
  Тип: ГруппаКомандногоИнтерфейса
  Важность: Обычная
  Видимость: Истина
  Доступность: Истина
  Изображение: Показатель.svg
  Представление: $ОсновноеЛокализация.Анализ
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Важность: Обычная
          Видимость: Истина
          Доступность: Истина
          ОпасностьДействия: Отсутствует
          Представление: $ПродажиЛокализация.ВоронкаПродаж
          ТипФормы: ВоронкаПродаж.АвтоматическаяФорма
      -
          Тип: НавигационнаяКоманда
          Представление: Отчет о сотрудниках
          ТипФормы: ФормаОтчетаОСотрудниках
  ```

### Результат

Запустите приложение и откройте вкладку **Отчеты** ⟶ **Отчет о сотрудниках**, чтобы увидеть получившийся отчет.
