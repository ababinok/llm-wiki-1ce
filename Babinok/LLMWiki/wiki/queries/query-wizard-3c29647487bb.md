## Обзор

Конструктор запросов — это инструмент для создания и редактирования запроса с помощью графического интерфейса.

## Документированный контракт и примеры

Конструктор запросов — это инструмент для создания и редактирования запроса с помощью графического интерфейса.

> [!NOTE] дополнительно
> В текущей версии конструктора поддерживается работа со следующими операторами пакета запросов: [`ВЫБРАТЬ`](../project/select-statement-0fef6f15002c.md), [`УНИЧТОЖИТЬ`](../project/drop-statement-2e25a487bf09.md).

Конструктор запросов можно открыть из [консоли запросов](query-console-e39bfa4ff80f.md), нажав на кнопку **Конструктор**.



Форма конструктора состоит из двух основных частей:

- Панель навигации
  
  — с ее помощью вы можете добавлять новые запросы в пакет запросов, а также переключаться между компонентами редактирования отдельных секций запроса:
  
  - Запрос
    
    — компонент редактирования секции описания запроса. С его помощью выполняется выбор таблиц и полей, настраиваются соединения таблиц, группировка, условия и предикаты запроса.
  - Объединения/Псевдонимы
    
    — компонент редактирования секции объединения запросов. С его помощью в запрос можно добавить новые части объединения, установить псевдонимы полей.
  - Порядок
    
    — компонент упорядочивания результатов запроса.
  - Индекс
    
    — компонент выбора полей индексирования временной таблицы (отображается, если для запроса выбран тип создания временной таблицы).
- Область секции запроса
  
  — область редактирования секции запроса, выбранной в панели навигации.

Форма конструктора запросов [Описание иллюстрации](../../raw/figures/8abba0f4e4581753d839e6ed2b3a49fe3bbcedd98a90a325dc1344015cca7d67-f47e278beec74b7b.md)

## Создание запроса

На примере [демонстрационного приложения](../project/demo-app-3768685a4428.md) создадим простой запрос выборки данных с помощью конструктора запросов.

1. Откройте конструктор запросов. Для этого в [консоли запросов](query-console-e39bfa4ff80f.md) нажмите **Конструктор**.
  
  
2. В меню **Тип запроса** выберите тип **Выборка данных**. Этот тип запроса позволяет сформировать запрос с помощью оператора [`ВЫБРАТЬ`](../project/select-statement-0fef6f15002c.md) без дополнительных условий. Если вы хотите сохранить результаты запроса во временной таблице с помощью предложения [`ПОМЕСТИТЬ`](../project/select-into-bacd882e109f.md), используйте тип запроса **Создание временной таблицы**.
  
  Тип запроса «Выборка данных» [Описание иллюстрации](../../raw/figures/d6f178468c4b9bc73ef882dcb1bb8314035a37a34982adfa2845dc134f35886d-ed931c5888222fb2.md)
3. В **Панели навигации** выберите **Запрос 1** для открытия области секции запроса.
4. На вкладке **Таблицы и поля** в колонке **База данных** отображаются все доступные в проекте подсистемы и пакеты, содержащие в себе таблицы для выборки. Чтобы переместить таблицы в колонку **Таблицы**, используйте кнопку **Выбрать**. Выберите таблицу **Задачи** из подсистемы **Активности** (в текст запроса добавится предложение [`ИЗ`](../project/select-from-27aff9beba95.md)):
  
  
5. Опционально установите псевдоним для таблицы с помощью кнопки **Настройки** (в тексте запроса изменится представление таблицы после ключевого слова [`КАК`](../project/select-statement-0fef6f15002c.md)).
6. Выберите поля запроса **Ссылка** и **Сделка** в колонке **Таблицы** и добавьте их в колонку **Поля** с помощью кнопки **Выбрать**. Поля запроса также можно добавить непосредственно из колонки **База данных**.
  
  В конструкторе запроса на вкладке «Таблицы и поля» показаны три колонки: «База данных», «Таблицы», «Поля». [Описание иллюстрации](../../raw/figures/016f8ef09a88acadd7fe2e045204ea030ff5c3a5e9621b31ea3a80e10aa173ff-554c83d16fe8d552.md)
7. На вкладке **Условия** настройте дополнительное условие выборки — `Задачи.Статус != &Завершено`. В текст запроса добавится предложение [`ГДЕ`](../project/select-where-b56f76db6754.md).
  
  
8. В **Панели навигации** выберите **Объединения/Псевдонимы** для открытия формы настройки отображения запроса.
9. В колонке **Имя поля** задайте псевдоним для поля `Задачи.Ссылка` — `Задача`.
  
  Установка псевдонима [Описание иллюстрации](../../raw/figures/d885778e4493ac3573c6df11a29578a9b27609ee85c46ec1c359e13c74baf677-7959b5d0836e81df.md)
10. Нажмите **ОК**, чтобы завершить составление запроса.

Результатом работы конструктора будет запрос в консоли запросов, который возвращает сделки по задачам, статус которых не равен значению параметра `Завершено`:

```xbql
ВЫБРАТЬ
    Задачи.Ссылка КАК Задача,
    Задачи.Сделка КАК Сделка
ИЗ
    Задачи КАК Задачи
ГДЕ
    Задачи.Статус != &Завершено
```

Перед выполнением запроса [задайте значение параметра](query-console-e39bfa4ff80f.md) `Завершено`.

## Объединение запросов

Объединение запросов позволяет получить единую выборку из двух или более независимых наборов данных. Для создания объединения в конструкторе запросов выполните следующие действия:

1. В [консоль запросов](query-console-e39bfa4ff80f.md) добавьте запрос из [примера выше](query-wizard-3c29647487bb.md).
2. Откройте конструктор запросов.
3. В **Панели навигации** выберите **Объединения/Псевдонимы**.
4. В колонке **Запросы** нажмите **Добавить запрос**.
  
  В конструкторе запроса, в колонке «Запросы», кнопка плюса добавляет запрос в пакет; рядом видны вкладки объединений и псевдонимов. [Описание иллюстрации](../../raw/figures/33f55b274d741e96639c0a5a79da0357a5b2a7374b83091c6f34ab20d61e651b-0603cf2ef04ba3f3.md)
5. Добавьте в запрос поля **Ссылка** и **Сделка** таблицы **События** из подсистемы **Активности**.
  
  
6. Добавьте условие `События.Начало > &Сейчас`.
  
  Добавление условия [Описание иллюстрации](../../raw/figures/cc4b498a6bc1b2be6059f8126e9798b815fbd7992b6b74d2904403877fdaa9cb-44d050261e42d6f9.md)
7. Нажмите **ОК**, чтобы завершить составление запроса.

Результатом работы конструктора будет объединение запросов с помощью предложения [`ОБЪЕДИНИТЬ`](../project/union-2df9f1dcbdd8.md). Этот запрос вернет задачи, статус которых не равен значению параметра `Завершено`, а также события, дата начала которых позже момента `Сейчас`:

```xbql
ВЫБРАТЬ
    Задачи.Ссылка КАК Задача,
    Задачи.Сделка КАК Сделка
ИЗ
    Задачи КАК Задачи
ГДЕ
    Задачи.Статус != &Завершено

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
    События.Ссылка,
    События.Сделка
ИЗ
    События КАК События
ГДЕ
    События.Начало > &Сейчас
```

Перед выполнением запроса [задайте значения параметров](query-console-e39bfa4ff80f.md) `Завершено` и `Сейчас`.

## Пакетный запрос

Усложним предыдущий пример, добавив в него пакетный запрос. Пакетный запрос позволяет выполнять несколько запросов последовательно, при этом результаты предыдущих запросов могут быть использованы в последующих, например, через временные таблицы.

1. В [консоль запросов](query-console-e39bfa4ff80f.md) добавьте запрос из [примера выше](query-wizard-3c29647487bb.md).
2. Откройте конструктор запросов.
3. В **Панели навигации** выберите **Запрос 1** и измените его тип на **Создание временной таблицы**, задайте имя временной таблицы — «ВТ_Активности».
  
  Тип запроса [Описание иллюстрации](../../raw/figures/e561054bc851b9aa5e131eda73b87eb3d5b444e3e92f7d413fb1a6ce7a0f7a2d-907fff91608d3d3f.md)
4. В **Панели навигации** нажмите **Добавить запрос пакета**.
5. Добавьте поля `Сделки.Ссылка`, `Сделки.ИтоговаяСумма` и `ВТ_Активности.Задача`.
  
  Запрос пакета [Описание иллюстрации](../../raw/figures/8fc875c003c0e9d44a18cf4c1f0a175294c3d8bd1f6e7455d904b3bb497fe58b-25ceab43c2c08185.md)
6. С помощью меню **Агрегатные функции** для поля `ВТ_Активности.Задача` выберите функцию [`КОЛИЧЕСТВО`](../project/count-function-6de4a6dd5b96.md).
  
  Агрегатные функции [Описание иллюстрации](../../raw/figures/eec388d306f2b3ee2895f5a64bfa59a473f8d38c0878ccc1fc8a0d4c612e158b-55570d4190df909f.md)
  
  > [!NOTE] примечание
  > Выражение можно добавить как с помощью текстового редактора, так и с помощью интерфейса.
  >
  > Редактор выражения [Описание иллюстрации](../../raw/figures/c51591ec97b92b953ca6921a9f404fd2c657c9fe94c33b1424c1f5af66d5b02f-40f6d6e2dd7ed9a8.md)
7. Перейдите на вкладку **Соединения**. Здесь выполняется настройка соединения, по умолчанию устанавливается `ЛЕВОЕ СОЕДИНЕНИЕ ПО Истина`. Укажите условие соединения для таблицы **ВТ_Активности**: `Сделки.Ссылка == ВТ_Активности.Сделка`.
  
  Вкладка «Соединения» [Описание иллюстрации](../../raw/figures/ebb743ce3392f7a5adf6982409d262c352fcddfef90bc657d96ff2ece579eea7-cf7603ae9c0d9f31.md)
8. Перейдите на вкладку **Группировка**. Здесь выполняется настройка полей и задаются условия группировки, которые добавляют в запрос предложение [`СГРУППИРОВАТЬ ПО`](../project/group-by-3a79b00f00c2.md).
  
  - Установите поля группировки: `Сделки.Ссылка`, `Сделки.ИтоговаяСумма`.
    
    В конструкторе пакетного запроса открыты «Группировка» → «Поля группировки». [Описание иллюстрации](../../raw/figures/60a995a8efd1f33cb48bd9a8e0f4f5da79b139881e084371ae6f0b5ea0c441a9-dc6832b98dbbafef.md)
  - Задайте условие группировки: `КОЛИЧЕСТВО(ВТ_Активности.Задача) > 0`.
    
    Условия группировки [Описание иллюстрации](../../raw/figures/cb7c3216896993d7dbdc750fbaaba535b846cf698292e60fc532f8ec161d6d65-4968db78648b8165.md)
9. На вкладке **Прочие** настройте дополнительные параметры отображения выборки. Параметры добавляют в текст запроса ключевые слова [`ПЕРВЫЕ`](../project/select-statement-0fef6f15002c.md) и [`РАЗЛИЧНЫЕ`](../project/select-statement-0fef6f15002c.md). Установите **Выбрать первые 10**:
  
  На вкладке «Прочее» конструктора запроса включено «Выбрать первые» со значением 10; отдельно доступно «Без повторяющихся». [Описание иллюстрации](../../raw/figures/4f36bdbbdf054fba4a16bf49eb796da39e40e9415421e7f887fe7936c60fe201-e3a501c028362e73.md)
10. В форме **Объединения/Псевдонимы** установите отображение имен (псевдонимов) для полей результата запроса с помощью ключевого слова [`КАК`](../project/select-statement-0fef6f15002c.md), а также порядок их следования:
  
  Форма «Объединения/Псевдонимы» [Описание иллюстрации](../../raw/figures/c806d8e4310f55eaf7b58d5fb451f34a301b6fe1b5bebc9e5b54dcd26a8dfbf3-555fdf79f8105520.md)
11. В форме **Порядок** установите условия для сортировки. В текст запроса добавится предложения [`УПОРЯДОЧИТЬ ПО`](../project/order-by-c7dce336ab54.md) с указанным условием:
  
  В конструкторе пакетного запроса в навигации выбрана форма «Порядок». [Описание иллюстрации](../../raw/figures/652b40f13baa0ee28a434d51c821e62fbfa7458ba03a760b1ea0a9a1fdba4161-09ef13da3520ea3a.md)
12. Нажмите **ОК** для сохранения запроса и возврата к консоли запросов.

Результатом работы конструктора будет запрос в консоли запросов, который возвращает первые 10 сделок c наибольшей суммой, по которым есть активные задачи. Для каждой такой сделки выводится итоговая сумма и количество связанных задач.

```xbql
ВЫБРАТЬ
    Задачи.Ссылка КАК Задача,
    Задачи.Сделка КАК Сделка
ПОМЕСТИТЬ
    ВТ_Активности
ИЗ
    Задачи КАК Задачи
ГДЕ
    Задачи.Статус != &Завершено

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
    События.Ссылка,
    События.Сделка
ИЗ
    События КАК События
ГДЕ
```
