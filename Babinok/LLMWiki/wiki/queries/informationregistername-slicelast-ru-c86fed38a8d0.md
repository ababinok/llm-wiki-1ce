## Обзор

Виртуальная таблица, которая возвращает последние внесенные в регистр сведений записи для каждой комбинации измерений.

## Документированный контракт и примеры

Виртуальная таблица, которая возвращает последние внесенные в регистр сведений записи для каждой комбинации измерений. Существует только для периодических регистров сведений.

Для регистров, у которых свойство элемента проекта `ХранитьСледующийПериод` = `Ложь`:

- виртуальная таблица имеет более сложную реализацию с использованием подзапроса;
- поле
  
  [СледующийПериод](informationregistername-slicelast-ru-c86fed38a8d0.md)
  
  вычисляется в момент обращения к виртуальной таблице;
- для параметра
  
  Период
  
  можно использовать только константные выражения;
- добавляется параметр
  
  Фильтр
  
  .

**Параметры:**

- Период:
  
  [Дата](../stdlib/date-ru-d160dc00114c.md)
  
  ?
  
  Дата, на которую будут получаться записи для формирования среза.
  
  Срез будет формироваться на основе записей, у которых значение поля
  
  [Период](informationregistername-slicelast-ru-c86fed38a8d0.md)
  
  меньше или равно указанному значению параметра. При наличии нескольких записей с одинаковыми значениями измерений в результате будет использоваться запись с самым большим значением периода.
  
  Если значение параметра
  
  `Неопределено`
  
  , возвращаются последние записи (с максимальным значением поля
  
  [Период](informationregistername-slicelast-ru-c86fed38a8d0.md)
  
  ).
  
  Для регистров, у которых свойство элемента проекта
  
  `ХранитьСледующийПериод`
  
  =
  
  `Ложь`
  
  , для значения параметра можно использовать только константные выражения.
  
  Если установлен флаг
  
  `ХранитьСледующийПериод`
  
  =
  
  `Истина`
  
  , то в качестве значения параметра можно также использовать неконстантные выражения, в том числе поля других таблиц, доступные для использования в условии соединения этой таблицы.

---

## Примеры

В примере ниже показано, как выбрать цены товаров из регистра **Цены**, актуальные на указанный **ПараметрПериод**:

```xbql
ВЫБРАТЬ
    Цены.Товар КАК Товар,
    Цены.Цена КАК Цена,
    Цены.Примечание КАК Примечание
ИЗ
    Цены.СрезПоследних(%ПараметрПериод) КАК Цены
УПОРЯДОЧИТЬ ПО
    Товар,
    Цена
```

### Период

```

```

Период, к которому относится запись регистра. Существует только для периодических регистров сведений.

---

### СледующийПериод

`Вычисляемое поле`

```
СледующийПериод: Дата
```

Значение поля [Период](informationregistername-slicelast-ru-c86fed38a8d0.md) из следующей записи с такими же значениями измерений или максимальное значение типа поля [Период](informationregistername-slicelast-ru-c86fed38a8d0.md), если следующей записи нет. Существует только для периодических регистров сведений с флагом `ХранитьСледующийПериод` = `Истина`.

#### Примеры

В примере ниже показано, как получить актуальный курс валюты из регистра сведений **Курсы** на указанную дату `%ДатаСреза` (используя виртуальную таблицу `СрезПоследних`) и определить период действия этого курса:

```xbsl
пер ДатаСреза: Дата
знч Запрос = Запрос{
        ВЫБРАТЬ
            Период,
            Курс,
            Валюта,
            СледующийПериод
        ИЗ
            Курсы.СрезПоследних(%ДатаСреза)
        }
знч Результат = Запрос.Выполнить().Единственный()
пер СледующийПериод = Результат.СледующийПериод
```

Чтобы проверить наличие следующей записи в таблице периодического регистра сведений, можно сравнить значение поля [СледующийПериод](informationregistername-slicelast-ru-c86fed38a8d0.md) с максимальным значением типа поля [Период](informationregistername-slicelast-ru-c86fed38a8d0.md). Если они равны — значит, следующей записи не существует.

Получить максимальное значение типа поля [Период](informationregistername-slicelast-ru-c86fed38a8d0.md) можно с помощью встроенного строкового литерала соответствующего типа: `Тип{Максимум}`.

### КлючОсновногоФильтра

`Вычисляемое поле`

```
КлючОсновногоФильтра: ИмяРегистраСведений.КлючОсновногоФильтра
```

Структура, описывающая ключ основного фильтра регистра сведений. Добавляется, даже если нет измерений, включаемых в основной фильтр. Имеет тип [ИмяРегистраСведений.КлючОсновногоФильтра](../data/informationregistername-mainfilterkey-ru-b2b91a95f0cf.md).

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяРегистраСведений.КлючЗаписи
```

Содержит значения измерений записи регистра сведений (и стандартного поля [Период](informationregistername-slicelast-ru-c86fed38a8d0.md) для периодических регистров сведений). Используется для указания на конкретную запись. Имеет тип [ИмяРегистраСведений.КлючЗаписи](../data/informationregistername-recordkey-ru-2cfab865dace.md).

#### Примеры

В примере ниже показано, как выбрать данные конкретной записи из виртуальной таблицы **Курсы.СрезПоследних** на указанную дату `%ДатаСреза` по ее ключу (значение поля [КлючЗаписи](informationregistername-slicelast-ru-c86fed38a8d0.md) равно параметру `%КлючКурсаРубля`):

```xbql
ВЫБРАТЬ
    Период,
    Курс,
    Валюта,
    СледующийПериод
ИЗ
    Курсы.СрезПоследних(%ДатаСреза)
ГДЕ
    КлючЗаписи == %КлючКурсаРубля
```
