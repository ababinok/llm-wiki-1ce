## Обзор

Таблица содержит записи, соответствующие элементам хранилища настроек.

## Документированный контракт и примеры

Таблица содержит записи, соответствующие элементам хранилища настроек. Одна запись таблицы — один элемент хранилища настроек. Таблица является ссылочной — к ее полям можно обращаться по их именам через точку от выражений, имеющих тип `{ИмяХранилищаНастроек}.Ссылка`.

---

## Примеры

Пример выбора настроек по заданным реквизитам:

```xbql
ВЫБРАТЬ
    Настройки.Ссылка,
    Настройки.Значение,
    Настройки.Наименование
ИЗ
    МоеХранилищеНастроек КАК Настройки 
ГДЕ
    Настройки.КлючОбъекта == %ИдентификаторСписка
    И Настройки.Пользователь == %ТекущийПользователь
    И Настройки.Общая == Истина
УПОРЯДОЧИТЬ ПО
    Настройки.Представление
```

## Поля

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита хранилища настроек.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяХранилищаНастроек.Ссылка
```

Ссылка на объект хранилища настроек.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра. Используется в механизме оптимистических блокировок.

---

### КлючОбъекта

```
КлючОбъекта: Строка
```

Идентифицирует настраиваемый объект.

---

### КлючНастройки

```
КлючНастройки: Строка
```

Однозначно идентифицирует данную настройку в разрезе ключа объекта и пользователя.

---

### Пользователь

```
Пользователь: Пользователи.Ссылка?
```

Пользователь, для которого сохраняется данная настройка.

---

### Вариант

```
Вариант: Булево
```

Позволяет различить, является ли запись вариантом настройки или уникальной записью.

---

### Значение

```
Значение: Строка
```

Сохраняемые данные настраиваемого объекта.

---

### Наименование

```
Наименование: Строка
```

Отображаемое наименование сохраненной настройки. По умолчанию используется в качестве представления записи хранилища.

---

### Общая

```
Общая: Булево
```

Флаг, который указывает, может ли запись быть доступна другим пользователям.

---

### Представление

`Вычисляемое поле`

```
Представление: Строка
```

Строковое представление записи хранилища.
