## Обзор

Таблица с информацией об иерархических связях в справочнике **ИмяСправочникаСГруппами.Группы**.

## Документированный контракт и примеры

`Версия 10.0 и выше`

Таблица с информацией об иерархических связях в справочнике **ИмяСправочникаСГруппами.Группы**.

> [!NOTE] примечание
> Справочник **ИмяСправочникаСГруппами.Группы** порождается автоматически для иерархического справочника, у которого свойство **Вид** иерархии имеет значение **ИерархияГруппИЭлементов**.

Таблица содержит информацию о связях **«родитель**-**ребенок»**. Для элемента в таблице указаны все его родители. Непосредственный родитель отмечен специальным флагом. Также для каждого элемента в таблице содержится запись **на себя** как родителя: **«текущий элемент**-**текущий элемент»**. Элементы, которые не имеют родителя, отражаются в таблице таким образом.

---

## Поля

### Родитель

`Ключевое поле`

```
Родитель: ИмяСправочникаСГруппами.Группы.Ссылка
```

Родитель узла.

---

### Ребенок

`Ключевое поле`

```
Ребенок: ИмяСправочникаСГруппами.Группы.Ссылка
```

Узел, для которого указана информация в строке.

---

### Непосредственный

```
Непосредственный: Булево
```

Флаг, который указывает, является ли родитель прямым для ссылки. Прямой родитель — ближайший предок узла, указанный в поле **Родитель**.

---

### Уровень

```
Уровень: Число
```

Количество родителей без учета собственной ссылки.

---

### КоличествоДетей

```
КоличествоДетей: Число
```

Количество непосредственных детей элемента, указанного в поле **Ребенок**.
