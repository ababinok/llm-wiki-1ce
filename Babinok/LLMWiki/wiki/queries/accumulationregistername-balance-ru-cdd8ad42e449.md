## Документированный контракт и примеры

Данные таблицы представляют собой итоги ресурсов в разрезе измерений.

Виртуальная таблица остатков не хранится в базе данных, а строится в момент обращения к ней. Для построения виртуальной таблицы могут использоваться данные таблиц итогов (если значения свойств регистра `ХранитьТекущиеИтоги` и `ХранитьПериодическиеИтоги` равны `Истина`) и таблицы движений регистра (из базы данных). При этом учитывается значение параметра виртуальной таблицы. Итоги ресурсов собираются только по активным записям.

Таблица существует только для регистра накопления вида **Остатки**.

**Параметры:**

- Период: [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md)? Дата, на которую рассчитываются остатки. Значение параметра не включается в условие, т. е. учитываются только записи, сделанные до указанной даты. Если параметр не задан, показываются самые актуальные остатки.
- Фильтр Выражение языка запросов типа `Булево`. В выражении доступны поля измерений регистра накопления, а также применимые к этим полям выражения (например, операция обращения через точку или вызов функций, кроме агрегатных). Данный параметр позволяет ограничить состав исходных записей, по которым будут собираться итоги при построении виртуальной таблицы. Если параметр не указан, для сбора итогов будут анализироваться все активные записи регистра, что в большинстве случаев менее эффективно.

## Примеры

Пример запроса к таблице остатков регистра накопления **ОстаткиНоменклатуры**:

```xbql
ВЫБРАТЬ
    ОстаткиНоменклатурыОстатки.Номенклатура КАК Номенклатура,
    ОстаткиНоменклатурыОстатки.Склад КАК Склад,
    ОстаткиНоменклатурыОстатки.КоличествоОстаток КАК КоличествоОстаток,
    ОстаткиНоменклатурыОстатки.СуммаОстаток КАК СуммаОстаток
ИЗ
    ОстаткиНоменклатуры.Остатки(%Дата, Склад == %СсылкаНаСклад) КАК ОстаткиНоменклатурыОстатки
УПОРЯДОЧИТЬ ПО
    ОстаткиНоменклатурыОстатки.Номенклатура
```

## Поля

### {ИмяИзмерения}

```
{ИмяИзмерения}: ТипИзмерения
```

Значение измерения регистра накопления.

---

### {ИмяРесурсаОстаток}

```
{ИмяРесурса}Остаток: Число
```

Остатки ресурса.

---

### {ИмяРесурсаОстатокПоложительный}

```
{ИмяРесурса}ОстатокПоложительный: Число
```

Положительные остатки ресурса. Имеет значение 0, если остаток ресурса отрицательный.

---

### {ИмяРесурсаОстатокОтрицательный}

```
{ИмяРесурса}ОстатокОтрицательный: Число
```

Отрицательные остатки ресурса (абсолютное значение). Имеет значение 0, если остаток ресурса положительный.
