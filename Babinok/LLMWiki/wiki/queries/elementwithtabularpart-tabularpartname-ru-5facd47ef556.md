## Документированный контракт и примеры

Таблица, порождаемая для табличной части.

## Поля

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Табличная часть содержит заданные разработчиком реквизиты. В таблице языка запросов значения этих реквизитов хранятся в одноименных колонках.

#### Примеры

В документе **ПриходнаяНакладная** есть табличная часть **Товары**. Запрос для получения значений реквизита **Товар** из табличной части может выглядеть следующим образом:

```xbql
ВЫБРАТЬ
    НомерСтроки,
    Товар
ИЗ
    ПриходнаяНакладная.Товары
ГДЕ
    Владелец == %МояНакладная
УПОРЯДОЧИТЬ ПО
    НомерСтроки
```

---

### Владелец

`Ключевое поле`

```
Владелец: ИмяЭлементаСТабличнойЧастью.Ссылка
```

Ссылка на запись, владеющую строками табличной части.

#### Примеры

В документе **ПриходнаяНакладная** есть табличная часть **Товары**. Запрос для получения записей табличной части может выглядеть следующим образом:

```xbql
ВЫБРАТЬ
    НомерСтроки,
    Товар,
    Цена,
    Количество
ИЗ
    ПриходнаяНакладная.Товары
ГДЕ
    Владелец == %МояНакладная
УПОРЯДОЧИТЬ ПО
    НомерСтроки
```

---

### Индекс

`Ключевое поле`

```
Индекс: Число
```

Индекс строки табличной части в рамках одного владельца.

---

### НомерСтроки

`Вычисляемое поле`

```
НомерСтроки: Число
```

Номер строки (индекс + 1) табличной части в рамках одного владельца.

Поле добавлено для удобства использования табличных частей. Например, при просмотре содержимого табличной части в отладчике удобно сверять номера строк с соответствующими номерами в печатной версии документа.
