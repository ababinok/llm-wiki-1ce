## Обзор

Таблица регистрации изменений создается, только если стандартное хранилище настроек включено в план обмена.

## Документированный контракт и примеры

Таблица регистрации изменений создается, только если стандартное хранилище настроек включено в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению элемента хранилища настроек, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице хранилища настроек. Одна запись таблицы — изменения в одном элементе хранилища настроек, зарегистрированные для одного узла.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **Ссылка** из таблицы регистрации изменений хранилища настроек **СтандартноеХранилищеНастроек.Изменения**:

```xbql
ВЫБРАТЬ
    СтандартноеХранилищеНастроек.Узел КАК Узел,
    СтандартноеХранилищеНастроек.Ссылка КАК Ссылка
ИЗ
    СтандартноеХранилищеНастроек.Изменения КАК СтандартноеХранилищеНастроек
```

## Поля

### Ссылка

`Ключевое поле`

```
Ссылка: СтандартноеХранилищеНастроек.Ссылка
```

Ссылка на элемент хранилища настроек, в котором были зарегистрированы изменения.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Если изменение не включено в сообщение, то значение `Неопределено`.
