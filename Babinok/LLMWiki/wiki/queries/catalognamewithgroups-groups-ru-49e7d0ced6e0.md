## Обзор

Таблица с информацией о группах в иерархическом справочнике с группами **ИмяСправочникаСГруппами**.

## Документированный контракт и примеры

`Версия 10.0 и выше`

Таблица с информацией о группах в иерархическом справочнике с группами **ИмяСправочникаСГруппами**.

> [!NOTE] примечание
> Справочник **ИмяСправочникаСГруппами.Группы** порождается автоматически для иерархического справочника, у которого свойство **Вид** иерархии имеет значение **ИерархияГруппИЭлементов**.

---

## Поля

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяСправочникаСГруппами.Группы.Ссылка
```

Ссылка на элемент справочника **ИмяСправочника.Группы**.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### МоментПометкиУдаления

```
МоментПометкиУдаления: Момент?
```

Момент пометки записи на удаление. Поле присутствует только у справочников с режимом удаления `ПометкаУдаления`.

Поле имеет значение типа `Момент` для помеченных на удаление записей и значение `Неопределено`, если запись не помечена на удаление.

---

### ПометкаУдаления

`Вычисляемое поле`

```
ПометкаУдаления: Булево
```

Признак того, что запись помечена на удаление. Поле присутствует только у справочников с режимом удаления `ПометкаУдаления`.

---

### Родитель

```
Родитель: ИмяСправочникаСГруппами.Группы.Ссылка?
```

Элемент, установленный в качестве родительского для текущего. Появляется только у иерархических справочников (справочник с установленным значением `Истина` для свойства `Иерархический`).

- Для справочников с видом иерархии
  
  `ИерархияГруппИЭлементов`
  
  имеет составной тип
  
  `ИмяСправочника.Группы.Ссылка|Неопределено`
- Для справочников с видом иерархии
  
  `ИерархияЭлементов`
  
  имеет составной тип
  
  `ИмяСправочника.Ссылка|Неопределено`

## Индексы

### НаименованиеАвтоИндекс

Индекс по полю **Наименование**. Присутствует только у справочников, у которых есть реквизит **Наименование**. Включает поле **Ссылка**.

---

### ПоляАвтонумерации

Индекс, используемый системным автонумератором. Может состоять из полей:

- Владелец
  
  (если нумерация идет в разрезе владельца),
- Префикс
  
  (если нумерация идет в разрезе префикса),
- Постфикс
  
  (если нумерация идет в разрезе постфикса).

---

### Код

Индекс по полю **Код**. Присутствует только у справочников, у которых есть реквизит **Код**. Включает поле **Ссылка**.

---

### Родитель

Индекс по полю **Родитель**. Присутствует только у справочников, у которых есть реквизит **Родитель**.
