## Обзор

Таблица регистрации изменений создается, только если документ включен в план обмена.

## Документированный контракт и примеры

Таблица регистрации изменений создается, только если документ включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению элемента документа, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице документа.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **Ссылка** из таблицы регистрации изменений документа **Накладные.Изменения**:

```xbql
ВЫБРАТЬ
    Накладные.Узел КАК Узел,
    Накладные.Ссылка КАК Ссылка
ИЗ
    Накладные.Изменения КАК Накладные
```

Эта таблица содержит записи, соответствующие изменениям в элементах документа, зарегистрированным для соответствующих узлов плана обмена. Одна запись таблицы — изменения в одном элементе документа, зарегистрированные для одного узла.

---

## Поля

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяДокумента.Ссылка
```

Ссылка на элемент документа, в котором были зарегистрированы изменения. Например, для документа **Накладные** это поле будет иметь тип `Накладные.Ссылка`.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена, для которого зарегистрированы изменения.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Если изменение не включено в сообщение, то значение `Неопределено`.
