Роль: Справочник XBQL.

Владелец: Std.

Имена для поиска: `{ИмяИнтегрируемогоПриложения}`, `IntegrableApplicationName`, `Std::IntegrableApplicationName`.

## Обзор

Таблица содержит записи, соответствующие экземплярам интегрируемого приложения.

## Документированный контракт и примеры

`Версия 10.0 и выше`

Таблица содержит записи, соответствующие экземплярам интегрируемого приложения. Одна запись таблицы — один экземпляр интегрируемого приложения.

Таблица является ссылочной — к ее полям можно обращаться по их именам через точку от выражений, имеющих тип `ИмяИнтегрируемогоПриложения.Ссылка`.

---

## Поля

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита интегрируемого приложения.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяИнтегрируемогоПриложения.Ссылка
```

Ссылка на экземпляр интегрируемого приложения. Например, для интегрируемого приложения **ИнформационныеСистемы** это поле будет иметь тип `ИнформационныеСистемы.Ссылка`.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### МоментПометкиУдаления

```
МоментПометкиУдаления: Момент?
```

Момент пометки записи на удаление. Поле присутствует только у интегрируемых приложений с режимом удаления `ПометкаУдаления`.

Поле имеет значение типа `Момент` для помеченных на удаление записей и значение `Неопределено`, если запись не помечена на удаление.

---

### ПометкаУдаления

`Вычисляемое поле`

```
ПометкаУдаления: Булево
```

Признак того, что запись помечена на удаление. Поле присутствует только у интегрируемых приложений с режимом удаления `ПометкаУдаления`.

---

### НастройкиПрямогоПодключения

```
НастройкиПрямогоПодключения: НастройкиПрямогоПодключенияИнтегрируемогоПриложения
```

Настройки прямого подключения интегрируемого приложения.

---

### Код

```
Код: Строка
```

Код интегрируемого приложения.

---

### Представление

`Вычисляемое поле`

```
Представление: Строка
```

Строковое представление экземпляра интегрируемого приложения.

---

## Индексы

### Код

Индекс по полю **Код**. Присутствует только у интегрируемого приложения, у которых есть реквизит **Код**.
