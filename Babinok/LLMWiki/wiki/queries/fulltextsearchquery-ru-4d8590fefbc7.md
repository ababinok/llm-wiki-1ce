## Свойства

### Запрос

`Доступность: Сервер`

```
Запрос: Строка
```

Строка с поисковым запросом, которая обычно приходит непосредственно из пользовательского интерфейса.

---

### ИндексСтраницы

`Доступность: Сервер`

```
ИндексСтраницы: Число
```

Сколько страниц среди найденных записей надо пропустить.

---

### ИскатьТолькоПоЗаголовкам

`Доступность: Сервер`

```
ИскатьТолькоПоЗаголовкам: Булево
```

`Истина`, если надо осуществить поиск не по основному содержимому, а только по заголовкам. Во многих случаях этого бывает достаточно для качественного поиска, при этом, сам поиск может быть существенно быстрее. По умолчанию в качестве заголовка используется представление записи.

---

### ОбластьИсключенийИзПоиска

`Доступность: Сервер`

```
ОбластьИсключенийИзПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>
```

Массив ссылочных типов, которые нужно исключить из области поиска. **Значение по умолчанию:** пустой массив. Вы можете заполнить либо массив [ОбластьИсключенийИзПоиска](fulltextsearchquery-ru-4d8590fefbc7.md), либо массив [ОбластьПоиска](fulltextsearchquery-ru-4d8590fefbc7.md), но не оба массива сразу.

---

### ОбластьПоиска

`Доступность: Сервер`

```
ОбластьПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>
```

Массив ссылочных типов, по которым нужен поиск; если передать пустой массив, будет поиск по всем типам. **Значение по умолчанию:** пустой массив.

---

### РазмерСтраницы

`Доступность: Сервер`

```
РазмерСтраницы: Число
```

Сколько записей приходится на одну страницу.

---

### Фильтр

`Доступность: Сервер`

```
Фильтр: Строка
```

Дополнение к поисковому запросу, которое скрыто добавляется через оператор `AND`, но в результатах поиска ключевые слова из этого фильтра не подсвечиваются и фильтр не влияет на то, как формируются выдержки текста; также важно знать, что фильтр работает быстрее обычного поискового запроса.
