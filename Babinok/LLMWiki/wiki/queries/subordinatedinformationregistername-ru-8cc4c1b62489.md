## Примеры

В примере ниже показано, как выбрать настройки пользователя из непериодического регистра сведений **НастройкиПользователя** для указанного пользователя (значение поля **Пользователь** равно параметру `%Пользователь`):

```xbql
ВЫБРАТЬ
    НастройкиПользователя.Пользователь Как Пользователь
    НастройкиПользователя.ТемаОформления КАК ТемаОформления,
    НастройкиПользователя.РазрешенияУведомлений КАК РазрешенияУведомлений,
    НастройкиПользователя.ПоказыватьОнлайн КАК ПоказыватьОнлайн,
    НастройкиПользователя.ДатаРегистрации КАК ДатаРегистрации,
    НастройкиПользователя.КлючЗаписи КАК КлючЗаписи
ИЗ
    НастройкиПользователя КАК НастройкиПользователя
ГДЕ
    Пользователь == %Пользователь
УПОРЯДОЧИТЬ ПО
    ДатаРегистрации
```

## Поля

### {ИмяИзмерения}

`Ключевое поле`

```
{ИмяИзмерения}: ТипИзмерения
```

Значение измерения записи регистра сведений.

---

### {ИмяРесурса}

```
{ИмяРесурса}: ТипРесурса
```

Значение ресурса записи регистра сведений.

---

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита записи регистра сведений.

---

### Период

`Ключевое поле`

```
Период: Дата
```

Период, к которому относится запись регистра. Существует только для периодических регистров сведений.

---

### Регистратор

```
Регистратор: ИмяДокумента.Ссылка?
```

Ссылка на документ, которому подчинена запись регистра сведений.

---

### Активность

```
Активность: Булево
```

Признак, определяющий влияние записи на результаты виртуальной таблицы `СрезПоследних` и расчет значения поля **СледующийПериод**. Если значение `Ложь`, то запись не учитывается при получении сведений из виртуальной таблицы и при расчете поля **СледующийПериод**.

---

### Индекс

`Вычисляемое поле`

```
Индекс: Число
```

Индекс (начиная с 0) записи регистра сведений в наборе записей, подчиненных документу, указанному в поле **Регистратор**.

---

### НомерСтроки

`Вычисляемое поле`

```
НомерСтроки: Число
```

Порядковый номер (начиная с 1) записи регистра сведений в наборе записей, подчиненных документу, указанному в поле **Регистратор**.

---

### СледующийПериод

`Вычисляемое поле`

```
СледующийПериод: Дата
```

Значение поля **Период** из следующей активной записи с такими же значениями измерений или максимальное значение типа поля **Период**, если следующей записи нет. Для неактивных записей подчиненного регистра всегда имеет максимальное значение типа поля **Период**. Существует только для периодических регистров сведений с флагом `ХранитьСледующийПериод` = `Истина`.

#### Примеры

В примере ниже показано, как получить цены товаров из регистра сведений **Цены** (флаг `ХранитьСледующийПериод` = `Истина`) вместе с периодом их действия (временным промежутком, в рамках которого они были действительны):

```xbsl
знч Запрос = Запрос{
        ВЫБРАТЬ 
            Период КАК ПериодС,
            ВЫБОР 
                КОГДА СледующийПериод == Дата{Максимум} ТОГДА "По настоящее время"
                ИНАЧЕ СледующийПериод
            КОНЕЦ КАК ПериодПо, // Исключая границу
            Товар,           
            Цена
        ИЗ
            Цены
        УПОРЯДОЧИТЬ ПО
            Товар, 
            Период
        }
```

Чтобы проверить наличие следующей записи в таблице периодического регистра сведений, можно сравнить значение поля **СледующийПериод** с максимальным значением типа поля **Период**. Если они равны — значит, следующей записи не существует.

Получить максимальное значение типа поля **Период** можно с помощью встроенного строкового литерала соответствующего типа: `Тип{Максимум}` (как в запросе выше).

### КлючОсновногоФильтра

`Вычисляемое поле`

```
КлючОсновногоФильтра: ИмяПодчиненногоРегистраСведений.КлючОсновногоФильтра
```

Структура, описывающая ключ основного фильтра регистра сведений. Добавляется, даже если нет измерений, включаемых в основной фильтр. Имеет тип [ИмяПодчиненногоРегистраСведений.КлючОсновногоФильтра](../data/subordinatedinformationregistername-mainfilterkey-ru-ccf5f7bfc0f4.md).

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяПодчиненногоРегистраСведений.КлючЗаписи
```

Содержит значения измерений записи регистра сведений (и стандартного поля **Период** для периодических регистров сведений). Используется для указания на конкретную запись. Имеет тип [ИмяПодчиненногоРегистраСведений.КлючЗаписи](../data/subordinatedinformationregistername-recordkey-ru-b4fbe9981ddf.md).

#### Примеры

В примере ниже показано, как выбрать данные конкретной записи из регистра сведений **Цены** по её ключу (значение поля **КлючЗаписи** равно параметру `%КлючНужнойЦены`):

```xbql
ВЫБРАТЬ
    Период,
    Товар,
    Цена,
    Регистратор
ИЗ
    Цены
ГДЕ
    КлючЗаписи == %КлючНужнойЦены
```
