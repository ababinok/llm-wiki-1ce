## Обзор

В объекте описываются имена и типы колонок источника данных языка запросов.

## Документированный контракт и примеры

`Стд::БазаДанных::ОписаниеИсточникаДанныхЗапроса<ТипДанныхБазыДанных>` `Доступность: Сервер`

## Конструкторы

### ОписаниеИсточникаДанныхЗапроса

`Доступность: Сервер`

```
ОписаниеИсточникаДанныхЗапроса(
  ИсточникДанных: ЧитаемаяКоллекция<ТипДанныхБазыДанных>,
  Колонки: ЧитаемоеСоответствие<Строка, ТипДанныхБазыДанных>)
```

Создает описание источника данных по коллекции источнику данных

`ИсточникДанных`

и описаниям колонок

`Колонки`

. При исполнении запроса значения колонок из элементов коллекции (источника данных) получаются как одноименные свойства. Если свойства с таким именем нет, но у объекта есть операция получения по ключу, например это

[ЧитаемоеСоответствие](../stdlib/readablemap-ru-8fb134a1c222.md)

- делается попытка получить значение с использованием строки с именем колонки в качестве ключа.

Не допускается передача пустой коллекции Колонки.
