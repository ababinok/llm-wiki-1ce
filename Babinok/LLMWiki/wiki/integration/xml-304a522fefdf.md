# Типы

## [PropertyList](propertylist-ru-2c1ba8924c01.md)

`Стд::Xml::PropertyList` `Доступность: Сервер`

Объект для работы с данными в формате Property List. Содержит иерархический список пар ключ-значение. Ключ всегда является значением типа [Строка](../stdlib/string-ru-1bac645acacf.md). Значения могут следующих типов: [Строка](../stdlib/string-ru-1bac645acacf.md), [Число](../stdlib/number-ru-dd4b54993c86.md), [Момент](../stdlib/instant-ru-09dd46b34eb4.md), [Булево](../stdlib/boolean-ru-7823d4239bcc.md), [Байты](../stdlib/bytes-ru-19f4d37ce009.md), [ЧитаемыйМассив](../stdlib/readablearray-ru-6bae9724f632.md), [ЧитаемоеСоответствие](../stdlib/readablemap-ru-8fb134a1c222.md). Иерархия достигается за счет значений типов [ЧитаемыйМассив](../stdlib/readablearray-ru-6bae9724f632.md), [ЧитаемоеСоответствие](../stdlib/readablemap-ru-8fb134a1c222.md). Адресация свойств в объекте осуществляется с помощью строкового пути, состоящего из имен ключей свойств, разделенных символом '/'.

## [ЗаписьXml](xmlwriter-ru-17497aa25674.md)

`Стд::Xml::ЗаписьXml` `Доступность: Сервер`

Объект для потоковой записи XML. Непосредственно осуществляет запись в поток в процессе формирования XML, не храня записанные данные в памяти. Запись типов данных осуществляется в соответствии со [стандартом XML](https://www.w3.org/TR/xmlschema-2/) для каноничной записи, если не указано иное.

## [ЧтениеXml](xmlreader-ru-f56ded3af2f9.md)

`Стд::Xml::ЧтениеXml` `Доступность: Сервер`

Объект для последовательного чтения XML-данных. Чтение XML-данных выполняется потоково, в конкретный момент времени объект позиционируется на конкретном узле XML. При ошибке разбора XML-данных вызывается исключение [ИсключениеЧтенияXml](xmlreaderexception-ru-0d8061eee533.md). Типы данных разбираются в соответствии со [стандартом XML](https://www.w3.org/TR/xmlschema-2/).
