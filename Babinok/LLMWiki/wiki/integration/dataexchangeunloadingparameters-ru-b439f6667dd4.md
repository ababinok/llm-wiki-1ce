## Свойства

### ВыгрузкаДанных

`Доступность: Сервер`

```
ВыгрузкаДанных: ДействиеПриВыгрузкеОбменаДанными
```

Варианты обработки данных выполняемой при выгрузке данных. При вызове обработчика данный параметр содержит значение Авто, что означает, что данные будут выгружены в сообщение. В обработчике можно присвоить параметру другое значение. Значение Удалить означает, что в сообщение будет помещено значение, предназначенное для удаления соответствующего элемента данных в той информационной базе, которой адресовано сообщение. В случае объекта базы данных в сообщение будет помещен объект типа УдалениеОбъекта, содержащий ссылку на объект базы данных. В случае набора записей будет помещен пустой набор записей.. Значение Игнорировать означает, что в сообщение не будет помещено ничего, связанного с элементом данных.
