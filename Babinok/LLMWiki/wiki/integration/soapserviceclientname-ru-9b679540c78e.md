## Обзор

Клиент Soap-сервиса.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяКлиентаSoapСервиса}` `Доступность: Сервер`

Клиент Soap-сервиса. Позволяет выполнять запросы к SOAP-сервису. Есть возможность настройки исходящих SOAP- и HTTP-заголовков, а также чтения входящих SOAP-заголовков.

## Конструкторы

### {ИмяКлиентаSoapСервиса}

`Доступность: Сервер`

```
{ИмяКлиентаSoapСервиса}(КлиентHttp: КлиентHttp|Undefined = Неопределено)
```

Создает экземпляр типа с подготовленным HTTP клиентом

`КлиентHttp`

. Если передано значение

`Неопределено`

, то используется HTTP клиент с параметрами по умолчанию. Область видимости совпадает с областью видимости элемента.

## События

### ПередЗапросомServiceMethodFunctionName

`Доступность: Сервер`

```
ПередЗапросомServiceMethodFunctionName: ((ЗапросHttp)->ничто)?
```

Значение свойства - метод, который позволяет настроить свойства HTTP запроса, выполняемого к сервису при вызове метода [ServiceMethodFunctionName](soapserviceclientname-ru-9b679540c78e.md). Например, позволяет задать заголовки для неподдерживаемых способов аутентификации. В параметре обработчику передается полностью подготовленный платформой запрос. Прикладной разработчик может настроить свойства запроса, например, определить его заголовки, но не может его выполнить. При попытке вызвать метод `Выполнить` выбрасывается исключение. Если установлено значение `Неопределено`, то выполняется запрос, подготовленный платформой.

## Методы

### ServiceMethodFunctionName

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ServiceMethodFunctionName(ПараметрЗаголовков: Объект|Undefined): ОтветФункцииSoap<ИмяКлиентаSoapСервиса.ИмяСтруктурыСервиса>
```

Выполняет запрос к методу-функции сервиса с именем

`<ServiceMethodFunctionName>`

согласно WSDL. Может содержать дополнительные параметры согласно WSDL, из значений которых формируется тело исходящего SOAP-сообщения.

`ПараметрЗаголовков`

передается в

[НастроитьЗаголовкиSoapServiceMethodFunctionName](soapserviceclientname-ru-9b679540c78e.md)

- обработчик для настройки секции

`Header`

исходящего SOAP-сообщения, в нем должны передаваться значения настраиваемых обработчиком заголовков. Возвращаемое методом значение позволяет получить прочитанные в обработчике

[ОбработатьЗаголовкиSoapServiceMethodFunctionName](soapserviceclientname-ru-9b679540c78e.md)

SOAP-заголовки, а также результат из тела SOAP-сообщения от сервиса.

[ИмяКлиентаSoapСервиса.ServiceStructureName](soapserviceclientname-servicestructurename-ru-c45aa6248a9d.md)

- тип структуры, сгенерированной согласно WSDL для хранения результата, возвращаемого методом-функцией SOAP-сервиса. Область видимости совпадает с областью видимости элемента.

#### Примеры

Soap-сервис магазина содержит операцию `ПолучитьТовар` для получения из каталога товара (строка-наименование и число-количество) по строковому идентификатору. Упрощенный фрагмент WSDL-описания сервиса:

```text
<definitions>
	<types>
		<schema>
			<element name="ПолучитьТовар" type="tns:ПолучитьТовар"/>
			<element name="ПолучитьТоварResponse" type="tns:ПолучитьТоварResponse"/>
			<element name="Товар" type="tns:Товар"/>
			<complexType final="extension restriction" name="Товар">
				<sequence>
					<element name="Количество" type="int"/>
					<element minOccurs="0" name="Наименование" type="string"/>
				</sequence>
			</complexType>
			<complexType name="ПолучитьТовар">
				<sequence>
					<element minOccurs="0" name="arg0" type="string"/>
				</sequence>
			</complexType>
			<complexType name="ПолучитьТоварResponse">
				<sequence>
					<element minOccurs="0" name="return" type="tns:Товар"/>
				</sequence>
			</complexType>
		</schema>
	</types>
	<message name="ПолучитьТовар">
		<part element="tns:ПолучитьТовар" name="parameters"/>
	</message>
	<message name="ПолучитьТоварResponse">
		<part element="tns:ПолучитьТоварResponse" name="parameters"/>
	</message>
	<portType name="СервисМагазина">
		<operation name="ПолучитьТовар">
			<input message="tns:ПолучитьТовар" wsam:Action="ПолучитьТовар"/>
			<output message="tns:ПолучитьТоварResponse"/>
		</operation>
	</portType>
</definitions>
```

У клиента `КлиентСервисаМагазина` генерируется метод `ПолучитьТовар` для вызова одноименной операции сервиса.

Полученный от сервиса результат строго типизирован, поэтому не требуется выполнять приведение типа.

```xbsl
метод ПолучитьТовар(ТоварИд: Строка): КлючИЗначение<Строка, Число>
    знч КлиентСервиса = новый КлиентСервисаМагазина()
    знч ОтветСервиса = КлиентСервиса.ПолучитьТовар(ТоварИд)
    знч НаименованиеТовара = ОтветСервиса.Результат.Наименование
    знч КоличествоТовара = ОтветСервиса.Результат.Количество

    возврат новый КлючИЗначение<Строка, Число>(НаименованиеТовара, КоличествоТовара)
;
```

## Обработчики

### НастроитьЗаголовкиSoapServiceMethodFunctionName

`Доступность: Сервер`

```
НастроитьЗаголовкиSoapServiceMethodFunctionName(
  ЗаписьSoap: ЗаписьSoap_1_1,
  ПараметрЗаголовков: Объект)
```

Опциональный обработчик для настройки xml-элемента

`Header`

исходящего SOAP-сообщения для клиента сервиса версии SOAP 1.1 (при работе с сервисом версии SOAP 1.2 тип параметра

`ЗаписьSoap`

-

[ЗаписьSoap_1_2](soapwriter-1-2-ru-30259547d0dd.md)

). Может содержать дополнительные параметры согласно WSDL, в таком случае получает значения, переданные при вызове метода-процедуры

[ServiceMethodFunctionName](soapserviceclientname-ru-9b679540c78e.md)

. Разработчик в теле метода может вызывать метод

[СоздатьЗаголовок](soapwriter-1-1-ru-58916d6c8a6f.md)

параметра

`ЗаписьSoap`

для создания заголовка. Область видимости локально.

#### Примеры

Soap-заголовки могут использоваться для передачи дополнительной информации, непосредственно не связанной с задачей, решаемой операцией сервиса. В частности, это может быть информация, используемая для проверки прав доступа к сервису. Для этого часто используется стандарт [Web Service Security](https://www.oasis-open.org/committees/tc_home.php?wg_abbrev=wss), который определяет набор стандартных Soap-заголовков для аутентификации и шифрования. В примере Soap-сервис магазина содержит операцию `ДобавитьВКаталог` для добавления товара (строка-наименование и число-количество) в каталог. Для этой операции в сервисе реализована проверка доступа через WSS-токен [UsernameToken](https://www.oasis-open.org/committees/download.php/16782/wss-v1.1-spec-os-UsernameTokenProfile.pdf). Тогда для вызова операции клиенту требуется передать сервису Soap-заголовок с именем пользователя и паролем. Упрощенный фрагмент WSDL-описания сервиса:

```text
<definitions>
	<types>
		<schema>
			<element name="ДобавитьВКаталог" type="tns:ДобавитьВКаталог"/>
			<element name="ДобавитьВКаталогResponse" type="tns:ДобавитьВКаталогResponse"/>
			<element name="Товар" type="tns:Товар"/>
			<complexType name="ДобавитьВКаталог">
				<sequence>
					<element minOccurs="0" name="arg0" type="tns:Товар"/>
				</sequence>
			</complexType>
			<complexType final="extension restriction" name="Товар">
				<sequence>
					<element name="Количество" type="int"/>
					<element minOccurs="0" name="Наименование" type="string"/>
				</sequence>
			</complexType>
			<complexType name="ДобавитьВКаталогResponse">
				<sequence>
					<element minOccurs="0" name="return" type="string"/>
				</sequence>
			</complexType>
		</schema>
	</types>
	<message name="ДобавитьВКаталог">
		<part element="tns:ДобавитьВКаталог" name="parameters"/>
	</message>
	<message name="ДобавитьВКаталогResponse">
		<part element="tns:ДобавитьВКаталогResponse" name="parameters"/>
	</message>
	<portType name="СервисМагазина">
		<operation name="ДобавитьВКаталог">
			<input message="tns:ДобавитьВКаталог" wsam:Action="ДобавитьВКаталог"/>
			<output message="tns:ДобавитьВКаталогResponse"/>
		</operation>
	</portType>
</definitions>
```

У клиента `КлиентСервисаМагазина` генерируется метод `ДобавитьВКаталог`. Для настройки Soap-заголовка с именем пользователя и паролем в модуле клиента Soap-сервиса надо добавить обработчик. Обработчик будет вызван при выполнении метода `ДобавитьВКаталог`, он добавит в запрос SOAP-заголовок с именем пользователя и паролем.

```xbsl
const ПРОСТРАНСТВО_WSS = "http://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-secext-1.0.xsd"

@ВПроекте
структура ЗаголовокТокенПользователя
    знч Пользователь: Строка
    знч Пароль: Строка
;

@Обработчик
метод НастроитьЗаголовкиSoapДобавитьВКаталог(Парам: КлиентСервисаМагазина.Товар?, ЗаписьSoap: ЗаписьSoap_1_1,
    ПараметрЗаголовков: Объект?)
    знч ЗаголовокWss = ЗаписьSoap.СоздатьЗаголовок("Security", ПРОСТРАНСТВО_WSS)

    если ПараметрЗаголовков это ЗаголовокТокенПользователя
        ЗаголовокWss.ЗаписатьНачалоЭлемента("UsernameToken", ПРОСТРАНСТВО_WSS)

        знч ТокенПользователя = ПараметрЗаголовков как ЗаголовокТокенПользователя
        ЗаголовокWss.ЗаписатьНачалоЭлемента("Username", ПРОСТРАНСТВО_WSS)
        ЗаголовокWss.ЗаписатьТекст(ТокенПользователя.Пользователь)
        ЗаголовокWss.ЗаписатьКонецЭлемента()

        ЗаголовокWss.ЗаписатьНачалоЭлемента("Password", ПРОСТРАНСТВО_WSS)
        ЗаголовокWss.ЗаписатьТекст(ТокенПользователя.Пароль)
        ЗаголовокWss.ЗаписатьКонецЭлемента()

        ЗаголовокWss.ЗаписатьКонецЭлемента()
    ;

    ЗаголовокWss.ЗаписатьКонецЭлемента()
;
```

При вызове метода `ДобавитьВКаталог` надо указать данные, которые требуется записать в SOAP-заголовок. Объект `ДанныеТокена` передается в обработчик `НастроитьЗаголовкиSoapДобавитьВКаталог` через параметр `ПараметрЗаголовков`.

```xbsl
знч КлиентСервиса = новый КлиентСервисаМагазина()
знч НовыйТовар = новый КлиентСервисаМагазина.Товар(Количество = 15, Наименование = "Пышка")
знч ДанныеТокена = новый КлиентСервисаМагазина.ЗаголовокТокенПользователя("User", "Password")
КлиентСервиса.ДобавитьВКаталог(НовыйТовар, ДанныеТокена)
```

### ОбработатьЗаголовкиSoapServiceMethodFunctionName

`Доступность: Сервер`

```
ОбработатьЗаголовкиSoapServiceMethodFunctionName(Заголовок: ЧтениеXml|Undefined): Объект?
```

Опциональный обработчик для чтения входящих SOAP-заголовков ответа метода-функции сервиса с именем

`<ServiceMethodFunctionName>`

. Вызывается платформой при получении ответа от SOAP-сервиса. Служит для чтения Soap-заголовков в виде xml. Xml-элемент

`Заголовок`

ответа передается в метод через параметр

`Заголовок`

. Если Soap-ответ не содержит элемент

`Заголовок`

, значение параметра -

`Неопределено`

. Возвращаемое значение - прочитанные заголовки. Область видимости локально.

#### Примеры

Soap-заголовки могут использоваться для передачи дополнительной информации, непосредственно не связанной с задачей, решаемой операцией сервиса. В частности, это может быть информация, используемая для диагностики работы сервиса и клиента. В примере Soap-сервис передает клиенту длительность обработки запроса в атрибуте `ДлительностьОбработкиЗапроса` Soap-заголовка `Диагностика`. Для чтения заголовка в модуль элемента проекта клиента Soap-сервиса надо добавить обработчик:

```xbsl
@Обработчик
метод ОбработатьЗаголовкиSoapДобавитьВКаталог(Заголовок: ЧтениеXml?): Объект?
    если Заголовок == Неопределено
        возврат Неопределено
    ;

    пока Заголовок.Следующий()
        если Заголовок.ВидУзла != ВидУзлаXml.НачалоЭлемента
            продолжить
        ;

        если Заголовок.ЛокальноеИмя == "Диагностика"
            попытка
                знч ДлительностьМсек = Заголовок.ЗначениеАтрибутаКакЧисло("ДлительностьОбработкиЗапроса")
                возврат Длительность.ИзМиллисекунд(ДлительностьМсек)
            поймать Искл: Исключение
            ;
        ;
    ;
    возврат Неопределено
;
```

Теперь прочитанные из заголовка данные можно получить из свойства [Заголовки](soapresponse-ru-1c747b82e956.md) - в нем будет то значение, которое вернет обработчик `ОбработатьЗаголовкиSoapДобавитьВКаталог`.

```xbsl
метод ДобавитьВКаталог(КоличествоТовара: Число, НаименованиеТовара: Строка): Длительность?
    знч КлиентСервиса = новый КлиентСервисаМагазина()
    знч НовыйТовар = новый КлиентСервисаМагазина.Товар(КоличествоТовара, НаименованиеТовара)
    знч ДанныеТокена = новый КлиентСервисаМагазина.ЗаголовокТокенПользователя("User", "Password")
    знч ОтветСервиса = КлиентСервиса.ДобавитьВКаталог(НовыйТовар, ДанныеТокена)
    знч ДлительностьОбработки = ОтветСервиса.Заголовки
    
    возврат ДлительностьОбработки как Длительность?
;
```
