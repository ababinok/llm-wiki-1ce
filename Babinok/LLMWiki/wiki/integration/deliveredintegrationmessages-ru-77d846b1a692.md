## Методы

### Выгрузить

`Доступность: Сервер`

```
Выгрузить(
  ПотокЗаписи: ПотокЗаписи,
  Якорь: ДоставленноеСообщениеИнтеграции,
  НаправлениеВыбора: НаправлениеВыбораСообщенийИнтеграции)
```

Выгрузить все сообщения до или после переданного якоря в поток в виде архива, содержащего в себе для каждого сообщения его тело и его параметры в виде json.

**Перегрузка** [Выгрузить(ПотокЗаписи: ПотокЗаписи, Узел: УзелСхемыИнтеграции? = Неопределено, Участник: Строка? = Неопределено, ДатаНачала: Момент? = Неопределено, ДатаКонца: Момент? = Неопределено, ИдСообщения: Строка? = Неопределено)](deliveredintegrationmessages-ru-77d846b1a692.md)

#### Примеры

Пример подсчета удаляемых или отправляемых доставленных сообщений.

```xbsl
метод Выгрузить(ИмяПроцесса: Строка, Якорь: ДоставленноеСообщениеИнтеграции, Направление: НаправлениеВыбораСообщенийИнтеграции): ПотокЧтения
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    исп ПотокЗаписи = новый ВременныйПотокЗаписи()
    
    Процесс.ДоставленныеСообщения.Выгрузить(ПотокЗаписи, Якорь, Направление)
    возврат ПотокЗаписи.ОткрытьПотокЧтения()
;
```

### Выгрузить

`Доступность: Сервер`

```
Выгрузить(
  ПотокЗаписи: ПотокЗаписи,
  Узел: УзелСхемыИнтеграции? = Неопределено,
  Участник: Строка? = Неопределено,
  ДатаНачала: Момент? = Неопределено,
  ДатаКонца: Момент? = Неопределено,
  ИдСообщения: Строка? = Неопределено)
```

Записывает в переданный поток информацию о сообщениях в виде архива, содержащего в себе для каждого сообщения его тело и его параметры в виде json.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если ДатаВремяНачала позже ДатаВремяКонца.

**Перегрузка** [Выгрузить(ПотокЗаписи: ПотокЗаписи, Якорь: ДоставленноеСообщениеИнтеграции, НаправлениеВыбора: НаправлениеВыбораСообщенийИнтеграции)](deliveredintegrationmessages-ru-77d846b1a692.md)

#### Примеры

Пример выгрузки доставленных сообщений.

```xbsl
метод ВыгрузитьВсеДоставленныеСообщения(ИмяПроцесса: Строка): ПотокЧтения
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    
    исп ПотокЗаписи = новый ВременныйПотокЗаписи()

    Процесс.ДоставленныеСообщения.Выгрузить(ПотокЗаписи)
    
    возврат ПотокЗаписи.ОткрытьПотокЧтения()
;

метод ВыгрузитьДоставленныеВУзелСообщенияДляУчастникаЗаСутки(ИмяПроцесса: Строка, ИмяУзла: Строка, КодУчастника: Строка): ПотокЧтения
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    
    исп ПотокЗаписи = новый ВременныйПотокЗаписи()
    
    пер Узел = Процесс.Схема.Узлы.КакСоответствие()[ИмяУзла]
    
    пер Сейчас = Момент.Сейчас()
    пер Старт = Сейчас - 1д
    пер Конец = Сейчас

    Процесс.ДоставленныеСообщения.Выгрузить(ПотокЗаписи, Узел, КодУчастника, Старт, Конец)
    
    возврат ПотокЗаписи.ОткрытьПотокЧтения()
;
```

### Найти

`Доступность: Сервер`

```
Найти(
  Узел: УзелСхемыИнтеграции? = Неопределено,
  Участник: Строка? = Неопределено,
  ДатаНачала: Момент? = Неопределено,
  ДатаКонца: Момент? = Неопределено,
  ИдСообщения: Строка? = Неопределено,
  Якорь: ДоставленноеСообщениеИнтеграции? = Неопределено,
  СортировкаПоДате: НаправлениеСортировки = НаправлениеСортировки.ПоУбыванию,
  Ограничить: Число = 10
): ЧитаемыйМассив<ДоставленноеСообщениеИнтеграции>
```

Возвращает массив доставленных сообщений, удовлетворяющих критериям поиска.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если ДатаВремяНачала позже ДатаВремяКонца.

#### Примеры

Пример поиска доставленных сообщений.

```xbsl
метод НайтиДоставленныеВУзелСообщенияДляУчастникаЗаСутки(ИмяПроцесса: Строка, ИмяУзла: Строка, КодУчастника: Строка, Ограничить: Число): Массив<ДоставленноеСообщениеИнтеграции>
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    пер Узел = Процесс.Схема.Узлы.КакСоответствие()[ИмяУзла]
    
    пер Сейчас = Момент.Сейчас()
    пер Старт = Сейчас - 1д
    пер Конец = Сейчас

    возврат Процесс.ДоставленныеСообщения.Найти(Узел, КодУчастника, Старт, Конец, Ограничить)
;
```

### НастроитьХранение

`Доступность: Сервер`

```
НастроитьХранение(
  Узлы: ЧитаемоеМножество<УзелСхемыИнтеграции>,
  Настройки: НастройкиХраненияДоставленныхСообщенийИнтеграции)
```

Настроить хранение доставленных для указанных узлов назначений процесса. Хранить доставленные сообщения можно для всех конечных узлов и для узлов Http и Sql вне зависимости от их местоположения на схеме. Если множество узлов пусто, то настраиваются все узлы.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - При попытке настроить хранение для узла, в котором хранение не предполагается (например, таймер).

#### Примеры

Пример настройки хранения доставленных сообщений.

```xbsl
метод НастроитьХранениеДоставленныхСообщенийДляУзла(ИмяПроцесса: Строка, ИмяУзла: Строка, ТаймаутУстаревания: Длительность)
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    пер Узел = Процесс.Схема.Узлы.КакСоответствие()[ИмяУзла]
    
    пер Настройки = новый НастройкиХраненияДоставленныхСообщенийИнтеграции(ТаймаутУстаревания)
    
    Процесс.ДоставленныеСообщения.НастроитьХранение(<УзелСхемыИнтеграции>{Узел}, Настройки)
;
```

### ПолучитьНастройкиХранения

`Доступность: Сервер`

```
ПолучитьНастройкиХранения(): ЧитаемоеСоответствие<УзелСхемыИнтеграции, НастройкиХраненияДоставленныхСообщенийИнтеграции>
```

Получить настройки хранения доставленных сообщений для каждого из узлов назначений. Если не вызывать метод

[НастроитьХранение](deliveredintegrationmessages-ru-77d846b1a692.md)

, то вернет соответствие, в котором все узлы назначения → 0мс.

#### Примеры

Пример получения настроек хранения доставленных сообщений.

```xbsl
метод ПолучитьНастройкиХраненияДоставленныхСообщенийДляУзла(ИмяПроцесса: Строка, ИмяУзла: Строка): НастройкиХраненияДоставленныхСообщенийИнтеграции
    пер Процесс = ПроцессыИнтеграции[ИмяПроцесса]
    пер Узел = Процесс.Схема.Узлы.КакСоответствие()[ИмяУзла]
    
    возврат Процесс.ДоставленныеСообщения.ПолучитьНастройкиХранения().Получить(Узел)
;
```
