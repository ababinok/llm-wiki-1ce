## Обзор

Блокировка для пространства блокировок `Ссылка` плана обмена {ИмяПланаОбмена}.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПланаОбмена}.Блокировки.Ссылка` `Доступность: Сервер`

Блокировка для пространства блокировок `Ссылка` плана обмена {ИмяПланаОбмена}. Пространство используется для блокировки объектов плана обмена по значению поля `Ссылка`.

## Конструкторы

### {ИмяПланаОбмена}.Блокировки.Ссылка

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяПланаОбмена}.Блокировки.Ссылка(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Ссылка: <ТипСсылки>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
