Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / ExchangePlans.

Имена для поиска: `ДопустимыйНомерСообщенияОбмена`, `AllowedExchangeMessageNumber`, `Стд::ПланыОбмена::ДопустимыйНомерСообщенияОбмена`, `Std::ExchangePlans::AllowedExchangeMessageNumber`.

## Обзор

Содержит варианты указаний, какой номер сообщения обмена данными следует считать допустимым при приеме сообщения.

## Документированный контракт и примеры

`Стд::ПланыОбмена::ДопустимыйНомерСообщенияОбмена` `Доступность: КлиентИСервер`

Содержит варианты указаний, какой номер сообщения обмена данными следует считать допустимым при приеме сообщения.

## Свойства

### Больший

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Больший
```

Данное значение показывает, что принимаемое сообщение может иметь любой номер больший, чем максимальный номер принятого сообщения. Максимальный номер принятого сообщения можно узнать, обратившись к реквизиту НомерПринятого узла плана обмена.

---

### Любой

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Любой
```

Принимаемое сообщение обмена может иметь любой номер.

---

### Следующий

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Следующий
```

Данное значение показывает, что номер принимаемого сообщения должен быть на 1 больше, чем максимальный номер принятого сообщения. Максимальный номер принятого сообщения можно узнать, обратившись к реквизиту НомерПринятого узла плана обмена.
