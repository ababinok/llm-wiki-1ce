## Свойства

### ПереносСтрок

`Доступность: Сервер`

```
ПереносСтрок: ПереносСтрокJson
```

Управляет размещением начала и конца объектов и массивов, ключей и значений на новой строке. Также установка данного свойства в значение, отличное от [Отсутствует](jsonlinebreak-ru-ea09a263d9f1.md), добавляет пробел между именем свойства, двоеточием и значением. Включает использование свойства [СимволыОтступа](jsonwriteroptions-ru-1ea966b35ac8.md)

---

### ПроверятьСтруктуру

`Доступность: Сервер`

```
ПроверятьСтруктуру: Булево
```

Признак проверки правильности структуры записываемого JSON объекта.

---

### СимволыОтступа

`Доступность: Сервер`

```
СимволыОтступа: Строка
```

Символы отступа, используемые при записи документа JSON. Свойство не используется, если свойство [ПереносСтрок](jsonwriteroptions-ru-1ea966b35ac8.md) установлено в значение [Отсутствует](jsonlinebreak-ru-ea09a263d9f1.md).

---

`Доступность: Сервер`

```
ФорматМомента: ФорматМоментаJson
```

Формат записи [Момент](../stdlib/instant-ru-09dd46b34eb4.md) в результирующий документ JSON.

ЭкранированиеСимволов: ЭкранированиеСимволовJson

`Доступность: Сервер`

```

Признак экранирования символа амперсанда при записи документа JSON.

---

### ЭкранироватьОдинарныеКавычки

`Доступность: Сервер`

```
ЭкранироватьОдинарныеКавычки: Булево
```

Признак экранирования символа одинарной кавычки при записи документа JSON.

---

### ЭкранироватьРазделителиСтрокИАбзацев

`Доступность: Сервер`

```
ЭкранироватьРазделителиСтрокИАбзацев: Булево
```

Определяет экранирование символов `"\ю08232"` как "\u2028" (разделитель строк) и `"\ю08233"` как "\u2029" (разделитель абзацев) для совместимости с JavaScript.

---

### ЭкранироватьСлеш

`Доступность: Сервер`

```
ЭкранироватьСлеш: Булево
```

Признак экранирования символа косой черты `/` при записи значения.

---

### ЭкранироватьУгловыеСкобки

```
