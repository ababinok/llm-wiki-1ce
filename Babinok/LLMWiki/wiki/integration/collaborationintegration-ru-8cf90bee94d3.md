## Свойства

### Активно

`Доступность: Сервер` `ТолькоЧтение`

```
Активно: Булево
```

Признак, показывающий включена интеграция или нет

---

### ВидВнешнейСистемы

`Доступность: Сервер` `ТолькоЧтение`

```
ВидВнешнейСистемы: Строка
```

Вид внешней системы: "Telegram", "WhatsApp", "WebChat" итд

---

### ДоступноРедактированиеСообщения

`Доступность: Сервер` `ТолькоЧтение`

```
ДоступноРедактированиеСообщения: Булево
```

Определяет возможность изменения отправленных сообщений в обсуждениях данной интеграции:

- Истина - изменение возможно
- Ложь - изменение невозможно (для интеграции типа WhatsApp).

---

### Ид

`Доступность: Сервер` `ТолькоЧтение`

```
Ид: Ууид
```

Идентификатор интеграции в системе взаимодействия.

---

### Имя

`Доступность: Сервер` `ТолькоЧтение`

```
Имя: Строка
```

Название интеграции. Используется для отображения в пользовательском интерфейсе.

---

### Ключ

`Доступность: Сервер` `ТолькоЧтение`

```
Ключ: Строка
```

Ключ интеграции системы взаимодействия. Если не пустая строка, то должен быть уникальным.

---

### НавигационнаяСсылкаТочкиПодключения

`Доступность: Сервер` `ТолькоЧтение`

```
НавигационнаяСсылкаТочкиПодключения: Строка
```

Содержит ссылку подключения для интеграции с веб-чатом или whatsapp. Содержит пустое значение для других интеграций. Свойство устанавливается Системой Взаимодействия, а не пользователем.

---

### ПараметрыВнешнейСистемы

`Доступность: Сервер` `ТолькоЧтение`

```
ПараметрыВнешнейСистемы: ЧитаемоеСоответствие<Строка, Строка>
```

Предопределенные параметры подключения внешней системы (соответствие ключа и значения), уникальные для каждого типа внешней системы.

---

### Участники

`Доступность: Сервер` `ТолькоЧтение`

```
Участники: ЧитаемыйМассив<Ууид>
```

Список Ид участников по умолчанию для обсуждения, созданного интеграцией

---
