## Обзор

Параметры процесса интеграции.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПроцессаИнтеграции}.Параметры` `Доступность: Сервер`

Параметры процесса интеграции. Набор параметров и начальные значения задаются при разработке схемы процесса. Для каждого параметра формируется свойство с его именем. Программный доступ к параметрам возможен по имени или по индексу. В процессе работы приложения значения могут быть изменены программно или через пользовательский интерфейс. При изменении параметра запущенного процесса производится его автоматический перезапуск (остановка, изменение параметра и запуск). Поэтому при одновременном изменении нескольких параметров рекомендуется перед их изменением выполнить остановку процесса явно (вызвать метод [Остановить](integrationprocess-ru-136570064b69.md), а после изменения - выполнить запуск процесса явно (вызвать метод [Запустить](integrationprocess-ru-136570064b69.md)) или изменить значения сразу всех параметров с использованием метода [ИзСоответствия](integrationprocessname-parameters-ru-65d5d13a978a.md). Запрещено менять параметры процесса интеграции из обработчика узла данного процесса интеграции, это приведет к выбросу исключения [ИсключениеИнтеграционнойШины](integrationbusexception-ru-0bbe235ac154.md).

## Операция []

`Изменяемый`

```
[Ключ: Строка]: Булево|Число|Строка|Длительность
```

Возвращает значение параметра процесса интеграции [ПроцессИнтеграции](integrationprocess-ru-136570064b69.md) по индексу, в качестве значения которого используется имя параметра.

При изменении параметра запущенного процесса производится его автоматический перезапуск (остановка, изменение параметра и запуск). Поэтому при одновременном изменении нескольких параметров рекомендуется перед их изменением выполнить остановку процесса явно (вызвать метод [Остановить](integrationprocess-ru-136570064b69.md), а после изменения - выполнить запуск процесса явно (вызвать метод [Запустить](integrationprocess-ru-136570064b69.md) или изменить значения сразу всех параметров с использованием метода [ИзСоответствия](integrationprocessname-parameters-ru-65d5d13a978a.md)).

**[ИсключениеИнтеграционнойШины](integrationbusexception-ru-0bbe235ac154.md)** - если параметры изменяются из обработчика узла данного процесса интеграции.

### Пример

Пример обработчика http-запроса, в котором изменяются значения параметров процесса интеграции `"СетьМагазинов"`.

```xbsl
метод ЗадатьПараметрыПроцесса(Запрос: HttpСервисЗапрос)
    пер Параметры: Соответствие<Строка, Объект> = {:}
    для Имя из Запрос.Параметры.Имена()
        Параметры.Вставить(Имя, Запрос.Параметры.ПолучитьПервый(Имя))
    ;
    СетьМагазинов.Остановить()
    пер ТипыПараметров = СетьМагазинов.Параметры.ВсеТипы()

    для Имя из СетьМагазинов.Параметры.ВсеИмена()
        если ТипыПараметров[Имя] == Тип<Число>
            СетьМагазинов.Параметры[Имя] = новый Число(Параметры.ПолучитьИлиУмолчание(Имя, "0").ВСтроку())
        иначе если ТипыПараметров[Имя] == Тип<Строка>
            СетьМагазинов.Параметры[Имя] = Параметры.ПолучитьИлиУмолчание(Имя, "").ВСтроку()
        иначе если ТипыПараметров[Имя] == Тип<Булево>
            СетьМагазинов.Параметры[Имя] = новый Булево(Параметры.ПолучитьИлиУмолчание(Имя, "Ложь").ВСтроку())
        иначе если ТипыПараметров[Имя] == Тип<Длительность>
            СетьМагазинов.Параметры[Имя] = Длительность.ИзМиллисекунд(новый Число(Параметры.ПолучитьИлиУмолчание(Имя, "0").ВСтроку()))
        ;
    ;
    если Запрос.Параметры.ПолучитьПервый("log") != Неопределено
        СетьМагазинов.РегистрироватьДоставкуВЖурналеСобытий = Истина
    ;
    СетьМагазинов.Запустить()
;
```

Следующие два способа обращения к параметру `"ДиректорияЛогов"` процесса интеграции `"СетьМагазинов"` эквивалентны:

- `СетьМагазинов.Параметры.ДиректорияЛогов`
- `СетьМагазинов.Параметры["ДиректорияЛогов"]`

## Методы

### ВсеИмена

`Доступность: Сервер`

```
ВсеИмена(): ЧитаемыйМассив<Строка>
```

Возвращает имена всех доступных параметров.

#### Примеры

Пример обработчика http-запроса, в котором параметры процесса интеграции `"СетьМагазинов"` записываются в тело http-ответа в формате json.

```xbsl
метод ПолучитьПараметрыПроцесса(Запрос: HttpСервисЗапрос)
    пер Json = новый ЗаписьJson(Запрос.Ответ.ОткрытьПотокЗаписиТела())
    Json.ЗаписатьНачалоОбъекта()
    для ИмяПараметра из СетьМагазинов.Параметры.ВсеИмена()
        пер ЗначениеПараметра = СетьМагазинов.Параметры[ИмяПараметра]
        Json.Записать(ИмяПараметра, ЗначениеПараметра.ВСтроку())
    ;
    Json.ЗаписатьКонецОбъекта()
;
```

### ИзСоответствия

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ИзСоответствия(Параметры: ЧитаемоеСоответствие<Строка,Число|Строка|Булево|Длительность>)
```

Устанавливает значения параметров процесса из переданного соответствия

`Параметры`

, в котором ключ - имя параметра, а значение - значение параметра. Меняются только те параметры процесса, которые есть в переданном соответствии, остальные остаются неизменными. Если в соответствии есть ключ, для которого не найден параметр, то выбрасывается исключение

[ИсключениеИнтеграционнойШины](integrationbusexception-ru-0bbe235ac154.md)

. При изменении параметров запущенного процесса автоматически выполняется его перезапуск. Рекомендуется использовать этот метод при одновременном изменении нескольких параметров запущенного процесса интеграции.

#### Исключения

**[ИсключениеИнтеграционнойШины](integrationbusexception-ru-0bbe235ac154.md)** - если метод выполняется из обработчика узла данного процесса интеграции.
