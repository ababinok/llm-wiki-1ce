## Обзор

В компонент интерфейса [СтандартноеКлиентскоеПриложениеСРазделами](../interface/standard-client-application-with-sections-component-49da52beb720.md) можно встраивать другие веб-приложения, выполненные на базе «1С:Предприятия» и «1С:Предприятие.Элемента».

## Документированный контракт и примеры

В компонент интерфейса [СтандартноеКлиентскоеПриложениеСРазделами](../interface/standard-client-application-with-sections-component-49da52beb720.md) можно встраивать другие веб-приложения, выполненные на базе «1С:Предприятия» и «1С:Предприятие.Элемента». Веб-страницы отображаются в области содержимого клиентского приложения посредством компонента [КонтейнерHTML](../interface/html-container-component-07a59cecebfd.md). Взаимодействие между внешним и родительским сайтами осуществляется путем передачи сообщений между ними.

## Добавление встроенной веб-страницы

Чтобы добавить веб-приложение в клиентское приложение, используйте его свойство [ВстроенныеВебСтраницы](../interface/standard-client-application-with-sections-component-49da52beb720.md).

В свойствах клиентского приложения раздел «ВстроенныеВебСтраницы» содержит добавление элемента и выбор его типа. [Описание иллюстрации](../../raw/figures/3c3aa42c4b4c54322b0dd771678bc432e1bc15aa28a875fe90cba343b7b8915e-1ffe4f009316730b.md)

Выберите тип добавляемого элемента:

- [`ВстроеннаяВебСтраница1СПредприятие`](../interface/embedded1centerprisewebpage-ru-beb590d93db9.md)
  
  — для взаимодействия со встроенной веб-страницей «1С:Предприятия»,
- [`ПроизвольнаяВстроеннаяВебСтраница`](../interface/customembeddedwebpage-ru-5c207144daf0.md)
  
  — для взаимодействия с произвольной встроенной веб-страницей.

Выбор типа добавляемого элемента [Описание иллюстрации](../../raw/figures/9d438d86d9a8c4b07aef986d9380f7ecf34e7810706b890154f815b2c410379f-7b50656668bb96bf.md)

Укажите свойства добавляемой веб-страницы:

- [`Url`](../interface/embeddedwebpage-ru-948b3b8bf499.md) (обязательное) — адрес встроенной веб-страницы, с которой осуществляется взаимодействие.
- [`Ид`](../interface/embeddedwebpage-ru-948b3b8bf499.md) (обязательное) — уникальный идентификатор встроенной веб-страницы. Назначается разработчиком.
- [`Представление`](../interface/embeddedwebpage-ru-948b3b8bf499.md) (обязательное) — текстовое представление встроенной веб-страницы в интерфейсе.
- [`Изображение`](../interface/embeddedwebpage-ru-948b3b8bf499.md) — иконка встроенной веб-страницы.
- [`Данные`](../interface/embeddedwebpage-ru-948b3b8bf499.md) — любая необходимая сопутствующая информация о веб-странице.
  
  > [!NOTE] примечание
  > Используется, чтобы привязать дополнительную информацию, относящуюся к встроенной веб-странице, к объекту `ВстроеннаяВебСтраница`. Например, если разработчику необходимо разделить приложения на основное и дополнительные, он может создать собственный объект, где будет содержаться данная информация, и указывать этот объект в свойстве **Данные** встроенной веб-страницы.

Чтобы установить собственное визуальное представление загрузки встроенной веб-страницы, вы можете задать свойство [`КомпонентСостоянияЗагрузки`](../interface/embeddedwebpage-ru-948b3b8bf499.md) и в обработчиках событий [`ПриНачалеЗагрузки`](../interface/embeddedwebpage-ru-948b3b8bf499.md) и [`ПриОткрытии`](../interface/embeddedwebpage-ru-948b3b8bf499.md) вызвать методы [`ПоказатьСостояниеЗагрузки()`](../interface/embeddedwebpage-ru-948b3b8bf499.md) и [`СкрытьСостояниеЗагрузки()`](../interface/embeddedwebpage-ru-948b3b8bf499.md) соответственно.

Описание добавленной произвольной веб-страницы в приложении

```yaml
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: ВПодсистеме
Ид: e667822f-f62d-4b8c-aca4-28981c5b0031
Имя: ПриложениеДляИнтеграции
Наследует:
    Тип: СтандартноеКлиентскоеПриложениеСРазделами
    ВстроенныеВебСтраницы:
        ВебСтраницы:
            -
                Тип: ПроизвольнаяВстроеннаяВебСтраница
                Url: http://mysite.ru/UNF/ru/?N=Администратор
                Ид: УНФ
                Представление: Набор решений "Бизнес"
                КомпонентСостоянияЗагрузки: Неопределено
```

Добавьте обработчики следующих событий:

- [`ПриНачалеЗагрузки`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  Пример обработчика события «ПриНачалеЗагрузки» test-context=
  
  ```xbsl
  метод ПриНачалеЗагрузкиСайта(Источник: ВстроеннаяВебСтраница,
          Событие:  СобытиеКомпонента)
      Источник.ПоказатьСостояниеЗагрузки()
  ;
  ```
- [`ПриОткрытии`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  Пример обработчика события «ПриОткрытии» test-context=
  
  ```xbsl
  метод ПриОткрытииСайта(Источник: ВстроеннаяВебСтраница, Событие: СобытиеКомпонента)
      Источник.СкрытьСостояниеЗагрузки()
  ;
  ```
- [`ПриПолученииСообщения`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  Пример обработчика события «ПриПолученииСообщения» test-context=
  
  ```xbsl
  метод ПриПолученииСообщенияСайта(Источник: ВстроеннаяВебСтраница,
          Событие:  СобытиеПриПолученииСообщенияВстроеннойВебСтраницы)
      попытка
          пер Данные = ПрочитатьДанные(Событие.Сообщение.ТекстСообщения)
          пер Действие = Данные.Получить("Действие") как Строка
          пер Получатель = Данные.Получить("Получатель") как Строка
          пер ПолучательПриложение = ВстроенныеВебСтраницы.ПолучитьВебСтраницу(Получатель)
          если Действие == "ОтправитьСообщение"
              ПолучательПриложение.ОтправитьСообщение(Событие.Сообщение)
          иначе если Действие == "ВыполнитьПереход"
              ВстроенныеВебСтраницы.ЗагрузитьВебСтраницу(Получатель, Неопределено)
              ПолучательПриложение.Активировать()
          ;
      поймать Исключение: неизвестно
      ;
  ;
  
  @ВПодсистеме
  @НаСервере @ДоступноСКлиента
  статический метод ПрочитатьДанные(Данные: Строка): Соответствие<Строка, Объект?>
      возврат СериализацияJson.ПрочитатьОбъект(Данные, Тип<Соответствие<Строка, Объект?>>)
  ;
  ```

## Отображение встроенной веб-страницы

Командное и визуальное представление области отображения встроенных веб-страниц определяется свойством **ИнтерфейсВстроенныхВебСтраниц** компонента **СтандартноеКлиентскоеПриложениеСРазделами**.

Панель веб-страниц содержит встроенное меню, из которого можно запускать любую веб-страницу. В нем также можно увидеть, какие страницы активны или запущены:

Меню встроенных веб-страниц [Описание иллюстрации](../../raw/figures/ae4c74b3a8f4c2a325121a7cf8417ed0235a1c88b6543fb751fd31bd9f396052-8667560e71a34160.md)

Вы можете переопределить визуальное представление интерфейса встроенных веб страниц, задав следующие параметры:

- [`Видимость`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — определяет отображение интерфейса для встроенных веб-страниц в приложении.
- [`Логотип`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — логотип интерфейса встроенных веб-страниц.
- [`ЛоготипКрупный`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — крупный логотип интерфейса встроенных веб-страниц.
- [`ЦветПанели`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — цвет панели встроенных веб-страниц.
- [`КомпонентМеню`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — встроенное меню панели веб-страниц. Чтобы использовать собственное визуальное представление меню, переопределите это свойство, присвоив в него собственный компонент.
- [`КомандыПанели`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — командный интерфейс панели веб-страниц.
- [`ОсновнаяКомандаМеню`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — основная команда меню веб-страниц.
- [`ДополнительныеКомандыМеню`](../interface/embeddedwebpagesinterface-ru-42e56c8809d2.md)
  
  — дополнительные команды меню веб-страниц.

## Взаимодействие с внешним сайтом

Для взаимодействия компонента клиентского приложения с внешним веб-сайтом используется свойство [ВнешнийВебСайт](../interface/standard-client-application-with-sections-component-49da52beb720.md).

Сообщения передаются внешнему веб-сайту с помощью метода [`ОтправитьСообщение()`](../interface/externalwebsite-ru-2a877ea99fc1.md). Чтобы получать сообщения от внешнего сайта, используется обработчик `ПриПолученииСообщенияВнешнегоПриложения()`.

У встроенной веб-страницы в поле обработчика события получения сообщения показана кнопка плюса для создания обработчика. [Описание иллюстрации](../../raw/figures/45458b3fb2746c4f52a0e8a5061c3c1754d7a1178f4bad782e07ceffe55d1560-383f9682a006062c.md)

Обработчик события «СобытиеПриПолученииСообщенияВнешнегоВебСайта»

```xbsl
метод ПриПолученииСообщенияВнешнегоПриложения(Источник: ВнешнийВебСайт,
        Событие: СобытиеПриПолученииСообщенияВнешнегоВебСайта)

    // Обработка получения сообщения от внешнего приложения
;
```

## Работа со встроенными веб-страницами

С помощью свойств и методов типа [`ВстроенныеВебСтраницы`](../interface/embeddedwebpages-ru-f75faba9fb8c.md) вы можете:

- получить массив всех зарегистрированных встроенных веб-страниц — свойство
  
  [`ВебСтраницы`](../interface/embeddedwebpages-ru-f75faba9fb8c.md)
  
  ;
- получить ссылку на встроенную веб-страницу, которая активна в данный момент (т. е. видна в области содержимого) — свойство
  
  [`АктивнаяВебСтраница`](../interface/embeddedwebpages-ru-f75faba9fb8c.md)
  
  ;
- загрузить веб-страницу — метод
  
  [`ЗагрузитьВебСтраницу()`](../interface/embeddedwebpages-ru-f75faba9fb8c.md)
  
  ;
- найти встроенную веб-страницу по ее идентификатору — метод
  
  [`ПолучитьВебСтраницу()`](../interface/embeddedwebpages-ru-f75faba9fb8c.md)
  
  .

С помощью методов типа [`ВстроеннаяВебСтраница`](../interface/embeddedwebpage-ru-948b3b8bf499.md) вы можете:

- остановить веб-страницу и удалить ее из панели запущенных веб-страниц и из области содержимого приложения — метод
  
  [`Остановить()`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  ;
- активировать веб-страницу в рабочей области и запустить ее, если она не была запущена — метод
  
  [`Активировать()`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  ;
- переслать сообщение веб-странице — метод
  
  [`ОтправитьСообщение()`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  ;
- включить и выключить отображение компонента загрузки для веб-страницы — методы
  
  [`ПоказатьСостояниеЗагрузки()`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  и
  
  [`СкрытьСостояниеЗагрузки()`](../interface/embeddedwebpage-ru-948b3b8bf499.md)
  
  .

Обмен сообщениями происходит с помощью объектов типов [`СообщениеВнешнегоВебСайта`](../interface/externalwebsitemessage-ru-0b57c5884406.md) и [`СообщениеВстроеннойВебСтраницы`](../interface/embeddedwebpagemessage-ru-22daadca3533.md).
