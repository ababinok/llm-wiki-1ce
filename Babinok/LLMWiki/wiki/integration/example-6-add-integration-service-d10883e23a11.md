## Обзор

На этом этапе вы добавите в информационную базу объект конфигурации вида **Сервис интеграции**.

## Документированный контракт и примеры

На этом этапе вы добавите в информационную базу объект конфигурации вида **Сервис интеграции**.

## Добавление сервиса интеграции в информационную базы «1С:Предприятия 8»

- Добавьте сервис интеграции с именем **СервисБазы**. Для этого откройте вкладку **Общее**, затем правой кнопкой мыши нажмите **Сервисы интеграции**, в контекстном меню выберите **Создать** ⟶ **Сервис интеграции**:
  
  
- Заполните имя для сервиса интеграции. Нажмите **Готово**:
  
  Добавление сервиса интеграции в информационную базы «1С:Предприятия 8» [Описание иллюстрации](../../raw/figures/884dc517bd9e8b686c53dc04db86c2daa2f201717f0586b5ed37fab4b00ae1c8-1a70ca00156189f4.md)
- Откройте приложение «1С:Предприятие.Элемента» в браузере и скопируйте адрес приложения:
  
  Приложение Элемента открыто в браузере; выделенная строка адреса содержит URL приложения, который копируется для настройки внешнего сервиса интеграции. [Описание иллюстрации](../../raw/figures/4a09f37b8c4baaaea5aee697cc9ae45433274b3e848687b31565f0807b1afb42-b2343ee00a6a7c6a.md)
- Вернитесь в среду разработки и установите скопированный адрес в качестве значения свойства **Адрес внешнего сервиса интеграции**:
  
  В свойствах сервиса интеграции указан скопированный адрес опубликованного приложения в поле «Адрес внешнего сервиса интеграции». [Описание иллюстрации](../../raw/figures/43fc605102ff6fb2589e5f1e5592f0628334ae2f28ff6cabd079eb1597b4a602-d25204b66f99623d.md)
  
  Чтобы сохранить изменения, нажмите **Ctrl + S**.
- Правой кнопкой мыши нажмите на сервис интеграции **СервисБазы** и выберите **Загрузить каналы**:
  
  
- В открывшейся форме укажите идентификатор и секрет клиента, полученные на этапе создания информационной системы **Книжный дом** в приложении «1С:Предприятие.Элемента». Затем нажмите кнопку **Получить каналы сервиса**:
  
  Добавление сервиса интеграции в информационную базы «1С:Предприятия 8» [Описание иллюстрации](../../raw/figures/b815c4001b1ca2ea718211deb12a408f421f3a975d6b56aca077c00dcdcaad64-db83561ed34e53e8.md)
- Установите галочку около канала **ИзБазы** и нажмите **Загрузить**:
  
  Добавление сервиса интеграции в информационную базы «1С:Предприятия 8» [Описание иллюстрации](../../raw/figures/9c13954476676be17f06cbd2171e07b67b205b5aa2853d2bb8c77ea5de8a667c-615f6ef45a9d8046.md)
- Дважды кликните на добавленный канал интеграции. В панели **Свойства**, в поле **Имя канала внешнего сервиса интеграции**, по умолчанию может стоять **Основной_МаршрутизацияСообщений.ИзБазы**. Вам следует изменить название на **Основной::МаршрутизацияСообщений.ИзБазы**:
  
  
  
  Имя канала должно совпадать с тем названием, которое у вас указано в «1С:Предприятие.Элементе»:
  
  Карточка процесса показывает его квалифицированное имя «Основной::МаршрутизацияСообщений», состояние «Запущен», время работы и счётчик входящих сообщений; имя служит ориентиром при согласовании имён канала интеграции. [Описание иллюстрации](../../raw/figures/44d5e338dfc800b2d6efecbecfa256ca5cbb75671c7a37be950ce9c7c7fd8f0f-002c0a7f7312230f.md)На фрагменте схемы выделено имя узла «ИзБазы»; оно используется как ориентир при согласовании имени внешнего канала интеграции. [Описание иллюстрации](../../raw/figures/47bc8759dcf541c855d45bd712013a3976fe17d5860cf1d0717774d601079606-5d0b612645246708.md)
  
  В настройках канала внешнего сервиса интеграции «1С:Предприятия» показаны: Имя — Основной_МаршрутизацияСообщений_ИзБазы; Имя канала внешнего сервиса интеграции — Основной::МаршрутизацияСообщений.ИзБазы; Направление сообщения — Отправка; «В транзакции» включено. [Описание иллюстрации](../../raw/figures/7bb8c94b0f90d32f35c35aab9bde7d6ed60f6bda19b0eecc0b22b1776d15a914-60205e0d615da8c0.md)
  
  Также задайте имя канала сервиса интеграции, совпадающее с названием канала в «1С:Предприятие.Элементе» — **ИзБазы**:
  
  Свойства канала сервиса интеграции: имя «ИзБазы», имя внешнего канала «Основной::МаршрутизацияСообщений.ИзБазы», направление сообщения «Отправка». [Описание иллюстрации](../../raw/figures/e808695867d358e29a39dbea758c6590370053b482709b54f01acd0f5d0ef14c-261a8f3227380fc6.md)
  
  Чтобы сохранить изменения, кликните **Ctrl + S**.
