Узел этого вида передает сообщения информационной системе, являющейся брокером сообщений [RabbitMQ](https://www.rabbitmq.com/) в указанный обмен (Exchange).

## Документированный контракт и примеры

Узел этого вида передает сообщения информационной системе, являющейся брокером сообщений [RabbitMQ](https://www.rabbitmq.com/) в указанный обмен (Exchange).

RabbitMQ использует протокол [AMQP](https://www.rabbitmq.com/tutorials/amqp-concepts.html), основное отличие которого от JMS в том, что сообщение от системы-отправителя доставляется не непосредственно в очередь, а через обмен (Exchange), в котором определяется, в какую очередь будет доставлено сообщение.

#### ВиртуальныйХост

```yaml
ВиртуальныйХост: ВычисляемоеВыражение|Строка
```

Задает [виртуальный хост](https://www.rabbitmq.com/vhosts.html). Виртуальный хост, в отличие от обычного хоста, понятие логическое. Он определяет права доступа пользователя к очередям и обменам RabbitMQ. Например, есть два виртуальных хоста **vhost1**, **vhost2** и пользователь **User**. **User** может иметь доступ ко всем очередям на чтение, запись и добавление/удаление в **vhost1**, но в **vhost2** он может только читать из очередей. Аналогично может быть два разных пользователя, привязанных к разным **vhost**.

#### ИмяОбмена

```yaml
ИмяОбмена: ВычисляемоеВыражение|Строка
```

Задает, в какую точку обмена будет доставлено сообщение для дальнейшего распределения по очередям.

Значение свойства может определяться с использованием одного параметра типа `Строка`.

[ИмяОбмена](rabbitmqdestination-ru-2854b502788c.md) и [КлючМаршрутизации](rabbitmqdestination-ru-2854b502788c.md) не могут быть одновременно пустыми — в таком случае сообщение не будет никуда доставлено. Если при отправке сообщения такое произойдет, «1С:Предприятие.Элемент» сгенерирует исключение, подсказывающее, как избежать данной проблемы: изменить свойство узла или задать ключ маршрутизации в параметрах сообщения

#### СохранятьСообщениеНаСторонеБрокера

```yaml
СохранятьСообщениеНаСторонеБрокера: СохранятьСообщениеНаСторонеБрокера
```

Позволяет настроить сохранение сообщений на стороне брокера RabbitMQ. Задается значением перечисления [СохранятьСообщениеНаСторонеБрокера](savemessageonbrokerside-ru-4cd70d9c6628.md).

Может принимать значения:

- СохранятьСообщение
  
  — отправленные из
  
  «1С:Предприятие.Элемента»
  
  сообщения будут сохранены в брокере RabbitMQ (будут отправлены «постоянные» (persistent) сообщения, со свойством RabbitMQ-сообщения
  
  `DeliveryMode=2`
  
  );

> [!NOTE] дополнительно
> Для того чтобы сообщения сохранялись в RabbitMQ, помимо установки соответствующего значения свойства узла [RabbitMqНазначение](rabbitmqdestination-ru-2854b502788c.md), также необходимо на стороне самого брокера:
>
> - Для обмена (Exchange) установить свойство
>   
>   `Durable=True`
>   
>   ;
> - Для очереди (Queue) установить свойство
>   
>   `Durable=True`
>   
>   .

- НеCохранятьСообщение
  
  — отправленные из
  
  «1С:Предприятие.Элемента»
  
  сообщения не будут сохранены в брокере RabbitMQ (будут отправлены «временные» (transient) сообщения, со свойством RabbitMQ-сообщения
  
  `DeliveryMode=1`
  
  );
- ИзОбработчика
  
  — в случае, если выбрано данное значение, необходимо указать в свойстве имя обработчика, который будет определять следует ли сохранять сообщение на стороне RabbitMq или нет.

### События

#### ВыборКлючаМаршрутизации

```yaml
ВыборКлючаМаршрутизации: Строка
```

Обработчик, который будет вызван для определения ключа маршрутизации, т. е. переопределения свойства [КлючМаршрутизации](rabbitmqdestination-ru-2854b502788c.md). Сообщение находится в параметре `Сообщение`. Нельзя модифицировать параметры заголовка, нельзя изменить тело. Если при выполнении обработчика возникает неперехваченная ошибка, ключ маршрутизации определяется значением свойства [КлючМаршрутизации](rabbitmqdestination-ru-2854b502788c.md).

---

#### ВыборСохраненияСообщенияНаСторонеБрокера

```yaml
ВыборСохраненияСообщенияНаСторонеБрокера: Строка
```

Обработчик, который позволяет на основе сообщения и процесса интеграции определить, следует ли сохранять сообщение на стороне RabbitMq. Метод обработчика возвращает `Истина`, если сообщение должно быть сохранено, иначе `Ложь`. Необходимо указать в случае, если свойству [СохранятьСообщениеНаСторонеБрокера](rabbitmqdestination-ru-2854b502788c.md) задано значение [ИзОбработчика](savemessageonbrokerside-ru-4cd70d9c6628.md).
