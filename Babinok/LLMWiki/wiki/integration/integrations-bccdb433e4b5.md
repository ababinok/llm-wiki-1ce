## Обзор

С помощью системы взаимодействия «1С:Предприятие.Элемента» вы можете отправлять уведомления пользователям, инициировавшим взаимодействие, из приложения во внешние системы взаимодействия.

## Документированный контракт и примеры

С помощью системы взаимодействия «1С:Предприятие.Элемента» вы можете отправлять уведомления пользователям, инициировавшим взаимодействие, из приложения во внешние системы взаимодействия. Поддерживаются такие популярные службы обмена сообщениями, как Telegram, WhatsApp, VK, MAX, WebChat и Webhook. Интеграции позволяют реализовать рассылку сообщений нескольким пользователям, отправить сообщение отдельному пользователю, а также получать уведомления о входящих сообщениях.

## Работа с интеграциями в интерфейсе на примере Telegram

Интеграция с Telegram осуществляется с помощью Telegram-бота. Благодаря этому с пользователем могут взаимодействовать сразу несколько человек. При этом для пользователя это будет выглядеть как общение с одним человеком.

Сценарий добавления интеграции с Telegram-ботом:

1. Создайте Telegram-бот. Воспользуйтесь утилитой [@BotFather](https://t.me/botfather), следуйте [инструкции](https://core.telegram.org/bots/features#creating-a-new-bot) и при завершении сохраните токен бота:
  
  Последовательность создания Telegram-бота через @BotFather: отправить `/newbot`; задать название `element_1c_integration`; задать username `element_1c_integration_bot`, заканчивающийся на bot; получить подтверждение создания и токен HTTP API. [Описание иллюстрации](../../raw/figures/70b294d13c880a30783852e30aca6f57100a8cf6a9f9bb4643644044b14b6bc2-40904d564c66e3f3.md)
  
  Токен будет выглядеть следующим образом:
  
  `6875068338:AAGLTvT-gLN_m5jn-LW9vuPoa1vEVNzsWxE`
2. [Зарегистрируйте](register-application-in-collaboration-system-4a6e06152ce5.md) свое приложение в системе взаимодействия.
3. В среде разработки добавьте форму `ФормаИнтеграцийСистемыВзаимодействия`:
  
  ```yaml
  ВидЭлемента: ФрагментКомандногоИнтерфейса
  Ид: 5b285b5b-d0b2-451e-bdaf-e85f2df9e02b
  Имя: Интеграции
  ОбластьВидимости: ВПодсистеме
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Представление: Интеграции
          Имя: Интеграции
          ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
  ```
  
  С ее помощью вы сможете создавать, копировать и редактировать интеграции системы взаимодействия.
  
  В списке «Интеграции системы взаимодействия» есть «Добавить интеграцию», «Обновить список» и поиск; колонки «Имя», «Вид внешней системы», «Ключ», «Использование». [Описание иллюстрации](../../raw/figures/687fa9df9a5b7d2274ab075c347591cc102fbaf365dc90ba580102d4ee1b5977-1c47f44596c8e168.md)
4. Откройте приложение, в которое вы добавили форму для создания интеграций, и перейдите на эту форму. Нажмите кнопку **+ Добавить интеграцию**. Укажите имя и наименование ключа интеграции. В поле **Вид интеграции** выберите **Telegram**. На вкладке **Параметры** введите токен бота:
  
  Форма «Интеграция» на вкладке «Описание» содержит поля имени, вида интеграции, ключа интеграции, флажок «Использовать интеграцию», навигационную ссылку точки подключения с действием копирования и выбор участников обсуждения. [Описание иллюстрации](../../raw/figures/16f17435d5f205969fd4c3dfc5e2dae37372767fef82e37bd58b7031bf06ad42-63fe3a0a113aefcd.md)
  
  > [!NOTE] примечание
  > Токен должен быть уникален среди всех информационных баз, зарегистрированных в используемом сервере взаимодействия. Другими словами, один бот Telegram не может быть подключен к разным информационным базам одного сервера взаимодействия.
5. Выберите участников обсуждения:
  
  В форме «Пользователи системы взаимодействия» отмечены пользователи «admin» и «fedotov»; «ilyin» не отмечен. [Описание иллюстрации](../../raw/figures/0845b3605b4aa973cca6f4dd668e776e1ad6a6a49c1b7c0099ea57f69b9ae87a-67085085dfc2212f.md)
  
  Все выбранные участники смогут взаимодействовать с пользователем Telegram от одного лица.
6. Нажмите кнопку **Сохранить и закрыть**. Интеграция должна появиться в списке доступных интеграций.
  
  Список интеграций системы взаимодействия: колонки имени, вида внешней системы, ключа и признака использования; выбранная строка имеет команды открытия и редактирования. [Описание иллюстрации](../../raw/figures/d79e622ba64a400c69b0a81812e096a4b9030ea82d7b64c3f46501450794fa65-7d100e63f1c67686.md)
7. Когда пользователь Telegram отправит сообщение вашему Telegram-боту, в системе взаимодействия будет создан внешний пользователь, а в разделе **Обсуждения** — новое обсуждение, в котором можно вести переписку:
  
  В системе взаимодействия показано новое обсуждение с внешним пользователем Telegram; в области обсуждения видны участники и переписка. [Описание иллюстрации](../../raw/figures/3ac2066b8a83936918b1f7f677d2d03bcde9635571c688f1d22c6cdab68e1d3a-a965fbf00c0a9dba.md)
  
  Администратор может просматривать обсуждения и распределять их между другими пользователями, добавляя в обсуждение других участников.

> [!NOTE] примечание
> Обратите внимание, что интеграцию нельзя удалить, ее можно только деактивировать. Для этого откройте форму редактирования интеграции и снимите галочку **Использовать интеграцию**. В списке доступных интеграций в колонке **Использование** интеграция будет отображаться как неактивная — без галочки в колонке **Использование**.

## Интеграция с MAX

Система взаимодействия позволяет интегрироваться с мессенджером MAX, чтобы обмениваться сообщениями с пользователями из приложения.

Чтобы реализовать интеграцию с MAX, выполните следующие действия:

1. Подключитесь к платформе «MAX для партнеров» на сайте [https://business.max.ru/](https://business.max.ru/). Создайте организацию ([подробнее](https://dev.max.ru/docs/maxbusiness/connection)) и бота ([подробнее](https://dev.max.ru/docs/chatbots/bots-create)). После модерации вы получите токен для подключения внешней системы.
2. [Зарегистрируйте](register-application-in-collaboration-system-4a6e06152ce5.md) свое приложение в системе взаимодействия.
3. В среде разработки добавьте форму `ФормаИнтеграцийСистемыВзаимодействия`:
  
  ```yaml
  ВидЭлемента: ФрагментКомандногоИнтерфейса
  Ид: 5b285b5b-d0b2-451e-bdaf-e85f2df9e02b
  Имя: Интеграции
  ОбластьВидимости: ВПодсистеме
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Представление: Интеграции
          Имя: Интеграции
          ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
  ```
  
  С ее помощью вы сможете создавать, копировать и редактировать интеграции системы взаимодействия.
4. Откройте приложение, в которое вы добавили форму для создания интеграций, и перейдите на эту форму. Нажмите кнопку **+ Добавить интеграцию**. Укажите имя и наименование ключа интеграции. В поле **Вид интеграции** выберите **MAX**. На вкладке **Параметры** введите токен, полученный в личном кабинете:
  
  Форма интеграции MAX: имя, вид интеграции MAX, ключ, флажок использования, навигационная ссылка подключения и выбор участников по умолчанию; токен вводится на вкладке параметров. [Описание иллюстрации](../../raw/figures/f3294fcb3647a90de8ec4a15d5022a6130421ca9f1cde837b64f8acda0a69283-c90ed672e0f5d6f1.md)
  
  > [!NOTE] примечание
  > Токен должен быть уникален среди всех информационных баз, зарегистрированных в используемом сервере взаимодействия. Другими словами, один бот MAX не может быть подключен к разным информационным базам одного сервера взаимодействия.

  В форме «Пользователи системы взаимодействия» отмечены пользователи «admin» и «fedotov»; «ilyin» не отмечен. [Описание иллюстрации](../../raw/figures/0845b3605b4aa973cca6f4dd668e776e1ad6a6a49c1b7c0099ea57f69b9ae87a-67085085dfc2212f.md)
  
  Все выбранные участники смогут взаимодействовать с пользователем MAX от одного лица.

## Интеграция с ВКонтакте

Механизм взаимодействия позволяет интегрироваться с социальной сетью ВКонтакте (VK), чтобы обмениваться сообщениями с пользователями сообщества из приложения.

Чтобы реализовать интеграцию с ВКонтакте, выполните следующие действия:

1. Для настройки интеграции пользователь, выполняющий действия в веб-интерфейсе ВКонтакте, должен обладать правами администратора сообщества. На сайте [https://vk.com](https://vk.com) перейдите на страницу управления выбранным сообществом или создайте новое сообщество. Затем:
  
  - Перейдите на страницу
    
    Управление → Настройки → Работа с API → Ключи доступа
    
    , нажмите
    
    Создать ключ
    
    и установите флаги:
    
    - Разрешить приложению доступ к управлению сообществом
      
      ,
    - Разрешить приложению доступ к сообщениям сообщества
      
      ,
    - Разрешить приложению доступ к документам
      
      .
  - Сохраните созданный ключ доступа — он потребуется для настройки интеграции.
  - Перейдите на страницу
    
    Управление → Настройки → Работа с API → Callback API
    
    и найдите текст вида
    
    `{"type": "confirmation", "group_id": 123456789}`
    
    . Число
    
    `123456789`
    
    — идентификатор группы, который нужно сохранить.
  - Перейдите на страницу
    
    Управление → Настройки → Сообщения
    
    , установите параметр
    
    Сообщения сообщества
    
    в значение
    
    Включено
    
    и нажмите
    
    Сохранить
    
    .
2. [Зарегистрируйте](register-application-in-collaboration-system-4a6e06152ce5.md) свое приложение в системе взаимодействия.
3. В среде разработки добавьте форму `ФормаИнтеграцийСистемыВзаимодействия`:

  ```yaml
  ВидЭлемента: ФрагментКомандногоИнтерфейса

  Имя: Интеграции
  ОбластьВидимости: ВПодсистеме
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Представление: Интеграции
          Имя: Интеграции
          ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
  ```
  
  С ее помощью вы сможете создавать, копировать и редактировать интеграции системы взаимодействия.
4. Откройте приложение, в которое вы добавили форму для создания интеграций, и перейдите на эту форму. Нажмите кнопку **+ Добавить интеграцию**. Укажите имя и наименование ключа интеграции. В поле **Вид интеграции** выберите **VK**. На вкладке **Параметры** введите идентификатор группы и ключ доступа, полученные в сообществе ВКонтакте:
  
  Форма создания интеграции ВКонтакте: вид интеграции VK, имя и наименование ключа, включение интеграции, параметры идентификатора группы и ключа доступа. [Описание иллюстрации](../../raw/figures/3c93564b7cadccc2c6b242e81426f8910c885daa78d2980d108241b4525a4336-c5337c81e05d43e8.md)

## Интеграция с WhatsApp и шаблоны сообщений

Чтобы реализовать интеграцию с WhatsApp, заключите договор с провайдером WhatsApp Business API — компанией «Девино Телеком» ([подробнее](https://v8.1c.ru/static/instruktsiya-po-podklyucheniyu-k-whatsapp-business-api/)). После заключения договора вы получите токен для подключения внешней системы и имя канала WhatsApp.
2. [Зарегистрируйте](register-application-in-collaboration-system-4a6e06152ce5.md) свое приложение в системе взаимодействия.
3. В среде разработки добавьте форму `ФормаИнтеграцийСистемыВзаимодействия`:
  
  ```yaml
  ВидЭлемента: ФрагментКомандногоИнтерфейса
  Ид: 5b285b5b-d0b2-451e-bdaf-e85f2df9e02b
  Имя: Интеграции
  ОбластьВидимости: ВПодсистеме
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Представление: Интеграции
          Имя: Интеграции
          ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
  ```
  
  С ее помощью вы сможете создавать, копировать и редактировать интеграции системы взаимодействия.
4. Откройте приложение, в которое вы добавили форму для создания интеграций, и перейдите на эту форму. Нажмите кнопку **+ Добавить интеграцию**. Укажите имя и наименование ключа интеграции. В поле **Вид интеграции** выберите **WhatsApp**. На вкладке **Параметры** введите токен и имя канала, полученные от провайдера:
  
  Форма интеграции WhatsApp: имя интеграции, вид провайдера WhatsApp, ключ интеграции, флажок использования, навигационная ссылка подключения и выбор участников обсуждения; параметры провайдера задаются на отдельной вкладке. [Описание иллюстрации](../../raw/figures/d797ca080a3ba77e266af59a6f05fb777b64ee734f3e4a5921b322b3a7ba3844-bb051ae0c1631f37.md)
5. Выберите участников обсуждения:
  
  В форме «Пользователи системы взаимодействия» отмечены пользователи «admin» и «fedotov»; «ilyin» не отмечен. [Описание иллюстрации](../../raw/figures/0845b3605b4aa973cca6f4dd668e776e1ad6a6a49c1b7c0099ea57f69b9ae87a-67085085dfc2212f.md)
  
  Все выбранные участники смогут взаимодействовать с пользователем WhatsApp от одного лица.
6. Нажмите кнопку **Сохранить и закрыть**. Интеграция должна появиться в списке доступных интеграций.

### Использование шаблонных сообщений

Инициировать общение с пользователем через WhatsApp можно только с помощью шаблонных сообщений. Кроме того, если с момента получения последнего сообщения пользователя прошло более 24 часов, то вы также можете отправить ему только шаблонное сообщение.

Шаблоны сообщений — это заранее подготовленные тексты сообщений, одобренные провайдером, которые используются для быстрого ответа или отправки информации. Они позволяют сэкономить время и обеспечить единообразие в коммуникации. Вы можете использовать шаблоны, чтобы отправлять ответы на часто задаваемые вопросы, приветствия, уведомления о заказах или акциях и т. д. Шаблоны могут включать параметры, например имя клиента или детали заказа.

При создании интеграции вида **WhatsApp Devino** в форме `ФормаИнтеграцийСистемыВзаимодействия` доступна вкладка **Шаблоны сообщения**, где отображаются доступные для данной интеграции шаблоны. Вы можете выбрать отдельный шаблон, задать его название и заполнить представления параметров.

В форме «Интеграция» открыта вкладка «Шаблоны сообщения». [Описание иллюстрации](../../raw/figures/027ce7eb63dbd47677b7b95484797d3a5cd3ca82e4f3abb9e3558706054ad5b5-c59fa02293003002.md)

Окно «Шаблонное сообщение»: выпадающий список Шаблон содержит «Статус обращения». [Описание иллюстрации](../../raw/figures/25339b80900b368ab10e051d64cdc627a4f536f3c6e86399b5fdec002ab027eb-0e3e103d928d3788.md)

Шаблонное сообщение и его параметры актуальны только на момент создания сообщения. После того как шаблонное сообщение добавлено, оно регистрируется на сервере системы взаимодействия как обычное сообщение, в котором текст сформирован путем добавления значений параметров в текст шаблона.

Шаблоны сообщений для WhatsApp описываются объектом [`ШаблонСообщенияВзаимодействия`](collaborationmessagetemplate-ru-2bb580725d76.md). Для него можно задать следующие свойства:

- [`Ид`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — идентификатор шаблона сообщения в системе взаимодействия;
- [`ИдИнтеграции`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — идентификатор интеграции, к которой относится шаблон сообщения;
- [`Имя`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — имя шаблона;
- [`ПредставленияПараметров`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — список представлений параметров в тексте шаблона;
- [`Представление`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — представление шаблона;
- [`Шаблон`](collaborationmessagetemplate-ru-2bb580725d76.md)
  
  — шаблон сообщения.

Для работы с шаблонами сообщений в коде используются такие методы типа [`СистемаВзаимодействия`](collaborationsystem-ru-51561bd68a2c.md), как:

- [`ПолучитьШаблоныСообщения()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — для интеграции с WhatsApp возвращает список шаблонов сообщений, для остальных интеграция возвращает пустой массив;
- [`НайтиШаблонСообщения()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — выполняет поиск шаблона сообщения по его идентификатору;
- [`УстановитьПредставлениеШаблонаСообщения()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — устанавливает представление шаблона и представление его параметров:
- [`СоздатьОбсуждениеСВнешнимПользователем()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — создает обсуждение с пользователем внешней системы;
- [`СоздатьСообщениеПоШаблону()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — создает сообщение по шаблону;
- [`ПолучитьВремяОкончанияДоступностиОтвета()`](collaborationsystem-ru-51561bd68a2c.md)
  
  — для интеграции типа WhatsApp получает время окончания 24-часового периода для ответа.

Примеры:

Получение шаблонов сообщений из интеграций с WhatsApp

```xbsl
метод ПолучитьШаблоныСообщенийИнтеграцийWhatsApp(): Массив<ШаблонСообщенияВзаимодействия>
    пер СписокИнтеграций = СистемаВзаимодействия.ПолучитьИнтеграции()
    пер Результат = новый Массив<ШаблонСообщенияВзаимодействия>()
    для Интеграция из СписокИнтеграций
        если Интеграция.ВидВнешнейСистемы == "WhatsApp Devino"
            пер ВсеШаблоны = СистемаВзаимодействия.ПолучитьШаблоныСообщения(ИдИнтеграции = Интеграция.Ид)
            для Шаблон из ВсеШаблоны
                Результат.Добавить(Шаблон)
            ;
        ;
    ;
    возврат Результат
;
```

Установка представления шаблона сообщения

```xbsl
метод УстановитьПредставлениеШаблонаСообщения()
    СистемаВзаимодействия.УстановитьПредставлениеШаблонаСообщения(
        Ууид{af70dc7b-ac92-4437-a522-e17f60deb68f},
        "Приветствие",
        ["Имя человека"])
;
```

## Интеграция с WebChat

Механизм веб-чата позволяет взаимодействовать с пользователем непосредственно из приложения ([подробнее](../project/web-chat-2bc4685d79ff.md)).

Чтобы реализовать интеграцию с WebChat, выполните следующие действия:

1. [Зарегистрируйте](register-application-in-collaboration-system-4a6e06152ce5.md) свое приложение в системе взаимодействия.
2. В среде разработки добавьте форму `ФормаИнтеграцийСистемыВзаимодействия`:
  
  ```yaml
  ВидЭлемента: ФрагментКомандногоИнтерфейса
  Ид: 5b285b5b-d0b2-451e-bdaf-e85f2df9e02b
  Имя: Интеграции
  ОбластьВидимости: ВПодсистеме
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Представление: Интеграции
          Имя: Интеграции
          ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
  ```
  
  С ее помощью вы сможете создавать, копировать и редактировать интеграции системы взаимодействия.
3. Запустите приложение и откройте форму для создания интеграций. Нажмите кнопку **+ Добавить интеграцию**. Введите имя и ключ интеграции. В поле **Вид интеграции** выберите **WebChat**. Добавьте пользователей системы взаимодействия.
4. На вкладке **Параметры** вы можете изменить настройки отображения веб-чата. Нажмите на кнопку с круглой стрелкой, чтобы сгенерировать ключ подписи:
  
  Кнопка для генерации ключа подписи [Описание иллюстрации](../../raw/figures/8c94bc5cba7bc3b1e47c38dea545cd38f2a2a9ad1ea925ed04e9389f631bbdc7-cf7aa41a1ccc038f.md)
  
  Сохраните ключ и нажмите **Сохранить и закрыть**.
5. Созданная интеграция отобразится в списке доступных интеграций системы взаимодействия. Откройте ее еще раз. На вкладке **Описание** скопируйте и сохраните сгенерированную навигационную ссылку точки подключения:
  
  В форме интеграции WebChat на вкладке описания показана сгенерированная навигационная ссылка точки подключения с кнопкой копирования. [Описание иллюстрации](../../raw/figures/f468cebd044d910854f1fad34812861f63aa5ff53261c35555dc7b6b42af9fad-d760dca37e7b113c.md)
  
  Ключ и ссылка понадобятся вам, чтобы добавить веб-чат в приложение ([подробнее](../project/web-chat-2bc4685d79ff.md)).

## Работа с интеграциями в коде

В «1С:Предприятие.Элементе» свойства и методы отдельной интеграции системы взаимодействия с внешним подключением описываются типом [`ИнтеграцияВзаимодействия`](collaborationintegration-ru-8cf90bee94d3.md).

### Получение информации о внешних системах

Чтобы получить типы внешних систем, поддерживаемых сервером взаимодействия, используйте метод [`ПолучитьВидыВнешнихСистем()`](collaborationsystem-ru-51561bd68a2c.md), который возвращает читаемый массив строк с названием поддерживаемых систем:

```xbsl
метод ПолучитьВидыВнешнихСистем(): ЧитаемыйМассив<Строка>
    возврат СистемаВзаимодействия.ПолучитьВидыВнешнихСистем()
    // Виды: [WebChat, Telegram, VK, MAX, Webhook, WhatsApp Devino]
;
```

С помощью метода [`ПолучитьОписаниеВнешнейСистемы()`](collaborationsystem-ru-51561bd68a2c.md) вы можете получить объект типа [`ОписаниеВнешнейСистемыВзаимодействия`](externalcollaborationsystemdescription-ru-6c1f235070df.md) с двумя свойствами:

- [`ВидВнешнейСистемы`](externalcollaborationsystemdescription-ru-6c1f235070df.md)
  
  — строка с названием описываемой внешней системы;
- [`ОписанияПараметров`](externalcollaborationsystemdescription-ru-6c1f235070df.md)
  
  — массив объектов типа
  
  [`ОписаниеПараметраВнешнейСистемыВзаимодействия`](externalcollaborationsystemparameterdescription-ru-80c4d8287922.md)
  
  с именем параметра и признаком обязательности.

```xbsl
метод ПолучитьОписаниеВнешнейСистемы(): ОписаниеВнешнейСистемыВзаимодействия?
    возврат СистемаВзаимодействия.ПолучитьОписаниеВнешнейСистемы("Telegram")
    // ВидВнешнейСистемы: Telegram
    // ОписаниеПараметров:
    //     Имя: token
    //     Обязательный: Истина
;
```

### Создание интеграций

Методы для работы с интеграциями содержатся в типе `СистемаВзаимодействия` пространства имен `Стд::СистемаВзаимодействия`:

- `СоздатьИнтеграцию()`
  
  ,
- `РедактироватьИнтеграцию()`
  
  ,
- `ПолучитьИнтеграции()`
  
  .

Пример создания интеграций с Telegram и WebChat

```xbsl
метод СоздатьИнтеграциюСТелеграм(КлючИнтеграции: Строка, Токен: Строка)
    пер ПараметрыИнтеграции = <Строка, Строка>{:}
    ПараметрыИнтеграции.Вставить("token", Токен)

    СоздатьИнтеграцию("Telegram", КлючИнтеграции, ПараметрыИнтеграции)
;

метод СоздатьИнтеграциюСВебЧатом(КлючИнтеграции: Строка, Заголовок: Строка): Ууид
    пер ПараметрыИнтеграции = <Строка, Строка>{:}
    ПараметрыИнтеграции.Вставить("allowVideoconferences", "allowed")
    ПараметрыИнтеграции.Вставить("colorTheme", "auto")
    ПараметрыИнтеграции.Вставить("defaultApplicationUserCameraState", "on")
    ПараметрыИнтеграции.Вставить("displayUserPictures", "true")
    ПараметрыИнтеграции.Вставить("languageCode", "en")
    ПараметрыИнтеграции.Вставить("mobileButtonOrientation", "rightBottom")
    ПараметрыИнтеграции.Вставить("orientation", "bottom")
    ПараметрыИнтеграции.Вставить("orientationPadding", "100")
    ПараметрыИнтеграции.Вставить("signKey", "")
    ПараметрыИнтеграции.Вставить("titleBackColor", "#FBED9E")
    ПараметрыИнтеграции.Вставить("titleText", Заголовок)
    ПараметрыИнтеграции.Вставить("titleTextColor", "#333333")

    возврат СоздатьИнтеграцию("WebChat", КлючИнтеграции, ПараметрыИнтеграции)
;

метод СоздатьИнтеграцию(ТипВнешнейСистемы: Строка, КлючИнтеграции: Строка, ПараметрыИнтеграции: ЧитаемоеСоответствие<Строка, Строка>): Ууид
    пер ОписаниеСистемы: ОписаниеВнешнейСистемыВзаимодействия = СистемаВзаимодействия.ПолучитьОписаниеВнешнейСистемы(ТипВнешнейСистемы)

    знч Пользователь = СистемаВзаимодействия.ПолучитьТекущегоПользователяВзаимодействия()
    пер УчастникиОбсуждения = [Пользователь.Ид]

    пер НазваниеИнтеграции = "Интеграция_WebChat"
    пер Таймаут = 30с

    пер НоваяИнтеграцияИд: Ууид? = СистемаВзаимодействия.СоздатьИнтеграцию(
        НазваниеИнтеграции,
        ОписаниеСистемы.ВидВнешнейСистемы,
        ПараметрыИнтеграции,
        УчастникиОбсуждения,
        КлючИнтеграции,
        Истина,
        Таймаут)

    возврат НоваяИнтеграцияИд
;
```
