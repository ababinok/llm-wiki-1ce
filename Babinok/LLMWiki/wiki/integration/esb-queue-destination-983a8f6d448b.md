## Обзор

Узел этого вида передает сообщения информационной системе SAP NetWeaver Process Integration.

## Документированный контракт и примеры

Узел этого вида передает сообщения информационной системе SAP NetWeaver Process Integration. Типом исходящего сообщения будет являться *Байтовое сообщение* (*BytesMessage*).

ОчередьШиныНазначение [Описание иллюстрации](../../raw/figures/92afd2ad86bacf2a046a1474394c5c3213778a92bac4d23d174c92986b3b4e39-62b92cc92aa5659b.md)

Узел может быть как связан с [группой участников](../project/participant-groups-93f2250d5853.md), так и использоваться самостоятельно.

## Свойства узла

### Имя

Имя узла, уникальное в рамках процесса интеграции. Используется для обращения к узлу в коде (`УзелСхемыИнтеграции`.`Имя`). Имя узла используется в сгенерированном имени очереди для внешнего подключения. Должно начинаться с буквы, за которой следуют буквы, цифры или символы '_' (нижнее подчеркивание). Минимальная длина — 2 символа

### ИмяПользователя

Имя пользователя для подключения внешним клиентом. Источником значения могут выступать:

- Константа
- Параметр процесса интеграции
- Свойство участника (если узел связан с группой участников)

### ОбновлениеМетрик

Обработчик, внутри которого можно обновлять метрики, добавленные в проект разработчиком. Пример:

```xbsl
// Разработчик добавил в проект метрику «РазмерФайлов». Тогда обновить метрику в узлах можно следующим образом:
метод ОбновлениеМетрик(Контекст: МойПроцессИнтеграции.КонтекстВызова, Сообщение: МойПроцессИнтеграции.Сообщение)
    пер РазмерФайлов = МойПроцессИнтеграции.Метрики["РазмерФайлов"]
    РазмерФайлов.Обновить(Сообщение.УзлыПути.Текущий.Узел.Имя, 1)
;
```

### Описание

Произвольное описание узла для разработчика. Используется при редактировании схемы процесса интеграции. Недоступно из кода

### Пароль

Пароль для подключения внешним клиентом (скрытое значение). Источником значения могут выступать:

- Константа
- Параметр процесса интеграции
- Свойство участника (если узел связан с группой участников)

## Пример использования

**Контекст:** Осуществляется отправка сообщения из системы «1С» в систему SAP PI.

**Задача:** Отправить сообщение из «1С:Предприятие.Элемента» в SAP PI.

**Решение:** Сообщение будет приходить в «1С:Предприятие.Элемент» от участника из [группы](../project/participant-groups-93f2250d5853.md) «Отправитель» и попадать в узел [Канал1СИсточник](channel-1c-source-ddb853b7d45d.md) («ИзОфиса»). Далее используем узел вида **ОчередьШиныНазначение** («ВСистемуSAP»), чтобы создать в «1С:Предприятие.Элементе» очередь, к которой впоследствии подключится внешняя информационная система и из которой будет считывать сообщения. На последнем шаге сообщение из узла [Канал1СИсточник](channel-1c-source-ddb853b7d45d.md) будет передано в узел «ВСистемуSAP», где будет сохранено в очереди сообщений «1С:Предприятие.Элемента», из которой впоследствии будет считано внешней информационной системой, выступающей в роли получателя.

Схема ОчередьШиныНазначение: группа «Офис» → Канал1СИсточник «ИзОфиса» → «ВСистемуSAP». Последний узел создаёт очередь, из которой внешний получатель впоследствии считывает сообщения.
