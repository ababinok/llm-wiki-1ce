## Обзор

На этом этапе вы добавите в каждую из информационных баз объект конфигурации вида **Сервис интеграции**.

## Документированный контракт и примеры

На этом этапе вы добавите в каждую из информационных баз объект конфигурации вида **Сервис интеграции**.

## Информационная база «Офис»

- Запустите конфигуратор информационной базы **Офис**.
- Добавьте сервис интеграции с именем **СервисОфиса**:
  
  В конфигурации базы «Офис» в ветке «Сервисы интеграции» добавлен «СервисОфиса». [Описание иллюстрации](../../raw/figures/ed50b369bc5394ccb99b05cdc5bb9f52d59f8434893c6d9bc21d2d9067b17434-ecc939a735e46389.md)
- [Откройте](../project/open-or-restart-application-2d42f8a2392d.md) приложение «1С:Предприятие.Элемента» в браузере и скопируйте адрес приложения:
  
  Копирование адреса приложения в браузере [Описание иллюстрации](../../raw/figures/bafe499cdd37e890cedca9847530228dbf2fda0244159264e9821fb77e064518-e6688ec92c8940d9.md)
- Вернитесь в конфигуратор и установите скопированный адрес в качестве значения свойства **Адрес внешнего сервиса интеграции**:
  
  В конфигураторе внешнего сервиса интеграции в поле «Адрес внешнего сервиса интеграции» вставлен адрес опубликованного приложения. [Описание иллюстрации](../../raw/figures/41fbde42f5cc7ccb3824ca11893f3af63caf34d07d12bece834b846da3be6e4b-99c6b1d37803e514.md)

## Информационная база «Магазин»

В информационной базе **Магазин** аналогичным образом создайте сервис интеграции с именем **СервисМагазина**. Установите для него тот же адрес внешнего сервиса интеграции.
