## Методы

### Выгрузить

`Доступность: Сервер`

```
Выгрузить(): ДвоичныйОбъект.Ссылка
```

Выгружает тело сообщения в виде архива, который содержит тело сообщения и его параметры. Возвращает бинарную ссылку на архив.

---

### ОтправитьВ

`Доступность: Сервер`

```
ОтправитьВ(node: УзелСхемыИнтеграции)
```

Отправить сообщение из канала в указанный узел. Нельзя отправить сообщение в узел-источник.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - указан узел, не принадлежащий схеме, или узел-источник.

---

### ПолучитьИсториюДвижений

`Доступность: КлиентИСервер`

```
ПолучитьИсториюДвижений(): ЧитаемыйМассив<ДвижениеСообщенияИнтеграции>
```

Получить историю перемещения сообщения по графу процесса интеграции.

---

### ПолучитьСообщение

`Доступность: Сервер`

```
ПолучитьСообщение(): СообщениеИнтеграции
```

Сообщение, которое не было доставлено

---

### Представление

`Доступность: КлиентИСервер`

```
Представление(): Строка
```

Возвращает пользовательское представление сообщения.

---

### Удалить

`Доступность: Сервер`

```
Удалить()
```

Удалить сообщение из канала недоставленных
