## Обзор

Узел этого вида получает файлы из указанного каталога.

## Документированный контракт и примеры

Узел этого вида получает файлы из указанного каталога. Тело сообщения формируется из одного или из нескольких файлов. В заголовок сообщения дописываются параметры, специфичные для файлов.

> [!WARNING] важно
> При работе с файлами может возникнуть ситуация, когда узел **ФайлИсточник** реагирует на изменение файла до того, как это изменение завершилось. Обычно такое случается при работе с большими файлами или при медленной записи. Это происходит потому, что узел **ФайлИсточник** несколько раз в секунду контролирует указанные ему каталоги и/или файлы и генерирует сообщения при изменении даты или размера файла. В результате может быть сгенерировано больше одного сообщения до завершения записи в файл. Вы можете узнать о решении данной проблемы в соответствующей [статье](integration-process-multiple-messages-are-created-when-file--5bb65d9754bb.md) раздела **Проблемы**.

#### ДействиеПослеЧтения

```yaml
ДействиеПослеЧтения: ДействиеПослеЧтения
```

Указывает, что сделает «1С:Предприятие.Элемент» с файлом сообщения после чтения. Принимает значения перечисления [ДействиеПослеЧтения](afterreadaction-ru-d489572a6de4.md):

- **Переместить**: «1С:Предприятие.Элемент» переместит файл сообщения. Новый путь к файлу определяется значением свойства [ИмяПослеЧтения](filesource-ru-5279f8af1efd.md) и результатом обработки события [ВыборИмениПослеЧтения](filesource-ru-5279f8af1efd.md).
- **Удалить**: «1С:Предприятие.Элемент» удалит файл сообщения.
- **Сохранить**: «1С:Предприятие.Элемент» сохранит файл сообщения на месте. «1С:Предприятие.Элемент» вычислит для него идемпотентный ключ, который содержит полный путь к файлу, размер файла и момент модификации файла с точностью до секунд.
  
  «1С:Предприятие.Элемент» повторно обработает этот файл, только если изменится ключ этого файла, например, в этот файл будет что-то дописано или файл будет перезаписан целиком ([подробнее](../project/retrieve-message-from-file-6152df025666.md)).

#### ИскатьВКаталогеРекурсивно

```yaml
ИскатьВКаталогеРекурсивно: ВычисляемоеВыражение|Булево
```

Если значение свойства равно **Ложь**, то «1С:Предприятие.Элемент» будет искать файлы сообщений только в указанном каталоге. Иначе поиск будет осуществляться и во всех вложенных каталогах с учетом свойств [МаскаВключенияФайлов](filesource-ru-5279f8af1efd.md) и [МаскаИсключенияФайлов](filesource-ru-5279f8af1efd.md) ([подробнее](../project/retrieve-message-from-file-6152df025666.md)).

#### ИмяФайла

```yaml
ИмяФайла: ВычисляемоеВыражение|Строка
```

---

#### ИспользоватьИмяФайлаБезПути

```yaml
ИспользоватьИмяФайлаБезПути: ВычисляемоеВыражение|Булево
```

Если при чтении файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу и включит в сообщение только имя файла. Иначе «1С:Предприятие.Элемент» включит в сообщение путь относительно значения свойства **Каталог**.

Если при записи файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу из сообщения и запишет файл в каталог, указанный в свойстве **Каталог**. Иначе «1С:Предприятие.Элемент» запишет файл в каталог, вложенный в **Каталог**. Имя вложенного каталога будет определено из сообщения.

### События

#### ВыборИмени

```yaml
ВыборИмени: Строка
```

Обработчик, позволяющий переопределить имя файла сообщения, который будет искать «1С:Предприятие.Элемент». Обработчик должен вернуть новое имя файла. Если заполнено свойство [ИмяФайла](filesource-ru-5279f8af1efd.md) и указан обработчик **ВыборИмени**, то имя файла берется из обработчика. В случае ошибки в обработчике имя файла будет взято из свойства [ИмяФайла](filesource-ru-5279f8af1efd.md).

---

#### ВыборИмениПослеЧтения

```yaml
ВыборИмениПослеЧтения: Строка
```

Обработчик, позволяющий переопределить имя файла, которое он будет иметь после чтения «1С:Предприятие.Элементом». Обработчик должен вернуть новое имя файла ([подробнее](../project/retrieve-message-from-file-6152df025666.md)). Если заполнено свойство [ИмяПослеЧтения](filesource-ru-5279f8af1efd.md) и указан обработчик **ВыборИмениПослеЧтения**, то имя файла берется из обработчика. В случае ошибки в обработчике имя файла будет взято из свойства [ИмяПослеЧтения](filesource-ru-5279f8af1efd.md).

---

```yaml
ОбновлениеМетрик: Строка
```

Обработчик, внутри которого можно обновлять метрики, добавленные в проект разработчиком.
