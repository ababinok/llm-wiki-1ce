## Конструкторы

### ВыражениеXPath

`Доступность: Сервер`

```
ВыражениеXPath(
  Значение: Строка,
  ПрефиксыПространствИмен: ЧитаемоеСоответствие<Строка, Строка>? = Неопределено)
```

Конструктор выражения XPath

- Значение
  
  - строка с выражением XPath, имя параметра в строке должно передаваться с префиксом $
- ПрефиксыПространствИмен
  
  - соответствие
  
  Префикс
  
  -
  
  Пространство имен
  
  , по умолчанию
  
  `Неопределено`

**Описание синтаксиса**

- [XPath 1.0](https://www.w3.org/TR/1999/REC-xpath-19991116/)
- [XPath 3.1](https://www.w3.org/TR/xpath-31/)

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если в выражении используется префикс, но он отсутствует в `ПрефиксыПространствИмен`

## Свойства

### Значение

`Доступность: Сервер` `ТолькоЧтение`

```
Значение: Строка
```

Строковое значение выражения XPath.

---

### ПрефиксыПространствИмен

`Доступность: Сервер` `ТолькоЧтение`

```
ПрефиксыПространствИмен: ЧитаемоеСоответствие<Строка, Строка>?
```

Соответствие *Префикс* - *Пространство имен*, обязательно для заполнения в для выражением с использованием пространств имен, в том числе пространства имен по умолчанию. Значение по умолчанию - `Неопределено`
