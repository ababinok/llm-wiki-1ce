## Свойства узла

### Имя

Имя узла, уникальное в рамках процесса интеграции. Используется для обращения к узлу в коде (`УзелСхемыИнтеграции.Имя`). Должно начинаться с буквы, за которой следуют буквы, цифры или символы '_' (нижнее подчеркивание). Минимальная длина — 2 символа.

### Описание

Произвольное описание узла для разработчика. Используется при редактировании схемы процесса интеграции. Недоступно из кода.

## Пример использования

**Контекст:** Есть каталог **D:\Источник**, который контролируется на предмет появления в нем файлов. Как только файл появляется, формируется сообщение и отправляется всем участникам интеграции. Также каждая из систем, которая участвует в обмене, с определенной регулярностью отправляет сообщение, которое записывается в файл в каталог **Z:\Назначение**.

**Задача:** Объединить участников процесса интеграции, с которыми «1С:Предприятие.Элемент» взаимодействует однотипно, в единую группу для удобства построения схемы интеграции.

**Решение:** Используем узел [ФайлИсточник](file-source-6a2c5cde7609.md), чтобы контролировать каталог **D:\Источник** на предмет появления новых файлов. Как только файл появляется, формируется сообщение и отправляется в [Канал1СНазначение](channel-1c-destination-3c02e5ef031f.md). Из [Канала1СНазначение](channel-1c-destination-3c02e5ef031f.md) это сообщение получается всеми информационными системами, включенными в группу **Участники**. Чтобы отправить сообщение от участников, используем узел [Канал1СИсточник](channel-1c-source-ddb853b7d45d.md) и соединим группу участников связью с этим узлом. Из узла [Канал1СИсточник](channel-1c-source-ddb853b7d45d.md) сообщение попадает в узел [ФайлНазначение](file-destination-d85acc8e8f96.md), где записывается в каталог **Z:\Назначение**.

В момент старта процесса интеграции «1С:Предприятие.Элемент» проанализирует схему и для каждой информационной системы из группы «Участники» создаст одну очередь, соответствующую узлу [Канал1СНазначение](channel-1c-destination-3c02e5ef031f.md), и одну очередь, соответствующую узлу [Канал1СИсточник](channel-1c-source-ddb853b7d45d.md). К этим двум очередям будет иметь доступ только та информационная система, для которой эта очередь была создана.
