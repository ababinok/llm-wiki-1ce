## Примеры

**Общие примеры**

Перехват исключения соединения с сервером взаимодействия при отправке сообщения:

```xbsl
метод ПоприветствоватьПользователяВСистемеВзаимодействия(
    ИдОбсуждения: Ууид = Ууид{eb649265-60f3-4ea4-978a-5ef6c7b9454c}, 
    ИдПолучателя: Ууид = Ууид{44dc66df-e836-40e9-bb83-4ac0212f5f38}
)
    попытка
        знч МассивПолучателейСообщения: ЧитаемыйМассив<Ууид> =
            [СистемаВзаимодействия.ПолучитьИдТекущегоПользователяВзаимодействия(), ИдПолучателя]

        знч ТекстСообщения = "Привет, пользователь!"
        СистемаВзаимодействия.СоздатьСообщение(
            ИдОбсуждения,
            МассивПолучателейСообщения,
            ТекстСообщения)
    поймать Исключение: ИсключениеСоединенияСистемыВзаимодействия
        ОтложитьОтправкуСообщенияПриветствия(ИдПолучателя)
    ;
;

метод ОтложитьОтправкуСообщенияПриветствия(ИдПолучателя: Ууид)
    // логика отложенной отправки   
;
```
