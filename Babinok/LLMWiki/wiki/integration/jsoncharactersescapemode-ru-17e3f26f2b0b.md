## Свойства

### Отсутствует

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Отсутствует
```

Не экранировать символы.

---

### СимволыВнеAscii

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
СимволыВнеAscii
```

Экранировать символы, не входящие в кодировку ASCII.

---

### СимволыВнеBmp

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
СимволыВнеBmp
```

Экранировать символы, которые в UTF-16 будут представлены "суррогатной парой" (двумя символами UTF-16).
