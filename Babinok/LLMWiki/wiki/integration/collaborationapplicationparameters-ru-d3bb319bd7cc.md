## Конструкторы

### ПараметрыПриложенияВзаимодействия

`Доступность: Сервер`

```
ПараметрыПриложенияВзаимодействия()
```

Создает параметры приложения системы взаимодействия по умолчанию.

**Перегрузка** [ПараметрыПриложенияВзаимодействия(ИдПриложения: Ууид, ОткрытыйКлюч: Строка)](collaborationapplicationparameters-ru-d3bb319bd7cc.md)

---

### ПараметрыПриложенияВзаимодействия

`Доступность: Сервер`

```
ПараметрыПриложенияВзаимодействия(
  ИдПриложения: Ууид,
  ОткрытыйКлюч: Строка)
```

Создает параметры приложения системы взаимодействия с идентификатором

`ИдПриложения`

и открытым ключом

`ОткрытыйКлюч`

.

**Перегрузка** [ПараметрыПриложенияВзаимодействия()](collaborationapplicationparameters-ru-d3bb319bd7cc.md)

`Доступность: Сервер`

```
ИдПриложения: Ууид
```

---

### ОткрытыйКлюч

`Доступность: Сервер`

```
ОткрытыйКлюч: Строка

`Доступность: Сервер`

```

`{%ИдентификаторПриложения, %ОткрытыйКлюч}`
