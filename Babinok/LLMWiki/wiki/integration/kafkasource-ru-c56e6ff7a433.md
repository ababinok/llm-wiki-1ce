## Обзор

Узел этого вида является клиентом-потребителем, предназначенным для чтения входящих в «1С:Предприятие.Элемент» сообщений из брокера Apache Kafka.

## Документированный контракт и примеры

Узел этого вида является клиентом-потребителем, предназначенным для чтения входящих в «1С:Предприятие.Элемент» сообщений из брокера Apache Kafka.

Узел может быть как связан с [группой участников](../project/participant-groups-93f2250d5853.md), так и использоваться самостоятельно.

```yaml
Порт: ВычисляемоеВыражение|Число
```

Параметр Kafka: `bootstrap.servers`. Номер порта bootstrap-сервера Kafka для подключения. По умолчанию — 9092.

---

#### ПротоколБезопасности

```yaml
ПротоколБезопасности: PlainText|Ssl|SaslPlainText|SaslSsl
```

Параметр Kafka: `security.protocol`. Протокол безопасности. Возможные значения:

- SaslPlainText
  
  (по умолчанию),
- SaslSsl
  
  ,
- Ssl
  
  ,
- PlainText
  
  .

> [!WARNING] важно
> Протокол безопасности **PlainText** рекомендуется использовать только на этапе разработки и тестирования, так как данный протокол является небезопасным.

---

#### МеханизмSasl

```yaml
МеханизмSasl: МеханизмSasl
```

Параметр Kafka: `sasl.mechanism`. Механизм SASL. Задается значением перечисления [МеханизмSasl](saslmechanism-ru-17e3d1923d49.md). Возможные значения:

- Plain
  
  — значение по умолчанию (будет использоваться модуль
  
  `org.apache.kafka.common.security.plain.PlainLoginModule`
  
  ),
- ScramSha256
  
  (будет использоваться модуль
  
  `org.apache.kafka.common.security.plain.ScramLoginModule`
  
  ),
- ScramSha512
  
  (будет использоваться модуль
  
  `org.apache.kafka.common.security.plain.ScramLoginModule`
  
  ).

#### ИдКлиента

```yaml

```

Параметр Kafka: `client.id`. Логический идентификатор клиента (узла или участника группы участников), который подключается к серверу Kafka.

---

#### Топик

```yaml
Топик: ВычисляемоеВыражение|Строка
```

Имя топика, из которого выполняется передача сообщения. Обязательно для заполнения только в том случае, если не указано имя обработчика [ВыборТопика](kafkadestination-ru-0a2daa6ce1ff.md). Если задан обработчик [ВыборТопика](kafkadestination-ru-0a2daa6ce1ff.md), значение свойства можно оставить пустым. Если при выполнении обработчика [ВыборТопика](kafkadestination-ru-0a2daa6ce1ff.md) произойдет ошибка, то значение будет вычислено из свойства [Топик](kafkadestination-ru-0a2daa6ce1ff.md). Если оно окажется пустым, то будет выброшено исключение обработчика и сообщение не будет доставлено.

```yaml
ИдГруппыПотребителей: ВычисляемоеВыражение|Строка
```

Идентификатор группы потребителей топика. Если не указан, генерируется из метаданных процесса интеграции ([подробнее](collaboration-with-apache-kafka-487d00ac9525.md)).

#### ТаймаутЗапроса

```yaml
ТаймаутЗапроса: ВычисляемоеВыражение|Длительность
```

Параметр Kafka: `request.timeout.ms`. Таймаут запроса, миллисекунды. По умолчанию — 30000.

---

#### АвтоУстановкаСмещения

```yaml
АвтоУстановкаСмещения: АвтоУстановкаСмещения
```

Параметр Kafka: `auto.offset.reset`. Режим установки смещения при изменениях в группе потребителей. Задается значением перечисления [АвтоУстановкаСмещения](autooffsetreset-ru-1776ea84afc4.md). Возможные значения:

- Ранний
  
  (
  
  `earliest`
  
  ) — при добавлении нового потребителя будет браться самое раннее значение офсета для чтения раздела.
- Последний
  
  (
  
  `latest`
  
  ) — при добавлении нового потребителя будет браться последнее подтвержденное значение офсета для чтения раздела. Используется по умолчанию.
- Отсутствует
  
  (
  
  `none`
  
  ) — при добавлении нового потребителя будет выброшена ошибка.

---

#### КоличествоПотребителей

```yaml
КоличествоПотребителей: ВычисляемоеВыражение|Число
```

Количество параллельных потребителей в группе. Группа потребителей — это механизм параллелизации чтения сообщений из топика. Если узел используется самостоятельно, то одна группа потребителей будет соответствовать одному узлу [KafkaИсточник](kafkasource-ru-c56e6ff7a433.md). Если узел связан с группой участников, то одна группа потребителей будет соответствовать одному участнику из группы.

Выбор значения зависит от количества разделов в топике, рекомендуется настраивать количество потребителей равным количеству разделов в топике. Максимальное значение — 5 потребителей. По умолчанию — 1.

---

#### ИнтервалАвтоФиксации

```yaml
ИнтервалАвтоФиксации: ВычисляемоеВыражение|Длительность
```

Параметр Kafka: `auto.commit.interval.ms`. Автофиксация — это режим автоматического подтверждения успешного получения сообщения, в результате которого происходит изменение смещения для потребителя в разделе топика. Данное свойство позволяет задать интервал в миллисекундах, с которым будет происходить автоматическая фиксация. По умолчанию — 5000.

---

#### ТаймаутСессии

```yaml
ТаймаутСессии: ВычисляемоеВыражение|Длительность
```

Параметр Kafka: `session.timeout.ms`. Таймаут сессии, миллисекунды. По умолчанию — 10000.

Клиент периодически посылает брокеру сигналы о своей активности. Если до истечения таймаута сессии брокер не получит ни одного сигнала, то брокер удалит этого клиента из группы и инициирует ребалансировку.

---

#### МаксимальныйРазмерВыборки

```yaml
МаксимальныйРазмерВыборки: ВычисляемоеВыражение|Число
```

Параметр Kafka: `fetch.max.bytes`. Максимальный размер данных в байтах, который сервер Kafka должен вернуть в ответ на запрос. Записи извлекаются потребителем партиями, и если первая партия записей в первом непустом разделе выборки больше этого значения, то эта партия записей все равно будет возвращена, чтобы потребитель мог продвигаться вперед. Таким образом, данное значение не является абсолютным максимумом. Данный параметр позволяет регулировать частоту запросов к серверу Kafka — чем меньше значение, тем большее количество запросов будет необходимо с увеличением количества данных. По умолчанию — 52428800.

---

#### МаксимальныйРазмерВыборкиИзРаздела

```yaml
МаксимальныйРазмерВыборкиИзРаздела: ВычисляемоеВыражение|Число
```

Параметр Kafka: `max.partition.fetch.bytes`. Максимальный размер данных в байтах, который ожидается в выборке из раздела. Запрос будет обработан даже в случае, если фактический размер ответа окажется больше указанного в свойстве значения. По умолчанию — 1048576.

---

#### ДесериализаторЗначения

```yaml
ДесериализаторЗначения: ВидСериализации
```

Параметр Kafka: `value.deserializer`. Десериализатор значения сообщения. Задается значением перечисления [ВидСериализации](serializationkind-ru-b83b7d164e15.md). Возможные значения:

- Байты
  
  — значение по умолчанию (
  
  `org.apache.kafka.common.serialization.ByteArrayDeserializer`
  
  ).
- Строка
  
  (
  
  `org.apache.kafka.common.serialization.StringDeserializer`
  
  с параметром кодировки UTF-8).

---

ДесериализаторКлюча: ВидСериализации

  (
  
  `org.apache.kafka.common.serialization.StringDeserializer`
