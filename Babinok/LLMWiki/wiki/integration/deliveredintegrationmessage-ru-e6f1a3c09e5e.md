```
Ид: Строка
```

### КодУчастника

`Доступность: КлиентИСервер` `ТолькоЧтение`


## Методы

### Выгрузить

`Доступность: Сервер`

```
Выгрузить(ПотокЗаписи: ПотокЗаписи)
```

Записывает в переданный поток информацию о сообщении в виде архива, содержащего в себе тело сообщения и его параметры в виде json.

---

### ОтправитьПовторно

`Доступность: Сервер`

```
ОтправитьПовторно()
```

Отправить сообщение в узел, в который оно было доставлено.

---

### ПолучитьСообщение

`Доступность: Сервер`

```
ПолучитьСообщение(): СообщениеИнтеграции
```

Сообщение, которое было доставлено

---

### Удалить

`Доступность: Сервер`

```
Удалить()
```

Удалить сообщение из хранилища доставленных
