## Документированный контракт и примеры

Тип [`Форматируемое`](../stdlib/formattable-ru-199658dd3e97.md) — это базовый тип, который указывает, что потомок такого типа может сформировать строковое представление хранимых данных с использованием различных форматов.

Для формирования такого представления служит метод `Представление()`. В качестве параметра метода выступает форматная строка. Собственно форматная строка определяется тем типом, значение которого надо представить.
