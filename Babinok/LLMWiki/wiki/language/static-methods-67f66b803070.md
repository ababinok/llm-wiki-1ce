## Обзор

Любой тип, порожденный элементом проекта и имеющий модуль, может иметь статические методы, в том числе перечисления.

## Документированный контракт и примеры

Любой тип, порожденный элементом проекта и имеющий модуль, может иметь статические методы, в том числе перечисления.

Статический метод — это метод, общий для всего типа. Для его обозначения используйте модификатор методов — ключевое слово `статический`. Статические методы не могут использовать контекст объекта и обращения к `этот`.

Статические методы необходимо использовать в том случае, когда нужно [передать исполнение кода](../project/move-execution-from-client-to-server-7c6a7eed7a44.md) с клиента на сервер.

Статические методы можно использовать в тех элементах проекта, которые не имеют типов-одиночек, например в [модуле элемента перечисления](enumeration-name-type-f44bc1348f6f.md), в [модуле компонента](../interface/interface-component-types-b9d0cf747ffb.md), в [модуле структуры](structure-type-0351a6528924.md).

Статический метод может быть вызван из модуля типа без квалификатора типа. Из статического метода нельзя вызывать обычные методы в данном модуле.

Запрещается иметь статический и обычный метод с сигнатурами, имеющими пересечения по типам параметров.

Если тип существует в окружении **Клиент**, то все его серверные методы должны быть статическими.

Аннотация `@ДоступноСКлиента` допускается только на статических методах.
