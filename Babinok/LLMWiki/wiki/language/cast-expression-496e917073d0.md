## Документированный контракт и примеры

Выражение `ВЫРАЗИТЬ` имеет следующий синтаксис:

```xbql
ВЫРАЗИТЬ (базовое-выражение КАК имя-типа [(квалификатор-типа)])
```

В качестве ***квалификатор-типа*** можно задать:

- для типа
  
  `Число`
  
  — <Длина целой части>[, <Длина дробной части>];
- для типа
  
  `Строка`
  
  — <Длина>;
- для типа
  
  `Байты`
  
  — <Длина>.

Если ***квалификатор-типа*** не указан, то сохраняется исходный квалификатор. Если исходного квалификатора не было, то используется неограниченная длина.

Выражение `ВЫРАЗИТЬ` не может приводить несовместимые типы. Например, нельзя привести значение типа `Число` к значению типа `Строка`.

Примеры использования:

- Из значения составного типа сделать значение несоставного типа.
- Из
  
  `Null`
  
  сделать значение любого типа.
- Изменить квалификатор значения (нельзя изменить на неограниченную длину).
