## Документированный контракт и примеры

Лямбда-операция является частью синтаксиса лямбда-выражения и представляет собой группу символов `->`, которая отделяет параметры лямбда-выражения от его тела:

```xbsl
(список_параметров) -> выражение
```

## Пример

Лямбда-выражения можно присваивать в переменные или передавать в методы в качестве параметра:

```xbsl
// В переменную присваивается лямбда-выражение, которое проверяет, является ли число четным
знч ЭтоЧетное = (Число: Число) -> Число % 2 == 0

знч Числа = [10, 15, 20, 25, 30]
// Лямбда-выражение передается в метод для фильтрации элементов массива
знч ЧетныеЧисла = Числа.Фильтровать(ЭтоЧетное) // [10, 20, 30]
```
