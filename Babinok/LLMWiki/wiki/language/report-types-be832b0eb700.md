## Документированный контракт и примеры

После того как вы добавили в проект отчет, «1С:Предприятие.Элемент» создаст несколько типов, имена которых в общем случае выглядят следующим образом:

- `<ИмяОтчета>`
- `<ИмяОтчета>.АвтоматическаяФорма`
- `<ИмяОтчета>.Открыть`

Например, если в проекте есть отчет **СводкаПоТоварам**, то будут созданы следующие типы:

- `СводкаПоТоварам`
- `СводкаПоТоварам.АвтоматическаяФорма`
- `СводкаПоТоварам.Открыть`

## <ИмяОтчета>

Для каждого отчета формируется соответствующий тип объекта.

Доступность: Сервер / Клиент

Базовый тип: [`Отчет`](../stdlib/report-ru-262c53c7ab2e.md)

Экземпляр объекта может быть создан в коде на сервере и на клиенте конструктором без параметров.

## <ИмяОтчета>.АвтоматическаяФорма

Автоматическая форма просмотра отчета в приложении.

Базовый тип: [`ФормаОтчета`](../interface/reportform-ru-a6c5b64077dc.md)

В качестве заголовка формы используется **Представление** отчета. Содержимое формы — компонент [ПросмотрОтчета](../interface/reportviewer-ru-c2fcfa1af193.md), который отображает соответствующий отчет в режиме чтения.

## <ИмяОтчета>.Открыть

Навигационная команда, которая открывает связанную с отчетом форму отчета.

Базовый тип: [`НавигационнаяКоманда`](../interface/navigationcommand-ru-8290d7424fc8.md)

## <ИмяОтчета>.Параметры.<ИмяПараметра>

Если в дизайнере отчета определен [параметр](../project/use-report-parameters-6257f3b8a42b.md), для которого задан список допустимых значений, то для этого параметра «1С:Предприятие.Элемент» создаст перечисление с именем `<ИмяОтчета>.Параметры.<ИмяПараметра>`. Имена элементов перечисления генерируются по колонке **Имя** в диалоге создания параметра.

Например, пусть в отчете **ОтчетОПродажах** задан параметр **СрезДанных**:

Пример параметра отчёта «Срез данных» (имя СрезДанных): Тип параметра — Строка, значение по умолчанию — «По клиенту»; включены «Создать элемент управления» и «Задать допустимые значения». [Описание иллюстрации](../../raw/figures/21ed1eca5dbd4caa09facd273dc7a28e441e361b1e41fa3ff25b85fb95d66a38-fa96f7661828164f.md)

«1С:Предприятие.Элемент» сформирует перечисление `ОтчетОПродажах.Параметры.СрезДанных`, содержащее следующие элементы:

- `ПоКлиенту`
  
  ,
- `ПоОтветственному`
  
  .

Вы можете установить значение параметра в коде следующими способами:

- в конструкторе:
  
  ```xbsl
  знч Отчет = новый ОтчетОПродажах(СрезДанных = ОтчетОПродажах.Параметры.СрезДанных.ПоОтветственному)
  ```
- с помощью свойства `<ИмяОтчета>.Параметры.<ИмяПараметра>`:
  
  ```xbsl
  знч Отчет = новый ОтчетОПродажах()
  Отчет.Параметры.СрезДанных = ОтчетОПродажах.Параметры.СрезДанных.ПоОтветственному
  ```
