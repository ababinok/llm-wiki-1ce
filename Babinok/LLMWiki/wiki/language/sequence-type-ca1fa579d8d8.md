## Документированный контракт и примеры

[`Последовательность<ТипЭлемента>`](../stdlib/sequence-ru-e9f8e0042ba9.md) — это тип, который предоставляет возможность выполнять потоковую обработку данных. Представляет собой ленивую версию типа [Обходимое](iterable-type-faa48a5b4872.md), т. е. реальные вычисления выполняются только при вызове терминального метода ([подробнее](../project/collections-7287d5708b4b.md)).

> [!WARNING] важно
> На клиенте в методах вычисления нельзя использовать любые асинхронные операции, например вызовы сервера. Это приведет к возникновению ошибки «Попытка выполнить асинхронное действие». Аналогичная ошибка может возникнуть при использовании отладчика для таких методов.

Например:

```xbsl
перечисление РольСотрудника
    Инженер
    Менеджер
    Руководитель
;

структура Сотрудник
    пер Фамилия: Строка
    пер Должность: РольСотрудника?
    пер Возраст: Число
;

метод ПримерИспользованиеПоследовательности(Сотрудники: Массив<Сотрудник>,
                                            СортироватьПоФамилии: Булево,
                                            ФильтроватьПоВозрасту: Булево): Массив<Сотрудник>
    пер СотрудникиПоследовательность: Последовательность<Сотрудник> = Сотрудники.КакПоследовательность()

    // Все вычисления над Последовательностью выполняются "лениво"
    если  СортироватьПоФамилии
        СотрудникиПоследовательность = СотрудникиПоследовательность.СортироватьПо(а -> а.Фамилия)
    ;
    если ФильтроватьПоВозрасту
        СотрудникиПоследовательность = СотрудникиПоследовательность.Фильтровать(а -> а.Возраст > 30)
    ;

    // Вызывается терминальный метод, все вычисления выполняются только здесь
    возврат СотрудникиПоследовательность.ВМассив()
;
```
