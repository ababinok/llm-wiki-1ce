## Документированный контракт и примеры

Значение переменной задается с помощью инструкции присваивания `=`:

```xbsl
назначение [арифметическая-операция]= источник
```

- `назначение`
  
  В качестве назначения может выступать имя переменной, свойство экземпляра [типа](types-and-their-hierarchy-282f6415d4e1.md) или элемент [массива](array-type-eee257947e0e.md). Также допускается использование термина **левое значение** в качестве синонима термина **назначение**.
- `источник`
  
  Выражение, значение которого будет установлено в переменную или свойство экземпляра. Также допускается использование термина **правое значение** в качестве синонима термина **источник**.
- `арифметическая-операция`
  
  Язык позволяет использовать инструкции присваивания, совмещенные с [арифметическими операциями](arithmetic-operations-0369ce6ea5e8.md). Если требуется изменить **назначение** на какое-либо значение, то сделать это можно с помощью выражения `назначение = назначение + выражение` или `назначение += выражение`. В качестве арифметической операции можно использовать сложение (`+`), вычитание (`-`), умножение (`*`) или деление (`/`). Также допустимы следующие операции: `+=`, `-=`, `*=`, `/=`.

## Пример

```xbsl
пер Счетчик = 1
Счетчик += 1   // 2
Счетчик = 5    // 5

знч Оценки = ["A", "B", "C", "F"]
Оценки[3] = "D"   // ["A", "B", "C", "D"]
Оценки[3] += "+" // ["A", "B", "C", "D+"]

знч РазмерМассива = Оценки.Размер() // 4
```
