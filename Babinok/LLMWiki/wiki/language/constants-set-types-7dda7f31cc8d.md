## Тип «ИмяНабораКонстант»

Тип [`{ИмяНабораКонстант}`](../stdlib/constantssetname-ru-10721a2e334f.md) — тип-одиночка.

Тип содержит методы для работы с конкретным набором констант. Например, методы для пересчета разрешений доступа, получения среза последних (для периодического набора), установки блокировок.

Этот тип не содержит конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Получить срез последних периодического набора констант «КурсДоллара»
КурсДоллара.ПолучитьСрезПоследних(Дата.Сейчас())

// Пересчитать разрешения доступа
КурсДоллара.ПересчитатьРазрешенияДоступа()
```

### Модуль набора констант

В проекте модуль, расширяющий тип [`{ИмяНабораКонстант}`](../stdlib/constantssetname-ru-10721a2e334f.md), называется **модулем набора констант**.

Модуль набора констант [Описание иллюстрации](../../raw/figures/900262504b2a1cd5855523946b58f8674a19d13e735d09e2444ab7bf3fc199e3-85a86f94c6d6dfef.md)

В этом модуле вы можете обработать события [вычисления разрешений доступа](../security/manage-access-control-2ec0764ce511.md).

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(): ЧитаемаяКоллекция<РазрешениеДоступа>
     возврат [новый РазрешениеДоступа([новый КлючДоступаРедактироватьДанныеОрганизации.Объект()],
                [НаборКонстантПраво.Изменение, НаборКонстантПраво.Чтение])]
;
```

> [!TIP] совет
> В модуле набора констант может находиться реализация [контракта сервиса](../project/service-contract-5b8423b5cca0.md).

## Тип «ИмяНабораКонстант.АвтоматическаяФормаЗаписи»

Тип [`{ИмяНабораКонстант}.АвтоматическаяФормаЗаписи`](../stdlib/constantssetname-automaticrecordform-ru-61f6e8bd7e14.md) доступен на клиенте. Описывает автоматически создаваемую форму записи набора констант.

## Тип «ИмяНабораКонстант.АвтоматическаяФормаСписка»

Тип [`{ИмяНабораКонстант}.АвтоматическаяФормаСписка`](../stdlib/constantssetname-automaticlistform-ru-ba52b8f6bda1.md) доступен на клиенте. Описывает автоматически создаваемую форму списка набора констант. Форма доступна только для [периодических наборов](../project/constants-set-element-3c8e873b235a.md).

## Тип «ИмяНабораКонстант.Данные»

Тип [`{ИмяНабораКонстант}.Данные`](../stdlib/constantssetname-data-ru-adfa46d7044a.md) доступен на сервере. Содержит набор данных, соответствующий какому-то состоянию объекта. Имена и типы свойств соответствуют именам и типам констант записи набора констант. Используется в обработчиках типа [`ИмяНабораКонстант.Запись`](../stdlib/constantssetname-record-ru-0435fbfdf30e.md).

## Тип «ИмяНабораКонстант.Запись»

Тип [`{ИмяНабораКонстант}.Запись`](../stdlib/constantssetname-record-ru-0435fbfdf30e.md) доступен на клиенте и сервере. Содержит данные одной записи набора констант. Структурно соответствует одной записи (строке) в основной таблице набора констант.

### Модуль записи

В проекте модуль, расширяющий тип [`{ИмяНабораКонстант}.Запись`](../stdlib/constantssetname-record-ru-0435fbfdf30e.md), называется **модулем записи**.



В нем вы можете реализовать обработчики параметров [записи](../project/constantsset-bae2805eef0b.md) и [удаления](../project/constantsset-bae2805eef0b.md).

> [!TIP] совет
> В модуле записи может находиться реализация методов [контракта типа](type-contract-ab9f0932850d.md).

## Тип «ИмяНабораКонстант.КлючЗаписи»

Тип [`{ИмяНабораКонстант}.КлючЗаписи`](../stdlib/constantssetname-recordkey-ru-561ab53f9174.md) доступен на клиенте и сервере. Содержит значения ключей записи набора констант.

### Модуль ключа записи

В проекте модуль, расширяющий тип [`{ИмяНабораКонстант}.КлючЗаписи`](../stdlib/constantssetname-recordkey-ru-561ab53f9174.md), называется модулем ключа записи.

В дереве набора констант КурсДоллара отдельно видны модули КурсДоллара, КурсДоллара.Запись и выделенный КурсДоллара.КлючЗаписи. [Описание иллюстрации](../../raw/figures/84b1cc76e3def692a332bcc049082a828b166b97c41cc03f4e9aa0c4df23982a-6c841bd1c7f82149.md)

## Тип «ИмяНабораКонстант.ОткрытьСписок»

Тип [`{ИмяНабораКонстант}.ОткрытьСписок`](../stdlib/constantssetname-openlist-ru-9af058cb6e2e.md) — тип-одиночка. Является командой открытия формы списка набора констант. Тип доступен только для [периодических наборов](../project/constants-set-element-3c8e873b235a.md).

## Тип «ИмяНабораКонстант.ПараметрыЗаписи»

Тип [`{ИмяНабораКонстант}.ПараметрыЗаписи`](../stdlib/constantssetname-writeparameters-ru-0bfe81fe4c23.md) доступен на клиенте и сервере. Содержит параметры записи, которые описаны в элементе проекта в разделе [ПараметрыЗаписи](../project/constantsset-bae2805eef0b.md). Формируется всегда, даже если параметры не описаны.

## Тип «ИмяНабораКонстант.ПараметрыУдаления»

Тип [`{ИмяНабораКонстант}.ПараметрыУдаления`](../stdlib/constantssetname-deleteparameters-ru-7a24a18912de.md) доступен на клиенте и сервере. Содержит параметры удаления, которые описаны в элементе проекта в свойстве [ПараметрыУдаления](../project/constantsset-bae2805eef0b.md). Формируется всегда, даже если параметры не описаны.

Тип [`{ИмяНеПериодическогоНабораКонстант}.ОткрытьОбъект`](../stdlib/nonperiodicconstantssetname-openobject-ru-e3880953b129.md) — тип-одиночка. Доступен на клиенте. Является командой открытия формы записи непериодического набора констант.
