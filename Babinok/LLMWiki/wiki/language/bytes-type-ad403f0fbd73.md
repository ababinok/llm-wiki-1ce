## Обзор

С помощью типа [`Байты`](../stdlib/bytes-ru-19f4d37ce009.md) можно хранить набор произвольных значений, заданных шестнадцатеричными цифрами.

## Документированный контракт и примеры

С помощью типа [`Байты`](../stdlib/bytes-ru-19f4d37ce009.md) можно хранить набор произвольных значений, заданных шестнадцатеричными цифрами. *Байт* — это единица хранения и обработки цифровой информации. Байт состоит из 8 бит и, следовательно, может принимать значения от 0 до 255 (включая оба значения).

Значение типа `Байты` можно задать следующими способами:

- литералом
  
  вида
  
  `Байты{<Шестнадцатеричное представление>}`
  
  , где
  
  `<Шестнадцатеричное представление>`
  
  — это последовательность шестнадцатеричных чисел;
- конструктором вида
  
  [`Байты(ШестнадцатеричнаяСтрока: Строка)`](../stdlib/bytes-ru-19f4d37ce009.md)
  
  , где
  
  `ШестнадцатеричнаяСтрока`
  
  — это строковое представление последовательности шестнадцатеричных чисел.

Шестнадцатеричное представление допускается указывать как в одну строку, так и в несколько строк.

## Пример

```xbsl
метод ПримерСБайтами()
    пер НаборБайтов1 = Байты{4d 5a}
    пер НаборБайтов2 = Байты{01
        02
        03}
    пер НаборБайтов3 = новый Байты("0112AAEE")
    пер Строка1 = "Размер = %{НаборБайтов1.Размер()} : %НаборБайтов1"    // Размер = 2b: 4d5a
    пер Строка2 = "Размер = %{НаборБайтов2.Размер()} : %НаборБайтов2"    // Размер = 3b: 010203
    пер Строка3 = "Размер = %{НаборБайтов3.Размер()} : %НаборБайтов3"    // Размер = 4b: 0112aaee
;
```
