## Документированный контракт и примеры

В языке «1С:Элемент» используются **литералы** — элементы программы, которые непосредственно представляют значение.

Самый простой пример литералов — любое число или строка. Примерами литералов также являются значения `Истина` или `Ложь` типа `Булево`.

Литералы можно использовать для создания экземпляров типов, которые перечислены далее.

## Строка

Значение типа [`Строка`](string-type-e8ad86f5efd8.md)

```xbsl
"этострока"
```

```xbsl
// Многострочный литерал обязательно должен начинаться с новой строки
"первая подстрока многострочной строки
вторая подстрока многострочной строки
третья подстрока многострочной строки"
```

## Число

Значение типа [`Число`](number-type-9dbc7d75be68.md)

```xbsl
12345
```

## Байты{16-ричное-представление}

Значение типа [`Байты`](bytes-type-ad403f0fbd73.md)

```xbsl
Байты{4D5A}
Байты{FF}
```

## Время{значение-времени}

Значение типа [`Время`](time-type-0dd2a356632b.md)

```xbsl

Время{18:00}
```

## Тип<имя-типа>

Значение типа `Тип`. В качестве `имя-типа` необходимо написать собственно имя типа. Например, для типа `Строка` литерал будет выглядеть следующим образом:

```xbsl
Тип<Строка>
```
