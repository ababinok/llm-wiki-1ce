## Обзор

Определение метода — это место в исходном коде, где создан метод.

## Документированный контракт и примеры

Определение метода — это место в исходном коде, где создан метод. Определение метода состоит из объявления метода, тела метода и символа `;`, описывающего завершение метода.

```xbsl
// Определение метода
метод СложитьЧисла(ПервоеЧисло: Число, ВтороеЧисло: Число): Строка
    возврат "Результат сложения чисел: ${ПервоеЧисло + ВтороеЧисло}"
;
```
