## Документированный контракт и примеры

Обратиться к модулю можно по его имени, так как оно совпадает с именем типа, который расширяет модуль.

Например, в модуле [справочника](../data/catalog-project-element-b6ca52d114d4.md) **Сотрудники** есть публичный метод `СоздатьКандидата()`:

```xbsl
@ВПроекте
метод СоздатьКандидата()
   // ...
;
```

Вызов этого метода из другого серверного модуля будет выглядеть так:

```xbsl
Сотрудники.СоздатьКандидата()
```

Другой пример: пусть в модуле описан тип, например структура:

```xbsl
@ВПроекте
структура НастройкиСотрудников   
   // ...
;
```

Использование этого типа в другом серверном модуле будет выглядеть так:

```xbsl
пер Настройки: Сотрудники.НастройкиСотрудников
```
