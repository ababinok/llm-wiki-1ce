## Документированный контракт и примеры

## Литералы

Помимо десятичного литерала числа имеют двоичный и шестнадцатеричный литералы.

Двоичные и шестнадцатеричные числа могут быть только целыми.

```xbsl
// Шестнадцатеричный литерал
знч Цвет = 0xFF0000

// Двоичный литерал
знч Маска = 0b11111100100
```

## Методы

Экземпляры типа `Число` имеют два метода: `Округлить()` и `ЦелаяЧасть()`.

«1С:Предприятие 8»

```bsl
Длина = 12543;
КилометрыТочноеЧисло = Цел(Длина / 1000); // 12
КилометрыОкругление = Окр(Длина / 1000); // 13
```

«1С:Предприятие.Элемент»

```xbsl
знч Длина = 12543
пер КилометрыТочноеЧисло = (Длина / 1000).ЦелаяЧасть() // 12
пер КилометрыОкругление = (Длина / 1000).Округлить() // 13
```
