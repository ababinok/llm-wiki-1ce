## Документированный контракт и примеры

В тех случаях, когда модуль нужно передать в качестве параметра в другой модуль, можно использовать ключевое слово `этот`.

Это ключевое слово возвращает объект, к которому относится модуль, и явно квалифицирует обращение к контексту объекта.

Например, в модуле справочника **Товары** может вызываться метод общего модуля, в который передается этот модуль справочника **Товары**.

```xbsl
метод МойМетод()
    ОбщийМодуль.ДругойМетод(этот)
;

@ВПроекте
метод ПубличныйМетод()
;
```

Тогда в вызываемом методе можно, например, вызвать публичный метод этого модуля.

```xbsl
@ВПроекте
метод ДругойМетод(Модуль: Товары)
    Товары.ПубличныйМетод()
;
```
