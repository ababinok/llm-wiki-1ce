## Обзор

В языке «1С:Элемент» поддерживаются коллекции трех типов — `Массив`, `Соответствие` и `Множество`.

## Документированный контракт и примеры

В языке «1С:Элемент» поддерживаются коллекции трех типов — `Массив`, `Соответствие` и `Множество`. `Множество` — это коллекция, которая содержит только уникальные элементы.

Значения типов коллекций могут быть заданы литералами, которые рекомендуется использовать вместо заполнения коллекций «вручную», с помощью методов `Добавить()` и `Вставить()`.

## Литерал массива

«1С:Предприятие 8»

```bsl
Процедура Скрипт()
    ИменаПолей = новый Массив;
    ИменаПолей.Добавить("Идентификатор");
    ИменаПолей.Добавить("Размер");
    ИменаПолей.Добавить("Цвет");
    ОбработатьПоля(ИменаПолей);
КонецПроцедуры

Процедура ОбработатьПоля(Поля)
КонецПроцедуры
```

«1С:Элемент»

```xbsl
метод Скрипт()
    // Использование литерала при объявлении массива
    пер ИменаПолей = ["Идентификатор", "Размер", "Цвет"]

    // Использование литерала при вызове метода
    ОбработатьПоля(["Идентификатор", "Размер", "Цвет"])
;

метод ОбработатьПоля(Поля: Массив<Строка>)
;
```

> [!TIP] совет
> Для ввода квадратных скобок `[` и `]` используйте сочетание клавиш **Alt + х** и **Alt + ъ** ([подробнее](../project/keyboard-shortcuts-a9db35885b20.md)).

## Литерал соответствия

«1С:Предприятие 8»

```bsl
Процедура Скрипт()
    КурсыВалют = новый Соответствие();
    КурсыВалют.Вставить("RUB", 1);
    КурсыВалют.Вставить("BYN", 31.01);
    ОбработатьВалюты(КурсыВалют);
КонецПроцедуры

Процедура ОбработатьВалюты(Валюты)
КонецПроцедуры
```

«1С:Элемент»

```xbsl
метод Скрипт()
    // Использование литерала при объявлении соответствия
    пер КурсыВалют = {"RUB": 1, "BYN": 31.01}

    // Использование литерала при вызове метода
    ОбработатьВалюты({"RUB": 1, "BYN": 31.01})
;

метод ОбработатьВалюты(Валюты: Соответствие<Строка, Число>)
;
```

> [!TIP] совет
> Для ввода фигурных скобок `{` и `}` используйте сочетание клавиш **Alt + 9** и **Alt + 0**. Для ввода вертикальной черты `|` используйте сочетание клавиш **Alt + \** ([подробнее](../project/keyboard-shortcuts-a9db35885b20.md)).

## Литерал множества

```xbsl
метод Скрипт()
    // Использование литерала при объявлении множества
    пер МножествоСДанными = {1, 2, 3}

    // Использование литерала при вызове метода
    ОбработатьДанные({1, 2, 3})
;

метод ОбработатьДанные(Данные: Множество<Число>)
;
```

> [!TIP] совет
> Для ввода фигурных скобок `{` и `}` используйте сочетание клавиш **Alt + 9** и **Alt + 0**. Для ввода вертикальной черты `|` используйте сочетание клавиш **Alt + \** ([подробнее](../project/keyboard-shortcuts-a9db35885b20.md)).
