## Документированный контракт и примеры

После того как вы добавили в проект контракт сервиса, «1С:Предприятие.Элемент» создаст тип с тем же именем, что и имя вашего контракта.

Например, если в проекте есть контракт **APIСервиса**, то будет создан тип `APIСервиса`. В общем случае имя этого типа выглядит следующим образом: `имя-контракта-сервиса`.

## Тип «имя-контракта-сервиса»

Это абстрактный тип. Он доступен в том же окружении, которое указано в свойстве контракта [Окружение](../project/servicecontract-ru-c54f5cfcd100.md): **КлиентИСервер**, **Клиент**, **Сервер**.

Этот тип содержит методы, объявленные в модуле контракта **имя-контракта-сервиса.xbsl**.

Кроме этого тип имеет статический метод, имя которого зависит от значения свойства контракта [Множественный](../project/servicecontract-ru-c54f5cfcd100.md):

- `Истина`
  
  — имя метода
  
  `ПолучитьСервисы()`
- `Ложь`
  
  — имя метода
  
  `ПолучитьСервис()`

Эти методы предназначены для того, чтобы получить все экземпляры типов-одиночек, которые реализуют этот контракт.

> [!NOTE] примечание
> «1С:Предприятие.Элемент» поддерживает механизм [подписки на системные события](../project/event-subscriptions-8a4718cb813e.md).

## Модуль контракта сервиса

В проекте модуль, расширяющий тип `имя-контракта-сервиса`, называется **модулем контракта сервиса**. Он доступен в том же окружении, которое указано в свойстве контракта [Окружение](../project/servicecontract-ru-c54f5cfcd100.md): **КлиентИСервер**, **Клиент**, **Сервер**.

В модуле контракта сервиса должны быть объявлены методы (с ключевым словом `абстрактный`), из которых состоит контракт. Реализация этих методов должна находиться в [элементах проекта](../project/service-contract-5b8423b5cca0.md), которые реализуют этот контракт.

Также в модуле контракта сервиса могут быть объявлены:

- [константы](variable-declaration-statement-defd1798c9ff.md)
  
  ,
- [структуры](../project/structure-a95b303918fa.md)
  
  ,
  
  [исключения](exceptions-a26c3b7e6dec.md)
  
  ,
  
  [перечисления](enumeration-type-5311bbd23ddf.md)
  
  .

Для методов и типов, объявляемых в модуле контракта сервиса, окружение не указывается, оно всегда равно окружению контракта (свойство [Окружение](../project/servicecontract-ru-c54f5cfcd100.md)).

Например, ниже показан модуль контракта сервиса, в котором объявлены два метода: `ЗаписатьЗначенияОперативныхПоказателей()` и `ЗарегистрироватьСдельныйЗаработок()`.

Также в нем объявлены три типа данных, `СтруктураЗаписи`, `СтруктураПоказателей` и `СтруктураЗаработка`, которые используются в параметрах этих методов.

```xbsl
// Импорт подсистемы Главная, чтобы к справочнику Организации
// обращаться по неквалифицированному имени.
импорт Главная

// Объявление типов, использующихся в параметрах методов.
структура СтруктураЗаписи
    пер Поле1: Строка
    пер Поле2: Число
;

структура СтруктураПоказателей
    пер Поле1: Строка
    пер Поле2: Число
;

структура СтруктураЗаработка
    пер Поле1: Строка
    пер Поле2: Число
;

// Регистрирует значения оперативных показателей расчета зарплаты.
абстрактный метод ЗаписатьЗначенияОперативныхПоказателей(
    Движения: Массив<СтруктураЗаписи>,
    Организация: Организации.Ссылка,
    ОперативныеПоказатели: СтруктураПоказателей,
    ЗаписыватьДвижения = Ложь
)

// Регистрирует данные о сдельном заработке.
абстрактный метод ЗарегистрироватьСдельныйЗаработок(
    Движения: Массив<СтруктураЗаписи>,
    Организация: Организации.Ссылка,
    СдельныйЗаработок: СтруктураЗаработка
)
```
