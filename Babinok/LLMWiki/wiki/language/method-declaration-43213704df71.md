## Обзор

Объявление метода — это часть определения метода, которая содержит его сигнатуру.

## Документированный контракт и примеры

Объявление метода — это часть определения метода, которая содержит его сигнатуру.

```xbsl
// Объявление метода
метод СложитьЧисла(ПервоеЧисло: Число, ВтороеЧисло: Число): Строка
    // Тело метода
    возврат "Результат сложения чисел: ${ПервоеЧисло + ВтороеЧисло}"
;
```
