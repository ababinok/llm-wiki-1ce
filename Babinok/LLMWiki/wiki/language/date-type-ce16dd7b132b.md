## Документированный контракт и примеры

Данный тип позволяет работать только с датой. Так, для указания дня рождения достаточно только даты. Отпуск или командировка, как правило, тоже нужно указывать без явного указания времени наступления события.

Значение типа [`Дата`](../stdlib/date-ru-d160dc00114c.md) может быть задано следующими способами:

- С помощью литерала вида `Дата{<дата>}`, где `<дата>` имеет формат: `гггг-ММ-дд`. Например:
  
  ```xbsl
  пер ДеньРождения = Дата{2025-02-20}
  ```
  
  Встроенные строковые литералы:
  
  - `Дата{}`
    
    — значение по умолчанию: 0001-01-01.
  - `Дата{Минимум}`
    
    — минимальное значение: 0001-01-01.
  - `Дата{Максимум}`
    
    — максимальное значение: 9999-12-31.

> [!NOTE] примечание
> Встроенные строковые литералы также можно использовать в языке запросов. Например, чтобы проверить наличие следующего периода у записи в таблице периодического регистра сведений, можно сравнить значение поля **СледующийПериод** с максимальным значением типа поля **Период** (см. [пример](../data/periodic-information-register-2e754cdbda44.md)). Если они равны, значит значение следующего периода для данной записи отсутствует.

- С помощью конструктора типа, в котором дата указывается в виде строки: [`Дата(Представление: Строка)`](../stdlib/date-ru-d160dc00114c.md). В общем случае формат строки совпадает с выражением литерала из примера выше. В примере ниже в переменную из примера выше помещается новый объект типа `Дата`, как аргумент для которого передается строка соответствующего формата:
  
  ```xbsl
  пер ДеньРождения = новый Дата("2025-02-20")
  ```
- С помощью конструктора типа, в котором составляющие даты вводятся отдельными параметрами конструктора: [`Дата(Год: Число, Месяц: Число, День: Число)`](../stdlib/date-ru-d160dc00114c.md).
  
  ```xbsl
  пер ДеньРождения = новый Дата(2025, 02, 20)
  ```
- С помощью метода [`Сейчас()`](../stdlib/date-ru-d160dc00114c.md), который принимает как необязательный аргумент значение типа [`ЧасовойПояс`](../stdlib/timezone-ru-b38f153ea5b7.md) и возвращает текущую дату в заданном часовом поясе.
  
  ```xbsl
  пер ТекущаяДата = Дата.Сейчас(ЧасовойПояс{UTC+1})
  ```

Вы также можете [форматировать](../project/formatting-datetime-values-4b62c94ded09.md) значение даты с помощью описателей формата из [этой таблицы](../project/formatting-datetime-values-4b62c94ded09.md), которые относятся к дате. Если форматная строка не задана, будет использоваться значение по умолчанию с учетом текущей [локали](../stdlib/locale-ru-eb59bd8c78bb.md).
