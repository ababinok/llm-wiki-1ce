## Документированный контракт и примеры

Тип [`Обходимое`](../stdlib/iterable-ru-283adb0cc9eb.md) — это базовый тип, который лежит в основе всей иерархии типов, предназначенных для работы с [коллекциями](../project/collections-7287d5708b4b.md). Тип указывает, что для потомка такого типа может быть применен цикл обхода коллекции [`для ... из`](for-in-loop-52f2e1fffd4d.md). При этом не гарантируется, что будет возможно выполнить повторный обход для значения такого типа (потомка типа `Обходимое`).

> [!WARNING] важно
> На клиенте в методах вычисления нельзя использовать любые асинхронные операции, например вызовы сервера. Это приведет к возникновению ошибки «Попытка выполнить асинхронное действие». Аналогичная ошибка может возникнуть при использовании отладчика для таких методов.
