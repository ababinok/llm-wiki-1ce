## Документированный контракт и примеры

Значения типа [`Строка`](../stdlib/string-ru-1bac645acacf.md) хранят неизменную последовательность символов Unicode. При необходимости каким-то образом изменить существующую последовательность символов создается копия оригинальной строки с выполненными изменениями.

## Создание строки

Новую строку можно создать с помощью [литерала](literals-e1c415690982.md), указав набор символов, заключенный в двойные кавычки. Значение по умолчанию для экземпляров типа [`Строка`](../stdlib/string-ru-1bac645acacf.md) — это пустая строка `""`.

```xbsl
знч СтрокаОдин = "Первая строка"
```

Также вы можете использовать конструктор типа [`Строка`](../stdlib/string-ru-1bac645acacf.md), чтобы создать строку из последовательности байтов с учетом заданной кодировки:

```xbsl
// СтрокаДва имеет значение "Вторая строка"
знч СтрокаДва = новый Строка(Байты{feff04120442043e04400430044f0020044104420440043e043a0430},
                             Кодировка.Utf16)
```

> [!NOTE] примечание
> На клиенте поддерживается только кодировка UTF-8.
>
> [Подробнее о поддерживаемых кодировках](../project/supported-encodings-0f8910737ada.md)

### Экранирование символов

Чтобы использовать в строковых литералах такие символы, как обратный слеш `\` и кавычки `"`, их необходимо экранировать с помощью символа обратного слеша `\`:

```xbsl
пер РабочийКаталог = "C:\\test\\"

пер Фраза = "Язык \"Элемента\""
```

[Подробнее про управляющие последовательности](../project/escape-sequence-c843c60a53d9.md).

## Представление строки в виде массива

Строку можно представить как в виде последовательности символов (собственно строки), так и в виде массива. В массиве каждый символ строки выступает в виде элемента массива, поэтому обращение к символу строки возможно по индексу с помощью операции `[]` ([подробнее](indexer-operator-6461034aa5ad.md)). Индекс может быть целым числом в интервале от 0 до длины строки минус единица.

Таким образом, если мы имеем строку `"пример"`, то:

- длина строки равна 6 символам;
- индекс первого символа равен 0 (это верно для любой непустой строки);
- индекс последнего символа равен 5: длина строки (в примере это 6) минус 1.

```xbsl
знч Строка = "пример"
знч Длина = Строка.Длина()              // 6
знч ПервыйСимвол = Строка[0]            // п
знч ПоследнийИндекс = Строка.Длина()-1  // 5
```
