## Свойства

### НеВыполнятьДействийСБазойДанных

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеВыполнятьДействийСБазойДанных
```

При удалении информационной базы, состояние базы данных не изменится.

---

### ОчиститьБазуДанных

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ОчиститьБазуДанных
```

При удалении информационной базы, база данных будет очищена.

---

### УдалитьБазуДанных

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
УдалитьБазуДанных
```

При удалении информационной базы будет удалена база данных.
