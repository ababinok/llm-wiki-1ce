## Конструкторы

### ЧастьТекстаПисьма

`Доступность: Сервер`

```
ЧастьТекстаПисьма(
  Текст: Строка,
  ВидТекста: ВидТекстаПисьма|Строка = ВидТекстаПисьма.ПростойТекст,
  Кодировка: Строка = "UTF-8")
```

Конструктор части текста письма от текста, его вида и кодировки.

---

## Свойства

### ВидТекста

`Доступность: Сервер` `ТолькоЧтение`

```
ВидТекста: Строка?
```

Тип текстовых данных письма. Значение заголовка `Content-Type`. Если значение заголовка отсутствует, возвращается `Неопределено`.

---

### Данные

`Доступность: Сервер` `ТолькоЧтение`

```
Данные: Байты
```

Необработанные данные тела письма. Данные были только разобраны, но работы над кодировкой текстов не производилось.

---

### ЕстьОшибкиВРазборе

`Доступность: Сервер` `ТолькоЧтение`

```
ЕстьОшибкиВРазборе: Булево
```

Признак кого, что при разборе текста письма возникли ошибки, Текст может содержать ошибки

---

### Кодировка

`Доступность: Сервер` `ТолькоЧтение`

```
Кодировка: Строка?
```

Содержит кодировку текстовых данных сообщения.

---

### КодировкаПередачи

`Доступность: Сервер` `ТолькоЧтение`

```
КодировкаПередачи: Строка?
```

Соответствует заголовку Content-Transport-Encoding, отвечает за то, как кодировать не ASCII символы. B - соответствует base64

---

### Текст

`Доступность: Сервер` `ТолькоЧтение`

```
Текст: Строка
```

Текстовые данные сообщения.
