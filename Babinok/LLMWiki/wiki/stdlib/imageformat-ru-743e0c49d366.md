---

### Bmp

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Bmp
```

Формат картинки BMP (Bitmap).

---

### Tiff

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Tiff
```

Формат картинки - однослойный TIFF. Многослойные не поддерживаются. Соответствует спецификации: [https://en.wikipedia.org/wiki/TIFF](https://en.wikipedia.org/wiki/TIFF).

### Png

`Доступность: КлиентИСервер` `ТолькоЧтение`

Png
```

Формат картинки PNG. Соответствует спецификации: [http://www.libpng.org/pub/png/spec/](http://www.libpng.org/pub/png/spec/).

---

### Gif

`Доступность: КлиентИСервер` `ТолькоЧтение`

Gif
```
