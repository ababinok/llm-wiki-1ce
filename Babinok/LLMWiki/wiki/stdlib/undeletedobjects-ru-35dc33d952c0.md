## Обзор

Объект, предназначенный для разрешения ссылок на объекты, которые препятствуют удалению сущностей.

## Документированный контракт и примеры

`Стд::Сущности::НеудаленныеОбъекты` `Тип-одиночка` `Доступность: Сервер`

Объект, предназначенный для разрешения ссылок на объекты, которые препятствуют удалению сущностей. При удалении данных система ведет глобальный реестр ссылок, препятствующих удалению объектов. Каждый запуск процесса удаления актуализирует данные в этом реестре. Объект `НеудаленныеОбъекты` позволяет разрешить ссылки на основании записей в этом реестре.

## Методы

### Заменить

`Доступность: Сервер`

```
Заменить(
  СтароеЗначение: Сущность.Ссылка,
  НовоеЗначение: Сущность.Ссылка?)
```

Заменить во всех объектах, ссылающихся на удаляемые данные, одно значение на другое.

- Параметр
  
  `СтароеЗначение`
  
  указывает значение удаляемого объекта, которое надо заменить.
- Параметр
  
  `НовоеЗначение`
  
  указывает новое значение, которое надо установить вместо старого.

Если ссылка на удаляемый объект стала неактуальна (например, объект изменили, и он больше не ссылается на удаляемую запись), то процесс разрешения ссылок пропустит такую связь и не будет изменять объект.

**Перегрузка** [Заменить(СсылающиесяОбъекты: Обходимое<Сущность.Ключ>, СтароеЗначение: Сущность.Ссылка, НовоеЗначение: Сущность.Ссылка?)](undeletedobjects-ru-35dc33d952c0.md)

### Заменить

`Доступность: Сервер`

```
Заменить(
  СсылающиесяОбъекты: Обходимое<Сущность.Ключ>,
  СтароеЗначение: Сущность.Ссылка,
  НовоеЗначение: Сущность.Ссылка?)
```

Заменить в указанных объектах, ссылающихся на удаляемые данные, одно значение на другое.

- Параметр
  
  `СсылающиесяОбъекты`
  
  определяет объекты, в которых будет производиться замена.
- Параметр
  
  `СтароеЗначение`
  
  указывает значение удаляемого объекта, которое надо заменить.
- Параметр
  
  `НовоеЗначение`
  
  указывает новое значение, которое надо установить вместо старого.

Если ссылка на удаляемый объект стала неактуальна (например, объект изменили, и он больше не ссылается на удаляемую запись), то процесс разрешения ссылок пропустит такую связь и не будет изменять объект.

**Перегрузка** [Заменить(СтароеЗначение: Сущность.Ссылка, НовоеЗначение: Сущность.Ссылка?)](undeletedobjects-ru-35dc33d952c0.md)

#### Примеры

Замена дубликата товара в документах ПриходнаяНакладная за текущий месяц.

```xbsl
метод ЗаменитьДубликатТовара(УдаляемыйТовар: Товары.Ссылка, АктуальныйТовар: Товары.Ссылка)
    
    знч НачалоМесяца = ДатаВремя.Сейчас().НачалоМесяца()
    знч КонецМесяца = ДатаВремя.Сейчас().КонецМесяца()
    
    знч Запрос = Запрос {
        ВЫБРАТЬ
            ПоступлениеТоваров.Ссылка КАК Ссылка
        ИЗ
            ПоступлениеТоваров КАК ПоступлениеТоваров
        ГДЕ
            ПоступлениеТоваров.Дата МЕЖДУ %НачалоМесяца И %КонецМесяца
    }
    
    знч ИскомыеДокументы = Запрос.Выполнить().Преобразовать(Запись -> Запись.Ссылка)
    
    НеудаленныеОбъекты.Заменить(ИскомыеДокументы, УдаляемыйТовар, АктуальныйТовар)
;
```

### Удалить

`Доступность: Сервер`

```
Удалить(СсылающийсяОбъект: Сущность.Ключ)
```

Удалить ссылающийся объект, если он указан в таблице неудаленных объектов. Если параметр

`СсылающийсяОбъект`

указывает на объект с режимом удаления ПометкаУдаления, то

`СсылающийсяОбъект`

будет помечен на удаление. Если параметр

`СсылающийсяОбъект`

указывает на объект с режимом удаления Немедленно, то

`СсылающийсяОбъект`

будет удален.
