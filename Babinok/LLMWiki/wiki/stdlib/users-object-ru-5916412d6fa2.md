### ЛокальОтображения

`Версия 8.0 и выше`

`Доступность: Сервер`

```
ЛокальОтображения: Локаль?
```

Предпочитаемая настроенная локаль для отображения интерфейса. Пользователь может в явном виде выбрать язык интерфейса и региональные особенности отображения. В этом случае, интерфейс будет отображаться в этой локали.

Значение `Неопределено` означает, что пользователь не настроил отдельных предпочтений по локализации и система будет выбирать язык автоматически, основываясь на настройках ОС и браузера.

---

### ЛокальФорматирования

`Версия 8.0 и выше`

`Доступность: Сервер`

```
ЛокальФорматирования: Локаль?
```

Предпочитаемая настроенная локаль для отображения форматирования дат и чисел.

Пользователь может в явном виде выбрать язык способ форматирования дат и чисел. Например, формат дат в американском и британском вариантах английского языка - различаются.

Значение `Неопределено` означает, что пользователь не настроил отдельных предпочтений по форматированию и региональный формат данных будет установлен в соответствии с локалью отображения.
