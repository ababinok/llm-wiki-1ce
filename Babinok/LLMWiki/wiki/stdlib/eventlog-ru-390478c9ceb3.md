`Стд::ЖурналСобытий::ЖурналСобытий` `Тип-одиночка` `Доступность: Сервер`

Журнал событий. Позволяет регистрировать и искать события, сохраняемые в журнале событий.

## Методы

### Загрузить

`Доступность: Сервер`

```
Загрузить(Ид: Ууид): СобытиеЖурналаСобытий?
```

Возвращает событие по идентификатору

`Ид`

или

`Неопределено`

, если события с указанным идентификатором нет.

#### Примеры

```xbsl
метод ПолучитьСобытиеПоИд(ИдСобытия: Ууид): СобытиеЖурналаСобытий?
    возврат ЖурналСобытий.Загрузить(ИдСобытия)
;
```

### Найти

`Доступность: Сервер`

```
@ИменованныеПараметры
Найти(
  ДатаНачала: Момент? = Неопределено,
  ДатаОкончания: Момент? = Неопределено,
  Якорь: Ууид? = Неопределено,
  Ограничить: Число? = Неопределено,
  СортировкаПоДате: НаправлениеСортировки = НаправлениеСортировки.ПоУбыванию,
  ТипыСобытий: ЧитаемоеМножество<Строка|Тип<СобытиеЖурналаСобытий>>,
  ИдОперации: Ууид? = Неопределено,
  Фильтр: ((СобытиеЖурналаСобытий)->Булево)?
): РезультатПоискаСобытийЖурналаСобытий
```

>

Вызов возможен только с именованными параметрами

Доступен только именованный вызов. Ищет в журнале события, зарегистрированные в указанный интервал времени. Возвращает объект, позволяющий итерационно обработать все найденные события.

- `ДатаНачала`
  
  - если
  
  `Неопределено`
  
  , то поиск с начала журнала.
- `ДатаОкончания`
  
  - если
  
  `Неопределено`
  
  , то поиск до конца журнала.
- `Якорь`
  
  - идентификатор якорного события. Если указан, то в результате поиска будут события, следующие после него (с учетом всех фильтров и порядка).
- `Ограничить`
  
  - максимальное количество событий в результате.
  
  `Неопределено`
  
  - количество не ограничено
- `СортировкаПоДате`
  
  - направление сортировки выбранных событий по дате. По умолчанию
  
  [ПоВозрастанию](sortingdirection-ru-5a30152c0721.md)
  
  .
- `ТипыСобытий`
  
  - типы или полные имена типов событий для поиска, если пусто, то поиск по всем событиям. Используются и имена, и типы, т.к. пользователь должен иметь возможность искать по удаленным типам событий. Если Событие имело имя А, а потом его переименовали в Б, и в данном множестве передали Б для поиска, то события, записанные как А будут включены в результат. Если передали даты такие, в которые могло быть записано только А, то события А так же будут включены в результат.
- `ИдОперации`
  
  - идентификатор операции, все события которой хочет найти пользователь, если
  
  `Неопределено`
  
  - принадлежность к операции не учитывается.
- `Фильтр`
  
  - предикат будет применен после того, как событие прошло все остальные фильтры. Если предикат возвращает Истина (по умолчанию), то событие попадет в результат поиска, иначе не попадет.

Указанные фильтры между собой соединяются по И, т.е. в результат поиска попадут события, удовлетворяющие всем критериям поиска одновременно. Например, если заданы `ИдОперации`, `ТипыСобытий` и `Фильтр`, то ищутся события указанных в `ТипыСобытий` типов в указанной операции `ИдОперации`, `Фильтр` по которым вернет `Истина`.

#### Примеры

```xbsl
@НаСервере
метод ПолучитьВсеСобытияЗаСутки(): Массив<СобытиеЖурналаСобытий>
    знч От = Момент.Сейчас() - 1д
    знч До = Момент.Сейчас()
    
    пер События = новый Массив<СобытиеЖурналаСобытий>()
    
    исп РезультатПоиска = ЖурналСобытий.Найти(ДатаНачала=От, ДатаОкончания=До)
    пока РезультатПоиска.Следующий()
        События.Добавить(РезультатПоиска.Событие)
    ;
    
    // Закрывать явно необязательно, РезультатПоиска в любом случае будет закрыт после выхода из контекста метода
    РезультатПоиска.Закрыть()
    
    возврат События
;
```
