## Свойства

### Gray8

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Gray8
```

Оттенки серого, где одна точка определяется одним из 2^8 вариантов градации серого цвета.

---

### Gray16

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Gray16
```

Оттенки серого, где одна точка определяется одним из 2^16 вариантов градации серого цвета.

---

### Rgb

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Rgb
```

Изображение, в котором цвет точки определяется смешением красного, зеленого и синего цветов. На каждый цвет приходится 2^8 вариантов. На каждый из каналов тратится по 8 бит, а вместе они предоставляют 24 бита на точку.

---

### Argb

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Argb
```

Изображение, в котором цвет точки определяется смешением красного, зеленого и синего цветов, на каждый из которых приходится 2^8 вариантов. Так же, есть дополнительный альфа-канал, который определяет степень прозрачности. На каждый из каналов тратится по 8 бит, а вместе они предоставляют 32 бита на точку.
