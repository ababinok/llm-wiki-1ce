## Обзор

Содержит свойства для получения и изменения значений параметров отчета.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяОтчета}.Параметры` `Доступность: КлиентИСервер`

Содержит свойства для получения и изменения значений параметров отчета.

Если отчет содержит параметры, или источником данных отчета является запрос или виртуальная таблица с параметрами, установить их значения можно в конструкторе или через специальное свойство [ИмяОтчета.Параметры](reportname-parameters-ru-2d42387feb19.md).

Экземпляры данного типа доступны через специальное свойство [ИмяОтчета.Параметры](reportname-parameters-ru-2d42387feb19.md).

## Свойства

### {ИмяПараметра}

`Доступность: КлиентИСервер`

```
ИмяПараметра: <ТипПараметра>
```

Возвращает или устанавливает значение параметра отчета.

Имя и тип свойства соответствуют параметру отчета или запроса/виртуальной таблицы, используемой в качестве источника данных.
