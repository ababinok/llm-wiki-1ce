## Обзор

Структура в которой настраиваются возвращаемые для каждой записи данные: заголовок, фрагменты.

## Документированный контракт и примеры

`Стд::ПолнотекстовыйПоиск::НастройкиРезультатаПолнотекстовогоПоиска` `Доступность: Сервер`

Структура в которой настраиваются возвращаемые для каждой записи данные: заголовок, фрагменты.

Структурное

Два экземпляра равны, если попарно равны все свойства.

## Конструкторы

### НастройкиРезультатаПолнотекстовогоПоиска

`Доступность: Сервер`

```
@ИменованныеПараметры
НастройкиРезультатаПолнотекстовогоПоиска(
  ПолучатьЗаголовки: Булево = Истина,
  ПолучатьФрагменты: Булево = Истина,
  ПолучатьФрагментыПоСвойствам: Булево = Ложь,
  НастройкиФрагментов: НастройкиФрагментовПолнотекстовогоПоиска)
```

Полный конструктор. Требует указания именованных аргументов.

---

## Свойства

### НастройкиФрагментов

`Доступность: Сервер` `ТолькоЧтение`

```
НастройкиФрагментов: НастройкиФрагментовПолнотекстовогоПоиска
```

Настройки для поиска и оформления фрагментов текста с найденными ключевыми словами из поискового запроса. Значение по умолчанию: не задано, поле опциональное.

---

### ПолучатьЗаголовки

`Доступность: Сервер` `ТолькоЧтение`

```
ПолучатьЗаголовки: Булево
```

`Истина`, если нужно возвращать заголовки по каждой найденной записи.

---

### ПолучатьФрагменты

`Доступность: Сервер` `ТолькоЧтение`

```
ПолучатьФрагменты: Булево
```

`Истина`, если нужно искать и возвращать фрагменты текста с подсветкой найденных вхождений. Эти фрагменты используются для построения стандартного представления объекта [ЭлементРезультатаПолнотекстовогоПоиска](fulltextsearchresultitem-ru-4768069fde33.md). Если вам не нужны фрагменты, тогда передайте в этот параметр ложь, а также параметр [ПолучатьФрагментыПоСвойствам](fulltextsearchresultoptions-ru-44aadb7696df.md) должен оставаться в значении ложь. Без предоставления фрагментов поиск будет значительно быстрее возвращать порции результатов поиска.

---

### ПолучатьФрагментыПоСвойствам

`Доступность: Сервер` `ТолькоЧтение`

```
ПолучатьФрагментыПоСвойствам: Булево
```

`Истина`, если требуется заполнение массива [ФрагментыПоСвойствам](fulltextsearchresultitem-ru-4768069fde33.md) в котором фрагменты разделены по свойствам. В этом режиме появляется возможность получения метаданных по свойствам и информации по каждому фрагменту в контексте свойства.
