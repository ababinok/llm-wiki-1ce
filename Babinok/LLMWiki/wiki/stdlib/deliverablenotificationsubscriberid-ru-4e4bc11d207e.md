Роль: Программный тип XBSL.

Владелец: Std / DeliverableNotifications.

Имена для поиска: `ИдПодписчикаДоставляемыхУведомлений`, `DeliverableNotificationSubscriberId`, `Стд::ДоставляемыеУведомления::ИдПодписчикаДоставляемыхУведомлений`, `Std::DeliverableNotifications::DeliverableNotificationSubscriberId`.

## Обзор

Информация необходимая для отправки уведомлений в данное приложение с удаленного сервера.

## Документированный контракт и примеры

`Стд::ДоставляемыеУведомления::ИдПодписчикаДоставляемыхУведомлений` `Доступность: КлиентИСервер`

Информация необходимая для отправки уведомлений в данное приложение с удаленного сервера. Должен быть передан с клиента на сервер штатными способами.
