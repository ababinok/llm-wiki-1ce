## Обзор

Отслеживает изменения в одном или нескольких каталогах.

## Документированный контракт и примеры

`Стд::ВводВывод::Файлы::МониторФайловойСистемы` `Доступность: Сервер`

Отслеживает изменения в одном или нескольких каталогах.

**Сравнение**

Ссылочное

## Примеры

**Общие примеры**

```xbsl
пер Каталог1 = новый Файл("C:\\Directory1")
пер Каталог2 = новый Файл("C:\\Directory2")
исп Монитор = новый МониторФайловойСистемы()
// Создайте методы для изначальной обработки
// имеющихся в каталоге файлов и подкаталогов
// ОбработатьВесьКаталог(Каталог1)
// ОбработатьВесьКаталог(Каталог2)
Монитор.Отслеживать(Каталог1)
Монитор.Отслеживать(Каталог2,
        ВидыСобытий = ВидСобытияФайловойСистемы.Удаление,
        ИменаФайлов = "*.txt")
пока Истина
    // Ожидание новых событий
    пер МассивСобытий = Монитор.ПолучитьСобытия()
    для Событие из МассивСобытий
        если Событие.ВидСобытия == ВидСобытияФайловойСистемы.Создание
            // Создайте метод для обработки событий создания файлов.
            // Используйте свойство "Событие.Файл", чтобы получить
            // информацию о созданном файле
            // ОбработатьСоздание(Событие)
        ;
        если Событие.ВидСобытия == ВидСобытияФайловойСистемы.Удаление
            // Создайте метод для обработки событий удаления файлов.
            // Используйте свойство "Событие.Файл", чтобы получить
            // информацию об удаленном файле
            // ОбработатьУдаление(Событие)
        ;
         если Событие.ВидСобытия == ВидСобытияФайловойСистемы.ПотеряСобытий
            // Заново обработайте весь каталог при потере событий
            // ОбработатьВесьКаталог(Событие.Файл)
        ;
    ;
;
```

## Конструкторы

### МониторФайловойСистемы

`Доступность: Сервер`

```
МониторФайловойСистемы()
```

Создает объект типа МониторФайловойСистемы.

#### Исключения

**[ИсключениеФайловойСистемы](filesystemexception-ru-fd95df425388.md)** - произошла внутренняя ошибка МонитораФайловойСистемы. Например, если файловая система не поддерживает отслеживание событий.

## Методы

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Возвращает "FileSystemMonitor ", а затем - список отслеживаемых каталогов через пробел.

#### Исключения

**[ИсключениеФайловойСистемы](filesystemexception-ru-fd95df425388.md)** - произошла внутренняя ошибка МонитораФайловойСистемы.

**Переопределение** [Объект::ВСтроку](object-ru-9e351f286699.md)

---

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

Прекращает работу и перестает следить за изменениями во всех каталогах. Если монитор уже был закрыт, не производит никаких действий.

**Переопределение** [Закрываемое::Закрыть](closeable-ru-67cd73fca69d.md)

---

### Отслеживать

`Доступность: Сервер`

```
Отслеживать(
  Каталог: Файл,
  ВидыСобытий: ВидСобытияФайловойСистемы|ЧитаемаяКоллекция<ВидСобытияФайловойСистемы>|? = Неопределено,
  ИменаФайлов: Образец|Строка|ЧитаемаяКоллекция<Образец|Строка>|? = Неопределено,
  Глубина: Число? = Неопределено)
```

Добавляет каталог в очередь для отслеживания. Выбрасывает

[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)

, если аргумент

`Каталог`

не является каталогом. В аргументе

`ИменаФайлов`

могут указываться строки (в том числе может использоваться шаблон поиска), регулярные выражения. Если дополнительные аргументы не указаны, по умолчанию будут отслеживаться:

- события видов
  
  [Создание](filesystemeventkind-ru-f2ab8b7b9083.md)
  
  ,
  
  [Удаление](filesystemeventkind-ru-f2ab8b7b9083.md)
  
  ,
  
  [Изменение](filesystemeventkind-ru-f2ab8b7b9083.md)
  
  ,
  
  [ПотеряСобытий](filesystemeventkind-ru-f2ab8b7b9083.md)
  
  ;
- любого формата;
- с любым именем;
- неограниченной глубины вложенности.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - указан некорректный путь. **[ИсключениеФайловойСистемы](filesystemexception-ru-fd95df425388.md)** - произошла внутренняя ошибка МонитораФайловойСистемы.

---

### ПолучитьСобытия

`Доступность: Сервер`

```
ПолучитьСобытия(Таймаут: Длительность? = Неопределено): ЧитаемыйМассив<СобытиеФайловойСистемы>
```

Возвращает массив объектов

[СобытиеФайловойСистемы](filesystemevent-ru-d801763bb693.md)

, каждое событие удовлетворяет настройкам события для своего каталога. Если очередь в данный момент пуста, можно указать длительность ожидания новых событий в аргументе

`Таймаут`

. Возвращает пустой массив, если событий в очереди не появилось по истечении времени. При отсутствии аргумента

`Таймаут`

ожидание происходит до регистрации каких-либо событий, удовлетворяющих настройкам поиска.

#### Исключения

**[ИсключениеНедопустимоеСостояние](illegalstateexception-ru-4c1cc853b874.md)** - МониторФайловойСистемы уже закрыт и ничего не отслеживает. **[ИсключениеФайловойСистемы](filesystemexception-ru-fd95df425388.md)** - произошла внутренняя ошибка МонитораФайловойСистемы.
