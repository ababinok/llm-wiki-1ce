## Обзор

Объект, с помощью которого можно проверять электронную подпись формата CMS.

## Документированный контракт и примеры

`Стд::Криптография::ВерификаторПодписи` `Доступность: КлиентИСервер`

Объект, с помощью которого можно проверять электронную подпись формата CMS.

**Сравнение**

Ссылочное

*Базовые типы:* [Объект](object-ru-9e351f286699.md)

## Примеры

**Общие примеры**

```xbsl
метод ПроверитьПодпись(Данные: ПотокЧтения, Подпись: Байты): Булево
    знч Криптопровайдер = Криптография.ПолучитьBouncyCastle()

    знч Верификатор = новый ВерификаторПодписи(Криптопровайдер, Подпись)

    возврат Верификатор.Проверить(Данные)
;
```

## Конструкторы

### ВерификаторПодписи

`Доступность: Сервер`

```
ВерификаторПодписи(
  Криптопровайдер: Криптопровайдер|Строка,
  Подпись: Байты|ПотокЧтения)
```

Создает экземпляр объекта для проверки подписи формата CMS.

`Криптопровайдер`

- провайдер криптографии, который предоставляет алгоритмы чтения формата CMS.

`Подпись`

- байты электронной подписи формата CMS.

#### Исключения

**[ИсключениеКриптографии](cryptoexception-ru-9269fbee8009.md)** - если криптопровайдер не поддерживает чтение подписи формата CMS или при ошибке чтения данных подписи.

**Перегрузка** [ВерификаторПодписи(Подпись: Байты|ДвоичныйОбъект.Ссылка, Криптопровайдер: Криптопровайдер? = Неопределено)](signatureverifier-ru-dd5459cc034d.md)

---

### ВерификаторПодписи

`Доступность: Клиент`

```
ВерификаторПодписи(
  Подпись: Байты|ДвоичныйОбъект.Ссылка,
  Криптопровайдер: Криптопровайдер? = Неопределено)
```

Создает экземпляр объекта для проверки подписи формата CMS.

`Подпись` - байты электронной подписи формата CMS. `Криптопровайдер` - провайдер криптографии, который предоставляет алгоритмы чтения формата CMS. Если не указан, определяется автоматически

**Перегрузка** [ВерификаторПодписи(Криптопровайдер: Криптопровайдер|Строка, Подпись: Байты|ПотокЧтения)](signatureverifier-ru-dd5459cc034d.md)

## Свойства

### Криптопровайдер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Криптопровайдер: Криптопровайдер
```

Провайдер криптографии, который предоставляет алгоритмы чтения формата CMS.

---

### МоментПодписи

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
МоментПодписи: Момент?
```

Момент, в который на подпись был поставлен штамп времени. Если штамп времени отсутствует, то содержит момент вычисления подписи, указанный в данных подписи CMS.

## Методы

### ПолучитьДанныеИзПодписи

`Доступность: Клиент`

```
ПолучитьДанныеИзПодписи(): Байты?
```

Извлекает подписанные данные из электронной подписи. Если данные отсутствуют в подписи, т.е. она является отсоединенной, возвращается Неопределено

---

`Доступность: КлиентИСервер`

Возвращает цифровые сертификаты, которые хранятся в данных подписи CMS.
