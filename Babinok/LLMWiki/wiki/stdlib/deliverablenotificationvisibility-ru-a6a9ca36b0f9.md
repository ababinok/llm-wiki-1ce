## Свойства

### Личное

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Личное
```

Уведомление отображается на заблокированном экране, если устройство не защищено. На защищенном экране отображается без текста.

---

### Публичное

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Публичное
```

Уведомление всегда отображается на заблокированном экране.

---

### Секретное

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Секретное
```

Уведомление никогда не отображается на заблокированном экране.
