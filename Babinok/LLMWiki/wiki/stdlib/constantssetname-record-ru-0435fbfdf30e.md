### Записать

`Доступность: Сервер`

```
Записать()
```

Сохраняет значения набора констант

При включенной периодичности:

- если редактируется период для существующей записи в базе данных, то при сохранении будет произведено обновление периода у существующей записи, а не дублирование записи в новый период
- если другая запись с данным периодом существует, то будет выброшено исключение ИсключениеЗаписьНеУникальна

**Перегрузка** [Записать(ПараметрыЗаписи: ИмяНабораКонстант.ПараметрыЗаписи)](constantssetname-record-ru-0435fbfdf30e.md)

#### Примеры

```xbsl
метод Записать(Период: Дата, Const1: String, Const2: Number)
  знч Запись = новый ИмяНабораКонстант.Запись(Период = Период, Const1Name = Const1, Const2Name = Const2)
  Запись.Записать()
;
```

## Обработчики

### ПередЗаписью

`Версия 10.0 и выше`

```
ПередЗаписью(
  До: НаборКонстант.Данные,
  ПараметрыЗаписи: НаборКонстант.ПараметрыЗаписи)
```

Обработчик, вызывается при вызове метода Записать(), после того как начата транзакция и захвачена блокировка. Для новых записей параметр

`До`

соответствует текущему состоянию набора записей. Параметр

`До`

содержит данные исходной записи набора констант.

#### Примеры

```xbsl
@Обработчик
метод ПередЗаписью(До: ИмяНабораКонстант.Данные, ПараметрыЗаписи: ИмяНабораКонстант.ПараметрыЗаписи)
    если Const2Name <= 0
        Const2Name = До.Const2Name
    ;
;
```

### ПриСозданииКопии

`Версия 10.0 и выше`

```
ПриСозданииКопии(Источник: ConstantsSetName.Данные)
```

Вызывается при создании нового экземпляра записи периодического набора констант копированием существующей. На момент вызова этого обработчика значения констант у новой записи будут уже заполнены из записи - источника. Не будет автоматически копироваться стандартное поле

`Период`

набора констант. Кроме того, не будут копироваться константы, копирование которых отключено в наборе констант с помощью свойства

`ЗаполнятьПриКопировании`

.

Параметр `Источник` содержит данные исходной записи набора констант, копированием которой и создается новая запись.

Обработчик не доступен при выключенной периодичности.

#### Примеры

В проекте есть периодический набор констант "ИмяНабораКонстант". Необходимо сделать так, чтобы при копировании записи этого набора констант у стандартного поля "Период" проставлялась текущая дата

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: ИмяНабораКонстант.Данные)
    Период = Дата.Сейчас()
;
```
