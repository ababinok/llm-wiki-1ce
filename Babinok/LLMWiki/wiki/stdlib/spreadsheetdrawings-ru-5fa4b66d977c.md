## Методы

### ПолучитьВсеРисунки

`Доступность: Сервер`

```
ПолучитьВсеРисунки(): ЧитаемыйМассив<РисунокТабличногоДокумента>
```

Получить все рисунки табличного документа.

---

### ПолучитьИзображение

`Доступность: Сервер`

```
ПолучитьИзображение(ИмяРисунка: Строка): ИзображениеТабличногоДокумента
```

Получить рисунок-изображение по имени.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - Если по имени запрашивается область.

---

### ПолучитьИменаВсехРисунков

`Доступность: Сервер`

```
ПолучитьИменаВсехРисунков(): ЧитаемыйМассив<Строка>
```

Получить имена всех рисунков табличного документа.

---

### ПолучитьРисунок

`Доступность: Сервер`

```
ПолучитьРисунок(ИмяРисунка: Строка): РисунокТабличногоДокумента
```

Получить рисунок по имени.

---

### СоздатьИзображение

`Доступность: Сервер`

```
СоздатьИзображение(): ИзображениеТабличногоДокумента
```

Создать изображение в табличном документе (будет помещен в начало документа - верхний левый угол).

---

### УдалитьВсеРисунки

`Доступность: Сервер`

```
УдалитьВсеРисунки()
```

Удалить все рисунки из табличного документа.

---

### УдалитьРисунок

`Доступность: Сервер`

```
УдалитьРисунок(Рисунок: РисунокТабличногоДокумента)
```

Удалить рисунок из табличного документа.
