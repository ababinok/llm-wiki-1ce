Роль: Программный тип XBSL.

Владелец: Std / GeographicMaps.

Имена для поиска: `НастройкиОформленияГеографическойКарты`, `GeographicMapDesignSettings`, `Стд::ГеографическиеКарты::НастройкиОформленияГеографическойКарты`, `Std::GeographicMaps::GeographicMapDesignSettings`.

## Обзор

Структура, в которой задаются пользовательские настройки внешнего вида объектов на карте: иконки и цвета маркеров, групповых маркеров и маршрутов.

## Документированный контракт и примеры

`Стд::ГеографическиеКарты::НастройкиОформленияГеографическойКарты` `Доступность: КлиентИСервер`

## Конструкторы

### НастройкиОформленияГеографическойКарты

`Доступность: КлиентИСервер`

```
НастройкиОформленияГеографическойКарты(
  ИконкаМаркеров: Авто|Url|ДвоичныйОбъект.Ссылка,
  ИконкаГрупповыхМаркеров: Авто|Url|ДвоичныйОбъект.Ссылка,
  ЦветТекстаГрупповыхМаркеров: Авто|Цвет,
  ЦветЛинийМаршрутов: Авто|Цвет,
  ИконкаНачалаМаршрутов: Авто|Url|ДвоичныйОбъект.Ссылка,
  ИконкаКонцаМаршрутов: Авто|Url|ДвоичныйОбъект.Ссылка,
  ИконкаМаркераГеолокации: Авто|Url|ДвоичныйОбъект.Ссылка)
```

Создает объект

[НастройкиОформленияГеографическойКарты](geographicmapdesignsettings-ru-026ef99513d0.md)

со значениями свойств, соответствующими параметрам конструктора.

## Свойства

### ИконкаГрупповыхМаркеров

`Доступность: КлиентИСервер`

```
ИконкаГрупповыхМаркеров: Авто|Url|ДвоичныйОбъект.Ссылка
```

Иконка групповых маркеров.

Если [Авто](auto-ru-1b14ed166f8e.md), используется иконка по умолчанию.

---

```

```

Иконка промежуточных и конечных точек маршрутов.

Если [Авто](auto-ru-1b14ed166f8e.md), используется иконка по умолчанию

---

### ИконкаМаркераГеолокации

```

Иконка маркера текущей геолокации.

Если [Авто](auto-ru-1b14ed166f8e.md), используется иконка по умолчанию.

```

`Доступность: КлиентИСервер`

```
ИконкаНачалаМаршрутов: Авто|Url|ДвоичныйОбъект.Ссылка
```

Иконка начальных точек маршрутов.

Если [Авто](auto-ru-1b14ed166f8e.md), используется иконка по умолчанию.

### ЦветЛинийМаршрутов

`Доступность: КлиентИСервер`

```
ЦветЛинийМаршрутов: Авто|Цвет
```

Цвет линий маршрутов на карте.

[Авто](auto-ru-1b14ed166f8e.md) разрешается, как [Красный](colors-ru-a841affb57c9.md).

---

### ЦветТекстаГрупповыхМаркеров

`Доступность: КлиентИСервер`

```
ЦветТекстаГрупповыхМаркеров: Авто|Цвет
```

Цвет текста числа объединенных в групповой маркер обычных маркеров.

[Авто](auto-ru-1b14ed166f8e.md) разрешается, как [АкцентныйПервичный](../interface/stylecolors-ru-20af25031776.md)
