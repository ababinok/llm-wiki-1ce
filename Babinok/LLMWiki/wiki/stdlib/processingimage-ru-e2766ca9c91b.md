## Методы

### ВОттенкиСерого

`Доступность: Сервер`

```
ВОттенкиСерого(): ОбрабатываемоеИзображение
```

Преобразует результирующее изображение в оттенки серого. Для

[Png](imageformat-ru-743e0c49d366.md)

с 16 бит, остальные форматы с 8 битами на цвет. Возвращает текущий экземпляр.

---

### ВыбратьОбласть

`Доступность: Сервер`

```
ВыбратьОбласть(
  X: Число,
  Y: Число,
  Ширина: Число,
  Высота: Число
): ОбрабатываемоеИзображение
```

Выбирает обрабатываемую область на исходном изображении. (

`X`

,

`Y`

) - координаты верхнего левого угла области.

`Ширина`

- ширина области.

`Высота`

- высота области.

---

### Масштабировать

`Доступность: Сервер`

```
Масштабировать(Множитель: Число): ОбрабатываемоеИзображение
```

Устанавливает множитель

`Множитель`

для размера изображения, применяемого после остальных преобразований. Вызов одновременно с

[УстановитьРазмер](processingimage-ru-e2766ca9c91b.md)

,

[УстановитьШирину](processingimage-ru-e2766ca9c91b.md)

,

[УстановитьВысоту](processingimage-ru-e2766ca9c91b.md)

приведет к ошибке.

Возвращает текущий экземпляр.

---

### ОбрезатьПоКругу

`Доступность: Сервер`

```
ОбрезатьПоКругу(): ОбрабатываемоеИзображение
```

Вырезает круглое изображение из исходного: картинка берется по центру, диаметр круга равен минимальному значению между длиной и шириной исходной картинки. Возвращает текущий экземпляр.

---

### Повернуть

`Доступность: Сервер`

```
Повернуть(Угол: Число): ОбрабатываемоеИзображение
```

Повернуть изображение по часовой стрелке на указанное число градусов

`Угол`

. При повороте не на 90°, 180°, 270° будут образовываться пустоты, которые:

1. [Jpeg](imageformat-ru-743e0c49d366.md)
  
  ,
  
  [Bmp](imageformat-ru-743e0c49d366.md)
  
  ,
  
  [Tiff](imageformat-ru-743e0c49d366.md)
  
  - заполняются черным цветом.
2. [Png](imageformat-ru-743e0c49d366.md)
  
  ,
  
  [Gif](imageformat-ru-743e0c49d366.md)
  
  - заполняются прозрачностью. Совместно с
  
  [Масштабировать](processingimage-ru-e2766ca9c91b.md)
  
  - пустоты будут образовываться во внешнем от изображения пространстве, Совместно с
  
  [УстановитьРазмер](processingimage-ru-e2766ca9c91b.md)
  
  ,
  
  [УстановитьШирину](processingimage-ru-e2766ca9c91b.md)
  
  ,
  
  [УстановитьВысоту](processingimage-ru-e2766ca9c91b.md)
  
  ) изображение будет вписано в указанный размер.

Возвращает текущий экземпляр.

---

### ПолучитьИзображение

`Доступность: Сервер`

```
ПолучитьИзображение(): Байты
```

Возвращает результат перекодирования в виде байтов.

#### Исключения

**[ИсключениеВводаВывода](inputoutputexception-ru-ceba5f672999.md)** - если произошли проблемы при перекодированнии изображения, связанные с вводом-выводом. **[ИсключениеНедопустимоеСостояние](illegalstateexception-ru-4c1cc853b874.md)** - если настройки перекодирования приводят к конфликту.

---

### УстановитьВысоту

`Доступность: Сервер`

```
УстановитьВысоту(Высота: Число): ОбрабатываемоеИзображение
```

Здает высоту изображения

`Высота`

. Если не будет задана ширина, то изображение будет изменено с сохранением соотношения сторон. Возвращает текущий экземпляр.

---

### УстановитьРазмер

`Доступность: Сервер`

```
УстановитьРазмер(
  Ширина: Число,
  Высота: Число,
  СохранятьСоотношениеСторон: Булево = Истина
): ОбрабатываемоеИзображение
```

Установить размер исходя из ширина

`Ширина`

и высота

`Высота`

. В случае, если ширина и высота в соотношении друг с другом были изменены и

`СохранятьСоотношениеСторон`

=

`Ложь`

, то пропорции сохранены не будут, иначе изображение будет вписано в заданный прямоугольник. Возвращает текущий экземпляр.

---

`Формат`

---

`ЦветовойФормат`

---

