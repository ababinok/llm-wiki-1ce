## Методы

### ПоддерживаетсяГеолокация

`Доступность: Клиент`

```
ПоддерживаетсяГеолокация(): Булево
```

Проверяет, поддерживаются ли службы геолокации.

Прошлые имена: ПоддерживаетсяГеопозиционирование

---

### ПолучитьПоставщика

`Доступность: Клиент`

```
ПолучитьПоставщика(ИмяПоставщика: Строка): ПоставщикГеолокации?
```

Возвращает поставщика гелокации по имени.

Возвращаемое значение - объект `ПоставщикГеолокации` или `Неопределенно`, если поставщик геолокации с указанным именем не найден.

---

### ПолучитьПоставщиков

`Доступность: Клиент`

```
ПолучитьПоставщиков(): ЧитаемыйМассив<ПоставщикГеолокации>
```

Возвращает доступных поставщиков геолокации.

---

### ПолучитьСамогоТочногоПоставщика

`Доступность: Клиент`

```
ПолучитьСамогоТочногоПоставщика(): ПоставщикГеолокации?
```

Возвращает поставщика геолокации, который обеспечивает максимальную точность определения координат. Если доступные провайдеры отсутствуют, возвращается

`Неопределенно`

.

---

### ПолучитьСамогоЭнергосберегающегоПоставщика

`Доступность: Клиент`

```
ПолучитьСамогоЭнергосберегающегоПоставщика(): ПоставщикГеолокации?
```

Возвращает поставщика геолокации, который обеспечивает минимальное энергопотребление. Если доступные провайдеры отсутствуют, возвращается

`Неопределенно`

.
