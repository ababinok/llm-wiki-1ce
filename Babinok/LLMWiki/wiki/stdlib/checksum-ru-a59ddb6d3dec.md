## Методы

### ВычислитьCrc32

`Доступность: Сервер`

```
ВычислитьCrc32(Данные: Байты|ПотокЧтения): Число
```

Возвращает контрольную сумму для

`Данные`

по алгоритму CRC32 (Cyclic redundancy check, Циклический избыточный код).
