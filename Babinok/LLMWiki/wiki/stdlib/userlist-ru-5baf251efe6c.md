## Примеры

**Сравнение**

Создается новый список пользователей с возможностью самостоятельной регистрации. Подтверждение пользователей выполняется путем отправки СМС через шлюз с адресом [http://example.org/send](http://example.org/send). При отправке смс, в сообщения не будут включаться личные данные пользователей.

```xbsl
метод СоздатьСписокПользователей(Название: Строка, ИдПриложенияВСмсШлюзе: Строка): СписокПользователей
    пер СписокПользователей = новый СписокПользователей(Название)
        .ССамостоятельнойРегистрацией(Истина, новый НастройкиСамостоятельнойРегистрацииПользователей(ТребуетсяТелефон = Истина))
        .СЛичнымиДаннымиВСообщениях(Ложь)
        .СНастройкамиАктивации(новый НастройкиАктивацииПользователей(АктивацияПоТелефону = Истина))

    СписокПользователей.ШлюзыSms.Добавить(новый ШлюзSms("http://example.org/send", ИдПриложенияВСмсШлюзе))
    возврат СписокПользователей
;
```

### ПолитикаПаролейВключена

`Доступность: КлиентИСервер` `ТолькоЧтение`

```

```

Признак, что используется политика паролей.

---

### РазрешенаСамостоятельнаяРегистрация

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
РазрешенаСамостоятельнаяРегистрация: Булево
```

Признак, что пользователи могут сами регистрироваться в данном списке. Если разрешена, то человек может завести для себя пользователя пользуясь ссылкой на страничке аутентификации.

Если на приложении включена опция автоматического подключения пользователей из данного списка, то пользователь сможет сразу войти в такое приложение.

---
