## Обзор

Описывает круговую область на географической карте.

## Документированный контракт и примеры

`Версия 9.0 и выше`

`Стд::Геолокация::Геозона` `Доступность: Клиент`

Описывает круговую область на географической карте.

**Сравнение**

Ссылочное

*Базовые типы:* [Объект](object-ru-9e351f286699.md)

## Примеры

**Общие примеры**

```xbsl
пер Координаты = новый ГеографическиеКоординаты(37, 56, 0)
пер Геозона = новый Геозона("Тест", Координаты, 100)

Геозоны.Добавить([Геозона])
```

## Конструкторы

### Геозона

`Доступность: Клиент`

```
Геозона(
  Координаты: ГеографическиеКоординаты,
  Радиус: Число)
```

Создает объект

`Геозона`

на основании географических координат и радиуса в метрах. Идентификатор будет присвоен автоматически.

**Перегрузка** [Геозона(Идентификатор: Строка, Координаты: ГеографическиеКоординаты, Радиус: Число)](geofence-ru-4d6e63f22657.md)

---

### Геозона

`Доступность: Клиент`

```
Геозона(
  Идентификатор: Строка,
  Координаты: ГеографическиеКоординаты,
  Радиус: Число)
```

Создает объект

`Геозона`

на основании идентификатора, географических координат и радиуса в метрах. Если передан пустой идентификатор или отрицательный радиус, будет выброшено

`ИсключениеНедопустимыйФормат`

.

**Перегрузка** [Геозона(Координаты: ГеографическиеКоординаты, Радиус: Число)](geofence-ru-4d6e63f22657.md)

### Идентификатор

`Доступность: Клиент` `ТолькоЧтение`

```

```

Возвращает идентификатор геозоны.

---

### Координаты

`Доступность: Клиент` `ТолькоЧтение`

```

```

Возвращает географические координаты центра геозоны.

---

`Доступность: Клиент` `ТолькоЧтение`

```
Радиус: Число
```

Возвращает радиус геозоны в метрах.
