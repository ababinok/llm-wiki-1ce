## Примеры

**Общие примеры**

```xbsl
метод ПолучитьДанныеПоследнейГеолокации()
    пер Поставщик = Геолокация.ПолучитьСамогоТочногоПоставщика()
    
    если Поставщик != Неопределено
        пер ДанныеГеолокации = Поставщик.ПолучитьДанныеПоследнейГеолокации()
        // Обработка полученных данных о геолокации
        ОбработкаГеолокации(ДанныеГеолокации)
    иначе
        // Не удалось получить поставщика геолокации
    ;
;

метод НачатьОтслеживание()
  пер Поставщик = Геолокация.ПолучитьСамогоТочногоПоставщика()
  
  если Поставщик != Неопределено
    пер Длительность = 5с
    пер Дистанция = 0
	пер РаботаВФоне = Истина
	
    если Поставщик.ПодключитьОбработчикИзмененияГеолокации(Длительность, 
        Дистанция, РаботаВФоне, &ОбработкаГеолокации)
        // Обработчик подключен
    иначе
        // Не удалось подключить обработчик
    ;
  иначе
    // Не удалось получить поставщика геоданных
  ;
;
 
метод ОбработкаГеолокации(Данные: ДанныеГеолокации)
    // Дата и время обновления координат
    пер Дата = Данные.Дата
    // Получение координат геолокации пользователя
    пер Широта = Данные.Координаты.Широта
    пер Долгота = Данные.Координаты.Долгота
    Сообщить("Широта: %Широта, Долгота: %Долгота, Дата: %Дата")
;
```

## Методы

### ОтключитьОбработчикИзмененияГеолокации

`Доступность: Клиент`

```
ОтключитьОбработчикИзмененияГеолокации(Обработчик: (ДанныеГеолокации)->ничто)
```

Выключает периодическое обновление координат.

`Обработчик` - ссылка на обработчик, подключенный в методе `ПодключитьОбработчикИзмененияМестоположения`.

Прошлые имена: ОтключитьОбработчикИзмененияМестоположения

---

### ПодключитьОбработчикИзмененияГеолокации

`Доступность: Клиент`

```
ПодключитьОбработчикИзмененияГеолокации(
  Период: Длительность,
  Дистанция: Число,
  ОбновлениеВФоне: Булево,
  Обработчик: (ДанныеГеолокации)->ничто
): Булево
```

Включает периодическое обновление координат.

Метод принимает следующие параметры:

- `Период`
  
  - время минимального периода обновления координат;
- `Дистанция`
  
  - минимальная дистанция в метрах, на которую должно передвинуться устройство для срабатывания обработчика;
- `РаботаВФоне`
  
  - указывает, что приложение может получать данные о геолокации в фоновом режиме;
- `Обработчик`
  
  - ссылка на функцию-обработчик, которая будет вызываться при получении новой геолокации. Обработчик должен принимать объект типа
  
  `ДанныеГеолокации`
  
  .

Возвращаемое значение - `Истина`, если обработчик успешно подключен, или `Ложь`, если при подключении произошла ошибка.

Прошлые имена: ПодключитьОбработчикИзмененияМестоположения

---

### ПолучитьДанныеПоследнейГеолокации

`Доступность: Клиент`

```
ПолучитьДанныеПоследнейГеолокации(): ДанныеГеолокации?
```

Возвращает последние известные данные о геолокации пользователя.

Возвращаемое значение - объект `ДанныеМестоположения`, содержащий географические координаты местоположения пользователя. Если пользователь не дал разрешение на доступ к геолокации или не удалось определить его последнее местоположение, возвращается `Неопределено`.

Прошлые имена: ПолучитьПоследнееМестоположение

---
