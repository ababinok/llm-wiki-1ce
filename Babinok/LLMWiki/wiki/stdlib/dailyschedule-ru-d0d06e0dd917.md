Имена для поиска: `ЕжедневноеРасписание`, `DailySchedule`, `Стд::Расписания::ЕжедневноеРасписание`, `Std::Schedules::DailySchedule`.

## Обзор

Расписание запусков раз в указанное число дней.

## Документированный контракт и примеры

`Стд::Расписания::ЕжедневноеРасписание` `Доступность: КлиентИСервер`

Расписание запусков раз в указанное число дней. Создается через методы объекта [Расписание](schedule-ru-f8ef0f9119e6.md).

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](object-ru-9e351f286699.md), [Расписание](schedule-ru-f8ef0f9119e6.md)

## Примеры

**Общие примеры**

```xbsl
// Расписание запуска через день в 8 утра.
знч ЧерезДень = Расписание.Ежедневно(Время{8:00}, ПериодПовтораДней = 2)

пер Задание = ЗапланированныеЗадания.Создать(&МойМодуль.МойМетод)
Задание.Настроить(Ключ = "МоеЗадание", Расписание = ЧерезДень)
Задание.Запланировать()
```

## Свойства

### ЗапуститьВ

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ЗапуститьВ: Время
```

Время запуска задания. Задается при создании расписания.

---

### ПериодПовтораДней

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПериодПовтораДней: Число
```

Раз в какое число дней запускать задание. Задается при создании расписания.
