## Конструкторы

### ДоставляемоеУведомление

`Доступность: КлиентИСервер`

```
ДоставляемоеУведомление(
  Ид: Строка = "",
  Заголовок: Строка = "",
  Текст: Строка = "",
  Данные: Строка = "",
  Триггер: ТриггерДоставляемыхУведомленийПоКалендарю|ТриггерДоставляемыхУведомленийПоСпискуПолучателей|ТриггерДоставляемыхУведомленийПоИнтервалуВремени|? = Неопределено,
  Канал: Строка = "",
  Категория: Строка = "")
```

Создает новое уведомление.

`Ид` - Уникальный идентификатор уведомления. `Заголовок` - Заголовок уведомления. `Текст` - Текст уведомления. `Данные` - Дополнительные данные уведомления. `Триггер` -Триггер уведомления. `Канал` - Строковый идентификатор канала уведомлений. `Категория` - Категория уведомления.

## Свойства

### Видимость

`Доступность: КлиентИСервер`

```
Видимость: ВидимостьДоставляемогоУведомления
```

Видимость уведомления. Используется только в Android.

---

### Группа

`Доступность: КлиентИСервер`

```
Группа: Строка
```

Строковый идентификатор группы для объединения уведомлений.

---

### Данные

`Доступность: КлиентИСервер`

```
Данные: Строка
```

Дополнительные данные уведомления, в уведомлении не отображаются. Отправитель может передать получателю команду (например, запрос сеанса связи).

---

### ДатаДоставки

`Доступность: КлиентИСервер`

```
ДатаДоставки: Момент?
```

Дата и время фактической доставки уведомления.

---

### Заголовок

`Доступность: КлиентИСервер`

```
Заголовок: Строка
```

Заголовок уведомления, который будет отображаться в системной области. Не используется в уведомлениях для iOS версии ниже 8.2. Если пустая строка в заголовке уведомления отображается название приложения.

---

### ЗвуковоеОповещение

`Доступность: КлиентИСервер`

```
ЗвуковоеОповещение: ЗвуковоеОповещениеДоставляемогоУведомления|Строка
```

Звуковое оповещение системного уведомления, которое появляется на устройстве под управлением iOS или Android, если мобильное приложение не активно. Может быть задан либо в виде стандартного звукового оповещения, либо в виде текстовой строки с именем аудиофайла. Если оповещение задано именем файла, файл должен быть добавлен в ресурсы мобильного приложения. Файл может быть указан без расширения. В этом случае на платформе iOS будет использован файл с расширением "caf", на платформе Android - с расширением "mp3".
