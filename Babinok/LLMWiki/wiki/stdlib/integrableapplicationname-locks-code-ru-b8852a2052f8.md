## Обзор

Блокировка для пространства блокировок `Код` интегрируемого приложения {ИмяИнтегрируемогоПриложения}.

## Документированный контракт и примеры

`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяИнтегрируемогоПриложения}.Блокировки.Код` `Доступность: Сервер`

Блокировка для пространства блокировок `Код` интегрируемого приложения {ИмяИнтегрируемогоПриложения}. Пространство используется для блокировки объектов интегрируемого приложения по значению поля `Код`. Доступно только если у интегрируемого приложения есть стандартный реквизит Код.

## Конструкторы

### {ИмяИнтегрируемогоПриложения}.Блокировки.Код

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяИнтегрируемогоПриложения}.Блокировки.Код(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Код: <ТипКода>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
