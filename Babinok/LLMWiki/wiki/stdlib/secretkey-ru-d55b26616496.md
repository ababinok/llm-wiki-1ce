## Конструкторы

### СекретныйКлюч

`Доступность: Сервер`

```
СекретныйКлюч(
  Данные: Байты|ПотокЧтения,
  Алгоритм: АлгоритмСимметричногоШифрования|Строка,
  Криптопровайдер: Криптопровайдер|Строка|? = Неопределено)
```

Создает новый экземпляр объекта секретного ключа.

#### Исключения

**[ИсключениеКриптографии](cryptoexception-ru-9269fbee8009.md)** - если `Данные` не являются данными секретного ключа или параметры `Алгоритм` или `Криптопровайдер` содержат недопустимые значения

#### Примеры

```xbsl
    знч ГенераторAes = новый ГенераторСекретногоКлюча(АлгоритмСимметричногоШифрования.Aes)
    знч КлючAes = ГенераторAes.СоздатьСекретныйКлюч()

    знч НовыйAes = новый СекретныйКлюч(КлючAes.ПолучитьДанные(), "AES")
```

## Методы

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Вывод в строку названия алгоритма шифрования и ключа шифрования в шестнадцатеричном представлении в формате

`Алгоритм`

:

`СекретныйКлюч`

**Переопределение** [Объект::ВСтроку](object-ru-9e351f286699.md)

---

### ПолучитьДанные

`Доступность: Сервер`

```
ПолучитьДанные(): Байты
```

Возвращает байтовое представление значения ключа.

#### Примеры

```xbsl
    знч ГенераторAes = новый ГенераторСекретногоКлюча(АлгоритмСимметричногоШифрования.Aes)
    знч Данные = ГенераторAes.СоздатьСекретныйКлюч().ПолучитьДанные()
```
