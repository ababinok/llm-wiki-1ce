## Методы

### СоздатьФормуСписка

`Доступность: Клиент`

```
СоздатьФормуСписка(): ФормаСписка
```

Создает форму списка журнала данных. Если журналу данных назначена форма списка, то будет создана форма ровно этого типа. Иначе будет создана автоматическая форма типа
