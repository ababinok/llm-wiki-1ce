## Обзор

Коллекции хранят наборы значений. `Массив<ТипЭлемента>` поддерживает доступ по индексу и повторяющиеся элементы. `Множество<ТипЭлемента>` содержит уникальные элементы и не поддерживает доступ по индексу. `Соответствие<ТипКлюча, ТипЗначения>` хранит пары ключ–значение с уникальными ключами.

## Общий контракт и изменяемость

В основе иерархии находится `Обходимое<ТипЭлемента>`. Документация различает обычные и фиксированные коллекции: фиксированные не позволяют менять состав. Проверяйте конкретный тип при добавлении, удалении и изменении элементов.

## Обработка значений

Для коллекций доступны методы последовательной обработки. Сверяйте, какой метод продолжает последовательность, а какой завершает обработку. Наследуемые методы ищите в базовых типах, а не только в собственных членах выбранного типа.

## Использование справочника

Для каждого вызова проверяйте полное имя типа, параметры обобщения, перегрузку, возвращаемый тип и исключения. Результат запроса может поддерживать контракт обхода; способ обработки определяется его фактическим типом.
