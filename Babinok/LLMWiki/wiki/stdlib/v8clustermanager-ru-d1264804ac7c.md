## Свойства

### ГлавныйМенеджер

`Доступность: Сервер` `ТолькоЧтение`

```
ГлавныйМенеджер: Булево
```

Указывает, является ли менеджер главным или дополнительным менеджером кластера.

---

### ИдМенеджераКластера

`Доступность: Сервер` `ТолькоЧтение`

```
ИдМенеджераКластера: Ууид
```

Идентификатор менеджера кластера.

---

### ИдПроцесса

`Доступность: Сервер` `ТолькоЧтение`

```
ИдПроцесса: Строка
```

Идентификатор процесса операционной системы дополнительного менеджера кластера.

---

### ИмяКомпьютера

`Доступность: Сервер` `ТолькоЧтение`

```
ИмяКомпьютера: Строка
```

Имя или IP-адрес рабочего сервера, на котором должен запущен процесс 'rmngr' менеджера кластера. Значение свойства совпадает с именем или адресом одного из рабочих серверов, определенных в кластере.

---

### Описание

`Доступность: Сервер` `ТолькоЧтение`

```
Описание: Строка
```

Описание менеджера кластера.

---

### Порт

`Доступность: Сервер` `ТолькоЧтение`

```
Порт: Число
```

Основной порт менеджера кластера (от 0 до 65535). Выбирается кластером серверов автоматически из диапазонов портов для динамического занятия, определенных для рабочего сервера.
