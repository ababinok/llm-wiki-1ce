## Конструкторы

### ГеографическийМаршрут

`Доступность: КлиентИСервер`

```
ГеографическийМаршрут(
  Точки: ЧитаемыйМассив<ГеографическиеКоординаты>,
  ТочкиОстановки: ЧитаемыйМассив<ГеографическиеКоординаты>,
  Длина: Число,
  ПрогнозируемаяДлительность: Длительность,
  Вид: ВидГеографическогоМаршрута)
```

Создает объект

[ГеографическийМаршрут](geographicroute-ru-114ec62ddb30.md)

со значениями свойств, соответствующими параметрам конструктора.

## Свойства

### Вид

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Вид: ВидГеографическогоМаршрута
```

Тип передвижения, для которого построен маршрут.

---

### Длина

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Длина: Число
```

Длина маршрута в метрах.

---

### ПрогнозируемаяДлительность

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПрогнозируемаяДлительность: Длительность
```

Примерная прогнозируемая длительность преодоления маршрута.

---

### Точки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Точки: ЧитаемыйМассив<ГеографическиеКоординаты>
```

Координаты точек, задающих маршрут, линию маршрута.

---

### ТочкиОстановки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ТочкиОстановки: ЧитаемыйМассив<ГеографическиеКоординаты>
```

Координаты промежуточных точек остановки, которые учитывались при построении маршрута.
