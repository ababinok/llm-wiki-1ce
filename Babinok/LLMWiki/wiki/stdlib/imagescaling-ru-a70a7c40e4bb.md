Определяет способ вывода изображения.

## Документированный контракт и примеры

`Стд::Изображения::МасштабированиеИзображения` `Доступность: КлиентИСервер`

## Свойства

### Автоматическое

`Версия 9.0 и выше`

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Автоматическое
```

Если указанные разработчиком размеры больше реальных размеров картинки, используется [РеальныйРазмер](imagescaling-ru-a70a7c40e4bb.md), иначе [Пропорционально](imagescaling-ru-a70a7c40e4bb.md).

---

### Растянуть

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Растянуть
```

Картинка будет заданных разработчиком размеров. Если они не соотносятся с размерами картинки, она будет соответствующим образом искажена.

---

### РеальныйРазмер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
РеальныйРазмер
```

Картинка отображается своим реальным размером. Если размер картинки больше размера компонента, то края картинки будут обрезаны.

---

### Пропорционально

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Пропорционально
```

Картинка растягивается или сжимается таким образом, что бы занять всю указанную ширину или высоту.

---

### Заполнить

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Заполнить
```

Аналогично [Пропорционально](imagescaling-ru-a70a7c40e4bb.md), но допускает обрезание краев картинки, если пропорции размеров компонента, указанные разработчиком, не соответствуют пропорциям картинки.

---

### Авто

`Версия 8.0 и ниже`

> **Исторический контракт:** верхняя граница версии 8.0; не используйте этот член для 10.0.


`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Авто
```

Элемент перечисления был переименован в [Автоматическое](imagescaling-ru-a70a7c40e4bb.md)

Если указанные разработчиком размеры больше реальных размеров картинки, используется [РеальныйРазмер](imagescaling-ru-a70a7c40e4bb.md), иначе [Пропорционально](imagescaling-ru-a70a7c40e4bb.md).
