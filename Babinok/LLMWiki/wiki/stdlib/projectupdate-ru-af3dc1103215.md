## Обзор

Используется для пометки методов обновления данных приложения.

## Документированный контракт и примеры

`Стд::Аннотации::Проект::ОбновлениеПроекта` `Доступность: КлиентИСервер`

`Места применения:` Статический метод, Метод

Используется для пометки методов обновления данных приложения. Параметры аннотации - идентификатор обновления и порядковый номер выполнения.

Проверяется уникальность идентификатора и номера в рамках приложения. Разрешается использовать только в модуле проекта Разрешается использовать только на методах без параметров или методах, принимающих два параметра типа [Версия](version-ru-29e92504e99e.md) (исходная версия, целевая версия)

## Параметры

### Ид

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Ид
```

Уникальный идентификатор обновления.

Идентификатор не может повторяться с идентификаторами, используемыми в аннотации [НастройкаПриложения](applicationsetup-ru-cc9bbca6abc2.md)

---

### Номер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Номер
```

Порядковый номер обновления.
