## Обзор

Вид элемента проекта, который порождает тип-одиночку глобального клиентского события.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяГлобальногоКлиентскогоСобытия}` `Тип-одиночка` `Доступность: Клиент`

Вид элемента проекта, который порождает тип-одиночку глобального клиентского события. Каждый тип представляет собой отдельное событие, на которое можно подписаться и отписаться. Также при помощи данного типа-одиночки можно оповестить подписчиков о событии данного типа.

В описании элемента проекта можно указать параметры данного события. Здесь будем обозначать их как Параметры/Parameters.

## Методы

### Оповестить

`Версия 10.0 и выше`

`Доступность: Клиент`

```
Оповестить(Параметры: )
```

Рассылает событие, которое будет получено всеми подписчиками, подписавшимися на него при помощи метода

[ПодключитьОбработчик](globalclienteventname-ru-99eaced091fa.md)

. Рассылка осуществляется синхронно. Если какой-то из обработчиков данного события инициировал серверный вызов, то обработчик следующего компонента будет запущен не дожидаясь завершения этого серверного вызова. Если в каком-то из обработчиков данного события происходит исключение, то оно не влияет на работу остальных обработчиков.

Параметры данного обработчика указываются в описании конкретного элемента проекта.

`Версия 10.0 и выше`

`Доступность: Клиент`

```
ОтключитьОбработчик(Обработчик: (Параметры)-ничто)
```

Позволяет отменить подписку указанного обработчика на данное глобальное событие.

`Handler` - Ссылка на обработчик, подписка которого на данное событие будет отменена.
