## Конструкторы

### НастройкиАктивацииПользователей

`Доступность: КлиентИСервер`

```
НастройкиАктивацииПользователей(
  АктивацияПоЭлектроннойПочте: Булево = Ложь,
  АктивацияПоТелефону: Булево = Ложь)
```

Создает настройки активации из переданных параметров.

`АктивацияПоЭлектроннойПочте`

- Включать ли способ активации по электронной почте.

`АктивацияПоТелефону`

- Включать ли способ активации по телефону.
