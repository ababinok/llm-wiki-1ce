### ЭкспортироватьВИзображение

`Доступность: Клиент`

```
ЭкспортироватьВИзображение(
  Ширина: Число? = Неопределено,
  Высота: Число? = Неопределено,
  Dpi: Число = 200,
  ЦветоваяСхема: ЦветоваяСхема = ЦветоваяСхема.Светлая
): Байты
```

Экспортирует отчет в массив байтов png-изображения.

`Ширина` - ширина элемента выполненного отчета. Если не задано и внутри отчета есть горизонтальная прокрутка, `Ширина` берется равным ширине содержимого прокручиваемого контейнера. Если не задано и прокрутки нет, берется значение по умолчанию - 1920.

`Высота` - высота элемента выполненного отчета. Если не задано и внутри отчета есть вертикальная прокрутка, `Высота` берется равным высоте содержимого прокручиваемого контейнера. Если не задано и прокрутки нет, берется значение по умолчанию - 1080.

`Dpi` - качество итогового изображения.

Размеры итогового изображения рассчитываются как соответствующие размеры элемента выполненного отчета, увеличенные в (`Dpi` / 72) раз. Например, при выполнении с `Ширина`=200, `Высота`=100, `Dpi`=144 итоговое изображение будет иметь размеры 400 * 200 пикселов.

По умолчанию изображение сохраняется в светлой схеме с качеством dpi = 200. Рекомендуется использовать dpi = 72 для минимального размера и dpi = 600 для отличного качества изображения.

#### Исключения

**[ИсключениеЭкспортаОтчета](reportexportexception-ru-a8fa5d8929ac.md)** - если

- значение
  
  `Ширина`
  
  или
  
  `Высота`
  
  не задано и соответствующий размер содержимого прокручиваемого контейнера внутри Отчета, увеличенный в (
  
  `Dpi`
  
  / 72) раз, превышает
  
  - 4096 пикселов, если экспорт выполняется в iOS Safari
  - 16384 пикселов иначе
- экспортируется ПанельОтчетов
- невозможно построить отчет (недостаточно измерений или мер, недостаточно полей с обязательными ролями и т.д.)
- возникла ошибка при загрузке данных для построения отчета
- данные для построения отчета отсутствуют
  
  [ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)
  
  - если
- значение
  
  `Ширина`
  
  или
  
  `Высота`
  
  , увеличенное в (
  
  `Dpi`
  
  / 72) раз, либо меньше 1, либо больше
  
  - 4096, если экспорт выполняется в iOS Safari
  - 16384 иначе
- `Dpi`
  
  либо меньше 1, либо больше 1200.
