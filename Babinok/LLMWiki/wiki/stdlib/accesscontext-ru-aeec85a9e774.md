## Методы

### Дополнить

`Доступность: Сервер` `Статический`

```
Дополнить(Ключи: ЧитаемаяКоллекция<КлючДоступа.Объект|ПравоНаДействие.Объект>): КонтекстДоступа
```

Возвращает контекст прав, дополняющий предыдущий указанными ключами

`Ключи`

.

**Перегрузка** [Дополнить(Тип: Тип, Права: ЧитаемаяКоллекция<ПравоНаЭлемент>): КонтекстДоступа](accesscontext-ru-aeec85a9e774.md)

---

### Дополнить

`Доступность: Сервер` `Статический`

```
Дополнить(
  Тип: Тип,
  Права: ЧитаемаяКоллекция<ПравоНаЭлемент>
): КонтекстДоступа
```

Возвращает контекст прав, дополняющий предыдущий указанными правами

`Права`

на тип

`Тип`

. Если в качестве типа выступает тип, поддерживающий RLS, то указанные права действуют на все записи соответствующей сущности.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - если указанный тип не поддерживает указанные права.

**Перегрузка** [Дополнить(Ключи: ЧитаемаяКоллекция<КлючДоступа.Объект|ПравоНаДействие.Объект>): КонтекстДоступа](accesscontext-ru-aeec85a9e774.md)

---

### Информация

`Доступность: Сервер` `Статический`

```
Информация(): Строка
```

Возвращает отладочную информацию о действующих контекстах доступа.

---

### Исходный

`Доступность: Сервер` `Статический`

```
Исходный(): КонтекстДоступа
```

Возвращает исходный контекст доступа. Перекрывает действия предыдущих контекстов.

---

### Пользователь

`Доступность: Сервер` `Статический`

```
Пользователь(Пользователь: Пользователи.Ссылка): КонтекстДоступа
```

Возвращает контекст доступа пользователя

`Пользователь`

. В рамках действия этого контекста считается что есть права указанного пользователя. Права пользователя (т.е. его ключи доступа) вычисляются в момент первой проверки и не перечитываются до конца действия контекста доступа. Перекрывает действия предыдущих контекстов.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - если пользователя не существует

---

### Привилегированный

`Доступность: Сервер` `Статический`

```
Привилегированный(): КонтекстДоступа
```

Возвращает контекст доступа, в котором полностью отключена проверка прав. Перекрывает действия предыдущих контекстов.

---

### Установить

`Доступность: Сервер` `Статический`

```
Установить(Ключи: ЧитаемаяКоллекция<КлючДоступа.Объект|ПравоНаДействие.Объект>): КонтекстДоступа
```
