## Свойства

### Данные

`Доступность: Сервер` `ТолькоЧтение`

```
Данные: Байты
```

Данные вложения электронной почты.

---

### Ид

`Доступность: Сервер`

```
Ид: Строка
```

Идентификатор вложения электронной почты. Соответствует заголовку `Content-Id`.

---

### КодировкаПередачи

`Доступность: Сервер`

```
КодировкаПередачи: Строка?
```

Кодировка передачи. Соответствует заголовку `Content-Transfer-Encoding`. Стоит иметь в виду, что значение "B" трактуется как "base64" (также можно задавать).

---

### Название

`Доступность: Сервер` `ТолькоЧтение`

```
Название: Строка
```

Название вложения электронной почты. Соответствует названию файла вложения.

---

### РасположениеСодержимого

`Доступность: Сервер`

```
РасположениеСодержимого: Строка?
```

Расположение содержимого. Соответствует заголовку `Content-Disposition`.

---

### ТипСодержимого

`Доступность: Сервер` `ТолькоЧтение`

```
ТипСодержимого: Строка
```

MIME-тип содержимого вложения электронной почты.
