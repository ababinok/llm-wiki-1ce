## Обзор

Исключение для отлова специфичных для полнотекстового поиска ошибок.

## Документированный контракт и примеры

`Стд::ПолнотекстовыйПоиск::ИсключениеПолнотекстовогоПоиска` `Доступность: Сервер`

Исключение для отлова специфичных для полнотекстового поиска ошибок. Все сообщения из этого исключения можно показывать конечному пользователю.
