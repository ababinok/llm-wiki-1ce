## Обзор

Аннотация доступности серверного метода для вызова с клиента.

## Документированный контракт и примеры

`Стд::Аннотации::Окружения::ДоступноСКлиента` `Доступность: КлиентИСервер`

`Места применения:` Статический метод, Метод

Аннотация доступности серверного метода для вызова с клиента. Может быть использована только в паре с аннотацией [НаСервере](onserver-ru-ff4072dae1ed.md). В таком случае метод исполняется на сервере, но доступен для вызова с клиента, т.е. присутствует и в клиентском и серверном окружениях.

## Параметры

### КешироватьРезультат

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
КешироватьРезультат
```

Если значение параметра `Истина`, то первый вызов такого метода проходит обычным образом и его результат сохраняется в кеше на клиенте, а последующие вызовы, осуществляемые в течение данного сеанса пользователя (пока открыта и не перезагружалась вкладка браузера), просто используют прошлый результат, не делая реального вызова сервера. Кешируется сериализованный ответ. Каждый раз при вызове метода будет заново происходить десериализация. Кеширование происходит в разрезе параметров метода, ключом являются все параметры, сериализованные в строку. Если метод завершился с исключением, его результат (исключение) не кешируется, и при следующем вызове снова будет произведён обычный запрос к серверу.
