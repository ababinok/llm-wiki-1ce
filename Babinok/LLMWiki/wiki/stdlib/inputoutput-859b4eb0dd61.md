Версия: `10.0`.

Роль: Пространство имён XBSL.

Владелец: Std.

Имена для поиска: `Стд::ВводВывод`, `InputOutput`, `Std::InputOutput`.

## Обзор

Поток для записи данных, хранящий их в памяти, пока размер не превышает указанное при создании ограничение.

## Документированный контракт и примеры

Типы для чтения и записи данных.

# Типы

## [ВременныйПотокЗаписи](temporarywritablestream-ru-402408acf5bc.md)

`Стд::ВводВывод::ВременныйПотокЗаписи` `Доступность: Сервер`

Поток для записи данных, хранящий их в памяти, пока размер не превышает указанное при создании ограничение. После этого запись производится во временный файл. Позволяет прочитать записанные данные.

## [МеткаПорядкаБайтов](bytesordermark-ru-b01380f240b7.md)

`Стд::ВводВывод::МеткаПорядкаБайтов` `Доступность: КлиентИСервер`

Стратегия добавления метки порядка байтов (BOM) при записи в поток. Метка порядка байтов (BOM) применяется только для 3 кодировок: `UTF-8`, `UTF-16` и `UTF-32`. Для остальных кодировок метка игнорируется.

## [ПотокЧтения](readablestream-ru-c306ee00c3af.md)

`Стд::ВводВывод::ПотокЧтения` `Доступность: Сервер`

Однонаправленный поток чтения данных. После достижения конца автоматически освобождает внутренние ресурсы и не требует явного закрытия. После явного закрытия методы чтения выбрасывают исключение [ИсключениеВводаВывода](inputoutputexception-ru-ceba5f672999.md).

## [РезультатЧтенияДанных](readdataresult-ru-cb902b234ec0.md)

`Стд::ВводВывод::РезультатЧтенияДанных` `Доступность: Сервер`

Используется для сохранения прочитанных данных и дальнейших операций с ними. Объект может работать со значительными объемами данных. Прочитанные данные не хранятся в оперативной памяти, а передаются в хранилище (временный файл на диске, хранилище данных, и т. д.).
