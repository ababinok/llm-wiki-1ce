## Методы

### Начать

`Доступность: Клиент`

```
Начать(
  ВидКонтакта: ВидКонтактаПользователя,
  СпособПодтвержденияОперации: СпособПодтвержденияОперации
): СтатусПодтверждаемойОперацииСамообслуживания
```

Начать операцию подтверждения контакта с указанием вида контакта. Поддверживается вид контакта

`Телефон`

,

`ЭлектроннаяПочта`

, иначе будет выброшено исключение

[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)

. Если контакт уже подтвержден, вернется неуспешный статус операции с соответствующем сообщением. Если указанный контакт отсутствует на данном пользователе, вернется неуспешный статус операции.

#### Исключения

**null** - если указанный вид контакта не поддерживается для подтверждения.

---

### ПовторитьОтправкуКодаПодтверждения

`Доступность: Клиент`

```
ПовторитьОтправкуКодаПодтверждения(): СтатусПодтверждаемойОперацииСамообслуживания
```

Повторить отправку кода подтверждения. Если превышено количество попыток отправить код подтверждения, то будет возвращена неуспешный статус операции.

---

### Подтвердить

`Доступность: Клиент`

```
Подтвердить(Код: Строка): СтатусПодтверждаемойОперацииСамообслуживания
```

Подтвердить контакт кодом.
