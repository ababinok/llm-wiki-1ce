## Свойства

### Важность

`Доступность: Сервер` `ТолькоЧтение`

```
Важность: ВажностьПисьма
```

Важность почтового сообщения. Значение данного свойства определяется значением заголовка "X-Priority".

---

### ДатаОтправления

`Доступность: Сервер` `ТолькоЧтение`

```
ДатаОтправления: Момент?
```

Значение заголовка "Date". `Неопределено`, если заголовок не установлен.

---

### ИдСообщения

`Доступность: Сервер` `ТолькоЧтение`

```
ИдСообщения: Строка?
```

Значение заголовка "Message-ID". `Неопределено`, если заголовок не установлен.

---

### ОбратныеАдреса

`Доступность: Сервер` `ТолькоЧтение`

```
ОбратныеАдреса: ЧитаемыйМассив<АдресПочты>
```

Массив адресов из заголовков "Reply-To".

---

### Отправитель

`Доступность: Сервер` `ТолькоЧтение`

```
Отправитель: АдресПочты?
```

Отправитель электронного сообщения.

---

### Получатели

`Доступность: Сервер` `ТолькоЧтение`

```
Получатели: ЧитаемыйМассив<АдресПочты>
```

Получатели сообщения электронной почты.

---

### ПолучателиКопии

`Доступность: Сервер` `ТолькоЧтение`

```
ПолучателиКопии: ЧитаемыйМассив<АдресПочты>
```

Получатели копии сообщения.

---

### ПолучателиСкрытойКопии

`Доступность: Сервер` `ТолькоЧтение`

```
ПолучателиСкрытойКопии: ЧитаемыйМассив<АдресПочты>
```

Получатели скрытой копии сообщения.

---

### Тема

`Доступность: Сервер` `ТолькоЧтение`

```
Тема: Строка?
```

Значение заголовка "Subject". `Неопределено`, если заголовок не установлен.
