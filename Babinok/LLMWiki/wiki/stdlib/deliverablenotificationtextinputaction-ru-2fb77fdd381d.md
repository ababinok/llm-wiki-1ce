## Обзор

Действие уведомления, аналогично обычному действию, только позволяет ввести текст.

## Документированный контракт и примеры

`Стд::ДоставляемыеУведомления::ДействиеДоставляемогоУведомленияВводТекста` `Доступность: КлиентИСервер`

Действие уведомления, аналогично обычному действию, только позволяет ввести текст. При нажатии кнопки отображается поле ввода с кнопкой. После ввода текста и нажатия кнопки вызывается обработчик, в который, помимо уведомления, будут переданы идентификатор действия и введенный текст.

### ДействиеДоставляемогоУведомленияВводТекста

`Доступность: КлиентИСервер`

```
ДействиеДоставляемогоУведомленияВводТекста(
  Ид: Строка,
  Заголовок: Строка,
  ЗаголовокКнопки: Строка,
  ЗамещающийТекст: Строка)
```

Конструктор объекта на основе указанных параметров.

`Ид` - Идентификатор действия. Уникальная строка. Должно быть заполнено. `Заголовок` - Название действия. Должно быть заполнено. `ЗаголовокКнопки` - Заголовок кнопки. Должно быть заполнено. `InputHint` - Подсказка ввода.
