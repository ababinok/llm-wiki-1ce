Код метода `ИмпортДанных`:

```xbsl
@НаСервере
метод ИмпортДанных(КлючЗадания: Строка, Данные: Файл)
    // КлючЗадания - ключ запланированного задания
    // Данные - импортируемый файл
    исп Контекст = новый ОперацияИмпортДанных(Задание = КлючЗадания).ЗаписатьНачало() // (1)

    исп ПотокДанных = Данные.ОткрытьПотокЧтения()
    пер Читатель = новый ЧтениеДанных(ПотокДанных)

    пока (не Читатель.ЧтениеЗавершено())
        пер Элемент = Читатель.ПрочитатьСтроку()
        попытка
            ВыполнитьИмпортДанных(Элемент)
            Контекст.Добавлено += 1
            новый ОтладкаИмпорта(Задание = КлючЗадания, ОписаниеОбъекта = Элемент.ПодстрокаСНачала(100)).Записать() // (2)
        поймать И: ИсключениеЧтенияJson
            новый ОшибкаИмпорта(
                Важность = ВажностьСобытияЖурналаСобытий.Обычная,
                Задание = КлючЗадания,
                ОписаниеОбъекта = Элемент,
                ОтладочнаяИнформация = И.ПоследовательностьВызовов).Записать() // (3)
                
            Контекст.Пропущено += 1    
        поймать И: Исключение
            новый ОшибкаИмпорта(
                Важность = ВажностьСобытияЖурналаСобытий.Высокая,
                Задание = КлючЗадания,
                ОписаниеОбъекта = Элемент,
                ОтладочнаяИнформация = И.ПоследовательностьВызовов).Записать() // (3)
                
            Контекст.Пропущено += 1
        ;
    ;
    
    // Контекст будет закрыт и запишется событие завершения операции (4)
    Контекст.Закрыть()
;

метод ВыполнитьИмпортДанных(Элемент: Строка)
    // Здесь осуществляется импорт данных
;
```

1. **Здесь регистрируется событие начала операции `ОперацияИмпортДанных`.**
  
  Свойства события:
  
  - НачалоОперации.Имя = ОперацияИмпортДанных
  - НачалоОперации.Описание = Операция импорт отмечается событиями с началом и концом операции. В событии конца операции при условии успешного завершения выводится информация об измененных объектах, задании импорта и времени выполнения операции.
  - НачалоОперации.Задание = КлючЗадания (из конструктора)
  - НачалоОперации.Важность = Низкая (из описания события)
  - НачалоОперации.Добавлено = 0 (из описания события)
  - НачалоОперации.Пропущено = 0 (из описания события)
  - НачалоОперации.ВидСобытия = НачалоОперации
  - НачалоОперации.Ид = случайное значение
  - НачалоОперации.Момент = момент записи события
  - НачалоОперации.Операции = []
  
  Представление начала операции, если КлючЗадания = "ИмпортОбъектов":
  
  - НачалоОперации.Представление() =
    
    Начало операции импорта ИмпортОбъектов
  
  Получение свойств через методы:
  
  - НачалоОперации.ПолучитьСвойство("Задание") = КлючЗадания
  - НачалоОперации.ПолучитьСвойства() = {"Имя": "ОперацияИмпортДанных", "Задание": КлючЗадания,... }
2. **Здесь регистрируется событие `ОтладкаИмпорта`, в свойства которого будет записана информация для отладки.**
  
  Свойства события:
  
  - Событие.Имя = ОтладкаИмпорта
  - Событие.Описание = Событие регистрируется в момент успешного окончания импорта фрагмента файла данных после подтверждения транзакции. Содержит информацию об измененных объектах, задании импорта и времени выполнения операции.
  - Событие.Задание = КлючЗадания (из конструктора)
  - Событие.ОписаниеОбъекта = Элемент (текущий импортируемый элемент)
  - Событие.Важность = Низкая (из описания события)
  - Событие.ВидСобытия = Информация
  - Событие.Ид = случайное значение
  - Событие.Момент = момент записи события
  - Событие.Операции = [НачалоОперации.Ид]
  - Событие.Родитель = - НачалоОперации.Ид
  
  Представление события, если КлючЗадания = "ИмпортОбъектов" и Элемент = "{"key": "value"}":
  
  - Событие.Представление() =
    
    Задание импорта ИмпортОбъектов успешно завершено. Объект {"key": "value"}.
  
  Получение свойств через методы:
  
  - Событие.ПолучитьСвойство("Задание") = КлючЗадания
  - Событие.ПолучитьСвойство("ОписаниеОбъекта") = Элемент
  - Событие.ПолучитьСвойства() = {"Имя": "ОтладкаИмпорта", "Задание": КлючЗадания, "ОписаниеОбъекта": Элемент,... }
3. **Здесь регистрируется событие `ОшибкаИмпорта`, в свойства которого будет записана информация для расследования ошибки.**
  
  Свойства события:
  
  - Ошибка.Имя = ОшибкаИмпорта
  - Ошибка.Описание = Событие регистрируется при любой ошибке импорта фрагмента файла данных независимо от транзакции. Содержит информацию о задании импорта и блоке данных, на котором произошел сбой.
  - Ошибка.Задание = КлючЗадания (из конструктора)
  - Ошибка.Важность = ВажностьСобытия.Высокая или ВажностьСобытия.Обычная (из конструктора)
  - Ошибка.ОписаниеОбъекта = Элемент (из конструктора)
  - Ошибка.ОтладочнаяИнформация = Последовательность вызовов до места выбрасывания исключения (из конструктора)
  - Ошибка.ВидСобытия = Ошибка
  - Ошибка.Ид = случайное значение
  - Ошибка.Момент = момент записи
  - Ошибка.ХарактерОшибки = ХарактерОшибки.ДляПоддержки
  - Ошибка.Операции = [НачалоОперации.Ид]
  - Ошибка.Родитель = - НачалоОперации.Ид
  
  Представление события, если КлючЗадания = "ИмпортОбъектов" и Элемент = "{"key": "value"}":
  
  - Ошибка.Представление() =
    
    Задание ИмпортОбъектов завершилось с ошибкой на этапе обработки объекта {"key": "value"}. ВыполнитьИмпортДанных[72]...
  
  Получение свойств через методы:
  
  - Ошибка.ПолучитьСвойство("Задание") = КлючЗадания
  - Ошибка.ПолучитьСвойство("ОписаниеОбъекта") = Элемент
  - Ошибка.ПолучитьСвойства() = {"Имя": "ОшибкаИмпорта", "Задание": КлючЗадания, "ОписаниеОбъекта": Элемент,... }
4. **Событие завершения операции `ОперацияИмпортДанных` записывается при вызове метода `Закрыть()`.**
  
  Свойства события ОперацияИмпортДанных на момент завершения операции:
  
  - КонецОперации.Имя = ОперацияИмпортДанных
  - КонецОперации.Описание = Операция импорт отмечается событиями с началом и концом операции. В событии конца операции при условии успешного завершения выводится информация об измененных объектах, задании импорта и времени выполнения операции.
  - КонецОперации.Задание = КлючЗадания (из конструктора)
  - КонецОперации.Важность = Низкая (из описания события)
  - КонецОперации.Добавлено = подсчитанное значение
  - КонецОперации.Пропущено = подсчитанное значение
  - КонецОперации.ВидСобытия = КонецОперации
  - КонецОперации.Ид = случайное значение
  - КонецОперации.Момент = момент записи конца операции
  - КонецОперации.Длительность = длительность операции
  - КонецОперации.Успешно = Признак успешности операции. Истина, если в ходе операции не было ошибок, иначе Ложь.
  - КонецОперации.Операции = []
  - КонецОперации.КонецОперации = - НачалоОперации.Ид
  - КонецОперации.ИдОшибочногоСобытия = - Ошибка.Ид (при наличии ошибки, возникшей при выполнении операции)
  
  Представление конца операции, если КлючЗадания = "ИмпортОбъектов", Добавлено = 42, Пропущено = 24, Длительность = 35с:
  
  - КонецОперации.Представление() =
    
    Операция импорта ИмпортОбъектов завершена успешно. Добавлено 42, пропущено 24 объектов. Общее время 35с.

  - КонецОперации.ПолучитьСвойство("Задание") = КлючЗадания

                Важность = ВажностьСобытияЖурналаСобытий.Обычная,

1. **Здесь регистрируется событие `ОшибкаИмпорта`, в свойства которого будет записана информация для расследования ошибки.**

  - Ошибка.Имя = ОшибкаИмпорта
  - Ошибка.Описание = Событие регистрируется при любой ошибке импорта фрагмента файла данных независимо от транзакции. Содержит информацию о задании импорта и блоке данных, на котором произошел сбой.
