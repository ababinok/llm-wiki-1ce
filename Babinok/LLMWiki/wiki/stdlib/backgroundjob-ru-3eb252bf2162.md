## Свойства

### Исключение

`Доступность: Сервер` `ТолькоЧтение`

```
Исключение: Исключение?
```

Исключение, которое стало причиной аварийного завершения обработчика. Если в момент обращения к свойству задание еще не завершило выполнение, то обращение будет ждать завершения задания. Если задание завершилось успешно, то свойство имеет значение `Неопределено`.

---

### Результат

`Доступность: Сервер` `ТолькоЧтение`

```
Результат: Объект?
```

Результат, который вернул обработчик задания. Если в момент обращения к свойству задание еще не завершило выполнение, то обращение будет ждать завершения задания. Если обработчик не возвращает значение, то свойство имеет значение `Неопределено`.

---

### Статус

`Доступность: Сервер` `ТолькоЧтение`

```
Статус: СтатусЗадания
```

Текущий статус фонового задания.

---

## Методы

### ОжидатьЗавершения

`Доступность: Сервер`

```
ОжидатьЗавершения()
```

Ожидать завершения задания. Если задание завершилось успешно, его результат будет доступен в свойстве

`Результат`

, если обработчик задания возвращает значение. Если обработчик не возвращает значение, то свойство

`Результат`

будет иметь значение

`Неопределено`

. Если задание завершилось с ошибкой или было отменено, то свойство

`Результат`

будет иметь значение

`Неопределено`

, а в свойстве

`Исключение`

будет то исключение, которое стало причиной аварийного завершения обработчика.

#### См. также

[ОжидатьЗавершения](backgroundjobs-ru-ce0a20cb1908.md)

---

### Отменить

`Доступность: Сервер`

```
Отменить()
```

Отменяет выполнение задания. Если задание уже запущено, то исполнение прерывается.
