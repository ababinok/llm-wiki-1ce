# МаркерГеографическойКарты

> Raw: [geographicmapmarker-ru-40dd1d51585c-c18fec23f3ad018f](../../raw/text-10.0/geographicmapmarker-ru-40dd1d51585c-c18fec23f3ad018f.md)
> Updated: 2026-10-05

Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / GeographicMaps.

Имена для поиска: `МаркерГеографическойКарты`, `GeographicMapMarker`, `Стд::ГеографическиеКарты::МаркерГеографическойКарты<ТипДанных>`, `Std::GeographicMaps::GeographicMapMarker`.

## Обзор

ТипДанных: Тип свойства `Данные` маркера.

## Документированный контракт и примеры

`Версия 10.0 и выше`

`Стд::ГеографическиеКарты::МаркерГеографическойКарты<ТипДанных>` `Доступность: КлиентИСервер`

ТипДанных: Тип свойства `Данные` маркера. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Структура, представляющая данные маркера на карте.

## Конструкторы

### МаркерГеографическойКарты

`Доступность: КлиентИСервер`

```
МаркерГеографическойКарты(
  Координаты: ГеографическиеКоординаты,
  Иконка: Авто|Url|ДвоичныйОбъект.Ссылка,
  Заголовок: Авто|Строка,
  Подзаголовок: Авто|Строка,
  Описание: Авто|Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?,
  Данные: ТипДанных)
```

Создает объект

[МаркерГеографическойКарты](geographicmapmarker-ru-40dd1d51585c.md)

со значениями свойств, соответствующими параметрам конструктора.
