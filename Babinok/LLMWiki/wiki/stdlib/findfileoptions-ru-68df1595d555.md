## Конструкторы

### НастройкиПоискаФайлов

`Доступность: Сервер`

```
НастройкиПоискаФайлов()
```

Конструктор настроек поиска файлов. По умолчанию поиск будет произведен:

- без учета фильтра по времени изменения,
- без учета фильтра по времени создания,
- включая каталоги, файлы и символьные ссылки,
- без учета размера файлов,
- глубина поиска не ограничена.

## Методы

### Изменено

`Доступность: Сервер`

```
Изменено(
  От: Момент? = Неопределено,
  До: Момент? = Неопределено
): НастройкиПоискаФайлов
```

Устанавливает фильтр по времени изменения в диапазоне от

`От`

до

`До`

, включая границы. Возвращает текущий экземпляр.

---

### ИмяСодержит

`Доступность: Сервер`

```
ИмяСодержит(Подстрока: Строка): НастройкиПоискаФайлов
```

Устанавливает фильтр по наименованию файла. Поиск происходит по вхождению подстроки

`Подстрока`

в наименование файла, без учета регистра. Если подстрока не задана (пустая строка), фильтрация по имени выключена. Включение данной настройки выключает фильтр поиска по регулярному выражению. Возвращает текущий экземпляр.

---

### ИмяСоответствует

`Доступность: Сервер`

```
ИмяСоответствует(Образец: Образец): НастройкиПоискаФайлов
```

Устанавливает фильтр по регулярному выражению. Поиск происходит по соответствию наименования файла паттерну

`Образец`

без учёта регистра. Если образец не задан, фильтрация по регулярному выражению выключена. Включение данной настройки выключает фильтр поиска по подстроке. Возвращает текущий экземпляр.

---

### МаксимальнаяГлубина

`Доступность: Сервер`


`Неопределено`
