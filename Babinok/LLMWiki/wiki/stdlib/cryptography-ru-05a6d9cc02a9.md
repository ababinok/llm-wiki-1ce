## Методы

### ПолучитьBouncyCastle

`Доступность: Сервер`

```
ПолучитьBouncyCastle(): Криптопровайдер
```

Возвращает криптопровайдер Bouncy Castle.

#### Исключения

**[ИсключениеКриптографии](cryptoexception-ru-9269fbee8009.md)** - если провайдер "BC" не зарегистрирован в системе.

---

### ПолучитьViPNet

`Доступность: Клиент`

```
ПолучитьViPNet(): Криптопровайдер
```

Возвращает криптопровайдер ViPNet.

При вызове пытается подключить расширение работы с криптографией. Если оно не установлено, пользователю будет предложено его установить.

---

### ПолучитьКриптоПро

`Доступность: КлиентИСервер`

```
ПолучитьКриптоПро(): Криптопровайдер
```

Возвращает криптопровайдер КриптоПро JCP.

При вызове на клиенте пытается подключить расширение работы с криптографией. Если оно не установлено, пользователю будет предложено его установить.

#### Исключения

**[ИсключениеКриптографии](cryptoexception-ru-9269fbee8009.md)** - если провайдер "JCP" не зарегистрирован в системе.

---

### ПолучитьКриптоПроJcsp

`Доступность: Сервер`

```
ПолучитьКриптоПроJcsp(): Криптопровайдер
```

Возвращает криптопровайдер КриптоПро Java CSP (JCSP).

#### Исключения

**[ИсключениеКриптографии](cryptoexception-ru-9269fbee8009.md)** - если провайдер "JCSP" не зарегистрирован в системе.

---

### ПолучитьКриптопровайдер

`Доступность: Клиент`

```
ПолучитьКриптопровайдер(): Криптопровайдер
```

Возвращает провайдер, который автоматически определяется в зависимости от выполняемых действий и используемых алгоритмов криптографии При вызове пытается подключить расширение работы с криптографией. Если оно не установлено, пользователю будет предложено его установить.

---

### ПолучитьКриптопровайдер

`Доступность: Сервер`

```
ПолучитьКриптопровайдер(Имя: Строка): Криптопровайдер?
```

Возвращает JCA-совместимый криптопровайдер с именем

`Имя`

или

`Неопределено`

, если провайдер не зарегистрирован в системе.

---

### РасширениеУстановлено

`Доступность: Клиент`

```
РасширениеУстановлено(): Булево
```

Возвращает Истина, если расширение работы с криптографией установлено и доступно для использования

---

### УстановитьРасширение

`Доступность: Клиент`

```
УстановитьРасширение(): Булево
```

Открывает диалог устнановки расширения работы с криптографией. Возвращает Истина, если расширение было успешно установлено
