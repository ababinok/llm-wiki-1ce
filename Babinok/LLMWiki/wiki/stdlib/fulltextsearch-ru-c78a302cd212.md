## Методы

### ЖдатьЗавершенияОбновленияИндекса

`Доступность: Сервер`

```
ЖдатьЗавершенияОбновленияИндекса(
  ТочкаИзменений: ТочкаИзмененийПолнотекстовогоПоиска,
  Таймаут: Длительность = 1м
): Булево
```

Функция ждет пока индексная база не обновится до момента обозначенного параметром

`ТочкаИзменений`

. Если индексная база уже в актуальном состоянии, функция не будет входить в ожидание и сразу вернет истину.

Индексная база считается обновленной если все прошлые изменения до точки `ТочкаИзменений` и включая саму точку, проиндексированы.

Точку изменений можно получить только через вызов функции [ПолучитьТекущуюТочкуИзменений](fulltextsearch-ru-c78a302cd212.md) и эту функцию желательно вызывать после того, как вы внесли какие-то изменения в инфо-базу. Функция ожидания будет ждать индексации только тех изменений, которые были захвачены вызовом [ПолучитьТекущуюТочкуИзменений](fulltextsearch-ru-c78a302cd212.md).

Функция может прерваться и выбросить исключение по следующим причинам:

- если сервис фоновой индексации не активирован;
- если текущее приложение кто-то остановил;
- если внешняя подсистема выставила флаг прерывания;
- администратор заблокировал индексацию;

Аргументы:

- `ТочкаИзменений`
  
  - точка в логе изменений по которую (включительно) мы ожидаем полной индексации всех данных;
- `Таймаут`
  
  - максимальное время ожидания; если превышено время ожидания, функция прервет ожидание и вернет ложь. Максимальное время ожидания не более 24 суток, значение по умолчанию: 1 минута.

Результат:

Функция возвращает истину, если мы успешно дождались окончания обновления. Функция возвращает ложь, если было превышено время ожидания.

### ИндексАктуален

`Доступность: Сервер`

```
ИндексАктуален(): Булево
```

Функция возвращает истину, если поисковый индекс актуален, то есть он существует, он полностью построен и соответствует текущему состоянию данных приложения. Это также означает, что все, произошедшие ранее, изменения были проиндексированы и/или переиндексированы (актуализированы).

---

### ИндексБылАктуален

`Доступность: Сервер`

```
ИндексБылАктуален(ЗаПоследнийПериод: Длительность = 1м): Булево
```

Функция возвращает истину, если были проиндексированы данные хотя бы по одному событию, которое появилось в логе изменений за последний период (по настоящее время). Если логе изменений нет событий за последний заданный период, тогда функция вернет истину только если индекс полностью актуален.

Если приложение активно используется большим количеством пользователей, которые регулярно вносят изменения в инфо-базу, возникает ситуация при которой функция [ИндексАктуален](fulltextsearch-ru-c78a302cd212.md) редко возвращает истину. Тогда лучше использовать функцию [ИндексБылАктуален](fulltextsearch-ru-c78a302cd212.md). А еще лучше использовать обе функции в комбинации: сначала вызывайте функцию [ИндексАктуален](fulltextsearch-ru-c78a302cd212.md), а если она вернулся Ложь, тогда вызывайте функцию [ИндексБылАктуален](fulltextsearch-ru-c78a302cd212.md).

Аргументы:

- `ЗаПоследнийПериод`
  
  - период начиная с недалекого прошлого до текущего момента. Рекомендуется передавать в этот параметр значение не превышающее один час, рекомендуемое значение - 1 минута, это значение по умолчанию. Если передать число 0, функция станет вести себя аналогично функции
  
  [ИндексАктуален](fulltextsearch-ru-c78a302cd212.md)
  
  ;

### Искать

`Доступность: Сервер`

```
Искать(
  Запрос: ЗапросПолнотекстовогоПоиска,
  НастройкиРезультата: НастройкиРезультатаПолнотекстовогоПоиска
): РезультатПолнотекстовогоПоиска
```

Осуществляет поиск по индексной базе с возвратом первой страницы результатов поиска. Результаты поиска упорядочены по релевантности.

Аргументы:

- `Запрос`
  
  - структура типа
  
  [ЗапросПолнотекстовогоПоиска](../queries/fulltextsearchquery-ru-4d8590fefbc7.md)
  
  ;
- `НастройкиРезультата`
  
  - структура типа
  
  [НастройкиРезультатаПолнотекстовогоПоиска](fulltextsearchresultoptions-ru-44aadb7696df.md)
  
  в которой настраиваются возвращаемые для каждой записи данные: заголовок, фрагменты;

Результат:

Объект типа [РезультатПолнотекстовогоПоиска](fulltextsearchresult-ru-38eac12853e8.md).

**Перегрузка** [Искать(ПоисковыйЗапрос: Строка, ИндексСтраницы: Число = 0, РазмерСтраницы: Число = 40, Фильтр: Строка = "", ИскатьТолькоПоЗаголовкам: Булево = Ложь, ОбластьПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>, ОбластьИсключенийИзПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>): ЧитаемыйМассив<Сущность.Ключ>](fulltextsearch-ru-c78a302cd212.md)

### Искать

`Доступность: Сервер`

```
Искать(
  ПоисковыйЗапрос: Строка,
  ИндексСтраницы: Число = 0,
  РазмерСтраницы: Число = 40,
  Фильтр: Строка = "",
  ИскатьТолькоПоЗаголовкам: Булево = Ложь,
  ОбластьПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>,
  ОбластьИсключенийИзПоиска: ЧитаемаяКоллекция<Тип<Сущность.Ключ|Сущность.Объект>>
): ЧитаемыйМассив<Сущность.Ключ>
```

Функция поиска без настроек результатов поиска. Осуществляет поиск по индексной базе с возвратом первой страницы результатов поиска в виде массива ссылок. Результаты поиска упорядочены по релевантности.

Аргументы:

- `ПоисковыйЗапрос`
  
  - пользовательский поисковый запрос в синтаксисе 1С-поиска;
- `ИндексСтраницы`
  
  - сколько страниц среди найденных записей надо предварительно пропустить;
- `РазмерСтраницы`
  
  - сколько записей приходится на одну страницу;
- `Фильтр`
  
  - дополнение к поисковому запросу, которое скрыто добавляется через оператор
  
  `AND`
  
  , но в результатах поиска ключевые слова из этого фильтра не подсвечиваются. И фильтр не влияет на то, как формируются выдержки текста. Также важно знать, что фильтр работает быстрее обычного поискового запроса.
- `ИскатьТолькоПоЗаголовкам`
  
  - истина, если надо осуществить поиск не по основному содержимому, а только по заголовкам.
- `ОбластьПоиска`
  
  - массив ссылочных типов, по которым нужен поиск; если передать пустой массив, будет поиск по всем типам;
  
  значение по умолчанию:
  
  пустой массив;
- `ОбластьИсключенийИзПоиска`
  
  - массив ссылочных типов, которые нужно исключить из области поиска. Значение по умолчанию: пустой массив. Вы можете заполнить либо массив
  
  `ОбластьИсключенийИзПоиска`
  
  , либо массив
  
  `ОбластьПоиска`
  
  , но не оба массива сразу;

Результат:

Объект типа [ЧитаемыйМассив](readablearray-ru-6bae9724f632.md) - массив ссылок на найденные записи;

**Перегрузка** [Искать(Запрос: ЗапросПолнотекстовогоПоиска, НастройкиРезультата: НастройкиРезультатаПолнотекстовогоПоиска): РезультатПолнотекстовогоПоиска](fulltextsearch-ru-c78a302cd212.md)

### КоличествоИзменений

`Доступность: Сервер`

```
КоличествоИзменений(): Число
```

Возвращает количество изменений на текущий момент времени, которое еще не попало в индекс полнотекстового поиска, то есть не было проиндексировано. Если была создана, удалена или изменена какая-то одна запись, это принимается за одно изменение. Если изменился элемент проекта, это тоже принимается вначале за одно изменение, но потом, на одном из этапов индексации, регистрируются ссылки на все записи элемента проекта и мы можем, переодически вызывая функцию

[КоличествоИзменений](fulltextsearch-ru-c78a302cd212.md)

, отслеживать - сколько осталось проиндексировать записей по этому элементу проекта. Если функция

[КоличествоИзменений](fulltextsearch-ru-c78a302cd212.md)

возвращает ненулевое значение, значит индекс не актуален, то есть функция

[ИндексАктуален](fulltextsearch-ru-c78a302cd212.md)

будет возвращать

`Ложь`

.

### НайтиСинонимы

`Доступность: Сервер`

```
НайтиСинонимы(Синоним: Строка): Массив<Строка>
```

Ищет и возвращает обобщённую группу синонимов. Возвращает пустой массив, если синонимы не найдены. В возвращаемой группе все синонимы нормализованы, то есть у них обрезаны окончания.

Аргументы:

- `Синоним`
  
  - Синоним, по которому ищем группу синонимов. Обычно это одно слово в любом падеже, реже два-три слова через пробел, например: ветеринарная клиника.

### ПолучитьТекущуюТочкуИзменений

`Доступность: Сервер`

```
ПолучитьТекущуюТочкуИзменений(): ТочкаИзмененийПолнотекстовогоПоиска
```

Функция возвращает точку для текущего момента времени, относительно которой мы можем отслеживать по логу изменений процесс индексации. Напомню, что в ППД любые изменения в инфо-базе сначала фиксируются в специальном логе изменений, затем задание по индексации считывает из этого лога данные, обновляет индекс, а в конце помечает в логе изменений события по которым данные проиндексированы.

Допустим, вы записали или изменили какие-то записи, затем сразу вызвали функцию [ПолучитьТекущуюТочкуИзменений](fulltextsearch-ru-c78a302cd212.md) и получили точку. Далее, относительно этой точки вы можете узнать количество событий в прошлом, включая сделанные вами изменения, которые еще не проиндексированы. Вы можете передать эту точку в функцию [ЖдатьЗавершенияОбновленияИндекса](fulltextsearch-ru-c78a302cd212.md) и дождаться, когда ваши изменения окажутся в поисковом индексе.

Тип результата:

Функция возвращает объект типа [ТочкаИзмененийПолнотекстовогоПоиска](fulltextsearchchangepoint-ru-4981693323a8.md), который описывает точку в логе изменений ППД. Точка это число условных тиков условного таймера. Вам не обязательно знать точное значение тиков и размерность, достаточно знать какие события относительно точки старее, а какие новее. Каждое событие в логе имеет такую точку и все события в логе строго упорядоченны по времени возникновения этих событий.

### ПолучитьФрагменты

`Доступность: Сервер`

```
ПолучитьФрагменты(
  ПоисковыйЗапрос: Строка,
  Ключ: Сущность.Ключ,
  НастройкиФрагментов: НастройкиФрагментовПолнотекстовогоПоиска
): ЭлементРезультатаПолнотекстовогоПоиска?
```

Предоставляет фрагменты по конкретной, ранее найденной записи. Например, могут потребоваться более подробные фрагменты.

Аргументы:

- `Запрос`
  
  - Поисковый запрос, который использовался для нахождения записи. Нужен для подсветки слов (вхождений).
- `Ключ`
  
  - Ключ записи, которую можно найти по заданному запросу.
- `НастройкиФрагментов`
  
  - Настройки фрагментов.

Результат:

Объект типа [ЭлементРезультатаПолнотекстовогоПоиска](fulltextsearchresultitem-ru-4768069fde33.md), содержит основные данные по одному элементу результата поиска. Функция может вернуть [Неопределено](undefined-ru-bad7e9ef4c2b.md), например, если запись кто-то успел удалить.

### УстановитьСловарьСинонимов

`Доступность: Сервер`

```
УстановитьСловарьСинонимов(
  Имя: Строка,
  Словарь: Строка|ЧитаемыйМассив<ЧитаемыйМассив<Строка>>|?)
```

Устанавливает именованный словарь синонимов и применяет его. Предыдущий словарь синонимов, перезаписывается новым.

Аргументы:

- `Имя`
  
  - Имя (название) словаря. Вы можете, разделить синонимы по разным словарям для удобства сопровождения, но при поиске они участвуют все вместе.
- `Словарь`
  
  - Словарь синонимов, где каждый элемент массива должен представлять собой полноценную группу синонимов. Отдельный синоним (строка) может состоять из нескольких слов, например "Государственная инспекция". Группу синонимов можно формировать в любом падеже, но лучше в именительном. Вы также можете передать синонимы одним сплошным многострочным текстом, где каждая строка - полноценная группа синонимов, заданная через запятую или точку с запятой. Если передать значение Неопределено, словарь по заданному имени будет удалён.
