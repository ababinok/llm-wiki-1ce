## Обзор

Рисунок табличного документа, который содержит Изображение.

## Документированный контракт и примеры

`Стд::ТабличныйДокумент::ИзображениеТабличногоДокумента` `Доступность: Сервер`

Рисунок табличного документа, который содержит Изображение.

```xbsl
метод ДобавитьРисунокПодЛоготип(Макет: ТабличныйДокумент)
    пер РисунокЛого = Макет.Рисунки.СоздатьИзображение()
    РисунокЛого.Высота = 40
    РисунокЛого.Ширина = 40
    РисунокЛого.РасположитьПоОбласти("R1C5:R4C8")
    РисунокЛого.МасштабированиеСодержимого = МасштабированиеИзображения.Пропорционально
    РисунокЛого.Имя = "ЛоготипОрганизации"
;
```

## Свойства

### МасштабированиеСодержимого

`Доступность: Сервер`

```
МасштабированиеСодержимого: МасштабированиеИзображения
```

Содержит варианты приспособления оригинальных размеров картинки к размерам области, отведенной для ее отображения. Значение [Заполнить](imagescaling-ru-a70a7c40e4bb.md) будет интерпретироваться как [Пропорционально](imagescaling-ru-a70a7c40e4bb.md)

## Методы

### ПолучитьИзображение

`Доступность: Сервер`

```
ПолучитьИзображение(): Байты?
```

Возвращает байты изображения, установленную в рисунке.

---

### ПолучитьУзор

`Доступность: Сервер`

```
ПолучитьУзор(): УзорТабличногоДокумента
```

Возвращает узор рисунка табличного документа.

---

### ПолучитьЦветУзора

`Доступность: Сервер`

```
ПолучитьЦветУзора(): Цвет
```

Возвращает цвет узора рисунка табличного документа.

---

### ПолучитьЦветФона

`Доступность: Сервер`

```
ПолучитьЦветФона(): Цвет
```

Возвращает цвет фона рисунка табличного документа.

---

### УстановитьИзображение

`Доступность: Сервер`

```
УстановитьИзображение(
  Изображение: Байты?,
  ПрозрачныйФон: Булево = Ложь)
```

Устанавливает изображение в рисунок табличного документа.

Поддерживаются изображения следующих форматов:

- BMP
- EMF
- GIF
- Icon
- JPEG
- PNG
- SVG
- TIFF
- WMF

---

### УстановитьУзор

`Доступность: Сервер`

```
УстановитьУзор(Узор: УзорТабличногоДокумента)
```

Устанавливает узор рисунка табличного документа.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - Если будет указано значение `НеизвестныйУзор`.

---

### УстановитьЦветУзора

`Доступность: Сервер`

```
УстановитьЦветУзора(Цвет: Цвет)
```

Устанавливает цвет узора рисунка табличного документа.

- `Цвет`
  
  - Цвет узора.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - Если будет передан НЕ абсолютный цвет.

---

### УстановитьЦветУзораПоУмолчанию

`Доступность: Сервер`

```
УстановитьЦветУзораПоУмолчанию()
```

Устанавливает в рисунок табличного документа цвет узора по умолчанию.

---

### УстановитьЦветФона

`Доступность: Сервер`

  - Цвет фона.
