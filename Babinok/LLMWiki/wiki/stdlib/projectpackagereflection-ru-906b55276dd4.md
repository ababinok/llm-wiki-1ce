### Элементы

Элементы проекта, входящие в пакет

#### Примеры

Обойти все элементы проекта для создания файлов документации

```xbsl
метод ОтобразитьЭлементыПроекта()
    знч БазовыйКаталог = Файлы.СоздатьВременныйКаталог()
    для Подсистема из Проект.ПолучитьПодсистемы()
        Вывести(БазовыйКаталог, Подсистема)
    ;
;

метод Вывести(БазовыйКаталог: Файл, Пакет: ОтражениеПакетаПроекта)
    знч КаталогПакета = Файлы.СоздатьКаталог(новый Файл(Пакет.Имя.Английский, БазовыйКаталог))
    для ДочернийПакет из Пакет.Пакеты
        Вывести(КаталогПакета, ДочернийПакет)
    ;
    
    для Элемент из Пакет.Элементы
        Вывести(КаталогПакета, Элемент)
    ;
;

метод Вывести(КаталогПакета: Файл, ЭлементПроекта: ОтражениеЭлементаПроекта)
    // Строка вида "Справочник Контрагенты.txt"
    знч ИмяФайла = "%{ЭлементПроекта.ВидЭлемента} %{ЭлементПроекта.Имя.Английский}.txt"
    знч ФайлШаблона = новый Файл(ИмяФайла, КаталогПакета)
    
    Файлы.Создать(ФайлШаблона)
;
```

## Методы

### ПоИмени

`Доступность: Сервер` `Статический`

```
ПоИмени(Имя: Строка): ОтражениеПакетаПроекта
```

Возвращает ОтражениеПакетаПроекта по имени

`Имя`

.

`Имя`

- полное строковое представление пространства имен.

#### Исключения

**[ИсключениеОтражения](reflectionexception-ru-eaf98f596473.md)** - не удалось найти отражение пакета по имени

#### Примеры

```xbsl
знч Утилиты = ОтражениеПакетаПроекта.ПоИмени("Dev::App::Main::Utils")
```

---

### ПоТипу

`Доступность: Сервер` `Статический`

```
ПоТипу(Тип: Тип): ОтражениеПакетаПроекта
```

Возвращает ОтражениеПакетаПроекта по типу

`Тип`

из этого пакета.

#### Исключения

**[ИсключениеОтражения](reflectionexception-ru-eaf98f596473.md)** - не удалось найти отражение пакета по типу

#### Примеры

```xbsl
знч ПакетПроекты = ОтражениеПакетаПроекта.ПоТипу(Тип<Проекты>)
```
