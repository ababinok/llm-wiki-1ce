## Обзор

Объект для управления доставляемыми уведомлениями.

## Документированный контракт и примеры

`Стд::ДоставляемыеУведомления::ДоставляемыеУведомления` `Тип-одиночка` `Доступность: Клиент`

Объект для управления доставляемыми уведомлениями.

## Примеры

**Общие примеры**

```xbsl
@ВПроекте
метод ПроверитьДоступность(): Булево
    возврат ДоставляемыеУведомления.ПроверитьДоступность()
;

@ВПроекте
метод ОбработчикПередОтображением(Уведомление: ДоставляемоеУведомление): Булево
    Сообщить("Получено уведомление\nЗаголовок: " + Уведомление.Заголовок + "\nТекст: " + Уведомление.Текст)
    возврат Ложь
;

@ВПроекте
метод ОбработчикДействия(Уведомление: ДоставляемоеУведомление, Действие: неизвестно, Текст: Строка | Неопределено)
    Сообщить("Пользователь нажал на уведомление\nЗаголовок: " + Уведомление.Заголовок + "\nТекст: " + Уведомление.Текст)
;

@ВПроекте
метод Инициализировать()
    если ПроверитьДоступность()
        ДоставляемыеУведомления.ПодключитьОбработчикиУведомлений(&ОбработчикПередОтображением, &ОбработчикДействия)
        пер Каналы: Массив<КаналДоставляемыхУведомлений>
        пер Канал = новый КаналДоставляемыхУведомлений("channel1", "Канал1")
        Канал.Наименование = "Канал1" 
        Каналы.Добавить(Канал)
        ДоставляемыеУведомления.УстановитьКаналыУведомлений(Каналы)

        пер Категории: Массив<КатегорияДоставляемогоУведомления>
        пер Действия: Массив<ДействиеДоставляемогоУведомления>
        Действия.Добавить(новый ДействиеДоставляемогоУведомления("ok", "OK", Ложь))
        Действия.Добавить(новый ДействиеДоставляемогоУведомления("cancel", "Cancel", Истина))
        Категории.Добавить(новый КатегорияДоставляемогоУведомления("cat1", Действия))
        ДоставляемыеУведомления.УстановитьКатегорииУведомлений(Категории)
    ;
;


@ВПроекте
метод ПолучитьИдентификаторПодписчика(): ИдПодписчикаДоставляемыхУведомлений
    ПроверитьДоступность()
    пер ИдентификаторПодписчика = ДоставляемыеУведомления.ПолучитьИдПодписчикаУведомлений()
    возврат ИдентификаторПодписчика
;

@ВПроекте
метод СоздатьЛокальноеУвдомление(Через: Число, Заголовок: Строка, Текст: Строка)
    пер Уведомление = новый ДоставляемоеУведомление("", Заголовок, Текст)
    Уведомление.Триггер = новый ТриггерДоставляемыхУведомленийПоИнтервалуВремени(Через, Ложь)
    Уведомление.Категория = "cat1"
    ДоставляемыеУведомления.ДобавитьУведомление(Уведомление)
;
```

## Методы

### ДобавитьУведомление

`Доступность: Клиент`

```
ДобавитьУведомление(Уведомление: ДоставляемоеУведомление)
```

Добавляет уведомление

`Уведомление`

. У уведомления должно быть заполнено поле "Текст". В противном случае выбрасывается исключение.

---

### ОтключитьОбработчикУведомлений

`Доступность: Клиент`

```
ОтключитьОбработчикУведомлений(Обработчик: ((ДоставляемоеУведомление)->Булево)|(ДоставляемоеУведомление, СтандартноеДействиеДоставляемыхУведомлений|Строка, Строка?)->ничто)
```

Отключает указанный обработчик

`Обработчик`

уведомлений.

---

### ПодключитьОбработчикиУведомлений

`Доступность: Клиент`

```
ПодключитьОбработчикиУведомлений(
  ОбработчикПередОтображением: (ДоставляемоеУведомление)->Булево,
  ОбработчикДействия: (ДоставляемоеУведомление, СтандартноеДействиеДоставляемыхУведомлений|Строка, Строка?)->ничто)
```

Подключает процедуры-обработчики

`ОбработчикПередОтображением`

и

`ОбработчикДействия`

получения уведомления.

---

### ПолучитьДоставленныеУведомления

`Доступность: Клиент`

```
ПолучитьДоставленныеУведомления(): ЧитаемыйМассив<ДоставляемоеУведомление>
```

Возвращает массив всех доставленных уведомлений.

---

### ПолучитьЗапланированныеУведомления

`Доступность: Клиент`

```
ПолучитьЗапланированныеУведомления(): ЧитаемыйМассив<ДоставляемоеУведомление>
```

Возвращает массив всех запланированных, но не доставленных уведомлений.

---

### ПолучитьЗначок

`Доступность: Клиент`

```
ПолучитьЗначок(): Число
```

Возвращает текущее значение значка.

---

### ПолучитьИдПодписчикаУведомлений

`Доступность: Клиент`

```
ПолучитьИдПодписчикаУведомлений(): ИдПодписчикаДоставляемыхУведомлений
```

Получает уникальный идентификатор подписчика. При использовании следует учитывать, что идентификатор при определенных условиях может быть изменен. Рекомендуется получать его и передавать на сервер при каждом запуске приложения.

---

### ПолучитьКаналыУведомлений

`Доступность: Клиент`

```
ПолучитьКаналыУведомлений(): ЧитаемыйМассив<КаналДоставляемыхУведомлений>
```

Возвращает массив каналов заданный ранее. Если многоканальность не поддерживается, всегда возвращает один канал. Если каналы ни разу не задавали возвращает канал по-умолчанию.

---

### ПолучитьКатегорииУведомлений

`Доступность: Клиент`

```
ПолучитьКатегорииУведомлений(): ЧитаемыйМассив<КатегорияДоставляемогоУведомления>
```

Возвращает массив категорий уведомлений, установленный ранее.

---

### ПроверитьДоступность

`Доступность: Клиент`

```
ПроверитьДоступность(): Булево
```

Проверяет, разрешено ли использование сервиса.

---

### УдалитьДоставленныеУведомления

`Доступность: Клиент`

```
УдалитьДоставленныеУведомления(Уведомления: Строка|ЧитаемыйМассив<ДоставляемоеУведомление>|?)
```

Удаляет доставленные уведомления.

`Уведомления`

- массив идентификаторов уведомлений, которые следует удалить. Если не указан, удаляются все доставленные уведомления.

---

### УдалитьЗапланированныеУведомления

`Доступность: Клиент`

```
УдалитьЗапланированныеУведомления(Уведомления: Строка|ЧитаемыйМассив<ДоставляемоеУведомление>|?)
```

Удаляет запланированные, но не доставленные уведомления

`Уведомления`

.

---

### УстановитьЗначок

`Доступность: Клиент`

```
УстановитьЗначок(Значение: Число)
```

Устанавливает значение

`Значение`

значка.

---

### УстановитьКаналыУведомлений

`Доступность: Клиент`

```
УстановитьКаналыУведомлений(КаналыУведомлений: ЧитаемыйМассив<КаналДоставляемыхУведомлений>)
```

Установить каналы уведомлений, требуемые приложению. Массив должен содержать хотя бы один канал. Если многоканальность не поддерживается, используется только первый канал. Данный метод должен быть вызван как можно раньше при старте приложения, до начала использования уведомлений. Как правило данный метод следует вызывать только один раз.

---

### УстановитьКатегорииУведомлений

`Доступность: Клиент`

```
УстановитьКатегорииУведомлений(КатегорииУведомлений: ЧитаемыйМассив<КатегорияДоставляемогоУведомления>)
```

Устанавливает список категорий уведомлений. Предыдущие категории уведомлений удаляются. Устанавливать категории уведомлений следует как можно ранее при старте приложения. Как правило данный метод следует вызывать только один раз. Если категории не поддерживаются данный метод ничего не делает.
