## Методы

### НайтиВсе

`Доступность: Сервер` `Статический`

```
НайтиВсе<ТипЭлемента>(): ЧитаемаяКоллекция<ТипЭлемента>
```

ТипЭлемента: искомый тип элемента проекта. Ограничения параметра типа: Стд::Отражение::ОтражениеЭлементаПроекта.

Статический метод. Позволяет найти все элементы проекта заданного типа.

**Перегрузка** [НайтиВсе(ВидЭлемента: ВидЭлементаПроекта): ЧитаемаяКоллекция<ОтражениеЭлементаПроекта>](projectelementreflection-ru-20a73ff0cc46.md) [НайтиВсе(Фильтр: (ОтражениеЭлементаПроекта)->Булево): ЧитаемаяКоллекция<ОтражениеЭлементаПроекта>](projectelementreflection-ru-20a73ff0cc46.md)

#### Примеры

```xbsl
знч ВсеСущности = ОтражениеЭлементаПроекта.НайтиВсе<ОтражениеСущности>()
```

### НайтиВсе

```
НайтиВсе(Фильтр: (ОтражениеЭлементаПроекта)->Булево): ЧитаемаяКоллекция<ОтражениеЭлементаПроекта>
```

### ПоТипу

`Доступность: Сервер` `Статический`

```

```

Статический метод. Позволяет получить элемент проекта по типу, порожденному элементом проекта.

