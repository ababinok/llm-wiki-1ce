## Методы

### Декодировать

`Доступность: Сервер`

```
Декодировать(СтрокаBase64: Строка): Байты
```

Декодирует строку

`СтрокаBase64`

из двоичных данных в формате

`Base64`

в байты.

---

### ДекодироватьВСтроку

`Доступность: Сервер`

```
ДекодироватьВСтроку(
  СтрокаBase64: Строка,
  Кодировка: Кодировка|Строка = Кодировка.Utf8
): Строка
```

Декодирует строку

`СтрокаBase64`

из двоичных данных в формате Base64 в строку. При этом, данные в Base64 представляют собой строку в кодировке

`Кодировка`

.

#### Исключения

**[ИсключениеНедопустимыйАргумент](illegalargumentexception-ru-fc532bf88932.md)** - если кодировка не поддерживается

---

### КодироватьВСтроку

`Доступность: Сервер`

```
КодироватьВСтроку(
  Данные: Байты,
  ВидКодировкиBase64: ВидBase64 = ВидBase64.Base64
): Строка
```

Кодирует последовательность байтов

`Данные`

в двоичные данные в формате Base64, используя вариант кодирования

`ВидКодировкиBase64`

.

**Перегрузка** [КодироватьВСтроку(ВходнаяСтрока: Строка, ВидКодировкиBase64: ВидBase64 = ВидBase64.Base64): Строка](base64encoding-ru-a1c943423c38.md)

---

### КодироватьВСтроку

`Доступность: Сервер`

```
КодироватьВСтроку(
  ВходнаяСтрока: Строка,
  ВидКодировкиBase64: ВидBase64 = ВидBase64.Base64
): Строка
```

Кодирует строку

`ВходнаяСтрока`

в двоичные данные в формате Base64, используя вариант кодирования

`ВидКодировкиBase64`

. Преобразование выполняется в два этапа:

1. Строка кодируется в двоичные данные.
2. Двоичные данные кодируются по алгоритму Base64.

Для преобразования строки в двоичные данные используется кодировка UTF-8.

**Перегрузка** [КодироватьВСтроку(Данные: Байты, ВидКодировкиBase64: ВидBase64 = ВидBase64.Base64): Строка](base64encoding-ru-a1c943423c38.md)
