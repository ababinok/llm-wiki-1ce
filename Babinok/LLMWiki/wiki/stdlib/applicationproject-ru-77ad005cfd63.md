## Методы

### ОткрытьПользовательскиеСоглашения

`Доступность: КлиентИСервер`

```
ОткрытьПользовательскиеСоглашения()
```

При вызове метода открываются пользовательские соглашения. Если соглашение одно и это ссылка, то выполняется переход по ссылке. Если соглашение одно и это файл, то он показывается в форме, где заголовок - наименование соглашения, содержимое - файл соглашения (txt, pdf, html). Если соглашений несколько, то они показываются в форме со страницами, где заголовок страницы - наименование соглашения, содержимое - файл соглашения (txt, pdf, html).

Файл пользовательского соглашения показывается в следующем виде:

- txt -
  
  `Надпись`
- pdf -
  
  `ПросмотрPdf`
- html -
  
  `КонтейнерHtml`
