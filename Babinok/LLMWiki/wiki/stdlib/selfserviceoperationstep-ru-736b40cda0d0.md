## Свойства

### ПодтверждениеКодомИзСмс

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПодтверждениеКодомИзСмс
```

Требуется подтверждение кодом из смс.

Переходы к состояниям:

- [ПовторнаяОтправкаКода](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - превышено количество попыток ввода кода, можно отправить новый код
- [Подтверждено](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - код подтвержден, требуется завершение операции
- [ЗавершеноНеуспешно](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - превышено количество попыток ввода кода, нельзя отправить новый код или произошла ошибка
- [ЗавершеноУспешно](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - код подтвержден, не требуется завершение операции

---

### ПовторнаяОтправкаКода

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПовторнаяОтправкаКода
```

Требуется повторная отправка кода.

Переходы к состояниям:

- [ПодтверждениеКодомИзСмс](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  или
  
  [ПодтверждениеКодомИзПисьма](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - новый код успешно отправлен
- [ЗавершеноНеуспешно](selfserviceoperationstep-ru-736b40cda0d0.md)
  
  - произошла ошибка при повторной отправке
