## Свойства

### ДатаОтзыва

`Доступность: Сервер` `ТолькоЧтение`

```
ДатаОтзыва: Момент
```

Возвращает момент, начиная с которого сертификат недействителен.

---

### ПричинаОтзыва

`Доступность: Сервер` `ТолькоЧтение`

```
ПричинаОтзыва: ПричинаОтзываСертификата
```

Возвращает причину отзыва сертификата.

---

### СерийныйНомер

`Доступность: Сервер` `ТолькоЧтение`

```
СерийныйНомер: Байты
```

Возвращает серийный номер сертификата.
