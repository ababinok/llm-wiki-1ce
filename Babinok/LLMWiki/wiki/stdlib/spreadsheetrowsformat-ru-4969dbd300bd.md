## Обзор

Содержит описание формата строк области табличного документа.

## Документированный контракт и примеры

`Стд::ТабличныйДокумент::ФорматСтрокТабличногоДокумента` `Доступность: Сервер`

Содержит описание формата строк области табличного документа. Формат строк есть у каждой строки табличного документа и по умолчанию общий для всех строк. При изменении ширины колонок строки области ячеек будет изменена ширина колонок других строк с тем же форматом строк. По умолчанию у нового табличного документа общий формат строк для каждой его строки.
