# ЭлементРезультатаПолнотекстовогоПоиска

Версия: `10.0`.

Роль: Программный тип XBSL.

Владелец: Std / FullTextSearch.

Имена для поиска: `ЭлементРезультатаПолнотекстовогоПоиска`, `FullTextSearchResultItem`, `Стд::ПолнотекстовыйПоиск::ЭлементРезультатаПолнотекстовогоПоиска`, `Std::FullTextSearch::FullTextSearchResultItem`.

## Обзор

Структура, которая содержит основные данные по одному элементу результата поиска.

## Документированный контракт и примеры

`Стд::ПолнотекстовыйПоиск::ЭлементРезультатаПолнотекстовогоПоиска` `Доступность: Сервер`

Структура, которая содержит основные данные по одному элементу результата поиска.

**Сравнение**

Структурное

Два экземпляра равны, если попарно равны все свойства.

## Иерархия типа

*Базовые типы:* [Объект](object-ru-9e351f286699.md)

## Свойства

### Заголовок

`Доступность: Сервер` `ТолькоЧтение`

```
Заголовок: Строка
```

Заголовок записи. Чаще всего это представление записи.

---

### ИзображениеСущности

`Доступность: Сервер` `ТолькоЧтение`

```
ИзображениеСущности: ДвоичныйОбъект.Ссылка?
```

Ссылка на изображение сущности (элемента проекта). Изображение можно добавить в секцию Интерфейс.Объект, либо в секцию Интерфейс.Список элемента проекта. В приоритете возвращается изображение для списка.

---

### Ключ

`Доступность: Сервер` `ТолькоЧтение`

```
Ключ: Сущность.Ключ
```

Ключ который однозначно идентифицирует найденную запись.

---

### ПредставлениеСущности

`Доступность: Сервер` `ТолькоЧтение`

```
ПредставлениеСущности: Строка
```

Возвращает пользовательское представление для типа сущности.

---

### ФрагментыПоСвойствам

`Доступность: Сервер` `ТолькоЧтение`

```
ФрагментыПоСвойствам: ЧитаемыйМассив<ФрагментыПолнотекстовогоПоискаПоСвойству>
```

Все найденные фрагменты текста, разделённые по свойствам. В массиве свойства представлены в таком же порядке, в каком они описаны для элемента проекта. В массиве свойства не повторяются. По умолчанию массив пустой. Чтобы массив заполнялся, нужно установить флаг [ПолучатьФрагментыПоСвойствам](fulltextsearchresultoptions-ru-44aadb7696df.md) в структуре [НастройкиРезультатаПолнотекстовогоПоиска](fulltextsearchresultoptions-ru-44aadb7696df.md).

---

## Методы

### Представление

`Доступность: Сервер`

```
Представление(): Строка
```

Возвращает представление найденной записи в виде строки, состоящей из серии фрагментов текста, в которых выделены ключевые слова (вхождения) из поискового запроса. Вхождения по умолчанию выделяются html-тегом <b>, это можно изменить в настройках

[НастройкиФрагментовПолнотекстовогоПоиска](fulltextsearchfragmentsoptions-ru-e6dafa502de1.md)

. Функция возвращает пустую строку, если выключен режим

[ПолучатьФрагменты](fulltextsearchresultoptions-ru-44aadb7696df.md)

в настройках

[НастройкиРезультатаПолнотекстовогоПоиска](fulltextsearchresultoptions-ru-44aadb7696df.md)

.

**Переопределение** [Объект::Представление](object-ru-9e351f286699.md)
