Тип-одиночка, обеспечивающий регистрацию и получения информации о веб-чате на сервере.

## Методы

### Зарегистрирован

`Доступность: Сервер`

```
Зарегистрирован(): Булево
```

Возвращает признак того, что веб-чат зарегистрирован в приложении.

---

### Зарегистрировать

`Доступность: Сервер`

```
Зарегистрировать(
  СсылкаВебЧата: Строка,
  КлючПодписи: Байты|Строка)
```

Зарегистрировать веб-чат в приложении. Данные регистрации будут записаны в базу данных приложения.

- `СсылкаВебЧата`
  
  - URL точки подключения веб-чата. Можно получить при создании интеграции веб-чата.
- `КлючПодписи`
  
  - Ключ подписи, который используется для сопоставления пользователя чата и системы взаимодействия.

---

### ОтменитьРегистрацию

`Доступность: Сервер`

```
ОтменитьРегистрацию()
```

Отменить регистрацию веб-чата. Буду очищены данные регистрации веб-чата в текущем приложении.

Прошлые имена: ОтменитьРегистрацию
