## Обзор

Стандартный реквизит, который содержит уникальный идентификатор элемента справочника или обеспечивает последовательную нумерацию элементов.

## Документированный контракт и примеры

Стандартный реквизит, который содержит уникальный идентификатор элемента справочника или обеспечивает последовательную нумерацию элементов.

#### Автонумерация

```yaml
Автонумерация: 
    ДлинаНумерации: Число
    Формат: 
        РазделительПрефикса: Строка
        РазделительПостфикса: Строка
        ДлинаПрефикса: Число
        ДлинаПостфикса: Число
        ОграниченияПоСимволам: Булево
    Префикс: Строка
    Постфикс: Строка
    Использовать: Булево
    КонтрольФормата: КонтрольФорматаАвтоНумерации
```

Содержит настройки [автоматического заполнения номера](autonumber-elements-b3820bf0ba6d.md).

<details>
<summary>**Свойства**</summary>

##### ДлинаНумерации

Может принимать следующие значения:

- положительное число — длина автоматически формируемого номера,
- 0
  
  — длина номера автоматически вычисляется исходя из значения свойства
  
  Длина
  
  ,
- ∞
  
  или
  
  -1
  
  — номер не дополняется нулями (значение по умолчанию).

##### Формат

Описание формата префикса и постфикса.

<details>
<summary>**Свойства**</summary>

##### РазделительПрефикса

Символы, отделяющие префикс от номера. Значение по умолчанию — пустая строка (разделитель отсутствует).

##### РазделительПостфикса

Символы, отделяющие номер от постфикса. Значение по умолчанию — пустая строка (разделитель отсутствует).

##### ДлинаПрефикса

Длина префикса. Может принимать следующие значения:

- 0
  
  — префикс запрещен (значение по умолчанию),
- положительное число — количество символов в префиксе,
- ∞
  
  или
  
  -1
  
  — длина не ограничена.

##### ДлинаПостфикса

Длина постфикса. Может принимать следующие значения:

- 0
  
  — постфикс запрещен (значение по умолчанию),
- положительное число — количество символов в постфиксе,
- ∞
  
  или
  
  -1
  
  — длина не ограничена.

##### ОграниченияПоСимволам

Указывает, использовать ли следующие ограничения по символам:

- префикс не может заканчиваться на цифру,
- постфикс не может содержать цифры.

</details>

##### Префикс

Префикс, который будет добавляться к номеру.

##### Постфикс

Постфикс, который будет добавляться к номеру.

##### Использовать

Признак использования автонумерации. Значение по умолчанию — **Истина**.

##### КонтрольФормата

Определяет необходимость контроля формата автонумерации при записи:

- [Строгий](../project/autonumberingformatcontrol-ru-1616290c8f92.md)
  
  — номер должен строго совпадать с заданным форматом, запись нестандартных номеров запрещена.
- [Выключено](../project/autonumberingformatcontrol-ru-1616290c8f92.md)
  
  — контроль не ведется, возможна запись объектов с нестандартным номером.

Если элементу явно задан префикс или постфикс помощью свойств `Префикс` и `Постфикс` типа `{ИмяЭлементаПроекта}.ПараметрыЗаписи`, то номер считается стандартным и обязан совпадать с форматом. В этом случае значение свойства **КонтрольФормата** игнорируется.

Если префикс или постфикс не заданы, то при записи «Элемент» разберет номер на составные части и примет во внимание значение **КонтрольФормата**:

- если номер стандартный (т. е. проходит контроль формата) то
  
  «Элемент»
  
  выполнит стандартные действия: запишет вместе с элементом поля префикс, постфикс и номер;
- если номер не проходит контроль формата, то:
  
  - если значение
    
    КонтрольФормата
    
    равно
    
    Строгий
    
    , то будет выдано исключение;
  - если значение
    
    КонтрольФормата
    
    равно
    
    Выключено
    
    , то в поле
    
    Код
    
    (для справочника) или
    
    Номер
    
    (для документа) будет записан номер, а в поля
    
    Префикс
    
    и
    
    Постфикс
    
    будут записаны значения по умолчанию.

</details>
