### ХранилищеJks

`Доступность: Сервер`

```
ХранилищеJks(
  Данные: Байты|ПотокЧтения,
  Пароль: Секрет|Строка = "")
```

Загружает хранилище ключей из данных

`Данные`

в формате JKS.

`Пароль`

- пароль к хранилищу. Для использования разрешены символы ASCII с кодом от 33 до 126.

#### Исключения

**[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке загрузки хранилища. **[ИсключениеКриптографииНеправильныйПароль](../stdlib/incorrectpasswordcryptoexception-ru-3a412b425cf1.md)** - если указан неправильный пароль. **[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы.

**Перегрузка** [ХранилищеJks()](jksstore-ru-5bf34f5475fc.md) [ХранилищеJks(Файл: Файл|Строка, Пароль: Секрет|Строка = "")](jksstore-ru-5bf34f5475fc.md)

## Методы

### ВБайты

`Доступность: Сервер`

```
ВБайты(Пароль: Секрет|Строка = ""): Байты
```

Сохраняет хранилище в массив байт формата JKS.

`Пароль`

- пароль, устанавливаемый на сохраненное хранилище. Для использования разрешены символы ASCII с кодом от 33 до 126.

#### Исключения

**[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы.

---

### ЗаписатьВПоток

`Доступность: Сервер`

```
ЗаписатьВПоток(
  Поток: ПотокЗаписи,
  Пароль: Секрет|Строка = "")
```

Сохраняет хранилище в поток

`Поток`

в формате JKS.

`Пароль`

- пароль, устанавливаемый на сохраненное хранилище. Для использования разрешены символы ASCII с кодом от 33 до 126.

#### Исключения

**[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы.

---

### ЗаписатьВФайл

`Доступность: Сервер`

```
ЗаписатьВФайл(
  Файл: Файл|Строка,
  Пароль: Секрет|Строка = "")
```

Сохраняет хранилище в файл

`Файл`

в формате JKS. Если файл по указанному пути существует, он будет перезаписан.

`Пароль`

- пароль, устанавливаемый на сохраненное хранилище. Для использования разрешены символы ASCII с кодом от 33 до 126.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../stdlib/illegalargumentexception-ru-fc532bf88932.md)** - при невалидных символах в пути к файлу. **[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы.
