## Обзор

Блокировка для пространства блокировок `Код` справочника {ИмяСправочника}.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяСправочника}.Блокировки.Код` `Доступность: Сервер`

Блокировка для пространства блокировок `Код` справочника {ИмяСправочника}. Пространство используется для блокировки объектов справочника по значению поля `Код`. Доступно только если у справочника есть стандартный реквизит Код.

## Конструкторы

### {ИмяСправочника}.Блокировки.Код

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяСправочника}.Блокировки.Код(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Код: <ТипКода>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
