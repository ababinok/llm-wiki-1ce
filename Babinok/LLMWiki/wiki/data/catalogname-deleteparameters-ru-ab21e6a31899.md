## Обзор

Содержит параметры записи которые описаны в элементе проекта в разделе ПараметрыУдаления Формируется всегда, даже если в элементе проекта не описаны параметры удаления

## Свойства

### ОбменДанными

`Доступность: Сервер` `ТолькоЧтение`

```
ОбменДанными: ПараметрыОбменаДанными
```

Используется для управления обменом данных.

```yaml
ВидЭлемента: Справочник
Ид: 44e4ac92-0642-497f-b577-4ed28113345f
Имя: Контрагенты
ОбластьВидимости: ВПроекте
Реквизиты:
  -
    Имя: Код
    Тип: Строка
    Длина: 8
  -
    Имя: Наименование
    Длина: 150
# Прочие поля опущены для краткости
#...
ПараметрыУдаления:
  -
    Имя: ПроверитьСделки
    Тип: Булево?
```

Вызов удаления с параметрами

```xbsl
метод УдалитьКонтрагента(Контрагент: Контрагенты.Ссылка)
    знч Объект = Контрагент.ЗагрузитьОбъект()
    Объект.Удалить(Истина)
;
```

Обработка параметра в обработчике ПередУдалением. Пример запрещает удаление контрагента если по нему есть сделки.

```xbsl
@Обработчик
метод ПередУдалением(ПараметрыЗаписи: Контрагенты.ПараметрыУдаления)
    
    если ПараметрыЗаписи.ПроверитьСделки == Истина и Сделки.ЕстьСделкиПоПартнеру(этот.Ссылка)
        выбросить новый ИсключениеУдаленияЗаписи("В системе существуют сделки по партнеру ${этот.Ссылка}")
    ;
;
```
