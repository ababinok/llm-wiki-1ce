## Методы

### ЗаписатьПоКлючам

`Доступность: Сервер`

```
ЗаписатьПоКлючам(
  КлючОбъекта: Строка,
  КлючНастройки: Строка,
  Значение: Строка)
```

Метод записи настройки для текущего пользователя по ключам. Ищутся и записываются только уникальные настройки (Вариант = Ложь). Если по указанным ключам запись не будет найдена, метод создает новую настройку с указанными ключами и значением. Для новой настройки остальные реквизиты будут установлены в значения по умолчанию.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на запись объекта.

**Перегрузка** [ЗаписатьПоКлючам(КлючОбъекта: Строка, КлючНастройки: Строка, Значение: Строка, Наименование: Строка, Общая: Булево, ПараметрыЗаписи: СтандартноеХранилищеНастроек.ПараметрыЗаписи? = Неопределено)](standardsettingsstorage-ru-45df1deaf228.md)

Метод записи настройки для текущего пользователя по ключам. Ищутся и записываются только уникальные настройки (Вариант = Ложь). Если по указанным ключам запись не будет найдена, метод создает новую настройку. Позволяет кроме значения настройки устанавливать значения дополнительных реквизитов и параметры записи. Для новой настройки неуказанные реквизиты будут установлены в значения по умолчанию.

**[ИсключениеТаймаутаБлокировки](../stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на запись объекта.

**Перегрузка** [ЗаписатьПоКлючам(КлючОбъекта: Строка, КлючНастройки: Строка, Значение: Строка)](standardsettingsstorage-ru-45df1deaf228.md)

### ПересчитатьРазрешенияДоступаДляОбъектов

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<СтандартноеХранилищеНастроек.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

**Перегрузка** [ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<СтандартноеХранилищеНастроек.Ссылка>)](standardsettingsstorage-ru-45df1deaf228.md) [ПересчитатьРазрешенияДоступаДляОбъектов(Общая: Булево, Пользователь: Пользователи.Ссылка?)](standardsettingsstorage-ru-45df1deaf228.md)

### СоздатьФормуОбъекта

`Доступность: Клиент`

```
@ИменованныеПараметры
СоздатьФормуОбъекта(КлючИсточникаКопирования: СтандартноеХранилищеНастроек.Ссылка): ФормаОбъекта<СтандартноеХранилищеНастроек.Объект, неизвестно>
```

>

Вызов возможен только с именованными параметрами

Создает форму объекта хранилища настроек. Для стандартного хранилища будет создана автоматическая форма

Параметр `КлючИсточникаКопирования` определяет, какой объект будет использоваться в качестве источника создания копированием. При этому будет открыта форма нового объекта, являющегося копией того, который был указан в качестве источника.

**Перегрузка** [СоздатьФормуОбъекта(Ключ: СтандартноеХранилищеНастроек.Ссылка? = Неопределено): ФормаОбъекта<СтандартноеХранилищеНастроек.Объект, неизвестно>](standardsettingsstorage-ru-45df1deaf228.md)

### СоздатьФормуОбъекта

`Доступность: Клиент`

```
СоздатьФормуОбъекта(Ключ: СтандартноеХранилищеНастроек.Ссылка? = Неопределено): ФормаОбъекта<СтандартноеХранилищеНастроек.Объект, неизвестно>
```

Параметр `Ключ` определяет, какой объект будет редактироваться в форме. Если в качестве значения ключа передано [Неопределено](../stdlib/undefined-ru-bad7e9ef4c2b.md), то будет открыта форма нового объекта.
