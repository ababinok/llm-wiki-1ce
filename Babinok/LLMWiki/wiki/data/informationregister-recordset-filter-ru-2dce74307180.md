## Обзор

Базовый тип для всех типов фильтров наборов записей регистров сведений.

## Документированный контракт и примеры

`Стд::РегистрыСведений::РегистрСведений.НаборЗаписей.Фильтр` `Доступность: Сервер`

Базовый тип для всех типов фильтров наборов записей регистров сведений. Изначально после создания фильтр не инициализирован. Изменение любого свойства, любого элемента фильтра считается инициализацией. Так же инициализацией считается вызов метода Установить, в т.ч. с пустым списком аргументов. Попытка записать, прочитать набор записей с неинициализированным фильтром или вызывать метод `ДобавитьЗапись()` приведет к ошибке "Фильтр не инициализирован".

