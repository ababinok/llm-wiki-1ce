Имена для поиска: `ИзмерениеРегистраСведений`, `InformationRegisterDimension`, `Std::ProjectElements::InformationRegister::Dimensions::InformationRegisterDimension`.

## Обзор

Значение (например, товар, склад, валюта), для которого в регистре сведений хранится некоторая информация.

## Документированный контракт и примеры

Значение (например, товар, склад, валюта), для которого в регистре сведений хранится некоторая информация.

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](../project/displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [Обычная](../project/displayimportance-ru-469c555fd91c.md).

#### НезаполненноеЗначение

```yaml
НезаполненноеЗначение: ПолитикаПроверки
```

Определяет политику проверки пустого значения элемента.

---

#### Ведущее

```yaml
Ведущее: Булево
```

Используется для автоматического удаления записи из регистра сведений при удалении соответствующего объекта из базы данных. Данное свойство следует использовать в том случае, когда типом измерения является ссылка на объект базы данных (например, элемент справочника).

---
