## Обзор

Блокировка для пространства блокировок `КлючЗаписи` регистра сведений `{ИмяРегистрСведений}`.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраСведений}.Блокировки.КлючЗаписи` `Доступность: Сервер`

Блокировка для пространства блокировок `КлючЗаписи` регистра сведений `{ИмяРегистрСведений}`. Пространство используется для блокировки записей регистра сведений с указанными значениями измерений и / или стандартного поля `Период`. При записи набора записей на это пространство платформой устанавливается исключительная блокировка со значениями полей-измерений, соответствующими фильтру набора записей.

### {ИмяРегистраСведений}.Блокировки.КлючЗаписи

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ИмяРегистраСведений.Блокировки.КлючЗаписи(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  <ИмяИзмерения>: <ТипИзмерения>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры необязательные. Если значение параметра, соответствующего полю блокировки, не задано, значение этого поля в блокировке не указано (блокируются все значения).
