### ВычислитьРазрешенияДоступа

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на справочник целиком.

---

### ВычислитьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступаДляОбъектов(Элементы: ЧитаемыйМассив<ИмяСправочника.ДанныеРасчетаРазрешений>): ЧитаемоеСоответствие<ИмяСправочника.ДанныеРасчетаРазрешений,ЧитаемаяКоллекция<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на отдельные элементы справочника.

Принимает данные для расчета разрешений доступа объектов, для которых нужно вычислить права, и возвращает соответствие данных для расчета разрешений доступа объектов и установленных для них разрешений.

Используется только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение `РазрешенияВычисляютсяДляКаждогоОбъекта`

### НайтиПоКоду

`Версия 10.0 и выше`

`Доступность: Сервер`

```
НайтиПоКоду(Код: <ТипКода>): <{ИмяСправочника}>
```

Метод поиска объектов по коду. Тип параметра зависит от типа кода, определенного для объекта.

Метод НайтиПоКоду выполняет только однозначный поиск ссылки по коду. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности.

#### Исключения

**[ИсключениеПоискаСущности](entitysearchexception-ru-ae3d905c5b5f.md)** - результат поиска неоднозначен. Найдено несколько ссылок с таким кодом.

---

### НайтиПоКоду

`Версия 10.0 и выше`

`Доступность: Сервер`

```
НайтиПоКоду(
  Код: <ТипКода>,
  Владелец: <ТипВладельца> = Неопределено
): <{ИмяСправочника}>
```

Метод поиска объектов по коду. Тип параметра зависит от типа кода, определенного для объекта.

Необязательный параметр "Владелец" присутствует только у справочников, подчиненных владельцу. Если параметр не указан, поиск выполняется во всем справочнике. Если указан - только в пределах подчинения владельцу.

Метод НайтиПоКоду выполняет только однозначный поиск ссылки по коду. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности.

#### Примеры

```xbsl
метод НайтиДоговорКлиента(ИскомыйКод: Строка, Контрагент: Контрагенты.Ссылка): Договоры.Ссылка?
    // Поиск по коду в пределах конкретного владельца
    возврат Договоры.НайтиПоКоду(ИскомыйКод, Контрагент)
;
```

### СоздатьНаОсновании

`Версия 10.0 и выше`

```
СоздатьНаОсновании(Основание: <Типыисточниковсозданиянаосновании>): <{ИмяСправочника}>
```

Метод создания нового объекта на основании другого.

Параметр `Основание` служит для указания основания при создании объекта. Значение этого параметра передастся в обработчик события `ПриСозданииНаОсновании`.

#### Примеры

Создание элемента справочника "Книги" на основании элемента справочника "Авторы".

У справочника "Книги" свойство `СозданиеНаОсновании` заполнено следующим образом:

```yaml
СозданиеНаОсновании: [Авторы.Ссылка]
```

Для создания на основании можно использовать следующий код:

```xbsl
метод СоздатьКнигуПоАвтору(Название: Строка, Автор: Авторы.Ссылка): Книги.Ссылка
    знч Книга = Книги.СоздатьНаОсновании(Основание = Автор)
    Книга.Наименование = Название
    Книга.Записать()
    
    возврат Книга.Ссылка
;
```

## Обработчики

### ПолучитьЗначенияВыбора

`Версия 10.0 и выше`

```
ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Событие вызываемое при попытке получить данные для выбора по введенной подстроке. В событие передается информация о набранной строке, и параметрах фильтра. Событие должно возвратить массив выбранных данных, или Неопределено если требуется выполнить стандартную обработку события.

#### Примеры

Отфильтровать возможные значения статуса сделки для выбранного бизнес-проекта

```xbsl
@Обработчик
метод ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемаяКоллекция<ЭлементСпискаВыбора>?
       
    знч Фильтр = Параметры.Фильтр
    
    пер ЕстьПроект = Ложь
    пер ЗначениеФильтраПроект: Объект? = Неопределено
    
    для Элемент из Фильтр.Элементы
        знч ЭлементФильтра = Элемент как ЭлементФильтра
        
        если ЭлементФильтра.Поле == "Проект"
            ЕстьПроект = Истина
            ЗначениеФильтраПроект = ЭлементФильтра.Значение
            прервать
        ;
    ;
    
    если ЕстьПроект
        возврат Проекты.ПолучитьВозможныеСтатусыСделок(ЗначениеФильтраПроект)
    ;
    
    возврат Неопределено
;
```

Обработчик, который вычисляет ссылку на справочник по внешней навигационной ссылке.

Параметры:

- `НавигационнаяСсылка`
  
  - внешняя навигационная ссылка.

Обработчик используется в контекстных обсуждениях системы взаимодействия и всегда используется в паре с обработчиком `ВычислитьВнешнююНавигационнуюСсылку`.
