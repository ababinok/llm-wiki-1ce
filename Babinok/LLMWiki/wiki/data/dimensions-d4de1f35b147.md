## Обзор

Ключевые реквизиты, описывающие разрезы, в которых хранится информация.

## Документированный контракт и примеры

#### Измерения

```yaml
Измерения: ИзмерениеРегистраСведений[]
```

Ключевые реквизиты, описывающие разрезы, в которых хранится информация. В качестве типов измерений нельзя использовать типы `Строка` и `Байты` неограниченной длины, а также тип `ДвоичныйОбъект.Ссылка`. Список измерений не может быть пустым.

Значения всех измерений записи образуют ключ этой записи: ключ записи должен быть уникален в пределах всего регистра. Таким образом, ключ однозначно идентифицирует запись регистра. Порядок измерений имеет значение — по ним в основной таблице регистра сведений создается индекс (измерения учитываются в том порядке, в котором они описаны).
