## Примеры

**Общие примеры**

```xbsl
метод УстановитьБлокировкуДляЗаписи(Регистратор: ЗаказКлиента.Ссылка)
    Блокировки.Заблокировать(новый ЗаказыКлиентов.Блокировки.Регистратор(Регистратор = Регистратор))
;
```

Блокировка для пространства блокировок `Регистратор` регистра накопления {ИмяРегистраНакопления}. Пространство используется для блокировки записей регистра накопления с указанными значением стандартного поля `Регистратор`. При записи набора записей на это пространство платформой устанавливается исключительная блокировка со значением поля `Регистратор` соответствующим фильтру набора записей.

## Конструкторы

### {ИмяРегистраНакопления}.Блокировки.Регистратор

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяРегистраНакопления}.Блокировки.Регистратор(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Регистратор: <ТипРегистратора>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
