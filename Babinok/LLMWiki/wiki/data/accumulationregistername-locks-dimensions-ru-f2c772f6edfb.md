## Обзор

Блокировка для пространства блокировок `Измерения` регистра накопления {ИмяРегистраНакопления}.

## Документированный контракт и примеры

Блокировка для пространства блокировок `Измерения` регистра накопления {ИмяРегистраНакопления}. Пространство используется для блокировки записей регистра накопления с указанными значениями измерений.

## Конструкторы

### {ИмяРегистраНакопления}.Блокировки.Измерения

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяРегистраНакопления}.Блокировки.Измерения(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  <ИмяИзмерения>: <ТипИзмерения>)
```

Конструирует блокировку данных в пространстве блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
