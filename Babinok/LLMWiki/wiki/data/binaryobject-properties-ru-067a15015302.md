## Обзор

Представляет описание прикладных свойств и требований к объектному хранилищу, в которое будет помещен двоичный объект.

## Документированный контракт и примеры

`Стд::ОбъектноеХранилище::ДвоичныйОбъект.Свойства` `Доступность: Сервер`

Представляет описание прикладных свойств и требований к объектному хранилищу, в которое будет помещен двоичный объект. На основе значений свойств администратор настраивает как объекты должны распределяться системой по различным хранилищам.

Свойства используются для классификации двоичных объектов с целью выбора оптимального объектного хранилища и не влияют на время жизни и доступ к данным.

## Примеры

**Общие примеры**

```xbsl
знч ВременныеФайлы = новый ДвоичныйОбъект.Свойства("temp").Временные()

знч РезервныеКопии = новый ДвоичныйОбъект.Свойства("backup")
    .РедкийДоступ()
    .Конфиденциальность(КонфиденциальностьДвоичногоОбъекта.Конфиденциальный)
    .НадежностьХранилища(НадежностьОбъектногоХранилища.Средняя)

знч ФайлыЗадач = новый ДвоичныйОбъект.Свойства("Файлы задач")
    .Конфиденциальность(КонфиденциальностьДвоичногоОбъекта.Конфиденциальный)
    .ЧастыйДоступ(30д)

знч ВременныйОбъект1 = ОбъектноеХранилище.Загрузить("data.tmp", "Данные", Свойства = ВременныеФайлы)
знч ВременныйОбъект2 = ОбъектноеХранилище.Загрузить(
    "data.tmp", "Данные", Свойства = новый ДвоичныйОбъект.Свойства("temp").Временные())

ОбъектноеХранилище.УстановитьСвойства(ВременныйОбъект2.Ссылка, ФайлыЗадач)
```

## Конструкторы

### ДвоичныйОбъект.Свойства

`Доступность: Сервер`

```
ДвоичныйОбъект.Свойства(Код: Строка)
```

Создает экземпляр объекта с кодом

`Код`

.

По коду может быть разделено хранение двоичных объектов по разным хранилищам, а также вестись статистика по занимаемому месту. Рекомендуется давать краткое описание прикладного назначения данных, например: "Картинки каталога", "Вложения почты", "Сканы документов" и т.п.
