## Обзор

Содержит параметры записи которые описаны в элементе проекта в разделе ПараметрыЗаписи Формируется всегда, даже если в элементе проекта не описаны параметры изменения

### Постфикс

`Доступность: КлиентИСервер`

```
Постфикс: Строка?
```

Постфикс кода автонумерации. Свойство предназначено для установки постфикса кода при записи. Свойство присутствует только если справочник имеет реквизит "Код" с нумерацией в разрезе постфикса.

Устанавливают значения постфикса, которые будут использованы в момент вызова Записать() для формирования нового кода. Непосредственно перед записью в базу данных, происходит присвоение кода по следующему алгоритму:

- если было изменение значения реквизита "Код"
  
  - Код не пуст → не генерируем новый номер в коде, берем значение из реквизита
  - Код пуст → генерируем новый номер и занимаем его
- если задан
  
  [Префикс](catalogname-writeparameters-ru-e5f7bfa025cc.md)
  
  или
  
  [Постфикс](catalogname-writeparameters-ru-e5f7bfa025cc.md)
  
  - освобождаем старый номер в коде
  - занимаем новый номер в коде в рамках нового префикса и постфикса

#### Примеры

Настройка объекта в yaml

```yaml
ВидЭлемента: Справочник
Ид: 44e4ac92-0642-497f-b577-4ed28113345f
Имя: Контрагенты
ОбластьВидимости: ВПроекте
Реквизиты:
  -
    Имя: Код
    Тип: Строка
    Длина: 8
  -
    Имя: Наименование
    Длина: 150
# Прочие поля опущены для краткости
#...
ПараметрыЗаписи:
  -
    Имя: ЗапуститьСогласование
    Тип: Булево?
```

Вызов записи с параметрами

```xbsl
знч НовыйКонтрагент = новый Контрагенты.Объект(Наименование = "ООО Ромашка", ИНН = "123456789")
НовыйКонтрагент.Записать(Истина)
```

Обработка параметра в обработчике ПередЗаписью

```xbsl
@Обработчик
метод ПередЗаписью(До: Контрагенты.Данные, ПараметрыЗаписи: Контрагенты.ПараметрыЗаписи)
    
    если ПараметрыЗаписи.ЗапуститьСогласование == Истина
        знч Согласование = новый Согласования.Объект(
            Предмет = Ссылка,
            Согласующие = [РолиСогласований.ФинДиректор, РолиСогласований.СлужбаБезопасности]
        )
        
        Согласование.Записать()
    ;
;
```

Запись с установкой префикса

```xbsl
знч НовыйКонтрагент = новый Контрагенты.Объект(
    Наименование = "ООО Ромашка",
    ИНН = "1234567890"
)

знч ПараметрыЗаписи = новый Контрагенты.ПараметрыЗаписи()
ПараметрыЗаписи.Префикс = "БП"
ПараметрыЗаписи.ЗапуститьСогласование = Ложь

НовыйКонтрагент.Записать(ПараметрыЗаписи)
```
