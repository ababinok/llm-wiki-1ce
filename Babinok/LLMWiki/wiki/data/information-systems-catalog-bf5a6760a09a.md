## Обзор

Все процессы интеграции используют [справочник](catalog-project-element-b6ca52d114d4.md) **ИнформационныеСистемы**, реализующий контракт сущности [СправочникИнформационныхСистем](information-systems-catalog-bf5a6760a09a.md).

## Документированный контракт и примеры

> [!WARNING] важно
> Процессы интеграции недоступны в облачной версии «1С:Предприятие.Элемента».

Все процессы интеграции используют [справочник](catalog-project-element-b6ca52d114d4.md) **ИнформационныеСистемы**, реализующий контракт сущности [СправочникИнформационныхСистем](information-systems-catalog-bf5a6760a09a.md).

> [!NOTE] примечание
> Системный справочник **ИнформационныеСистемы** удален в версии 8.0. Если вы использовали расширения этого справочника в своем проекте, то при переходе в режим совместимости 8.0 вам необходимо [создать новый справочник информационных систем](information-systems-catalog-bf5a6760a09a.md), перенести в него все данные, а затем удалить расширения системного справочника.

В пользовательском интерфейсе «1С:Предприятие.Элемента» справочник информационных систем отображается в разделе **Инфосистемы**.

Раздел «Инфосистемы» приложения: слева список информационных систем, справа карточка выбранной системы с реквизитами, ключом API и участием в процессах и группах. [Описание иллюстрации](../../raw/figures/50c2d46d316ef72e927534f5fee7a63137f49e480b1e15b0d915c26f9691242f-0a53dc5f76c5089c.md)

Элемент этого справочника связан с пользователем, от имени которого информационная система подключается к серверу «1С:Предприятие.Элемента». «1С:Предприятие.Элемент» создает этого пользователя одновременно с элементом справочника. Созданные таким образом пользователи могут подключаться к серверу только с использованием токенов. Чтобы [получить токен](../integration/amqp-connection-3210085a03a8.md), необходимо нажать кнопку **Выдать ключ API**, сгенерировать **Идентификатор ключа** и **Секрет клиента**, а затем предоставить эти данные «1С:Предприятие.Элементу» ([подробнее](../project/create-information-system-50be9432f751.md)).

Связанные с инфосистемами пользователи показываются в панели управления в разделе **Пользователи**.

> [!NOTE] примечание
> Настоятельно рекомендуем не удалять пользователей, связанных с инфосистемами, средствами панели управления, так как после этого информационная система не сможет подключиться к «1С:Предприятие.Элементу», а направленные ей сообщения не будут получены.

Справочник информационных систем имеет следующие обязательные поля, которые заполняются при создании участника и выдаче ключей API в разделе **Инфосистемы**:

- `Код`
  
  — строка (36 символов). Коды элементов должны использоваться отправителями сообщений для указания участников, которым это сообщение предназначено.
- `Наименование`
  
  — строка (255 символов).
- `Описание`
  
  — строка.
- `ПользовательПоУмолчанию`
  
  — объект типа
  
  `Пользователи.Ссылка?`
  
  . Свойство содержит ссылку на созданного и подключенного к приложению пользователя.
- `ИдТокена`
  
  — строка (255 символов). Идентификатор выпущенного для пользователя токена. Доступ по токену должен быть разрешен (
  
  [подробнее](../stdlib/users-eee22ba38c57.md)
  
  ).

Создание элемента справочника «Информационные системы» [Описание иллюстрации](../../raw/figures/bb8fdfbf2a02de34073084acbedbf29dd10d7dd57c1ec5f754005865fcfa7898-6d041d8a5f41cee5.md)

Помимо этого, в среде разработки в справочник можно [добавлять новые реквизиты](../project/create-attributes-for-information-system-a64ba148c36c.md). Вы сможете заполнить их в пользовательском интерфейсе приложения как **Свойства участника** при добавлении новой информационной системы в разделе **Инфосистемы** или программно в коде приложения.

> [!NOTE] примечание
> Чтобы добавить справочник информационных систем в процесс интеграции, выберите его в поле **СправочникУчастников** панели свойств процесса интеграции. Если в вашем проекте только один справочник, реализующий контракт [СправочникИнформационныхСистем](information-systems-catalog-bf5a6760a09a.md), он добавится автоматически при создании процесса интеграции.

## Контракт сущности «СправочникИнформационныхСистем»

Если в вашем проекте нет справочника информационных систем, вы можете создать его самостоятельно. Создайте элемент проекта **Справочник** и добавьте в него контракт сущности **СправочникИнформационныхСистем**. Для этого в панели свойств справочника для свойства **НастройкиТипов** для типа `Справочник.Объект` укажите значение `СправочникИнформационныхСистем.Объект`:

Добавление контракта сущности для справочника [Описание иллюстрации](../../raw/figures/9a095a86f8961e1c5b64c2678e34e34da5a717d86d47ed0253e05bf427fadd68-b710c877d3f36a33.md)

Пример описания собственного справочника

```yaml
ВидЭлемента: Справочник
Ид: fd0c91fb-5954-4a20-95ad-ab23c4fe210a
Имя: МойСправочник
ОбластьВидимости: ВПодсистеме
НастройкиТипов:
    Справочник.Объект:
        Контракты:
            - СправочникИнформационныхСистем.Объект
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
КонтрольДоступа:
    Разрешения:
        ПоУмолчанию: РазрешеноАутентифицированным
Реквизиты:
    -
        Имя: Наименование
        Длина: 255
    -
        Имя: Код
        Длина: 36
        Тип: Строка
    -
        Ид: b780bf1d-296b-492e-886f-799d69590116
        Имя: Описание
        Тип: Строка
    -
        Ид: e1042104-cada-4c4e-921b-620cd6196f6b
        Имя: ПользовательПоУмолчанию
        Тип: Пользователи.Ссылка?
    -
        Ид: 34a68ff4-5349-40b6-9c86-2763ef5d0031
        Имя: ИдТокена
        Тип: Строка
        МаксимальнаяДлина: 255
```

При необходимости после добавления контракта сущности вы можете добавить в справочник [собственные реквизиты](../project/create-attributes-for-information-system-a64ba148c36c.md).

После этого его можно будет выбрать в поле **СправочникУчастников** панели свойств процесса интеграции:
