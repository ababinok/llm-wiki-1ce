### ПриСозданииНаОсновании

`Версия 10.0 и выше`

```
ПриСозданииНаОсновании(Основание: <Типисточникасозданиянаосновании>)
```

Вызывается при создании нового экземпляра документа на основании другого объекта. Подразумевается, что в этом обработчике события разработчик приложения должен реализовать логику создания документа на основании чего-то.

Параметр `Основание` содержит то, на основании чего создается объект.

Если в элементе проекта документа в качестве источников создания на основании (свойство `СозданиеНаОсновании`) указано несколько оснований, то будет столько же перегрузок этого события (параметр `Основание` будет тех типов, которые указаны в свойстве `СозданиеНаОсновании`).

Например, если у документа указаны источники создания на основании:

```yaml
СозданиеНаОсновании: [СчетНаОплату.Ссылка, ЗаказКлиента.Ссылка]
```

То нужно сделать следующие обработчики события `ПриСозданииНаОсновании`:

```xbsl
@Обработчик
метод ПриСозданииНаОсновании(Основание: Накладная.Ссылка)
    //Код создания на основании тут
;

@Обработчик
метод ПриСозданииНаОсновании(Основание: ЗаказКлиента.Ссылка)
    //Код создания на основании тут
;
```

Если у элемента проекта не указано источников создания на основании, то это событие будет отсутствовать.

#### Примеры

Ввод накладной на основании ранее выписанного счета на оплату

```xbsl
@Обработчик
метод ПриСозданииНаОсновании(Основание: ЗаказКлиента.Ссылка)
    
    знч ДанныеОснования = Основание.ЗагрузитьОбъект()
    
    этот.Контрагент = ДанныеОснования.Контрагент
    этот.Договор = ДанныеОснования.Договор
    
    для СтрокаОснования из ДанныеОснования.Товары
        этот.Товары.Добавить(новый СтрокаСчета(
            Товар = СтрокаОснования.Товар,
            Цена = СтрокаОснования.Цена,
            Количество = СтрокаОснования.Количество
        ))
    ;   
;
```

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяДокумента}.Данные)
```

Вызывается при создании нового экземпляра документа копированием существующего. На момент вызова этого обработчика значения реквизитов у нового объекта будут уже заполнены из документа - источника. Не будут автоматически копироваться стандартные реквизиты документа:

- Номер
- Дата

Кроме того, не будут копироваться реквизиты, копирование которых отключено в документе с помощью свойства `ЗаполнятьПриКопировании`.

Параметр `Источник` содержит данные исходного документа, копированием которого и создается новый документ.

#### Примеры

Допустим, в проекте есть документ "ЗаказКлиента". И у этого документа есть реквизит "Автор" с типом `Пользователи.Ссылка`. При создании нового заказа клиента копированием существующего, неправильно, чтобы значение реквизита "Автор" копировалось из исходного документа. Необходимо, чтобы в значение реквизита "Автор" подставлялся текущий пользователь. В этом случае можно в обработчике `ПриСозданииКопии` это исправить:

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: ЗаказКлиента.Данные)
    Автор = Пользователи.ТекущийПользователь
;
```

### ПередЗаписью

```
ПередЗаписью(
```

Обработчик, вызываемый перед записью объекта в базу данных. Для нового объекта параметр

Параметр `ПараметрыЗаписи` содержит объявленные в объекте параметры записи (см. [ИмяДокумента.ПараметрыЗаписи](documentname-writeparameters-ru-38399d5ab845.md)).

Обработка объявленного в объекте параметра записи ОповещатьМенеджеров

```xbsl
@Обработчик
метод ПередЗаписью(До: ЗаказКлиента.Данные, ПараметрыЗаписи: ЗаказКлиента.ПараметрыЗаписи)
    
    если ПараметрыЗаписи.ОповещатьМенеджеров != Ложь
        // Оповещение не выключено. Оповещаем
        РаботаСОповещениями.УведомитьОЗаказе(Ссылка)
    ;
    
;
```


### ПослеУдаления

```
ПослеУдаления(ПараметрыУдаления: {ИмяДокумента}.ПараметрыУдаления)
```

Обработчик, вызываемый после удаления объекта в базе данных.

Выполняется в транзакции.

Параметр `ПараметрыУдаления` содержит объявленные в объекте параметры удаления (см. [ИмяДокумента.ПараметрыУдаления](documentname-deleteparameters-ru-db0131a3263a.md)).

#### Примеры

Подписка на событие, объявленная в общем модуле

```xbsl
@Подписка(Событие{ЗаказКлиента.Объект.ПослеУдаления})
метод ПодпискаПослеУдаленияЗаказаКлиента(Источник: ЗаказКлиента.Данные, Параметры: ЗаказКлиента.ПараметрыУдаления)
    // Обработка события
;
```
