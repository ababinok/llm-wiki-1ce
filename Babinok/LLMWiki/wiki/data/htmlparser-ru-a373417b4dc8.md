## Методы

### Разобрать

`Доступность: Сервер`

```
Разобрать(
  Html: Строка,
  БазовыйUrl: Строка = ""
): РезультатРазбораДокументаHtml
```

> - Если переданный html не обернут в теги
>   
>   `<html>`
>   
>   ,
>   
>   `<body>`
>   
>   ..., то соответствующие теги будут проставлены, переданный контент будет помещен в тело

- Если полученный html не содержит тега
  
  `<head>`
  
  , он будет проставлен
- При разборе будут удалены дублирующиеся атрибуты на одном элементе. В ошибках разбора будет выдано соответствующее предупреждение
- При разборе элементов с блочными тегами, если они не проставлены блочно в ошибках разбора будет содержатся соответствующее предупреждение. При нормализации документа, данная проблема будет исправлена. То есть элемент вида
  
  `<tag/>`
  
  будет превращен в
  
  `<tag></tag>`
  
  , если тег блочный

Разобрать html код с базовым урлом.

**Перегрузка** [Разобрать(Источник: Файл|ПотокЧтения, Кодировка: Кодировка|Строка = Кодировка.Utf8, БазовыйUrl: Строка = ""): РезультатРазбораДокументаHtml](htmlparser-ru-a373417b4dc8.md)

#### Примеры

```xbsl
метод РазобратьHtmlСБазовымУрлом(Парсер: РазборHtml): ДокументHtml
    пер Результат = Парсер.Разобрать(
        "<p style=\"margin: 0 0 16px;\">Мы пришлем Вам доступ в течении дня. Ожидайте.</p>\n" +
        "<p style=\"margin: 0 0 16px;\">Если вдруг по каким-то причинам вы не получили ключ...</p>")
    если не Результат.ОшибкиРазбора.Пусто()
        // Можно выдать пользователю ошибки.
    ;
    возврат Результат.Документ 
;
```
