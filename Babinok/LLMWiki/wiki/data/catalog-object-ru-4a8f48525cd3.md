### ЭтоНовый

`Доступность: КлиентИСервер`

```
ЭтоНовый(): Булево
```

Признак того, что объект только что создан и не был еще записан.

#### Примеры

Установка времени создания или модификации записи

```xbsl
@Обработчик
метод ПередЗаписью(До: Договоры.Данные, ПараметрыЗаписи: Договоры.ПараметрыЗаписи)
    
    // Устанавливается значение реквизита ДатаСоздания или ДатаИзменения
    // справочника Договоры, в зависимости от того, новый это объект или существующий.
    
    если ЭтоНовый()
        ДатаСоздания = ДатаВремя.Сейчас()
    иначе
        ДатаИзменения = ДатаВремя.Сейчас()
    ;    
;
```
