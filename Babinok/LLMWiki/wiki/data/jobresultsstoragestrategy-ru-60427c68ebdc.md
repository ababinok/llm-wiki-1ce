## Примеры

**Общие примеры**

**Устаревший тип будет удален в следующей версии!**

Хранить только последний результат выполнения задания

```xbsl
// Хранить только последний результат выполнения задания
пер Задание = ЗапланированныеЗадания.Создать(&МойМодуль.МойМетод)
Задание.Настроить(Ключ = "МоеЗадание",
    Расписание = Расписание.Еженедельно(Время{8:00}, {ДеньНедели.Понедельник}),
    ХранениеРезультатов = СтратегияХраненияРезультатовЗаданий.Последний())
Задание.Запланировать()
```

## Методы

### Все

`Доступность: КлиентИСервер` `Статический`

```
Все(): СтратегияХраненияРезультатовЗаданий
```

Стратегия, которая предписывает хранить все результаты выполнения задания.

---

### Дней

`Доступность: КлиентИСервер` `Статический`

```
Дней(Дней: Число): СтратегияХраненияРезультатовЗаданий
```

Стратегия, которая предписывает хранить результаты выполнения задания указанное число дней

`Дней`

.

### Отсутствует

`Доступность: КлиентИСервер` `Статический`

```
Отсутствует(): СтратегияХраненияРезультатовЗаданий
```

Стратегия, которая предписывает не хранить результат выполнения задания.

---

### Последний

```
Последний(): СтратегияХраненияРезультатовЗаданий
```
