## Обзор

Блокировка для пространства блокировок `Номер` документа <Имя документа>.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяДокумента}.Блокировки.Номер` `Доступность: Сервер`

Блокировка для пространства блокировок `Номер` документа <Имя документа>. Пространство используется для блокировки объектов справочника по значению поля `Номер`. Доступно только если у документа есть стандартный реквизит Номер.

## Конструкторы

### {ИмяДокумента}.Блокировки.Номер

`Доступность: Сервер`

```
@ИменованныеПараметры
{ИмяДокумента}.Блокировки.Номер(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Номер: <ТипНомера>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
