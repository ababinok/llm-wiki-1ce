## Документированный контракт и примеры

`Стд::Pdf::ДокументPdf` `Доступность: Сервер`

Объект для работы с документом формата PDF.

Методы чтения и импорта PDF-документов можно вызывать только для непустых входных потоков. Если поток пуст, то выбрасывается `ИсключениеВводаВывода`.

## Методы

### ДобавитьСтраницу

`Доступность: Сервер`

```
ДобавитьСтраницу(
  Индекс: Число,
  Размер: РазмерСтраницы
): СтраницаPdf
```

Добавить пустую страницу размера

`Размер`

в PDF документ под индексом

`Индекс`

. Все страницы документа, имеющие индекс больше или равный

`Индекс`

, будут располагаться после добавляемой.

По умолчанию, страница добавляется в конец документа. Если документ пустой, то размер страницы по умолчанию - A4. Если страница вставляется в начало непустого документа, то берутся размеры страницы под нулевым индексом. Если существует предыдущая страница, то для создания используется её размер.

Метод возвращает объект типа `СтраницаPdf`, ссылающийся на добавленную страницу.

#### Исключения

**[ИсключениеИндексВнеГраниц](../stdlib/indexoutofboundsexception-ru-2b34a623369c.md)** - если индекс не лежит в границах: `0 ... ЧислоСтраниц`. **[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт.

#### Примеры

```xbsl
метод ДобавитьТитульнуюИФинальнуюСтраницы(Документ: ДокументPdf)
    Документ.ДобавитьСтраницу(0)
    Документ.ДобавитьСтраницу()
;
```

### ДобавитьСтраницуИзИзображения

`Доступность: Сервер`

```
ДобавитьСтраницуИзИзображения(
  Поток: ПотокЧтения,
  Индекс: Число,
  Размер: РазмерСтраницы
): СтраницаPdf
```

Добавить страницу в PDF документ под индексом

`Индекс`

на основе изображения из потока. Поддерживаемые форматы изображения: JPEG, TIFF, GIF, BMP, PNG. Страница будет иметь указанные в миллиметрах размеры. Все страницы документа, имеющие индекс больше или равный

`Индекс`

, будут располагаться после добавляемой.

По умолчанию, страница добавляется в конец документа. Если документ пустой, то размер страницы по умолчанию - A4. Если страница вставляется в начало непустого документа, то берутся размеры страницы под нулевым индексом. Если существует предыдущая страница, то для создания используется её размер.

Левый верхний угол изображения будет размещен в (`x = 0, y = 0`). Размеры картинки, как максимально возможные, определяются автоматически, но так, чтобы она целиком уместилась на странице, при этом сохраняется отношение сторон.

Метод возвращает объект типа `СтраницаPdf`, ссылающийся на добавленную страницу.

#### Исключения

**[ИсключениеИндексВнеГраниц](../stdlib/indexoutofboundsexception-ru-2b34a623369c.md)** - если индекс не лежит в границах: `0 ... ЧислоСтраниц`. **[ИсключениеВводаВывода](../stdlib/inputoutputexception-ru-ceba5f672999.md)** - если чтение изображения завершилось неудачей. **[ИсключениеPdf](../stdlib/pdfexception-ru-fca07efa7071.md)** - ошибка при вставке изображения на страницу документа. **[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт.

#### Примеры

```xbsl
метод ДобавитьСтраницуИзИзображенияВКонецДокумента(Документ: ДокументPdf, Поток: ПотокЧтения)
    Документ.ДобавитьСтраницуИзИзображения(Поток)
;
```

### Записать

`Доступность: Сервер`

```
Записать(
  Поток: ПотокЗаписи,
  Формат: ФорматДокументаPdf = ФорматДокументаPdf.Pdf,
  Пароль: Секрет|Строка = "")
```

Записать документ в формате PDF в

`Поток`

типа

`ПотокЗаписи`

. Аргумент

`Формат`

позволяет указать формат для сохранения (обычный, для долгосрочного хранения). Если требуется защитить итоговый документ паролем, то его нужно передать в строковом представлении. Если документ записывается в одном из форматов для долгосрочного хранения (

`ФорматДокументаPdf.PdfA1/2/3`

), то он не будет защищён паролем, указанным в аргументе

`Пароль`

.

При записи документа будет встроен шрифт, используемый в нем. Если шрифт отсутствует в окружении, то он будет заменен на шрифт по умолчанию в операционной системе.

#### Исключения

**[ИсключениеВводаВывода](../stdlib/inputoutputexception-ru-ceba5f672999.md)** - если запись документа завершилось неудачей, или производится запись с паролем в одном из форматов: `PdfA1`, `PdfA2`, `PdfA3`. **[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт.

#### Примеры

```xbsl
метод ЗаписатьЗащищенныйДокументВФорматеPdfA1(ПотокЧтения: ПотокЧтения, ПотокЗаписи: ПотокЗаписи)
    исп Документ = ДокументPdf.Прочитать(ПотокЧтения, "template123") 

    // Запись документа в формате PDF/A-1a
    Документ.Записать(ПотокЗаписи, ФорматДокументаPdf.PdfA1) 
;
```

### ИмпортироватьИзDocx

`Доступность: Сервер` `Статический`

```
ИмпортироватьИзDocx(
  Поток: ПотокЧтения,
  Пароль: Секрет|Строка = ""
): ДокументPdf
```

Преобразовать документ из формата docx в pdf, читаемого из

`Поток`

типа

`ПотокЧтения`

. Если документ в формате DOCX защищён паролем, то его нужно указать в строковом представлении. Пароль от документа не сохраняется.

Импорт документа из формата DOCX может занимать продолжительное время, а вид итогового PDF-документа может отличаться от первоначального.

Если в документ не были встроены шрифты, то они будут заменены на шрифт по умолчанию в операционной системе.

Метод возвращает объект типа `ДокументPdf`.

#### Исключения

**[ИсключениеВводаВывода](../stdlib/inputoutputexception-ru-ceba5f672999.md)** - если чтение документа завершилась неудачей. **[ИсключениеPdf](../stdlib/pdfexception-ru-fca07efa7071.md)** - если конвертация документа завершилась неудачей.

#### Примеры

```xbsl
метод ИмпортироватьДокументИзDocx(ПотокДокумента: ПотокЧтения, ПотокЗаписи: ПотокЗаписи)
    // Импорт защищённого документа
    исп Документ = ДокументPdf.ИмпортироватьИзDocx(ПотокДокумента, "template123")    
    
    Документ.Записать(ПотокЗаписи)
;
```

### ИмпортироватьИзТаблицы

`Доступность: Сервер` `Статический`

```
ИмпортироватьИзТаблицы(
  Поток: ПотокЧтения,
  НастройкиИмпорта: НастройкиИмпортаPdfИзТаблицы,
  Пароль: Секрет|Строка = ""
): ДокументPdf
```

Прочитать документ в формате PDF из потока, содержащего электронную таблицу. Формат документа из потока определяется автоматически. Поддерживаются следующие форматы файлов: Microsoft Excel XLS/XLSX, OpenOffice Calc ODS. По умолчанию, используются настройки импорта с фиксированным размером страницы формата A4, с величинами отступов и ориентацией листа, полученными при импорте.

Если документ формата XLSX защищён паролем, то его нужно передать в строковом представлении. Чтение защищенных документов иного формата не поддерживается. Пароль от документа не сохраняется.

Импорт документа может занимать продолжительное время, а вид итогового PDF-документа может отличаться от первоначального.

Если в документ не были встроены шрифты, то они будут заменены на шрифт по умолчанию в операционной системе.

#### Исключения

**[ИсключениеВводаВывода](../stdlib/inputoutputexception-ru-ceba5f672999.md)** - если чтение документа завершилась неудачей. **[ИсключениеPdf](../stdlib/pdfexception-ru-fca07efa7071.md)** - если конвертация документа завершилась неудачей.

#### Примеры

```xbsl
метод ИмпортироватьДокументИзТаблицы(Поток: ПотокЧтения) : ДокументPdf
  пер Настройки = НастройкиИмпортаPdfИзТаблицы.ФиксированныйРазмерСтраницы(РазмерСтраницы = РазмерСтраницы.A5(),
  ПолеСверху = 30, ПолеСнизу = 30, ПолеСлева = 20, ПолеСправа = 20)
 
  возврат ДокументPdf.ИмпортироватьИзТаблицы(Поток, Настройки, "12345")
;
```
