## Обзор

В обычной жизни необъектные данные являются простым набором некоторых записей, каждая из которых полностью описывается значением своих полей.

## Документированный контракт и примеры

В обычной жизни необъектные данные являются простым набором некоторых записей, каждая из которых полностью описывается значением своих полей. Например, табель учета рабочего времени сотрудников. В каждой записи есть дата, фамилия сотрудника, время прихода и время ухода. Другой пример — журнал регистрации входящих документов. В каждой записи есть входящий номер, дата, отправитель и заголовок документа.

Особенность таких данных заключается в том, что любая из записей не обладает какой-либо уникальностью, важны только значения полей, содержащихся в записи. Когда такие данные хранятся в «1С:Предприятие.Элементе», для каждого экземпляра сущности (записи) создается и хранится идентификатор — ключ записи. Этот идентификатор непосредственно связан с данными (со значениями полей записи) и имеет чисто технический смысл — позволяет отличить одну строку таблицы от другой.

> [!NOTE] примечание
> Элементы объектных данных тоже имеют идентификаторы (ссылки), но эти идентификаторы никак не связаны с данными и имеют собственный прикладной смысл ([подробнее](object-data-f248c0368587.md)).

Записи с теми же ключами можно создавать неограниченное количество раз. Вы можете удалить запись, а затем создать другую с такими же значениям полей, что были раньше. В результате, с точки зрения «1С:Предприятие.Элемента», состояние приложения не изменится.

> [!NOTE] примечание
> У объектных данных нельзя удалить элемент данных и заново создать точно такой же. Идентификатор объектных данных (ссылка) не зависит от данных. Состояние приложения изменится, поскольку у новых данных будет новая ссылка ([подробнее](object-data-f248c0368587.md)).

Еще одна особенность необъектных данных заключается в том, что «1С:Предприятие.Элемент» при создании, изменении и удалении необъектных данных работает сразу с несколькими записями — набором записей. Набор записей содержит сразу несколько элементов необъектных данных (записей).

> [!NOTE] примечание
> У объектных данных записывается и удаляется объект, содержащий один элемент данных ([подробнее](object-data-f248c0368587.md)).

В «1С:Предприятие.Элементе» для работы с необъектными данными используются элементы проекта вида [РегистрСведений](information-register-project-element-8932693c91b1.md), [РегистрНакопления](accumulation-register-overview-699bd9df5dda.md) и [НаборКонстант](../project/constants-set-element-3c8e873b235a.md).
