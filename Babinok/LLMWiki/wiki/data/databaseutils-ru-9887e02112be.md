## Методы

### Сравнить

`Доступность: Сервер`

```
Сравнить(
  Первое: Объект?,
  Второе: Объект?
): Число
```

Сравнивает два значения в том же порядке, в которым их сравнивает язык запросов. Возвращает

- 0, если величины равны
- 1, если первое больше второго
- -1, если первое меньше второго
