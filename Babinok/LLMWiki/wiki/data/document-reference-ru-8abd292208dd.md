### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): Документ.Объект?
```

Загружает объект из базы данных по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.

#### Примеры

Чтение объекта в транзакции с последующим изменением.

```xbsl
метод ЗаменитьДоговор(Документы: ЧитаемыйМассив<Накладная.Ссылка>, НовыйДоговор: Договоры.Ссылка)
    исп Транзакция = Транзакции.Начать()
    
    для Ссылка из Документы
        // Изменяемый в транзакции документ нужно считывать с исключительной блокировкой,
        // иначе при параллельном исполнении может возникнуть взаимоблокировка (deadlock)
        знч Накладная = Ссылка.ЗагрузитьОбъект(Истина)
        
        если Накладная == Неопределено
            // Ссылка может быть недействительной
            продолжить
        ;
           
        Накладная.Договор = НовыйДоговор
        Накладная.Записать()
    ;
    
    Транзакция.Фиксировать()
;
```
