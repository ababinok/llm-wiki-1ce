## Обзор

Объект предназначен для задания значений полей, по которым отбираются записи попадающие в набор записей.

## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}.НаборЗаписей.Фильтр` `Доступность: Сервер`

Объект предназначен для задания значений полей, по которым отбираются записи попадающие в набор записей. Является составной частью объектов типа [ИмяРегистраНакопления.НаборЗаписей](accumulationregistername-recordset-ru-b4bf21480f3e.md) (см. свойство `Фильтр`). Содержит единственный элемент фильтра [Сущность.НаборЗаписей.Фильтр.Элемент](entity-recordset-filter-item-ru-881dec7d18c2.md) для стандартного поля `Регистратор`.

### Регистратор

`Доступность: Сервер` `ТолькоЧтение`

```
Регистратор: Сущность.НаборЗаписей.Фильтр.Элемент<{ИмяДокумента}.Ссылка?>
```

Элемент фильтра соответствующий стандартному полю `Регистратор`, содержащий ссылку на документ-регистратор по которому выполняется отбор записей.
