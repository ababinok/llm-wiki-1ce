## Документированный контракт и примеры

`Стд::Сущности::Сущность.НаборЗаписей.Фильтр.Элемент<ТипПоля>` `Доступность: Сервер`

ТипПоля: Тип значения поля которому соответствует этот элемент фильтра

Составная часть фильтров наборов записей необъектных сущностей. Конструируется платформой для каждого поля по которому может выполняться фильтрация набора записей.

## Свойства

### Значение

`Доступность: Сервер`

```
Значение: ТипПоля
```

Значение поля, по которому требуется фильтровать.

#### Примеры

```xbsl
знч НаборЗаписей = новый КурсыВалют.НаборЗаписей()
знч Валюта = "RUB" 

НаборЗаписей.Фильтр.Валюта.Значение = Валюта
```

---

### Использование

`Доступность: Сервер`

```
Использование: Булево
```

Использовать ли элемент фильтра:

- истина - элемент фильтра используется, т.е. учитывается при фильтре записей
- ложь - элемент фильтра не используется, т.е. не учитывается при фильтре записей

#### Примеры

```xbsl
знч НаборЗаписей = новый КурсыВалют.НаборЗаписей() 
НаборЗаписей.Фильтр.Валюта.Использование = Истина
```

## Методы

### Установить

`Доступность: Сервер`

```
Установить(Значение: ТипПоля)
```

Устанавливает значение элемента фильтра в переданное и использование в

`Истина`

.

#### Примеры

```xbsl
знч НаборЗаписей = новый КурсыВалют.НаборЗаписей()
знч Валюта = "RUB" 

НаборЗаписей.Фильтр.Валюта.Установить(Валюта)
```
