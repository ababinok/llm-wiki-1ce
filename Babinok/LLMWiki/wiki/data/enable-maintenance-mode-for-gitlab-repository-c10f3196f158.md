## Документированный контракт и примеры

Чтобы устранить неполадки в работе подключенной системы управления репозиториями, вы можете перевести ее в режим обслуживания, как описано ниже. В этом случае «1С:Предприятие.Элемент» не будет использовать ее для создания репозиториев.

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. Нажмите **Инфраструктура** ⟶ **Репозитории**.
3. Нажмите кнопку **Включить режим обслуживания** для нужного хранилища.
  
  
4. Статус хранилища изменится на **Не используется**.
  
  В панели управления таблица «Хранилища репозиториев» показывает для хранилища «Test repo» статус «Не используется» и URL `http://gitlab.com`.. [Описание иллюстрации](../../raw/figures/08add97d606883d6f6e22c251b1c59428e33d60ab8beb65f6775dbd79386e279-f8bef546c379d1c9.md)
