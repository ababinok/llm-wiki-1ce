## [НеудаленныеОбъекты](../stdlib/undeletedobjects-ru-35dc33d952c0.md)

`Стд::Сущности::НеудаленныеОбъекты` `Тип-одиночка` `Доступность: Сервер`

Объект, предназначенный для разрешения ссылок на объекты, которые препятствуют удалению сущностей. При удалении данных система ведет глобальный реестр ссылок, препятствующих удалению объектов. Каждый запуск процесса удаления актуализирует данные в этом реестре. Объект `НеудаленныеОбъекты` позволяет разрешить ссылки на основании записей в этом реестре.

## [УдалениеОбъекта](../stdlib/objectdeletion-ru-2123d957f665.md)

`Стд::Сущности::УдалениеОбъекта` `Доступность: Сервер`

Предназначен для удаления объекта базы данных. Объект хранит ссылку на объект базы данных и при обращении к методу Записать() производит удаление объекта базы данных, на который показывает ссылка. Основное назначение данного объекта - переносить удаление объектов базы данных при использовании в составе других механизмов обмена данными.
