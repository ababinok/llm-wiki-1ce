## Методы

### ДобавитьЗакрытыйКлюч

`Доступность: Сервер`

```
ДобавитьЗакрытыйКлюч(
  Псевдоним: Строка,
  Ключ: ЗакрытыйКлюч,
  Пароль: Секрет|Строка,
  Сертификат: ЦифровойСертификат)
```

Добавляет закрытый ключ

`Ключ`

и сертификат

`Сертификат`

в хранилище.

`Пароль`

- пароль для извлечения записи о ключе. Для использования разрешены символы ASCII с кодом от 33 до 126.

Будет добавлена вся цепочка сертификатов, полученная из свойств [СертификатИздателя](../stdlib/digitalcertificate-ru-d7ab871cc7b1.md). В зависимости от типа хранилища, если запись с указанным псевдонимом `Псевдоним` есть в хранилище - она может быть либо перезаписана, либо будет выброшено [ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md).

#### Исключения

**[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы. **[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### ДобавитьСертификат

`Доступность: Сервер`

```
ДобавитьСертификат(
  Псевдоним: Строка,
  Сертификат: ЦифровойСертификат)
```

Добавляет цифровой сертификат

`Сертификат`

в хранилище. В зависимости от типа хранилища, если запись с указанным псевдонимом

`Псевдоним`

есть в хранилище - она может быть либо перезаписана, либо будет выброшено

[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)

.

#### Исключения

**[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)** - если в данном типе хранилища невозможно перезаписать существующий сертификат.

---

### НайтиЗакрытыйКлюч

`Доступность: Сервер`

```
НайтиЗакрытыйКлюч(
  Псевдоним: Строка,
  Пароль: Секрет|Строка
): ЗакрытыйКлюч?
```

Возвращает закрытый ключ асимметричного алгоритма шифрования по указанному псевдониму

`Псевдоним`

или

`Неопределено`

, если запись отсутствует в хранилище.

`Пароль`

- пароль для извлечения записи о ключе. Для использования разрешены символы ASCII с кодом от 33 до 126.

#### Исключения

**[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке получения ключа из хранилища. **[ИсключениеКриптографииНеправильныйПароль](../stdlib/incorrectpasswordcryptoexception-ru-3a412b425cf1.md)** - если указан неправильный пароль. **[ИсключениеНедопустимыйФормат](../stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если пароль содержит недопустимые символы.

---

### Удалить

`Доступность: Сервер`

```
Удалить(Псевдоним: Строка)
```

Удаляет запись с псевдонимом

`Псевдоним`

из хранилища.

#### Исключения

**[ИсключениеКриптографии](../stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.
