## Свойства

### ОбработчикиСобытий

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ОбработчикиСобытий
```

Из документа будут удалены все атрибуты, имя которых начинается на on. Например,<div onclick="test">Пример текста</div> будет преобразован в <div>Пример текста</div>.

---

### Все

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Все
```

Из документа будут удалены уязвимости, которые удовлетворяют хотя бы одному из критериев: обработчики событий, элементы w3-includes, элементы applet, area, embed, и так далее.

---

### W3IncludeАтрибуты

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
W3IncludeАтрибуты
```

Из документа будут удалены все атрибуты "w3-include-html". Например, <div w3-include-html="content.html"> Some text</div>будет преобразован в <div> Some text </div>.

---

### StyleТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
StyleТеги
```

Из документа будут удалены все элементы <style> с атрибутом type, значение которого отличается от text/css, т.е.: <style type="text/html" src="some/link/to/src"> будет удален, а < style type="text/css" src="some/link/to/src"> удален не будет.

---

### SourceТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
SourceТеги
```

Из документа будут удалены все элементы <source> и их дочерние элементы.

---

### ObjectТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ObjectТеги
```

Из документа будут удалены все элементы <<object> и их дочерние элементы.

---

### NoembedТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
NoembedТеги
```

Из документа будут удалены все элементы <noembed> и их дочерние элементы.

---

### LinkТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
LinkТеги
```

Из документа будут удалены все элементы <link>, у которых атрибут type не равен css, т.е.: <link type="text/html"> будет удален, а <link type="css"> удален не будет.

---

### JavaScriptТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
JavaScriptТеги
```

Из документа будут удалены все элементы <script> и их дочерние элементы.

---

### ImportАтрибуты

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ImportАтрибуты
```

Из документа будут удалены все элементы, у которых есть атрибуты rel="import" и href с любым значением, т.е. будут удалены выражения вида: <link rel="import" href="any/href/link"/>.

---

---

### EmbedТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
EmbedТеги
```

Из документа будут удалены все элементы <embed> и их дочерние элементы

---

### AreaТеги

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
AreaТеги
```

Из документа будут удалены все атрибуты href, содержащиеся в элементах <<area>. Таким образом, <area href="dest"> примет вид <area>

---

### AppletТеги
