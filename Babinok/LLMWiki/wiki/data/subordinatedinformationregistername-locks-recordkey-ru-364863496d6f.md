## Примеры

**Общие примеры**

```xbsl
метод УстановитьБлокировкуДляЗаписи(ПользовательСсылка: Пользователи.Ссылка) 
    Блокировки.Заблокировать(новый ЦеныТоваров.Блокировки.КлючЗаписи(Период = Дата{2022-05-26}, Пользователь = ПользовательСсылка))
;
```

Блокировка для пространства блокировок `КлючЗаписи` регистра сведений `{ИмяПодчиненногоРегистраСведений}`. Пространство используется для блокировки записей регистра сведений с указанными значениями измерений и / или стандартного поля `Период`. При записи набора записей на это пространство платформой устанавливается исключительная блокировка со значениями полей-измерений, соответствующими фильтру набора записей.

### {ИмяПодчиненногоРегистраСведений}.Блокировки.КлючЗаписи

`Доступность: Сервер`

```
ИмяПодчиненногоРегистраСведений.Блокировки.КлючЗаписи(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  <ИмяИзмерения>: <ТипИзмерения>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры необязательные. Если значение параметра, соответствующего полю блокировки, не задано, значение этого поля в блокировке не указано (блокируются все значения).
