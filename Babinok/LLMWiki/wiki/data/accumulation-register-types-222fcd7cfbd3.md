## Тип «ИмяРегистраНакопления»

Это тип-одиночка.

Тип [`{ИмяРегистраНакопления}`](accumulationregistername-ru-ca3f7a553094.md) содержит методы для работы с конкретным регистром накопления. Например, методы для [пересчета разрешений доступа](../security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md) и блокировки записей по полям, указанным в фильтре.

Этот тип не содержит конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Пересчитать разрешения доступа для регистра «ОстаткиНоменклатуры»
ОстаткиНоменклатуры.ПересчитатьРазрешенияДоступа()
```

### Модуль регистра накопления

В проекте модуль, расширяющий тип [`{ИмяРегистраНакопления}`](accumulationregistername-ru-ca3f7a553094.md), называется **модулем регистра накопления**.

Модуль регистра накопления [Описание иллюстрации](../../raw/figures/cbd65819dedcb6e0f500170f1c39000ae64230407c7e064df72db4d7ba25266d-16de041c620dc530.md)

В этом модуле вы можете обработать [события вычисления разрешений доступа](../security/manage-access-control-2ec0764ce511.md):

- [`ВычислитьКлючиДоступаДляЧтения`](accumulationregistername-ru-ca3f7a553094.md)
  
  ,
- [`ВычислитьКлючиДоступаДляИзменения`](accumulationregistername-ru-ca3f7a553094.md)
  
  .

> [!TIP] совет
> В модуле регистра накопления может находиться реализация [контракта сервиса](../project/service-contract-5b8423b5cca0.md).

## Тип «ИмяРегистраНакопления.КлючЗаписи»

Тип [`{ИмяРегистраНакопления}.КлючЗаписи`](accumulationregistername-recordkey-ru-9247d6fd0ee5.md) доступен и на клиенте, и на сервере. Предназначен для указания на конкретную запись регистра накопления. Не может использоваться в типах реквизитов хранимых объектов (справочников, регистров и т. п.).

Данный тип имеет конструктор, который позволяет создать ключ записи с заданными параметрами: ссылкой на документ-регистратор и индексом записи.

### Модуль ключа записи

В проекте модуль, расширяющий тип [`{ИмяРегистраНакопления}.КлючЗаписи`](accumulationregistername-recordkey-ru-9247d6fd0ee5.md), называется **модулем ключа записи**. Он исполняется и на клиенте, и на сервере.

В дереве регистра накопления «ОстаткиНоменклатуры» выделен модуль «ОстаткиНоменклатуры.КлючЗаписи»; рядом видны типы записи и набора записей. [Описание иллюстрации](../../raw/figures/dca3a2c70f45cb975bd064e7f6662171a9afb92d01da3a481400ad7641398e1f-57ccd4ced187d0b5.md)

## Тип «ИмяРегистраНакопления.КлючОсновногоФильтра»

Тип [`{ИмяРегистраНакопления}.КлючОсновногоФильтра`](accumulationregistername-mainfilterkey-ru-fb566c677c70.md) доступен и на клиенте, и на сервере. Он представляет собой структуру, описывающую ключ основного фильтра регистра накопления. Содержит единственное свойство [Регистратор](accumulationregistername-mainfilterkey-ru-fb566c677c70.md), возвращающее ссылку на документ-регистратор, по которому выполняется фильтр записей.

Присутствует как поле в [таблице регистра накопления](../queries/accumulationregistername-ru-57b11df3637a.md) и [таблице изменений данных регистра накопления](../queries/accumulationregistername-changes-ru-3028160c1ab9.md).

Тип [`{ИмяРегистраНакопления}.КлючОсновногоФильтра`](accumulationregistername-mainfilterkey-ru-fb566c677c70.md) используется в программном интерфейсе для работы с изменениями данных регистров накопления. Имеет конструктор, который позволяет создать новый ключ основного фильтра.

Данный тип формируется по элементу проекта всегда, даже если регистр накопления не включен в состав плана обмена.

## Тип «ИмяРегистраНакопления.Запись»

Тип [`{ИмяРегистраНакопления}.Запись`](accumulationregistername-record-ru-e8eb9213772a.md) доступен на клиенте и сервере. Содержит данные одной записи регистра накопления, структурно соответствует одной строке в основной таблице регистра.

Имеет конструктор, который позволяет создать новую запись с указанными значениями полей (измерений, ресурсов и реквизитов).

### Модуль записи

В проекте модуль, расширяющий тип [`{ИмяРегистраНакопления}.Запись`](accumulationregistername-record-ru-e8eb9213772a.md), называется **модулем записи**. Он исполняется на сервере.

В дереве регистра накопления «ОстаткиНоменклатуры» выделен модуль «ОстаткиНоменклатуры.Запись», рядом остальные порождённые типы регистра. [Описание иллюстрации](../../raw/figures/fde942e80932aa16f45e7075d15da639908c921135015c0a5ebdaf38aa300e5a-0774e4b3f13e1434.md)

В нем вы можете обработать событие [`ПриСозданииКопии`](accumulationregistername-record-ru-e8eb9213772a.md), которое вызывается при создании новой записи регистра путем копирования существующей.

> [!TIP] совет
> В модуле записи может находиться реализация методов [контракта типа](../language/type-contract-ab9f0932850d.md).

## Тип «ИмяРегистраНакопления.НаборЗаписей»

Тип [`{ИмяРегистраНакопления}.НаборЗаписей`](accumulationregistername-recordset-ru-b4bf21480f3e.md) доступен на сервере. Он содержит набор записей и предназначен для чтения и записи данных в соответствии с некоторым фильтром.

Он имеет конструктор `новый {ИмяРегистраНакопления}.НаборЗаписей()`, который позволяет создать пустой набор. Заполнив этот набор записями, вы можете затем сохранить их в базе данных. Также вы можете прочитать в набор те записи из базы данных, которые соответствуют фильтру, установленному в наборе записей. Если набор не был пустым, все записи из него будут удалены.

### Модуль набора записей

В проекте модуль, расширяющий тип [`{ИмяРегистраНакопления}.НаборЗаписей`](accumulationregistername-recordset-ru-b4bf21480f3e.md), называется **модулем набора записей**. Он исполняется на сервере.

Модуль набора записей [Описание иллюстрации](../../raw/figures/b0f92796be04fd02aaaeb3923988d88a22d381aadbc011a3f6b183492daa0b34-c56819bfe0235e38.md)

В нем вы можете обработать такие события, как:

- [`ПередЗаписью`](accumulationregistername-recordset-ru-b4bf21480f3e.md)
  
  ,
- [`ПослеЗаписи`](accumulationregistername-recordset-ru-b4bf21480f3e.md)
  
  .

Например:

```xbsl
@Обработчик
метод ПередЗаписью(Замещать: Булево,
                   ПараметрыЗаписи: ОстаткиНоменклатуры.ПараметрыЗаписи)
    // Действия, которые выполняются перед записью 
    // набора записей регистра накопления
;
```

Во время записи набора записей «Элемент» открывает в базе данных транзакцию записи и вызывает следующие события:

Схема записи набора регистра накопления: ПередЗаписью → запись набора в базу данных → ПослеЗаписи. [Описание иллюстрации](../../raw/figures/5b56aa264ccc47b65ce43c6ea4239ae0a766a97d73ffa1d223f11168102cd247-6c69cdc4a14e74f7.md)

## Тип «ИмяРегистраНакопления.НаборЗаписей.Данные»

Тип [`{ИмяРегистраНакопления}.Данные`](accumulationregistername-data-ru-40a04163d3a8.md) доступен на сервере. Он содержит набор данных, соответствующий некоторому состоянию записи регистра накопления. Используется в обработчике события [`ПриСозданииКопии`](accumulationregistername-record-ru-e8eb9213772a.md).

## Тип «ИмяРегистраНакопления.НаборЗаписей.Фильтр»

Предназначен для указания значений полей, по которым отбираются записи, попадающие в набор записей. Содержит единственный элемент фильтра для стандартного поля **Регистратор**.

## Тип «ИмяРегистраНакопления.НаборЗаписей.Фильтр.Данные»

Тип [`{ИмяРегистраНакопления}.НаборЗаписей.Фильтр.Данные`](accumulationregistername-recordset-filter-data-ru-a2e55f5d0b34.md) доступен на сервере. Он содержит набор данных, соответствующий некоторому состоянию фильтра набора записей регистра накопления.

Является составной частью типа [`{ИмяРегистраНакопления}.НаборЗаписей.Данные`](accumulationregistername-recordset-data-ru-37efdec1322b.md).

## Тип «ИмяРегистраНакопления.КлючРазрешенийИзмерений»

Тип [`{ИмяРегистраНакопления}.КлючРазрешенийИзмерений`](../security/accumulationregistername-dimensionspermissionskey-ru-1006e95b00da.md) доступен на сервере и порождается только в том случае, если регистр использует разрешение **РазрешенияВычисляютсяДляКаждогоОбъекта**. Он указывает на группу записей с одинаковыми значениями полей, указанных в настройке **РасчетРазрешенийПо**.

Экземпляры этого типа «Элемент» передает в обработчик события [`ВычислитьКлючиДоступаДляЧтения`](accumulationregistername-ru-ca3f7a553094.md).

[Подробнее о формировании разрешений и выдаче экземпляров ключей](../security/manage-access-control-2ec0764ce511.md)

В примере ниже показана настройка прав на чтение данных регистра для пользователя, указанного в измерении **Пользователь**.

```xbsl
@Обработчик
метод ВычислитьКлючиДоступаДляЧтения(
    Ключи: ЧитаемыйМассив<ОстаткиНоменклатуры.КлючРазрешенийИзмерений>): ЧитаемоеСоответствие<ОстаткиНоменклатуры.КлючРазрешенийИзмерений, ЧитаемыйМассив<КлючДоступа.Объект>>
    знч КлючиНаЧтение = <ОстаткиНоменклатуры.КлючРазрешенийИзмерений, ЧитаемыйМассив<КлючДоступа.Объект>>{:}

    для Ключ из Ключи
        КлючиНаЧтение.Вставить(Ключ, [новый КлючДоступаПользователя.Объект(Ключ.Пользователь)])
    ;

    возврат КлючиНаЧтение
;
```

## Тип «РегистрыНакопления»

Тип [`РегистрыНакопления`](accumulationregisters-ru-906ed7644b39.md) существует независимо от того, есть ли в проекте регистры накопления. Он предназначен для обхода всех регистров накопления и вызова [пересчета разрешений доступа](../security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md), например:

```xbsl
для Регистр из РегистрыНакопления
    Регистр.ПересчитатьРазрешенияДоступа()
;
```

Этот тип не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа.
