## Свойства

### КлючЗаписи

`Доступность: КлиентИСервер`

```
КлючЗаписи: {ИмяРегистраСведений}.КлючЗаписи
```

Свойство унаследовано от базового типа, при наследовании уточнен тип и добавлена возможность изменения. Значения измерений из ключа соответствуют значениям в самой записи — при изменении значений измерения в свойство автоматически помещается новый ключ записи (с новыми значениями). При присвоении ключа записи значения измерений в самой записи заполняются из него.

Переопределение: [КлючЗаписи](informationregistername-record-ru-2194321bf71d.md)

### СоздатьКопию

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопию(
  Период: <ТипПериода>,
  <Измерение1>: <ТипИзмерения1> = <ЗначениеПоУмолчаниюИзмерения1>,
  ....<ИзмерениеN>: <ТипИзмеренияN> = <ЗначениеПоУмолчаниюИзмеренияN>,
  <Ресурс1>: <ТипРесурса1> = <ЗначениеПоУмолчаниюРесурса1>,
  ...<РесурсN>: <ТипРесурсаN> = <ЗначениеПоУмолчаниюРесурсаN>,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр записи регистра сведений копированием этой записи.

Параметр `Период` существует только для периодического регистра сведений.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку записи.

#### Примеры

Дублирование записи о курсе валюты сегодняшним днем.

```xbsl
метод ДублироватьЗаписьСегодняшнимДнем(ЗаписьЦеныТовара: ЦеныТоваров.Запись): ЦеныТоваров.Запись
    знч НоваяЗапись = ЗаписьЦеныТовара.СоздатьКопию(Период = Дата.Сейчас())
    ЦеныТоваров.Записать(НоваяЗапись)
    возврат НоваяЗапись 
;
```

---

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяРегистраСведений}.Данные)
```

Вызывается при создании нового экземпляра записи регистра сведений копированием существующей. На момент вызова этого обработчика значения измерений, ресурсов и реквизитов у новой записи будут уже заполнены из записи-источника.

Не будет автоматически копироваться стандартное поле `Период` регистра сведений. Кроме того, не будут копироваться измерения, ресурсы и реквизиты, копирование которых отключено в регистре сведений с помощью свойства `ЗаполнятьПриКопировании`.

Параметр `Источник` содержит данные исходной записи регистра сведений, копированием которой и создается новая запись.

#### Примеры

В проекте есть периодический регистр сведений **ЦеныТоваров**. Необходимо сделать так, чтобы при копировании записи этого регистра сведений у стандартного поля `Период` проставлялась текущая дата

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: ЦеныТоваров.Данные)
    Период = Дата.Сейчас()
;
```
