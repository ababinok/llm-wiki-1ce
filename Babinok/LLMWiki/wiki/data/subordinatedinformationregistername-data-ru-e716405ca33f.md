## Документированный контракт и примеры

`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПодчиненногоРегистраСведений}.Данные` `Доступность: Сервер`

Используется в обработчике [ПриСозданииКопии](subordinatedinformationregistername-record-ru-5f5d606d63e0.md).

## Свойства

### Активность

`Доступность: Сервер` `ТолькоЧтение`

```
Активность: Булево
```

Содержит признак, определяющий влияние записи на результаты виртуальной таблицы [ИмяПодчиненногоРегистраСведений.СрезПоследних](../queries/subordinatedinformationregistername-slicelast-ru-5dadf507fbef.md) и расчет значения поля [СледующийПериод](../queries/subordinatedinformationregistername-ru-8cc4c1b62489.md). Если значение `Ложь`, то запись не учитывается при получении сведений из виртуальной таблицы и при расчете поля `СледующийПериод`.

---

### Период

`Доступность: Сервер` `ТолькоЧтение`

```
Период: Дата
```

Содержит значение периода записи. Существует только для периодического регистра сведений.

---

### Регистратор

`Доступность: Сервер` `ТолькоЧтение`

```
Регистратор: {ИмяДокумента}.Ссылка?
```

Ссылка на документ-регистратор, которому подчинена запись.

---

### {ИмяРеквизита}

`Доступность: Сервер` `ТолькоЧтение`

```
ИмяРеквизита: ТипРеквизита
```

Набор свойств содержит значения реквизитов регистра сведений. Доступ к значению осуществляется по имени, как оно задано в проекте.

---

### {ИмяИзмерения}

`Доступность: Сервер` `ТолькоЧтение`

```
ИмяИзмерения: ТипИзмерения
```

Набор свойств содержит значения измерений регистра сведений. Имена свойств совпадают с именами измерений, как они заданы в проекте.

---

### {ИмяРесурса}

`Доступность: Сервер`

```
ИмяРесурса: ТипРесурса
```

Набор свойств содержит значения ресурсов регистра сведений. Доступ к значению осуществляется по имени, как оно задано в проекте.

---

### {СледующийПериод}

`Доступность: Сервер`

```
СледующийПериод: ТипПериода
```

Значение поля [Период](subordinatedinformationregistername-data-ru-e716405ca33f.md) из следующей активной записи с такими же значениями измерений или максимальное значение типа поля [Период](subordinatedinformationregistername-data-ru-e716405ca33f.md), если следующей записи нет. Для неактивных записей подчиненного регистра всегда имеет максимальное значение типа поля [Период](subordinatedinformationregistername-data-ru-e716405ca33f.md).

Существует только для периодических регистров сведений с флагом `ХранитьСледующийПериод` = `Истина`.
