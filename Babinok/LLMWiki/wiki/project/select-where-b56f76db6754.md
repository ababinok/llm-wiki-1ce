## Обзор

Предложение `ГДЕ` позволяет задать условие отбора данных из таблиц запроса.

## Документированный контракт и примеры

Предложение `ГДЕ` позволяет задать условие отбора данных из таблиц запроса. В запросе будут обрабатываться только те записи, для которых данное условие оказывается истинным.

```xbql
ВЫБРАТЬ
    Сотрудники.Ссылка КАК Ссылка,
    Сотрудники.ФИО КАК ФИО
ИЗ
    Сотрудники КАК Сотрудники
ГДЕ
    Сотрудники.Возраст < 40
УПОРЯДОЧИТЬ ПО
    Сотрудники.ФИО
```

Предложение имеет следующий синтаксис:

```xbql
ГДЕ
    условие-выборки-записей
```

В качестве ***условие-выборки-записей*** можно использовать любые выражения типа `Булево` кроме выражений, содержащих агрегатные функции.
