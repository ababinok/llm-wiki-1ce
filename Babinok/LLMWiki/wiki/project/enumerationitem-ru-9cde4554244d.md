## Обзор

Описывает отдельный элемент перечисления.

## Документированный контракт и примеры

Описывает отдельный элемент перечисления.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление элемента.

---

#### Аннотации

```yaml
Аннотации: Аннотация[]
```

[Аннотации](../language/annotations-dcff696b460d.md) элемента перечисления.

---

#### ПоУмолчанию

```yaml
ПоУмолчанию: Булево
```

Признак того, что данный элемент используется стандартно при выборе перечисления. Может иметь значение `Истина` только у одного из элементов.
