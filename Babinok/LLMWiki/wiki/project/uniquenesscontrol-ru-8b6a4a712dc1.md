## Литералы

#### Отсутствует

Значение по умолчанию. Для справочников, у которых есть реквизит **Код**, уникальность кода будет обеспечиваться в пределах одного справочника.

---

#### СквознойПоВсемРеализациям

Контроль уникальности кода будет применяться сквозным образом ко всем справочникам, реализующим контракт сущности. Если задано это значение, контракт сущности может быть реализован только элементами проекта вида [Справочник](../data/catalog-e0da7d4e8e72.md).
