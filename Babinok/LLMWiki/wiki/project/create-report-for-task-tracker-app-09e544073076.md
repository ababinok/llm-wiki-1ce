## Обзор

## Документированный контракт и примеры

В данном примере показывается, как создать [отчет](create-report-b99954f7595c.md) для приложения [«Планировщик задач»](create-task-tracker-app-991877a27ceb.md). В отчете для каждого проекта будет отображаться общее количество задач, разделенных по степени важности (приоритету). Пользователи смогут отфильтровать задачи по статусу выполнения.

Макет отчета [Описание иллюстрации](../../raw/figures/b4952abb40aa20908867f4c40a409b98effd60511076067bce7342f8032a310f-35ad220abe970559.md)

Для более удобного восприятия информации руководство по созданию отчета доступно как в видеоформате, так и в виде подробной пошаговой инструкции.

## Видеоруководство

Данное обучающее видео демонстрирует создание отчета в «1С:Предприятие.Элементе». Все выполняемые в видео действия описаны далее в этой статье.

## Создание и настройка отчета

1. Чтобы создать отчет для справочника **Задачи**, в навигаторе проекта нажмите на знак плюса рядом с именем справочника и выберите пункт **Отчет** в открывшемся окне.
  
  
2. Введите имя отчета — **ОтчетПоЗадачам**.
3. В панели свойств отчета, в группе **Интерфейс** укажите изображение для команды открытия отчета — **Доска.svg**.
  
  
4. В дизайнере отчета нажмите на поля **Приоритет** и **Количество записей**, чтобы добавить их к отчету.
  
  В дизайнере отчёта добавлены Приоритет и Количество записей; эти поля отображаются цветными плашками над результатом. [Описание иллюстрации](../../raw/figures/7f83755babded32cc35e841dde7178e9b934169b85d491dcb73e00d2bbb6091e-23fb4a0b5248aa72.md)
5. В дизайнере отчета измените вид диаграммы на **Стек**.
  
  Меню выбора представления отчёта показывает варианты Таблица, Круговая, Столбчатая, Стек, График, График областей, Индикатор, Спидометр, Пузырьковая. [Описание иллюстрации](../../raw/figures/296acddc38e9b89a8c4766b09be808031b964a8a273a14017994bcfa3fa73146-fae1cf8602204ba7.md)
6. Настройте отображение диаграммы. Для этого нажмите на поле **Приоритет** в панели состава отчета и выберите пункт **Цвет** в выпадающем меню, чтобы использовать разные цвета для сегментов столбцов диаграммы.
  
  
7. Добавьте к отчету поле **Проект**. Перетащите его на первое место в панели состава отчета, расположив его перед полем **Приоритет**.
8. Нажмите на поле **Проект** и выберите **Ось X** в выпадающем меню, чтобы расположить названия проектов вдоль оси X. Для каждого проекта будет показываться общее количество задач, разделенных по приоритету.
  
  Настройка отображения проектов по оси X [Описание иллюстрации](../../raw/figures/cb53101d75b31039d443434c0cb90629ccde23324f7ade4cd821399e15d220e3-b8f37d7349672e82.md)
9. Нажмите на поле **Количество записей** в панели состава отчета и выберите пункт **Маркеры**, чтобы отобразить подписи данных — количество задач — для каждого сегмента стека.
  
  В отчете по задачам у показателя «Количество записей» открыт список настроек, флажок «Маркеры» установлен. [Описание иллюстрации](../../raw/figures/69f1740b5da53f679627d02bc3f2143dc54bf1c58c45a8448df41a32fb51f955-c301cc786aa6e816.md)
10. Добавьте возможность фильтровать задачи по статусу выполнения. Для этого нажмите на вертикальное троеточие рядом с полем **Статус задачи** и выберите **Создать** → **Элемент управления**.
  
  
11. Новый элемент управления появится на вкладке **Элементы управления** дизайнера отчета. Тип элемента управления будет выбран автоматически. Так как в данном примере поле содержит значения перечисления `СтатусЗадачи`, «1С:Предприятие.Элемент» сгенерирует элемент управления **Выпадающий список**.
  
  Вкладка «Элементы управления» [Описание иллюстрации](../../raw/figures/acaa9dd27a227fe8bd7c5646be534b7bc73ecb9be904f88bce74eaf43a318f60-9e8a8e75dd47f1b2.md)

## Добавление отчета в клиентское приложение

Если вы используете автоматический интерфейс приложения, «1С:Предприятие.Элемент» самостоятельно добавит к нему команду для открытия отчета.

Если вы [создавали командный интерфейс вручную](create-task-tracker-app-991877a27ceb.md), вы можете добавить к нему команду открытия отчета следующим образом:

1. В навигаторе проекта выделите компонент **Приложение**, чтобы открыть его в [редакторе компонентов интерфейса](../interface/ide-overview-and-basic-actions-969a6e6501a6.md).
2. К элементам [командного интерфейса панели навигации](../interface/standard-client-application-with-sections-component-49da52beb720.md) добавьте команду для открытия отчета: `ОтчетПоЗадачам.Открыть`.
  
  Добавление команды «Отчет» [Описание иллюстрации](../../raw/figures/9c43033fb3bf7e04f1bb5b672cf09211a573d117cd78a8edcaf2f399db6527b2-a14c0caf9cbc3bd6.md)

## Запуск приложения

1. Чтобы запустить приложение, выберите **Открыть приложение** в выпадающем меню **Запуск и публикация** или нажмите **Ctrl+F5**.
  
  Запуск приложения [Описание иллюстрации](../../raw/figures/a41269dd726360b1e94455f41e5144e3757de3fbfbfe95a09a23a6b04afdc184-61de2986e3c08b50.md)
2. При наличии неопубликованных изменений в проекте «1С:Предприятие.Элемент» отобразит окно с предложением выполнить публикацию. Нажмите **Опубликовать и запустить**.
  
  
3. В приложении переключитесь на вкладку **Отчет**, чтобы отобразить отчет по задачам.
4. Отфильтруйте задачи по статусу выполнения. Для этого нажмите на значок шестеренки в панели команд отчета, чтобы открыть меню **Настройки**. В выпадающем списке **Статус задачи** выберите значение **Закрыта** и активируйте опцию **Кроме**, чтобы отобразить только те задачи, которые еще не были выполнены.
  
  В отчёте по задачам открыты настройки фильтра «Статус задачи». [Описание иллюстрации](../../raw/figures/bc2f970ef4c03a1ace51fc9c3ec476e3f0262a1a686f2116882aeea3d4f3588f-0ad31d5b5be1196e.md)
