## Обзор

Многие программы должны выполнять разные действия в зависимости от условий.

## Документированный контракт и примеры

Многие программы должны выполнять разные действия в зависимости от условий. В Python для этого служат инструкции `if` и `match`, а в языке «1С:Элемент» — инструкции `если` и `выбор`.

Рассмотрим простое *ветвление*. В Python условие записывают после ключевого слова `if`, тело выделяют отступами, а ветка, в которой условие не выполняется, начинается с ключевого слова `else`. После каждого ключевого слова, начинающего новую ветку, ставят двоеточие. В языке «1С:Элемент» ветвление начинается со слова `если`, двоеточие после условия не ставится, отдельная ветка начинается с ключевого слова `иначе`, а весь блок завершается символом `;`.

Python

```python
def check_even(number):
    if number % 2 == 0:
        return "Четное число"
    else:
        return "Нечетное число"
```

«1С:Элемент»

```xbsl
метод ПроверитьЧетность(Число: Число): Строка
    если Число % 2 == 0
        возврат "Четное число"
    иначе
        возврат "Нечетное число"
    ;
;
```

Выбор из двух вариантов в Python можно записать короче — с помощью *условного выражения* вида: `a if условие else b`. В языке «1С:Элемент» для этого используют [тернарную операцию](../language/question-mark-operation-4d6230bab755.md): `условие ? А : Б`. Здесь части выражения `?` и `:` играют ту же роль, что и ключевые слова `если` и `иначе`.

Python

```python
def check_even(number):
    return "Четное число" if number % 2 == 0 else "Нечетное число"
```

«1С:Элемент»

```xbsl
метод ПроверитьЧетность(Число: Число): Строка
    возврат Число % 2 == 0 ? "Четное число" : "Нечетное число"
;
```

Когда вариантов больше двух, в Python добавляют ветки `elif`. В языке «1С:Элемент» их заменяют цепочкой `иначе если` — каждая дополнительная проверка начинается с этих двух слов.

Python

```python
def set_score(score):
    if score >= 90:
        return "Отлично"
    elif score >= 70:
        return "Хорошо"
    elif score >= 50:
        return "Удовлетворительно"
    else:
        return "Неудовлетворительно"
```

«1С:Элемент»

```xbsl
метод ВыставитьОценку(Оценка: Число): Строка
    если Оценка >= 90
        возврат "Отлично"
    иначе если Оценка >= 70
        возврат "Хорошо"
    иначе если Оценка >= 50
        возврат "Удовлетворительно"
    иначе
        возврат "Неудовлетворительно"
    ;
;
```

Если вариантов слишком много, удобнее использовать *инструкцию выбора*. В Python для этого служит конструкция `match` с ветками `case`, а в языке «1С:Элемент» — инструкция `выбор` с ветками `когда`. Ветка `иначе` срабатывает, когда ни одно из значений не подошло, аналогично `case _:` в Python.

Python

```python
def run_command(command):
    match command:
        case "start":
            return "Запустить программу"
        case "stop":
            return "Остановить программу"
        case "pause":
            return "Приостановить выполнение"
        case _:
            return "Неизвестная команда"
```

«1С:Элемент»

```xbsl
метод ВыполнитьКоманду(Команда: Строка): Строка
    выбор Команда
    когда "start"
        возврат "Запустить программу"
    когда "stop"
        возврат "Остановить программу"
    когда "pause"
        возврат "Приостановить выполнение"
    иначе
        возврат "Неизвестная команда"
    ;
;
```
