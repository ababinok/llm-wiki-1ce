## Обзор

Удаляет одну или несколько строк из временной таблицы.

## Документированный контракт и примеры

Удаляет одну или несколько строк из временной таблицы. Оператор имеет следующий синтаксис:

```xbql
УДАЛИТЬ ИЗ
    имя-таблицы | псевдоним-таблицы
[ИСПОЛЬЗУЯ
    элемент-списка-из,
      ...,
    элемент-списка-из]
[ГДЕ
    условие-удаления]
```

После `УДАЛИТЬ ИЗ` можно указать имя таблицы или псевдоним таблицы запроса из списка `ИЗ`.

В качестве результата запроса возвращается результат с единственной строкой и количеством удаленных записей в поле **КоличествоЗаписей**.
