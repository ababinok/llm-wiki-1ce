## Обзор

Функция подсчитывает количество значений поля, указанного в операнде, попавших в выборку и не равных `Null`.

## Документированный контракт и примеры

Функция подсчитывает количество значений поля, указанного в операнде, попавших в выборку и не равных `Null`. Она имеет следующий синтаксис:

```xbql
КОЛИЧЕСТВО([РАЗЛИЧНЫЕ] операнд)
```

Если выборка, по которой рассчитывается ***операнд***, пустая, то результатом функции будет 0.

Пример:

```xbql
ВЫБРАТЬ
    КОЛИЧЕСТВО(Сотрудники.Возраст) КАК КоличествоСотрудников
ИЗ
    Сотрудники КАК Сотрудники
```

Также поддерживаются другие варианты этой функции. Они позволяют подсчитать количество строк в выборке:

```xbql
КОЛИЧЕСТВО(*)
КОЛИЧЕСТВО(константа)
```
