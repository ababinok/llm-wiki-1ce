## Обзор

В «1С:Предприятие.Элементе» есть встроенный брокер сообщений.

## Документированный контракт и примеры

В «1С:Предприятие.Элементе» есть встроенный брокер сообщений. Для каждого участника из групп, связанных с узлом вида [«Канал1СИсточник»](../integration/channel-1c-source-ddb853b7d45d.md) или [«Канал1СНазначение»](../integration/channel-1c-destination-3c02e5ef031f.md), создается индивидуальная очередь. К этой очереди может подключиться только тот участник, для которого она была создана. Участник может получать сообщения из очередей, созданных для узлов вида «Канала1СНазначение». Участник может отправлять сообщения в очереди, созданные для узлов вида «Канал1СИсточник». Очередь создается в тот момент, когда участник включается в группу. Если участник исключается из группы, очередь удаляется, а сообщения переносятся в [канал недоставленных сообщений](undelivered-message-channel-54c826eff47a.md). Также очередь удаляется, если в новой версии процесса интеграции больше нет соответствующих узла или группы участников. При удалении самого процесса интеграции, удаляются все очереди данного процесса. В этом случае удаляется также и канал недоставленных сообщений.

Кроме того, «1С:Предприятие.Элементе» создаются очереди, к которым снаружи подключиться невозможно — с ними работает только «1С:Предприятие.Элемент». Очереди данного типа создаются для [«Канала, хранящего сообщения»](channel-that-stores-messages-ec1bd8365d50.md), а также для узла [«ПрограммныйИсточник»](../integration/programmatic-source-ca1eb29ad522.md).
