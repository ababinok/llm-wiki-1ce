## Обзор

Единый мобильный клиент — это приложение для Android и iOS, которое позволяет пользователям с помощью одного мобильного клиента работать с несколькими публикациями приложения.

## Документированный контракт и примеры

Единый мобильный клиент — это приложение для Android и iOS, которое позволяет пользователям с помощью одного мобильного клиента работать с несколькими публикациями приложения.

Чтобы использовать мобильное приложение в качестве единого мобильного клиента, при [сборке мобильного приложения](build-mobile-app-bdb51dd3d670.md) выберите соответствующую настройку.

В форме «Создание мобильного приложения» выбрана ОС Android. [Описание иллюстрации](../../raw/figures/03c18b2be3185d24919725fbae9e9337b5cc2878bcef586cf2d70159d407c69e-5713f8801b6e7065.md)

## Сервис активации

С помощью сервиса активации вы можете пригласить конкретного человека или группу людей перейти в мобильное приложение.

Приглашение описывается типом [`ПриглашениеЕдиногоМобильногоКлиента`](../stdlib/unifiedmobileclientinvitation-ru-60110bca7c09.md) и представляет собой код активации для единого мобильного клиента.

Чтобы зарегистрировать приглашение в сервисе активации, используйте метод [`Зарегистрировать()`](../stdlib/unifiedmobileclientinvitations-ru-46904aaa1a8f.md) типа [`ПриглашенияЕдиногоМобильногоКлиента`](../stdlib/unifiedmobileclientinvitations-ru-46904aaa1a8f.md). Поиск приглашения выполняется по коду активации. Вы можете указать дополнительные **ПараметрыПоискаПриглашения**, такие как почта и номер телефона. При попытке повторной регистрации приглашения хотя бы с одним существующим ключом выбрасывается исключение [`ИсключениеПриглашенияЕдиногоМобильногоКлиента`](../stdlib/unifiedmobileclientinvitationexception-ru-57368b91aad6.md).

## Примеры

Добавление общего приглашения для всех пользователей

```xbsl
метод ЗарегистрироватьПриглашениеВсехПользователей()
    пер Приглашение = ПриглашенияЕдиногоМобильногоКлиента.Зарегистрировать()

    ВыслатьКодАктивацииВсем(Приглашение.КодАктивации)
;
```

Добавление персонального приглашения для каждого пользователя

```xbsl
метод ЗарегистрироватьПерсональноеПриглашение(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>)
    для Пользователь из Пользователи
        пер Приглашение = ПриглашенияЕдиногоМобильногоКлиента.Зарегистрировать(
            СсылкаНаСервисСаморегистрации = "http://1c.ru",
            ОднократнаяАктивация = Истина)

        ВыслатьКодАктивации(Приглашение.КодАктивации, Пользователь)
    ;
;
```

Добавление персонального приглашения с дополнительным типом активации

```xbsl
метод ЗарегистрироватьПриглашениеСДополнительнымТипомАктивации(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>)
    для Пользователь из Пользователи
        пер ТипыАктивации = {
            ВидКонтактаПользователя.Почта: "test@1c.ru",
            ВидКонтактаПользователя.Телефон: "+79121234578"
        }
        пер Приглашение = ПриглашенияЕдиногоМобильногоКлиента.Зарегистрировать(
            ПараметрыПоискаПриглашения = ТипыАктивации,
            ОднократнаяАктивация = Истина)

        ВыслатьКодАктивации(Приглашение.КодАктивации, Пользователь)
    ;
;
```

Добавление приглашения сроком жизни 30 дней

```xbsl
метод ЗарегистрироватьПриглашение(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>)
    для Пользователь из Пользователи
        пер Приглашение = ПриглашенияЕдиногоМобильногоКлиента.Зарегистрировать(
            ДатаОкончания = ДатаВремя.Сейчас().ДобавитьДни(30).ВМомент(ЧасовойПояс.Текущий()))

        ВыслатьКодАктивации(Приглашение.КодАктивации, Пользователь)
    ;
;
```

Отзыв ранее созданного приглашения

```xbsl
метод УдалитьПриглашение(Приглашение: ПриглашениеЕдиногоМобильногоКлиента)
    ПриглашенияЕдиногоМобильногоКлиента.Отменить(Приглашение.Ид)
;
```
