Важнейшим понятием «Элемента» является проект.

## Документированный контракт и примеры

Важнейшим понятием «Элемента» является проект. Он полностью описывает всю логику приложения, которое будет исполняться сервером и с которым будут работать пользователи. Проект имеет имя, например **Личный кабинет**.

Обычно со временем проект изменяется и развивается. Появляются его новые версии, которые работают лучше, например **версия 1** и **версия 2**. Таким образом, пользователи в каждый конкретный момент времени работают с приложением, которое содержит конкретную версию проекта, например **Личный кабинет, версия 1** или **Личный кабинет, версия 2**.

Разработчик создает и изменяет проект в среде разработки, а затем запускает и отлаживает его на сервере. Когда очередная версия проекта готова, он публикует ее на сервере и передает администратору.

Чтобы группа пользователей (например, фирма **Крон-Ц**) могла подключиться к серверу и работать, администратор сервера создает для них приложение, выбирая для него некоторую версию проекта и указывая [СУБД](https://1cmycloud.com/console/help/element/10.0/docs/topics/database-management-system/), в которой приложение будет хранить данные, например: **Крон-Ц: Личный кабинет, версия 2**. Работая с этим приложением, пользователи создают собственные данные, которые хранятся в приложении.

Пользователи подключаются непосредственно к серверу, он хранит информацию о пользователях и выполняет их аутентификацию. Администратор может объединять пользователей в различные списки и подключать их к тем или иным приложениям, которые исполняет сервер.

Таким образом:

- Сервер исполняет приложения.
- Пользователи работают с приложениями.
- Приложение содержит пользовательские данные.
- Приложения могут быть одной и той же версии проекта, например:
  
  - Личный кабинет, версия 2
    
    для работы;
  - Личный кабинет, версия 2
    
    для тестирования.
  
  Это могут быть приложения разных версий проекта, например:
  
  - Личный кабинет, версия 2
    
    для фирмы
    
    Крон-Ц
    
    ;
  - Личный кабинет, версия 1
    
    для
    
    ООО Товары
    
    ;
  
  Это могут быть приложения разных проектов, например:
  
  - Личный кабинет, версия 7
    
    для
    
    ООО Конфетпром
    
    ;
  - Мобильная касса, версия 3
    
    для
    
    ООО Кафе Сказка
    
    .
- Логика приложения полностью определяется проектом, конкретной его версией.
- Разработчик создает и модифицирует проект в среде разработки и загружает версии проекта на сервер.
- Администратор создает на сервере приложения, выбирая для них версию проекта и СУБД.
- Администратор подключает пользователей, которые вошли на сервер, к приложениям.
- Одного и того же пользователя можно подключить сразу к нескольким приложениям.
