## Документированный контракт и примеры

Чтобы перезапустить «Менеджер хостов внешних компонент», выполните описанные ниже действия.

- Windows
- Linux

1. В строке поиска Windows введите «Службы».
2. Запустите приложение
  
  Службы
  
  (
  
  Services
  
  ).
3. Найдите в списке службу
  
  `1c-enterprise-echostmanager`
  
  .
4. Нажмите
  
  Перезапустить
  
  в контекстном меню. Служба будет остановлена и запущена заново.
