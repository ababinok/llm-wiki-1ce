## Обзор

Источником данных списка (в примере — **СписокМероприятий**, расположенный внутри компонента **Группа**) может являться экземпляром системного компонента `ИсточникДанныхМассив` ([пример](../interface/custom-list-0a05086d6d89.md)).

## Документированный контракт и примеры

Источником данных списка (в примере — **СписокМероприятий**, расположенный внутри компонента **Группа**) может являться экземпляром системного компонента `ИсточникДанныхМассив` ([пример](../interface/custom-list-0a05086d6d89.md)). В отличие от динамического списка, данные источника этого типа могут быть заполнены с помощью произвольного запроса, что демонстрируется ниже:

```xbsl
метод ИсточникДанныхСпискаМероприятий(): ИсточникДанныхМассив<ДанныеМероприятия>
   возврат Компоненты.СписокМероприятий.Источник
;
```

```xbsl
@ВПроекте
метод ЗагрузитьМероприятия(Сделка: Сделки.Ссылка, ТолькоЗадачи: Булево, ТолькоСобытия: Булево)
    ИсточникДанныхСпискаМероприятий().Данные.Очистить()
    знч Мероприятия = ПолучитьМероприятия(Сделка, ТолькоЗадачи, ТолькоСобытия)
    ИсточникДанныхСпискаМероприятий().Данные.ДобавитьВсе(Мероприятия)
;
```

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ПолучитьМероприятия(
    Владелец: Сделки.Ссылка, 
    ТолькоЗадачи: Булево, 
    ТолькоСобытия: Булево
): ЧитаемыйМассив<ДанныеМероприятия>

    знч Мероприятия = <ДанныеМероприятия>[]
    
    знч Запрос = Запрос{
        ВЫБРАТЬ
            События.Ссылка КАК Ссылка,
            События.Наименование КАК Наименование,
            События.Описание КАК Описание,
            События.Владелец КАК Владелец,
            События.ДатаНачала КАК ДатаНачала,
            События.ДатаЗавершения КАК ДатаЗавершения,
            Неопределено КАК СтатусЗадачи 
         ИЗ 
            События КАК События 
         ГДЕ 
            Владелец == %Владелец
            И НЕ %ТолькоЗадачи
            
         ОБЪЕДИНИТЬ ВСЕ
         
         ВЫБРАТЬ
            Задачи.Ссылка,
            Задачи.Наименование,
            Задачи.Описание,
            Задачи.Владелец,
            Неопределено,
            Задачи.ДатаЗавершения,
            Задачи.Статус
         ИЗ 
            Задачи КАК Задачи 
         ГДЕ 
            Владелец == %Владелец
            И НЕ %ТолькоСобытия
            
         УПОРЯДОЧИТЬ ПО 
            ДатаЗавершения УБЫВ}
    
    для СтрокаРезультата из Запрос.Выполнить()
        знч Мероприятие = новый ДанныеМероприятия()
        Мероприятие.Ссылка = СтрокаРезультата.Ссылка
        Мероприятие.Наименование = СтрокаРезультата.Наименование
        Мероприятие.Описание = СтрокаРезультата.Описание
        Мероприятие.Владелец = СтрокаРезультата.Владелец
        Мероприятие.ДатаНачала = СтрокаРезультата.ДатаНачала == Неопределено ? 
                                     Момент{} : СтрокаРезультата.ДатаНачала
        Мероприятие.ДатаЗавершения = СтрокаРезультата.ДатаЗавершения
        Мероприятие.СтатусЗадачи = СтрокаРезультата.СтатусЗадачи
        
        Мероприятия.Добавить(Мероприятие)  
    ;

    возврат Мероприятия
;   
```
