## Обзор

Предложение `ПОМЕСТИТЬ` позволяет создать временную таблицу.

## Документированный контракт и примеры

Предложение `ПОМЕСТИТЬ` позволяет создать временную таблицу.

```xbql
ВЫБРАТЬ
    Сотрудники.Ссылка КАК Ссылка,
    Сотрудники.ФИО КАК ФИО,
    Сотрудники.Код КАК Код
ПОМЕСТИТЬ
    ВременнаяТаблица
ИЗ
    Сотрудники КАК Сотрудники
ИНДЕКСИРОВАТЬ ПО
    Сотрудники.Код
```

## Синтаксис

Предложение `ПОМЕСТИТЬ` имеет следующий синтаксис:

```xbql
[ПОМЕСТИТЬ
    имя-временной-таблицы]
```

## Функция АвтоНомерЗаписи

В запросах создания временных таблиц в качестве выражения в [списке выборки](select-statement-0fef6f15002c.md) можно использовать функцию `АвтоНомерЗаписи`. В этом случае во временной таблице создается целочисленное поле, в которое автоматически присваивается уникальное значение для каждой записи. При использовании функции `АвтоНомерЗаписи` существует ряд ограничений:

- функция может использоваться только непосредственно в элементе списка выборки запроса создания временной таблицы и не может использоваться в других местах, например в выражениях (так, нельзя записать
  
  `АвтоНомерЗаписи() + 5`
  
  );
- в запросе с функцией
  
  `АвтоНомерЗаписи`
  
  не могут использоваться объединения;
- в запросе может быть только один элемент списка выборки, содержащий функцию
  
  `АвтоНомерЗаписи`
  
  .
