## Обзор

Эта функция проверяет наличие подстроки в конце.

## Документированный контракт и примеры

Эта функция проверяет наличие подстроки в конце. Она имеет следующий синтаксис:

```xbql
исходная-строка.ЗаканчиваетсяНа(искомая-подстрока)
```

***исходная-строка*** должна иметь тип `Строка`. ***искомая-подстрока*** должна иметь тип `Строка`. Допускается использовать только константы (строковые литералы или параметры).

Поиск выполняется без учета регистра.

Пример:

```xbql
"0123456789".ЗаканчиваетсяНа("345") // вернет Ложь
"0123456789".ЗаканчиваетсяНа("89")  //вернет Истина
```
