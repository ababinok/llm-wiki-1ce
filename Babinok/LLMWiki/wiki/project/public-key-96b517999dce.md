## Обзор

Открытый ключ — это криптографический ключ, который свободно распространяется и используется для асимметричного шифрования данных и проверки цифровой подписи.

## Документированный контракт и примеры

Открытый ключ — это криптографический ключ, который свободно распространяется и используется для асимметричного шифрования данных и проверки цифровой подписи. Открытый ключ передается с помощью цифровых сертификатов, например SSL / TLS.
