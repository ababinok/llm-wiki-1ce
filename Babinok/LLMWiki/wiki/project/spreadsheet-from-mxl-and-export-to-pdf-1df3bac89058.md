## Обзор

Если вы ранее создали макет табличного документа в «1С:Предприятии» и выгрузили шаблон в формате MXL, то вы можете импортировать его в «1С:Предприятие.Элемент» для дальнейшей работы: заполнения полей, экспорта в различные форматы, вывода на экран.

## Документированный контракт и примеры

## Создание табличного документа из MXL-шаблона

Если вы ранее создали макет табличного документа в «1С:Предприятии» и выгрузили шаблон в формате MXL, то вы можете импортировать его в «1С:Предприятие.Элемент» для дальнейшей работы: заполнения полей, экспорта в различные форматы, вывода на экран. В общем случае, для того чтобы получить необходимую область макета табличного документа, присвоить в нее параметры и вывести значение данных параметров, необходимо выполнить следующие шаги:

1. Прочитайте табличный документ из макета:
  
  ```xbsl
  исп ПотокМакета = Ресурс{ПФ_MXL_СчетНаОплату.mxl}.ОткрытьПотокЧтения()
  знч МакетПечати = ТабличныйДокумент.Прочитать(ПотокМакета, Истина)
  ```
2. Получите из макета необходимую область:
  
  ```xbsl
  пер ОбластьЗаголовок = МакетПечати.ПолучитьОбласть("Заголовок")
  ```
3. Создайте пустой табличный документ и присвойте для удобства объект для записи табличного документа в переменную (в примере — `Писатель`):
  
  ```xbsl
  пер ИтоговыйДокумент = новый ТабличныйДокумент()
  знч Писатель = ИтоговыйДокумент.Запись
  ```
4. Получите выводимую область табличного документа из текущей области и установите в нее необходимые параметры:
  
  ```xbsl
  пер ВыводимаяОбластьЗаголовок = ОбластьЗаголовок.ВВыводимуюОбласть().УстановитьПараметры(
      {"ПредставлениеДокумента": "Счет на оплату № 12000018 от 18 ноября 2022 г."}
  )
  ```
5. Выведите область с установленными параметрами в табличный документ:
  
  ```xbsl
  Писатель.ВывестиВертикально(ВыводимаяОбластьЗаголовок)
  ```

Итоговый документ будет содержаться в переменной `ИтоговыйДокумент`.

## Экспорт документа в PDF

После того как вы вывели в документ все необходимые области с установленными параметрами, вы можете экспортировать документ в PDF. Для этого следует выполнить следующие шаги:

1. Экспортируйте полученный документ в нужный формат:
  
  ```xbsl
  пер БайтыТаблицы = ИтоговыйДокумент.ЭкспортироватьВБайты(ФорматЭкспортаТабличногоДокумента.Pdf)
  ```
2. Загрузите двоичный объект из байтов и сохраните его в файл:
  
  ```xbsl
  пер СвойстваДвоичногоОбъекта = новый ДвоичныйОбъект.Свойства("ВыгрузкаЗадач").Временные()
  
  знч ДвоичныйОбъект = ОбъектноеХранилище.Загрузить(ИмяФайла = "СчетОплаты.pdf",
                                                    Байты = БайтыТаблицы,
                                                    Свойства = СвойстваДвоичногоОбъекта)
  ```

## Отображение документа на клиенте

Вы также можете отобразить документ на клиенте [с помощью компонента просмотра PDF](../interface/pdf-view-component-2aa10f00a4db.md). Для этого выполните следующие шаги:

1. Добавьте в проект компонент интерфейса **ПросмотрPdf** и назовите его **ПросмотрДокумента**:
  
  В проект добавлен компонент интерфейса ПросмотрPdf с именем «ПросмотрДокумента», который отображается в навигаторе проекта. [Описание иллюстрации](../../raw/figures/41c91ec223c4e796974a7e90d6196ab411f4942269bc8525f8b585f0da2dc120-57bb0ba90a019f99.md)
2. В описании элемента проекта, в свойстве **Данные** укажите ссылку на двоичный объект. Предположим, что в проекте есть общий модуль с названием **ПечатьДокумента**. В общем модуле содержится статический метод `ПолучитьСчет`, который возвращает ссылку на двоичный объект (итоговый табличный документ). Тогда описание элемента проекта может выглядеть следующим образом:
  
  Пример YAML-файла компонента «ПросмотрPdf»
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 26a35f43-5247-4bc1-91cc-33eca25a5b18
  Имя: ПросмотрДокумента
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: ПросмотрPdf
      Данные: =ПечатьДокумента.ПолучитьСчет()
  ```
3. Для отображения документа в интерфейсе приложения добавьте в проект компонент интерфейса типа [**ПроизвольноеКлиентскоеПриложение**](../interface/custom-client-application-component-a5e093d01cdd.md) с именем **Главная**:
  
  В навигаторе проекта добавлено произвольное клиентское приложение с именем «Главная» и его модуль для отображения документа в интерфейсе. [Описание иллюстрации](../../raw/figures/4e92e043f0824ae615e5f53a42f6c2f898eb35c19eab36de31023042e854bbc9-7c88ba93aadbcb18.md)
  
  Описание элемента может выглядеть следующим образом:
  
  Пример YAML-файла компонента «ПроизвольноеКлиентскоеПриложение»
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  ОбластьВидимости: ВПодсистеме
  Ид: 9182fc79-d4d6-4ef7-a5e4-e90021730f98
  Имя: Главная
  Наследует:
      Тип: ПроизвольноеКлиентскоеПриложение
      Содержимое:
          Тип: Группа
          Содержимое:
              -
                  Тип: ПросмотрДокумента
  ```

## Пример создания табличного документа из MXL-шаблона и экспорта его в PDF

Далее рассмотрим пример целиком. Предположим, есть шаблон табличного документа, который представляет из себя шаблон счета на оплату и выглядит следующим образом:

Шаблон счета на оплату в табличном документе разделен красными границами на именованные области. [Описание иллюстрации](../../raw/figures/6932208fd3de4c2d5a1ce4247fb54a4dc3c37edb4228374c20b5aef75f7f410b-9bc9fa3625ea3237.md)

В данном примере вы создадите приложение, которое считывает шаблон табличного документа, заполняет его необходимыми данными и экспортирует в PDF. Ваше приложение также будет содержать справочник с товарами. После нажатия на кнопку **Сгенерировать счет** товары из справочника автоматически добавляются в счет на оплату, после чего готовый документ выводится на экран и скачивается в формате PDF. Вы также добавите поле для ввода имени файла и скачаете документ с заданным именем.

Приступим к выполнению примера. Создайте новый проект в «1С:Предприятие.Элементе». Создайте подсистему и назовите ее **ВыводДокумента**. [Скачайте](https://doc-files.1cmycloud.com/downloads?state=element/%D0%A0%D0%B5%D1%81%D1%83%D1%80%D1%81%D1%8B.zip) логотип и MXL-шаблон табличного документа. Добавьте в проект **Ресурсы** и поместите MXL-шаблон документа, а также логотип в ресурсы проекта:

Отображение добавленных ресурсов [Описание иллюстрации](../../raw/figures/b690300ef260f338e3cbffd87268e646460c13b52fd90fa092cb69f4cc2a0cee-d370bd55466d55c6.md)

Создайте новый элемент проекта **Общий модуль**, назовите его **ПечатьДокумента**. В этом модуле будет осуществляться чтение шаблона табличного документа, а также заполнение всех необходимых полей.

	пер ОбластьНомерСтраницы = МакетПечати.ПолучитьОбласть("НомерСтраницы")

Модуль формы генерации счета

```xbsl
// Обработчик нажатия на кнопку. При нажатии на кнопку происходит формирование
// счета на оплату, вывод счета на экран, а также запускается скачивание
@НаКлиенте
метод ПриНажатииСгенерироватьСчет(Источник: Кнопка, Событие: СобытиеПриНажатии)
    попытка
        Источник.Доступность = Ложь

        пер СсылкаНаДвоичныйОбъектСчет = ПечатьДокумента.ПолучитьСчет()

        // Получаем имя документа из структуры данных
        пер ИмяДокумента = ПечатьДокумента.ДанныеПечати().ПредставлениеДокумента

        // Вывод документа на экран
        Компоненты.ВыводPdf.Данные = СсылкаНаДвоичныйОбъектСчет

        // Задаем имя скачиваемого файла
        Компоненты.ВыводPdf.ИмяФайла = ИмяДокумента

        // Сохранение файла на клиенте
        ВыгрузкаФайлов.НачатьВыгрузку(СсылкаНаДвоичныйОбъектСчет, Компоненты.ВыводPdf.ИмяФайла как Строка)
    вконце
        Источник.Доступность = Истина
    ;
;

// Изменение имени сохраняемого файла через форму
// Используйте, если требуется сохранить готовый документ с разными именами
@НаКлиенте
метод ИзменениеИмениФайла(Источник: ПолеВвода<Строка>, Событие: СобытиеПриИзменении<Строка>)
    Компоненты.ВыводPdf.ИмяФайла = Событие.НовоеЗначение
;

// Заполнение справочника Товары тестовыми данными
@Обработчик
метод ПослеСоздания()
    ЗаполнитьТовары()
;

@НаСервере @ДоступноСКлиента
статический метод ЗаполнитьТовары()
    для Индекс = 1 по 50
        знч СГ = новый СлучайныйГенератор()
        знч Количество = СГ.СлучайноеЦелое(1, 1500)
        знч Цена = СГ.СлучайноеЦелое(500, 2500000) / 100

        пер Товар = СоздатьТовар(Код = Индекс.ВСтроку(), Наименование = "Товар номер %{Индекс}",
                                 Цена = Цена, Количество = Количество)
    ;
;

@НаСервере
статический метод СоздатьТовар(Код: Строка, Наименование: Строка, Цена: Число, Количество: Число): Товары.Ссылка
    пер Товар = Товары.НайтиПоКоду(Код)
    если Товар != Неопределено
        возврат Товар
    ;

    пер НовыйТовар = новый Товары.Объект(
        Код = Код,
        Наименование = Наименование,
        Цена = Цена,
        Количество = Количество)
    НовыйТовар.Записать()

    возврат НовыйТовар.Ссылка
;
```
