## Обзор

## Документированный контракт и примеры

Объединяет пользователей, созданных в панели управления. Списки пользователей подключаются к приложениям. К одному приложению могут быть подключены несколько списков пользователей. Таким образом, пользователи из одного списка могут работать с несколькими приложениями.

При создании приложения для него автоматически создается список пользователей, который сразу же подключается к этому приложению.
