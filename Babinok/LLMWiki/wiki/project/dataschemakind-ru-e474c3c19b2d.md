## Обзор

Описание внешней системы, состава и структуры данных, участвующих в обмене.

## Документированный контракт и примеры

Описание внешней системы, состава и структуры данных, участвующих в обмене. Схема данных формируется автоматически по элементам проекта, заданным в свойств [Состав](../integration/exchangeplan-47d882fe414b.md), с учетом заданных правил конвертации данных.

## Литералы

#### Проект1СПредприятияЭлемент

Внешняя система — «1С:Предприятие.Элемент». Обмен данными выполняется между приложениями «1С:Предприятие.Элемента» в формате XML, который используется для сериализации данных объектов, порождаемых элементами проекта «1С:Предприятие.Элемента».

---

#### Конфигурация1СПредприятия8

Внешняя система — «1С:Предприятие». Обмен данными выполняется между приложением «1С:Предприятие.Элемента» и информационной базой «1С:Предприятия» в формате XML, который используется механизмом обмена данными «1С:Предприятия» ([пример](../integration/data-exchange-with-1c-enterprise-d09e80bf9aea.md)).
