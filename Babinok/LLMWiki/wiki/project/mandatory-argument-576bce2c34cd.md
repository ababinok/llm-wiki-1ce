## Обзор

Обязательный аргумент — это аргумент, которому соответствует параметр без значения по умолчанию.

## Документированный контракт и примеры

Обязательный аргумент — это аргумент, которому соответствует параметр без значения по умолчанию.

В примере ниже описан метод `Объем()` с параметрами `Длина`, `Ширина` и `Высота`. Для ширины и высоты заданы значения по умолчанию: 80 и 120. При вызове метода аргумент `100` передается в обязательный параметр `Длина`:

```xbsl
метод Объем(Длина: Число, Ширина: Число = 80, Высота: Число = 120): Строка
    возврат "Объем равен ${Длина*Ширина*Высота}"
;

метод Скрипт()
    Объем(100, Высота = 100, Ширина = 10)
;
```
