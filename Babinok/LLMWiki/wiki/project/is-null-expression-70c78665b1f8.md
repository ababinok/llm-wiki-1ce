## Обзор

Выражение `ЕСТЬ NULL` сравнивает значение с `Null`.

## Документированный контракт и примеры

Выражение `ЕСТЬ NULL` сравнивает значение с `Null`. Оно имеет следующий синтаксис:

```xbql
проверяемое-значение ЕСТЬ [НЕ] NULL
```

Если ***проверяемое-значение*** равно `Null`, то выражение возвращает значение `Истина`, иначе — `Ложь`.
