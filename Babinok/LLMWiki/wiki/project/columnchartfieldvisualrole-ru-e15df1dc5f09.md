## Литералы

#### ОсьX

Может быть назначена только на размерность для вертикальных столбцов и только на факт для горизонтальных столбцов. Значения размерности формируют ось X графика.

---

#### Группы

Может быть назначена только на размерность. Значения размерности формируют столбчатые серии графика.

---

#### ЛеваяОсьY

Может быть назначена только на факт для вертикальных столбцов и только на размерность для горизонтальных столбцов. Столбцы факта отображаются в масштабе левой оси графика.

---

#### ЛинииЛевойОсиY

Доступна только для вертикальных столбцов. Может быть назначена только на факт. Линия факта отображается в масштабе левой оси графика.

---

#### ЛинииПравойОсиY

Доступна только для вертикальных столбцов. Может быть назначена только на факт. Линия факта отображается в масштабе правой оси графика.

---

#### Маркеры

Может быть назначена только на поле с ролью **ОсьX**, **ОсьY** или **Группы**. Добавляет на каждый столбец маркер со значением поля в этом столбце.

---

#### МаркерыЛиний

Доступна только для вертикальных столбцов. Может быть назначена только на факт с ролью **ЛинииЛевойОсиY** или **ЛинииПравойОсиY**. Добавляет на каждую точку линии факта маркер со значением факта в этой точке.

---

#### Цвет

Может быть назначена только на размерность с ролью **ОсьX** (для вертикальных столбцов), **ОсьY** (для горизонтальных столбцов) или **Группы**.

При установке на размерность с ролью **Группы** все столбчатые серии на графике раскрашиваются в разные цвета.

При установке на осевую размерность все столбцы, соответствующие одному элементу оси, раскрашиваются в один цвет, а соответствующие разным элементам — в разные.
