## Обзор

Обязательный стандартный реквизит, содержащий наименование элементов плана обмена.

## Документированный контракт и примеры

Обязательный стандартный реквизит, содержащий наименование элементов плана обмена.

---

## Свойства

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [Обычная](displayimportance-ru-469c555fd91c.md).

---

#### Длина

```yaml
Длина: Число
```

Максимальная длина наименования. По умолчанию — 150. Максимальная длина — 400.

---

#### НезаполненноеЗначение

```yaml
НезаполненноеЗначение: ПолитикаПроверки
```

Определяет политику проверки пустого значения. Возможные значения:

- [Разрешить](checkpolicy-ru-a29d42ab39ba.md)
  
  ,
- [ЗапретитьВсегда](checkpolicy-ru-a29d42ab39ba.md)
  
  (значение по умолчанию).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных этого реквизита для использования в [полнотекстовом поиске](full-text-search-99b98022003a.md).

---

#### ЗаполнятьПриКопировании

```yaml
ЗаполнятьПриКопировании: Булево
```

Свойство определяет, заполнять ли элемент при копировании.
