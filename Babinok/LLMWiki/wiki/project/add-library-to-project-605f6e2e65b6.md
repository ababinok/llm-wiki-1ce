## Документированный контракт и примеры

Чтобы подключить библиотеку к проекту, выполните следующие действия:

1. В навигаторе проекта нажмите на **Описание проекта**, чтобы отобразить его свойства.
2. Если к проекту пока не подключена ни одна библиотека, в разделе **Библиотеки** палитры свойств нажмите кнопку **Добавить элемент**, чтобы добавить новую зависимость.
  
  В свойствах проекта раздел «Библиотеки» содержит кнопку «Добавить элемент» для подключения зависимости. [Описание иллюстрации](../../raw/figures/338da50f13be6794c758a86c53bbd0aa9ead147f401087d339ae05a8b0ae3cac-df18b7ecceaf2b38.md)
3. Выберите релизную версию требуемой библиотеки в выпадающем списке. Не допускается использовать разные версии одной и той же библиотеки внутри проекта.
  
  В свойствах проекта раскрыт список версии библиотеки: для CurrencyConverter доступны релизные версии 2.0 и 1.0, выбирается одна версия. [Описание иллюстрации](../../raw/figures/dfc287ff4c7c8ae2e0031b2ba5f202d72f0a4ec0d0c5b102fb8b6977cb2e6753-c2fc242b8aba5315.md)

Если подключается внешняя библиотека, она добавляется в раздел **Зависимости** навигатора проекта. Внешние библиотеки отображаются только в **режиме чтения** и недоступны для редактирования. Если для внешней библиотеки доступна новая версия релиза, вы можете подключить ее к проекту следующим образом: [удалите текущую зависимость](exclude-library-from-project-references-e408bf987b12.md) и добавьте зависимость от новой версии. Если вы хотите менять код библиотеки вместе с проектом, то создайте эту библиотеку внутри проекта, как показано в данной статье: [Создать библиотеку внутри проекта](create-library-within-project-647cc59006b5.md).



Подключенные к проекту зависимости также отображаются в файле **Проект.yaml** в разделе **Библиотеки**:

```yaml
Ид: e698f2a4-2d73-4573-be3c-390cc7b61a2a
Имя: DemoCrmProject
Представление: Демо CRM
# Остальные свойства проекта
# ...
Библиотеки:
    -
        Имя: CurrencyConverter
        Поставщик: e1c
        Версия: 2.0
```

После подключения библиотеки все ее типы с [областью видимости](name-scope-f4e2d086669a.md) `Глобально` станут доступны в вашем проекте. Пространство имен типов имеет следующий вид:

```text
Поставщик::ИмяПроекта::Подсистема[::Пакет]::ИмяТипа
```

В конструкциях [Использование](../language/modular-development-80166cfecf93.md) и [импорт](../language/modular-development-80166cfecf93.md) необходимо указывать полное имя подсистемы:

```text
Поставщик::ИмяПроекта::Подсистема
```

Например, для библиотеки в данной статье пространство имен будет выглядеть следующим образом:

```text
e1c::CurrencyConverter::Основное
```
