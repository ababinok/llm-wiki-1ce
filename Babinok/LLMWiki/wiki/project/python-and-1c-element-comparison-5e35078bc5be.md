## Обзор

Разные языки программирования во многом схожи между собой: в любом из них есть переменные, операции, типы данных и синтаксические конструкции.

## Документированный контракт и примеры

Разные языки программирования во многом схожи между собой: в любом из них есть переменные, операции, типы данных и синтаксические конструкции. В данном разделе мы сравним основные конструкции языка Python с их аналогами в языке «1С:Элемент».

Прежде чем перейти к отличиям в синтаксисе, отметим главные различия между языками. Python — язык с *динамической типизацией*: тип переменной определяется во время выполнения программы. «1С:Элемент» — язык со *статической типизацией*: тип переменной, как правило, известен заранее и проверяется до запуска. Специальный тип [`неизвестно`](../language/unknown-type-a543abb3a169.md) отключает проверки компилятора, но применяют его в редких случаях, когда тип значения заранее узнать невозможно.

## Форматирование кода

В языке Python блоки кода выделяются с помощью *отступов*. Для каждого уровня отступа используют 4 пробела. Двоеточие (`:`) в конце строки указывает на начало нового вложенного блока. В языке «1С:Элемент» отступы носят рекомендательный характер для улучшения читаемости кода. Границы блоков строго фиксируются с помощью ключевых слов, а каждый блок обязательно закрывается точкой с запятой (`;`).

Для комментариев в Python служит символ `#`, а в языке «1С:Элемент» — символы `//`.

Python

```python
# Вычисление суммы чисел в списке
def calculate_sum(number_list):
    total = 0
    for number in number_list:
        total += number
    return total
```

«1С:Элемент»

```xbsl
// Вычисление суммы чисел в массиве
метод РассчитатьСумму(МассивЧисел: Массив<Число>): Число
    пер Сумма = 0
    для Число из МассивЧисел
        Сумма += Число
    ;
    возврат Сумма
;
```

## Стили именования

Стандарты оформления (PEP 8 для Python и официальный стандарт для языка «1С:Элемент») диктуют принципиально разные стили написания имен:

| Элементы кода | Стиль в Python | Пример в Python | Стиль в «1С:Элементе» | Пример в «1С:Элементе» |
| --- | --- | --- | --- | --- |
| Функции / Методы | snake_case | `calculate_total()` | UpperCamelCase | `РассчитатьИтог()` |
| Классы / Структуры | UpperCamelCase | `UserData` | UpperCamelCase | `ДанныеПользователя` |
| Переменные | snake_case | `user_name` | UpperCamelCase | `ИмяПользователя` |
| Константы | UPPER_CASE | `SERVER_VERSION` | UPPER_CASE | `ВЕРСИЯ_СЕРВЕРА` |
