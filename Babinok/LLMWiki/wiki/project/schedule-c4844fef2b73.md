## Обзор

Расписание, по которому выполняется запланированное задание.

## Документированный контракт и примеры

#### Расписание

```yaml
Расписание: Однократно|Периодическое|Ежедневно|Еженедельно|Ежемесячно[]
```

Расписание, по которому выполняется запланированное задание. Если расписание не задано, то свойство [ПредопределенноеЗадание](scheduledjob-82127f45462a.md) может иметь только одно значение — **НеСоздавать**.
