## Обзор

Удаление данных — это процесс, связанный с удалением или скрытием объектов приложения.

## Документированный контракт и примеры

Удаление данных — это процесс, связанный с удалением или скрытием объектов приложения. В «1С:Предприятие.Элементе» реализовано удаление объектов с возможностью их восстановления.

## Режимы удаления

«1С:Предприятие.Элемент» поддерживает два режима удаления объекта:

- пометить на удаление — тогда вы сможете восстановить его, если передумаете;
- удалить немедленно — удалить его без возможности восстановления.

Режим удаления объекта выбирается с помощью его свойства **РежимУдаления**, которое может принимать значения **Немедленно** или **ПометкаУдаления**:



### Режим «ПометкаУдаления»

Чтобы удалить элемент из списка, выберите его и в открывшейся форме объекта нажмите на значок **Удалить** в правом верхнем углу.

В форме объекта «Задача» выделен значок удаления справа вверху для удаления открытого объекта. [Описание иллюстрации](../../raw/figures/56f923ee6711a6d49e1376c40e8b8c00a233b3fdf87e4f9d0f8493e91f2f0229-898b518268a6916f.md)

При удалении объекта в режиме **ПометкаУдаления** в его свойство **ПометкаУдаления** типа `имя-сущности.Объект` записывается значение `Истина`, а в свойство **МоментПометкиУдаления** — момент установки пометки удаления. Объекты, для которых свойство **ПометкаУдаления** имеет значение `Истина`, в форме списка не отображаются.

Чтобы установить или снять пометку удаления, можно воспользоваться методом `УстановитьПометкуУдаления()` типа `имя-сущности`. Если объект является владельцем других объектов (например, справочник, имеющий подчиненные справочники), то пометка удаления устанавливается и на все подчиненные записи.

При загрузке данных из внешних источников может потребоваться создавать объекты уже помеченными на удаление. При этом момент пометки удаления может поступать из внешней системы. Чтобы установить пометку удаления при обмене данными, используйте метод `УстановитьПометкуУдаленияПриЗагрузкеДанных()` типа `имя-сущности.Объект`. Он позволяет установить свойства **ПометкаУдаления** и **МоментПометкиУдаления** непосредственно при загрузке объекта.

> [!WARNING] важно
> Метод `УстановитьПометкуУдаленияПриЗагрузкеДанных()` работает только в контексте загрузки данных.

В форме списка объектов, для которых установлен режим **ПометкаУдаления**, можно включить отображение удаленных объектов в настройках фильтра:

В настройках фильтра списка задач выделен переключатель «Показывать удалённые», включающий отображение помеченных объектов. [Описание иллюстрации](../../raw/figures/f24e9f8cb53d6a53a937f3f0f0e3c2e0cb6a72ed0960af270dc1ba3f263d5bc1-d10ce6fd37fc5c02.md)

Тогда помеченные на удаление объекты появятся в списке с красной отметкой:

Отображение удаленного объекта в списке [Описание иллюстрации](../../raw/figures/b033a9c90602d2a85dbddc2f5d49a4da1a7411ce333092ea9025b2c3e8aa4b83-fa5be4a22a4f6ab9.md)

Если вам снова понадобится удаленный объект, включите режим «Показывать удаленные», выберите в списке нужный объект и в открывшейся форме объекта нажмите на значок **Восстановить** в правом верхнем углу:



> [!NOTE] примечание
> Чтобы удалить объект без возможности восстановления, вы можете воспользоваться методом `{ИмяСущности}.Объект.Удалить()` или добавить команду [`УдалитьНавсегда`](../interface/object-form-component-98dd1d49f7f9.md) на форму объекта вручную.

### Режим «Немедленно»

Если установлен режим **Немедленно**, то при удалении элемента из списка вы нажимаете команду **Удалить** и объект удаляется навсегда без возможности восстановления.

Система проверяет, нет ли ссылок на удаляемый объект в других объектах. Если ссылок нет, он удаляется. Если ссылки найдены, то объект не получится удалить, пока не будут [разрешены конфликты, мешающие удалению](data-deletion-141a62f69ff7.md).

### Разрешение конфликтов, связанных со ссылками на удаляемые объекты

В «1С:Предприятие.Элементе» реализована поддержка ссылочной целостности.

Если у объекта есть реквизит, измерение или ресурс ссылочного типа, то обработка связей при удалении объекта, указанного в этом поле, определяется его свойством `ПриУдаленииОбъектаПоСсылке`. В процессе удаления значение свойства анализируется при поиске ссылок, и в зависимости от него принимается решение о поведении при удалении.

Свойство `ПриУдаленииОбъектаПоСсылке` может принимать следующие значения:

- ЗапрещатьУдаление
  
  — запрещает удалять объект без разрешения конфликтов, мешающих удалению. Если реквизит ссылается на элемент, для которого установлен
  
  РежимУдаления
  
  равный
  
  Немедленно
  
  , то в свойстве
  
  `ПриУдаленииОбъектаПоСсылке`
  
  этого реквизита нельзя использовать значение
  
  ЗапрещатьУдаление
  
  .
- НетДействия
  
  — отсутствует контроль за целостностью ссылок; при удалении остается битая ссылка.
- Очищать
  
  — при удалении ссылающегося объекта устанавливает значение поля элемента проекта по умолчанию.
- УдалятьТекущий
  
  — позволяет удалять и зависимый, и ссылающийся объект (например, удаляет вложенный файл при удалении письма). Если в элементе проекта включен режим удаления
  
  ПометкаУдаления
  
  , то в его реквизитах нельзя устанавливать свойство
  
  `ПриУдаленииОбъектаПоСсылке`
  
  равным
  
  УдалятьТекущий
  
  .

## Удаление помеченных объектов

Чтобы удалить помеченные объекты, используйте встроенную форму удаления `ФормаУправленияУдалениемДанных`. В ней вы можете выполнить следующие действия:

- запустить удаление всех помеченных объектов;
- настроить параметры удаления (области, сроки давности удаления) и запустить удаление с этими параметрами;
- просмотреть объекты, которые не получилось удалить, и перейти к форме управления связями, препятствующими их удалению.

### Как запустить удаление всех помеченных объектов

Чтобы вручную удалить все помеченные объекты, добавьте в интерфейс встроенную форму `ФормаУправленияУдалениемДанных` и откройте ее:

Форма «Управление удалением» содержит две большие команды: «Очистить удаленные данные» с подписью «Очистка всех удаленных ранее данных» и «Управлять связями, препятствующими очистке» с пояснением о просмотре препятствий и разрешении конфликтов.. [Описание иллюстрации](../../raw/figures/62c5b051ddae6f90b2073ebab17c043d455b065f6791327537297a99f1a78281-4dfcbfa49ca1cba4.md)

[Подробнее о том, как добавить форму в интерфейс](../interface/create-custom-form-5f06351aa37a.md)

Чтобы удалить все помеченные объекты, перейдите в раздел «Очистить удаленные данные» и в открывшейся форме нажмите **Начать очистку**:

Форма «Очистить удалённые данные» с выключенным указанием параметров: поля отбора неактивны, кнопка «Начать очистку» запускает очистку всех помеченных объектов. [Описание иллюстрации](../../raw/figures/e16f37d39db6b620c95540d60597a0b3065aeac7f02e3853968cb61176536116-2665ea1525d209f3.md)

### Как настроить параметры удаления

Вы можете задать такие параметры удаления, как:

- срок давности удаления (например, старше 30 дней);
- типы удаляемых объектов (например,
  
  Сделки
  
  ).

Для этого откройте форму `ФормаУправленияУдалениемДанных` и перейдите в раздел «Очистить удаленные данные». Чтобы указать параметры удаления, включите соответствующий режим:

Форма «Очистить удалённые данные» с включённым указанием параметров: отбор по возрасту данных, тип данных и кнопка «Начать очистку». [Описание иллюстрации](../../raw/figures/d7f35dc63416ffc261d16dbb22c15230667c03fda5bbb74129268caecf28b5ad-fadeeefbe7788e95.md)

Укажите требуемые параметры и нажмите кнопку **Начать очистку**.

### Как разрешить конфликты, мешающие удалению

Если на объект есть ссылки в других объектах системы, удалить его не получится. В этом случае в форме `ФормаУправленияУдалениемДанных` перейдите в раздел **Управлять связями, препятствующими очистке**. В открывшейся форме отображаются таблицы, содержащие неудаленные данные:

Форма управления связями, препятствующими очистке, содержит таблицы с неудалёнными данными: тип объекта и количество неудалённых объектов. [Описание иллюстрации](../../raw/figures/f20d1b2a7a82b13fa6855feed9ea2705bd87c67ac10087839b2e25ef76a522f2-c0d65acebc895fce.md)

Выберите объект. Откроется форма управления ссылками. Здесь вы можете выполнить следующие действия:

- удалить ссылку на удаляемый объект;
- выбрать новый объект, который заменит удаляемый;
- пометить на удаление объект, ссылающийся на удаляемый объект.

Форма управления ссылками показывает объекты, ссылающиеся на удаляемый объект, и действия над этими ссылками, включая пометку ссылающегося объекта на удаление. [Описание иллюстрации](../../raw/figures/34bda4cd4b2f94ddc65e1eb788c9e0b18397fbc21acc0ca355255ea97e81e04e-1244a179f39a0165.md)

## Типы для реализации удаления

### Тип «УдалениеОбъектов»

Для управления процессом удаления записей используется тип [`УдалениеОбъектов`](../stdlib/objectsdeletion-ru-73b8077caa2a.md) пространства имен [`Стд::Сущности`](../data/entities-7b2acb4f9eee.md). Он также управляет системным фоновым заданием удаления данных. С помощью его свойств можно задать объекты, подлежащие удалению и исключаемые из удаления, а также срок давности удаления.

Задание параметров удаления объектов

```xbsl
знч ПараметрыУдаления = новый УдалениеОбъектов()

ПараметрыУдаления.Включаемые = [Тип<ВходящееПисьмо.Ссылка>]
ПараметрыУдаления.Исключаемые = ПолучитьПисьмаВКорзинеДиректора()
ПараметрыУдаления.ТаймаутУстаревания = 10д

ПараметрыУдаления.Выполнить()
```

### Тип «НеудаленныеОбъекты»

При запуске процесса удаления выбранный объект блокируется и помещается в системную таблицу. Она хранит состояния удаления объектов и нужна для того, чтобы сократить время накладываемой исключительной блокировки ссылок и не препятствовать работе остальной системы.

Если объект невозможно удалить, он помещается в системную таблицу **НеудаленныеОбъекты** и дальнейшее решение по нему принимает администратор системы. Для работы с неудаленными объектами используется тип [`НеудаленныеОбъекты`](../stdlib/undeletedobjects-ru-35dc33d952c0.md). С его помощью можно заменить удаляемый объект на новый или удалить ссылающийся объект.

Вы также можете обработать неудаленные объекты интерактивно с помощью системной формы [ФормаУправленияУдалениемДанных](data-deletion-141a62f69ff7.md).

Замена ссылок на удаляемые объекты

```xbsl
метод КонтрольСсылокСправочник(ТаблицаЗамен: Соответствие<Сотрудники.Ссылка, Сотрудники.Ссылка|Неопределено>)
    для Замена из ТаблицаЗамен
        НеудаленныеОбъекты.Заменить(Замена.Ключ, Замена.Значение)
    ;
;
```
