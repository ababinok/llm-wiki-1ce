## Обзор

Выражение `ОТЛИЧАЕТСЯ ОТ` позволяет сравнить два значения без учета `Null`-семантики.

## Документированный контракт и примеры

Выражение `ОТЛИЧАЕТСЯ ОТ` позволяет сравнить два значения без учета `Null`-семантики. Выражение имеет следующий синтаксис:

```xbql
операнд-1 [НЕ] ОТЛИЧАЕТСЯ ОТ операнд-2
```

Выражение `ОТЛИЧАЕТСЯ ОТ` эквивалентно операции `!=` (не равно), но интерпретирует `Null` как обычное значение. Например:

```xbql
42 ОТЛИЧАЕТСЯ ОТ 42 → Ложь
42 ОТЛИЧАЕТСЯ ОТ "42" → Истина
42 ОТЛИЧАЕТСЯ ОТ Null → Истина
Null ОТЛИЧАЕТСЯ ОТ Null → Ложь
```

Выражение `НЕ ОТЛИЧАЕТСЯ ОТ` эквивалентно операции `=` (равно), но интерпретирует `Null` как обычное значение. Например:

```xbql
42 НЕ ОТЛИЧАЕТСЯ ОТ 42 → Истина
42 НЕ ОТЛИЧАЕТСЯ ОТ "42" → Ложь
42 НЕ ОТЛИЧАЕТСЯ ОТ Null → Ложь
Null НЕ ОТЛИЧАЕТСЯ ОТ Null → Истина
```
