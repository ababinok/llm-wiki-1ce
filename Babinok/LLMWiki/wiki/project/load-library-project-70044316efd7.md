## Документированный контракт и примеры

Если вы хотите подключить к проекту внешнюю библиотеку, поставляемую другими разработчиками, вам необходимо сначала загрузить ее в панель управления. Для этого выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** нажмите **+ Добавить проект** и выберите пункт **Загрузить проект из файла** в выпадающем меню.
  
  Загрузка проекта из файла [Описание иллюстрации](../../raw/figures/ccc224e9355a16fbe34301cfd8c8f7b36d5e2954779b7d7e9b5cb28dd4684ed7-8e0c4d3c618a7e81.md)
3. Выберите сборку проекта библиотеки в формате *.xlib* или *.zip*.
4. В открывшемся окне нажмите **Добавить**. Поля диалога будут автоматически заполнены данными из файла проекта библиотеки.
  
  

Если загрузка пройдет успешно, библиотека появится в общем списке на вкладке **Проекты**. После этого вы можете [использовать загруженную библиотеку в своем проекте](add-library-to-project-605f6e2e65b6.md).

В списке проектов библиотек отображается успешно загруженная библиотека «Конвертер валют»; сверху доступны поиск, фильтры и добавление проекта. [Описание иллюстрации](../../raw/figures/58dc20a3740e2860c3d77a90af154bb40a970bf0ef27c0665b67211a31df62e0-1f83a2762f05b3b5.md)

## Загрузить новую версию библиотеки

Если для внешней библиотеки выпущена новая версия, вы можете загрузить ее в панель управления, а затем подключить к своему проекту. Загруженная сборка библиотеки будет помечена как [релизная](create-or-cancel-release-89b0fc793f03.md). Чтобы получить более подробную информацию, перейдите в следующие статьи:

- [Как добавить сборку проекта](add-assembly-from-file-3fb038d36fd7.md)
- [Как подключить библиотеку к проекту](add-library-to-project-605f6e2e65b6.md)
