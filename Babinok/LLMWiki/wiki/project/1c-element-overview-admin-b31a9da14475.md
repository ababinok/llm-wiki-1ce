## Документированный контракт и примеры

«1С:Предприятие.Элемент» — облачная технология low-code разработки веб-кабинетов, порталов, браузерных и мобильных приложений. Ее встроенные механизмы помогут упростить управление тысячами приложений. Используйте готовые решения для часто встречающихся задач без необходимости писать большой объем кода.

### Как подключить базу данных к серверу

«1С:Предприятие.Элемент» поддерживает использование следующих систем управления базами данных (СУБД):

- PostgreSQL,
- Tantor SE-1C,
- Microsoft SQL Server,
- встроенная файловая СУБД.

Вы можете установить СУБД [PostgreSQL](https://1cmycloud.com/console/help/element/10.0/docs/topics/install-and-configure-postgresql/), [Tantor SE-1C](https://docs.tantorlabs.ru/tdb/ru/16_8/se1c/admin.html) или [Microsoft SQL Server](https://1cmycloud.com/console/help/element/10.0/docs/topics/microsoft-sql-server/), а затем [подключить их к серверу](https://1cmycloud.com/console/help/element/10.0/docs/topics/connect-database-to-server/) с помощью панели управления.

### Как подключить хранилище двоичных данных

Для эффективного хранения двоичных данных «1С:Предприятие.Элемент» использует специальные хранилища. Вы можете [просматривать информацию](https://1cmycloud.com/console/help/element/10.0/docs/topics/connected-storages/) о подключенных к серверу хранилищах двоичных данных, [добавлять](https://1cmycloud.com/console/help/element/10.0/docs/topics/add-binary-data-storage-to-server/) новые хранилища и [создавать правила их использования](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-default-rules/).
