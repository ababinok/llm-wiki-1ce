## Обзор

«1С:Предприятие.Элемент» позволяет добавлять и изменять конфигурации запуска и отладки приложения.

## Документированный контракт и примеры

«1С:Предприятие.Элемент» позволяет добавлять и изменять конфигурации запуска и отладки приложения. Для настройки отладки перейдите в представление **Отладка** и нажмите на значок шестеренки. Откроется диалоговое окно **Запуск и отладка**, содержащее конфигурацию отладки по умолчанию.

Окно «Запуск и отладка» содержит конфигурацию "1C:Enterprise.Element" Debugger. [Описание иллюстрации](../../raw/figures/bc467025302b428d3cc541f9d4269d8d7e99740b320844cbbd47c93ac245227a-bd186b140e716f28.md)

Конфигурации отладки хранятся в файле *launch.json*. Чтобы просмотреть его, нажмите **{} Редактировать как JSON**. По умолчанию он выглядит так:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "\"1C:Enterprise.Element\" Debugger",
            "type": "xbsl",
            "request": "attach",
            "stopOnEntry": false,
            "endSessionIfClientDisconnected": true
        }
    ]
}
```

Файл соответствует [спецификации настроек отладки Visual Studio Code](https://code.visualstudio.com/docs/debugtest/debugging-configuration). Свойства `version`, `request` и `type` являются служебными. Они используются самой средой разработки и не должны изменяться вручную. Остальные свойства отвечают за настройку отладки в «1С:Предприятие.Элементе». Вы можете изменить параметры конфигурации в окне **Запуск и отладка** или отредактировать их напрямую в файле *launch.json*.

## Добавление конфигурации отладки

Вы можете создать конфигурацию отладки несколькими способами:

- перейдите в представление **Отладка** и выберите **Добавить конфигурацию** в выпадающем списке доступных конфигураций:
  
  В представлении «Отладка» раскрыт список конфигураций и выбран пункт «Добавить конфигурацию…». [Описание иллюстрации](../../raw/figures/ed6ba1de45632c378f415af0d22da87cfe71de71d5cf3be29668d0eb5c92d5db-da37f34ae61cc353.md)
- откройте диалоговое окно **Запуск и отладка** и нажмите **Добавить конфигурацию**.

Укажите название новой конфигурации и задайте необходимые параметры отладки.

## Выбор приложения для отладки

В проекте может быть несколько клиентских приложений, и вы можете выбрать, для какого именно приложения запускать отладку. Это можно сделать разными способами:

- [задать настройки отладки для конкретного приложения вручную](debug-configuration-5de1baf7fe9e.md)
  
  ,
- [запустить отладку из «Навигатора проекта»](debug-configuration-5de1baf7fe9e.md)
  
  .

### Создание конфигурации отладки для приложения

Создайте новую конфигурацию отладки в окне **Запуск и отладка** и укажите ее имя (например, **Отладчик "Первое приложение"**). В свойстве **Путь клиентского приложения для отладки** (`clientApplicationPath`) укажите значение, совпадающее со свойством **Путь** клиентского приложения. Тогда при отладке выбранное приложение откроется по этому пути. Если свойство не задано, запускается приложение по корневому пути. Если такого приложения в проекте нет, используется [автоматический интерфейс](../interface/auto-generated-ui-7150689c0714.md).

В конфигурации отладки «Отладчик Первое приложение» поле «Путь клиентского приложения для отладки» заполнено `first-app`; подпись требует совпадения с «Путь клиентского приложения». [Описание иллюстрации](../../raw/figures/6cd474dd35d3ab9a45669cf8804a02acff711343f401f41f57ad7022b9a0172b-bcd4571bc47e1734.md)

Созданная конфигурация будет записана в файл *launch.json*:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "\"1C:Enterprise.Element\" Debugger",
            "type": "xbsl",
            "request": "attach",
            "stopOnEntry": false,
            "endSessionIfClientDisconnected": true
        },
        // Настройки отладки первого приложения
        {
            "type": "xbsl",
            "name": "Отладчик 'Первое приложение'",
            "stopOnEntry": false,
            "request": "attach",
            "endSessionIfClientDisconnected": true,
            "clientApplicationPath": "first-app",
            "langAlias": "russian",
            "authMode": "current_user"
        }
    ]
}
```

Выберите добавленную конфигурацию в панели команд представления **Отладка**:

В представлении «Отладка» раскрыт выбор конфигурации отладчика; выбирается добавленная конфигурация отладки «1С:Предприятия». [Описание иллюстрации](../../raw/figures/3d0a9eca71aaa3027526823e00be1a807a41e6ece0dcb455b7cc796f62e257d9-7b7df38a38c2179c.md)

[Опубликуйте](publish-project-on-server-dade1898bf5e.md) проект и запустите [отладку](start-debugging-d5c5117b447f.md). В новой вкладке откроется выбранное приложение в режиме отладки с заданными настройками.

### Запуск отладки из «Навигатора проекта»

Отладку определенного клиентского приложения можно запустить из **Навигатора проекта**. Для этого в представлении **1C** нажмите правой кнопкой мыши на любой элемент приложения, отладку которого вы хотите запустить, и в контекстном меню выберите **Начать отладку приложения**.

В контекстном меню элемента приложения в навигаторе выбран пункт «Начать отладку приложения». [Описание иллюстрации](../../raw/figures/dee364f6ef122f122dc9e727f9e596a9c7a07766b1eb72e5d930889e456425d2-430348f9884eb66a.md)

В новой вкладке откроется выбранное приложение в режиме отладки. При этом будет автоматически создана конфигурация отладки для этого приложения:

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "\"1C:Enterprise.Element\" Debugger",
            "type": "xbsl",
            "request": "attach",
            "stopOnEntry": false,
            "endSessionIfClientDisconnected": true
        },
        // Настройки, добавленные автоматически
        // при запуске отладки из навигатора проекта
        {
            "type": "xbsl",
            "request": "attach",
            "name": "Отладка приложения 'ВтороеПриложение'",
            "stopOnEntry": false,
            "endSessionIfClientDisconnected": true,
            "clientApplicationPath": "second-app",
            "langAlias": "russian",
            "authMode": "current_user"
        }
    ]
}
```

Если в представлении **1C** правой кнопкой мыши нажать на элемент проекта, не относящийся ни к одному из клиентских приложений, и в контекстном меню выбрать **Начать отладку приложения**, появится список всех клиентских приложений этого проекта.



> [!NOTE] примечание
> На этом рисунке **АвтоматическоеПриложение** соответствует автоматическому интерфейсу, потому что в проекте нет приложения, которое запускается по корневому пути.

Выберите нужное приложение. Оно откроется в новой вкладке в режиме отладки с настройками, прописанными в файле **launch.json** для этого приложения. Если для этого приложения не заданы настройки отладки, они автоматически добавятся в файл **launch.json**.

## Выбор пользователя для запуска отладки

«1С:Предприятие.Элемент» позволяет выполнить отладку от имени другого пользователя. Для этого в окне **Запуск и отладка** задайте настройку **Запуск от имени другого пользователя** (`authMode`).

Выбор пользователя для отладки [Описание иллюстрации](../../raw/figures/b75569d8011ec2dca1d733f77e2398834af0851f13b86a9ce88ebd96d8075b04-bffb321a5d7106d7.md)

Вы можете выбрать одно из следующих значений:

- Не использовать
  
  (
  
  `current_user`
  
  ) — вход в приложение выполняется от имени текущего пользователя (используется по умолчанию);
- Спрашивать при запуске
  
  (
  
  `another_user`
  
  ) — при запуске отладки откроется страница аутентификации, на которой вы можете выполнить вход в приложение от имени нужного пользователя;
- Анонимный пользователь
  
  (
  
  `anonymous`
  
  ) — позволяет выполнить анонимный (без аутентификации) вход в приложение, которое поддерживает данную возможность. Если приложение не допускает анонимный вход, при запуске отладки откроется страница аутентификации.

## Запуск отладки

При запуске отладки из строки состояния, меню или с помощью **F5** запускается конфигурация отладки, выбранная в представлении **Отладка**. Если файл с настройками отладки **launch.json** пустой или отсутствует, при запуске отладки откроется диалоговое окно **Запуск и отладка**, в котором необходимо задать конфигурацию отладки и ее свойства.
