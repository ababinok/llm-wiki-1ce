## Обзор

В осях XY можно строить три типа диаграмм: линейную, столбчатую и пузырьковую.

## Документированный контракт и примеры

В осях XY можно строить три типа диаграмм: линейную, столбчатую и пузырьковую. Для их построения используется компонент интерфейса [«XYДиаграмма»](../interface/xy-chart-component-39ac97259e35.md). Тип визуализации зависит от используемой серии данных:

- для построения линейной диаграммы используется
  
  `ЛинейнаяСерияДиаграммы`
  
  ;
- для построения столбчатой диаграммы используется
  
  `СтолбчатаяСерияДиаграммы`
  
  ;
- для построения пузырьковой диаграммы используется
  
  `ПузырьковаяСерияДиаграммы`
  
  .

На одной XY-диаграмме можно комбинировать различные серии данных, получая таким образом комбинированные графики.

Для создания воронкообразной диаграммы используется компонент интерфейса [«ВоронкообразнаяДиаграмма»](../interface/funnel-chart-component-fa49bd9425cf.md) в сочетании с типом серии данных `ВоронкообразнаяСерияДиаграммы`. Для построения круговой диаграммы используется компонент интерфейса [«КруговаяДиаграмма»](../interface/pie-chart-component-8d4b05819515.md) в сочетании с типом серии данных `КруговаяСерияДиаграммы`.

Алгоритм построения вышеупомянутых диаграмм схож и состоит из нескольких основных этапов. Далее разберем эти шаги подробно на примере построения линейно-столбчатой диаграммы.

## Построение линейно-столбчатой диаграммы в системе координат XY

Приступим к созданию графика. Создадим форму и поместим в нее компонент `XYДиаграмма`. Описание YAML может выглядеть следующим образом:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Имя: Диаграммы
Id: 52cb4c45-8bb4-472f-bbc0-2e8895d13c97
ОбластьВидимости: ВПроекте
Наследует:
    Тип: Форма
    Заголовок: Диаграммы
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Компоновка: Вертикальная
            Заголовок: Линейно-столбчатая диаграмма без групп
            Высота: 600
            Ширина: 800
            Содержимое:
                -
                    Тип: XYДиаграмма<Диаграммы.СтруктураСтолбчатойДиаграммы, СтолбчатаяСерияДиаграммы|ЛинейнаяСерияДиаграммы>
                    Имя: СтолбцыИЛинии
```

В обработчике **ПослеСоздания** зададим метод, который будет формировать диаграмму и заполнять ее данными:

### Шаг №1

В первую очередь следует определить структуру, которую в дальнейшем вы будете использовать для заполнения данных диаграммы. Например:

```xbsl
@ВПодсистеме
структура СтруктураСтолбчатойДиаграммы
    пер Категория: Число
    пер ФорматКатегория: Строка
    пер Значение1: Число
    пер ФорматЗначение1: Строка
    пер Значение2: Число
    пер ФорматЗначение2: Строка
    пер Значение3: Число
    пер ФорматЗначение3: Строка
    пер Маркер: Строка
    пер Цвет: Цвет?
;
```

### Шаг №2

Далее следует получить компонент типа `XYДиаграмма` и сохранить его в переменную:

```xbsl
пер Диаграмма: XYДиаграмма<СтруктураСтолбчатойДиаграммы, СтолбчатаяСерияДиаграммы|ЛинейнаяСерияДиаграммы> = Компоненты.СтолбцыИЛинии
```

### Шаг №3

Затем необходимо сформировать оси X и Y. Важно помнить, что числовых осей может быть несколько, однако категориальная ось — лишь одна. К примеру, можно сформировать две числовые оси Y:

```xbsl
// Формируем левую ось Y
пер ЛеваяОсьY: ЧисловаяОсьДиаграммы = новый ЧисловаяОсьДиаграммы()
Диаграмма.ОсиY.Добавить(ЛеваяОсьY)

// Формируем правую ось Y
пер ПраваяОсьY: ЧисловаяОсьДиаграммы = новый ЧисловаяОсьДиаграммы()
ПраваяОсьY.ИнвертироватьРасположение = Истина
Диаграмма.ОсиY.Добавить(ПраваяОсьY)

// Формируем ось X
пер ОсьX: КатегориальнаяОсьДиаграммы = новый КатегориальнаяОсьДиаграммы()
ОсьX.ПолеДанных.ПолеЗначения = "Категория"
ОсьX.ПолеДанных.ОтображаемоеЗначение = "ФорматКатегория"
Диаграмма.ОсиX.Добавить(ОсьX)
```

Следующим шагом следует сформировать источник данных диаграммы:


### Шаг №5

Затем необходимо сформировать серии данных. Серия данных — это массив элементов (в самом простом варианте — массив чисел), которые будут отображаться на диаграмме. Тип серии данных определяет способ визуализации этих данных. На одну диаграмму можно добавлять одновременно несколько серий данных. Для каждого типа диаграмм предназначен соответствующий тип серии:

- XYДиаграмма
  
  —
  
  `ЛинейнаяСерияДиаграммы`
  
  ,
  
  `ПузырьковаяСерияДиаграммы`
  
  ,
  
  `СтолбчатаяСерияДиаграммы`
  
  (на одну XY-диаграмму можно добавлять различные серии одновременно)
- ВоронкообразнаяДиаграмма
  
  —
  
  `ВоронкообразнаяСерияДиаграммы`
- КруговаяДиаграмма
  
  —
  
  `КруговаяСерияДиаграммы`

Для примера сформируем одну столбчатую и одну линейную серии диаграммы:

```xbsl
// Формируем столбчатую серию
пер СтолбчатаяСерияДиаграммы1: СтолбчатаяСерияДиаграммы = новый СтолбчатаяСерияДиаграммы()
СтолбчатаяСерияДиаграммы1.Имя = "Товары"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Ключ.ПолеЗначения = "Категория"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Ключ.ОтображаемоеЗначение = "ФорматКатегория"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Значение.ПолеЗначения = "Значение1"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Значение.ОтображаемоеЗначение = "ФорматЗначение1"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Цвет = "Цвет"
СтолбчатаяСерияДиаграммы1.ПоляДанных.Маркер = "ФорматЗначение1"
СтолбчатаяСерияДиаграммы1.Ось = ЛеваяОсьY
Диаграмма.Серии.Добавить(СтолбчатаяСерияДиаграммы1)

// Формируем линейную серию
пер ЛинейнаяСерияДиаграммы1: ЛинейнаяСерияДиаграммы = новый ЛинейнаяСерияДиаграммы()
ЛинейнаяСерияДиаграммы1.Имя = "Услуги"
ЛинейнаяСерияДиаграммы1.ОтображатьВЛегенде = Истина
ЛинейнаяСерияДиаграммы1.ПоляДанных.Ключ.ПолеЗначения = "Категория"
ЛинейнаяСерияДиаграммы1.ПоляДанных.Ключ.ОтображаемоеЗначение = "ФорматКатегория"
ЛинейнаяСерияДиаграммы1.ПоляДанных.Значение.ПолеЗначения = "Значение2"
ЛинейнаяСерияДиаграммы1.ПоляДанных.Значение.ОтображаемоеЗначение = "ФорматЗначение2"
ЛинейнаяСерияДиаграммы1.ПоляДанных.Цвет = "Цвет"
ЛинейнаяСерияДиаграммы1.ПоляДанных.Маркер = "Маркер"
ЛинейнаяСерияДиаграммы1.Ось = ПраваяОсьY
Диаграмма.Серии.Добавить(ЛинейнаяСерияДиаграммы1)
```
