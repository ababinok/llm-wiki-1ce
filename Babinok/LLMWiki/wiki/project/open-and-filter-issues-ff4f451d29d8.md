## Обзор

Чтобы открыть список задач для конкретного проекта, в панели управления на вкладке **Проекты** нажмите на нужный проект и перейдите на вкладку **Задачи**.

## Документированный контракт и примеры

Чтобы открыть список задач для конкретного проекта, в панели управления на вкладке **Проекты** нажмите на нужный проект и перейдите на вкладку **Задачи**.

Список задач проекта на вкладке «Задачи»: поиск по названию или номеру и переключатели статусов «Все», «Открыта», «В работе», «На проверке», «Выполнена», «Закрыта». [Описание иллюстрации](../../raw/figures/2d9e24fefd159cdcc9ff45bc972015a42bb5001b9ee92cc18a4d3d0188b0f424-8509ca9b9b3d260c.md)

Если вы хотите отобразить список задач по всем проектам, в панели управления нажмите **Разработка** ⟶ **Задачи**.



## Фильтрация списка задач

Используйте кнопки в верху списка задач, чтобы отфильтровать задачи по статусу:

В верхней части списка задач выделена строка переключателей фильтрации: «Все», «Открыта», «В работе», «На проверке», «Выполнена», «Закрыта», «Только мои», «Я проверяю». [Описание иллюстрации](../../raw/figures/4af99d8275a2aa479dd829b0df2a95cb634182661ddac89ba8ffc705a0981426-61b5b1395fa40cad.md)

Для более гибкой настройки условий отбора нажмите кнопку **Фильтры** в правой верхней части экрана. Вы можете фильтровать задачи по проектам, приложениям, статусу, дате создания, авторам, меткам и т. д.

Пример панели фильтрации задач: в поле Проект раскрыт список проектов с отметкой выбранного проекта. [Описание иллюстрации](../../raw/figures/286aec147fb7a7522d4873cf6200123a9b08bda4e4a155896613f13429d35570-ea3abaac02f60db3.md)
