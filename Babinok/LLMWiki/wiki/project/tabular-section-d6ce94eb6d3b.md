Табличная часть — это вложенная таблица, предназначенная для хранения вместе с каждой сущностью однородной по своей структуре информации.

## Документированный контракт и примеры

Табличная часть — это вложенная таблица, предназначенная для хранения вместе с каждой сущностью однородной по своей структуре информации. Количество строк такой информации заранее неизвестно и может быть разным для разных элементов данных.

Например, справочник **Заказы** вместе с каждым элементом (заказом) может хранить состав заказа: товар, его количество и цену. В одном заказе может быть три товара, в другом — два, а в третьем — четыре товара.
