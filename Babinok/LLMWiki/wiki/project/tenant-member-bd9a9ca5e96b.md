## Обзор

Участник абонента — пользователь, наделенный определенными правами в рамках абонента.

## Документированный контракт и примеры

Участник абонента — пользователь, наделенный определенными правами в рамках абонента. Каждый участник связан с абонентом через роль, которая определяет уровень доступа к пространствам, проектам и приложениям.

Роль **Участник** предоставляет ограниченный доступ. Пользователь с этой ролью может взаимодействовать только с теми пространствами абонента, в которые он был явно добавлен. Доступ к другим частям абонента для такого пользователя закрыт, если не предоставлено явное право.
