## Документированный контракт и примеры

«1С:Предприятие.Элемент» содержит стандартную библиотеку картинок. Эти картинки можно использовать для оформления кнопок и других компонентов интерфейса.

Картинки доступны как обычные ресурсы по квалифицированному имени `Стд::имя-ресурса` или по неквалифицированному.

Например, в компоненте интерфейса их можно использовать следующим образом:

```yaml
Тип: Кнопка 
      Заголовок: Вызов картинки через Стд 
      Изображение: Стд::Аккаунт.svg
   -
      Тип: Кнопка 
      Заголовок: Вызов картинки без указания пространства имен тоже возможен 
      Изображение: Аккаунт.svg 
```

В коде их можно использовать следующим образом:

```xbsl
метод ПолучитьКартинкуГрузовикаАнг(): ДвоичныйОбъект.Ссылка
   возврат Ресурс{Стд::Грузовик.svg}.Ссылка 
; 
```
