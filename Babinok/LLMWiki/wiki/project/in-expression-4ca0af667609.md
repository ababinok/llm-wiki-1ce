## Обзор

Выражение `В` позволяет проверить, входит ли значение в указанный список.

## Документированный контракт и примеры

Выражение `В` позволяет проверить, входит ли значение в указанный список.

```xbql
ВЫБРАТЬ
    Сотрудники.Ссылка КАК Ссылка,
    Сотрудники.ФИО КАК ФИО
ИЗ
    Сотрудники КАК Сотрудники
ГДЕ
    Сотрудники.Код В (1, 2, 3)
```

```xbql
ГДЕ
    Сотрудники.Код В (&Коды)
```

```xbql
ГДЕ
    Сотрудники.Код В (&Коды1, &Коды2, 42, &ДополнительныйКод)
```

Синтаксис выражения `В`:

```xbql
проверяемое-значение [НЕ] В (список-значений | запрос-на-выборку-данных)
```

## Ограничения

Для выражения действуют следующие ограничения:

- элемент списка не может быть выражением
  
  `В`
  
  ,
- если в списке больше 128 значений, в нем допускаются только константы и параметры.

> [!NOTE] примечание
> Если в списке больше 128 значений, выражение можно заменить на эквивалентное с использованием временной таблицы.

## Использование выражения «В» с подзапросом для выражений составного типа

Не рекомендуется использовать вариант `В` с подзапросом для выражений составного типа: он неэффективно реализован на большинстве СУБД. Вместо этого рекомендуется использовать выражение [`СУЩЕСТВУЕТ`](exists-expression-96fd1b953866.md). Например, пусть `Объект` составного типа. Тогда:

Правильно. [Описание иллюстрации](../../raw/figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbql
СУЩЕСТВУЕТ (
    ВЫБРАТЬ
        1
    ИЗ
        ТаблицаФильтр КАК Ф
    ГДЕ
        Ф.Объект = Т.Объект
)
```

Неправильно. [Описание иллюстрации](../../raw/figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbql
Т.Объект В (
    ВЫБРАТЬ
        Ф.Объект
    ИЗ
        ТаблицаФильтр КАК Ф
)
```
