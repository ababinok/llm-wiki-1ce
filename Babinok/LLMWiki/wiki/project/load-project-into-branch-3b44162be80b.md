## Обзор

«1С:Предприятие.Элемент» поддерживает возможность загрузить файл или сборку проекта в [новую](load-project-into-branch-3b44162be80b.md) или [существующую ветку](load-project-into-branch-3b44162be80b.md), что позволит вам заменить содержимое данной ветки.

## Документированный контракт и примеры

«1С:Предприятие.Элемент» поддерживает возможность загрузить файл или сборку проекта в [новую](load-project-into-branch-3b44162be80b.md) или [существующую ветку](load-project-into-branch-3b44162be80b.md), что позволит вам заменить содержимое данной ветки.

## Загрузить файл проекта при создании новой ветки

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. На вкладке **Ветки** нажмите **+ Новая ветка** и выберите тип ветки в выпадающем меню.
4. В [окне создания ветки](create-branch-without-issue-f26ca9ffbcab.md) активируйте настройку **Загрузить файл проекта** и выберите файл или сборку проекта для загрузки. Допустимые форматы: *.xasm*, *.xlib*, *.xprj*, *.xsas* и *.zip*.
  
  Выбор файла проекта для загрузки [Описание иллюстрации](../../raw/figures/b275c0764b1ebb17996ac81131e723e06e9534a0f7e979b80eaa95167495a32d-3d0cdbfa8598d6bf.md)
5. Введите сообщение коммита и нажмите **Создать ветку**. Новая ветка будет создана по содержимому выбранного файла проекта.
  
  

## Загрузить файл проекта в существующую ветку

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. Перейдите на вкладку **Ветки**, нажмите на значокПиктограмма «Значок меню». [Описание иллюстрации](../../raw/figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для нужной ветки и выберите пункт **Загрузить файл проекта** в выпадающем меню.
  
  Выбор пункта «Загрузить файл проекта» в меню ветки [Описание иллюстрации](../../raw/figures/d3e9c5f49b7d9e5fcf9e61a1a99244ba16730252579a812935e81c0b617b8b82-d45e3a273aab9faa.md)
4. В открывшемся окне выберите файл или сборку проекта для загрузки. Допустимые форматы: *.xasm*, *.xlib*, *.xprj*, *.xsas* и *.zip*.
  
  Выбор файла проекта для загрузки [Описание иллюстрации](../../raw/figures/afc0cf9c7bac870cb9fb8cd06c7e1065af42a6485c5576052eb4541b66488767-c735921357592a76.md)
5. Введите сообщение коммита и нажмите **Загрузить**.
  
  Форма загрузки проекта из файла: выбрана ветка, заполнено сообщение коммита, действие подтверждается кнопкой «Загрузить». [Описание иллюстрации](../../raw/figures/39d341cd948dd6b27dee12221a3c33f2b939a1600b602bb522942255c23d6a94-ccfb14aa8afbd61c.md)
