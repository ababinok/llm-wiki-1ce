## Обзор

Команда выполняется при переключении своего состояния.

## Документированный контракт и примеры

Команда выполняется при переключении своего состояния. Отображается в виде картинки и заголовка, которые показывают состояние команды. Используется, например, для переключения представлений компонентов на форме ([подробнее](../language/switchable-command-71037e8e27ae.md)).

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../language/modular-development-80166cfecf93.md).

---

#### ИзображениеАктивного

```yaml
ИзображениеАктивного: Url|ДвоичныйОбъект.Ссылка|?
```

Ссылка на картинку, которая будет показана для активной команды.

---

#### ИзображениеНеактивного

```yaml
ИзображениеНеактивного: Url|ДвоичныйОбъект.Ссылка|?
```

Ссылка на картинку, которая будет показана для неактивной команды.

---

#### ПредставлениеАктивного

```yaml
ПредставлениеАктивного: Строка|СсылкаНаЛокализованнуюСтроку
```

Строка, которая будет показана как заголовок активной команды.

---

#### ПредставлениеНеактивного

```yaml
ПредставлениеНеактивного: Строка|СсылкаНаЛокализованнуюСтроку
```

Строка, которая будет показана как заголовок неактивной команды.

---

#### Видимость

```yaml
Видимость: Булево
```

Управляет видимостью команды. Если `Ложь`, команда скрыта в интерфейсе.

---

#### Доступность

```yaml
Доступность: Булево
```

Управляет доступностью команды. Если `Ложь`, команда недоступна для выполнения.

---

#### Активна

```yaml
Активна: Булево
```

Управляет отображением команды. Для активной команды применяются свойства [ИзображениеАктивного](../interface/switchablecommand-ru-3acc18feae98.md) и [ПредставлениеАктивного](../interface/switchablecommand-ru-3acc18feae98.md). Для неактивной команды применяются свойства [ИзображениеНеактивного](../interface/switchablecommand-ru-3acc18feae98.md) и [ПредставлениеНеактивного](../interface/switchablecommand-ru-3acc18feae98.md).

---

#### Важность

```yaml
Важность: Низкая|Обычная|Высокая
```

Определяет приоритет при отображении нескольких команд. Например, команда с важностью **Низкая** будет отображаться в выпадающем меню **Еще**. Возможные значения:

- Высокая
  
  ,
- Обычная
  
  ,
- Низкая
  
  .

---

#### НастройкиТипа

```yaml
НастройкиТипа: 
    Контракты: Строка[]
```

Имена [контрактов типа](../language/type-contract-ab9f0932850d.md), которые реализует данный компонент.

#### ОпасностьДействия


Определяет опасность действия, совершаемого пользователем. Например, может ли нажатие на кнопку привести к удалению данных. Возможные значения:

- Средняя
  
  ,
