## Обзор

Контракт типа предназначен для описания свойств и программного интерфейса у некоторых элементов проекта.

## Документированный контракт и примеры

Контракт типа предназначен для описания свойств и программного интерфейса у некоторых элементов проекта.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### ОбластьРеализации

```yaml
ОбластьРеализации: ОбластьВидимости
```

Определяет область, в которой можно создавать элементы, реализующие контракт. Может принимать следующие значения:

- Глобально
  
  — элементы можно создавать глобально, во всех проектах;
- ВПроекте
  
  — элементы можно создавать в проекте, которому принадлежит контракт;
- ВПодсистеме
  
  — элементы можно создавать в подсистеме, которой принадлежит контракт.

```yaml

```

[Окружение](context-60cdcec65127.md), в котором доступен элемент проекта: **Клиент**, **Сервер**, **КлиентИСервер**.

---

#### НастройкиТипа

```yaml
НастройкиТипа: 
    Контракты: Строка[]
```

Содержит типы контрактов типа. Указанные типы становятся базовыми для типа, порожденного по текущему элементу.
