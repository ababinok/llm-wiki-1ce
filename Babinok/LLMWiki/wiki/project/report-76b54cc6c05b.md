## Документированный контракт и примеры

Используется для создания и отображения [отчетов](create-report-b99954f7595c.md).

ПросмотрОтчета показывает «Отчет о продажах»: сверху команды Открыть, Обновить и значок настроек; ниже столбчатая диаграмма. Ось Y — Сумма сделок, ось X — Услуга. Синие и жёлтые столбцы соответствуют двум сериям; их подписи в легенде обрезаны («Разработка и продвижение са…», «Разработка мобильных прило…»). Видимые подписи значений: 64 000, 105 000, 131 000, 133 000, 178 000, 235 000, 340 000; у первого синего столбца значение не подписано. Имена услуг частично обрезаны и не восстановлены. [Описание иллюстрации](../../raw/figures/c93765b36c944b74c7b3d4e331b3c17468c4624a995c4d5e96c4130f4a31b1f3-45620458b1f4b223.md)

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

Название отчета / панели отчетов.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../language/modular-development-80166cfecf93.md).

---

#### ВидИсточникаДанных

```yaml
ВидИсточникаДанных: ВидИсточникаДанныхОтчета
```

Вид источника данных для отчета. Может принимать следующие значения:

- Таблица
  
  (значение по умолчанию) — таблица, указанная в свойстве
  
  [ИсточникДанных](report-76b54cc6c05b.md)
  
  ;
- Запрос
  
  — произвольный запрос (
  
  [пример](../queries/use-query-to-create-report-3cf7e26dbbbc.md)
  
  ).

---

#### ИсточникДанных

```yaml
ИсточникДанных: Строка
```

Имя таблицы источника данных для отчета. В качестве источника данных могут выступать таблицы языка запросов, порождаемые элементами проекта (таблицы справочника, документа, регистра сведений и т. д.), а также [виртуальные таблицы](use-virtual-table-to-create-report-89c726b4186d.md).

Если в качестве источника данных выступает [запрос](../queries/use-query-to-create-report-3cf7e26dbbbc.md), то задавать значение свойства **ИсточникДанных** не нужно.

---

#### Описание

```yaml
Описание: Строка
```

Описание отчета / панели отчетов. По умолчанию — пустая строка.

---

#### Интерфейс

```yaml
Интерфейс: 
    ВключатьВАвтоИнтерфейс: Булево
    Форма: Строка
    Изображение: ДвоичныйОбъект.Ссылка?
```

Группа свойств, которые описывают пользовательский интерфейс отчета / панели отчетов.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды открытия формы в [автоматический интерфейс](../interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Форма

Имя объекта конфигурации, являющегося формой данного отчета / панели отчетов. Форма должна наследовать тип [ФормаОтчета](../interface/reportform-ru-a6c5b64077dc.md). Если значение не указано, то используется автоматически сгенерированная форма.

##### Изображение

Задает картинку для команды открытия формы.

</details>

## Дочерние элеметы

#### ПараметрыЗапроса

```yaml
ПараметрыЗапроса: ПараметрОтчета[]
```

Параметры запроса. Свойство может быть пустым, если [запрос](../queries/use-query-to-create-report-3cf7e26dbbbc.md), выступающий в качестве источника данных для отчета, не содержит параметров.

В свойстве должны быть указаны все параметры, используемые в запросе. Недопустимо указывать параметры, которые отсутствуют в тексте запроса.

---

#### Макет

```yaml
Макет: МакетОтчета
```

Содержит описание макета отчета. Описание макета формируется автоматически при редактировании отчета в дизайнере «1С:Аналитики», встроенном в среду разработки.
