Роль: Элемент проекта.

Имена для поиска: `НаборКонстант`, `ConstantsSet`, `Std::ProjectElements::ConstantsSet`.

## Обзор

[НаборКонстант](constants-set-element-3c8e873b235a.md) предназначен для хранения постоянной или условно-постоянной информации, которая либо совсем не изменяется в процессе работы приложения, либо изменяется достаточно редко.

## Документированный контракт и примеры

[НаборКонстант](constants-set-element-3c8e873b235a.md) предназначен для хранения постоянной или условно-постоянной информации, которая либо совсем не изменяется в процессе работы приложения, либо изменяется достаточно редко.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

[КонстантаНабораКонстант](constantssetconstant-ru-45869cdd5275.md), значение которой «1С:Предприятие.Элемент» будет использовать в качестве представления экземпляра набора констант.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../language/modular-development-80166cfecf93.md).

#### Периодичность

```yaml
Периодичность: Непериодический|День|Месяц|Квартал|Год
```

Если значение этого свойства задано и отлично от **Непериодический**, указывает минимальную периодичность, с которой могут изменяться значения набора констант:

- День
  
  — раз в день (тип
  
  `Дата`
  
  );
- Месяц
  
  — раз в месяц (тип
  
  `Дата`
  
  );
- Квартал
  
  — раз в квартал (тип
  
  `Дата`
  
  );
- Год
  
  — раз в год (тип
  
  `Дата`
  
  ).

#### Интерфейс

```yaml
Интерфейс: 
    ВключатьВАвтоИнтерфейс: Булево
    Список: 
        Представление: Строка|СсылкаНаЛокализованнуюСтроку
        Изображение: ДвоичныйОбъект.Ссылка?
        Форма: Строка
    Запись: 
        Представление: Строка|СсылкаНаЛокализованнуюСтроку
        Изображение: ДвоичныйОбъект.Ссылка?
        Форма: Строка
```

Группа свойств, которые описывают пользовательский интерфейс элемента проекта.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды в [автоматический интерфейс](../interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Список

Секция, которая содержит описание, влияющее на автоматически генерируемую форму списка и команду `ОткрытьСписок`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой списка для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

##### Запись

Секция, которая содержит описание, влияющее на автоматически генерируемую форму записи и команду `СоздатьЗапись`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой объекта для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

</details>

#### КонтрольДоступа

```yaml
КонтрольДоступа: 
    Разрешения: 
        ПоУмолчанию: КонтрольДоступа
        Чтение: КонтрольДоступа
        Изменение: КонтрольДоступа
```

[Описание прав](../security/project-element-permissions-12c1d76e1615.md) на набор констант.

<details>
<summary>**Свойства**</summary>

##### Разрешения

Набор разрешений на выполнение основных операций с набором констант.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Чтение

Задает разрешение на чтение записи набора констант из базы данных. Проверяется только в момент загрузки ключа записи из базы данных.

##### Изменение

Задает разрешение на изменение записи набора констант, хранящейся в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

</details>

</details>

#### ПараметрыЗаписи

```yaml
ПараметрыЗаписи: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать запись объекта. В обработчики `ПередЗаписью()`, `ПослеЗаписи()` и перегрузку метода `Записать()` добавляются соответствующие параметры. Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Множество типов, доступных для параметра.

</details>

---

#### ПараметрыУдаления

```yaml
ПараметрыУдаления: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать удаление объекта. В обработчики `ПередУдалением()`, `ПослеУдаления()` и перегрузку метода `Удалить()` добавляются соответствующие параметры. Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
<summary>**Свойства**</summary>

</details>
