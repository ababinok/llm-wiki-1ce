## Документированный контракт и примеры

Главный сценарий групповой разработки — это работа в облаке «1С:Предприятие.Элемента». В этом случае все необходимое программное обеспечение уже подключено и настроено на серверах провайдера.

Если вы используете локальную установку «1С:Предприятие.Элемента», то вы должны самостоятельно установить и настроить требуемое программное обеспечение.

Основным инструментом групповой разработки является система контроля версий Git. [Установите](git-installation-9f5d34603556.md) ее на компьютер сервера. После этого вам станут доступны функции [работы с Git-репозиториями](collaborative-development-c0bea647f5a3.md) — например, подключение существующих репозиториев, добавление коммитов, создание веток и другие возможности.

Чтобы использовать возможности управления [внутренними репозиториями](collaborative-development-c0bea647f5a3.md) через панель управления, [подключите](connect-to-gitlab-daf8c8c732dc.md) к серверу систему управления репозиториями. Это может быть облачный сервис или локальный GitLab, [установленный](gitlab-installation-48e5e0c558d7.md) в вашей организации. Это позволит создавать и настраивать репозитории через панель управления, упрощая совместную работу.

## Системы управления репозиториями

«1С:Предприятие.Элемент» поддерживает только систему управления репозиториями [GitLab](https://about.gitlab.com/).

К серверу можно подключить несколько экземпляров GitLab. Для создания репозиториев «1С:Предприятие.Элемент» будет автоматически выбирать экземпляр с наименьшей загруженностью по количеству репозиториев.

Подключенные экземпляры можно [переводить в режим обслуживания](../data/enable-maintenance-mode-for-gitlab-repository-c10f3196f158.md). В этом случае они временно не будут использоваться для создания репозиториев. Это может быть полезно для устранения неполадок в работе экземпляра.

## Работа с внутренними репозиториями через панель управления

Весь основной функционал групповой разработки находится в панели управления на вкладке проекта.

На вкладке «Задачи» проекта панели управления показаны ветки и приложения разработки для разных задач; основной интерфейс групповой разработки расположен на странице проекта. [Описание иллюстрации](../../raw/figures/eb8d14ee30d77f78ab49238479db8b633ab548a2b32cead8c9a64d81fcc5d517-d5172209b7787980.md)

Сначала [настройте групповую разработку](set-up-collaborative-development-62562bbfba3b.md) в проекте. Затем вы можете [добавить в проект разработчиков](add-developer-f3519932fdbf.md) — пользователей панели управления, которые будут участвовать в разработке проекта.

После этого вы можете [создать задачи](create-issue-57a918108fb3.md) для разработки функциональности приложения.

Когда вы [приступите к работе над задачей](open-issue-in-ide-c8f61e972a3d.md), «1С:Предприятие.Элемент» предложит вам создать новую ветку для разработки задачи и новое приложение для отладки кода.

Выполненную задачу можно [отправить на проверку](send-issue-for-review-2c33171c9ea1.md) другому разработчику.

После выполнения вы [включаете](close-and-merge-issue-into-main-branch-a6c1a1715412.md) задачу в основную ветку проекта. При необходимости [разрешаете конфликт слияния](resolve-merge-conflict-161f4ec5c6c5.md).

Когда работа над задачами окончена, ваш программный продукт прошел тестирование и готов к выпуску, вы можете указать стабильную [сборку проекта](project-assemblies-22705683fda4.md), содержащую все необходимые изменения, как [релизную](create-or-cancel-release-89b0fc793f03.md). Выпущенный релиз станет доступен пользователям для создания, обновления и модификации приложений.

## Совместная разработка

«1С:Предприятие.Элемент» предоставляет возможность одновременной совместной разработки одного проекта несколькими разработчиками в общей среде разработки. При совместной разработке разработчики могут одновременно редактировать код, просматривать изменения в реальном времени и взаимодействовать через встроенные в среду разработки инструменты ([подробнее](collaborative-development-in-ide-6dac91729e4e.md)).

> [!NOTE] дополнительно
> В текущей версии совместная разработка доступна только в [редакторе текстовых файлов](../interface/ide-overview-and-basic-actions-969a6e6501a6.md).

Совместное редактирование модуля ПечатьДокумента: жёлтым и зелёным выделены участки разных участников. В строке состояния видны значки участников; справа панель Структура. Жёлтый участок содержит просьбу другому разработчику, зелёный — метод формирования строки товара. Фрагмент учебного кода, видимый целиком (другие строки на снимке — конец предыдущего метода): [Описание иллюстрации](../../raw/figures/c9e1bb431e81903a61c871c75e7313e2592a944c7577b3e0bc6a266d4a4e8ef4-30a33f0f41a5e983.md)
