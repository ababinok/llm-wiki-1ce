## Обзор

Элемент **Описание проекта** содержит описание основных свойств проекта приложения.

## Документированный контракт и примеры

Элемент **Описание проекта** содержит описание основных свойств проекта приложения. «1С:Предприятие.Элемент» автоматически создает такой элемент в новом проекте. Он расположен в самом верху проекта.

> [!WARNING] предупреждение
> При заполнении свойств проекта соблюдайте [обязательный стандарт](project-properties-standard-370cc77fc2b0.md).

## Свойства

#### ВидПроекта

```yaml
ВидПроекта: ВидПроекта
```

Описывает вид проекта: [Приложение](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-new-application-in-control-panel/), [Библиотека](create-library-project-7aaf759c2627.md) или [Расширение](extension-overview-baac93654940.md).

#### Поставщик

`Версия 4.0 и выше`

```yaml
Поставщик: Строка
```

Имя, уникально идентифицирующее поставщика проекта — организацию или группу разработчиков, которая занимается разработкой и поддержкой проекта, а также обладает авторскими правами на него. Задается в соответствии с [правилами заполнения свойств проекта](project-properties-standard-370cc77fc2b0.md).

---

#### Имя

`Версия 4.0 и выше`

```yaml
Имя: Строка
```

Имя проекта. Задается в соответствии с [правилами заполнения свойств проекта](project-properties-standard-370cc77fc2b0.md).

#### РежимСовместимости

```yaml
РежимСовместимости: Строка
```

Одна из предыдущих версий конфигурации сервера, которую можно выбрать для запуска приложения на текущей версии сервера. Позволяет сохранить поведение соответствующих элементов проекта при переходе на новую версию.

Свойство **РежимСовместимости** настраивается следующим образом:

- Допускается указывать режим совместимости, соответствующий старой версии технологии (не ниже версии 6.0). В таком режиме технология ведет себя как указанная версия:
  
  - работают старые названия методов, свойств и типов;
  - работают устаревшие формы API;
  - поведение системы соответствует указанной версии технологии.
- Настройки режима совместимости должны совпадать с настройками приложений и всех библиотек (в том числе транзитивных).
- Запрещается понижать режим совместимости. После публикации на сервере приложения с режимом совместимости
  
  N
  
  публикация с настройкой
  
  N-1
  
  невозможна.

При переходе на новую версию конфигурации сервера часть функциональности может быть помечена аннотацией [Устарело](../stdlib/deprecated-ru-ac9527c3202f.md).

#### РасширяемыеПроекты

`Версия 10.0 и выше`

```yaml
РасширяемыеПроекты: 
    -
        Имя: Строка
        Поставщик: Строка
        Версии: 
            От: 
                Версия: Строка
                Включать: Булево
            До: 
                Версия: Строка
                Включать: Булево
```

Доступно для проектов вида [Расширение](projectkind-ru-82cc169ccc4f.md). Проекты, в которых используется данное расширение.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя расширяемого проекта.

##### Поставщик

Имя поставщика расширяемого проекта.

##### Версии

Диапазон версий расширяемого проекта, для которых применимо данное расширение. Если свойство не указано, расширение применяется к любой версии расширяемого проекта.

<details>
<summary>**Свойства**</summary>

##### От

Нижняя граница диапазона версий.

<details>
<summary>**Свойства**</summary>

##### Версия

Значение версии, определяющее границу диапазона.

##### Включать

Определяет, включается ли указанная версия в допустимый диапазон.

- `Истина`
  
  — граница входит в диапазон.
- `Ложь`
  
  — граница не входит в диапазон.

По умолчанию: `Истина`.

</details>

##### До

Верхняя граница диапазона версий.

КлиентскоеПриложениеСамостоятельнойРегистрации: Строка

---

#### ОбновлениеСВерсии

```yaml
ОбновлениеСВерсии: Строка
```

Минимальная версия, с которой можно применить обновление на текущий проект. Значение **ОбновлениеСВерсии** должно быть не больше, чем значение **Версия**.

---

#### ПользовательскиеСоглашения

```yaml
ПользовательскиеСоглашения: Ссылка|Ресурс[]
```

Массив пользовательских соглашений, отображаемых при входе или регистрации и доступных по ссылке в нижней части формы. Указание соглашений для проекта [библиотеки](create-and-use-libraries-38193c200df0.md) не допускается.

---

#### ПредставлениеПоставщика

```yaml
ПредставлениеПоставщика: Строка
```

Название организации или группы разработчиков, которая занимается разработкой и поддержкой проекта, а также обладает авторскими правами на него. Во время работы приложения «Элемент» отображает его в диалоге **О приложении**.

---

#### ЯзыкиЛокализации

```yaml
ЯзыкиЛокализации: Язык[]
```

Языки, для которых есть перевод интерфейса этого приложения.

---

#### ЯзыкПоУмолчанию

```yaml
ЯзыкПоУмолчанию: Язык
```

Язык, который будет использовать приложение в том случае, если язык пользователя не поддерживается приложением.

---

#### ЯзыкРазработки

`Версия 5.0 и выше`

```yaml
ЯзыкРазработки: ЯзыкРазработки
```

Язык, на котором ведется разработка проекта.
