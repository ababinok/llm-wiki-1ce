## Литералы

#### ИзКонструктора

Значение по умолчанию. Важность события задается в конструкторе.

---

#### Обычная

Протоколирование в журнале свершившегося факта. Такое событие:

- обычно не требует реакции;
- фиксирует произошедший факт;
- может быть полезно для анализа журнала.

---

#### Максимальная

Самый высокий уровень значимости. Такое событие:

- требует скорейшей реакции;
- оказывает существенное влияние на работу приложения;
- необходимо для анализа журнала (содержит критичные сведения).

---

#### Высокая

Отражение в журнале существенных событий. Такое событие:

- не требует немедленной реакции;
- оказывает существенное влияние на работу приложения;
- необходимо для анализа журнала (содержит важные сведения).

---

#### Низкая

Cамый низкий уровень значимости. Такое событие:

- Не требует реакции. Например, уточняет другое событие (расширяет, расшифровывает и т. д. — то есть фиксирует дополнительную информацию в определенных случаях).
- Может использоваться для отладки и трассировки.
- Событие имеет смысл на ограниченный период времени или для ограниченного круга заинтересованных лиц:
  
  - быстро теряет свою актуальность;
  - может содержать специфическую информацию;
  - как правило, не предназначено для длительного регулярного использования.
