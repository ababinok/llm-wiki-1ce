## Документированный контракт и примеры

Чтобы запустить «Менеджер хостов внешних компонент», выполните следующие действия:

- Windows
- Linux

1. В строке поиска Windows введите «Службы».
2. Запустите приложение
  
  Службы
  
  (
  
  Services
  
  ).
3. Найдите в списке службу
  
  `1c-enterprise-echostmanager`
  
  .
4. Нажмите
  
  Запустить
  
  в контекстном меню.

В случае успешного запуска состояние службы изменится на **Выполняется**.



## Запуск из командной строки

В тестовых целях вы можете запускать «Менеджер хостов внешних компонент» из командной строки. Для этого выполните перечисленные ниже действия.

> [!WARNING] важно
> Пользователь операционной системы, от имени которого запускается экземпляр «Менеджера хостов внешних компонент», должен иметь полные права на [каталог экземпляра менеджера](install-external-component-host-manager-e43cb4411eb9.md) и все его подкаталоги. Кроме того, он должен иметь права чтения и записи в стандартный каталог временных файлов операционной системы.

- Windows
- Linux

1. В строке поиска Windows введите «cmd» или «Командная строка».
2. Нажмите по найденному приложению правой кнопкой мыши и выберите **Запуск от имени администратора** в контекстном меню.
3. В командной строке выполните следующую команду (указанная ниже версия менеджера может отличаться от установленной у вас версии):
  
  ```powershell
  "C:\Program Files\1C\1CE\components\1c-enterprise-echostmanager-9.1.9+17-x86_64\bin\1ce-echostmanager.exe" start --instance C:\ProgramData\1C\1CE\instances\1c-enterprise-echostmanager
  ```

В случае успеха вы увидите сообщение, что «Менеджер хостов внешних компонент» готов к использованию.
