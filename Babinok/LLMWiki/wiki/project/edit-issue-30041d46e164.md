## Документированный контракт и примеры

Вы можете отредактировать существующую задачу следующим образом:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект и переключитесь на вкладку **Задачи**, чтобы отобразить список задач для выбранного проекта. Если вы хотите открыть список задач по всем проектам, в меню панели управления нажмите **Разработка** ⟶ **Задачи**.
3. Выполните одно из следующих действий:
  
  - Кликните на задачу, которую вы хотите изменить. Появится окно, содержащее основные сведения о текущей задаче: ее название, описание, статус, метки, имя исполнителя, ссылки на ветку и приложение для разработки.
    
    Карточка задачи [Описание иллюстрации](../../raw/figures/94179ba65ac5c3ae942468370cf0f60606ea64fc1a355d3e6148e6eafa4a1d5e-59998c9e32ced4fd.md)
    
    В правом верхнем углу окна нажмите на значокПиктограмма «Значок меню». [Описание иллюстрации](../../raw/figures/eeec48637e32c4f2ec0cc9ade2b45debe2df98791c721a93c2826cace650091a-7826430e32669bbb.md) и выберите пункт **Редактировать задачу**.
    
    В меню карточки задачи выбран пункт «Редактировать задачу» для изменения её данных, включая метки. [Описание иллюстрации](../../raw/figures/377907fd391b14568d23b09e01e3f53248a7e613f122514da8bdbe0f3e6e7220-9c43691709d696f6.md)
  - Щелкните на значокПиктограмма «Значок меню». [Описание иллюстрации](../../raw/figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для нужной задачи и выберите пункт **Редактировать задачу** в выпадающем меню.
    
    В строке задачи раскрыто меню действий и выделено «Редактировать задачу». [Описание иллюстрации](../../raw/figures/4838ee8424593af4928e0d6d4023a7978ff8e2867f2459b79b5a4ee06bbcc4b8-09cc3a6a9d8921bd.md)
4. В открывшемся окне **Редактирование задачи** внесите нужные изменения и нажмите **Сохранить**.
