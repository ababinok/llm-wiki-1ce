## Методы

### ПересчитатьКлючи

`Доступность: Сервер`

```
ПересчитатьКлючи(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>? = Неопределено)
```

Пересчитывает все ключи доступа соответствующего типа для пользователей

`Пользователи`

. Если

`Неопределено`

- пересчитывает для всех пользователей.
