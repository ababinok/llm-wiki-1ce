## Методы

### ЗавершитьДругиеСеансы

`Доступность: Клиент`

```
ЗавершитьДругиеСеансы()
```

Выполняет завершение сеанса пользователя на всех устройствах, кроме текущего.

---

### ЗавершитьТекущийСеанс

`Доступность: Клиент`

```
ЗавершитьТекущийСеанс(АдресПеренаправления: Строка? = Неопределено)
```

Выполняет завершение сеанса пользователя. По завершению сеанса клиент можно перенаправить на

`АдресПеренаправления`

.

`АдресПеренаправления`

может быть как относительным URL-ом (относительно корня приложения), так и абсолютным (включает схему http(s)://...).
