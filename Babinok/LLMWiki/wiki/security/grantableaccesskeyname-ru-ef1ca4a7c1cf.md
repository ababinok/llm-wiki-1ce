## Методы

### ОтозватьКлючи

`Доступность: Сервер`

```
ОтозватьКлючи(
  Пользователи: ЧитаемаяКоллекция<Пользователи.Ссылка>|Undefined = Неопределено,
  <Параметр1>: <ТипПараметра1>,
  ....<ПараметрN>: <ТипПараметраN>)
```

Вызов возможен только с именованными параметрами.

Отзывает ключи доступа типа [ИмяВыдаваемогоКлючаДоступа.Объект](grantableaccesskeyname-object-ru-cc8812305674.md), значения параметров которых совпадают со значениями параметров, переданных в метод, для пользователей `Пользователи`. Если `Пользователи` = `Неопределено` - отзывает у всех пользователей и выполняет удаление всех записей из основной таблицы ключа доступа, содержащих экземпляры ключа доступа, значения параметров которых совпадают со значениями параметров, переданных в метод. В качестве параметров в метод могут быть переданы любые параметры, содержащиеся в [ИмяВыдаваемогоКлючаДоступа.Объект](grantableaccesskeyname-object-ru-cc8812305674.md), кроме параметров, являющихся множественными реквизитами. Все параметры передаются в именованном формате.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - если текущий пользователь не является администратором (или не включен привилегированный режим).
