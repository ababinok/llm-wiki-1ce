## Методы

### Выдать

`Доступность: Сервер`

```
Выдать(Пользователи: ЧитаемаяКоллекция<Пользователи.Ссылка>)
```

Выдает ключ доступа пользователям

`Пользователи`

.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - если текущий пользователь не является администратором (или не включен привилегированный режим).

---

### Отозвать

`Доступность: Сервер`

```
Отозвать(Пользователи: ЧитаемаяКоллекция<Пользователи.Ссылка>? = Неопределено)
```

Отзывает ключ доступа у пользователей

`Пользователи`

. Если

`Неопределено`

- отзывает у всех пользователей и выполняет удаление записи, содержащей экземпляр ключа доступа, из основной таблицы ключа доступа.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - если текущий пользователь не является администратором (или не включен привилегированный режим).
