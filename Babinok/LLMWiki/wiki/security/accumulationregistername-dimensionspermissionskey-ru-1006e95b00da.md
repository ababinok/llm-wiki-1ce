## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}.КлючРазрешенийИзмерений` `Доступность: Сервер`

Представляет собой структуру с измерениями регистра, указанными в настройке `РасчетРазрешенийПо` элемента проекта. Используется при расчёте ключей доступа на чтение записей регистра накопления - при реализации обработчика `ВычислитьДескрипторыДоступаДляЧтения` [ВычислитьКлючиДоступаДляЧтения](../data/accumulationregistername-ru-ca3f7a553094.md). Доступен только если включено управление доступом для отдельных объектов регистра.
