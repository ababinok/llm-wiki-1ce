При создании SOAP-сервиса вы можете настроить права доступа на двух уровнях:

- [на уровне SOAP-сервиса](soap-service-access-permissions-c22a942b554f.md)
  
  ;
- [на уровне отдельной операции](soap-service-access-permissions-c22a942b554f.md)
  
  .

При вызове конкретной операции проверка разрешений доступа в SOAP-сервисе будет производиться следующим образом:

- Если для операции задана группа свойств
  
  [КонтрольДоступа](../integration/servicehandler-ru-d99b0889159b.md)
  
  , то будет выполнена проверка по заранее рассчитанным разрешениям доступа для данной операции. Дальнейшие пункты не выполняются.
- Если вышеупомянутая группа свойств не задана, то проверяются общие разрешения доступа для SOAP-сервиса, заданные группой свойств
  
  [КонтрольДоступа](../integration/soapservice-33331940c1db.md)
  
  SOAP-сервиса.

> [!NOTE] дополнительно
> Если операция имеет группу свойств [КонтрольДоступа](../integration/servicehandler-ru-d99b0889159b.md) и в очередном обновлении вы изменили свойство операции [Имя](../integration/servicehandler-ru-d99b0889159b.md), то нужно обязательно вызвать перерасчет разрешений доступа для этого SOAP-сервиса в [обработчике обновления проекта](../project/update-app-data-356eca7811d0.md). В противном случае, права доступа для переименованных операций могут работать с ошибкой, так как рассчитанные разрешения доступа хранятся в разрезе имен операций.

## Настройка прав доступа для SOAP-сервиса

Чтобы настроить права доступа для вызова SOAP-сервиса в целом, следует в группе свойств SOAP-сервиса [КонтрольДоступа](../integration/soapservice-33331940c1db.md) задать необходимые [настройки прав доступа](automatically-grant-permissions-to-user-groups-c39cf49a7075.md).

Данные настройки будут распространяться на все доступные в SOAP-сервисе операции. Если необходимо настроить нестандартный расчет прав доступа, то в группе свойств [КонтрольДоступа](../integration/soapservice-33331940c1db.md) вы можете указать значение [РазрешенияВычисляются](../project/accesscontrol-ru-c40ccedbcdb4.md), а в модуле SOAP-сервиса задать обработчик, который будет выполнять расчет прав доступа.

Пример модуля SOAP-сервиса:

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа() : Массив<РазрешениеДоступа>

    знч Разрешения: Массив<РазрешениеДоступа>   // массив для возврата разрешений доступа

    // Получить экземпляры ключей доступа
    знч КлючМенеджеров = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Менеджеры)
    знч КлючРуководителей = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Руководители)

    // Создать разрешение доступа
    Разрешения.Добавить(новый РазрешениеДоступа([КлючМенеджеров, КлючРуководителей], [SoapСервисПраво.Вызов]))

    возврат Разрешения
;
```

## Настройка прав доступа для отдельной операции сервиса

Чтобы настроить права доступа для отдельной операции, следует добавить группу свойств [КонтрольДоступа](../integration/servicehandler-ru-d99b0889159b.md) у нужного обработчика в описании SOAP-сервиса.

Если необходимо настроить нестандартный расчет прав доступа, то в группе свойств [КонтрольДоступа](../integration/servicehandler-ru-d99b0889159b.md) у нужного обработчика, в свойстве [Вызов](../integration/servicehandler-ru-d99b0889159b.md), следует задать значение [РазрешенияВычисляются](../project/accesscontrol-ru-c40ccedbcdb4.md), а в свойстве [Обработчик](../integration/servicehandler-ru-d99b0889159b.md) указать имя обработчика, который будет выполнять расчет прав доступа для вызова данной операции. Код обработчика следует расположить в модуле SOAP-сервиса.

Пример модуля SOAP-сервиса:

```xbsl
метод ВычислитьРазрешенияДляОперации(): ЧитаемаяКоллекция<КлючДоступа.Объект>
    возврат [новый МойКлючДоступа.Объект()]
;
```
