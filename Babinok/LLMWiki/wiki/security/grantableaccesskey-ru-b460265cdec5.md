## Методы

### ОтозватьКлючи

`Доступность: Сервер`

```
ОтозватьКлючи(Пользователи: ЧитаемаяКоллекция<Пользователи.Ссылка>? = Неопределено)
```

Отзывает все ключи доступа соответствующего типа у пользователей

`Пользователи`

. Если

`Неопределено`

- отзывает у всех пользователей и выполняет удаление всех записей из основной таблицы ключа доступа.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - если текущий пользователь не является администратором (или не включен привилегированный режим).
