## Обзор

[Описывает объекты](document-element-0c6b898a8b13.md), которые имеют привязку ко времени и отражают некие свершившиеся факты, актуальность которых падает с течением времени.

## Документированный контракт и примеры

[Описывает объекты](document-element-0c6b898a8b13.md), которые имеют привязку ко времени и отражают некие свершившиеся факты, актуальность которых падает с течением времени.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

Реквизит документа, значение которого «1С:Предприятие.Элемент» будет использовать в качестве [представления экземпляра документа](../project/record-view-935a747731d9.md). Если реквизит отсутствует, то представление документа будет значением поля [Номер](number-ru-a0fbe7ea1b89.md).

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды в [автоматический интерфейс](../interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Список

Секция, которая содержит описание, влияющее на автоматически генерируемую форму списка и команду `ОткрытьСписок`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](../project/app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой списка для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

##### ИспользоватьСозданиеПриВводе

Определяет отображение кнопки создания элемента в выпадающем списке поля ввода ссылочного типа, если:

- не задано свойство
  
  ОтображатьКомандуСоздания
  
  в свойстве
  
  [НастройкиВводаСсылок](../interface/edit-ru-4027d1cb7b27.md)
  
  поля ввода;
- не задано свойство
  
  [ОтображатьКомандуСоздания](../interface/edit-ru-4027d1cb7b27.md)
  
  для поля ввода.

Секция, которая содержит описание, влияющее на автоматически генерируемую форму объекта и команду `СоздатьОбъект`.

<summary>**Свойства**</summary>

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](../project/app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой объекта для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

#### КонтрольДоступа

```yaml
КонтрольДоступа: 
    Разрешения: 
        ПоУмолчанию: КонтрольДоступа
        Создание: КонтрольДоступа
        Чтение: КонтрольДоступа
        Изменение: КонтрольДоступа
        Удаление: КонтрольДоступа
    РасчетРазрешенийПо: Строка[]
```

[Описание прав](../security/project-element-permissions-12c1d76e1615.md) на документ.

<details>
<summary>**Свойства**</summary>

##### Разрешения

Набор разрешений на выполнение основных операций с документом.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Создание

Задает разрешение на создание нового экземпляра документа. Проверяется непосредственно перед записью изменения в базу данных.

##### Чтение

Задает разрешение на чтение экземпляра документа из базы данных. Проверяется только в момент загрузки ссылки из базы данных.

##### Изменение

Задает разрешение на изменение экземпляра документа, хранящегося в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

##### Удаление

Задает разрешение на удаление экземпляра документа. Проверяется в момент вызова удаления.

</details>

##### РасчетРазрешенийПо

Массив полей, по которым выполняется расчет разрешений доступа. Заполняется при выборе значения [РазрешенияВычисляютсяДляКаждогоОбъекта](../project/accesscontrol-ru-c40ccedbcdb4.md).

</details>

#### ПараметрыЗаписи

```yaml
ПараметрыЗаписи: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать запись объекта. В обработчики `ПередЗаписью()`, `ПослеЗаписи()` и перегрузку метода `Записать()` добавляются соответствующие параметры. Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Множество типов, доступных для параметра.

</details>

Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.
