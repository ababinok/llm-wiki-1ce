## Обзор

Операция самостоятельной регистрации по логину и паролю.

## Документированный контракт и примеры

`Стд::Пользователи::Самообслуживание::ОперацияПошаговойРегистрацииСЛогином` `Доступность: Клиент`

Операция самостоятельной регистрации по логину и паролю.

Операция выполняется пошагово (шаги 2-7 можно вызывать в любом порядке, однако шаги 6-7 могут вызываться только после отправки кода на шаге 5):

1. [Начать](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — начать операцию,
2. [УстановитьЛогин](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — установить логин,
3. [УстановитьПароль](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — установить пароль,
4. [УстановитьПараметр](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — установить пользовательский параметр,
5. [УстановитьКонтакт](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — установить контакт,
6. [ПодтвердитьКонтакт](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — подтвердить контакт,
7. [ПовторитьОтправкуКодаПодтверждения](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — вызывается опционально для повторной отправки кода,
8. [Завершить](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md)
  
  — завершить операцию.

## Методы

### Завершить

`Доступность: Клиент`

```
Завершить(СсылкаПослеРегистрации: Строка? = Неопределено): СтатусОперацииПошаговойРегистрацииСЛогином
```

Завершить регистрацию. Пользователь создается и подключается к приложению.

Если задан параметр самостоятельной регистрации пользователя, то у него вызываются следующие обработчики:

- необязательный обработчик
  
  `ПриПроверкеПараметра`
  
  (при наличии);
- обязательный обработчик
  
  `ПослеПодключения`
  
  .

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - операция не готова к завершению (см. [ОжидаемыеДанные](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md)).

---

### Начать

`Доступность: Клиент`

```
@ИменованныеПараметры
Начать(УстановкаПараметраОбязательна: Булево): СтатусОперацииПошаговойРегистрацииСЛогином
```

>

Вызов возможен только с именованными параметрами

Начать операцию. Разрешен только именованный вызов.

Если обязательный параметр `УстановкаПараметраОбязательна` принимает значение `Истина`, то в ходе операции нужно указать параметр самостоятельной регистрации пользователя. Если значение параметра равно `Ложь`, то при установке параметра самостоятельной регистрации возникнет ошибка.

---

### ПовторитьОтправкуКодаПодтверждения

`Доступность: Клиент`

```
ПовторитьОтправкуКодаПодтверждения(): СтатусОперацииПошаговойРегистрацииСЛогином
```

Повторить отправку кода подтверждения.

Пользователю будет отправлен новый код подтверждения. После отправки нового кода подтвердить операцию с помощью старого кода будет невозможно.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до отправки кода в методе [УстановитьКонтакт](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md) или до начала операции [Начать](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md).

---

### ПодтвердитьКонтакт

`Доступность: Клиент`

```
ПодтвердитьКонтакт(КодПодтверждения: Строка): СтатусОперацииПошаговойРегистрацииСЛогином
```

Подтвердить контакт с помощью кода.

Если указан неправильный код или код верный, но пользователь подтвердил неуникальный телефон, то свойство [ПредыдущийШагУспешен](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) принимает значение `Ложь`, а в свойство [Сообщение](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) записывается текст ошибки.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [УстановитьКонтакт](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md) или [Начать](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md).

---

### УстановитьЛогин

`Доступность: Клиент`

```
УстановитьЛогин(Логин: Строка): СтатусОперацииПошаговойРегистрацииСЛогином
```

Установить логин. Логин будет проверен на уникальность.

Если логин неуникальный, то свойство [ПредыдущийШагУспешен](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) принимает значение `Ложь`, а в свойство [Сообщение](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) записывается текст ошибки.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [Начать](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md).

### УстановитьПараметр

`Доступность: Клиент`

```
УстановитьПараметр(Параметр: ПараметрСамостоятельнойРегистрацииПользователя): СтатусОперацииПошаговойРегистрацииСЛогином
```

Установить пользовательский параметр регистрации. Обработчик

`ПриПроверкеПараметра`

будет вызван во время завершения операции.

Если операция начата с параметром `УстановкаПараметраОбязательна`, равным `Истина`, то вызов данного метода обязателен до завершения операции.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [Начать](stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md) или операция начата с параметром `УстановкаПараметраОбязательна`, равным `Ложь`.

---

### УстановитьПароль

`Доступность: Клиент`

```
УстановитьПароль(Пароль: Строка): СтатусОперацииПошаговойРегистрацииСЛогином
```

Установить пароль. Пароль будет проверен на соответствие политике паролей.

Если пароль не соответствует политике, то свойство [ПредыдущийШагУспешен](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) принимает значение `Ложь`, а в свойство [Сообщение](../stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md) записывается текст ошибки.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [Начать](stepwiseregistrationwithloginoperation-ru-487f14a6022d.md).
