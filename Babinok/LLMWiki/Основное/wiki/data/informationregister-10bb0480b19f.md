## Обзор

[Регистры сведений](information-register-project-element-8932693c91b1.md) используются для хранения произвольных данных в разрезе нескольких измерений, например цен товаров в разрезе номенклатуры и типа цен.

## Документированный контракт и примеры

[Регистры сведений](information-register-project-element-8932693c91b1.md) используются для хранения произвольных данных в разрезе нескольких измерений, например цен товаров в разрезе номенклатуры и типа цен.

Информацию в регистре можно представить в виде таблицы, имеющей одну или несколько колонок. По своему назначению колонки делятся на три группы:

**Измерения** — это «координаты» или значения, для которых в регистре хранится некоторая информация. Например, в регистре **Цены товаров** измерениями будут товар и покупатель, для которого данный товар имеет некоторую цену. **Ресурсы** — это основная информация, хранимая в регистре. Например, в том же регистре это будет цена товара. **Реквизиты** — это вспомогательная информация, которая относится только к одной строке таблицы. Например, фамилия менеджера, который установил цену на товар.

Регистры могут быть [периодическими](periodic-information-register-2e754cdbda44.md) (хранят историю изменений данных) или непериодическими (хранят только актуальное состояние).

## Дочерние элеметы

#### Ресурсы

```yaml
Ресурсы: РесурсРегистраСведений[]
```

Ресурсы регистра, используемые для хранения основной информации (цены, количества, значений и т. д.) в разрезе измерений.

---

#### Реквизиты

```yaml
Реквизиты: РеквизитРегистраСведений|Регистратор[]
```

Реквизиты для хранения вспомогательной (неключевой) информации о записях регистра.

---

#### Измерения

```yaml
Измерения: ИзмерениеРегистраСведений[]
```

Ключевые реквизиты, описывающие разрезы, в которых хранится информация. В качестве типов измерений нельзя использовать типы `Строка` и `Байты` неограниченной длины, а также тип `ДвоичныйОбъект.Ссылка`. Список измерений не может быть пустым.

Значения всех измерений записи образуют ключ этой записи: ключ записи должен быть уникален в пределах всего регистра. Таким образом, ключ однозначно идентифицирует запись регистра. Порядок измерений имеет значение — по ним в основной таблице регистра сведений создается индекс (измерения учитываются в том порядке, в котором они описаны).
