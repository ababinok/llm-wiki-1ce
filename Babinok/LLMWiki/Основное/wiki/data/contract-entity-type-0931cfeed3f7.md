## Тип «ИмяКонтрактаСущности»

Тип `{ИмяКонтрактаСущности}` — абстрактный тип. Содержит методы для работы с экземплярами типов-одиночек элементов, которые реализуют контракт сущности:

- [`ПолучитьОдиночки()`](entitycontractname-ru-d85298230aa3.md)
  
  — возвращает множество экземпляров типов-одиночек элементов, которые реализуют данный контракт сущности. Метод доступен, если в элементе проекта значение свойства
  
  [ПолучениеВсехОдиночек](entitycontract-ef962eb24775.md)
  
  имеет значение
  
  Доступно
  
  .
- [`ПолучитьОдиночку()`](entitycontractname-ru-d85298230aa3.md)
  
  — возвращает экземпляр типа-одиночки, который реализует данный контракт сущности и соответствует типу элемента, переданного в параметрах.

```xbsl
// Модуль объекта справочника СостояниеДокументов
// При записи справочника получаем экземпляр типа-одиночки и вызываем метод контракта
@Обработчик
@ВыполнятьПриЗагрузкеДанных
метод ПослеЗаписи(ПредыдущееЗначение: СостояниеДокументов.Данные, ПараметрыЗаписи: СостояниеДокументов.ПараметрыЗаписи)
    исп КонтекстДоступа.Привилегированный()
    пер Док = ДокументИмеющийСостояние.ПолучитьОдиночку(этот)
    Док.ПослеЗаписиСостоянияДокумента(этот, ПредыдущееЗначение, ПараметрыЗаписи)
;
```

### Модуль контракта сущности

В проекте модуль, расширяющий тип [`{ИмяКонтрактаСущности}`](entitycontractname-ru-d85298230aa3.md), называется модулем контракта сущности.

В модуле контракта сущности могут быть объявлены методы (с ключевым словом `абстрактный`), из которых состоит контракт.

Например, ниже показан модуль контракта сущности, в котором объявлен абстрактный метод `ПослеЗаписиСостоянияДокумента()`.

```xbsl
абстрактный метод ПослеЗаписиСостоянияДокумента(
    ТекущееЗначение: СостояниеДокументов.Объект,
    ПредыдущееЗначение: СостояниеДокументов.Данные,
    ПараметрыЗаписи: СостояниеДокументов.ПараметрыЗаписи)
```

## Тип «ИмяКонтрактаСущности.Данные»

Абстрактный тип. Содержит свойства, объявленные в контракте сущности.

## Тип «ИмяКонтрактаСущности.Объект»

Абстрактный тип. Содержит свойства и методы объекта контракта.

## Тип «ИмяКонтрактаСущности.ПараметрыЗаписи»

Абстрактный тип. Содержит параметры записи, которые должны присутствовать во всех элементах, реализующих контракт `{ИмяКонтрактаСущности}`.

## Тип «ИмяКонтрактаСущности.ПараметрыУдаления»

Абстрактный тип. Содержит параметры удаления, которые должны присутствовать во всех элементах, реализующих контракт `{ИмяКонтрактаСущности}`.

## Тип «ИмяКонтрактаСущности.Ссылка»

Ссылка на контракт.
