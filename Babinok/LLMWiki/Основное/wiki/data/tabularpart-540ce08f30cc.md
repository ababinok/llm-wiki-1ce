## Обзор

Вложенная таблица, предназначенная для хранения вместе с каждым элементом данных однородной по своей структуре информации.

## Документированный контракт и примеры

Вложенная таблица, предназначенная для хранения вместе с каждым элементом данных однородной по своей структуре информации. Количество строк такой информации заранее неизвестно и может быть разным для разных элементов данных ([подробнее](../project/tabular-section-9c4a0403bcba.md)).

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](../project/displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [Низкая](../project/displayimportance-ru-469c555fd91c.md).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных для использования в [полнотекстовом поиске](../project/full-text-search-99b98022003a.md).

---

#### ЗаполнятьПриКопировании

```yaml
ЗаполнятьПриКопировании: Булево
```

Свойство определяет, заполнять ли элемент при копировании.

---

#### Индексы

```yaml
Индексы: 
    -
        Имя: Строка
        Поля: Строка[]
        ДополнительныеПоля: Строка[]
```

Наборы основных и дополнительных полей, по которым «Элемент» создаст индексы в базе данных.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Поля

Набор основных полей, по которым будет создан индекс в базе данных.

##### ДополнительныеПоля

Набор дополнительных полей, по которым будет создан индекс в базе данных.

</details>
