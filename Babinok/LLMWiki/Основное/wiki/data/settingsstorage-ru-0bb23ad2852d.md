## Методы

### ПересчитатьРазрешенияДоступа

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступа()
```

Пересчитывает разрешения доступа на хранилище настроек целиком.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов()
```

Пересчитывает разрешения доступа на отдельные объекты в хранилище настроек.

---

### ПолучитьСтандартныеЗначенияВыбора

`Доступность: Сервер`

```
ПолучитьСтандартныеЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Выполняет стандартный поиск значений по подстроке, предназначен для вызова из обработчика

[ПолучитьЗначенияВыбора](settingsstoragename-ru-f7a28628e636.md)

, имеет те же самые параметры типа

[ПараметрыПолученияЗначенийВыбора](../interface/choicevaluesgettingparameters-ru-d09cd7fb3fef.md)

.
