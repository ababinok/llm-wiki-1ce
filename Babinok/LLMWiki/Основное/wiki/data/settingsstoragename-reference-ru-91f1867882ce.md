### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): {ИмяХранилищаНастроек}.Объект?
```

Загружает объект хранилища настроек по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.

**Переопределение** [ХранилищеНастроек.Ссылка::ЗагрузитьОбъект](settingsstorage-reference-ru-caee23c51502.md)

### СоздатьКопиюОбъекта

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопиюОбъекта(
  Ид: Ууид = Неопределено,
  КлючОбъекта: Строка,
  КлючНастройки: Строка,
  Пользователь: Пользователи.Ссылка = Неопределено,
  Вариант: Булево = Ложь,
  Значение: Строка,
  Наименование: Строка,
  Общая: Булево = Ложь,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>
): {ИмяХранилищаНастроек}.Объект
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр настройки копированием настройки на которую указывает эта ссылка.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта - источника создания копированием. **[ИсключениеИсточникКопированияСущностиНеСуществует](entitycopysourcenotexistsexception-ru-ccae6b569bee.md)** - Если ссылка у которой был вызван метод указывает на несуществующий объект.
