## Документированный контракт и примеры

В данной статье рассматриваются различные способы загрузки двоичных данных в [хранилища](https://1cmycloud.com/console/help/element/10.0/docs/topics/binary-data-storage/).

## Загрузка файлов путем перетаскивания в компонент интерфейса

Чтобы выполнить загрузку файлов, которые перетаскиваются в компонент пользовательского интерфейса, используйте обработчик события [`ПриПеретаскивании`](../interface/component-ru-bad1c84be995.md) для данного компонента. Например, если файл перетаскивается в форму объекта справочника, то в модуле этого компонента вы можете загрузить файл следующим образом:

```xbsl
метод ПриПеретаскивании(Источник: Компонент, Событие: СобытиеПриПеретаскивании)
    знч Файлы = Событие.Значение как ЧитаемыйМассив<ВыбранныйФайл>
    Событие.СтандартнаяОбработка = Ложь
     
    для Файл из Файлы
        пер Cсылка = ЗагрузкаФайлов.НачатьЗагрузку(Файл).ПолучитьРезультат()
        // Сохранение ссылки на двоичные данные
        // ...
    ;
;
```

## Использование компонента «ВыборФайлов» для загрузки данных

Если приложение использует компонент [ВыборФайлов](../interface/files-choice-component-f28c0737018e.md), вы можете выполнить загрузку файлов в обработчике события [`ПриИзменении`](../interface/fileschoice-ru-65be716cb62b.md), которое возникает у этого компонента.

```xbsl
метод ОбработчикПриИзменении(Источник: ВыборФайлов, 
                             Событие: СобытиеПриИзменении<ЧитаемыйМассив<ВыбранныйФайл>>)
    знч Файлы = Событие.НовоеЗначение
    для Файл из Файлы
        пер Cсылка = ЗагрузкаФайлов.НачатьЗагрузку(Файл).ПолучитьРезультат()
        // Сохранение ссылки на двоичные данные
        // ...
    ;
;
```

## Указание типа содержимого при загрузке файла на клиенте

При загрузке файла в хранилище двоичных данных на клиенте, вы можете явно указать MIME-тип содержимого этого файла. Для этого задайте значение параметра `ТипСодержимого` при вызове метода [`НачатьЗагрузку()`](../interface/filesupload-ru-8389bafc654f.md) типа [`ЗагрузкаФайлов`](../interface/filesupload-ru-8389bafc654f.md). Если этот параметр задан, файл загружается в объектное хранилище с указанным типом, иначе тип определяется автоматически. Указанный тип также будет использоваться при скачивании файла из хранилища.

Рассмотрим следующий пример. Предположим, что приложение содержит компонент [ВыборФайлов](../interface/files-choice-component-f28c0737018e.md), через который пользователи могут загружать только ZIP-архивы с документами. Для компонента задан фильтр, указывающий допустимый тип файлов для выбора:

```yaml
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: ВПроекте
Ид: c2d7b9a1-4f10-4803-8054-dfdeb935ef89
Имя: ВыборАрхиваДокументов
Наследует:
    Тип: ВыборФайлов
    Фильтр: ".zip"
    МножественныйВыбор: Ложь
    ОтображатьИконку: Истина
    Описание: Загрузите ZIP-архив
    ПриИзменении: ОбработчикПриИзменении
```

Чтобы загрузить выбранный архив в хранилище, используется обработчик события [`ПриИзменении`](../interface/fileschoice-ru-65be716cb62b.md) для компонента [ВыборФайлов](../interface/files-choice-component-f28c0737018e.md). При вызове метода [`НачатьЗагрузку()`](../interface/filesupload-ru-8389bafc654f.md) вы можете явно указать MIME-тип загружаемого файла: `application/zip`.

```xbsl
метод ОбработчикПриИзменении(Источник: ВыборФайлов, 
                             Событие: СобытиеПриИзменении<ЧитаемыйМассив<ВыбранныйФайл>>)
    знч Файл = Событие.НовоеЗначение[0]
    если Файл.Расширение == "zip"
        пер Ссылка = ЗагрузкаФайлов.НачатьЗагрузку(Файл = Файл, ТипСодержимого = "application/zip").ПолучитьРезультат()
        // Сохранение ссылки на двоичные данные
        // ...
    иначе
        Сообщить("Выбранный файл не является ZIP-архивом!")
    ;
;
```

## Загрузка данных в объектное хранилище на сервере

Для загрузки двоичных данных на сервере используйте перегрузки метода [`Загрузить()`](objectstorage-ru-2ba8627c997d.md) типа [`ОбъектноеХранилище`](objectstorage-ru-2ba8627c997d.md). Вы можете явно указать MIME-тип загружаемого объекта, используя параметр `ТипСодержимого`. Если указанное значение имеет не соответствующий MIME-типу формат или его длина превышает 255 символов, выбрасывается [`ИсключениеНедопустимыйФормат`](../stdlib/illegalformatexception-ru-8ff587175d1a.md). Если тип содержимого не указан, он определяется автоматически. Если определить тип не удалось, используется тип `application/octet-stream`.

В примере ниже показано, как с помощью HTTP-запроса получить изображение и сохранить его в справочнике **Изображения**:

```xbsl
@ВПроекте
метод ДобавитьИзображение(Запрос: HttpСервисЗапрос)
    // Получить заголовки запроса.
    знч Код            = Запрос.Параметры.ПолучитьПервый("imageCode")
    знч Размер         = Запрос.Заголовки.ПолучитьПервый("Content-Length")
    знч ТипСодержимого = Запрос.Заголовки.ПолучитьПервый("Content-Type")
 
    // Загрузить двоичные данные в хранилище.
    знч Изображение: ДвоичныйОбъект = ОбъектноеХранилище.Загрузить("Изображение", Запрос.Тело, новый Число(Размер), ТипСодержимого)
 
    // Создать элемент справочника «Изображения» и в его реквизите «Данные» сохранить ссылку на двоичные данные.
    знч ИзображениеЭлемент = новый Изображения.Объект()
    ИзображениеЭлемент.Код    = Код
    ИзображениеЭлемент.Данные = Изображение.Ссылка
    ИзображениеЭлемент.Записать()
 
    Запрос.Ответ.УстановитьТело(Изображение.Ссылка.ВСтроку())
;
```

## Использование загрузки по частям

Вы можете использовать метод [`НачатьСоставнуюЗагрузку()`](objectstorage-ru-2ba8627c997d.md) типа [`ОбъектноеХранилище`](objectstorage-ru-2ba8627c997d.md) и тип [`ДвоичныйОбъект.СоставнаяЗагрузка`](binaryobject-multipartupload-ru-a9a5fb4dd627.md) для загрузки данных на сервер по частям.

Также вы можете использовать тип `ДвоичныйОбъект.СоставнаяЗагрузка` и его методы для генерации уникальных подписанных ссылок, позволяющих сторонним приложениям загружать данные напрямую в ваше S3-хранилище. Если размер загружаемого объекта известен заранее, используйте метод `ПолучитьСсылкиНаЗагрузку(РазмерЧасти: РазмерБайтов|Число|? = Неопределено)`, в противном случае — `ПолучитьСсылкиНаЗагрузку(КоличествоЧастей: Число, НомерПервойЧасти: Число)`. Время жизни ссылок не может быть более 7 дней (значение по умолчанию). При вызове методов для хранилищ, отличных от S3, выбрасывается `ИсключениеНеподдерживаемаяОперация`.

В примере ниже показана загрузка резервной копии через сторонний сервис, который возвращает готовый массив идентификаторов **ETag** для завершения загрузки.

```xbsl
метод ЗагрузитьРезервнуюКопиюСервиса(Код: Строка, Размер: Число, ИмяФайла: Строка, ТипСодержимого: Строка)
    знч СоставнаяЗагрузка =
        ОбъектноеХранилище.НачатьСоставнуюЗагрузку(ИмяФайла, Размер, ТипСодержимого, новый ДвоичныйОбъект.Свойства(Код), 1д)

    // Получение массива HTTP-ссылок на загрузку объекта
    знч СсылкиНаЗагрузку = СоставнаяЗагрузка.ПолучитьСсылкиНаЗагрузку()
    знч РазмерЧасти = СоставнаяЗагрузка.ПолучитьРазмерЧастиПоУмолчанию()

    // Вызов стороннего сервиса для загрузки объекта в хранилище
    знч СписокИдентификаторовETag = СтороннийСервис.ЗагрузитьРезервнуюКопию(СсылкиНаЗагрузку, РазмерЧасти)

    СоставнаяЗагрузка.ЗавершитьЗагрузку(СписокИдентификаторовETag)
;
```

## Обработка недопустимых символов в имени файла

Имена файлов могут содержать символы, недопустимые на какой-либо из поддерживаемых ОС. Например, файл `log?.txt`, созданный в Linux, содержит символ `?`, который Windows не позволяет использовать в именах файлов. Метод [`Загрузить()`](objectstorage-ru-2ba8627c997d.md) проверяет имя загружаемого файла и в случае обнаружения недопустимых символов действует в соответствии с режимом обработки таких символов, установленным для всего приложения. Аналогичным образом работает метод [`ВыгрузкаФайлов.НачатьВыгрузку()`](../interface/filesdownload-ru-97065aa8f041.md) при выгрузке файлов из хранилища.

Установить режим и строку замены для всего приложения можно методом [`УстановитьАвтоматическоеИсправлениеИмениФайла()`](objectstorage-ru-2ba8627c997d.md).

Вы можете задать режим обработки значением перечисления [`РежимИсправленияИмениФайлаДвоичногоОбъекта`](binaryobjectfilenamecorrectionmode-ru-1421ce56e705.md):

- `НеИсправлять`
  
  — при недопустимом имени файла выбрасывается исключение.
- `ИсправлятьПриЗагрузке`
  
  — недопустимые символы в имени файла исправляются в момент загрузки.
- `ИсправлятьПриВыгрузке`
  
  — оригинальное имя файла сохраняется в хранилище и исправляется только в момент выгрузки.

Также вы можете указать строку замены — подстроку, на которую будут заменены все недопустимые символы в имени файла. Если строка замены не указана, недопустимые символы удаляются из имени.

Получить текущие значения настроек можно с помощью методов [`ПолучитьРежимАвтоматическогоИсправленияИмениФайла()`](objectstorage-ru-2ba8627c997d.md) и [`ПолучитьЗаменуНедопустимыхСимволовВИмениФайла()`](objectstorage-ru-2ba8627c997d.md).

В примере ниже показано, как настроить автоматическое исправление имен файлов при загрузке с заменой недопустимых символов на символ подчеркивания `_`:

```xbsl
метод ЗадатьОбработкуНедопустимыхСимволов()
    ОбъектноеХранилище.УстановитьАвтоматическоеИсправлениеИмениФайла(
        РежимИсправленияИмениФайлаДвоичногоОбъекта.ИсправлятьПриЗагрузке, "_")
;
```
