## Задача и границы примера

Нужна форма создания и редактирования элемента справочника. `ФормаОбъекта` предназначена для создания, редактирования и удаления сущностей с базовым типом `РедактируемыйОбъект`. Пример изменения формы использует справочник `КонтактныеЛица` приложения «Демо CRM»; это требование исходного примера, а не встроенный справочник любого проекта.

## Порядок переходов по документации

1. Откройте «Типы, порождаемые элементом проекта вида Справочник» и различите менеджер, `.Ссылка`, `.Объект` и `.Данные`. `Сотрудники` — прикладное имя демонстрационного справочника. Его `.Данные` создаёт платформа для событий записи; это не тип, который нужно конструировать для редактирования.
2. Для создания сверяйте конструктор `.Объект`; для существующей записи — `.Ссылка.ЗагрузитьОбъект()`. Типы ссылки и объекта доступны в окружении `КлиентИСервер`, но метод `ЗагрузитьОбъект()` и метод объекта `Записать()` доступны на сервере. Проверяйте окружение операции отдельно от окружения типа.
3. Для формы откройте «Компонент интерфейса ФормаОбъекта». `КлючОбъекта` задаёт ключ сущности, `Объект` предоставляет данные формы. Свойства `Записать`, `ЗаписатьИЗакрыть`, `Удалить` и `УдалитьНавсегда` описывают команды формы; не подменяйте их вызовами одноимённых произвольных методов.
4. Для расположения полей используйте пример «Как изменить содержимое формы»: поля оборачиваются в `Группа`, её `Компоновка` задаётся как `Горизонтальная`. Имена полей и компоненты должны существовать в целевом проекте.
5. Перед сохранением сверяйте `Записать()` в справочнике объекта: документированы исключения блокировки, одновременного изменения сущности и запрета доступа. Сохранение и удаление требуют проверки отдельного контракта; «удалить» и «удалить навсегда» являются разными командами формы.

## Пример из документации

Исходный пример создаёт кандидата и возвращает ссылку. Он требует справочника `Сотрудники`, реквизитов `ФИО`, `Статус` и перечисления `СтатусыСотрудников`; собственный метод размещён в модуле справочника.

```xbsl
// Создает сотрудников-кандидатов в справочнике «Сотрудники»
@ВПроекте
метод СоздатьКандидата(ФИО: Строка): Сотрудники.Ссылка

    пер Сотрудник = новый Сотрудники.Объект()
    Сотрудник.ФИО = ФИО
    Сотрудник.Статус = СтатусыСотрудников.Кандидат
    Сотрудник.Записать()

    возврат Сотрудник.Ссылка

;
```

## Проверка решения

Укажите используемый прикладной тип, окружение каждой операции, выбранную команду формы и обработку документированных ошибок. Этот маршрут связывает исходные контракты; он не подтверждает исполнение примера в конкретном проекте.
