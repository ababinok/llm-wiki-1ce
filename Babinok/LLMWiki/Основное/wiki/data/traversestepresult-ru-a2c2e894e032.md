## Примеры

**Общие примеры**

```xbsl
метод ПеречислениеДляРезультатаШагаОбходаУзла(Документ: ДокументHtml)
    /*
    Дан ДокументHtml, соответсвующий отправляемому письму. Многие почтовые серверы не поддерживают svg. Поэтому если в коде
    встречается тег svg, то такой код обрабатывать не будем, а иначе выписываем все jpg изображения, чтобы оформить их во
    вложение.
    */
    пер ИзображенияJpg = новый Массив<ЭлементHtml>()
    Документ.ОбойтиВГлубину(метод(Узел: УзелHtml, Глубина: Число)->
            если Узел это ЭлементHtml
                пер Элемент = Узел как ЭлементHtml
                если Элемент.Имя == "svg"
                    возврат РезультатШагаОбхода.ОстановитьОбход
                иначе если Элемент.Имя == "head"
                    возврат РезультатШагаОбхода.ПропуститьДочерние
                иначе если Элемент.Имя == "img" и Элемент.Атрибуты.ЕстьЗначение("src") и 
                            Элемент.Атрибуты.Получить("src").ЗаканчиваетсяНа(".jpg")
                    ИзображенияJpg.Добавить(Элемент)
                ;
            ;
            возврат РезультатШагаОбхода.ПродолжитьОбход
        ;
    )
;
```
