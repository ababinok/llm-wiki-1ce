## Обзор

Обязательный стандартный реквизит, содержащий ссылки на документы, которые являются регистраторами для регистра накопления.

## Документированный контракт и примеры

Обязательный стандартный реквизит, содержащий ссылки на документы, которые являются регистраторами для регистра накопления.

---

## Свойства

#### Тип

```yaml
Тип: Тип[]
```

Тип реквизита. Должен содержать ссылки на элементы проекта вида [Документ](document-element-0c6b898a8b13.md).

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](../project/displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [Обычная](../project/displayimportance-ru-469c555fd91c.md).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных для использования в [полнотекстовом поиске](../project/full-text-search-99b98022003a.md).

---

#### ЗаполнятьПриКопировании

```yaml
ЗаполнятьПриКопировании: Булево
```

Свойство определяет, заполнять ли элемент при копировании.
