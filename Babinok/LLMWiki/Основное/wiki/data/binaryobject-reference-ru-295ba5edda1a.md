## Обзор

Ссылка на двоичный объект.

## Документированный контракт и примеры

`Стд::ОбъектноеХранилище::ДвоичныйОбъект.Ссылка` `Доступность: КлиентИСервер`

Ссылка на двоичный объект. Позволяет загрузить объект из хранилища.

Ссылки на двоичные объекты могут храниться в реквизитах сущностей.

**Сравнение**

Структурное

## Методы

### Загрузить

`Доступность: Сервер`

```
Загрузить(): ДвоичныйОбъект
```

Загружает двоичный объект по ссылке.

Метод не загружает содержимое объекта, а только получает необходимую метаинформацию из хранилища: размер содержимого, тип содержимого и другие свойства.

#### Исключения

**[ИсключениеДвоичногоОбъекта](binaryobjectexception-ru-ccf2a7416223.md)** - при ошибке получения двоичного объекта.

### СоздатьHttpСсылку

`Доступность: Сервер`

```
СоздатьHttpСсылку(
  ТаймаутУстаревания: Длительность? = Неопределено,
  ИмяФайла: Строка? = Неопределено,
  ТребуетсяАутентификация: Булево = Истина,
  БезПеренаправления: Булево = Ложь,
  ТипРасположенияСодержимого: Строка? = Неопределено
): ДвоичныйОбъект.HttpСсылка
```

Возвращает относительную ссылку для загрузки объекта завернутую в объект ДвоичныйОбъект.HttpСсылка.

`ИмяФайла` - имя получаемого по ссылке файла `ТребуетсяАутентификация` - получить объект по ссылке сможет только аутентифицированный пользователь, если передано Истина, иначе - объект будет доступен публично. По умолчанию Истина. `ТаймаутУстаревания` - устанавливается время жизни ссылки. Значение по умолчанию Неопределено, что интерпретируется, как бесконечность. `БезПеренаправления` - запретить перенаправление на внешнее хранилище. Работает только для объектов во внешних хранилищах. По умолчанию Ложь `ТипРасположенияСодержимого` - значение типа для заголовка Content-Disposition при получении объекта по ссылке, по умолчанию `attachment`. В соответствие с RFC 6266 (см. п. 4.2. Disposition Type), может быть указано любое значение, и определены стандартные `attachment` и `inline`. Если установлено значение `attachment` при переходе по ссылке должно быть предложено сохранение файла. Для того, чтобы определить обработку по умолчанию, необходимо указать значение `inline` - в этом случае некоторые браузеры вместо сохранения файла на диск могут открыть файл во вкладке, если формат поддерживается (например для изображений и PDF).
