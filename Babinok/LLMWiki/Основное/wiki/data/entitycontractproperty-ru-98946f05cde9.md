## Обзор

Коллекция описания свойств.

## Документированный контракт и примеры

Коллекция описания свойств. Для каждого свойства задаются параметры.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Тип

```yaml
Тип: Тип[]
```

Тип свойства контракта сущности.

---

#### ДлинаЦелойЧасти

```yaml
ДлинаЦелойЧасти: Число
```

Максимально допустимая длина целой части числа.

---

#### МаксимальнаяДлина

```yaml
МаксимальнаяДлина: Число
```

Максимально допустимая длина строки.

---

#### ДлинаДробнойЧасти

```yaml
ДлинаДробнойЧасти: Число
```

Максимально допустимая длина дробной части числа.

---

#### МаксимальноеЗначение

```yaml
МаксимальноеЗначение: Число
```

Максимально допустимое значение числа.

---

#### МинимальноеЗначение

```yaml
МинимальноеЗначение: Число
```

Минимально допустимое значение числа.

---

#### ОграниченияЭлементов

```yaml
ОграниченияЭлементов: 
    ДлинаЦелойЧасти: Число
    ДлинаДробнойЧасти: Число
    МаксимальноеЗначение: Число
    МинимальноеЗначение: Число
    МаксимальнаяДлина: Число
```

Задает ограничения, применимые к элементам.

---

#### ПриУдаленииОбъектаПоСсылке

```yaml
ПриУдаленииОбъектаПоСсылке: ДействиеПриУдаленииОбъектаПоСсылке
```

Определяет поведение при удалении элемента, указанного в качестве реквизита ([подробнее](../project/data-deletion-141a62f69ff7.md)).

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: Булево
```

Определяет доступность свойства для чтения. Значение по умолчанию — **Ложь**.
