## Обзор

Компонент интерфейса **ПанельТегов** отображает список значений в виде тегов.

## Документированный контракт и примеры

Компонент интерфейса **ПанельТегов** отображает список значений в виде тегов. **Тег** — это метка или ярлык, предназначенный для маркировки, классификации и фильтрации контента. Каждый тег может иметь свой цвет, содержать текст и картинку. Вы можете создавать информационные (неинтерактивные) и [кликабельные](tag-panel-74f7123dd302.md) (интерактивные) теги.

Панель тегов показывает одну горизонтальную строку разноцветных тегов с иконками и подписями «Задача», «Ошибка», «Эпик», «Улучшение», «Дизайн/Анализ», «Инфраструктура», «Документация», «Рефакторинг». [Описание иллюстрации](../../raw/figures/6c0b30596ae439a1413f347f94cb28556aaef7886ade14db95ae23cccdb29911-b909f10a782bcfbe.md)

## Добавление панели тегов

Рассмотрим, как добавить панель тегов в интерфейс приложения на примере формы объекта справочника.

Форма «Анкета кандидата» содержит панель «Ключевые навыки» под полями должности и навыков. [Описание иллюстрации](../../raw/figures/8480487cf844047d7c8b1916e78973fa9dd06401080c080b4031a1cff068121b-9a1eba1202bbf144.md)

В этом примере панель тегов используется для отображения значений, выбранных пользователем в поле **Навыки**.

Чтобы создать изображенную выше форму, выполните следующие действия:

1. Создайте справочник **Кандидаты** для хранения анкет кандидатов. Добавьте указанные ниже реквизиты:
  
  - Код
    
    типа
    
    `Строка`
    
    ,
  - Наименование
    
    типа
    
    `Строка`
    
    ,
  - ДатаРождения
    
    типа
    
    `Дата`
    
    ,
  - Телефон
    
    типа
    
    `Строка`
    
    ,
  - Email
    
    типа
    
    `Строка`
    
    ,
  - Должность
    
    типа
    
    `Должность`
    
    (здесь
    
    `Должность`
    
    — это перечисление, хранящее названия должностей, на которые открыты вакансии),
  - Навыки
    
    типа
    
    `Массив<Навыки.Ссылка>`
    
    (здесь
    
    `Навыки`
    
    — это справочник, используемый для хранения профессиональных навыков, которыми должны обладать кандидаты).
2. [Создайте для справочника форму объекта](add-project-element-forms-2ae9079946eb.md) с именем **КандидатыФормаОбъекта**.
  
  Конструктор формы объекта справочника «Кандидаты». [Описание иллюстрации](../../raw/figures/5a8981fa4be3dc5cbcf4e6787aa0d21cecbd7836112eebf621c2649216fe478d-cf372390d7c1be69.md)
3. Добавьте панель тегов на форму объекта. Для этого выделите **ОсновнойРаздел** формы и нажмите на знак плюса. В открывшемся окне выберите **ПанельТегов**. В [панели свойств](ide-overview-and-basic-actions-969a6e6501a6.md) укажите тип компонента — `ПанельТегов<Навыки.Ссылка>`.
  
  Добавление панели тегов [Описание иллюстрации](../../raw/figures/8a0161165060dd1ece5b2b76b5c3eb2f538e8bc325ecedbbeaac8b3d95a24ef7-8796d55924d75391.md)
4. Чтобы настроить привязку значений тегов к значениям поля ввода **Навыки**, в свойстве [СписокЗначений](tagspanel-ru-43a5346e801d.md) панели тегов укажите выражение `Компоненты.Навыки.Значение`.
5. Настройте отображение панели тегов:
  
  - в свойстве [Заголовок](tagspanel-ru-43a5346e801d.md) введите значение **Ключевые навыки**,
  - в свойстве [Изображение](tagspanel-ru-43a5346e801d.md) выберите *ЛампочкаКонтур.svg*,
  - для свойства [ЦветТегов](tagspanel-ru-43a5346e801d.md) укажите значение `Цвета.Голубой`.
    
    > [!TIP] совет
    > Если вы хотите использовать разные цвета для тегов, в качестве значения свойства [СписокЗначений](tagspanel-ru-43a5346e801d.md) укажите массив объектов [`ЭлементСпискаЗначений<ТипДанных>`](valuelistitem-ru-c68a213e54f6.md), каждый из которых может иметь свой [цвет](valuelistitem-ru-c68a213e54f6.md) и [изображение](valuelistitem-ru-c68a213e54f6.md).
    
    Св�ойства панели тегов [Описание иллюстрации](../../raw/figures/90434d2c55604f8b0233172ff9c287ff7ad6ecc7b82940f54d3a3cbfdf629b63-5d8ee4a9381c11d2.md)

## Компактное отображение панели тегов

Если панель тегов располагается в перечисленных ниже компонентах, она отображается в компактном виде (в частности, у нее отсутствует [Заголовок](tagspanel-ru-43a5346e801d.md) и [Изображение](tagspanel-ru-43a5346e801d.md)):

- в колонке
  
  СтандартнаяКолонкаТаблицы
  
  или
  
  ПроизвольнаяКолонкаТаблицы
  
  компонента интерфейса
  
  [Таблица](../project/table-overview-0bc2ec1e1bb3.md)
  
  ,
- в строке списка компонента интерфейса
  
  [ПроизвольныйСписок](custom-list-0a05086d6d89.md)
  
  ,
- в компонентах интерфейса
  
  [СтандартнаяКарточка](standard-card-component-12665d7eda6b.md)
  
  или
  
  [ПроизвольнаяКарточка](custom-card-component-b505ea7a5b7d.md)
  
  ,
- в компоненте интерфейса
  
  ПроизвольноеОкноМаркераГеографическойКарты
  
  .

Также для свойства [Вид](standardtablecolumn-ru-0b1e3e80ca73.md) компонента **СтандартнаяКолонкаТаблицы** доступно значение **Теги**, которое позволяет отобразить содержимое колонки таблицы в виде тегов. Это значение применяется автоматически, если тип данных в колонке — массив или перечисление.

Например, так колонка **Навыки** будет выглядеть в форме списка справочника **Кандидаты**, созданного в [примере выше](tag-panel-74f7123dd302.md).

В форме списка «Кандидаты» справа показана колонка «Навыки» с компактными тегами в каждой строке. [Описание иллюстрации](../../raw/figures/0151413b8b80469ff07564dd8e39083f710fd568b3c372cef4b5ac531dd8ac44-40dd6122a7ea17a5.md)

## Обработка нажатия на тег

Используйте событие [`ПриНажатииНаТег`](tagspanel-ru-a300b5efac7e.md), чтобы сделать панель тегов интерактивной. Например, вы можете фильтровать список элементов при нажатии на тег, как показано ниже.

Реализуем возможность фильтровать задачи по статусу при нажатии на тег. Для этого в панели **Свойства** компонента интерфейса **ПанельТегов** создайте обработчик события **ПриНажатииНаТег**. В данном примере создается обработчик с именем `ПриНажатииНаТегСтатусаЗадачи`.

Добавьте в обработчик код для фильтрации списка задач по выбранному тегу.

Фильтрация списка задач по тегу

```xbsl
метод ПриНажатииНаТегСтатусаЗадачи(Источник: ПанельТегов<СтатусЗадачи>, Событие: СобытиеСДанными<СтатусЗадачи>)
    // Очистка ранее примененных фильтров
    Компоненты.ОсновнаяТаблица.Источник.Фильтр.Элементы.Очистить()
    // Создание фильтра для отображения задач,
    // статус которых совпадает с выбранным тегом
    знч ЭлементФильтра = новый ЭлементФильтра()
    ЭлементФильтра.Поле = "Статус"
    ЭлементФильтра.Значение = Событие.Данные
    ЭлементФильтра.ВидСравнения = ВидСравнения.Равно
    // Применение фильтра к списку задач
    Компоненты.ОсновнаяТаблица.Источник.Фильтр.Элементы.Добавить(ЭлементФильтра)
    Компоненты.ОсновнаяТаблица.Обновить()
;
```

Теперь при нажатии на тег будут показываться задачи, статус которых соответствует выбранному тегу.

Нажат тег «Новая» в панели тегов над таблицей задач; список показывает только строки со статусом «Новая». [Описание иллюстрации](../../raw/figures/f7da3fe433a72204bc978f7ae883a6958b7dff4df291aa46f82dbc4696048f88-e314f187ffe2ff82.md)
