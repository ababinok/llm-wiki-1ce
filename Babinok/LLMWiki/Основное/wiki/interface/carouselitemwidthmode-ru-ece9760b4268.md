## Свойства

### Колонки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Колонки
```

Ширина элемента содержимого указывается в колонках. Все элементы будут одинаковой ширины. Ширина элементов будет зависеть от ширины колонки и не будет зависеть от собственных параметров ширины и ширины Карусели. Высота элементов вычисляется следующим образом:

- если
  
  [Высота](component-ru-bad1c84be995.md)
  
  Карусели задана (числовое значение), то высота всех элементов содержимого принимается равной высоте Карусели, вне зависимости от их собственных параметров высоты;
- если
  
  [Высота](component-ru-bad1c84be995.md)
  
  Карусели не задана (
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  ), то высота всех элементов содержимого принимается по максимальной среди этих элементов; сама высота элемента определяется его собственными параметрами высоты.

### ПроцентШириныКонтейнера

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПроцентШириныКонтейнера
```

- если
  
  [Высота](component-ru-bad1c84be995.md)
  
  Карусели задана (числовое значение), то высота всех элементов содержимого принимается равной высоте Карусели, вне зависимости от их собственных параметров высоты;
- если
  
  [Высота](component-ru-bad1c84be995.md)
  
  Карусели не задана (
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  ), то высота всех элементов содержимого принимается по максимальной среди этих элементов; сама высота элемента определяется его собственными параметрами высоты.

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Пиксели
```

  [Высота](component-ru-bad1c84be995.md)

  [Высота](component-ru-bad1c84be995.md)
  
  Карусели не задана (
  
  [Авто](../stdlib/auto-ru-1b14ed166f8e.md)
  
  ), то высота всех элементов содержимого принимается по максимальной среди этих элементов; сама высота элемента определяется его собственными параметрами высоты.

### СобственнаяШирина

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
СобственнаяШирина
```

Используется ширина, указанная в собственных параметрах элемента. Все элементы будут собственной ширины, вычисленной на основе их содержимого и заданных в них параметрах ширины. Ширина элементов может быть разной. Высота элемента определяется его собственными параметрами высоты. Высота элементов может быть разной.
