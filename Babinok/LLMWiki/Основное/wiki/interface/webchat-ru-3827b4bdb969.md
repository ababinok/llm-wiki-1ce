Обеспечивает управление окном веб-чата на уровне приложения.

## Методы

### ЗапроситьДанныеПользователя

`Доступность: Клиент`

```
ЗапроситьДанныеПользователя()
```

Инициирует запрос данных пользователя для отображения их в обсуждении. Данные пользователя передаются с использованием события

[ПриПолученииДанныхПользователя](webchat-ru-3827b4bdb969.md)

---

### ОбсуждениеПрочитано

`Доступность: Клиент`

```
ОбсуждениеПрочитано(): Булево
```

Возвращает Истина, если в чате присутствует хотя бы одно непрочитанное сообщение

---

### ОкноОткрыто

`Доступность: Клиент`

```
ОкноОткрыто(): Булево
```

Возвращает Истина, если на данный момент чат развёрнут, Ложь – в противном случае

---

### ОткрытьОкно

`Доступность: Клиент`

```
ОткрытьОкно()
```

Разворачивает окно веб-чата.

---

### СвернутьОкно

`Доступность: Клиент`

```
СвернутьОкно()
```

Сворачивает окно веб-чата, отключение пользователя при этом не происходит.
