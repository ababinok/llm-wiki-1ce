## Обзор

ТипЗаписи: Тип записи набора констант.

## Документированный контракт и примеры

`Стд::Интерфейс::Формы::ФормаЗаписиПериодическогоНабораКонстант<ТипЗаписи,ТипРезультата>` `Доступность: Клиент`

ТипЗаписи: Тип записи набора констант. Ограничения параметра типа: Стд::Сущности::РедактируемаяЗаписьПериодическогоНабораКонстант<неизвестно,неизвестно,неизвестно>. ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](form-ru-89fb5e7eaeb3.md) без передачи аргумента, в качестве результата открытия возвращается `Неопределено`.

Форма записи периодического набора констант. Содержит стандартные функции для создания и редактирования периодических наборов констант приложения. ФормаЗаписиПериодическогоНабораКонстант редактирует записи наборов констант, которые имеют в базовых типах [РедактируемаяЗаписьПериодическогоНабораКонстант](../stdlib/editableperiodicconstantssetrecord-ru-de9c906ce5a0.md) для периодических наборов констант.

## Методы

### Записать

`Доступность: Клиент`

```
Записать()
```

Сохраняет данные сущности. В процесс записи в качестве параметров записи передается значение свойства

[ПараметрыЗаписи](periodicconstantssetrecordform-ru-7920f052b7f6.md)

.

---

### Прочитать

`Доступность: Клиент`

```
Прочитать(КлючЗаписи: ТипЗаписи.KeyType? = Неопределено)
```

Перечитывает и обновляет данные сущности на форме. Если указан параметр

`КлючЗаписи`

, то читает данные по ключу и устанавливает новое значение в

[КлючЗаписи](periodicconstantssetrecordform-ru-7920f052b7f6.md)

.

---

### Удалить

`Доступность: Клиент`

```
Удалить()
```

Удаляет сущность из базы данных приложения. В процесс удаления передаются параметры удаления из свойства

[ПараметрыУдаления](periodicconstantssetrecordform-ru-7920f052b7f6.md)

. Внимание! После вызова этого метода форма закрывается, если она была открыта.

---

### ЭтоНовый

`Доступность: Клиент`

```
ЭтоНовый(): Булево
```

Возвращает признак: что в форме редактируется новый объект сущности.
