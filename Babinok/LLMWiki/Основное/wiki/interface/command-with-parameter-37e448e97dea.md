## Обзор

Компонент командного интерфейса **КомандаСПараметром** позволяет передать во время выполнения команды параметр.

## Документированный контракт и примеры

Компонент командного интерфейса **КомандаСПараметром** позволяет передать во время выполнения команды параметр. Это может быть полезно для передачи дополнительной информации, такой как, например, какие-либо условия или настройки. Во время исполнения параметр передается как аргумент в обработчик, как показано на примере ниже:

```xbsl
метод ВыполнитьКомандуСПараметром(
    Команда: КомандаСПараметром<Массив<Сущность.Ссылка>>, 
    Параметр: Массив<Сущность.Ссылка>)
    // ...
;
```

После того как вы добавили в проект команду с параметром, «1С:Предприятие.Элемент» создаст тип с тем же именем, что и имя вашей команды. Так, для команды с параметром **ВыполнитьЗадачи** из примера ниже будет создан тип `ВыполнитьЗадачи`.

## Свойства

В проекте компонент командного интерфейса **КомандаСПараметром** имеет следующие свойства:

### Важность

`ВажностьКоманды`. Определяет приоритет при отображении нескольких команд. Например, команда с важностью **Низкая** будет отображаться в выпадающем меню «Еще». Возможные значения:

- Высокая
  
  ,
- Обычная
  
  ,
- Низкая
  
  .

### Видимость

`Булево`. Управляет видимостью команды. Если `Ложь`, команда скрыта в интерфейсе.

### Доступность

`Булево`. Управляет доступностью команды. Если `Ложь`, команда недоступна для выполнения.

### Изображение

`Url|ДвоичныйОбъект.Ссылка|?`. Графическое изображение на кнопке группы командного интерфейса.

### ОпасностьДействия

`ОпасностьДействия`. Определяет опасность действия, совершаемого пользователем, например, может ли нажатие на кнопку привести к удалению данных. Возможные значения:

- Высокая
  
  ,
- Средняя
  
  ,
- Отсутствует
  
  .

### Представление

`Строка`. Текст кнопки группы командного интерфейса.

## Пример

Рассмотрим пример использования команды с параметром из демонстрационного приложения. В данном примере такой командой является выполнение задач, но не всех, а только отмеченных. Именно список отмеченных задач и передается в команду как параметр:

Список задач в режиме выделения: флажками отмечены строки; внизу показана панель команды выполнения выбранных задач. В команду передаётся список отмеченных задач. [Описание иллюстрации](../../raw/figures/433c42be99887683ed8353edbfed3dafa5550e8c31702686590788e8468c6da0-4a38094004056790.md)

Так выглядит команда с параметром в YAML-файле соответствующей формы списка документа **Задачи**:

```yaml
КомандыОтмеченныхСтрок:
    Тип: ФрагментКомандногоИнтерфейса<КомандаСПараметром<Массив<Задачи.Ссылка>>>
    Элементы:
        -
            Тип: КомандаСПараметром<Массив<Задачи.Ссылка>>
            Изображение: Галочка.svg
            Обработчик: ЗавершитьОтмеченныеЗадачиОбработчик
            Представление: $ЗадачиЛокализация.ЗавершитьЗадачи
```

А так — обработчик этой команды в модуле формы списка документа **Задачи**:

```xbsl
метод ЗавершитьОтмеченныеЗадачиОбработчик(Команда: КомандаСПараметром<Массив<Задачи.Ссылка>>, Параметр: Массив<Задачи.Ссылка>)
    знч Ответ = Диалог.Вопрос<СтатусЗадачи>(
        Текст = ЗадачиЛокализация.ЗавершениеЗадач(),
        Кнопки = [
            новый КнопкаДиалога(СтатусЗадачи.Выполнено, ЗадачиЛокализация.ЗадачиВыполнены()), 
            новый КнопкаДиалога(СтатусЗадачи.Отменено, ЗадачиЛокализация.ЗадачиОтменены()), 
            СтандартнаяКнопкаДиалога.Отмена
        ],
        Пояснение = ЗадачиЛокализация.УкажитеСтатусЗавершенияЗадач()
    )
    
    если Ответ != СтандартнаяКнопкаДиалога.Отмена
        знч Статус = Ответ как СтатусЗадачи
        
        Задачи.УстановитьСтатусЗадач(Параметр, Статус)
        
        ОбновитьТаблицу()
        
        знч Уведомление = новый Уведомление(
            Заголовок = ЗадачиЛокализация.ЗавершениеЗадач(),
            Текст = Статус == СтатусЗадачи.Выполнено ? ЗадачиЛокализация.ЗадачиВыполнены() : ЗадачиЛокализация.ЗадачиОтменены()
        )
         
        Уведомление.Показать()
        
        Компоненты.ОсновнаяТаблица.ОчиститьОтмеченныеСтроки()
    ;
;
```
