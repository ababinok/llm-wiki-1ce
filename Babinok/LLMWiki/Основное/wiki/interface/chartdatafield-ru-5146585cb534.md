## Обзор

Описывает отображение данных диаграммы на ее визуальные элементы.

## Документированный контракт и примеры

`Стд::Интерфейс::Диаграммы::ПолеДанныхДиаграммы` `Доступность: КлиентИСервер`

## Свойства

### ОтображаемоеЗначение

`Доступность: КлиентИСервер`

```
ОтображаемоеЗначение: Строка
```

Имя поля в структуре данных, значения которой будут отображаться на диаграмме. Поддерживаемые типы данных отображаемых значений: [Строка](../stdlib/string-ru-1bac645acacf.md), [Число](../stdlib/number-ru-dd4b54993c86.md).

---

### ПолеЗначения

`Доступность: КлиентИСервер`

```
ПолеЗначения: Строка
```

Имя поля в структуре данных, значения которой задают данные диаграммы. Поддерживаемые типы данных значений поля: [Строка](../stdlib/string-ru-1bac645acacf.md), [Число](../stdlib/number-ru-dd4b54993c86.md), [Булево](../stdlib/boolean-ru-7823d4239bcc.md), [Null](../data/null-ru-0059ad0ae7ba.md), [Дата](../stdlib/date-ru-d160dc00114c.md).
