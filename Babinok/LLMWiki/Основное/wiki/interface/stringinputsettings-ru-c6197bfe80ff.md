## Конструкторы

### НастройкиВводаСтроки

`Доступность: КлиентИСервер`

```
НастройкиВводаСтроки(
  Многострочная: Авто|Булево,
  МинимальнаяВысотаВСтроках: Авто|Число,
  МаксимальнаяВысотаВСтроках: Авто|Число,
  МоноширинныйШрифт: Авто|Булево,
  ОбрабатыватьТабуляцию: Авто|Булево,
  ПроверятьОрфографию: Авто|Булево,
  МаксимальнаяДлина: Авто|Число,
  ОтображатьИндикаторДлины: Авто|Булево,
  Маска: Авто|Образец|?,
  ЗамещающийСимволМаски: Авто|Строка|?)
```

Создает новый объект

[НастройкиВводаСтроки](stringinputsettings-ru-c6197bfe80ff.md)

.

## Свойства

### ЗамещающийСимволМаски

`Доступность: КлиентИСервер`

```
ЗамещающийСимволМаски: Авто|Строка|?
```

Устанавливает замещающий символ, которым заполняются динамические части маски до того, как пользователь ввел значение в соответствующей позиции ввода строкового значения.

---

### МаксимальнаяВысотаВСтроках

`Доступность: КлиентИСервер`

```
МаксимальнаяВысотаВСтроках: Авто|Число
```

Максимальная высота многострочного поля в строках. Значение 0 снимает ограничение по высоте. Данное свойство является менее приоритетным, чем свойство [МинимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md). [МаксимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md) будет увеличена, если значение меньше, чем [МинимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md).

---

### МаксимальнаяДлина

`Доступность: КлиентИСервер`

```
МаксимальнаяДлина: Авто|Число
```

Максимально допустимая длина строки. `Авто` или `0` = без ограничений.

---

### Маска

`Доступность: КлиентИСервер`

```
Маска: Авто|Образец|?
```

Устанавливает маску ввода строкового значения. Вводимое значение должно соответствовать указанному образцу. `Неопределено` или `Авто` = маска не задана, вводимые значения не проверяются.

---

### МинимальнаяВысотаВСтроках

`Доступность: КлиентИСервер`

```
МинимальнаяВысотаВСтроках: Авто|Число
```

Минимальная высота многострочного поля в строках. Является приоритетным над свойством [МаксимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md). [МаксимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md) будет увеличена, если значение меньше, чем [МинимальнаяВысотаВСтроках](stringinputsettings-ru-c6197bfe80ff.md).

---

### Многострочная

`Доступность: КлиентИСервер`

```
Многострочная: Авто|Булево
```

Определяет является ли строка многострочной или нет. Если является, то появляется возможность использовать другие настройки ввода многострочных строк.

Свойство игнорируется, если задан [РежимВыбораИзСписка](edit-ru-cde85140b31e.md) отличный от [НеИспользовать](listchoicemode-ru-1e5ddc67399c.md).

---

### МоноширинныйШрифт

`Доступность: КлиентИСервер`

```
МоноширинныйШрифт: Авто|Булево
```

Включает использование моноширинного шрифта в поле ввода. Например, для ввода кода.

---

### ОбрабатыватьТабуляцию

`Доступность: КлиентИСервер`

```
ОбрабатыватьТабуляцию: Авто|Булево
```

Если свойство установлено в `Истина`, то включается обработка компонентом сочетаний клавиш `Tab` и `Shift+Tab` для вставки и удаления символов табуляции. Пробелы, уже существующие в значении поля, обрабатываются как частичная табуляция.

- `Tab`
  
  : на позиции курсора или в начале выделенных строк текста увеличивается отступ. Перехода фокуса к следующему элементу не происходит.
- `Shift+Tab`
  
  : в начале текущей или выделенных строк текста уменьшается отступ, если он есть. Перехода фокуса к предыдущему элементу не происходит.

---

### ОтображатьИндикаторДлины

`Доступность: КлиентИСервер`

```
ОтображатьИндикаторДлины: Авто|Булево
```

Включает или выключает отображение индикатора максимальной длины. Если [МаксимальнаяДлина](stringinputsettings-ru-c6197bfe80ff.md) не установлена, индикатор отображает количество введённых символов.

---

### ПроверятьОрфографию

`Доступность: КлиентИСервер`

```
ПроверятьОрфографию: Авто|Булево
```

Включает режим проверки орфографии встроенными средствами браузера.
