## Обзор

В данном примере вы найдете [элемент проекта](../project/project-element-e0f54b4a4951.md), который описывает командный интерфейс приложения.

## Документированный контракт и примеры

> [!NOTE] примечание
> Этот пример использует [приложение «Демо CRM»](../project/demo-app-3768685a4428.md).

В данном примере вы найдете [элемент проекта](../project/project-element-e0f54b4a4951.md), который описывает командный интерфейс приложения. Зная его, вы можете менять состав существующих команд и добавлять собственные команды.

Командный интерфейс демо-приложения [Описание иллюстрации](../../raw/figures/b5e78b882b1aca16a2a62cbfb849fc232318a4f8c45eb78c822466fc26116ae2-2d57ac44718b5d59.md)

При запуске веб-клиент ищет в проекте один из компонентов, унаследованных от [СтандартноеКлиентскоеПриложениеСРазделами](standard-client-application-with-sections-component-49da52beb720.md) или [ПроизвольноеКлиентскоеПриложение](custom-client-application-component-a5e093d01cdd.md), и запускает его экземпляр ([подробнее](selecting-interface-at-application-startup-8bfc6b427dba.md)).

Чтобы найти этот компонент в проекте, [откройте](../project/open-app-in-ide-2c0162ac1160.md) демо-приложение в среде разработки и выполните следующие действия:

1. Откройте представление **Поиск**. В строку поиска введите «КлиентскоеПриложение». Это позволит вам найти компоненты любого из этих типов.
  
  В данном примере будет найден один компонент — **Приложение**. Также из результатов поиска видно, что этот компонент находится в [подсистеме](../project/hierarchical-project-structure-397ba5e7f9df.md) **Основное** (подсистемы создают структуру каталогов, внутри которых находятся файлы проекта).
  
  Поиск по проекту [Описание иллюстрации](../../raw/figures/b9efd6d7caf985e86affe82f76a7a0f5d44fe6ab9b3f04c20714caabbd5f7e39-dfb773df4717e24e.md)
2. Нажмите правой кнопкой мышки на строку «Приложение» и выберите **Выделить в навигаторе**. Откроется навигатор проекта с подсвеченным элементом **Приложение**. Щелкните на него, чтобы открыть дерево компонентов.
  
  
3. В командном интерфейсе панели навигации находятся элементы, описывающие команды навигации, — [фрагменты командного интерфейса](command-interface-fragment-f742e5d6797f.md), как отдельные, так и объединенные в группы.
  
  Командный интерфейс панели навигации [Описание иллюстрации](../../raw/figures/a07c81850167b7ee40aa37f56827e1115d2292ef06c7a7a22d7bec412db6c177-948a94e1fe533677.md)
4. Чтобы перейти к редактированию отдельного фрагмента компонента интерфейса, например **НавигацияАктивности**, введите «НавигацияАктивности» в строку поиска.
  
  
5. Будет найдено несколько файлов, в которых упоминается эта строка. Вам нужен тот, в котором описывается элемент проекта с таким именем. Правой кнопкой мышки нажмите на строку «НавигацияАктивности» и выберите **Выделить в навигаторе**.
  
  Откроется фрагмент командного интерфейса **НавигацияАктивности**. В его свойстве **Элементы** перечисляются команды, которые вы видите на экране.
  
  В дереве фрагмента «НавигацияАктивности» раздел «Элементы» содержит команды открытия списков задач и событий. [Описание иллюстрации](../../raw/figures/dc41aef778f0493b18429d23fa35ef5b1b1c6c150de5a14d7c028be9e07934ec-ffb55d8aec13eb29.md)
6. Если вы хотите определить, где находится найденный элемент в структуре проекта, выберите файл *НавигацияАктивности.yaml* в области редакторов и выполните одно из следующих действий:
  
  - в представлении **Проект** нажмите на значок **Выделить в навигаторе**:
    
    Значок «Выделить в навигаторе» [Описание иллюстрации](../../raw/figures/d2c5c00effd09d8732960e84f44cec49147da398eb8af1bbebc5d695b26df8a0-e7a95d7e46a80798.md)
  - нажмите правой кнопкой мыши на заголовок файла в области редакторов и выберите пункт **Выделить в навигаторе** в контекстном меню:
    
    Пункт меню «Выделить в навигаторе» [Описание иллюстрации](../../raw/figures/9cec5edcfc03280f3142fba11143d279c7ee7b78cf43fd9b23b14e2c146c7dab-e5969e455b05b94b.md)
  - нажмите **Alt+R**.
  
  Элемент **НавигацияАктивности** будет выделен в навигаторе проекта.
  
  Элемент «НавигацияАктивности» в навигаторе проекта [Описание иллюстрации](../../raw/figures/b68d99db124fad8554e99c9afad20239a22ae106c378c5f6aa85700dc09b4fa2-9963f2279a1aded6.md)
