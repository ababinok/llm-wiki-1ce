### КомпонентОбластиФормы

`Доступность: Клиент`

```
КомпонентОбластиФормы: Страницы|СтековаяГруппа
```

Ссылка на компонент [Страницы](pages-ru-9b4ca3b4a152.md) или [СтековаяГруппа](stackgroup-ru-e78423e50743.md), в котором по умолчанию будут открываться формы приложения:

- [Страницы](pages-ru-9b4ca3b4a152.md)
  
  : формы оборачиваются в компонент
  
  [Страница](page-ru-0c0a530fde03.md)
  
  , показывающий заголовок формы и саму форму.
- [СтековаяГруппа](stackgroup-ru-e78423e50743.md)
  
  : формы показываются как есть.

Если не задано, формы будут открываться в модальном окне

---

`Доступность: Клиент`

```
ОтступПоВертикали: Авто|РазмерОтступа
```

---

### ОтступПоГоризонтали

`Доступность: Клиент`

```
ОтступПоГоризонтали: Авто|РазмерОтступа
```

Отступ от границ приложения до границ содержимого по горизонтали.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент?
```

Компонент, который определяет содержимое компонента приложения.
