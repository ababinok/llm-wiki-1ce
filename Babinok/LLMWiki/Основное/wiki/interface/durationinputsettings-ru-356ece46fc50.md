## Конструкторы

### НастройкиВводаДлительности

`Доступность: КлиентИСервер`

```
НастройкиВводаДлительности(
  НаибольшаяЕдиница: Авто|ЕдиницаВремени,
  НаименьшаяЕдиница: Авто|ЕдиницаВремени,
  ДлинаНаибольшейЧасти: Авто|Число,
  Отрицательная: Булево)
```

Создает новый объект

[НастройкиВводаДлительности](durationinputsettings-ru-356ece46fc50.md)

.

## Свойства

### ДлинаНаибольшейЧасти

`Доступность: КлиентИСервер`

```
ДлинаНаибольшейЧасти: Авто|Число
```

Количество цифр в наибольшей части длительности.

---

### НаибольшаяЕдиница

`Доступность: КлиентИСервер`

```
НаибольшаяЕдиница: Авто|ЕдиницаВремени
```

Наибольшая возможная единица времени, доступная для ввода.

---

### НаименьшаяЕдиница

`Доступность: КлиентИСервер`

```
НаименьшаяЕдиница: Авто|ЕдиницаВремени
```

Наименьшая возможная единица времени, доступная для ввода.

---

### Отрицательная

`Доступность: КлиентИСервер`

```
Отрицательная: Булево
```

Ввод отрицательной длительности. `Ложь` - допустимы только положительная или нулевая длительность, `Истина` - только отрицательная или нулевая.
