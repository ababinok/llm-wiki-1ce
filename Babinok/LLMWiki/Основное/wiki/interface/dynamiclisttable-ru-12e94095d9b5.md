## Обзор

Основная таблица выборки динамического списка.

## Документированный контракт и примеры

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ТаблицаДинамическогоСписка` `Доступность: КлиентИСервер`

Основная таблица выборки динамического списка. Определяет не только выборку данных, но и поведение интерфейсных компонентов, использующих динамический список в качестве источника данных.

## Конструкторы

### ТаблицаДинамическогоСписка

`Доступность: КлиентИСервер`

```
ТаблицаДинамическогоСписка(
  Таблица: Строка,
  Псевдоним: Строка,
  Аргументы: Массив<АргументТаблицы|АргументТаблицыВыражение>)
```

Создает таблицу динамического списка с полями по умолчанию.

---

## Свойства

### Аргументы

`Доступность: КлиентИСервер`

```
Аргументы: Массив<АргументТаблицы|АргументТаблицыВыражение>
```

Аргументы таблицы, неименованные аргументы указываются в соответствии с объявленным порядком.

---

### Псевдоним

`Доступность: КлиентИСервер`

```
Псевдоним: Строка
```

Псевдоним основной таблицы. Может использоваться в выражениях полей для разрешения неоднозначности имен полей, если есть присоединенные таблицы.

---

### Таблица

`Доступность: КлиентИСервер`

```
Таблица: Строка
```

Имя таблицы.
