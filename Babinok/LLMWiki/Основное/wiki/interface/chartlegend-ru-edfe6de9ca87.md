## Свойства

### Непрозрачность

`Доступность: КлиентИСервер`

```
Непрозрачность: Авто|Число
```

Прозрачность фона легенды в процентах, где 0 - легенда полностью непрозрачная, 100 - легенда полностью прозрачная. Работает только в случае, если легенда расположена поверх диаграммы.

---

### Расположение

`Доступность: КлиентИСервер`

```
Расположение: Авто|РасположениеЛегендыДиаграммы
```

Расположение легенды на диаграмме.
