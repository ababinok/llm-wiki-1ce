## Добавление группы в редакторе компонентов интерфейса

Чтобы добавить группу к компоненту интерфейса, перейдите к его разделу **Содержимое** и нажмите на знак плюса. В открывшемся окне выберите **Группа**.

В разделе «Содержимое» формы открыто добавление компонента; из списка выбран тип «Группа». [Описание иллюстрации](../../raw/figures/eb975396421d11f25d3e669b73637e36219bbfe0c695d7bb8b3b499d9e1f39d3-f0be631ac1ef053e.md)

Группа включает в себя следующие разделы:

- Команды
  
  — список команд группы. Отображаются в правой части заголовка группы.
- Содержимое
  
  — описывает экземпляры компонентов интерфейса, расположенные в группе. Нажмите на знак плюса, чтобы добавить новый компонент к группе.
- Подвал
  
  — задает содержимое области подвала. Эта область предназначена для размещения элементов, которые не пропадают при прокрутке.

В [панели свойств](ide-overview-and-basic-actions-969a6e6501a6.md) группы вы можете настроить параметры ее отображения ([свойства группы](group-ru-ac8d45ab0db2.md)).

## Компоновка элементов в группе

Используйте свойство **Компоновка**, чтобы задать расположение элементов в группе. Ниже подробно рассмотрены значения, которые может принимать это свойство.

### Авто

Если содержимое группы можно распределить по колонкам, то значение **Авто** интерпретируется как **ПоКолонкам**, иначе используется **Вертикальная** компоновка.

### ПоКолонкам

Элементы группы располагаются горизонтально по колонкам формы. Если места недостаточно, содержимое переносится на следующую строку. Используются только размеры компонентов в колонках — **ШиринаВКолонках**.

Группировка по колонкам: компоненты 1, 2, 3, 4 помещены в первую строку; 5 и 6 перенесены во вторую и выровнены с первыми двумя колонками. [Описание иллюстрации](../../raw/figures/70af5042ed2a856cfa66f5679ff9cd41de41fbd4ddabea849abeac4ddd15ca63-3b528fadcbd68545.md)

### Горизонтальная

Элементы группы располагаются горизонтально в одну строку. Если места недостаточно, содержимое сжимается или прокручивается в зависимости от значения свойства **ПрокруткаПоГоризонтали**. Используются только размеры в пикселях — **Ширина**, **МинимальнаяШирина**, **МаксимальнаяШирина**, **РастягиватьПоГоризонтали**, **ВесПриРастягивании**. Если размеры не заданы, используются размеры по умолчанию.

Горизонтальная группа [Описание иллюстрации](../../raw/figures/b7823112cda385fa276cee4b79432732b4a3dac85cd5594556fa4f30fff0707d-f1acdc54f927535c.md)

### Вертикальная

Элементы группы располагаются вертикально в одну колонку. Ширина компонентов зависит от значения свойств **Ширина**, **МинимальнаяШирина**, **МаксимальнаяШирина**, **РастягиватьПоГоризонтали**.

Вертикальная группа [Описание иллюстрации](../../raw/figures/8f59b45fc96d374f0d1caa7a000527c78f08e8e9f682f9e8c3fa6969029c5682-e067a744f100a255.md)

### Матричная

Представляет собой набор колонок и строк, на пересечении которых находятся ячейки. В этих ячейках «1С:Предприятие.Элемент» показывает компоненты, являющиеся содержимым матричной группы.

Матричная группа [Описание иллюстрации](../../raw/figures/a3adaae4a256a310bb7dc72808fe7b2c7972287afbccf01a476ea7b6d90b9fee-b6957fc53f57fa20.md)

Если вы опишете только **колонки**, «1С:Предприятие.Элемент» поместит содержимое группы в первую строку, слева направо. Если элементов группы больше, чем колонок, то добавит снизу новую строку и начнет заполнять ее.

Аналогично, если вы опишете только **строки**, «1С:Предприятие.Элемент» заполнит первую колонку сверху вниз, добавит справа новую колонку и начнет заполнять ее.

Если вы опишите и строки, и колонки, то группа будет состоять как минимум из фиксированного количества ячеек (*ЧислоКолонок* х *ЧислоСтрок*).

Свойство **НастройкиМатричнойКомпоновки** описывает параметры компоновки элементов в матричной группе:

- **АвтоЗаполнение** — `Авто|АвтоЗаполнениеМатричнойГруппы`. Способ автоматического добавления строк или колонок в группу. Используется, когда компонентов содержимого больше, чем ячеек.
  
  - `Авто`
    
    — принимает следующие значения:
    
    - `АвтоЗаполнениеМатричнойГруппы.ДобавлятьКолонки`
      
      , если у группы описаны строки;
    - `АвтоЗаполнениеМатричнойГруппы.ДобавлятьСтроки`
      
      , если у группы описаны только колонки или и строки, и колонки;
  - элементы перечисления
    
    `АвтоЗаполнениеМатричнойГруппы`
    
    :
    
    - `ДобавлятьСтроки`
      
      — компоненты содержимого, которые не поместились, будут добавляться в новые строки;
    - `ДобавлятьКолонки`
      
      — компоненты содержимого, которые не поместились, будут добавляться в новые колонки;
    - `ДобавлятьКолонкиИСтроки`
      
      — компоненты содержимого, которые не поместились, будут добавляться в новые колонки. Когда доступное по горизонтали место закончится, будет добавлена новая строка.
- **ОписаниеАвтоматическихКолонок** — `КолонкаМатричнойГруппы`. Задает описание колонок, которые добавляются автоматически.
- **ОписаниеАвтоматическихСтрок** — `СтрокаМатричнойГруппы`. Задает описание строк, которые добавляются автоматически.
- **Колонки** — `Массив<КолонкаМатричнойГруппы>`. Задает описание колонок матричной группы. Каждый элемент массива описывает одну колонку.
- **Строки** — `Массив<СтрокаМатричнойГруппы>`. Задает описание строк матричной группы. Каждый элемент массива описывает одну строку.

### Карусель

Элементы группы располагаются горизонтально в одну строку с возможностью их переключения.

Пример карусели: на экране видна одна карточка; кнопки со стрелками переключают карточки по горизонтали. [Описание иллюстрации](../../raw/figures/fe206417919081a4d025483a53c5df5af789abfae982d1354c3bdafb787e3c4f-eb6192b6ec804a57.md)

- РежимШириныЭлемента
  
  — включает режим указания ширины элемента внутри Карусели. По умолчанию равно
  
  Авто
  
  .
  
  - Авто
    
    — значение по умолчанию, поведение аналогично
    
    Колонки
    
    .
  - Колонки
    
    — ширина элемента указывается в колонках. Задает одинаковую ширину всем элементам. Ширина элементов будет зависеть от ширины колонки и не будет зависеть от собственных параметров ширины и ширины группы.
  - Процент ширины контейнера
    
    — ширина элемента указывается в процентах относительно ширины группы. По умолчанию равно

  - Пиксели

### Бенто

Элементы группы располагаются внутри сетки из прямоугольных и квадратных блоков разного размера. Расположение элементов внутри сетки определяется специальным алгоритмом компоновки и зависит от параметра **РазрешитьИзменениеПорядка** свойства **НастройкиКомпоновкиБенто**.

Пример сетки «Бенто» в приложении: крупная приветственная область сверху и блоки разного размера ниже — воронка продаж, списки сделок и задач, таблица и круговая диаграмма. [Описание иллюстрации](../../raw/figures/e896e00585c2aba2f2fbb2f10e6cea934bba210e1a8beecd03a56b1fd9079c93-e9fa5c1371621d61.md)

Параметр **РазрешитьИзменениеПорядка** описывает правила компоновки элементов:

- Авто
  
  — поведение аналогично
  
  Истина
  
  ;
- Истина
  
  — расположение элементов определяется алгоритмом как наиболее компактное, порядок элементов может быть изменен алгоритмом компоновки;
- Ложь
  
  — расположение элементов определяется по их порядку в содержимом и не может быть изменено алгоритмом компоновки.

Порядок при компоновке определяется слева направо, сверху вниз. При позиционировании каждого элемента используются его размеры в колонках и строках. Если после позиционирования в группе остается пустое пространство, то элементы растягиваются до границ группы сначала по горизонтали, затем по вертикали.
