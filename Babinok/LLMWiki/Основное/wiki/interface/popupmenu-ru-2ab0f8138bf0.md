Всплывающее меню, которое открывается рядом с указанным компонентом.

## Свойства

### Открыто

`Доступность: Клиент` `ТолькоЧтение`

```
Открыто: Булево
```

Равно `Истина`, если всплывающее меню в данный момент открыто.

---

### ТекущийЭлемент

`Доступность: Клиент`

```
ТекущийЭлемент: ЭлементМеню?
```

Текущий выбранный элемент меню. Выбранный элемент отображается со специальной отметкой.

---

### Элементы

`Доступность: Клиент`

```
Элементы: Массив<ЭлементМеню>
```

Элементы (пункты) меню.

---

## События

### ПриВыбореЭлемента

`Доступность: Клиент`

```
ПриВыбореЭлемента: (
  ВсплывающееМеню,
  СобытиеСДанными<ЭлементМеню>)->ничто
```

Вызывается при нажатии на пункт меню.

---

## Методы

### Закрыть

`Доступность: Клиент`

```
Закрыть(ПараметрЗакрытия: Объект? = Неопределено)
```

Закрывает меню, если оно открыто. Значение параметра

`ПараметрЗакрытия`

будет возвращаемым значением метода

[Открыть](popupmenu-ru-2ab0f8138bf0.md)

, если тот был вызван с параметром

`ОжидатьЗакрытия`

равным

`Истина`

.

---

### Открыть

`Доступность: Клиент`

```
Открыть(
  Компонент: Компонент? = Неопределено,
  ОжидатьЗакрытия: Булево = Истина
): Объект?
```

Открывает всплывающее меню рядом с компонентом, заданным параметром

`Компонент`

. Если параметр

`Компонент`

не задан (равен

`Неопределено`

), то меню открывается рядом с текущим активным компонентом.
