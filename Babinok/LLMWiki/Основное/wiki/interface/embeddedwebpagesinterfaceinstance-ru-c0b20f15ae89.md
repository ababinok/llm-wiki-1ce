## Обзор

Описывает интерфейс для представления встроенных веб-страниц.

## Документированный контракт и примеры

Описывает интерфейс для представления встроенных веб-страниц.

---

## Свойства

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Определяет, будет ли в приложении отображаться интерфейс для встроенных веб-страниц: панель, меню и т. д.

По умолчанию интерфейс показывается, если в [СтандартноеКлиентскоеПриложениеСРазделами](standardclientapplicationwithsections-fd5fbdc63cd1.md) добавлена хотя бы одна встроенная веб-страница.

---

#### Логотип

```yaml
Логотип: ВычисляемоеВыражение|Авто|Url|ДвоичныйОбъект.Ссылка
```

Логотип интерфейса встроенных веб-страниц. При значении **Авто** в интерфейсе встроенных веб-страниц будут задействованы картинки по умолчанию, в зависимости от контекста.

---

#### ЛоготипКрупный

```yaml
ЛоготипКрупный: ВычисляемоеВыражение|Авто|Url|ДвоичныйОбъект.Ссылка
```

Крупный логотип интерфейса встроенных веб-страниц. При значении **Авто** изображение берется из свойства **Логотип**.

---

#### ЦветПанели

```yaml
ЦветПанели: ВычисляемоеВыражение|Авто|Цвет
```

Цвет панели.

---

## Дочерние элеметы

#### КомандыПанели

```yaml
КомандыПанели: ФрагментКомандногоИнтерфейса?
```

Содержит описание командного интерфейса панели встроенных веб-страниц.

---

#### КомпонентМеню

```yaml
КомпонентМеню: ВсплывающийКомпонент?
```

Компонент для представления меню встроенных веб-страниц. Если не задан, используется встроенный компонент.

---

#### ОсновнаяКомандаМеню

```yaml
ОсновнаяКомандаМеню: Команда?
```

Задает команду, которая определяет основное действие в меню встроенных веб-страниц.

---

#### ДополнительныеКомандыМеню

```yaml
ДополнительныеКомандыМеню: ФрагментКомандногоИнтерфейса?
```

Задает дополнительные команды в меню встроенных веб-страниц.
