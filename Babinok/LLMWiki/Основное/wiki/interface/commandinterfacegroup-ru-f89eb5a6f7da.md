Роль: Программный тип XBSL.

Владелец: Std / Interface / Commands.

Имена для поиска: `ГруппаКомандногоИнтерфейса`, `CommandInterfaceGroup`, `Стд::Интерфейс::Команды::ГруппаКомандногоИнтерфейса<ТипКоманды>`, `Std::Interface::Commands::CommandInterfaceGroup`.

## Обзор

ТипКоманды: тип команды группы.

## Документированный контракт и примеры

`Стд::Интерфейс::Команды::ГруппаКомандногоИнтерфейса<ТипКоманды>` `Доступность: Клиент`

ТипКоманды: тип команды группы. По умолчанию [Команда](command-ru-ad3bc8ea1407.md). Ограничения параметра типа: Стд::Интерфейс::Команды::Команда, Стд::Интерфейс::Команды::КомандаСПараметром<неизвестно>.

Логическое объединение команд в некоторую группу. Имеет текстовое представление и картинку. В пользовательском интерфейсе может быть представлена в виде группы меню, выпадающего списка и т.д.

**Сравнение**

Ссылочное

Структурное сравнение.

## Свойства

### Важность

`Доступность: Клиент`

```
Важность: ВажностьКоманды
```

Определяет важность группы. Важность может использоваться при отображении команды. Например, все команды с важностью [Низкая](commandimportance-ru-986d64839edb.md) из свойства формы [ДополнительныеКоманды](form-ru-89fb5e7eaeb3.md) будут отображены в выпадающем меню "Еще"

---

### ВидОтображения

`Доступность: Клиент`

```
ВидОтображения: ВидОтображенияГруппыКомандногоИнтерфейса
```

Определяет вид отображения группы. См. [ВидОтображенияГруппыКомандногоИнтерфейса](commandinterfacegroupdisplaykind-ru-41b09fc7443a.md)

---

### Видимость

`Доступность: Клиент`

```
Видимость: Булево
```

Управляет видимостью группы

---

### Доступность

`Доступность: Клиент`

```
Доступность: Булево
```

Если `Ложь`, команды в группе недоступны для выполнения
