## Обзор

Группа списка с деталями предназначена для реализации трансформируемого шаблона с областью списка и областью компонентов, отображающих информацию, связанную с текущей строкой списка.

## Документированный контракт и примеры

`Стд::Интерфейс::Группы::ГруппаСписокСДеталями<ТипИсточника>` `Доступность: Клиент`

Группа списка с деталями предназначена для реализации трансформируемого шаблона с областью списка и областью компонентов, отображающих информацию, связанную с текущей строкой списка. Основная механика компонента состоит в трансформации для мобильных устройств. На больших экранах области мастер и детали расположены рядом друг с другом, а на маленьких экранах область деталей отображается в блокирующем окне при выделении строки списка.

### СодержимоеДетали

`Доступность: Клиент`

```
СодержимоеДетали: Авто|Компонент
```

Эта область описывает тип компонента, который будет создаваться при выборе строки списка. Этот компонент создается не во время создания компонента [ГруппаСписокСДеталями](listwithdetailsgroup-ru-958b0495002d.md), а при выборе строки. В качестве типа компонента области детали может выступать тип любого компонента, включая типы унаследованные от типа [Форма](form-ru-89fb5e7eaeb3.md). При изменении текущей строки будет происходить стандартное закрытие компонента текущей строки, и создание нового компонента с указанным типом. Если тип - [ФормаОбъекта](objectform-ru-b5cec9fb1ea3.md) и она была изменена, то будет предложено сохранить данные. Если тип списка это [ДинамическийСписок](dynamiclist-ru-ab61b0be4de4.md), и [СодержимоеДетали](listwithdetailsgroup-ru-958b0495002d.md) равно [Авто](../stdlib/auto-ru-1b14ed166f8e.md), то в качестве типа [СодержимоеДетали](listwithdetailsgroup-ru-958b0495002d.md) автоматически будет использована форма объекта основной таблицы этого списка. Если тип списка это [ДинамическийСписок](dynamiclist-ru-ab61b0be4de4.md), и подразумевается, что в области детали должна находиться форма объекта основной таблицы этого списка, то тип содержимого деталей можно не указывать.

**Связывание компонента области детали с данными**

- Если компонент области деталей определен по месту в том же файле, где и сама группа, то для обращения к данным текущей строки списка можно использовать автоматическое свойство
  
  `ДанныеСтроки`
  
  типа
  
  [Объект](../stdlib/object-ru-9e351f286699.md)
  
  ? корневого компонента области детали.
- Если тип компонента области деталей унаследован от
  
  [СтрокаСписка](listrow-ru-0e5c748cc6b5.md)
  
  , то для обращения к данным текущей строки списка можно использовать свойство
  
  [ДанныеСтроки](listrow-ru-0e5c748cc6b5.md)
  
  , независимо от того, где определен компонент.
- Если тип компонента области деталей это
  
  [ФормаОбъекта](objectform-ru-b5cec9fb1ea3.md)
  
  основной таблицы списка мастер, то вся механика формы объекта будет работать стандартным образом, включая события и свойства доступа к данным.
- Для других типов компонент, определенных в отдельном файле, связывание с данными необходимо произвести явно с помощью свойства
  
  `ДанныеСтроки`
  
  .

---

### СодержимоеОсновное

`Доступность: Клиент`

```
СодержимоеОсновное: Компонент?
```

Основное содержимое группы. Основной список должен находиться в иерархии компонент, заданной с помощью свойства [СодержимоеОсновное](listwithdetailsgroup-ru-958b0495002d.md). При этом содержимое этой области никак не ограничено, в ней могут находиться любые другие компоненты, в том числе другие списки.
