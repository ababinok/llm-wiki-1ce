### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): {ИмяПланаОбмена}.Объект?
```

Загружает объект плана обмена по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](../data/noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.

**Переопределение** [ПланОбмена.Ссылка::ЗагрузитьОбъект](exchangeplan-reference-ru-286f28c54458.md)

### СоздатьКопиюОбъекта

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопиюОбъекта(
  Ид: Ууид = Неопределено,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр узла плана обмена копированием узла на который указывает эта ссылка.

#### Исключения

**[ИсключениеДоступЗапрещен](../stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта - источника создания копированием. **[ИсключениеИсточникКопированияСущностиНеСуществует](../data/entitycopysourcenotexistsexception-ru-ccae6b569bee.md)** - Если ссылка у которой был вызван метод указывает на несуществующий объект.

### СоздатьКопиюОбъекта

`Версия 9.0 и ниже`

> **Исторический контракт:** верхняя граница версии 9.0; не используйте этот член для 10.0.


`Доступность: Сервер`

```
@ИменованныеПараметры

  Ид: Ууид,
  Код: Строка,

  ЭтотУзел: Булево,
```
