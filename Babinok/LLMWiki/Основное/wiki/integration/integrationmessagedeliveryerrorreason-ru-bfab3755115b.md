## Свойства

### ВнутренняяОшибка

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВнутренняяОшибка
```

Неустановленная внутренняя ошибка при доставке.

---

### ОшибкаОбработчика

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ОшибкаОбработчика
```

Исключение в обработчике повлияло на выполнение маршрутизации. Ошибка определения имени или другая ошибка обработчика в узле, которая сделала доставку невозможной.

---

### ОшибкаВУзле

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ОшибкаВУзле
```

При передаче сообщения в узле произошла ошибка. Например, в свойстве url узла http задан недоступный хост.

---

### НеизвестныйПолучатель

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеизвестныйПолучатель
```

В параметре сообщения КодПолучателя указан неизвестный код получателя.

---

### НеправильныйРеквизитПолучателя

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеправильныйРеквизитПолучателя
```

Для узлов, связанных с группами получателей и использующих реквизиты получателей для вычисления свойств узла. Аналогично ОшибкаВУзле, но причина в том, что к ошибке вычисления свойства привело неверное значение реквизита получателя. Например, для задания порта в узле http использовалось отрицательное значение.

---

### УстареваниеСообщения

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
УстареваниеСообщения
```

Сообщение не было доставлено до момента устаревания. Устаревание произошло в процессе доставки или в канале до подтверждения от участника-получателя.

---

### НетРазрешения

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НетРазрешения
```

Нет разрешения для доступа к ресурсу в узле или для участника процесса интеграции. Например, нет разрешения для подключения к удаленному серверу или каталогу файловой системы.
