### ЗаписатьОбъект

`Доступность: Сервер`

```
ЗаписатьОбъект(
  Значение: Объект?,
  Настройки: НастройкиЗаписиОбъектовJson
```

`Значение`

в JSON с настройками

`Настройки`

и возвращает результат. Можно записывать объекты любого типа объявленного в коде (структура, перечисление) и некоторых встроенных типов:

- [Булево](../stdlib/boolean-ru-7823d4239bcc.md)

**Перегрузка** [ЗаписатьОбъект(Приемник: ПотокЗаписи|ЗаписьJson, Значение: Объект?, Настройки: НастройкиЗаписиОбъектовJson)](jsonserialization-ru-d810a802893e.md)

#### Примеры

```xbsl
структура КлиентыСтруктура
  обз пер Клиенты: Множество<КлиентСтруктура>
;

структура КлиентСтруктура
  обз пер Ид: Число
  обз пер Имя: Строка
  обз пер Отчество: Строка
  обз пер Фамилия: Строка
;

метод ЗаписатьОбъектВСтрокуJson(): Строка
  знч КлиентыОбъект = новый КлиентыСтруктура(новый Множество<КлиентСтруктура>())	
  КлиентыОбъект.Клиенты.Добавить(новый КлиентСтруктура(1, "Иван", "Иванович", "Иванов"))
  КлиентыОбъект.Клиенты.Добавить(новый КлиентСтруктура(2, "Петр", "Петрович", "Петров"))

  возврат Результат
```

Результат:

```json
{
  "Клиенты" : [

      "Ид" : 1,
      "Имя" : "Иван",
      "Отчество" : "Иванович",
      "Фамилия" : "Иванов"
    },
    {
      "Ид" : 2,
      "Имя" : "Петр",
      "Отчество" : "Петрович",
      "Фамилия" : "Петров"
    }
  ]
}
```

### ЗаписатьОбъект

`Версия 8.0 и выше`

`Доступность: Сервер`

```
ЗаписатьОбъект(
  Приемник: ПотокЗаписи|ЗаписьJson,
  Значение: Объект?,
  Настройки: НастройкиЗаписиОбъектовJson)
```

`Значение`

в JSON с настройками

`Настройки`

в поток

`Приемник`

`Приемник`

типа

`ЗаписьJson`

, запись будет в поток, который использовался для создания этого объекта. Можно записывать объекты любого типа объявленного в коде (структура, перечисление) и некоторых встроенных типов:

  ,
- [Число](../stdlib/number-ru-dd4b54993c86.md)
  
  ,
- [Булево](../stdlib/boolean-ru-7823d4239bcc.md)


### ПрочитатьМассив

`Доступность: Сервер`

```
@Устарело(Сообщение = "Используйте "ПрочитатьОбъект(Источник: ПотокЧтения|ЧтениеJson|Строка, Тип: Тип<ТипОбъекта>, Настройки: НастройкиЧтенияОбъектовJson, Кодировка: Кодировка|Строка): ТипОбъекта"")
ПрочитатьМассив(
  Источник: ПотокЧтения|Строка,
  Кодировка: Кодировка|Строка = Кодировка.Utf8
): Массив<Объект?>
```

Читает массив объектов из

`Источник`

. Вызывает метод

[ПрочитатьОбъект](jsonserialization-ru-d810a802893e.md)

с параметром Тип = Тип<Массив<Объект?>>) и кодировкой

`Кодировка`

.

#### Примеры

Исходный JSON:

```json
[
  {
    "Имя1": "Значение1"
  },
  {
    "Имя2": "Значение2"
  }
]
```

```xbsl
метод ПрочитатьМассивИзСтрокиJson(СтрокаJson: Строка): Строка
  знч Результат = СериализацияJson.ПрочитатьМассив(СтрокаJson)
  
  возврат Результат.ВСтроку()
;
```

Результат:

```text
[{Имя1: Значение1}, {Имя2: Значение2}]
```

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ПрочитатьОбъект<ТипОбъекта>(
```

Считывает объект JSON из `Источник` в объект типа `ТипОбъекта` с настройками `Настройки` и кодировкой `Кодировка` (если чтение происходит из потока). Можно читать объекты любого типа, объявленного в коде (структура, перечисление), и некоторых встроенных типов:

- [Коллекция](../stdlib/collection-ru-3bc2025a9946.md)
  
  :
  
  - [Массив](../stdlib/array-ru-f0659b9628e1.md)
    
    ,
  - [Множество](../stdlib/set-ru-629ffebe489c.md)
    
    ,
- [Соответствие](../stdlib/map-ru-075f0ef55c6b.md)
  
  ,
- [Строка](../stdlib/string-ru-1bac645acacf.md)
  
  ,
- [Число](../stdlib/number-ru-dd4b54993c86.md)
  
  ,
- [Булево](../stdlib/boolean-ru-7823d4239bcc.md)
  
  ,
- [Момент](../stdlib/instant-ru-09dd46b34eb4.md)
  
  ,
- [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md)
  
  ,
- [Дата](../stdlib/date-ru-d160dc00114c.md)
  
  ,
- [Время](../stdlib/time-ru-bbaed59a0dcd.md)
  
  ,
- [Длительность](../stdlib/duration-ru-fef7ea46f329.md)
  
  ,
- [Ууид](../stdlib/uuid-ru-4831970f1083.md)
  
  ,
- [Версия](../stdlib/version-ru-29e92504e99e.md)
  
  ,
- [Перечисление](../stdlib/enum-ru-a7a357b96b4c.md)
  
  ,
- [Байты](../stdlib/bytes-ru-19f4d37ce009.md)
  
  ,
- [Диапазон](../stdlib/range-ru-eb762726fd87.md)
  
  ,
- [ЗакрытыйДиапазон](../stdlib/closedrange-ru-7f62ab997f5b.md)
  
  .

Если значение типа объекта не указано, тогда чтение выполняется в [Соответствие](../stdlib/map-ru-075f0ef55c6b.md).

Сопоставление полей и свойств происходит следующим образом:

- Любое число (1, 1.56, 0) - отображается в
  
  [Число](../stdlib/number-ru-dd4b54993c86.md)
  
  ,
- `Истина`
  
  ,
  
  `Ложь`
  
  - отображаются в
  
  [Булево](../stdlib/boolean-ru-7823d4239bcc.md)
  
  ,
- `null`
  
  - отображаются в
  
  [Неопределено](../stdlib/undefined-ru-bad7e9ef4c2b.md)
  
  ,
- `"Любая строка"`
  
  - отображается в
  
  [Строка](../stdlib/string-ru-1bac645acacf.md)
  
  ,
- Объект
  
  `{ ... }`
  
  - отображается в структуру либо в
  
  [Соответствие](../stdlib/map-ru-075f0ef55c6b.md)
  
  ,
- Массив
  
  `[ ... ]`
  
  - отображается в
  
  [Массив](../stdlib/array-ru-f0659b9628e1.md)
  
  или
  
  [Множество](../stdlib/set-ru-629ffebe489c.md)
  
  ,
- Строка в формате
  
  [Момент](../stdlib/instant-ru-09dd46b34eb4.md)
  
  или
  
  [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md)
  
  отображается в
  
  [Момент](../stdlib/instant-ru-09dd46b34eb4.md)
  
  или
  
  [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md)
  
  ,
- Строка в формате
  
  [Ууид](../stdlib/uuid-ru-4831970f1083.md)
  
  отображается в
  
  [Ууид](../stdlib/uuid-ru-4831970f1083.md)
  
  ,
- Строка в формате
  
  [Версия](../stdlib/version-ru-29e92504e99e.md)
  
  отображается в
  
  [Версия](../stdlib/version-ru-29e92504e99e.md)
  
  .

Имя свойства в структуре сопоставляется с именем свойства в исходном JSON.

Если необходимого поля структуры нет в читаемом тексте JSON, тогда значение поле устанавливается в `Неопределено`.

#### Исключения

**[ИсключениеЧтенияJson](jsonreaderexception-ru-62be4dbb30ff.md)** - если при чтении произойдет неоднозначность чтения (неявное чтение). Например, при чтении значения `"2000-01-01"` в типы [Дата](../stdlib/date-ru-d160dc00114c.md), [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md) нельзя однозначно определить какой тип должен быть прочитан.

**Перегрузка** [ПрочитатьОбъект<ТипОбъекта>(Источник: ПотокЧтения|ЧтениеJson|Строка, Тип: Тип<ТипОбъекта>, Настройки: НастройкиЧтенияОбъектовJson, Кодировка: Кодировка|Строка = Кодировка.Utf8): ТипОбъекта](jsonserialization-ru-d810a802893e.md)

  [Момент](../stdlib/instant-ru-09dd46b34eb4.md)
  
  или
  
  [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md)
  
  ,
- Строка в формате
  
  [Ууид](../stdlib/uuid-ru-4831970f1083.md)
  
  отображается в
  
  [Ууид](../stdlib/uuid-ru-4831970f1083.md)
  
  ,
- Строка в формате
  
  [Версия](../stdlib/version-ru-29e92504e99e.md)
  
  отображается в
  
  [Версия](../stdlib/version-ru-29e92504e99e.md)
  
  .

Имя свойства в структуре сопоставляется с именем свойства в исходном JSON.

Если необходимого поля структуры нет в читаемом тексте JSON, тогда значение поле устанавливается в `Неопределено`.

#### Исключения

**[ИсключениеЧтенияJson](jsonreaderexception-ru-62be4dbb30ff.md)** - если при чтении произойдет неоднозначность чтения (неявное чтение). Например, при чтении значения `"2000-01-01"` в типы [Дата](../stdlib/date-ru-d160dc00114c.md), [ДатаВремя](../stdlib/datetime-ru-b9ec40d17fe0.md) нельзя однозначно определить какой тип должен быть прочитан.

**Перегрузка** [ПрочитатьОбъект<ТипОбъекта>(Источник: ПотокЧтения|ЧтениеJson|Строка, Настройки: НастройкиЧтенияОбъектовJson, Кодировка: Кодировка|Строка = Кодировка.Utf8): ТипОбъекта](jsonserialization-ru-d810a802893e.md)

### ПрочитатьСоответствие

`Доступность: Сервер`

```
@Устарело(Сообщение = "Используйте "ПрочитатьОбъект(Источник: ПотокЧтения|ЧтениеJson|Строка, Тип: Тип<ТипОбъекта>, Настройки: НастройкиЧтенияОбъектовJson, Кодировка: Кодировка|Строка): ТипОбъекта"")
ПрочитатьСоответствие(
  Источник: ПотокЧтения|Строка,
  Кодировка: Кодировка|Строка = Кодировка.Utf8
): Соответствие<Строка, Объект?>
```

Читает соответствие из

`Источник`

. Вызывает метод

[ПрочитатьОбъект](jsonserialization-ru-d810a802893e.md)

`Тип = Тип<Соответствие<Строка, Объект?>>`

и кодировкой

`Кодировка`

.

```xbsl
метод ПрочитатьСоответствиеИзСтрокиJson(СтрокаJson: Строка): Строка
```
