## Свойства

### ДобавлятьОтступы

`Доступность: Сервер`

```
ДобавлятьОтступы: Булево
```

Определяет, что требуется форматировать записываемый XML-файл с помощью отступов и переносов строк.

---

### РазрешитьПустыеЭлементы

`Доступность: Сервер`

```
РазрешитьПустыеЭлементы: Булево
```

Определяет, что для узлов без содержимого можно использовать краткую форму `<tag/>` вместо полной `<tag></tag>`.
