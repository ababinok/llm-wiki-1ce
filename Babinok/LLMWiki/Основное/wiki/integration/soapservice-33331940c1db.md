## Документированный контракт и примеры

Реализует функциональность [поставщика SOAP-сервиса](soap-web-service-6fc6a00d4cc7.md). Позволяет обрабатывать входящие SOAP-запросы, поступающие от внешних информационных систем. Обращение к SOAP-сервису выполняется при помощи HTTP POST-запроса по URL-адресу. При этом само SOAP-сообщение передается в теле запроса.

Функциональность клиента SOAP-сервиса реализует элемент проекта [Клиент SOAP-сервиса](soap-web-service-client-e79277c8f091.md).

#### Ошибки

```yaml
Ошибки: Тип<Исключение>[]
```

Типы исключений, описывающих ошибки SOAP-сервиса. Могут быть переопределены для конкретной операции с помощью свойства обработчика [Ошибки](servicehandler-ru-d99b0889159b.md).

«1С:Предприятие.Элемент» формирует WSDL-контракт (секция `faults`):

- из данного свойства;
- из списков типов, указанных в свойстве
  
  [Ошибки](servicehandler-ru-d99b0889159b.md)
  
  всех обработчиков.

«1С:Предприятие.Элемент» накладывает [ограничения](soap-service-types-a958b90025c0.md) на типы исключений.

## Дочерние элеметы

#### Обработчики

```yaml
Обработчики: ОбработчикСервиса[]
```

Описание операций, которые выполняют обработку данных из входящего SOAP-сообщения от клиента сервиса и формируют результат для исходящего SOAP-сообщения. Для каждой операции указывается метод, который реализует необходимую функциональность.
