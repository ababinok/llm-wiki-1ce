Версия: `10.0`.

Роль: Схема процесса интеграции.

Владелец: Nodes.

Имена для поиска: `Таймер`, `Timer`, `Std::Schema::Nodes::Timer`.

## Обзор

Узел этого вида создает сообщение через равные интервалы времени.

## Документированный контракт и примеры

Узел этого вида создает сообщение через равные интервалы времени. Может быть только первым узлом в маршруте.

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Период

```yaml
Период: ВычисляемоеВыражение|Длительность
```

Периодичность срабатывания таймера — один раз в указанный в миллисекундах период.

---

#### КоличествоПовторов

```yaml
КоличествоПовторов: ВычисляемоеВыражение|Число
```

Число повторений таймера. При достижении указанного значения генерация сообщений прекращается. Значение **0** — для бесконечной генерации.

---

#### Описание

```yaml
Описание: Строка
```

Описание элемента.

Обработчик, внутри которого можно обновлять метрики, добавленные в проект разработчиком.
