
Имя метода, который реализует операцию SOAP-сервиса.

---

#### КонтрольДоступа

```yaml
КонтрольДоступа: 
    Разрешения: 
        Вызов: КонтрольДоступа
    Обработчик: Строка
```

Содержит [настройки прав доступа](../security/automatically-grant-permissions-to-user-groups-c39cf49a7075.md) для вызова данной операции сервиса. Если значение не указано, то берется значение свойства [КонтрольДоступа](soapservice-33331940c1db.md), заданное для всего SOAP-сервиса.

#### Ошибки

```yaml
Ошибки: Тип<Исключение>[]
```

Типы исключений, которые может выбрасывать метод. Если указанный тип не является исключением, возникает ошибка проверки проекта. «1С:Предприятие.Элемент» накладывает [ограничения](soap-service-types-a958b90025c0.md) на типы исключений.
