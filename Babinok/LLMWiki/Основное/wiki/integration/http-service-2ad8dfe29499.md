## Документированный контракт и примеры

HTTP-сервисы позволяют вам создать программный интерфейс приложения (API), который будет доступен с помощью HTTP-запросов.

HTTP-сервис — это ограниченный набор действий (список HTTP-методов) и разветвленный набор ресурсов, к которым можно обратиться. Состав ресурсов определяется в процессе разработки сервиса и описывает его функциональные возможности.

При разработке интеграционной шины [HTTP-сервис](http-service-element-20a693318e85.md) позволяет «1С:Предприятие.Элементу» обрабатывать входящие HTTP-запросы, поступающие от внешних информационных систем. Например, [процесс интеграции](integration-process-project-element-fe0b29a88e3c.md) может быть настроен следующим образом: внешняя система отправляет сообщение по протоколу HTTP в «1С:Предприятие.Элемент», после чего в HTTP-сервисе вызывается [обработчик](http-service-element-20a693318e85.md), который данное сообщение обрабатывает и передает дальше в [программный источник](programmatic-source-ca1eb29ad522.md). Подробнее про использование HTTP-сервиса в интеграционной шине можно прочитать [здесь](http-web-service-26e7909503fa.md).

Обращение к HTTP-сервису выполняется по адресу — URL. Одному HTTP-сервису могут соответствовать несколько URL, каждый из которых выполняет свое действие. Например, при обращении по одному URL сервис возвращает список документов, а при обращении по другому URL будет возвращен один конкретный документ.

Действие, которое следует выполнить HTTP-сервису, определяется тем, какой HTTP-метод ему адресован. Например, если отправляется GET-запрос, то выполняется получение данных, DELETE-запрос приводит к удалению данных и т. д.

Чтобы в приложении реализовать функциональность поставщика HTTP-сервиса, используйте элемент проекта вида [`HttpСервис`](http-service-element-20a693318e85.md).

Функциональность потребителя HTTP-сервисов реализуют типы `КлиентHttp`, `ЗапросHttp`, `ОтветHttp` и т. д. ([подробнее](http-requests-2fbe5c3df089.md)).
