### ЗагрузкаДанных

`Доступность: Сервер`

```
ЗагрузкаДанных: ДействиеПриЗагрузкеОбменаДанными
```

При вызове обработчика параметр имеет значение Авто, что означает безусловную загрузку данных. Значение параметра Игнорировать означает, что прочитанные данные не будут загружены. Значение параметра ЗагрузитьЕслиНетКонфликта означает, что данные будут загружены, если не были зарегистрированы изменения данных для узла, от которого получено сообщение.

---

### ОбменДанными

`Доступность: Сервер` `ТолькоЧтение`

```
ОбменДанными: ПараметрыОбменаДанными
```

Используется для управления обменом данных. С помощью данного свойства настраивается состав узлов-получателей, для которых будут регистрироваться изменения данных, узел-отправитель, из которого получена записываемая информация.

---

### ОтправлятьНазад

`Доступность: Сервер`

```
ОтправлятьНазад: Булево
```

Если Истина, то измененное состояние в текущем узле будет передано отправителю По умолчанию Ложь.
