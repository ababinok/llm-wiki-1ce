## Обзор

Используется для управления обменом данных.

## Документированный контракт и примеры

`Стд::ПланыОбмена::ПараметрыОбменаДанными` `Доступность: Сервер`

Используется для управления обменом данных. С помощью данного объекта настраивается состав узлов-получателей, для которых будут регистрироваться изменения данных, узел-отправитель, из которого получена записываемая информация.

## Свойства

### АвтоЗаполнениеПолучателей

`Доступность: Сервер`

```
АвтоЗаполнениеПолучателей: Булево
```

Если значение свойства Истина, то изменения регистрируются для всех узлов планов обмена, в состав которых входит элемент проекта с указанием авторегистрации, значения Получатели игнорируется. По умолчанию Истина

---

### Отправитель

`Доступность: Сервер`

```
Отправитель: ПланОбмена.Ссылка?
```

При записи элемента данных после получения элемента данных из сообщения регистрация изменений должна быть выполнена для всех узлов планов обмена, в состав которых входит объект данных, за исключением того узла, из которого получено изменение. Для того чтобы регистрация изменений для узла-отправителя не выполнялась, необходимо перед записью объекта данных присвоить свойству Отправитель значение ссылки на узел, из которого получено изменение.

#### Примеры

Регистрации изменений, для всех узлов за исключением отправителя

```xbsl
метод ПрочитатьСообщениеОбмена(ПотокФайла: ПотокЧтения)
    знч ЧтениеXml = новый ЧтениеXml(ПотокФайла)
    исп ГрупповаяОперация.Начать(РежимЗагрузкиДанных = Истина)
    
    исп ОбработкаВходящегоСообщенияОбмена = УдаленныеСклады.СоздатьОбработкуВходящегоСообщения(ЧтениеXml)
    пока ЧтениеXml.ВидУзла == ВидУзлаXml.НачалоЭлемента
        если ЧтениеXml.Имя == "Товары.Object"
            // Реализация чтения данных из сообщения, зависит от конкретных данных.            
            знч Данные = ПрочитатьТовары(ЧтениеXml, ОбработкаВходящегоСообщенияОбмена.Отправитель как УдаленныеСклады.Ссылка)
            знч ПараметрыЗаписи = новый Товары.ПараметрыЗаписи()
            ПараметрыЗаписи.ОбменДанными.Отправитель = ОбработкаВходящегоСообщенияОбмена.Отправитель
            Данные.Записать(ПараметрыЗаписи)
        иначе
            ЧтениеXml.Пропустить()   
        ;
    ;
;
```

### Получатели

`Доступность: Сервер` `ТолькоЧтение`

```
Получатели: Множество<ПланОбмена.Ссылка>
```

Используется в зависимости от значения свойства АвтоЗаполнениеПолучателей. Если Ложь, набор узлов, для которых будут регистрироваться изменения при записи или удаления объекта данных. Если Истина игнорируется. При изменении списка получателей если АвтоЗаполнениеПолучателей = Истина выбрасывается исключение

---

## Методы

### ЗаполнитьПолучателей

`Доступность: Сервер`

```
ЗаполнитьПолучателей()
```

Предназначен для заполнения набора узлов. Обращение к данному методу вызывает заполнение набора узлов ссылками на все узлы всех планов обмена, в состав которых входит элемент проекта с указанием авторегистрации. Если АвтоЗаполнениеПолучателей = Истина, то устанавливает его АвтоЗаполнениеПолучателей=Ложь
