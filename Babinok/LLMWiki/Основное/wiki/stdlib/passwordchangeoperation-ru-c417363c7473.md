## Методы

### Начать

`Доступность: Клиент`

```
Начать(
  СтарыйПароль: Строка,
  НовыйПароль: Строка
): СтатусПодтверждаемойОперацииСамообслуживания
```

Начать операцию изменения пароля с указанием старого и нового пароля. Если новый пароль не удовлетворяет политике паролей или передан неправильный старый пароль, вернется неуспешный статус операции с соответствующем сообщением. Если способ входа через логин-пароль отсутствует на данном пользователе, вернется неуспешный статус операции.

---

### ПовторитьОтправкуКодаПодтверждения

`Доступность: Клиент`

```
ПовторитьОтправкуКодаПодтверждения(): СтатусПодтверждаемойОперацииСамообслуживания
```

Повторить отправку кода подтверждения. Если превышено количество попыток отправить код подтверждения, то будет возвращена неуспешный статус операции.

---

### Подтвердить

`Доступность: Клиент`

```
Подтвердить(Код: Строка): СтатусПодтверждаемойОперацииСамообслуживания
```

Подтвердить изменение пароля.
