## Обзор

Операция для удаления устройства из множества доверенных устройства для текущего пользователя.

## Документированный контракт и примеры

## Методы

### Выполнить

`Доступность: Клиент`

```
Выполнить(Описание: Строка): СтатусОперацииСамообслуживания
```

Выполнить операцию удаления устройства из множества доверенных устройства для текущего пользователя. Если устройство с переданным описание не найдено у текущего пользователя, то вернется неуспешный статус операции с соответствующем сообщением. Если удаляется текущее доверенное устройство, с которого выполнен вход, то вернется неуспешный статус операции с соответствующем сообщением.
