### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): ИнтегрируемоеПриложение.Объект?
```

Загружает объект интегрируемого приложения по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](../data/noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.
