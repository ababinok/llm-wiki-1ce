## Обзор

Позволяет формировать печатные формы и конвертировать их в различные форматы.

## Документированный контракт и примеры

`Стд::ТабличныйДокумент::ТабличныйДокумент` `Доступность: Сервер`

Позволяет формировать печатные формы и конвертировать их в различные форматы. Обеспечивается совместимость с 1С:Предприятие 8 (с некоторыми ограничениями).

При работе с табличным документом может возникать ИсключениеТабличногоДокумента. Например, при ошибках экспорта в `Excel` форматах.

```
ПолучитьОбласть(ИмяОбласти: Строка): ОбластьТабличногоДокумента
```

`Неопределено`


Возвращает табличный документ, прочитанный из данные в памяти.

- `Источник`

Для чтения табличного документа с конвертацией оформления, нужно воспользоваться параметром `КонвертироватьОформление` со значением `Истина`. **[ИсключениеВводаВывода](inputoutputexception-ru-ceba5f672999.md)** - При проблемах работы с источником.

### Экспортировать

`Доступность: Сервер`

```
Экспортировать(
  Формат: ФорматЭкспортаТабличногоДокумента,
  ПутьФайла: Строка)
```

Экспортирует табличный документ в файл указанного формата.

- `Формат`
  
  - Формат экспорта табличного документа.
- `ПутьФайла`
  
  - Путь к результирующему файлу.

Экспортируем один и тот же документ во все поддерживаемые форматы:

```xbsl
метод ЭкспортироватьТабличныйДокументВоВсехФорматах(
    Документ: ТабличныйДокумент, 
    ШаблонИмени: Строка = "Путь/К/Каталогу/ТабличныйДокумент"
)
    для Формат из Тип<ФорматЭкспортаТабличногоДокумента>.Элементы()
        Документ.Экспортировать(Формат, "%{ШаблонИмени}_%Формат")
    ;    
;
```

При экспорте табличного документа в PDF будут встроены используемые шрифты. Если шрифт отсутствует в операционной системе, то будет использован шрифт по умолчанию.

```
Экспортировать(
  Формат: ФорматЭкспортаТабличногоДокумента,
  Поток: ПотокЗаписи)
```

Экспортирует табличный документ в поток в указанном формате.

- `Формат`
  
  - Формат экспорта табличного документа.
- `Поток`
  
  - Поток записи, в который будет записан табличный документ в указанном формате.

При экспорте табличного документа в PDF будут встроены используемые шрифты. Если шрифт отсутствует в операционной системе, то будет использован шрифт по умолчанию.

#### Исключения

**[ИсключениеВводаВывода](inputoutputexception-ru-ceba5f672999.md)** - При проблемах работы с вводом-выводом. **[ИсключениеТабличногоДокумента](spreadsheetexception-ru-5cca8ccd5cbf.md)** - При ошибках экспорта табличного документа.
