# Типы

## [Аннотация](annotation-ru-6b10a8deda1f.md)

`Стд::Аннотации::Аннотация` `Доступность: КлиентИСервер`

Базовый тип всех аннотаций. Аннотация - метка в исходном коде. Аннотации могут размещаться на:

- типах
- свойствах
- конструкторах
- константах
- методах
- параметрах
- элементах перечислений

---

## [ИменованныеПараметры](namedparameters-ru-7dc8566ecb6f.md)

`Стд::Аннотации::ИменованныеПараметры` `Доступность: КлиентИСервер`

`Места применения:` Метод, Статический метод, Конструктор

Аннотация, запрещающая вызывать метод/конструктор с позиционной формой параметров. Т.е. в вызове метода/конструктора все параметры должны быть заданы в именованной форме.

---

## [Контекстный](contextual-ru-468258bf9c74.md)

`Стд::Аннотации::Контекстный` `Доступность: КлиентИСервер`

`Места применения:` Метод

Аннотация Контекстный. Может быть размещена только на не статических методах, исполняется только на сервере. Должна быть использована только в паре с аннотацией [НаСервере](onserver-ru-ff4072dae1ed.md). Может быть использована в паре с аннотацией [ДоступноСКлиента](availablefromclient-ru-e1a5a666d615.md), в таком случае метод исполняется на сервере, но доступен для вызова с клиента (т.е. присутствует и в клиентском и серверном окружениях). Аннотация доступна только в модулях пользовательских компонентов интерфейса.

`Стд::Аннотации::Обработчик` `Доступность: КлиентИСервер`

## [Подписка](subscription-ru-9e7e7a49ab5d.md)

`Стд::Аннотации::Подписка` `Доступность: КлиентИСервер` `Повторяемая`

`Места применения:` Статический метод

Аннотация подписки на событие. Данная аннотация может быть размещена на статических методах или методах модулей типов-одиночек. Подписка позволяет выполнять действия при возникновении события, не меняя основной обработчик события, задаваемый с помощью аннотации [Обработчик](handler-ru-c623088e34ee.md) Подписки запускаются после отработки основного обработчика события в той же транзакции. Порядок запуска подписок не определен. На одно событие можно создать несколько подписок в одном или нескольких проектах. С помощью механизма подписок можно подписываться на события следующих объектов:

- Справочники
- Документы
- Планы обмена
- Хранилища настроек
- Регистры сведений
- Пользователи
- Контракты сущностей
