## Методы

### ВСтроку

`Доступность: КлиентИСервер`

```
ВСтроку(): Строка
```

Стабильное, не зависящее от локали и иных настроек представление объекта в виде строки. По умолчанию: полное имя типа (с пространством имен), для стандартных типов - на английском языке.

---

### ПолучитьТип

`Доступность: КлиентИСервер`

```
ПолучитьТип(): Тип
```

Возвращает тип текущего экземпляра объекта.

---

### Представление

`Доступность: КлиентИСервер`

```
Представление(): Строка
```

Представление объекта в виде строки, по умолчанию равносилен вызову метода

[ВСтроку](object-ru-9e351f286699.md)

.
