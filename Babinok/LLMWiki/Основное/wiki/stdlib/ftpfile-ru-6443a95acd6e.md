## Свойства

### Изменен

`Доступность: Сервер` `ТолькоЧтение`

```
Изменен: Момент
```

Момент последнего изменения файла или директории.

---

### Имя

`Доступность: Сервер` `ТолькоЧтение`

```
Имя: Строка
```

Имя файла или директории.

---

### ИмяБезРасширения

`Доступность: Сервер` `ТолькоЧтение`

```
ИмяБезРасширения: Строка
```

Имя файла без расширения.

---

### Размер

`Доступность: Сервер` `ТолькоЧтение`

```
Размер: РазмерБайтов?
```

Размер файла в байтах. Для каталога - `Неопределено`.

---

### Расширение

`Доступность: Сервер` `ТолькоЧтение`

```
Расширение: Строка
```

Расширение файла.

---

## Методы

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Возвращает имя файла или директории.

**Переопределение** [Объект::ВСтроку](object-ru-9e351f286699.md)

---

### ЭтоКаталог

`Доступность: Сервер`

```
ЭтоКаталог(): Булево
```

Проверяет, является ли запись каталогом.

---

### ЭтоФайл

`Доступность: Сервер`

```
ЭтоФайл(): Булево
```

Проверяет, является ли запись файлом.
