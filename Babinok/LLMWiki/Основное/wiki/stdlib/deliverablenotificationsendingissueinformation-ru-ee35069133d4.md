## Свойства

### ВидОшибки

`Доступность: Сервер`

```
ВидОшибки: ВидОшибкиОтправкиДоставляемогоУведомления
```

Содержит вид ошибки, возникшей при запросе на отправку конкретного уведомления конкретному получателю.

---

### Описание

`Доступность: Сервер`

```
Описание: Строка
```

Подробное описание возникнувшей ошибки, (если есть).

---

### Получатели

`Доступность: Сервер`

```
Получатели: ЧитаемыйМассив<ИдПодписчикаДоставляемыхУведомлений>
```

Массив получателей, запрос на отправку уведомления для которых завершился неудачно с одним и тем же типом ошибки.

---

### Уведомление

`Доступность: Сервер`

```
Уведомление: ДоставляемоеУведомление?
```

Уведомление, при отправке которого возникла проблема.
