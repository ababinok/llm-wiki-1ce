## Конструкторы

### АдресПочты

`Доступность: Сервер`

```
АдресПочты(Адрес: Строка)
```

Создает объект с адресом электронной почты

`Адрес`

.

#### Исключения

**[ИсключениеАдресаПочты](emailaddressexception-ru-5fd482a6cbc1.md)** - при неверном формате.

**Перегрузка** [АдресПочты(Адрес: Строка, ОтображаемоеИмя: Строка)](emailaddress-ru-000c5864525b.md)

---

### АдресПочты

`Доступность: Сервер`

```
АдресПочты(
  Адрес: Строка,
  ОтображаемоеИмя: Строка)
```

Создает объект с адресом электронной почты

`Адрес`

и отображаемым именем

`ОтображаемоеИмя`

владельца адреса.

#### Исключения

## Методы

### ВСтроку

`Доступность: КлиентИСервер`

```
ВСтроку(): Строка
```

Возвращает строковое представление в виде:

- `"<%Адрес>"`
  
  - если ОтображаемоеИмя пусто
- `"%ОтображаемоеИмя <%Адрес>"`
  
  - иначе

**Переопределение** [Объект::ВСтроку](object-ru-9e351f286699.md)
