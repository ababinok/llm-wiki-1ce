## Свойства

### Исключение

`Доступность: Сервер` `ТолькоЧтение`

```
Исключение: ИсключениеОтправкиПочты?
```

Исключение, возникшее во время отправки сообщения, или `Неопределено`, если ошибки не было.

---

### Сообщение

`Доступность: Сервер` `ТолькоЧтение`

```
Сообщение: Письмо
```

Сообщение, статус которого описывает данный объект.

`Доступность: Сервер`

