## Свойства

### ДанныеИзображения

`Доступность: Сервер`

```
ДанныеИзображения: Байты?
```

Данные изображения. Поддерживаются изображения следующих форматов:

- BMP
- EMF
- GIF
- Icon
- JPEG
- PNG
- SVG
- TIFF
- WMF

Не поддерживаются картинки указанных форматов:

- Картинки формата ICO, содержащие изображения в формате PNG
- Картинки формата BMP, использующие тип сжатия данных JPEG и PNG

---

### ПрозрачныйФон

`Доступность: Сервер`

```
ПрозрачныйФон: Булево
```

Признак прозрачности фона изображения.
