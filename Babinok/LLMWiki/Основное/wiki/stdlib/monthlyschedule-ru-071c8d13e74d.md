## Обзор

Расписание запусков в указанное время указанных дней указанных месяцев.

## Документированный контракт и примеры

`Стд::Расписания::ЕжемесячноеРасписание` `Доступность: КлиентИСервер`

Расписание запусков в указанное время указанных дней указанных месяцев. Создается через методы объекта [Расписание](schedule-ru-f8ef0f9119e6.md).

**Сравнение**

Структурное

## Примеры

**Общие примеры**

```xbsl
// Расписание запуска в 8 утра в первый и последний день каждого месяца.
знч Расписание1 = Расписание.Ежемесячно(
        Время{8:00},
        Месяцы = новый Множество(Месяц.Элементы()),
        ДниВМесяце = {-1, 1})

// Расписание запуска в 8 утра в первый и третий понедельник каждого месяца.
знч Расписание2 = Расписание.Ежемесячно(
        Время{8:00},
        Месяцы = новый Множество(Месяц.Элементы()),
        НеделиМесяца = {НеделяМесяца.Первая, НеделяМесяца.Третья},
        ДниНедели = {ДеньНедели.Понедельник})
        
пер Задание = ЗапланированныеЗадания.Создать(&МойМодуль.МойМетод)
Задание.Настроить(Ключ = "МоеЗадание", Расписание = [Расписание1, Расписание2])
Задание.Запланировать()
```

## Свойства

### ДниВМесяце

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ДниВМесяце: ЧитаемоеМножество<Число>
```

Дни месяца запуска задание. Числа в диапазоне -28..-1 и 1..31. Положительные числа - дни месяца (1 - первый день, 2 - второй день и т.д.). Отрицательные числа дни с конца предыдущего месяца (-1 - последний день предыдущего месяца, -2 предпоследний день и т.д.) Задается при создании расписания.

---

### ДниНедели

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ДниНедели: ЧитаемоеМножество<ДеньНедели>
```

Дни недели запуска задания. Задается при создании расписания.

---

### ЗапуститьВ

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ЗапуститьВ: Время
```

Время запуска задания. Задается при создании расписания.

---

### Месяцы

```
Месяцы: ЧитаемоеМножество<Месяц>
```

Месяцы запуска задания. Задается при создании расписания.

---

### НеделиМесяца

`Доступность: КлиентИСервер` `ТолькоЧтение`
