## Обзор

Структура, которая описывает настройки для поиска и оформления фрагментов текста.

## Документированный контракт и примеры

## Конструкторы

### НастройкиФрагментовПолнотекстовогоПоиска

`Доступность: Сервер`

```
@ИменованныеПараметры
НастройкиФрагментовПолнотекстовогоПоиска(
  РазмерФрагмента: Число = 100,
  ОткрывающийТег: Строка = "<b>",
  ЗакрывающийТег: Строка = "</b>",
  МаксимальноеКоличествоФрагментов: Число = 3,
  ВидФрагмента: ВидФрагментаПолнотекстовогоПоиска = ВидФрагментаПолнотекстовогоПоиска.Html)
```

Полный конструктор. Все параметры имеют значение по умолчанию.

## Свойства

### ВидФрагмента

`Доступность: Сервер` `ТолькоЧтение`

```
ВидФрагмента: ВидФрагментаПолнотекстовогоПоиска
```

В каком виде нужен фрагмент текста; влияет на то, какие символы и как будут кодироваться и/или экранироваться. Например, для html и xml угловые скобки кодируются как `&gt` и `&lt`, а для простого текста этого не требуется. Поддерживаемые значения: Xml, Html, Text.

---

### ЗакрывающийТег

`Доступность: Сервер` `ТолькоЧтение`

```
ЗакрывающийТег: Строка
```

Закрывающий тег после слова для его подсветки (выделения).

---

### МаксимальноеКоличествоФрагментов

`Доступность: Сервер` `ТолькоЧтение`

```
МаксимальноеКоличествоФрагментов: Число
```

Максимальное количество независимых фрагментов текста, которое можно генерировать по одному документу. Чем больше фрагментов текста мы генерируем, тем большее количество ключевых слов мы можем подсветить (выделить). Допустимые значения в пределах от 1 до 1000.

---

### ОткрывающийТег

`Доступность: Сервер` `ТолькоЧтение`

```
ОткрывающийТег: Строка
```

Открывающий тег перед словом для его подсветки (выделения).

---

### РазмерФрагмента

`Доступность: Сервер` `ТолькоЧтение`

```
РазмерФрагмента: Число
```

Максимальный размер одного фрагмента текста в символах. Допустимые значения в пределах от 1 до 1000000.
