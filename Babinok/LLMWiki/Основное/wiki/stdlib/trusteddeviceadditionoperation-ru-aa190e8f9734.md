Операция для добавления доверенного устройства для текущего пользователя.

## Методы

### Выполнить

`Доступность: Клиент`

```
Выполнить(): СтатусОперацииСамообслуживания
```

Выполнить операцию добавления доверенного устройства для текущего пользователя. Если устройство уже добавлено в доверенные, вернется неуспешный статус операции с соответствующем сообщением.
