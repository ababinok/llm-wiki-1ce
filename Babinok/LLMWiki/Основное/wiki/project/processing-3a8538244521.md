## Обзор

Элемент проекта вида «Обработка» — это объект конфигурации, предназначенный для обработки данных на стороне сервера.

## Документированный контракт и примеры

Элемент проекта вида «Обработка» — это объект конфигурации, предназначенный для обработки данных на стороне сервера. Он позволяет автоматизировать работу с данными: удалять, сохранять и создавать данные по заданному алгоритму ([подробнее](processing-project-element-acb124c72bfa.md)).

Обработка может содержать [Реквизиты](processing-3a8538244521.md) и [Операции](processing-3a8538244521.md), а также **форму обработки**, с помощью которой можно вводить параметры, влияющие на ход алгоритма обработки, и отображать результаты. Сам алгоритм обработки задается в модуле объекта обработки.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

```yaml

    Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Группа свойств, которые описывают пользовательский интерфейс обработки.

<summary>**Свойства**</summary>

##### Представление

Заголовок кнопки, соответствующей данной операции. Если не указано, то используется свойство операции **Имя**.

Признак включения формы в [автоматический интерфейс](../interface/automatic-interface-df2ea881a675.md).

##### Изображение

Ссылка на картинку, отображаемую на кнопке.

Форма обработки.

</details>
