## Обзор

Контекстное обсуждение — это обсуждение, привязанное к какому-либо объекту приложения, например к документу или элементу справочника.

## Документированный контракт и примеры

Контекстное обсуждение — это обсуждение, привязанное к какому-либо объекту приложения, например к документу или элементу справочника. Обсуждение в виде текстовых сообщений отображается в форме выбранного объекта для всех пользователей, у которых есть права доступа к объекту. В данный момент контекстное обсуждение поддерживается в Документах и Справочниках.

## Объектная модель контекстного обсуждения

Сопоставление контекстных обсуждений системы взаимодействия происходит по навигационным ссылкам объектов обсуждения в форматах «1С:Предприятия 8» и «1С:Предприятие.Элемента» соответственно.

Ссылки формируются в следующих обработчиках объектных сущностей:

- `ВычислитьВнешнююНавигационнуюСсылку()` — вычисляет навигационную ссылку на объект внешней системы по ссылке на сущность;
  
  Вычисление внешней навигационной ссылки для «Элемента»
  
  ```xbsl
  @Обработчик
  метод ВычислитьВнешнююНавигационнуюСсылку(Ссылка: Заказчики.Ссылка): ВнешняяНавигационнаяСсылка?
      пер ИдЭлементаПроекта = "e7e6077a-d4c2-4f55-adf0-b1357d87b30e"
      возврат ВнешняяНавигационнаяСсылка.Элемент(новый Ууид(ИдЭлементаПроекта), Ссылка.Ид)
  ;
  ```
  
  Вычисление внешней навигационной ссылки для «1С:Предприятия 8»
  
  ```xbsl
  @Обработчик
  метод ВычислитьВнешнююНавигационнуюСсылку(Ссылка: Контрагенты.Ссылка): ВнешняяНавигационнаяСсылка?
      пер ИмяМетаданногоV8 = "Справочник.Контрагенты"
      возврат ВнешняяНавигационнаяСсылка.Предприятие8(ИмяМетаданногоV8, Ссылка.Ид)
  ;
  ```
- `ВычислитьСсылкуПоВнешнейНавигационнойСсылке()` — вычисляет ссылку на сущность по внешней навигационной ссылке.
  
  ```xbsl
  @Обработчик
  метод ВычислитьСсылкуПоВнешнейНавигационнойСсылке(НавигационнаяСсылка: ВнешняяНавигационнаяСсылка): Контрагенты.Ссылка?
      пер ИмяМетаданногоV8 = "Справочник.Контрагенты"
      если НавигационнаяСсылка.Вид == ВидВнешнейНавигационнойСсылки.Элемент
          // Если внешняя система — «Элемент», по идентификатору внешней ссылки возвращаем ссылку на элемент
          возврат Контрагенты.ПолучитьСсылку(НавигационнаяСсылка.ИдСсылки)
      иначе
          // Если внешняя система — «1С:Предприятие 8», проверяем идентификатор сущности
          // и по идентификатору ссылки ищем объект
          если НавигационнаяСсылка.ИдСущности != ИмяМетаданногоV8
              возврат Неопределено
          ;
          знч ИД = НавигационнаяСсылка.ИдСсылки
          // Поиск и возврат объекта по идентификатору
      ;
      возврат Неопределено
  ;
  ```

Внешняя навигационная ссылка описывается объектом типа [`ВнешняяНавигационнаяСсылка`](../stdlib/externalnavigationlink-ru-b293721d5224.md). Тип имеет следующие свойства:

- [`Вид`](../stdlib/externalnavigationlink-ru-b293721d5224.md)
  
  — вид внешней навигационной ссылки (принимает значения
  
  [`ВидВнешнейНавигационнойСсылки.Предприятие8`](../stdlib/externalnavigationlinkkind-ru-5eecd0666842.md)
  
  и
  
  [`ВидВнешнейНавигационнойСсылки.Элемент`](../stdlib/externalnavigationlinkkind-ru-5eecd0666842.md)
  
  );
- [`ИдСсылки`](../stdlib/externalnavigationlink-ru-b293721d5224.md)
  
  — идентификатор ссылки во внешней системе;
- [`ИдСущности`](../stdlib/externalnavigationlink-ru-b293721d5224.md)
  
  — идентификатор сущности во внешней системе (например,
  
  Справочник.Сотрудники
  
  для внешней системы
  
  `1С:Предприятие 8`
  
  или идентификатор элемента проекта
  
  Справочник
  
  `1e4a7f58-0142-466b-b88f-e7ae79c2fdcb`
  
  для внешней системы
  
  `1С:Предприятие.Элемент`
  
  ).

Для создания внешних навигационных ссылок в форматах «1С:Предприятия 8» и «1С:Предприятие.Элемента» используйте следующие методы типа [`ВнешняяНавигационнаяСсылка`](../stdlib/externalnavigationlink-ru-b293721d5224.md):

- [`Предприятие8()`](../stdlib/externalnavigationlink-ru-b293721d5224.md)
  
  ,
- [`Элемент()`](../stdlib/externalnavigationlink-ru-b293721d5224.md)
  
  .

На основании внешней навигационной ссылки можно создать объект типа [`КонтекстОбсужденияВзаимодействия`](../integration/collaborationconversationcontext-ru-4a47514c5c25.md) с помощью конструктора:

```xbsl
КонтекстОбсужденияВзаимодействия(Ключ: Строка|ВнешняяНавигационнаяСсылка)
```

## Пример реализации контекстного обсуждения между двумя системами

В этом примере мы покажем, как организовать контекстное обсуждение между «1С:Предприятием 8» и «1С:Предприятие.Элементом».

### Пользовательский сценарий

Реализуем следующий пользовательский сценарий:

- В обеих системах есть справочник
  
  Сотрудники
  
  . В
  
  «Элементе»
  
  в регистре сведений
  
  СопоставлениеИдентификаторовСВ
  
  содержатся данные, позволяющие сопоставить объекты двух систем.
- В обоих справочниках
  
  Сотрудники
  
  есть запись
  
  Иванов Иван Иванович
  
  .
- В «1С:Предприятии 8» открываем форму объекта с наименованием
  
  Иванов Иван Иванович
  
  и пишем сообщение в контекстном обсуждении.
- В
  
  «Элементе»
  
  открываем соответствующий элемент справочника и видим сообщение из «1С:Предприятия 8». Пишем и отправляем ответное сообщение.
- В «1С:Предприятии 8» проверяем получение ответного сообщения из
  
  «Элемента»
  
  .

### Подготовка проекта в «1С:Предприятии 8»

1. [Скачайте](https://doc-files.1cmycloud.com/downloads?state=element/%D0%BA%D0%BE%D0%BD%D1%82%D0%B5%D0%BA%D1%81%D1%82%D0%BD%D1%8B%D0%B5_%D0%BE%D0%B1%D1%81%D1%83%D0%B6%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.dt) готовую информационную базу проекта для «1С:Предприятия 8».
2. Откройте «1С:Предприятие 8». [Создайте пустую информационную базу](https://its.1c.ru/db/v8326doc#bookmark:adm:TI000000094) **Demo Контекстное обсуждение** и откройте ее в **Конфигураторе**.
3. Загрузите скачанный файл информационной базы: **Администрирование** → **Загрузить информационную базу**.
4. После перезапуска **Конфигуратора** выполните вход с именем пользователя **Яковлев**. Пароль оставьте пустым.
5. Откройте конфигурацию: **Конфигурация** → **Открыть конфигурацию**.
6. Запустите проект.
7. Проверьте, что в справочнике есть запись **Иванов Иван Иванович**.
  
  
  
  Сохраните идентификатор этого элемента `c0f6e12f-e9f4-11ef-bc3e-08bfb833c67f`, он понадобится позднее.

  // Имя справочника в «1С:Предприятии 8»
  конст ИмяМетаданногоV8 = "Справочник.Сотрудники"
  
  @Обработчик
  метод ВычислитьВнешнююНавигационнуюСсылку(Ссылка: Сотрудники.Ссылка): ВнешняяНавигационнаяСсылка?

          ВЫБРАТЬ
              Сопоставление.УуидВнешнейСистемы КАК Идентификатор
          ИЗ
              СопоставлениеИдентификаторовСВ КАК Сопоставление
          ГДЕ
              Сопоставление.Объект == %Ссылка
      }
  
      пер ИдентификаторИзЗапроса = Запрос.Выполнить().Первый().Идентификатор
  
      // Получаем внешнюю навигационную ссылку в формате «1С:Предприятия 8»
      возврат ВнешняяНавигационнаяСсылка.Предприятие8(ИмяМетаданногоV8, ИдентификаторИзЗапроса)
  ;
  
  @Обработчик
  метод ВычислитьСсылкуПоВнешнейНавигационнойСсылке(НавигационнаяСсылка: ВнешняяНавигационнаяСсылка): Сотрудники.Ссылка?
      // Если внешняя система — «1С:Предприятие 8», получаем ссылку на объект из запроса к регистру сведений
      // Если внешняя система — «Элемент», получаем ссылку по идентификатору ссылки
      если НавигационнаяСсылка.Вид == ВидВнешнейНавигационнойСсылки.Предприятие8
          // Если ссылка не соответствует заданной сущности, возвращаем Неопределено

          если НавигационнаяСсылка.ИдСущности != ИмяМетаданногоV8
              возврат Неопределено
          ;
          знч Идентификатор = НавигационнаяСсылка.ИдСсылки
          знч Запрос = Запрос{
              ВЫБРАТЬ
                  Сопоставление.Объект КАК Объект
              ИЗ
                  СопоставлениеИдентификаторовСВ КАК Сопоставление
              ГДЕ
                  Сопоставление.УуидВнешнейСистемы == %Идентификатор
          }

### Настройка системы взаимодействия

Настройте систему взаимодействия:

1. Зарегистрируйте приложение «1С:Предприятия 8» в системе взаимодействия. Для этого перейдите в справочник **Сотрудники** и в главном меню выберите пункт **Функции для технического специалиста** → **Стандартные** → **Управление системой взаимодействия**.
  
  Меню «Функции для технического специалиста» в приложении «1С:Предприятия 8» используется для перехода к стандартному управлению системой взаимодействия. [Описание иллюстрации](../../raw/figures/2e979129a90def06f3410489906ef9242b311399fa2699b6f7cf1402584f2b3f-5e5cfc5b4995f19c.md)
  
  Укажите адрес электронной почты и наименование приложения. Получите код подтверждения и введите его в соответствующее поле.
  
  
2. [Зарегистрируйте приложение](../integration/register-application-in-collaboration-system-4a6e06152ce5.md) «Элемента» в системе взаимодействия.
3. Объедините приложения в «1С:Предприятии 8». В разделе **Функции для технического специалиста** перейдите в раздел **Совместное использование приложений**.
  
  В управлении системой взаимодействия выбран пункт «Совместное использование приложений». [Описание иллюстрации](../../raw/figures/dbf852ff13cf9a80ddcb7894a698932c6fba169d377de7e554f6b1069e16933d-2943d136a8563305.md)
  
  Выберите нужные приложения, поставьте галочку напротив пункта **Сопоставление предметных обсуждений** и нажмите **ОК**.
  
  Диалог совместного использования приложений: отмечены нужные приложения и «Сопоставление предметных обсуждений»; ниже отдельно задаётся сопоставление пользователей, завершение — «ОК». [Описание иллюстрации](../../raw/figures/d922a3b9e18d57e51970bdbbc9dbef8ebfa67ba17c4330c2f5c3937cdc5597f7-3f60a58fbc7f310e.md)
