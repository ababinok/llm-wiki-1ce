## Обзор

*Метки* — это ключевые слова или теги, с помощью которых вы можете организовать, категоризировать и приоритизировать задачи проекта.

## Документированный контракт и примеры

*Метки* — это ключевые слова или теги, с помощью которых вы можете организовать, категоризировать и приоритизировать задачи проекта.

В данной статье мы рассмотрим, как создавать метки, добавлять их к задачам, редактировать существующий список меток, удалять метки, а также использовать их для фильтрации задач в проекте.

## Добавить метки к задаче

Вы можете назначать метки как на этапе создания задачи, так и при ее редактировании. Чтобы создать метку, выполните следующие действия:

1. Откройте диалог для [создания новой задачи проекта](create-issue-57a918108fb3.md) или [редактирования существующей](edit-issue-30041d46e164.md).
2. В поле **Метки** начните вводить имя метки. Если в проекте уже есть метки, то во время ввода вам будет показываться список сохраненных ранее значений, которые соответствуют вводимым символам. Вы можете кликнуть по одному из предложений, чтобы быстро завершить ввод, или же ввести свой текст полностью, чтобы создать новую метку.
  
  При вводе имени метки показываются сохранённые предложения, совпадающие с введёнными символами; можно выбрать предложение или закончить ввод новой метки. [Описание иллюстрации](../../raw/figures/30933a2fb9c5a19a12162fc8eadc16f7e6f4b78c9f845092669ea2c0c1b5cb97-493adc7158e1403f.md)
3. Нажмите **Enter** или знак **+** рядом с полем ввода, чтобы завершить создание новой метки. Метка будет добавлена к текущей задаче и станет доступна для всех остальных задач проекта.
  
  В поле «Метки» введено новое имя метки, справа кнопка плюса завершает создание; существующие метки показаны отдельными элементами с кнопками удаления. [Описание иллюстрации](../../raw/figures/dbe525be36b499d4f37ba8de31178285c8a21e68a4a72ef1c0c7ce319055081f-e2f4b2cc3a8f910e.md)

## Просмотреть и отредактировать список меток для задачи

Если вы хотите посмотреть метки, добавленные к какой-либо задаче, нажмите на эту задачу в списке всех задач проекта на вкладке **Задачи**. В открывшемся окне вы можете ознакомиться с основными сведениями о задаче и увидеть назначенные ей метки.

В карточке задачи метки расположены справа под исполнителем, в разделе «Метки». [Описание иллюстрации](../../raw/figures/c2164bc024c0a05fac165d7e655ad4e1c45f78d337593d32ba658aad6f16c987-4b28d6a0f93aa3e6.md)

Если вы хотите отредактировать список меток, нажмите на значокПиктограмма «Значок меню». [Описание иллюстрации](../../raw/figures/eeec48637e32c4f2ec0cc9ade2b45debe2df98791c721a93c2826cace650091a-7826430e32669bbb.md) в правом верхнем углу окна и выберите пункт **Редактировать задачу**.

В меню карточки задачи выбран пункт «Редактировать задачу» для изменения её данных, включая метки. [Описание иллюстрации](../../raw/figures/377907fd391b14568d23b09e01e3f53248a7e613f122514da8bdbe0f3e6e7220-9c43691709d696f6.md)

Будет открыт [диалог редактирования текущей задачи](edit-issue-30041d46e164.md). Перейдите к полю **Метки**, [удалите ненужные метки](add-labels-to-issue-515c0f6e341f.md) и добавьте актуальные. Нажмите кнопку **Сохранить**, чтобы сохранить изменения.

## Использовать метки для фильтрации задач

Чтобы отфильтровать задачи проекта по меткам, нажмите кнопку **Фильтры** на вкладке **Задачи**. В выпадающем списке поля **Метки** выберите нужные метки и нажмите **Применить**. В результате будет выведен список всех задач, содержащих указанные метки.

## Удалить метки

Если задача содержит неактуальный список меток, вы можете удалить ненужные метки следующим образом:

1. Откройте [диалог редактирования задачи](edit-issue-30041d46e164.md).
2. Перейдите к полю **Метки**. Нажмите на крестик рядом с именем нужной метки, чтобы удалить ее.
  
  В поле меток нажата кнопка «×» у выбранной метки для удаления её из задачи. [Описание иллюстрации](../../raw/figures/edb18e3999eb4a56315a63d1b5bf652f4f8ba437d0f3dfac6baa82a6f0344ffc-adc6a865b2582a96.md)
3. Нажмите кнопку **Сохранить**, чтобы сохранить изменения.
