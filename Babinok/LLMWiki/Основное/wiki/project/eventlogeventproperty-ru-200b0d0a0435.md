## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Тип

```yaml
Тип: Тип<Булево|ХарактерОшибки|ВажностьСобытияЖурналаСобытий|ВидСобытияЖурналаСобытий|Число|Строка|Длительность|Момент|Ууид>
```

Тип значения свойства.

---

#### ЗначениеПоУмолчанию

```yaml
ЗначениеПоУмолчанию: Объект
```

Значение свойства по умолчанию. Указанное значение будет записано в журнал событий, если явно не указано другое.

---

#### Обязательное

```yaml
Обязательное: Булево
```

Признак обязательности свойства у события данного типа.

---

#### Описание

```yaml
Описание: Строка|СсылкаНаЛокализованнуюСтроку
```

Человекочитаемое описание свойства события. Необязательное свойство. При обращении к свойству события используется то описание, которое было актуально на момент регистрации события. Локализуется.
