## Обзор

В отличие от веб-клиента, который не требует сборки и установки, мобильное приложение нужно сначала собрать, а затем установить на мобильное устройство.

## Документированный контракт и примеры

В отличие от веб-клиента, который не требует сборки и установки, мобильное приложение нужно сначала собрать, а затем установить на мобильное устройство.

После того как вы создали проект приложения, добавили в него [пакет мобильного приложения](mobile-application-package-f0570db86779.md) и выполнили публикацию, перейдите в панель управления. Вы можете собрать мобильное приложение для двух платформ: Android и iOS. После запуска сборки вы получите готовое приложение, которое можно загрузить на устройство или в магазин приложений.

## Параметры доступа к компьютеру Apple Mac

> [!NOTE] дополнительно
> Приложения для платформы iOS могут быть собраны только с использованием компьютера Apple Mac. Если вы собираете приложение для Android или iOS на компьютере Apple Mac, вы можете пропустить этот этап и сразу перейти к секции [**Сборка**](build-mobile-app-bdb51dd3d670.md). Если вы собираете мобильное приложение для платформы iOS, но при этом используете компьютер с ОС Windows или Linux, то вам необходимо установить удаленное подключение к компьютеру Apple Mac, на котором будет осуществляться сборка.

В панели управления перейдите на вкладку **Инфраструктура** ⟶ **Мобильные** и нажмите **+ Добавить компьютер Mac**:

Вкладка «Инфраструктура» в панели управления [Описание иллюстрации](../../raw/figures/e00c65f702a89577643c3d856ecd1223d5353ccf73fe025e965635e2bde09df7-30f684edb4d4649f.md)

В открывшемся окне введите:

- Наименование
  
  — наименование компьютера, которое будет отображаться в
  
  «1С:Предприятие.Элементе»
  
  .
- Адрес
  
  — адрес компьютера Apple Mac. На этом компьютере должен быть включен доступ по протоколу SSH.
- Порт
  
  — номер порта для подключения по протоколу SSH.
- Имя пользователя
  
  — имя пользователя, от имени которого будет осуществляться доступ по протоколу SSH.
- Пароль
  
  — пароль пользователя, от имени которого будет осуществляться доступ по протоколу SSH.
- Максимальное количество одновременных сборок
  
  .



Нажмите **Записать и закрыть**.

На компьютере Apple Mac во время сборки в домашнем каталоге пользователя будет создан каталог с именем в виде случайно созданного GUID. В него будут загружены артефакты, необходимые для подписания сборки. Далее будет выполнено подписание, и результат передан обратно. Каталог будет удален.

> [!NOTE] примечание
> На компьютере Apple должна быть установлена программа Xcode. Получить пакет можно на [официальном сайте](https://developer.apple.com/xcode/). Также вам следует убедиться, что разрешен доступ к компьютеру по SSH.

## Сборка

Осуществить сборку мобильного приложения можно из нескольких мест:

1. В панели управления выберите в меню **Мобильные** ⟶ **Мобильные приложения** и нажмите **+ Создать мобильное приложение**:
  
  Вкладка «Мобильные» в панели управления [Описание иллюстрации](../../raw/figures/b90507d557fd3e04edb944255975fb616e543609b631a746a24ee02ef56abb23-6b67ffb866c30044.md)
2. В карточке приложения перейдите на вкладку **Мобильные** и нажмите **+ Новое мобильное приложение**:
  
  В карточке приложения на вкладке «Мобильные» выделена кнопка «Новое мобильное приложение». [Описание иллюстрации](../../raw/figures/f7b123d53f638af07307c8e52de56807f221b189abc4a413b38b94eb3a2f1c0a-0e7c5dacb3611b8f.md)

В открывшемся окне заполните все необходимые параметры сборки:

- Приложение
  
  — наименование приложения, для которого необходимо собрать мобильный клиент.
- Приложение в проекте
  
  — наименование клиентского приложения, для которого определен пакет мобильного приложения.
- Наименование
  
  — наименование мобильного приложения, которое будет отображаться в
  
  «1С:Предприятие.Элементе»
  
  .
- Имя файла пакета
  
  — имя файла, который будет получен в результате сборки. Данный файл вы затем сможете скачать и установить на телефон либо выложить в магазин приложений.
- Адрес публикации
  
  — адрес приложения, к которому будет подключаться мобильное приложение. Можно указать адрес приложения, отличного от приложения для текущей сборки.
- Номер сборки
  
  .

Форма создания мобильного приложения: слева выбор приложения и приложения в проекте, наименование, имя файла пакета (латиницей без пробелов) со значением MobileApp, адрес публикации и номер сборки 1. [Описание иллюстрации](../../raw/figures/6bc8ca2cf6c2eaf02cc4969f4d249905622e29cef8609c190fd1a4b39b356aac-f43b58a79241b6c6.md)

#### Ключ подписи и ключ загрузки приложения

- **Ключ подписи** — это ключ, с помощью которого подписывается собранное приложение в виде apk-файла. Ключ подписи приложения никогда не меняется в течение всего времени существования вашего приложения. Ключ подписи хранится в виде хранилища ключей Java и представляет из себя двоичный файл, который служит хранилищем сертификатов и закрытых ключей. Ключ подписи приложения является конфиденциальной информацией и должен храниться в секрете.
- **Ключ загрузки приложения** — это ключ, который будет использован для подписи пакета приложений во время сборки пакета. Ключ загрузки записан в виде хранилища ключей Java и представляет из себя двоичный файл, который служит хранилищем сертификатов и закрытых ключей. Ключ загрузки приложения является конфиденциальной информацией и должен храниться в секрете. Однако, существует возможность предоставить третьим лицам сертификат криптографии, созданный с помощью вашего ключа загрузки.

Эти ключи вам следует сгенерировать самостоятельно с использованием утилиты keytool, которая входит в состав Java SDK / JRE. Пример создания ключей с использованием командной строки Windows:

```powershell
@REM Название хранилища ключей:
set STORE_FILE=app.jks
@REM Пароль хранилища ключей:
set STORE_PASS=123456
@REM Название ключа подписи:
set SIGNING_KEY_NAME=signing
@REM Пароль ключа подписи:
set SIGNING_KEY_PASS=123456
@REM Имя ключа загрузки:
set UPLOAD_KEY_NAME=upload
@REM Пароль ключа загрузки:
set UPLOAD_KEY_PASS=123456

keytool -keystore %STORE_FILE% -storepass %STORE_PASS% -genkey -alias %SIGNING_KEY_NAME% -keypass %SIGNING_KEY_PASS% -keyalg RSA -keysize 2048 -validity 10000
keytool -keystore %STORE_FILE% -storepass %STORE_PASS% -genkey -alias %UPLOAD_KEY_NAME% -keypass %UPLOAD_KEY_PASS% -keyalg RSA -keysize 2048 -validity 10000
```

Сгенерированные ключи вам также следует загрузить в ваш [аккаунт разработчика](https://play.google.com/console) Google Play.

## Добавление учетной записи в магазинах приложений

Для того чтобы публиковать приложения в магазины, вам необходимо создать в магазине учетную запись разработчика.

В «1С:Предприятие.Элементе» вы можете добавить учетные записи магазинов App Store либо Google Play. Это необходимо для того, чтобы после сборки мобильного приложения вы могли сразу выгрузить его в магазин приложений.

Чтобы добавить новую учетную запись, выберите в меню **Мобильные** ⟶ **Учетные записи в магазинах приложений** и нажмите **+ Создать**:

В панели управления открыт раздел «Мобильные» → «Учётные записи в магазинах приложений»; кнопка «Создать» добавляет учётную запись. [Описание иллюстрации](../../raw/figures/51d07470dfb104cd67e3c8d7940528624f276009fc5c42bc56c6f157f9d13f7b-e8ae064621c57b36.md)

Укажите:

- Наименование
  
  — наименование учетной записи, которое будет отображаться в
  
  «1С:Предприятие.Элементе»
  
  .
- Тип
  
  — тип магазина: App Store либо Google Play.
- Логин
  
  — логин вашей учетной записи.
- Пароль
  
  (для App Store) — пароль от вашей учетной записи.
- Ключ подписи
  
  (для Google Play) — сертификат в формате
  
  p12
  
  .

Создание учетной записи магазина приложений [Описание иллюстрации](../../raw/figures/aab3e6f4905253cba612f58708fbe4d6cc82e9dd674a88a7638e3702410af6bc-2c9e88635ed00e34.md)

Нажмите **Готово**.

Теперь вы можете загрузить собранное приложение в магазин. Для этого на вкладке **Мобильные** перейдите на страницу нужного мобильного приложения. Здесь вы можете выбрать сборку и загрузить ее в магазин приложений.

Далее следует перейти в магазин приложений и выполнить публикацию загруженного приложения ([Google Play](https://play.google.com/apps/publish/), [App Store](https://appstoreconnect.apple.com/)).

> [!NOTE] примечание
> В общем случае описание работы с файлами приложений и консолью разработчика вы можете получить в справочной системе соответствующего магазина: [Google Play](https://support.google.com/googleplay/android-developer), [App Store](https://developer.apple.com/support/).
