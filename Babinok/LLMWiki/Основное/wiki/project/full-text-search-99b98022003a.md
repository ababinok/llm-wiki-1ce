## Документированный контракт и примеры

Полнотекстовый поиск данных — это инструмент «1С:Предприятие.Элемента», позволяющий выполнять поиск записей в базе данных по их текстовым представлениям.

Механизм полнотекстового поиска включает:

- программные средства для формирования полнотекстового индекса и его периодического обновления;
- программные средства для поиска по полнотекстовому индексу и оформления результатов поиска;
- полнотекстовый индекс, содержащий текстовые представления всех записей базы данных.

### Настройка режимов поиска

Для настройки поиска нажмите на значок шестеренки рядом с кнопкой **Найти**. Доступны следующие опции:

- **Соблюдать порядок слов в запросе**
  
  Первыми в результатах поиска будут отображаться записи, в которых слова представлены в том же порядке, что и в запросе. Опция аналогична поиску строгой последовательности нескольких слов, заключенных в кавычки `""`, например: **"звонок клиенту"**.
- **Добавлять поиск по началу слова**
  
  К результатам совпадения целых слов добавляются совпадения по началу слова. Например, по запросу **Пара** можно также найти слова **Парапсихолог** и **Паранормальный**. Опция аналогична добавлению знака `*` к начальной части слова, например: **Пара***.
- **Искать только по заголовкам**
  
  В заголовках представлена наиболее важная информация, необходимая и достаточная для успешного поиска. Кроме того, поиск по заголовкам быстрее.
- **Строгий поиск окончаний в словах**
  
  Режим поиска слов в заданной падежной форме. Например, по запросу **Ивановой** не будут найдены слова **Иванов**, **Иванову**, **Ивановым**. Опция аналогична использованию одинарных кавычек `''`, например: **'Ивановой'**.
- **Нечеткий поиск**
  
  Режим поиска опечаток и орфографических ошибок. Например, по запросу **Тролинг** будут найдены слова **Троллинг**, **Тротлинг**, **Скролинг**. Опция аналогична нечеткому поиску с помощью знака `~`, например: **~клент** или **клент~**.
- **Показывать фрагменты**
  
  Без фрагментов текста отображение более компактное, скорость пролистывания страниц выше. В любом режиме просмотр расширенного фрагмента доступен в представлении **С деталями**.
- **Поиск синонимов**
  
  Режим поиска синонимов по каждому слову поискового запроса. Активируется с помощью знака `!`, например: **!ГОСТ**.
  
  [Подробнее о словаре синонимов](full-text-search-99b98022003a.md)

## Выполнение полнотекстового поиска в коде

Для работы с функциями полнотекстового поиска используется тип-одиночка [`ПолнотекстовыйПоиск`](../stdlib/fulltextsearch-ru-c78a302cd212.md). Методы данного типа позволяют выполнить все необходимые операции по управлению и использованию полнотекстового поиска: проверить актуальность поискового индекса, получить количество непроиндексированных изменений, перестроить индекс и вызвать функцию поиска.

Для выполнения полнотекстового поиска вызовите метод [`Искать()`](../stdlib/fulltextsearch-ru-c78a302cd212.md) и укажите поисковое выражение в виде строки или экземпляра структуры [`ЗапросПолнотекстовогоПоиска`](../queries/fulltextsearchquery-ru-4d8590fefbc7.md). Вы также можете настроить результаты поиска и задать область поиска.

Пример поиска по справочнику **Сотрудники**:

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ВыполнитьПоиск(СтрокаПоиска: Строка): ЧитаемыйМассив<Сущность.Ключ>
    возврат ПолнотекстовыйПоиск.Искать(ПоисковыйЗапрос = СтрокаПоиска, ИндексСтраницы = 0, 
                                       РазмерСтраницы= 50, ОбластьПоиска = [Тип<Сотрудники.Ссылка>])
;
```

## Настройки результатов полнотекстового поиска

Чтобы настроить результаты поиска, используйте свойства типа [`НастройкиРезультатаПолнотекстовогоПоиска`](../stdlib/fulltextsearchresultoptions-ru-44aadb7696df.md):

- [`ПолучатьЗаголовки`](../stdlib/fulltextsearchresultoptions-ru-44aadb7696df.md)
  
  — указывает, нужно ли возвращать заголовки (краткое представление) по каждой найденной записи.
- [`ПолучатьФрагменты`](../stdlib/fulltextsearchresultoptions-ru-44aadb7696df.md)
  
  — указывает, нужно ли возвращать фрагменты текста с подсветкой найденных вхождений. Для получения оформленного набора фрагментов используйте метод
  
  [`ЭлементРезультатаПолнотекстовогоПоиска.Представление()`](../stdlib/fulltextsearchresultitem-ru-4768069fde33.md)
  
  .
- [`ПолучатьФрагментыПоСвойствам`](../stdlib/fulltextsearchresultoptions-ru-44aadb7696df.md)
  
  — указывает, нужно ли заполнять массив
  
  [`ЭлементРезультатаПолнотекстовогоПоиска.ФрагментыПоСвойствам`](../stdlib/fulltextsearchresultitem-ru-4768069fde33.md)
  
  , в котором фрагменты текста разделены по свойствам. Используйте данный режим, если вам требуется получить метаданные по свойствам и информацию по каждому фрагменту в контексте свойства.
- [`НастройкиФрагментов`](../stdlib/fulltextsearchresultoptions-ru-44aadb7696df.md)
  
  — позволяет настроить представление найденных фрагментов текста.

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ВыполнитьПоиск(Запрос: Строка): Массив<Строка>
    // Настройка результатов полнотекстового поиска
    знч НастройкиРезультата = новый НастройкиРезультатаПолнотекстовогоПоиска(
                    ПолучатьЗаголовки = Истина,
                    ПолучатьФрагменты = Истина,
                    НастройкиФрагментов = новый НастройкиФрагментовПолнотекстовогоПоиска(
                        ВидФрагмента = ВидФрагментаПолнотекстовогоПоиска.Html,
                        МаксимальноеКоличествоФрагментов = 10,
                        РазмерФрагмента = 150,
                        ОткрывающийТег = "<strong>",
                        ЗакрывающийТег = "</strong>"))

    знч МассивФрагментовТекста = <Строка>[]
    
    // Выполнение поиска с заданными настройками
    знч РезультатПоиска = ПолнотекстовыйПоиск.Искать(
                новый ЗапросПолнотекстовогоПоиска(
                    Запрос = Запрос,
                    ИндексСтраницы = 0,
                    РазмерСтраницы = 50),
                НастройкиРезультата)
    
    // Заполнение массива найденных фрагментов текста
    для Элемент из РезультатПоиска.Порция
        МассивФрагментовТекста.Добавить(Элемент.Представление())
    ;
    
    возврат МассивФрагментовТекста
;
```

## Словарь синонимов

«1С:Предприятие.Элемент» поддерживает динамический словарь синонимов. Он разделен на отдельные тематические словари, которые хранятся в базе данных в системной таблице. При использовании или изменении (при вызове метода [`УстановитьСловарьСинонимов()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)) все словари объединяются.

> [!NOTE] примечание
> Делить словарь на темы необязательно. Пользователь может поддерживать один общий словарь.

Словарь синонимов можно задать в виде текстового файла, который удовлетворяет следующим требованиям:

- Файл содержит многострочный текст. Рекомендуемый разделить строк —
  
  `\r\n`
  
  .
- Каждая строка — это группа синонимов, разделенных
  
  `,`
  
  или
  
  `;`
  
  , после которых может быть пробел.
- Допускаются пустые строки.
- Синонимы рекомендуется указывать в именительном падеже.
- Синонимы могут состоять из нескольких слов.

Кроме того, действуют следующие ограничения:

- Допускается использовать буквы, цифры и символы
  
  `-`
  
  и
  
  `_`
  
  .
- Максимальная длина группы синонимов — 1000 символов.
- Максимальное количество элементов в группе синонимов — 100 элементов.
- Максимальная длина одного синонима — 500 символов.

Пример словаря:

```text
ГосВетИнспекция, ВетИнспекция, Государственная ветинспекция, Государственная ветеринарная инспекция
ГОСТ, Государственный стандарт
компания, организация, фирма
компания, команда, коллектив

партнер, компаньон, напарник, товарищ
словарь, глоссарий
```

Если слово может употребляться в разном контексте (например, **компания**) и входит в несколько групп синонимов, при поиске группы объединяются в одну общую.

Пример работы со словарем


## Представление результатов полнотекстового поиска

Найденные в результате поиска фрагменты текста могут быть представлены следующими способами:

- Собраны в стандартное представление с помощью метода [`Представление()`](../stdlib/fulltextsearchresultitem-ru-4768069fde33.md) типа [`ЭлементРезультатаПолнотекстовогоПоиска`](../stdlib/fulltextsearchresultitem-ru-4768069fde33.md). По умолчанию составной фрагмент оформляется так:
  
  - Все разрывы фрагментов обозначаются троеточием
    
    `...`
    
    .
  - Табличные части выводятся в сокращенном виде:
    
    `Представление: ...Вхождение1... ...Вхождение2...`
    
    .
  - Если запись найдена по основному тексту, среди фрагментов будут свойства с выделенными (подсвеченными) вхождениями.
  - Если запись найдена не по основному тексту, тогда выводятся несколько первых наиболее приоритетных свойств без выделения вхождений.
- Разделены по свойствам: будет заполнен массив [`ЭлементРезультатаПолнотекстовогоПоиска.ФрагментыПоСвойствам`](../stdlib/fulltextsearchresultitem-ru-4768069fde33.md). В одном свойстве может быть более одного текстового фрагмента. Фрагмент может быть полным значением свойства. Вместе с фрагментом также предоставляется список вхождений.
- Собраны в одно представление с помощью метода [`ПостроитьПредставление()`](../stdlib/fulltextsearchresult-ru-38eac12853e8.md) типа [`РезультатПолнотекстовогоПоиска`](../stdlib/fulltextsearchresult-ru-38eac12853e8.md). Используйте данный метод, если вам требуется настроить вывод результатов поиска. Вы можете указать разделитель свойств и символы для разрыва текста слева, справа и в середине; включить в представление дополнительные свойства; вывести фрагменты по табличным частям в упрощенном виде. Пример:
  
  ```xbsl
  @НаСервере @ДоступноСКлиента
  статический метод ВыполнитьПоиск(Запрос: Строка): Массив<Строка>
      знч МассивФрагментовТекста = <Строка>[]
      
      // Выполнение поиска
      знч РезультатПоиска = ПолнотекстовыйПоиск.Искать(
                  новый ЗапросПолнотекстовогоПоиска(
                      Запрос = Запрос,
                      ИндексСтраницы = 0,
                      РазмерСтраницы = 50)
                  )
      
      // Заполнение массива найденных фрагментов текста 
      // c настройкой их представления
      для Элемент из РезультатПоиска.Порция
          знч Представление = РезультатПолнотекстовогоПоиска.ПостроитьПредставление(
                  ИсточникФрагментов = Элемент, 
                  РазрывТекстаВСередине = "...",
                  РазделительСвойств = "<br/>")
          МассивФрагментовТекста.Добавить(Представление)
      ;
      
      возврат МассивФрагментовТекста
  ;
  ```

## Поддержка актуальности индекса полнотекстового поиска

Чтобы поиск работал корректно, необходимо поддерживать индекс полнотекстового поиска в актуальном состоянии. Для этого необходимо добавлять в индекс новую информацию (новые объекты информационной базы), удалять устаревшие данные (которые располагались в удаленных объектах) и обновлять сведения об измененных объектах информационной базы.

Для работы с полнотекстовым индексом в «1С:Предприятие.Элементе» предусмотрены следующие методы типа [`ПолнотекстовыйПоиск`](../stdlib/fulltextsearch-ru-c78a302cd212.md):

- [`ИндексАктуален()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — возвращает
  
  `Истина`
  
  , если поисковый индекс актуален, то есть он существует, полностью построен и соответствует текущему состоянию данных приложения.
- [`ИндексБылАктуален()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — возвращает
  
  `Истина`
  
  , если были проиндексированы данные хотя бы по одному событию, которое появилось в логе изменений за последний период. Данный метод рекомендуется использовать, если поисковый индекс меняется слишком часто.
- [`КоличествоИзменений()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — возвращает количество непроиндексированных изменений на текущий момент времени.
- [`ПерестроитьИндекс()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — запускает фоновое задание для полного перестроения поискового индекса.
- [`ПолучитьТекущуюТочкуИзменений()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — возвращает точку в логе изменений полнотекстового поиска на текущий момент времени.
- [`ЖдатьЗавершенияОбновленияИндекса()`](../stdlib/fulltextsearch-ru-c78a302cd212.md)
  
  — ожидает обновления индексной базы до момента, обозначенного параметром
  
  `ТочкаИзменений`
  
  .

**Пример 1**. Перестроение индекса полнотекстового поиска:

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ПерестроитьПолнотекстовыйИндекс()
    ПолнотекстовыйПоиск.ПерестроитьИндекс()
;
```

**Пример 2**. Полное обновление индекса полнотекстового поиска:

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ОбновитьПолнотекстовыйИндекс()
    знч Точка = ПолнотекстовыйПоиск.ПолучитьТекущуюТочкуИзменений()
    пока не ПолнотекстовыйПоиск.ЖдатьЗавершенияОбновленияИндекса(Точка, 5с)
    ;
;
```

По умолчанию обновление полнотекстового индекса происходит автоматически при внесении изменений в приложение. Ручное обновление индекса может потребоваться, если, например, в кластере серверов запрещен автозапуск фоновых заданий.
