## Обзор

**Избранное** — место, куда пользователь может добавлять объекты, которые хочет сохранить для быстрого доступа.

## Документированный контракт и примеры

**Избранное** — место, куда пользователь может добавлять объекты, которые хочет сохранить для быстрого доступа. В **Избранное** можно добавлять формы, сущности и произвольные ссылки.

Команда добавления в **Избранное** отображается по умолчанию во всех формах.

Видимость команды открытия **Избранного** для определенного элемента определяется его свойством **ВажностьИзбранногоПользователя**. Возможные значения:

- [`ВажностьИзбранногоПользователя.Отсутствует`](../interface/userfavoritesimportance-ru-55a73563da0e.md)
  
  —
  
  Избранное
  
  не отображается;
- [`ВажностьИзбранногоПользователя.Обычная`](../interface/userfavoritesimportance-ru-55a73563da0e.md)
  
  — в формах появляется индикатор слева от заголовка и дополнительная команда в панели команд, в клиентском приложении — иконка в панели действий;
- [`ВажностьИзбранногоПользователя.Высокая`](../interface/userfavoritesimportance-ru-55a73563da0e.md)
  
  — в формах появляется команда слева от заголовка (или первая в списке дополнительная команда в мобильном приложении), в клиентском приложении — иконка в панели действий.

Свойства пересекаются и используются в порядке важности. Значение свойства проверяется в следующем порядке:

- для сущностей и списка сущностей
  
  : форма → сущность → клиентское приложение;
- для формы
  
  : форма → клиентское приложение.

Применяется первое найденное значение. Если значение не задано ни на одном из уровней, используется `ВажностьИзбранногоПользователя.Обычная`.

## Ограничения

Для **Избранного** действуют следующие ограничения:

- В приложениях, не требующих аутентификации, иконка
  
  Избранного
  
  и команды добавления в
  
  Избранное
  
  не отображаются, независимо от значений свойств
  
  ВажностьИзбранногоПользователя
  
  .

- Если вы размещаете команду добавления в **Избранное** на форме создания объекта, пользователь может получить не тот результат, который ожидает: в **Избранное** будет добавляться форма создания объекта, а не сам объект. Поэтому при добавлении в **Избранное** формы создания объекта отображается окно с предупреждением:
  
  Предупреждение «Добавить форму создания объекта?» поясняет: в избранное добавляется форма создания; чтобы добавить сам объект, сначала его сохранить. [Описание иллюстрации](../../raw/figures/713a1b8123f6d580602531cb079760de29129307f51b077be5a0eb9953f7d09e-9668a6dea0daf0a5.md)

- Удаленные объекты отображаются в **Избранном**, но при открытии такого объекта показывается предупреждение:
  
  Предупреждение при открытии удаленного объекта в избранном [Описание иллюстрации](../../raw/figures/d3337acce114f9a1a72acc5a656b7088e77800ec65e3aa876a917c35b76216ba-1fc9daa28cb5fe5f.md)
- Поиск в **Избранном** выполняется по представлениям объектов, навигационных ссылок и папок.
  
  Панель «Избранное»: значок поиска раскрывает поле ввода, по введённой строке отобраны подходящие представления объектов или ссылок. [Описание иллюстрации](../../raw/figures/d805681b99a8cb8a5990dc64192f7b8a724369efac2251786937844c129deb9b-e2b1c5db912f0f9b.md)

## Настройка избранного

Чтобы открыть настройки **Избранного**, нажмите на значок шестеренки в правом верхнем углу окна **Избранное**.

### Как создать папку и переместить в нее элементы

В окне настройки **Избранного** можно создавать папки и добавлять в них элементы **Избранного**. Для этого нажмите на ссылку **+ Создать** → **Новая папка**. Задайте имя папки и нажмите **Создать**.

Далее выделите в списке **Избранного** нужный элемент, в меню нажмите **Переместить** и выберите папку, в которую необходимо перенести элемент.

В настройке избранного выбран элемент и раскрыто меню «Переместить» со списком папок; в примере элемент переносится в папку «Сделки». [Описание иллюстрации](../../raw/figures/f361f44d3457276c1ef45c39ad18ea2a35906b776f450894c9716caf15cc3522-29af1dd1ef97aeb4.md)

### Как редактировать и удалить элементы и папки

Чтобы отредактировать элемент или папку, выделите нужную строку в списке **Избранного** и в меню вверху нажмите **Редактировать**.

Чтобы удалить элемент из списка **Избранного**, нажмите кнопку **Удалить** в верхнем меню. При удалении папки отображается окно с предупреждением о том, что все элементы в папке будут также удалены:

Как удалить папку из избранного [Описание иллюстрации](../../raw/figures/b424515615a57a50375108117626853c58b69df5fa7be079d64a733f22abc3ca-f4fcd61dd769e7d7.md)

### Как закрепить элементы и изменить их расположение

И папки, и отдельные элементы можно закреплять, чтобы они отображались в начале списка **Избранного**. Для этого выберите нужный элемент или папку и в меню вверху нажмите **Закрепить**.

Чтобы переместить элемент выше или ниже по списку, используйте соответствующие кнопки меню **Вверх** и **Вниз**.

Как закрепить или изменить расположение элемента [Описание иллюстрации](../../raw/figures/a3b761e23cac641fcecc23f3c76a784312f897d9efe59f43ba59e1d1737bb32a-bc1124ffcf9f46d1.md)

### Как добавить в избранное произвольную HTTP-ссылку

Вы можете добавить в **Избранное** произвольную HTTP-ссылку. Для этого нажмите на ссылку **+ Создать** и выберите **Новая ссылка**. Заполните нужные поля и нажмите **Создать**.

Как добавить ссылку в избранное [Описание иллюстрации](../../raw/figures/b66c76eedbd453f4b45d0b371926bcbff1cea621767623014af51b2912036571-939fb99a250e119a.md)

## Примеры использования избранного в коде

Для работы с **Избранным** в коде используется тип [`ИзбранноеПользователя`](../interface/userfavorites-ru-e71189e469ca.md).

Добавление в избранное нового объекта

```xbsl
метод ДобавитьВИзбранное(Задача: Задачи.Ссылка?)
    если ИзбранноеПользователя.Найти(Задача) == Неопределено
        ИзбранноеПользователя.Записать(Задача)
    ;
;
```

Добавление в избранное формы

```xbsl
метод ДобавитьФормуВИзбранное(СписокЗадач: ЗадачиФормаСписка)
    знч МассивЗаписей = ИзбранноеПользователя.ЗагрузитьВсе()
    
    знч ФормаЗаказовЭлемент = новый ЭлементИзбранногоПользователя(
        Ид = новый Ууид(),
        Ссылка = НавигационнаяСсылка.Относительная(СписокЗадач),
        Представление = "Список задач",
        Закреплено = Истина)
    
    МассивЗаписей.Вставить(0, ФормаЗаказовЭлемент)

    ИзбранноеПользователя.ЗаписатьВсе(МассивЗаписей)
;
```
