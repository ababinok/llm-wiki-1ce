## Обзор

Хеширование — это процесс преобразования входных данных (например, строки, файла или любого другого типа информации) в выходные данные фиксированного размера, называемые хешем или хеш-значением.

## Документированный контракт и примеры

Хеширование — это процесс преобразования входных данных (например, строки, файла или любого другого типа информации) в выходные данные фиксированного размера, называемые хешем или хеш-значением. Хеширование используется для хранения паролей, цифровых подписей, проверки целостности и быстрого поиска данных.

## Вычисление хеша данных

Для вычисления хеша данных в «1С:Предприятие.Элементе» используется тип [`ХешированиеДанных`](../stdlib/datahashing-ru-4a3be6c45827.md). Чтобы вычислить хеш данных, создайте объект для хеширования с помощью конструктора [`ХешированияДанных()`](../stdlib/datahashing-ru-4a3be6c45827.md). В нем укажите [`АлгоритмХеширования`](../stdlib/hashalgorithm-ru-1f971c731c9e.md):

- `Md5`
  
  ,
- `Sha1`
  
  ,
- `Sha256`
  
  ,
- `Sha512`
  
  ,
- `Гост3411_2012_256`
  
  ,
- `Гост3411_2012_512`
  
  .

Криптопровайдер подбирается автоматически в зависимости от указанного алгоритма. Чтобы самостоятельно задать криптопровайдер, передайте его в качестве аргумента перегрузки конструктора [`ХешированияДанных()`](../stdlib/datahashing-ru-4a3be6c45827.md). Если указанный криптопровайдер не поддерживает выбранный алгоритм, выбрасывается исключение [`ИсключениеКриптографии`](../stdlib/cryptoexception-ru-9269fbee8009.md).

> [!NOTE] примечание
> Для работы криптопровайдеров требуется установить на сервере соответствующие модули ([подробнее](https://1cmycloud.com/console/help/element/10.0/docs/topics/cryptography-modules/)).

После создания объекта хеширования добавьте в него данные с помощью метода [`ДобавитьДанные()`](../stdlib/datahashing-ru-4a3be6c45827.md). Вы также можете указать используемую [кодировку](supported-encodings-0f8910737ada.md).

Результат хеширования хранится в свойстве [`Результат`](../stdlib/datahashing-ru-4a3be6c45827.md) объекта типа [`ХешированиеДанных`](../stdlib/datahashing-ru-4a3be6c45827.md).

Пример вычисления хеша данных, полученных из файла

```xbsl
исп СодержимоеФайла = новый Файл("<Путь к файлу>").ОткрытьПотокЧтения()
знч Хеш = новый ХешированиеДанных(АлгоритмХеширования.Sha1)
              .ДобавитьДанные(СодержимоеФайла)
              .Результат
```

## Вычисление кода аутентификации сообщения с использованием алгоритма HMAC

В «1С:Предприятие.Элементе» реализован механизм вычисления кода аутентификации сообщения с помощью хеш-функции — HMAC. Использование HMAC позволяет гарантировать, что сообщение не было модифицировано и исходит от подлинного источника.

Чтобы вычислить код аутентификации сообщения с помощью хеш-функции, используйте объект типа [`ВычислительHmac`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md):

```xbsl
// Создание объекта типа ВычислительHmac
// с применением ключа "СекретныйКлюч" и алгоритма хеширования SHA256
// и вычисление кода аутентификации для строки "12345678900987654321"

знч Вычислитель = новый ВычислительHmac("СекретныйКлюч".ВБайты(), АлгоритмХеширования.Sha256)
знч Результат = Вычислитель.ПолучитьРезультат("12345678900987654321".ВБайты())
```

В объект типа [`ВычислительHmac`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md) можно добавлять данные частями, используя метод [`ДобавитьДанные()`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md), а затем вычислить результат HMAC для всех добавленных данных с помощью метода [`ПолучитьРезультат()`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md):

```xbsl
знч Вычислитель = новый ВычислительHmac("СекретныйКлюч".ВБайты(),
                                        АлгоритмХеширования.Sha256)
Вычислитель.ДобавитьДанные("1234567890".ВБайты())
Вычислитель.ДобавитьДанные("0987654321".ВБайты())
знч Результат = Вычислитель.ПолучитьРезультат()
```

Метод [`ПолучитьРезультат()`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md) в качестве параметра может принимать поток данных:

```xbsl
исп Поток = новый Файл("<Путь к файлу>").ОткрытьПотокЧтения()
знч Вычислитель = новый ВычислительHmac("СекретныйКлюч".ВБайты(),
                                        АлгоритмХеширования.Sha256)
знч Результат = Вычислитель.ПолучитьРезультат(Поток)
```

Для небольшого объема данных используется статический метод [`Вычислить()`](../stdlib/hmaccalculator-ru-ec9441cb4e40.md):

```xbsl
знч РезультатСтатический = ВычислительHmac.Вычислить("1234567890".ВБайты(),
                                                     "Ключ".ВБайты(),
                                                     АлгоритмХеширования.Sha256)
```
