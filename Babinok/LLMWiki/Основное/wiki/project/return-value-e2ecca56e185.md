## Обзор

Возвращаемое значение — это результат, который метод передает в вызывающий код после выполнения.

## Документированный контракт и примеры

Возвращаемое значение — это результат, который метод передает в вызывающий код после выполнения. Метод может возвращать значение любого типа или не возвращать ничего. Для явного указания того, что метод не возвращает значение, можно использовать ключевое слово [`ничто`](void-keyword-730057a75f40.md). Тип возвращаемого значения указывается в сигнатуре метода после символа двоеточия.

```xbsl
// Метод с возвращаемым значением типа Число
метод Сумма(А: Число, Б: Число): Число
    возврат А + Б
;

// Метод без возвращаемого значения
метод ПоменятьМестами(А: Число, Б: Число)
    пер Временное = А
    А = Б
    Б = Временное
;

// Метод без возвращаемого значения с явным указанием типа «ничто»
метод ЗаполнитьСлучайными(Массив: Массив<Число>, Мин: Число, Макс: Число): ничто
    пер Генератор = новый СлучайныйГенератор()
    для Индекс = 0 по Массив.Размер()-1
        Массив[Индекс] = Мин + Генератор.СлучайноеЧисло(Мин, Макс)
    ;
;
```
