## Процесс установки

Начнется запуск «Установщика». «Установщик» кроссплатформенный, он имеет одинаковый (насколько это возможно) графический интерфейс на всех перечисленных операционных системах.



Через некоторое время «Установщик» покажет название и характеристики устанавливаемой версии «1С:Предприятие.Элемента».

Нажмите на значок шестеренки, чтобы установить дополнительные компоненты, например [«Менеджер хостов внешних компонент»](install-external-component-host-manager-e43cb4411eb9.md).

Название и характеристики устанавливаемой версии [Описание иллюстрации](../../raw/figures/917aeaa7acf7a991633fa6c400b43d1d1295c58cf1501e7962a0aebb098dd5bc-f4db4ed02a9856a2.md)

### Проверка цифровой подписи

Все компоненты комплекта поставки подписываются цифровой подписью. «Установщик» проверяет эту подпись и отображает результат проверки рядом с названием версии.

Положительный результат проверки цифровой подписи обозначен зелёным значком сертификата рядом с названием версии в установщике. [Описание иллюстрации](../../raw/figures/bdd5c34d2dba1a292a7035b21deefa422b4ac9d2db2789b4f5c0ec4e27aa087a-95623cfc87b8acb5.md)

Если отображается зеленая «медаль», значит, цифровая подпись успешно проверена и вы можете устанавливать дистрибутив.

Если отображается красный треугольник, значит, цифровая подпись не прошла проверку.

В установщике рядом с дистрибутивом показан красный треугольник: отрицательный результат проверки цифровой подписи. [Описание иллюстрации](../../raw/figures/dc81c4fc73628180d09da7cdf234255085b781e2ce141a3a5f2fbcd8e7c95e5e-920c491acf1f02f2.md)

В этом случае вы тоже можете установить дистрибутив, но на свой страх и риск. Цифровая подпись может не пройти проверку по двум причинам: либо файлы дистрибутива были скомпрометированы (то есть это не те файлы, которые поставляет фирма «1С»), либо на вашем компьютере неправильно настроена проверка цифровых подписей. Настоятельно не рекомендуем устанавливать скомпрометированные дистрибутивы. Нажмите на красный треугольник, и вы получите более подробную информацию о проверке цифровой подписи по каждому компоненту, входящему в комплект поставки.

### Назначение домашней директории установки при первом запуске

Только при первом запуске нового «Установщика» вы можете выбрать домашнюю директорию, в которую будут устанавливаться все версии «1С:Предприятие.Элемента» и другие программы. Отдельная собственная домашняя директория, которую использует «Установщик», позволяет всегда иметь только одну копию «1С:Предприятие.Элемента» некоторой версии, без дублирования.

При следующих запусках «Установщика» вы уже не сможете изменить домашнюю директорию в его диалоге. Но при необходимости вы можете перенести домашнюю директорию на любой диск, поставив ссылку на файловой системе на первоначальную директорию.



### Установка

Чтобы начать установку, нажмите **Установить**. О ходе установки вас будет информировать индикатор.

Окно установщика Элемента: индикатор показывает текущий ход установки и копирования файлов. [Описание иллюстрации](../../raw/figures/42a0173f98567a1126d9c6fe55158ede5e3f863229d827f7d11459bf228911cb-44dec1abf198df06.md)

Когда установка закончится, ее результат будет показан на экране. Вы можете перейти по ссылке **Панель управления будет доступна после запуска**, чтобы дождаться запуска сервера и [изменить](https://1cmycloud.com/console/help/element/10.0/docs/topics/change-administrator-password/) пароль администратора.

Финальная страница установщика сообщает «Установка завершена!» и «Установка завершена успешно». [Описание иллюстрации](../../raw/figures/065245877580d3104976c87b9234c499ad1cb0cadb9dea844764cb50dfa7023f-f3530a28ec437368.md)

## Результат установки

После установки сервер будет запущен автоматически, поэтому вы можете:

- [проверить](https://1cmycloud.com/console/help/element/10.0/docs/topics/functionality-check/)
  
  его работоспособность из браузера (серверу требуется некоторое время для запуска);
- [изменить](https://1cmycloud.com/console/help/element/10.0/docs/topics/change-administrator-password/)
  
  пароль администратора.

В результате установки на компьютере будут созданы два каталога:

- Каталог исполняемых файлов сервера. Он содержит, в частности:
  
  - исполняемый файл (скрипт) для запуска сервера;
  - каталог
    
    instance-template
    
    , в котором находится шаблон экземпляра сервера. Этот шаблон вы можете использовать для запуска других экземпляров сервера на этом же компьютере.
- Каталог экземпляра сервера
  
  . Изначально в него копируется
  
  instance-template
  
  , а после запуска этот каталог содержит всю информацию об исполняющемся экземпляре сервера.

Кроме этих каталогов будет создан и запущен сервис (демон) для исполнения сервера. Для его запуска будет создан пользователь USR1CE (usr1ce).

В разных операционных системах каталоги и службы имеют разные имена:

- Windows
- Linux

Каталог исполняемых файлов сервера (версия поставляемого сервера может отличаться от указанной здесь версии):

```text
C:\Program Files\1C\1CE\components\1c-enterprise-element-server-with-ide-2.0.1-rc+32-x86_64
```

Каталог экземпляра сервера:

```text
C:\ProgramData\1C\1CE\instances\1c-enterprise-element-server-with-ide
```

Служба сервера:

```text
1c-enterprise-element-server-with-ide
```
