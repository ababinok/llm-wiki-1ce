## Обзор

Проверку значения на неопределенность следует выполнять через равенство или неравенство, а не с помощью операций `это` или `это` `не`:

## Документированный контракт и примеры

Проверку значения на неопределенность следует выполнять через равенство или неравенство, а не с помощью операций `это` или `это` `не`:

Правильно. [Описание иллюстрации](../../raw/figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер Значение: Объект?
// ...
если Значение == Неопределено
    пер Результат = "Это Неопределено"
;
```

Неправильно. [Описание иллюстрации](../../raw/figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер Значение: Объект?
// ...
если Значение это Неопределено
    пер Результат = "Это Неопределено"
;
```

Правильно. [Описание иллюстрации](../../raw/figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер Значение: Объект?
// ...
если Значение != Неопределено
    пер Результат = "Это другое значение"
;
```

Неправильно. [Описание иллюстрации](../../raw/figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер Значение: Объект?
// ...
если Значение это не Неопределено
    пер Результат = "Это другое значение"
;
```
