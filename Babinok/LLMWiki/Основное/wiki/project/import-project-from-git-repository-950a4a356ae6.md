## Обзор

В среду разработки можно импортировать уже существующий проект из внешнего Git-репозитория.

## Документированный контракт и примеры

В среду разработки можно импортировать уже существующий проект из внешнего Git-репозитория. Для этого выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. Нажмите **Проекты** ⟶ **+ Добавить проект** ⟶ **Импортировать из Git-репозитория**.
3. К репозиторию можно обратиться по протоколам SSH или HTTP.
  
  - Подключение по HTTP
  - Подключение по SSH
  
  Заполните следующие поля:
  
  - Адрес git-репозитория
    
    .
  - Логин пользователя и пароль
    
    для доступа к репозиторию. В качестве пароля вы также можете указать
    
    [персональный токен](create-gitlab-token-66fabd491403.md)
    
    (
    
    Personal access token
    
    ) или
    
    [токен доступа к проекту](create-gitlab-token-66fabd491403.md)
    
    (
    
    Project access token
    
    ).
  - Имя пользователя/электронная почта для коммитов
    
    — если оставить эти поля пустыми, то будут использованы имя пользователя и электронная почта, указанные в панели управления.
  - Используется HTTP прокси-сервер
    
    — активируйте эту настройку, если вы хотите использовать прокси-сервер для доступа к репозиторию. Введите сетевой адрес и порт прокси-сервера. Если для подключения требуется аутентификация, укажите имя пользователя и пароль.
  - Основная ветка разработки
    
    — основная ветка репозитория. Все изменения (реализация нового функционала и исправление ошибок) либо изначально делаются в этой ветке, либо вливаются в нее из других веток проекта. После указания настроек подключения к репозиторию вы можете обновить список существующих веток и выбрать основную ветку из списка.
  - Префикс задач проекта
    
    — уникальный префикс, который будет добавляться в начало номера каждой
    
    задачи
    
    через дефис «-».
  - Настройка использования задач и веток
    
    — позволяет настроить работу с ветками и задачами проекта. По умолчанию включены все возможности, кроме интеграции по HTTP API. В дальнейшем вы можете изменить свой выбор в
    
    [настройках репозитория проекта](set-up-collaborative-development-62562bbfba3b.md)
    
    .
  
  Импорт проекта из Git-репозитория [Описание иллюстрации](../../raw/figures/a51ef2a297b9b84e26a4d06e7c797f104b011ff2b931b389b878dedb3e85ca8a-6d1fc20079e643b4.md)
4. Нажмите **Импортировать**. «1С:Предприятие.Элемент» оповестит вас, что импорт начался, и через некоторое время вы увидите новый проект в списке.
  
  Уведомление о начале импорта проекта [Описание иллюстрации](../../raw/figures/a27c2c27faf61607d07c40151fc3516866a14955e6c9e0d3a662974cb2313848-a0b320fb6dd8c906.md)
