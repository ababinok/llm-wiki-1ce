## Обзор

Аргумент — это значение, которое указывается во время вызова метода.

## Документированный контракт и примеры

Аргумент — это значение, которое указывается во время вызова метода.

Аргументы бывают:

- позиционные
  
  и
  
  именованные
  
  ,
- обязательные
  
  и
  
  необязательные
  
  .

```xbsl
метод НастроитьНовоеУстройство(Имя: Строка, Адрес: Строка, Порт = 8080, Включено = Ложь): Строка
    возврат "Устройство: ${Имя} (${Адрес}:${Порт}), Статус: ${Включено ? "Вкл" : "Выкл"}"
;

метод Скрипт()
    // Позиционные обязательные аргументы
    НастроитьНовоеУстройство("Сервер", "192.168.1.1") // Устройство: Сервер (192.168.1.1:8080), Статус: Выкл
    
    // Именованные аргументы. Адрес и Имя — обязательные, Порт и Включено — необязательные
    НастроитьНовоеУстройство(Адрес = "10.0.0.1", Имя = "Роутер", Включено = Истина, Порт = 80)
    // Устройство: Роутер (10.0.0.1:80), Статус: Вкл
;
```
