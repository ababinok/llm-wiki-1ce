---

## Литералы

#### Этап

Может быть назначена только на размерность. Значения размерности формируют названия этапов воронки.

---

#### Значение

Может быть назначена только на факт. Значения факта определяют размеры этапов воронки.

---

#### Маркеры

Может быть назначена только на поле с ролью **Этап** или **Значение**.

При установке на размерность с ролью **Этап** рядом с этапами отображаются значения размерности.

При установке на факт с ролью **Значение** внутри этапов отображаются значения факта.

---

#### Цвет

Может быть назначена только на поле с ролью **Этап**. При наличии все этапы воронки раскрашиваются в разные цвета.
