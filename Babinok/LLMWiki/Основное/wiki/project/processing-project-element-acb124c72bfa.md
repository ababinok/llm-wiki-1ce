## Обзор

Элемент проекта вида «Обработка» — это объект конфигурации, предназначенный для обработки данных на стороне сервера.

## Документированный контракт и примеры

Элемент проекта вида «Обработка» — это объект конфигурации, предназначенный для обработки данных на стороне сервера. Он позволяет автоматизировать работу с данными: удалять, сохранять и создавать данные по заданному алгоритму.

Обработка может содержать [реквизиты](processing-project-element-acb124c72bfa.md) и [операции](processing-project-element-acb124c72bfa.md), а также [форму обработки](processing-project-element-acb124c72bfa.md), с помощью которой можно вводить параметры, влияющие на ход алгоритма обработки, и отображать результаты. Сам алгоритм обработки задается в модуле объекта обработки.

## Реквизиты

Реквизиты содержат вспомогательную информацию, которая относится к объекту обработки.

Реквизиты описываются следующими свойствами:

- Имя
  
  — имя реквизита.
- Тип
  
  — тип реквизита.
- Представление
  
  — заголовок поля ввода, соответствующего данному реквизиту. Если не указано, то используется свойство реквизита
  
  Имя
  
  .

## Операции

Операции — это методы, которые выполняет обработка. Наименование операций указывается в yaml-файле обработки, а их описание — в модуле объекта обработки. Методы, соответствующие операциям, помечаются аннотацией `@Обработчик`.

> [!NOTE] примечание
> При создании операции в ее модуль автоматически добавляется шаблон кода обработчика. Если метод, соответствующий операции, отсутствует в модуле, выводится ошибка «Обязательный обработчик `ИмяОперации` не определен».

На каждую операцию в форме обработки создается команда.

Операции описываются следующими свойствами:

- Имя
  
  — имя операции.
- Представление
  
  — заголовок кнопки, соответствующей данной операции. Если не указано, то используется свойство операции
  
  Имя
  
  .
- Основная
  
  — признак основной операции. Кнопка, соответствующая данной операции, становится
  
  основной
  
  . Если для обработки задана единственная операция, то она помечается как основная. Если несколько операций помечены как основные, то выводится сообщение об ошибке.

## Форма обработки

Разработчик может создать свою форму обработки типа [`ФормаОбработки`](../interface/processingform-ru-b73444916721.md), либо среда разработки создает автоматическую форму [`{ИмяОбработки}.АвтоматическаяФорма`](../interface/processingname-automaticform-ru-40572408be14.md). На нее будут добавлены:

- Поля
  
  — на форму добавляется столько компонентов интерфейса
  
  ПолеВвода
  
  , сколько имеется реквизитов у объекта обработки. Данные поля используются для ввода значений реквизитов и вывода результатов обработки. Заголовок поля ввода берется из свойства
  
  Представление
  
  .
- Кнопки
  
  — добавляются для каждой операции. Наименование кнопки берется из свойства
  
  Представление
  
  .
- Команды
  
  — команды, порождаемые обработкой. Вызывают методы исполнения операций.

При открытии формы обработки вызывается обработчик `ПриЗаполнении()`. Он предназначен для заполнения объекта обработки в интерактивном режиме.

После создания и заполнения объекта обработки вызывается обработчик `ПослеЗаполнения()`.

## Пример

В этом примере вы создадите обработку, которая будет рассчитывать стоимость доставки по заданным параметрам. Выполните следующие действия:

1. Создайте новый элемент проекта **Обработка** с именем **РасчетСтоимостиДоставки**.
  
  Создание новой обработки [Описание иллюстрации](../../raw/figures/938d1bf76921bbf7d535d5ac1623e8f26fb25e0ea08b9f623b219deb10f71db4-93f535f1569588aa.md)
2. Добавьте реквизиты типа `Число`:
  
  Добавление реквизитов [Описание иллюстрации](../../raw/figures/9e2a19cf914e9316aa185b2f3c3dce63fe4fdc8673b132d144cb0e00de811478-8bf8ee3372bf8b39.md)
  
  | Имя реквизита | Описание | Свойство «Представление» |
  | --- | --- | --- |
  | Вес | вес доставляемого груза | Вес, кг |
  | Расстояние | расстояние до пункта назначения | Расстояние, км |
  | АвтоБазоваяСтавка | базовая ставка доставки автотранспортом | Базовая ставка |
  | АвиаБазоваяСтавка | базовая ставка доставки авиатранспортом | Базовая ставка |
  | АвтоСтоимостьКМ | доплата за 1 км свыше 100 км | Стоимость 1 км (свыше 100 км) |
  | АвиаСтоимостьКМ | доплата за 1 км свыше 100 км | Стоимость 1 км (свыше 100 км) |
  | АвтоСтоимостьКГ | доплата за 1 кг свыше 500 кг | Стоимость 1 кг (свыше 500 кг) |
  | АвиаСтоимостьКГ | доплата за 1 кг свыше 100 кг | Стоимость 1 кг (свыше 100 кг) |
  | СтоимостьДоставкиАвтотранспортом | результат расчета | Стоимость доставки автотранспортом |
  | СтоимостьДоставкиАвиатранспортом | результат расчета | Стоимость доставки авиатранспортом |
3. Добавьте операции **Рассчитать** (основная), **РассчитатьАвтотранспортом**, **РассчитатьАвиатранспортом**.

4. Добавьте модуль объекта обработки с описанием обработчиков операций.
  
  Добавление модуля объекта обработки показано через меню выбора связанных элементов: для обработки РасчетСтоимостьДоставки доступен пункт «Модуль объекта» в группе Модули. [Описание иллюстрации](../../raw/figures/27bd056993cc37eb729408958e4b442bdc8797ddc0e8dcf37a4e3bab04874fb4-60b1e5ca34b991c2.md)
  
  Пример модуля объекта обработки
  
  ```xbsl
  конст АвтоРасстояние = 100
  конст АвтоВес = 500
  конст АвиаРасстояние = 100
  конст АвиаВес = 100
  
  @Обработчик
  метод Рассчитать()
      РассчитатьАвтотранспортом()
      РассчитатьАвиатранспортом()
  ;
  
  @Обработчик
  метод РассчитатьАвтотранспортом()
      пер ДополнительныеКМ = РасчетДополнительныхКМ(Расстояние, АвтоРасстояние)
      пер ДополнительныеКГ = РасчетДополнительныхКГ(Вес, АвтоВес)
      СтоимостьДоставкиАвтотранспортом = АвтоБазоваяСтавка + 
                                      ДополнительныеКМ * АвтоСтоимостьКМ + 
                                      ДополнительныеКГ * АвтоСтоимостьКГ
  ;
  
  @Обработчик
  метод РассчитатьАвиатранспортом()
      пер ДополнительныеКМ = РасчетДополнительныхКМ(Расстояние, АвиаРасстояние)
      пер ДополнительныеКГ = РасчетДополнительныхКГ(Вес, АвиаВес)
      СтоимостьДоставкиАвиатранспортом = АвиаБазоваяСтавка + 
                                      ДополнительныеКМ * АвиаСтоимостьКМ + 
                                      ДополнительныеКГ * АвиаСтоимостьКГ
  ;
  
  метод РасчетДополнительныхКМ(Расстояние: Число, РасстояниеБаза: Число): Число
      возврат Расстояние > РасстояниеБаза ? Расстояние - РасстояниеБаза : 0
  ;
  
  метод РасчетДополнительныхКГ(Вес: Число, ВесБаза: Число): Число
      возврат Вес > ВесБаза ? Вес - ВесБаза : 0
  ;
  ```
5. Вы можете создать собственный компонент **ФормаОбработки** или использовать автоматическую форму.
  
  Для создания собственной формы обработки в навигаторе выбран РасчетСтоимостиДоставки. [Описание иллюстрации](../../raw/figures/79734da95009cb4a8eec11903073108ea729f0fb89416eb53533595151fb2fb6-054f23212f817d59.md)

  - в третьей отображаются поля для вывода результатов, доступные только для чтения.
