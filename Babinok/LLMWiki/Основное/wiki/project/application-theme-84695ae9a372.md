## Документированный контракт и примеры

В «1С:Предприятие.Элементе» можно изменять настройки внешнего вида пользовательского интерфейса вашего приложения: тему, логотипы, фоновое изображение и т. д. Например, можно оформить ваше приложение в соответствии с фирменным стилем вашей организации.

Пример применения к приложению фирменного стиля «1С»:

Пример фонового изображения клиентского приложения: рисунок размещён позади канбан-доски и остальных элементов; это демонстрация свойства фона приложения. [Описание иллюстрации](../../raw/figures/47b779d9cd3202708254bf1e7c68d20c6f04be1848e7b7f92327bc31ca57c06e-1293e864b63c1143.md)

Настройки указываются в YAML-файле клиентского приложения для свойства `ТемаОформления` типа `ТемаОформления`. Так, для примера выше это следующие настройки:

```yaml
ТемаОформления:
    АкцентныйВторичныйЦвет:
        Тип: АбсолютныйЦвет
        Значение: RGB(D71920)
    АкцентныйПервичныйЦвет:
        Тип: АбсолютныйЦвет
        Значение: RGB(FFDD00)
    Логотип: logo_1.png
    ФоновоеИзображение: logo1cp.png
    ФоновоеИзображениеРазмытие: Ложь
    ФоновоеИзображениеУровеньРазмытия: 0
```

Описание настроек:

> [!NOTE] примечание
> Каждый из двух брендовых цветов применяется только к фиксированному списку компонентов интерфейса.

## АкцентныйВторичныйЦвет

Дополнительный акцентный цвет приложения. Если не определен, то принимает значение системы по умолчанию.

Тип `Цвет|Авто`.

Применяется к индикаторам загрузки, а также к следующим компонентам интерфейса:

- [Дополнительная кнопка](../interface/button-component-9e3a091652f8.md)
  
  ,
- [Флажок](../interface/checkbox-component-28feae196391.md)
  
  ,
- [Радиокнопка](../interface/radio-button-component-6d172cc50293.md)
  
  .

В примере приложения цвет вторичного акцента показан на выделенном индикаторе загрузки: кольцо имеет светло-голубую дорожку и синий активный участок. [Описание иллюстрации](../../raw/figures/c1f13eac7263618f80df7dfd35829ed40bc70df05db83b157600da19868c51af-ff8069d35e8292e5.md)

## АкцентныйПервичныйЦвет

Основной акцентный цвет приложения. Если не определен, то принимает значение системы по умолчанию.

Тип `Цвет|Авто`.

Применяется к [основным кнопкам](../interface/button-component-9e3a091652f8.md) и к выбранным элементам интерфейса (вкладкам форм, элементам панели навигации):

В форме сделки акцентным первичным цветом выделены активная вкладка «Детали» и основная кнопка «Готово». [Описание иллюстрации](../../raw/figures/f3eb227c1715fa210a41fd88b00cc3b25e8a45ff088fb5db043fe8aa62564d8e-c342d7908dc66778.md)

## ДопустимыеЦветовыеСхемы

Допустимые цветовые схемы приложения.

Тип `Авто|Множество<ЦветоваяСхема>`.

`Авто` разрешается в зависимости от режима совместимости:

- если РС <= 6.0, то {
  
  [`Светлая`](../interface/colorschema-ru-793649bed4b2.md)
  
  };
- если РС >= 7.0, то {
  
  [`Светлая`](../interface/colorschema-ru-793649bed4b2.md)
  
  ,
  
  [`Темная`](../interface/colorschema-ru-793649bed4b2.md)
  
  }.

Если множество пустое, то принимает значение `Авто`.

## ЗаголовокСтраницыВхода

Заголовок страницы входа. Если не задан, то не отображается в интерфейсе.

Тип `Строка`.

## Логотип

Логотип приложения. Если не определен, то принимает значение системы по умолчанию. Отображается в свернутом меню при вертикальной навигации, а также в развернутом меню вместе с названием приложения, если не задан крупный логотип.

В мобильной версии приложения логотипы не отображаются.

Тип `Url|ДвоичныйОбъект.Ссылка|?`.

## ЛоготипКрупный

Крупная версия логотипа приложения. Отображается в развернутом меню при вертикальной навигации.

В мобильной версии приложения логотипы не отображаются.

Тип `Url|ДвоичныйОбъект.Ссылка|?`.

## ОтображатьТекстКомандНавигации

Определяет необходимость отображения текста команд навигации в панели вкладок мобильного интерфейса.

Тип `Авто|Булево`.

## ПриветственныйТекстСтраницыВхода

Приветственный текст страницы входа, который отображается под заголовком. Если не задан, то не отображается в интерфейсе.

Тип `Строка`.

## СообщениеСтраницыВхода

Подсказка, отображается в нижней части страницы входа. Если не задана, то не отображается в интерфейсе.

Тип `Строка`.

## ФоновоеИзображение

Ссылка на изображение, которое может быть загружено через [Ресурсы](resource-in-project-b42041684d83.md). Изображение будет показано на заднем плане всего приложения. Недоступно для мобильных устройств.

Тип `ДвоичныйОбъект.Ссылка`.

## ФоновоеИзображениеРазмытие

Флаг, отвечающий за использование на фоновом изображении эффекта размытия.

Тип `Булево`.

## ФоновоеИзображениеУровеньРазмытия

Уровень размытия фонового изображения в пикселях (размытие по Гауссу).

Тип `Число`.

## ЦветоваяСхема

Цветовая схема приложения. По умолчанию может быть: светлая, темная или выбираться автоматически.

Тип `Авто|ЦветоваяСхема`

## ЦветАктивнойВкладкиНавигации

Определяет цвет активной вкладки в мобильном интерфейсе.

Тип `Авто|ЦветАктивнойВкладкиНавигации`.

## ЦветСсылок

Цвет компонента интерфейса [Надпись](../interface/label-component-975bcb38121f.md), если надпись является [гиперссылкой](../interface/label-component-975bcb38121f.md). Итоговый цвет гиперссылки определяется исходя из значений свойств `Цвет`, `Важность` и `ОценкаИнформации`, а также значения `Авто`. Используются дополнительные оттенки при наведении и активности.

Тип `Цвет|Авто`.

Пример в YAML:

```yaml
ЦветСсылок:
    Тип: АбсолютныйЦвет
    Значение: RGB(ED1C24)
```

## Настройка темы оформления в коде

Чтобы добавить свойство `ТемаОформления` программно, присвойте в поле `ТемаОформления` объекта `КлиентскоеПриложение` новый объект типа `ТемаОформления` и укажите для него соответствующие параметры:

```xbsl
КлиентскоеПриложение.ТемаОформления = новый ТемаОформления(АкцентныйПервичныйЦвет=Цвета.Красный)
```

Чтобы управлять этими настройками далее, присвойте значения соответствующим настройкам свойства `ТемаОформления` компонента `КлиентскоеПриложение`, например:

```xbsl
КлиентскоеПриложение.ТемаОформления.АкцентныйВторичныйЦвет=Цвета.Синий
```
