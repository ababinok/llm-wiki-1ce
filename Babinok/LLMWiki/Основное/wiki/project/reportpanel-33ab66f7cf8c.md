## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

Название отчета / панели отчетов.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../language/modular-development-80166cfecf93.md).

---

#### Описание

```yaml
Описание: Строка
```

Описание отчета / панели отчетов. По умолчанию — пустая строка.

---

#### Интерфейс

```yaml
Интерфейс: 
    ВключатьВАвтоИнтерфейс: Булево
    Форма: Строка
    Изображение: ДвоичныйОбъект.Ссылка?
```

Группа свойств, которые описывают пользовательский интерфейс отчета / панели отчетов.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды открытия формы в [автоматический интерфейс](../interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Форма

Имя объекта конфигурации, являющегося формой данного отчета / панели отчетов. Форма должна наследовать тип [ФормаОтчета](../interface/reportform-ru-a6c5b64077dc.md). Если значение не указано, то используется автоматически сгенерированная форма.

##### Изображение

Задает картинку для команды открытия формы.

</details>

---

## Дочерние элеметы

#### Макет

```yaml
Макет: МакетПанелиОтчетов
```

Содержит описание макета панели отчетов. Описание макета формируется автоматически при редактировании панели отчетов в дизайнере «1С:Аналитики», встроенном в среду разработки.
