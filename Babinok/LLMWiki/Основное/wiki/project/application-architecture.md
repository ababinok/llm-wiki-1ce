## Обзор

Проект описывает логику приложения. Подсистемы и пакеты задают его структуру, элементы проекта определяют функциональность, а модули содержат программный код. Ресурсы — это файлы, необходимые приложению.

## От задачи к элементу проекта

Выбирайте элемент проекта по требуемой функции: структура хранения данных, интерфейс и программный модуль имеют разные роли. Модуль относится к типу и расширяет его контракт. Общий модуль подходит для переиспользуемого кода.

При работе с прикладным объектом сначала найдите описание элемента проекта, затем описание порождаемых типов и только после этого — контракт конкретного метода. Пример модуля не заменяет описание структуры данных.

## Повторное использование

Библиотеки объединяют переиспользуемый код и элементы проекта. Подсистемы разделяют приложение на части; ресурсы могут иметь собственную область видимости. Учитывайте эти границы при обращении к элементам и модулям.
