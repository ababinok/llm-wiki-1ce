## Свойства

### Важность

`ВажностьКоманды`. Определяет приоритет при отображении нескольких команд. Например, команда с важностью **Низкая** будет отображаться в выпадающем меню «Еще». Возможные значения:

- Высокая
  
  ,
- Обычная
  
  ,
- Низкая
  
  .

### Видимость

`Булево`. Управляет видимостью команды. Если `Ложь`, команда скрыта в интерфейсе.

### ВидЭлемента

Вид элемента проекта ([подробнее](../interface/all-project-elements-5977d6a645f5.md)).

### Доступность

`Булево`. Управляет доступностью команды. Если `Ложь`, команда недоступна для выполнения.

### Ид

Идентификатор элемента проекта. «1С:Предприятие.Элемент» создает этот идентификатор автоматически.

### Изображение

Ссылка на ресурс картинки, которая будет показана в команде. Пример YAML-файла:

```yaml
ВидЭлемента: НавигационнаяКоманда
ОбластьВидимости: ВПодсистеме
Ид: 9188766e-e84c-4e3f-9d01-3f130d783136
Имя: МояНавигационнаяКоманда
Представление: Задачи 
Изображение: icon-q.svg
ТипФормы: ФормаГлавногоРаздела
```

### Импорт

Список импортированных пространств имен ([подробнее](../language/modular-development-80166cfecf93.md)).

### Имя

Имя элемента проекта.

### ОбластьВидимости

Видимость элемента проекта ([подробнее](../language/modular-development-80166cfecf93.md)):

- ВПодсистеме
  
  — элемент виден внутри одной подсистемы во всех пакетах.
  
  Значение по умолчанию
  
  .
- ВПроекте
  
  — элемент виден во всех подсистемах одного проекта.
- Глобально
  
  — элемент виден во всех подсистемах всех проектов.

### ОпасностьДействия

`ОпасностьДействия`. Определяет опасность действия, совершаемого пользователем, например, может ли нажатие на кнопку привести к удалению данных. Возможные значения:

- Высокая
  
  ,
- Средняя
  
  ,
- Отсутствует
  
  .

### Представление

Строка, которая будет показана как заголовок команды. Пример YAML-файла:

```yaml
ВидЭлемента: НавигационнаяКоманда
ОбластьВидимости: ВПодсистеме
Ид: 9188766e-e84c-4e3f-9d01-3f130d783136
Имя: МояНавигационнаяКоманда
Представление: Задачи 
Изображение: icon-q.svg
ТипФормы: ФормаГлавногоРаздела
```

### ТипФормы

Форма, которая будет открыта в результате выполнения команды. Пример YAML-файла:

```yaml
ВидЭлемента: НавигационнаяКоманда
ОбластьВидимости: ВПодсистеме
Ид: 9188766e-e84c-4e3f-9d01-3f130d783136
Имя: МояНавигационнаяКоманда
Представление: Задачи 
Изображение: icon-q.svg
ТипФормы: ФормаГлавногоРаздела
```
