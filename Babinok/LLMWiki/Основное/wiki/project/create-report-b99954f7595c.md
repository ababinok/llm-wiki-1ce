## Обзор

Отчет можно добавить в проект двумя способами.

## Документированный контракт и примеры

Отчет можно добавить в проект двумя способами.

**Способ 1**. Создать отчет через меню создания нового элемента проекта:

1. В навигаторе проекта нажмите на значок плюса рядом с нужной подсистемой и добавьте новый элемент проекта **Отчет**:
  
  В окне добавления элемента проекта выбран «Отчёт» для создания отчёта в подсистеме. [Описание иллюстрации](../../raw/figures/42a3327a63310ef4f5ab9600f4cef8d6abadbcfb239071eccd7b66bcd7610a00-cccd5ef3cfdace36.md)
2. Укажите в панели свойств источник данных для отчета:
  
  В свойствах учебного отчёта ОтчетОСотрудниках задан ВидИсточникаДанных — Таблица, ИсточникДанных — Сотрудники, ОбластьВидимости — ВПодсистеме. [Описание иллюстрации](../../raw/figures/bf4a4581880c4c36d51140ea11b50f1551302c93a38fa8fa484ce30e35225ad7-4b3f9d3f9f67880d.md)

**Способ 2**. Добавить отчет для уже существующего элемента проекта, порождающего таблицу языка запросов (справочника, документа, регистра сведений и т. д.). В этом случае отчет будет создан в подсистеме, содержащей выбранный элемент, а в источнике данных отчета будет указана соответствующая таблица.

1. В навигаторе проекта нажмите на значок плюса рядом с именем нужного элемента проекта и выберите **Отчет** в открывшемся окне:
  
  
  
  Задайте имя отчета и нажмите **Ввод**.
2. Источник данных в таком случае заполнится автоматически: в качестве источника будет выбран тот элемент проекта, от которого был создан отчет.

После того как вы добавили элемент проекта **Отчет**, у вас откроется встроенный редактор отчетов:

## Экспорт отчета в изображение

Используйте метод [`ЭкспортироватьВИзображение()`](../stdlib/report-ru-262c53c7ab2e.md) типа [`Отчет`](../stdlib/report-ru-262c53c7ab2e.md), чтобы сохранить отчет как изображение в формате PNG. Вы можете указать размер изображения, его разрешение (DPI) и цветовую схему, которую необходимо применить к отчету при экспорте.

В примере ниже показано, как экспортировать отчет в форматы PNG и PDF. Для экспорта в PDF отчет сохраняется как изображение, которое затем вставляется в новый PDF-документ ([`ДокументPdf`](../data/pdfdocument-ru-0f22a31f119f.md)).

```xbsl
@НаКлиенте
метод ЭкспортироватьОтчет(Отчет: Отчет)
    знч ИзображениеОтчета = Отчет.ЭкспортироватьВИзображение(Dpi = 600)
    // Экспорт отчета в PNG-изображение
    ЭкспортироватьОтчетВPng(ИзображениеОтчета)
    // Экспорт отчета в PDF-документ
    ЭкспортироватьОтчетВPdf(ИзображениеОтчета)
;

@НаСервере @ДоступноСКлиента
статический метод ЭкспортироватьОтчетВPng(БайтыИзображения: Байты)
    знч Файл = новый Файл("Report.png", Файлы.ПолучитьДомашнийКаталогПользователя())
    исп ПотокЗаписи = Файл.ОткрытьПотокЗаписи()
    ПотокЗаписи.Записать(БайтыИзображения)
;

@НаСервере @ДоступноСКлиента
статический метод ЭкспортироватьОтчетВPdf(БайтыИзображения: Байты)
    // Создание нового PDF-документа
    пер Документ = новый ДокументPdf()
    исп ПотокИзображения = ПотокЧтения.ИзБайтов(БайтыИзображения)
    // Добавление страницы с изображением отчета в начало документа
    Документ.ДобавитьСтраницуИзИзображения(ПотокИзображения)
    
    // Сохранение PDF-документа в файл
    знч Файл = новый Файл("Report.pdf", Файлы.ПолучитьДомашнийКаталогПользователя())
    исп ПотокЗаписи = Файл.ОткрытьПотокЗаписи()
    Документ.Записать(ПотокЗаписи)
;
```

### Ограничения экспорта

«1С:Предприятие.Элемент» выбрасывает [`ИсключениеЭкспортаОтчета`](../stdlib/reportexportexception-ru-a8fa5d8929ac.md) в следующих случаях:

- если ширина или высота изображения не задана явно и соответствующий размер содержимого прокручиваемого контейнера внутри отчета превышает 5000 пикселей;
- невозможно построить отчет: недостаточно измерений или фактов, отсутствуют поля с обязательными ролями и т. д.;
- данные для построения отчета отсутствуют или при их загрузке произошла ошибка;
- экспорт выполняется для
  
  [панели отчетов](create-report-panel-87c9cc72c0f5.md)
  
  .
