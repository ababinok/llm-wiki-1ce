## Документированный контракт и примеры

В «1С:Предприятие.Элементе» для работы с документами формата PDF предназначены сущности, расположенные в пространстве имен [`Стд::Pdf`](../stdlib/pdf-c634ed811ea0.md):

- Тип
  
  [`ДокументPdf`](../data/pdfdocument-ru-0f22a31f119f.md)
  
  — используется для создания новых документов формата PDF, добавления и удаления страниц, чтения и записи, импорта PDF из формата DOCX и др.
- Тип
  
  [`СтраницаPdf`](../stdlib/pdfpage-ru-568344e1aad1.md)
  
  — используется для работы с отдельными страницами документа: добавления изображений, конвертации страниц, получения информации о странице.
- Исключение
  
  [`ИсключениеPdf`](../stdlib/pdfexception-ru-fca07efa7071.md)
  
  — специальное исключение, возникающее при работе с документами формата PDF.
- Перечисление
  
  [`ФорматДокументаPdf`](../data/pdfdocumentformat-ru-7f20219e2313.md)
  
  — описывает доступные PDF форматы.

С их помощью вы можете создать новый пустой документ формата PDF или конвертировать его из DOCX, а так же редактировать документ, конвертировать его отдельные страницы в изображения, сохранять защищенный документ с использованием пароля.

## Создание документа PDF

Для создания пустого документа формата PDF воспользуйтесь конструктором типа [`ДокументPdf`](../data/pdfdocument-ru-0f22a31f119f.md). Конструктор типа создает документ, который не содержит страниц. Для добавления пустых страниц в документ воспользуйтесь методом [`ДобавитьСтраницу()`](../data/pdfdocument-ru-0f22a31f119f.md).

Метод [`ДобавитьСтраницу()`](../data/pdfdocument-ru-0f22a31f119f.md) добавляет страницу указанного `Размера` под указанным `Индексом`. Параметры метода [`ДобавитьСтраницу()`](../data/pdfdocument-ru-0f22a31f119f.md) не являются обязательными, поэтому в общем случае страницы добавляются по следующим правилам:

- если параметр
  
  `Индекс`
  
  не задан, то страница добавляется в конец документа;
- если добавить страницу без указания параметра
  
  `Размер`
  
  в пустой документ, то страница добавляется с размером по умолчанию — А4;
- если добавить страницу без указания параметра
  
  `Размер`
  
  в начало непустого документа, то ей будет установлен размер страницы под индексом 0;
- если добавить страницу без указания параметра
  
  `Размер`
  
  в непустой документ, то размер будет взят у предыдущей страницы.

```xbsl
метод СоздатьДокументPdf(): ДокументPdf
    // Конструктор — создаст пустой документ формата PDF
    пер Документ = новый ДокументPdf()
    // Добавит страницу в пустой документ с форматом по умолчанию — А4
    Документ.ДобавитьСтраницу(0)
    // Добавит страницу в начало непустого документа с форматом А5
    Документ.ДобавитьСтраницу(0, РазмерСтраницы.A5())
    // Добавит страницу в конец непустого документа с форматом предыдущей — А4
    Документ.ДобавитьСтраницу()
    // Добавит страницу в начало c размером страницы с индексом 0 — А5
    Документ.ДобавитьСтраницу(0)
    // Добавит страницу с индексом 4 размера 400х400
    Документ.ДобавитьСтраницу(4, новый РазмерСтраницы(400, 400))
    // Добавит страницу с индексом 5 и возьмет размер у предыдущей — 400х400
    Документ.ДобавитьСтраницу(5)
    возврат Документ
;
```

Также вы можете добавить страницы в документ из изображений форматов JPEG, TIFF, GIF, BMP, PNG. Для этого используйте метод [`ДобавитьСтраницуИзИзображения()`](../data/pdfdocument-ru-0f22a31f119f.md). При добавлении изображения его левый верхний угол будет размещен по координатам `x = 0, y = 0`. Размеры изображения, как максимально возможные, определяются автоматически, но так, чтобы оно целиком поместилось на странице. При этом сохраняется отношение сторон.

```xbsl
метод СоздатьPdfИзИзображений(): ДокументPdf
    пер Документ = новый ДокументPdf()
    исп ПотокИзображения0 = Ресурс{Логотип.png}.ОткрытьПотокЧтения()
    // Добавит страницу с изображением формата А4 в начало документа
    Документ.ДобавитьСтраницуИзИзображения(ПотокИзображения0)
    исп ПотокИзображения1 = Ресурс{Тест.bmp}.ОткрытьПотокЧтения()
    // Добавит страницу с изображением формата 200х400 мм в начало документа
    Документ.ДобавитьСтраницуИзИзображения(ПотокИзображения1, 0, новый РазмерСтраницы(200, 400))
    исп ПотокИзображения2 = Ресурс{Кот.jpg}.ОткрытьПотокЧтения()
    // Добавит страницу с изображением формата А5 в начало документа
    Документ.ДобавитьСтраницуИзИзображения(ПотокИзображения2, 0, РазмерСтраницы.A5())
    возврат Документ
;
```

Результат создания PDF из трёх изображений: три страницы с разными иллюстрациями; на первой странице видны команды обновления, поворота и удаления. Это содержимое документа из приведённого текстового примера. [Описание иллюстрации](../../raw/figures/e3c92f1e59a30ee43308deba7e5885037aa7a4bc9befc4a1e55a44c115fc2bfa-0f5490759b6c6183.md)

Каждое изображение изменило свои размеры до максимально возможных для каждого формата листа с сохранением соотношения сторон.

После создания документа вы можете записать его в [`ПотокЗаписи`](../stdlib/writablestream-ru-db9a09ef1933.md) в одном из доступных форматов с помощью метода [`Записать()`](../data/pdfdocument-ru-0f22a31f119f.md). Доступные форматы описываются в специальном перечислении [`ФорматДокументаPdf`](../data/pdfdocumentformat-ru-7f20219e2313.md). Формат документа может быть обычным ([`Pdf`](../data/pdfdocumentformat-ru-7f20219e2313.md)) или для долгосрочного хранения ([`PdfA1`](../data/pdfdocumentformat-ru-7f20219e2313.md), [`PdfA2`](../data/pdfdocumentformat-ru-7f20219e2313.md), [`PdfA3`](../data/pdfdocumentformat-ru-7f20219e2313.md)).

Для защиты документа паролем используйте параметр `Пароль`. Пароль может быть установлен только на документы, записываемые в формате [`Pdf`](../data/pdfdocumentformat-ru-7f20219e2313.md).

```xbsl
метод ЗаписатьPdf()
    пер Документ = новый ДокументPdf()
    исп Поток = новый ВременныйПотокЗаписи()
    // Способы записи документа в обычном формате без пароля:
    Документ.Записать(Поток)
    Документ.Записать(Поток, ФорматДокументаPdf.Pdf)
    Документ.Записать(Поток, ФорматДокументаPdf.Pdf, "")
    // Запись документа в обычном формате с паролем 12345 
    Документ.Записать(Поток, ФорматДокументаPdf.Pdf, "12345")
    // Запись документа в формате PdfA1 без пароля. Установка пароля вызовет ошибку
    Документ.Записать(Поток, ФорматДокументаPdf.PdfA1, "")
;
```

По окончании работы с документом воспользуйтесь методом [`Закрыть()`](../data/pdfdocument-ru-0f22a31f119f.md) для закрытия документа. После закрытия документа его нельзя изменить. Повторный вызов метода не выполняет никаких действий.

```xbsl
метод СоздатьPdf(): ДокументPdf
    пер Документ = новый ДокументPdf()
    Документ.ДобавитьСтраницу()
    Документ.Закрыть()
    Документ.ДобавитьСтраницу() // Добавление выбросит исключение ИсключениеНедопустимоеСостояние
    возврат Документ
;
```

### Импорт из других форматов

### Импорт из форма DOCX

Чтобы создать документ формата PDF из DOCX-документа, читаемого из потока [`ПотокЧтения`](../stdlib/readablestream-ru-c306ee00c3af.md), используйте статический метод [`ИмпортироватьИзDocx()`](../data/pdfdocument-ru-0f22a31f119f.md).

Если импортируемый документ DOCX защищен паролем, передайте его в виде строки в параметр `Пароль` метода [`ИмпортироватьИзDocx()`](../data/pdfdocument-ru-0f22a31f119f.md). Пароль от документа не сохраняется.

> [!NOTE] примечание
> Импорт документа из формата DOCX может занимать продолжительное время, а вид итогового PDF-документа может отличаться от импортируемого.

```xbsl
метод ИмпортироватьДокументИзDocx(ПотокДокумента: ПотокЧтения)
    // Способы импорта документа без пароля:
    исп Документ1 = ДокументPdf.ИмпортироватьИзDocx(ПотокДокумента)
    исп Документ2 = ДокументPdf.ИмпортироватьИзDocx(ПотокДокумента, "")
    // Импорт документа, защищенного паролем
    исп Документ3 = ДокументPdf.ИмпортироватьИзDocx(ПотокДокумента, "template123")
;
```

### Импорт из таблиц

Чтобы создать документ формата PDF из таблиц поддерживаемых форматов (Microsoft Excel XLS/XLSX и OpenOffice Calc ODS), читаемых из потока [`ПотокЧтения`](../stdlib/readablestream-ru-c306ee00c3af.md), используйте статический метод [`ИмпортироватьИзТаблицы()`](../data/pdfdocument-ru-0f22a31f119f.md).

По умолчанию используются настройки импорта с фиксированным размером страницы формата A4. Чтобы настроить ориентацию листа, отступы, режим импорта страниц, используйте методы и свойства специального типа [`НастройкиИмпортаPdfИзТаблицы`](../stdlib/pdfimportfromtablesettings-ru-a52c0b441821.md).

Если импортируемая таблица формата XLSX защищена паролем, передайте его в виде строки в параметр `Пароль` метода [`ИмпортироватьИзТаблицы()`](../data/pdfdocument-ru-0f22a31f119f.md). Пароль от документа не сохраняется.

> [!NOTE] примечание
> Импорт защищенных таблиц поддерживается только для формата XLSX. Импорт документа может занимать продолжительное время, а вид итогового PDF-документа может отличаться от импортируемого.

```xbsl
метод ИмпортироватьДокументИзТаблицы(Поток: ПотокЧтения) : ДокументPdf
  пер Настройки = НастройкиИмпортаPdfИзТаблицы.ФиксированныйРазмерСтраницы(РазмерСтраницы = РазмерСтраницы.A5(),
                                                                           ПолеСверху = 30, 
                                                                           ПолеСнизу = 30, 
                                                                           ПолеСлева = 20, 
                                                                           ПолеСправа = 20)
 
  возврат ДокументPdf.ИмпортироватьИзТаблицы(Поток, Настройки, "12345")
;
```

## Редактирование документа PDF

Для редактирования документа необходимо знать индекс редактируемой в документе страницы и их общее количество. Для определения количества страниц в документе используйте метод [`ПолучитьКоличествоСтраниц()`](../data/pdfdocument-ru-0f22a31f119f.md), а для получения индекса конкретной страницы — метод [`ПолучитьИндекс()`](../stdlib/pdfpage-ru-568344e1aad1.md).

```xbsl
статический метод УзнатьИндексПоследнейСтраницы(Ссылка: ДвоичныйОбъект.Ссылка): Число
    пер ИсходныйДокумент = ДокументPdf.Прочитать(Ссылка.Загрузить().ОткрытьПотокЧтения(), "")
    // Определяет количество страниц в документе
    пер Размер = ИсходныйДокумент.ПолучитьКоличествоСтраниц()
    // Если количество страниц = 4, то вернет Индекс = 3
    пер Индекс = ИсходныйДокумент.ПолучитьСтраницу(Размер-1).ПолучитьИндекс()
    возврат Индекс
;
```

Зная индекс необходимой страницы, вы можете удалить ее из документа с помощью метода [`УдалитьСтраницу()`](../data/pdfdocument-ru-0f22a31f119f.md):

```xbsl
статический метод УдалитьПоследнийЛист(Ссылка: ДвоичныйОбъект.Ссылка)
    пер ИсходныйДокумент = ДокументPdf.Прочитать(Ссылка.Загрузить().ОткрытьПотокЧтения())
    пер Размер = ИсходныйДокумент.ПолучитьКоличествоСтраниц()
    ИсходныйДокумент.УдалитьСтраницу(Размер - 1)
;
```

Или можете получить экземпляр этой страницы типа [`СтраницаPdf`](../stdlib/pdfpage-ru-568344e1aad1.md) с помощью метода [`ПолучитьСтраницу()`](../data/pdfdocument-ru-0f22a31f119f.md) для последующего добавления на эту страницу изображения или конвертации ее в изображение.

## Добавление изображений

Для добавления изображения на страницу используйте метод [`ДобавитьИзображение()`](../stdlib/pdfpage-ru-568344e1aad1.md). Метод добавляет изображение из потока [`ПотокЧтения`](../stdlib/readablestream-ru-c306ee00c3af.md) в прямоугольную область. Метод поддерживает такие форматы изображения, как JPEG, TIFF, GIF, BMP, PNG. Параметры области задаются в миллиметрах через передачу в параметр `Область` объекта [`ПрямоугольнаяОбласть`](../stdlib/rectangulararea-ru-e161d9cad47b.md). Изображение добавляется на страницу поверх любых других объектов. В случае, если ширина и высота в соотношении друг с другом не соответствуют параметрам изображения, то оно записывается по координатам `x = Область.X`, `y = Область.Y` с сохранением отношения сторон. Размеры изображения, как максимально возможные, определяются автоматически, но так, чтобы оно целиком уместилось в `Область`. Если изображение не умещается на страницу в указанных координатах, то оно будет обрезано.

```xbsl
метод ДобавитьИзображениеНаСтраницу(Страница: СтраницаPdf, Поток: ПотокЧтения)
    // ...
    Страница.ДобавитьИзображение(Поток, новый ПрямоугольнаяОбласть(0, 0, 100, 100))
;
```

Чтобы определить свободные области на странице для добавления изображения, воспользуйтесь методами [`ПолучитьСвободныеОбластиНаСтранице()`](../stdlib/pdfpage-ru-568344e1aad1.md) и [`ПолучитьВысотуСодержимого()`](../stdlib/pdfpage-ru-568344e1aad1.md).

Метод [`ПолучитьВысотуСодержимого()`](../stdlib/pdfpage-ru-568344e1aad1.md) используется для вычисления нижней границы контента на странице.

```xbsl
метод ДобавитьИзображениеВОбласть(Страница: СтраницаPdf, Поток: ПотокЧтения)
    пер ГраницаСодержимого = Страница.ПолучитьВысотуСодержимого()
    пер ВысотаСтраницы = Страница.Размер.Высота

    если (Страница.Размер.Ширина > 100 и ВысотаСтраницы - ГраницаСодержимого > 100)
        пер Область = новый ПрямоугольнаяОбласть(0, ГраницаСодержимого, 100, 100)
        Страница.ДобавитьИзображение(Поток, Область)
    ;
;
```

Метод [`ПолучитьСвободныеОбластиНаСтранице()`](../stdlib/pdfpage-ru-568344e1aad1.md) используется для определения на странице PDF-документа всех свободных прямоугольных областей, размеры которых больше переданных в метод в качестве параметров. Гарантируется, что все прямоугольные области целиком лежат на странице. В случае внесения изменений в страницу документа метод требуется вызвать повторно.

```xbsl
метод ДобавитьИзображениеВОбласть(Страница: СтраницаPdf, Поток: ПотокЧтения)
    пер Области = Страница.ПолучитьСвободныеОбластиНаСтранице(100, 100)
    если Области.Размер() > 0
        Страница.ДобавитьИзображение(Поток, Области[0])
    ;
;
```

### Пример добавления штампа ЭЦП к PDF-документу

В этом примере вы добавите штамп с информацией об электронной цифровой подписи к пользовательскому PDF-документу. Если на последней странице есть свободная область, то штамп размещается на ней, или на новой странице в противном случае. Штамп размещается в область заданного размера (150 мм х 70 мм) с помощью метода [`ДобавитьИзображение()`](../stdlib/pdfpage-ru-568344e1aad1.md).

> [!TIP] совет
> Чтобы вставляемое изображение имело точные размеры в миллиметрах, необходимо указать ширину и высоту прямоугольной области с сохранением отношения сторон картинки (см. описание метода [`ДобавитьИзображение()`](../stdlib/pdfpage-ru-568344e1aad1.md)).

Пример добавления штампа ЭЦП

```xbsl
метод ВывестиШтамп(Документ: ДокументPdf, ПотокШтампа: ПотокЧтения)
    пер ЧислоСтраниц = Документ.ПолучитьКоличествоСтраниц()
    пер Страница = Документ.ПолучитьСтраницу(ЧислоСтраниц - 1)

    пер ШиринаШтампа = 150
    пер ВысотаШтампа = 70

    пер ГраницаСодержимого = Страница.ПолучитьВысотуСодержимого()
    если ((Страница.Размер.Ширина > ШиринаШтампа) и ((Страница.Размер.Высота - ГраницаСодержимого) > ВысотаШтампа))
        пер Область = новый ПрямоугольнаяОбласть(0, ГраницаСодержимого, ШиринаШтампа, ВысотаШтампа)
        Страница.ДобавитьИзображение(ПотокШтампа, Область)
    иначе
        Страница = Документ.ДобавитьСтраницу()
        пер Область = новый ПрямоугольнаяОбласть(0, 0, ШиринаШтампа, ВысотаШтампа)
        Страница.ДобавитьИзображение(ПотокШтампа, Область)
    ;
;
```

## Конвертация страницы в изображение

Для конвертации страницы в изображение и записи его в [`ПотокЗаписи`](../stdlib/writablestream-ru-db9a09ef1933.md) используйте метод [`КонвертироватьВИзображение()`](../stdlib/pdfpage-ru-568344e1aad1.md). В зависимости от перегрузки метод позволяет конвертировать изображение либо с заданным качеством, либо с заданным разрешением.

```xbsl
статический метод КонвертироватьПервуюСтраницу(Ссылка: ДвоичныйОбъект.Ссылка): ДвоичныйОбъект.Ссылка
    пер ИсходныйДокумент = ДокументPdf.Прочитать(Ссылка.Загрузить().ОткрытьПотокЧтения(), "")
    пер Страница0 = ИсходныйДокумент.ПолучитьСтраницу(0)
    пер Поток = новый ВременныйПотокЗаписи()
    // Выберите один из вариантов сохранения файла
    // Качество по умолчанию — dpi = 200
    Страница0.КонвертироватьВИзображение(Поток, ФорматИзображения.Png)
    // dpi = 400
    Страница0.КонвертироватьВИзображение(Поток, ФорматИзображения.Png, 400)
    // Размер изображения 500х200
    Страница0.КонвертироватьВИзображение(Поток, ФорматИзображения.Png, новый РазмерИзображения(500, 200))
    знч ДвоичныйОбъект = ОбъектноеХранилище.Загрузить("СконвертированнаяСтраница.png", Поток.ОткрытьПотокЧтения())
    
    возврат ДвоичныйОбъект.Ссылка
;
```
