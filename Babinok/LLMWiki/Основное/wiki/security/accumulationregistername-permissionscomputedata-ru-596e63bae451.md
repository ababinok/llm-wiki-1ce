## Документированный контракт и примеры

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений` `Доступность: Сервер`

Представляет собой структуру с измерениями указанными в настройке `РасчетРазрешенийПо` элемента проекта. Используется при расчёте ключей доступа для объектов регистра накопления - при реализации обработчика `ВычислитьКлючиДоступаДляИзменения` [ВычислитьКлючиДоступаДляИзменения](../data/accumulationregistername-ru-ca3f7a553094.md). Доступен только если включено управление доступом для отдельных объектов регистра.
