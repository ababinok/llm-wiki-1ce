`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПроцессаИнтеграции}.Метрики` `Доступность: Сервер`

Метрики процесса интеграции. Набор метрик и способы их обновления задаются при разработке схемы процесса. Для каждой метрики формируется свойство с ее именем. Программный доступ к метрикам возможен по имени или по индексу.

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Операция []

`Только чтение`

```
[Ключ: Строка]: неизвестно
```

Возвращает метрику процесса интеграции [ПроцессИнтеграции](../../wiki/integration/integrationprocess-ru-136570064b69.md) по индексу, в качестве значения которого используется имя метрики.

### Пример

Следующие два способа обращения к метрике `СчетчикОшибок` процесса интеграции `СетьМагазинов` эквивалентны:

```xbsl
пер СчетчикОшибок1 = СетьМагазинов.Метрики.СчетчикОшибок
пер СчетчикОшибок2 = СетьМагазинов.Метрики["СчетчикОшибок"]
```

## Методы

### КакСоответствие

`Версия 10.0 и выше`

`Доступность: Сервер`

```
КакСоответствие(): ЧитаемоеСоответствие<Строка,ИмяПроцессаИнтеграции.ИмяМетрикиПроцессаИнтеграции>
```

Возвращает соответствие, в котором ключ - имя метрики, а значение - метрика.
