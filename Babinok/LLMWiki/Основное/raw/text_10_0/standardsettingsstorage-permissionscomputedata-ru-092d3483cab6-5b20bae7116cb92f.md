`Стд::ХранилищаНастроек::СтандартноеХранилищеНастроек.ДанныеРасчетаРазрешений` `Доступность: Сервер`

Представляет собой структуру с реквизитами хранилища настроек необходимыми для пересчета стандартных разрешений доступа.

### СтандартноеХранилищеНастроек.ДанныеРасчетаРазрешений

`Доступность: Сервер`

```
СтандартноеХранилищеНастроек.ДанныеРасчетаРазрешений(Объект: СтандартноеХранилищеНастроек.Объект)
```

Конструктор из объекта. Создает данные для расчета разрешений со значениями реквизитов, необходимых для расчета разрешений доступа равными значениям реквизитов в переданном объекте.
