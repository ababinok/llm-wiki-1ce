#### ПараметрыЗапроса

```yaml
ПараметрыЗапроса: ПараметрОтчета[]
```

Параметры запроса. Свойство может быть пустым, если [запрос](../../wiki/queries/use-query-to-create-report-3cf7e26dbbbc.md), выступающий в качестве источника данных для отчета, не содержит параметров.

В свойстве должны быть указаны все параметры, используемые в запросе. Недопустимо указывать параметры, которые отсутствуют в тексте запроса.
