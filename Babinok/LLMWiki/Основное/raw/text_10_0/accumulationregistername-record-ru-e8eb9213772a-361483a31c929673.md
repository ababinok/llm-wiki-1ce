## Конструкторы

### {ИмяРегистраНакопления}.Запись

`Доступность: КлиентИСервер`

```
@ИменованныеПараметры
{ИмяРегистраНакопления}.Запись(
  Регистратор: <ТипРегистратора>,
  Активность: Булево = Истина,
  Период: ДатаВремя,
  ВидЗаписи: ВидЗаписиРегистраНакопления,
  <ИмяИзмерения1>: <ТипИзмерения1> = <ЗначениеПоУмолчаниюИзмерения1>,
  ....<ИмяИзмеренияN>: <ТипИмениИзмеренияN> = <ЗначениеПоУмолчаниюИмениИзмеренияN>,
  <ИмяРесурса1>: <ТипРесурса1> = <ЗначениеПоУмолчаниюРесурса1>,
  ...<ИмяРесурсаN>: <ТипРeсурcаN> = <ЗначениеПоУмолчаниюРесурсаN>,
  <ИмяРеквизита1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<ИмяРеквизитаN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

Конструктор по значениям всех полей (измерений, ресурсов, реквизитов) - создаёт запись с указанными значениями. Можно использовать только форму вызова с указанием имён параметров. Стандартное поле

`ВидЗаписи`

доступно только для регистра остатков.

### СоздатьКопию

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопию(
  Регистратор: <ТипРегистратора> = <ЗначениеРегистратора>,
  Активность: Булево = <ЗначениеАктивности>,
  Период: ДатаВремя,
  ВидЗаписи: ВидЗаписиРегистраНакопления = <ЗначениеВидаЗаписи>,
  <Измерение1>: <ТипИзмерения1> = <ЗначениеИзмерения1>,
  ....<ИзмерениеN>: <ТипИзмеренияN> = <ЗначениеИзмеренияN>,
  <Ресурс1>: Number = <ЗначениеРесурса1>,
  ...<РесурсN>: Number = <ЗначениеРесурсаN>,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр записи регистра накопления копированием этой записи. Не будет автоматически копироваться стандартное поле `Период` регистра накопления. Кроме того, не будут копироваться измерения, ресурсы и реквизиты, копирование которых отключено в регистре накопления с помощью свойства `ЗаполнятьПриКопировании`. Стандартное поле `ВидЗаписи` доступно только для регистра остатков. При вызове можно явно задать значения отдельным полям.

## Обработчики

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяРегистраНакопления}.Данные)
```

Вызывается при создании нового экземпляра записи регистра накопления копированием существующей. На момент вызова этого обработчика значения измерений, ресурсов и реквизитов у новой записи будут уже заполнены из записи - источника. Не будет автоматически копироваться стандартное поле

`Период`

регистра накопления. Кроме того, не будут копироваться измерения, ресурсы и реквизиты, копирование которых отключено в регистре накопления с помощью свойства

`ЗаполнятьПриКопировании`

.

Параметр `Источник` содержит данные исходной записи регистра накопления, копированием которой и создается новая запись.

#### Примеры

В проекте есть регистр накопления "ЗаказыКлиентов". Необходимо сделать так, чтобы при копировании записи этого регистра накопления у стандартного поля `Период` проставлялась текущая дата

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: ЗаказыКлиентов.Данные)
    Период = ДатаВремя.Сейчас()
;
```
