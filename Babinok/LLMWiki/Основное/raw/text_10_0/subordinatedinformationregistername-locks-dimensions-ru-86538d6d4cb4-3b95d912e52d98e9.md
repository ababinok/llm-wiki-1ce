`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПодчиненногоРегистраСведений}.Блокировки.Измерения` `Доступность: Сервер`

Блокировка для пространства блокировок `Измерения` регистра сведений `ИмяПодчиненногоРегистраСведений`. Пространство используется для блокировки записей регистра сведений с указанными значениями измерений без учета периода. При записи набора записей на это пространство платформой устанавливается исключительная блокировка со значениями полей-измерений, соответствующими фильтру набора записей.

Доступно только для периодических регистров сведений.

### {ИмяПодчиненногоРегистраСведений}.Блокировки.Измерения

`Доступность: Сервер`

```
ИмяПодчиненногоРегистраСведений.Блокировки.Измерения(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  <ИмяИзмерения>: <ТипИзмерения>)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры необязательные. Если значение параметра, соответствующего полю блокировки, не задано, значение этого поля в блокировке не указано (блокируются все значения).
