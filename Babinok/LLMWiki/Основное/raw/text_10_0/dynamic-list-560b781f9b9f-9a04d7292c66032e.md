Источником данных для таблиц большинства форм списков (списки справочников клиентов, контактных лиц и др.) является системный компонент [`ДинамическийСписок`](../../wiki/interface/dynamiclist-ru-ab61b0be4de4.md).

Для динамических списков указывается основная таблица и выражения полей, для которых можно использовать псевдонимы, как в примере ниже для поля **Владелец.Клиент**.

```yaml
Тип: Таблица<ДинамическийСписок>
Имя: ТаблицаСписка
Источник:
    ОсновнаяТаблица:
        Таблица: Задачи
    Поля:
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Код
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Наименование
        -
            Тип: ПолеДинамическогоСписка
            Выражение: ДатаСоздания
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Владелец.Клиент
            Псевдоним: Владелец_Клиент
            Представление: Клиент
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
    Сортировка:
        -
            Поле: ДатаСоздания
            НаправлениеСортировки: ПоУбыванию
```

Кроме того, можно указывать присоединенные таблицы, которые соединяются с основной для уточнения выборки. Так, в примере ниже, в форме списка валют имеются присоединенные таблицы динамического списка. Основная таблица справочника **Общие::КурсыВалют::Валюты** соединяется с виртуальной таблицей среза последних регистра сведений **Общие::КурсыВалют::КурсыВалют**:

В форме списка валют видны колонки «Наименование», «Код», «Дата курса», «Курс», «Кратность». [Описание иллюстрации](../figures/67a65d602eb8ae1b8f7754d4618a7d5838280ed8cc5c779a830eb95b74ad5dda-9871a8d58f527e36.md)

И для основной, и для присоединенной таблиц указываются псевдонимы, которые используются в выражении соединения таблиц и в выражениях полей динамического списка:

```yaml
Тип: Таблица<ДинамическийСписок>
ИспользованиеПоиска: Ложь
Имя: ТаблицаСписка
Источник:
    ОсновнаяТаблица:
        Таблица: Валюты
        Псевдоним: Валюты
    Поля:
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Валюты.Ссылка
            Псевдоним: Валюты_Ссылка
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Валюты.Наименование
            Псевдоним: Валюты_Наименование
        -
            Тип: ПолеДинамическогоСписка
            Выражение: Валюты.Код
            Псевдоним: Валюты_Код
        -
            Тип: ПолеДинамическогоСписка
            Выражение: КурсыСрезПоследних.Курс
            Псевдоним: КурсыСрезПоследних_Курс
        -
            Тип: ПолеДинамическогоСписка
            Выражение: КурсыСрезПоследних.Кратность
            Псевдоним: КурсыСрезПоследних_Кратность
        -
            Тип: ПолеДинамическогоСписка
            Выражение: КурсыСрезПоследних.Период
            Псевдоним: КурсыСрезПоследних_Период
     ПрисоединенныеТаблицы:
        -
            Таблица: КурсыВалют.СрезПоследних
            Псевдоним: КурсыСрезПоследних
            Фильтр:
                Элементы:
                    -
                        Тип: ЭлементФильтраВыражение
                        Выражение: Валюты.Ссылка == КурсыСрезПоследних.Валюта
```

## Фильтрация данных

Кроме того, можно задать условия фильтрации данных в выборке с помощью свойства `Фильтр`. Для фильтра могут использоваться поля как основной, так и присоединенных таблиц. Условие фильтрации сравнивается со значением поля данных. Это может быть одно значение, выражение или группа значений и/или выражений, соединенных логическими операторами.

> [!WARNING] важно
> Если динамический список отображает иерархию, то при использовании фильтров и поиска иерархический вид отключается.

## Настройка фильтрации и сортировки списка

### Режим работы с фильтрами и сортировкой

Режим работы с фильтрами и сортировкой задается с помощью свойства списка [`РежимНастроек`](../../wiki/interface/list-ru-58c40755a735.md).

Доступны три режима настройки списка:

- [`Простой`](../../wiki/interface/listsettingsmode-ru-afb5c5be0937.md) – компактный вид настроек списка. Доступны:
  
  - предопределенные варианты сортировок,
  - заранее подготовленные фильтры-выключатели,
  - автоматические фильтры на основе полей динамического списка с возможностью уточнять выборку данных через установку значения поддерживаемого типа такого поля.
    
    Простой фильтр списка [Описание иллюстрации](../figures/cd6f48efb13e408339772fb383f551b2f3a313b5d62c0686a83cee4b4fc1186e-61b51d1480b6a08f.md)
- [`Расширенный`](../../wiki/interface/listsettingsmode-ru-afb5c5be0937.md) – отображается так же, как простой режим, но с возможностью указывать вид сравнения для автоматических фильтров на основе полей динамического списка.
  
  Расширенный фильтр списка: для поля «Номер» раскрыт выбор сравнения «Заполнено», «Не заполнено», «Содержит», «Не содержит»; выбран «Содержит». [Описание иллюстрации](../figures/4b19ad7866f62c35f92ddc6dc5c12763f699e40603e5b5833fd28e72d0956f19-261f72b7f3a3b0cf.md)
- [`Произвольный`](../../wiki/interface/listsettingsmode-ru-afb5c5be0937.md) – можно добавлять произвольные фильтры и объединять их по условию.
  
  Произвольный фильтр динамического списка: включение условия флажком, выбор поля и оператора, ввод значения; кнопка добавляет дополнительное условие. [Описание иллюстрации](../figures/3c47ddfd40dc5cac3fe955a47fa3210e6bf1b432095b87068aa73025c98f81c2-51c86f0a15daea79.md)

С помощью свойства [`ИспользоватьМножественнуюСортировку`](../../wiki/interface/list-ru-58c40755a735.md) вы можете включить или отключить интерфейс настройки множественной сортировки. Если в источнике данных не задано ни одной автоматической сортировки, значение свойства всегда будет `Истина`.

### Настройка автоматического фильтра

Вы также можете настроить автоматический фильтр списков с помощью структур [`НастройкиАвтоматическогоФильтраПоляДинамическогоСписка`](../../wiki/interface/dynamiclistfieldautofiltersettings-ru-1339f3d7430d.md) и [`НастройкиАвтоматическогоФильтраПоляКоллекцииДинамическогоСписка`](../../wiki/interface/dynamiclistcollectionfieldautofiltersettings-ru-3019eb54556d.md).

Для **поля динамического списка** вы можете настроить такие параметры, как:

- представление сортировки по возрастанию и убыванию,
- настройки ввода числа, длительности и ссылок,
- значение фильтра по умолчанию.

Для **поля коллекции динамического списка** вы можете настроить такие параметры, как:

- настройки ввода ссылок,
- значение фильтра по умолчанию.

### Цветовое оформление активных фильтров

Вы можете выбрать цветовую схему отображения фильтров и применить ее на уровне приложения. Для этого в теме оформления задайте свойство [`ЦветНастроекСписка`](../../wiki/interface/designtheme-ru-fd772ce038a8.md). Доступны следующие варианты:

- акцентный первичный,
  
  Строка активных фильтров динамического списка оформлена акцентным первичным цветом: сортировка и условия выделены жёлтым оттенком. [Описание иллюстрации](../figures/e5cba0588b965b2b555fc2dfb48b0cf57d02565fad57eeb7ebb3dc41cbb2320d-aa36b8e35b9a90ef.md)
- акцентный вторичный,
  
  Строка фильтров динамического списка оформлена акцентным вторичным цветом: видны сортировка, условие количества товара, бренд и наименование. [Описание иллюстрации](../figures/4694db9ff3b5ed58927c76fa06f5db573da657fb5b09acd814cb0f1c1fce9d2b-464234e6fb9add6b.md)
- бесцветный.
  
  Строка фильтров динамического списка в бесцветном варианте: сортировка и условия показаны на нейтральном фоне без цветового акцента. [Описание иллюстрации](../figures/5099542582384750d1293d781d3684bc33e5923648735a806ee7ce71f5d95092-30e1c220752efaf7.md)

## Типизация строк

Строки динамического списка поддерживают типизацию с помощью свойства **ИмяТипаДанныхСтроки**. Если значение свойства установлено, то генерируется тип `<имя-элемента-проекта>.<имя-типа-данных-строки>`.

Например, для динамического списка в форме **КурсыВалютФормаСписка** параметризация может быть установлена следующим образом:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: 4eeaba79-571b-4801-9a2d-fa068b9446aa
Имя: КурсыВалютФормаСписка
ОбластьВидимости: ВПроекте
Наследует:
    Тип: ФормаСписка
    ВключатьВАвтоИнтерфейс: Ложь
    ПовторноеИспользованиеФормы: Ложь
    ДополнительныеКоманды:
        Тип: ФрагментКомандногоИнтерфейса
        Элементы:
            - =Обновить
    КомпонентТаблицы: =Компоненты.ТаблицаСписка
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Таблица<ДинамическийСписок<КурсыВалютФормаСписка.ДанныеСтрокиСписка>>
            Имя: ТаблицаСписка
            Источник:
                ИмяТипаДанныхСтроки: ДанныеСтрокиСписка
                ОсновнаяТаблица:
                    Таблица: КурсыВалют
                Поля:
                    -
                        Тип: ПолеДинамическогоСписка
                        Выражение: Период
                    -
                        Тип: ПолеДинамическогоСписка
                        Выражение: Валюта
                    -
                        Тип: ПолеДинамическогоСписка
                        Выражение: Курс
                    -
                        Тип: ПолеДинамическогоСписка
                        Выражение: Кратность
```

Для такого примера будет сгенерирован тип `КурсыВалютФормаСписка.ДанныеСтрокиСписка`, доступный из кода:

```xbsl
метод СоздатьСтрокуСписка(Кратность: Число, Период: Дата, Валюта: Валюты.Ссылка?, Курс: Число)
    пер СтрокаСписка = новый КурсыВалютФормаСписка.ДанныеСтрокиСписка(Кратность, Период, Валюта, Курс)
;
```

Если у динамического списка задано свойство **ИмяТипаДанныхСтроки**, то для него должны быть указны свойства **ОсновнаяТаблица** и **Поля**. Если используется присоединенная таблица, то для нее должен быть настроен **Фильтр**.

Значение типа `<имя-элемента-проекта>.<имя-типа-данных-строки>` не может быть вычислено в реальном времени, а значит нельзя использовать вычисляемые выражения внутри свойств:

- ОсновнаяТаблица
  
  ,
- Поля
  
  ,
- ПрисоединенныеТаблицы
  
  ,
- Параметры
  
  .

## Параметры и аргументы

Условие запроса можно указать непосредственно в описании динамического списка или одной из его таблиц, как значение свойства. Это позволяет:

- передавать условия запроса во время исполнения программы;
- упрощать написание и чтение длинных, сложных запросов;
- переиспользовать одно и то же условие, которое повторяется несколько раз в одном или нескольких запросах.

**Параметры** позволяют добавлять условия выборки напрямую в описание динамического списка как значения его свойств. В дальнейшем они могут использоваться в виде ссылок в значениях или выражениях фильтра.

Чтобы добавить параметр, добавьте в описание динамического списка свойство `Параметры`, после чего укажите один или несколько параметров, каждый из которых будет иметь специальный тип [`ПараметрДинамическогоСписка`](../../wiki/interface/dynamiclistparameter-ru-0437a7bdc276.md), имя и значение. Значением может быть как собственно значение определенного типа, так и ссылка на объект, например, условие выборки, переданное пользователем во время исполнения запроса:

```yaml
Тип: Таблица<ДинамическийСписок>
Имя: ТаблицаСПараметрами
Источник:
    ОсновнаяТаблица:
        Таблица: Срез
    Параметры:
        -
            Тип: ПараметрДинамическогоСписка
            Имя: Параметр1
            Значение:
                Тип: Число
                Значение: 110
        -
            Тип: ПараметрДинамическогоСписка
            Имя: Параметр2
            Значение: =УсловиеОтПользователя
    Фильтр:
        Элементы:
            -
                Тип: ЭлементФильтраВыражение
                Выражение: Срез.Курс == &Параметр2
```

**Аргументы** позволяют добавлять значения в основную или присоединенные таблицы динамического списка. Аргументом таблицы может быть просто значение или целое выражение. При использовании таблицы аргумент будет передан автоматически во время исполнения запроса.

Чтобы добавить аргумент, добавьте свойство `Аргументы`, после чего укажите для него одно или несколько свойств `Значение`. Например, для следующей выборки на языке запросов:

```xbql
ВЫБРАТЬ
    Период,
    Курс,
    Валюта
ИЗ
    КурсыВалют.СрезПоследних(Дата{2021-04-05})
```

Описание аргументов в файле YAML будет выглядеть следующим образом:

- для основной таблицы:
  
  ```yaml
  Тип: Таблица<ДинамическийСписок>
  Источник:
      ОсновнаяТаблица:
          Таблица: КурсыВалют.СрезПоследних
          Псевдоним: Срез
          Аргументы:
              -
                  Тип: АргументТаблицы
                  Значение:
                      Тип: Дата
                      Значение: 2021-04-05
      Поля:
          - 
              Тип: ПолеДинамическогоСписка
              Выражение: Срез.Период
          - 
              Тип: ПолеДинамическогоСписка
              Выражение: Срез.Валюта
  ```
- для присоединенной таблицы:
  
  ```yaml
  ПрисоединенныеТаблицы:
      - 
          Тип: ПрисоединеннаяТаблица
          Таблица: КурсыВалют.СрезПоследних
          Аргументы:
              -
                  Тип: АргументТаблицы
                  Значение:
                      Тип: Дата
                      Значение: 2021-04-05
  ```

Пример использования выражения как аргумента таблицы:

```yaml
Тип: Таблица<ДинамическийСписок>
ИспользованиеПоиска: Ложь
Источник:
    ОсновнаяТаблица:
        Таблица: КурсыВалют.СрезПоследних
        Псевдоним: Срез
        Аргументы:
            -
                Тип: АргументТаблицыВыражение
                Выражение: =ПараметрДата
    Параметры:
        - 
            Тип: ПараметрДинамическогоСписка
            Имя: ПараметрДата
            Значение:
                Тип: Дата
                Значение: 10.10.2021
```

## Реквизиты-коллекции

Если в **Справочнике** либо **Документе** есть [реквизит-коллекция](../../wiki/data/collection-type-attribute-55d55dbeb248.md), то его можно получить как поле выборки динамического списка. В частности, поддерживается возможность получения реквизитов-коллекций в выборке динамического списка и использования их в фильтрах динамического списка. Также можно осуществлять отбор по множественному полю с особыми условиями сравнения.

Пример описания поля с реквизитом-коллекцией в выборке динамического списка:

```yaml
Тип: Таблица<ДинамическийСписок>
Имя: Таблица
Источник:
    Тип: ДинамическийСписок
    ОсновнаяТаблица:
        Таблица: СправочникСотрудники
    Поля:
        -
            Тип: ПолеДинамическогоСписка
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
            Выражение: Код
        -
            Тип: ПолеКоллекцияДинамическогоСписка
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
            Выражение: НомераТелефонов
    Колонки:
        -
            Тип: СтандартнаяКолонкаТаблицы<СтрокаДинамическогоСписка>
            Заголовок: Код
            ПолеЗначения: Код
        -
            Тип: СтандартнаяКолонкаТаблицы<СтрокаДинамическогоСписка>
            ПолеЗначения: НомераТелефонов
            Заголовок: Номера телефонов
```

Для фильтрации строк по полю с реквизитом-коллекцией используется перечисление `ВидСравненияПоляКоллекция`. Оно содержит следующие элементы:

- Пусто
  
  — условие истинно, если множественное поле не содержит ни одного значения (поле фильтра «Значение» игнорируется);
- СодержитЛюбой
  
  — условие истинно, если хотя бы одно значение фильтра присутствует в значении множественного поля;
- СодержитВсе
  
  — условие истинно, если каждое значение фильтра присутствует в значении множественного поля;
- СодержитТолько
  
  — условие истинно, если все значения множественного поля совпадают с заданными значениями фильтра;
- НеСодержит
  
  — условие истинно, если ни одно значение фильтра не совпадает со значениями множественного поля.

Пример фильтрации по полю с реквизитом-коллекцией в среде разработки:

```yaml
Тип: Таблица<ДинамическийСписок>
Имя: Таблица
Источник:
    Тип: ДинамическийСписок
    ОсновнаяТаблица:
        Таблица: СправочникСотрудники
    Поля:
        -
            Тип: ПолеДинамическогоСписка
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
            Выражение: Код
        -
            Тип: ПолеКоллекцияДинамическогоСписка
            ОтображатьВНастройкахФильтров: Истина
            ОтображатьВАвтоматическихФильтрах: Всегда
            Выражение: ПройденныеКурсы
    Колонки:
        -
            Тип: СтандартнаяКолонкаТаблицы<СтрокаДинамическогоСписка>
            Заголовок: Код
            ПолеЗначения: Код
        -
            Тип: СтандартнаяКолонкаТаблицы<СтрокаДинамическогоСписка>
            ПолеЗначения: ПройденныеКурсы
            Заголовок: Пройденные курсы
    Фильтр:
        Элементы:
            - 
                Тип: ЭлементФильтраПоляКоллекция
                Поле: ПройденныеКурсы
                ВидСравненияПоляКоллекция: СодержитЛюбой
                Значение:
                    Тип: Строка
                    Значение: Курс по программированию
```

Пример фильтрации по полю с реквизитом-коллекцией в пользовательском интерфейсе:

- Для того чтобы использовать фильтрацию с особыми условиями в пользовательском интерфейсе, следует поменять тип фильтра на **Продвинутый фильтр**. Для этого откройте фильтр, нажмите на символПиктограмма «Меню». [Описание иллюстрации](../figures/62741f487c0f64c685ac0b6ded85ca1ab60184f70b7574592d5ee1eb0f09e2ca-5b909888db99e969.md) и выберите **Тип фильтров**:
  
  Фильтр открывается значком в правой части панели таблицы. [Описание иллюстрации](../figures/c096e07db88c4518061ed88281dcb3d814ca5786624bea55e7a58692b278bdb3-782d2a3189684f4f.md)
- В открывшемся окне выберите **Продвинутые** и нажмите **Применить**:
  
  
- После этого снова откройте фильтр и нажмите **+ Добавить фильтр**. В открывшемся окне укажите необходимый столбец с реквизитом-коллекцией, задайте условие отбора, а также отметьте все необходимые значения в выпадающем списке поля **Значение**. Нажмите **Сохранить**:
  
  В настройках сортировки и фильтров добавлен фильтр по коллекции «Метки», выбран оператор «Содержит все»; в списке значений несколько меток отмечены флажками. [Описание иллюстрации](../figures/50ef53dac88a816b6328a3424cb8e9a5d31ea32733ed53b437824983454ff491-2c349e1175aed0ac.md)
