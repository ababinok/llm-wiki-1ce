## Методы

### Зарегистрировать

`Доступность: Сервер`

```
@ИменованныеПараметры
Зарегистрировать(
  СсылкаНаСервисСаморегистрации: Строка? = Неопределено,
  ПараметрыПоискаПриглашения: ЧитаемоеСоответствие<ВидКонтактаПользователя, Строка>? = Неопределено,
  ДатаОкончания: Момент? = Неопределено,
  ОднократнаяАктивация: Булево? = Неопределено
): ПриглашениеЕдиногоМобильногоКлиента
```

>

Вызов возможен только с именованными параметрами

Регистрирует приглашение в сервисе активации.

Метод принимает следующие параметры:

- `СсылкаНаСервисСаморегистрации`
  
  - ссылка на сервис регистрации, куда перейдет пользователь после ввода кода активации. Если параметр не задан, ссылка будет искаться в настройках приложения в ПУ. Если параметр не задан и ссылки не в настройках будет выброшено исключение ИсключениеПриглашенияЕдиногоМобильногоКлиента
- `ПараметрыПоискаПриглашения`
  
  - дополнительные параметры, которые могут быть использованы вместе кодом активации для поиска приглашений. Сейчас это Почта и/или Телефон. При указании доп. параметров, поиск ссылки будет производиться не только по коду активации, но и по переданному значению адреса эл. почты или телефона. При попытке повторной регистрации приглашения хотя бы с одним существующим ключом будет выкинуто исключение ИсключениеПриглашенияЕдиногоМобильногоКлиента
- `ДатаОкончания`
  
  - дата, после которой приглашение будет удалено. После удаление воспользоваться кодом будет не возможно. Если передана дата в прошлом будет выброшено исключение ИсключениеНедопустимыйАргумент
- `ОднократнаяАктивация`
  
  - флаг указывающий, является приглашение одноразовым или нет. По умолчанию = Ложь

возвращает объект ПриглашениеЕдиногоМобльногоКлиента с идентификатором и кодом активации.

---

### Отменить

`Доступность: Сервер`

```
Отменить(ИдПриглашения: Ууид)
```

Удаляет ранее зарегистрированное приглашение.
