`Версия 10.0 и выше`

Таблица с информацией о наличии циклов в иерархических связях справочника с группами **ИмяСправочникаСГруппами**. Таблица порождается, если свойство **Вид** иерархии справочника имеет значение **ИерархияГруппИЭлементов**.

Таблица содержит информацию об элементах, образующих цикл в иерархии. Цикл создается, если в качестве родителя для элемента записать одного из его непрямых потомков.

При записи объектов, входящих в иерархию (если объект новый или изменено значение родителя), проверяется, что эта запись не создаст цикл в иерархии.

Если обнаруживается цикл:

- при отсутствии активного контекста загрузки выкидывается исключение;
- при наличии активного контекста загрузки запись выполняется, при этом в таблицу
  
  ИмяСправочникаСГруппами.ИерархияГруппИЭлементов.Циклы
  
  записывается информация о наличии циклов для всех входящих в цикл объектов. При разрыве циклов эта информация автоматически удаляется.

Цикл из одного объекта (когда объект является собственным родителем) нельзя записать ни в каком режиме.

---

## Поля

### ВершинаЦикла

```
ВершинаЦикла: ИмяСправочникаСГруппами.Группы.Ссылка|ИмяСправочникаСГруппами.Ссылка
```

Элемент, при записи которого был образован или обнаружен (если к уже имеющемуся справочнику добавляется иерархия) цикл.

---

### Элемент

`Ключевое поле`

```
Элемент: ИмяСправочникаСГруппами.Группы.Ссылка|ИмяСправочникаСГруппами.Ссылка
```

Элемент, который образует цикл.
