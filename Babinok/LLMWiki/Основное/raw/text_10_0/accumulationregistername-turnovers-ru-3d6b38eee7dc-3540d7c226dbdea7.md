Позволяет получить итоговые обороты ресурсов в разрезе измерений за определенный промежуток времени (период). Итоговые значения могут быть получены в разрезе комбинаций значений измерений и/или в развороте дополнительной периодичности.

Виртуальная таблица оборотов не хранится в базе данных, а строится в момент обращения к ней. Для построения виртуальной таблицы могут использоваться данные таблицы итогов (если значение свойства регистра `ХранитьПериодическиеИтоги` равно `Истина`) и таблицы движений регистра (из базы данных). При этом учитываются значения параметров виртуальной таблицы. Итоги ресурсов собираются только по активным записям.

**Параметры:**

- НачалоПериода: [ДатаВремя](../../wiki/stdlib/datetime-ru-b9ec40d17fe0.md)? Используется для указания начала периода расчета оборотов. Значение параметра включается в период расчета. Если параметр не задан, обороты рассчитываются с самой первой записи.
- КонецПериода: [ДатаВремя](../../wiki/stdlib/datetime-ru-b9ec40d17fe0.md)? Используется для указания конца периода расчета оборотов. Значение параметра включается в период расчета. Если параметр не задан, обороты рассчитываются по самую последнюю запись.
- Периодичность: [ПериодичностьИтоговРегистраНакопления](../../wiki/data/accumulationregistertotalsperiodicity-ru-3bb775cf3108.md) Позволяет задать дополнительную группировку данных по стандартным периодам. Принимает значения перечисления `ПериодичностьИтоговРегистраНакопления`: `Авто`, `Период` (значение по умолчанию), `Год`, `Полугодие`, `Квартал`, `Месяц`, `Декада`, `Неделя`, `День`, `Час`, `Минута`, `Секунда`, `Регистратор`, `Запись`. Если значение параметра равно `Период`, обороты предоставляются за весь период (с **НачалоПериода** по **КонецПериода**) без дополнительных разворотов. При `Авто` периодичность определяется по используемым в запросе полям.
- Фильтр Выражение языка запросов типа `Булево`. В выражении доступны поля измерений регистра накопления, а также применимые к этим полям выражения (например, операция обращения через точку или вызов функций, кроме агрегатных). Данный параметр позволяет ограничить состав исходных записей, по которым будут собираться итоги при построении виртуальной таблицы. Если параметр не указан, для сбора итогов будут анализироваться все активные записи регистра, что в большинстве случаев менее эффективно.

## Примеры

Пример запроса к таблице оборотов регистра накопления **ОстаткиНоменклатуры**:

```xbql
ВЫБРАТЬ
    ОстаткиНоменклатурыОбороты.Период КАК Период,
    ОстаткиНоменклатурыОбороты.Номенклатура КАК Номенклатура,
    ОстаткиНоменклатурыОбороты.Склад КАК Склад,
    ОстаткиНоменклатурыОбороты.КоличествоОборот КАК КоличествоОборот,
    ОстаткиНоменклатурыОбороты.КоличествоПриход КАК КоличествоПриход,
    ОстаткиНоменклатурыОбороты.КоличествоРасход КАК КоличествоРасход
ИЗ
    ОстаткиНоменклатуры.Обороты(%НачалоПериода, %КонецПериода, ПериодичностьИтоговРегистраНакопления.Месяц) КАК ОстаткиНоменклатурыОбороты
УПОРЯДОЧИТЬ ПО
    ОстаткиНоменклатурыОбороты.Период,
    ОстаткиНоменклатурыОбороты.Номенклатура,
    ОстаткиНоменклатурыОбороты.Склад
```

## Поля

### {ИмяИзмерения}

```
{ИмяИзмерения}: ТипИзмерения
```

Значение измерения регистра накопления.

---

### {ИмяРесурсаОборот}

```
{ИмяРесурса}Оборот: Число
```

Оборот ресурса. Для регистров оборотов считается как сумма всех движений. Для регистров остатков считается как сумма всех движений вида **Приход** со знаком «+» (плюс) и вида **Расход** со знаком «-» (минус).

---

### {ИмяРесурсаПриход}

```
{ИмяРесурса}Приход: Число
```

Содержит сумму всех движений вида **Приход** по ресурсу регистра. Существует только для регистра накопления остатков.

---

### {ИмяРесурсаРасход}

```
{ИмяРесурса}Расход: Число
```

Содержит сумму всех движений вида **Расход** по ресурсу регистра. Существует только для регистра накопления остатков.

---

### Период

`Версия 8.0 и выше`

```
Период: ДатаВремя
```

Содержит начальную дату периода, к которому относятся обороты регистра. Поле существует только в случае, если указано значение параметра **Периодичность**: `Год`, `Полугодие`, `Квартал`, `Месяц`, `Декада`, `Неделя`, `День`, `Час`, `Минута`, `Секунда`, `Регистратор` или `Запись`. В случае использования дополнительного разворота итогов по записям в поле **Период** содержится значение поля **Период** записи регистра.
