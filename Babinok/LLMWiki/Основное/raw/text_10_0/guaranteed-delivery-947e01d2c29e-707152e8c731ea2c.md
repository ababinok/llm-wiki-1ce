# Гарантированная доставка

«1С:Предприятие.Элемент» реализует гарантированную доставку сообщений. Сообщение хранится в приложении «1С:Предприятие.Элемента» до тех пор, пока «1С:Предприятие.Элемент» не получит подтверждение о том, что получатель это сообщение принял. Рассмотрим реализацию на примере взаимодействия двух систем «1С:Предприятия» через «1С:Предприятие.Элемент»:

Пример взаимодействия двух систем «1С:Предприятия» через «1С:Шина» [Описание иллюстрации](../figures/916dbfdae8c06b52c7d103e1ab1945136c1557bdae8b6d9f88c6370a6a533087-055b82705e4b5767.md)

Отправитель, приложение «1С:Предприятия», отправляет сообщение. Оно сохраняется в информационной базе и после этого служебными фоновыми заданиями отправляется в приложение «1С:Предприятие.Элемента». До тех пор пока не будет получено подтверждение от «1С:Предприятие.Элемента», что сообщение получено, будут выполняться повторные попытки отправить сообщение. Только после получения подтверждения от «1С:Предприятие.Элемента» сообщение удаляется из информационной базы.

Приложение «1С:Предприятие.Элемента» получает сообщение. Оно сразу его сохраняет во внутреннем хранилище, чтобы обеспечить гарантированную доставку. После этого приложение «1С:Предприятие.Элемента» отправляет сообщение через канал получателю. Сообщение будет храниться во внутреннем хранилище, пока получатель не подтвердит получение.

Получатель, приложение «1С:Предприятия», асинхронно, в фоне, получает это сообщение. Сохраняет его в информационной базе и после этого дает подтверждение получения сообщения «1С:Предприятие.Элементу». Обработчики запускаются уже после отправки подтверждения.
