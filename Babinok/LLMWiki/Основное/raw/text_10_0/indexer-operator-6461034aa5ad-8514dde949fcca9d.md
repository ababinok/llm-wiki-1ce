# Операция доступа по индексу «[]»

Операция `[]` используется для обращения к элементу коллекции по его индексу или имени.

Например, вы можете обратиться к первому элементу [массива](../../wiki/language/array-type-eee257947e0e.md) следующим образом:

```xbsl
знч МассивЧисел = [1, 2, 3, 3, 5]
знч ПервыйЭлемент = МассивЧисел[0] // 1
```

Операция `[]` может использоваться для обращения к символу в строке. Как указано в описании типа [`Строка`](../../wiki/language/string-type-e8ad86f5efd8.md), со строкой можно обращаться как с массивом, в котором каждый символ строки выступает в роли элемента массива. Поэтому вы можете обратиться к символу строки по индексу, где индекс — это целое число в интервале от `0` до `Строка.Длина() - 1`.

Например, чтобы обратиться к первому символу строки, используйте следующий код:

```xbsl
знч ПримерСтроки = "Это пример строки"
знч ПервыйСимвол = ПримерСтроки[0] // "Э"
```
