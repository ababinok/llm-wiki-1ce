Перегрузка метода — это использование одинакового имени метода с разными параметрами ([подробнее](../../wiki/language/methods-in-built-in-script-language-3c568746fa15.md)).

```xbsl
метод Сложить(А: Число, Б: Число): Число
    возврат А + Б
;

метод Сложить(А: Число, Б: Число, В: Число): Число
    возврат А + Б + В
;

метод Сложить(СтрокаА: Строка, СтрокаБ: Строка): Строка
    возврат СтрокаА + СтрокаБ
;
```
