*Базовые типы:* [Закрываемое](../../wiki/stdlib/closeable-ru-67cd73fca69d.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

## Операция []

`Только чтение`

```
[Ключ: Строка]: Объект
```

Возвращает значение поля с указанным именем.

---

## Динамические свойства

Свойство содержит значение одноименного поля результата выполнения запроса. Если имя поля результата выполнения запроса не является корректным идентификатором с точки зрения встроенного языка — обращение возможно с помощью операции []. Например: `Результат["Имя поля"]`. Если результат не спозиционирован на записи (см. метод [Следующий](../../wiki/data/sqlselectresult-ru-b351439e205b.md))- при обращении к свойству выдается ошибка. Изначально результат создается неспозиционированным на выборке.

---

## Методы

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

Закрывает результат выполнения запроса и освобождает связанные с ним ресурсы.

**Переопределение** [Закрываемое::Закрыть](../../wiki/stdlib/closeable-ru-67cd73fca69d.md)

---

### КакСоответствие

`Доступность: Сервер`

```
КакСоответствие(): Соответствие<Строка, Объект>
```

Возвращает соответствие, в котором ключ - имя поля выборки, а значение - значение поля. Если результат не спозиционирован на записи (см. метод

[Следующий](../../wiki/data/sqlselectresult-ru-b351439e205b.md)

), выбрасывается исключение

[ИсключениеSql](../../wiki/data/sqlexception-ru-c108d8de1746.md)

.

---

### Получить

`Доступность: Сервер`

```
Получить(ИмяПоля: Строка): Объект
```

Возвращает значение одноименного поля результата запроса. Если результат не спозиционирован на записи (см. метод

[Следующий](../../wiki/data/sqlselectresult-ru-b351439e205b.md)

)), выбрасывается исключение

[ИсключениеSql](../../wiki/data/sqlexception-ru-c108d8de1746.md)

. Если нет поля с указанным именем, выбрасывается исключение

[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)

. Необходимо иметь в виду, что при работе с некоторыми базами (например MS SQL) значение Blob полей, которые читаются потоками, нельзя получить после обращения к другому полю, т.к. при обращении к другому полю этот поток закрывается.

---

### Следующий

`Доступность: Сервер`

```
Следующий(): Булево
```

Пытается спозиционироваться на следующую запись результата. Изначально результат создается не спозионированным на записи. Возвращает

`Истина`

, если есть следующая запись результата.
