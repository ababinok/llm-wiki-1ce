Вызов метода — это место в тексте программы, где указывается имя метода с указанием аргументов, если метод имеет параметры, и использованием результата работы, если метод возвращает результат. Для вызова необходимо:

1. Указать
  
  имя метода
  
  .
2. Передать в метод
  
  аргументы
  
  , если метод имеет
  
  параметры
  
  .
3. Обработать возвращаемое значение, если метод возвращает результат.

```xbsl
// Определение методов
метод РассчитатьСумму(ПервоеЧисло: Число, ВтороеЧисло: Число): Число
    возврат ПервоеЧисло + ВтороеЧисло
;

метод ЗаписатьДанные(Массив: Массив<Число>, Данные: Число)
    Массив.Добавить(Данные)
;


метод Скрипт()
    пер Массив = новый Массив<Число>()
    // Вызов метода с параметрами и возвращаемым значением
    пер Результат = РассчитатьСумму(5, 3)
    // Вызов метода с параметрами и без возвращаемого значения
    ЗаписатьДанные(Массив, Результат)
;
```
