## Свойства

### Автоматическое

`Версия 9.0 и выше`

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Автоматическое
```

Если указанные разработчиком размеры больше реальных размеров картинки, используется [РеальныйРазмер](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md), иначе [Пропорционально](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md).

---

### Растянуть

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Растянуть
```

Картинка будет заданных разработчиком размеров. Если они не соотносятся с размерами картинки, она будет соответствующим образом искажена.

---

### РеальныйРазмер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
РеальныйРазмер
```

Картинка отображается своим реальным размером. Если размер картинки больше размера компонента, то края картинки будут обрезаны.

---

### Пропорционально

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Пропорционально
```

Картинка растягивается или сжимается таким образом, что бы занять всю указанную ширину или высоту.

---

### Заполнить

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Заполнить
```

Аналогично [Пропорционально](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md), но допускает обрезание краев картинки, если пропорции размеров компонента, указанные разработчиком, не соответствуют пропорциям картинки.

---

### Авто

`Версия 8.0 и ниже`

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Авто
```

Элемент перечисления был переименован в [Автоматическое](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md)

Если указанные разработчиком размеры больше реальных размеров картинки, используется [РеальныйРазмер](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md), иначе [Пропорционально](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md).
