`Стд::Интерфейс::ПоследовательностьОбучающихПодсказок` `Доступность: Клиент`

Описывает последовательность обучающих подсказок, которые показываются последовательно друг за другом. Такие подсказки обучают пользователя непосредственно в интерфейсе приложения. Последовательность может существовать только в рамках конкретной формы. См. [ПодсказкиПриПервомОткрытии](../../wiki/interface/form-ru-89fb5e7eaeb3.md) или [ЗапуститьОбучающиеПодсказки](../../wiki/interface/form-ru-89fb5e7eaeb3.md).

Структурное

## Конструкторы

### ПоследовательностьОбучающихПодсказок

`Доступность: Клиент`

```
ПоследовательностьОбучающихПодсказок(Элементы: Массив<ОбучающаяПодсказка>)
```

Создает обучающую подсказку со значениями свойств, соответствующими параметрам конструктора.

---

## Свойства

### Элементы

`Доступность: Клиент`

```
Элементы: Массив<ОбучающаяПодсказка>
```

Обучающие подсказки в составе данной последовательности. Каждый шаг описывается с помощью объекта [ОбучающаяПодсказка](../../wiki/interface/tutorialtooltip-ru-e538f221bd73.md).
