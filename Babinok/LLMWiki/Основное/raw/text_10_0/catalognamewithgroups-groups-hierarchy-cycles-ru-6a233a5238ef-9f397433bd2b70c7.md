`Версия 10.0 и выше`

Таблица с информацией о наличии циклов в иерархических связях справочника **ИмяСправочникаСГруппами.Группы**.

> [!NOTE] примечание
> Справочник **ИмяСправочникаСГруппами.Группы** порождается автоматически, если свойство **Вид** иерархии справочника имеет значение **ИерархияГруппИЭлементов**.

Таблица содержит информацию об элементах, образующих цикл в иерархии. Цикл создается, если в качестве родителя для элемента записать одного из его непрямых потомков.

Например, пусть иерархический справочник **Подразделения** содержит следующие элементы:

- Наименование:
  
  Головной офис
  
  .
- Наименование:
  
  Бухгалтерия
  
  . Родитель:
  
  Головной офис
  
  .
- Наименование:
  
  Вспомогательный персонал
  
  . Родитель:
  
  Бухгалтерия
  
  .

Для элемента **Головной офис** родитель меняется на **Вспомогательный персонал** и записывается в контексте загрузки. В результате образуется цикл. В таблице **Подразделения.Группы.Иерархия.Циклы** появятся следующие записи:

| ВершинаЦикла | Элемент |
| --- | --- |
| Головной офис | Бухгалтерия |
| Головной офис | Головной офис |
| Головной офис | Вспомогательный персонал |

При записи объектов, входящих в иерархию (если объект новый или изменено значение родителя), проверяется, что эта запись не создаст цикл в иерархии.

Если обнаруживается цикл:

- при отсутствии активного контекста загрузки выкидывается исключение;
- при наличии активного контекста загрузки запись выполняется, при этом в таблицу
  
  ИмяСправочникаСГруппами.Группы.Иерархия.Циклы
  
  записывается информация о наличии циклов для всех входящих в цикл объектов. При разрыве циклов эта информация автоматически удаляется.

Цикл из одного объекта (когда объект является собственным родителем) нельзя записать ни в каком режиме.

---

## Поля

### ВершинаЦикла

```
ВершинаЦикла: ИмяСправочникаСГруппами.Группы.Ссылка
```

Элемент, при записи которого был образован или обнаружен (если к уже имеющемуся справочнику добавляется иерархия) цикл.

---

### Элемент

`Ключевое поле`

```
Элемент: ИмяСправочникаСГруппами.Группы.Ссылка
```

Элемент, который образует цикл.
