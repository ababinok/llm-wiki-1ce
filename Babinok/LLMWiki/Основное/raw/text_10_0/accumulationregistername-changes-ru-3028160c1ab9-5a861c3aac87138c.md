Таблица регистрации изменений создается, только если регистр накопления включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению набора записей регистра накопления, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице регистра накопления.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **КлючОсновногоФильтра** из таблицы регистрации изменений **ОстаткиНоменклатуры.Изменения**:

```xbql
ВЫБРАТЬ
    ОстаткиНоменклатуры.Узел КАК Узел,
    ОстаткиНоменклатуры.КлючОсновногоФильтра КАК Ключ
ИЗ
    ОстаткиНоменклатуры.Изменения КАК ОстаткиНоменклатуры
```

---

## Поля

### КлючОсновногоФильтра

`Ключевое поле`

```
КлючОсновногоФильтра: ИмяРегистраНакопления.КлючОсновногоФильтра
```

Структура, описывающая ключ основного фильтра регистра накопления. Содержит единственное поле — **Регистратор**.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена, для которого зарегистрированы изменения.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Если изменение не включено в сообщение, то значение `Неопределено`.
