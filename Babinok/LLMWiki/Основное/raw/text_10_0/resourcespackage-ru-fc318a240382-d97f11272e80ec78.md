## Методы

### Получить

`Доступность: Сервер`

```
Получить(Путь: Строка): Ресурс
```

Возвращает ресурс по пути

`Путь`

.

`Путь`

- полный путь до ресурса.

#### Исключения

**[ИсключениеРесурсНеНайден](../../wiki/stdlib/resourcenotfoundexception-ru-9455193031c3.md)** - если ресурс по пути `Путь` не найден.

#### Примеры

Пример метода, который возвращает ссылку на ресурс по переданному имени.

```xbsl
метод КартинкаРанга(Ранг: Строка): ДвоичныйОбъект.Ссылка?
    возврат ПакетРесурсов.Текущий().Получить("Ранги/%Ранг.svg").Ссылка
;
```

### ПолучитьВсе

`Доступность: Сервер`

```
ПолучитьВсе(
  Путь: Строка = "",
  ВключитьВложенные: Булево = Истина
): Массив<Ресурс>
```

Возвращает все ресурсы по пути

`Путь`

.

`Путь`

- путь до папки с ресурсами.

`ВключитьВложенные`

- указывает, нужно ли возвращать ресурсы, расположенные во вложенных папках.

#### Исключения

**[ИсключениеРесурсНеНайден](../../wiki/stdlib/resourcenotfoundexception-ru-9455193031c3.md)** - если ресурсы по пути `Путь` не найдены или в качестве `Путь` используется полный путь до ресурса.

#### Примеры

```xbsl
// Получить все ресурсы относительно текущего пространства имен
знч Ресурсы = ПакетРесурсов.Текущий().ПолучитьВсе()

// Получить ресурсы относительно текущего пространства имен, которые лежат в папке 'Картинки'
// Но не включая ресурсы вложенных папок (например 'Картинки/Ранги')
знч Картинки = ПакетРесурсов.Текущий().ПолучитьВсе("Картинки", Ложь)
```
