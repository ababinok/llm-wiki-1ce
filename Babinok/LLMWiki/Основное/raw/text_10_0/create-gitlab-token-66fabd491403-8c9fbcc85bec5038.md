Чтобы создавать репозитории в одном из [подключенных хранилищ Gitlab](../../wiki/project/connect-to-gitlab-daf8c8c732dc.md) или использовать существующие внешние Git-репозитории для групповой разработки, вам необходимо выпустить *токен доступа*. Токен представляет собой уникальный идентификатор, который служит для аутентификации и авторизации пользователя в GitLab, а также позволяет выполнять основные операции с репозиториями кода: клонирование, внесение изменений и удаление.

## Выпустить персональный токен доступа

1. Войдите в свой аккаунт на платформе GitLab. Если у вас еще нет аккаунта, создайте его.
2. Нажмите на иконку пользователя в панели слева и выберите пункт **Preferences** в выпадающем меню.
  
  
3. Перейдите в раздел **Access Tokens** и нажмите **Add new token**, чтобы создать новый персональный токен.
  
  Создание нового персонального токена [Описание иллюстрации](../figures/879d405461fd0567d7bea0f8c4070517e17547ffd87c8f08ac74ca8a97b758e9-c350e1568a1b723d.md)
4. Задайте параметры токена:
  
  - Token name
    
    — имя токена;
  - Expiration date
    
    — срок действия токена (максимум 365 дней от даты создания);
  - Выберите следующий набор разрешений (
    
    scopes
    
    ):
    
    - api,
    - read_repository,
    - write_repository.
5. Нажмите **Create personal access token**.
6. Скопируйте и сохраните созданный токен. Он отображается только один раз. Когда вы закроете страницу, то больше не сможете посмотреть значение токена.

## Выпустить токен доступа к проекту

1. В GitLab откройте страницу проекта, для которого вы хотите создать токен доступа. В панели слева нажмите **Settings** ⟶ **Access Tokens**.
  
  
2. Нажмите **Add new token**, чтобы создать новый токен доступа к проекту.
  
  Создание нового токена доступа к проекту [Описание иллюстрации](../figures/ab9290b2c95077fe19dd076b7c93ff2121db8ece154d207767d3d852ded7a767-6bda462fedb2335d.md)
3. Задайте параметры токена:
  
  - Token name
    
    — имя токена;
  - Expiration date
    
    — срок действия токена (максимум 365 дней от даты создания);
  - Select a role
    
    — выберите роль для токена доступа. Чтобы токен мог взаимодействовать с репозиторием, для него необходимо указать роль
    
    Developer
    
    ,
    
    Maintainer
    
    или
    
    Owner
    
    ;
  - Выберите следующий набор разрешений (
    
    scopes
    
    ):
    
    - read_repository,
    - write_repository.
4. Нажмите **Create project access token**.
5. Скопируйте и сохраните созданный токен. Он отображается только один раз. Когда вы закроете страницу, то больше не сможете посмотреть значение токена.
