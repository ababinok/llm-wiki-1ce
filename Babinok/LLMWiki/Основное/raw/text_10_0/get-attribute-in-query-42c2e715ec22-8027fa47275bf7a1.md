Выражение получения реквизита имеет следующий синтаксис:

```xbql
базовое-выражение.имя-реквизита
```

***базовое-выражение*** должно иметь ссылочный тип, например `имя-справочника.Ссылка`. При отсутствии прав на все таблицы, на основе которых формируется реквизит, результат обращения к этому реквизиту через точку будет зависеть от выбора ключевого слова:

- `РАЗРЕШЕННЫЕ`
  
  — результатом запроса станет
  
  `Null`
  
  ;
- `ПОЛНОСТЬЮ`
  
  — исключение.

Например, справочник **События** имеет реквизит **Ответственный**, который ссылается на элемент справочника **Сотрудники** (имеет тип `Сотрудники.Ссылка`). В справочнике **Сотрудники** есть реквизит **ФИО**, который содержит фамилию, имя и отчество сотрудника. Тогда, обращаясь к полю **Ответственный**, вы можете через точку получить значение поля **ФИО** таблицы, на которую ссылается реквизит **Ответственный**:

```xbql
ВЫБРАТЬ
    События.Ссылка,
    События.Ответственный.ФИО
ИЗ
    События КАК События
```
