## Конструкторы

### ТипДанныхБазыДанных

`Доступность: Сервер`

```
ТипДанныхБазыДанных(
  Типы: ЧитаемоеМножество<Тип>,
  КвалификаторЧисла: КвалификаторЧисла? = Неопределено,
  КвалификаторСтроки: КвалификаторСтроки? = Неопределено,
  КвалификаторБайт: КвалификаторБайт? = Неопределено)
```

Создаёт описание типа данных. Множество типов не может быть пустым. Если в множестве типов есть

[Число](../../wiki/stdlib/number-ru-dd4b54993c86.md)

- параметр

`КвалификаторЧисла`

должен быть указан, при этом его значение не может равняться

`Неопределено`

. Если в множестве типов нет

[Число](../../wiki/stdlib/number-ru-dd4b54993c86.md)

- указание параметра

`КвалификаторЧисла`

не допускается. Если в множестве типов есть

[Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)

- параметр

`КвалификаторСтроки`

обязательно должен быть указан, при этом его значение не может равняться

`Неопределено`

. Если в множестве типов нет

[Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)

- указание параметра

`КвалификаторСтроки`

не допускается. Если в множестве типов есть

[Байты](../../wiki/stdlib/bytes-ru-19f4d37ce009.md)

- параметр

`КвалификаторБайт`

обязательно должен быть указан, при этом его значение не может равняться

`Неопределено`

. Если в множестве типов нет

[Байты](../../wiki/stdlib/bytes-ru-19f4d37ce009.md)

- указание параметра

`КвалификаторБайт`

не допускается.


[Байты](../../wiki/stdlib/bytes-ru-19f4d37ce009.md)

`ДлинаБайт`

. Длина 0 означает что длина не ограничена.
