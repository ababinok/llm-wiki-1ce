## Свойства

### Аутентификация

`Доступность: Сервер`

```
Аутентификация: АутентификацияПочты?
```

Данные аутентификации на сервере. `Неопределено`, если данные аутентификации не указаны.

---

### ИспользоватьSsl

`Доступность: Сервер`

```
ИспользоватьSsl: Булево
```

Использование защищенного соединение `SSL` (`TLS`) при работе с сервером.

---

### Порт

`Доступность: Сервер`

```
Порт: Число
```

Порт. При установке значения не в диапазоне (0, 65535) будет выброшено [ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md).

---

### РазрешитьStartTls

`Доступность: Сервер`

```
РазрешитьStartTls: Булево
```

Разрешает использование защищенного соединения `STARTTLS` при работе с сервером.

---

### Сервер

`Доступность: Сервер`

```
Сервер: Строка
```

Сервер. При установке пустого значения будет выброшено [ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md).

---

### ТаймаутПередачиДанных

`Доступность: Сервер`

```
ТаймаутПередачиДанных: Длительность
```

Время ожидания передачи данных при работе с почтовым сервером. При превышении данного времени выбрасывается исключение. При установке отрицательного значения будет выброшено [ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md).

---

### ТаймаутСоединения

`Доступность: Сервер`

```
ТаймаутСоединения: Длительность
```

Время ожидания соединения с сервером. При превышении данного времени выбрасывается исключение. При установке отрицательного значения будет выброшено [ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md).
