Элемент для хранения данных структуры.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Тип

```yaml
Тип: Тип[]
```

Тип поля структуры.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### ЗначениеПоУмолчанию

```yaml
ЗначениеПоУмолчанию: Объект
```

Значение поля по умолчанию.

---

#### Аннотации

```yaml
Аннотации: Аннотация[]
```

[Аннотации](../../wiki/language/annotations-dcff696b460d.md) поля структуры.

---

#### Обязательное

```yaml
Обязательное: Булево
```

Значение по умолчанию — `Ложь`. Если значение — `Истина`, то поле становится обязательным параметром конструктора, даже если имеет неявное значение инициализации.

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: Булево
```

Значение по умолчанию — `Ложь`. Если значение — `Истина`, то поле нельзя изменить после инициализации.

---
