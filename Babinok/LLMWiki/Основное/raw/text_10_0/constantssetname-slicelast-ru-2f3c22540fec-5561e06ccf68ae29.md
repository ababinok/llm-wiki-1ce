`Версия 9.0 и выше`

Виртуальная таблица, которая возвращает запись набора констант за определенный период. Таблица доступна при включенной периодичности.

**Параметры:**

- Период:
  
  [Дата](../../wiki/stdlib/date-ru-d160dc00114c.md)
  
  ?
  
  Граница, включая которую будет формироваться срез.
  
  Срез будет формироваться на основе записей, у которых значение поля
  
  Период
  
  меньше или равно указанному значению параметра. При наличии нескольких записей в результате будет использоваться запись с самым большим значением периода.
  
  Если значение параметра
  
  `Неопределено`
  
  , возвращается запись с максимальным значением поля
  
  `Период`
  
  на текущий момент.

---

## Примеры

В примере ниже показано, как выбрать константы из набора **ДанныеОрганизации**, актуальные на указанный **ПараметрПериод** (у которых значение поля **Период** меньше или равно переданному):

```xbql
ВЫБРАТЬ
    ДанныеОрганизации.ИмяОрганизации КАК ИмяОрганизации,
    ДанныеОрганизации.Адрес КАК Адрес
ИЗ
    ДанныеОрганизации.СрезПоследних(%ПараметрПериод) КАК ДанныеОрганизации
```

---

## Поля

### {ИмяКонстанты}

```
{ИмяКонстанты}: ТипКонстанты
```

Значение константы набора констант.

---

### Период

`Ключевое поле`

```
Период: Дата
```

Период, к которому относится запись набора констант.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяНабораКонстант.КлючЗаписи
```

Содержит значения констант набора констант и стандартного поля **Период**. Используется для указания на конкретную запись. Имеет тип `имя-набора-констант.КлючЗаписи`.

#### Примеры

В примере ниже показано, как выбрать данные конкретной записи из виртуальной таблицы **ДанныеОрганизации.СрезПоследних** на указанную дату `%ДатаСреза`:

```xbql
ВЫБРАТЬ
    Период,
    ИмяОрганизации,
    Адрес
ИЗ
    ДанныеОрганизации.СрезПоследних(%ДатаСреза)
```
