`Стд::Сущности::ГрупповаяОперация` `Доступность: Сервер`

Контекст групповой операции, выполняемой в особых условиях. Применяется при операциях массовой загрузки данных.

Групповая операция может устанавливать несколько особых "режимов":

- РежимЗагрузкиДанных - отключаются проверки логической целостности при записи объектов, отключаются обработчики событий в объектах
- ОтложенныйРасчетПрав - права доступа расчитываются не сразу при записи, а пакетно, по множеству объектов. Фактический расчет прав доступа запускается при закрытии контекста. Требует наличия также привилегированного режима и транзакцию.
- Транзакция - открыть транзакцию в начале операции, закрыть по завершении
- ПривилегированныйРежим - отключить контроль прав доступа на время операции

## Методы

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

Завершить групповую операцию в случае успеха. Фиксируются результаты операции:

- Если была начата транзакция - она фиксируется
- Если был начат режим отложенного расчета прав, запускается фактический расчет.

**Переопределение** [Закрываемое::Закрыть](../../wiki/stdlib/closeable-ru-67cd73fca69d.md)

### Начать

`Доступность: Сервер` `Статический`

```
@ИменованныеПараметры
Начать(
  РежимЗагрузкиДанных: Булево? = Неопределено,
  ОтложенныйРасчетДоступов: Булево? = Неопределено,
  Транзакция: Булево? = Неопределено,
  ПривилегированныйРежим: Булево? = Неопределено
): ГрупповаяОперация
```

>

Вызов возможен только с именованными параметрами

Если параметр имеет значение Истина, то режим будет открыт в рамках групповой операции. В случае, если параметр имеет значение Ложь - режим будет отключен в рамках операции. Если в рамках операции наличие/отсутствие режима не имеет значения, следует опустить параметр, или установить ему значение Неопределено.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если указаны несовместимые режимы, например, отложенный расчет вне транзакции и привилегированного режима

#### Примеры

```xbsl
исп Операция = ГрупповаяОперация.Начать(ОтложенныйРасчетДоступов = Истина, Транзакция = Истина, ПривилегированныйРежим = Истина)
// Некоторый набор действий в рамках групповой операции
Операция.Закрыть() 
```

Некоторые режимы нельзя отменить, если они уже начались выше по стеку вызовов. Например, нельзя временно отключить уже начатую транзакцию или отложенный расчет прав, указав соответствующий параметр равным Ложь.

Например:

- Выше по стеку начата транзакция, а групповая операция создается с флагом Транзакция = Ложь
- Выше по стеку открыт привилегированный контекст доступа, а групповая операция создается с флагом ПривилегированныйРежим = Ложь
- Выше по стеку открыт режим отложенного расчета прав доступа, а групповая операция создается с флагом ОтложенныйРасчетПрав = Ложь

Существует возможность переопределить созданный выше по стеку режим загрузки данных. Если какой-то объект/набор объектов нужно записать без режима загрузки, то допускается создание групповой операции с флагом РежимЗагрузкиДанных = Ложь. Это позволит переопределить выставленный выше по стеку режим загрузки данных на время действия текущей групповой операции.

### Откатить

`Доступность: Сервер`

```
Откатить()
```

Отмена результатов операции. Метод применяется при отрицательном результате групповой операции:

- Если была начата транзакция - она откатывается
- Если был начат режим отложенного расчета прав - он отменяется, права остаются неизменными
