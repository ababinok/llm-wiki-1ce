Пакет — это часть подсистемы. Подсистема может содержать один или несколько пакетов. Пакет может содержать элементы проекта, ресурсы и другие пакеты. Возможность разделения подсистемы на пакеты существует исключительно для удобства разработки приложения ([подробнее](../../wiki/language/modular-development-80166cfecf93.md)).
