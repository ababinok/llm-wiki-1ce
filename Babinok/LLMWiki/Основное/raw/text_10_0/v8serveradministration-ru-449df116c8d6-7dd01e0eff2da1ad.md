## Конструкторы

### АдминистрированиеСервераV8

`Доступность: Сервер`

```
АдминистрированиеСервераV8(
  АдресАгента: Строка,
  Порт: Число,
  ТаймаутСоединения: Длительность = 2с)
```

Создает объект администрирования сервера. Требуется наличие запущенного сервера администрирования (ras).

`АдресАгента`

- имя (символический или IP-адрес) компьютера, на котором расположен сервис ras.

`Порт`

- порт, на котором расположен сервис ras.

`ТаймаутСоединения`

- таймаут соединения.

## Методы

### ВыполнитьАутентификацию

`Доступность: Сервер`

```
ВыполнитьАутентификацию(
  ИмяПользователя: Строка = "",
  Пароль: Секрет|Строка = "")
```

Выполняет аутентификацию администратора центрального сервера

`ИмяПользователя`

с паролем

`Пароль`

в агенте администрирования сервера.

---

### ПолучитьАдминистраторов

`Доступность: Сервер`

```
ПолучитьАдминистраторов(): ЧитаемыйМассив<АдминистраторV8>
```

Возвращает массив администраторов центрального сервера. Для успешного выполнения метода необходима аутентификация одного из администраторов центрального сервера.

---

### ПолучитьКластер

`Доступность: Сервер`

```
ПолучитьКластер(Ид: Ууид): КластерV8
```

Возвращает кластер по идентификатору

`Ид`

.

---

### ПолучитьКластеры

`Доступность: Сервер`

```
ПолучитьКластеры(): ЧитаемыйМассив<КластерV8>
```

Возвращает список кластеров, зарегистрированных в центральном сервере.

---

### СоздатьАдминистратора

`Доступность: Сервер`

```
СоздатьАдминистратора(): АдминистраторV8
```

Возвращает нового администратора кластера с пустыми значениями свойств. Этот объект может быть использован для регистрации нового администратора после установки требуемых значений свойств.

---

### СоздатьКластер

`Доступность: Сервер`

```
СоздатьКластер(): КластерV8
```

Возвращает новый кластер с пустыми значениями свойств. Новый кластер может быть использован, например, для регистрации кластера. Для этого требуется явно задать необходимые значения его свойств.
