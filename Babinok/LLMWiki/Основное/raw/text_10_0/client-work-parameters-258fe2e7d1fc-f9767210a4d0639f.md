Вы можете получать необходимые для работы клиента параметры (например, текущего пользователя, его права и роли, настройки приложения и т. д.) при открытии приложения. Для этого используйте элемент проекта вида **Параметры работы клиента**.

Данный элемент проекта позволяет описать произвольный набор свойств — **параметров**. Эти свойства инициализируются на сервере при открытии приложения пользователем. Для каждого параметра указываются его **имя** и **тип**. Допускаются только типы, которые можно передавать с сервера на клиент.

Для элемента проекта автоматически генерируется модуль, содержащий обработчик [`ВычислитьПараметрыРаботыКлиента()`](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md), в котором на сервере выполняется вычисление значений параметров. При открытии приложения «1С:Предприятие.Элемент» вызывает все определенные в проекте обработчики и передает их параметры на клиент одним серверным вызовом. Вы можете получить значения параметров на клиенте с помощью одноименных свойств объектов [`{ИмяПараметровРаботыКлиента}`](../../wiki/project/client-work-parameters-258fe2e7d1fc.md), которые генерируются для каждого элемента проекта вида **Параметры работы клиента**.

## Типы, порождаемые элементом проекта вида «Параметры работы клиента»

После того как вы добавили в проект параметры работы клиента, «1С:Предприятие.Элемент» создаст следующие типы:

- [`{ИмяПараметровРаботыКлиента}`](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md)
  
  ,
- [`{ИмяПараметровРаботыКлиента}.Параметры`](../../wiki/stdlib/clientworkparametersname-parameters-ru-5d5afa6451b2.md)
  
  .

### Тип «ИмяПараметровРаботыКлиента»

Тип-одиночка для работы с параметрами работы клиента. Для каждого описанного в элементе проекта параметра генерируется одноименное свойство у этого объекта, которое позволяет получить доступ к значению параметра, заполненному в обработчике [`ВычислитьПараметрыРаботыКлиента()`](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md).

Если при выполнении обработчика происходит исключение, то при обращении к параметрам на клиенте выполняется попытка вычислить их еще раз, и если она также оказывается неудачной, выбрасывается [`ИсключениеПараметрыРаботыКлиентаНеИнициализированы`](../../wiki/interface/clientworkparametersnotinitializedexception-ru-852da47af9f8.md).

### Тип «ИмяПараметровРаботыКлиента.Параметры»

Служебный тип для заполнения значений параметров работы клиента в обработчике [`ВычислитьПараметрыРаботыКлиента()`](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md). Используется как возвращаемое значение данного обработчика.

## Пример

Рассмотрим настройку параметров работы клиента на простом примере.

1. Создайте новый элемент проекта вида **Параметры работы клиента** с именем **ПараметрыАдаптацииСотрудника**.
  
  В окне добавления элемента проекта выбран вид «Параметр работы клиента» для создания «ПараметрыАдаптацииСотрудника». [Описание иллюстрации](../figures/536d11b3b9f35bcec5671af7423d553ad812d45d3453fbb5d6aceb9e78cc742d-54000b5f603003b4.md)
2. Добавьте следующие параметры:
  
  - ЭтоНовыйСотрудник
    
    типа
    
    `Булево`
    
    ,
  - ПоказатьОзнакомительныйРаздел
    
    типа
    
    `Булево`
    
    ,
  - Уровень
    
    типа
    
    `Строка`
    
    .
  
  В дереве элемента «ПараметрыАдаптацииСотрудника» показаны параметры ЭтоНовыйСотрудник, ПоказатьОзнакомительныйРаздел и Уровень. [Описание иллюстрации](../figures/49959c2500003f86de40a5b065e2d9de4fff03abca24b7667d6251189398eb8b-25a34a99e0d66509.md)
  
  <details>
  <summary>Пример YAML-файла</summary>
  
  ```yaml
  ВидЭлемента: ПараметрыРаботыКлиента
  ОбластьВидимости: ВПодсистеме
  Ид: 301190f1-6aa3-4ba6-8852-7a6e188e251f
  Имя: ПараметрыАдаптацииСотрудника
  Параметры:
      -
          Имя: ЭтоНовыйСотрудник
          Тип: Булево
      -
          Имя: ПоказатьОзнакомительныйРаздел
          Тип: Булево
      -
          Имя: Уровень
          Тип: Строка
  ```
  
  </details>
3. Откройте модуль элемента проекта и заполните значения параметров в обработчике [`ВычислитьПараметрыРаботыКлиента()`](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md):
  
  ```xbsl
  @Обработчик
  @НаСервере
  статический метод ВычислитьПараметрыРаботыКлиента(): ПараметрыАдаптацииСотрудника.Параметры
  
      возврат новый ПараметрыАдаптацииСотрудника.Параметры(
          ЭтоНовыйСотрудник = Истина,
          ПоказатьОзнакомительныйРаздел = Истина,
          Уровень = "Начальный") 
  ;
  ```
4. Значения параметров доступны на клиенте как значения одноименных свойств объекта `ПараметрыАдаптацииСотрудника`, например: `ПараметрыАдаптацииСотрудника.ЭтоНовыйСотрудник`.
