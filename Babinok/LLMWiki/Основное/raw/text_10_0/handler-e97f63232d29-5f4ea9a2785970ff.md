Обработчик — это метод, вызываемый «1С:Предприятие.Элементом» при наступлении определенного события.

В «1С:Предприятие.Элементе» существуют обработчики с заранее зафиксированной сигнатурой и функциональностью, логику которых можно переопределить. Такие обработчики называются переопределяемыми. К ним относятся:

- Справочник.Объект
  
  - `ПриЗаполнении`
  - `ПередЗаписью`
  - `ПослеЗаписи`
  - `ПередУдалением`
  - `ПослеУдаления`
- Справочник
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьРазрешенияДоступаДляОбъектов`
- Документ.Объект
  
  - `ПриЗаполнении`
  - `ПередЗаписью`
  - `ПослеЗаписи`
  - `ПередУдалением`
  - `ПослеУдаления`
- Документ
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьРазрешенияДоступаДляОбъектов`
- Пользователи.Объект
  
  - `ПослеПодключения`
  - `ПослеОтключения`
  - `ПослеИзменения`
- ПланОбмена.Объект
  
  - `ПриЗаполнении`
  - `ПередЗаписью`
  - `ПослеЗаписи`
  - `ПередУдалением`
  - `ПослеУдаления`
- ПланОбмена
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьРазрешенияДоступаДляОбъектов`
- РегистрСведений.Запись
  
  - `ПриЗаполнении`
  - `ПриСозданииКопии`
- РегистрСведений.НаборЗаписей
  
  - `ПередЗаписью`
  - `ПослеЗаписи`
- РегистрСведений
  
  (если задано свойство
  
  Периодичность
  
  )
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьКлючиДоступаДляЧтения`
  - `ВычислитьКлючиДоступаДляИзменения`
- РегистрСведений
  
  (если не задано свойство
  
  Периодичность
  
  )
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьРазрешенияДоступаДляОбъектов`
- РегистрНакопления.Запись
  
  - `ПриСозданииКопии`
- РегистрНакопления.НаборЗаписей
  
  - `ПередЗаписью`
  - `ПослеЗаписи`
- РегистрНакопления
  
  - `ВычислитьРазрешенияДоступа`
  - `ВычислитьКлючиДоступаДляЧтения`
  - `ВычислитьКлючиДоступаДляИзменения`
- ПравоНаДействие
  
  - `ВычислитьРазрешенияДоступа`
- КлючДоступа
  
  - `ПроверитьНаличиеКлючейДоступа`
- HttpСервис
  
  - `ВычислитьРазрешенияДоступа`

Такие обработчики следует в обязательном порядке помечать аннотацией `@Обработчик`.
