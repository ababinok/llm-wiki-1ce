Типы для работы с объектным хранилищем и двоичными объектами.

# Типы

## [ДвоичныйОбъект](../../wiki/data/binaryobject-ru-a65f10db6bb3.md)

`Стд::ОбъектноеХранилище::ДвоичныйОбъект` `Доступность: Сервер`

Содержит описание двоичного объекта, содержимое которого, потенциально очень большого размера, хранится в специальном хранилище.

---

## [ДвоичныйОбъект.HttpСсылка](../../wiki/integration/binaryobject-httplink-ru-18e973b76106.md)

`Стд::ОбъектноеХранилище::ДвоичныйОбъект.HttpСсылка` `Доступность: КлиентИСервер`

Http ссылка на двоичный объект. Позволяет сформировать ссылку на объект в виде строки для загрузки объект из хранилища по протоколу HTTP. Ссылка поддерживает запросы типа GET и HEAD. Возвращает заголовки:

- `Content-Disposition`
  
  - содержит имя файла
- `Content-Length`
  
  - размер объекта в байтах
- `Content-Type`
  
  - MIME тип объекта
- `Content-Digest`
  
  - SHA-256 хеш объекта
- `Accept-Ranges: bytes`
  
  - доступно получение части объекта по ссылке через стандартный заголовок Range. Поддерживается возврат только одного диапазона, если в заголовке Range указано несколько диапазонов, сервер вернёт ошибку 416 Range Not Satisfiable.

---

## [ДвоичныйОбъект.Свойства](../../wiki/data/binaryobject-properties-ru-067a15015302.md)

`Стд::ОбъектноеХранилище::ДвоичныйОбъект.Свойства` `Доступность: Сервер`

Представляет описание прикладных свойств и требований к объектному хранилищу, в которое будет помещен двоичный объект. На основе значений свойств администратор настраивает как объекты должны распределяться системой по различным хранилищам.

---

## [ДвоичныйОбъект.СоставнаяЗагрузка](../../wiki/data/binaryobject-multipartupload-ru-a9a5fb4dd627.md)

`Стд::ОбъектноеХранилище::ДвоичныйОбъект.СоставнаяЗагрузка` `Доступность: Сервер`

Объект управления загрузкой по частям. Позволяет восстанавливать начатую загрузку, начинать новую, завершать или прерывать процесс загрузки, а также генерировать подписанные ссылки для прямой загрузки частей файла в хранилище через сторонние приложения.
