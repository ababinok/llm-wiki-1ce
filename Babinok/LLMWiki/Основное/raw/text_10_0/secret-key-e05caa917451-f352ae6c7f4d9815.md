Закрытый ключ — это секретный криптографический ключ, который используется для расшифрования данных, зашифрованных открытым ключом, и создания цифровой подписи. Он хранится в секрете и не передается.

Один из удобных и безопасных способов хранить закрытый ключ — это файл `.pfx` (аналогичный формату `.p12`). Этот формат основан на стандарте PKCS#12. Файл защищен стойким паролем, содержит открытый ключ, закрытый ключ и сертификат.
