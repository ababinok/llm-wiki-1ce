## Методы

### ЗаписатьПоКлючам

`Доступность: Сервер`

```
ЗаписатьПоКлючам(
  КлючОбъекта: Строка,
  КлючНастройки: Строка,
  Значение: Строка)
```

Метод записи настройки для текущего пользователя по ключам. Ищутся и записываются только уникальные настройки (Вариант = Ложь). Если по указанным ключам запись не будет найдена, метод создает новую настройку с указанными ключами и значением. Для новой настройки остальные реквизиты будут установлены в значения по умолчанию.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../../wiki/stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на запись объекта.

**Перегрузка** [ЗаписатьПоКлючам(КлючОбъекта: Строка, КлючНастройки: Строка, Значение: Строка, Наименование: Строка, Общая: Булево, ПараметрыЗаписи: СтандартноеХранилищеНастроек.ПараметрыЗаписи? = Неопределено)](../../wiki/data/standardsettingsstorage-ru-45df1deaf228.md)

Метод поиска объекта хранилища настройки для текущего пользователя по ключам. Ищутся только уникальные настройки (у которых Вариант = Ложь).

### ПересчитатьРазрешенияДоступаДляОбъектов

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<СтандартноеХранилищеНастроек.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

**Перегрузка** [ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<СтандартноеХранилищеНастроек.Ссылка>)](../../wiki/data/standardsettingsstorage-ru-45df1deaf228.md) [ПересчитатьРазрешенияДоступаДляОбъектов(Общая: Булево, Пользователь: Пользователи.Ссылка?)](../../wiki/data/standardsettingsstorage-ru-45df1deaf228.md)

### СоздатьФормуОбъекта

`Доступность: Клиент`

```
@ИменованныеПараметры
СоздатьФормуОбъекта(КлючИсточникаКопирования: СтандартноеХранилищеНастроек.Ссылка): ФормаОбъекта<СтандартноеХранилищеНастроек.Объект, неизвестно>
```

>

Вызов возможен только с именованными параметрами

Создает форму объекта хранилища настроек. Для стандартного хранилища будет создана автоматическая форма

Параметр `КлючИсточникаКопирования` определяет, какой объект будет использоваться в качестве источника создания копированием. При этому будет открыта форма нового объекта, являющегося копией того, который был указан в качестве источника.

**Перегрузка** [СоздатьФормуОбъекта(Ключ: СтандартноеХранилищеНастроек.Ссылка? = Неопределено): ФормаОбъекта<СтандартноеХранилищеНастроек.Объект, неизвестно>](../../wiki/data/standardsettingsstorage-ru-45df1deaf228.md)
