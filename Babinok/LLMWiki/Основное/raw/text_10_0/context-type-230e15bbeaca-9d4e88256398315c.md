Тип [`Контекст`](../../wiki/stdlib/context-ru-aa03c6bdd5aa.md) реализует тип [`Закрываемое`](../../wiki/stdlib/closeable-ru-67cd73fca69d.md) и является базовым типом объектов, неявно меняющих поведение системы. Тип `Контекст` обязательно должен использоваться в `исп`-выражении или `исп`-переменной при возврате из метода или создании конструктором. Таким образом, областью действия контекста является область видимости.

## Примеры

Пример работы с типом «ТранзакцияSql»

```xbsl
метод ЗаписатьТовары(Соединение: СоединениеSql)
    исп Соединение.НачатьТранзакцию() // ТранзакцияSql
    //...
;
```

Пример работы с типом «КонтекстДоступа» и регистром сведений

```xbsl
@ВПроекте
метод Заполнено(): Булево
    исп КонтекстДоступа.Дополнить(Тип<ПараметрыПодключения.Запись>, [Сущность.Право.Чтение])
    возврат не Запрос{
        ВЫБРАТЬ ПЕРВЫЕ 1
            Истина КАК ЕстьЗаписи
        ИЗ ПараметрыПодключения
    }.Выполнить().Пусто()
;
```

Пример работы с типом «КонтекстДоступа» и справочником «Валюты»

```xbsl
@ВПодсистеме
метод ЗагрузитьКурсыВалют(ВалютаСсылка: Валюты.Ссылка, НачалоПериода: Дата, КонецПериода: Дата)
    знч Валюта = ВалютаСсылка.ЗагрузитьОбъект()
    
    // Получение идентификатора валюты во внешнем справочнике ...

        если не Валюта.ВнешнийИдентификатор.Пусто()
            исп КонтекстДоступа.Дополнить(Тип<Валюты.Объект>, [Сущность.Право.Изменение])
            Валюта.Записать()
        иначе
            выбросить новый ИсключениеЗагрузкиКурсовВалют(
                "Во внешнем справочнике не удалось найти валюту с кодом %{Валюта.Код}", ВалютаСсылка)
        ;

    // Дальнейшая загрузка и запись курсов валюты ...

;
```
