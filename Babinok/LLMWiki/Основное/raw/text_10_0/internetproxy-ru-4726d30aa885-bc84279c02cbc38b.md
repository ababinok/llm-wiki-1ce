## Конструкторы

### ИнтернетПрокси

`Доступность: Сервер`

```
ИнтернетПрокси(
  Сервер: Строка,
  Порт: Число)
```

Создает прокси по указанному имени сервера

`Сервер`

и порту

`Порт`

.

**Перегрузка** [ИнтернетПрокси(Сервер: Строка, Порт: Число, Аутентификация: АутентификацияHttp)](../../wiki/integration/internetproxy-ru-4726d30aa885.md)

---

### ИнтернетПрокси

`Доступность: Сервер`

```
ИнтернетПрокси(
  Сервер: Строка,
  Порт: Число,
  Аутентификация: АутентификацияHttp)
```

Создает прокси по указанному имени сервера

`Сервер`

, порту

`Порт`

с данными аутентификации

`Аутентификация`

.

**Перегрузка** [ИнтернетПрокси(Сервер: Строка, Порт: Число)](../../wiki/integration/internetproxy-ru-4726d30aa885.md)

## Методы

### ПолучитьАутентификацию

`Доступность: Сервер`

```
ПолучитьАутентификацию(Протокол: Строка): АутентификацияHttp?
```

Возвращает данные аутентификации прокси-сервера для протокола

`Протокол`

.

---

### ПолучитьПорт

`Доступность: Сервер`

```
ПолучитьПорт(Протокол: Строка): Число
```

Возвращает порт прокси-сервера для протокола

`Протокол`

.

---

### ПолучитьСервер

`Доступность: Сервер`

```
ПолучитьСервер(Протокол: Строка): Строка
```

Возвращает имя прокси-сервера или его IP-адрес для протокола

`Протокол`

.
