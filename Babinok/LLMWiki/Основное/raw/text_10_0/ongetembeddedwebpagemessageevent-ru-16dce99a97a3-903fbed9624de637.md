## Свойства

### Сообщение

`Доступность: Клиент` `ТолькоЧтение`

```
Сообщение: СообщениеВстроеннойВебСтраницы?
```

Содержит данные сообщения от встроенной веб-страницы. Страница не всегда может поддерживать формат сообщения, принятый для коммуникации приложений 1С:Предприятие. Если сообщение от встроенной веб-страница имеем свой формат, например приходит в виде обычного текста, данное свойство остается незаполненным.
