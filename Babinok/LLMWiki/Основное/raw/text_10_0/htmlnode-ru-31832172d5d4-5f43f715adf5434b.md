## Свойства

### ДиапазонВКоде

`Доступность: Сервер` `ТолькоЧтение`

```
ДиапазонВКоде: ДиапазонВТексте?
```

Возвращает диапазон начала блока или `Неопределено` - узел еще не размещен в дереве на момент разбора.

> Диапазон для узла не меняется при нормализации, а также при модификации документа (напр вставка узлов до данного). Данный диапазон соответствует индексам в исходном html, который был разобран. Чтобы узнать новое положение, можно, например, вызвать на документе внешний html и подать снова на вход парсеру.

#### Примеры

```xbsl
метод ДиапазонВКоде(Документ: ДокументHtml)
    /*
    Для кода:
    <html xmlns="http://www.w3.org/1999/xhtml" xmlns:svg="http://www.w3.org/2000/svg">
    <head>
    </head>
    <body onload="test()">
      <svg version="1.1"
        width="100px" height="100px"
        viewBox="0 0 100 100">
        <circle cx="50" cy="50" r="30" style="fill:#aaa" id="circle"/>
      </svg>
      <textarea id="text" rows="4" cols="55"/>
    </body>
    </html>
    */
    
    Документ.Тело.ДиапазонВКоде.ВСтроку() // - 4:1 - 11:8:(98-328)
;
```

### ДокументВладелец

`Доступность: Сервер` `ТолькоЧтение`

```
ДокументВладелец: ДокументHtml?
```

Документ, в котором находится узел. Если узел удален или не расположен в документе, то значение `Неопределено`

#### Примеры

```xbsl
метод ДокументВладелец(Документ: ДокументHtml)
    /*
    Для кода:
    <html>
        <div id="first">
            <div id="second">
                <p>Some text</p>
            </div>
        </div>
    </html>
    */
    знч ВложенныйDiv = Документ.ПолучитьИзПоддереваЭлементыПоАтрибуту("div", "id", "second")[0]
    знч ВладелецЛиДокумент = ВложенныйDiv.ДокументВладелец == Документ // Истина
    знч Родитель = ВложенныйDiv.Родитель
    
    если Родитель != Неопределено
        знч Ид = (Родитель как ЭлементHtml).Ид // Будет равен "first"
    ;

    ВложенныйDiv.Удалить()
    знч НеопределенЛиДокументВладелей = ВложенныйDiv.ДокументВладелец == Неопределено // Истина
    знч НеопределенЛиРодитель = ВложенныйDiv.Родитель  == Неопределено // Истина
;
```

### ПредыдущийСосед

`Доступность: Сервер` `ТолькоЧтение`

```
ПредыдущийСосед: УзелHtml?
```

Непосредственно предыдущий узел (узел который лежит на том же уровне до текущего). `Неопределено`, если у узла нет соседа или узел не размещен в дереве/удален

#### Примеры

```xbsl
метод НепосредственноПредыдущийУзел(Документ: ДокументHtml)
    /* Пример части кода:
    <label for="1">Russian</label>
    <input type="radio" id="1" name="fav_language" value="Russian">
    */
    // Для пользовательского ввода данных радио кнопок задать class = Radio, а их лейблам class = Label
    
    пер РадиоКнопки = Документ.ПолучитьИзПоддереваЭлементыПоАтрибуту("input", "type", "radio")
    РадиоКнопки.ДобавитьКласс("Radio")
    
    для Кнопка из РадиоКнопки
        пер УзелЛейбл = РадиоКнопки.ПолучитьПредыдущихПрямыхСоседей().ЕдинственныйИлиНеопределено()
        если УзелЛейбл != Неопределено и УзелЛейбл это ЭлементHtml
            пер Лейбл = УзелЛейбл как ЭлементHtml
            Лейбл.Атрибуты.Вставить("class", "Label")
        ;
    ;
    
    /* Пример части результата:
    <label for="1" class="Label">Russian</label>
    <input type="radio" id="1" name="fav_language" value="Russian" class="Radio">
    */
;
```

## Методы

### ВнешнийКод

`Доступность: Сервер`

```
ВнешнийКод(НастройкиЗаписи: НастройкиЗаписиHtml? = Неопределено): Строка
```

Получить внешний код (Html) для данного узла. Если настройки не указаны, то будут использованы настройки, созданные по умолчанию.

#### Примеры

```xbsl
метод ПолучитьВнешнийКодДляДанногоУзла(Документ: ДокументHtml)
    /*
    Для кода:
    <html>
        <div id="first">
            <div id="second">
                <p>Some text</p>
            </div>
        </div>
    </html>
    */
    
    пер ВложенныйDiv = Документ.ПолучитьИзПоддереваЭлементыПоАтрибуту("div", "id", "second")[0]
    пер Настройки = новый НастройкиЗаписиHtml()
    Настройки.РазмерОтступов = 1
    Настройки.УлучшениеВывода = Истина
    пер Код = ВложенныйDiv.ВнешнийКод(Настройки)
    /*
    Код будет равен:
    <div id="second">
     <p>Some text</p>
    </div>
    */ 
;
```

### ВставитьКопииУзловДоТекущего

`Доступность: Сервер`

```
ВставитьКопииУзловДоТекущего(Узлы: УзелHtml|Обходимое<УзелHtml>)
```

Клонирует переданные узлы и вставляет перед данным узлом (то есть как предыдущ(его/их) соседа). Если узел является терминальным (например ТекстовыйУзел), то при вызове метода произойдет конкатенация содержимых. Применим, если текущий узел имеет родителя. Например, не применим для

`ДокументHtml`

.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если текущий узел не имеет родителя.

#### Примеры

```xbsl
метод ВставитьКопииУзловДоТекущего(Контейнер: УзелHtml)
    /*
    Для элемента контейнера с кодом: <div data-package="myPackage" data-language="xbsl" class="group">
    Нужно добавить комментарий выше с текстом: "Исходный код примера работы"
    */
    Контейнер.ВставитьКопииУзловДоТекущего(новый УзелКомментарийHtml("Исходный код примера работы"))
    /*
    Результат:
    <!--Исходный код примера работы-->
    <div data-package="myPackage" data-language="xbsl" class="group">
    */
;
```

### ВставитьКопииУзловПослеТекущего

`Доступность: Сервер`

```
ВставитьКопииУзловПослеТекущего(Узлы: УзелHtml|Обходимое<УзелHtml>)
```

Клонирует переданные узлы и вставляет после данного узла (то есть как следующ(его/их) соседа). Если узел является терминальным (например ТекстовыйУзел), то при вызове метода произойдет конкатенация содержимых. Применим, если текущий узел имеет родителя. Например, не применим для

`ДокументHtml`

.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если текущий узел не имеет родителя.

#### Примеры

```xbsl
метод ВставитьКопииУзловПослеТекущего(ТекущийУзел: УзелHtml)
    /*
    Добавить в текст параграфа два переноса строки.
    Код:
    <p>Текст параграфа</p>
    */
    пер ПереносСтроки = новый ЭлементHtml("br") 
    ТекущийУзел.ВставитьКопииУзловПослеТекущего([ПереносСтроки, ПереносСтроки])
    /*
    Код:
    <p>Текст параграфа<br><br></p>
    */
;
```

```xbsl
метод ВставитьКопииУзловПослеТекущего(ТекущийУзел: УзелHtml)
    если (ТекущийУзел как ЭлементHtml).СобственныйТекст == "Первая часть текста"
        ТекущийУзел.ВставитьКопииУзловПослеТекущего(новый ТекстовыйУзелHtml(", а это вторая часть текста"))
    ;
    
    // Тогда: ТекущийУзел.Текст - "Первая часть текста, а это вторая часть текста"
;
```

### ОбойтиВГлубину

`Доступность: Сервер`

```
ОбойтиВГлубину(
  ПриВходеВУзел: (УзелHtml, Число)->РезультатШагаОбхода,
  ПриВыходеИзУзла: ((УзелHtml, Число)->РезультатШагаОбхода)? = Неопределено)
```

Выполняет DFS на узлах на основании фильтров. Аргументы нужны для регулирования направления обхода, при входе в узел во время обхода будет вызван ПриВходеВУзел, при выходе - ПриВыходеИзУзла Число соответствует глубине прохода.

#### Примеры

```xbsl
метод ОбойтиВГлубину(Документ: ДокументHtml)
    // Обойдем все дерево, удалим атрибут "style" у таблиц и установим на строки.
    Документ.ОбойтиВГлубину(метод(Узел: УзелHtml, Глубина: Число)->
        если Узел это ЭлементHtml
            пер Элемент = Узел как ЭлементHtml
            если Элемент.Имя == "table" и Элемент.Атрибуты.ЕстьЗначение("style")
                Элемент.Атрибуты.Удалить("style")
                Элемент
                    .ПолучитьДочерниеЭлементы(Ложь, ДочернийЭлемент -> ДочернийЭлемент.Имя == "tr")
                    .УстановитьАтрибут("style", "background-color:#00FF00")
            ;
        ;
        возврат РезультатШагаОбхода.ПродолжитьОбход
    ;)
;
```
