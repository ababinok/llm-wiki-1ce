## [ВсплывающийКомпонент](../../wiki/interface/popupcomponent-ru-260aa5761385.md)

`Стд::Интерфейс::ОбщиеКомпоненты::ВсплывающийКомпонент<ТипРезультата>` `Доступность: Клиент`

ТипРезультата: Тип возвращаемого значения при открытии во всплывающем окне. По умолчанию - `Неопределено`. Если пользователь закрыл компонент кликом мимо или был вызван метод [Закрыть](../../wiki/interface/popupcomponent-ru-260aa5761385.md) без передачи аргумента, в качестве результата открытия возвращается `Неопределено`.

Представляет собой всплывающее окно с заданным содержимым.

---

## [ВыборДатыВремени](../../wiki/interface/datetimechoice-ru-4d2b8197edef.md)

`Стд::Интерфейс::ОбщиеКомпоненты::ВыборДатыВремени` `Доступность: Клиент`

Компонент ввода даты и времени. Отображается как календарь и(или) выбор времени. Компонент не меняет компоненты даты, которые не входят в редактируемый тип. Например, при редактировании значения типа [Время](../../wiki/stdlib/time-ru-bbaed59a0dcd.md) не меняются компоненты даты, в режиме даты не меняется время. При отключенных секундах они также остаются теми, которыми были до момента редактирования.

---

## [ВыборЗначения](../../wiki/interface/valuechoice-ru-b6140ef5eb57.md)

`Стд::Интерфейс::ОбщиеКомпоненты::ВыборЗначения<ТипДанных>` `Доступность: Клиент`

ТипДанных: тип значения компонента выбора значений. Если это [Массив](../../wiki/stdlib/array-ru-f0659b9628e1.md), компонент будет принимать вид группы флажков, иначе - группы радиокнопок или сегментов. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент, позволяющий выбрать один или несколько вариантов из заданного списка.

## [Картинка](../../wiki/interface/picture-ru-efed61d49ad9.md)

`Стд::Интерфейс::ОбщиеКомпоненты::Картинка` `Доступность: Клиент`

Компонент, позволяющий отображать картинки разных форматов, в том числе SVG. Чтобы цвет SVG-картинки был изменяемым, она должна содержать элементы, использующие в качестве цвета значение "currentColor". К этим элементам и будет применен цвет, задаваемый через свойства [ОценкаИнформации](../../wiki/interface/picture-ru-efed61d49ad9.md) и [Цвет](../../wiki/interface/picture-ru-efed61d49ad9.md).

ТипДанных: тип значения компонента **ПанельТегов**.

Компонент **ПанельТегов** отображает указанные данные в виде области с тегами, которые расположены по всей ширине. Отдельные теги содержат текст и картинку с возможностью обработки нажатия. Область с тегами может быть свернута по высоте до одной строки или развернута на всю высоту.

## [РадиоКнопка](../../wiki/interface/radiobutton-ru-a7fb4187dadf.md)

`Стд::Интерфейс::ОбщиеКомпоненты::РадиоКнопка<ТипДанных>` `Доступность: Клиент`

ТипДанных: Тип значения радиокнопки. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент предназначен для реализации сценария выбора из двух и более различных значений. Каждый компонент радиокнопки представляет отдельный пункт выбора. Для обеспечения множественности значений необходимо использовать два или более компонента радиокнопки, у которых значения свойства [ЗначениеВыбора](../../wiki/interface/radiobutton-ru-a7fb4187dadf.md) различны, а свойство [Значение](../../wiki/interface/radiobutton-ru-a7fb4187dadf.md) привязано к одним и тем же данным. Для того чтобы объединить несколько радиокнопок в одну группу выбора, необходимо указать каждой радиокнопке такой группы одинаковое значение свойства [РадиоГруппа](../../wiki/interface/radiobutton-ru-a7fb4187dadf.md).

## [СворачиваемыйКомпонент](../../wiki/interface/collapsiblecomponent-ru-ee7207d806e8.md)

`Стд::Интерфейс::ОбщиеКомпоненты::СворачиваемыйКомпонент` `Доступность: Клиент`

Представляет собой компонент, позволяющий скрывать (сворачивать) и показывать (разворачивать) свое содержимое. Сворачивание и разворачивание осуществляется нажатием на заголовок компонента, который включает в себя:

- Кнопку сворачивания (обязательная)
- Заголовок (обязательный)
- Второстепенный заголовок (необязательный)
- Кнопка действия (необязательная)
- Содержимое (обязательное)
