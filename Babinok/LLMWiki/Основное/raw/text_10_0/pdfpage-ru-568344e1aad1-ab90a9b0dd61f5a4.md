## Методы

### ДобавитьИзображение

`Доступность: Сервер`

```
ДобавитьИзображение(
  Поток: ПотокЧтения,
  Область: ПрямоугольнаяОбласть)
```

Добавить на страницу изображение, полученное из потока Поток в прямоугольную область

`Область`

.

Поддерживаемые форматы изображения: JPEG, TIFF, GIF, BMP, PNG. Все параметры прямоугольной области указываются в миллиметрах.

Изображение будет вставлено поверх любого другого объекта. В случае, если ширина и высота в соотношении друг с другом не соответствуют параметрам изображения, то оно записывается по координате(`x = Область.X, y = Область.Y`), с сохранением отношения сторон. Размеры изображения, как максимально возможные, определяются автоматически, но так, чтобы она целиком уместилась в `Область`. Если изображение не умещается на страницу в указанных координатах, то оно будет обрезано.

#### Исключения

**[ИсключениеВводаВывода](../../wiki/stdlib/inputoutputexception-ru-ceba5f672999.md)** - если чтение изображения завершилось неудачей. **[ИсключениеPdf](../../wiki/stdlib/pdfexception-ru-fca07efa7071.md)** - ошибка при вставке изображения на страницу документа. **[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт или страница удалена из него.

#### Примеры

```xbsl
метод ДобавитьСтраницуСИзображением(Документ: ДокументPdf, Поток: ПотокЧтения)
    пер Страница = Документ.ДобавитьСтраницу()
    Страница.ДобавитьИзображение(Поток, новый ПрямоугольнаяОбласть(0, 0, 100, 100))
;
```

### КонвертироватьВИзображение

`Доступность: Сервер`

```
КонвертироватьВИзображение(
  Поток: ПотокЗаписи,
  Формат: ФорматИзображения,
  Dpi: Число = 200)
```

Преобразовать страницу документа в изображение (в формате

`Формат`

и качеством

`Dpi`

) и записать в поток

`Поток`

.

Поддерживаемые форматы изображения: JPEG, TIFF, GIF, BMP, PNG. По умолчанию, изображение сохраняется с качеством dpi = 200.

Если в страницу документа не были встроены шрифты, то они будут заменены на шрифт по умолчанию в операционной системе.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - неподдерживаемый формат изображения или число `dpi` не является положительным. **[ИсключениеВводаВывода](../../wiki/stdlib/inputoutputexception-ru-ceba5f672999.md)** - ошибка при преобразовании страницы в изображение. **[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт или страница удалена из него.

**Перегрузка** [КонвертироватьВИзображение(Поток: ПотокЗаписи, Формат: ФорматИзображения, Размер: РазмерИзображения)](../../wiki/stdlib/pdfpage-ru-568344e1aad1.md)

#### Примеры

```xbsl
метод КонвертироватьСтраницуВИзображение(Страница: СтраницаPdf, Поток: ПотокЗаписи)
    Страница.КонвертироватьВИзображение(Поток, ФорматИзображения.Png, 250)
;
```

### КонвертироватьВИзображение

`Доступность: Сервер`

```
КонвертироватьВИзображение(
  Поток: ПотокЗаписи,
  Формат: ФорматИзображения,
  Размер: РазмерИзображения)
```

Преобразовать страницу документа в изображение в формате

`Формат`

и размером

`Размер`

. Сохраненная картинка записывается в поток

`Поток`

.

В случае, если ширина и высота в соотношении друг с другом не соответствуют параметрам страницы документа, то итоговое изображение будет иметь максимально возможный размер (с сохранением пропорций), чтобы оно умещалось в описанный размерами `Размер` прямоугольник (длина и ширина измеряется в пикселях).

Поддерживаемые форматы изображения: JPEG, TIFF, GIF, BMP, PNG.

Если в страницу документа не были встроены шрифты, то они будут заменены на шрифт по умолчанию в операционной системе.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - неподдерживаемый формат изображения. **[ИсключениеВводаВывода](../../wiki/stdlib/inputoutputexception-ru-ceba5f672999.md)** - ошибка при преобразовании страницы в изображение. **[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт или страница удалена из него.

**Перегрузка** [КонвертироватьВИзображение(Поток: ПотокЗаписи, Формат: ФорматИзображения, Dpi: Число = 200)](../../wiki/stdlib/pdfpage-ru-568344e1aad1.md)

#### Примеры

```xbsl
метод КонвертироватьСтраницуВИзображениеСРазмером(Страница: СтраницаPdf, Поток: ПотокЗаписи)
    Страница.КонвертироватьВИзображение(Поток, ФорматИзображения.Jpeg, новый РазмерИзображения(500, 200))
;   
    
```

### ПолучитьВысотуСодержимого

`Доступность: Сервер`

```
ПолучитьВысотуСодержимого(): Число
```

Вычислить нижнюю границу контента на странице. Метод возвращает число, равное координате на оси Y, которая описывает параллельную оси X прямую, ниже которой нет отображаемых объектов.

#### Исключения

**[ИсключениеPdf](../../wiki/stdlib/pdfexception-ru-fca07efa7071.md)** - ошибка при обработке объектов страницы документа. **[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт или страница удалена из него.

#### Примеры

```xbsl
метод ДобавитьИзображениеНаСтраницуЕслиЕстьСвободноеМесто(Страница: СтраницаPdf, Поток: ПотокЧтения)
    пер ГраницаСодержимого = Страница.ПолучитьВысотуСодержимого()
    пер ВысотаСтраницы = Страница.Размер.Высота

    если (Страница.Размер.Ширина > 100 и ВысотаСтраницы - ГраницаСодержимого > 100)
        пер Область = новый ПрямоугольнаяОбласть(0, ГраницаСодержимого, 100, 100)
        Страница.ДобавитьИзображение(Поток, Область)
    ;
;
```

### ПолучитьСвободныеОбластиНаСтранице

`Доступность: Сервер`

```
ПолучитьСвободныеОбластиНаСтранице(
  Ширина: Число,
  Высота: Число
): ЧитаемыйМассив<ПрямоугольнаяОбласть>
```

Найти свободные места на странице PDF-документа. Каждый из найденных прямоугольников имеет ширину минимум

`Ширина`

и высоту минимум

`Высота`

. Массив свободных прямоугольников доступен только для чтения. В массиве могут присутствовать пересекающиеся прямоугольники, или внутри которых присутствуют части изображений или текста. Гарантируется, что все прямоугольные области целиком лежат на странице.

В случае внесений изменений в страницу документа, требуется повторно вызвать метод `ПолучитьСвободныеМестаНаСтранице`.

#### Исключения

**[ИсключениеPdf](../../wiki/stdlib/pdfexception-ru-fca07efa7071.md)** - ошибка при обработке объектов страницы документа. **[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - указаны отрицательные значения параметров размера области. **[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - если документ закрыт или страница удалена из него.

#### Примеры

```xbsl
метод ДобавитьИзображениеНаСтраницуВСвободнуюОбласть(Страница: СтраницаPdf, Поток: ПотокЧтения)
    пер Области = Страница.ПолучитьСвободныеОбластиНаСтранице(100, 100)
    если Области.Размер() > 0
        Страница.ДобавитьИзображение(Поток, Области[0])
    ;
;
```
