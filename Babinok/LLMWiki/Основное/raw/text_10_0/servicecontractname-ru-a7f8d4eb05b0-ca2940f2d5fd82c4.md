## Методы

### ПолучитьСервис

`Версия 10.0 и выше`

```
ПолучитьСервис(): {ИмяКонтрактаСервиса}?
```

Получить экземпляр типа-одиночки, который реализуют данный тип.

Метод существует, если в элементе проекта значение свойства "Множественный" равно Ложь.

Тип возвращаемого значения зависит от значения свойства "Обязательный":

- Истина, то тип будет ServiceContractName
- Ложь, то тип будет ServiceContractName?

---

### ПолучитьСервисы

`Доступность: КлиентИСервер` `Статический`

```
ПолучитьСервисы(): ЧитаемоеМножество<{ИмяКонтрактаСервиса}>
```

Получить экземпляры типов-одиночек, которые реализуют данный тип.

Метод существует, если в элементе проекта значение свойство "Множественный" равно Истина.
