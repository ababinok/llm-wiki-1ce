Определяет визуальные роли поля для диаграммы **Спидометр**.

---

## Литералы

#### Значение

Может быть назначена только на факт. Значение факта отображается как значение спидометра.

---

#### ВерхняяГраницаЗоны

Может быть назначена только на факт. Значение факта определяет верхнюю границу очередной зоны спидометра.

---

#### Минимум

Может быть назначена только на факт. Значение факта определяет нижнюю границу спидометра.
