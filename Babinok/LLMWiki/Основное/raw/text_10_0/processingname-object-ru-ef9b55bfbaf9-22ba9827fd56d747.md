### Заполнить

`Версия 10.0 и выше`

`Доступность: Сервер`

```
Заполнить(): Объект
```

Заполняет объект обработки, как при интерактивном вызове, путем вызова обработчика

[ПриЗаполнении](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md)

, если он есть. Возвращает сам объект обработки.

---

`Доступность: Сервер`


## Обработчики

### ПриЗаполнении

```
ПриЗаполнении()
```

Обработчик, вызываемый при:

- Интерактивном создании (открытии формы обработки)
- Вызове метода
  
  [Заполнить](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md)

Предназначен для предзаполнения объекта обработки в интерактивном режиме.
