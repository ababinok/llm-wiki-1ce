`Стд::Интерфейс::Диаграммы::ЭлементДиаграммыГанта<ТипДанныхЭлемента,ТипДанныхИнтервала>` `Доступность: КлиентИСервер`

ТипДанныхЭлемента: Тип данных элемента диаграммы Ганта. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов. ТипДанныхИнтервала: Тип данных интервала диаграммы Ганта

Описывает один элемент диаграммы Ганта (строку диаграммы, которая содержит интервалы).

**Сравнение**

Структурное

## Конструкторы

### ЭлементДиаграммыГанта

`Доступность: КлиентИСервер`

```
ЭлементДиаграммыГанта(
  Наименование: Строка,
  Данные: ТипДанныхЭлемента,
  Интервалы: Массив<ИнтервалДиаграммыГанта<ТипДанныхИнтервала>>, ДочерниеЭлементы: Массив<ЭлементДиаграммыГанта<ТипДанныхЭлемента, ТипДанныхИнтервала>>)
```

Создает элемент диаграммы Ганта.

---

## Свойства

### Данные

`Доступность: КлиентИСервер`

```
Данные: ТипДанныхЭлемента
```

Произвольные данные, связанные с элементом. Не используются при отображении, но могут использоваться при обработке событий, связанных с элементом.

---

### ДочерниеЭлементы

`Доступность: КлиентИСервер`

```
ДочерниеЭлементы: Массив<ЭлементДиаграммыГанта<ТипДанныхЭлемента, ТипДанныхИнтервала>>
```

Дочерние элементы. Образуют иерархическое дерево.

Переопределение: [ДочерниеЭлементы](../../wiki/interface/ganttchartitem-ru-952871018e2b.md)

---

Интервалы данного элемента.
