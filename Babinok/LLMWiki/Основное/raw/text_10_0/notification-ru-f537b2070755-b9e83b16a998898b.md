## Свойства

### Важность

`Версия 6.0 и ниже`

`Доступность: Клиент`

```
Важность: ВажностьКлиентскогоУведомления
```

Свойство было заменено свойством [Вид](../../wiki/interface/notification-ru-f537b2070755.md).

---

### Вид

`Версия 7.0 и выше`

`Доступность: Клиент`

```
Вид: ВидУведомления
```

Определяет вид уведомления, от которого зависит способ отображения уведомления в интерфейсе.

---

### Данные

`Доступность: Клиент`

```
Данные: неизвестно
```

Дополнительные данные, связанные с уведомлением. Могут использоваться в обработчиках команд уведомления.

---

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Текст заголовка уведомления.

---

### Ид

`Доступность: Клиент`

```
Ид: Строка
```

Уникальный идентификатор уведомления. По умолчанию система заполняет уникальным идентификатором. Может быть изменен прикладным разработчиком.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Определяет изображение уведомления.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/notification-ru-f537b2070755.md).

---

### КлючУникальности

`Доступность: Клиент`

```
КлючУникальности: Строка
```

Ключ уникальности уведомления. Если в центре уведомлений или в списке отображаемых уведомлений есть уведомление с тем же ключом уникальности, то оно будет замещено новым уведомлением.

---

### Команды

`Доступность: Клиент`

```
Команды: ФрагментКомандногоИнтерфейса<КомандаСПараметром<Уведомление>>?
```

Команды уведомления.

Примечание:

- В режиме отображения
  
  [Системное](../../wiki/interface/notificationkind-ru-c04da4316025.md)
  
  свойство
  
  [Команды](../../wiki/interface/notification-ru-f537b2070755.md)
  
  используется частично. Обработчик нажатия на первую из кнопок, заданных в массиве свойства
  
  [Команды](../../wiki/interface/notification-ru-f537b2070755.md)
  
  , будет выполнен при нажатии на уведомление. Остальные элементы массива будут проигнорированы. Сами кнопки ни в каком виде не будут отображены в интерфейсе уведомления.
- В режиме отображения
  
  [Обычное](../../wiki/interface/notificationkind-ru-c04da4316025.md)
  
  для задания обработчиков можно задать массив из не более чем двух кнопок. Обработчики нажатия будут вызываться при нажатии на соответствующую кнопку.

---

### ОтображатьОбратныйОтсчет

`Доступность: Клиент`

```
ОтображатьОбратныйОтсчет: Булево
```

Управляет отображением в интерфейсе уведомления компонента обратного отсчета, который показывает время до исчезновения всплывающего окна с уведомлением. Обратный отсчет отображается для уведомлений с [Вид](../../wiki/interface/notification-ru-f537b2070755.md) = [Обычное](../../wiki/interface/notificationkind-ru-c04da4316025.md) и в центре уведомлений.

## События

### ПриЗакрытии

`Доступность: Клиент`

```
ПриЗакрытии: (Уведомление)->ничто
```

Вызывается при закрытии уведомления:

- уведомление находится в центре уведомлений приложения, и пользователь нажал кнопку "Очистить все",
- пользователь нажал на крестик в компоненте уведомления в центре уведомлений.
