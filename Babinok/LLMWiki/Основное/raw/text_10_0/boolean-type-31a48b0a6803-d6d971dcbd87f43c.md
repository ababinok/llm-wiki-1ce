Для хранения логических значений используется тип `Булево`. Этот тип имеет только два значения: `Истина` и `Ложь`.

Значение типа `Булево`является результатом вычисления [логического выражения](../../wiki/language/logical-and-boolean-operations-2e9bec28652f.md). Тип `Булево` используется везде, где вычисляются какие-либо условия. Так, если написать выражение `А < Б`, то результатом вычисления такого выражения будет значение типа `Булево`.

## Примеры

```xbsl
метод Скрипт()
    пер А: Число = 2
    пер Б: Число = 3
    пер РезультатЛожь = А > Б     // Имеет значение Ложь типа Булево
    пер РезультатИстина = А < 123 // Имеет значение Истина типа Булево
;
```

```xbsl
метод Сравнить(А: Число, Б: Число): Булево
    возврат А == Б
;

метод Скрипт()
    пер В: Булево = Сравнить(2,3) // Имеет значение Ложь типа Булево
;
```

Значения данного типа удобно использовать для таких свойств объектов, которые имеют только два состояния, например: `Использовать`, `ИспользоватьВсегда`, `ИспользоватьРасширенныеНастройки`, `ВключатьВДанныеСтроки`, `ТолькоЧтение`, `ПоУмолчанию` и многие другие.

Пример использования в языке «1С:Элемент»:

```xbsl
структура ПользовательПриложения
    пер Имя: Строка
    пер Ид: Ууид
    пер ДоступКПриложению: Булево = Истина
;
```
