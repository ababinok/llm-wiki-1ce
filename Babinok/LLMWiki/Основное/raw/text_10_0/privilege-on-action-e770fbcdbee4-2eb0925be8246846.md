Элемент проекта, описывающий права на действия.

Право на действие — право, не привязанное к конкретной сущности, а право на действие вообще. Может содержать параметры. Наличие права на действие проверяется вручную разработчиком.

После того как вы добавили в проект право на действие, «1С:Предприятие.Элемент» создаст несколько типов, имена которых в общем случае выглядят следующим образом:

- [`{ИмяПраваНаДействие}`](../../wiki/stdlib/privilegeonactionname-ru-3650a0a22835.md)
  
  ,
- [`{ИмяПраваНаДействие}.Объект`](../../wiki/stdlib/privilegeonactionname-object-ru-b0eb3a0d1eae.md)
  
  .

Например, для права на действие с именем **ПравоНаОтправкуПисьма** будут созданы следующие типы:

- `ПравоНаОтправкуПисьма`
  
  ,
- `ПравоНаОтправкуПисьма.Объект`
  
  .

## Тип «ИмяПраваНаДействие»

Тип [`{ИмяПраваНаДействие}`](../../wiki/stdlib/privilegeonactionname-ru-3650a0a22835.md) является типом-одиночкой и доступен на сервере. Он содержит метод `Проверить()`, который позволяет проверить наличие прав на действия у текущего пользователя:

```xbsl
ПравоНаДействие.Проверить(%Параметры%)
```

## Модуль права на действие

В проекте модуль, расширяющий тип [`{ИмяПраваНаДействие}`](../../wiki/stdlib/privilegeonactionname-ru-3650a0a22835.md), называется **модулем права на действие**. Он исполняется на сервере.

В дереве проекта показан модуль права на действие; он расширяет тип соответствующего права и выполняется на сервере. [Описание иллюстрации](../figures/3abebca8a60f4379d1c7758af293584aa0882a07768a507a8f36b6d8f4283d7b-7845c554fe436321.md)

В нем задается обработчик вычисления разрешений доступа:

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(Права: ЧитаемыйМассив<ПравоНаДействие.Объект>): 
                                ЧитаемоеСоответствие<ПравоНаДействие.Объект, ЧитаемаяКоллекция<КлючДоступа.Объект>>
   // TODO Вставить содержимое обработчика
   возврат {:}
;
```

## Тип «ИмяПраваНаДействие.Объект»

Тип [`{ИмяПраваНаДействие}.Объект`](../../wiki/stdlib/privilegeonactionname-object-ru-b0eb3a0d1eae.md), предназначен для описания одного права на действие. Например, для элемента с именем **МоеПравоНаДействие** это будет тип `МоеПравоНаДействие.Объект`.

Чтобы создать экземпляр права (экземпляр этого типа), нужно просто вызвать конструктор этого типа:

```xbsl
пер ЭкземплярПрава = новый ПравоНаОтправкуПисьма.Объект()
```

Элемент проекта вида `ПравоНаДействие` может иметь параметры. Для каждого сочетания значений этих параметров «Элемент» будет создавать свой уникальный экземпляр права на действие.

Таким образом, если ваш элемент проекта не имеет параметров, то такое право на действие может иметь только один единственный экземпляр:

```xbsl
пер ЭкземплярПрава = новый ПравоНаОтправкуПисьма.Объект()
```

Но если вы добавите ему два параметра, каждый из которых является перечислением и содержит по два элемента:

- ВремяСуток
  
  (
  
  Рабочее
  
  ,
  
  Нерабочее
  
  ),
- СпособПодключения
  
  (
  
  Локально
  
  ,
  
  Удаленно
  
  ),

то право на действие будет иметь уже четыре экземпляра:

```xbsl
пер ЭкземплярПрава1 = новый ПравоНаОтправкуПисьма.Объект(ВремяСуток.Рабочее, СпособПодключения.Локально)
пер ЭкземплярПрава2 = новый ПравоНаОтправкуПисьма.Объект(ВремяСуток.Рабочее, СпособПодключения.Удаленно)
пер ЭкземплярПрава3 = новый ПравоНаОтправкуПисьма.Объект(ВремяСуток.Нерабочее, СпособПодключения.Локально)
пер ЭкземплярПрава4 = новый ПравоНаОтправкуПисьма.Объект(ВремяСуток.Нерабочее, СпособПодключения.Удаленно)
```

## Модуль объекта права на действие

В проекте модуль, расширяющий тип [`{ИмяПраваНаДействие}.Объект`](../../wiki/stdlib/privilegeonactionname-object-ru-b0eb3a0d1eae.md), называется **модулем объекта права на действие**. Он доступен в окружении **Сервер**.



## Пример установки права на отправку письма контрагенту

Предположим, в проекте есть справочник **Контрагенты**. Требуется установить права таким образом, чтобы отправлять сообщения контрагентам могли только руководители.

Также, ранее мы добавили в приложение собственный ключ доступа с именем **КлючиГруппСотрудников**. Этот ключ имеет один параметр **Группа**, типа перечисление **ГруппыСотрудников**. Это перечисление мы также добавили сами и оно имеет два элемента: **Менеджеры** и **Руководители**. Таким образом, мы можем создавать до двух экземпляров этого ключа, и разделять с их помощью всех пользователей на две группы.

Описание элемента проекта **ПравоНаДействие** может выглядеть следующим образом:

```yaml
ВидЭлемента: ПравоНаДействие
ОбластьВидимости: ВПодсистеме
Имя: ПравоНаОтправкуПисьма
Ид: 790c6e50-88af-4605-adf5-972fd690f218
```

Выдача прав осуществляется в обработчике вычисления разрешений доступа, в модуле права на действие:

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(Права: ЧитаемыйМассив<ПравоНаОтправкуПисьма.Объект>): 
                                 Соответствие<ПравоНаОтправкуПисьма.Объект, Коллекция<КлючДоступа.Объект>>

    пер Разрешения: Соответствие<ПравоНаОтправкуПисьма.Объект, Коллекция<КлючДоступа.Объект>>

    // Получить экземпляры ключа доступа
    пер КлючРуководителей = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Руководители)

    для Право из Права
        Разрешения.Вставить(Право, [КлючРуководителей])
    ;
    возврат Разрешения
;
```

В результате все пользователи, обладающие ключом **КлючРуководителей**, теперь будут иметь право на отправку сообщения контрагенту.

Проверку права на отправку сообщения можно реализовать в самом методе отправки:

```xbsl
метод ОтправитьСообщениеКонтрагенту(Контрагент: Контрагенты.Ссылка)
    ПравоНаОтправкуПисьма.Проверить()

   // Отправка письма
;
```
