[Действие](../../wiki/integration/http-requests-2fbe5c3df089.md), которое сервер должен выполнить с ресурсом, указанным с помощью URI. Состоит из любых символов US-ASCII (кроме управляющих символов и разделителей). Имя метода метода может быть любым, но рекомендуется использовать методы, описанные в спецификации HTTP 1.1 (RFC 2616).

---

## Свойства

#### Метод

```yaml
Метод: Строка
```

Имя метода.

---

#### Обработчик

```yaml
Обработчик: Строка
```

Метод-обработчик, который объявлен в [модуле](../../wiki/integration/http-service-types-f4cbd0b4c8b8.md) данного сервиса. Реализует обработку запроса на уровне приложения.

---

#### КонтрольДоступа

```yaml
КонтрольДоступа: 
    Разрешения: 
        Вызов: КонтрольДоступа
    Обработчик: Строка
```

Содержит [настройки прав доступа](../../wiki/security/http-service-access-permissions-0998f45d9af8.md) для данного HTTP-метода URL-шаблона.
