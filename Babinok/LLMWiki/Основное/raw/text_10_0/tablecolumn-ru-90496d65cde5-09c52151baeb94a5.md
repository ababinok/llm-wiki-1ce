## Свойства

### Важность

`Доступность: Клиент`

```
Важность: ВажностьКомпонента
```

Определяет важность колонки. Влияет на отображение ячейки данной колонки.

При трансформации таблицы в мобильном окружении в список карточек, стандартные колонки с [Высокая](../../wiki/interface/componentimportance-ru-6c7fef2e318b.md) будут помещены выше остальных, далее по убыванию важности соответственно. В режиме иерархии, в отсутствие среди колонок колонки с важностью [Высокая](../../wiki/interface/componentimportance-ru-6c7fef2e318b.md) - наверх будет помещена первая по приоритету остаточной важности колонка.

---

### ДанныеСтроки

`Доступность: Клиент` `ТолькоЧтение`

```
ДанныеСтроки: ТипДанных
```

Если используется в вычислении свойства непосредственно колонки, например [Заголовок](../../wiki/interface/tablecolumn-ru-90496d65cde5.md), то равно `Неопределено`. Если используется для вычисления свойства ячейки, например [Изображение](../../wiki/interface/standardtablecolumn-ru-92a62dc49597.md), то содержит данные строки таблицы.

---

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Заголовок колонки.

---

### НастройкиРедактирования

`Доступность: Клиент`

```
НастройкиРедактирования: НастройкиРедактированияПоляВвода|НастройкиРедактированияПереключателя|?
```

Описывает настройки поля ввода или флажка, используемого для редактирования данных в ячейке.

---

### ОтключитьСортировку

`Доступность: Клиент`

```
ОтключитьСортировку: Булево
```

Принудительно отключает сортировку по данной колонке.

---

### ОтображатьЗаголовокВКарточке

`Доступность: Клиент`

```
ОтображатьЗаголовокВКарточке: Булево
```

Устанавливает видимость заголовка ячейки в случае, когда таблица отображается в виде списка карточек. По умолчанию заголовки ячеек в карточке отображаются.

---

### ПолеЗначения

`Доступность: Клиент`

```
ПолеЗначения: Строка
```

Указывает поле данных строки, значение которого будет отображено в ячейке. Также это поле будет использоваться для сортировки по данной колонке.

---

### РазрешитьСжатие

`Доступность: Клиент`

```
РазрешитьСжатие: Авто|Булево
```

Устанавливает поведение колонки при автоматическом расчете ширин колонок. Если `Истина` - содержимое будет вмещаться в ширину видимой области таблицы с учетом других колонок вплоть до минимально возможной ширины колонки. Если `Ложь` - ширина колонки будет подобрана так, чтобы вместить все свое содержимое.
