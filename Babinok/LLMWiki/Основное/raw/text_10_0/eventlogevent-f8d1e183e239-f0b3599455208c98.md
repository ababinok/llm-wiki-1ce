Событие, регистрируемое в [журнале событий](../../wiki/project/event-log-8a28c1a3e2b6.md). Элемент предназначен для регистрации событий, которые может анализировать пользователь приложения.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### ШаблонПредставления

```yaml
ШаблонПредставления: Строка|СсылкаНаЛокализованнуюСтроку
```

Обязательно для вида события [Информация](../../wiki/project/eventkind-ru-7df565b57627.md) и [Ошибка](../../wiki/project/eventkind-ru-7df565b57627.md). Форматная строка, в которой формируется человекочитаемое сообщение. В качестве аргументов используются свойства события. Формат используется тот же, что в [интерполяции](../../wiki/project/string-interpolation-11a240556103.md): `%{ИмяСвойстваСобытия}` либо `${ИмяСвойстваСобытия}` (возможна также запись без фигурных скобок). Могут использоваться как предопределенные, так и добавленные пользователем свойства событий. Локализуется. При обращении к событию используется та форматная строка, которая была актуальна на момент регистрации события.
