### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): {ИмяИнтегрируемогоПриложения}.Объект?
```

Загружает объект интегрируемого приложения по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../../wiki/stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](../../wiki/data/noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.

**Переопределение** [ИнтегрируемоеПриложение.Ссылка::ЗагрузитьОбъект](../../wiki/stdlib/integrableapplication-reference-ru-e8cf211a7b95.md)

### СоздатьКопиюОбъекта

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопиюОбъекта(
  Ид: Ууид = Неопределено,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр интегрируемого приложения копированием экземпляра интегрируемого приложения на который указывает эта ссылка.

#### Исключения

**[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта - источника создания копированием. **[ИсключениеИсточникКопированияСущностиНеСуществует](../../wiki/data/entitycopysourcenotexistsexception-ru-ccae6b569bee.md)** - Если ссылка у которой был вызван метод указывает на несуществующий объект.
