## Перенос выражений

Выражения переносятся в тех случаях, когда:

- инструкция, содержащая выражение, превышает
  
  [максимальную длину строки](../../wiki/project/general-design-ef45fcfa44b8.md)
  
  ;
- перенос выражения улучшает понимание инструкции.

В каждой перенесенной строке может содержаться одна или несколько операций.

Операции пишутся в начале перенесенных строк.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
если Переменная1 > 5
     или Переменная2 < Переменная3
     и не Переменная4
    Метод1()
    Метод2()
;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
если Переменная1 > 5 или
     Переменная2 < Переменная3 и
     не Переменная4
    Метод1()
    Метод2()
;
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер Сумма = Переменная1
            + Переменная2
            - Переменная3
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер Сумма = Переменная1 +
            Переменная2 -
            Переменная3
```

> [!TIP] совет
> При конкатенации строк допускается писать операцию в конце строки:
>
> ```xbsl
> пер Строка = "Сегодня " +
>              НомерДняНедели +
>              "-й день недели"
> ```

### Выравнивание перенесенных строк

Перенесенные строки выравниваются:

- по началу первого операнда:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    если Переменная1 > 5
        или Переменная2 < Переменная3
        и не Переменная4
        Метод1()
        Метод2()
    ;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    если Переменная1 > 5
    или Переменная2 < Переменная3
    и не Переменная4
        Метод1
        Метод2()
    ;
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    пер Строка = "Сегодня " +
                 НомерДняНедели +
                 "-й день недели"
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    пер Строка = "Сегодня " +
                  НомерДняНедели +
                 "-й день недели"
```

- одним синтаксическим отступом:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    если Переменная1 > 5
        или Переменная2 < Переменная3

        Метод1()
        Метод2()
    ;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    если
        Переменная1 > 5
        или Переменная2 < Переменная3

        Метод1()
        Метод2()
    ;
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    пер Строка = "Сегодня " +
        НомерДняНедели +
        "-й день недели"
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    пер Строка =
        "Сегодня " +
        НомерДняНедели +
        "-й день недели"
```

## Перенос параметров

Параметры методов переносятся в тех случаях, когда:

- вызов или объявление метода превышает
  
  [максимальную длину строки](../../wiki/project/general-design-ef45fcfa44b8.md)
  
  ,
- перенос параметров улучшает понимание инструкции.

В каждой перенесенной строке может содержаться один или несколько параметров.

Запятые, разделяющие параметры, пишутся в конце строк:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
Массив.Добавить(Свойство.Параметр1,
                Свойство.Параметр2,
                Свойство.Параметр3,
                Свойство.Параметр4)
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
Массив.Добавить(Свойство.Параметр1, Свойство.Параметр2,
                Свойство.Параметр3, Свойство.Параметр4)
```

### Выравнивание перенесенных параметров

Перенесенные параметры выравниваются:

- по началу первого параметра, в случае чего закрывающая скобка пишется в конце последней перенесенной строки:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    Массив.Добавить(Свойство.Параметр1,
                    Свойство.Параметр2,
                    Свойство.Параметр3,
                    Свойство.Параметр4)
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    Массив.Добавить(Свойство.Параметр1,
        Свойство.Параметр2,
        Свойство.Параметр3,
        Свойство.Параметр4)
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    метод Метод1(Параметр1: Число,
                 Параметр2: Строка,
                 Параметр3: Строка): Булево

        пер Переменная1 = 40
        возврат Истина
    ;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
    метод Метод1(Параметр1: Число,
        Параметр2: Строка,
        Параметр3: Строка): Булево

        пер Переменная1 = 40
        возврат Истина
    ;
```

- одним синтаксическим отступом, в случае чего параметры переносятся начиная с первого, а закрывающая скобка пишется:
  
  - на отдельной строке с отступом, соответствующим отступу всей инструкции,
  - в конце последней перенесенной строки.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    Массив.Добавить(
        Свойство.Параметр1,
        Свойство.Параметр2,
        Свойство.Параметр3,
        Свойство.Параметр4
    )

    Массив.Добавить(
        Свойство.Параметр1,
        Свойство.Параметр2,
        Свойство.Параметр3,
        Свойство.Параметр4)
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
    метод Метод1(
        Параметр1: Число, 
        Параметр2: Строка, 
        Параметр3: Строка
    ): Булево

        пер Переменная1 = 40
        возврат Истина
    ;

    метод Метод1(
        Параметр1: Число, 
        Параметр2: Строка, 
        Параметр3: Строка): Булево

        пер Переменная1 = 40
        возврат Истина
    ;
```

## Перенос литералов коллекций

Литералы коллекций переносятся по тем же правилам, что и параметры методов:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер ИменаПолей = ["Идентификатор", 
                  "Размер", 
                  "Цвет"]
пер ИменаПолей = [
    "Идентификатор", 
    "Размер", 
    "Цвет"
]
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер МножествоСДанными = {1, 
                         2, 
                         3}

пер МножествоСДанными = {
    1, 
    2, 
    3
}
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер КурсыВалют = {"RUB": 1, 
                  "BYN": 31.01}

пер КурсыВалют = {
    "RUB": 1, 
    "BYN": 31.01
}
```
