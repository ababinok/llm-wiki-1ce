Использование литералов коллекций предпочтительнее, чем наполнение вручную:

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер ИменаПолей = ["Идентификатор", "Размер", "Цвет"]
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер ИменаПолей: Массив<Строка>
ИменаПолей.Добавить("Идентификатор")
ИменаПолей.Добавить("Размер")
ИменаПолей.Добавить("Цвет")
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер МножествоСДанными = {1, 2, 3}
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер МножествоСДанными: Множество<Число>
МножествоСДанными.Добавить(1)
МножествоСДанными.Добавить(2)
МножествоСДанными.Добавить(3)
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
пер КурсыВалют = {"RUB": 1, "BYN": 31.01}
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
пер КурсыВалют: Соответствие<Строка, Число>
КурсыВалют.Вставить("RUB", 1)
КурсыВалют.Вставить("BYN", 31.01)
```
