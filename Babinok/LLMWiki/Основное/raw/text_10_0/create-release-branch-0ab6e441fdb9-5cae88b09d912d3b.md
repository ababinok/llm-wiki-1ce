*Ветка релиза* — это изолированное от основного состояния проекта ответвление разработки, направленное на подготовку к [выпуску релиза](../../wiki/project/create-or-cancel-release-89b0fc793f03.md) и его последующую поддержку. Вы можете создать ветку релиза от основной или любой другой ветки проекта. После создания релизной ветки вы можете дальше разрабатывать новую функциональность в основной ветке, а в ветку релиза вносить только исправления ошибок, обнаруженные в соответствующей версии проекта. Таким образом вы сможете подготовить эту версию к публичному выпуску, не мешая развитию нового функционала.

Вы можете выпускать несколько релизов из одной ветки. Например, вы выпустили релиз *2.0.0* на основе релизной ветки *release/2.0*. Далее из этой ветки вы можете выпустить релиз *2.0.1*, который будет содержать исправления ошибок предыдущей версии, затем релиз *2.0.2* и т. д.

Чтобы создать ветку релиза, выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. На вкладке **Ветки** нажмите **+ Новая ветка** и выберите пункт **Релизная** в выпадающем меню.
  
  
4. В открывшемся окне выберите ветку проекта, от которой необходимо создать релизную ветку, и введите название новой ветки. По умолчанию в качестве ветки-источника будет выбрана основная ветка проекта, а имя релизной ветки будет указано в формате *release/x.x*, где *x.x* — текущая версия проекта. Если вы введете другую версию, «1С:Предприятие.Элемент» также изменит версию проекта в файле *Проект.yaml* на указанную.
  
  Диалог «Создание релизной ветки» содержит Ветка-источник (в примере main), Версия (2.0), Название ветки (release/2.0), поле Приложение, ссылку «+ Создать новое приложение» и кнопку Создать ветку. [Описание иллюстрации](../figures/26279101fef00d33d5f00b174c989728a6299d7e5e338d33854ad6b91e1c11e3-774e656256c6b43b.md)
5. Для тестирования кода в релизной ветке вы можете создать новое приложение или выбрать существующее. Если вы выбрали создание нового приложения, «1С:Предприятие.Элемент» отобразит диалоговое окно для настройки параметров приложения.
  
  Создание приложения для ветки [Описание иллюстрации](../figures/a517b81a08c0ec0d4319c882084c23c65f0de0137e7326d85961e7cadd5ed22d-d71a53857b72afbc.md)
6. Когда приложение будет создано, нажмите кнопку **Создать ветку**.

Созданная ветка появится в общем списке на вкладке **Ветки**. В качестве типа ветки будет указано **Релизная**.

В общем списке веток выделена ветка release/2.0; в колонке типа у неё метка «Релизная». [Описание иллюстрации](../figures/5531c056079322d3f962bd090d08925c033009f5ffba426cfeb7e8a4cd3f3cee-b327e41df787d70e.md)

> [!TIP] совет
> Вы также можете указать существующую ветку проекта как релизную. Для этого щелкните на значокПиктограмма «Значок меню». [Описание иллюстрации](../figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для нужной ветки и выберите пункт **Назначить релизной** в выпадающем меню.

После создания релизной ветки вы можете приступить к тестированию кода в этой ветке, внесению необходимых правок и [выпуску релиза](../../wiki/project/create-or-cancel-release-89b0fc793f03.md).
