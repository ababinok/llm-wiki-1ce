### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): {ИмяДокумента}.Объект?
```

Загружает объект документа по текущей ссылке.

`Заблокировать` - признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает `Неопределено`.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../../wiki/stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](../../wiki/data/noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.

**Переопределение** [Документ.Ссылка::ЗагрузитьОбъект](../../wiki/data/document-reference-ru-8abd292208dd.md)

#### Примеры

Чтение объекта в транзакции с последующим изменением.

```xbsl
метод ЗаменитьДоговор(Документы: ЧитаемыйМассив<Накладная.Ссылка>, НовыйДоговор: Договоры.Ссылка)
    исп Транзакция = Транзакции.Начать()
    
    для Ссылка из Документы
        // Изменяемый в транзакции документ нужно считывать с исключительной блокировкой,
        // иначе при параллельном исполнении может возникнуть взаимоблокировка (deadlock)
        знч Накладная = Ссылка.ЗагрузитьОбъект(Истина)
        
        если Накладная == Неопределено
            // Ссылка может быть недействительной
            продолжить
        ;
           
        Накладная.Договор = НовыйДоговор
        Накладная.Записать()
    ;
    
    Транзакция.Фиксировать()
;
```

### СоздатьКопиюОбъекта

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопиюОбъекта(
  Ид: Ууид = Неопределено,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр документа копированием документа на который указывает эта ссылка.

#### Исключения

**[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта - источника создания копированием. **[ИсключениеИсточникКопированияСущностиНеСуществует](../../wiki/data/entitycopysourcenotexistsexception-ru-ccae6b569bee.md)** - Если ссылка у которой был вызван метод указывает на несуществующий объект.

#### Примеры

Создание нового документа копированием существующего.

```xbsl
метод ДублироватьНакладную(ДокументСсылка: Накладная.Ссылка): Накладная.Ссылка
    знч ДокументКопия = ДокументСсылка.СоздатьКопиюОбъекта(Дата = ДатаВремя.Сейчас(ЧасовойПояс.Текущий()))
    ДокументКопия.Записать()
    
    возврат ДокументКопия.Ссылка
;
```
