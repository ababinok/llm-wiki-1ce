Таблица регистрации изменений создается, только если регистр сведений включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению набора записей регистра сведений, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице регистра сведений.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **КлючОсновногоФильтра** из таблицы регистрации изменений **Цены.Изменения**:

```xbql
ВЫБРАТЬ
    Цены.Узел КАК Узел,
    Цены.КлючОсновногоФильтра КАК Ключ
ИЗ
    Цены.Изменения КАК Цены
```

---

## Поля

### КлючОсновногоФильтра

`Ключевое поле`

```
КлючОсновногоФильтра: ИмяРегистраСведений.КлючОсновногоФильтра
```

Структура, описывающая ключ основного фильтра регистра сведений. Добавляется, даже если нет измерений, включаемых в основной фильтр. Имеет тип [ИмяРегистраСведений.КлючОсновногоФильтра](../../wiki/data/informationregistername-mainfilterkey-ru-b2b91a95f0cf.md).

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена, для которого зарегистрированы изменения. Имеет тип [ИмяПланаОбмена.Ссылка](../../wiki/integration/exchangeplanname-reference-ru-ea9b8c731c88.md).

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Имеет тип `Число`. Если изменение не включено в сообщение, то значение `Неопределено`.

---

## Индексы

### УзелНомерСообщенияКлючДанных

Индекс по полям: **Узел**, **НомерСообщения**, **КлючДанных**. Если регистр сведений периодический и период входит в основной фильтр, то добавляется индекс по полю **Измерения**.
