Элементы проекта позволяют описать [функциональность приложения](../../wiki/interface/all-project-elements-5977d6a645f5.md) и его [командный интерфейс](../../wiki/interface/all-project-elements-5977d6a645f5.md). Чтобы добавить элемент проекта, выполните следующие действия:

1. Откройте представление
  
  Проект
  
  .
2. Наведите мышку на подсистему, пакет или элемент проекта и нажмите на знак плюса.
3. В открывшемся окне выберите нужный элемент проекта.
4. Введите имя элемента и нажмите
  
  Enter
  
  .

> [!WARNING] важно
> Для добавления [элементов проекта](../../wiki/interface/all-project-elements-5977d6a645f5.md) используйте [представление **Проект**](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md). Использование элементов, недоступных в навигаторе проекта, приведет к ошибке сборки проекта.

## Реквизиты, поля и т. д.

Чтобы добавить составную часть элемента проекта (например, измерение для регистра сведений или поле для структуры), в представлении **Проект** разверните структуру элемента проекта и нажмите на знак плюса в соответствующем разделе (**Поля**, **Реквизиты**, **Измерения** и т. д.). В открывшемся окне выберите тип добавляемого объекта.

В дереве регистра сведений кнопка плюса рядом с «Измерения» открывает выбор типа нового измерения. [Описание иллюстрации](../figures/31e62b73aa114c1640bb3f6e573e08dece56fa43f9ae68d06d96144b0ca39512-258ec07d0d433447.md)

Введите имя элемента и нажмите **Enter**.

## Формы

Чтобы добавить форму элемента проекта, в представлении **Проект** нажмите на знак плюса рядом с именем нужного элемента проекта. В открывшемся окне выберите тип добавляемой формы.

Добавление формы объекта [Описание иллюстрации](../figures/942e19a131c5909d41c613031e719d69140b93336c867bc56d8c338232409554-663903fc64dace4b.md)

## Модули

Чтобы добавить модуль элемента проекта, в представлении **Проект** нажмите на знак плюса рядом с именем нужного элемента проекта. В открывшемся окне выберите тип добавляемого модуля: **Модуль** или **Модуль объекта**.

## Редактирование

Вы можете изменить описание элемента проекта в панели **Свойства**. Чтобы открыть ее, выделите нужный элемент проекта в представлении **Проект**.
