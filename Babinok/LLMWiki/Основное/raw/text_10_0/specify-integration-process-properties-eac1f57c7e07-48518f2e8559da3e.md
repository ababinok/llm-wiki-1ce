> [!WARNING] важно
> Процессы интеграции недоступны в облачной версии «1С:Предприятие.Элемента».

Во время создания проекта («design-time») можно создать набор параметров и заполнить ими свойства узла процесса интеграции. Значения этих параметров задаются уже непосредственно во время исполнения (в режиме «runtime»). Значения параметров хранятся в системных таблицах в базе приложения в открытом виде.

В качестве примера рассмотрим задание значений параметров, которыми заполнены свойства [узла «Http»](../../wiki/integration/http-integration-scheme-node-d9bde3031004.md) процесса интеграции «ОбменССайтом» (см. [Пример 1](../../wiki/integration/esb-demo-example-1-023afe2b56d5.md)).

1. Откройте страницу приложения «1С:Предприятие.Элемента» и кликните на процесс интеграции.
2. Откроется схема процесса интеграции. Если кликнуть по пустому месту на схеме, то на вкладке **Свойства** отобразятся свойства процесса интеграции, а также параметры, [созданные в среде разработки](../../wiki/integration/integration-process-parameters-cecc1db499d5.md) на этапе проектирования.
  
  Свойства процесса интеграции «ОбменССайтом» разделены на параметры API, Login, Password, URL и общие свойства процесса. [Описание иллюстрации](../figures/61418a8e47503a08c08facbfe9546d969399b4282ae2d7667245789f006ea2f6-50a59df8dd042067.md)
3. Задайте их значения. В данном примере значения параметров заполняются следующим образом:
  
  - URL
    
    :
    
    `https://имя-сервера/имя-сайта`
    
    ;
  - API
    
    :
    
    `/{метод API/}`
    
    ;
  - в
    
    Login
    
    и
    
    Password
    
    указывается пользовательский ключ и секретный код пользователя, полученные при генерации ключа на сайте.
  
  Заполнение параметров процесса интеграции [Описание иллюстрации](../figures/cdf99edb6b42c0ee5c2dab699069bb6f8e5251e00973049cb78b6db6a40c0b9c-74bc17e82955dfb3.md)
  
  После того как вы заполнили значения параметров, нажмите **Применить**.

> [!NOTE] дополнительно
> Если вы изменяете значения параметров в ходе запущенного процесса интеграции, их применение вызовет остановку и повторный запуск процесса. Это может занять значительное время.
