«1С:Предприятие.Элемент» позволяет вам безопасно хранить в приложении *секреты* — пароли, токены доступа, ключи и другие конфиденциальные данные.

Для работы с секретами используется абстрактный базовый тип [`Секрет`](../../wiki/security/secret-ru-be3e2bf29a04.md). Данный тип предоставляет возможность хранить значение в зашифрованном виде. От него наследуются все поддерживаемые виды секретов, в частности секрет приложения, который может использоваться для доступа к другим сервисам, базам данных и т. п.

## Секрет приложения

Вы можете создать секрет, уникальный для приложения, с помощью конструктора типа [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md). Максимальный размер шифруемого значения — 1000 символов.

Создание секрета приложения

```xbsl
знч СекретДемоПриложения = новый СекретПриложения("ЗначениеСекрета")
```

Значение секрета приложения хранится на сервере в зашифрованном виде. Если вы хотите посмотреть открытое значение секрета, вызовите метод [`Раскрыть()`](../../wiki/security/secret-ru-be3e2bf29a04.md).

Раскрытие секрета приложения

```xbsl
знч СекретДемоПриложения = новый СекретПриложения("ЗначениеСекрета")
знч ОткрытоеЗначение = СекретДемоПриложения.Раскрыть()
```

При использовании этого метода следует учитывать следующие особенности:

- На клиенте можно раскрыть только секрет, созданный в клиентском окружении. Если секрет создан на сервере, то раскрыть его значение можно только на сервере, в противном случае выбрасывается
  
  [`ИсключениеДоступаКСекрету`](../../wiki/security/secretaccessexception-ru-b71fa04e142e.md)
  
  .
- Если ключ шифрования секрета отсутствует, то выбрасывается
  
  [`ИсключениеДоступаКСекрету`](../../wiki/security/secretaccessexception-ru-b71fa04e142e.md)
  
  .

## Использование секрета в коде

Экземпляры типов, унаследованных от типа [`Секрет`](../../wiki/security/secret-ru-be3e2bf29a04.md), могут передаваться в методы различных типов в качестве значения параметра `Пароль`, например:

Создание зашифрованного ZIP-архива

```xbsl
метод ЗаписатьСШифрованием(ПутьКАрхиву: Строка, Пароль: Секрет)
    пер Архив = новый ФайлZip(ПутьКАрхиву, Пароль)

    // Добавление папки с файлами в архив
    Архив.Добавить(Файлы.ПолучитьДомашнийКаталогПользователя().Путь + "/ПапкаСФайламиДляСжатия",
                   УровеньСжатия = УровеньСжатияZip.Максимальный, МетодШифрования = МетодШифрованияZip.Aes256)
;
```

## Использование секрета в реквизитах сущностей

Тип [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md) может использоваться в реквизитах элемента проекта. Это атомарное значение реквизита, которое хранится как структура в таблице сущности.

Например, для справочника, который содержит основную информацию о приложении, вы можете создать реквизит **Секрет** типа [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md):

В выборе типа реквизита справочника отмечен «СекретПриложения» из раздела безопасности; создаётся реквизит для хранения секрета приложения. [Описание иллюстрации](../figures/325cc9d4fa6903f6b9cfb0a286da105afbb573dea8bd92b46a27acdb574b7e2d-7ce6aded3953c483.md)

### Миграция строковых значений в «СекретПриложения» и обратно

При изменении типа реквизита с типа [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md) на тип [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md) строковое значение автоматически преобразуется в секрет.

При изменении типа реквизита с типа [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md) на тип [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md) значение секрета автоматически раскрывается.

## Работа с секретом в интерфейсе приложения

Вы можете указать тип [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md) в качестве типа компонента интерфейса.

Например, если вы создаете форму для указания/редактирования настроек доступа к хранилищу данных и добавляете поле для ввода ключа приложения, то в качестве типа поля следует выбрать [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md):

В панели свойств поля ввода открыт выбор типа «СекретПриложения» для ввода секрета приложения. [Описание иллюстрации](../figures/d941ccb5704e8cd42ac467d75702d1cdd7e96f48329af5b4bde4b48827c2e5f1-6168a75b2a229aa4.md)

Для поля ввода с типом [`СекретПриложения`](../../wiki/security/applicationsecret-ru-f32310c0e6f2.md) автоматически активируется настройка [РежимПароля](../../wiki/interface/edit-ru-4027d1cb7b27.md), которая не может быть отключена (значение `Ложь` игнорируется).

Если пользователь создает новый секрет, поле ввода содержит значок **Показать/Скрыть** для отображения введенного значения.

В поле «Секрет» введённое значение скрыто точками; справа выделен значок глаза с перечёркиванием для показа или скрытия нового секрета. [Описание иллюстрации](../figures/e72c3f36ccca408e5fba7cdfbd3fa6abab128ce36194418b4221046ea80b5ae6-50cd54e90afca01b.md)

Если пользователь открывает форму для редактирования существующего секрета, он не может посмотреть его значение: секрет отображается в виде маски, а значок **Показать/Скрыть** отсутствует. При этом пользователь может задать новое значение секрета. При установке фокуса на поле ввода старое значение стирается. После того как пользователь ввел и сохранил новое значение, на сервере создается новый экземпляр секрета приложения.
