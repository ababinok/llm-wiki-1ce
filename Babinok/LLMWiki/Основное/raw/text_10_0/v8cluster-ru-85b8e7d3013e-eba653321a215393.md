## Свойства

### ВремяПринудительногоЗавершения

`Доступность: Сервер`

```
ВремяПринудительногоЗавершения: Длительность
```

Время принудительного завершения процесса. Интервал времени, по истечении которого выключенный процесс будет завершен принудительно даже, если еще имеются установленные с ним соединения. Если процесс выключен автоматически по достижении времени перезапуска, то после принудительного завершения процесс будет удален из кластера. Если значение равно `0мс`, то принудительное завершение не выполняется.

---

### ИмяКомпьютера

`Доступность: Сервер`


Имя (символический или IP-адрес) компьютера, на котором расположен реестр кластера и процесс главного менеджера кластера.

---

### ПериодПерезапускаПроцесса

`Доступность: Сервер`

```
ПериодПерезапускаПроцесса: Длительность
```

Интервал времени после запуска процессов, по истечении которого будет выполнен перезапуск рабочих процессов кластера. Если рабочий процесс активен в течение этого времени, то будет выполнен запуск нового процесса, а старый процесс будет выключен. Выключенный процесс будет обслуживать соединения, установленные ранее, не устанавливая при том новых соединений. Если значение равно `0мс`, то перезапуск рабочих процессов не производится.

---
