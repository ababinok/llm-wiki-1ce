## Свойства

### ПереносСтрок

`Доступность: Сервер`

```
ПереносСтрок: ПереносСтрокJson
```

Управляет размещением начала и конца объектов и массивов, ключей и значений на новой строке. Также установка данного свойства в значение, отличное от [Отсутствует](../../wiki/integration/jsonlinebreak-ru-ea09a263d9f1.md), добавляет пробел между именем свойства, двоеточием и значением. Включает использование свойства [СимволыОтступа](../../wiki/integration/jsonwriteroptions-ru-1ea966b35ac8.md)

---

### ПроверятьСтруктуру

`Доступность: Сервер`

```
ПроверятьСтруктуру: Булево
```

Признак проверки правильности структуры записываемого JSON объекта.

---

### СимволыОтступа

`Доступность: Сервер`

```
СимволыОтступа: Строка
```

Символы отступа, используемые при записи документа JSON. Свойство не используется, если свойство [ПереносСтрок](../../wiki/integration/jsonwriteroptions-ru-1ea966b35ac8.md) установлено в значение [Отсутствует](../../wiki/integration/jsonlinebreak-ru-ea09a263d9f1.md).

---

### ЭкранироватьРазделителиСтрокИАбзацев

`Доступность: Сервер`

```
ЭкранироватьРазделителиСтрокИАбзацев: Булево
```

Определяет экранирование символов `"\ю08232"` как "\u2028" (разделитель строк) и `"\ю08233"` как "\u2029" (разделитель абзацев) для совместимости с JavaScript.
