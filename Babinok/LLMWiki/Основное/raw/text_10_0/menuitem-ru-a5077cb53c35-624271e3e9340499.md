`Стд::Интерфейс::ЭлементМеню` `Доступность: КлиентИСервер`

Описывает элемент (пункт) меню. Может содержать внутренние пункты.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Конструкторы

### ЭлементМеню

`Версия 9.0 и выше`

`Доступность: КлиентИСервер`

```
ЭлементМеню(
  Заголовок: Строка,
  Элементы: Массив<ЭлементМеню>,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?,
  ДополнительныеПараметры: Объект?)
```

Создает новый объект

[ЭлементМеню](../../wiki/interface/menuitem-ru-a5077cb53c35.md)

.

---

### ЭлементМеню

`Версия 8.0 и ниже`

`Доступность: КлиентИСервер`

```
ЭлементМеню(
  Заголовок: Строка,
  Элементы: Массив<ЭлементМеню>,
  Изображение: ДвоичныйОбъект.Ссылка?,
  ДополнительныеПараметры: Объект?)
```

Конструктор удален.

---

## Свойства

### ДополнительныеПараметры

`Доступность: КлиентИСервер`

```
ДополнительныеПараметры: Объект?
```

Любые дополнительные данные, связанные с этим пунктом меню. Могут использоваться в обработке события выбора из меню.

---

### Заголовок

`Доступность: КлиентИСервер`

```
Заголовок: Строка
```

Заголовок пункта меню.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: КлиентИСервер`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Картинка пункта меню. Рекомендуется использовать картинки размером 24х24 пикселя.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: КлиентИСервер`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/menuitem-ru-a5077cb53c35.md).

---

### Элементы

`Доступность: КлиентИСервер`

```
Элементы: Массив<ЭлементМеню>
```

Вложенные пункты меню.
