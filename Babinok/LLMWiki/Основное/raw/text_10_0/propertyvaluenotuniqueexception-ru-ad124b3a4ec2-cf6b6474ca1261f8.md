`Стд::Сущности::ИсключениеЗначениеСвойстваНеУникально` `Доступность: Сервер`

Исключение, выбрасываемое при попытке записи сущности с неуникальным значением поля, для которого контролируется уникальность.

Для Справочников это поле Код, для Документов - поле Номер, у которых включен контроль уникальности.
