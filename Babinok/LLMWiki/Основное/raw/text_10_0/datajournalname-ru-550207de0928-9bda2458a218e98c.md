`Версия 10.0 и выше`

Таблица [журнала данных](../../wiki/project/data-journal-project-element-7531ea42bb4a.md). Таблица содержит записи, соответствующие данным сущностей, входящих в состав журнала. Одна запись таблицы представляет собой один элемент справочника или один документ.

---

## Примеры

Пример запроса к таблице журнала данных **ЖурналТорговыхДокументов**:

```xbql
ВЫБРАТЬ
    Журнал.Дата КАК Дата,
    Журнал.КлючЗаписи КАК КлючЗаписи,
    Журнал.Тип КАК Тип,
    Журнал.Склад КАК Склад,
    Журнал.Информация КАК Информация
ИЗ
    ЖурналТорговыхДокументов КАК Журнал
```

---

## Поля

### {ИмяКолонки}

```
{ИмяКолонки}: ТипКолонки
```

Значение реквизита сущности, соответствующего колонке журнала.

Может принимать значение `Неопределено`, если для сущности, входящей в журнал, не указан соответствующий колонке реквизит.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяДокумента.Ссылка|ИмяСправочника.Ссылка|?
```

Ссылка на сущность, входящую в журнал.

---

### ПометкаУдаления

```
ПометкаУдаления: Булево
```

Пометка удаления сущности, входящей в журнал.

---

### Тип

`Вычисляемое поле`

```
Тип: Тип
```

Тип ссылки на сущность, входящую в журнал.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяЖурналаДанных.КлючЗаписи
```

Структура с одним полем **Ссылка**, которое содержит ссылку на сущность, входящую в журнал.
