`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений` `Доступность: Сервер`

Представляет собой структуру с измерениями указанными в настройке `РасчетРазрешенийПо` элемента проекта. Используется при расчёте ключей доступа для объектов регистра накопления - при реализации обработчика `ВычислитьКлючиДоступаДляИзменения` [ВычислитьКлючиДоступаДляИзменения](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md). Доступен только если включено управление доступом для отдельных объектов регистра.

## Конструкторы

### {ИмяРегистраНакопления}.ДанныеРасчетаРазрешений

`Доступность: Сервер`

```
{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений(Запись: <ТипЗаписи>)
```

Конструктор из записи. Создаёт данные для расчета разрешений со значениями измерений, необходимых для расчета разрешений доступа (тех измерений, что указаны в настройке

`РасчетРазрешенийПо`

), равными значениям измерений в переданной записи.
