# Изменить форму аутентификации для приложения

Когда пользователи переходят в приложение по главной ссылке, для них отображается **основная форма аутентификации**. По умолчанию эта форма содержит все способы входа, доступные пользователям из подключенных к приложению списков пользователей. Например, если к приложению подключены два списка пользователей, один из которых поддерживает вход по логину и паролю, а второй — с помощью [сервисов внешних учетных записей](https://1cmycloud.com/console/help/element/10.0/docs/topics/external-account-services/), то форма аутентификации будет иметь следующий вид:

Основная форма «Вход в систему» содержит поля «Логин» и «Пароль», «Забыли пароль?» и жёлтую кнопку «Войти». [Описание иллюстрации](../figures/129970af24bd72a524e9a83a650e88657031624619c7ffd7b158a8981ef63e22-de2c3502417116e9.md)

«1С:Предприятие.Элемент» позволяет вам изменить форму аутентификации в соответствии с вашими потребностями. Для этого выполните описанные ниже действия.

> [!NOTE] дополнительно
> Редактирование формы аутентификации доступно только администраторам панели управления и администраторам приложения.

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Приложения** нажмите на приложение, для которого вы хотите изменить форму аутентификации.
3. Переключитесь на вкладку **Формы аутентификации**, чтобы открыть макет формы.
  
  Выбор вкладки «Формы аутентификации» [Описание иллюстрации](../figures/953eb06679b631252f80880b11d37fb157c7b93f25dc45d7f079e4935f784906-611d56b1a22bde0b.md)
4. Нажмите кнопку **Редактировать**, чтобы изменить содержимое формы. Вы можете выполнить следующие действия:
  
  - Изменить порядок способов входа с помощью стрелок вверх/вниз. Способ входа в начале списка считается приоритетным.
    
    Способы входа, которые не поместились на форме, отображаются в выпадающем списке **Другие способы**.
    
    Редактор формы аутентификации: слева список и порядок способов входа, справа предварительный просмотр; не поместившиеся способы входа доступны через «Другие способы». [Описание иллюстрации](../figures/decbbdcf12426993376b499d4637b03063161a9f569fc7783ab9852a056504c9-f6f9db442a50a471.md)
  - Скрыть какие-либо способы входа, переместив их на вкладку **Неиспользуемые способы входа**. После этого они перестанут отображаться в форме аутентификации пользователя.
    
    В редакторе формы аутентификации есть вкладки «Используемые способы входа» и «Неиспользуемые способы входа». [Описание иллюстрации](../figures/752909eec0149f6e35de903efa73a5c9f57fe28730aef7cdfd48f73358039b6e-6c76cce2fa8fa649.md)
5. В окне предварительного просмотра отображаются все изменения, применяемые к форме. Чтобы сохранить их, нажмите кнопку **Сохранить**.
  
  Редактор формы входа показывает слева «Используемые способы входа», справа предварительный просмотр. [Описание иллюстрации](../figures/0a9111eafc4c764a14c0aa664caab7b1b8a535710d06673a4e5a4b5c7c56ff0d-6e0bf0ca49143a08.md)
