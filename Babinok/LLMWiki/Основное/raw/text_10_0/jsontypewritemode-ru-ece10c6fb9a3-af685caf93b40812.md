### НеЗаписывать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеЗаписывать
```

Не записывать информацию о типе для записываемых значений.

---

### ЗаписыватьВсегда

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ЗаписыватьВсегда
```

Всегда записывать информацию о типе для записываемых значений.

---

### ЗаписыватьПриНеоднозначности

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ЗаписыватьПриНеоднозначности
```

Записывать информацию о типе, когда записываемое значение может принимать значения нескольких типов. Например, если в объявлении поля структуры указано несколько типов или тип "скрыт" за полиморфным.
