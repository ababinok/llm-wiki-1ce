`Стд::Интерфейс::ОбщиеКомпоненты::Картинка` `Доступность: Клиент`

Компонент, позволяющий отображать картинки разных форматов, в том числе SVG. Чтобы цвет SVG-картинки был изменяемым, она должна содержать элементы, использующие в качестве цвета значение "currentColor". К этим элементам и будет применен цвет, задаваемый через свойства [ОценкаИнформации](../../wiki/interface/picture-ru-efed61d49ad9.md) и [Цвет](../../wiki/interface/picture-ru-efed61d49ad9.md).

## Свойства

### АдаптацияКЦветуКонтейнера

`Доступность: Клиент`

```
АдаптацияКЦветуКонтейнера: Авто|Булево
```

Определяет, будет ли иконка адаптироваться к цвету контейнера или нет. При [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) - подстраивать цвет иконки под цвет контейнера если иконка одноцветная.

---

### АльтернативныйТекст

`Доступность: Клиент`

```
АльтернативныйТекст: Авто|Строка
```

Задает произвольное описание Картинки, которое будет применено в атрибут, отвечающий за альтернативный текст такой картинки в разметке страницы. Используется для оптимизации поисковой выдачи в сети Интернет и вспомогательным инструментом для людей с ограниченным возможностями.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) смотрит на свойство [Подсказка](../../wiki/interface/picture-ru-efed61d49ad9.md). Если оно заполнено – использует его. Иначе – пустая строка.

---

### Масштабирование

`Доступность: Клиент`

```
Масштабирование: Авто|МасштабированиеИзображения
```

Определяет, как будет вычисляться размер картинки при несовпадении реального ее размера и размеров, указанных разработчиком.

---

### ОбрабатыватьНажатие

`Доступность: Клиент`

```
ОбрабатыватьНажатие: Авто|Булево
```

Указывает - является ли картинка нажимаемой:

- [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  - разыменуется в
  
  `Истина`
  
  , если будет выполнено одно из условий:
  
  - свойство
    
    [Ссылка](../../wiki/interface/picture-ru-efed61d49ad9.md)
    
    заполнено
  - задан обработчик события
    
    [ПриНажатии](../../wiki/interface/picture-ru-efed61d49ad9.md)
- `Истина`
  
  - картинка обрабатывает нажатие (вызывается событие
  
  [ПриНажатии](../../wiki/interface/picture-ru-efed61d49ad9.md)
  
  ), может принимать фокус.
- `Ложь`
  
  - картинка не обрабатывает нажатие, не принимает фокус. Нажатие обрабатывается родительскими компонентами.

`Доступность: Клиент`

### ОтображатьПодсказку

`Версия 9.0 и выше`

`Доступность: Клиент`

```
ОтображатьПодсказку: Авто|ОтображениеПодсказки
```

Управляет видимостью всплывающей подсказки. При [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) - подсказка показывается при наведении, если задан текст подсказки (свойство [Подсказка](../../wiki/interface/picture-ru-efed61d49ad9.md)).

---

### ОценкаИнформации

`Доступность: Клиент`

```
ОценкаИнформации: Авто|ОценкаИнформации
```

Оценка информации картинки. Применяется только для поддерживаемых картинок - правильно оформленных SVG.

---

### Подсказка

`Доступность: Клиент`

```
Подсказка: Авто|Строка
```

Текст подсказки, который отображается при наведении на картинку.

---

### Ссылка

`Доступность: Клиент`

```
Ссылка: Сущность.Ключ|Строка|?
```

Ссылка, которая откроется при нажатии на картинку. Стандартная обработка открывает ссылку в зависимости от ее типа.

---

### Фигура

`Доступность: Клиент`

```
Фигура: Авто|Фигура
```

Определяет фигуру картинки.

---

### Цвет

`Доступность: Клиент`

```
Цвет: Авто|Цвет
```

Задает цвет отображения картинки. Применяется только для поддерживаемых картинок - правильно оформленных SVG.

---

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  Картинка,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на картинку, если свойство [ОбрабатыватьНажатие](../../wiki/interface/picture-ru-efed61d49ad9.md) = `Истина`. Если обработчик установил событию [СтандартнаяОбработка](../../wiki/interface/onclickevent-ru-15fc28e42f99.md) = `Ложь`, то стандартной обработки нажатия на ссылку не происходит.
