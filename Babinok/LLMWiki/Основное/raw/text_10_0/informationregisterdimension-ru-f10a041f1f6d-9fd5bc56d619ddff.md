Значение (например, товар, склад, валюта), для которого в регистре сведений хранится некоторая информация.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](../../wiki/project/displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [Обычная](../../wiki/project/displayimportance-ru-469c555fd91c.md).

---

#### Тип

```yaml
Тип: Тип[]
```

Тип реквизита.

---

#### ДлинаЦелойЧасти

```yaml
ДлинаЦелойЧасти: Число
```

Максимально допустимая длина целой части числа.

---

#### МаксимальнаяДлина

```yaml
МаксимальнаяДлина: Число
```

Максимально допустимая длина строки.

---

#### ЗначениеПоУмолчанию

```yaml
ЗначениеПоУмолчанию: Объект
```

Значение реквизита по умолчанию.

---

#### НезаполненноеЗначение

```yaml
НезаполненноеЗначение: ПолитикаПроверки
```

Определяет политику проверки пустого значения элемента.

---

#### Ведущее

```yaml
Ведущее: Булево
```

Используется для автоматического удаления записи из регистра сведений при удалении соответствующего объекта из базы данных. Данное свойство следует использовать в том случае, когда типом измерения является ссылка на объект базы данных (например, элемент справочника).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных этого реквизита для использования в [полнотекстовом поиске](../../wiki/project/full-text-search-99b98022003a.md). Значение по умолчанию — **Истина**.

---

#### ДлинаДробнойЧасти

```yaml
ДлинаДробнойЧасти: Число
```

Максимально допустимая длина дробной части числа.

---

#### МаксимальноеЗначение

```yaml
МаксимальноеЗначение: Число
```

Максимально допустимое значение числа.

---

#### МинимальноеЗначение

```yaml
МинимальноеЗначение: Число
```

Минимально допустимое значение числа.

---

#### КонтрольПредельныхЗначений

```yaml
КонтрольПредельныхЗначений: КонтрольДлины
```

Указывает, как осуществлять контроль предельных значений числа:

- [ВыдаватьОшибку](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  ,
- [Исправлять](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  .

---

#### КонтрольДробнойЧасти

```yaml
КонтрольДробнойЧасти: КонтрольДлины
```

Указывает, как осуществлять контроль дробной части числа:

- [ВыдаватьОшибку](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  ,
- [Исправлять](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  .

---

#### Многострочная

```yaml
Многострочная: Булево
```

Указывает, является ли строка многострочной.

---

#### КонтрольДлины

```yaml
КонтрольДлины: КонтрольДлины
```

Способы контроля длины.

---

#### ИспользоватьВОсновномФильтре

```yaml
ИспользоватьВОсновномФильтре: Булево
```

Признак включения измерения в [основной фильтр](../../wiki/project/main-filter-18aefc9ef008.md) регистра сведений. Значение по умолчанию — `Истина`.

---

#### ЗаполнятьПриКопировании

```yaml
ЗаполнятьПриКопировании: Булево
```

Свойство определяет, заполнять ли элемент при копировании.

---

#### ОграниченияЭлементов

```yaml
ОграниченияЭлементов: 
    НезаполненноеЗначение: ПолитикаПроверки
    ДлинаЦелойЧасти: Число
    ДлинаДробнойЧасти: Число

    Многострочная: Булево

```
