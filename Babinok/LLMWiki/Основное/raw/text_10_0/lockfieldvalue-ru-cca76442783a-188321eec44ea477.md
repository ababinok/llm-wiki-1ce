## Свойства

### Значение

`Доступность: Сервер` `ТолькоЧтение`

```
Значение: ТипПоля
```

Значение поля, по которому требуется блокировать.

---

### Использование

`Доступность: Сервер` `ТолькоЧтение`

```
Использование: Булево
```

Использовать ли значение поля. `Истина` - значение поля используется, т.е. является частью спецификации блокировки. `Ложь` - значение поля не используется, т.е. не является частью спецификации блокировки.
