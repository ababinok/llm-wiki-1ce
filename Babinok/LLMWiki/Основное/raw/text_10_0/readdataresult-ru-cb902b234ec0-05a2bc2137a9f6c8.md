`Стд::ВводВывод::РезультатЧтенияДанных` `Доступность: Сервер`

Используется для сохранения прочитанных данных и дальнейших операций с ними. Объект может работать со значительными объемами данных. Прочитанные данные не хранятся в оперативной памяти, а передаются в хранилище (временный файл на диске, хранилище данных, и т. д.).

## Свойства

### ИндексМаркера

`Доступность: Сервер` `ТолькоЧтение`

```
ИндексМаркера: Число
```

Индекс найденного маркера. Если маркер не найден или операция не предполагает поиска маркера, значение свойства будет равно `-1`.

---

### МаркерНайден

`Доступность: Сервер` `ТолькоЧтение`

```
МаркерНайден: Булево
```

Признак обнаружения маркера:

- `Истина`
  
  - если в процессе чтения данных был обнаружен маркер.
- `Ложь`
  
  - если маркер не был найден или операция не предполагала поиска маркера.

---

### Размер

`Доступность: Сервер` `ТолькоЧтение`

```
Размер: РазмерБайтов
```

Размер данных. Может быть равен нулю, например, при чтении двоичных данных из конца потока.

---

## Методы

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

Закрывает поток, очищает ресурсы, связанные с данным объектом.

**Переопределение** [Закрываемое::Закрыть](../../wiki/stdlib/closeable-ru-67cd73fca69d.md)

---

### ОткрытьПотокЧтения

`Доступность: Сервер`

```
ОткрытьПотокЧтения(): ПотокЧтения
```

Открывает поток для чтения данных из объекта.

---

### ПолучитьБайты

`Доступность: Сервер`

```
ПолучитьБайты(): Байты
```

Возвращает результат чтения в виде байтов.
