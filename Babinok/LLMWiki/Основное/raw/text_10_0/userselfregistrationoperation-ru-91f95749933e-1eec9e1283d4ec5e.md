## Методы

### Завершить

`Доступность: Клиент`

```
Завершить(СсылкаПослеРегистрации: Строка? = Неопределено): СтатусПодтверждаемойОперацииСамообслуживания
```

Завершить операцию самостоятельной регистрации пользователя. В случае успешного завершения пользователь становится авторизованным в приложение. Если указана

`СсылкаПослеРегистрации`

, то выполняется переход по указанной ссылке.

---

### Начать

`Доступность: Клиент`

```
Начать(
  ПоставщикАутентификации: ПоставщикАутентификации,
  Параметр: ПараметрСамостоятельнойРегистрацииПользователя? = Неопределено
): СтатусПодтверждаемойОперацииСамообслуживания
```

Начать операцию самостоятельной регистрации пользователя используя внешнюю учетную запись пользователя.

**Перегрузка** [Начать(Логин: Строка, Пароль: Строка, СпособПодтверждения: СпособПодтвержденияОперации, КонтактПодтверждения: Строка, Параметр: ПараметрСамостоятельнойРегистрацииПользователя? = Неопределено): СтатусПодтверждаемойОперацииСамообслуживания](../../wiki/data/userselfregistrationoperation-ru-91f95749933e.md)

### Начать

`Доступность: Клиент`

```
Начать(
  Логин: Строка,
  Пароль: Строка,
  СпособПодтверждения: СпособПодтвержденияОперации,
  КонтактПодтверждения: Строка,
  Параметр: ПараметрСамостоятельнойРегистрацииПользователя? = Неопределено
): СтатусПодтверждаемойОперацииСамообслуживания
```

Начать операцию самостоятельной регистрации пользователя используя локальную учетную запись.

**Перегрузка** [Начать(ПоставщикАутентификации: ПоставщикАутентификации, Параметр: ПараметрСамостоятельнойРегистрацииПользователя? = Неопределено): СтатусПодтверждаемойОперацииСамообслуживания](../../wiki/data/userselfregistrationoperation-ru-91f95749933e.md)

### ОтправитьПодтверждение

`Доступность: Клиент`

```
ОтправитьПодтверждение(Значение: Строка): СтатусПодтверждаемойОперацииСамообслуживания
```

Отправить код подтверждения. Если превышено количество попыток отправить код подтверждения, то будет возвращена неуспешный статус операции.

---

### ПовторитьОтправкуКодаПодтверждения

`Доступность: Клиент`

```
ПовторитьОтправкуКодаПодтверждения(): СтатусПодтверждаемойОперацииСамообслуживания
```

Повторить отправку кода подтверждения. Если превышено количество попыток отправить код подтверждения, то будет возвращена неуспешный статус операции.
