Структурное

## Конструкторы

### ЭлементФильтраВыражение

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ЭлементФильтраВыражение(
  Выражение: Строка,
  Использовать: Булево,
  ОтображатьВНастройках: Авто|ВидОтображенияФильтра,
  Представление: Авто|Строка)
```

Создает элемент фильтра с указанными значениями полей.

---

### ЭлементФильтраВыражение

`Версия 9.0 и ниже`

`Доступность: КлиентИСервер`

```
ЭлементФильтраВыражение(
  Выражение: Строка,
  Использовать: Булево)
```

Конструктор удален.

---

## Свойства

### Выражение

`Доступность: КлиентИСервер`

```
Выражение: Строка
```

Логическое выражение на языке запроса.

---

### Использовать

`Доступность: КлиентИСервер`

```
Использовать: Булево
```

Признак использования данного элемента фильтра для фильтрации выборки. Может использоваться для включения выключения отдельных элементов фильтра.

---

### ОтображатьВНастройках

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВНастройках: Авто|ВидОтображенияФильтра
```

Включает отображение описанного фильтра в интерфейс настроек.

Такая настройка влияет на свойство [Использовать](../../wiki/interface/filteritemexpression-ru-2253b5a4a6ee.md), связанного с ней фильтра.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[НеОтображать](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).

---

### Представление

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
Представление: Авто|Строка
```

Задает представление фильтра в интерфейсе.
