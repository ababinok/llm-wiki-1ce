`Версия 9.0 и выше`

`Стд::Интерфейс::Группы::НастройкиКомпоновкиБенто` `Доступность: КлиентИСервер`

Содержит настройки компоновки бенто-сетки, такие как разрешение изменения порядка содержимого при позиционировании.

Группа бенто определяет размеры элементов содержимого в колонках и строках стандартной сетки. После этого алгоритм позиционирует элементы содержимого, учитывая их размер.

[РазрешитьИзменениеПорядка](../../wiki/interface/bentolayoutsettings-ru-b9947312a61f.md) указывает, какой из двух подходов стоит использовать при позиционировании:

1. Наиболее компактно (для этого может быть нужно изменить порядок элементов)
2. По порядку, в котором они указаны в содержимом:
  
  - [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
    
    — подход 1,
  - `Истина`
    
    — подход 1,
  - `Ложь`
    
    — подход 2.

Порядок при компоновке определяется слева направо, сверху вниз.

[РазрешитьРастягиваниеЭлементов](../../wiki/interface/bentolayoutsettings-ru-b9947312a61f.md) указывает, может ли бенто-сетка растягивать дочерние элементы больше максимальных размеров для устранения пустот:

- `Истина`
  
  — дочерние элементы позиционируются со своими размерами и при необходимости могут быть растянуты (даже больше максимальных размеров) для устранения пустот;
- `Ложь`
  
  — дочерние элементы позиционируются со своими размерами и после этого не растягиваются;
- [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  — поведение аналогично
  
  `Ложь`
  
  .

Порядок при компоновке определяется слева направо, сверху вниз.

## Конструкторы

### НастройкиКомпоновкиБенто

`Доступность: КлиентИСервер`

```
НастройкиКомпоновкиБенто(
  РазрешитьИзменениеПорядка: Авто|Булево,
  РазрешитьРастягиваниеЭлементов: Авто|Булево)
```

Создает компонент со значениями свойств, соответствующими параметрам конструктора.

## Свойства

### РазрешитьИзменениеПорядка

`Доступность: КлиентИСервер`

```
РазрешитьИзменениеПорядка: Авто|Булево
```

Определяет, какой подход будет использоваться при позиционировании элементов содержимого:

- `Истина`
  
  — порядок элементов может быть изменен,
- `Ложь`
  
  — порядок элементов не может быть изменен,
- [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  — поведение аналогично
  
  `Истина`
  
  .

---

РазрешитьРастягиваниеЭлементов: Авто|Булево

Определяет, может ли бенто-сетка растягивать дочерние элементы больше максимальных размеров для устранения пустот:
