Данные элемента SOAP-запроса или SOAP-ответа [ЭлементSoap](../../wiki/integration/soapelement-ru-2e11ea4af034.md), не определенного в XSD-схеме.

## Конструкторы

### ДанныеЭлементаSoap

`Доступность: Сервер`

```
ДанныеЭлементаSoap(
  Атрибуты: ЧитаемоеСоответствие<КвалифицированноеИмяXml, Строка>,
  Содержимое: ЧитаемыйМассив<ЭлементSoap|Строка>)
```

Создает объект с атрибутами

`Атрибуты`

и содержимым

`Содержимое`

. Содержимое может включать дочерние элементы в виде объектов типа

[ЭлементSoap](../../wiki/integration/soapelement-ru-2e11ea4af034.md)

, текст элемента в виде объекта типа

[Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)

.

---

## Свойства

### Атрибуты

`Доступность: Сервер` `ТолькоЧтение`

```
Атрибуты: ЧитаемоеСоответствие<КвалифицированноеИмяXml, Строка>
```

Атрибуты элемента, ключ соответствия - имя атрибута, значение соответствия - значение атрибута.

---

### Содержимое

`Доступность: Сервер` `ТолькоЧтение`

```
Содержимое: ЧитаемыйМассив<ЭлементSoap|Строка>
```

Содержимое элемента. Содержимое может включать дочерние элементы в виде объектов типа [ЭлементSoap](../../wiki/integration/soapelement-ru-2e11ea4af034.md), текст элемента в виде объекта типа [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md).
