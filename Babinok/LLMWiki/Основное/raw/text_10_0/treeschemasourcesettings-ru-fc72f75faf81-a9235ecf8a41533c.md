`Стд::Интерфейс::ГрафическиеСхемы::НастройкиИсточникаДревовиднойСхемы<ТипДанных>` `Доступность: Клиент`

Описывает настройки для автоматического заполнения древовидной схемы по данным в источнике данных. Схема будет использовать указанное описание для запроса данных элементов каждого уровня. Первым запросом будет запрос с добавленным фильтром `Родитель` == `Неопределено`, при раскрытии уровня, будет добавлен фильтр `Родитель` == `РаскрываемыйЭлемент`, и т.д.

## Конструкторы

### НастройкиИсточникаДревовиднойСхемы

`Доступность: Клиент`

```
НастройкиИсточникаДревовиднойСхемы()
```

Создает объект настроек источника данных древовидной схемы.

---

## Свойства

### ПолеРодителя

`Доступность: Клиент`

```
ПолеРодителя: Строка
```

Задает поле, используемое для связи элементов схемы. Должно присутствовать в источнике данных.

---

### Элемент

`Доступность: Клиент`

```
Элемент: ЭлементОрганиграммы?
```

Задает описание элемента схемы. Если свойство элемента задается вычисляемым выражением, то в него передается параметр `ДанныеЭлемента`.
