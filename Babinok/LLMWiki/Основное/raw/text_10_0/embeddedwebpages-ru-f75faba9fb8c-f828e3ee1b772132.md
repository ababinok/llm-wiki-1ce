## Свойства

### АктивнаяВебСтраница

`Доступность: Клиент`

```
АктивнаяВебСтраница: ВстроеннаяВебСтраница?
```

Возвращается встроенную веб-страницу, которая активна (видна в рабочей области) в данный момент.

---

### ВебСтраницы

`Доступность: Клиент`

```
ВебСтраницы: Массив<ВстроеннаяВебСтраница>
```

Возвращает все зарегистрированные встроенные веб-страницы

---

## Методы

### ЗагрузитьВебСтраницу

`Доступность: Клиент`

```
ЗагрузитьВебСтраницу(
  Ид: Строка,
  Url: Строка?
): Булево
```

Запускает встроенную веб-страницу. Блокирует поток вызова до завершения запуска. При успешном запуске возвращает

`Истина`

Параметры:

- `Ид`
  
  - уникальный идентификатор встроенной веб-страницы.
- `Url`
  
  - адрес встроенной веб-страницы. Если значение не указано, то страница запускается с адресом, указанным в свойстве Url встроенной веб-страницы. Если значение параметра указано, то приложение запускается именно по этому адресу.

---

### ПолучитьВебСтраницу

`Доступность: Клиент`

```
ПолучитьВебСтраницу(Ид: Строка): ВстроеннаяВебСтраница?
```

Производит поиск встроенной веб-страницы по её идентификатору, возвращает объект

[ВстроеннаяВебСтраница](../../wiki/interface/embeddedwebpage-ru-948b3b8bf499.md)

или Неопределено, если страница не найдена.

Параметры:

- `Ид`
  
  - уникальный идентификатор встроенной веб-страницы, назначаемый разработчиком.
