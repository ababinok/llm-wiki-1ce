Для получения кода активации используйте метод [`УправлениеПриложениямиВзаимодействия.ЗапроситьКодАктивации()`](../../wiki/integration/collaborationapplicationsmanagement-ru-437d8f88f8c5.md).

В методе укажите адрес электронной почты пользователя, который создает приложение. На указанный адрес будет отправлен код, который необходимо использовать при [создании](../../wiki/integration/collaboration-system-working-with-apps-990779602d1e.md) приложения.

Вы также можете использовать [стандартную функцию](https://its.1c.ru/db/v8324doc#bookmark:adm:TI000000169) «Управление системой взаимодействия» для получения кода активации.
