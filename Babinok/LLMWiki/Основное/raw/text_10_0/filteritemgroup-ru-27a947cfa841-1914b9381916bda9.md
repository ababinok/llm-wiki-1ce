`Стд::Интерфейс::Фильтры::ГруппаЭлементовФильтра` `Доступность: КлиентИСервер`

Группа элементов фильтра. Содержит коллекцию элементов фильтра и вид объединения по И/ИЛИ. Может содержать вложенные группы фильтров. Позволяет делать сложные фильтры с различными логическими И/ИЛИ.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Конструкторы

### ГруппаЭлементовФильтра

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ГруппаЭлементовФильтра(
  ВидГруппы: ВидГруппыЭлементовФильтра,
  Элементы: Массив<ЭлементФильтра|ЭлементФильтраВыражение|ЭлементФильтраПоляКоллекция|ГруппаЭлементовФильтра>,
  Использовать: Булево,
  ОтображатьВНастройках: Авто|ВидОтображенияФильтра,
  Представление: Авто|Строка)
```

Создает группу элементов фильтра со значениями полей по умолчанию.

## Свойства

### ВидГруппы

`Доступность: КлиентИСервер`

```
ВидГруппы: ВидГруппыЭлементовФильтра
```

Вид группы элементов фильтра. Указывает логическую операцию, по которой объединяются условия. Если указаны значения [ГруппаНеИ](../../wiki/interface/filteritemgroupkind-ru-cd2e5290861b.md) или [ГруппаНеИли](../../wiki/interface/filteritemgroupkind-ru-cd2e5290861b.md), то это означает что вся группа условий предваряется операцией НЕ.

---

### Использовать

`Доступность: КлиентИСервер`

```
Использовать: Булево
```

Признак использования данного элемента фильтра для фильтрации выборки. Может использоваться для включения выключения отдельных групп фильтра.

---

### ОтображатьВНастройках

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВНастройках: Авто|ВидОтображенияФильтра
```

Включает отображение описанной группы элементов фильтра в интерфейс настроек.

Такая настройка влияет на свойство [Использовать](../../wiki/interface/filteritemgroup-ru-27a947cfa841.md), связанной с ней группы фильтров.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[НеОтображать](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).

---

### Представление

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
Представление: Авто|Строка
```

Задает представление группы фильтров в интерфейсе.
