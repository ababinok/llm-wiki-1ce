[SOAP-сервис](../../wiki/integration/soap-web-service-6fc6a00d4cc7.md) позволяет «1С:Предприятие.Элементу» обрабатывать входящие SOAP-запросы, поступающие от внешних информационных систем. Например, процесс интеграции может быть настроен следующим образом: внешняя система отправляет сообщение по протоколу SOAP в «1С:Предприятие.Элемент», после чего в SOAP-сервисе «1С:Предприятие.Элемента» вызывается [обработчик](../../wiki/queries/request-processing-ed6518881396.md), который данное сообщение обрабатывает и передает дальше в узел вида **ПрограммныйИсточник**. Сама схема процесса интеграции может выглядеть следующим образом:

Схема процесса интеграции [Описание иллюстрации](../figures/ecc1e7e9a5635eac8bcd05c7a4be973022236f66846fc45374db78a345fda48c-5bbb84cf436675a1.md)

Чтобы создать новый SOAP-сервис, можно нажать на значок плюса рядом с подсистемой **Основной** и затем выбрать **SOAP-сервис**:

В навигаторе проекта рядом с подсистемой «Основной» выделена кнопка плюса для добавления SOAP-сервиса. [Описание иллюстрации](../figures/46e6964ee90f63186d82bb57ab3952e711f61de4cd826ba8b3831aee7871f169-fc3e0bb850d0a51c.md)

В окне добавления элемента проекта выбран «SOAP-сервис». [Описание иллюстрации](../figures/fb495800268666b40c3d6f94e0ff933788a07b3b8546092c12eec8d5d5ef77d5-5179dbcbe40a3605.md)

После чего следует задать имя SOAP-сервиса и нажать **Ввод**. В структуре проекта отобразится новый SOAP-сервис:

Новый элемент проекта «SOAP-сервис» [Описание иллюстрации](../figures/ce94cc3bf0d3ccbc553702d674e670043781aeb066f6f16236f1144ef9016793-4c4eb791eaf4f661.md)

В панели **Свойства** следует задать два обязательных свойства: [**КорневойUrl**](../../wiki/integration/soapservice-33331940c1db.md) и [**ПространствоИменСервиса**](../../wiki/integration/soapservice-33331940c1db.md):

В свойствах SOAP-сервиса выделены обязательные КорневойUrl и ПространствоИменСервиса. [Описание иллюстрации](../figures/4e0b49b1e1b2cafca7275f63a54253672fc4f2343f12b8526741e643ff9d70c2-0117d8d08845cd44.md)

Затем необходимо добавить обработчик. Для этого нажмите на значок плюса напротив пункта **Обработчики**:

В навигаторе проекта раскрыт SOAP-сервис «SoapСервисШины». [Описание иллюстрации](../figures/0504b4d53658d9e2eccb40572111229065c59475c2ae0d18959d353cea68514d-b430c36cdfd36856.md)

Задайте имя обработчика и нажмите **Ввод**.

> [!NOTE] примечание
> Имя обработчика не может содержать кириллицы и пробельных символов.

Если не задать имя вручную, то оно будет сгенерировано автоматически с использованием следующих схем:

- [Обработчик](../../wiki/integration/servicehandler-ru-d99b0889159b.md):
  
  - `ИмяОбработчика + «Обработчик»`
- [Контроль доступа](../../wiki/integration/servicehandler-ru-d99b0889159b.md) обработчика:
  
  - `ИмяОбработчика + «КонтрольДоступаОбработчика»`

Созданный вами обработчик отобразится во вкладке **Обработчики**:

В дереве проекта раскрыт SoapСервисШины → Обработчики. Новый обработчик messages отображается дочерней строкой во вкладке Обработчики. Соответствующая строка выделена рамкой; это результат создания обработчика в учебном примере. [Описание иллюстрации](../figures/d537c844c056d82d6aa854e10a39e256217e794ca39165e00bae1377896aabde-b07ac2e70de3fe75.md)

Следующим шагом следует задать метод для обработчика. Для этого в свойствах созданного вами обработчика в поле **Метод** введите имя метода и нажмите на значок плюса:

В настройках SOAP-обработчика messages поле разрешения = «РазрешеноАдминистраторам». [Описание иллюстрации](../figures/6ebdf1ae0c6b7c472b76d37054f3582c6287761133a6ea456c24c33c936c063e-dbeca76acf58a1c5.md)

Откроется модуль SOAP-сервиса, в котором автоматически будет создан метод с заданным вами названием. Впишите в тело метода следующий код:

```xbsl
метод ПередатьДанныеВШину(Данные: Байты)
    исп Тело = новый ВременныйПотокЗаписи()
    Тело.Записать(Данные)
    знч Сообщение = новый СообщениеИнтеграции({:}, Тело.ОткрытьПотокЧтения())
    ОбменСSoap.ОтправитьСообщениеВУзлы(Сообщение, ОбменСSoap.Схема.Узлы.ИзSoapВШину)
;
```

При вызове клиентом операции **messages** SOAP-сервиса «1С:Предприятие.Элемента», будет выполняться метод `ПередатьДанныеВШину()`. Данные, которые необходимо отправить в «1С:Предприятие.Элемент», будут передаваться клиентом в параметре **Данные**. Из полученных данных будет сформировано сообщение интеграции, которое затем отправится в узел вида **ПрограммныйИсточник**.

В свойствах SOAP-сервиса в поле **Контроль доступа** также есть возможность указать пользователей, которым будет доступен вызов этого сервиса:

В панели свойств «SoapСервисШины» выделен «КонтрольДоступа»: для «ПоУмолчанию» и «Вызов» выбрано «РазрешеноАдминистраторам». [Описание иллюстрации](../figures/02f1dd0b3e04166782348eb3bfd723d01e8b08183056e68a697f14e6a5c7cc61-1d6ea6341a75995a.md)

Для того чтобы отправить сообщение в SOAP-сервис «1С:Предприятие.Элемента», вам следует вызвать операцию **messages** из клиента сервиса и передать необходимые данные в параметре **Данные** (в «1С:Предприятие.Элементе» вы также можете создать [клиент SOAP-сервиса](../../wiki/integration/soap-web-service-client-e79277c8f091.md)). SOAP-запросы к данному сервису будут обрабатываться по пути:

```text
http://[адрес сервера]/applications/[имя приложения]/api/esbservice
```
