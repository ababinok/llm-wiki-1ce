Локализация приложения позволяет пользователю видеть надписи в интерфейсе приложения на том языке, который он использует для работы ([порядок определения языка локализации](../../wiki/project/app-localization-15f5b1317f82.md)).

Локализованные строки могут использоваться в таких элементах, как:

- команды меню;
- заголовки кнопок, полей, переключателей и т. д.;
- строки, формируемые в коде.

Полный список компонентов, поддерживающих подстановку локализованных строк, можно посмотреть [здесь](../../wiki/interface/components-with-localization-support-4153919eea00.md).

## Языки локализации и язык по умолчанию

Чтобы локализация приложения стала возможной, в элементе [Описание проекта](../../wiki/project/update-app-data-356eca7811d0.md) должны быть заданы языки локализации и один из них должен быть указан как язык по умолчанию. Например:

В свойствах проекта «ЯзыкиЛокализации» содержит «Русский» и «English». [Описание иллюстрации](../figures/1709c7f2af04373996081cb989ca784ec154edf701bbc5e71c5bbe65c5007b2d-f7106c4258fbc2dd.md)

Пример YAML-файла элемента «Описание проекта»

```yaml
Ид: 0195ec77-ce86-73ba-aecc-4d840e00d78f
Версия: 1.0
Имя: ПримерЛокализации
Поставщик: e1c
Представление: Пример локализации
ПредставлениеПоставщика: e1c
РежимСовместимости: 9.0
ЯзыкРазработки: Русский
ЯзыкПоУмолчанию: Русский
ЯзыкиЛокализации:
    - Русский
    - Английский
```

Если не указать ни одного языка, это будет означать, что проект не нуждается в локализации. В качестве языков локализации можно выбрать только значения перечисления [`Язык`](../../wiki/stdlib/language-ru-16b63462a511.md). На данный момент поддерживаются русский, английский, китайский, вьетнамский и таджикский языки.

## Элемент проекта вида «ЛокализованныеСтроки»

Используйте элемент проекта вида **ЛокализованныеСтроки** для хранения строк, которые должны быть переведены на другие языки. Данный элемент проекта содержит ключи (идентификаторы) локализуемых строк и их значения на [языке по умолчанию](../../wiki/project/app-localization-15f5b1317f82.md). Блоки идентификаторов разделены на две секции:

- **Строки**
  
  Строки можно использовать в описании компонентов интерфейса и элементов проекта, а также в коде.
- **Шаблоны**
  
  Шаблоны можно использовать только в коде. В них можно подставлять значения переменных.

Пример:

ЛокализованныеСтроки.yaml

```yaml
ВидЭлемента: ЛокализованныеСтроки
Ид: d0adc076-d030-4546-bd1a-8b497668b0fc
Имя: ЛокализованныеСтроки
ОбластьВидимости: ВПроекте
Строки:
    # Ключ: Значение
    Мероприятия: Мероприятия
    Задачи: Задачи
    События: События
    Событие: Событие
    Роль: Роль
Шаблоны:
    ТекущееВремя: "Текущее время: %0"
    СозданаЗадача: "Создана задача \"$0\""
    СозданоСобытие: "Создано событие \"$0\""
```

Чтобы создать элемент проекта **ЛокализованныеСтроки**, используйте один из описанных ниже способов.

### Автоматическая генерация локализованных строк

1. В навигаторе проекта щелкните правой кнопкой мыши по имени компонента интерфейса или элемента проекта, который вы хотите локализовать, и выберите пункт **Локализовать строки** в контекстном меню. Вы также можете вызвать эту команду для подсистемы или пакета, чтобы локализовать все содержащиеся в них объекты.
  
  

1. «1С:Предприятие.Элемент» отобразит диалог **Локализовать строки**. Данный диалог содержит таблицу ключей и значений локализуемых строк, автоматически сгенерированных для всех объектов, поддерживающих локализацию.
  
  Диалог «Локализовать строки» показывает поле имени нового набора локализованных строк, поиск и таблицу с колонками Объект, Расположение, Ключ, Значение. [Описание иллюстрации](../figures/2aa32ab31ffef64427c73c32289ef75d530bc6cae8946f41a984d754f79f0991-821e71fb77db0fc8.md)
2. В поле **Новые локализованные строки** введите имя элемента проекта **ЛокализованныеСтроки**.
  
  Если в проекте уже есть локализованные строки, диалог покажет список доступных ([видимых](../../wiki/language/modular-development-80166cfecf93.md) для выбранных локализуемых объектов) элементов проекта вида **ЛокализованныеСтроки**. Вы можете выбрать один из этих элементов, чтобы добавить к нему новые строки.
  
  
3. Отметьте те строки, которые вы хотите применить к соответствующим объектам. При необходимости отредактируйте ключи и значения строк. Вы можете выбрать существующий ключ в диалоге локализации, чтобы избежать создания ключей с одинаковыми значениями.
  
  Выбор ключа локализованной строки [Описание иллюстрации](../figures/adc7fc4a22cc5005033aab467b7a70803fa610cd3944f4def7e670161452bff2-c7a1796ca090af90.md)
  
  В случае ошибки (пустого значения или ввода ключа, имеющего невалидный формат) поле ввода подсвечивается красным, а во всплывающей подсказке показывается текст ошибки.
4. Нажмите **Применить**. «1С:Предприятие.Элемент» создаст элемент проекта **ЛокализованныеСтроки** с заданным именем. Если для проекта указаны другие языки локализации, «1С:Предприятие.Элемент» также добавит [раздел локализации](../../wiki/project/app-localization-15f5b1317f82.md).

### Создание локализованных строк вручную

1. Наведите мышку на нужную подсистему и нажмите на знак плюса.
2. В открывшемся окне выберите элемент проекта **Локализованные строки**.
  
  Добавление элемента проекта «Локализованные строки» [Описание иллюстрации](../figures/95d5a77e8012750b86b8e4e3ed46628035fb42a6eb44e2b8308cb7b2524f02cb-c22ef1ec91101890.md)
3. Введите имя создаваемого элемента проекта.
4. «1С:Предприятие.Элемент» предложит вам добавить файлы локализации на других языках. Нажмите **Создать**, чтобы автоматически добавить [раздел локализации](../../wiki/project/app-localization-15f5b1317f82.md) к проекту. Если вы хотите создать этот раздел позднее, нажмите **Отменить**.
  
  Диалог создания раздела локализации [Описание иллюстрации](../figures/ce96fffd55560c61a670cc2ce41c5132e9d225f9c8b8d09a1c629ed70b28ebc7-0f19cef3f86cac72.md)
5. Укажите ключи и значения локализуемых строк в панели свойств элемента проекта **ЛокализованныеСтроки**.
  
  В панели свойств элемента «ЛокализованныеСтроки» вручную заданы ключи и значения строк; каждая строка содержит отдельный ключ и переводы. [Описание иллюстрации](../figures/f6ab28a6c3193e95d71439d332654bf4adfdc55a3b42ae8d34a365d54eaaf7f3-7798d18564029665.md)

## Раздел проекта «Локализация»

Чтобы сохранить в проекте значения локализуемых строк на другом языке (язык может быть только тот, который указан в описании проекта в свойстве [ЯзыкиЛокализации](../../wiki/project/app-localization-15f5b1317f82.md)), вы должны добавить к проекту раздел **Локализация**. Если вы не сделали этого при [создании элемента проекта ЛокализованныеСтроки](../../wiki/project/app-localization-15f5b1317f82.md), вы можете добавить этот раздел следующим образом:

1. Наведите мышку на элемент проекта **ЛокализованныеСтроки** и нажмите на знак плюса.
2. В открывшемся окне выберите язык, на который нужно перевести строки.
  
  В меню добавления перевода к ЛокализованныеСтроки выбран язык «Английский». [Описание иллюстрации](../figures/7e4704d453032aee1d4e631dd4050e8351b47d5edc888b68703016b5974c4ad6-017fe57200688b51.md)

«1С:Предприятие.Элемент» создаст раздел локализации, содержащий пустой элемент локализации. Имя элемента локализации будет совпадать с именем элемента проекта вида **ЛокализованныеСтроки**.

В результате проект будет иметь следующую структуру:

Структура локализованного проекта в навигаторе: внутри подсистемы отображается раздел Локализация, в нём язык en, затем элемент ЛокализованныеСтроки. [Описание иллюстрации](../figures/2b47e26e7038a0300a6d2dea6970761b36cb7336767b0c7b700204dea15692e8-a1da39365e0b5ed7.md)

Элемент локализации должен содержать только секции с именами и значениями локализуемых строк. Например:

ЛокализованныеСтроки.yaml

```yaml
ВидЭлемента: ЛокализованныеСтроки
Ид: d0adc076-d030-4546-bd1a-8b497668b0fc
Имя: ЛокализованныеСтроки
ОбластьВидимости: ВПроекте
Строки:
    Мероприятия: Activities
    Задачи: Tasks
    События: Events
    Событие: Event
    Роль: Role
Шаблоны:
    ТекущееВремя: "Current time: %0"
    СозданаЗадача: "Task \"$0\" created"
    СозданоСобытие: "Event \"$0\" created"
```

Вы можете указать перевод строк в панели свойств элемента локализации:

Добавление перевода строк [Описание иллюстрации](../figures/9c52ea83824355237dd9a574ace8df912fa59e29476a7fecad544a5e73ec929c-18e2b38e9d50dd33.md)

Для удобства добавления перевода новых строк и просмотра уже переведенных значений вы можете изменить язык отображения компонентов интерфейса в окне предпросмотра и значений локализованных строк в панели свойств. Для этого в строке состояния среды разработки нажмите на индикатор переключения языка и выберите нужный язык.

В строке состояния среды разработки раскрыт переключатель языка. Он меняет язык предпросмотра компонентов и отображения локализованных строк в свойствах. [Описание иллюстрации](../figures/2dee3130a027eb38dd9b92136e848b4e844a5d1cec2bd0cfb2d2461a11cb8e3b-bff1d877192d7c41.md)

После переключения языка вы можете добавлять переводы строк следующими способами:

- в диалоге **Локализовать строки**:
  
  В диалоге «Локализовать строки» объект «События», элемент «Мероприятия::ЛокализованныеСтроки». [Описание иллюстрации](../figures/73e859483a2513f49f12ac00ad9650d34e78a94e38533d634e1ff19e0695585f-c6eaa3bab6c9d01a.md)
- в панели свойств локализуемого объекта:
  
  В свойстве «Представление» выбрано `ЛокализованныеСтроки.Дата`. [Описание иллюстрации](../figures/61ca3d43d209f7adbf26daaaf2fe55a52e79948b83f1fad69cdd45259b148eb4-f2fdf29401352add.md)

## Использование в значениях свойств элементов проекта

«1С:Предприятие.Элемент» позволяет вам задавать идентификаторы локализованных строк в панели свойств элементов проекта и компонентов интерфейса. Для этого активируйте настройку **Использовать локализованное значение**Пиктограмма «Иконка локализации». [Описание иллюстрации](../figures/4d1c2884d73e6bec5cc094944f20ef3c59ef01af5247c953295af4bb0fca1cbc-7be90d25a438099e.md) для нужного свойства. В открывшемся меню выберите имя элемента проекта **ЛокализованныеСтроки**, содержащего нужную строку, и ключ строки.

В редакторе локализованного значения свойства выбраны элемент «ЛокализованныеСтроки» и ключ «Дата». [Описание иллюстрации](../figures/654f30be5d672f0556cab363ab18f99f247f60ff413a9fd38b938d9bb4e14231-2bc428874d7bc046.md)

Если необходимо, вы можете отредактировать значение выбранной строки или создать новую строку. Для этого нажмите **Создать новую локализованную строку** и укажите ключ и значение строки в открывшемся диалоговом окне.

Диалог «Создать локализованную строку»: выбор локализации, ключ, значения на русском и английском, «Создать» и «Отменить». [Описание иллюстрации](../figures/d7b22a762c656af1d510a5eab104e636e1d80e598a187c60773ade2dcbaf4d63-6d7e8f8524ce94f9.md)

В случае использования локализованной строки в значении свойства элемента в YAML необходимо указать идентификатор строки, начиная с символа «$». Идентификатор локализованной строки состоит из трех частей и выглядит следующим образом: `$<Имя подсистемы>::<Имя элемента проекта локализованных строк>.<Имя локализованной строки в данном элементе>`.

Пример:

Задачи.yaml

```yaml
ВидЭлемента: Документ
Ид: c59a5bbd-d917-4efa-b9f5-d51dfc031426
Имя: НовыеЗадачи
ОбластьВидимости: ВПроекте
Реквизиты:
    -
        Имя: Дата
Интерфейс:
    Объект:
        Форма: НовыеЗадачиФормаОбъекта
        Представление: $Мероприятия::ЛокализованныеСтроки.Задача
    Список:
        Форма: НовыеЗадачиФормаСписка
        Представление: $Мероприятия::ЛокализованныеСтроки.Задачи
```

> [!TIP] совет
> Если вам необходимо задать строку, начинающуюся с символа «$», экранируйте данный символ с помощью еще одного символа «$».

### Правила разрешения коллизий

- Если локализованные строки находятся в той же подсистеме, где и вызываются, то указание подсистемы после «$» необязательно.
- Если подсистема с нужными локализованными строками импортируется, то указание подсистемы после «$» необязательно.
- Коллизии локализованных строк с текущей и импортируемыми подсистемами разрешается в пользу локальных локализованных строк.
- Необходимо указывать нелокальную подсистему в идентификаторе локализованных строк, если подсистема используется, но не импортируется.

## Использование в представлении типов

Для некоторых системных типов, а также типов, порождаемых элементами проекта [Документ](../../wiki/data/document-element-0c6b898a8b13.md), [Справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md), [Плана обмен](../../wiki/integration/data-exchange-385ce993615c.md), [Хранилище настроек](../../wiki/data/settings-repository-3d8ee27a26de.md), [Перечисление](../../wiki/project/fixed-set-of-values-8517518057de.md) и [Право на элемент](../../wiki/project/privilege-on-element-3c75b1690650.md) реализована поддержка локализованного представления типов, которое используется в следующих компонентах интерфейса:

- в колонках таблицы с динамическим списком для полей типа
  
  [`Тип`](../../wiki/stdlib/type-ru-d603a6747a42.md)
  
  ;
- в списках выбора типов и значений в
  
  [поле ввода множественных типов](../../wiki/interface/edit-component-a54ad83ade7f.md)
  
  ;
- при создании нового элемента ссылочного типа в поле ввода множественных типов;
- при
  
  [создании на основании](../../wiki/project/copy-and-create-base-on-a74961f227c0.md)
  
  ;
- в
  
  панели навигации
  
  .

Локализованные представления типов для системных перечислений и предопределенных элементов проекта заданы на системном уровне и не могут быть изменены. Например: тип [`Стд::Время::ДатаВремя`](../../wiki/stdlib/datetime-ru-b9ec40d17fe0.md) имеет представление **Дата время**.

Локализованные представления для пользовательских типов определяются в свойствах элемента проекта. Например, описание права на элемент может выглядеть следующим образом:

```yaml
ВидЭлемента: ПравоНаЭлемент
ОбластьВидимости: ВПодсистеме
Ид: 51adc0fe-5fdf-4939-bbb4-93ade53a71e8
Имя: ПравоНаЭлемент
Представление: $Мероприятия::ЛокализованныеСтроки.ПравоНаЭлемент
Элементы:
    -
        Ид: d5d271fc-18de-4bbf-9e43-e72c2071a3a8
        Имя: Чтение
        Представление: $Мероприятия::ЛокализованныеСтроки.Чтение
    -
        Ид: a69e9740-68d1-4e8f-ade5-c5aa85c9afaf
        Имя: Запись
        Представление: $Мероприятия::ЛокализованныеСтроки.Запись
```

## Использование в коде

В коде можно обратиться к локализованной строке, указав имя элемента проекта вида **ЛокализованныеСтроки** и, через точку, имя локализованной строки. Если это строка-шаблон, то подставляемое значение можно передать в виде аргумента:

```xbsl
Сообщить(ЛокализованныеСтроки.ТекущееВремя("${Время.Сейчас()|ч:мм}"))
```

В этом примере используется строка-шаблон с именем **ТекущееВремя**, в которую подставляется отформатированное представление текущего времени.

При запуске с русскими региональными установками «1С:Предприятие.Элемент» выведет строку на русском языке:

```text
Текущее время: 5:38
```

При запуске с английскими региональными установками он выведет строку на английском языке:

```text
Current time: 5:38
```

### Локализация строк в коде модуля

«1С:Предприятие.Элемент» позволяет быстро преобразовать строки, используемые в модуле, в локализованные.

- Для локализации одной строки используйте механизм быстрых исправлений.
  
  Для строки «Представление не может быть пустым» открыто меню «Быстрое исправление…»; в нём выбрана команда «Локализовать строку». [Описание иллюстрации](../figures/7a6c95ef5cdae2ef8d6e0db3110557915ca08b260d8ccc9a221fc4b589c155e8-79ce4d1975f6ff65.md)
- Для локализации всех строк модуля щелкните по нему правой кнопкой мыши и выберите пункт **Локализовать строки** в контекстном меню.
  
  Локализация всех строк модуля [Описание иллюстрации](../figures/b8896c6c08a738ae2b200ec0637ba0e747274480c509b74913a1d7916d05bbea-56ef246f4a7e453c.md)

«1С:Предприятие.Элемент» откроет диалог **Локализовать строки**, содержащий автоматически сгенерированные ключи и значения локализуемых строк. При необходимости отредактируйте эти значения и нажмите **Применить**.

### Получение текущего языка локализации

Вы можете получить значение текущего языка локализации с помощью статического метода [`Язык.Текущий()`](../../wiki/stdlib/language-ru-16b63462a511.md):

```xbsl
@НаСервере @ДоступноСКлиента
статический метод ЯзыкИнтерфейса(): Строка
    возврат Язык.Текущий().Код
    // Вернет строку "ru", если текущий язык — русский
    // Вернет строку "en", если текущий язык — английский
;
```

### Переключение языка через «КонтекстЛокализации»

Тип [`КонтекстЛокализации`](../../wiki/stdlib/localizationcontext-ru-9813c22da69d.md) позволяет временно изменить язык системы. Пока контекст открыт, используется указанная при открытии локаль. После его закрытия автоматически возвращается исходная локаль.

В методе [`Открыть()`](../../wiki/stdlib/localizationcontext-ru-9813c22da69d.md) контекста локализации можно указать два параметра:

- `ЛокальОтображения` — определяет язык интерфейса, сообщений и локализованных строк.
- `ЛокальФорматирования` — управляет правилами отображения дат, чисел и других значений.

```xbsl
метод ОбработчикЗапланированногоЗадания()

    // Пусть текущий язык — русский
    для Заказ из Заказы.ПолучитьВыполненные()
        // Устанавливаем локаль отображения в соответствии с языком клиента
        // Предположим, язык клиента — английский
        исп ЯзыковойКонтекст = КонтекстЛокализации.Открыть(Заказ.ЯзыкКлиента)
        // ДатаЗаказа форматируется в соответствии с английской локалью, 
        // текст письма берется из английской локализации
        ТекстПисьма = ЛокализованныеСтроки.УведомлениеОВыполненномЗаказе(Заказ.ДатаЗаказа, Заказ.НомерЗаказа)
        ЯзыковойКонтекст.Закрыть()
        // С этого момента снова действует русская локаль
        Заказы.ЗарегистрироватьВЖСОтправкуУведомления(Заказ)
    ;
;
```

### Использование локали

Тип [`Локаль`](../../wiki/stdlib/locale-ru-eb59bd8c78bb.md) позволяет создать локаль, определить текущие настройки и получить список поддерживаемых локалей. Это удобно, когда нужно адаптировать поведение приложения в зависимости от языка пользователя.

```xbsl
если Локаль.ТекущаяЛокальОтображения().КодРегиона == "ES"
    // Предлагаем акцию для Испании
    знч Уведомление = новый Уведомление("Акция!", "Только сейчас скидки в наших магазинах в Испании!")
    Уведомление.Показать()
;
```

## Порядок определения текущих региональных установок при подключении пользователя

- Параметр **locale**, передаваемый в URL. Например:
  
  ```text
  http://localhost:9090/applications/demo-app?locale=en_EN
  ```
  
  Если параметр не указан или не поддерживается «1С:Предприятие.Элементом», то используется следующий пункт.
- Поддерживаемый приложением язык из списка предпочтительных языков браузера. Список языков браузера берется из значения HTTP-заголовка `Accept-Language`. В случае неудачи используется следующий пункт. Возможные причины неудачи:
  
  - В списке языков браузера нет ни одного языка из поддерживаемых
    
    «1С:Предприятие.Элементом»
    
    .
  - Браузер устарел, и у него нельзя узнать предпочтительные языки.
- Локаль приложения (в панели управления **Приложения** ⟶ **Название приложения** ⟶ **Настройки** ⟶ **Общие** ⟶ **Локаль**), которая задается при [создании приложения](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-app-from-archive/). Если локаль приложения не указана, тогда используется следующий пункт.
- **ЯзыкПоУмолчанию** из [файла описания проекта](../../wiki/project/projectdescriptor-d54722c348c7.md).
