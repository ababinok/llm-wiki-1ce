Компонент, который позволяет отображать элементы на временной шкале.

Диаграмма Ганта содержит слева названия работ, справа — временную шкалу декабря 2023 и января 2024 года. [Описание иллюстрации](../figures/7b72ee5c66a94b13841d9c70250f01b03121c1a35cd88ed3ea5fc3ffbf661187-f9212597a6937e4c.md)

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### РасположениеТаблицы

```yaml
РасположениеТаблицы: ВычисляемоеВыражение|Авто|РасположениеТаблицыДиаграммыГанта
```

Определяет расположение таблицы диаграммы Ганта. Возможные значения:

- Авто
  
  :
  
  - в мобильном приложении принимает значение
    
    [Переключатель](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    ;
  - в других случаях принимает значение
    
    [ВНачале](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    ;
- элементы перечисления
  
  [РасположениеТаблицыДиаграммыГанта](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
  
  :
  
  - [НеОтображать](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    — таблица не отображается;
  - [Переключатель](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    — появляется переключатель между таблицей и диаграммой;
  - [ВНачале](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    — таблица отображается в начале компонента (слева);
  - [ВКонце](../../wiki/interface/ganttcharttablelocation-ru-42fb4f5e5d21.md)
    
    — таблица отображается в конце компонента (справа).

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/ganttchart-ru-9f9a235275cf.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/ganttchart-ru-9f9a235275cf.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Доступность

```yaml

```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](../../wiki/interface/ganttchart-ru-9f9a235275cf.md).

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/ganttchart-ru-9f9a235275cf.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/ganttchart-ru-9f9a235275cf.md).

```yaml
ПриВыделенииЭлемента: Строка
```

```yaml

```

Возникает при интерактивном изменении масштаба диаграммы Ганта.

---

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

## Дочерние элеметы

#### Колонки

```yaml
Колонки: неизвестно
```

Описание колонок таблицы диаграммы Ганта. В качестве параметров связывания данных в параметре `ДанныеСтроки` колонке передается объект [ЭлементДиаграммыГанта](../../wiki/interface/ganttchartitem-ru-952871018e2b.md).

---

#### КомандыСтроки

```yaml
КомандыСтроки: неизвестно
```

Команды над строкой. В качестве параметров команд передается объект [ЭлементДиаграммыГанта](../../wiki/interface/ganttchartitem-ru-952871018e2b.md).
