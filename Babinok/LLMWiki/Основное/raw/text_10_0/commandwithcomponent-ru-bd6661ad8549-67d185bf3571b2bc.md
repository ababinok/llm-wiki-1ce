Описывает команду, которая относится к конкретному компоненту.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../../wiki/language/modular-development-80166cfecf93.md).

---

#### ТипКомпонента

```yaml
ТипКомпонента: Строка
```

Тип компонента, над которым будет выполнена команда.

---

#### Изображение

```yaml
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Ссылка на картинку, которая будет показана в команде.

---

#### Видимость

```yaml
Видимость: Булево
```

Управляет видимостью команды. Если `Ложь`, команда скрыта в интерфейсе.

---

#### Доступность

```yaml
Доступность: Булево
```

Управляет доступностью команды. Если `Ложь`, команда недоступна для выполнения.

---

#### Важность

```yaml
Важность: Низкая|Обычная|Высокая
```

Определяет приоритет при отображении нескольких команд. Например, команда с важностью **Низкая** будет отображаться в выпадающем меню **Еще**. Возможные значения:

- Высокая
  
  ,
- Обычная
  
  ,
- Низкая
  
  .

---

#### НастройкиТипа

```yaml
НастройкиТипа: 
    Контракты: Строка[]
```

Имена [контрактов типа](../../wiki/language/type-contract-ab9f0932850d.md), которые реализует данный компонент.

#### ОпасностьДействия

```yaml
ОпасностьДействия: Отсутствует|Средняя|Высокая
```

Определяет опасность действия, совершаемого пользователем. Например, может ли нажатие на кнопку привести к удалению данных. Возможные значения:

- Высокая
  
  ,
- Средняя
  
  ,
- Отсутствует
  
  .
