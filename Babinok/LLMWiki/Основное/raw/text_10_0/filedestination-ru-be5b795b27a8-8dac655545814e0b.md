Узел этого вида передает файлы в указанный каталог. Тело сообщения записывается в файл.

---

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ДействиеНадСуществующимФайлом

```yaml
ДействиеНадСуществующимФайлом: ДействиеНадСуществующимФайлом
```

Указывает, что сделает «1С:Предприятие.Элемент», если файл, в который нужно записать тело сообщения, уже существует. Принимает значения перечисления [ДействиеНадСуществующимФайлом](../../wiki/integration/existingfileaction-ru-578551ed3769.md):

- Перезаписывать
  
  :
  
  «1С:Предприятие.Элемент»
  
  перезапишет существующий файл.
- Дописывать
  
  :
  
  «1С:Предприятие.Элемент»
  
  допишет тело сообщения в конец существующего файла. Такой файл будет содержать тела нескольких сообщений.
- ВыдаватьОшибку
  
  :
  
  «1С:Предприятие.Элемент»
  
  не изменит существующий файл и вызовет исключение. Сообщение не будет считаться доставленным.
- Оставлять
  
  :
  
  «1С:Предприятие.Элемент»
  
  не изменит существующий файл. Сообщение будет считаться доставленным.

---

#### РазрешитьПустойФайл

```yaml
РазрешитьПустойФайл: Булево
```

Определяет, будет ли «1С:Предприятие.Элемент» создавать пустые файлы для сообщений с пустым телом:

- Если
  
  Истина
  
  , то она создаст пустой файл сообщения.
- Если
  
  Ложь
  
  , то она не создаст файл сообщения и вызовет исключение.
- Если
  
  Истина
  
  и
  
  [ДействиеНадСуществующимФайлом](../../wiki/integration/filedestination-ru-be5b795b27a8.md)
  
  равно
  
  Перезаписывать
  
  , то вместо существующего файла она запишет пустой файл.
- Если
  
  Истина
  
  и
  
  [ДействиеНадСуществующимФайлом](../../wiki/integration/filedestination-ru-be5b795b27a8.md)
  
  равно
  
  Дописывать
  
  , то существующий файл останется неизменным.

#### ИспользоватьИмяФайлаБезПути

```yaml
ИспользоватьИмяФайлаБезПути: ВычисляемоеВыражение|Булево
```

Если при чтении файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу и включит в сообщение только имя файла. Иначе «1С:Предприятие.Элемент» включит в сообщение путь относительно значения свойства **Каталог**.

Если при записи файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу из сообщения и запишет файл в каталог, указанный в свойстве **Каталог**. Иначе «1С:Предприятие.Элемент» запишет файл в каталог, вложенный в **Каталог**. Имя вложенного каталога будет определено из сообщения.

### События

#### ВыборИмени

```yaml
ВыборИмени: Строка
```

Обработчик, который позволяет переопределить имя файла, в которое будет записано сообщение. Обработчик должен вернуть новое имя файла. Если заполнено свойство [ИмяФайла](../../wiki/integration/filedestination-ru-be5b795b27a8.md) и указан обработчик **ВыборИмени**, то имя файла берется из обработчика. В случае ошибки в обработчике имя файла будет взято из свойства [ИмяФайла](../../wiki/integration/filedestination-ru-be5b795b27a8.md).

---

```yaml
ОбновлениеМетрик: Строка
```
