Чтобы создать новую задачу, выполните следующие шаги:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. Выполните одно из следующих действий:
  
  - На вкладке **Проекты** щелкните на нужный проект. Переключитесь на вкладку **Задачи** и нажмите кнопку **+ Новая задача**.
    
    Создание новой задачи [Описание иллюстрации](../figures/a8c34af58b864c7e3f38d09d3226041eb9bb87fa55f33afd6ccbc74aa40ec873-6544c1a6b08ddafd.md)
  - Нажмите **Разработка** ⟶ **Задачи**.
    
    
    
    Откроется список задач по всем проектам. Нажмите **+ Новая задача**.
    
    
  
  > [!NOTE] примечание
  > При создании самой первой задачи в репозитории вам будет предложено выбрать, вести ли разработку каждой задачи в отдельной ветке. Это позволит вам избежать конфликтов с другими разработчиками. Если вы установите переключатель в положение **Ложь**, для разработки будет использоваться только основная ветка проекта. В дальнейшем вы можете изменить свой выбор в [настройках репозитория проекта](../../wiki/project/set-up-collaborative-development-62562bbfba3b.md).
  
  Диалог «Ветки в задачах»: включены «Разрабатывать задачу в отдельной ветке» и «Использовать проверку задач». [Описание иллюстрации](../figures/6bc488d4fa4b521ed4d11fdb6e887e8f571a7d33ec2795a62515b6c8b6aff937-9e5945638dae627a.md)
3. Заполните название и описание задачи, укажите ее исполнителя, добавьте [метки](../../wiki/project/add-labels-to-issue-515c0f6e341f.md), если необходимо. Если вы создаете задачу из вкладки **Разработка** ⟶ **Задачи**, вам также необходимо указать проект, к которому относится новая задача.
  
  Выберите ветку для разработки задачи. Вы можете вести разработку в основной ветке проекта, указать существующую ветку или создать новую с помощью опции **Создать новую ветку от основной или релизной ветки перед разработкой**. Новая ветка будет создана только при начале разработки задачи. Если при создании ветки обнаружится, что репозиторий уже содержит ветку с таким именем (например, если она была создана вручную), то задача будет привязана к этой ветке.
  
  Редактирование задачи [Описание иллюстрации](../figures/b4e68ac2dc6c6b4edbb9d88543b049d38e14d5c653e585e6e90a8c3a5485f1d6-f18540af48403e3d.md)
4. Нажмите **Создать задачу**. Новая задача появится в общем списке на вкладке **Задачи**.
