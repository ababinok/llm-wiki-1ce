Реализует функциональность [поставщика SOAP-сервиса](../../wiki/integration/soap-web-service-6fc6a00d4cc7.md). Позволяет обрабатывать входящие SOAP-запросы, поступающие от внешних информационных систем. Обращение к SOAP-сервису выполняется при помощи HTTP POST-запроса по URL-адресу. При этом само SOAP-сообщение передается в теле запроса.

Функциональность клиента SOAP-сервиса реализует элемент проекта [Клиент SOAP-сервиса](../../wiki/integration/soap-web-service-client-e79277c8f091.md).

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);

  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

#### Ошибки

```yaml
Ошибки: Тип<Исключение>[]
```

Типы исключений, описывающих ошибки SOAP-сервиса. Могут быть переопределены для конкретной операции с помощью свойства обработчика [Ошибки](../../wiki/integration/servicehandler-ru-d99b0889159b.md).

«1С:Предприятие.Элемент» формирует WSDL-контракт (секция `faults`):

- из данного свойства;
- из списков типов, указанных в свойстве
  
  [Ошибки](../../wiki/integration/servicehandler-ru-d99b0889159b.md)
  
  всех обработчиков.

«1С:Предприятие.Элемент» накладывает [ограничения](../../wiki/integration/soap-service-types-a958b90025c0.md) на типы исключений.

## Дочерние элеметы

#### Обработчики

```yaml
Обработчики: ОбработчикСервиса[]
```

Описание операций, которые выполняют обработку данных из входящего SOAP-сообщения от клиента сервиса и формируют результат для исходящего SOAP-сообщения. Для каждой операции указывается метод, который реализует необходимую функциональность.
