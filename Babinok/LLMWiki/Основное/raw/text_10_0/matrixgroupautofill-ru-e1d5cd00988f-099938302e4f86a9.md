## Свойства

### ДобавлятьСтроки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ДобавлятьСтроки
```

Если количество дочерних компонентов превышает количество явно описанных ячеек, то лишние компоненты будут добавлять новые строки.

---

### ДобавлятьКолонки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ДобавлятьКолонки
```

Если количество дочерних компонентов превышает количество явно описанных ячеек, то лишние компоненты будут добавлять новые колонки.

---

### ДобавлятьКолонкиИСтроки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ДобавлятьКолонкиИСтроки
```

Компоненты будут заполнять доступное по горизонтали место, добавляя колонки. При заполнении места по горизонтали, будет образована новая строка. При этом требуется точное описание размера колонок (например, от 300 до 400 пикселей), добавляемые колонки не могут иметь автоматический размер по содержимому.
