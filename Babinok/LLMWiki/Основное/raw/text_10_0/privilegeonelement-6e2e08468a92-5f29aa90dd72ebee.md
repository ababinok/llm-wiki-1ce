Элемент проекта, описывающий права на сущности.

Право на элемент — это право доступа, связанное с элементом проекта или с записью конкретного экземпляра сущности. Наличие права на элемент проверяется вручную разработчиком. После того как вы добавили в проект право на элемент, «1С:Предприятие.Элемент» создаст тип с именем `ИмяПраваНаЭлемент`. Например, если в проекте есть право на элемент **ПравоНаКонтрагента**, то будет создан единственный тип — `ПравоНаКонтрагента`.

Данный тип представляет из себя перечисление, наследующее базовый тип [ПравоДоступа](../../wiki/security/accessprivilege-ru-ec1f634a9bdc.md). Не имеет модуля.

## Свойства

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.
