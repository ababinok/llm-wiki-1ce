Если вы не [подключили](../../wiki/project/connect-to-gitlab-daf8c8c732dc.md) к серверу хранилище репозиториев кода GitLab, вы можете использовать существующий внешний Git-репозиторий для групповой разработки. Для этого выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. Нажмите **Проекты** и щелкните на нужный проект.
3. В правом верхнем углу кликните на иконкуПиктограмма «Значок меню». [Описание иллюстрации](../figures/eeec48637e32c4f2ec0cc9ade2b45debe2df98791c721a93c2826cace650091a-7826430e32669bbb.md) и выберите пункт **Настроить репозиторий**.
  
  
4. Репозиторий можно подключить по протоколам SSH или HTTP.
  
  - Подключение по HTTP
  - Подключение по SSH
  
  Заполните следующие поля:
  
  - Адрес git-репозитория
    
    .
  - Логин пользователя и пароль
    
    для доступа к репозиторию. В качестве пароля вы также можете указать
    
    [персональный токен](../../wiki/project/create-gitlab-token-66fabd491403.md)
    
    (
    
    Personal access token
    
    ) или
    
    [токен доступа к проекту](../../wiki/project/create-gitlab-token-66fabd491403.md)
    
    (
    
    Project access token
    
    ).
  - Имя пользователя/электронная почта для коммитов
    
    — если оставить эти поля пустыми, то будут использованы имя пользователя и электронная почта, указанные в панели управления.
  - Используется HTTP прокси-сервер
    
    — активируйте эту настройку, если вы хотите использовать прокси-сервер для доступа к репозиторию. Введите сетевой адрес и порт прокси-сервера. Если для подключения требуется аутентификация, укажите имя пользователя и пароль.
  - Основная ветка разработки
    
    — центральная ветка репозитория, в которую будет загружена текущая версия проекта. Вы можете либо изначально вести разработку в этой ветке (реализовывать новый функционал и вносить исправления), либо вливать в нее изменения из других веток проекта. После указания настроек подключения к репозиторию обновите список существующих веток и выберите основную ветку из списка.
  - Сборка для загрузки в основную ветку
    
    —
    
    [сборка проекта](../../wiki/project/project-assemblies-22705683fda4.md)
    
    , которую необходимо загрузить в основную ветку. Если не выбрана, основная ветка останется без изменений.
  - Префикс задач проекта
    
    — уникальный префикс, который будет добавляться в начало номера каждой
    
    задачи
    
    через дефис «-».
  - Настройка использования задач и веток
    
    — позволяет настроить работу с ветками и задачами проекта. По умолчанию включены все возможности, кроме интеграции по HTTP API. В дальнейшем вы можете изменить свой выбор в
    
    [настройках репозитория проекта](../../wiki/project/set-up-collaborative-development-62562bbfba3b.md)
    
    .
  
  Форма подключения Git-репозитория содержит адрес репозитория, выбор доступа «Логин и пароль» или «Закрытый ключ», поля пользователя и пароля/токена. [Описание иллюстрации](../figures/80c5bcb7d7c089a185cbe1a7d6870bf06a5801be48c707df58cc78a82a94e84a-70145c81ddf9f972.md)
5. «1С:Предприятие.Элемент» оповестит вас, что подключение началось, и через некоторое время вы увидите ветки репозитория в списке. Чтобы перейти к разработке, в меню ветки нажмите **Разработка**.
  
  Переход к разработке ветки [Описание иллюстрации](../figures/b2d0354affa12b42bfb02b7219a52fabe4d5bfceb219591a435324cfa34413dd-3d1bfb36a11cb875.md)
