`Версия 8.0 и выше`

Таблица с информацией об иерархических связях. Создается, если справочник иерархический.

Таблица содержит информацию о связях **«родитель**-**ребенок»**. Для элемента в таблице указаны все его родители. Непосредственный родитель отмечен специальным флагом. Также для каждого элемента в таблице содержится запись **на себя** как родителя: **«текущий элемент**-**текущий элемент»**. Элементы, которые не имеют родителя, отражаются в таблице таким образом.

---

## Примеры

В примере ниже показано, как получить поля **Ссылка**, **Код** и **Наименование** родительских элементов справочника **Подразделения** для текущего элемента справочника:

```xbql
ВЫБРАТЬ
    Подразделения.Ссылка,
    Подразделения.Код,
    Подразделения.Наименование
ИЗ
    Подразделения КАК Подразделения
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ Подразделения.Иерархия КАК ТаблицаИерархии
        ПО Подразделения.Ссылка == ТаблицаИерархии.Родитель И ТаблицаИерархии.Ребенок == %ТекущийЭлементСправочника
```

## Поля

### Родитель

`Ключевое поле`

```
Родитель: ИмяИерархии.Ссылка|ИмяСправочника.Ссылка
```

Родитель узла.

---

### Ребенок

`Ключевое поле`

```
Ребенок: ИмяИерархии.Ссылка|ИмяСправочника.Ссылка
```

Узел, для которого указана информация в строке.

---

### Непосредственный

```
Непосредственный: Булево
```

Флаг, который указывает, является ли родитель прямым для ссылки. Прямой родитель — ближайший предок узла, указанный в поле **Родитель**.

---

### Уровень

```
Уровень: Число
```

Количество родителей без учета собственной ссылки.

---

### КоличествоДетей

```
КоличествоДетей: Число
```

Количество непосредственных детей элемента, указанного в поле **Ребенок**.
