Узел этого вида получает файлы из каталога по протоколу FTP.

> [!WARNING] важно
> При работе с файлами может возникнуть ситуация, когда узел **FtpИсточник** реагирует на изменение файла до того, как это изменение завершилось. Обычно такое случается при работе с большими файлами или при медленной записи. Это происходит потому, что узел **FtpИсточник** несколько раз в секунду контролирует указанные ему каталоги и/или файлы и генерирует сообщения при изменении даты или размера файла. В результате может быть сгенерировано больше одного сообщения до завершения записи в файл. Вы можете узнать о решении данной проблемы в соответствующей [статье](../../wiki/integration/integration-process-multiple-messages-are-created-when-file--5bb65d9754bb.md) раздела **Проблемы**.

#### ДействиеПослеЧтения

```yaml
ДействиеПослеЧтения: ДействиеПослеЧтения
```

Указывает, что сделает «1С:Предприятие.Элемент» с файлом сообщения после чтения. Принимает значения перечисления [ДействиеПослеЧтения](../../wiki/integration/afterreadaction-ru-d489572a6de4.md):

- **Переместить**: «1С:Предприятие.Элемент» переместит файл сообщения. Новый путь к файлу определяется значением свойства [ИмяПослеЧтения](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md) и результатом обработки события [ВыборИмениПослеЧтения](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md).
- **Удалить**: «1С:Предприятие.Элемент» удалит файл сообщения.
- **Сохранить**: «1С:Предприятие.Элемент» сохранит файл сообщения на месте. «1С:Предприятие.Элемент» вычислит для него идемпотентный ключ, который содержит полный путь к файлу, размер файла и момент модификации файла с точностью до секунд.
  
  «1С:Предприятие.Элемент» повторно обработает этот файл, только если изменится ключ этого файла, например, в этот файл будет что-то дописано или файл будет перезаписан целиком ([подробнее](../../wiki/project/retrieve-message-from-file-6152df025666.md)).

#### МенятьКаталогПошагово

```yaml
МенятьКаталогПошагово: ВычисляемоеВыражение|Булево
```

Возможность выполнения нескольких команд последовательно.

При подключении к некоторым FTP-серверам в команде `cd` сразу можно указать целевой каталог, например: `cd dir/subdir/subsubdir`. Для таких серверов мы рекомендуем устанавливать значение этого свойства **Ложь**.

В других FTP-серверах нужно выполнить несколько команд последовательно, например: `cd dir cd subdir/ cd subsubdir`. Обычно это связано с настроенным на сервере разграничением доступа. Для таких серверов устанавливайте значение этого свойства **Истина**.

#### Скачивать

```yaml
Скачивать: Булево
```

Если установлено значение **Истина**, то файл скачивается с FTP-сервера и помещается в тело сообщения. Если задано значение **Ложь**, тело сообщения будет пустым.

> [!NOTE] дополнительно
> Некоторые FTP-сервера позволяют загружать файлы, только если значение свойства **МенятьКаталогПошагово** равно **Истина**, в то время как другие могут загружать файлы только при значении свойства **МенятьКаталогПошагово** равным **Ложь**.

#### ИспользоватьИмяФайлаБезПути

```yaml
ИспользоватьИмяФайлаБезПути: ВычисляемоеВыражение|Булево
```

Если при чтении файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу и включит в сообщение только имя файла. Иначе «1С:Предприятие.Элемент» включит в сообщение путь относительно значения свойства **Каталог**.

Если при записи файла значение свойства равно **Истина**, то «1С:Предприятие.Элемент» проигнорирует путь к файлу из сообщения и запишет файл в каталог, указанный в свойстве **Каталог**. Иначе «1С:Предприятие.Элемент» запишет файл в каталог, вложенный в **Каталог**. Имя вложенного каталога будет определено из сообщения.

### События

#### ВыборИмени

```yaml
ВыборИмени: Строка
```

Обработчик, позволяющий переопределить имя файла сообщения, который будет искать «1С:Предприятие.Элемент». Обработчик должен вернуть новое имя файла. Если заполнено свойство [ИмяФайла](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md) и указан обработчик **ВыборИмени**, то имя файла берется из обработчика. В случае ошибки в обработчике имя файла будет взято из свойства [ИмяФайла](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md).

---

#### ВыборИмениПослеЧтения

```yaml
ВыборИмениПослеЧтения: Строка
```

Обработчик, позволяющий переопределить имя файла, которое он будет иметь после чтения «1С:Предприятие.Элементом». Обработчик должен вернуть новое имя файла ([подробнее](../../wiki/project/retrieve-message-from-file-6152df025666.md)). Если заполнено свойство [ИмяПослеЧтения](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md) и указан обработчик **ВыборИмениПослеЧтения**, то имя файла берется из обработчика. В случае ошибки в обработчике имя файла будет взято из свойства [ИмяПослеЧтения](../../wiki/integration/ftpsource-ru-a43e85e4ee35.md).

---
