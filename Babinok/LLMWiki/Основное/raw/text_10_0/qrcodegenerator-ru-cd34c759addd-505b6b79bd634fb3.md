## Конструкторы

### ГенераторQrКода

`Доступность: Сервер`

```
ГенераторQrКода(
  Ширина: Число,
  Высота: Число,
  Коррекция: УровеньКоррекцииQrКода = УровеньКоррекцииQrКода.Низкий,
  Формат: ФорматИзображения = ФорматИзображения.Png,
  ТочныйРазмер: Булево = Ложь)
```

Создает генератор QR-кодов с уровнем коррекции

`Коррекция`

, который записывает сгенерированные QR-коды в изображения формата

`Формат`

шириной

`Ширина`

и высотой

`Высота`

. Также задает обязательность

`ТочныйРазмер`

соответствия размера сгенерированного изображения заданному.

---

## Свойства

### Коррекция

`Доступность: Сервер` `ТолькоЧтение`

```
Коррекция: УровеньКоррекцииQrКода
```

Уровень коррекции QR-кода при его генерации.

---

### Размер

`Доступность: Сервер` `ТолькоЧтение`

```
Размер: РазмерИзображения
```

Размер изображения, в которое будет помещен генерируемый QR-код.

---

### ТочныйРазмер

`Доступность: Сервер` `ТолькоЧтение`

```
ТочныйРазмер: Булево
```

Обязательность соответствия размера сгенерированного изображения с QR-кодом заданному размеру.

Может отличаться в случае указания недостаточного размера изображения для записи QR-кода (размер будет автоматически увеличен до минимально возможного для записи QR-кода).

---

### Формат

`Доступность: Сервер` `ТолькоЧтение`

```
Формат: ФорматИзображения
```

Формат изображения, в которое будет помещен генерируемый QR-код.

### КодироватьВизитку

`Версия 9.0 и выше`

`Доступность: Сервер`

```
КодироватьВизитку(
  Имя: Строка,
  Телефон: Строка,
  Почта: АдресПочты|Строка,
  Заголовок: Строка = "",
  Компания: Строка = "",
  Адрес: Строка = "",
  ВебСайт: Строка = "",
  Заметка: Строка = ""
): Байты
```

Кодирование визитной карточки в формате QR-кода.

`Имя`

- имя владельца визитной карточки.

`Телефон`

- телефон владельца визитной карточки.

`Почта`

- адрес электронной почты владельца визитной карточки.

`Заголовок`

- заголовок визитной карточки.

`Компания`

- компания владельца визитной карточки.

`Адрес`

- адрес компании/владельца визитной карточки.

`Website`

- адрес сайта компании/владельца визитной карточки.

`Заметка`

- заметка на визитной карточке. Возвращает изображение с сгенерированным QR-кодом в виде байтов.
