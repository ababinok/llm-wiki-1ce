Данные регистрации приложения взаимодействия.

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Общие примеры**

Создание объекта с данными регистрации, которые были ранее известны:

```xbsl
знч ОткрытыйКлюч = "QWERTYU4567=..."
знч ЗакрытыйКлюч = "QWERTYU4567=..."
знч КлючиПриложенияВзаимодействия = новый КлючиПриложенияВзаимодействия(ОткрытыйКлюч, ЗакрытыйКлюч)
знч АдресСервера = "wss://1c.dialog.ru:443"
знч ИдПриложения = Ууид{86669b56-32c9-49bb-9b5b-31cde9a79538}
знч ОткрытыйКлючСервераВзаимодействия = "QWERTYU4567=..."

знч ДанныеРегистрации = новый ДанныеРегистрацииПриложенияВзаимодействия(
    Сервер = АдресСервера,
    ИдПриложения = ИдПриложения,
    КлючиПриложения = КлючиПриложенияВзаимодействия,
    ОткрытыйКлючСервера = ОткрытыйКлючСервераВзаимодействия
) 
```

## Конструкторы

### ДанныеРегистрацииПриложенияВзаимодействия

`Доступность: Сервер`

```
ДанныеРегистрацииПриложенияВзаимодействия(Данные: Байты)
```

Создает объект с указанными данными, которые ранее были получение с помощью метода

[ВБайты](../../wiki/integration/collaborationapplicationregistrationdata-ru-479ad972e1bb.md)

.

Будет выброшено исключение [ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md), если `Данные` имеет невалидный формат.

**Перегрузка** [ДанныеРегистрацииПриложенияВзаимодействия(ИдПриложения: Ууид, КлючиПриложения: КлючиПриложенияВзаимодействия, ОткрытыйКлючСервера: Байты|Строка, Сервер: Строка)](../../wiki/integration/collaborationapplicationregistrationdata-ru-479ad972e1bb.md)

---

### ДанныеРегистрацииПриложенияВзаимодействия

`Доступность: Сервер`

```
ДанныеРегистрацииПриложенияВзаимодействия(
  ИдПриложения: Ууид,
  КлючиПриложения: КлючиПриложенияВзаимодействия,
  ОткрытыйКлючСервера: Байты|Строка,
  Сервер: Строка)
```

Создает объект с указанными параметрами данных регистрации приложения взаимодействия.

**Перегрузка** [ДанныеРегистрацииПриложенияВзаимодействия(Данные: Байты)](../../wiki/integration/collaborationapplicationregistrationdata-ru-479ad972e1bb.md)

`Доступность: Сервер` `ТолькоЧтение`

---

## Методы

### ВБайты

`Доступность: Сервер`

```
ВБайты(): Байты
```

Возвращает данные регистрации приложения взаимодействия в виде массива байтов.

Может быть использовано для переноса данных регистрации в другое приложение.

---

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Возвращает строковое представление данных регистрации приложения взаимодействия.

**Переопределение** [Объект::ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)
