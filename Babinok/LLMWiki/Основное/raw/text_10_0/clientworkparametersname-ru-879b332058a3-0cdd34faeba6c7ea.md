`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПараметровРаботыКлиента}` `Тип-одиночка` `Доступность: Клиент`

Объект-одиночка для работы с параметрами работы клиента. Сами значения параметров необходимо заполнить в обработчике `ВычислитьПараметрыРаботыКлиента`. Обработчик выполняется на сервере. В этом обработчике надо вернуть объект типа [ИмяПараметровРаботыКлиента.Параметры](../../wiki/stdlib/clientworkparametersname-parameters-ru-5d5afa6451b2.md). Значения свойств этого объекта будут доступны на клиенте через одноимённые свойства у типа-синглтона [ИмяПараметровРаботыКлиента](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md). Если при выполнении обработчика происходит исключение, то при обращении к параметрам на клиенте будет попытка их вычисления ещё раз, а если и она не удалась - выброшено исключение [ИсключениеПараметрыРаботыКлиентаНеИнициализированы](../../wiki/interface/clientworkparametersnotinitializedexception-ru-852da47af9f8.md) При открытии приложения происходит вызов всех обработчиков и все их параметры передаются на клиента одним серверным вызовом.

## Примеры

**Сравнение**

```yaml
ВидЭлемента: ПараметрыРаботыКлиента
ОбластьВидимости: ВПодсистеме
Ид: 1970ba8f-0c74-4b80-a8fd-c038f0f75c1c
Имя: ПараметрыПользователя
Параметры:
    -
        Имя: ИмяПользователя
        Тип: Строка
    -
        Имя: ЭтоАдмин
        Тип: Булево
```

Для заполнения элементов надо описать обработчик в модуле:

```xbsl
@Обработчик
@НаСервере
статический метод ВычислитьПараметрыРаботыКлиента(): ПараметрыПользователя.Параметры
    возврат новый ПараметрыПользователя.Параметры(
        ИмяПользователя = "Админ",
        ЭтоАдмин = Истина
    )
;
```

Для данного описания параметров будет сгенерирован тип `ПараметрыПользователя` со следующими свойствами:

- `Строка`
  
  :
  
  [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  со значением "Админ"
- `ЭтоАдмин`
  
  :
  
  [Булево](../../wiki/stdlib/boolean-ru-7823d4239bcc.md)
  
  со значением Истина

## Обработчики

### ВычислитьПараметрыРаботыКлиента

```
ВычислитьПараметрыРаботыКлиента(): {ИмяПараметровРаботыКлиента}.Параметры
```

Вызывается при вычислении параметров работы клиента. В этом обработчике надо вычислить параметры и вернуть их. Если при выполнении обработчика происходит исключение, то при обращении к параметрам на клиенте будет попытка их вычисления ещё раз, а если и она не удалась - выброшено исключение
