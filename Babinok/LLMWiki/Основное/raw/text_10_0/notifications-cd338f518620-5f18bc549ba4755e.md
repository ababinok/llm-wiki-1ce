Уведомления — это системный механизм, позволяющий оповестить пользователя о том или ином событии. Он доступен только на клиенте.

Уведомление содержит заголовок «Заявка на ремонт отправлена» и текст «Заявка отправлена мастеру. [Описание иллюстрации](../figures/1293e3fba0e6d5ce06c9b0dc68bc3062a34a0db92322648bb6cb2ecf1f4836a1-23b698340ca9ea63.md)

Вместе с [центром уведомлений](../../wiki/project/notifications-cd338f518620.md), который открывается при нажатии на колокольчик в интерфейсе приложения, уведомления позволяют приложению взаимодействовать с пользователем. Например, они могут использоваться, чтобы:

- оповестить о новом письме;
- уведомить о том, что совещание скоро начнется;
- подтвердить, что заявка на отпуск/больничный была успешно создана и отправлена;
- вывести информацию о добавлении товара в корзину.

Для описания уведомлений используется тип [Уведомление](../../wiki/interface/notification-ru-f537b2070755.md). Вы можете создать простое уведомление следующим образом:

```xbsl
знч Уведомление = новый Уведомление("Заявка на ремонт отправлена", 
                                    "Заявка отправлена мастеру. Он свяжется с вами в ближайшее время")
Уведомление.Показать()  
```

## Виды уведомлений

«1С:Предприятие.Элемент» поддерживает несколько видов уведомлений, подробная информация о которых представлена ниже. Для настройки вида уведомления используйте свойство [Вид](../../wiki/interface/notification-ru-f537b2070755.md) объекта [Уведомление](../../wiki/interface/notification-ru-f537b2070755.md).

### Системное

Отображается как стандартное уведомление браузера. Пользователь увидит такое уведомление, даже если у него не открыта вкладка с приложением или окно браузера свернуто. Используйте этот вид уведомлений для оповещения о срочных или важных событиях, о которых пользователь захочет узнать, даже если в данный момент он не работает в приложении. Это может быть уведомление о новом сообщении в чате или оповещение о начале видеоконференции.

Системное уведомление Google Chrome содержит заголовок «У вас одно новое сообщение!» и текст «Вам пришло новое личное сообщение. [Описание иллюстрации](../figures/0e6825d64086237b976a12e63178040642579dca08dae37f86ec9c7e7bf4f416-3d79bfceb0c3f546.md)

Чтобы показать системное уведомление, присвойте свойству [Вид](../../wiki/interface/notification-ru-f537b2070755.md) значение [Системное](../../wiki/interface/notificationkind-ru-c04da4316025.md):

```xbsl
знч Уведомление = новый Уведомление("У вас одно новое сообщение!",
                                    "Вам пришло новое личное сообщение. Нажмите, чтобы прочитать")
Уведомление.Вид = ВидУведомления.Системное
Уведомление.Показать()
```

### Обычное

Отображается в правом верхнем углу окна приложения. Используется для оповещения о менее важном событии, когда немедленная реакция пользователя не требуется. Это может быть уведомление о завершении какой-либо длительной операции, например обновления, выгрузки или удаления приложения.

Обычное уведомление об успешном обновлении приложения расположено справа вверху: зелёная полоса, заголовок и текст о готовности к работе, кнопка закрытия. [Описание иллюстрации](../figures/2f6783a8c5618043c52229ccc577c5512b50747a2a81d61b0cb2847669edfd4b-56edd892f0aa06ce.md)

Чтобы показать обычное уведомление в приложении, присвойте свойству [Вид](../../wiki/interface/notification-ru-f537b2070755.md) значение [Обычное](../../wiki/interface/notificationkind-ru-c04da4316025.md). Вы также можете задать дополнительные настройки для уведомления: добавить [изображение](../../wiki/interface/notification-ru-f537b2070755.md), задать [оценку информации](../../wiki/interface/notification-ru-f537b2070755.md), отобразить компонент [обратного отсчета](../../wiki/interface/notification-ru-f537b2070755.md).

```xbsl
знч Уведомление = новый Уведомление("Обновление приложения",
                                    "Приложение успешно обновлено и готово к работе")
Уведомление.Вид = ВидУведомления.Обычное
Уведомление.ОценкаИнформации = ОценкаИнформации.Положительная
Уведомление.Показать()
```

### Всплывающее

Всплывающее уведомление, которое отображается внизу экрана. Используется для подтверждения действия пользователя и показывается сразу после совершения действия. Например, пользователь нажал кнопку **Сохранить** или **Скопировать** и сразу же получил уведомление, что действие выполнено.

Всплывающее уведомление подтверждает действие: зелёная галочка и текст «Пример скопирован в буфер обмена» в тёмной области. [Описание иллюстрации](../figures/4ec0e6f3620534c82b589d7f53160503f8c118b280ae1a153600b9e6cd7658a8-6e04aa588c963df3.md)

Чтобы показать всплывающее уведомление в приложении, присвойте свойству [Вид](../../wiki/interface/notification-ru-f537b2070755.md) значение [Всплывающее](../../wiki/interface/notificationkind-ru-c04da4316025.md):

```xbsl
знч Уведомление = новый Уведомление("", "Пример скопирован в буфер обмена")
Уведомление.Вид = ВидУведомления.Всплывающее
Уведомление.ОценкаИнформации = ОценкаИнформации.Положительная
Уведомление.Показать()
```

### Скрытое

Не отображается в приложении, но может сохраняться в центре уведомлений, если включена настройка [`СохранитьВЦентреУведомлений`](../../wiki/interface/notification-ru-f537b2070755.md). Предназначено для уведомления о неважных длительных операциях.

Открытый центр уведомлений показывает сообщение «Заполнение данными» с текстом «Завершено заполнение демонстрационными данными». [Описание иллюстрации](../figures/1a87b61e65923e325f0c52983d7fe75d13f405803703f9bd015ab6ef497c640e-93f3e0b6ea0fdfce.md)

Чтобы создать такое уведомление, присвойте свойству [Вид](../../wiki/interface/notification-ru-f537b2070755.md) значение [Невидимое](../../wiki/interface/notificationkind-ru-c04da4316025.md):

```xbsl
знч Уведомление = новый Уведомление("Заполнение данными",
                                    "Заполнение тестовыми данными завершено")
Уведомление.Вид = ВидУведомления.Невидимое
Уведомление.СохранитьВЦентреУведомлений = Истина
Уведомление.ОценкаИнформации = ОценкаИнформации.Положительная
Уведомление.Показать()
```

## Добавление кнопок к уведомлению

По умолчанию уведомления не содержат кнопок, однако вы можете их добавить.

Рассмотрим следующий сценарий: менеджер создал новое поручение сотруднику и сразу же получил уведомление о том, что поручение было создано.

Уведомление «Поручение создано» содержит пояснение и кнопки «Открыть» и «Отмена», а также значок закрытия. [Описание иллюстрации](../figures/e950a7f5401a38e15974164a0343761a6a148276ebcaf4316214679b8c9a7520-8b48b0070eafc8b9.md)

Далее менеджер может открыть форму с поручением, нажав на кнопку **Открыть**, либо отменить поручение, нажав на кнопку **Отмена**. Кроме того, менеджер может закрыть уведомление нажатием на крестик: в таком случае ничего не произойдет.

Для добавления кнопок используйте тип `ФрагментКомандногоИнтерфейса<КомандаСПараметром<Уведомление>>` и свойство уведомления [`Команды`](../../wiki/interface/notification-ru-f537b2070755.md). Оно содержит массив описаний команд:

```xbsl
знч Уведомление = новый Уведомление("Поручение создано", 
                                    "Вы успешно создали новое поручение. Можете просмотреть его или отменить")

знч КомандаОткрыть = новый КомандаСПараметром<Уведомление>(&ОткрытьПоручениеИзУведомления, "Открыть")
знч КомандаОтмена = новый КомандаСПараметром<Уведомление>(&ОтменаИзУведомления, "Отмена")

Уведомление.Команды = новый ФрагментКомандногоИнтерфейса<КомандаСПараметром<Уведомление>>([КомандаОткрыть, КомандаОтмена])

Уведомление.Показать()
```

Обработчики событий кнопок `ПриНажатии` могут выглядеть следующим образом:

```xbsl
метод ОткрытьПоручениеИзУведомления(Команда: КомандаСПараметром<Уведомление>, Уведомление: Уведомление)
    // Действия при нажатии на кнопку "Открыть"
    // ...
;

метод ОтменаИзУведомления(Команда: КомандаСПараметром<Уведомление>, Уведомление: Уведомление)
    // Действия при нажатии на кнопку "Отмена"
    // ...
;
```

Кнопки не отображаются для [стандартных уведомлений браузера](../../wiki/project/notifications-cd338f518620.md): вы можете нажать только на само уведомление, и в этом случае будет выполнен обработчик нажатия первой кнопки. Остальные кнопки будут проигнорированы.

## Обработка закрытия уведомления

С помощью свойства `ПриЗакрытии` вы можете назначить обработчик, который будет выполнен при закрытии уведомления:

```xbsl
метод СоздатьУведомление()
    знч Уведомление = новый Уведомление("Поручение создано", 
                                        "Вы успешно создали новое поручение. Можете просмотреть его или отменить")
    Уведомление.СохранитьВЦентреУведомлений = Истина
    
    Уведомление.ПриЗакрытии = &ПриЗакрытииУведомления

    Уведомление.Показать()
;

метод ПриЗакрытииУведомления(Уведомление: Уведомление)
    // Действия при закрытии уведомления
    // ...
;
```

Этот обработчик будет вызван в следующих случаях:

- уведомление находится в центре уведомлений и пользователь нажал кнопку
  
  Очистить все
  
  ;
- пользователь нажал на крестик в компоненте уведомления в центре уведомлений.

Закрытие уведомления [Описание иллюстрации](../figures/bb4d01243501c1e54a698859296bdd66a26b692f5780c3564ea506f8e5412a61-795f8b52cccacfbd.md)

## Центр уведомлений

Центр уведомлений — это всплывающее окно, в котором сохраняются уведомления с флагом [`СохранитьВЦентреУведомлений`](../../wiki/interface/notification-ru-f537b2070755.md), равным `Истина` (по умолчанию он равен `Ложь` и уведомления не сохраняются в центре уведомлений).

Центр уведомлений [Описание иллюстрации](../figures/afa05a57d5b2bd818a6c649b7b221f6c9b132cbb1f9c228d858b2d0d67ffed6f-9b6c4cd3da2417ea.md)

Чтобы открыть центр уведомлений, нажмите на колокольчик в интерфейсе приложения. Уведомления, сохраняющиеся в центре уведомлений, появляются здесь одновременно с отображением всплывающего окна с уведомлением.
