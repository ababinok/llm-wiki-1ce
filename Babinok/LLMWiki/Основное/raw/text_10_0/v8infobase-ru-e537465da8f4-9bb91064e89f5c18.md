### ВключенаБлокировкаНачалаСеансов

`Доступность: Сервер`

```
ВключенаБлокировкаНачалаСеансов: Булево
```

Управляет режимом блокировки сеансов. Если установлено значение `Истина` и текущее время находится в диапазоне, определяемом свойствами [ВремяНачалаБлокировки](../../wiki/stdlib/v8infobase-ru-e537465da8f4.md) и [ВремяОкончанияБлокировки](../../wiki/stdlib/v8infobase-ru-e537465da8f4.md), то начало новых сеансов с информационной базой запрещено. Если при этом попытаться установить новый сеанс, то будет выброшено исключение, содержащее текст из значения свойства [СообщениеБлокировки](../../wiki/stdlib/v8infobase-ru-e537465da8f4.md). Для начала сеанса вопреки блокировке сеансов необходимо указать код разрешения, определяемый свойством [КодРазрешенияНачалаСеансов](../../wiki/stdlib/v8infobase-ru-e537465da8f4.md).

### ОбязательноеИспользованиеВнешнегоУправления

`Доступность: Сервер`

```
ОбязательноеИспользованиеВнешнегоУправления: Булево
```

Обязательность использования внешнего управления сеансами:

- `Истина`
  
  - при недоступности сервиса внешнего управления сеансами пользователю, начинающему сеанс, выдается сообщение об ошибке и начало сеанса с информационной базой не выполняется.
- `Ложь`
  
  - при недоступности сервиса внешнего управления сеансами, начало сеанса с информационной базой выполняется.

### СтрокаПараметровВнешнегоУправленияСеансами

`Доступность: Сервер`

```
СтрокаПараметровВнешнегоУправленияСеансами: Строка
```

Свойство предназначено для внешнего управления сеансами. В качестве значения используется строка параметров веб сервиса внешнего управления сеансами в формате: <Имя параметра>=<Значение> через символ ';' (точка с запятой).

Если <Значение> содержит пробелы или символы ';', то строку значения параметра следует заключать в кавычки ("). При этом, каждый из символов кавычки ("), присутствующий в строке <Значение>, должен быть экранирован (""). Параметры:

- 'wsdl' – URL-адрес для получения wsdl веб-сервиса;
- 'ns' – пространство имен веб-сервиса;
- 'srvc' – имя веб-сервиса;
- 'port' – имя порта веб-сервиса.
