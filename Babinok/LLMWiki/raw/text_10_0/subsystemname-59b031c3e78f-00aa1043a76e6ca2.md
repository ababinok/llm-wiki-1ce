## [{ИмяКомпонента}.Контекст](../../wiki/interface/componentname-context-ru-e40a3f370a75.md)

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяКомпонента}.Контекст` `Доступность: Сервер`

Специальный тип, который генерируется для каждого пользовательского компонента, содержит только контекстные свойства. Тип генерируется всегда, безусловно, независимо от того есть ли у него контекстные свойства или нет. В описании свойства компонента интерфейса существует признак Контекстное, тип [Булево](../../wiki/stdlib/boolean-ru-7823d4239bcc.md), значение по умолчанию `Ложь`. Свойство помеченное как Контекстное, обязано иметь тип доступный на клиенте и сервере. У пользовательского компонента появляется возможность описывать собственные серверные нестатические методы, помеченные аннотацией [Контекстный](../../wiki/stdlib/contextual-ru-468258bf9c74.md). Эта возможность доступна только в модулях пользовательских компонентов. В теле серверного метода, помеченного аннотацией [Контекстный](../../wiki/stdlib/contextual-ru-468258bf9c74.md), тип объекта этот будет заменен с [ИмяКомпонента](../../wiki/interface/componentname-ru-ca3fcf138ae8.md) на [ИмяКомпонента.Контекст](../../wiki/interface/componentname-context-ru-e40a3f370a75.md). Состояние этого объекта будет передаваться с клиента на сервер при каждом вызове этого метода с клиента. На сервере, в теле метода, можно изменять состояние этого объекта, затем оно автоматически будет доставлено на клиент и клиенсткий компонент, для которого был вызван этот метод; будет переинициализирован из этого состояния.

## [{ИмяПараметровРаботыКлиента}](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md)

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПараметровРаботыКлиента}` `Тип-одиночка` `Доступность: Клиент`

Объект-одиночка для работы с параметрами работы клиента. Сами значения параметров необходимо заполнить в обработчике `ВычислитьПараметрыРаботыКлиента`. Обработчик выполняется на сервере. В этом обработчике надо вернуть объект типа [ИмяПараметровРаботыКлиента.Параметры](../../wiki/stdlib/clientworkparametersname-parameters-ru-5d5afa6451b2.md). Значения свойств этого объекта будут доступны на клиенте через одноимённые свойства у типа-синглтона [ИмяПараметровРаботыКлиента](../../wiki/stdlib/clientworkparametersname-ru-879b332058a3.md). Если при выполнении обработчика происходит исключение, то при обращении к параметрам на клиенте будет попытка их вычисления ещё раз, а если и она не удалась - выброшено исключение [ИсключениеПараметрыРаботыКлиентаНеИнициализированы](../../wiki/interface/clientworkparametersnotinitializedexception-ru-852da47af9f8.md) При открытии приложения происходит вызов всех обработчиков и все их параметры передаются на клиента одним серверным вызовом.

## [{ИмяПроцессаИнтеграции}.Параметры](../../wiki/integration/integrationprocessname-parameters-ru-65d5d13a978a.md)

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПроцессаИнтеграции}.Параметры` `Доступность: Сервер`

Запрещено менять параметры процесса интеграции из обработчика узла данного процесса интеграции, это приведет к выбросу исключения [ИсключениеИнтеграционнойШины](../../wiki/integration/integrationbusexception-ru-0bbe235ac154.md).
