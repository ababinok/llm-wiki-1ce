## Свойства

### АкцентныйВторичныйЦвет

`Доступность: КлиентИСервер`

```
АкцентныйВторичныйЦвет: Авто|Цвет
```

Акцентный дополнительный цвет приложения.

---

### АкцентныйПервичныйЦвет

`Доступность: КлиентИСервер`

```
АкцентныйПервичныйЦвет: Авто|Цвет
```

Акцентный основной цвет приложения.

---

### ДопустимыеЦветовыеСхемы

`Доступность: КлиентИСервер`

```
ДопустимыеЦветовыеСхемы: Авто|Множество<ЦветоваяСхема>
```

Задаёт допустимые цветовые схемы, используемые приложением. Авто разрешается в зависимости от режима совместимости:

- Если РС <= 6.0: { Светлая }
- Если РС >= 7.0: { Светлая, Темная }

Если множество пустое, трактуется как Авто

---

### ЗаголовокСтраницыВхода

`Доступность: КлиентИСервер`

```
ЗаголовокСтраницыВхода: Строка
```

Заголовок страницы входа. Если не задан, то не отображается в интерфейсе.

---

### Логотип

`Доступность: КлиентИСервер`

```
Логотип: Url|ДвоичныйОбъект.Ссылка|?
```

Логотип приложения.

---

### ЛоготипКрупный

`Доступность: КлиентИСервер`

```
ЛоготипКрупный: Url|ДвоичныйОбъект.Ссылка|?
```

Задает макроверсию логотипа, которая будет отображаться:

- В развернутой версии меню в планшетной версии
- В развернутой версии меню в вертикальной версии декстоп
- В горизонтальной навигации десктоп

---

### ОтображатьТекстКомандНавигации

`Доступность: КлиентИСервер`

```
ОтображатьТекстКомандНавигации: Авто|Булево
```

Указывает необходимость отображения текста команд навигации в таббаре мобильного интерфейса.

---

### ПриветственныйТекстСтраницыВхода

`Доступность: КлиентИСервер`

```
ПриветственныйТекстСтраницыВхода: Строка
```

Приветственный текст страницы входа, который отображается под заголовком. Если не задан, то не отображается в интерфейсе.

---

### СообщениеСтраницыВхода

`Доступность: КлиентИСервер`

```
СообщениеСтраницыВхода: Строка
```

Подсказка, отображается в подвале страницы входа. Если не задана, то не отображается в интерфейсе.

---

### ФоновоеИзображение

`Доступность: КлиентИСервер`

```
ФоновоеИзображение: ДвоичныйОбъект.Ссылка?
```

Изображение будет отображаться на заднем плане всего приложения. Доступно только для веб-версии.

---

### ФоновоеИзображениеРазмытие

`Доступность: КлиентИСервер`

```
ФоновоеИзображениеРазмытие: Булево
```

Включает эффект размытия для фонового изображения.

---

### ФоновоеИзображениеУровеньРазмытия

`Доступность: КлиентИСервер`

```
ФоновоеИзображениеУровеньРазмытия: Число
```

Уровень размытия фонового изображения в пикселях.

---

### ЦветАктивнойВкладкиНавигации

`Доступность: КлиентИСервер`

```
ЦветАктивнойВкладкиНавигации: Авто|ЦветАктивнойВкладкиНавигации
```

Определяет цвет активной вкладки в мобильном интерфейсе.

---

### ЦветНастроекСписка

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ЦветНастроекСписка: Авто|ЦветНастроекСписка
```

Определяет цвета для панели настроек компонента [Список](../../wiki/interface/list-ru-58c40755a735.md) (фильтры, сортировки и т.п.).

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ЦветНастроекСписка](../../wiki/interface/listsettingscolor-ru-f52139e2bd8f.md).[Бесцветный](../../wiki/interface/listsettingscolor-ru-f52139e2bd8f.md).

---

### ЦветСсылок

`Доступность: КлиентИСервер`

```
ЦветСсылок: Авто|Цвет
```

Цвет для представления свойства [Значение](../../wiki/interface/label-ru-6b4ca5274ef9.md) компонента [Надпись](../../wiki/interface/label-ru-6b4ca5274ef9.md) в режиме гиперссылки (заполнено свойство [ПриНажатии](../../wiki/interface/label-ru-6b4ca5274ef9.md) или [Ссылка](../../wiki/interface/label-ru-6b4ca5274ef9.md), если [ОбрабатыватьНажатие](../../wiki/interface/label-ru-6b4ca5274ef9.md) равно `Истина`).

---

### ЦветоваяСхема

`Доступность: КлиентИСервер`

```
ЦветоваяСхема: Авто|ЦветоваяСхема
```

Цветовая схема приложения - тёмная, светлая либо Авто.
