Чтобы загрузить существующий [файл сборки](../../wiki/project/project-assemblies-22705683fda4.md) в панель управления, выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. На вкладке **Сборки** нажмите кнопку **+ Добавить сборку из выгрузки**.
  
  На вкладке «Сборки» проекта выделена кнопка «Добавить сборку из выгрузки» со знаком «+». [Описание иллюстрации](../figures/068b6d58662ba063174667a870fbf4b337653268d501c2a644ce89cd1a0de00c-f037f4049da96b3e.md)
4. Выберите файл сборки, который необходимо загрузить. Допустимые форматы: *.xasm*, *.xlib*, *.xprj*, *.xsas* и *.zip*.
5. В открывшемся окне нажмите **Создать**. Поля диалога будут заполнены автоматически данными из файла выгрузки сборки.
  
  Окно добавления сборки из выгрузки [Описание иллюстрации](../figures/b908187db4d08eb96a7e0a7d6b981b7323e4e5bf92ad4369f47a32b25aa85041-9bcf38a4e6c78688.md)

Если загрузка пройдет успешно, новая сборка появится в общем списке на вкладке **Сборки**.



Вы также можете загрузить сборку в панель управления с помощью HTTP-запроса. Более подробную информацию вы можете найти в данной статье: [Загрузить сборку из файла](https://1cmycloud.com/console/help/element/10.0/docs/console/post-console-api-v-2-1-projects-project-id-assemblies/).
