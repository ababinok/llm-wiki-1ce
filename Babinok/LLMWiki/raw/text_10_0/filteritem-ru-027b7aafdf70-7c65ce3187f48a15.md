`Стд::Интерфейс::Фильтры::ЭлементФильтра` `Доступность: КлиентИСервер`

Условие фильтра данных в виде сравнения поля данных с каким либо значением.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Конструкторы

### ЭлементФильтра

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ЭлементФильтра(
  Поле: Строка,
  ВидСравнения: ВидСравнения,
  Значение: Объект?,
  Использовать: Булево,
  Иерархия: Строка,
  ОтображатьВНастройках: Авто|ВидОтображенияФильтра,
  Представление: Авто|Строка)
```

Создает элемент фильтра с указанными значениями полей.

## Свойства

### ВидСравнения

`Доступность: КлиентИСервер`

```
ВидСравнения: ВидСравнения
```

Указывает вид сравнения.

---

### Значение

`Доступность: КлиентИСервер`

```
Значение: Объект?
```

Значение фильтра, с которым сравнивается значение поля выборки.

---

### Иерархия

`Версия 8.0 и выше`

`Доступность: КлиентИСервер`

```
Иерархия: Строка
```

Имя иерархии, для вида сравнения ВИерархии.

---

### Использовать

`Доступность: КлиентИСервер`

```
Использовать: Булево
```

Признак использования данного элемента фильтра для фильтрации выборки. Может использоваться для включения выключения отдельных элементов обора.

---

### ОтображатьВНастройках

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВНастройках: Авто|ВидОтображенияФильтра
```

Включает отображение описанного фильтра в интерфейс настроек.

Такая настройка влияет на свойство [Использовать](../../wiki/interface/filteritem-ru-027b7aafdf70.md), связанного с ней фильтра.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[НеОтображать](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).

---

### Поле

`Доступность: КлиентИСервер`

```
Поле: Строка
```

Имя поля выборки, по которому будет осуществляться фильтр. Если в выборке больше одной таблицы, и имя поля неоднозначно, то требуется указать псевдоним таблицы.

---

### Представление

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
Представление: Авто|Строка
```

Задает представление фильтра в интерфейсе.
