Представление — это строка, которая будет обозначать для пользователя тот или иной объект **Документа** во время работы приложения. Пока пользователь работает с документом, который представлен в виде таблицы, он видит все колонки этой таблицы и может отличить один объект **Документа** от другого. Но в тех случаях, когда, например, нужно обозначить конкретный объект **Документа** в отчете, необходима строка, по которой пользователь сможет однозначно понять, что это за объект **Документа**. Такая строка и называется **представлением**.

Чтобы задать представление объектов **Документа**, в проекте используйте свойство **Документа** **Представление**. В этом свойстве можно указать имя любого из реквизитов **Документа**, имеющего тип `Строка`. В том числе можно использовать те реквизиты, в которых содержатся строки неограниченной длины.

Также этот реквизит будет стандартно использоваться «1С:Предприятие.Элементом» в тех случаях, когда нужно отсортировать список объектов **Документа** или представить подходящие объекты документа при вводе по строке.

Если в проекте свойство **Документа** **Представление** не задано, то «Элемент» в качестве представления объектов **Документа** будет использовать строку "<>".

Если данные объекта **Документа** отсутствуют в базе данных («битая ссылка») или они недоступны в результате ограничений по правам, то в качестве представления «Элемент» будет использовать следующие строки:

- В обычном режиме:
  
  `<Объект не найден>`
  
  ;
- В
  
  режиме разработки
  
  :
  
  `<Объект не найден: Test::Документ.Накладная>`
  
  .
