Свойство — это способ доступа к внутреннему состоянию экземпляра, имитирующий переменную некоторого типа.

Пример:

```xbsl
метод ДанныеОФайле(МойФайл: Файл): Строка
    
    // Используем свойства экземпляра типа «Файл» как переменные
    знч ИмяФайла = МойФайл.Имя
    знч Путь = МойФайл.Путь

    возврат "Получен файл: $ИмяФайла, расположенный: $Путь"
;
```
