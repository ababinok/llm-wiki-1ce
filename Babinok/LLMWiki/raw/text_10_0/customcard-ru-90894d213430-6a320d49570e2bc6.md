## Свойства

### ОтступПоВертикали

`Доступность: Клиент`

```
ОтступПоВертикали: Авто|РазмерОтступа
```

Отступ от границ карточки до границ содержимого по вертикали.

---

### ОтступПоГоризонтали

`Доступность: Клиент`

```
ОтступПоГоризонтали: Авто|РазмерОтступа
```

Отступ от границ карточки до границ содержимого по горизонтали.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент?
```

Компонент, который будет предсталять собой содержимое карточки.
