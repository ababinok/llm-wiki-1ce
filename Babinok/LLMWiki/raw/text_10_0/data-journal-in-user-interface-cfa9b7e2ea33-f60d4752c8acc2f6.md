Во время работы приложения «1С:Предприятие.Элемент» автоматически генерирует форму списка для журнала данных. Вы не можете изменить внешний вид или логику работы этой формы. Поскольку журнал данных предназначен прежде всего для отображения данных нескольких элементов проекта, форма объекта для него не генерируется — журнал использует формы элементов, включенных в его [Состав](../../wiki/project/datajournal-3d0e7aa19753.md).

Автоматическая форма списка журнала данных **ОбщийЖурнал**:

Автоматическая форма списка журнала «ОбщийЖурнал»: общий поиск и создание записи, таблица с типом, номером и реквизитами документов разных видов. [Описание иллюстрации](../figures/5618875679473672a1a0a179e2ac7b683e02b6935e1ba0f5160e1a17980d972f-ca8fab6f0b6168f4.md)

## Создание собственных форм

Вы можете создать собственные формы, а затем указать, что журнал данных должен использовать именно их, с помощью свойства [Интерфейс.Список.Форма](../../wiki/project/datajournal-3d0e7aa19753.md).

Пользовательская форма списка «Общий журнал» показывает документы разных видов; команды и оформление отличаются от автоматической формы. Форму выбирают через Интерфейс.Список.Форма. Чтобы создать форму в коде, используйте метод [`СоздатьФормуСписка()`](../../wiki/stdlib/datajournalname-ru-529de137c48e.md) типа [`{ИмяЖурналаДанных}`](../../wiki/stdlib/datajournalname-ru-529de137c48e.md).

Например:

```xbsl
// Имя журнала данных — ОбщийЖурналДанных
пер ФормаЖурнала = ОбщийЖурналДанных.СоздатьФормуСписка()
ФормаЖурнала.Открыть()
```

Если для журнала данных задана соответствующая форма, то создается форма этого типа. Иначе создается автоматическая форма.

## Команды открытия форм

При добавлении элемента проекта **ЖурналДанных** «1С:Предприятие.Элемент» порождает тип [`{ИмяЖурналаДанных}.АвтоматическаяФормаСписка`](../../wiki/stdlib/datajournalname-automaticlistform-ru-1529ae9e298f.md) для работы с автоматической формой списка и добавляет в автоматический интерфейс приложения команду ее открытия.

Добавление формы в автоматический интерфейс приложения настраивается в группе свойств [Интерфейс](../../wiki/project/datajournal-3d0e7aa19753.md).

По умолчанию команда, которую «1С:Предприятие.Элемент» добавляет в интерфейс приложения, в качестве своего представления использует имя журнала данных в проекте. Вы можете изменить представление команды с помощью свойства [Интерфейс.Список.Представление](../../wiki/project/datajournal-3d0e7aa19753.md). Указанное представление будет также использоваться в качестве представления команды `{ИмяЖурналаДанных}.АвтоматическаяФормаСписка.Открыть()`.
