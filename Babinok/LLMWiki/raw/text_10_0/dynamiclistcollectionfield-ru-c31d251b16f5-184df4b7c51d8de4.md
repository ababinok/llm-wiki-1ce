## Конструкторы

### ПолеКоллекцияДинамическогоСписка

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ПолеКоллекцияДинамическогоСписка(
  Выражение: Строка,
  Псевдоним: Строка,
  Ограничить: Число,
  Представление: Строка,
  ОтображатьВНастройкахФильтров: Авто|Булево,
  ВключатьВДанныеСтроки: Булево,
  ОтображатьВАвтоматическихФильтрах: Авто|ВидОтображенияФильтра,
  ОграничениеДопустимыхЗначенийФильтра: ОписаниеОграниченияДопустимыхЗначенийФильтра,
  НастройкиАвтоматическогоФильтра: НастройкиАвтоматическогоФильтраПоляКоллекцииДинамическогоСписка)
```

Создает поле коллекцию динамического списка с полями по умолчанию.

## Свойства

### ВключатьВДанныеСтроки

`Доступность: КлиентИСервер`

```
ВключатьВДанныеСтроки: Булево
```

Флаг, указывающий на то, будет ли поле участвовать в выборке данных при запросе динамического списка. Если `Ложь` – поле будет применяться только для настройки динамического списка.

---

### Выражение

`Доступность: КлиентИСервер`

```
Выражение: Строка
```

Выражение, описывающее значение поля выборки. Могут использоваться поля основной и присоединенных таблиц. Нельзя использовать функции агрегации данных.

---

### НастройкиАвтоматическогоФильтра

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
НастройкиАвтоматическогоФильтра: НастройкиАвтоматическогоФильтраПоляКоллекцииДинамическогоСписка
```

Определяет настройки для автоматического фильтра.

---

### ОграничениеДопустимыхЗначенийФильтра

`Доступность: КлиентИСервер`

```
ОграничениеДопустимыхЗначенийФильтра: ОписаниеОграниченияДопустимыхЗначенийФильтра
```

Описание зависимости поля от другого для обеспечения фильтрации используемых настраиваемым полем данных относительно контрольного поля. Если контрольное поле будет содержать значение, которое не может содержаться в настраиваемом поле по определенному признаку - эти значения будут исключены из выбора значений для фильтра по этому полю.

#### Примеры

Здесь фильтр по полю `Метки` будет заполнен только метками, которые содержатся в реквизите `ИспользуемыеМетки` справочника поля `Задача`.

```yaml
-
    Тип: ПолеДинамическогоСписка
    ОтображатьВНастройкахФильтров: Истина
    Выражение: Задача
-
    Тип: ПолеКоллекцияДинамическогоСписка
    ОтображатьВНастройкахФильтров: Истина
    Выражение: Метки
    ОграничениеДопустимыхЗначенийФильтра:
        РеквизитПоляФильтраОграничения: ИспользуемыеМетки
        ВыражениеЗначенияФильтраОграничения: Задача
```

---

### Ограничить

`Доступность: КлиентИСервер`

```
Ограничить: Число
```

Максимальное количество элементов выбираемых из поля коллекция. 0 - без ограничения.

---

### ОтображатьВАвтоматическихФильтрах

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВАвтоматическихФильтрах: Авто|ВидОтображенияФильтра
```

Определяет способ отображения автоматического фильтра.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[Опционально](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).

---

### ОтображатьВНастройкахФильтров

`Доступность: КлиентИСервер`

```
ОтображатьВНастройкахФильтров: Авто|Булево
```

Флаг, указывающий на то, будет ли поле использоваться в механизме фильтров при настройке пользователем.

---

### ОтображатьВПростыхФильтрах

`Версия 9.0 и ниже`

`Доступность: КлиентИСервер`

```
ОтображатьВПростыхФильтрах: Авто|Булево
```

Флаг, указывающий на то, будет ли поле использоваться в окне простых фильтров при [ОтображатьВНастройкахФильтров](../../wiki/interface/dynamiclistcollectionfield-ru-c31d251b16f5.md) равным `Истина`.

Заменено на свойство [ОтображатьВАвтоматическихФильтрах](../../wiki/interface/dynamiclistcollectionfield-ru-c31d251b16f5.md).

---

### Представление

`Доступность: КлиентИСервер`

```
Представление: Строка
```

Представление для [ПолеКоллекцияДинамическогоСписка](../../wiki/interface/dynamiclistcollectionfield-ru-c31d251b16f5.md), которое будет отображено в окнах настроек компонента [Таблица](../../wiki/interface/table-ru-ccc43dec1ca9.md) (например, фильтрах) и в [КолонкаТаблицы](../../wiki/interface/tablecolumn-ru-90496d65cde5.md), если им явно не задано свойство [Заголовок](../../wiki/interface/tablecolumn-ru-90496d65cde5.md).

---

### Псевдоним

`Доступность: КлиентИСервер`

```
Псевдоним: Строка
```

Псевдоним поля. Если не задан, и в выражении задано обращение к полю, то псевдоним равен имени поля. Если из поля невозможно сформировать псевдоним, то рантайм ошибка. По псевдониму поля можно получить доступ к данным в строке динамического списка.
