`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПодчиненногоРегистраСведений}.НаборЗаписей.Фильтр` `Доступность: Сервер`

Объект предназначен для задания значений ключевых полей, по которым отбираются записи, попадающие в набор записей. Является составной частью объектов типа [ИмяПодчиненногоРегистраСведений.НаборЗаписей](../../wiki/data/subordinatedinformationregistername-recordset-ru-2530ab1eeede.md) (см. свойство `Фильтр`). Подчиненный регистр сведений содержит **единственный** элемент фильтра `Регистратор`.

`Доступность: Сервер` `ТолькоЧтение`

КлючОсновногоФильтра: {ИмяПодчиненногоРегистраСведений}.КлючОсновногоФильтра

### Регистратор

`Доступность: Сервер` `ТолькоЧтение`

```
Регистратор: Сущность.НаборЗаписей.Фильтр.Элемент<{ИмяДокумента}.Ссылка?>
```

Элемент фильтра, соответствующий стандартному полю `Регистратор`. Содержит ссылку на документ-регистратор, по которому выполняется отбор записей.
