## Примеры

**Общие примеры**

```xbsl
метод ПолучитьАтрибутЭлемента(Элемент: ЭлементHtml)
    // Дано Элемент.ВнешнийКод() <div id="app-switcher" class="aui-dropdown2 aui-style-default" role="menu"></div>
    пер Результат = ""
    для Атрибут из Элемент.Атрибуты
        Результат += Атрибут.Имя + " : " + Атрибут.Значение + "\н"
    ;
    // Результат будет равен
    // id : app-switcher
    // class : aui-dropdown2 aui-style-default 
    // role : menu
;
```

## Конструкторы

### АтрибутHtml

`Доступность: Сервер`

```
АтрибутHtml(
  Имя: Строка,
  Значение: Строка?,
  КодированноеЗначение: Булево = Ложь)
```

Создает новый атрибут из значения (передавать Неопределено, если это булевый атрибут в html5), автоматически атрибут добавлен в коллекцию не будет. Если установлен флаг КодированноеЗначение, то значение не будет кодироваться дополнительно.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если переданное имя атрибута не удовлетворяет стандарту.

## Свойства

### ДиапазонВКоде

`Доступность: Сервер` `ТолькоЧтение`

```
ДиапазонВКоде: ДиапазонВТексте?
```

Диапазон атрибута в коде или `Неопределено`, если элемента, к которому относится атрибут не было в изначальном html.

---

### ЕстьЗначение

`Доступность: Сервер` `ТолькоЧтение`

```
ЕстьЗначение: Булево
```

Признак того, что значение для атрибута установлено.

---

### Значение

`Доступность: Сервер`

```
Значение: Строка?
```

Раскодированное значение атрибута. `Неопределено`, если атрибут булевый.

---

### Имя

`Доступность: Сервер` `ТолькоЧтение`

```
Имя: Строка
```

Имя атрибута.
