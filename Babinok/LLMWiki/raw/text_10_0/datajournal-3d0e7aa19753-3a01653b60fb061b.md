Предназначен для совместного просмотра различных документов и справочников. Для журнала данных могут быть заданы [Колонки](../../wiki/project/datajournal-3d0e7aa19753.md), предназначенные для отображения реквизитов сущностей, включенных в данный журнал.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../../wiki/language/modular-development-80166cfecf93.md).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных для использования в [полнотекстовом поиске](../../wiki/project/full-text-search-99b98022003a.md).

---

#### Состав

```yaml
Состав: 
    -
        Элемент: Строка
```

Коллекция элементов проекта, входящих в данный журнал. Не может быть пустым.

<details>
<summary>**Свойства**</summary>

##### Элемент

Имя элемента проекта, входящего в состав журнала. Поддерживаются следующие виды элементов проекта:

- [Справочник](../../wiki/data/catalog-e0da7d4e8e72.md)
  
  ,
- [Документ](../../wiki/data/document-4eb9c3e92277.md)
  
  .

</details>

---

#### Индексы

```yaml
Индексы: 
    -
        Имя: Строка
        Поля: Строка[]
        ДополнительныеПоля: Строка[]
```

Наборы основных и дополнительных полей, по которым будут созданы индексы в базе данных.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Поля

Набор основных полей, по которым будет создан индекс в базе данных.

##### ДополнительныеПоля

Набор дополнительных полей, по которым будет создан индекс в базе данных.

</details>

---

#### Интерфейс

```yaml
Интерфейс: 
    ВключатьВАвтоИнтерфейс: Булево
    Список: 
        Представление: Строка|СсылкаНаЛокализованнуюСтроку
        Изображение: ДвоичныйОбъект.Ссылка?
        Форма: Строка
```

Группа свойств, которые описывают пользовательский интерфейс элемента проекта.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды в [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Список

Секция, которая содержит описание, влияющее на автоматически генерируемую форму списка и команду `ОткрытьСписок`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](../../wiki/project/app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой списка для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

</details>

## Дочерние элеметы

#### Колонки

```yaml
Колонки: КолонкаЖурналаДанных[]
```

Перечень колонок журнала. Колонки журнала соответствуют полям таблицы в базе данных. Может быть пустым. Если свойство не задано, журнал состоит только из стандартных колонок.
