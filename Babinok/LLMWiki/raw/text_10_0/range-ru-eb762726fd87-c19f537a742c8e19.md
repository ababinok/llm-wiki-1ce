`Стд::Диапазон<ТипГраницы>` `Доступность: КлиентИСервер`

ТипГраницы: тип границы диапазона. Ограничения параметра типа: Стд::Сравнимое<BoundType>.

Диапазон, границы интерпретируются включительно. Диапазон называется открытым (сверху/снизу), если в качестве границы указано `Неопределено` (трактуется как значение большее/меньшее всех остальных)

**Сравнение**

Структурное

Оба типа диапазонов ([ЗакрытыйДиапазон](../../wiki/stdlib/closedrange-ru-7f62ab997f5b.md) и [Диапазон](../../wiki/stdlib/range-ru-eb762726fd87.md)) сравнимы между собой и не учитывают параметр типа. Сравниваются границы между собой.

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

*Дочерние типы:* [ЗакрытыйДиапазон](../../wiki/stdlib/closedrange-ru-7f62ab997f5b.md)

## Конструкторы

### Диапазон

`Доступность: КлиентИСервер`

```
Диапазон(
  От: ТипГраницы?,
  До: ТипГраницы?)
```

Создает диапазон с указанными границами

`От`

и

`До`

.

`Неопределено`

в качестве границы трактуется как значение большее/меньшее всех остальных.

---

## Свойства

### До

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
До: ТипГраницы?
```

Верхняя граница диапазона. `Неопределено` трактуется как значение большее всех остальных.

---

### От

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
От: ТипГраницы?
```

Нижняя граница диапазона. `Неопределено` трактуется как значение меньшее всех остальных.

---


Возвращает строковое представление в виде

---

### Пересекает

`Доступность: КлиентИСервер`

```
Пересекает(Диапазон: Диапазон<ТипГраницы>): Булево
```

Проверяет пересечение диапазона

`Диапазон`

с текущим диапазоном.

---

### Содержит

`Доступность: КлиентИСервер`

```
Содержит(Диапазон: Диапазон<ТипГраницы>): Булево
```

Проверяет полное вхождение диапазона

`Диапазон`

в текущий диапазон.

**Перегрузка** [Содержит(Значение: ТипГраницы): Булево](../../wiki/stdlib/range-ru-eb762726fd87.md)

---

### Содержит

`Доступность: КлиентИСервер`

```
Содержит(Значение: ТипГраницы): Булево
```

Проверяет вхождение значения

`Значение`

в диапазон.

**Перегрузка** [Содержит(Диапазон: Диапазон<ТипГраницы>): Булево](../../wiki/stdlib/range-ru-eb762726fd87.md)
