Реализует механизм хранения настроек каких-либо настраиваемых объектов, а также предоставляет функционал по управлению настройками и организации доступа к ним.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

Представление элемента, которое отображается в интерфейсе приложения.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../../wiki/language/modular-development-80166cfecf93.md).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования записей хранилища настроек для использования в [полнотекстовом поиске](../../wiki/project/full-text-search-99b98022003a.md).

#### Интерфейс

```yaml
Интерфейс: 
    ВключатьВАвтоИнтерфейс: Булево
    Список: 
        Представление: Строка|СсылкаНаЛокализованнуюСтроку
        Изображение: ДвоичныйОбъект.Ссылка?
        Форма: Строка
    ИспользоватьСозданиеПриВводе: Булево
    Объект: 
        Представление: Строка|СсылкаНаЛокализованнуюСтроку
        Изображение: ДвоичныйОбъект.Ссылка?
        Форма: Строка
    ВажностьИзбранногоПользователя: Отсутствует|Обычная|Высокая
```

Группа свойств, которые описывают пользовательский интерфейс элемента проекта.

<details>
<summary>**Свойства**</summary>

##### ВключатьВАвтоИнтерфейс

Признак включения команды в [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md). Значение по умолчанию — **Истина**.

##### Список

Секция, которая содержит описание, влияющее на автоматически генерируемую форму списка и команду `ОткрытьСписок`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](../../wiki/project/app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой списка для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

##### ИспользоватьСозданиеПриВводе

Определяет отображение кнопки создания элемента в выпадающем списке поля ввода ссылочного типа, если:

- не задано свойство
  
  ОтображатьКомандуСоздания
  
  в свойстве
  
  [НастройкиВводаСсылок](../../wiki/interface/edit-ru-4027d1cb7b27.md)
  
  поля ввода;
- не задано свойство
  
  [ОтображатьКомандуСоздания](../../wiki/interface/edit-ru-4027d1cb7b27.md)
  
  для поля ввода.

##### Объект

Секция, которая содержит описание, влияющее на автоматически генерируемую форму объекта и команду `СоздатьОбъект`.

<details>
<summary>**Свойства**</summary>

##### Представление

Представление команды.

Значение по умолчанию — пустая строка, в качестве представления используется имя сущности в проекте.

Свойство **Представление** поддерживает [локализацию](../../wiki/project/app-localization-15f5b1317f82.md). Чтобы задать идентификатор локализованной строки, необходимо в начале использовать символ «$», например: `$МояПодсистема::МоиЛокализованныеСтроки.Строка1`.

##### Изображение

Картинка команды.

##### Форма

Имя компонента пользовательского интерфейса, являющегося формой объекта для данного элемента проекта. Значение по умолчанию — пустая строка, форма генерируется автоматически.

</details>

##### ВажностьИзбранногоПользователя

Определяет вид отображения команды работы с **Избранным** внутри формы.

</details>

#### КонтрольДоступа

```yaml
КонтрольДоступа: 
    Разрешения: 
        ПоУмолчанию: КонтрольДоступа
        Создание: КонтрольДоступа
        Чтение: КонтрольДоступа
        Изменение: КонтрольДоступа
        Удаление: КонтрольДоступа
    РасчетРазрешенийПо: Строка[]
    СтандартныеРазрешения: Булево
```

Описание прав на элемент.

<details>
<summary>**Свойства**</summary>

##### Разрешения

Набор записей следующего вида: [`Право: СпособКонтроляДоступа`](../../wiki/security/project-element-permissions-12c1d76e1615.md).

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Создание

Возможность создания нового экземпляра сущности. Проверяется непосредственно перед записью изменения в базу данных.

##### Чтение

Возможность чтения экземпляра сущности из базы данных. Проверяется только в момент загрузки ссылки/ключа записи из базы данных.

##### Изменение

Возможность изменения экземпляра сущности, хранящегося в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

##### Удаление

Возможность удаления экземпляра сущности. Проверяется в момент вызова удаления.

</details>

##### РасчетРазрешенийПо

Реквизиты, по которым рассчитываются разрешения.

##### СтандартныеРазрешения

Признак использования [стандартных разрешений](../../wiki/data/settings-repository-3d8ee27a26de.md) контроля доступа. Если значение свойства равно `Истина`, то хранилище настроек использует следующую стандартную реализацию контроля доступа на уровне отдельных элементов проекта (RLS):

- аутентифицированный пользователь имеет полный доступ к собственным настройкам;
- администраторы имеют полный доступ к настройкам других пользователей;
- аутентифицированный пользователь может загрузить (только чтение) общую настройку.

</details>

```yaml

        Имя: Строка

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Поля

Набор основных полей, по которым будет создан индекс в базе данных.

##### ДополнительныеПоля

Набор дополнительных полей, по которым будет создан индекс в базе данных.

</details>

#### ПараметрыЗаписи

```yaml
ПараметрыЗаписи: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать запись объекта. В обработчики `ПередЗаписью()`, `ПослеЗаписи()` и перегрузку метода `Записать()` добавляются соответствующие параметры. Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Множество типов, доступных для параметра.

</details>

---

#### ПараметрыУдаления

ПараметрыУдаления: 
    -
        Имя: Строка
        Тип: Тип[]

Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
