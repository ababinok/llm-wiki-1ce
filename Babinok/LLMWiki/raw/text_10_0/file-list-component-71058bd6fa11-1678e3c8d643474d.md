Позволяет добавлять, просматривать и удалять прикрепленные файлы. Поддерживает загрузку файлов через стандартный диалог выбора файлов, кнопку добавления или перетаскивание.

Компонент «СписокФайлов»: пунктирная область с пиктограммой и подсказкой выбрать либо перетащить файлы; ниже показано ограничение размера файла в демонстрационном примере. [Описание иллюстрации](../figures/4d746ea7699ccc95be7c3b74e9f7435a19f35927b3a85f1e8e3caac4434180ad-4cb423c51b9037ce.md)

Чтобы добавить компонент в свой проект и настроить его, выполните следующие действия:

- [Добавьте компонент](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md) с помощью дерева компонентов в редакторе компонентов интерфейса.
- С помощью панели [свойств](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md) установите [заголовок](../../wiki/interface/file-list-component-71058bd6fa11.md) и [текст кнопки загрузки](../../wiki/interface/file-list-component-71058bd6fa11.md).
- С помощью панели [свойств](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md) настройте ограничения на прикрепляемые файлы по [размеру отдельных файлов](../../wiki/interface/file-list-component-71058bd6fa11.md), по [общему размеру всех прикрепляемых файлов](../../wiki/interface/file-list-component-71058bd6fa11.md), по их количеству (укажите [максимальное](../../wiki/interface/file-list-component-71058bd6fa11.md) или [минимальное](../../wiki/interface/file-list-component-71058bd6fa11.md)) или [по формату](../../wiki/interface/file-list-component-71058bd6fa11.md).
- Установите события, вызываемые [загрузкой](../../wiki/interface/file-list-component-71058bd6fa11.md) или [удалением](../../wiki/interface/file-list-component-71058bd6fa11.md) файла из списка, а также [нажатием](../../wiki/interface/file-list-component-71058bd6fa11.md) на строку списка.

Форма со списками файлов: загруженные файлы представлены строками с иконкой, именем, форматом, размером и командой удаления; загружаемый файл имеет индикатор прогресса. Ниже отдельные области перетаскивания документов и фотографий. [Описание иллюстрации](../figures/de2686f83b86d7e6b463a048c43f21d6e7fe28ff3459e40582856c5df3bd285a-dab41fb38e535591.md)

## Свойства

### Заголовок

`Авто|Строка`. Заголовок компонента — строка, которая отображается над левым верхнем углом компонента. Значение по умолчанию — имя связанного реквизита.

Заголовок «Заголовок» расположен над левым верхним краем компонента списка файлов; ниже область выбора или перетаскивания файлов. [Описание иллюстрации](../figures/e0b43636879b383e9ac5aa4ce15a3b1d3c4d1b5d38b502949d07d3fca04ad2cc-1309fcda3189dcaf.md)

### Значение

`Массив<ДвоичныйОбъект.Ссылка>`. Задает изначальное значение загруженных файлов. Значение по умолчанию — пустой массив.

### МаксимальноеКоличествоФайлов

`Авто|Число`. Устанавливает ограничение на максимальное количество прикрепляемых файлов. `0` — ограничений нет. `Авто = 0` (по умолчанию ограничений нет).

### МаксимальныйРазмерФайла

`Авто|РазмерБайтов`. Устанавливает ограничение на максимальный размер файла в байтах. `0` — ограничений нет. `Авто = 10737418240` (10 ГБ).

### МаксимальныйСуммарныйРазмерФайлов

`Авто|РазмерБайтов`. Устанавливает ограничение на максимальный суммарный размер в байтах всех загружаемых файлов. `0` — ограничений нет. `Авто = 10737418240` (10 ГБ).

### МинимальноеКоличествоФайлов

`Авто|Число`. Устанавливает ограничение на минимальное количество прикрепленных файлов. `0` — ограничение нет. `Авто = 0` (по умолчанию ограничений нет).

### ПриЗагрузкеФайла

Событие, вызываемое при успешной загрузке файла.

Сигнатура обработчика события:

```xbsl
метод СписокФайловПриЗагрузкеФайла(Источник: СписокФайлов, 
                                   Событие: СобытиеСДанными<ДвоичныйОбъект.Ссылка>)
;
```

### ПриНажатииСтроки

Событие, вызываемое при нажатии на строку списка.

Сигнатура обработчика события:

```xbsl
метод СписокФайловПриНажатииСтроки(Источник: СписокФайлов,
                                   Событие: СобытиеСДанными<ДвоичныйОбъект.Ссылка>)
;
```

Если обработчик события не задан, то по умолчанию в веб-приложении на компьютере пользователя никакие действия не выполняются, а в мобильном приложении выполняется скачивание файла.

### ПриУдаленииФайла

Событие, вызываемое при удалении файла из списка.

Сигнатура обработчика события:

```xbsl
метод СписокФайловПриУдаленииФайла(Источник: СписокФайлов, 
                                   Событие: СобытиеСДанными<ДвоичныйОбъект.Ссылка>)
;
```

### ТекстКнопкиЗагрузки

`Авто|Строка`. Текст кнопки добавления файлов к списку. Кнопка отображается, если добавлен хотя бы один файл и дальнейшее добавление возможно (например, не достигнуто [`МаксимальноеКоличествоФайлов`](../../wiki/interface/file-list-component-71058bd6fa11.md)). Значение по умолчанию — `Авто = "Добавить файл"`.

В списке файлов под прикреплённым документом показана кнопка со знаком «+» и текстом «Текст кнопки загрузки файлов»; её подпись выделена рамкой.. [Описание иллюстрации](../figures/007937bbbce0017a66d98f17e04cb98b2e55cbf057e6a13fd2376384e27c37e6-b2d8f6b1d45195a7.md)

### Фильтр

`Массив<Строка>`. Список разрешенных к загрузке расширений (начинаются с точки: `.doc`, `.pdf`, `.xls` и др.) и/или MIME-типов файлов (например: `image/*`, `application/pdf`, `video/mp4` и т. д.).
