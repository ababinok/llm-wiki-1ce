Пользовательский интерфейс — это часть приложения, обеспечивающая взаимодействие пользователя с приложением. Состоит из двух частей:

1. Непосредственно пользовательский интерфейс — визуальные элементы, предназначенные для показа информации пользователю и для изменения этой информации.
2. Командный интерфейс
  
  — кнопки, ссылки, команды, которые позволяют пользователю перемещаться по разделам приложения, открывать формы, выполнять те или иные действия.

Пользовательский интерфейс, генерируемый компонентом [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md), может содержать следующие элементы:

- панель навигации
  
  ;
- область содержимого
  
  ;
- вкладки последнего уровня навигации;
- панель действий
  
  ;
- дополнительный командный интерфейс
  
  .
