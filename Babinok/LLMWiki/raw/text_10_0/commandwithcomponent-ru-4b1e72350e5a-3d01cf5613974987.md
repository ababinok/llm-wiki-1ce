`Стд::Интерфейс::Команды::КомандаСКомпонентом<ТипКомпонента>` `Доступность: Клиент`

ТипКомпонента: Тип компонента, над экземпляром которого будет выполняться команда. Ограничения параметра типа: Стд::Интерфейс::Компонент.

Команда с компонентом - позволяет описать команду привязанную к конкретному компоненту. Например, команду закрытия формы.

**Сравнение**

Ссылочное

Структурное сравнение.

## Конструкторы

### КомандаСКомпонентом

`Версия 9.0 и выше`

`Доступность: Клиент`

```
КомандаСКомпонентом(
  Компонент: ТипКомпонента,
  Обработчик: (КомандаСКомпонентом<ТипКомпонента>)->ничто,
  Представление: Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|? = Неопределено,
  Важность: ВажностьКоманды = ВажностьКоманды.Обычная,
  Доступность: Булево = Истина,
  Видимость: Булево = Истина,
  ОпасностьДействия: ОпасностьДействия = ОпасностьДействия.Отсутствует)
```

Создает команду с компонентом с заданными полями и обработчиком.
