## Методы

### Открыть

`Версия 10.0 и выше`

`Доступность: Клиент` `Статический`

```
@ИменованныеПараметры
Открыть(
  СвойствоФормы1: ТипСвойстваФормы1,
  СвойствоФормы2: ТипСвойстваФормы2,
  СвойствоФормыN: ТипСвойстваФормыN
): ТипРезультата?
```

>

Вызов возможен только с именованными параметрами

Открывает форму данного типа. Допускает только именованную форму вызова. Открывает форму по-разному и возвращает разные результаты в зависимости от свойства [СпособОткрытия](../../wiki/interface/form-ru-89fb5e7eaeb3.md).

- Если
  
  [СпособОткрытия](../../wiki/interface/form-ru-89fb5e7eaeb3.md)
  
  =
  
  [ВМодальномОкне](../../wiki/interface/formopenmethod-ru-9ca1bcb027a4.md)
  
  или
  
  [ВоВсплывающемОкне](../../wiki/interface/formopenmethod-ru-9ca1bcb027a4.md)
  
  , то возвращает значение, переданное в метод
  
  [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md)
  
  или
  
  `Неопределено`
  
  , если форма была закрыта через "крестик". Метод не вернет управление вызывающему коду, пока окно не закроется.
- Иначе, возвращает
  
  `Неопределено`
  
  . Метод вернет управление вызывающему коду, как только окно откроется.

Параметры:

- `СвойстваФормы`
  
  - дополнительные свойства формы, которые будут ей установлены при ее открытии.

### Открыть

- `КлючИсточникаКопирования`
  
  - Ссылка на источник копирования.

## Обработчики

### ПослеСоздания

```
ПослеСоздания()
```

Вызывается после создания UI-компонента системой:

- установлены значения свойств самого компонента, указанные в описании,
- созданы внутренние компоненты данного компонента, значения их свойств установлены из описаний их экземпляров,
- обработчики событий подписаны на события самого компонента и его внутренних компонентов. Предназначено для дополнительной инициализации свойств компонента на клиенте и вызова прикладной логики инициализации компонента.

---

### ПриОбновлении

```
ПриОбновлении()
```

Событие возникает при инициации обновления данных формы с использованием команды

[Обновить](../../wiki/interface/form-ru-89fb5e7eaeb3.md)

или с помощью жеста

`Pull-To-Refresh`

на мобильных устройствах. При этом в

[ФормаОбъекта](../../wiki/interface/objectform-ru-b5cec9fb1ea3.md)

это происходит после обновления данных объекта. В

[ФормаСписка](../../wiki/interface/listform-ru-f0fc0cdb7cd0.md)

- после обновления данных списка системой.

---

### ПослеЗакрытия

```
ПослеЗакрытия()
```

Событие возникающие после закрытия формы, означающее что форма уже закрыта и процесс закрытия нельзя отменить или прервать.

---

### ПередЗакрытием

```
ПередЗакрытием(Событие: ПараметрыЗакрытияФормы)
```

Событие возникающие перед закрытием формы. Параметр

`Событие`

типа

[ПараметрыЗакрытияФормы](../../wiki/interface/formcloseparams-ru-b4203dc56e56.md)

содержит свойство

[РежимЗакрытияФормы](../../wiki/interface/formcloseparams-ru-b4203dc56e56.md)

, которое может принять следующие значения:

- [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  - Закрывает форму и выполняет стандартную обработку.
- [Закрыть](../../wiki/interface/formclosemode-ru-03d39171d2f5.md)
  
  - Закрывает форму без выполнения стандартной обработки.
- [НеЗакрывать](../../wiki/interface/formclosemode-ru-03d39171d2f5.md)
  
  - Не закрывает форму, стандартная обработка не выполняется.

---

### ПослеЧтения

```
ПослеЧтения()
```

Возникает после чтения данных объекта. Вызывается, в том числе, для формы новой записи, а также после записи, так как в процессе записи данные могли измениться на сервере.

---

### ПередЗаписью

```
ПередЗаписью()
```

Вызывается перед началом записи на сервере.

---

### ПослеЗаписи

```
ПослеЗаписи()
```

Вызывается после завершения процесса записи на сервере.

---

### ПередУдалением

```
ПередУдалением()
```

Вызывается перед началом удаления объекта на сервере.

---

### ПослеУдаления

```
ПослеУдаления()
```

Вызывается после завершения процесса удаления объекта на сервере.
