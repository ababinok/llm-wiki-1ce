### ПриСозданииНаОсновании

```
ПриСозданииНаОсновании(Основание: <Типисточникасозданиянаосновании>)
```

Вызывается при создании нового экземпляра интегрируемого приложения на основании другого объекта. Подразумевается, что в этом обработчике события разработчик приложения должен реализовать логику создания экземпляра интегрируемого приложения на основании чего-то.

Параметр `Основание` содержит то, на основании чего создается объект.

Если в элементе проекта интегрируемого приложения в качестве источников создания на основании (свойство `СозданиеНаОсновании`) указано несколько оснований, то будет столько же перегрузок этого события (параметр `Основание` будет тех типов, которые указаны в свойстве `СозданиеНаОсновании`).

Например, если у интегрируемого приложения указаны источники создания на основании:

Если у элемента проекта не указано источников создания на основании, то это событие будет отсутствовать.

## Обработчики

### ПриЗаполнении

```
ПриЗаполнении(ТекстЗаполнения: Строка = "")
```

Обработчик, вызываемый при:

- Интерактивном создании (открытии формы нового объекта)
- Вызове метода
  
  [Заполнить](../../wiki/stdlib/integrableapplicationname-object-ru-2facace672c0.md)
  
  (Параметр
  
  `ТекстЗаполнения`
  
  при этом равен пустой строке)

Предназначен для предзаполнения сущности в интерактивном режиме. Параметр `ТекстЗаполнения` содержит текст, введенный в поле ввода перед нажатием кнопки создания нового элемента.

---

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяИнтегрируемогоПриложения}.Данные)
```

Вызывается при создании нового экземпляра интегрируемого приложения копированием существующего. На момент вызова этого обработчика значения реквизитов у нового объекта будут уже заполнены из элемента - источника Не будет автоматически копироваться стандартный реквизит

`Код`

интегрируемого приложения. Кроме того, не будут копироваться реквизиты, копирование которых отключено в интегрируемом приложении с помощью свойства

`ЗаполнятьПриКопировании`

.

Параметр `Источник` содержит данные исходного экземпляра интегрируемого приложения, копированием которого и создается новый элемент.
