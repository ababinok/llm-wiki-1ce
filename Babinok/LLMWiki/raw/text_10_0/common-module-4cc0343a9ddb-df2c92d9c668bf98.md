Общий модуль — это произвольный модуль, который вы можете создать в проекте и использовать по своему желанию. Эти модули создают тип-одиночку, имя которого совпадает с именем модуля.



Обычно общие модули используют для того, чтобы разместить в них переиспользуемые фрагменты кода — методы, которые вы вызываете из разных частей вашего проекта.

Общему модулю необходимо указать окружение, в котором он будет доступен. Используйте для этого свойство **Окружение**: **Сервер**, **Клиент** или **КлиентИСервер**.

> [!TIP] совет
> В общем модуле может находиться реализация [контракта сервиса](../../wiki/project/service-contract-5b8423b5cca0.md).
