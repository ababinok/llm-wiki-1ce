Элемент проекта — это часть проекта, описывающая некоторую функциональность, например: справочник **Сотрудники**, перечисление **СостояниеЗаказов** и т. д.

«1С:Предприятие.Элемент» поддерживает различные виды элементов: **Справочник**, **Перечисление**, **Структура** и т. д. Вы можете добавлять их в проект, тем самым создавая описание логики приложения.

Для описания интерфейса приложения существуют элементы специального вида — компоненты интерфейса.
