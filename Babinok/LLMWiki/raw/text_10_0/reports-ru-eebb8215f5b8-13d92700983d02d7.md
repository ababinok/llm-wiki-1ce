## Свойства

### ОткрытьАнализДанных

`Доступность: Клиент` `ТолькоЧтение`

```
ОткрытьАнализДанных: Команда
```

Команда открытия приложения для анализа данных. Приложение открывается в новом окне (вкладке) браузера.

```yaml
ВидЭлемента: ФрагментКомандногоИнтерфейса

Элементы:
  - =Отчет1.Открыть
  - =Отчет2.Открыть
  - =Отчет3.Открыть
  - =Отчеты.ОткрытьАнализДанных
```

## Методы

### НайтиОтчетПоИд

`Доступность: Сервер`

```
НайтиОтчетПоИд(Ид: Строка): Отчет?
```

Выполняет поиск отчета по идентификатору

`Ид`

.

Если отчет с указанным `Ид` не существует, возвращает `Неопределено`.

---

### ОткрытьОтчет

`Доступность: Клиент`

```
ОткрытьОтчет(
  Отчет: Отчет,
  ОткрыватьВНовомОкне: Булево = Истина)
```

Открывает отчет

`Отчет`

в приложении для анализа данных с возможностью редактирования.

Параметр `ОткрыватьВНовомОкне` указывает, следует ли открывать отчет в новом окне (вкладке) браузера.
