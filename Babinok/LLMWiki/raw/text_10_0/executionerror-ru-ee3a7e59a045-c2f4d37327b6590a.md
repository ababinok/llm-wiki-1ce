### ИдКлиента

`Версия 9.0 и выше`

`Доступность: Сервер` `ТолькоЧтение`

```
ИдКлиента: Строка?
```

Содержит идентификатор, уникальный для данного клиентского устройства.

Для всех приложений на данном сервере этот идентификатор будет одинаковый. Идентификатор создается системой и хранится в браузере пользователя. Если пользователь пользуется несколькими браузерами, то для каждого используемого браузера идентификатор будет свой. Идентификатор будет сборшен при полной очистки данных браузера для страницы приложения. В приватном режиме браузера идентификатор не сохраняется при закрытии окна браузера.
