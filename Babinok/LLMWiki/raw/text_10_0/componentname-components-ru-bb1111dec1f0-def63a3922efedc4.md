`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяКомпонента}.Компоненты` `Доступность: Клиент`

Специальный тип, позволяющий обращаться к компонентам, описанным в YAML-описании пользовательского компонента по именам. Каждому компоненту, описанному в YAML с указанием имени соответствует одноименное свойство, имеющее тип этого компонента.

Доступно через свойство [ИмяКомпонента.Компоненты](../../wiki/interface/componentname-components-ru-bb1111dec1f0.md) в модуле компонента интерфейса

**Сравнение**

Ссылочное

Сравнение по ссылке.

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Сравнение**

```yaml
ТипОбъекта: ПроизвольноеКлиентскоеПриложение
Имя: МоеПриложение
КорневойКомпонент:
    Тип: Группа
    Имя: КорневаяГруппа
    ДочерниеКомпоненты:
        -
            Тип: Кнопка
            Имя: ТестКнопка
            Заголовок: Тест кнопка
```

Для данного описания пользовательского компонента будет сгенерирован тип `МоеПриложение.Компоненты` со следующими свойствами:

- `КорневаяГруппа`
  
  :
  
  [Группа](../../wiki/interface/group-ru-9e7fcb6be273.md)
- `ТестКнопка`
  
  :
  
  [Кнопка](../../wiki/interface/button-ru-d0cdd9e186f7.md)
