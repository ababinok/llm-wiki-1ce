`Стд::МассивБитов` `Доступность: КлиентИСервер`

Изменяемая конечная последовательность битов фиксированного размера. Бит с индексом `0` является младшим. Размер массива задает допустимый диапазон индексов: `0 .. Размер() - 1`.

Сравнение структурное: массивы считаются равными, если у них совпадают размер и значения битов с одинаковыми индексами.

## Операция []

`Изменяемый`

```
[Ключ: Число]: Булево
```

Чтение и запись значения бита по индексу. При чтении возвращается текущее значение бита. При записи биту присваивается указанное значение.

**[ИсключениеИндексВнеГраниц](../../wiki/stdlib/indexoutofboundsexception-ru-2b34a623369c.md)** - если Индекс не лежит в диапазоне `0 .. Размер() - 1`.

### Пример

```xbsl
метод ПримерИндексатора(): Число
  знч Массив = МассивБитов.ИзЧисла(0b0000, 4)
  // Массив[1] = Истина
  возврат Массив.ВЧисло()
;
```

Результат:

```text
0b0010
```

### МассивБитов

`Доступность: КлиентИСервер`

```
МассивБитов(
  Размер: Число,
  Значение: Булево = Ложь)
```

Создает битовый массив заданного размера и инициализирует все биты указанным значением. Если параметр

`Значение`

не задан, используется

`Ложь`

, то есть все биты создаются сброшенными. Если

`Значение = Истина`

, все биты становятся установленными.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Размер < 0.

**Перегрузка** [МассивБитов()](../../wiki/stdlib/bitarray-ru-825b6d370ecc.md) [МассивБитов(Источник: МассивБитов, Размер: Число? = Неопределено)](../../wiki/stdlib/bitarray-ru-825b6d370ecc.md)

#### Примеры

```xbsl
метод ПримерКонструктораСРазмером(): Число
  возврат новый МассивБитов(4, Истина).ВЧисло() // все 4 бита сразу становятся установленными
;
```

Результат:

```text
0b1111
```

### МассивБитов

`Доступность: КлиентИСервер`

```
МассивБитов(
  Источник: МассивБитов,
  Размер: Число? = Неопределено)
```

Создает новый битовый массив из

`Источник`

. Если

`Размер`

не задан, используется размер источника. Если

`Размер`

больше размера источника, недостающие старшие биты становятся сброшенными. Если

`Размер`

меньше размера источника, старшие биты отбрасываются.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Размер < 0.

**Перегрузка** [МассивБитов()](../../wiki/stdlib/bitarray-ru-825b6d370ecc.md) [МассивБитов(Размер: Число, Значение: Булево = Ложь)](../../wiki/stdlib/bitarray-ru-825b6d370ecc.md)

#### Примеры

```xbsl
метод ПримерКонструктораИзМассива(): Число
  знч Источник = МассивБитов.ИзЧисла(0b101101, 6)
  возврат новый МассивБитов(Источник, 4).ВЧисло() // старшие биты за пределами размера 4 отбрасываются
;
```

Результат:

```text
0b1101
```

### ВБайты

`Доступность: КлиентИСервер`

```
ВБайты(Длина: Число? = Неопределено): Байты
```

Преобразует массив битов в байтовое представление. Если

`Длина`

не задана, возвращается минимально достаточная длина в байтах:

`ceil(Размер() / 8)`

. Если

`Длина`

задана, результат имеет ровно указанную длину. При недостатке длины старшие байты отбрасываются, при избытке результат дополняется нулевыми старшими байтами.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Длина < 0.

#### Примеры

```xbsl
метод ПримерПреобразованияВБайты(): Число
  знч Байты = МассивБитов.ИзЧисла(0b101011, 8).ВБайты() // получается один байт 00101011
  возврат МассивБитов.ИзБайтов(Байты, 8).ВЧисло() // обратное преобразование восстанавливает то же значение
;
```

Результат:

```text
0b00101011
```

### ВСтроку

`Доступность: КлиентИСервер`

```
ВСтроку(): Строка
```

Возвращает строковое двоичное представление массива битов. Длина строки всегда равна

`Размер()`

. Первый символ соответствует старшему биту массива, последний символ - младшему. Ведущие сброшенные биты сохраняются, поэтому строка подходит для отладки и визуального сравнения массивов одинакового размера. Если

`Размер() = 0`

, возвращается пустая строка.

#### Примеры

```xbsl
метод ПримерПреобразованияВСтроку(): Строка
  возврат МассивБитов.ИзЧисла(0b110001, 8).ВСтроку() // ведущие нули сохраняются
;
```

Результат:

```text
00110001
```

### ВЧисло

`Доступность: КлиентИСервер`

```
ВЧисло(Положительное: Булево = Истина): Число
```

Преобразует массив битов в число. Если

`Положительное = Истина`

, значение интерпретируется как неотрицательное. Если

`Положительное = Ложь`

, значение интерпретируется как число в дополнительном коде относительно текущего размера массива. Это позволяет корректно восстановить отрицательное число из фиксированной разрядности.

#### Примеры

```xbsl
метод ПримерПреобразованияВЧисло(): Число
  возврат МассивБитов.ИзЧисла(-5, 8).ВЧисло(Ложь) // значение читается как число в дополнительном коде
;
```

Результат:

```text
-5
```

### ИзЧисла

`Доступность: КлиентИСервер` `Статический`

```
ИзЧисла(
  Источник: Число,
  Размер: Число? = Неопределено
): МассивБитов
```

Создает новый битовый массив из числа. Если

`Источник`

неотрицательный и

`Размер`

не задан, используется минимальная битовая длина двоичного представления источника. Если

`Источник`

отрицательный,

`Размер`

должен быть задан явно. В этом случае используется представление в дополнительном коде в рамках заданной разрядности. Если

`Размер`

задан, результат имеет ровно указанную длину: недостающие старшие биты становятся сброшенными, а лишние старшие биты отбрасываются.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Размер < 0.

#### Примеры

```xbsl
метод ПримерИзЧисла(): Число
  возврат МассивБитов.ИзЧисла(0b101011, 8).ВЧисло() // число дополняется до 8 битов ведущими нулями
;
```

Результат:

```text
0b00101011
```

```xbsl
;
```

### ПобитовыйАрифметическийСдвигВправо

`Доступность: КлиентИСервер`

```
ПобитовыйАрифметическийСдвигВправо(Смещение: Число): МассивБитов
```

Выполняет арифметический сдвиг вправо на заданное количество позиций. Освободившиеся старшие биты получают значение знакового бита, то есть старшего бита текущего массива. В отличие от логического сдвига вправо, освободившиеся старшие биты могут становиться установленными, если старший бит массива был установлен. Если Смещение >= Размер(), весь массив заполняется сброшенными или установленными битами в зависимости от текущего старшего бита. Возвращает этот же экземпляр МассивБитов.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Смещение < 0.

#### Примеры

```xbsl
метод ПримерПобитовогоАрифметическогоСдвигаВправо(): Число
  знч Массив = МассивБитов.ИзЧисла(-16, 8)
  Массив.ПобитовыйАрифметическийСдвигВправо(2)
  возврат Массив.ВЧисло(Ложь)
;
```

Результат:

```text
-4
```

### ПобитовыйЛогическийСдвигВправо

`Доступность: КлиентИСервер`

```
ПобитовыйЛогическийСдвигВправо(Смещение: Число): МассивБитов
```

Выполняет логический сдвиг вправо на заданное количество позиций. Освободившиеся старшие биты становятся сброшенными. В отличие от арифметического сдвига вправо, значение старшего бита массива при заполнении не учитывается. Если Смещение >= Размер(), все биты массива сбрасываются, а размер сохраняется. Возвращает этот же экземпляр МассивБитов.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Смещение < 0.

#### Примеры
