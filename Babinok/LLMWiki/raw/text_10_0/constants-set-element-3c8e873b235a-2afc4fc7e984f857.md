Элемент проекта **НаборКонстант** предназначен для хранения постоянной или условно-постоянной информации. Такая информация либо совсем не изменяется в процессе работы приложения, либо изменяется достаточно редко. Наиболее простой пример подобной информации — название организации, которое, как правило, не меняется.

Информацию из констант можно использовать, например, при формировании документов, в расчетах, при построении отчетных форм. Значение константы также можно редактировать.

Чтобы создать собственный набор констант, [добавьте в проект](../../wiki/project/add-project-element-9c25777c6bb1.md) элемент вида **НаборКонстант**. Данные о константах будут храниться в составной части элемента проекта — **Константы**.

Пример набора констант ДанныеОрганизации в навигаторе: внутри раздела Константы находятся Название, Адрес, Телефон, ЭлПочта. [Описание иллюстрации](../figures/24dfc0d5fcd139b181d0ab9cc41853f92be1248a52137f99cbcab8e348d4a45d-6813a42ba0eab0e4.md)

Для набора констант «1С:Предприятие.Элемент» формирует в языке запросов соответствующую таблицу [`{ИмяНабораКонстант}`](../../wiki/queries/constantssetname-ru-1f089c423cf4.md), которая содержит записи данного набора. Для примера выше можно использовать следующий запрос:

```xbsl
знч Запрос = Запрос{
    ВЫБРАТЬ
        ДанныеОрганизации.Название КАК Название,
        ДанныеОрганизации.Адрес КАК Адрес,
        ДанныеОрганизации.Телефон КАК Телефон,
        ДанныеОрганизации.ЭлПочта КАК ЭлПочта
    ИЗ
        ДанныеОрганизации КАК ДанныеОрганизации
}
```

## Периодический набор констант

Вы можете хранить в наборе констант постоянную информацию за определенные периоды времени, например для хранения информации о курсе валют в определенный день. Для этого в свойствах элемента проекта задайте значение свойства **Периодичность**.

<details>
<summary>Пример YAML-файла периодического набора констант</summary>

```yaml

Ид: 3f94dc11-4bc1-4abc-8fa2-2a9bbdfd3db5
Имя: КурсДоллара
ОбластьВидимости: ВПодсистеме
Периодичность: День
ИспользоватьВПолнотекстовомПоиске: Истина
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
Константы:
    -
        Ид: 948984a8-71a9-4624-82a9-a0d5418f6266
        Имя: КурсЦБ
        Тип: Число
        ИспользоватьВПолнотекстовомПоиске: Истина
        ДлинаДробнойЧасти: 2
        ДлинаЦелойЧасти: 3
    -
        Ид: 93863898-9858-44a1-9eea-729a10a187d1
        Имя: КурсМосБиржи
        Тип: Число?
        ИспользоватьВПолнотекстовомПоиске: Истина
        ДлинаДробнойЧасти: 4
        ДлинаЦелойЧасти: 3
    -
        Ид: 2244ebb0-aac8-4e2a-ae98-b44ac7f1f6e5
        Имя: Комментарий
        Тип: Строка
        ИспользоватьВПолнотекстовомПоиске: Истина
ПараметрыЗаписи:
    -
        Имя: Валидировать
        Тип: Булево?

    -
        Имя: НельзяУдалятьСтарыеЗаписи
        Тип: Булево?
```

</details>

В таблицах, которые «1С:Предприятие.Элемент» формирует в языке запросов для периодического набора констант, автоматически создается поле **Период**, которое позволяет выбрать записи за заданный период времени.

Например, следующий запрос выбирает все изменения курса доллара за указанный месяц, где курс ЦБ превышает 80 рублей, сортируя результаты от последних к более ранним датам.

```xbsl
знч Запрос = Запрос{
    ВЫБРАТЬ
        Курс.Период КАК ДатаИзменения,
        Курс.КурсЦБ КАК КурсЦентробанка,
        Курс.КурсМосБиржи КАК КурсБиржи
    ИЗ
        КурсДоллара КАК Курс
    ГДЕ
        Курс.Период >= %НачалоМесяца
        И Курс.Период < %КонецМесяца
        И Курс.КурсЦБ > 80
    УПОРЯДОЧИТЬ ПО
        ДатаИзменения УБЫВ
}
```

Также для периодического набора констант «1С:Предприятие.Элемент» формирует виртуальную таблицу [`{ИмяНабораКонстант.СрезПоследних}`](../../wiki/queries/constantssetname-slicelast-ru-2f3c22540fec.md), которая возвращает последние внесенные в набор записи. Срез формируется на основе записей, у которых значение поля **Период** меньше или равно указанному значению параметра. При наличии нескольких записей с одинаковыми значениями в результате будет использоваться запись с самым большим значением периода.

Если значение параметра `Неопределено`, возвращаются последние актуальные записи (с максимальным значением поля `Период` на текущий момент).

Например, следующий запрос выбирает курсы валют, актуальные на дату `ДатаСреза`.

```xbsl
знч Запрос = Запрос{
    ВЫБРАТЬ
        Курс.Период КАК ДатаАктуальности,
        Курс.КурсЦБ КАК КурсЦентробанка,
        Курс.КурсМосБиржи КАК КурсБиржи
    ИЗ
        КурсДоллара.СрезПоследних(%ДатаСреза) КАК Курс
    УПОРЯДОЧИТЬ ПО
        ДатаАктуальности УБЫВ
}
```

## Права набора констант

Для работы с правами набора констант используйте перечисление [`НаборКонстантПраво`](../../wiki/stdlib/constantssetprivilege-ru-634dda6518e0.md). Перечисление имеет следующие элементы: **Чтение** и **Изменение**.

Например, для некоторого набора констант, который описывает настройки телеграм-бота, можно установить право на чтение следующим образом:

```xbsl
метод ПолучитьТокен(): Строка
    исп КонтекстДоступа.Дополнить(Тип<НастройкиТелеграмБота.Запись>, [НаборКонстантПраво.Чтение])
    возврат НастройкиТелеграмБота.Получить().ТокенТелеграмБота
;
```
