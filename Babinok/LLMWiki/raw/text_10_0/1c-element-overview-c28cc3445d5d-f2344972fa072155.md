«1С:Предприятие.Элемент» — облачная технология low-code разработки веб-кабинетов, порталов, браузерных и мобильных приложений. Ее встроенные механизмы помогут упростить управление тысячами приложений. Используйте готовые решения для часто встречающихся задач без необходимости писать большой объем кода.

### Знакомство со средой разработки

Среда разработки — это компонент «1С:Предприятие.Элемента» для создания, изменения и отладки проектов, которые хранятся на сервере. Веб-среда разработки предоставляет:

- [встроенный редактор кода](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md)
  
  с функциями поиска, подсветки синтаксиса, автодополнения, проверки и форматирования кода;
- [редактор интерфейса](../../wiki/interface/application-ui-overview-0af555da9f86.md)
  
  с функцией предварительного просмотра для редактирования и настройки компонентов интерфейса прямо в среде разработки без запуска приложения;
- [механизм отладки](../../wiki/project/start-debugging-d5c5117b447f.md)
  
  с возможностью задавать точки останова, просматривать значения переменных и пошагово выполнять код;
- [систему контроля версий](../../wiki/project/connect-to-gitlab-daf8c8c732dc.md)
  
  , которая позволяет управлять исходным кодом, отслеживать изменения, создавать ветки для изолированной разработки и тестирования нового функционала;
- возможность
  
  [групповой разработки](../../wiki/project/set-up-collaborative-development-62562bbfba3b.md)
  
  для эффективного взаимодействия команды разработчиков.

### Работа с приложениями

Прочтите, как [создать новое приложение](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-new-application-in-control-panel/), [включить режим разработки](../../wiki/project/enable-development-mode-a5c31499eca5.md), [обновить приложение](https://1cmycloud.com/console/help/element/10.0/docs/topics/update-one-app/), [создать его резервную копию](https://1cmycloud.com/console/help/element/10.0/docs/topics/back-up-application/) или [восстановить из выгрузки](https://1cmycloud.com/console/help/element/10.0/docs/topics/restore-application/).

### Интерфейс

«1С:Предприятие.Элемент» предоставляет готовые [компоненты пользовательского интерфейса](../../wiki/interface/application-ui-overview-0af555da9f86.md): кнопки, диаграммы, выпадающие меню и другие. Вы можете изменить их внешний вид и поведение или оставить предопределенные настройки.

Если ваш проект содержит только функциональные элементы и не содержит компонентов интерфейса, «1С:Предприятие.Элемент» сгенерирует для приложения [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md). Он позволяет переходить ко всем элементам приложения, а также создавать и сохранять их данные.

### Пользователи

В «1С:Предприятие.Элементе» работать с пользователями можно из [панели управления](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-user/), а также [в коде](../../wiki/project/users-3a8d7024a3d7.md).

Используйте различные системы аутентификации (например, [CAS](https://1cmycloud.com/console/help/element/10.0/docs/topics/cas-authentication/), [Active Directory](https://1cmycloud.com/console/help/element/10.0/docs/topics/active-directory-authentication/) или [ЕСИА](https://1cmycloud.com/console/help/element/10.0/docs/topics/set-up-esia-authentication/)), встроенные в технологию «1С:Предприятие.Элемент».

### API панели управления

Используйте [API панели управления](https://1cmycloud.com/console/help/element/10.0/docs/console/%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D1%8B-api/), чтобы автоматизировать и упростить взаимодействие с большим количеством объектов. С его помощью вы можете выполнять почти все действия, которые доступны из пользовательского интерфейса: [создавать пользователей](https://1cmycloud.com/console/help/element/10.0/docs/console/%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D0%B8/), настраивать работу [приложений](https://1cmycloud.com/console/help/element/10.0/docs/console/%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F/), работать с [пространствами](https://1cmycloud.com/console/help/element/10.0/docs/console/%D0%BF%D1%80%D0%BE%D1%81%D1%82%D1%80%D0%B0%D0%BD%D1%81%D1%82%D0%B2%D0%B0/) и т. д.
