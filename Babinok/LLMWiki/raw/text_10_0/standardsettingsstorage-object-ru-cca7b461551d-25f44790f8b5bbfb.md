## Свойства

### Вариант

`Доступность: КлиентИСервер`

```
Вариант: Булево
```

"Уникальная" настройка или "Вариант".

Хранилище должно обеспечивать одну уникальную запись для набора значений КлючОбъекта, КлючНастройки, Пользователь и значением Вариант = Ложь, но при этом может быть несколько записей с теми же значениями полей КлючОбъекта, КлючНастройки, Пользователь и значением Вариант = Истина.
