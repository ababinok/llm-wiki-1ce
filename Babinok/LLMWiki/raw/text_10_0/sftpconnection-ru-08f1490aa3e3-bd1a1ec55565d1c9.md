`Стд::Ssh::СоединениеSftp` `Доступность: Сервер`

Представляет интерфейс для взаимодействия с сервером про протоколу SFTP. Возвращается методом [ОткрытьСоединениеSftp](../../wiki/integration/sshconnection-ru-ddf18cfbb82f.md).

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Закрываемое](../../wiki/stdlib/closeable-ru-67cd73fca69d.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Общие примеры**

```xbsl
метод ЗагрузитьФайл(Файл: Файл)
    исп Соединение = новый СоединениеSsh("192.168.0.3", "user", "password")
    исп Фтп = Соединение.ОткрытьСоединениеSftp()
    Фтп.УстановитьТекущийКаталог("/tmp/")
    Фтп.Поместить(Файл)
;
```

---

## Свойства

### СоединениеSsh

`Доступность: Сервер` `ТолькоЧтение`

```
СоединениеSsh: СоединениеSsh
```

Соединение SSH, на основе которого работает данное соединение SFTP. При закрытии соединения SSH-соединения данное SFTP-соединение также будет закрыто.

---

### ТекущийКаталог

`Доступность: Сервер` `ТолькоЧтение`

```
ТекущийКаталог: Строка
```

Текущая директория на сервере. При открытии соединения свойство заполняется директорией по умолчанию. Команда SFTP: pwd.

---

## Методы

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Возвращает строковое представление в виде

`SFTP Connection: "%Пользователь@%Сервер:%Порт"`

**Переопределение** [Объект::ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)

---

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

Закрывает соединение. Повторное закрытие не выполняет никаких действий. После закрытия соединения все остальные методы будут выбрасывать ИсключениеSftp.

**Переопределение** [Закрываемое::Закрыть](../../wiki/stdlib/closeable-ru-67cd73fca69d.md)

---

### Переименовать

`Доступность: Сервер`

```
Переименовать(
  Путь: Строка,
  НовоеИмя: Строка,
  Таймаут: Длительность? = Неопределено)
```

Переименовывает файл или директорию по пути

`Путь`

на сервере в новое имя

`НовоеИмя`

. Путь абсолютный (начинается с "/") или относительный текущему каталогу на сервере.

`Таймаут`

- время ожидания завершения операции, при значении

`Неопределено`

время ожидания не ограничено.

#### Исключения

**[ИсключениеSftp](../../wiki/integration/sftpexception-ru-b1502c5e1bd8.md)** - в случае ошибки взаимодействия с сервером или по истечении таймаута. **[ИсключениеФайловойСистемыSftp](../../wiki/integration/sftpfilesystemexception-ru-90f123104919.md)** - в случае ошибки файловой системы на стороне сервера.
