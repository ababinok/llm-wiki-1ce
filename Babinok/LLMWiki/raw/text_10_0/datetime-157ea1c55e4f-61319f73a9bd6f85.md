`ДатаВремя` — это преемник типа `Дата` из языка «1С:Предприятия 8». Он предназначен для работы одновременно и с датой, и с временем (локальные дата и время). Экземпляры этого типа содержат время с точностью до миллисекунд.

## Литерал

Значение типа `ДатаВремя` может быть задано в читаемом формате с помощью литерала.

«1С:Предприятие 8»

```bsl
// Результат = 29.05.2020 16:53:00
Дата1 = '202005291653';
```

«1С:Элемент»

```xbsl
// Результат = 29.05.2020 16:53:00.000
пер Дата1 = ДатаВремя{2020-05-29 16:53}
```

## Свойства и методы

Экземпляры типа `ДатаВремя` имеют свойства и методы.

«1С:Предприятие 8»

```bsl
Дата1 = '202005291653';
НачалоМесяца = НачалоМесяца(Дата1);
НачалоЗавтра = КонецДня(Дата1) + 1;
```

«1С:Элемент»

```xbsl
пер Дата1 = ДатаВремя{2020-05-29 16:53}
пер НачалоМесяца = Дата1.НачалоМесяца()
пер НачалоЗавтра = Дата1.НачалоДня()
                        .ДобавитьДни(1)
```

[Подробнее](../../wiki/language/datetime-type-d35f61464c24.md) про тип `ДатаВремя`.

Кроме типа `ДатаВремя` существуют и другие типы для работы с датой и временем:

- `Время`
  
  — для работы исключительно со временем, без учета даты;
- `Дата`
  
  — для работы исключительно с датой, без учета времени;
- `Момент`
  
  — для работы одновременно и с датой, и со временем (дата и время, указанные для временной зоны UTC);
- `Длительность`
  
  — количество миллисекунд, описывающих некоторый интервал времени.
