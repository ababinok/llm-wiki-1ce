Содержит строки, которые должны быть переведены на доступные языки локализации ([подробнее](../../wiki/project/app-localization-15f5b1317f82.md)).

Локализованные строки могут использоваться в таких элементах, как:

- команды меню;
- заголовки кнопок, полей, переключателей и т. д.;
- строки, формируемые в коде.

Полный список компонентов, поддерживающих подстановку локализованных строк, можно посмотреть [здесь](../../wiki/interface/components-with-localization-support-4153919eea00.md).

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../../wiki/language/modular-development-80166cfecf93.md).

---

#### Строки

```yaml
Строки: Соответствие<Строка,Строка>
```

Строки, которые должны быть переведены на другие языки. Для каждой строки указывается ее ключ (идентификатор) и значение. Строки можно использовать в описании компонентов интерфейса и элементов проекта, а также в коде.

---

#### Шаблоны

```yaml
Шаблоны: Соответствие<Строка,Строка>
```

Локализуемые строковые шаблоны, в которые можно подставлять значения переменных. Для каждого шаблона указывается его ключ (идентификатор) и значение. Шаблоны можно использовать только в коде.
