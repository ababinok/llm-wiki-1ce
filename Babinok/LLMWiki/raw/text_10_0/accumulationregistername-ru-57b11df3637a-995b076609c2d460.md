Таблица движений регистра накопления. Записи таблицы генерируются в процессе проведения и обработки документов, являющихся регистраторами для регистра накопления.

---

## Примеры

Пример запроса к таблице регистра накопления **ОстаткиНоменклатуры**:

```xbql
ВЫБРАТЬ
    ОстаткиНоменклатуры.Регистратор КАК Регистратор,
    ОстаткиНоменклатуры.Период КАК Период,
    ОстаткиНоменклатуры.ВидЗаписи КАК ВидЗаписи,
    ОстаткиНоменклатуры.Номенклатура КАК Номенклатура,
    ОстаткиНоменклатуры.Склад КАК Склад,
    ОстаткиНоменклатуры.Количество КАК Количество,
    ОстаткиНоменклатуры.Сумма КАК Сумма,
    ОстаткиНоменклатуры.Индекс КАК Индекс,
    ОстаткиНоменклатуры.КлючЗаписи КАК КлючЗаписи
ИЗ
    ОстаткиНоменклатуры КАК ОстаткиНоменклатуры
```

---

## Поля

### {ИмяИзмерения}

```
{ИмяИзмерения}: ТипИзмерения
```

Значение измерения записи регистра накопления.

---

### {ИмяРесурса}

```
{ИмяРесурса}: ТипРесурса
```

Числовое значение ресурса записи регистра накопления. Длина целой части числа не может превышать 24.

---

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита записи регистра накопления.

---

### Регистратор

`Ключевое поле`

```
Регистратор: ИмяДокумента.Ссылка?
```

Ссылка на документ, которому подчинена запись регистра накопления.

---

### Период

```
Период: ДатаВремя
```

Дата записи регистра накопления.

---

### Активность

```
Активность: Булево
```

Признак влияния записи на итоги регистра.

---

### ВидЗаписи

```
ВидЗаписи: ВидЗаписиРегистраНакопления
```

Значение системного перечисления `ВидЗаписиРегистраНакопления`, которое обозначает направление приращения указанных в записи ресурсов: `Приход` или `Расход`. Данное поле актуально только для регистра накопления вида **Остатки**.

---

### Индекс

`Вычисляемое поле`

```
Индекс: Число
```

Индекс (начиная с 0) записи регистра накопления в наборе записей, подчиненных документу, указанному в поле **Регистратор**.

---

### НомерСтроки

`Вычисляемое поле`

```
НомерСтроки: Число
```

Порядковый номер (начиная с 1) записи регистра накопления в наборе записей, подчиненных документу, указанному в поле **Регистратор**.

---

### КлючОсновногоФильтра

`Вычисляемое поле`

```
КлючОсновногоФильтра: ИмяРегистраНакопления.КлючОсновногоФильтра
```

Структура, описывающая ключ основного фильтра регистра накопления. Содержит единственное поле — **Регистратор**.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяРегистраНакопления.КлючЗаписи
```

Ссылка на запись регистра накопления.

---

## Индексы

### ПериодРегистраторИндекс

Индекс, включающий поля **Период**, **Регистратор** и **Индекс**.

---

### ПоляДанныхДляРасчетаРазрешений

Индекс по полям указанными в настройке `РасчетРазрешенийПо` элемента проекта.
