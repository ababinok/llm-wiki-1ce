После того как вы добавили в проект панель отчетов, «1С:Предприятие.Элемент» создаст несколько типов, имена которых в общем случае выглядят следующим образом:

- `<ИмяПанелиОтчетов>`
  
  ,
- `<ИмяПанелиОтчетов>.АвтоматическаяФорма`
  
  ,
- `<ИмяПанелиОтчетов>.Открыть`
  
  .

Например, если в проекте есть панель отчетов **ОтчетыРуководителя**, то будут созданы следующие типы:

- `ОтчетыРуководителя`
  
  ,
- `ОтчетыРуководителя.АвтоматическаяФорма`
  
  ,
- `ОтчетыРуководителя.Открыть`
  
  .

## <ИмяПанелиОтчетов>

Для каждой панели отчетов формируется соответствующий тип объекта.

Доступность: Сервер / Клиент

Базовый тип: [`Отчет`](../../wiki/stdlib/report-ru-262c53c7ab2e.md)

Экземпляр объекта может быть создан в коде на сервере и на клиенте с помощью конструктора без параметров.

## <ИмяПанелиОтчетов>.АвтоматическаяФорма

Автоматическая форма просмотра панели отчетов в приложении.

Базовый тип: [`ФормаОтчета`](../../wiki/interface/reportform-ru-a6c5b64077dc.md)

В качестве заголовка формы используется **Представление** панели отчетов. Содержимое формы — компонент [ПросмотрОтчета](../../wiki/interface/reportviewer-ru-c2fcfa1af193.md), который отображает панель отчетов в режиме чтения.

## <ИмяПанелиОтчетов>.Открыть

Навигационная команда, которая открывает связанную с панелью отчетов форму отчета.

Базовый тип: [`НавигационнаяКоманда`](../../wiki/interface/navigationcommand-ru-8290d7424fc8.md)

## <ИмяПанелиОтчетов>.Параметры.<ИмяПараметра>

Если в дизайнере панели отчетов определен [параметр](../../wiki/project/use-report-parameters-6257f3b8a42b.md), для которого задан список допустимых значений, то для этого параметра «1С:Предприятие.Элемент» создаст перечисление с именем `<ИмяПанелиОтчетов>.Параметры.<ИмяПараметра>`.

Например, пусть в панели **ОтчетыОСотрудниках** задан параметр **Срез**, содержащий следующие значения:

У параметра панели «Срез» включено «Создать элемент управления»; значение по умолчанию — «По региону». [Описание иллюстрации](../figures/7af5d11ad8ca56b2d0f5c426fc33ec46390416ee3e6991eff165e5a5d5896405-aa0baf2c4f514fc9.md)

«1С:Предприятие.Элемент» сформирует перечисление `ОтчетыОСотрудниках.Параметры.Срез`, содержащее следующие элементы:

- `ПоРегиону`
  
  ,
- `ПоДолжности`
  
  .

Вы можете установить значение параметра в коде следующими способами:

- в конструкторе:
  
  ```xbsl
  знч Панель = новый ОтчетыОСотрудниках(Срез = ОтчетыОСотрудниках.Параметры.Срез.ПоДолжности)
  ```
- с помощью свойства `<ИмяПанелиОтчетов>.Параметры.<ИмяПараметра>`:
  
  ```xbsl
  знч Панель = новый ОтчетыОСотрудниках()
  Панель.Параметры.Срез = ОтчетыОСотрудниках.Параметры.Срез.ПоДолжности
  ```
