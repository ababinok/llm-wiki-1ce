`Стд::Интерфейс::ОбщиеКомпоненты::Надпись` `Доступность: Клиент`

Компонент для вывода надписей в виде текста или гиперссылки. Может иметь заголовок, изображение и дополнительное значение.

**Сравнение**

Ссылочное

*Базовые типы:* [Компонент](../../wiki/interface/component-ru-bad1c84be995.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

### МаксимальнаяВысотаВСтроках

`Доступность: Клиент`

```
МаксимальнаяВысотаВСтроках: Авто|Число
```

Максимальная высота надписи в строках. Значение 0 снимает ограничение на расширение по высоте. Если текст не влезает в заданное количество строк, то в месте обрезки текста добавляется многоточие. Свойство [МинимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md) является более приоритетным, [МаксимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md) будет увеличена, если значение меньше, чем [МинимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md).

---

### МинимальнаяВысотаВСтроках

`Доступность: Клиент`

```
МинимальнаяВысотаВСтроках: Авто|Число
```

Минимальная высота надписи в строках. Вертикальный размер надписи не станет меньше ограничения, несмотря на содержимое текста. Может использоваться для выравнивания высоты строк в таблицах или других компонентах. Свойство [МинимальнаяВысота](../../wiki/interface/component-ru-bad1c84be995.md) имеет больший приоритет. Свойство [МаксимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md) является менее приоритетным. Значение свойства [МаксимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md) будет увеличено, если его значение меньше, чем у свойства [МинимальнаяВысотаВСтроках](../../wiki/interface/label-ru-6b4ca5274ef9.md).

---

### ОбрабатыватьНажатие

`Доступность: Клиент`

```
ОбрабатыватьНажатие: Авто|Булево
```

Управляет отображением надписи в виде гиперссылки.

- `Авто`
  
  - определяется системой автоматически, будет равно
  
  `Истина`
  
  , если выполнено одно из условий:
  
  - свойство
    
    [Значение](../../wiki/interface/label-ru-6b4ca5274ef9.md)
    
    имеет ссылочный тип
  - свойство
    
    [Ссылка](../../wiki/interface/label-ru-6b4ca5274ef9.md)
    
    заполнено
  - задан обработчик события
    
    [ПриНажатии](../../wiki/interface/label-ru-6b4ca5274ef9.md)
- `Истина`
  
  - компонент принимает внешний вид гиперссылки. Обрабатывает нажатие (позволяет обработать событие
  
  [ПриНажатии](../../wiki/interface/label-ru-6b4ca5274ef9.md)
  
  и стандартную обработку перехода по ссылке), может принимать фокус.
- `Ложь`
  
  - обычная надпись. Не обрабатывает нажатие, не принимает фокус. Событие нажатия передается родительским компонентам.

Управляет тем, растягивает ли надпись родительский компонент. При значении `Ложь` надпись не будет влиять на размеры родительского контейнера. т.е. размер родительского контейнера, например, группы, будет определяться другими содержащимися в нем компонентами.

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  Надпись,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на значение надписи, если свойство [ОбрабатыватьНажатие](../../wiki/interface/label-ru-6b4ca5274ef9.md) равно `Истина`. Если разработчик установил свойство события [СтандартнаяОбработка](../../wiki/interface/onclickevent-ru-15fc28e42f99.md) в `Ложь`, то стандартной обработки нажатия на ссылку не происходит. Иначе после завершения обработчика вызывается стандартная обработка нажатия на ссылку.
