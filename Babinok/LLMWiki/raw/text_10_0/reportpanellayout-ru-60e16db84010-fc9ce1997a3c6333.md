Макет панели отчетов. Описание макета формируется автоматически при редактировании панели отчетов в дизайнере «1С:Аналитики», встроенном в среду разработки.

---

## Свойства

#### АвтоматическоеОбновление

```yaml
АвтоматическоеОбновление: 
    Использовать: Булево
```

Содержит настройки автоматического обновления данных в панели отчетов.

<details>
<summary>**Свойства**</summary>

##### Использовать

Включает или отключает автоматическое обновление данных в панели отчетов.

</details>

---

#### Виджеты

```yaml
Виджеты: 
    -
        Ид: Строка
        Ссылка: 
            Url: Строка
            Заголовок: Строка
            Фильтры: Строка[]
        ОтображатьОбводку: Булево
```

Содержит описание виджетов панели отчетов.

<details>
<summary>**Свойства**</summary>

##### Ид

Уникальный идентификатор виджета.

##### Ссылка

Описывает ссылку, которая открывается при нажатии на виджет.

<details>
<summary>**Свойства**</summary>

##### Url

Задает адрес ссылки.

##### Заголовок

Задает текст, отображаемый при наведении на ссылку.

##### Фильтры

Указывает, какие фильтры необходимо передавать при переходе по ссылке.

</details>

##### ОтображатьОбводку

Указывает, следует ли отображать обводку для виджета.

</details>

#### Параметры

```yaml
Параметры: 
    -
        Имя: Строка
        Тип: Тип<Булево|Сущность.Ссылка|Перечисление|Число|Строка|ДатаВремя>
        Представление: Строка
        ЗначениеПоУмолчанию: Объект
        Обязательный: Булево
        ПараметрыОтчетов: ПараметрыОтображенияПанелиОтчета[]
        Значения: ЗначениеПараметраКомпоновкиПанелиОтчета[]
```

Содержит описание параметров панели отчетов.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Тип параметра.

##### Представление

Имя параметра, отображаемое в отчете.

##### ЗначениеПоУмолчанию

Значение параметра по умолчанию. Если не указано, используется значение по умолчанию для типа параметра.

Если для параметра задан список значений, то значение свойства **ЗначениеПоУмолчанию** не указывается.

##### Обязательный

Указывает, является ли параметр обязательным. Если значение обязательного параметра не задано, отчет не будет построен.

##### ПараметрыОтчетов

Указывает, каким параметрам отчетов, расположенных на панели, соответствует данный параметр панели отчетов.

##### Значения

Список допустимых значений. Если указаны, параметр может принимать только значения из списка.

Если список заполнен, создается перечисление `{ИмяПанелиОтчетов}.Параметры.{ИмяПараметра}` с элементами, соответствующими указанным значениям.

</details>

#### Поля

```yaml
Поля: 
    -
        Имя: Строка
        Представление: Строка
        ИсточникиДанных: 
            -
                ИсточникДанных: Строка
                Выражение: Строка
                Использовать: Булево
```

Содержит описание полей панели отчетов.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя поля.

##### Представление

Отображаемое имя поля.

##### ИсточникиДанных

Задает выражения, используемые в поле для разных источников данных.

<details>
<summary>**Свойства**</summary>

##### ИсточникДанных

Имя источника данных.

##### Выражение

Выражение, используемое для указанного источника данных.

##### Использовать

Указывает, активно ли поле.

</details>

</details>

#### ЭлементыУправления

```yaml
ЭлементыУправления: 
    -
        Ид: Строка
        Использовать: Булево
        Заголовок: Строка
        Выражение: Строка
        Параметр: Булево
```

Содержит описание элементов управления панели отчетов.

<details>
<summary>**Свойства**</summary>

##### Ид

Идентификатор элемента управления.

##### Использовать

Указывает, применяется ли элемент управления к отчету в данный момент.

##### Заголовок

Заголовок элемента управления.

##### Выражение

Поле или выражение, для которого создается элемент управления.

##### Параметр

**Истина**, если элемент управления создан для параметра.

</details>
