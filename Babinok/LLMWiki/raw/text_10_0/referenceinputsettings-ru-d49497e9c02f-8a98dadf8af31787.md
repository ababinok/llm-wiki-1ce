Содержит настройки ввода для одного конкретного ссылочного типа в [ПолеВвода](../../wiki/interface/edit-ru-cde85140b31e.md).

## Конструкторы

### НастройкиВводаСсылки

`Доступность: КлиентИСервер`

```
НастройкиВводаСсылки(
  Фильтр: ГруппаЭлементовФильтра,
  ОтображатьКомандуСоздания: Авто|Булево,
  ПрисоединенныеТаблицы: Массив<ПрисоединеннаяТаблица>,
  ПсевдонимОсновнойТаблицы: Строка,
  РазрешитьВыборПомеченныхНаУдаление: Авто|Булево)
```

Создает новый объект

[НастройкиВводаСсылки](../../wiki/interface/referenceinputsettings-ru-d49497e9c02f.md)

.

---

## Свойства

### ОтображатьКомандуСоздания

`Доступность: КлиентИСервер`

```
ОтображатьКомандуСоздания: Авто|Булево
```

Настройка отображения кнопки создания при вводе. В случае [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) отображение определяется свойством [ОтображатьКомандуСоздания](../../wiki/interface/edit-ru-cde85140b31e.md) или свойством ИспользоватьСозданиеПриВводе сущности, на которую указывает ссылка.

---

### ПрисоединенныеТаблицы

`Доступность: КлиентИСервер`

```
ПрисоединенныеТаблицы: Массив<ПрисоединеннаяТаблица>
```

Массив описаний присоединенных таблиц для фильтра в списке подбора.

---

### ПсевдонимОсновнойТаблицы

`Доступность: КлиентИСервер`

```
ПсевдонимОсновнойТаблицы: Строка
```

Псевдоним основной таблицы для поиска по подстроке. Используется для указания полей основной таблицы в условиях присоединенных таблиц.

---

### РазрешитьВыборПомеченныхНаУдаление

`Доступность: КлиентИСервер`

```
РазрешитьВыборПомеченныхНаУдаление: Авто|Булево
```

Разрешает или запрещает выбор помеченных на удаление объектов в списке подбора

---

### Фильтр

`Доступность: КлиентИСервер`

```
Фильтр: ГруппаЭлементовФильтра
```

Элементы фильтра для списка подбора значений.
