## [Форма](../../wiki/interface/form-ru-89fb5e7eaeb3.md)

`Стд::Интерфейс::Формы::Форма<ТипРезультата>` `Доступность: Клиент`

ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md) без передачи аргумента - в качестве результата открытия возвращается `Неопределено`.

Базовый компонент для форм приложения.

---

## [ФормаЗаписи](../../wiki/interface/recordform-ru-07b0d25bd622.md)

`Стд::Интерфейс::Формы::ФормаЗаписи<ТипЗаписи,ТипРезультата>` `Доступность: Клиент`

ТипЗаписи: Тип записи регистра. Ограничения параметра типа: Стд::Сущности::РедактируемаяЗапись<неизвестно,неизвестно>. ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md) без передачи аргумента, в качестве результата открытия возвращается `Неопределено`.

Форма записи. Содержит стандартные функции для создания и редактирования сущностей приложения. ФормаЗаписи редактирует не объектные сущности, а записи, т.е. те, которые имеют в базовых типах [РедактируемаяЗапись](../../wiki/stdlib/editablerecord-ru-f31b09c7a7cc.md), такие как записи регистров сведений.
