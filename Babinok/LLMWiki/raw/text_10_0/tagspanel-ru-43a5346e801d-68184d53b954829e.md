Отображает список значений в виде тегов. Область тегов может быть свернута до одной строки или развернута на всю высоту. Каждый тег может иметь свой цвет, содержать текст и картинку. Вы можете создавать информационные (неинтерактивные) и кликабельные (интерактивные) теги.

Панель тегов показывает одну горизонтальную строку разноцветных тегов с иконками и подписями «Задача», «Ошибка», «Эпик», «Улучшение», «Дизайн/Анализ», «Инфраструктура», «Документация», «Рефакторинг». [Описание иллюстрации](../figures/6c0b30596ae439a1413f347f94cb28556aaef7886ade14db95ae23cccdb29911-b909f10a782bcfbe.md)

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### СписокЗначений

```yaml
СписокЗначений: ВычисляемоеВыражение|неизвестно
```

Задает список значений тегов.

В качестве списка значений можно использовать массив элементов любого типа, который указывается в параметре `ТипДанных`. В этом случае используется строковое представление элементов этого типа.

В качестве списка значений можно также использовать массив объектов типа [ЭлементСпискаЗначений](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md), где в качестве представления элементов используется значение свойства [Представление](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md). Если оно не задано, то используется строковое представление свойства [Значение](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md).

#### Заголовок

```yaml
Заголовок: Авто|Строка
```

Заголовок, который отображается над областью с тегами.

Пример панели тегов с заголовком «Ключевые навыки»: заголовок расположен над горизонтальным рядом голубых тегов. [Описание иллюстрации](../figures/210b1902cb3af5a850b1be8d4530af644abc2bd44354a2bb8d52affc248ed844-01330d866495bf15.md)

#### ЦветТегов

```yaml
ЦветТегов: ВычисляемоеВыражение|Авто|Цвет
```

Определяет цвет фона тегов. Если в качестве значения свойства [СписокЗначений](../../wiki/interface/tagspanel-ru-43a5346e801d.md) используется массив объектов [ЭлементСпискаЗначений](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md), то при окрашивании тега берется цвет соответствующего элемента, если для него задано свойство [Цвет](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md).

---

#### ОкрашиватьФонТегов

```yaml
ОкрашиватьФонТегов: ВычисляемоеВыражение|Авто|Булево
```

Указывает, следует ли окрашивать интерактивные (кликабельные) теги цветом, заданным в свойстве [ЦветТегов](../../wiki/interface/tagspanel-ru-43a5346e801d.md). Значение свойства игнорируется, если свойство [ЦветТегов](../../wiki/interface/tagspanel-ru-43a5346e801d.md) равно **Авто**.

---

#### Свернут

```yaml
Свернут: ВычисляемоеВыражение|Булево
```

Задает состояние панели тегов: свернута или развернута. Свойство требует двунаправленной связи с данными.

Если свойство имеет значение **Ложь**, отображается весь набор тегов. Если **Истина**, то набор тегов свернут в одну строку. Кнопка сворачивания/разворачивания показывается, если теги не вмещаются в одну строку.

Свойство **Свернут** игнорируется, если свойство [ОтображатьКнопкуСворачивания](../../wiki/interface/tagspanel-ru-43a5346e801d.md) равно **Ложь** или компонент отображается в компактном виде.

---

#### ОтображатьКнопкуСворачивания

```yaml
ОтображатьКнопкуСворачивания: ВычисляемоеВыражение|Авто|Булево
```

Указывает, отображать ли кнопку сворачивания/разворачивания тегов. Значение **Авто** интерпретируется как **Истина**.

Компонент тегов с несколькими строками: справа снизу показана круглая кнопка со стрелкой вверх и подсказкой «Свернуть». [Описание иллюстрации](../figures/d9d4b8d7f183b9d1706b81d51fb9897139fa12f114bbd76e240684c2c28a5279-1c602daaf048a302.md)

Если кнопка скрыта, компонент всегда развернут. Если свойство **ОтображатьКнопкуСворачивания** равно **Ложь**, то значение свойства [Свернут](../../wiki/interface/tagspanel-ru-43a5346e801d.md) игнорируется.

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/tagspanel-ru-43a5346e801d.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/tagspanel-ru-43a5346e801d.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/tagspanel-ru-43a5346e801d.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/tagspanel-ru-43a5346e801d.md).

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](../../wiki/interface/tagspanel-ru-43a5346e801d.md) равно **Ложь**.

---

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриНажатииНаТег

```yaml
ПриНажатииНаТег: Строка
```

Вызывается при нажатии на тег ([пример](../../wiki/interface/tag-panel-74f7123dd302.md)).

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
