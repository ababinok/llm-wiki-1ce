`Стд::Интерфейс::ИсточникиДанных::Массив::НастройкаПоляИсточникаДанныхМассив` `Доступность: КлиентИСервер`

Настройка поля объекта [ИсточникДанныхМассив](../../wiki/interface/arraydatasource-ru-2842d399ff6f.md). Уточняет поведение того или иного поля в системе. Настраиваемое поле источника данных может не отображаться в компоненте [Таблица](../../wiki/interface/table-ru-ccc43dec1ca9.md) или [Список](../../wiki/interface/list-ru-58c40755a735.md). Например, оно может участвовать в поиске, но при этом не отображаться пользователю.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

## Конструкторы

### НастройкаПоляИсточникаДанныхМассив

`Доступность: КлиентИСервер`

```
НастройкаПоляИсточникаДанныхМассив(
  ПутьКПолю: Строка,
  ИспользованиеВПоиске: Авто|Булево)
```

Создает объект

[НастройкаПоляИсточникаДанныхМассив](../../wiki/interface/arraydatasourcefieldsetting-ru-ee785e7b7013.md)

с указанными параметрами.

## Свойства

### ИспользованиеВПоиске

`Доступность: КлиентИСервер`

```
ИспользованиеВПоиске: Авто|Булево
```

- Если
  
  `Истина`
  
  – значение поля не будет использовано в поиске.
- Если
  
  `Ложь`
  
  – значение поля будет использовано в поиске, если тип поля
  
  [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  ,
  
  [Сущность.Ключ](../../wiki/data/entity-key-ru-7032eabc056b.md)
  
  или
  
  [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md)
- Если
  
  [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  :
  
  - Для компонента
    
    [Таблица](../../wiki/interface/table-ru-ccc43dec1ca9.md)
    
    : значение поля будет использовано в поиске, если тип поля
    
    [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)
    
    ,
    
    [Сущность.Ключ](../../wiki/data/entity-key-ru-7032eabc056b.md)
    
    или
    
    [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md)
    
    и только, если колонка таблицы, в которой присутствует это поле, видима пользователю
  - Для компонента
    
    [Список](../../wiki/interface/list-ru-58c40755a735.md)
    
    : равнозначно значению
    
    `Истина`

---

### ПутьКПолю

`Доступность: КлиентИСервер`

```
ПутьКПолю: Строка
```

Путь к настраиваемому полю. Для вложенных полей/свойств объектов указывается через точку, начиная с поля родителя.

Например, если у нас есть три поля одной структуры `Фио`: `Фамилия`, `Имя` и `Отчество`, – свойство для каждого из этих полей будет иметь значение соответственно: `Фио.Фамилия`, `Фио.Имя`, `Фио.Отчество`
