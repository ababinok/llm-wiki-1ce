В этом разделе описываются способы построения диаграммы Ганта.

> [!TIP] совет
> Чтобы данные примеры отобразились в интерфейсе приложения, вам следует добавить в проект компонент интерфейса **СтандартноеКлиентскоеПриложениеСРазделами**. Его описание может выглядеть следующим образом:
>
> ```yaml
> ВидЭлемента: КомпонентИнтерфейса
> Ид: 42990ed5-7d51-407a-9013-c5d8a77dc9ba
> Имя: МоеСтандартноеКлиентскоеПриложениеСРазделами
> ОбластьВидимости: ВПодсистеме
> Наследует:
>     Тип: СтандартноеКлиентскоеПриложениеСРазделами
>     КомандныйИнтерфейсПанелиНавигации:
>         Тип: ФрагментКомандногоИнтерфейса<Команда>
>         Элементы:
>             - =НазваниеФормы.ОткрытьФорму # Следует указать название формы для отображения
> ```

## Заполнение элементов диаграммы Ганта вручную в коде

Диаграмма Ганта, заполненная вручную [Описание иллюстрации](../figures/c8fb720afdbbf65a56f388a7b284e28ffb517f1af349cb310b401ed86e9aee0b-35513a0d3c0520ac.md)

Создадим форму и поместим в нее компонент `ДиаграммаГанта`. Описание YAML может выглядеть следующим образом:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Имя: ФормаДиаграммыГанта
Id: ea3ea82e-a63a-4d2f-9390-faa4668291d7
ОбластьВидимости: ВПроекте
Наследует:
    Тип: Форма
    Заголовок: Диаграмма Ганта
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Содержимое:
                -
                    Тип: ДиаграммаГанта<ИсточникДанныхДерево<ЭлементДиаграммыГанта<Объект?, Объект?>>>
                    Имя: ДиаграммаГанта
                    ПрокруткаПоВертикали: Истина
                    ПриВыделенииЭлемента: ПриВыделенииЭлемента
                    КомандыСтроки:
                        Тип: ФрагментКомандногоИнтерфейса<КомандаСПараметром<ЭлементДиаграммыГанта<Объект?, Объект?>>>
                        Элементы:
                            -
                                Тип: КомандаСПараметром<Объект?>
                                Представление: Команда 1
                                Обработчик: Команда1Обработчик
                                Изображение: Отпуск.svg
                            -
                                Тип: КомандаСПараметром<Объект?>
                                Представление: Команда 2
                                Обработчик: Команда2Обработчик
                                Изображение: Настройки.svg
                    Колонки: 
                        -
                            Тип: СтандартнаяКолонкаТаблицы<ЭлементДиаграммыГанта<Объект?, Объект?>>
                            ПолеЗначения: Наименование
```

В обработчике **ПослеСоздания** заполним диаграмму Ганта данными. Для этого создадим массив из элементов типа `ЭлементДиаграммыГанта` и запишем его в свойство `Источник` диаграммы Ганта. Пример того, как может выглядеть файл XBSL:

```xbsl
@Обработчик
метод ПослеСоздания()
    пер Элементы: Массив<ЭлементДиаграммыГанта<Объект?, Объект?>> = [
        новый ЭлементДиаграммыГанта<Объект?, Объект?>(
            Наименование = "Группа элементов 1",
            Интервалы = [
                новый ИнтервалДиаграммыГанта<Объект?>(
                    Наименование = "Элемент 1 - 1",
                    Диапазон = новый ЗакрытыйДиапазон(
                        От = Момент{2022-01-03Z},
                        До = Момент{2022-01-10Z}
                    ),
                    Цвет = Цвета.Красный
                ),
                новый ИнтервалДиаграммыГанта<Объект?>(
                    Наименование = "Элемент 1 - 2",
                    Диапазон = новый ЗакрытыйДиапазон(
                        От = Момент{2022-01-13Z},
                        До = Момент{2022-01-18Z}
                    ),
                    Цвет = Цвета.Красный
                )
            ]
        ),
        // ...
        новый ЭлементДиаграммыГанта<Объект?, Объект?>(
            Наименование = "Группа элементов 9",
            Интервалы = [
                новый ИнтервалДиаграммыГанта<Объект?>(
                    Наименование = "Элемент 9",
                    Диапазон = новый ЗакрытыйДиапазон(
                        От = Момент{2022-01-14Z},
                        До = Момент{2022-01-24Z}
                    ),
                    Цвет = Цвета.Розовый
                )
            ]
        )
    ]

    Компоненты.ДиаграммаГанта.Источник.Данные = Элементы
;
метод ПриВыделенииЭлемента(Источник: ДиаграммаГанта<ИсточникДанныхДерево<ЭлементДиаграммыГанта<Объект?, Объект?>>>,
    Событие: СобытиеПриНажатииНаДиаграммуГанта<ЭлементДиаграммыГанта<Объект?, Объект?>>)
    // Событие, возникающее при выделении элемента
    Сообщить("Выделили %{Событие.Элемент.Наименование}")
;

метод Команда1Обработчик(Команда: КомандаСПараметром<Объект?>, Параметр: Объект?)
    // Событие, возникающее при вызове команды 1
    Сообщить("Команда 1 %{Параметр}")
;

метод Команда2Обработчик(Команда: КомандаСПараметром<Объект?>, Параметр: Объект?)
    // Событие, возникающее при вызове команды 2
    Сообщить("Команда 2 %{Параметр}")
;
```

## Заполнение элементов диаграммы Ганта вручную через массив данных

Диаграмма Ганта, заполненная вручную ч�ерез массив [Описание иллюстрации](../figures/aca45eb2c2eb9f3864cc58a7e9d700a2aa904ba943580a15219ac10c42f97bd0-bdf692b84c2edf5f.md)

Создадим форму и поместим в нее компонент `ДиаграммаГанта`:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Имя: ФормаОтпусков
Id: e8736f49-ec45-4594-b6a8-9fd13739cee9
ОбластьВидимости: ВПроекте
Наследует:
    Тип: Форма
    Заголовок: Диаграмма Ганта
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Содержимое:
                -
                    Тип: ДиаграммаГанта<ИсточникДанныхДерево<ЭлементДиаграммыГанта<ФормаОтпусков.Сотрудник?, ФормаОтпусков.ОтпускСотрудника>>>
                    Имя: ДиаграммаГанта
                    ПрокруткаПоВертикали: Истина
                    ПриВыделенииЭлемента: ПриВыделенииЭлемента
                    Колонки:
                        -
                            Тип: СтандартнаяКолонкаТаблицы<ЭлементДиаграммыГанта<ФормаОтпусков.Сотрудник?, ФормаОтпусков.ОтпускСотрудника>>
                            Заголовок: Сотрудник
                            Представление: =ПолучитьПредставление(ДанныеСтроки)
```

Сформируем и зададим источник данных в модуле XBSL:

```xbsl
// Создадим структуры данных для заполнения
@ВПроекте
структура Сотрудник
    обз пер Наименование: Строка
    обз пер Ид: Ууид
;

@ВПодсистеме
структура ОтпускСотрудника
    обз пер Сотрудник: Сотрудник
    обз пер Отпуск: ЗакрытыйДиапазон<Момент> | Неопределено 
;

@Обработчик
метод ПослеСоздания()
    пер ТекущийЧасовойПояс = ЧасовойПояс.Текущий()

    пер Сотрудник1Ид = новый Ууид()
    пер Сотрудник2Ид = новый Ууид()
    пер Сотрудник3Ид = новый Ууид()
    пер Сотрудник4Ид = новый Ууид()

    пер Сотрудник1 = новый Сотрудник(
        "Сотрудник 1",
        Сотрудник1Ид
    )
    пер Сотрудник2 = новый Сотрудник(
        "Сотрудник 2",
        Сотрудник2Ид
    )
    пер Сотрудник3 = новый Сотрудник(
        "Сотрудник 3",
        Сотрудник3Ид
    )
    пер Сотрудник4 = новый Сотрудник(
        "Сотрудник 4",
        Сотрудник4Ид
    )

    // В переменной «Отпуска» сохраним массив данных
    пер Отпуска: Массив<ОтпускСотрудника?> = [
        новый ОтпускСотрудника(
            Сотрудник1,
            новый ЗакрытыйДиапазон(ДатаВремя{2022-01-10}.ВМомент(ТекущийЧасовойПояс), 
            ДатаВремя{2022-01-17}.ВМомент(ТекущийЧасовойПояс))
        ),
        // ...
        новый ОтпускСотрудника(
            Сотрудник4,
            новый ЗакрытыйДиапазон(ДатаВремя{2022-02-15}.ВМомент(ТекущийЧасовойПояс), 
            ДатаВремя{2022-02-26}.ВМомент(ТекущийЧасовойПояс))
        )
    ]


    // Каждому сотруднику поставим в соответствие элемент диаграммы Ганта
    // и заполним значение интервала по данным об отпуске
    пер ОтпускаПоСотруднику = новый Соответствие<Сотрудник, ЭлементДиаграммыГанта<Сотрудник?, ОтпускСотрудника>>()

    для Отпуск из Отпуска
        пер ОтпускаСотрудника = ОтпускаПоСотруднику.ВставитьЕслиОтсутствует(
            Отпуск.Сотрудник,
            (Сотрудник) -> новый ЭлементДиаграммыГанта<Сотрудник?, ОтпускСотрудника>(
                Данные = Сотрудник,
                Наименование = Сотрудник.Наименование))
        ОтпускаСотрудника.Интервалы.Добавить(новый ИнтервалДиаграммыГанта<ОтпускСотрудника>(
            Диапазон = Отпуск.Отпуск,
            Наименование = Отпуск.Сотрудник.Наименование))
    ;

    // Зададим источник данных диаграммы Ганта
    Компоненты.ДиаграммаГанта.Источник.Данные = ОтпускаПоСотруднику.Значения().ВМассив()
;


метод ПриВыделенииЭлемента(
        Источник: ДиаграммаГанта<ИсточникДанныхДерево<ЭлементДиаграммыГанта<Сотрудник?, ОтпускСотрудника>>>,
        Событие: СобытиеПриНажатииНаДиаграммуГанта<ЭлементДиаграммыГанта<Сотрудник?, ОтпускСотрудника>>
    )
    если Событие.Интервал != Неопределено
        Сообщить(Событие.Интервал.ВСтроку())
    ;
;

метод ПолучитьПредставление(
        ДанныеСтроки: ЭлементДиаграммыГанта<ФормаОтпусков.Сотрудник?, ФормаОтпусков.ОтпускСотрудника>
    ): Строка
    если ДанныеСтроки.Интервалы.Пусто()
        возврат "Представление сотрудника отсутствует"
    иначе
        пер ПервыйЭлемент = ДанныеСтроки.Интервалы.Первый()

        если ПервыйЭлемент.Данные != Неопределено
            возврат ПервыйЭлемент.Данные.Сотрудник.Наименование
        иначе
            возврат "Представление сотрудника отсутствует"
        ;
    ;
;
```

## Динамическая загрузка и отображение элементов на диаграмме Ганта

Предположим, мы хотели бы динамически заполнять диаграмму Ганта данными из некоторого справочника «Задачи». Необходимо, чтобы при создании новой записи в справочнике данные сразу отображались на диаграмме:

Диаграмма Ганта, заполняемая динамически [Описание иллюстрации](../figures/8909b38d85c5a588ec46ae2d0e6447752d31f3aed9bdf6dfc911049dcfa99a92-0c46e5edcf68d91c.md)

1. Добавим в проект справочник «Задачи»:
  
  ```yaml
  ВидЭлемента: Справочник
  Ид: 79a57551-072b-444d-9f06-4374af7d460f
  Имя: Задачи
  ОбластьВидимости: ВПроекте
  КонтрольДоступа:
      Разрешения:
          Создание: РазрешеноВсем
          Чтение: РазрешеноВсем
          Изменение: РазрешеноВсем
          Удаление: РазрешеноВсем
          ПоУмолчанию: РазрешеноВсем
  Интерфейс:
      Объект:
          Форма: ЗадачиФормаОбъекта
  ВводПоСтроке:
      - Код
  Представление: Код
  Реквизиты:
      -
          Имя: Код
          Тип: Строка
          Длина: 50
          Автонумерация:
              Использовать: Ложь
      -
          Ид: 5b4c158b-23c1-4273-8712-d365b2ae39fd
          Имя: Родитель
          Тип: Задачи.Ссылка?
      -
          Ид: 39d0f8cf-4b7a-4a27-b4a1-63e469420fe5
          Имя: Зависимость
          Тип: Задачи.Ссылка?
      -
          Ид: 215fbcb1-c50b-4a87-882c-f4a0b7043744
          Имя: Начало
          Тип: Момент?
      -
          Ид: fd2592fa-0210-4acd-8a5f-f8125ad3b242
          Имя: Конец
          Тип: Момент?
  ```
2. Для справочника создадим форму объекта:
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 9da39088-2a28-483a-b1fd-d811404abb56
  Имя: ЗадачиФормаОбъекта
  ОбластьВидимости: ВПодсистеме
  Свойства: 
      -
          Имя: Родитель
          Тип: Задачи.Ссылка?
  Наследует:
      Тип: ФормаОбъекта<Задачи.Объект>
      Заголовок: Задачи
      ШиринаВКолонках: Двойная
      ОсновнаяКоманда: =ЗаписатьИЗакрыть
      ОбычныеКоманды:
          Тип: ФрагментКомандногоИнтерфейса<Команда>
          Элементы:
              - =Удалить
      ДополнительныеКоманды:
          Тип: ФрагментКомандногоИнтерфейса<Команда>
          Элементы:
              - =Обновить
      Содержимое:
          Тип: ПроизвольныйШаблонФормы
          Содержимое:
              Тип: Группа
              Имя: ГруппаПолей
              Содержимое:
                  -
                      Тип: ПолеВвода<Строка>
                      Имя: Код
                      Заголовок: Код
                      Значение: =Объект.Код
                  -
                      Тип: ПолеВвода<Задачи.Ссылка?>
                      Имя: Родитель
                      Заголовок: Родитель
                      Значение: =Объект.Родитель
                  -
                      Тип: ПолеВвода<Задачи.Ссылка?>
                      Имя: Зависимость
                      Заголовок: Зависимость
                      Значение: =Объект.Зависимость
                  -
                      Тип: ПолеВвода<Момент?>
                      Имя: Начало
                      Заголовок: Начало
                      Значение: =Объект.Начало
                  -
                      Тип: ПолеВвода<Момент?>
                      Имя: Конец
                      Заголовок: Конец
                      Значение: =Объект.Конец
  ```
3. В модуле формы объекта опишем обработчик события **ПослеЧтения**:
  
  ```xbsl
  @Обработчик
  метод ПослеЧтения()
      если Родитель != Неопределено
          Объект.Родитель = Родитель
      ;
  ;
  ```
4. Для того чтобы автоматически заполнить справочник «Задачи» данными и отобразить их на диаграмме, изменим обработчик события **ПослеСоздания** и в модуле формы добавим следующий код:
  
  ```xbsl
  @Обработчик
  метод ПослеСоздания()
      ЗаполнитьЗадачи()
  ;
  
  @НаСервере @ДоступноСКлиента
  статический метод ЗаполнитьЗадачи()
      пер Задача1 = СоздатьЗадачу("Задача1", ДатаВремя{2022-08-17}, ДатаВремя{2022-08-26})
      пер Задача2 = СоздатьЗадачу("Задача2", ДатаВремя{2022-08-18}, ДатаВремя{2022-08-19}, Задача1)
      пер Задача3 = СоздатьЗадачу("Задача3", ДатаВремя{2022-08-19}, ДатаВремя{2022-08-20}, Задача2)
      пер Задача4 = СоздатьЗадачу("Задача4", ДатаВремя{2022-08-22}, ДатаВремя{2022-08-25}, Задача3)
      
      пер ПодЗадача1 = СоздатьЗадачу("ПодЗадача1", ДатаВремя{2022-08-17}, ДатаВремя{2022-08-19}, Неопределено, Задача1)
      пер ПодЗадача2 = СоздатьЗадачу("ПодЗадача2", ДатаВремя{2022-08-19}, ДатаВремя{2022-08-21}, ПодЗадача1, Задача1)
      пер ПодЗадача3 = СоздатьЗадачу("ПодЗадача3", ДатаВремя{2022-08-21}, ДатаВремя{2022-08-23}, ПодЗадача2, Задача1)
      пер ПодЗадача4 = СоздатьЗадачу("ПодЗадача4", ДатаВремя{2022-08-23}, ДатаВремя{2022-08-25}, ПодЗадача3, Задача1)
  ;
  
  @НаСервере
  статический метод СоздатьЗадачу(Код: Строка, Начало: ДатаВремя, Конец: ДатаВремя, 
                                  Зависимость: Задачи.Ссылка? = Неопределено, 
                                  Родитель: Задачи.Ссылка? = Неопределено): Задачи.Ссылка
      пер Задача = Задачи.НайтиПоКоду(Код)
      если Задача != Неопределено
          возврат Задача
      ;
  
      пер НоваяЗадача = новый Задачи.Объект(
          Код = Код,
          Начало = Начало.ВМомент(ЧасовойПояс.Текущий()),
          Конец = Конец.ВМомент(ЧасовойПояс.Текущий()),
          Зависимость = Зависимость,
          Родитель = Родитель
      )
      НоваяЗадача.Записать()
  
      возврат НоваяЗадача.Ссылка
  ;
  ```
5. Затем перейдем к основной части примера: создадим форму и поместим в нее компонент `ДиаграммаГанта`. В качестве источника данных укажем `ИсточникДанныхДерево`, у которого дочерние элементы имеют тип `Задачи.Ссылка`:
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Имя: ФормаЗадач
  Id: 2c642308-bb7d-40ab-a465-1e1ef1b6c552
  ```

6. В модуле формы зададим следующие методы:
  
  ```xbsl
  @Обработчик
  метод ПослеСоздания()
      ОбновитьДиаграмму()
  ;
  
  метод ОбновитьДиаграмму()
      Компоненты.ДиаграммаГанта.Источник.Данные = ПрочитатьЗадачи()
  ;
  
  @НаСервере @ДоступноСКлиента
  статический метод ПрочитатьЗадачи(): Массив<ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>>
      пер Запрос = Запрос{
          ВЫБРАТЬ
              Задачи.Ссылка КАК Ссылка,
              Задачи.Код КАК Код,
              Задачи.Родитель КАК Родитель,
              Задачи.Зависимость КАК Зависимость,
              Задачи.Начало КАК Начало,
              Задачи.Конец КАК Конец,
              Задачи.Представление КАК Представление
          ИЗ
              Задачи КАК Задачи
          УПОРЯДОЧИТЬ ПО
              Задачи.Начало, 
              Задачи.Представление
      }
  
      пер Результат = <ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>>[]
  
      пер ЗадачиПоРодителю = <Задачи.Ссылка, ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>>{:}
      пер Задачи = Запрос.Выполнить().ВМассив()
      для Задача из Задачи
          ЗадачиПоРодителю.Вставить(Задача.Ссылка, новый ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>(
              Данные = Задача.Ссылка,
              Интервалы = [
                  новый ИнтервалДиаграммыГанта<Задачи.Ссылка>(
                      Ид = Задача.Ссылка.Ид,
                      Наименование = Задача.Код,
                      Данные = Задача.Ссылка,
                      Диапазон = новый ЗакрытыйДиапазон<Момент>(От = Задача.Начало, До = Задача.Конец),
                      Зависимости = Задача.Зависимость != Неопределено ? [Задача.Зависимость.Ид] : []
                  )
              ]
          ))
      ;
  
      для Задача из Задачи
          пер Элемент = ЗадачиПоРодителю.Получить(Задача.Ссылка)
          если Задача.Родитель != Неопределено
              ЗадачиПоРодителю.Получить(Задача.Родитель).ДочерниеЭлементы.Добавить(Элемент)
          иначе
              Результат.Добавить(Элемент)
          ;
      ;
  
      возврат Результат
  ;
  
  метод СоздатьЗадачу(Команда: ОбычнаяКоманда)
      Задачи.АвтоматическаяФормаОбъекта.Открыть(СпособОткрытия = СпособОткрытияФормы.ВМодальномОкне)
      ОбновитьДиаграмму()
  ;
  
  метод ПриВыделенииЭлемента(Источник: ДиаграммаГанта<ИсточникДанныхДерево<ЭлементДиаграммыГанта<Задачи.Ссылка?,Задачи.Ссылка>>>, 
                          Событие: СобытиеПриНажатииНаДиаграммуГанта<ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>>)    
      если Событие.Интервал != Неопределено
          пер Интервал = Событие.Интервал
          ЗадачиФормаОбъекта.Открыть(КлючОбъекта = Интервал.Данные,
              СпособОткрытия = СпособОткрытияФормы.ВМодальномОкне)
      ;
  ;
  
  метод СоздатьПодзадачу(
      Команда: КомандаСПараметром<ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>>, Параметр: ЭлементДиаграммыГанта<Задачи.Ссылка?, Задачи.Ссылка>)
      ЗадачиФормаОбъекта.Открыть(Родитель = Параметр.Данные, 
          СпособОткрытия = СпособОткрытияФормы.ВМодальномОкне)
      ОбновитьДиаграмму()
  ;
  ```
