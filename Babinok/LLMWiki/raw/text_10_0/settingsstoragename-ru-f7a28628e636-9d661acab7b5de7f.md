## Методы

### ВычислитьРазрешенияДоступа

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на хранилище настроек целиком.

Недопустим когда включены стандартные разрешения доступа (настройка `СтандартныеРазрешения` элемента проекта установлена в значение Истина).

#### Примеры

В данном примере мы разрешаем все действия, кроме удаления, всем аутентифицированным пользователям.

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(): ЧитаемыйМассив<РазрешениеДоступа>
    возврат [
        новый РазрешениеДоступа([новый КлючДоступаДляАутентифицированных.Объект()], 
            [Сущность.Право.Создание, Сущность.Право.Чтение, Сущность.Право.Изменение])
    ]
;
```

### ВычислитьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступаДляОбъектов(Элементы: ЧитаемыйМассив<ИмяХранилищаНастроек.ДанныеРасчетаРазрешений>): ЧитаемоеСоответствие<ИмяХранилищаНастроек.ДанныеРасчетаРазрешений,ЧитаемаяКоллекция<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на отдельные объекты хранилища настроек.

Принимает данные для расчета разрешений доступа объектов, для которых нужно вычислить права, и возвращает соответствие данных для расчета разрешений доступа объектов и установленных для них разрешений.

Используется только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение `РазрешенияВычисляютсяДляКаждогоОбъекта` Недопустим когда включены стандартные разрешения доступа (настройка `СтандартныеРазрешения` элемента проекта установлена в значение Истина).

#### Примеры

Предполагаем, что в проекте описан ключ доступа КлючДоступаДляМенеджеров. В данном примере мы выдаем менеджерам права изменять и удалять общие настройки других пользователей.

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступаДляОбъектов(
    Данные: ЧитаемыйМассив<МоеХранилищеНастроек.ДанныеРасчетаРазрешений>
): Соответствие<МоеХранилищеНастроек.ДанныеРасчетаРазрешений, Массив<РазрешениеДоступа>>

    пер Разрешения = <МоеХранилищеНастроек.ДанныеРасчетаРазрешений, Массив<РазрешениеДоступа>>{:}

    для Настройка из Данные
        знч РазрешенияДляОбъекта = <РазрешениеДоступа>[]

        РазрешенияДляОбъекта.Добавить(новый РазрешениеДоступа(
            [новый КлючДоступаПользователя.Объект(Настройка.Пользователь)],
            [Сущность.Право.Создание, Сущность.Право.Чтение, Сущность.Право.Изменение, Сущность.Право.Удаление]))
       
        если Настройка.Общая
            РазрешенияДляОбъекта.Добавить(новый РазрешениеДоступа(
                [новый КлючДоступаДляАутентифицированных.Объект()], [Сущность.Право.Чтение]))
        
            РазрешенияДляОбъекта.Добавить(новый РазрешениеДоступа(
                [новый КлючДоступаДляМенеджеров.Объект()], [Сущность.Право.Изменение, Сущность.Право.Удаление]))
        ;
        Разрешения.Вставить(Настройка, РазрешенияДляОбъекта)
    ;

    возврат Разрешения
;
```

### ЗаписатьПоКлючам

`Доступность: Сервер`

```
ЗаписатьПоКлючам(
  КлючОбъекта: Строка,
  КлючНастройки: Строка,
  Значение: Строка)
```

Метод записи настройки для текущего пользователя по ключам. Ищутся и записываются только уникальные настройки (Вариант = Ложь). Если по указанным ключам запись не будет найдена, метод создает новую настройку с указанными ключами и значением. Для новой настройки остальные реквизиты будут установлены в значения по умолчанию.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../../wiki/stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на запись объекта.

**Перегрузка** [ЗаписатьПоКлючам(КлючОбъекта: Строка, КлючНастройки: Строка, Значение: Строка, Наименование: Строка, Общая: Булево, ПараметрыЗаписи: ИмяХранилищаНастроек.ПараметрыЗаписи? = Неопределено)](../../wiki/data/settingsstoragename-ru-f7a28628e636.md)

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяХранилищаНастроек.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

### СоздатьФормуОбъекта

`Версия 10.0 и выше`

`Доступность: Клиент`

```

```

>

Вызов возможен только с именованными параметрами

Создает форму объекта хранилища настроек. Если хранилищу настроек назначена форма объекта, то будет создана форма ровно этого типа. ## Обработчики

### ПолучитьЗначенияВыбора

`Версия 10.0 и выше`

```
ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Событие вызываемое при попытке получить данные для выбора по введенной подстроке. В событие передается информация о набранной строке, и параметрах фильтра. Событие должно возвратить массив выбранных данных, или Неопределено если требуется выполнить стандартную обработку события.

#### Примеры

В данном примере мы не изменяем стандартную логику поиска, а только добавляем в представление почтовый адрес.

```xbsl
@Обработчик
метод ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемаяКоллекция<ЭлементСпискаВыбора>?
    знч РезультатПоиска = ПолучитьСтандартныеЗначенияВыбора(Параметры) 
    для СтрокаРезультата из РезультатПоиска
        СтрокаРезультата.Представление += " " + ПолучитьАдресПочты(СтрокаРезультата.Значение)
    ;
    возврат РезультатПоиска
;

метод ПолучитьАдресПочты(Значение: неизвестно) : Строка
    пер АдресПочты = ""
    //  получаем адрес почты из значения выбора и устанавливаем в переменную АдресПочты
    возврат АдресПочты
;
```
