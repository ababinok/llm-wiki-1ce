Таблица содержит записи, соответствующие узлам плана обмена. Одна запись таблицы — один узел плана обмена.

Таблица является ссылочной — к ее полям можно обращаться по их именам через точку от выражений, имеющих тип `ИмяПланаОбмена.Ссылка`.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Ссылка** и **Наименование** из плана обмена **Склады**:

```xbql
ВЫБРАТЬ 
   Склады.Ссылка КАК Ссылка,
   Склады.Наименование КАК Наименование 
ИЗ 
   Склады КАК Склады
```

---

## Поля

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита плана обмена.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена. Например, для плана обмена **Склады** это поле будет иметь тип `Склады.Ссылка`.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### МоментПометкиУдаления

```
МоментПометкиУдаления: Момент?
```

Момент пометки записи на удаление. Поле присутствует только у планов обмена с режимом удаления `ПометкаУдаления`.

Поле имеет значение типа `Момент` для помеченных на удаление записей и значение `Неопределено`, если запись не помечена на удаление.

---

### ПометкаУдаления

`Вычисляемое поле`

```
ПометкаУдаления: Булево
```

Признак того, что запись помечена на удаление. Поле присутствует только у планов обмена с режимом удаления `ПометкаУдаления`.

---

### Код

```
Код: Строка
```

Код узла плана обмена.

---

### НомерОтправленного

```
НомерОтправленного: Число
```

Номер последнего сообщения, отправленного из текущего узла приложения в адрес данного периферийного узла.

---

### НомерПринятого

```
НомерПринятого: Число
```

Максимальный из номеров сообщений, принятых текущим узлом приложения от данного периферийного узла.

---

### ЭтотУзел

```
ЭтотУзел: Булево
```

Флаг, который указывает, является ли данный узел текущим узлом приложения. В противном случае, узел является периферийным.

---

### ПередачаДанных

`Версия 10.0 и выше`

```
ПередачаДанных: ИмяПланаОбмена.НастройкиПередачиДанных
```

Содержит информацию о настройках передачи данных.

---

### Представление

`Вычисляемое поле`

```
Представление: Строка
```

Строковое представление узла плана обмена.

---

## Индексы

### Код

Индекс по полю **Код**. Присутствует только у планов обмена, у которых есть реквизит **Код**.
