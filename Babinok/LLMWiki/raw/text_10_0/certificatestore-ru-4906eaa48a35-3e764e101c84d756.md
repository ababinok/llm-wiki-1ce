`Стд::Криптография::ХранилищеСертификатов` `Доступность: КлиентИСервер`

Представляет базовый тип хранилища цифровых сертификатов.

Ссылочное

*Дочерние типы:* [СистемноеХранилищеСертификатов](../../wiki/data/systemcertificatestore-ru-f5dc6ed5edf6.md), [ХранилищеКлючей](../../wiki/data/keystore-ru-d23b0ab7f855.md)

## Методы

### НайтиПоОтпечатку

`Доступность: Клиент`

```
НайтиПоОтпечатку(Отпечаток: Байты): ЦифровойСертификат?
```

Ищет сертификат по его отпечатку. Если найти не удалось(сертификата с таким отпечатком нет), возвращает

`Неопределено`

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### НайтиПоСерийномуНомеру

`Доступность: КлиентИСервер`

```
НайтиПоСерийномуНомеру(СерийныйНомер: Байты): ЧитаемыйМассив<ЦифровойСертификат>
```

Возвращает список цифровых сертификатов, у которых серийный номер равен указанному

`СерийныйНомер`

.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### НайтиПоСубъекту

`Доступность: КлиентИСервер`

```
НайтиПоСубъекту(Субъект: Строка): ЧитаемыйМассив<ЦифровойСертификат>
```

Возвращает список цифровых сертификатов, у которых имя субъекта содержит текст

`Субъект`

.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### НайтиСертификат

`Доступность: Сервер`

```
НайтиСертификат(Псевдоним: Строка): ЦифровойСертификат?
```

Возвращает цепочку сертификатов по псевдониму записи

`Псевдоним`

или

`Неопределено`

, если запись отсутствует в хранилище.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### ПолучитьПсевдонимы

`Доступность: Сервер`

```
ПолучитьПсевдонимы(): ЧитаемыйМассив<Строка>
```

Возвращает список псевдонимов записей хранилища.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### ПолучитьСертификаты

`Доступность: КлиентИСервер`

```
ПолучитьСертификаты(): ЧитаемыйМассив<ЦифровойСертификат>
```

Возвращает список цифровых сертификатов, которые находятся в хранилище.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### Размер

`Доступность: КлиентИСервер`

```
Размер(): Число
```

Возвращает количество записей в хранилище.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.

---

### Содержит

`Доступность: Сервер`

```
Содержит(Псевдоним: Строка): Булево
```

Проверяет, содержит ли хранилище запись с псевдонимом

`Псевдоним`

.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - при ошибке обращения к хранилищу.
