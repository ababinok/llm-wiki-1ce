`Версия 10.0 и выше`

`Стд::ГеографическиеКарты::МаркерГеографическойКарты<ТипДанных>` `Доступность: КлиентИСервер`

ТипДанных: Тип свойства `Данные` маркера. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Структура, представляющая данные маркера на карте.

## Конструкторы

### МаркерГеографическойКарты

`Доступность: КлиентИСервер`

```
МаркерГеографическойКарты(
  Координаты: ГеографическиеКоординаты,
  Иконка: Авто|Url|ДвоичныйОбъект.Ссылка,
  Заголовок: Авто|Строка,
  Подзаголовок: Авто|Строка,
  Описание: Авто|Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?,
  Данные: ТипДанных)
```

Создает объект

[МаркерГеографическойКарты](../../wiki/stdlib/geographicmapmarker-ru-40dd1d51585c.md)

со значениями свойств, соответствующими параметрам конструктора.
