## Конструкторы

### НастройкиХраненияДоставленныхСообщенийИнтеграции

`Доступность: КлиентИСервер`

```
НастройкиХраненияДоставленныхСообщенийИнтеграции(ТаймаутУстаревания: Длительность)
```

Конструктор по таймауту устаревания. Если 0, то сообщения не хранятся.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - Если таймаут устаревания не равен 0 и меньше, чем 1ч.


Изменяемое. Таймаут устаревания доставленного сообщения. Если 0, то сообщения не хранятся.
