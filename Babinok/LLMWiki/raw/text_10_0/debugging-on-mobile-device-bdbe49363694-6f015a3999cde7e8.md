Чтобы запустить отладку на мобильном устройстве, выполните следующие действия.

1. В главном меню выберите **Запустить** ⟶ **Начать отладку приложения на мобильном устройстве**.
2. Откроется окно с QR-кодом. Отсканируйте его в приложении, чтобы начать отладку.
  
  Окно мобильной отладки содержит QR-код и инструкцию отсканировать его в приложении для начала отладки; ниже есть ссылка для создания мобильного клиента с разрешённой разработкой. QR-код зависит от сеанса, его пиксели не являются постоянным параметром настройки. [Описание иллюстрации](../figures/466ed0c5e23e67638597be189e8eb37ce4d76b71efb20ead061873b41830ec4a-14bbe9d104b604e1.md)
3. Если мобильное приложение не создано или не собрано с разрешенной разработкой, перейдите по ссылке под QR-кодом. Задайте настройки [сборки](../../wiki/project/build-mobile-app-bdb51dd3d670.md).
  
  Чтобы выполнять отладку приложения на мобильном устройстве, необходимо выбрать параметр **Разрешить разработку** в настройках.
4. Вернитесь в среду разработки и запустите отладку еще раз. Отсканируйте QR-код, после чего запустится отладка.
