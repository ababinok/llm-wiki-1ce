# Выбор обработчика для шаблона URL

После успешного сопоставления шаблона URL происходит выбор обработчика. Выбор производится на основе HTTP-метода запроса:

- Сначала происходит попытка поиска обработчика для конкретного метода.
- Если обработчик для метода найден, то используется найденный обработчик.
- Если обработчик не найден, то используется обработчик по умолчанию (
  
  [ЛюбойМетод](../../wiki/integration/urltemplate-d1624a2e37c0.md)
  
  ).
- В случае если обработчик по умолчанию не задан, возвращается ответ с кодом
  
  HTTP 405 (Недопустимый метод)
  
  .

Если обработчик выбран, то маршрутизация запроса успешно завершена и «1С:Предприятие.Элемент» переходит к обработке запроса.
