## Методы

### ВызватьМетод

`Доступность: Клиент`

```
ВызватьМетод(
  Имя: Строка,
  Параметры: Массив<Булево|ОбъектJs|Число|Строка|?>? = Неопределено
): Булево|ОбъектJs|Число|Строка|?
```

Вызывает метод объекта и возвращает результат выполнения. Если идет обращение к процедуре, возвращается

`Неопределено`

. В качестве результата выполнения может быть возвращен объект

[ОбъектJs](../../wiki/interface/jsobject-ru-3b7864d1402d.md)

, описывающий объект JavaScript. Параметры:

- `Имя`
  
  - Имя вызываемого метода. Допустима передача составных имен, разделенных точкой, например "Address.GetStreet"
- `Аргументы`
  
  - Массив передаваемых в метод аргументов. В качестве аргумента допустимо использование JsObject.

---

### ПолучитьСвойство

`Доступность: Клиент`

```
ПолучитьСвойство(Имя: Строка): Булево|ОбъектJs|Число|Строка|?
```

Возвращает значение свойства объекта. В качестве результата обращения к свойству может быть возвращен объект

[ОбъектJs](../../wiki/interface/jsobject-ru-3b7864d1402d.md)

, описывающий объект JavaScript. Параметры:

- `Имя`
  
  - Имя свойства. Допустима передача комплексных имен, разделенных точкой, например "Person.Name"

---

### УстановитьСвойство

`Доступность: Клиент`

```
УстановитьСвойство(
  Имя: Строка,
  Значение: Булево|ОбъектJs|Число|Строка|?)
```

Присваивает значение свойству объекта. Параметры:

- `Имя`
  
  - Имя свойства. Допустима передача комплексных имен, разделенных точкой, например "Person.Name"
- `Значение`
  
  - Новое значение свойства. Допустимо использование
  
  [ОбъектJs](../../wiki/interface/jsobject-ru-3b7864d1402d.md)
  
  в качестве присваиваемого значения.
