## Свойства

### Вариант

`Доступность: КлиентИСервер`

```
Вариант: Булево
```

"Уникальная" настройка или "Вариант".

Хранилище должно обеспечивать одну уникальную запись для набора значений КлючОбъекта, КлючНастройки, Пользователь и значением Вариант = Ложь, но при этом может быть несколько записей с теми же значениями полей КлючОбъекта, КлючНастройки, Пользователь и значением Вариант = Истина.

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяХранилищаНастроек}.Данные)
```

Вызывается при создании нового элемента хранилища настроек копированием существующего. На момент вызова этого обработчика значения реквизитов у нового объекта будут уже заполнены из элемента - источника Не будут копироваться реквизиты, копирование которых отключено в хранилище настроек с помощью свойства

`ЗаполнятьПриКопировании`

.

Параметр `Источник` содержит данные исходного элемента хранилища настроек, копированием которого и создается новый элемент.

#### Примеры

В проекте есть хранилище настроек "МоеХранилищеНастроек". Необходимо сделать так, чтобы при копировании существующей настройки ссылка на исходную настройку сохранялась в реквизите "ИсходнаяНастройка", а так же реквизит "Вариант" должен принимать значение `Истина`

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: МоеХранилищеНастроек.Данные)
    ИсходнаяНастройка = Источник.Ссылка
    Вариант = Истина
;
```
