## Методы

### Пересчитать

`Доступность: Сервер`

```
Пересчитать(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>? = Неопределено)
```

Пересчитывает ключ для пользователей

`Пользователи`

. Если

`Неопределено`

- пересчитывает для всех пользователей.
