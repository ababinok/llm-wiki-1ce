## Свойства

### Низкая

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Низкая
```

Низкая - самый низкий уровень значимости. Такое событие:

- не требует реакции;
  
  - событие уточняет другое событие (расширяет, расшифровывает и т.д. - то есть фиксирует дополнительную информацию в определенных случаях);
- может использоваться для отладки и трассировки;
- событие имеет смысл на ограниченном периоде времени или для ограниченного круга заинтересованных лиц
  
  - быстро теряет свою актуальность;
  - может содержать специфическую информацию;
  - как правило, не предназначено для длительного регулярного использования.

---

### Обычная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Обычная
```

Обычная - протоколирование в журнале свершившегося факта. Такое событие:

- реакция обычно не требуется;
- фиксирует произошедший факт;
- полезно для анализа журнала.

---

### Высокая

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Высокая
```

Высокая - отражение в журнале существенных событий. Такое событие:

- не требует немедленной реакции;
- оказывает существенное влияние на работу приложения;
- необходимо для анализа журнала (содержит важные сведения).

---

### Максимальная

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Максимальная
```

Максимальная - самый высокий уровень значимости. Такое событие:

- требует скорейшей реакции;
- оказывает существенное влияние на работу приложения;
- необходимо для анализа журнала (содержит критичные сведения).
