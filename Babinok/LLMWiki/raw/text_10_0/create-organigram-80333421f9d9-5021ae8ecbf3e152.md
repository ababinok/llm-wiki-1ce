В этом разделе описываются способы построения органиграммы.

> [!TIP] совет
> Чтобы данные примеры отобразились в интерфейсе приложения, вам следует:
>
> 1. Добавить в проект изображения с именами: *1.jpg*, *2.jpg*, *3.jpg*, *4.jpg*, *5.jpg*, *6.jpg*, *fit.svg*.
> 2. Добавить в проект компонент интерфейса **СтандартноеКлиентскоеПриложениеСРазделами**. Его описание может выглядеть следующим образом:
>   
>   ```yaml
>   ВидЭлемента: КомпонентИнтерфейса
>   Ид: 42990ed5-7d51-407a-9013-c5d8a77dc9ba
>   Имя: МоеСтандартноеКлиентскоеПриложениеСРазделами
>   ОбластьВидимости: ВПодсистеме
>   Наследует:
>       Тип: СтандартноеКлиентскоеПриложениеСРазделами
>       КомандныйИнтерфейсПанелиНавигации:
>           Тип: ФрагментКомандногоИнтерфейса<Команда>
>           Элементы:
>               - =НазваниеФормы.ОткрытьФорму # Следует указать название формы для отображения
>   ```

## Заполнение элементов органиграммы вручную в коде

Органиграмма с двумя корневыми элементами [Описание иллюстрации](../figures/e77b439907a62449ac0c901c9ff10bd63bcd500b152f0289484ee44b1ea2e099-25f1a32625f6f649.md)

Создадим форму и поместим в нее компонент `Органиграмма`. Описание YAML может выглядеть следующим образом:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Имя: ФормаОрганиграмма
ОбластьВидимости: ВПроекте
Id: b49b4f49-8011-4b60-966b-0aa9b1d0b606
Свойства:
    -
        Имя: ВыбранныйЭлемент
        Тип: ЭлементОрганиграммы?
Наследует:
    Тип: Форма
    Заголовок: Органиграмма 
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Содержимое:
                -
                    Тип: Органиграмма<ИсточникДанныхДеревоПодгружаемый<ЭлементОрганиграммы>>
                    Имя: Органиграмма
                    ПриНажатии: ПриНажатии
                    РастягиватьПоГоризонтали: Истина
                    РастягиватьПоВертикали: Истина
                    КомандыЭлемента:
                        Тип: ФрагментКомандногоИнтерфейса<КомандаСПараметром<ЭлементОрганиграммы>>
                        Элементы:
                            -
                                Тип: КомандаСПараметром<ЭлементОрганиграммы>
                                Представление: Центрировать
                                Изображение: Лупа.svg
                                Обработчик: КомандаЦентрировать
                            -
                                Тип: КомандаСПараметром<ЭлементОрганиграммы>
                                Представление: Свернуть
                                Изображение: Минус.svg
                                Обработчик: КомандаСвернуть
                            -
                                Тип: КомандаСПараметром<ЭлементОрганиграммы>
                                Представление: Развернуть
                                Изображение: Плюс.svg
                                Обработчик: КомандаРазвернуть
```

В обработчике **ПослеСоздания** заполним органиграмму данными. Создадим два корневых элемента, которые будут содержать некоторое количество дочерних. Для этого создадим два элемента типа `ЭлементОрганиграммы`, после чего вызовем метод `Органиграмма.УстановитьЭлементы(Элементы: Обходимое<ЭлементОрганиграммы>))`. Пример того, как может выглядеть файл XBSL:

```xbsl
@Обработчик
метод ПослеСоздания()
    Заполнить()
;

метод Заполнить()
    пер Команды = новый ФрагментКомандногоИнтерфейса<КомандаСПараметром<ЭлементОрганиграммы>>()
    пер КомандаСвернуть = новый КомандаСПараметром<ЭлементОрганиграммы>(
        Обработчик = метод (Команда: КомандаСПараметром<ЭлементОрганиграммы>, Элемент: ЭлементОрганиграммы) ->
            Элемент.Свернут = не Элемент.Свернут 
        ;,
        Представление = "Свернуть/Развернуть"

                    новый ЭлементОрганиграммы(
                        Наименование = "Дочерний элемент 1.1",
                        Описание = "Дополнительное текстовое описание"
                    ),
                    новый ЭлементОрганиграммы(
                        Изображение = Ресурс{3.jpg}.Ссылка,
                        Наименование = "Дочерний элемент 1.2",

                        Изображение = Ресурс{4.jpg}.Ссылка,
                        Наименование = "Дочерний элемент 2.1",
                        Пояснение = "Должность 3",

                            ВидКонтактнойИнформации.ЭлектроннаяПочта: ["employee@example.com"],

    Элемент.Свернут = Истина

    Элемент.Свернут = Ложь
;
```

## Использование динамического списка для отображения элементов на органиграмме

Предположим, мы хотели бы динамически заполнять органиграмму данными из некоторого справочника «СправочникОрганизации». Необходимо, чтобы при создании новой записи в справочнике, данные сразу отображались на диаграмме:

Органиграмма имеет один корневой элемент сверху и восемь дочерних карточек следующего уровня. У первой ветки показаны два дочерних элемента, у второго из них — ещё три элемента нижнего уровня. Соединительные линии показывают иерархию; имена и фотографии относятся к демонстрационным данным. [Описание иллюстрации](../figures/53d2ef190000c70e75c3ab32561ebfa9c5aaf2f230bd7edf6f4761ce1e667c42-2508427f36d46b4c.md)

Добавим в проект справочник «СправочникОрганизации»:

```yaml
ВидЭлемента: Справочник
Имя: СправочникОрганизации
Id: 4a2a68e1-da8b-4645-a3fb-fd7c2709a2f7
КонтрольДоступа:
    Разрешения:
        ПоУмолчанию: РазрешеноВсем
Представление: Код
Реквизиты:
    -
        Имя: Код
        Тип: Строка
        Автонумерация:
            Использовать: Ложь
        Длина: 30
    -
        Имя: Руководитель
        Ид: 39cfe9d0-e165-4ab5-b3d9-853e0bdc49a9
        Тип: СправочникОрганизации.Ссылка?
    -
        Имя: Фото
        Ид: f4fffc9b-d661-4969-b049-d109d944d66c
        Тип: ДвоичныйОбъект.Ссылка?
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
```

Затем перейдем к основной части примера: создадим форму и поместим в нее компонент `Органиграмма` типа `Органиграмма<ДинамическийСписок>`, а в качестве источника укажем «СправочникОрганизации»:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Имя: ФормаДинамическаяОрганиграмма
ОбластьВидимости: ВПроекте
Id: 47bdfa1b-cdd7-4c7e-9112-e10e5874b264
Наследует:
    Тип: Форма
    Заголовок: Органиграмма
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Содержимое:
                -
                    Тип: Органиграмма<ДинамическийСписок>
                    Имя: Органиграмма
                    РастягиватьПоГоризонтали: Истина
                    РастягиватьПоВертикали: Истина
                    НастройкиИсточника:
                        Тип: НастройкиИсточникаДревовиднойСхемы<СтрокаДинамическогоСписка>
                        ПолеРодителя: Руководитель
                        Элемент: 
                            Тип: ЭлементОрганиграммы
                            Наименование: =ДанныеЭлемента.Данные["Код"] как Строка
                            Изображение: =ДанныеЭлемента.Данные["Фото"] как ДвоичныйОбъект.Ссылка
                    Источник:
                        ОсновнаяТаблица:
                            Таблица: СправочникОрганизации
                        Поля:
                            - 
                                Тип: ПолеДинамическогоСписка
                                Выражение: Ссылка
                            - 
                                Тип: ПолеДинамическогоСписка
                                Выражение: Код
                            - 
                                Тип: ПолеДинамическогоСписка
                                Выражение: Фото
                            - 
                                Тип: ПолеДинамическогоСписка
                                Выражение: Руководитель
```

Теперь при добавлении нового сотрудника в справочник он будет автоматически отображаться на органиграмме.

Для того чтобы автоматически заполнить «СправочникОрганизации» данными и отобразить их на диаграмме, добавьте у формы обработчик **ПослеСоздания**. В модуле формы напишите следующий код:

```xbsl
@Обработчик
метод ПослеСоздания()
    ЗаполнитьСправочник()
;

@НаСервере @ДоступноСКлиента
статический метод ЗаполнитьСправочник()
    пер Руководитель = СоздатьЭлемент("Корневой элемент", Неопределено)

    пер Дочерний1 = СоздатьЭлемент("Дочерний 1", Ресурс{1.jpg}.Ссылка, Руководитель)
    СоздатьЭлемент("Дочерний 1 - 1", Ресурс{2.jpg}.Ссылка, Дочерний1)
    пер Дочерний12 = СоздатьЭлемент("Дочерний 1 - 2", Ресурс{3.jpg}.Ссылка, Дочерний1)
    СоздатьЭлемент("Дочерний 1 - 2 - 1", Ресурс{4.jpg}.Ссылка, Дочерний12)
    СоздатьЭлемент("Дочерний 1 - 2 - 2", Ресурс{5.jpg}.Ссылка, Дочерний12)
    СоздатьЭлемент("Дочерний 1 - 2 - 3", Ресурс{6.jpg}.Ссылка, Дочерний12)

    пер Дочерний2 = СоздатьЭлемент("Дочерний 2", Ресурс{1.jpg}.Ссылка, Руководитель)
    СоздатьЭлемент("Дочерний 2 - 1", Ресурс{2.jpg}.Ссылка, Дочерний2)
    СоздатьЭлемент("Дочерний 2 - 2", Ресурс{3.jpg}.Ссылка, Дочерний2)
    СоздатьЭлемент("Дочерний 2 - 3", Ресурс{4.jpg}.Ссылка, Дочерний2)

    пер Дочерний3 = СоздатьЭлемент("Дочерний 3", Ресурс{5.jpg}.Ссылка, Руководитель)
    СоздатьЭлемент("Дочерний 3 - 1", Ресурс{6.jpg}.Ссылка, Дочерний3)
    СоздатьЭлемент("Дочерний 3 - 2", Ресурс{1.jpg}.Ссылка, Дочерний3)
    СоздатьЭлемент("Дочерний 3 - 3", Ресурс{2.jpg}.Ссылка, Дочерний3)
    СоздатьЭлемент("Дочерний 3 - 4", Ресурс{3.jpg}.Ссылка, Дочерний3)

    пер Дочерний4 = СоздатьЭлемент("Дочерний 4", Ресурс{4.jpg}.Ссылка, Руководитель)
    СоздатьЭлемент("Дочерний 4 - 1", Ресурс{5.jpg}.Ссылка, Дочерний4)
    СоздатьЭлемент("Дочерний 4 - 2", Ресурс{6.jpg}.Ссылка, Дочерний4)
;

@НаСервере
статический метод СоздатьЭлемент(Код: Строка, Фото: ДвоичныйОбъект.Ссылка?, 
                                 Руководитель: СправочникОрганизации.Ссылка? = Неопределено): СправочникОрганизации.Ссылка
    пер Элемент = СправочникОрганизации.НайтиПоКоду(Код)
    если Элемент == Неопределено
        пер НовыйЭлемент = новый СправочникОрганизации.Объект()
        НовыйЭлемент.Код = Код
        НовыйЭлемент.Фото = Фото
        НовыйЭлемент.Руководитель = Руководитель
        НовыйЭлемент.Записать()
        Элемент = НовыйЭлемент.Ссылка
    ;
    возврат Элемент
;
```
