Форма [обработки](../../wiki/project/processing-project-element-acb124c72bfa.md).

processing-form [Описание иллюстрации](../figures/d37cd444e657c15fc73084e025b30691dd0b841f6edd7373921aaf903fddec57-6c044f0efa678138.md)

При открытии формы в модальном или всплывающем окне возвращается значение типа `ТипРезультата`. По умолчанию — `Неопределено`. Если закрыть форму нажатием на крестик или кликом мимо окна при открытии во всплывающем окне или вызвать метод [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md) без передачи аргумента, результатом открытия будет `Неопределено`. Чтобы узнать, открыта ли форма в данный момент, используйте свойство [Открыта](../../wiki/interface/form-ru-89fb5e7eaeb3.md).

---

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Заголовок

```yaml
Заголовок: Авто|Строка
```

Заголовок формы.

---

#### Представление

```yaml
Представление: Строка
```

Строка, которая будет показана как заголовок формы.

---

#### ВключатьВАвтоИнтерфейс

```yaml
ВключатьВАвтоИнтерфейс: Булево
```

Признак включения формы в [автоматический интерфейс](../../wiki/interface/automatic-interface-df2ea881a675.md).

---

#### SeoОписание

```yaml
SeoОписание: Авто|Строка
```

Задает описание содержимого формы, которое сохраняется в HTML-разметке страницы как значение мета-тега `description`. Используется поисковыми системами для создания краткого описания страницы в поисковой выдаче ([подробнее](../../wiki/project/seo-optimization-27876869518e.md)).

**Авто** — пустая строка.

---

#### ВажностьИзбранногоПользователя

`Версия 10.0 и выше`

```yaml
ВажностьИзбранногоПользователя: ВычисляемоеВыражение|Авто|ВажностьИзбранногоПользователя
```

Определяет вид отображения команды работы с **Избранным** внутри формы.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/processingform-ru-b6a0c6cd781d.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/processingform-ru-b6a0c6cd781d.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Высота

```yaml
Высота: ВычисляемоеВыражение|Авто|Число
```

Высота компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](../../wiki/interface/processingform-ru-b6a0c6cd781d.md).

#### ПовторноеИспользованиеФормы

```yaml
ПовторноеИспользованиеФормы: ВычисляемоеВыражение|Авто|Булево
```

Признак повторного использования формы. Возможные значения свойства:

- Авто
  
  — (по умолчанию) система сама определяет, может ли форма использоваться повторно. Формы списков по возможности используются повторно, остальные формы — нет.
- Истина
  
  — форма используется повторно. Форма, открытая в основной области, при закрытии не удаляется. При повторном открытии формы открывается тот же самый экземпляр.
- Ложь
  
  — форма не используется повторно.

Последовательность подсказок, которая запускается автоматически при первом открытии формы. Если данная последовательность уже была просмотрена пользователем до конца, то больше она запускаться не будет.

Состоит из элементов типа [ОбучающаяПодсказка](../../wiki/interface/tutorialtooltip-ru-e538f221bd73.md). Обучающая подсказка обладает следующими свойствами:

- Заголовок
  
  — заголовок подсказки,
- Описание
  
  — текст внутри подсказки,
- ОпорныйЭлемент
  
  — компонент, около которого появляется подсказка,
- Изображение
  
  — изображение внутри подсказки.

  — открывает форму в
  
  [области содержимого](../../wiki/project/content-area-6e990db68726.md)
  
  приложения (рекомендуется использовать для списков и форм навигации).
- ВДиалоговомОкне
  
  — открывает форму в диалоговом окне (рекомендуется использовать для форм сущностей). Диалоговое окно блокирует область содержимого, однако его можно свернуть, чтобы вернуться к приложению.
- ВМодальномОкне
  
  — открывает форму в модальном окне (рекомендуется использовать, когда требуется получить от пользователя данные, необходимые для продолжения операции). Модальное окно блокирует родительское диалоговое окно (при наличии) или область содержимого приложения. Сворачивается вместе с родительским окном.
- ВоВсплывающемОкне
  
  — открывает форму во всплывающем окне (рекомендуется использовать для форм выбора).

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/processingform-ru-b6a0c6cd781d.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/processingform-ru-b6a0c6cd781d.md).

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](../../wiki/interface/processingform-ru-b6a0c6cd781d.md) равно **Ложь**.

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

## Дочерние элеметы

#### Содержимое

```yaml
Содержимое: ШаблонФормы?
```

Экземпляр компонента интерфейса, расположенный в данном компоненте.

---

#### ОсновнаяКоманда

```yaml
ОсновнаяКоманда: Команда?
```

Задает команду, которая определяет главное действие формы. Здесь мы рекомендуем использовать команду, после вызова которой форма будет закрыта. Типичные примеры:

- Сохранить (и закрыть),
- Отправить (письмо),
- Закрыть.

---

#### КомандыСоздания

```yaml
КомандыСоздания: Команда|ГруппаКомандногоИнтерфейса|?
```

Задает команду или группу команд кнопке создания. Место и вид отображения кнопки создания может быть различным в зависимости от вида интерфейса:

- В мобильном интерфейсе это
  
  [ПлавающаяКнопка](../../wiki/interface/floatingbutton-ru-d10e39581f0c.md)
  
  , которая отображается в правом нижнем углу экрана;
- В веб-интерфейсе кнопка отображается справа от заголовка формы.

---

#### ОбычныеКоманды

```yaml
ОбычныеКоманды: ФрагментКомандногоИнтерфейса?
```

Список основных команд формы. Отображаются в нижней панели команд формы в виде [обычных кнопок](../../wiki/project/secondary-button-1ea0bfea1df0.md). Обычные команды отображаются рядом с командой [ОсновнаяКоманда](../../wiki/interface/processingform-ru-b6a0c6cd781d.md).

---

#### ДополнительныеКоманды

```yaml
ДополнительныеКоманды: ФрагментКомандногоИнтерфейса?
```

Список дополнительных команд формы. Отображаются в правой части заголовка формы ([веб-интерфейс](../../wiki/interface/web-interface-25dbf3b8529c.md)) или под заголовком формы ([мобильный интерфейс](../../wiki/interface/mobile-interface-842a75f7790c.md)).
