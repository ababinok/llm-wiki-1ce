Таблица регистрации изменений создается, только если справочник включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению элемента справочника, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице справочника.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **Ссылка** из таблицы регистрации изменений справочника **ЖурналИзменений.Изменения**:

```xbql
ВЫБРАТЬ
    ЖурналИзменений.Узел КАК Узел,
    ЖурналИзменений.Ссылка КАК Ссылка
ИЗ
    ЖурналИзменений.Изменения КАК Журнал
```

Эта таблица содержит записи, соответствующие изменениям в элементах справочника, зарегистрированным для соответствующих узлов. Одна запись таблицы — изменения в одном элементе справочника, зарегистрированные для одного узла.

---

## Поля

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяСправочника.Ссылка
```

Ссылка на элемент справочника, в котором были зарегистрированы изменения. Например, для справочника **Товары** это поле будет иметь тип `Товары.Ссылка`.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена, для которого зарегистрированы изменения.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Если изменение не включено в сообщение, то значение `Неопределено`.
