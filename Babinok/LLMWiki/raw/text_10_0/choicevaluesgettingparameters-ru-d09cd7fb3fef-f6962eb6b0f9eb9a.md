## Конструкторы

### ПараметрыПолученияЗначенийВыбора

`Доступность: Сервер`

```
ПараметрыПолученияЗначенийВыбора()
```

Создает параметры выбора значений со значениями полей по умолчанию.

### Подстроки

`Доступность: Сервер`

```
Подстроки: ЧитаемыйМассив<Строка>
```

Массив подстрок поиска.

---

### ПрисоединенныеТаблицы

`Доступность: Сервер`

```
ПрисоединенныеТаблицы: Массив<ПрисоединеннаяТаблица>
```

Список присоединенных таблиц, участвующих в выборке данных. Могут использоваться для дополнительной фильтрации данных. В данных присоединенных таблиц поиск по подстроке не осуществляется.
