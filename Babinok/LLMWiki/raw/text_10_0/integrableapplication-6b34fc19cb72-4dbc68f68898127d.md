#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

```yaml
        Изменение: КонтрольДоступа
        Удаление: КонтрольДоступа

```

Содержит [настройки прав доступа](../../wiki/security/automatically-grant-permissions-to-user-groups-c39cf49a7075.md) к элементам интегрируемого приложения.

<details>
<summary>**Свойства**</summary>

##### Разрешения

Набор разрешений на выполнение основных операций с интегрируемым приложением.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Создание

Задает разрешение на создание нового элемента интегрируемого приложения. Проверяется непосредственно перед записью изменения в базу данных.

##### Чтение

Задает разрешение на чтение элемента интегрируемого приложения из базы данных. Проверяется только в момент загрузки ссылки из базы данных.

##### Изменение

Задает разрешение на изменение элемента интегрируемого приложения, хранящегося в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

##### Удаление

Задает разрешение на удаление элемента интегрируемого приложения. Проверяется в момент вызова удаления.

</details>

##### РасчетРазрешенийПо

Массив полей, по которым выполняется расчет разрешений доступа. Заполняется при выборе значения [РазрешенияВычисляютсяДляКаждогоОбъекта](../../wiki/project/accesscontrol-ru-c40ccedbcdb4.md).

</details>

#### ИмяВИнтегрируемомПриложении

```yaml
ИмяВИнтегрируемомПриложении: Строка
```

Имя интегрируемого приложения во внешнем проекте, по которому устанавливается соответствие.

Если внешний проект отличается от текущего, то в нем может не быть интегрируемого приложения с тем же именем. В этом случае соответствие ищется по значению свойства **ИмяВИнтегрируемомПриложении**.

Если **ИмяВИнтегрируемомПриложении** не задано, поиск во внешнем проекте выполняется по имени текущего интегрируемого приложения: сначала по полному имени с пространством имен, при отсутствии — по короткому. Если найдено несколько элементов с одним коротким именем, обмен данными прерывается.

Если **ИмяВИнтегрируемомПриложении** задано, поиск выполняется по этому имени вместо имени текущего интегрируемого приложения. При использовании короткого имени поиск выполняется только по нему. Если найдено несколько элементов, обмен данными прерывается.

Во внешнем проекте используется аналогичная настройка: соответствие устанавливается по совпадению значений **ИмяВИнтегрируемомПриложении** в обоих проектах. Например, в текущем проекте есть элемент **ИмяИнтегрируемогоПриложения1** со свойством **ИмяВИнтегрируемомПриложении = ИП**, а во внешнем — **ИмяИнтегрируемогоПриложения2** с таким же значением свойства. Соответствие будет найдено по совпадению этих значений.
