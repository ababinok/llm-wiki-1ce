---

### ВыравниваниеКопирайтаПоГоризонтали

```
ВыравниваниеКопирайтаПоГоризонтали: Авто|ВыравниваниеПоГоризонтали
```

---

### ГоризонтальнаяПозицияКопирайта

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
ГоризонтальнаяПозицияКопирайта: Авто|ВыравниваниеПоГоризонтали
```

Переименован на [ВыравниваниеКопирайтаПоГоризонтали](../../wiki/interface/customclientapplication-ru-4315de55a773.md)

---

### КомпонентОбластиФормы

`Доступность: Клиент`

```
КомпонентОбластиФормы: Страницы|СтековаяГруппа
```

Ссылка на компонент [Страницы](../../wiki/interface/pages-ru-9b4ca3b4a152.md) или [СтековаяГруппа](../../wiki/interface/stackgroup-ru-e78423e50743.md), в котором по умолчанию будут открываться формы приложения:

- [Страницы](../../wiki/interface/pages-ru-9b4ca3b4a152.md)
  
  : формы оборачиваются в компонент
  
  [Страница](../../wiki/interface/page-ru-0c0a530fde03.md)
  
  , показывающий заголовок формы и саму форму.
- [СтековаяГруппа](../../wiki/interface/stackgroup-ru-e78423e50743.md)
  
  : формы показываются как есть.

Если не задано, формы будут открываться в модальном окне

---

### ОтступПоВертикали

`Доступность: Клиент`

```
ОтступПоВертикали: Авто|РазмерОтступа
```

Отступ от границ приложения до границ содержимого по вертикали.

---

### ОтступПоГоризонтали

`Доступность: Клиент`

```
ОтступПоГоризонтали: Авто|РазмерОтступа
```

Отступ от границ приложения до границ содержимого по горизонтали.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент?
```

Компонент, который определяет содержимое компонента приложения.
