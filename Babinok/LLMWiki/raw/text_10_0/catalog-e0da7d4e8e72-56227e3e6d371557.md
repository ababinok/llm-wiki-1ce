[Справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md) содержит однородные данные, которые можно представить в виде таблицы, имеющей одну или несколько колонок. Строки этой таблицы являются элементами справочника. Каждый элемент имеет уникальный идентификатор, называемый [ссылкой](../../wiki/project/reference-94bfeabd231c.md). На каждый элемент можно сослаться во время работы приложения, например выбрать его при заполнении ведомости учета рабочего времени.

Справочник содержит специальные свойства, которые называются [реквизитами](../../wiki/data/attribute-e6a1152077c2.md). Реквизит — это описание одной колонки в такой таблице. У справочника есть стандартные реквизиты: **Код**, **Владелец**, **Наименование**, **Родитель** и **Файлы**. В проекте вы можете добавить справочнику один или несколько стандартных реквизитов, а также любое количество собственных реквизитов, чтобы описать дополнительные колонки, например **ФИО**, **Возраст**, **Адрес**, **Должность** и т. д.

##### РазделительПрефикса

Символы, отделяющие префикс от номера. Значение по умолчанию — пустая строка (разделитель отсутствует).

##### РазделительПостфикса

Символы, отделяющие номер от постфикса. Значение по умолчанию — пустая строка (разделитель отсутствует).

##### ДлинаПрефикса

Длина префикса. Может принимать следующие значения:

- 0
  
  — префикс запрещен (значение по умолчанию),
- положительное число — количество символов в префиксе,
- ∞
  
  или
  
  -1
  
  — длина не ограничена.

##### ДлинаПостфикса

Длина постфикса. Может принимать следующие значения:

- 0
  
  — постфикс запрещен (значение по умолчанию),
- положительное число — количество символов в постфиксе,
- ∞
  
  или
  
  -1
  
  — длина не ограничена.

##### ОграниченияПоСимволам

Указывает, использовать ли следующие ограничения по символам:

- префикс не может заканчиваться на цифру,
- постфикс не может содержать цифры.

</details>

Префикс, который будет добавляться к номеру.

##### Постфикс

Постфикс, который будет добавляться к номеру.

</details>

##### Разрешения

Набор разрешений на выполнение основных операций со справочником.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Создание

Задает разрешение на создание нового элемента справочника. Проверяется непосредственно перед записью изменения в базу данных.

##### Чтение

Задает разрешение на чтение элемента справочника из базы данных. Проверяется только в момент загрузки ссылки из базы данных.

##### Изменение

Задает разрешение на изменение элемента справочника, хранящегося в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

##### Удаление

Задает разрешение на удаление элемента справочника. Проверяется в момент вызова удаления.

</details>

##### РасчетРазрешенийПо

Массив полей, по которым выполняется расчет разрешений доступа. Заполняется при выборе значения **РазрешенияВычисляютсяДляКаждогоОбъекта**.

</details>

#### ИерархияПоУмолчанию

`Версия 8.0 и выше`

```yaml
ИерархияПоУмолчанию: Строка
```

Имя иерархии по умолчанию. Указывается имя дополнительной иерархии, которая будет использоваться по умолчанию.

Если свойство не задано, то иерархия по умолчанию определяется следующим образом:

- если имеется иерархия элементов, то она станет иерархией по умолчанию;
- если иерархия элементов отсутствует и задана только одна дополнительная иерархия, то она станет иерархией по умолчанию;
- в остальных случаях иерархия по умолчанию считается незаданной.
