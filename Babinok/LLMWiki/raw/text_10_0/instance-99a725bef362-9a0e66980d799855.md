Экземпляр — это значение некоторого типа.

```xbsl
знч ВключитьКэширование = Истина                    // Экземпляр типа «Булево»
знч Документ = новый Файл("C:\\docs\\report.txt")   // Экземпляр типа «Файл»
знч Результат = 10 + 5                              // Экземпляр типа «Число»
```
