Рассмотрим пример использования регистра накопления для хранения остатков. В регистре накопления **ОстаткиНоменклатуры** накапливаются данные о количестве и сумме товаров в разрезе двух измерений — складов и номенклатуры.

Изменение состояния регистра происходит при записи документов **ПриходнаяНакладная** и **РасходнаяНакладная**. Эти документы являются регистраторами для регистра накопления и формируют в нем записи вида **Приход** и **Расход**.

В примере показан метод записи документов с проведением и без него. Режим записи устанавливается с помощью параметра записи **РежимЗаписиДокумента**.

> [!NOTE] примечание
> Полный код данного примера доступен на сайте [Практические примеры разработки на «1С:Предприятие.Элементе»](https://hub.1cmycloud.com/?state=examples/balance-accumulation-register).

## Создание вспомогательных справочников и документов

### Справочник «Номенклатура»

1. Создайте справочник **Номенклатура** для хранения данных о товарах. Добавьте стандартные реквизиты **Наименование** и **Код**.
  
  <details>
  <summary>Пример YAML-файла справочника «Номенклатура»</summary>
  
  ```yaml
  ВидЭлемента: Справочник
  Ид: 4227e34a-40e6-42c8-aec1-5fa50e46e44c
  Имя: Номенклатура
  ОбластьВидимости: ВПодсистеме
  Реквизиты:
      -
          Имя: Наименование
      -
          Имя: Код
          Длина: 11
          Автонумерация:
              ДлинаНумерации: 0
  ```
  
  </details>
2. Заполните справочник тестовыми данными.
  
  ```xbsl
  @НаСервере @ДоступноСКлиента
  статический метод ЗаполнитьСправочникНоменклатура(): ЧитаемыйМассив<Номенклатура.Ссылка>
      знч Номенклатура = <Номенклатура.Ссылка>[]
  
      Номенклатура.Добавить(СоздатьНоменклатуру("Варочная панель"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Посудомоечная машина"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Стиральная машина"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Духовой шкаф"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Микроволновая печь"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Вытяжка"))
      Номенклатура.Добавить(СоздатьНоменклатуру("Холодильник"))
  
      возврат Номенклатура
  ;
  
  @НаСервере @ДоступноСКлиента
  статический метод СоздатьНоменклатуру(Наименование: Строка): Номенклатура.Ссылка
      знч Номенклатура = новый Номенклатура.Объект(Наименование = Наименование)
      Номенклатура.Записать()
      возврат Номенклатура.Ссылка
  ;
  ```

3. Добавьте к проекту перечисление **РежимЗаписиДокумента** со следующими значениями:
  
  - Проведение
    
    — документ будет проведен, то есть отражен в учете;
  - Запись
    
    — документ будет сохранен без проведения;
  - ОтменаПроведения
    
    — для документа будет выполнена отмена проведения.

## Формирование движения по регистру

В данном примере показано, как вручную обработать проведение приходных и расходных накладных и сформировать соответствующие записи в регистре накопления.

### Проведение приходных накладных

1. Для элемента проекта **ПриходнаяНакладная** создайте [модуль объекта](../../wiki/data/document-types-18ccdbf51e8a.md).
2. В обработчики событий `ПередЗаписью` и `ПослеЗаписи` добавьте логику проведения приходных накладных. Для добавления записей о приходе в регистр накопления используйте метод [`{ИмяРегистраНакопления}.НаборЗаписей.ДобавитьЗапись()`](../../wiki/data/accumulationregistername-recordset-ru-b4bf21480f3e.md):
  
  ```xbsl
  @Обработчик
  метод ПередЗаписью(До: ПриходнаяНакладная.Данные, ПараметрыЗаписи: ПриходнаяНакладная.ПараметрыЗаписи)
      выбор ПараметрыЗаписи.РежимЗаписи
      когда Проведение
          если ПометкаУдаления
              выбросить новый ИсключениеНедопустимоеСостояние(
                  "Помеченный на удаление документ не может быть проведен.")
          ;
          Проведен = Истина
          
      когда ОтменаПроведения
          Проведен = Ложь
          
      когда Неопределено
          если ПометкаУдаления
              Проведен = Ложь
          ;
      ;
      
      СуммаПоДокументу = СписокНоменклатуры.Преобразовать(СписокНоменклатуры -> СписокНоменклатуры.Сумма).Сумма()
  ;
  
  @Обработчик
  метод ПослеЗаписи(До: ПриходнаяНакладная.Данные, ПараметрыЗаписи: ПриходнаяНакладная.ПараметрыЗаписи)
      если ПараметрыЗаписи.РежимЗаписи == РежимЗаписиДокумента.Проведение 
          или (ПараметрыЗаписи.РежимЗаписи == РежимЗаписиДокумента.Запись и Проведен)
          
          ВыполнитьПроведение()
          
      иначе если ПараметрыЗаписи.РежимЗаписи == РежимЗаписиДокумента.ОтменаПроведения
          или ПометкаУдаления != До.ПометкаУдаления и ПометкаУдаления
          
          ОтменитьПроведение()
      ;
  ;
  
  метод ВыполнитьПроведение()
      знч НаборЗаписей = новый ОстаткиНоменклатуры.НаборЗаписей()
      НаборЗаписей.Фильтр.Установить(Регистратор = Ссылка)
      
      // Добавление записей в регистр накопления
      для Строка из СписокНоменклатуры
          НаборЗаписей.ДобавитьЗапись(
              Период = Дата,
              ВидЗаписи = ВидЗаписиРегистраНакопления.Приход,
              Номенклатура = Строка.Номенклатура,
              Склад = Склад,
              Количество = Строка.Количество,
              Сумма = Строка.Сумма
          )
      ;
      
      НаборЗаписей.Записать()
  ;
  
  метод ОтменитьПроведение()
      знч НаборЗаписей = новый ОстаткиНоменклатуры.НаборЗаписей()
      НаборЗаписей.Фильтр.Установить(Регистратор = Ссылка)
      НаборЗаписей.Записать()
  ;
  ```

### Проведение расходных накладных

1. Для элемента проекта **РасходнаяНакладная** создайте [модуль объекта](../../wiki/data/document-types-18ccdbf51e8a.md).
2. В обработчики событий `ПередЗаписью` и `ПослеЗаписи` добавьте логику проведения расходных накладных. При проведении накладной выполняется проверка наличия товаров на складах путем запроса к [виртуальной таблице остатков](../../wiki/queries/accumulationregistername-balance-ru-cdd8ad42e449.md).
  
  ```xbsl
  @Обработчик
  метод ПередЗаписью(До: РасходнаяНакладная.Данные, ПараметрыЗаписи: РасходнаяНакладная.ПараметрыЗаписи)
      выбор ПараметрыЗаписи.РежимЗаписи
      когда Проведение
          если ПометкаУдаления
              выбросить новый ИсключениеНедопустимоеСостояние(
                  "Помеченный на удаление документ не может быть проведен.")
          ;
          Проведен = Истина
  
      когда ОтменаПроведения
          Проведен = Ложь
  
      когда Неопределено
          если ПометкаУдаления
              Проведен = Ложь
          ;
      ;
  
      СуммаПоДокументу = СписокНоменклатуры.Преобразовать(СписокНоменклатуры -> СписокНоменклатуры.Сумма).Сумма()
  ;
  
  
  @Обработчик
  метод ПослеЗаписи(До: РасходнаяНакладная.Данные, ПараметрыЗаписи: РасходнаяНакладная.ПараметрыЗаписи)
      если ПараметрыЗаписи.РежимЗаписи == РежимЗаписиДокумента.Проведение или (ПараметрыЗаписи.РежимЗаписи
              == РежимЗаписиДокумента.Запись и Проведен)
          ВыполнитьПроведение()
  
      иначе если ПараметрыЗаписи.РежимЗаписи == РежимЗаписиДокумента.ОтменаПроведения или ПометкаУдаления != До
              .ПометкаУдаления и ПометкаУдаления
          ОтменитьПроведение()
      ;
  ;
  
  метод ВыполнитьПроведение()
      ОтменитьПроведение()
  
      знч БлокировкиПоНоменклатуре =
          СписокНоменклатуры.Преобразовать(Строка -> новый ОстаткиНоменклатуры.Блокировки.Измерения(
                                          Номенклатура = Строка.Номенклатура)).Уникальные()
      Блокировки.Заблокировать(БлокировкиПоНоменклатуре)
  
      исп ОбластьВидимостиВременныхТаблиц.Открыть()
  
      знч ЗапросНоменклатуры = Запрос{
          ВЫБРАТЬ
              РасходнаяНакладнаяСписокТоваров.Номенклатура КАК Номенклатура,
              СУММА(РасходнаяНакладнаяСписокТоваров.Количество) КАК Количество
          ПОМЕСТИТЬ
              ВТ_Номенклатура
          ИЗ
              РасходнаяНакладная.СписокНоменклатуры КАК РасходнаяНакладнаяСписокТоваров
          ГДЕ
              РасходнаяНакладнаяСписокТоваров.Владелец == %Ссылка
          СГРУППИРОВАТЬ ПО
              РасходнаяНакладнаяСписокТоваров.Номенклатура
      }
      ЗапросНоменклатуры.Выполнить()
  
      знч Запрос = Запрос{
          ВЫБРАТЬ
              ВТ_Номенклатура.Номенклатура КАК Номенклатура,
              ВТ_Номенклатура.Номенклатура.Представление.ЗаменитьNull("") КАК НоменклатураПредставление,
              ВТ_Номенклатура.Количество КАК КоличествоВДокументе,
              ОстаткиНоменклатурыОстатки.Склад КАК Склад,
              ОстаткиНоменклатурыОстатки.КоличествоОстаток.ЗаменитьNull(0) КАК КоличествоОстаток,
              ОстаткиНоменклатурыОстатки.СуммаОстаток.ЗаменитьNull(0) КАК СуммаОстаток
          ПОРОДИТЬ
              ОстаткиНоменклатурыСводная
          ИЗ
              ВТ_Номенклатура КАК ВТ_Номенклатура
                  ЛЕВОЕ СОЕДИНЕНИЕ ОстаткиНоменклатуры.Остатки КАК ОстаткиНоменклатурыОстатки
                  ПО ВТ_Номенклатура.Номенклатура == ОстаткиНоменклатурыОстатки.Номенклатура
          УПОРЯДОЧИТЬ ПО
              ОстаткиНоменклатурыОстатки.Номенклатура
      }
  
      пер Номенклатура: Номенклатура.Ссылка? = Неопределено
      пер НоменклатураПредставление = ""
      пер ОсталосьСписать = 0
  
      знч НаборЗаписей = новый ОстаткиНоменклатуры.НаборЗаписей()
      НаборЗаписей.Фильтр.Установить(Регистратор = Ссылка)
  
      для Строка из Запрос.Выполнить()
          если Номенклатура != Строка.Номенклатура
              если ОсталосьСписать != 0
                  выбросить новый ИсключениеВыполнения(
                      "Не хватает %НоменклатураПредставление в количестве %ОсталосьСписать.")
              ;
              ОсталосьСписать = Строка.КоличествоВДокументе
              Номенклатура = Строка.Номенклатура
              НоменклатураПредставление = Строка.НоменклатураПредставление
  
          иначе если ОсталосьСписать == 0
              продолжить
          ;
  
          если Строка.КоличествоОстаток == 0
              продолжить
          ;
  
          знч КоличествоКСписанию = Мин(ОсталосьСписать, Строка.КоличествоОстаток)
  
          пер СуммаКСписанию: Число
          если КоличествоКСписанию == Строка.КоличествоОстаток
              СуммаКСписанию = Строка.СуммаОстаток
          иначе
              СуммаКСписанию = Строка.СуммаОстаток / Строка.КоличествоОстаток * КоличествоКСписанию
          ;
  
          НаборЗаписей.ДобавитьЗапись(
              Период = Дата,
              ВидЗаписи = ВидЗаписиРегистраНакопления.Расход,
              Номенклатура = Номенклатура,
              Склад = Строка.Склад как Склады.Ссылка,
              Количество = КоличествоКСписанию,
              Сумма = СуммаКСписанию)
  
          ОсталосьСписать = ОсталосьСписать - КоличествоКСписанию
      ;
  
      если ОсталосьСписать != 0
          выбросить новый ИсключениеВыполнения("Не хватает %НоменклатураПредставление в количестве %ОсталосьСписать.")
      ;
  
      НаборЗаписей.Записать()
  ;
  
  метод ОтменитьПроведение()
      знч НаборЗаписей = новый ОстаткиНоменклатуры.НаборЗаписей()
      НаборЗаписей.Фильтр.Установить(Регистратор = Ссылка)
      НаборЗаписей.Записать()
  ;
  ```
