`Стд::Интерфейс::Команды::КомандаСПараметром<ТипПараметра>` `Доступность: Клиент`

ТипПараметра: тип параметра команды.

Команда с дополнительным параметром. При выполнении команды в ее обработчик передается дополнительный параметр.

**Сравнение**

Ссылочное

Структурное сравнение.

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Конструкторы

### КомандаСПараметром

`Версия 9.0 и выше`

`Доступность: Клиент`

```
КомандаСПараметром(
  Обработчик: (КомандаСПараметром<ТипПараметра>, ТипПараметра)->ничто,
  Представление: Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|? = Неопределено,
  Важность: ВажностьКоманды = ВажностьКоманды.Обычная,
  Доступность: Булево = Истина,
  Видимость: Булево = Истина,
  ОпасностьДействия: ОпасностьДействия = ОпасностьДействия.Отсутствует)
```

Создает команду с параметром с заданными значениями полей и обработчиком.

## Свойства

### Важность

`Доступность: Клиент`

```
Важность: ВажностьКоманды
```

Определяет важность команды. Важность может использоваться при отображении команды. Например, все команды с важностью [Низкая](../../wiki/interface/commandimportance-ru-986d64839edb.md) из свойства формы [ДополнительныеКоманды](../../wiki/interface/form-ru-89fb5e7eaeb3.md) будут отображены в выпадающем меню "Еще"

---

### Видимость

`Доступность: Клиент`

```
Видимость: Булево
```

Управляет видимостью команды

---

### Доступность

`Доступность: Клиент`

```
Доступность: Булево
```

Если `Ложь`, команда недоступна для выполнения

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Картинка команды.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/commandwithparameter-ru-4a1123ae43c7.md).

---

### ОпасностьДействия

`Доступность: Клиент`

```
ОпасностьДействия: ОпасностьДействия
```

Управляет визуальным отображением опасности действия команды. Опасность действия отображается только тогда, когда компонент, используемый для отображения команды умеет ее показывать. На данный момент это только компонент [Кнопка](../../wiki/interface/button-ru-d0cdd9e186f7.md).

---

### Представление

`Доступность: Клиент`

```
Представление: Строка
```

Текстовое представление команды.
