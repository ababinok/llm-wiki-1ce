## Свойства

### Отсутствует

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Отсутствует
```

Список всегда отображется без навигации. При этом часть данных может быть недоступна, если эти данные не помещаются в размер списка.

---

### ПереключательСтраниц

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПереключательСтраниц
```

Навигация по списку осуществляется с помощью переключателя страниц внизу. Если все данные помещаются на одной странице, переключатель не отображается.

---

### КнопкаПодгрузки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
КнопкаПодгрузки
```

При таком значении свойства [Навигация](../../wiki/interface/list-ru-58c40755a735.md) список работает следующим образом:

- при создании запрашивается размер данных, равный
  
  [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md)
- если данные еще есть, то в конце списка появляется кнопка "Еще...", при нажатии на которую загружается еще одна порция, равная
  
  [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md)
  
  Примечание: после создания списка изменение свойства
  
  [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md)
  
  влияет только на размер подгружаемых порций, то есть при его изменении список в этом режиме не обновится, в отличие от навигации
  
  [ПереключательСтраниц](../../wiki/interface/listnavigation-ru-07130a8f2cf5.md)
  
  .

---

### ПодгрузкаПриПрокрутке

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПодгрузкаПриПрокрутке
```

При таком значении свойства [Навигация](../../wiki/interface/list-ru-58c40755a735.md) данные автоматически подгружаются в процессе прокрутки к концу списка.

При создании отображается размер данных, равный [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md). Если [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md) меньше, чем количество строк, которые список может одновременно отобразить, то данные подгружаются до полного заполнения страницы. Размер одной порции загружаемых данных - [РазмерСтраницы](../../wiki/interface/list-ru-58c40755a735.md).
