Чтобы удалить зависимость от библиотеки из проекта, выполните следующие действия:

1. В навигаторе проекта нажмите на **Описание проекта**, чтобы отобразить его свойства.
2. В палитре свойств в разделе **Библиотеки** нажмите кнопку **Удалить** для нужной библиотеки.
  
  

Вы также можете удалить зависимость от библиотеки путем изменения файла **Проект.yaml**:

```yaml
Ид: e698f2a4-2d73-4573-be3c-390cc7b61a2a
Имя: DemoCrmProject
Представление: Демо CRM
# Остальные свойства проекта
# ...
Библиотеки:
# Удалите выделенные строки, чтобы исключить библиотеку из проекта.
    -
        Имя: Библиотека1
        Поставщик: e1c
        Версия: 1.0
    -
        Имя: Библиотека2
        Поставщик: e1c
        Версия: 1.0
```
