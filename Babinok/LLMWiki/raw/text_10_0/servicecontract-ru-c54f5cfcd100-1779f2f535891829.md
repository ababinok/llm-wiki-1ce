---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### ОбластьРеализации

```yaml
ОбластьРеализации: ОбластьВидимости
```

Определяет область, в которой можно создавать элементы, реализующие контракт. Может принимать следующие значения:

- Глобально
  
  — элементы можно создавать глобально, во всех проектах;
- ВПроекте
  
  — элементы можно создавать в проекте, которому принадлежит контракт;
- ВПодсистеме
  
  — элементы можно создавать в подсистеме, которой принадлежит контракт.

#### Окружение

```yaml
Окружение: ВидОкружения
```

[Окружение](../../wiki/project/context-60cdcec65127.md), в котором доступен элемент проекта: **Клиент**, **Сервер**, **КлиентИСервер**.

---

#### Множественный

```yaml
Множественный: Булево
```

Признак того, что у контракта может быть не одна, а несколько [реализаций](../../wiki/project/implementation-d8e9302907a6.md). Значение по умолчанию — **Истина**.

От значения этого свойства зависит наличие методов `ПолучитьСервис()` и `ПолучитьСервисы()`:

- Истина
  
  — присутствует метод
  
  `ПолучитьСервисы()`
  
  ;
- Ложь
  
  — присутствует метод
  
  `ПолучитьСервис()`
  
  .

---

#### Обязательный

```yaml
Обязательный: Булево
```

Признак того, что у контракта есть хотя бы одна реализация. Значение по умолчанию — **Ложь**.

---

#### НастройкиТипа

```yaml
НастройкиТипа: 
    Контракты: Строка[]
```

Содержит типы контрактов сервиса. Указанные типы становятся базовыми для типа, порожденного по текущему элементу.
