## Свойства

### Запуск

`Доступность: КлиентИСервер`

```
Запуск: Булево
```

Указывает было приложение запущено или переход был в уже запущенный экземпляр.

---

### НавигационнаяСсылка

`Доступность: КлиентИСервер`

```
НавигационнаяСсылка: НавигационнаяСсылка?
```

Будет содержать объект [НавигационнаяСсылка](../../wiki/interface/navigationlink-ru-ca80622e4181.md), если переход был по навигационной ссылке. В остальных случаях свойство будет `Неопределено`.

---

### Ссылка

`Доступность: КлиентИСервер`

```
Ссылка: Url?
```

Содержит объект Url с данными ссылки.

---

### СтандартнаяОбработка

`Доступность: КлиентИСервер`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной (системной) обработки события. Если установить данному свойству значение `Ложь`, стандартная обработка события производиться не будет. Отказ от стандартной обработки не отменяет действие. Если переход осуществлен по навигационной ссылке, то [СтандартнаяОбработка](../../wiki/interface/onopenbylinkevent-ru-a00962916f22.md) будет установлена в `Истина`. В остальных случаях [СтандартнаяОбработка](../../wiki/interface/onopenbylinkevent-ru-a00962916f22.md) устанавливается в `Ложь`.
