`Стд::ЗакрытыйДиапазон<ТипГраницы>` `Доступность: КлиентИСервер`

ТипГраницы: тип границы диапазона. Ограничения параметра типа: Стд::Сравнимое<BoundType>.

Закрытый (ограниченный) диапазон, границы интерпретируются включительно.

**Сравнение**

Структурное

Оба типа диапазонов ([ЗакрытыйДиапазон](../../wiki/stdlib/closedrange-ru-7f62ab997f5b.md) и [Диапазон](../../wiki/stdlib/range-ru-eb762726fd87.md)) сравнимы между собой и не учитывают параметр типа. Сравниваются границы между собой.

## Иерархия типа

*Базовые типы:* [Диапазон<ТипГраницы>](../../wiki/stdlib/range-ru-eb762726fd87.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Сравнение**

```xbsl
знч Равны = новый Диапазон(1, 10) == новый ЗакрытыйДиапазон(1, 10) // true
```

---

## Конструкторы

### ЗакрытыйДиапазон

`Доступность: КлиентИСервер`

```
ЗакрытыйДиапазон(
  От: ТипГраницы,
  До: ТипГраницы)
```

Создает закрытый диапазон с указанными границами

`От`

и

`До`

.

---
