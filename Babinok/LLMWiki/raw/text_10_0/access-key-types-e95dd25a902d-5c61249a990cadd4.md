## Тип «ИмяВыдаваемогоКлючаДоступа»

Тип [`{ИмяВыдаваемогоКлючаДоступа}`](../../wiki/security/grantableaccesskeyname-ru-ef1ca4a7c1cf.md) доступен на сервере.

Он содержит метод [`ОтозватьКлючи()`](../../wiki/security/grantableaccesskeyname-ru-ef1ca4a7c1cf.md). Этот метод позволяет отозвать ключи доступа, значения параметров которых совпадают со значениями указанных параметров, для всех или определенных пользователей. При отзыве у всех пользователей также выполняется удаление соответствующих записей из основной таблицы ключа доступа.

Этот тип не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Получить менеджера ключа доступа «ВыдаваемыйКлючДоступаСотрудника»
пер МенеджерВыдаваемогоКлюча = ВыдаваемыйКлючДоступаСотрудника
```

## Тип «ИмяВыдаваемогоКлючаДоступа.Объект»

Тип [`{ИмяВыдаваемогоКлючаДоступа.Объект}`](../../wiki/security/grantableaccesskeyname-ru-ef1ca4a7c1cf.md) доступен на сервере.

Он содержит методы [`Выдать()`](../../wiki/security/grantableaccesskey-object-ru-851edad3d627.md)/[`Отозвать()`](../../wiki/security/grantableaccesskey-object-ru-851edad3d627.md), которые позволяют выдать или отозвать ключ доступа для указанных пользователей. При отзыве у всех пользователей также выполняется удаление записи, содержащей экземпляр ключа, из основной таблицы ключа доступа.

Этот тип имеет конструктор, с помощью которого вы можете получать экземпляры ключа доступа, например:

```xbsl
пер КлючСотрудника = новый ВыдаваемыйКлючДоступаСотрудника.Объект()
```

## Тип «ИмяВычисляемогоКлючаДоступа»

Тип [`{ИмяВычисляемогоКлючаДоступа}`](../../wiki/security/computableaccesskeyname-ru-ab6483a7029c.md) доступен на сервере.

Он содержит метод [`ПересчитатьКлючи()`](../../wiki/security/computableaccesskeyname-ru-ab6483a7029c.md), который позволяет пересчитать экземпляры ключей доступа ([подробнее](../../wiki/security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md)).

Этот тип не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Получить менеджера ключа доступа «КлючиГруппСотрудников»
пер МенеджерВычисляемогоКлюча = КлючиГруппСотрудников
```

## Тип «ИмяВычисляемогоКлючаДоступа.Объект»

Тип [`{ИмяВычисляемогоКлючаДоступа}.Объект`](../../wiki/security/computableaccesskeyname-object-ru-513b36fec08b.md) доступен на сервере.

Он содержит метод [`Пересчитать()`](../../wiki/security/computableaccesskey-object-ru-0d0b5f774cb0.md), который позволяет обновить конкретный экземпляр ключа доступа для всех или некоторых пользователей ([подробнее](../../wiki/security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md)).

Этот тип имеет конструктор, с помощью которого вы можете получать экземпляры ключа доступа, например:

```xbsl
пер КлючМенеджеров = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Менеджеры)
```

## Модуль ключа доступа

В проекте модуль, расширяющий тип [`{ИмяВычисляемогоКлючаДоступа}`](../../wiki/security/computableaccesskeyname-ru-ab6483a7029c.md)/[`{ИмяВыдаваемогоКлючаДоступа}`](../../wiki/security/grantableaccesskeyname-ru-ef1ca4a7c1cf.md), называется **модулем ключа доступа**. Он исполняется на сервере.



В нем вы можете определить обработчик [`ПроверитьНаличиеКлючейДоступа`](../../wiki/security/computableaccesskeyname-ru-ab6483a7029c.md) для вычисляемого ключа доступа ([подробнее](../../wiki/security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md)).

## Модуль экземпляра ключа доступа

В проекте модуль, расширяющий тип [`{ИмяВычисляемогоКлючаДоступа}.Объект`](../../wiki/security/computableaccesskeyname-object-ru-513b36fec08b.md)/[`{ИмяВыдаваемогоКлючаДоступа}.Объект`](../../wiki/security/grantableaccesskeyname-object-ru-cc8812305674.md), называется **модулем экземпляра ключа доступа**. Он исполняется на сервере.

## Тип «КлючиДоступа»

Тип [`КлючиДоступа`](../../wiki/security/accesskeys-ru-366038857e8d.md) существует независимо от того, есть в проекте ключи доступа или нет. Он предназначен для обхода всех ключей доступа.

Этот тип не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа.

```xbsl
// Получить менеджера всех ключей доступа
пер МенеджерВсехКлючей = КлючиДоступа
```
