`Стд::Интерфейс::Фильтры::ОписаниеОграниченияДопустимыхЗначенийФильтра` `Доступность: КлиентИСервер`

Содержит указание на контрольное [ПолеДинамическогоСписка](../../wiki/interface/dynamiclistfield-ru-123b2f37f3d2.md), которое будет использоваться для динамического изменения конечных значений зависимого. Ограничение применимо только к ссылочным типам.

**Сравнение**

Структурное

## Примеры

**Общие примеры**

Пример описания динамического списка с использованием ограничения:

```yaml
-
  Выражение: Спринт
  ОграничениеДопустимыхЗначенийФильтра:
    РеквизитПоляФильтраОграничения: Команда
    ВыражениеЗначенияФильтраОграничения: Спринт.Команда    
-
  Выражение: Спринт.Команда
```
