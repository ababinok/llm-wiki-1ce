В данной статье показывается, как создать простое приложение «Планировщик задач» с помощью технологии «1С:Предприятие.Элемент».

В итоговом приложении пользователь сможет добавлять и редактировать задачи для различных проектов, а также выполнять поиск и фильтрацию задач.

Итоговый планировщик задач: слева навигация «Задачи», «Проекты». [Описание иллюстрации](../figures/6b382d3d169bba51e7ff175d1d2f11f566520af20af12d01d01a1c0377bc065d-d87cd3f53be81904.md)

Для более удобного восприятия информации руководство по созданию приложения доступно как в видеоформате, так и в виде подробной пошаговой инструкции.

## Видеоруководство

Данное обучающее видео демонстрирует создание приложения «Планировщик задач» в «1С:Предприятие.Элементе». Все выполняемые в видео действия описаны далее в этой статье.

## Создание нового приложения

Выполните следующие действия, чтобы создать новое приложение:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Приложения** нажмите **+ Новое приложение**.
  
  На вкладке «Приложения» панели управления выделена ссылка «Новое приложение» для создания приложения. [Описание иллюстрации](../figures/dd76e7275eb688227f5548500bc540425036b9b470af5bdc1c34329cfe1624e2-16d0604e154f03ad.md)
3. В открывшемся окне выберите **Из проекта** ⟶ **Новый проект**. В выпадающем меню **Шаблон проекта** выберите пункт **Приложение с разделами**.
  
  Диалоговое окно «Новое приложение» [Описание иллюстрации](../figures/ce6c963d62eb47230a643dec176a010a4c158b6ebb9c578e2e3fd45e99ff494c-840d6f0f46ad0648.md)
4. Заполните остальные поля диалога: укажите поставщика, представление, имя и версию проекта, задайте имя приложения. Включите режим разработки для создаваемого приложения и нажмите **Создать**.
  
  Диалог «Новое приложение»: поля поставщика, представления, имени и версии проекта, имени приложения; включён режим разработки, завершение — «Создать». [Описание иллюстрации](../figures/3abfb720b4078bdc3d9b770c2d22f32b2f32f3c36382a0e9995e245ea1815b77-f8ac463ef7a7732e.md)

Новое приложение появится в общем списке приложений. Нажмите **Разработать**, чтобы открыть его в среде разработки.

В списке приложений созданное приложение показано отдельной строкой; выделена ссылка «Разработать» для открытия приложения в среде разработки. [Описание иллюстрации](../figures/d68df7661bd348ad76af2b917c93349365a39d234d0ebdb4bef1c4a2a4985f13-e6c7f197585488b2.md)

## Добавление элементов проекта

### Добавление справочника «Проекты»

Создайте [справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md) для хранения информации о разрабатываемых проектах:

1. Наведите мышку на подсистему **Основное** и нажмите на знак плюса.
2. В открывшемся окне выберите элемент проекта **Справочник**.
  
  
3. Задайте имя справочника — **Проекты**. По умолчанию справочник будет иметь один реквизит — **Наименование**.
4. В группе свойств **Интерфейс** ⟶ **Список** укажите представление и иконку для команды открытия стандартной формы списка проектов.
  
  В свойствах команды открытия стандартной формы списка заданы представление «Проекты» и изображение «Список2.svg». [Описание иллюстрации](../figures/378227963adc221a638eb20c02bcaf1dec813241d93dfb07d2117f3196840f75-1d10f0f150a9fe64.md)

### Добавление справочника «Задачи»

Аналогичным образом создайте [справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md) **Задачи** для хранения информации о задачах. Добавьте к справочнику описанные ниже реквизиты.

#### Реквизит «Код»

Чтобы создать новый реквизит, разверните структуру справочника и нажмите на знак плюса в разделе **Реквизиты**. В открывшемся меню выберите стандартный реквизит **Код**.



#### Реквизит «Приоритет»

Добавьте классификацию задач по степени важности. Для этого выполните следующие действия:

1. К подсистеме **Основное** добавьте новый элемент проекта вида **Перечисление**. Укажите его имя — **ПриоритетЗадачи**.
  
  В окне добавления элемента проекта выбран тип «Перечисление» для создания ПриоритетЗадачи. [Описание иллюстрации](../figures/fe4e66615e0ad5ef73a33fa3c2da999233253f09d60d0ad576ac41152a92a343-46de3561852cedfd.md)
2. Добавьте к перечислению следующие элементы:
  
  - Высокий
    
    ,
  - Средний
    
    ,
  - Низкий
    
    .
  
  
3. Выделите элемент **Средний**, чтобы открыть для него панель свойств. Установите значение свойства **ПоУмолчанию** как **Истина**.
  
  
4. Перейдите к справочнику **Задачи** и создайте для него реквизит **Приоритет**.
5. В панели свойств реквизита **Приоритет** для свойства **Тип** укажите значение `ПриоритетЗадачи`.
  
  В свойствах реквизита «Приоритет» открыт выбор типа и отмечено перечисление ПриоритетЗадачи. [Описание иллюстрации](../figures/4e310ecd6c5317b1987710d4220c15077c9c825e691517a2fc133d127871639d-add019d9a13ed5fd.md)

#### Реквизит «СтатусЗадачи»

Добавьте возможность указать статус выполнения задачи. Для этого выполните следующие действия:

1. К подсистеме **Основное** добавьте перечисление **СтатусЗадачи** со следующими элементами:
  
  - Новая
    
    — выберите как значение по умолчанию,
  - НаВыполнении
    
    ,
  - Закрыта
    
    .
2. Перейдите к справочнику **Задачи** и создайте для него новый реквизит с именем **СтатусЗадачи** и типом данных `СтатусЗадачи`.
  
  В справочнике «Задачи» выбран реквизит «СтатусЗадачи». [Описание иллюстрации](../figures/60df81b13311fc58cc25b023174245f462bc4fc8d87e6cf84899d70ad8d45e01-608f6095d071a34e.md)

#### Реквизит «Проект»

Так как все задачи должны выполняться в рамках какого-либо проекта, добавьте к справочнику **Задачи** новый реквизит **Проект** с типом данных `Проекты.Ссылка | Неопределено`.

#### Реквизит «Описание»

Добавьте реквизит **Описание** типа [`Строка`](../../wiki/language/string-83dd85331ece.md), в котором будет храниться подробное описание задачи. В панели свойств реквизита установите значение свойства **Многострочная** как **Истина**.

Активация свойства «Многострочная» [Описание иллюстрации](../figures/b2342ae859e6e6a89c8a4406243a9ac6b765ceb2dbf19dfce8201de252db3272-9b221adc10cbd107.md)

#### Реквизит «СрокВыполнения»

Добавьте к справочнику **Задачи** реквизит с именем **СрокВыполнения** и типом данных [`Момент`](../../wiki/language/instant-type-7c8265ee310d.md).

## Разработка интерфейса приложения

### Создание формы списка для справочника «Задачи»

Добавьте к справочнику **Задачи** форму для отображения списка задач:

1. Нажмите на знак плюса рядом с именем справочника и выберите **ФормаСписка** в открывшемся окне.
  
  Создание формы списка для справочника [Описание иллюстрации](../figures/9dda7107fa13d517e95d759f162bd5ece4978a2ab1ed2fa76be5ff19b67c179b-91db1624c8503b0d.md)
2. Для формы будет сгенерировано имя по умолчанию — **ЗадачиФормаСписка**.
3. Откройте панель свойств справочника и в группе **Интерфейс** ⟶ **Список** укажите представление и иконку для команды открытия формы списка задач.
  
  В свойствах списка справочника задано представление команды «Задачи» и изображение «Задачи.svg» для открытия формы списка. [Описание иллюстрации](../figures/4107e17f2a003017ddea92188bac23142e686228a18f8aae81880c754199ec45-6db8a49630510c66.md)

#### Настройка внешнего вида формы

1. Выделите форму в навигаторе проекта, чтобы открыть ее в [редакторе компонентов интерфейса](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md).
2. Раскройте дерево компонентов формы, перейдите к компоненту **ОсновнаяТаблица** и удалите колонку таблицы **Описание**.
  
  В дереве компонентов формы списка выбрана колонка «Описание» компонента ОсновнаяТаблица перед её удалением; справа показан предпросмотр таблицы. [Описание иллюстрации](../figures/570b93acd20f5b4ec35ab4a1595b045ac5d2e581e8365034968d5430ad1e097c-dd746746f1e01ec3.md)
3. Измените отображение колонки **Приоритет**:
  
  - В панели свойств колонки измените значение свойства [Вид](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) на **Значок**, чтобы отобразить значение в колонке в виде значка.
    
    В свойствах колонки таблицы «Приоритет» раскрыт список «Вид» и выбрано «Значок»; в предпросмотре приоритеты отображаются значками. [Описание иллюстрации](../figures/4ea25c9ff75b89a9e73c6664894094beb397877f8b25587056f9a467475e3414-a3ec4471aa008b7e.md)
  - Сделайте значки в колонке цветными. Цвет значка будет зависеть от значения перечисления **ПриоритетЗадачи**.
    
    - Создайте модуль перечисления **ПриоритетЗадачи**. Для этого нажмите на знак плюса рядом с именем перечисления и выберите пункт **Модуль**.
    - В модуле перечисления создайте метод `ПолучитьЦвет()`. Укажите для него аннотацию видимости `@ВПодсистеме`, чтобы метод был доступен в других модулях подсистемы.
      
      Модуль перечисления «ПриоритетЗадачи»
      
      ```xbsl
      @ВПодсистеме
      метод ПолучитьЦвет(): Цвет
          выбор этот
          когда Высокий
              возврат Цвета.Красный
          когда Средний
              возврат Цвета.Желтый
          когда Низкий
              возврат Цвета.Зеленый
          иначе
              возврат Цвета.Зеленый
          ;
      ;
      ```
    - В дереве компонентов формы **ЗадачиФормаСписка** выделите колонку **Приоритет**. В свойстве **Цвет** введите выражение `ДанныеСтроки.Данные.Приоритет.ПолучитьЦвет()`.

### Создание формы объекта для справочника «Задачи»

Добавьте к справочнику **Задачи** форму для создания и редактирования отдельной задачи:

1. Нажмите на знак плюса рядом с именем справочника и выберите **ФормаОбъекта** в открывшемся окне.
  
  Создание формы объекта для справочника [Описание иллюстрации](../figures/ba445349d466217ae7c06a43e36a44e361f5dc203156789bfdbadb8f87298f94-a1c266014a3383c9.md)
2. Для формы будет сгенерировано имя по умолчанию — **ЗадачиФормаОбъекта**.

#### Настройка внешнего вида формы

1. Выделите форму в навигаторе проекта, чтобы открыть ее в [редакторе компонентов интерфейса](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md).
2. Раскройте дерево компонентов формы и удалите поле ввода **Код** из шаблона формы. Код задачи генерируется автоматически, и пользователю не требуется вводить его вручную.
  
  

### Добавление форм в клиентское приложение

«1С:Предприятие.Элемент» [автоматически сгенерирует командный интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md) приложения. Вы можете использовать его и сразу перейти к [запуску приложения](../../wiki/project/create-task-tracker-app-991877a27ceb.md).

Вы также можете самостоятельно добавить необходимые команды к приложению, например, чтобы расположить их в нужном вам порядке. Для этого выполните следующие действия:

1. Перейдите в [редактор](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md) компонента **Приложение**. Добавьте [ФрагментКомандногоИнтерфейса](../../wiki/interface/command-interface-fragment-f742e5d6797f.md) в командный интерфейс панели навигации.
  
  В командный интерфейс панели навигации приложения добавляется «ФрагментКомандногоИнтерфейса» через окно выбора нового командного элемента. [Описание иллюстрации](../figures/4b743f12576f42a8aa9c7cfd6a8f43249592bde433c99c8c31a0a0a121320f98-bbd1a13e05136502.md)
2. Во фрагмент командного интерфейса добавьте команду для открытия списка задач: `Задачи.ОткрытьСписок`.
  
  В выборе команды фрагмента командного интерфейса указана глобальная команда Задачи.ОткрытьСписок для открытия списка задач. [Описание иллюстрации](../figures/3d8a4b3d5bfc26a4c19dfd52619b38cdb6a46c49fc924d2cebcad83c3eac5fad-b0479b6f864ddb1e.md)
3. Добавьте еще одну команду для открытия списка проектов: `Проекты.ОткрытьСписок`.
  
  В конструкторе приложения открыт выбор команды для фрагмента командного интерфейса. [Описание иллюстрации](../figures/5b4b2a8be7a16d3bc5da748d929f34ea261983278e6218bd961327608270de87-7763e0f2f4ddc4af.md)
4. Измените оформление приложения, чтобы форма списка задач отображалась на белом фоне. Для этого в дереве компонентов выберите **СтандартноеКлиентскоеПриложениеСРазделами** и задайте для свойства **ОсобоеОформлениеПервогоРаздела** значение **Ложь**.
  
  В свойствах клиентского приложения ОсобоеОформлениеПервогоРаздела установлено в «Ложь», чтобы список задач отображался на белом фоне. [Описание иллюстрации](../figures/49ef9486f1fb40ae818f322b6c515179db530bf8cc0196b9eb190c0b84098d4e-ed35b2a5bd2bc38e.md)

## Запуск приложения

1. Чтобы запустить приложение, выберите **Открыть приложение** в выпадающем меню **Запуск и публикация** или нажмите **Ctrl+F5**.
  
  Запуск приложения [Описание иллюстрации](../figures/a41269dd726360b1e94455f41e5144e3757de3fbfbfe95a09a23a6b04afdc184-61de2986e3c08b50.md)
2. При наличии неопубликованных изменений в проекте «1С:Предприятие.Элемент» отобразит окно с предложением выполнить публикацию. Нажмите **Опубликовать и запустить**.
  
  
3. В приложении на вкладке **Проекты** создайте один или несколько тестовых проектов.
4. На вкладке **Задачи** добавьте задачи для каждого проекта.
  
  Результат учебного приложения: форма списка задач с названием, кодом, приоритетом, проектом и сроком выполнения; над таблицей поиск и создание, снизу навигация страниц. [Описание иллюстрации](../figures/edc8d7d710ce371b6dd346d57c75e2c73a469f13c0796366a2adba5f5499c588-abf9c7de509859fd.md)

Вы можете расширить функциональность получившегося приложения, добавив к нему возможность просматривать отчеты по задачам. Подробный пример приведен в статье [Создание отчета для приложения «Планировщик задач»](../../wiki/project/create-report-for-task-tracker-app-09e544073076.md).
