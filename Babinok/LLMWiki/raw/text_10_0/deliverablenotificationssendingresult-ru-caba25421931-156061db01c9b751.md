## Методы

### ПолучитьИнформациюОПроблемахОтправки

`Доступность: Сервер`

```
ПолучитьИнформациюОПроблемахОтправки(): ЧитаемыйМассив<ИнформацияОПроблемеОтправкиДоставляемогоУведомления>
```

Возвращает информацию о проблемах, возникших при отправке уведомлений. Если во время отправки уведомления одинаковые ошибки произошли для двух и более получателей, они передаются в массив

`Получатели`

. Если при отправке уведомления произошла ошибка, из-за которой ни один получатель не получит уведомление (например, ошибка подключения к провайдеру), то значение свойства

[Получатели](../../wiki/stdlib/deliverablenotificationsendingissueinformation-ru-ee35069133d4.md)

будет совпадать с значением свойства

`Получатели`

уведомления.

---

### ПолучитьИсключенныхПолучателей

`Доступность: Сервер`

```
ПолучитьИсключенныхПолучателей(): ЧитаемыйМассив<Строка>
```

На устройствах под управлением Android с помощью данного параметра возвращается массив строк с идентификаторами устройств, которые не подходят для отправки, и соответственно, должны быть исключены из будущих рассылок. Этим устройствам ранее отправлялись уведомления с этим ключом авторизации. Но не обязательно в этом вызове. На устройствах под управлением iOS массив всегда пустой.
