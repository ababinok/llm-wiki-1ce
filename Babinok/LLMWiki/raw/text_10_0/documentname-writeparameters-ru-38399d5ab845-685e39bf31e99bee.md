---

### Постфикс

`Доступность: КлиентИСервер`

```
Постфикс: Строка?
```

Устанавливают значения постфикса, которые будут использованы в момент вызова Записать() для формирования нового номера. Если длина постфикса равна нулю, то соответствующее свойство отсутствует. Непосредственно перед записью в базу данных, происходит присвоение номера по следующему алгоритму:

- если было изменение значения реквизита "Номер"
  
  - Номер не пуст → не генерируем новый номер, берем значение из реквизита
  - Номер пуст → генерируем новый номер и занимаем его
- если задан
  
  [Префикс](../../wiki/data/documentname-writeparameters-ru-38399d5ab845.md)
  
  или
  
  [Постфикс](../../wiki/data/documentname-writeparameters-ru-38399d5ab845.md)
  
  - освобождаем старый номер
  - занимаем новый номер в рамках нового префикса и постфикса

---
