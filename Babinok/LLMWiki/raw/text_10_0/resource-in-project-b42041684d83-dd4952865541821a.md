Ресурс — это произвольный файл, который требуется для работы приложения. В каждой подсистеме и в каждом пакете может быть собственный набор ресурсов со своей областью видимости. Все файлы хранятся в каталоге **Ресурсы**, внутри которого по умолчанию создается элемент **Описание ресурсов**. С помощью его свойства **ОбластьВидимости** можно ограничить область видимости ресурсов.

В дереве проекта дополнительные файлы подсистемы или пакета находятся в папке «Ресурсы». [Описание иллюстрации](../figures/2e6f2ed14d32e5d34205f2838e6eaa4e6b30ad5587f51e1e3a42566540942899-b0f449cacf64a1bb.md)

## Использование в проекте

Ссылку на ресурс можно использовать в компонентах интерфейса для задания значения свойства типа `ДвоичныйОбъект.Ссылка`. Например:

```yaml
-
    Тип: Кнопка
    Заголовок: ИзменитьСообщение
    Изображение: Картинки/Редактировать.png
-
    Тип: Кнопка
    Заголовок: УдалитьСообщение
    Изображение: Сообщения::Удалить.png
```

Ссылка на ресурс имеет следующий формат:

```text
имя_подсистемы::путь/в/фс
```

Разделитель каталогов — «/». Например, ссылка:

```text
Главная::Каталог1/test.xml
```

указывает на ресурс, находящийся в проекте по пути:

```text
Главная/Ресурсы/Каталог1/test.xml
```

При этом имя подсистемы указывать в ссылке необязательно — при неоднозначности будет ошибка валидации.

Тип (mime-type) содержимого, который будет отдавать [хранилище двоичных данных](../../wiki/data/binary-data-931dc014638b.md), определяется автоматически, исходя из расширения файла. Если автоматически определить его не удалось, то присваивается тип application/octet-stream.

## Использование в коде

К ресурсу можно обращаться:

- в форме литерала (если ресурс находится в другой подсистеме, необходимо указывать пространство имен полностью или использовать импорт). Например:
  
  ```xbsl
  исп РесурсПоток = Ресурс{picture.png}.ОткрытьПотокЧтения()
  пер РесурсСтрока = Ресурс{template_1.txt}.ОткрытьПотокЧтения().ПрочитатьКакСтроку()
  ```
- в форме строки. Для этого используется тип [ПакетРесурсов](../../wiki/stdlib/resourcespackage-ru-fc318a240382.md), который предоставляет доступ как к ресурсу, так и к нескольким или сразу всем ресурсам в рамках пространства имен. Например:
  
  ```xbsl
  метод ПолучитьРесурс(ИмяРесурса: Строка): ДвоичныйОбъект.Ссылка?
      возврат ПакетРесурсов.Текущий().Получить("Главная/Ресурсы/%ИмяРесурса.png").Ссылка
  ;
  ```
