## Методы

### Выполнить

`Доступность: Клиент`

```
Выполнить(): СтатусОперацииСамообслуживания
```

Выполнить операцию удаления биометрии с доверенного устройства для текущего пользователя. Если устройство не входит в множество доверенных, вернется неуспешный статус операции с соответствующем сообщением.
