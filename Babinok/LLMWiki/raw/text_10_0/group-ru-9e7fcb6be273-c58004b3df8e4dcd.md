`Стд::Интерфейс::Группы::Группа` `Доступность: Клиент`

Компонент группы, содержащей в себе другие компоненты и располагающий их в своей области в соответствии с настройками компоновки. Может иметь рамку и заголовок. Может прокручиваться и отображать фиксированную при прокрутке область подвала.

**Сравнение**

Ссылочное

*Базовые типы:* [Компонент](../../wiki/interface/component-ru-bad1c84be995.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

*Дочерние типы:* [КомпонентСамостоятельнойРегистрации](../../wiki/interface/selfregistrationcomponent-ru-0c366f494356.md)

## Свойства

### ВыравниваниеСодержимогоПоВертикали

`Версия 8.0 и выше`

`Доступность: Клиент`

```
ВыравниваниеСодержимогоПоВертикали: Авто|ВыравниваниеПоВертикали
```

Устанавливает вертикальное выравнивание дочерних компонентов. Для вертикальной группы не имеет смысла, если какой-то из дочерних компонентов растягивается по вертикали. Если же растягиваемых компонентов нет, то все содержимое группы сдвинется к соответствующей границе.

---

### ВыравниваниеСодержимогоПоГоризонтали

`Версия 8.0 и выше`

`Доступность: Клиент`

```
ВыравниваниеСодержимогоПоГоризонтали: Авто|ВыравниваниеПоГоризонтали
```

Устанавливает горизонтальное выравнивание дочерних компонентов. Для горизонтальной группы не имеет смысла, если какой-то из дочерних компонентов растягивается по горизонтали. Если растягиваемых компонентов нет, то все содержимое группы сдвинется к соответствующей границе.

---

### Подвал

`Версия 8.0 и выше`

`Доступность: Клиент`

```
Подвал: Группа?
```

Задает содержимое области подвала. Это область, предназначенная для размещения фиксированных элементов управления, которые не пропадают при прокрутке.

---

### ПодвалСвернут

`Версия 8.0 и выше`

`Доступность: Клиент`

```
ПодвалСвернут: Авто|Булево
```

Задает состояние отображения подвала.

---

### ПрокруткаПоВертикали

`Версия 8.0 и выше`

`Доступность: Клиент`

```
ПрокруткаПоВертикали: Авто|Булево
```

Включает вертикальную прокрутку группы, если дочерние компоненты не помещаются в группе по высоте. Если дочерние компоненты не помещаются, но прокрутка выключена, то группа будет растянута. При этом прокрутка появится у ее родительской группы, для которой она включена.

---

### ПрокруткаПоГоризонтали

`Версия 8.0 и выше`

`Доступность: Клиент`

```
ПрокруткаПоГоризонтали: Авто|Булево
```

Включает горизонтальную прокрутку группы, если дочерние компоненты не помещаются в группе по ширине. Если дочерние компоненты не помещаются, но прокрутка выключена, то группа будет растянута. При этом прокрутка появится у ее родительской группы, для которой она включена. Игнорируется для [Группа](../../wiki/interface/group-ru-9e7fcb6be273.md) в режиме компоновки [Карусель](../../wiki/interface/contentlayout-ru-979de0be9298.md).
