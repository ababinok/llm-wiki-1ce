# Поиск записей документа при вводе по строке

Во время работы приложения, чтобы выбрать один из объектов **Документа**, пользователь может просто начать вводить в поле ввода известный ему фрагмент названия, номера, или другого реквизита **Документа**. «1С:Предприятие.Элемент» автоматически подберет ему подходящие объекты.

Вы можете задать список тех реквизитов **Документа**, в которых «Элемент» будет искать текст, введенный пользователем. Для этого в проекте используйте свойство **Документа** **ВводПоСтроке**. В этом свойстве находится массив, содержащий имена реквизитов, в которых будет осуществляться поиск.

Вы можете переопределить стандартный алгоритм поиска, существующий в «Элементе». Для этого обрабатывайте событие `имя-документа.ПолучитьЗначенияВыбора()` ([подробнее](../../wiki/data/document-types-18ccdbf51e8a.md)).
