Элемент для хранения данных структуры.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### Тип

```yaml
Тип: Тип[]
```

Тип поля хранимой структуры.

---

#### ДлинаЦелойЧасти

```yaml
ДлинаЦелойЧасти: Число
```

Максимально допустимая длина целой части числа.

---

#### МаксимальнаяДлина

```yaml
МаксимальнаяДлина: Число
```

Максимально допустимая длина строки.

---

#### НезаполненноеЗначение

```yaml
НезаполненноеЗначение: ПолитикаПроверки
```

Определяет политику проверки пустого значения элемента.

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных для использования в [полнотекстовом поиске](../../wiki/project/full-text-search-99b98022003a.md).

---

#### ДлинаДробнойЧасти

```yaml
ДлинаДробнойЧасти: Число
```

Максимально допустимая длина дробной части числа.

---

#### МаксимальноеЗначение

```yaml
МаксимальноеЗначение: Число
```

Максимально допустимое значение числа.

---

#### МинимальноеЗначение

```yaml
МинимальноеЗначение: Число
```

Минимально допустимое значение числа.

---

#### КонтрольПредельныхЗначений

```yaml
КонтрольПредельныхЗначений: КонтрольДлины
```

Указывает, как осуществлять контроль предельных значений числа:

- [ВыдаватьОшибку](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  ,
- [Исправлять](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  .

---

#### КонтрольДробнойЧасти

```yaml
КонтрольДробнойЧасти: КонтрольДлины
```

Указывает, как осуществлять контроль дробной части числа:

- [ВыдаватьОшибку](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  ,
- [Исправлять](../../wiki/project/limitscontrol-ru-9d8743537a6e.md)
  
  .

---

#### Многострочная

```yaml
Многострочная: Булево
```

Указывает, является ли строка многострочной.

---

#### КонтрольДлины

```yaml
КонтрольДлины: КонтрольДлины
```

Способы контроля длины.

---

#### ЗначениеПоУмолчанию

```yaml
ЗначениеПоУмолчанию: Объект
```

Значение поля по умолчанию.

---

#### Аннотации

```yaml
Аннотации: Аннотация[]
```

[Аннотации](../../wiki/language/annotations-dcff696b460d.md) поля хранимой структуры.

---

#### ПриУдаленииОбъектаПоСсылке

```yaml
ПриУдаленииОбъектаПоСсылке: ДействиеПриУдаленииОбъектаПоСсылке
```

Определяет поведение при удалении элемента, указанного в качестве реквизита ([подробнее](../../wiki/project/data-deletion-141a62f69ff7.md)).

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: Булево
```

Значение по умолчанию — `Ложь`. Если значение — `Истина`, то поле нельзя изменить после инициализации.
