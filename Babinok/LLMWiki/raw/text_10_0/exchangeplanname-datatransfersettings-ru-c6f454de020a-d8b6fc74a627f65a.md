`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПланаОбмена}.НастройкиПередачиДанных` `Доступность: КлиентИСервер`

Описывает настройки передачи данных. Позволяет организовать обмен данными данного приложения с внешним приложением. Порождается, только если свойство элемента проекта **ИмяПланаОбмена.ПередачаДанных.Использовать** имеет значение `Истина`.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Свойства

### Активность

`Доступность: КлиентИСервер`

```
Активность: Булево
```

Признак активации передачи данных для узла плана обмена. По умолчанию `Ложь`.

При установке в `Истина` создается запланированное задание, выполняющее обмен данными.

При установке в `Ложь` запланированное задание удаляется.

---

### ИнтегрируемоеПриложение

`Доступность: КлиентИСервер`

```
ИнтегрируемоеПриложение: {ИмяИнтегрируемогоПриложения}.Ссылка?
```

Ссылка на интегрируемое приложение, описывающая внешнее приложение, с которым выполняется обмен данными узла плана обмена.

Если передача данных активирована, интегрируемое приложение нельзя удалить (проверка выполняется при записи узла плана обмена).

---

### КлючЗапланированногоЗадания

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
КлючЗапланированногоЗадания: Строка
```

Ключ запланированного задания, выполняющего обмен данными узла плана обмена. Создается автоматически при активации передачи данных.
