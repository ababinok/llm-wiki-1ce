# Функция Подстрока

Эта функция выделяет подстроку. Она имеет следующий синтаксис:

```xbql
исходная-строка.Подстрока(индекс-первого-символа[, индекс-следующего-за-последним-символом])
```

Индексы отсчитывается от 0. Если значение не целое или меньше 0, то будет выдана ошибка.

Если ***индекс-следующего-за-последним-символом*** меньше, чем ***индекс-первого-символа***, то будет выдана ошибка.

Второй параметр не обязательный, значение по умолчанию 1 073 741 824 (1 ГБ). В качестве значения можно указать `Неопределено`, оно будет интерпретировано как неуказанное значение.

Пример:

```xbql
"0123456789".Подстрока(3, 6) // вернет "345"
```
