Аннотации окружения — это аннотации, которые используются для явного указания окружения для языковых конструкций в модуле. Аннотация окружения пишется с новой строки и определяет окружение, в котором будет исполняться метод или в котором будет существовать тип. Например:

```xbsl
@НаКлиенте
конст СЕКУНД_В_ОДНОМ_ДНЕ = 60 * 60 * 24

@НаСервере
перечисление ВидКнопки
    Круглая,
    Квадратная
;

@НаСервере @ДоступноСКлиента
статический метод ПолучитьОписаниеТовара(): Строка
    возврат "Описание товара"
;
```

Существуют следующие аннотации окружения:

- `@НаКлиенте`
  
  ;
- `@НаСервере`
  
  ;
- `@ДоступноСКлиента`
  
  .
