«1С:Предприятие.Элемент» предоставляет возможность создавать иерархический справочник.

Чтобы указать, что справочник является иерархическим, задайте его свойству [Иерархический](../../wiki/data/catalog-e0da7d4e8e72.md) значение `Истина`.

Выберите [Вид](../../wiki/data/catalog-e0da7d4e8e72.md) иерархии:

- ИерархияГруппИЭлементов
  
  — значение по умолчанию,
- ИерархияЭлементов
  
  .

### Иерархия групп и элементов

При выборе вида иерархии **ИерархияГруппИЭлементов** автоматически создается справочник групп **{ИмяСправочника}.Группы** с иерархией, в которой в качестве родителя выступает элемент справочника групп, а в качество потомка — элемент иерархического справочника, по которому порождается справочник групп.

Настройки справочника групп задаются в разделе [СправочникГрупп](../../wiki/data/catalog-e0da7d4e8e72.md) панели свойств.

<details>
<summary>Пример иерархического справочника с группами</summary>

```yaml
ВидЭлемента: Справочник
Ид: 43bb178c-1f7c-4e42-a5c8-14f9722e2e89
Имя: Товары
ОбластьВидимости: ВПодсистеме
Иерархический: Истина
РежимУдаления: Немедленно
Иерархия:
    Вид: ИерархияГруппИЭлементов
    СправочникГрупп:
        Автонумерация:
            ДлинаНумерации: 3
            Постфикс: Гр
            Префикс: ПС
            Формат:
                ДлинаПостфикса: 2
                ДлинаПрефикса: 2
                РазделительПостфикса: "-"
                РазделительПрефикса: "-"
        Представление:
            Объект: Товары (Группа)
            Список: Товары (Группы)
Реквизиты:
    -
        Имя: Наименование
    -
        Имя: Код
        Длина: 9
```

</details>

Иерархический справочник с группами [Описание иллюстрации](../figures/e639fc478970cb1630c69b53b7bd77a864bd0cc3d28b18a8971fe289e8b7e382-4964484527d61be4.md)

> [!WARNING] важно
> Для справочника групп формы не включаются в интерфейс автоматически. При необходимости вы можете задать автоматическое включение форм в настройке справочника групп [ВключатьВАвтоИнтерфейс](../../wiki/data/catalog-e0da7d4e8e72.md) или указать их самостоятельно. Например:
>
> ```yaml
> ТипФормы: Товары.Группы.АвтоматическаяФормаСписка
> ```

Для справочника с иерархией групп и элементов:

- автоматически создается реквизит
  
  [Родитель](../../wiki/data/hierarchical-catalog-80c1ad8e7082.md)
  
  ,
- порождаются следующие таблицы языка запросов:
  
  - `ИмяСправочника.Группы`
    
    ,
  - `ИмяСправочника.Группы.Иерархия`
    
    ,
  - `ИмяСправочника.Группы.Иерархия.Циклы`
    
    ,
  - `ИмяСправочника.ИерархияГруппИЭлементов`
    
    ,
  - `ИмяСправочника.ИерархияГруппИЭлементов.Циклы`
    
    .

### Иерархия элементов

На автоматические формы объекта и списка такого справочника добавляется поле **Родитель**. Динамический список начинает работать в иерархическом режиме:

Список «Подразделения» показывает иерархию строк: «Производство» раскрыто, под ним «Печатный цех» и «Швейный цех»; у обеих строк в колонке «Родитель» ссылка «Производство». [Описание иллюстрации](../figures/7005be324a62bd3fb1195c81fb37d2a52a93843559e93fd5e2f446f5709cf3a3-891abe7b720417ef.md)

- автоматически создается реквизит
  
  [Родитель](../../wiki/data/hierarchical-catalog-80c1ad8e7082.md)
  
  ,
- порождаются следующие таблицы языка запросов:

## Реквизит «Родитель»

Если для справочника устанавливается свойство **Иерархический**, то для него автоматически создается реквизит с именем **Родитель**, который имеет тип `ИмяСправочника.Ссылка?`. Если у справочника был собственный реквизит с именем **Родитель**, то при установке флажка **Иерархический**:

- этот реквизит удаляется и заменяется на системный;
- начинают действовать следующие требования:
  
  - отсутствие свойств реквизита
    
    Ид
    
    и
    
    Тип
    
    ,
  - отсутствие каких-либо ограничений типа.

## Реквизит «Владелец»

Если у справочника есть поле **Владелец**, то его значение должно быть одинаковым для всех дочерних элементов и быть таким же, как у родительского элемента. В противном случае возникает [`ИсключениеНесоответствияВладельцевИерархии`](../../wiki/stdlib/hierarchyownersmismatchexception-ru-0887bade9def.md).

> [!NOTE] примечание
> Проверка значения поля **Владелец** отключена в [контексте загрузки](../../wiki/language/group-operations-6d6c6a6c6ef5.md) (`РежимЗагрузкиДанных = Истина`).

## Дополнительные иерархии

Для справочников можно указать дополнительные иерархии, состоящие из двух типов:

- тип элементов — тип основного справочника,
- тип групп — тип родительского справочника.

Иерархическую связь можно установить только по полю, которое имеет значение типа `РодительскийСправочник.Ссылка?`.

> [!NOTE] примечание
> Если справочник иерархический, то его иерархия автоматически включается в дополнительную.

Чтобы добавить дополнительную иерархию в среде разработки, нажмите на значок плюса рядом с нужным справочником и выберите **Дополнительная иерархия**.



В свойствах дополнительной иерархии укажите имя и поле родителя.

Свойства дополнительной иерархии [Описание иллюстрации](../figures/c4559c315d587bd17e8eb947da008ffc5ea12ab9bfdac84f9ba46dfd4b5e2315-088244cb248aaf77.md)

Дополнительных иерархий в справочнике может быть несколько. Чтобы указать, какую из них необходимо использовать по умолчанию, используйте свойство справочника [ИерархияПоУмолчанию](../../wiki/data/catalog-e0da7d4e8e72.md).

## Пример справочника с дополнительными иерархиями

Справочник **Подразделения** — иерархический справочник, содержащий подразделения компании.

<details>
<summary>Пример YAML-файла справочника «Подразделения»</summary>

```yaml

ОбластьВидимости: ВПодсистеме
Ид: a0d13c34-3697-4ca0-9156-2fea699a31dc
Имя: Подразделения
Иерархический: Истина
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
Реквизиты:
    -
        Имя: Наименование
```

</details>

Справочник **Должности** — справочник, содержащий информацию о должностях сотрудников.

<details>
<summary>Пример YAML-файла справочника «Должности»</summary>

```yaml
Имя: Должности
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
Реквизиты:
    -
        Имя: Наименование
```

</details>

Справочник **Сотрудники** — иерархический справочник с информацией о сотрудниках компании. Для каждого сотрудника определены подразделение и должность. Для справочника заданы две дополнительные иерархии: по подразделениям и по должностям.

<details>
<summary>Пример YAML-файла справочника «Сотрудники»</summary>

```yaml
Иерархический: Истина
ИерархияПоУмолчанию: СотрудникиПоПодразделениям

        Ид: fa5adcd4-975a-4ce8-9287-2d8aa5f94bea

        ПолеРодителя: Подразделение
    -

        ПолеРодителя: Должность
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
Реквизиты:
    -
        Имя: Наименование
    -
        Ид: 22c11da4-e475-480d-bb15-193b29553555
        Имя: Подразделение
        Тип: Подразделения.Ссылка?
    -
```

## Таблицы языка запросов с информацией об иерархических связях

Для иерархических справочников и дополнительных иерархий порождаются следующие таблицы языка запросов:

- `ИмяСправочника.Иерархия`
  
  — таблица для иерархического справочника с информацией о связях;
- `ИмяСправочника.Иерархия.Циклы`
  
  — таблица для иерархического справочника с информацией о циклах;
- `ИмяСправочника.ИмяИерархии`
  
  — таблица для дополнительной иерархии с информацией о связях;
- `ИмяСправочника.ИмяИерархии.Циклы`
  
  — таблица для дополнительной иерархии с информацией о циклах.

[Подробнее о таблицах, порождаемых в языке запросов для справочников с иерархией](../../wiki/queries/catalogname-hierarchy-ru-8b0270e819be.md)

> [!NOTE] примечание
> Таблицы иерархий не содержат данных, требующих защиты с помощью [контроля доступа](../../wiki/security/access-control-0ea6e235f2d6.md). Они доступны всем для чтения.

## Примеры получения данных с помощью языка запросов

Получение всех родительских элементов

```xbql
ВЫБРАТЬ
    Подразделения.Ссылка,
    Подразделения.Код,
    Подразделения.Наименование
ИЗ
    Подразделения как Подразделения
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ Подразделения.Иерархия КАК ТаблицаИерархии
        ПО Подразделения.Ссылка == ТаблицаИерархии.Родитель И ТаблицаИерархии.Ребенок == %Ребенок
```

Получение всех дочерних элементов в определенной иерархии

```xbql
ВЫБРАТЬ
    Ссылка,
    Код,
    Наименование
ИЗ
    Сотрудники
ГДЕ
    Ссылка В ИЕРАРХИИ Сотрудники.Подразделения (%Подразделение)
```

Получение уровня элемента в иерархии

```xbql
ВЫБРАТЬ
    Подразделения.Ссылка,
    Подразделения.Код,
    Подразделения.Наименование,
    Подразделения.Уровень
ИЗ
    Подразделения КАК Подразделения
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ Подразделения.Иерархия КАК ТаблицаИерархии
        ПО Подразделения.Ссылка == ТаблицаИерархии.Ребенок
```
