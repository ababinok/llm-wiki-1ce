Во время работы приложения «1С:Предприятие.Элемент» автоматически генерирует форму списка записей для регистра накопления.

Пример формы записи регистра накопления [ОстаткиНоменклатуры](../../wiki/data/accumulation-register-example-08cac330ee7d.md):

Пример автоматически созданной формы списка регистра «Остатки номенклатуры»: таблица содержит Регистратор, Период, Активность, Вид записи, Номенклатура. [Описание иллюстрации](../figures/27d5294b51e7520a0e25cb56ec8541752576bab7f5a113de79b975a9fff60cc6-8df0ea05d9ceb60d.md)

Вы также можете создать собственную форму списка записей. Для этого используйте группу свойств регистра накопления — [Интерфейс](../../wiki/data/accumulationregister-c199835a97cc.md).

YAML-файл регистра накопления

```yaml
ВидЭлемента: РегистрНакопления

    ВключатьВАвтоИнтерфейс: Истина
    Список:
        Форма: ОстаткиНоменклатурыФормаСписка
ВидРегистра: Остатки
# Остальные свойства регистра
# ...
```

## Команда открытия формы списка

«1С:Предприятие.Элемент» добавляет в [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md) приложения команду открытия списка записей регистра накопления. Например, для регистра **ОстаткиНоменклатуры** команда будет иметь вид `ОстаткиНоменклатуры.ОткрытьСписок`.

Если вы не хотите, чтобы пользователь мог работать с данными регистра, вы можете отключить добавление этой команды в автоматический интерфейс. Для этого используйте свойство регистра накопления [ВключатьВАвтоИнтерфейс](../../wiki/data/accumulationregister-c199835a97cc.md).

В свойствах регистра накопления выделено ВключатьВАвтоИнтерфейс и установлено «Ложь», чтобы команда списка регистра не добавлялась в автоматический интерфейс. [Описание иллюстрации](../figures/da1a86c4c11cba05657a4537cb1841b9225a154b73f67e92091130193ad58ee3-541b5d88e98cc330.md)

По умолчанию команда, которую «1С:Предприятие.Элемент» добавляет в интерфейс приложения, в качестве своего представления использует имя регистра в проекте. Вы можете изменить представление команды с помощью свойства **Интерфейс.Список.Представление**. Указанное представление будет также использоваться в качестве представления команды `<ИмяРегистраНакопления>.ОткрытьСписок`.

## Создание формы списка регистра накопления

Во время работы приложения «Элемент» автоматически сгенерирует форму списка для работы с записями регистра. Вы не можете изменить внешний вид или логику работы этой формы. Однако вы можете создать собственную форму, а затем указать, что регистр должен использовать именно ее. Для этого используйте свойство **Интерфейс.Список.Форма**.

### Создание формы в коде

Вы можете создать форму списка в коде с помощью метода [`СоздатьФормуСписка()`](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) типа [`{ИмяРегистраНакопления}`](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md).

Например:

```xbsl
ОстаткиНоменклатуры.СоздатьФормуСписка().Открыть()
```

Если для регистра накопления задана форма списка, то будет создана форма этого типа. Иначе будет создана автоматическая форма типа [`<ИмяРегистраНакопления>.АвтоматическаяФормаСписка`](../../wiki/data/accumulationregistername-automaticlistform-ru-b58cdbecf7fa.md).
