`Стд::Задания::Интерфейс::ФормаЗаданий` `Доступность: Клиент`

Форма для управления запланированными заданиями. Позволяет выполнить следующие действия:

- просмотреть список запланированных заданий приложения;
- найти задание по ключу;
- отфильтровать задания по статусу;
- просмотреть данные запланированного задания с детализацией следующей информации: ключ, статус, момент запуска или следующего исполнения, описание, длительность последнего исполнения, число неуспешных попыток, число успешных повторов, расписание;
- перейти в журнал событий, чтобы просмотреть события выбранного задания;
- приостановить, возобновить, отменить и удалить запланированное задание;
- изменить расписание задания (если свойство
  
  [РазрешеноИзменение](../../wiki/interface/jobsform-ru-a640c24a627c.md)
  
  установлено в
  
  `Истина`
  
  );
- программно настроить фильтр отображаемых в форме заданий (через свойство
  
  [ФильтрЗаданий](../../wiki/interface/jobsform-ru-a640c24a627c.md)
  
  ).

## Примеры

**Общие примеры**

Пример фрагмента командного интерфейса, включающего команды для открытия формы для управления запланированными заданиями с различными настройками. В обработчиках создается и открывается форма `ФормаЗаданий`. Возможность изменения данных запланированных заданий определяется значением свойства [РазрешеноИзменение](../../wiki/interface/jobsform-ru-a640c24a627c.md), настройка фильтра отображаемых заданий - значением свойства [ФильтрЗаданий](../../wiki/interface/jobsform-ru-a640c24a627c.md).

```yaml
ВидЭлемента: ФрагментКомандногоИнтерфейса
ОбластьВидимости: ВПодсистеме
Ид: 10feccea-8e6c-4e39-a4d8-6d9a72516433
Имя: Команды
Элементы:
    -
        Тип: ОбычнаяКоманда
        Имя: ФормаПоУмолчанию
        Представление: По умолчанию (все задания, без изменения)
        Обработчик: ОткрытьФормуУправленияЗаданиямиПоУмолчанию
    -
        Тип: ОбычнаяКоманда
        Имя: ФормаСИзменением
        Представление: С изменением
        Обработчик: ОткрытьФормуУправленияЗаданиямиСИзменением
    -
        Тип: ОбычнаяКоманда
        Имя: ФормаСИзменениемНесистемных
        Представление: С изменением несистемных
        Обработчик: ОткрытьФормуУправленияНесистемнымиЗаданиямиСИзменением
    -
        Тип: ОбычнаяКоманда
        Имя: ФормаСФильтромПоКлючу
        Представление: С фильтром по ключу
        Обработчик: ОткрытьФормуУправленияЗаданиямиСФильтромПоКлючу
```

```xbsl
метод ОткрытьФормуУправленияЗаданиямиПоУмолчанию(Команда: ОбычнаяКоманда)
    // Открыть форму без возможности изменять задания
    новый ФормаЗаданий().Открыть()
;

метод ОткрытьФормуУправленияЗаданиямиСИзменением(Команда: ОбычнаяКоманда)
    // Открыть форму с возможностью изменять задания
    новый ФормаЗаданий(РазрешеноИзменение = Истина).Открыть()
;

метод ОткрытьФормуУправленияНесистемнымиЗаданиямиСИзменением(Команда: ОбычнаяКоманда)
    // Открыть форму с возможностью изменять задания, с фильтром только несистемных заданий
    новый ФормаЗаданий(РазрешеноИзменение = Истина, ФильтрЗаданий = Задание -> не Задание.Системное).Открыть()
;

метод ОткрытьФормуУправленияЗаданиямиСФильтромПоКлючу(Команда: ОбычнаяКоманда)
    // Открыть форму с фильтром заданий, ключ которых начинается на MyJob
    новый ФормаЗаданий(ФильтрЗаданий = Задание -> Задание.Ключ.НачинаетсяС("MyJob")).Открыть()
;
```

## Свойства

### РазрешеноИзменение

`Доступность: Клиент`

```
РазрешеноИзменение: Булево
```

Определяет, разрешено ли изменение данных запланированных заданий. Если `Истина`, то в форме можно изменять расписание заданий. По умолчанию `Ложь`.

#### Примеры

Пример создания и отрытия формы для управления запланированными заданиями с разрешением изменения данных. В такой форме можно изменять расписания заданий.

```xbsl
новый ФормаЗаданий(РазрешеноИзменение = Истина).Открыть()
```

## События

### ФильтрЗаданий

`Доступность: Клиент`

```
ФильтрЗаданий: ((ОписаниеЗадания)->Булево)?
```

Определяет условие фильтрации запланированных заданий, которые будут отображены в форме. Если `Неопределено`, то отображаются все задания. По умолчанию `Неопределено`.

#### Примеры

Пример создания и отрытия формы для управления запланированными заданиями с фильтром заданий, ключ которых начинается на `"MyJob"`.

```xbsl
новый ФормаЗаданий(ФильтрЗаданий = Задание -> Задание.Ключ.НачинаетсяС("MyJob")).Открыть()
```
