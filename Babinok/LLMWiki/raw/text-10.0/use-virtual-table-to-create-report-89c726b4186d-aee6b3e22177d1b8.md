# Создание отчета на основе данных виртуальной таблицы

Вы можете создать отчет на основе данных [виртуальной таблицы](../../wiki/project/virtual-table-b6d396b92d20.md). Для этого выполните следующие действия:

1. Создайте элемент проекта **Отчет**. Для свойства **ВидИсточникаДанных** выберите значение **Таблица** и укажите свою виртуальную таблицу в качестве источника данных.
  
  В свойствах отчёта ВидИсточникаДанных установлен в «Таблица», а ИсточникДанных — в созданную виртуальную таблицу сотрудников. [Описание иллюстрации](../figures/348d9becf93a1f54c41590bcc9f4d888327de6378debbb5b345ccad3430cb351-6ce8b9ba5218488a.md)
  
  В данном примере используется **ВиртуальнаяТаблицаСотрудники**, создание которой описано в статье [Виртуальная таблица](../../wiki/project/virtual-table-b6d396b92d20.md). Таблица содержит параметр **Должность** типа `РольСотрудника`. Для параметра обязательно должно быть указано значение по умолчанию. Если оно отсутствует, виртуальную таблицу нельзя использовать в отчете.
2. В конструкторе добавьте поля виртуальной таблицы, которые нужно отобразить в отчете. Для этого выберите нужные поля на панели слева, и они отобразятся на панели отчета справа.
  
  В данном примере добавляются поля **Наименование**, **Пользователь**, **Бизнес регион**, **Роль**.
  
  Добавление полей к отчету [Описание иллюстрации](../figures/89d0821d3c6f827e0c16c92489fabf2b81a89935f11e8246e73713cf8a1df41b-bf1f2488b97e4176.md)
  
  <details>
  <summary>Пример YAML-файла отчета «ОтчетОСотрудникахНаОсновеВиртуальнойТаблицы»</summary>
  
  ```yaml
  ВидЭлемента: Отчет
  Ид: 56f27fb8-77d6-47fb-894a-ecde1e96e1a3
  Имя: ОтчетОСотрудникахНаОсновеВиртуальнойТаблицы
  ОбластьВидимости: ВПодсистеме
  ИсточникДанных: МояВиртуальнаяТаблица
  Макет:
      ВидОтображения: СводнаяТаблица
      Поля:
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Наименование
              Ид: f39dbe7c183541198fcd00c40988752c
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Пользователь
              Ид: 1a8ef45e63b84a53a086f9c7bb7d8a00
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: БизнесРегион
              Ид: 56c04b775ffa4268be991147789de7f8
              Использовать: Истина
          -
              Вид: Измерение
              ВизуальныеРоли:
                  - Строки
              Выражение: Роль
              Ид: 310a8b5e578344dd9d25a7bc90397645
              Использовать: Истина
  ```
  
  </details>
3. Создайте форму отчета и добавьте поле ввода для выбора должности сотрудника. В свойстве **Значение** поля ввода настройте привязку к значениям параметра отчета.
  
  В редакторе формы отчёта добавлено поле выбора должности сотрудника; его значение привязывается к параметру отчёта, рядом расположен компонент просмотра результата. [Описание иллюстрации](../figures/e581693a2b8b1a17aa72ed6c3b14ebae3a74ef51f44bf14e6566205359175254-b309f6274ee142f7.md)
  
  Пример YAML-файла формы отчета:
  
  ФормаОтчетаОСотрудниках.yaml
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 810daed6-61a6-4990-ada0-24551e2aea4b
  Имя: ФормаОтчетаОСотрудникахНаОсновеВиртуальнойТаблицы
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: ФормаОтчета<ОтчетОСотрудниках>
      ВключатьВАвтоИнтерфейс: Ложь
      Отчет:
          Тип: ОтчетОСотрудниках
      Содержимое:
          Тип: ПроизвольныйШаблонФормы
          Содержимое:
              Тип: Группа
              Содержимое:
                  -
                      Тип: ПолеВвода<Строка>
                      Имя: Должность
                      Значение: =Отчет.Параметры.Должность
                  -
                      Тип: ПросмотрОтчета<ОтчетОСотрудниках>
                      РастягиватьПоВертикали: Истина
                      РастягиватьПоГоризонтали: Истина
                      Отчет: =Отчет
  ```
4. Включите в интерфейс команду открытия формы отчета. Нажмите на элемент проекта **ПанельНавигации** и перейдите к разделу **Отчеты**. Добавьте [навигационную команду](../../wiki/project/navigation-command-e62fae29cc19.md), которая открывает форму отчета.
  
  [Подробнее о том, где находится командный интерфейс](../../wiki/interface/locate-command-interface-7543048d998d.md)
  
  Приложение.yaml
  
  ```yaml
  # Элементы раздела «Анализ»
  Тип: ГруппаКомандногоИнтерфейса
  Важность: Обычная
  Видимость: Истина
  Доступность: Истина
  Изображение: Показатель.svg
  Представление: $ОсновноеЛокализация.Анализ
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Важность: Обычная
          Видимость: Истина
          Доступность: Истина
          ОпасностьДействия: Отсутствует
          Представление: $ПродажиЛокализация.ВоронкаПродаж
          ТипФормы: ВоронкаПродаж.АвтоматическаяФорма
      -
          Тип: НавигационнаяКоманда
          Представление: Отчет о сотрудниках
          ТипФормы: ФормаОтчетаОСотрудникахНаОсновеВиртуальнойТаблицы
  ```

### Результат

Запустите приложение и откройте вкладку **Отчеты** ⟶ **Отчет о сотрудниках**, чтобы увидеть получившийся отчет.
