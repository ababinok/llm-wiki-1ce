## Сервер

### Операционная система

- Microsoft Windows 7 x64,
- Microsoft Windows 10 x64,
- Microsoft Windows Server 2012 x64 и выше,
- Linux Ubuntu 20.04 x64,
- Linux Ubuntu 24.04 x64,
- Linux Alpine 3.11 x64,
- Linux Astra Special Edition 1.7,
- Linux РЕД ОС 7.3,
- Linux РЕД ОС 8.

> [!NOTE] примечание
> Если вы используете операционную систему Linux, убедитесь, что у вас установлена кодировка файлов UTF-8.

### Java Platform

64-разрядная Java Runtime Environment (JRE) версии 17.

> [!WARNING] важно
> При использовании Java других версий (например, Java 8, 11, 21, 22 и т. д.) работоспособность «1С:Предприятие.Элемента» не гарантируется.

### Жесткий диск

Диск, на котором вы размещаете сервер, должен иметь не менее 1 Гб свободного места.

### Оперативная память

Рекомендуется 8 Гб, но реальная потребность определяется используемым приложением и количеством пользователей.
