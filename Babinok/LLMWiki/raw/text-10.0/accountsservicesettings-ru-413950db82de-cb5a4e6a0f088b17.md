`Доступность: КлиентИСервер`

```

```

Признак использования сервиса. Если `Ложь`, то сервис учетных записей не используется.

### СоздаватьПользователяПриВходе

`Доступность: КлиентИСервер`

```
СоздаватьПользователяПриВходе: Булево
```

Признак автоматического создания пользователя, если произошла успешная аутентификация через сервис, но такого пользователя нет в списке пользователей.

Включает создание пользователя при успешной аутентификации через данный провайдер учетных записей. Например, таким образом можно автоматически создавать пользователей, прошедших аутентификацию через Active Directory или другие сторонние сервисы. Данная настройка только включает создание пользователей в списке, созданного пользователя требуется подключить в приложение. Для этого следует использовать метод [Создать](../../wiki/stdlib/serviceusers-ru-558e621dc6f7.md).
