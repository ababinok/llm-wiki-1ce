`Стд::Отчеты::Интерфейс::ФормаОтчета<ТипОтчета,ТипРезультата>` `Доступность: Клиент`

ТипОтчета: Тип используемого отчета в форме. По умолчанию - `Отчет`. Ограничения параметра типа: Стд::Отчеты::Отчет. ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию - `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md) без передачи аргумента, в качестве результата открытия возвращается `Неопределено`.

Форма отчета. Служит для отображения отчета.

**Сравнение**

Ссылочное
