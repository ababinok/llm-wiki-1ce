## Методы

### МасштабироватьТаблицуПодРазмерСтраницы

`Доступность: Сервер` `Статический`

```
@ИменованныеПараметры
МасштабироватьТаблицуПодРазмерСтраницы(
  РазмерСтраницы: РазмерСтраницы,
  ОриентацияСтраницы: ОриентацияСтраницы? = Неопределено,
  ПолеСверху: Число? = Неопределено,
  ПолеСлева: Число? = Неопределено,
  ПолеСнизу: Число? = Неопределено,
  ПолеСправа: Число? = Неопределено
): НастройкиИмпортаPdfИзТаблицы
```

>

Вызов возможен только с именованными параметрами

Масштабировать таблицу так, чтобы документ помещался на одну страницу по ширине.

По умолчанию, используется размер страницы формата A4.

Если величины отступов или ориентация листа не определены, то используются значения, полученные при импорте.

---

### ПодогнатьРазмерСтраницыПодСодержимое

`Доступность: Сервер` `Статический`

```
@ИменованныеПараметры
ПодогнатьРазмерСтраницыПодСодержимое(
  ВысотаСтраницы: Число,
  ПолеСверху: Число? = Неопределено,
  ПолеСлева: Число? = Неопределено,
  ПолеСнизу: Число? = Неопределено,
  ПолеСправа: Число? = Неопределено
): НастройкиИмпортаPdfИзТаблицы
```

>

Вызов возможен только с именованными параметрами

Установить такой размер страницы итогового документа с заданной высотой (в миллиметрах), чтобы таблица вмещалась по ширине на лист со стандартным масштабом.

По умолчанию, высота страницы задается таким образом, чтобы документ целиком помещался на одну страницу. Если высоту таблицы определить невозможно, то используется размер страницы c соотношением сторон 1.41 к 1.

Если величины отступов не определены, то используются значения, полученные при импорте.

---

### ФиксированныйРазмерСтраницы

`Доступность: Сервер` `Статический`

```
@ИменованныеПараметры
ФиксированныйРазмерСтраницы(
  РазмерСтраницы: РазмерСтраницы,
  ОриентацияСтраницы: ОриентацияСтраницы? = Неопределено,
  ПолеСверху: Число? = Неопределено,
  ПолеСлева: Число? = Неопределено,
  ПолеСнизу: Число? = Неопределено,
  ПолеСправа: Число? = Неопределено
): НастройкиИмпортаPdfИзТаблицы
```

>

Вызов возможен только с именованными параметрами

Использовать фиксированный размер листа в итоговом документе. Таблица импортируется со стандартным масштабом.

По умолчанию, используется лист формата A4.

Если величины отступов или ориентация листа не определены, то используются значения, полученные при импорте.
