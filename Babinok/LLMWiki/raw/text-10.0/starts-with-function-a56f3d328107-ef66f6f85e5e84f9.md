Эта функция проверяет наличие подстроки в начале. Она имеет следующий синтаксис:

```xbql
исходная-строка.НачинаетсяС(искомая-подстрока)
```

***исходная-строка*** должна иметь тип `Строка`. ***искомая-подстрока*** должна иметь тип `Строка`. Допускается использовать только константы (строковые литералы или параметры).

Поиск выполняется без учета регистра.

Пример:

```xbql
"0123456789".НачинаетсяС("345") // вернет Ложь
"0123456789".НачинаетсяС("01")  // вернет Истина
```
