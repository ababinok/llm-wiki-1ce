Вы можете добавить в отчет параметры, чтобы отфильтровать или сгруппировать его данные. Это позволит упростить понимание и анализ информации в отчете.

Параметры отчета можно создавать несколькими способами:

- использовать в качестве источника данных
  
  [запрос](../../wiki/queries/use-query-to-create-report-3cf7e26dbbbc.md)
  
  или
  
  [виртуальную таблицу](../../wiki/project/use-virtual-table-to-create-report-89c726b4186d.md)
  
  c параметрами;
- создать параметр вручную в дизайнере отчета.

Рассмотрим пример, как добавить произвольный параметр к отчету.

1. Создайте элемент проекта **Отчет**. Для свойства **ВидИсточникаДанных** оставьте значение **Таблица**. В свойстве **ИсточникДанных** выберите справочник **Сотрудники**.
  
  > [!NOTE] примечание
  > В данном примере используется справочник **Сотрудники** [приложения «Демо CRM»](../../wiki/project/demo-app-3768685a4428.md).
  
  
2. В дизайнере отчета измените вид диаграммы на **Круговая**.
  
  Выбор типа диаграммы [Описание иллюстрации](../figures/e73968c6f4da4296ec31ed25190f03ddd228ac68e66fa24d4e8cd616ecb1ed28-81542f666697ba4e.md)
3. Добавьте параметр отчета. Для этого на вкладке **Поля и параметры** нажмите на знак плюса и выберите пункт **Создать параметр**.
  
  На вкладке «Поля и параметры» отчёта меню кнопки плюса содержит «Создать поле» и «Создать параметр»; выбран пункт создания параметра. [Описание иллюстрации](../figures/559aee45ea36d5541080e9558ca9d263f9d565d239ffe07f2f35c8b7dc30ace6-c63d7f207b3ae5e9.md)
4. В открывшемся окне введите имя параметра — **Срез**. Выберите тип параметра — **Строка**. Активируйте настройку **Задать допустимые значения** и укажите значения параметра в таблице.
  
  В данном примере параметр содержит два значения, чтобы показать распределение сотрудников по регионам и занимаемым должностям.
  
  Форма нового параметра отчёта «Срез»: тип Строка, значение по умолчанию «По региону», включены создание элемента управления и задание доступных значений. Таблица значений содержит варианты «По региону» и «По должности». [Описание иллюстрации](../figures/464842b9a01cb9bdf93147130f6fe0438740de28e1ace236b74767390258c3b0-273ee2334bff0bac.md)
5. Созданный параметр появится в списке доступных полей отчета. Нажмите на него, чтобы добавить его к отчету. Добавленный параметр будет выступать как измерение, по которому будет производиться группировка данных.
6. Добавьте к отчету поле **Имя** как факт. Функция **Количество** будет автоматически выбрана для агрегации факта по измерениям.
  
  В конструкторе отчёта у поля «Имя» раскрыто меню с пунктами добавления поля, факта и группировки; поле добавляется как факт для агрегации. [Описание иллюстрации](../figures/43dcaa89acf79bd59dc6ccf6e68f5420166ec1120ce103e70b421671c14f0198-c91c3e52eba6763d.md)
7. Настройте отображение диаграммы. Для этого нажмите на созданный параметр в панели состава отчета и выберите следующие пункты в выпадающем меню:
  
  - Маркеры
    
    , чтобы добавить подписи данных;
  - Цвет
    
    , чтобы использовать разные цвета для сегментов диаграммы.
  
  В меню выражения отчёта видны включённые опции «Значения», «Маркеры», «Цвет»; указатель наведён на «Цвет». [Описание иллюстрации](../figures/84466378ba2586946a0d4ca5784947c0a7273ec019542ea0a3b0e809c9069b12-a8f01b62c9f669ed.md)

Так как параметр содержит значения, необходимо добавить в отчет поле для переключения этих значений. Вы можете сделать это двумя способами:

- в дизайнере отчета создать элемент управления
  
  Выпадающий список
  
  ;
- добавить поле выбора значения в форму отчета.

Рассмотрим каждый из этих способов более подробно.

## Создание элемента управления в дизайнере отчета

Если отчет содержит параметр, вы можете добавить для него элемент управления. Сделать это можно в диалоговом окне создания нового параметра с помощью настройки **Создать элемент управления**.

В настройках параметра отчёта «Срез» выбран тип «Строка» и значение по умолчанию «По региону». [Описание иллюстрации](../figures/0601338797e0527f7d0ba2c100f378511fe1d7240d9561990c683bf9910feab8-d66083495d4cd194.md)

Если вы хотите добавить элемент управления для существующего параметра отчета, нажмите на троеточие рядом с именем параметра в панели источника и выберите пункт **Создать** → **Элемент управления**.



Новый элемент управления появится на вкладке **Элементы управления** дизайнера отчета. Тип элемента управления будет выбран автоматически. Так как в данном примере параметр содержит значения, «1С:Предприятие.Элемент» сгенерирует элемент управления **Выпадающий список**.

На вкладке «Элементы управления» дизайнера отчёта параметр «Срез» представлен выпадающим списком. [Описание иллюстрации](../figures/1a9f1b3a8cdb19476660d315111406974de36ab839b45352982f5264769827bb-1fd9f0f28ed1c3e2.md)

Для переключения значения параметра в самом отчете необходимо нажать на значок шестеренки в панели команд, чтобы открыть меню **Настройки**, содержащее созданный элемент управления.

В отчёте открыты настройки через шестерёнку; элемент управления параметром «Срез» позволяет выбрать вариант группировки отображаемой диаграммы. [Описание иллюстрации](../figures/3616d2374cb3842992fa7bd264e95cb06370af3c34d7e8443cd477da05e0ba77-bf80ecf98e644568.md)

## Добавление поля выбора значений параметра в форму отчета

1. Создайте форму отчета с именем **ФормаОтчетаОСотрудниках**.
2. Добавьте в форму компонент [ПолеВвода](../../wiki/interface/edit-component-a54ad83ade7f.md) для выбора значения параметра. Задайте имя компонента — **Срез**. В качестве типа поля ввода укажите перечисление `ОтчетОСотрудниках.Параметры.Срез`, [автоматически сгенерированное](../../wiki/language/report-types-be832b0eb700.md) для параметра **Срез** и содержащее значения параметра. В свойстве **Значение** поля ввода настройте привязку к значениям параметра отчета.
  
  В форме отчета добавлено поле ввода «Срез». [Описание иллюстрации](../figures/6c4909daab3cb39e3445c2d14939854102f6b88e7b8d671eee607638cb3efa4c-9d889118bb1cdcdb.md)
  
  <details>
  <summary>Пример YAML-файла формы отчета</summary>
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 5c2ebd7e-c796-41e5-a5a7-6d1578ed2724
  Имя: ФормаОтчетаОСотрудниках
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: ФормаОтчета<ОтчетОСотрудниках>
      ВключатьВАвтоИнтерфейс: Ложь
      Отчет:
          Тип: ОтчетОСотрудниках
      Содержимое:
          Тип: ПроизвольныйШаблонФормы
          Содержимое:
              Тип: Группа
              Содержимое:
                  -
                      Тип: ПолеВвода<ОтчетОСотрудниках.Параметры.Срез>
                      Имя: Срез
                      Заголовок: Распределение сотрудников
                      Значение: =ОтчетОСотрудниках.Параметры.Срез
                  -
                      Тип: ПросмотрОтчета<ОтчетОСотрудниках>
                      РастягиватьПоВертикали: Истина
                      РастягиватьПоГоризонтали: Истина
                      Отчет: =Отчет
  ```
  
  </details>
3. Включите в интерфейс [демонстрационного приложения](../../wiki/project/demo-app-3768685a4428.md) команду открытия формы отчета. Нажмите на элемент проекта **Приложение** и перейдите к элементу **ГруппаКомандногоИнтерфейса** раздела **Анализ**. Добавьте [навигационную команду](../../wiki/project/navigation-command-e62fae29cc19.md), которая открывает форму **ФормаОтчетаОСотрудниках**.
  
  [Подробнее о том, где находится командный интерфейс](../../wiki/interface/locate-command-interface-7543048d998d.md)
  
  ```yaml
  # Элементы раздела «Анализ»
  Тип: ГруппаКомандногоИнтерфейса
  Важность: Обычная
  Видимость: Истина
  Доступность: Истина
  Изображение: Показатель.svg
  Представление: $ОсновноеЛокализация.Анализ
  Элементы:
      -
          Тип: НавигационнаяКоманда
          Важность: Обычная
          Видимость: Истина
          Доступность: Истина
          ОпасностьДействия: Отсутствует
          Представление: $ПродажиЛокализация.ВоронкаПродаж
          ТипФормы: ВоронкаПродаж.АвтоматическаяФорма
      -
          Тип: НавигационнаяКоманда
          Представление: Отчет о сотрудниках
          ТипФормы: ФормаОтчетаОСотрудниках
  ```

Запустите приложение и откройте вкладку **Анализ** ⟶ **Отчет о сотрудниках**, чтобы увидеть получившийся отчет.

## Создание параметров в панели отчетов

Если панель содержит отчеты с параметрами, вы можете создать для нее собственный параметр и связать его с параметрами отчетов для более удобного управления данными в этих отчетах.

Предположим, что панель отчетов содержит два отчета о сотрудниках: один в виде диаграммы, а другой в виде таблицы. Для каждого отчета определен параметр **Срез**, создание которого показано выше.

Чтобы добавить параметр в панель отчетов, откройте ее дизайнер и перейдите на вкладку **Поля и параметры**. Нажмите на знак плюса и выберите пункт **Создать параметр**.

В дизайнере панели отчётов на вкладке «Поля и параметры» меню кнопки плюса содержит «Создать поле» и «Создать параметр»; выбран новый параметр. [Описание иллюстрации](../figures/e6601eeedc06d63807026712d9ac2768e0794155edcb43f10f82a681f8821f1f-46fb9abee85cf740.md)

В открывшемся окне укажите имя нового параметра — **Срез**. Выберите параметры отчетов, с которыми вы хотите связать новый параметр. В данном примере это параметры **Срез** отчетов о сотрудниках. Нажмите **Далее**.

Создание параметра «Срез»: в диалоге отмечаются одноимённые параметры отчётов, которые нужно связать с ним; переход к следующему шагу — «Далее». [Описание иллюстрации](../figures/39875ddf2b494dae9aa4f55788e0b994f14b92de19ef7e665ac7f29c832fbaa9-81ca4f8f77dd9a18.md)

Задайте заголовки и имена значений параметра панели отчетов. Для каждого значения укажите соответствующие значения параметров отчетов. Активируйте опцию **Создать элемент управления** и нажмите **Готово**.

У параметра панели «Срез» включено «Создать элемент управления»; значение по умолчанию — «По региону». [Описание иллюстрации](../figures/7af5d11ad8ca56b2d0f5c426fc33ec46390416ee3e6991eff165e5a5d5896405-aa0baf2c4f514fc9.md)

Для изменения значения параметра в панели отчетов нажмите на значок шестеренки, чтобы открыть меню **Настройки**, содержащее созданный элемент управления. При переключении значения параметра изменяются отображаемые данные в обоих отчетах.

На панели отчетов «Сотрудники» открыто меню шестеренки «Настройки». [Описание иллюстрации](../figures/6b808a0b82081db79094153f2d8e6afa6b4b8e523ea11cb5ea31d8ca48fdf345-a8a73c81843c2db2.md)
