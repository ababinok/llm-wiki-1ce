`Стд::ГеографическиеКарты::Интерфейс::СтандартноеОкноМаркераГеографическойКарты<ТипДанныхМаркера>` `Доступность: Клиент`

ТипДанныхМаркера: Тип свойства `Данные` маркеров. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент стандартного окна маркера географической карты, который служит для отображения информации в окне на карте по нажатию на маркер.

Ссылочное

## Свойства

### Заголовок

`Доступность: Клиент`

```
Заголовок: Авто|Строка
```

Текст заголовка маркера, который показывается в его стандартном окне.

Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), используется заголовок маркера, к которому относится это окно.

---

### Изображение

`Доступность: Клиент`

```
Изображение: Авто|Url|ДвоичныйОбъект.Ссылка|?
```

Изображение, которое показывается в стандартном окне маркера.

Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), используется изображение маркера, к которому относится это окно.

---

### КонтактнаяИнформация

`Доступность: Клиент`

```
КонтактнаяИнформация: Массив<Надпись>
```

Список дополнительной информации (например: телефон, почта, адрес и т. д.), отображаемой над описанием в группе, отделенной разделителями.

---

### ОбычныеКоманды

`Доступность: Клиент`

```
ОбычныеКоманды: Команда|ГруппаКомандногоИнтерфейса|?
```

Список основных команд, назначенных маркеру, которые отображаются в его стандартном окне в виде кнопки над главной кнопкой.

---

### Описание

`Доступность: Клиент`

```
Описание: Авто|Строка
```

Описание маркера, которое показывается в его стандартном окне.

Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), используется описание маркера, к которому относится это окно.

---

### ОсновнаяКоманда

`Доступность: Клиент`

```
ОсновнаяКоманда: Команда?
```

Задает команду, определяющую главное действие в стандартном окне маркера.

---

### Подзаголовок

`Доступность: Клиент`

```
Подзаголовок: Авто|Строка
```

Текст подзаголовка маркера, который показывается в его стандартном окне.

Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), используется подзаголовок маркера, к которому относится это окно.

---

### Теги

`Доступность: Клиент`

```
Теги: Массив<КомпонентВыбора>
```

Список ярлыков, которые показываются в стандартном окне маркера.
