## Свойства

### ВидСобытия

`Доступность: Сервер` `ТолькоЧтение`

```
ВидСобытия: ВидСобытияФайловойСистемы
```

Информация о виде события. Имеет одно из значений перечисления [ВидСобытияФайловойСистемы](../../wiki/stdlib/filesystemeventkind-ru-f2ab8b7b9083.md).

---

### Файл

`Доступность: Сервер` `ТолькоЧтение`

```
Файл: Файл
```

Файл, с которым произошли изменения. Если `ВидСобытия` - `ПотеряСобытий`, возвращает зарегистрированный в МонитореФайловойСистемы каталог, в котором произошла потеря событий.
