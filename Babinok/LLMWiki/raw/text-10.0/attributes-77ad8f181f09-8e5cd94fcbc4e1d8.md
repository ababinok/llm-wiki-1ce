#### Реквизиты

```yaml
Реквизиты: РеквизитРегистраНакопления|Регистратор[]
```

Реквизиты регистра накопления. Используются для хранения вспомогательной информации, относящейся к отдельным записям регистра.

Регистр накопления должен содержать обязательный стандартный реквизит **Регистратор**. В этом реквизите указываются ссылки на элементы проекта вида [Документ](../../wiki/data/document-element-0c6b898a8b13.md), которые являются регистраторами для регистра накопления.
