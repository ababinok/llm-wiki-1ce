`Стд::Интерфейс::Формы::Форма<ТипРезультата>` `Доступность: Клиент`

ТипРезультата: Тип возвращаемого значения при открытии формы в модальном или всплывающем окне. По умолчанию `Неопределено`. Если пользователь закрыл форму крестиком, кликом мимо при открытии во всплывающем окне или был вызван метод [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md) без передачи аргумента - в качестве результата открытия возвращается `Неопределено`.

Базовый компонент для форм приложения.

Форма - это компонент, для которого определены операции открытия и закрытия. Форма образует связь с оконной системой приложения. Для примера, если пользователь нажмет клавишу `Esc`, когда фокус в компоненте внутри формы, то форма закроется. В качестве содержимого форме задается компонент шаблона формы, который определяет содержимое формы и управляет его трансформацией в различные форм-факторы.

Порождает тип одиночку команды открытия формы - `<ИмяФормы>.ОткрытьФорму`/`<ИмяФормы>.OpenForm`, наследника [НавигационнаяКоманда](../../wiki/interface/navigationcommand-ru-8290d7424fc8.md).

## Свойства

### SeoОписание

`Доступность: Клиент`

```
SeoОписание: Авто|Строка
```

Задает произвольное описание формы, которое будет применено для мета-тега description страницы формы. Используется для оптимизации поисковой выдачи в сети Интернет.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) интерпретируется, как пустая строка.

### ВажностьИзбранногоПользователя

`Версия 10.0 и выше`

`Доступность: Клиент`

```
ВажностьИзбранногоПользователя: Авто|ВажностьИзбранногоПользователя
```

Вид отображения команд работы с **Избранным**.

`Высокая` — команда отображается слева от заголовка в формах на настольном компьютере или первой в списке дополнительных команд формы на мобильных устройствах.

`Обычная` — команда отображается последней в списке дополнительных команд формы. Индикатор добавления в **Избранное** отображается слева от заголовка.

`Отсутствует` — **Избранное** не отображается.

`Авто` — значение определяется следующим образом:

- для форм, открытых в главной рабочей области без зависимых параметров, наследуется от клиентского приложения;
- для форм сущностей и форм списков наследуется от соответствующей настройки сущности. Если настройка не задана, то наследуется от клиентского приложения;
- в остальных случаях принимает значение
  
  `Отсутствует`
  
  .

### ЗаписыватьВИсториюРаботыПользователяПриОткрытии

`Доступность: Клиент`

```
ЗаписыватьВИсториюРаботыПользователяПриОткрытии: Авто|Булево
```

Признак записи в историю при открытии формы. Если `Истина`, то форма записывается в Историю без параметров открытия всегда, кроме тех случаев, когда ее открыли в приложении с режимом без аутентификации. Если `Ложь`, то форма не записывается в Историю. [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) - определяется системой автоматически. Для форм сущности, форм списка и форм, открытых в главной рабочей области без зависимых параметров - Истина, в остальных случаях - Ложь.

## Методы

### ЕстьВИзбранномПользователя

`Доступность: Клиент`

```
ЕстьВИзбранномПользователя(): Булево
```

Проверяет, входит ли форма или сущность(если вызвано в форме объекта) в избранное пользователя.

---

### Закрыть

`Доступность: Клиент`

```
Закрыть(ПараметрЗакрытия: ТипРезультата? = Неопределено): Булево
```

Закрывает форму. Переданный параметр служит возвращаемым из метода открытия значением, если он был вызван с параметром

`ОжидатьЗакрытия`

=

`Истина`

.

---

### ЗаписатьВИзбранноеПользователя

`Доступность: Клиент`

```
ЗаписатьВИзбранноеПользователя()
```

Записывает форму или сущность(если вызвано в форме объекта) в избранное пользователя

Форма должна быть открыта во время вызова данного метода, иначе будет выброшено `ИсключениеФормаНеОткрыта`

Если форма или сущность уже есть в избранном выбрасывается `ИсключениеЭлементИзбранногоПользователяНеУникален` Показывает

---

### ЗапуститьОбучающиеПодсказки

`Доступность: Клиент`

```
ЗапуститьОбучающиеПодсказки(Последовательность: ПоследовательностьОбучающихПодсказок)
```

Запускает последовательность обучающих подсказок в текущей форме. При таком запуске, механизм не будет сам запоминать факт просмотренности подсказок пользователем: последовательность будет запускаться всегда. Параметры:

- `Последовательность`
  
  - последовательность подсказок, которую нужно запустить.

---

### ОстановитьОбучающиеПодсказки

`Доступность: Клиент`

```
ОстановитьОбучающиеПодсказки(Последовательность: ПоследовательностьОбучающихПодсказок? = Неопределено)
```

Останавливает указанную последовательность обучающих подсказок в текущей форме. Параметры:

- `Последовательность`
  
  - последовательность подсказок, которую нужно остановить. Если равно
  
  `Неопределено`
  
  , то останавливает текущую активную последовательность.

---

### Открыть

`Доступность: Клиент`

```
Открыть(): ТипРезультата?
```

Открывает экземпляр формы. Открывает форму по-разному и возвращает разные результаты в зависимости от свойства

[СпособОткрытия](../../wiki/interface/form-ru-89fb5e7eaeb3.md)

.

- Если
  
  [СпособОткрытия](../../wiki/interface/form-ru-89fb5e7eaeb3.md)
  
  =
  
  [ВМодальномОкне](../../wiki/interface/formopenmethod-ru-9ca1bcb027a4.md)
  
  или
  
  [ВоВсплывающемОкне](../../wiki/interface/formopenmethod-ru-9ca1bcb027a4.md)
  
  , то возвращает значение, переданное в метод
  
  [Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md)
  
  или
  
  `Неопределено`
  
  , если форма была закрыта через "крестик". Метод не вернет управление вызывающему коду, пока окно не закроется.
- Иначе, возвращает
  
  `Неопределено`
  
  . Метод вернет управление вызывающему коду, как только окно откроется.

---

### ОткрытьВМодальномОкне

`Доступность: Клиент`

```
ОткрытьВМодальномОкне(ОжидатьЗакрытия: Булево = Истина): ТипРезультата?
```

Открывает форму модально. Нельзя вызывать метод на форме, которая уже открыта. Если параметр

`ОжидатьЗакрытия`

не равен

`Истина`

, метод возвращает

`Неопределено`

. Иначе возвращает значение, переданное в метод

[Закрыть](../../wiki/interface/form-ru-89fb5e7eaeb3.md)

открытой формы. Если форма была закрыта через "крестик", возвращает

`Неопределено`

.

---

`Доступность: Клиент`

```
УдалитьИзИзбранногоПользователя()
```
