## Методы

### ПолучитьОдиночки

`Версия 10.0 и выше`

```
ПолучитьОдиночки(): ЧитаемоеМножество<{ИмяКонтрактаСущности}>
```

Получить экземпляры типов-одиночек элементов, которые реализуют данный контракт сущности.

Метод существует, если в элементе проекта значение свойства "ПолучениеВсехОдиночек" имеет значение `Доступно`.

```xbsl
метод ЗавершитьСогласованиеДокументовДляВсехАктуальныхМаршрутов()
    для Док из СогласуемыйДокумент.ПолучитьОдиночки()
        для Маршрут из Док.ПолучитьАктуальныеМаршруты()
            если Маршрут.КоличествоВыполненныхШагов == Маршрут.КоличествоШагов и Маршрут.СогласуемыйДокумент != Неопределено
                знч Об = Маршрут.СогласуемыйДокумент.ЗагрузитьОбъект()
                Об.ЗавершитьСогласование()
            ;
        ;
    ;
;
```

### ПолучитьОдиночку

`Версия 10.0 и выше`

`Доступность: КлиентИСервер` `Статический`

```
ПолучитьОдиночку(Источник: Тип<{ИмяКонтрактаСущности}.Объект>|Тип<{ИмяКонтрактаСущности}.Ссылка>|{ИмяКонтрактаСущности}.Объект|{ИмяКонтрактаСущности}.Ссылка): {ИмяКонтрактаСущности}
```

Получить экземпляр типа-одиночки, который реализует реализуют данный контракт сущности. Возвращается одиночка, соответствующий типу переданного источника, например, если передать ссылку на справочник, который реализует данный контракт, то возвращается экземпляр типа-одиночки этого справочника.

```xbsl
метод ПолучитьДокументДляПечати(ОбъектПечатиСсылка: ОбъектПечати.Ссылка): ДвоичныйОбъект.Ссылка
    знч Форма = ОбъектПечати.ПолучитьОдиночку(ОбъектПечатиСсылка).ПечатнаяФорма(ОбъектПечатиСсылка)
    возврат Форма.ДокументPDF
;
```
