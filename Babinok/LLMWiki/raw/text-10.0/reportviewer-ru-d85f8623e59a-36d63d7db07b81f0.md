`Стд::Отчеты::Интерфейс::ПросмотрОтчета<ТипОтчета>` `Доступность: Клиент`

ТипОтчета: Тип используемого отчета. По умолчанию - `Отчет`. Ограничения параметра типа: Стд::Отчеты::Отчет.

Компонент предназначен для отображения отчетов и панелей отчетов.

**Сравнение**

Ссылочное

  ВыравниваниеВГруппеПоГоризонтали: Авто|ВыравниваниеПоГоризонтали,

---

## Свойства

### ОтображатьПанельКоманд

`Доступность: Клиент`

```
ОтображатьПанельКоманд: Авто|Булево
```

Включает или выключает панель команд для отображаемого отчета.

---

### Отчет

`Доступность: Клиент`

```
Отчет: ТипОтчета?
```

Отчет или панель отчетов, которую необходимо отобразить.

---

## Методы

### Обновить

`Доступность: Клиент`

```
Обновить()
```

Инициирует принудительное обновление данных отчета. Данный метод следует вызывать после изменения значений параметров или данных в источнике данных отчета.
