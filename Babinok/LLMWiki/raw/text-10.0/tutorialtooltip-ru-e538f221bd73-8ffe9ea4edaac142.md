Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Конструкторы

### ОбучающаяПодсказка

`Версия 9.0 и выше`

`Доступность: Клиент`

```
ОбучающаяПодсказка(
  ОпорныйЭлемент: Компонент?,
  Заголовок: Строка,
  Описание: Строка,
  Изображение: Url|ДвоичныйОбъект.Ссылка|?)
```

Создает обучающую подсказку со значениями свойств, соответствующими параметрам конструктора.

---

### ОбучающаяПодсказка

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
ОбучающаяПодсказка(
  ОпорныйЭлемент: Компонент?,
  Заголовок: Строка,
  Описание: Строка,
  Изображение: ДвоичныйОбъект.Ссылка?)
```

Конструктор удален.

---

## Свойства

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Заголовок подсказки. Можно занимать максимум 2 строки текста.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Дополнительное изображение внутри подсказки. С помощью картинки можно украсить подсказку и добавить в нее дополнительную полезную информацию.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/tutorialtooltip-ru-e538f221bd73.md).

---

### Описание

`Доступность: Клиент`

```
Описание: Строка
```

Текст с содержательной информацией подсказки. Можно занимать максимум 10 строк текста. Если задана пустая строка, то описание не отобразится.

---

### ОпорныйЭлемент

`Доступность: Клиент`

```
ОпорныйЭлемент: Компонент?
```

Компонент интерфейса, около которого появится подсказка. Опорный элемент обязательно должен быть задан.

---

## Методы

### ВСтроку

`Доступность: Клиент`

```
ВСтроку(): Строка
```

Возвращает строковое представление.
