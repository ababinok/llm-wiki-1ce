`Стд::Интерфейс::Команды::ГруппаКомандногоИнтерфейса<ТипКоманды>` `Доступность: Клиент`

ТипКоманды: тип команды группы. По умолчанию [Команда](../../wiki/interface/command-ru-ad3bc8ea1407.md). Ограничения параметра типа: Стд::Интерфейс::Команды::Команда, Стд::Интерфейс::Команды::КомандаСПараметром<неизвестно>.

Логическое объединение команд в некоторую группу. Имеет текстовое представление и картинку. В пользовательском интерфейсе может быть представлена в виде группы меню, выпадающего списка и т.д.

**Сравнение**

Ссылочное

Структурное сравнение.

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

## Свойства

### Важность

`Доступность: Клиент`

```
Важность: ВажностьКоманды
```

Определяет важность группы. Важность может использоваться при отображении команды. Например, все команды с важностью [Низкая](../../wiki/interface/commandimportance-ru-986d64839edb.md) из свойства формы [ДополнительныеКоманды](../../wiki/interface/form-ru-89fb5e7eaeb3.md) будут отображены в выпадающем меню "Еще"

---

### ВидОтображения

`Доступность: Клиент`

```
ВидОтображения: ВидОтображенияГруппыКомандногоИнтерфейса
```

Определяет вид отображения группы. См. [ВидОтображенияГруппыКомандногоИнтерфейса](../../wiki/interface/commandinterfacegroupdisplaykind-ru-41b09fc7443a.md)

---

### Видимость

`Доступность: Клиент`

```
Видимость: Булево
```

Управляет видимостью группы

---

### Доступность

`Доступность: Клиент`

```
Доступность: Булево
```

Если `Ложь`, команды в группе недоступны для выполнения
