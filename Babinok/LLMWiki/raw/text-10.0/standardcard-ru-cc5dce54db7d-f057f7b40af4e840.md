`Стд::Интерфейс::ОбщиеКомпоненты::СтандартнаяКарточка` `Доступность: Клиент`

Представляет собой карточку с предопределенной структурой. Структура карточки зависит от значения свойства [ВидОтображения](../../wiki/interface/standardcard-ru-cc5dce54db7d.md).

Карточка:

- заголовок с текстом и картинкой,
- содержимое карточки,
- команду или группу команд.

Баннер:

- основная область, состоящая из заголовка, содержимого и команд
- картинка, сопровождающая основную область

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Карточка](../../wiki/interface/card-ru-236110dd3bc1.md), [Компонент](../../wiki/interface/component-ru-bad1c84be995.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

## Свойства

### ВидОтображения

`Доступность: Клиент`

```
ВидОтображения: Авто|ВидОтображенияСтандартнойКарточки
```

Меняет вид отображения стандартной карточки: карточка или баннер. При `Авто` выбирается [Карточка](../../wiki/interface/standardcarddisplaykind-ru-69977cacf63a.md)

---

### ВыравниваниеСодержимогоПоВертикали

`Доступность: Клиент`

```
ВыравниваниеСодержимогоПоВертикали: Авто|ВыравниваниеПоВертикали
```

Выравнивание области содержимого по вертикали.

---

### ВыравниваниеСодержимогоПоГоризонтали

`Доступность: Клиент`

```
ВыравниваниеСодержимогоПоГоризонтали: Авто|ВыравниваниеПоГоризонтали
```

Выравнивание области содержимого по горизонтали.

---

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Текст заголовка карточки.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Изображение в заголовке карточки.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/standardcard-ru-cc5dce54db7d.md).

---

### Картинка

`Доступность: Клиент`

```
Картинка: Картинка?
```

Указывает на внутренний компонент [Картинка](../../wiki/interface/picture-ru-efed61d49ad9.md) в заголовке. Может использоваться для дополнительного ее оформления.

---

### Команды

`Доступность: Клиент`

```
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или группа команд, назначенных карточке.

---

### РасположениеИзображенияВБаннере

`Доступность: Клиент`

```
РасположениеИзображенияВБаннере: Авто|РасположениеИзображенияВБаннере
```

Способ расположения изображения относительно контента в баннере. Применяется, если [ВидОтображения](../../wiki/interface/standardcard-ru-cc5dce54db7d.md) == [Баннер](../../wiki/interface/standardcarddisplaykind-ru-69977cacf63a.md)

---

### РастягиватьИзображениеВБаннере

`Доступность: Клиент`

```
РастягиватьИзображениеВБаннере: Авто|Булево
```

Нужно ли растягивать изображение до краев баннера, игнорируя отступы области содержимого. Применяется, если [ВидОтображения](../../wiki/interface/standardcard-ru-cc5dce54db7d.md) == [Баннер](../../wiki/interface/standardcarddisplaykind-ru-69977cacf63a.md)

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент|Строка
```

Основное содержимое карточки. Может быть указано как в виде строки, так и произвольным компонентом.

---

### Фон

`Доступность: Клиент`

```
Фон: Авто|Цвет|Url|ДвоичныйОбъект.Ссылка
```

Заливка фона карточки: может быть как цветом, так и произвольным изображением.

---

### ЦветЗаголовка

`Доступность: Клиент`

```
ЦветЗаголовка: Авто|Цвет
```

Цвет заголовка карточки.

---

### ЦветСодержимого

`Доступность: Клиент`

```
ЦветСодержимого: Авто|Цвет
```

Цвет содержимого карточки. Не применяется, если содержимого нет, либо содержимое является компонентом.

---

### ШрифтЗаголовка

`Доступность: Клиент`

```
ШрифтЗаголовка: Авто|Шрифт
```

Шрифт заголовка карточки.

---

### ШрифтСодержимого

`Доступность: Клиент`

```
ШрифтСодержимого: Авто|Шрифт
```

Шрифт содержимого карточки. Не применяется, если содержимого нет, либо содержимое является компонентом.
