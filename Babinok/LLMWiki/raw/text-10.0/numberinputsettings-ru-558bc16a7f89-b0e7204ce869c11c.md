## Конструкторы

### НастройкиВводаЧисла

`Доступность: КлиентИСервер`

```
НастройкиВводаЧисла(
  ШагИзменения: Авто|Число,
  ДлинаЦелойЧасти: Авто|Число,
  ДлинаДробнойЧасти: Авто|Число,
  МаксимальноеЗначение: Авто|Число,
  МинимальноеЗначение: Авто|Число)
```

Создает новый объект

[НастройкиВводаЧисла](../../wiki/interface/numberinputsettings-ru-558bc16a7f89.md)

---

## Свойства

### ДлинаДробнойЧасти

`Доступность: КлиентИСервер`

```
ДлинаДробнойЧасти: Авто|Число
```

Максимально допустимая длина дробной части числа. Авто = не ограничено

---

### ДлинаЦелойЧасти

`Доступность: КлиентИСервер`

```
ДлинаЦелойЧасти: Авто|Число
```

Максимально допустимая длина целой части числа. Авто(и 0) = не ограничено

---

### МаксимальноеЗначение

`Доступность: КлиентИСервер`

```
МаксимальноеЗначение: Авто|Число
```

Максимально допустимое значение. Авто = не ограничено.

---

### МинимальноеЗначение

`Доступность: КлиентИСервер`

```
МинимальноеЗначение: Авто|Число
```

Минимальное допустимое значение. Авто = не ограничено.

---

### ШагИзменения

`Доступность: КлиентИСервер`

```
ШагИзменения: Авто|Число
```

Устанавливает шаг изменения числа при использовании кнопкок регулирования значения.
