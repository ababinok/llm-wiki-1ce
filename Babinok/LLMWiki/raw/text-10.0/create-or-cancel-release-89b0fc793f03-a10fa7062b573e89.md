Когда ваш программный продукт прошел тестирование и готов к выпуску, вы можете указать стабильную сборку, содержащую все необходимые изменения, как релизную. Для этого выполните следующие шаги:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. Выполните одно из следующих действий:
  
  - Перейдите на вкладку **Релизы** и нажмите кнопку **+ Выпустить новый релиз**.
    
    На вкладке «Релизы» выделена кнопка «Выпустить новый релиз». [Описание иллюстрации](../figures/dd6c5bb1a7b302b9b74a3b83c7d0d590354da43712272fd73d86c11d665ecf72-e96ba82dcf02cb33.md)
  - На вкладке **Сборки** щелкните на значокПиктограмма «Значок меню». [Описание иллюстрации](../figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для нужной сборки и выберите пункт **Выпустить релиз** в выпадающем меню.
    
    В меню строки сборки выделен пункт «Выпустить релиз». [Описание иллюстрации](../figures/ee654601a428483b8e0f16dc90f8b255d96002250334c57561285eeb04dceeaa-f628d4d280d424e3.md)
  - На вкладке **Ветки** щелкните на значокПиктограмма «Значок меню». [Описание иллюстрации](../figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для релизной ветки и выберите пункт **Выпустить релиз** в выпадающем меню.
    
    
    
    Если для ветки обнаружатся незафиксированные изменения, «1С:Предприятие.Элемент» отобразит соответствующее предупреждение:
    
    Предупреждение о незафиксированных изменениях [Описание иллюстрации](../figures/9d29401655c20c941716a5590961d2b8d320f92f153925b3347a151e1ec9f967-76d59265b2b10804.md)
    
    Нажмите кнопку **Открыть**, чтобы перейти в среду разработки и [зафиксировать изменения](../../wiki/project/commit-changes-8ac78032ff13.md), либо щелкните **Продолжить**, чтобы проигнорировать наличие незафиксированных изменений и продолжить выпуск релиза.
4. В открывшемся окне заполните информацию о релизе:
  
  - Добавьте описание релиза. Если вы используете задачи при разработке, в этом поле автоматически будут перечислены выполненные и включенные в основную ветку задачи.
  - Укажите релизную ветку (вы можете выбрать существующую ветку или создать новую, если необходимо).
  
  Диалог выпуска релиза содержит описание релиза, релизную ветку, выбор действия с веткой и приложением; завершение — кнопка выпуска релиза. [Описание иллюстрации](../figures/f25d62c4afff627b2544e22488bdf72ad8a31a69b5099d48100f7ba6ecfd8d94-80cbda5d1c63ef2f.md)
  
  Версия релиза задается на основе версии сборки автоматически. Номер релиза не содержит суффикс сборки и не может быть изменен вручную — он всегда соответствует версии входящих в него сборок.
  
  Если вы вызываете диалог выпуска нового релиза из меню релизной ветки, для которой не существует сборки, вам будет предложено создать новую сборку из этой ветки:
  
  Создание новой сборки из релизной ветки [Описание иллюстрации](../figures/870a73ce27917b09ff7c5e6ef90c91a265e5173674774570a6518eb334e5c959-d125466d0bfe7e8a.md)
  
  Если вы выпускаете релиз, включающий в себя [библиотеки](../../wiki/project/create-library-project-7aaf759c2627.md) или [расширения](../../wiki/project/extension-overview-baac93654940.md), описание можно добавить для каждого элемента релиза.
  
  Добавление описаний релизов [Описание иллюстрации](../figures/ad4217deb3dc8425c350d13dd6e7e8a11352fb235fa8041e3b605cfcc351130c-275b6367fb54ff1a.md)
5. Нажмите **Выпустить релиз**, чтобы завершить операцию.

Новый релиз появится в общем списке всех релизов и станет доступен пользователям для создания, обновления и модификации приложений.

Новый релиз в списке релизов проекта [Описание иллюстрации](../figures/a17912760faf57441e238a03b2ab6a2a8636f968f97f067140baa43566699bbb-54d3d7839216c594.md)

Релиз группы проектов, содержащих [библиотеки](../../wiki/project/create-library-project-7aaf759c2627.md) или [расширения](../../wiki/project/extension-overview-baac93654940.md), включает в себя сборки разрабатываемых библиотек и расширений, а также соответствующих им тестовых приложений.



Все проекты группы публикуются из среды разработки одновременно, и каждому проекту присваивается один и тот же номер версии сборки. Для выпуска релиза необходимо выбрать исходную версию сборки, из которой будет выпущен релиз. В релиз войдут все проекты группы с этой версией.



Версия релиза соответствует версии, заданной в [свойствах проекта](../../wiki/project/projectdescriptor-d54722c348c7.md), и не может быть задана вручную.

Чтобы посмотреть статистику использования релиза и выгрузить сборки, входящие в релиз, кликните по нему на вкладке **Релизы**. Вам будет доступна следующая информация:

- количество созданных приложений (в данном проекте и других проектах пространства);
- количество проектов на основе проекта поставщика (за основу могут браться только релизные версии);
- количество использований в проектах приложений (для
  
  [библиотек](../../wiki/project/create-and-use-libraries-38193c200df0.md)
  
  ).

## Отозвать релиз

Если вы вдруг обнаружили, что релиз содержит критические ошибки, вы можете отозвать его одним из следующих способов:

1. На вкладке **Релизы** кликните на релиз, который вы хотите отозвать. Нажмите **Отозвать релиз** в появившемся окне.
  
  В карточке выбранного релиза выделена красная кнопка «Отозвать релиз». [Описание иллюстрации](../figures/443d764b65896cee04a7eafcfc75784ee23f74004146e04e6dfaffba1530b5c6-c5e69c2cdf0377b6.md)
2. Щелкните на значокПиктограмма «Значок меню». [Описание иллюстрации](../figures/487b1da26e1af58f9aa708d6940111bce83883528dec1a8ba9c84be4cf4bdcb1-7826430e32669bbb.md) для нужного релиза и выберите пункт **Отозвать** в выпадающем меню.
  
  Выбор пункта «Отозвать» в меню релиза [Описание иллюстрации](../figures/ae795418a2733ea4ec06eee0f2c3619b394fb3a4c5ec060068231e70b4699244-7f904b333e836dcb.md)
3. В открывшемся окне введите причину отзыва релиза, а также укажите рекомендуемые действия для текущих пользователей релиза. Например, вы можете посоветовать им откатиться на предыдущую версию либо дать рекомендации, как обойти найденные ошибки. Затем нажмите **Подтвердить отзыв релиза**.
  
  Диалог отзыва релиза содержит предупреждение, поле обязательной причины и рекомендуемых действий для пользователей; завершение — «Подтвердить отзыв релиза». [Описание иллюстрации](../figures/49f7dddf024fef639fe4034060d8ae98b174367e35fce225b679fff5407ca4dd-ba51ff2e45b6f4de.md)

В результате релиз будет отмечен как отозванный на вкладке **Релизы**, а пользователи релиза получат уведомления о его отзыве. После этого релиз перестанет быть доступен для использования. При этом пользовательские приложения, созданные на основе этого релиза, сохранятся.
