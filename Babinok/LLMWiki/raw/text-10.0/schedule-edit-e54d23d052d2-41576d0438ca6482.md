«1С:Предприятие.Элемент» предоставляет компоненты для редактирования расписания.

## Компонент интерфейса КомпонентРасписаний

Компонент интерфейса [`КомпонентРасписаний`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) служит для отображения расписания (массива объектов типа [Расписание](../../wiki/stdlib/schedule-ru-f8ef0f9119e6.md)) с возможностью его редактирования.

События компонента [`КомпонентРасписаний`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md):

- [`ПриИзменении: СобытиеСДанными<КлючИЗначение<Число, Расписание>>`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md)
  
  — возникает, когда расписание изменено;
- [`ПриДобавлении: СобытиеСДанными<Расписание>`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md)
  
  — возникает, когда расписание добавлено;
- [`ПриУдалении: СобытиеСДанными<КлючИЗначение<Число, Расписание>>`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md)
  
  — возникает, когда расписание удалено.

Для него доступны следующие методы:

- [`УстановитьРасписания(Расписания: ЧитаемыйМассив<Расписание>)`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md)
  
  — устанавливает массив расписаний в компоненте;
- [`УстановитьРазрешениеИзменения(РазрешеноИзменение: Булево)`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md)
  
  — устанавливает признак разрешения изменения расписаний.

А также свойство [`Заголовок`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md).

Вы можете добавить компонент [`КомпонентРасписаний`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) в форму с помощью среды разработки, а также создать его в коде:

Создание компонента КомпонентРасписаний

```xbsl
@НаКлиенте
метод СоздатьКомпонентЗадания(Ключ: Строка)
    // Получаем задание по ключу
    пер Задание = ПолучитьЗадание(Ключ)

    // Создаем и настраиваем компонент расписания
    пер КомпонентРасписания = новый КомпонентРасписаний(Заголовок = "Расписание задания " + Задание.Ключ)
    КомпонентРасписания.УстановитьРасписания(Задание.Расписания)
    КомпонентРасписания.УстановитьРазрешениеИзменения(Истина)

    // Добавляем компонент в форму
    Компоненты.Группа1.Содержимое.Очистить()
    Компоненты.Группа1.Содержимое.Добавить(КомпонентРасписания)
;
```

Созданный компонент [`КомпонентРасписаний`](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) будет отображаться на форме таким образом:

Пример компонента расписаний с заголовком «Расписание задания РекламнаяРассылка»: одна строка описана как «Еженедельно — по понедельникам в 10:00:00». [Описание иллюстрации](../figures/27e677eccc037b8365b9e05c410df4efbac1979a7dfb83d0cda8ded38a00bac2-37a5b912116c081c.md)

## Компонент интерфейса КомпонентРасписания

Компонент интерфейса [`КомпонентРасписания`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) служит для отображения одного объекта типа [Расписание](../../wiki/stdlib/schedule-ru-f8ef0f9119e6.md) с возможностью его редактирования.

Для него доступны следующие методы:

- [`УстановитьРасписание(Расписание: Расписание)`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md)
  
  — устанавливает расписание;
- [`УстановитьРазрешениеИзменения(РазрешеноИзменение: Булево)`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md)
  
  — устанавливает признак разрешения изменения расписания;
- [`РасписаниеВалидно()`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md)
  
  — проверяет правильность данных расписания, отображаемых в компоненте;
- [`ПолучитьВалидноеРасписание()`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md)
  
  — возвращает расписание, настроенное в соответствии с данными в элементах компонента.

Вы можете добавить компонент [`КомпонентРасписания`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) в форму с помощью среды разработки, а также создать его в коде:

Пример создания компонента КомпонентРасписания

```xbsl
метод СоздатьРасписание()
    // Создаем расписание
    пер Расписание = Расписание.Периодическое(60с)

    // Создаем и настраиваем компонент расписания
    пер РедакторРасписания = новый КомпонентРасписания()
    РедакторРасписания.УстановитьРасписание(Расписание)
    РедакторРасписания.УстановитьРазрешениеИзменения(Истина)
    
    // Добавляем компонент в форму
    Компоненты.Группа1.Содержимое.Очистить()
    Компоненты.Группа1.Содержимое.Добавить(РедакторРасписания)
;
```

Созданный компонент [`КомпонентРасписания`](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) будет отображаться на форме таким образом:

Форма компонента расписания содержит поля дней, часов, минут и секунд для периода, а также переключатели выполнения пропущенного и настройки диапазона. [Описание иллюстрации](../figures/2f8d6231d0d588406c1656745c6d7d12d1be9b0e4623d86ba904a5dc0f8e1633-f48d6473754c41fb.md)
