`Стд::БазаДанных::ОбластьВидимостиВременныхТаблиц` `Доступность: Сервер`

Контекст для управления областями видимости временных таблиц языка запросов. При выполнении запроса используется текущая (самая близкая к запросу) область видимости временных таблиц. Если области нет - с временными таблицами работать нельзя, если только это не пакетный запрос. Временная таблица созданная в одной области видимости не видна в другой области видимости.

**Сравнение**

Ссылочное

## Примеры

**Общие примеры**

```xbsl
знч Группа = "КорневаяГруппа"

// Новая пустая область видимости временных таблиц
исп ОбластьВидимостиВременныхТаблиц.Открыть()

// Времемнная таблица изначально заполненная только непосредственно присутствующими в группе подразделениями
Запрос{
    ВЫБРАТЬ
        Т.Ссылка КАК Подразделение
    ПОМЕСТИТЬ ПодразделенияВГруппе
    ИЗ
        Подразделения КАК Т
    ГДЕ
        Т.Родитель == %Группа
    ИНДЕКСИРОВАТЬ ПО
        Подразделение
}.Выполнить()

// Запрос добавления подразделений следующего уровня
знч Запрос = Запрос{
    ВСТАВИТЬ В ПодразделенияВГруппе (Подразделение)
    ВЫБРАТЬ
        НовыеПодразделения.Ссылка
    ИЗ
        Подразделения КАК НовыеПодразделения
            ВНУТРЕННЕЕ СОЕДИНЕНИЕ ПодразделенияВГруппе КАК Родители
            ПО НовыеПодразделения.Родитель == Родители.Подразделение
    ГДЕ
        НЕ СУЩЕСТВУЕТ
            (ВЫБРАТЬ
                1
            ИЗ
                ПодразделенияВГруппе КАК СтарыеПодразделения
            ГДЕ
                НовыеПодразделения.Ссылка == СтарыеПодразделения.Подразделение)
}

// Заполняем временную таблицу подразделениями
пока Запрос.Выполнить() != 0
    // Пустое тело цикла
;

// как-то используем заполненную временную таблицу
                    
```

## Методы

### Закрыть

`Доступность: Сервер`

```
Закрыть()
```

**Переопределение** [Закрываемое::Закрыть](../../wiki/stdlib/closeable-ru-67cd73fca69d.md)

---

### Открыть

`Доступность: Сервер` `Статический`

```
Открыть(Перекрывать: Булево = Истина): ОбластьВидимостиВременныхТаблиц
```

Создает новую область видимости временных таблиц. В зависимости от значения параметра

`Перекрывать`

уже созданные временные таблицы (если они есть) будут в ней доступны (

`Ложь`

) или нет (

`Истина`

).
