События, генерируемые «1С:Предприятие.Элементом», доступны только для чтения, программно зарегистрировать такие события нельзя. Как и все остальные события, события «1С:Предприятие.Элемента» расширяют базовый тип **СобытиеЖурналаСобытий**. Для каждого системного события есть свой тип в соответствующем пространстве имен.

## Стд::БазаДанных::События

### СобытиеПодтверждениеТранзакции

Тип: [`СобытиеПодтверждениеТранзакции`](../../wiki/data/transactioncommitevent-ru-58015ec5a219.md)

Вид: Информация

Событие записывается при успешном подтверждении транзакции.

### СобытиеОткатТранзакции

Тип: [`СобытиеОткатТранзакции`](../../wiki/data/transactionrollbackevent-ru-4b815f2b556e.md)

Вид: Информация

Событие записывается при неудачном завершении и отмене транзакции.

## Стд::Задания::События

### ОперацияЗапланированногоЗадания

Тип: [`ОперацияЗапланированногоЗадания`](../../wiki/stdlib/scheduledjoboperation-ru-faf09e9de4bd.md)

Вид: Операция

Операция, начало которой регистрируется вместе с началом выполнения запланированного задания. Конец операции регистрируется по окончанию выполнения запланированного задания. В случае возникновения ошибки при выполнении задания будет зарегистрирован конец операции с ошибкой.

### СобытиеЗапланированноеЗаданиеДобавленоПриОбновленииПроекта

Тип: [`СобытиеЗапланированноеЗаданиеДобавленоПриОбновленииПроекта`](../../wiki/stdlib/scheduledjobaddedonprojectupdateevent-ru-6f58d87c4537.md)

Вид: Информация

Событие записывается при добавлении нового запланированного задания при применении проекта. Заполняются следующие свойства:

- КлючЗадания
  
  — ключ добавленного задания;
- ЯвляетсяПредопределенным
  
  — флаг, который показывает, каким образом создано задание (из элемента проекта или на его основе);
- Причина
  
  — причина добавления задания.

### СобытиеЗапланированноеЗаданиеЗавершено

Тип: [`СобытиеЗапланированноеЗаданиеЗавершено`](../../wiki/stdlib/scheduledjobfinishevent-ru-ac31a93e1372.md)

Вид: Информация

Событие записывается при завершении запланированного задания. Запись в журнал событий производится в любом случае, независимо от результата выполнения задания.

### СобытиеЗапланированноеЗаданиеИзмененоПриОбновленииПроекта

Тип: [`СобытиеЗапланированноеЗаданиеИзмененоПриОбновленииПроекта`](../../wiki/stdlib/scheduledjobupdatedonprojectupdateevent-ru-c86940c67b77.md)

Вид: Информация

Событие записывается при изменении существующего запланированного задания при применении проекта. Заполняются следующие свойства:

- КлючЗадания
  
  — ключ изменившегося задания;
- ЯвляетсяПредопределенным
  
  — флаг, который показывает, каким образом создано задание (из элемента проекта или на его основе);
- Причина
  
  — причина изменения задания.

### СобытиеЗапланированноеЗаданиеУдаленоПриОбновленииПроекта

Тип: [`СобытиеЗапланированноеЗаданиеУдаленоПриОбновленииПроекта`](../../wiki/stdlib/scheduledjobdeletedonprojectupdateevent-ru-ba685f45f25f.md)

Вид: Информация

Событие записывается при удалении существующего запланированного задания при применении проекта. Заполняются следующие свойства:

- КлючЗадания
  
  — ключ удаленного задания;
- ЯвляетсяПредопределенным
  
  — флаг, который показывает, каким образом создано задание (из элемента проекта или на его основе);
- Причина
  
  — причина удаления задания.

### СобытиеЗапланированныеЗаданияВключены

Тип: [`СобытиеЗапланированныеЗаданияВключены`](../../wiki/stdlib/scheduledjobsenabledevent-ru-0fe16ee6deb8.md)

Вид: Информация

Событие, регистрируемое в начале работы сервиса запланированных заданий для приложения.

### СобытиеЗапланированныеЗаданияВыключены

Тип: [`СобытиеЗапланированныеЗаданияВыключены`](../../wiki/stdlib/scheduledjobsdisabledevent-ru-f61ee1a7291e.md)

Вид: Информация

Событие, регистрируемое по окончанию работы сервиса запланированных заданий для приложения.

## Стд::ИнтеграционнаяШина::События

### ОперацияВыполнениеПроцессаИнтеграции

Тип: [`ОперацияВыполнениеПроцессаИнтеграции`](../../wiki/integration/integrationprocessexecutionoperation-ru-1a618b997df9.md)

Вид: Операция

Операция, начало которой регистрируется в начале запуска процесса интеграции. Конец регистрируется при остановке процесса интеграции. В случае любой ошибки, возникшей при запуске или остановке, операция будет завершена с ошибкой.

### ОшибкаВалидацииСообщенияПроцессаИнтеграции

Тип: [`ОшибкаВалидацииСообщенияПроцессаИнтеграции`](../../wiki/integration/integrationprocessmessagevalidationerror-ru-6bc7d5ac3456.md)

Вид: Ошибка

Событие регистрируется при ошибке валидации сообщения, полученного в узле-источнике.

### ОшибкаВыполненияПроцессаИнтеграции

Тип: [`ОшибкаВыполненияПроцессаИнтеграции`](../../wiki/integration/integrationprocessexecutionerror-ru-b60ff9230728.md)

Вид: Ошибка

Событие регистрируется при любой ошибке, возникающей при доставке сообщения процессом интеграции. Если ошибка связана с определенным узлом процесса, имя этого узла будет записано в свойстве **Узел**. Если ошибка связана с определенным маршрутом процесса, имя этого маршрута будет записано в свойстве **Маршрут**.

### ОшибкаВычисленияСвойстваУзлаПроцессаИнтеграции

Тип: [`ОшибкаВычисленияСвойстваУзлаПроцессаИнтеграции`](../../wiki/integration/integrationprocessnodepropertycalculationerror-ru-64852aaac4df.md)

Вид: Ошибка

Событие регистрируется при ошибке вычисления свойства узла, связанного с участником.

### ОшибкаЗапускаПроцессаИнтеграции

Тип: [`ОшибкаЗапускаПроцессаИнтеграции`](../../wiki/integration/integrationprocessstarterror-ru-0c6bcd9e1b13.md)

Вид: Ошибка

Событие будет зарегистрировано при любой ошибке, возникшей в ходе запуска процесса интеграции.

### ОшибкаОстановкиПроцессаИнтеграции

Тип: [`ОшибкаОстановкиПроцессаИнтеграции`](../../wiki/integration/integrationprocessstoperror-ru-42f755f2a271.md)

Вид: Ошибка

Событие будет зарегистрировано при любой ошибке, возникшей в ходе остановки процесса интеграции.

### СобытиеДоставленноеСообщениеОтправлено

Тип: [`СобытиеДоставленноеСообщениеОтправлено`](../../wiki/integration/deliveredmessagesentevent-ru-381a87c3e8bb.md)

Вид: Информация

Событие, регистрируемое при отправке доставленного сообщения в узел процесса интеграции.

### СобытиеНедоставленноеСообщениеОтправлено

Тип: [`СобытиеНедоставленноеСообщениеОтправлено`](../../wiki/integration/undeliveredmessagesentevent-ru-de75a337f804.md)

Вид: Информация

Событие, регистрируемое при отправке недоставленного сообщения в узел процесса интеграции.

### СобытиеПараметрПроцессаИнтеграцииИзменен

Тип: [`СобытиеПараметрПроцессаИнтеграцииИзменен`](../../wiki/integration/integrationprocessparameterchangedevent-ru-bd7472ad0841.md)

Вид: Информация

Событие регистрируется при обновлении значения параметра процесса интеграции.

### СобытиеПроцессИнтеграцииЗапущен

Тип: [`СобытиеПроцессИнтеграцииЗапущен`](../../wiki/integration/integrationprocessstartedevent-ru-abb1686affb3.md)

Вид: Информация

Событие, регистрируемое сразу после успешного запуска процесса.

### СобытиеПроцессИнтеграцииОстановлен

Тип: [`СобытиеПроцессИнтеграцииОстановлен`](../../wiki/integration/integrationprocessstoppedevent-ru-5b1f1d2c4411.md)

Вид: Информация

Событие, регистрируемое сразу после успешной остановки процесса.

### СобытиеСообщениеПроцессаИнтеграцииДоставлено

Тип: [`СобытиеСообщениеПроцессаИнтеграцииДоставлено`](../../wiki/integration/integrationprocessmessagedeliveredevent-ru-fecf06232736.md)

Вид: Информация

Событие регистрируется при доставке сообщения в узел-назначение процесса интеграции. Событие будет зарегистрировано только в том случае, если свойство процесса интеграции **РегистрироватьДоставкуВЖурналеСобытий** равно **Истина**. По умолчанию данное свойство имеет значение **Ложь**.

## Стд::Сущности::УдалениеДанных::События

### ОперацияУдаленияДанных

Вид: информация

Событие регистрируется при старте и завершении операции удаления данных.

### СобытиеДействиеПриУдаленииОбъектаПоСсылке

Вид: информация

Событие регистрируется, когда объект меняется по причине автоматического разрешения конфликтов, связанных со ссылками на удаляемые объекты (путем очистки поля или удаления связанного объекта).

### ОшибкаДействияПриУдаленииОбъектаПоСсылке

Вид: ошибка

Событие регистрируется, если при автоматическом разрешении конфликтов, связанных со ссылками на удаляемые объекты, произошла ошибка.

### ОшибкаУдаленияОбъекта

Вид: ошибка

Событие регистрируется при ошибке удаления объекта.
