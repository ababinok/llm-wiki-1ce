#### Путь

`Версия 10.0 и выше`

```yaml
Путь: Строка
```

Задает путь публикации данного приложения ([подробнее](../../wiki/interface/selecting-interface-at-application-startup-8bfc6b427dba.md)). Должен содержать один сегмент пути или пустую строку. Не должен содержать следующие зарезервированные пути:

- api,
- stdapi,
- sys,
- ui.

Если содержит пустую строку, то входом в приложение является точка публикации проекта. Если путь указан, то входом в приложение является путь публикации проекта плюс данный путь.

#### РежимАутентификации

`Версия 10.0 и выше`

```yaml
РежимАутентификации: ВычисляемоеВыражение|Аутентифицированный|НеАутентифицированный
```

Определяет необходимость аутентификации пользователя при входе в приложение:

- Аутентифицированный
  
  — пользователь будет автоматически перенаправлен на страницу аутентификации;
- НеАутентифицированный
  
  — может работать анонимный пользователь.

По умолчанию это свойство имеет значение **Аутентифицированный**, но вы можете установить его в значение **НеАутентифицированный**, и тогда пользователь не будет перенаправлен на страницу аутентификации при входе в приложение. Такого пользователя не будет в списке подключенных пользователей, и [ТекущийПользователь](../../wiki/stdlib/users-ru-f417ba72157b.md) будет возвращать `Неопределено`.

Итоговый цвет гиперссылки определяется исходя из значений свойств [Цвет](../../wiki/interface/label-ru-7b686f06261a.md), [Важность](../../wiki/interface/label-ru-7b686f06261a.md) и [ОценкаИнформации](../../wiki/interface/label-ru-7b686f06261a.md), а также значения **Авто**. ##### Логотип

Логотип приложения. Отображается в свернутом меню при вертикальной навигации, а также в развернутом меню вместе с названием приложения, если не задан крупный логотип.

В мобильной версии приложения логотипы не отображаются.

##### ЛоготипКрупный

Крупная версия логотипа приложения. Отображается в развернутом меню при вертикальной навигации.

В мобильной версии приложения логотипы не отображаются.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### ПараметрыКаноническогоUrl

```yaml
ПараметрыКаноническогоUrl: Авто|Массив<Строка>
```

Указывает, какие дополнительные параметры URL (при их наличии) необходимо использовать при составлении *канонической ссылки*. Данная ссылка будет использоваться поисковыми системам, чтобы определить, какую версию страницы считать основной среди одинаковых или похожих страниц. Это позволит избежать проблем с индексацией и улучшить качество поиска ([подробнее](../../wiki/project/seo-optimization-27876869518e.md)).

Параметры URL чувствительны к регистру.

При **Авто** все дополнительные параметры отбрасываются.

Независимо от значения свойства, для приложения, унаследованного от типа [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standardclientapplicationwithsections-ru-2bf3e285c484.md), в каноническую ссылку включаются параметры **state** и **navLink** (при их наличии). Если приложение унаследовано от [ПроизвольноеКлиентскоеПриложение](../../wiki/interface/customclientapplication-ru-4315de55a773.md), то в каноническую ссылку включается параметр *state* (также при наличии).

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
