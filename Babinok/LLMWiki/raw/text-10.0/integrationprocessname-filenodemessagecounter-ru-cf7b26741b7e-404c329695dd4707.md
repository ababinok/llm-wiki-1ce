`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПроцессаИнтеграции}.СчетчикСообщенийФайловыхУзлов` `Доступность: Сервер`

Предопределенная метрика-счетчик сообщений в файловых узлах. Содержит один параметр: имя узла, в котором увеличилась метрика.

При перезапуске процесса значение метрики НЕ обнуляется.

### ПолучитьИсториюИзмерений

`Доступность: Сервер`

```

  До: Момент
```

Возвращает массив измерений счетчика сообщений в файловых узлах в указанном временном диапазоне. Элементы массива отсортированы по возрастанию значения момента измерения
