Позволяет прочитать информацию об отозванных сертификатах.

## Конструкторы

### СписокОтозванныхСертификатов

`Доступность: Сервер`

```
СписокОтозванныхСертификатов(Данные: Байты|ПотокЧтения)
```

Загружает список отозванных сертификатов из байт/потока.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - если не удалось прочитать данные.

**Перегрузка** [СписокОтозванныхСертификатов(Файл: Файл|Строка)](../../wiki/stdlib/certificaterevocationlist-ru-4fca5fdd32d3.md)

---

### СписокОтозванныхСертификатов

`Доступность: Сервер`

```
СписокОтозванныхСертификатов(Файл: Файл|Строка)
```

Загружает список отозванных сертификатов из файла.

#### Исключения

**[ИсключениеКриптографии](../../wiki/stdlib/cryptoexception-ru-9269fbee8009.md)** - если не удалось прочитать данные. **[ИсключениеРазрешениеОтсутствует](../../wiki/security/nopermissionexception-ru-1f930860881b.md)** - при отсутствии прав на чтение файла по указанному пути

**Перегрузка** [СписокОтозванныхСертификатов(Данные: Байты|ПотокЧтения)](../../wiki/stdlib/certificaterevocationlist-ru-4fca5fdd32d3.md)

## Свойства

`Доступность: Сервер` `ТолькоЧтение`

```
ДействителенС: Момент
```

Дата выпуска списка отзыва.

---

### Издатель

`Доступность: Сервер` `ТолькоЧтение`

```
Издатель: Строка
```

Наименование издателя в формате RFC 2253 (CN, L, ST, O, OU, C, STREET, DC, UID).

---

### СледующееОбновление

`Доступность: Сервер` `ТолькоЧтение`


Дата выпуска следующего списка отзыва, если указана.

## Методы

### ВБайты

`Доступность: Сервер`

```
ВБайты(): Байты
```

Записывает список отозванных сертификатов в массив байт в ASN.1 DER кодировке.

---

### ЗаписатьВПоток

`Доступность: Сервер`

```
ЗаписатьВПоток(Поток: ПотокЗаписи)
```

Записывает список отозванных сертификатов в поток в ASN.1 DER кодировке.

---

### ЗаписатьВФайл

`Доступность: Сервер`

```
ЗаписатьВФайл(Файл: Файл|Строка)
```

Записывает список отозванных сертификатов в файл в ASN.1 DER кодировке.

#### Исключения

**[ИсключениеВводаВывода](../../wiki/stdlib/inputoutputexception-ru-ceba5f672999.md)** - при ошибке записи файла. **[ИсключениеРазрешениеОтсутствует](../../wiki/security/nopermissionexception-ru-1f930860881b.md)** - при отсутствии прав на запись файла по указанному пути.

---

### ПолучитьОтозванныеСертификаты

`Доступность: Сервер`

```
ПолучитьОтозванныеСертификаты(): ЧитаемыйМассив<ОтозванныйСертификат>
```

Возвращает список отозванных сертификатов.

---

### ПолучитьОтозванныйСертификат

`Доступность: Сервер`

```
ПолучитьОтозванныйСертификат(Сертификат: Байты|ЦифровойСертификат): ОтозванныйСертификат?
```

Выполняет поиск информации об отзыве по сертификату / серийному номеру.

---

### ПроверитьПодпись

`Доступность: Сервер`

```
ПроверитьПодпись(СертификатИздателя: ЦифровойСертификат): Булево
```

Проверяет подпись списка отозванных сертификатов с помощью сертификата открытого ключа издателя.
