`Стд::Геолокация::ГеографическиеКоординаты` `Доступность: КлиентИСервер`

Описывает географические координаты местоположения объекта.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Общие примеры**

```xbsl
пер Координаты = новый ГеографическиеКоординаты(37, 56, 10)
пер Широта = Координаты.Широта    // 37
пер Долгота = Координаты.Долгота  // 56
пер Высота = Координаты.Высота    // 10
Сообщить("Широта: %Широта, Долгота: %Долгота, Высота: %Высота")
```

---

## Конструкторы

### ГеографическиеКоординаты

`Доступность: КлиентИСервер`

```
ГеографическиеКоординаты(
  Широта: Число,
  Долгота: Число,
  Высота: Число?)
```

Создает объект

[ГеографическиеКоординаты](../../wiki/stdlib/geographiccoordinates-ru-cb1b92a0d0c9.md)

на основании указанных значений широты, долготы и высоты над уровнем моря.
