HTTP — это протокол передачи данных в Интернете, который используется для обмена информацией между клиентом и сервером.

## Алгоритм работы протокола HTTP

Основные принципы работы HTTP:

1. Клиент формирует и отправляет запрос серверу.
2. Сервер обрабатывает запрос и возвращает ответ.
3. Клиент получает ответ, соединение закрывается.
