Представление данных в виде иерархического списка — это способ организации информации, при котором каждый элемент списка может иметь вложенные элементы, которые также могут иметь подэлементы и так далее. Такая структура данных позволяет легко организовывать и находить информацию, а также упрощает ее представление и понимание.

Например, в [демо-приложении](../../wiki/project/demo-app-3768685a4428.md) иерархический список используется для справочника **Бизнес-регионы**:

Иерархический справочник «Бизнес-регионы» в демоприложении: список регионов с колонками названия, кода страны и кода города; доступны поиск и создание. [Описание иллюстрации](../figures/4c5c548699ac621e8a765e7a35b12be1f8cc3d23b258ef229faa3d198225f2d2-b0fa5fd9e380d38c.md)

## Источник данных для иерархических структур

Для описания структуры иерархии используются объекты типов, описанных в пространстве имен [`Стд::Интерфейс::ИсточникиДанных::Дерево`](../../wiki/interface/tree-97072a88f5cc.md).

Чтобы создать иерархическую структуру, необходимо заполнить объект типа [`ИсточникДанныхДерево`](../../wiki/interface/treedatasource-ru-367f34c33419.md) нужными элементами — узлами типа [`УзелДерева`](../../wiki/interface/treenode-ru-b50ba8aea683.md) со свойством [`ДочерниеЭлементы`](../../wiki/interface/treenode-ru-b50ba8aea683.md) — и использовать его в качестве источника данных списка, таблицы, органиграммы или диаграммы Ганта.

Для динамической загрузки иерархической структуры можно использовать тип [`ИсточникДанныхДеревоПодгружаемый`](../../wiki/interface/loadabletreedatasource-ru-feb2e5334aa8.md). Он работает так же, как и [`ИсточникДанныхДерево`](../../wiki/interface/treedatasource-ru-367f34c33419.md), но имеет дополнительное событие [`ПриЗаполненииДочернихЭлементов`](../../wiki/interface/loadabletreedatasource-ru-feb2e5334aa8.md), в котором реализуется логика загрузки дочерних элементов для заданного узла дерева. Система вызывает это событие автоматически. Элементами иерархической структуры типа [`ИсточникДанныхДеревоПодгружаемый`](../../wiki/interface/loadabletreedatasource-ru-feb2e5334aa8.md) являются структуры типа [`УзелДереваПодгружаемый`](../../wiki/interface/loadabletreenode-ru-ee20b1cb5057.md).

Для типов [`ИсточникДанныхДерево`](../../wiki/interface/treedatasource-ru-367f34c33419.md) и [`ИсточникДанныхДеревоПодгружаемый`](../../wiki/interface/loadabletreedatasource-ru-feb2e5334aa8.md) указываются следующие параметры:

- параметр
  
  `ТипДанныхУзлов`
  
  задает тип данных дочерних элементов, являющихся узлами дерева;
- параметр
  
  `ТипДанныхЭлементов`
  
  задает тип данных элементов, не имеющих дочерних элементов.

Если элемент может быть как узлом, так и крайним элементом, то его нужно указать в обоих параметрах.

Если вам необходимо создать структуру с элементами, которые содержат собственные данные, используйте типы [`УзелДереваСДанными`](../../wiki/interface/treenodewithdata-ru-c4d692cff100.md) и [`УзелДереваСДаннымиПодгружаемый`](../../wiki/interface/loadabletreenodewithdata-ru-99f8911a6722.md). Данные, связанные с элементом, помещаются в свойство [`Данные`](../../wiki/interface/loadabletreenodewithdata-ru-99f8911a6722.md), а иерархическая структура реализуется с помощью свойства [`ДочерниеЭлементы`](../../wiki/interface/loadabletreenodewithdata-ru-99f8911a6722.md).

## Отображение иерархий в списках и таблицах

«1С:Предприятие.Элемент» поддерживает отображение иерархий для списков и таблиц. Для работы со строками в иерархических структурах используются следующие свойства типа [`Список`](../../wiki/interface/list-ru-58c40755a735.md):

- [`ПредставлениеГрупповойСтроки`](../../wiki/interface/list-ru-58c40755a735.md)
  
  ― задает представление строк, являющихся группами в иерархических источниках данных;
- [`КомандыСтрокиГруппы`](../../wiki/interface/list-ru-58c40755a735.md)
  
  ― команды, доступные для групповой строки;
- [`ОтметитьВсеВГруппе`](../../wiki/interface/list-ru-58c40755a735.md)
  
  ― отмечает все элементы внутри группы;
- [`ОтмечатьГруппыСДочерними`](../../wiki/interface/list-ru-58c40755a735.md)
  
  ― отмечает группу со всеми дочерними элементами.

С помощью метода [`ДобавитьСтрокуВГруппу()`](../../wiki/interface/list-ru-58c40755a735.md) типа [`Список`](../../wiki/interface/list-ru-58c40755a735.md) можно получить команду или группу команд добавления новой записи.

### Сворачивание и разворачивание узлов иерархического списка

С помощью свойства **НачальныйУровеньРазворачивания** типа `Авто|Число` компонента **Список** вы можете установить начальное отображение дерева относительно корня. `Авто` интерпретируется как `0`. Значение `-1` рекурсивно разворачивает все дочерние узлы. При раскрытии узла типа `УзелДереваСДаннымиПодгружаемый` для него инициируется событие `ПриЗаполненииДочернихЭлементов`.

Используйте следующие методы, чтобы свернуть или развернуть узлы в иерархическом списке:

- `Развернуть(ИдУзла: ТипИсточника.ТипДанныхУзлов | Неопределено, УровеньРазворачивания: Число): ничто` — инициирует разворачивание узла типа [`УзелДереваСДанными`](../../wiki/interface/treenodewithdata-ru-c4d692cff100.md) или [`УзелДереваСДаннымиПодгружаемый`](../../wiki/interface/loadabletreenodewithdata-ru-99f8911a6722.md).
  
  Если `ИдУзла = Неопределено`, то разворачивание выполняется от корня с учетом аргумента `УровеньРазворачивания`.
  
  Если `ИдУзла` — `УзелДереваСДаннымиПодгружаемый`, то инициируется событие `ПриЗаполненииДочернихЭлементов`, которое рекурсивно вызывается для каждого вложенного узла типа `УзелДереваСДаннымиПодгружаемый`, если аргумент `УровеньРазворачивания` подразумевает их разворачивание.
  
  Если `УровеньРазворачивания = -1`, то рекурсивно разворачиваются все дочерние узлы.
  
  В мобильной версии метод игнорируется.
- `Свернуть(ИдУзла: ТипИсточника.ТипДанныхУзлов?, УровеньСворачивания: Число): ничто` — инициирует сворачивание узла типа [`УзелДереваСДанными`](../../wiki/interface/treenodewithdata-ru-c4d692cff100.md) или [`УзелДереваСДаннымиПодгружаемый`](../../wiki/interface/loadabletreenodewithdata-ru-99f8911a6722.md).
  
  Если `ИдУзла = Неопределено`, то сворачивание выполняется от корня с учетом аргумента `УровеньСворачивания`.
  
  Если аргумент `УровеньСворачивания = -1`, то рекурсивно сворачиваются все дочерние узлы.
  
  В мобильной версии метод игнорируется.
- `ПерейтиВУзел(ИдУзла: ТипИсточника.ТипДанныхУзлов?, АвтоВыделениеСтроки: АвтоВыделениеСтроки? = Неопределено): ничто` — переходит (разворачивает и осуществляет навигацию) к узлу `ИдУзла`.
  
  Если это узел типа `УзелДереваСДаннымиПодгружаемый`, который ранее не был подгружен, то метод игнорируется.
  
  Если `ИдУзла = Неопределено`, то осуществляется переход в корень дерева.
  
  Аргумент `АвтоВыделениеСтроки` работает, только если компонент использует режим выделения строк. Значение интерпретируется следующим образом:
  
  - если
    
    `Неопределено`
    
    , используется значение свойства
    
    АвтоВыделениеСтроки
    
    компонента;
  - если
    
    `АвтоВыделениеСтроки = ВыделятьПервый`
    
    , то выделяется первый элемент в переданном узле.

## Пример создания иерархического списка

В этом примере мы создадим иерархический список задач из справочника **Задачи**. Справочник **Задачи** содержит наименование, код и описание задачи в соответствующих реквизитах. Кроме того, для каждой задачи можно создать несколько подзадач, связав их с родительской задачей с помощью свойства **Родитель**.

Справочник задач [Описание иллюстрации](../figures/ee1b16546a8e76e81a347e9f7cc51b169c79335034826647b326120d1b1f60cf-7af73f6efbf0872d.md)

В качестве источника данных списка будем использовать `ИсточникДанныхДерево` с элементами типа `УзелДереваСДанными`.

1. [Создайте справочник](../../wiki/data/add-catalog-e9262e40ce1d.md) **Задачи**. К автоматически созданным реквизитам **Наименование** и **Код** добавьте следующие реквизиты:
  
  - Родитель
    
    типа
    
    `Задачи.Ссылка?`
    
    , который содержит ссылку на родительскую задачу;
  - Описание
    
    типа
    
    `Строка`
    
    , который содержит описание задачи.
  
  Описание справочника в yaml-файле будет выглядеть так:
  
  ```yaml
  ВидЭлемента: Справочник
  Ид: a0976a95-5b11-420f-a41a-5f3601d5ee5a
  Имя: Задачи
  ОбластьВидимости: ВПодсистеме
  Реквизиты:
      -
          Имя: Наименование
      -
          Имя: Код
      -
          Ид: dd1b427f-1be5-4117-9223-9c8bb904400d
          Имя: Родитель
          Тип: Задачи.Ссылка?
      -
          Ид: 42946a85-e6b4-49bb-bf07-01ec7e1c8e23
          Имя: Описание
          Тип: Строка
  ```
2. [Создайте форму](../../wiki/interface/create-custom-form-5f06351aa37a.md) с именем **ФормаИерархическогоСписка**, в которой будет отображаться иерархический список.
3. Чтобы данный пример отобразился в интерфейсе приложения, добавьте в проект компонент интерфейса **СтандартноеКлиентскоеПриложениеСРазделами**, как показано ниже:
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 5063782a-a7c5-4ecf-a4f1-2af9eeb5c1ab
  Имя: МоеСтандартноеКлиентскоеПриложениеСРазделами
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: СтандартноеКлиентскоеПриложениеСРазделами
      КомандныйИнтерфейсПанелиНавигации:
          Тип: ФрагментКомандногоИнтерфейса<Команда>
          Элементы:
              -
                  Тип: НавигационнаяКоманда
                  Представление: Задачи
                  ТипФормы: Задачи.АвтоматическаяФормаСписка
              -
                  Тип: НавигационнаяКоманда
                  Представление: Список задач тестирования
                  ТипФормы: ФормаИерархическогоСписка # Имя формы для отображения
  ```
4. В модуль формы **ФормаИерархическогоСписка** добавьте описание структуры **СтруктураЗадачи**, которая будет использоваться для представления данных из справочника **Задачи**:
  
  Модуль формы «ФормаИерархическогоСписка»
  
  ```xbsl
  @ВПроекте
  @НаСервере
  @НаКлиенте
  структура СтруктураЗадачи
      обз знч Наименование: Строка
      знч Описание: Строка
      знч Подзадачи: Массив<СтруктураЗадачи>
  ;
  ```
5. В форму **ФормаИерархическогоСписка** добавьте компонент `ПроизвольныйШаблонФормы`:
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: b0bcbd4b-0c94-4bab-9d5f-4086d0a38b8c
  Имя: ФормаИерархическогоСписка
  ОбластьВидимости: ВПодсистеме
  Наследует:
      Тип: Форма
      Заголовок: Список задач тестирования
      Содержимое:
          Тип: ПроизвольныйШаблонФормы
  ```
6. [Добавьте компонент](../../wiki/interface/list-with-details-group-component-5a6bc6a119e6.md) `ГруппаСписокСДеталями` с именем **ГруппаЗадач**. Он позволит разделить форму на две части: слева будет отображаться иерархический список задач, а справа — название и описание выбранной задачи.
  
  В качестве типа источника укажите `ИсточникДанныхДерево`, у которого `ТипДанныхУзлов` и `ТипДанныхЭлементов` — `УзелДереваСДанными` с типом данных `СтруктураЗадачи?`.
  
  ```yaml
  Тип: ГруппаСписокСДеталями<ИсточникДанныхДерево<УзелДереваСДанными<ФормаИерархическогоСписка.СтруктураЗадачи?>, УзелДереваСДанными<ФормаИерархическогоСписка.СтруктураЗадачи?>>>
  Имя: ГруппаЗадач
  ```
7. В основное содержимое группы добавьте группу, в которую добавьте [стандартный список](../../wiki/interface/standardlist-ru-1010f63ab92e.md) с именем **ИерархическийСписокЗадач**. Включите такие свойства, как `ИспользоватьВыделениеСтроки` и `РастягиватьПоГоризонтали`. Значение строки получается с помощью метода `ПолучитьНаименованиеЗадачи()`, в который передаются `ДанныеСтроки`.
  
  ```yaml
  СодержимоеОсновное:
      Тип: Группа
      Компоновка: Вертикальная
      Имя: ГруппаОсновногоСодержимого
      Содержимое:
          -
              Тип: СтандартныйСписок<ИсточникДанныхДерево<УзелДереваСДанными<ФормаИерархическогоСписка.СтруктураЗадачи?>, УзелДереваСДанными<ФормаИерархическогоСписка.СтруктураЗадачи?, ФормаИерархическогоСписка.СтруктураЗадачи>>>
              Имя: ИерархическийСписокЗадач
              ЗначениеСтроки: =ПолучитьНаименованиеЗадачи(ДанныеСтроки)
              ИспользоватьВыделениеСтроки: Истина
              РастягиватьПоГоризонтали: Истина
  ```
8. В качестве компонента списка выберите **ВычисляемоеВыражение**, в котором укажите только что добавленный список **ИерархическийСписокЗадач**:
  
  ```yaml
  КомпонентСписка: =Компоненты.ИерархическийСписокЗадач
  ```
9. Добавьте детали содержимого:
  
  - Создайте группу, заголовок которой получается с помощью метода
    
    ПолучитьНаименованиеЗадачи()
    
    .
  - Добавьте
    
    [надпись](../../wiki/interface/label-component-975bcb38121f.md)
    
    ОписаниеЗадачи
    
    , в которой будет отображаться описание задачи, получаемое с помощью метода
    
    ПолучитьОписаниеЗадачи()
    
    .
  
  ```yaml
  СодержимоеДетали:
      Тип: Группа
      Имя: ГруппаСодержимогоЗадачи
      Заголовок: =ПолучитьНаименованиеЗадачи(ДанныеСтроки)
      Содержимое:
          -
              Тип: Надпись
              Имя: ОписаниеЗадачи
              Значение: =ПолучитьОписаниеЗадачи(ДанныеСтроки)
  ```
10. В модуле формы **ФормаИерархическогоСписка** опишите методы для получения значений строк списка:
  
  Модуль формы «ФормаИерархическогоСписка»
  
  ```xbsl
  // Метод возвращает наименование задачи
  метод ПолучитьНаименованиеЗадачи(ДанныеСтроки: УзелДереваСДанными<СтруктураЗадачи?>): Строка
      возврат ДанныеСтроки.Данные.Наименование
  ;
  
  // Метод возвращает описание задачи
  метод ПолучитьОписаниеЗадачи(ДанныеСтроки: УзелДереваСДанными<СтруктураЗадачи?>): Строка
      возврат ДанныеСтроки.Данные.Описание
  ;
  ```
11. Добавьте обработчик `ПослеСоздания`. В нем с помощью метода **ПрочитатьЗадачи()** создается список задач, организованный как иерархическая структура:
  
  Модуль формы «ФормаИерархическогоСписка»
  
  ```xbsl
  @Обработчик
  метод ПослеСоздания()
      пер МассивЗадач = ПрочитатьЗадачи()
      Компоненты.ИерархическийСписокЗадач.Источник.Данные.ДобавитьВсе(МассивЗадач)
  ;
  
  @НаСервере @ДоступноСКлиента
  статический метод ПрочитатьЗадачи(): Массив<УзелДереваСДанными<СтруктураЗадачи?>>
      пер Запрос = Запрос{
          ВЫБРАТЬ
              Задачи.Ссылка КАК Ссылка,
              Задачи.Родитель КАК Родитель,
              Задачи.Наименование КАК Наименование,
              Задачи.Описание КАК Описание
          ИЗ
              Задачи КАК Задачи
          УПОРЯДОЧИТЬ ПО
              Задачи.Наименование
      }
  
      пер Результат = <УзелДереваСДанными<СтруктураЗадачи?>>[]
  
      пер ЗадачиПоРодителю = <Задачи.Ссылка, УзелДереваСДанными<СтруктураЗадачи?>>{:}
      пер Задачи = Запрос.Выполнить().ВМассив()
      для Задача из Задачи
          пер ЗадачаПоРодителю = новый УзелДереваСДанными<СтруктураЗадачи?>()
          ЗадачаПоРодителю.Данные = новый СтруктураЗадачи(
              Наименование = Задача.Наименование,
              Описание = Задача.Описание)
          ЗадачиПоРодителю.Вставить(Задача.Ссылка, ЗадачаПоРодителю)
      ;
  
      для Задача из Задачи
          пер Элемент = ЗадачиПоРодителю.Получить(Задача.Ссылка)
  ```
