## Создание нового приложения

Перед созданием нового приложения вам необходимо [получить код активации](../../wiki/data/activation-code-c4e495e5df75.md).

Для создания нового приложения используйте метод [`УправлениеПриложениямиВзаимодействия.СоздатьПриложениеВзаимодействия()`](../../wiki/integration/collaborationapplicationsmanagement-ru-437d8f88f8c5.md). Укажите следующие параметры:

- **КлючиПриложенияВзаимодействия**
  
  Экземпляр типа [`КлючиПриложенияВзаимодействия`](../../wiki/integration/collaborationapplicationkeys-ru-33a523f67fc7.md), который хранит открытый и закрытый ключ создаваемого приложения.
  
  Ключи могут быть сгенерированы «1С:Предприятие.Элементом» автоматически при конструировании экземпляра типа `КлючиПриложенияВзаимодействия`:
  
  ```xbsl
  метод СоздатьКлючАвтоматически()
      пер Ключи = новый КлючиПриложенияВзаимодействия()
  ;
  ```
  
  Также вы можете генерировать ключи внешними утилитами, например ***keytool***.
  
  Можно создать экземпляр `КлючиПриложенияВзаимодействия` с передачей в параметры конструктора ключей шифрования:
  
  ```xbsl
  метод СоздатьКлючи(ОткрытыйКлюч: Байты, ЗакрытыйКлюч: Байты)
      пер Ключи = новый КлючиПриложенияВзаимодействия(ОткрытыйКлюч, ЗакрытыйКлюч)
      // ...
  ;
  ```
  
  Здесь `ОткрытыйКлюч` и `ЗакрытыйКлюч` — это пара ключей в формате:
  
  - массива байтов;
  - строк в формате Base64.
- **ИдПользователяПриложения**
  
  [`Ууид`](../../wiki/stdlib/uuid-ru-4831970f1083.md). Идентификатор пользователя приложения.
- **ИмяПользователяПриложения**
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md). Краткое имя пользователя приложения.
- **ПолноеИмяПользователяПриложения**
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md). Полное имя пользователя приложения.
- **КодАктивации**
  
  [Заранее полученный](../../wiki/data/activation-code-c4e495e5df75.md) от сервера системы взаимодействия код для регистрации приложения.
- **ПочтаАбонента**
  
  Адрес электронной почты пользователя, создающего приложение.
- **ИмяПриложения**
  
  Имя приложения.
- **Сервер**
  
  Адрес сервера взаимодействия.
- **ПараметрыСоединения**
  
  Параметры защищенного соединения.
- **Таймаут**
  
  Предельное время выполнения запроса к системе взаимодействия.

После вызова метода [`УправлениеПриложениямиВзаимодействия.СоздатьПриложениеВзаимодействия()`](../../wiki/integration/collaborationapplicationsmanagement-ru-437d8f88f8c5.md) сервер системы взаимодействия вернет набор реквизитов зарегистрированного приложения в экземпляре типа [`ПараметрыПриложенияВзаимодействия`](../../wiki/integration/collaborationapplicationparameters-ru-d3bb319bd7cc.md). Их нужно сохранить для дальнейшего использования:

- [`ИдПриложения`](../../wiki/integration/collaborationapplicationparameters-ru-d3bb319bd7cc.md)
  
  — идентификатор приложения на сервере системы взаимодействия типа
  
  [`Ууид`](../../wiki/stdlib/uuid-ru-4831970f1083.md)
  
  ;
- [`ОткрытыйКлюч`](../../wiki/integration/collaborationapplicationparameters-ru-d3bb319bd7cc.md)
  
  — открытый ключ системы взаимодействия типа
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  .

Все параметры можно сохранить как строки любым доступным способом (в зависимости от дальнейшего использования).

## Получение кода активации и регистрация приложения в «1С:Диалог»

Регистрация и отмена регистрации в системе взаимодействия выполняется с помощью встроенной формы [управление системой взаимодействия](../../wiki/integration/register-application-in-collaboration-system-4a6e06152ce5.md), а также через прикладной код.

```xbsl
метод ЗарегистрироватьПриложениеВ1СДиалог()
    знч ПочтаАбонента = "admin@company.ru"

    // Получение кода активации на электронную почту.
    УправлениеПриложениямиВзаимодействия.ЗапроситьКодАктивации(ПочтаАбонента)

    знч КодАктивации = "КодИзПочты"

    // Регистрация приложения в системе взаимодействия.
    СистемаВзаимодействия.ЗарегистрироватьПриложение(
                            ПочтаАбонента = ПочтаАбонента,
                            ИмяПриложения = "Приложение для торговли",
                            КодАктивации = КодАктивации)
;
```

## Установка данных регистрации приложения в системе взаимодействия вручную

Данный способ предназначен для миграции приложения или восстановления данных подключения из резервной копии.

```xbsl
метод УстановитьДанныеРегистрации()
    // В примере используется публичный сервис «1С:Диалог».

    // Известные данные.
    знч ОткрытыйКлюч = "QWERTYU4567=..."
    знч ЗакрытыйКлюч = "QWERTYU4567=..."
    знч КлючиПриложения = новый КлючиПриложенияВзаимодействия(ОткрытыйКлюч.ВБайты(), ЗакрытыйКлюч.ВБайты())

    знч ДанныеРегистрации = новый ДанныеРегистрацииПриложенияВзаимодействия(
                                    Сервер = "wss://1cdialog.com:443",
                                    ИдПриложения = Ууид{86669b56-32c9-49bb-9b5b-31cde9a79538},
                                    КлючиПриложения = КлючиПриложения,
                                    ОткрытыйКлючСервера = "QWERTYU4567=...")

    // Установка данных регистрации должна выполняться от имени администратора.
    СистемаВзаимодействия.УстановитьДанныеРегистрацииПриложения(ДанныеРегистрации)
;
```

## Объединение приложений взаимодействия

Объединение приложений позволяет пользователям этих приложений вести переписку между собой.

```xbsl
метод ОбъединитьПриложенияВзаимодействия()
    знч ТекущееПриложение = СистемаВзаимодействия.ПолучитьТекущееПриложение()
    знч ИдВторогоПриложения = Ууид{6c79fc60-2373-11ed-861d-0242ac120002}
    знч ОбъединениеПриложений = новый ОбъединениеПриложенийВзаимодействия(ТекущееПриложение.Ид, ИдВторогоПриложения,
    РежимСопоставленияПользователейВзаимодействия.ПоПолномуИмени)
    СистемаВзаимодействия.ОбъединитьПриложения(ОбъединениеПриложений)
;
```

## Отмена всех объединений приложений взаимодействия у абонента

```xbsl
метод ОтменитьОбъединение()
    знч ОбъединенияПриложений = СистемаВзаимодействия.ПолучитьОбъединенияПриложений()
    для Объединение из ОбъединенияПриложений
        СистемаВзаимодействия.ОтменитьОбъединениеПриложений(Объединение.ИдПриложения, Объединение.ИдПарногоПриложения)
    ;
;
```

## Получение необъединенных приложений взаимодействия

```xbsl
метод ПолучитьНеобъединенныеПриложения()
    знч СписокПриложений = СистемаВзаимодействия.ПолучитьПриложенияАбонента()
    знч ОбъединенияПриложений = СистемаВзаимодействия.ПолучитьОбъединенияПриложений()

    пер ПриложенияБезОбъединения = новый Массив<ПриложениеВзаимодействия>()

    для Приложение из СписокПриложений
        пер ОбъединениеНайдено = Ложь
        для Объединение из ОбъединенияПриложений
            если Приложение.Ид != Объединение.ИдПриложения или Приложение.Ид != Объединение.ИдПарногоПриложения
                ОбъединениеНайдено = Истина
                прервать
            ;
        ;

        если не ОбъединениеНайдено
            ПриложенияБезОбъединения.Добавить(Приложение)
        ;
    ;
;
```
