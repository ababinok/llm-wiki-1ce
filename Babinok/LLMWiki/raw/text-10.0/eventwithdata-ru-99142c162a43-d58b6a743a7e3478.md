`Стд::Интерфейс::СобытиеСДанными<ТипДанных>` `Доступность: Клиент`

ТипДанных: Тип данных события.

Объект с параметрами события, которое содержит какие-либо данные.

**Сравнение**

Структурное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md), [СобытиеКомпонента](../../wiki/interface/componentevent-ru-530aa61a20f9.md)

---

## Конструкторы

### СобытиеСДанными

`Доступность: Клиент`

```
СобытиеСДанными(
  Данные: ТипДанных,
  СтандартнаяОбработка: Булево)
```

Создает объект параметров события с указанными данными.

---

## Свойства

### Данные

`Доступность: Клиент` `ТолькоЧтение`

```
Данные: ТипДанных
```

Данные, относящиеся к событию.

---

### СтандартнаяОбработка

`Доступность: Клиент`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной (системной) обработки события. Если установить данному свойству значение `Ложь`, то стандартная обработка события производиться не будет. Отказ от стандартной обработки не отменяет действие.

---
