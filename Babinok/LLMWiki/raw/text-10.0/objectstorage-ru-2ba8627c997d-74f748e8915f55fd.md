## Примеры

**Общие примеры**

```xbsl
метод Экспорт(Заказ: ЗаказКлиента.Объект): ДвоичныйОбъект.Ссылка
    исп Поток = новый ВременныйПотокЗаписи()

    возврат ДвоичныйОбъект.Ссылка
```

## Методы

### Загрузить

`Доступность: Сервер`

```
@Устарело(Сообщение = "Используйте "Загрузить(ИмяФайла: Строка?, ВходнойПоток: ПотокЧтения, Размер: РазмерБайтов|Число|?, ТипСодержимого: Строка?, Свойства: ДвоичныйОбъект.Свойства?, ТаймаутУстаревания: Длительность?): ДвоичныйОбъект"")
Загрузить(
  ВходнойПоток: ПотокЧтения,
  Размер: РазмерБайтов|Число|?,
  Свойства: ДвоичныйОбъект.Свойства,
  ТаймаутУстаревания: Длительность? = Неопределено
): ДвоичныйОбъект
```

Создает и возвращает двоичный объект из потока

`ВходнойПоток`

указанного размера

`Размер`

. Если размер не указан будет прочитан весь поток и загружен в хранилище. Рекомендуется всегда указывать размер, если он известен.

`Свойства` - прикладные свойства загружаемого объекта. `ТаймаутУстаревания` - время, через которое сборщик мусора сможет удалить объект, если ссылка на него не будет сохранена в базу данных. Если не указано, используется время по умолчанию 24 часа.

MIME-тип содержимого будет определен автоматически. Если определить не удастся, будет присвоен "application/octet-stream".

Для загрузки данных анонимным пользователем требуется дополнительное разрешение, см. [УстановитьРазрешениеЗагрузкиАнонимнымПользователем](../../wiki/data/objectstorage-ru-2ba8627c997d.md).

#### Исключения

**[ИсключениеЗагрузкиДвоичногоОбъекта](../../wiki/data/binaryobjectuploadexception-ru-f7b277993953.md)** - при ошибке загрузки двоичного объекта или превышении максимального размера загружаемого объекта.

### Загрузить

`Доступность: Сервер`

```
Загрузить(
  ИмяФайла: Строка?,
  Байты: Байты,
  ТипСодержимого: Строка? = Неопределено,
  Свойства: ДвоичныйОбъект.Свойства? = Неопределено,
  ТаймаутУстаревания: Длительность? = Неопределено
): ДвоичныйОбъект
```

Создает и возвращает двоичный объект с именем файла

`ИмяФайла`

из байтов

`Байты`

.

`ТипСодержимого` - MIME-тип содержимого. Если не указан - будет определен автоматически. Если определить не удастся, будет присвоен "application/octet-stream". `Свойства` - прикладные свойства загружаемого объекта. `ТаймаутУстаревания` - время, через которое сборщик мусора сможет удалить объект, если ссылка на него не будет сохранена в базу данных. Если не указано, используется время по умолчанию 24 часа.

Пробельные символы в начале и конце имени файла `ИмяФайла` будут удалены. Пустая строка будет заменена на `Нeопределено`.

Для загрузки данных анонимным пользователем требуется дополнительное разрешение, см. [УстановитьРазрешениеЗагрузкиАнонимнымПользователем](../../wiki/data/objectstorage-ru-2ba8627c997d.md).

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если имя `ИмяФайла` содержит недопустимые для имени файла символы (запрещены все символы с кодами 0-31 и `' " < > | : * ? \ /`). **[ИсключениеНедопустимыйФормат](../../wiki/stdlib/illegalformatexception-ru-8ff587175d1a.md)** - если формат значения параметра `ТипСодержимого` не соответствует MIME-типу (тип/подтип;параметр=значение) или длина значения больше 255 символов. **[ИсключениеЗагрузкиДвоичногоОбъекта](../../wiki/data/binaryobjectuploadexception-ru-f7b277993953.md)** - при ошибке загрузки двоичного объекта или превышении максимального размера загружаемого объекта.

**Перегрузка** [Загрузить(ИмяФайла: Строка?, ВходнойПоток: ПотокЧтения, Размер: РазмерБайтов|Число|? = Неопределено, ТипСодержимого: Строка? = Неопределено, Свойства: ДвоичныйОбъект.Свойства? = Неопределено, ТаймаутУстаревания: Длительность? = Неопределено): ДвоичныйОбъект](../../wiki/data/objectstorage-ru-2ba8627c997d.md) [Загрузить(ИмяФайла: Строка?, Строка: Строка, ТипСодержимого: Строка? = Неопределено, Свойства: ДвоичныйОбъект.Свойства? = Неопределено, ТаймаутУстаревания: Длительность? = Неопределено): ДвоичныйОбъект](../../wiki/data/objectstorage-ru-2ba8627c997d.md) [Загрузить(ВходнойПоток: ПотокЧтения, Размер: РазмерБайтов|Число|? = Неопределено, ТипСодержимого: Строка? = Неопределено, Свойства: ДвоичныйОбъект.Свойства? = Неопределено, ТаймаутУстаревания: Длительность? = Неопределено): ДвоичныйОбъект](../../wiki/data/objectstorage-ru-2ba8627c997d.md) [Загрузить(ВходнойПоток: ПотокЧтения, Размер: РазмерБайтов|Число|?, Свойства: ДвоичныйОбъект.Свойства, ТаймаутУстаревания: Длительность? = Неопределено): ДвоичныйОбъект](../../wiki/data/objectstorage-ru-2ba8627c997d.md)

означает, что ограничения нет.

В мобильном приложении всегда возвращает `Неопределено`.

### УстановитьАвтоматическоеИсправлениеИмениФайла

`Доступность: Сервер`

```
УстановитьАвтоматическоеИсправлениеИмениФайла(
  РежимИсправления: РежимИсправленияИмениФайлаДвоичногоОбъекта = РежимИсправленияИмениФайлаДвоичногоОбъекта.ИсправлятьПриЗагрузке,

```

Устанавливает режим исправления имени файла. В зависимости от

`РежимИсправления`

может изменить поведение

[Загрузить](../../wiki/data/objectstorage-ru-2ba8627c997d.md)

или

[НачатьВыгрузку](../../wiki/interface/filesdownload-ru-97065aa8f041.md)

. По умолчанию

[ИсправлятьПриЗагрузке](../../wiki/data/binaryobjectfilenamecorrectionmode-ru-1421ce56e705.md)

`Замена`

- символ, на который будут заменены недопустимые символы в имени файла. По умолчанию пустая строка - символы будут удалены.

### УстановитьИмяФайла

`Доступность: Сервер`

```
УстановитьИмяФайла(
  Ссылка: ДвоичныйОбъект.Ссылка,
  НовоеИмяФайла: Строка?)
```

Устанавливает имя файла

`НовоеИмяФайла`

для двоичного объекта по ссылке

`Ссылка`

.

Пробельные символы в начале и конце имени файла `НовоеИмяФайла` будут удалены. Пустая строка будет заменена на `Нeопределено`.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если имя `НовоеИмяФайла` содержит недопустимые для имени файла символы (запрещены все символы с кодами 0-31 и `' " < > | : * ? \ /`).

### УстановитьМоментУстаревания

`Доступность: Сервер`

```
УстановитьМоментУстаревания(
  Ссылка: ДвоичныйОбъект.Ссылка,
  Момент: Момент
): Булево
```

Устанавливает время
