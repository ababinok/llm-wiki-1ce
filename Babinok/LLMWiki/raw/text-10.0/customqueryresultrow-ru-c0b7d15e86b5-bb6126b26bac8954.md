## Операция []

`Только чтение`

```
[Ключ: Строка]: неизвестно
```

В качестве параметра ожидается строка с именем колонки результата запроса. Можно использовать для обращения к полям запроса в случае невозможности использовать обращение просто по имени поля. Например, псевдоним колонки является некорректным идентификатором с точки зрения встроенного языка.

---

## Динамические свойства

Свойство содержит значение одноименного поля результата запроса. Если имя поля результата запроса не является корректным идентификатором с точки зрения встроенного языка — обращение возможно с помощью операции []. Например: `СтрокаРезультата[Имя поля]`.
