Асимметричное шифрование (или шифрование с открытым ключом) — это метод шифрования, при котором используются два разных ключа:

- открытый ключ — доступен всем, используется для шифрования данных;
- закрытый ключ — хранится в секрете, используется для расшифрования данных.

Асимметричное шифрование медленнее симметричного, поэтому используется для обмена симметричными ключами (например, в протоколе TLS). Закрытый ключ должен держаться в секрете: при его компрометации безопасность соединения нарушится.
