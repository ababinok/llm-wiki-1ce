## Конструкторы

### АдресПочты

`Доступность: Сервер`

```
АдресПочты(Адрес: Строка)
```

Создает объект с адресом электронной почты

`Адрес`

.

### АдресПочты

`Доступность: Сервер`

```
АдресПочты(
  Адрес: Строка,
  ОтображаемоеИмя: Строка)
```

Создает объект с адресом электронной почты

`Адрес`

## Методы

### ВСтроку

`Доступность: КлиентИСервер`

```
ВСтроку(): Строка
```

Возвращает строковое представление в виде:

- `"<%Адрес>"`
  
  - если ОтображаемоеИмя пусто
- `"%ОтображаемоеИмя <%Адрес>"`
  
  - иначе

**Переопределение** [Объект::ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)
