Для работы с системой взаимодействия необходимо сначала выполнить регистрацию приложения. Для этого в «1С:Предприятие.Элементе» используются встроенные формы:

- `ФормаУправленияСистемойВзаимодействия`
  
  — форма управления системой взаимодействия;
- `ФормаРегистрацииСистемыВзаимодействия`
  
  — форма регистрации в системе взаимодействия.

## Форма управления системой взаимодействия

Форма управления системой взаимодействия в двух состояниях: до регистрации приложения показаны ошибка и ссылка «Зарегистрировать»; после регистрации — сведения об абоненте и приложении, ключ администрирования и ссылка отмены регистрации. [Описание иллюстрации](../figures/e788502cb9e2a56b7aaf9b03c179d252614571acd8ebe6a3e1090db98936d763-4c941ce1a1be58cd.md)

С помощью данной формы можно:

- перейти к регистрации приложения в системе взаимодействия (будет открыта
  
  [форма регистрации приложения](../../wiki/integration/register-application-in-collaboration-system-4a6e06152ce5.md)
  
  );
- отменить регистрацию приложения;
- посмотреть информацию о зарегистрированном приложении и сервере системы взаимодействия.

Пример фрагмента командного интерфейса для включения формы управления системой взаимодействия в интерфейс приложения

```yaml
ВидЭлемента: ФрагментКомандногоИнтерфейса
ОбластьВидимости: ВПроекте
Ид: 6283f42d-cd67-4136-aa5b-3f5a9459ab5e
Имя: ПанельНавигации
Элементы:
    -
        Тип: НавигационнаяКоманда
        Представление: Управление системой взаимодействия
        Имя: УправлениеСВ
        ТипФормы: ФормаУправленияСистемойВзаимодействия
```

## Форма регистрации в системе взаимодействия

Форма регистрации приложения в системе взаимодействия [Описание иллюстрации](../figures/9fd68d9f2642bc0c446db8f7960f488e0560b260a8a7a10d2630ae2cdbab7b51-d752091c2b96787b.md)

С помощью данной формы можно:

- зарегистрировать приложение в системе взаимодействия;
- проверить информацию о подключении приложения к системе взаимодействия;
- отменить регистрацию приложения.

Пример фрагмента командного интерфейса для включения формы регистрации в интерфейс приложения

```yaml
ВидЭлемента: ФрагментКомандногоИнтерфейса
ОбластьВидимости: ВПроекте
Ид: 6283f42d-cd67-4136-aa5b-3f5a9459ab5e
Имя: ПанельНавигации
Элементы:
    -
        Тип: НавигационнаяКоманда
        Представление: Регистрация в системе взаимодействия
        Имя: Регистрация
        ТипФормы: ФормаРегистрацииСистемыВзаимодействия
```

## Регистрация приложения

Для регистрации приложения в системе взаимодействия необходимо заполнить следующие поля:

- адрес сервера: вы можете подключиться к публичному сервису «1С:Диалог» или указать адрес собственного экземпляра сервера системы взаимодействия;
- электронную почту абонента;
- имя текущего приложения (используется как представление приложения).

Если при регистрации выбрано подключение к «1С:Диалог», то на указанную электронную почту отправляется код активации, который необходимо ввести в соответствующее поле формы подтверждения.
