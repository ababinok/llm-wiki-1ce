### ПолучитьОбычные

`Доступность: Клиент`

```
ПолучитьОбычные(): ФрагментКомандногоИнтерфейса
```

Возвращает

[ФрагментКомандногоИнтерфейса](../../wiki/interface/commandinterfacefragment-ru-70af6e9ace5a.md)

заполненный командами вызова операций обработки, не являющимися основными.

---

### ПолучитьОсновную

`Доступность: Клиент`

```
ПолучитьОсновную(): Команда?
```

Возвращает команду вызова основной операции обработки при её наличии. Если у обработки нет операции с признаком "основная", то вернёт тип

[Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md)

.
