Описывает маршрут на схеме процесса интеграции: движение сообщений между узлами внутри «1С:Предприятие.Элемента». Сообщение может перемещаться строго в определенном направлении и не может вернуться к отправителю.

---

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ИмяКанала

```yaml
ИмяКанала: Строка
```

Имя канала.

---

#### ЭтоКанал

```yaml
ЭтоКанал: Булево
```

Является ли канал хранящим сообщения. Чтобы отметить канал как хранящий сообщения, следует установить значение **Истина** (по умолчанию — **Ложь**).

---

### События

#### ОбновлениеМетрик

```yaml
ОбновлениеМетрик: Строка
```

Обработчик, внутри которого можно обновлять метрики, добавленные в проект разработчиком.

---

## Дочерние элеметы

#### Точки

```yaml
Точки: Точка[]
```

Координаты начальной и конечной точек стрелки на схеме.

---

#### Из

```yaml
Из: Строка
```

Узел, из которого отправляются сообщения.

---

#### В

```yaml
В: Строка
```

Узел, в который отправляются сообщения.
