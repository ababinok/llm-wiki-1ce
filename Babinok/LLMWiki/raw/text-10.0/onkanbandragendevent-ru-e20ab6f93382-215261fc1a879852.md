`Стд::Интерфейс::КанбанДоска::СобытиеПриОкончанииПеретаскиванияКанбана<ТипДанных,ТипЗначенияКолонки,ТипЗначенияСвимлайна>` `Доступность: Клиент`

ТипДанных: Тип данных карточки ТипЗначенияКолонки: Тип значения карточки, по которому определяется принадлежность к колонке ТипЗначенияСвимлайна: Тип значения карточки, по которому определяется принадлежность к свимлайну

Объект, в котором задаются параметры необходимые для обработки окончания перетаскивания на канбан-доску. Если источником данных канбан-доски является динамический список, то в случае стандартной обработки события происходит обновление данных перетаскиваемой карточки.
