После того как вы добавили в проект обработку и дали ей имя, «1С:Предприятие.Элемент» создаст следующие типы:

- [`{ИмяОбработки}`](../../wiki/stdlib/processingname-ru-9603ab69754c.md)
  
  ,
- [`{ИмяОбработки}.Объект`](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md)
  
  ,
- [`{ИмяОбработки}.Команды`](../../wiki/stdlib/processingname-commands-ru-2a6bad581328.md)
  
  .

### Тип «ИмяОбработки»

Это тип-одиночка.

Тип [`{ИмяОбработки}`](../../wiki/stdlib/processingname-ru-9603ab69754c.md) доступен и на клиенте, и на сервере. Служит для работы с конкретной обработкой.

Тип `{ИмяОбработки}` содержит метод [`СоздатьФорму()`](../../wiki/stdlib/processingname-ru-9603ab69754c.md), доступный на клиенте, с помощью которого вы можете создать [форму заданного типа](../../wiki/project/processing-project-element-acb124c72bfa.md) или форму типа [`{ИмяОбработки}.АвтоматическаяФорма`](../../wiki/interface/processingname-automaticform-ru-40572408be14.md).

### Тип «ИмяОбработки.Объект»

Тип [`{ИмяОбработки}.Объект`](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md) доступен и на клиенте, и на сервере. Содержит реквизиты и методы объекта обработки.

Этот тип имеет конструктор [`{ИмяОбработки}.Объект()`](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md), в который в качестве аргументов передаются [реквизиты](../../wiki/project/processing-project-element-acb124c72bfa.md) обработки (при наличии).

Для заполнения объекта обработки вызывается метод [`Заполнить()`](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md). Метод позволяет заполнить реквизиты объекта обработки, как при его интерактивном создании с помощью формы обработки.

В модуле объекта обработки вы можете описать обработчик [`ПриЗаполнении()`](../../wiki/stdlib/processingname-object-ru-ef9b55bfbaf9.md), который выполняет инициализацию реквизитов объекта обработки перед открытием формы обработки. Например, для обработки **РасчетСтоимостиДоставки** из [примера](../../wiki/project/processing-project-element-acb124c72bfa.md) обработчик `ПриЗаполнении()` может быть следующим:

```xbsl
@Обработчик
метод ПриЗаполнении()
    АвтоБазоваяСтавка = 1000
    АвтоСтоимостьКМ = 10
    АвтоСтоимостьКГ = 5
    АвиаБазоваяСтавка = 1000
    АвиаСтоимостьКМ = 10
    АвиаСтоимостьКГ = 5

    Вес = 600
    Расстояние = 250
;
```

### Тип «ИмяОбработки.Команды»

Тип [`{ИмяОбработки}.Команды`](../../wiki/stdlib/processingname-commands-ru-2a6bad581328.md) предоставляет доступ к командам, выполняющим операции обработки. Для каждой команды в типе создается свойство с именем, соответствующим имени операции из описания элемента проекта.

Тип содержит методы для получения основной и обычных команд:

- [`ПолучитьОсновную()`](../../wiki/stdlib/processingname-commands-ru-2a6bad581328.md)
  
  — возвращает основную команду, соответствующую основной операции;
- [`ПолучитьОбычные()`](../../wiki/stdlib/processingname-commands-ru-2a6bad581328.md)
  
  — возвращает
  
  [ФрагментКомандногоИнтерфейса](../../wiki/interface/command-interface-fragment-f742e5d6797f.md)
  
  , заполненный командами вызова обычных операций обработки.
