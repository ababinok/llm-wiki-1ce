## Свойства

### НеИсправлять

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеИсправлять
```

Не исправлять. При загрузке файла, содержащего недопустимы символы, будет выброшена ошибка.

---

### ИсправлятьПриЗагрузке

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ИсправлятьПриЗагрузке
```

Исправлять при загрузке. Имя файла будет нормализовано при загрузке.

---

### ИсправлятьПриВыгрузке

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ИсправлятьПриВыгрузке
```

Исправлять при выгрузке. Имя файла будет нормализовано при выгрузке.
