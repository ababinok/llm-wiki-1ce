Контракт сущности — элемент проекта, который предназначен для описания общих методов и хранимых свойств, которыми обладают элементы, реализующие данный контракт. Контракт сущности обладает основной таблицей и таблицами множественных свойств, в которых хранятся свойства, описанные в контракте.

Важное отличие контракта сущности от контракта типа состоит в том, что контракт типа определяет только интерфейс, в то время как контракт сущности задает ограничения на данные. Для контракта сущности может создаваться отдельная таблица, которая хранит «общие» данные. Эта таблица доступна в языке запросов. Для контракта сущности также создается ссылочный тип, и его можно использовать в хранимых полях.

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### ОбластьРеализации

```yaml
ОбластьРеализации: ОбластьВидимости
```

Определяет область, в которой можно создавать элементы, реализующие контракт. Может принимать следующие значения:

- Глобально
  
  — элементы можно создавать глобально, во всех проектах;
- ВПроекте
  
  — элементы можно создавать в проекте, которому принадлежит контракт;
- ВПодсистеме
  
  — элементы можно создавать в подсистеме, которой принадлежит контракт.


Задается элементами перечисления [ПолучениеВсехОдиночек](../../wiki/project/gettingallsingletons-ru-de6b16c11772.md).

#### НастройкиТипов

```yaml
НастройкиТипов: 
    КонтрактСущности.Объект: 
        Контракты: Строка[]
```

Содержит объектные типы контрактов сущности. Указанные типы становятся базовыми для объектного типа, созданного по текущему элементу. Соответствующие им ссылочные типы становятся базовыми для порожденного ссылочного типа.

#### ПараметрыЗаписи

```yaml
ПараметрыЗаписи: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать запись объекта. Содержит параметры записи, которые должны присутствовать во всех элементах, реализующих этот контракт.

<summary>**Свойства**</summary>

##### Тип

Множество типов, доступных для параметра.

</details>
