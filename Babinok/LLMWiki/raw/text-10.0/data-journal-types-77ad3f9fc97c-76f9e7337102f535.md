## Тип «ИмяЖурналаДанных»

Тип [`{ИмяЖурналаДанных}`](../../wiki/stdlib/datajournalname-ru-529de137c48e.md) — тип-одиночка.

Тип содержит методы для работы с конкретным журналом данных. Так как журнал данных предназначен прежде всего для отображения данных разных сущностей, тип имеет только один собственный метод [`СоздатьФормуСписка()`](../../wiki/stdlib/datajournalname-ru-529de137c48e.md). Тип `{ИмяЖурналаДанных}` не дает возможности работать с данными сущностей, включенных в журнал.

Этот тип не содержит конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Имя журнала данных — ОбщийЖурнал
пер ФормаЖурнала = ОбщийЖурнал.СоздатьФормуСписка()
ФормаЖурнала.Открыть()
```

## Модуль журнала данных

В проекте модуль, расширяющий тип `{ИмяЖурналаДанных}`, называется **модулем журнала данных**.

В дереве журнала «ОбщийЖурнал» выделен модуль журнала; выше расположены колонки и форма списка. [Описание иллюстрации](../figures/f926b2875489fa61bc8c21f70303d8bb4738cf1ff8c6b3f3cb9e5f29b175243d-c2145828d27e5bb4.md)

В этом модуле вы можете реализовать дополнительную логику работы журнала данных.

## Тип «ИмяЖурналаДанных.АвтоматическаяФормаСписка»

Тип [`{ИмяЖурналаДанных}.АвтоматическаяФормаСписка`](../../wiki/stdlib/datajournalname-automaticlistform-ru-1529ae9e298f.md) доступен на клиенте. Описывает автоматически создаваемую форму списка журнала данных.

## Тип «ИмяЖурналаДанных.КлючЗаписи»

Тип [`{ИмяЖурналаДанных}.КлючЗаписи`](../../wiki/stdlib/datajournalname-recordkey-ru-6227fcfc1677.md) доступен на клиенте и сервере. Используется для указания на конкретную запись. Не может использоваться в типах реквизитов хранимых объектов.

## Тип «ИмяЖурналаДанных.ОткрытьСписок»

Тип [`{ИмяЖурналаДанных}.ОткрытьСписок`](../../wiki/stdlib/datajournalname-openlist-ru-cb746a30d312.md) — тип-одиночка. Является командой открытия формы списка журнала данных.
