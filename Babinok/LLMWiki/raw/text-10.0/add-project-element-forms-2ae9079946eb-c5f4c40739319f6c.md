> [!NOTE] примечание
> Этот пример использует [приложение «Демо CRM»](../../wiki/project/demo-app-3768685a4428.md).

[В предыдущем примере](../../wiki/data/add-catalog-e9262e40ce1d.md) вы добавили в проект элемент вида [Справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md). В этом примере вы создадите для него форму списка и форму объекта.

[Откройте](../../wiki/project/open-app-in-ide-2c0162ac1160.md) демо-приложение в среде разработки и выполните следующие действия:

1. В навигаторе проекта перейдите к справочнику **Проекты**. Нажмите на знак плюса рядом с именем справочника и выберите **ФормаСписка** в открывшемся окне.
  
  
2. Для формы будет сгенерировано имя по умолчанию — **ПроектыФормаСписка**.
3. Форма автоматические откроется в [редакторе компонентов интерфейса](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md).
4. В дереве компонентов перейдите к колонкам основной таблицы. Выделите колонку **Описание** и перетащите ее между колонками **Наименование** и **Код**.
  
  
  
  Изменение порядка колонок отобразится в конструкторе формы.
5. Добавьте к справочнику форму объекта для создания и редактирования отдельного проекта. Для этого нажмите на знак плюса рядом с именем справочника и выберите **ФормаОбъекта** в открывшемся окне.
  
  
6. Для формы будет сгенерировано имя по умолчанию — **ПроектыФормаОбъекта**.
7. Форма автоматические откроется в [редакторе компонентов интерфейса](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md).
8. В дереве компонентов перейдите в основной раздел формы. Выделите поле **Код** и удалите его.
  
  
9. Поскольку в [предыдущем примере](../../wiki/data/add-catalog-e9262e40ce1d.md) вы уже добавили в командный интерфейс стандартную команду открытия списка справочника, вы можете просто [опубликовать](../../wiki/project/publish-project-on-server-dade1898bf5e.md) проект на сервере и перезапустить приложение. Нажмите **Активности** ⟶ **Проекты**, чтобы увидеть новые формы справочника.
