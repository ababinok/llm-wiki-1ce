Таблица, порождаемая для реквизита-коллекции. Каждому элементу коллекции соответствует одна запись таблицы.

---

## Поля

### Владелец

`Ключевое поле`

```
Владелец: ИмяЭлементаСРеквизитомКоллекцией.Ссылка
```

Ссылка на запись, владеющую элементами реквизита-коллекции.

#### Примеры

В справочнике **Сотрудники** есть реквизит **Телефоны** с типом `Массив<Строка>`. Запрос для получения всех телефонов сотрудника может выглядеть следующим образом:

```xbql
ВЫБРАТЬ
    Индекс,
    Элемент КАК Телефон
ИЗ
    Сотрудники.Телефоны
ГДЕ
    Владелец == %Сотрудник
УПОРЯДОЧИТЬ ПО
    Индекс
```

---

### Индекс

`Ключевое поле`

```
Индекс: Число
```

Индекс элемента реквизита-коллекции в рамках одного владельца.

---

### Элемент

```
Элемент: Строка
```

Элемент реквизита-коллекции.

#### Примеры

В справочнике **Сотрудники** есть реквизит **Телефоны** с типом `Массив<Строка>`. В поле **Элемент** записей таблицы **Сотрудники.Телефоны** хранятся значения этого массива. Запрос для получения всех телефонов сотрудника может выглядеть следующим образом:

```xbql
ВЫБРАТЬ
    Элемент КАК Телефон
ИЗ
    Сотрудники.Телефоны
ГДЕ
    Владелец == %Сотрудник
УПОРЯДОЧИТЬ ПО
    Элемент
```
