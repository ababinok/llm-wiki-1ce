`Стд::ОбъектноеХранилище::ДвоичныйОбъект.СоставнаяЗагрузка` `Доступность: Сервер`

Объект управления загрузкой по частям. Позволяет восстанавливать начатую загрузку, начинать новую, завершать или прерывать процесс загрузки, а также генерировать подписанные ссылки для прямой загрузки частей файла в хранилище через сторонние приложения.

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Общие примеры**

```xbsl
@ВПроекте
метод ЗагрузитьРезервнуюКопиюСервиса(Код: Строка, Размер: Число, ИмяФайла: Строка, ТипСодержимого: Строка)
    знч СоставнаяЗагрузка = ОбъектноеХранилище.НачатьСоставнуюЗагрузку(ИмяФайла, Размер, ТипСодержимого, новый ДвоичныйОбъект.Свойства(Код), 1д)

    знч СсылкиНаЗагрузку = СоставнаяЗагрузка.ПолучитьСсылкиНаЗагрузку()
    знч РазмерЧасти = СоставнаяЗагрузка.ПолучитьРазмерЧастиПоУмолчанию()

    // Вызов стороннего сервиса для загрузки объекта в ваше хранилище
    знч EtagСписок = СтороннийСервис.ЗагрузитьРезервнуюКопию(СсылкиНаЗагрузку, РазмерЧасти)

    СоставнаяЗагрузка.ЗавершитьЗагрузку(EtagСписок)
;
```

## Методы

### ЗавершитьЗагрузку

`Доступность: Сервер`

```
ЗавершитьЗагрузку(
  ЗагруженныеЧасти: Массив<Строка>,
  Хеш: Байты? = Неопределено,
  Размер: РазмерБайтов|Число|? = Неопределено,
  ПроверитьХеш: Булево = Ложь
): ДвоичныйОбъект
```

Завершает загрузку по частям и возвращает новый двоичный объект.

`ЗагруженныеЧасти` - массив заголовков ETag, которые вернули запросы загрузки по ссылкам, отсортированные в порядке номеров частей. `Размер` - размер двоичного объекта. Если `Размер = Неопределено` - будет взят из загруженного объекта. `Хеш` - хеш sha256. Если хеш не передан в метод или параметр `ПроверитьХеш = Истина` - будет вычислен (для s3 приведёт к скачиванию объекта). `ПроверитьХеш` - указывает надо ли проверять хеш объекта перед сохранением (для s3 приведёт к скачиванию объекта).

#### Исключения

**[ИсключениеЗагрузкиДвоичногоОбъекта](../../wiki/data/binaryobjectuploadexception-ru-f7b277993953.md)** - при ошибке загрузки двоичного объекта, если указанный `Размер` или указанный `Хеш` не соответствует загруженному. Ошибка загрузки отменяет процесс и удаляет загруженный объект из хранилища.

### ПолучитьСсылкиНаЗагрузку

`Доступность: Сервер`

```
ПолучитьСсылкиНаЗагрузку(РазмерЧасти: РазмерБайтов|Число|? = Неопределено): Массив<Строка>
```

Возвращает массив HTTP-ссылок на загрузку объекта. Количество вычисляется на основе размера, указанного в методе

[НачатьСоставнуюЗагрузку](../../wiki/data/objectstorage-ru-2ba8627c997d.md)

.

`РазмерЧасти`

- размер части в диапазоне от 5 Мб до 1 Гб.

В ответ на запрос по ссылке возвращается заголовок ETag, который требуется сохранить для последующей передачи в метод [ЗавершитьЗагрузку](../../wiki/data/binaryobject-multipartupload-ru-a9a5fb4dd627.md).

Используйте этот метод для случая когда размер загружаемого объекта заранее известен.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - при вызове метода, когда размер не определен. **[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если указан невалидный `РазмерЧасти`.

**Перегрузка** [ПолучитьСсылкиНаЗагрузку(КоличествоЧастей: Число, НомерПервойЧасти: Число): Массив<Строка>](../../wiki/data/binaryobject-multipartupload-ru-a9a5fb4dd627.md)

### ПолучитьСсылкиНаЗагрузку

`Доступность: Сервер`

```
ПолучитьСсылкиНаЗагрузку(
  КоличествоЧастей: Число,
  НомерПервойЧасти: Число
): Массив<Строка>
```

Возвращает заданный массив ссылок на загрузку.

Время жизни генерируемых ссылок приравнивается к значению аргумента, переданного в параметр `ТаймаутУстаревания` метода [НачатьСоставнуюЗагрузку](../../wiki/data/objectstorage-ru-2ba8627c997d.md), но не может быть более 7 дней. Если `Неопределено`, используется время по умолчанию 7 дней. В ответ на запрос по ссылке возвращается заголовок ETag, который требуется сохранить для последующей передачи в метод [ЗавершитьЗагрузку](../../wiki/data/binaryobject-multipartupload-ru-a9a5fb4dd627.md).

Используйте этот метод для случая, когда размер загружаемого объекта заранее неизвестен, а так же для перегенерации ссылок, если их срок действия истёк или это требуется по каким-то другим причинам.

`КоличествоЧастей` - сколько частей необходимо загрузить. Положительное целое число, не превышающее 10000 (ограничения со стороны s3) `НомерПервойЧасти` - номер части с которого нужно начинать генерировать ссылки. Положительное целое число, не превышающее 10000.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если передано невалидное значения одного из параметров.

**Перегрузка** [ПолучитьСсылкиНаЗагрузку(РазмерЧасти: РазмерБайтов|Число|? = Неопределено): Массив<Строка>](../../wiki/data/binaryobject-multipartupload-ru-a9a5fb4dd627.md)
