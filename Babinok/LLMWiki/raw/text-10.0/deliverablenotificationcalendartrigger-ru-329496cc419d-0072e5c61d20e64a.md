`Стд::ДоставляемыеУведомления::ТриггерДоставляемыхУведомленийПоКалендарю` `Доступность: КлиентИСервер`

Информация о вызове уведомления по календарю. Описывает информацию о вызове уведомления по календарю. Устанавливается в свойство `Триггер` объекта `ДоставляемоеУведомление` перед добавлением уведомления. Уведомление с этим триггером появляется в заданное непустыми полями время и может опционально повторяться в это же время каждый следующий раз.

### Повторяется

`Доступность: КлиентИСервер`

```
Повторяется: Булево
```

Повторять. Если Истина, то: Если указана только секунда, повторяется каждую минуту. Если указана только минута и, опционально, секунда, то повторяется каждый час. Если указан только час и, опционально, минута и секунда, то повторяется каждый день. Если указан только день недели и, опционально, час, минута и секунда, то повторяется каждую неделю в этот день. Если указан только день и, опционально, час, минута и секунда, то повторяется каждый месяц в этот день. Если указан только месяц и, опционально, день, час, минута и секунда, то повторяется каждый год в этот месяц и день. Если указан год, данный параметр игнорируется, а уведомление не повторяется.
