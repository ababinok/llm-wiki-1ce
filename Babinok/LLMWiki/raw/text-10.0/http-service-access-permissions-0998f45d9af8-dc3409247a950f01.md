При создании HTTP-сервиса вы можете настроить права доступа на трех уровнях:

- [на уровне HTTP-сервиса](../../wiki/security/http-service-access-permissions-0998f45d9af8.md)
  
  ;
- [на уровне отдельного URL-шаблона](../../wiki/security/http-service-access-permissions-0998f45d9af8.md)
  
  ;
- [на уровне отдельного HTTP-метода шаблона](../../wiki/security/http-service-access-permissions-0998f45d9af8.md)
  
  .

При вызове конкретного HTTP-метода, принадлежащего определенному URL-шаблону, проверка разрешений доступа в HTTP-сервисе будет производиться следующим образом:

- Если для данного HTTP-метода задана группа свойств
  
  [КонтрольДоступа](../../wiki/integration/method-ru-44c98737758b.md)
  
  , то будет выполнена проверка по заранее рассчитанным разрешениям доступа для данного HTTP-метода конкретного URL-шаблона. Дальнейшие пункты не выполняются.
- Если для данного URL-шаблона задана группа свойств
  
  [КонтрольДоступа](../../wiki/integration/urltemplate-d1624a2e37c0.md)
  
  , то будет выполнена проверка по заранее рассчитанным разрешениям доступа для конкретного URL-шаблона. Дальнейшие пункты не выполняются.
- Если вышеупомянутые группы свойств не заданы, то проверяются общие разрешения доступа для HTTP-сервиса, заданные группой свойств
  
  [КонтрольДоступа](../../wiki/integration/httpservice-77f3ea4c73b2.md)
  
  HTTP-сервиса.

> [!NOTE] дополнительно
> Если URL-шаблон или его HTTP-метод имеет группу свойств **КонтрольДоступа** и в очередном обновлении вы изменили свойство URL-шаблона [Имя](../../wiki/integration/urltemplate-d1624a2e37c0.md), то нужно обязательно вызвать перерасчет разрешений доступа для этого HTTP-сервиса в [обработчике обновления проекта](../../wiki/project/update-app-data-356eca7811d0.md). В противном случае, права доступа для переименованных шаблонов могут работать с ошибкой, так как рассчитанные разрешения доступа хранятся в разрезе имен URL-шаблонов. Аналогично и при добавлении новых URL-шаблонов с группой свойств **КонтрольДоступа**: если вы добавили такой шаблон в существующий HTTP-сервис, то при обновлении приложения необходимо заново рассчитать разрешения доступа.

## Настройка прав доступа для HTTP-сервиса

Чтобы настроить права доступа для вызова HTTP-сервиса в целом, следует в группе свойств HTTP-сервиса [КонтрольДоступа](../../wiki/integration/httpservice-77f3ea4c73b2.md) задать необходимые [настройки прав доступа](../../wiki/security/automatically-grant-permissions-to-user-groups-c39cf49a7075.md).

Данные настройки будут распространяться на все доступные в HTTP-сервисе URL-шаблоны и их методы. Если необходимо настроить нестандартный расчет прав доступа, то в группе свойств [КонтрольДоступа](../../wiki/integration/httpservice-77f3ea4c73b2.md) вы можете указать значение [РазрешенияВычисляются](../../wiki/project/accesscontrol-ru-c40ccedbcdb4.md), а в модуле HTTP-сервиса задать обработчик, который будет выполнять расчет прав доступа для HTTP-сервиса.

Пример реализации обработчика `ВычислитьРазрешенияДоступа()` в модуле HTTP-сервиса:

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа() : Массив<РазрешениеДоступа>

    пер Разрешения: Массив<РазрешениеДоступа>   // массив для возврата разрешений доступа

    // Получить экземпляры ключа доступа
    пер КлючМенеджеров = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Менеджеры)
    пер КлючРуководителей = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Руководители)

    // Создать разрешение доступа
    Разрешения.Добавить(новый РазрешениеДоступа([КлючМенеджеров, КлючРуководителей], [HttpСервисПраво.Вызов]))

    возврат Разрешения
;
```

## Настройка прав доступа для отдельного URL-шаблона

Чтобы настроить права доступа для отдельного URL-шаблона, следует добавить группу свойств [КонтрольДоступа](../../wiki/integration/urltemplate-d1624a2e37c0.md) у нужного URL-шаблона в описании HTTP-сервиса.

Если необходимо настроить нестандартный расчет прав доступа, то в группе свойств [КонтрольДоступа](../../wiki/integration/urltemplate-d1624a2e37c0.md) URL-шаблона, в свойстве [Вызов](../../wiki/integration/urltemplate-d1624a2e37c0.md), следует задать значение [РазрешенияВычисляются](../../wiki/project/accesscontrol-ru-c40ccedbcdb4.md), а в свойстве [Обработчик](../../wiki/integration/urltemplate-d1624a2e37c0.md) указать имя обработчика, который будет выполнять расчет прав доступа для данного URL-шаблона. Код обработчика следует расположить в модуле HTTP-сервиса.

Пример модуля HTTP-сервиса:

```xbsl
метод ВычислитьРазрешения(): ЧитаемаяКоллекция<КлючДоступа.Объект>
    возврат [новый МойКлючДоступа.Объект()]
;
```

## Настройка прав доступа для отдельного HTTP-метода URL-шаблона

Чтобы настроить права доступа для вызова конкретного HTTP-метода URL-шаблона, следует добавить группу свойств [КонтрольДоступа](../../wiki/integration/method-ru-44c98737758b.md) у нужного HTTP-метода в описании HTTP-сервиса.

Если необходимо настроить нестандартный расчет прав доступа, то в группе свойств [КонтрольДоступа](../../wiki/integration/method-ru-44c98737758b.md) HTTP-метода URL-шаблона, в свойстве [Вызов](../../wiki/integration/method-ru-44c98737758b.md), следует задать значение [РазрешенияВычисляются](../../wiki/project/accesscontrol-ru-c40ccedbcdb4.md), а в свойстве [Обработчик](../../wiki/integration/method-ru-44c98737758b.md) указать имя обработчика, который будет выполнять расчет прав доступа для данного HTTP-метода URL-шаблона. Код обработчика следует расположить в модуле HTTP-сервиса. Пример модуля HTTP-сервиса:

```xbsl
метод ВычислитьРазрешения(): ЧитаемаяКоллекция<КлючДоступа.Объект>
    возврат [новый МойКлючДоступа.Объект()]
;
```
