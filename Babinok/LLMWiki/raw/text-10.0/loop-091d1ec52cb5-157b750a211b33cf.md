Цикл — это управляющая конструкция, которая позволяет многократно выполнять блок кода до выполнения заданного условия. В языке «1С:Элемент» существуют разные виды циклов: `для по`, `для из`, `пока`.

```xbsl
метод ПодсчетСуммы(): Число
    пер Числа = [1, 2, 3, 4, 5]
    пер Сумма = 0
    
    // Цикл по элементам массива
    для Число из Числа
        Сумма = Сумма + Число
    ;
    
    возврат Сумма // 15
;
```
