Имя метода — это уникальный идентификатор, расположенный после ключевого слова `метод`, используемый для его объявления и вызова. Имя должно точно отражать действие, выполняемое методом, и следовать соглашениям при написании кода.

```xbsl
// Объявление метода с именем «Приветствие»
метод Приветствие(Имя: Строка): Строка
    возврат "Привет, ${Имя}!"
;
```
