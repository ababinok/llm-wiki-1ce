## Свойства

### ВключатьВДанныеСтроки

`Доступность: КлиентИСервер`

```
ВключатьВДанныеСтроки: Булево
```

Флаг, указывающий на то, будет ли поле участвовать в выборке данных при запросе динамического списка. Если `Ложь` – поле будет применяться только для настройки динамического списка.

---

### Выражение

`Доступность: КлиентИСервер`

```
Выражение: Строка
```

Выражение, описывающее значение поля выборки. Могут использоваться поля основной и присоединенных таблиц. Нельзя использовать функции агрегации данных.

---

### ИспользованиеВПоиске

`Доступность: КлиентИСервер`

```
ИспользованиеВПоиске: Авто|Булево
```

- Если
  
  `Ложь`
  
  – значение поля не будет использовано в поиске
- Если
  
  `Истина`
  
  – значение поля будет использовано в поиске по таблице, если тип поля
  
  [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  ,
  
  [Сущность.Ключ](../../wiki/data/entity-key-ru-7032eabc056b.md)
  
  или
  
  [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md)
- Если
  
  [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md)
  
  :
  
  - Для
    
    [Таблица](../../wiki/interface/table-ru-ccc43dec1ca9.md)
    
    : значение поля будет использовано в поиске, если тип поля
    
    [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md)
    
    ,
    
    [Сущность.Ключ](../../wiki/data/entity-key-ru-7032eabc056b.md)
    
    или
    
    [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md)
    
    и только, если колонка таблицы, в которой присутствует это поле видима пользователю
  - Для
    
    [Список](../../wiki/interface/list-ru-58c40755a735.md)
    
    : равнозначно значению
    
    `Истина`

---

НастройкиАвтоматическогоФильтра: НастройкиАвтоматическогоФильтраПоляДинамическогоСписка

### ОграничениеДопустимыхЗначенийФильтра

`Доступность: КлиентИСервер`

```
ОграничениеДопустимыхЗначенийФильтра: ОписаниеОграниченияДопустимыхЗначенийФильтра
```

Описание зависимости поля от другого для фильтрации используемых настраиваемым полем данных относительно контрольного поля. Если контрольное поле будет содержать значение, которое не может содержаться в настраиваемом поле по определенному признаку - эти значения будут исключены из выбора значений для фильтра по этому полю. Используется для механизма настроек таблицы.

#### Примеры

Здесь фильтр по полю `Участник` будет заполнен только такими участниками, которые относятся к командам, которые были выбраны в фильтре поля `ОтветственнаяКоманда`.

```yaml
-
    Тип: ПолеДинамическогоСписка
    ОтображатьВНастройкахФильтров: Истина
    Выражение: ОтветственнаяКоманда
-
    Тип: ПолеДинамическогоСписка
    ОтображатьВНастройкахФильтров: Истина
    Выражение: Участник
    ОграничениеДопустимыхЗначенийФильтра:
        РеквизитПоляФильтраОграничения: Команда
        ВыражениеЗначенияФильтраОграничения: ОтветственнаяКоманда
```

### ОтображатьВАвтоматическихСортировках

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВАвтоматическихСортировках: Авто|Булево
```

Включает поле в интерфейс автоматических сортировок.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – `Истина` для типов: [Число](../../wiki/stdlib/number-ru-dd4b54993c86.md), [Дата](../../wiki/stdlib/date-ru-d160dc00114c.md) и производные, [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md), ссылочные типы.

Для всех типов, кроме дат и времени, используется сортировка по возрастанию. Для дат и времени используются оба направления сортировки.

---

### ОтображатьВАвтоматическихФильтрах

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВАвтоматическихФильтрах: Авто|ВидОтображенияФильтра
```

Определяет способ отображения автоматического фильтра.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[Опционально](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md) для поддерживаемых типов: [Строка](../../wiki/stdlib/string-ru-1bac645acacf.md), [Число](../../wiki/stdlib/number-ru-dd4b54993c86.md), [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md), [Длительность](../../wiki/stdlib/duration-ru-fef7ea46f329.md), [Дата](../../wiki/stdlib/date-ru-d160dc00114c.md) и производные, [Булево](../../wiki/stdlib/boolean-ru-7823d4239bcc.md), ссылочный тип.

---

### Представление

`Доступность: КлиентИСервер`

```
Представление: Строка
```

Представление для [ПолеДинамическогоСписка](../../wiki/interface/dynamiclistfield-ru-123b2f37f3d2.md), которое будет отображено в окнах настроек компонента [Таблица](../../wiki/interface/table-ru-ccc43dec1ca9.md) (например, фильтрах) и в [КолонкаТаблицы](../../wiki/interface/tablecolumn-ru-90496d65cde5.md), если им явно не задано свойство [Заголовок](../../wiki/interface/tablecolumn-ru-90496d65cde5.md).

---

### Псевдоним

`Доступность: КлиентИСервер`

```
Псевдоним: Строка
```

Псевдоним поля. Если не задан, и в выражении задано обращение к полю, то псевдоним равен имени поля. По псевдониму поля можно получить доступ к данным в строке динамического списка.
