`Стд::ТабличныйДокумент::ИзображениеТабличногоДокумента` `Доступность: Сервер`

Рисунок табличного документа, который содержит Изображение.

```xbsl
метод ДобавитьРисунокПодЛоготип(Макет: ТабличныйДокумент)
    пер РисунокЛого = Макет.Рисунки.СоздатьИзображение()
    РисунокЛого.Высота = 40
    РисунокЛого.Ширина = 40
    РисунокЛого.РасположитьПоОбласти("R1C5:R4C8")
    РисунокЛого.МасштабированиеСодержимого = МасштабированиеИзображения.Пропорционально
    РисунокЛого.Имя = "ЛоготипОрганизации"
;
```

## Свойства

### МасштабированиеСодержимого

`Доступность: Сервер`

```
МасштабированиеСодержимого: МасштабированиеИзображения
```

Содержит варианты приспособления оригинальных размеров картинки к размерам области, отведенной для ее отображения. Значение [Заполнить](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md) будет интерпретироваться как [Пропорционально](../../wiki/stdlib/imagescaling-ru-a70a7c40e4bb.md)

### УстановитьИзображение

`Доступность: Сервер`

```
УстановитьИзображение(
  Изображение: Байты?,
  ПрозрачныйФон: Булево = Ложь)
```

Устанавливает изображение в рисунок табличного документа.

Поддерживаются изображения следующих форматов:

- BMP
- EMF
- GIF
- Icon
- JPEG
- PNG
- SVG
- TIFF
- WMF

---

### УстановитьУзор

`Доступность: Сервер`

```
УстановитьУзор(Узор: УзорТабличногоДокумента)
```

Устанавливает узор рисунка табличного документа.

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - Если будет указано значение `НеизвестныйУзор`.
