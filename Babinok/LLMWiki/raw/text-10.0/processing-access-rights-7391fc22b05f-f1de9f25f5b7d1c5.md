Обработка поддерживает [контроль прав доступа](../../wiki/security/access-control-0ea6e235f2d6.md). Вы можете задать права доступа для всех операций обработки или для каждой операции отдельно. При вызове конкретной операции проверка разрешений прав доступа будет выполняться следующим образом:

- Если для операции задана группа свойств
  
  КонтрольДоступа
  
  , то выполняется проверка заданных прав доступа для данной операции. Дальнейшие пункты не выполняются.
- Если группа свойств
  
  КонтрольДоступа
  
  для операции не задана, то проверяются общие разрешения доступа для обработки, заданные группой свойств
  
  КонтрольДоступа
  
  обработки.

> [!NOTE] дополнительно
> Если операция имеет группу свойств [**КонтрольДоступа**](../../wiki/project/processing-3a8538244521.md) и в очередном обновлении вы изменили свойство операции **Имя**, то нужно обязательно вызвать перерасчет разрешений доступа для этой обработки в [обработчике обновления проекта](../../wiki/project/update-app-data-356eca7811d0.md). В противном случае, права доступа для переименованных операций могут работать с ошибкой, так как рассчитанные разрешения доступа хранятся в разрезе имен операций.

## Пример

В данном примере показана обработка **ОбработкаРасчет** с двумя операциями: **РассчитатьЗП** и **РассчитатьНДС**. Для всех операций обработки зададим разрешение доступа по умолчанию **РазрешеноАутентифицированным** в группе свойств **КонтрольДоступа** обработки.

В свойствах обработки «ОбработкаРасчет» раскрыт КонтрольДоступа и задано разрешение получения по умолчанию РазрешеноАутентифицированным; ниже разрешение вызова оставлено в «Авто». Эти настройки применяются к операциям обработки в описанном примере. [Описание иллюстрации](../figures/fff327e4ae0e8e1ee10c4cc83d00e79cf21453a6ba5f49c31b7fe7a3168baf71-a8b2f54a83c66ce6.md)

Для операции **РассчитатьЗП** настроим разрешение доступа отдельно: разрешим ее использование только администраторам. Для этого в группе свойств **КонтрольДоступа** операции **РассчитатьЗП** укажем значение **РазрешеноАдминистраторам**.



Пример YAML-файла обработки

```yaml
ВидЭлемента: Обработка
ОбластьВидимости: ВПодсистеме
Ид: c09a3879-fa79-4bd9-b14e-9647c8fa0d86
Имя: ОбработкаРасчет
КонтрольДоступа:
    Разрешения:
        ПоУмолчанию: РазрешеноАутентифицированным
Операции:
    -
        Имя: РассчитатьЗП
        КонтрольДоступа:
            Разрешения:
                Вызов: РазрешеноАдминистраторам
    -
        Имя: РассчитатьНДС
```
