`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПодчиненногоРегистраСведений}.Запись` `Доступность: КлиентИСервер`

Содержит данные одной записи регистра сведений — структурно соответствует одной записи (строке) в основной таблице регистра.

## Свойства

### Активность

`Доступность: КлиентИСервер`

```
Активность: Булево
```

Содержит признак, определяющий влияние записи на результаты виртуальной таблицы [ИмяПодчиненногоРегистраСведений.СрезПоследних](../../wiki/queries/subordinatedinformationregistername-slicelast-ru-5dadf507fbef.md) и расчет значения поля [СледующийПериод](../../wiki/queries/subordinatedinformationregistername-ru-8cc4c1b62489.md).

Если значение `Ложь`, то запись не учитывается при получении сведений из виртуальной таблицы и при расчете поля `СледующийПериод`.

Переопределение: [Активность](../../wiki/data/subordinatedinformationregistername-record-ru-5f5d606d63e0.md)

---

### КлючЗаписи

`Доступность: КлиентИСервер`

```
КлючЗаписи: {ИмяПодчиненногоРегистраСведений}.КлючЗаписи
```

Свойство унаследовано от базового типа, при наследовании уточнен тип и добавлена возможность изменения. Значения измерений из ключа соответствуют значениям в самой записи — при изменении значений измерения в свойство автоматически помещается новый ключ записи (с новыми значениями). При присвоении ключа записи значения измерений в самой записи заполняются из него.

Переопределение: [КлючЗаписи](../../wiki/data/subordinatedinformationregistername-record-ru-5f5d606d63e0.md)

`Доступность: КлиентИСервер`


Существует только для периодических регистров сведений с флагом `ХранитьСледующийПериод` = `Истина`.

### СоздатьКопию

`Доступность: Сервер`

```
@ИменованныеПараметры
СоздатьКопию(
  Период: <ТипПериода>,
  Регистратор: <ТипРегистратора>,
  Активность: Булево = Истина,
  <Измерение1>: <ТипИзмерения1> = <ЗначениеПоУмолчаниюИзмерения1>,
  ....<ИзмерениеN>: <ТипИзмеренияN> = <ЗначениеПоУмолчаниюИзмеренияN>,
  <Ресурс1>: <ТипРесурса1> = <ЗначениеПоУмолчаниюРесурса1>,
  ...<РесурсN>: <ТипРесурсаN> = <ЗначениеПоУмолчаниюРесурсаN>,
  <Реквизит1>: <ТипРеквизита1> = <ЗначениеПоУмолчаниюРеквизита1>,
  ....<РеквизитN>: <ТипРеквизитаN> = <ЗначениеПоУмолчаниюРеквизитаN>)
```

>

Вызов возможен только с именованными параметрами

Создает новый экземпляр записи регистра сведений копированием этой записи.

Параметр `Период` существует только для периодического регистра сведений.

#### Исключения

**[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку записи.

#### Примеры

Дублирование записи о курсе валюты сегодняшним днем.

```xbsl
метод ДублироватьЗаписьСегодняшнимДнем(ЗаписьЦены: Цены.Запись, НовыйРегистратор: ПоступлениеТоваров.Ссылка): Цены.Запись
    знч НоваяЗапись = ЗаписьЦены.СоздатьКопию(Период = Дата.Сейчас(), Регистратор = НовыйРегистратор)
    возврат НоваяЗапись 
;
```

## Обработчики

### ПриСозданииКопии

```
ПриСозданииКопии(Источник: {ИмяПодчиненногоРегистраСведений}.Данные)
```

Вызывается при создании нового экземпляра записи регистра сведений копированием существующей. На момент вызова этого обработчика значения измерений, ресурсов и реквизитов у новой записи будут уже заполнены из записи-источника.

Не будет автоматически копироваться стандартное поле `Период` регистра сведений. Кроме того, не будут копироваться измерения, ресурсы и реквизиты, копирование которых отключено в регистре сведений с помощью свойства `ЗаполнятьПриКопировании`.

Параметр `Источник` содержит данные исходной записи регистра сведений, копированием которой и создается новая запись.

#### Примеры

В проекте есть периодический регистр сведений **ИмяРегистраСведений**. Необходимо сделать так, чтобы при копировании записи этого регистра сведений у стандартного поля `Период` проставлялась текущая дата

```xbsl
@Обработчик
метод ПриСозданииКопии(Источник: ИмяРегистраСведений.Данные)
    Период = Дата.Сейчас()
;
```
