Функция вычисляет среднее значение всех попавших в выборку значений поля. Она имеет следующий синтаксис:

```xbql
СРЕДНЕЕ([РАЗЛИЧНЫЕ] операнд)
```

Операнд должен иметь тип `Число`. Если выборка, по которой рассчитывается ***операнд***, пустая, то результатом функции будет `Null`.

Пример:

```xbql
ВЫБРАТЬ
    СРЕДНЕЕ(Сотрудники.Возраст) КАК СреднийВозраст
ИЗ
    Сотрудники КАК Сотрудники
```
