## Свойства

### UrlСервераПостроенияМаршрутов

`Доступность: Клиент`

```
UrlСервераПостроенияМаршрутов: Строка?
```

Url сервера с API для построения маршрутов.

API должно соответствовать документации OpenSourceRoutingMachine ([https://project-osrm.org/docs/v5.24.0/api/#](https://project-osrm.org/docs/v5.24.0/api/#)).

Требуется указывать при использовании [OpenStreetMap](../../wiki/stdlib/geographicmapsprovider-ru-442e16f070f5.md) и [Произвольный](../../wiki/stdlib/geographicmapsprovider-ru-442e16f070f5.md). При использовании [ЯндексКарты](../../wiki/stdlib/geographicmapsprovider-ru-442e16f070f5.md) не используется.

---

### КлючApi

`Доступность: Клиент`

```
КлючApi: Строка?
```

API-ключ для API поставщика карт (нужен для платных API - Яндекс Карт).

---

### Поставщик

`Доступность: Клиент`

```
Поставщик: Авто|ПоставщикГеографическихКарт
```

Используемый поставщик API для построения маршрутов. При [Произвольный](../../wiki/stdlib/geographicmapsprovider-ru-442e16f070f5.md) используется OpenStreetMap.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) разрешается, как [OpenStreetMap](../../wiki/stdlib/geographicmapsprovider-ru-442e16f070f5.md).

---

## Методы

### ПостроитьМаршрут

`Доступность: Клиент`

```
ПостроитьМаршрут(
  ТочкиОстановки: ЧитаемыйМассив<ГеографическиеКоординаты>,
  Вид: ВидГеографическогоМаршрута
): ГеографическийМаршрут?
```

Находит и возвращает маршрут, проходящий по указанным точкам в порядке их следования. Если маршрут не найден, возвращает

[Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md)

.

- ТочкиОстановки - координаты точек, между которыми строить маршрут (две или больше),
- Вид - тип маршрута для поиска, если вид маршрута не поддерживается поставщиком, то возвращается маршрут для
  
  [Автомобильный](../../wiki/stdlib/geographicroutekind-ru-8815af850ad3.md)
  
  .
