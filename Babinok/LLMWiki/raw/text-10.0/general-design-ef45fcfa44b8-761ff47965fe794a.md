## Синтаксический отступ

Блоки вложенных инструкций, находящиеся на одном уровне, выделяются одним синтаксическим отступом.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
метод Скрипт()

    пер Переменная1: Строка
    
    для Счетчик = 1 по 5 
        Метод1()
    ;
    
;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
метод Скрипт()

пер Переменная1: Строка
    
для Счетчик = 1 по 5 
Метод1()
; 
    
;
```

Один синтаксический отступ составляет 4 пробела. Символы табуляции не используются.

## Длина строки

Максимальная длина строки — 120 символов.

> [!TIP] совет
> Допускаются строки большей длины, если разбиение таких строк на части по 120 символов ухудшает их чтение и понимание.

## Составные инструкции

Составные инструкции завершаются символом `;`, который пишется на отдельной строке с тем же синтаксическим отступом, что и сама инструкция.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
для Счетчик = 1 по 5 
    Метод1()
    Метод2()
;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
для Счетчик = 1 по 5 
    Метод1()
    Метод2();
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
если Переменная1 > 5
    Метод1()
    Метод2()
иначе
    Метод3()
;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

```xbsl
если Переменная1 > 5
    Метод1()
    Метод2()
иначе
    Метод3();
```

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

```xbsl
метод Метод1(): Булево
    пер Переменная1 = Истина
    возврат Переменная1
;
```

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)
