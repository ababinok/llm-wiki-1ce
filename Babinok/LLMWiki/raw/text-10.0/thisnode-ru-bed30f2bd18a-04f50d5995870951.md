Стандартный реквизит, который указывает, является ли данный узел текущим узлом приложения.

---

## Свойства

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление реквизита.

---

#### ВажностьПриОтображении

```yaml
ВажностьПриОтображении: ВажностьПриОтображении
```

Важность реквизита при отображении в интерфейсе приложения. Задается значением перечисления [ВажностьПриОтображении](../../wiki/project/displayimportance-ru-469c555fd91c.md). Значение по умолчанию — [НеОтображать](../../wiki/project/displayimportance-ru-469c555fd91c.md).

---

#### ИспользоватьВПолнотекстовомПоиске

```yaml
ИспользоватьВПолнотекстовомПоиске: Булево
```

Признак индексирования данных для использования в [полнотекстовом поиске](../../wiki/project/full-text-search-99b98022003a.md).
