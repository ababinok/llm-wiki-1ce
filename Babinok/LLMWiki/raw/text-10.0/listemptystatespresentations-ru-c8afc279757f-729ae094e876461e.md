## Свойства

### НетДанныхДляОтображения

`Доступность: Клиент`

```
НетДанныхДляОтображения: Авто|ПредставлениеПустогоСостоянияСписка|?
```

Состояние, когда в списке нет данных для отображения. При `Неопределено` пустое состояние отключается.

---

### НетРезультатовПоиска

`Доступность: Клиент`

```
НетРезультатовПоиска: Авто|ПредставлениеПустогоСостоянияСписка|?
```

Состояние, когда применен поиск, но по нему нет ни одного вхождения. При `Неопределено` пустое состояние отключается.

---

### НетРезультатовФильтрации

`Доступность: Клиент`

```
НетРезультатовФильтрации: Авто|ПредставлениеПустогоСостоянияСписка|?
```

Состояние, когда применены фильтры, но по ним нет ни одного вхождения. При `Неопределено` пустое состояние отключается.
