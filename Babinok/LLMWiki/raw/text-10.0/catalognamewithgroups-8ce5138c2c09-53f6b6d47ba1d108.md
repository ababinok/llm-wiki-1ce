## [{ИмяСправочникаСГруппами}](../../wiki/queries/catalognamewithgroups-ru-7ec77b3b2e5c.md)

Таблица содержит записи, соответствующие элементам [иерархического справочника с группами](../../wiki/data/hierarchical-catalog-80c1ad8e7082.md) **ИмяСправочникаСГруппами**. Одна запись таблицы — один элемент справочника.

## [{ИмяСправочникаСГруппами}.ИерархияГруппИЭлементов](../../wiki/queries/catalognamewithgroups-hierarchyofgroupsandelements-ru-9e1be44310c5.md)

Таблица с информацией об иерархических связях. Создается для иерархического справочника с группами, то есть для иерархического справочника, у которого свойство **Вид** иерархии равно **ИерархияГруппИЭлементов**.

## [{ИмяСправочникаСГруппами}.ИерархияГруппИЭлементов.Циклы](../../wiki/queries/catalognamewithgroups-hierarchyofgroupsandelements-cycles-ru-a40bd8d0d826.md)

Таблица с информацией о наличии циклов в иерархических связях справочника с группами **ИмяСправочникаСГруппами**. Таблица порождается, если свойство **Вид** иерархии справочника имеет значение **ИерархияГруппИЭлементов**.
