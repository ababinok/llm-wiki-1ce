`Стд::ВводВывод::Файлы::ИсключениеФайловойСистемы` `Доступность: Сервер`

Общее исключение при работе с файловой системой. Исключение выбрасывается при одном из следующих условий:

- запрещен доступ к файлу,
- при попытке создать файл с именем, которое уже существует,
- при попытке произвести действие над каталогом, который не является пустым,
- при работе с файлом, которого не существует,
- при выполнении специфичных для каталогов/ссылок операций над файлом, который не является каталогом/ссылкой.
