`Стд::ТабличныйДокумент::РисунокТабличногоДокумента` `Доступность: Сервер`

Рисунок табличного документа - это выделенный элемент табличного документа, который может являться изображением, либо иным видом рисунка из "1С:Предприятие 8". То есть объект является логическим контейнером для рисунка.

```xbsl
метод ДобавитьРисунокПодЛоготип(Макет: ТабличныйДокумент)
    пер РисунокЛого = Макет.Рисунки.СоздатьИзображение()
    РисунокЛого.Высота = 40
    РисунокЛого.Ширина = 40
    РисунокЛого.РасположитьПоОбласти("R1C5:R4C8")
    РисунокЛого.МасштабированиеСодержимого = МасштабированиеИзображения.Пропорционально
    РисунокЛого.Имя = "ЛоготипОрганизации"
;
```

## Свойства

### Верх

`Доступность: Сервер`

```
Верх: Число
```

Содержит положение верхней границы рисунка, отсчитываемое от верхней стороны табличного документа (в миллиметрах).

---

### Высота

`Доступность: Сервер`

```
Высота: Число
```

Высота рисунка в миллиметрах.

---

### Имя

`Доступность: Сервер`

```
Имя: Строка
```

Имя рисунка табличного документа.

---

### Начало

`Доступность: Сервер`

```
Начало: Число
```

Содержит положение левой границы рисунка, отсчитываемое от левой стороны табличного документа (в миллиметрах).

---

### Ширина

`Доступность: Сервер`

```
Ширина: Число
```

Ширина рисунка в миллиметрах.

`Доступность: Сервер`

### РасположитьПоОбласти

`Доступность: Сервер`

```
РасположитьПоОбласти(Область: ОбластьТабличногоДокумента|Строка)
```

Устанавливает расположение рисунка табличного документа по области, беря от нее координаты. Следует помнить, что рисунок не принадлежит области.
