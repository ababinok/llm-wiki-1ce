# Тип «Момент»

Значение типа [`Момент`](../../wiki/stdlib/instant-ru-09dd46b34eb4.md) хранит **абсолютный момент времени**. Говоря более простым языком, это дата и время, указанные для часового пояса UTC. Это позволяет располагать на одной шкале времени события, которые происходят в различных часовых поясах, т. к. дата и время в конкретном часовом поясе всегда имеют прямое отображение в UTC путем корректировки на время смещения конкретного часового пояса. Представление типа формируется с учетом текущей [локали](../../wiki/stdlib/locale-ru-eb59bd8c78bb.md).

Значение типа `Момент` может быть создано следующими способами:

- С помощью литерала вида `Момент{<дата><разделитель_сегментов><время><часовой_пояс>}`, где
  
  - `<дата>`
    
    имеет вид:
    
    `гггг-ММ-дд`
    
    .
  - `<разделитель_сегментов>`
    
    — символ неразрывного пробела
    
    ``
    
    или
    
    `T`
    
    .
  - `<время>`
    
    имеет вид:
    
    `ЧЧ:мм(:cc(.ССС)?)?`
    
    .
  - `<часовой_пояс>`
    
    — имя часового пояса или смещение в виде
    
    `[+-]ЧЧ:мм`
    
    .
  
  Например:
  
  ```xbsl
  пер МоментСоздания = Момент{2025-05-01 23:30:40.345 UTC+3}
  ```
  
  Встроенные строковые литералы:
  
  - `Момент{}`
    
    — значение по умолчанию: 0001-01-01 00:00:00.000 Z.
  - `Момент{Минимум}`
    
    — минимальное значение: 0000-12-31 06:00:00.000 Z.
  - `Момент{Максимум}`
    
    — максимальное значение: 4000-01-01 17:59:59.999 Z.

> [!NOTE] примечание
> Встроенные строковые литералы также можно использовать в языке запросов. Например, чтобы проверить наличие следующего периода у записи в таблице периодического регистра сведений, можно сравнить значение поля **СледующийПериод** с максимальным значением типа поля **Период** (см. [пример](../../wiki/data/periodic-information-register-2e754cdbda44.md)). Если они равны, значит значение следующего периода для данной записи отсутствует.

- С помощью конструктора типа, в котором дата и время указывается в виде строки: [`Момент(Представление: Строка)`](../../wiki/stdlib/instant-ru-09dd46b34eb4.md). При указании в виде строки момент времени должен указываться приведенным к UTC. Пример:
  
  ```xbsl
  пер МоментСоздания = новый Момент("2025-05-01 23:30:40.345 UTC+3")
  ```
- С помощью конструктора типа, в котором составляющие даты и времени вводятся отдельными параметрами конструктора: [`Момент(Год: Число, Месяц: Число, День: Число, Час: Число, Минута: Число, Секунда: Число, Миллисекунда: Число, ЧасовойПояс: ЧасовойПояс)`](../../wiki/stdlib/instant-ru-09dd46b34eb4.md). Также в конструкторе следует указать используемый часовой пояс. Пример:
  
  ```xbsl
  пер МоментСоздания = новый Момент(2025, 05, 01, 23, 30, 40, 345, ЧасовойПояс{UTC+3})
  ```
- С помощью конструктора типа, в который отдельными параметрами вводятся составляющие даты и часовой пояс: [`Момент(Год: Число, Месяц: Число, День: Число, ЧасовойПояс: ЧасовойПояс)`](../../wiki/stdlib/instant-ru-09dd46b34eb4.md). Пример:
  
  ```xbsl
  пер МоментСоздания = новый Момент(2025, 05, 01, ЧасовойПояс{UTC+3})
  ```
- С помощью конструктора типа, в который передаются значения типов `Дата` и `Время`, а также часовой пояс: [`Момент(Дата: Дата, Время: Время, ЧасовойПояс: ЧасовойПояс)`](../../wiki/stdlib/instant-ru-09dd46b34eb4.md). Пример:
  
  ```xbsl
  пер МоментСоздания = новый Момент(Дата{2025-05-01}, Время{23:30:40}, ЧасовойПояс{UTC+3})
  ```
- Из значения типа `ДатаВремя` с помощью метода `ВМомент()`. При этом необходимо указать, для какого часового пояса было сформировано значение типа `ДатаВремя`. Пример:
  
  ```xbsl
  метод Скрипт()
      пер МоментСоздания = новый ДатаВремя(2025, 05, 01, 23, 30, 40, 345)
      пер МоментСозданияФормат = МоментСоздания.ВМомент(ЧасовойПояс{UTC})
  ;
  ```
