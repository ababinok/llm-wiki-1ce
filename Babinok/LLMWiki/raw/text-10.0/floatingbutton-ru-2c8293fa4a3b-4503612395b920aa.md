## Свойства

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Изображение кнопки. Если не задано, то отображается иконка со знаком '+'.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/floatingbutton-ru-2c8293fa4a3b.md).

---

### Картинка

`Доступность: Клиент`

```
Картинка: Картинка
```

Указывает на внутренний компонент [Картинка](../../wiki/interface/picture-ru-efed61d49ad9.md). Может использоваться для дополнительного ее оформления.

---

### Команды

`Доступность: Клиент`

```
Команды: Команда|ГруппаКомандногоИнтерфейса|?
```

Команда или группа команд, назначенных кнопке. Если указана группа команд, то команды группы будут размещены в меню кнопки.

---

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  ПлавающаяКнопка,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на кнопку.
