Чтобы обновить исходное приложение, нужно поднять версию разрабатываемого проекта и загрузить его на сервер. После этого вы сможете обновить приложение, причем будет вызван [обработчик обновления](../../wiki/project/update-app-data-356eca7811d0.md).

[Откройте](../../wiki/project/open-app-in-ide-2c0162ac1160.md) приложение в среде разработки и выполните следующие действия:

1. Нажмите на элемент **Описание проекта**, чтобы открыть панель **Свойства**.
  
  Свойства проекта [Описание иллюстрации](../figures/9078a62f5000816a89c8b1c9e42485d7d7cc01de2ff338ef3a4d02b111a06e17-ba78f7d461f0c665.md)
2. В поле **Версия** нажмите на значок карандаша. Увеличьте номер версии проекта в открывшемся окне. Нажмите **Применить**.
  
  Изменение версии проекта [Описание иллюстрации](../figures/8eb3136b193f724714e96f04f588b1200c9ca07a4ebc97ec2d1f208d010e39be-102fd533ef814dc2.md)
3. [Опубликуйте](../../wiki/project/publish-project-on-server-dade1898bf5e.md) проект на сервере. В результате на сервере появится новая версия [сборки проекта](../../wiki/project/project-assemblies-22705683fda4.md).
  
  
4. Исходное работающее приложение будет автоматически обновлено.
