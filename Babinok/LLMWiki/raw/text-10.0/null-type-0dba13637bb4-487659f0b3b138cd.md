Тип `Null` имеет единственное значение, задаваемое литералом `Null`. Значение `Null` — это специальное значение, которое должно использоваться исключительно в случаях работы с базой данных и результатом исполнения запросов. `Null` означает отсутствие значения, неизвестный результат.

> [!WARNING] важно
> Не рекомендуется использовать данное значение вне фрагментов кода, работающих с СУБД.
