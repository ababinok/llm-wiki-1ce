## Панель команд

Все команды для работы с таблицей должны располагаться в панели команд:

- поиск,
- фильтрация,
- различные действия (например,
  
  Обновить
  
  ).

Исключением является форма, содержащая только действие создания экземпляра сущности. В этом случае соответствующая команда отображается в заголовке.

- Использовать какие-либо другие компоненты для отображения поля поиска.

## Наполнение таблицы

При заполнении таблицы данными убедитесь, что:

- Таблица не перегружена данными и все важные реквизиты легко читаются.
- В таблице настроена важность колонок для управления вниманием пользователя.
- Колонки таблицы содержат понятные заголовки.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

Правильно: над таблицей «Задачи» расположены строка поиска, команда «Обновить», значок фильтра и меню дополнительных команд. [Описание иллюстрации](../figures/77c9fd990805347151757f32641ecaafd00c0ea58c6d811e3b9e1794f6843542-f01564aa7de1b0ae.md)

Не рекомендуется:

- Отображать в таблице слишком много реквизитов.
- Использовать только текст для отображения реквизитов. В этом случае пользователю трудно удерживать внимание и искать нужную информацию. Исключением являются таблицы с небольшим количеством реквизитов — не более 5.

## Множественный выбор строк в таблице

Таблицы поддерживают выделение нескольких строк. Для этого используется флажок выбора массива строк.

При выборе хотя бы одной строки внизу таблицы отображается панель действий. Она содержит действия, которые можно применить к выбранным строкам: удалить, напечатать, скопировать, сгруппировать их и т. д.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

Правильно: в таблице Задачи отмечены три строки; снизу появилась общая панель «Выбрано: 3» с действиями «Печать» и «Удалить». Панель находится под строками и показывает число выбранных объектов. [Описание иллюстрации](../figures/c59c681ab49d55b221589e33e8e1b4b4a00702e797945035038c63c2a7cbd300-e5470b835bb7e47f.md)

Не рекомендуется:

- Отказываться от использования функции множественного выбора в таблицах, которые используют команды строк.
- Делать дополнительные кнопки в интерфейсе для включения/отключения режима множественного выделения и выбора строк.

Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)

Пример множественного выделения строк: флажки рядом со строками и дополнительные кнопки панели позволяют выбирать строки и выполнять команды над выбором. [Описание иллюстрации](../figures/404e413290d0f291b5951974ce039ba658269e6d17704169719fd55953479749-00392ef5fa23841c.md)

## Редактирование таблицы

Существует два режима редактирования данных в строке таблицы:

1. Редактирование данных в каждой ячейке таблицы.
  
  В этом случае принцип редактирования каждой ячейки может быть разным. В первой ячейке пользователь может ввести текст, во второй — выбрать значение из выпадающего списка, в третьей — задать дату.
2. Изменение всех ячеек строки с помощью формы редактирования объекта сущности, которая отображается при нажатии на соответствующую строку.

Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)

## Таблица или список: что выбрать

Таблицы и списки — два основных способа организовать информацию на веб-странице. Каждый из них имеет свои особенности и преимущества, которые важно учитывать при выборе между ними.

### Таблица

- Подходит для отображения большого количества сгруппированных данных.
- Поддерживает множество настроек отображения.
- Для большого объема данных отображает горизонтальные и вертикальные полосы прокрутки.
- Позволяет
  
  [редактировать каждую ячейку отдельно](../../wiki/project/ui-recommendations-table-b0edddd56a91.md)
  
  .

Пример таблицы [Описание иллюстрации](../figures/d12c0eb5018c4ae02ab03da466be3aa4feb7f9025976ef85c906721ec5581d29-de1e80f2e84575ab.md)

### Список

- Строки списка могут отображать сокращенные данные.
- Элементы списка независимы друг от друга.
- Возможности настроек отображения ограничены.
- Элементы списка часто содержат различные визуальные элементы и изображения.
- Содержимое списка не может уходить за пределы области отображения по ширине.

Пример списка: записи отсутствий расположены вертикально, каждая содержит аватар, имя и период. [Описание иллюстрации](../figures/6280fa9ad33e38ef37c9f92a32c3215ec7eb95c7facd9a9abecbebb25e152691-618c61deadfc6329.md)
