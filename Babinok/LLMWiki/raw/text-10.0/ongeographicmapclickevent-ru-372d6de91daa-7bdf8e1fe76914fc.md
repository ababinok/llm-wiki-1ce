`Стд::ГеографическиеКарты::Интерфейс::СобытиеПриНажатииНаГеографическуюКарту<ТипДанныхМаркера>` `Доступность: Клиент`

ТипДанныхМаркера: Тип свойства `Данные` нажатого на карте маркера. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Событие, возникающее при нажатии на карту.

## Конструкторы

### СобытиеПриНажатииНаГеографическуюКарту

`Доступность: Клиент`

```
СобытиеПриНажатииНаГеографическуюКарту(
  Координаты: ГеографическиеКоординаты,
  Маркер: МаркерГеографическойКарты<ТипДанныхМаркера>?,
  СтандартнаяОбработка: Булево)
```

Создает объект

## Свойства

### Координаты

`Доступность: Клиент`

```
Координаты: ГеографическиеКоординаты
```

Координаты точки нажатия на карте.

---

### Маркер

`Доступность: Клиент`

```
Маркер: МаркерГеографическойКарты<ТипДанныхМаркера>?
```

Данные нажатого на карте маркера.

---

### СтандартнаяОбработка

`Доступность: Клиент`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной (системной) обработки события. Если установить данному свойству значение `Ложь`, то стандартная обработка события производиться не будет. Отказ от стандартной обработки не отменяет действие.
