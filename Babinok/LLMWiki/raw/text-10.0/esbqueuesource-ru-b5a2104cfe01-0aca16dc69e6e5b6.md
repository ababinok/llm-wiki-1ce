Узел этого вида предоставляет публичную очередь для отправки сообщений из внешних клиентов по протоколам JMS (Openwire), AMQP, MQTT. Например, внешним клиентом может выступать интеграционная шина SAP NetWeaver Process Integration (в таком случае, подключение выполняется по протоколу JMS).

> [!NOTE] дополнительно
> Ожидаемый тип входящих сообщений для узла [ОчередьШиныИсточник](../../wiki/integration/esbqueuesource-ru-b5a2104cfe01.md) — байтовое сообщение (*BytesMessage*). В SAP PI, в конфигурации канала-получателя, следует использовать параметр `JMS.Message.type` = *bytes* (по умолчанию используется *text*). В случае несоответствия типа входящего сообщения ожидаемому, сообщение будет перенесено в недоставленные сообщений, а в журнал событий будет добавлена соответствующая запись об ошибке.

Узел может быть как связан с [группой участников](../../wiki/project/participant-groups-93f2250d5853.md), так и использоваться самостоятельно.

#### ИмяПользователя

```yaml
ИмяПользователя: ВычисляемоеВыражение|Строка
```

Имя пользователя для подключения внешним клиентом. Источником значения могут выступать:

- Константа,
- Параметр процесса интеграции,
- Свойство участника (если узел связан с группой участников).

---

#### Пароль

```yaml

```

Пароль для подключения внешним клиентом (скрытое значение). Источником значения могут выступать:

- Константа,
- Параметр процесса интеграции,
- Свойство участника (если узел связан с группой участников).
