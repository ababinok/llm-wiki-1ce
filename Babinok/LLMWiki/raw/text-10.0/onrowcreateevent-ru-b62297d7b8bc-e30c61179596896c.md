## Свойства

### СтандартнаяОбработка

`Доступность: Клиент`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной обработки.

При стандартной обработке выполняет создание строки конструктором по умолчанию, если возможно.

В случае, если тип строки является <ТипДанныхУзлов> [ИсточникДанных](../../wiki/interface/datasource-ru-000e18be8897.md) и не входит в список <ТипДанныхЭлемента> [ИсточникДанных](../../wiki/interface/datasource-ru-000e18be8897.md), стандартная обработка откроет форму для создания, а в случае, если Строка была уже заполнена в обработчике – форму редактирования. Возможность открытия формы определяется следующими факторами:

- Тип данных узла не составной
- Тип данных узла можно воссоздать в виде формы с типами
  
  [ПолеВвода](../../wiki/interface/edit-ru-cde85140b31e.md)
  
  (все поддерживаемые в нем типы) и
  
  [Флажок](../../wiki/interface/checkbox-ru-2596f521fb30.md)
  
  (тип
  
  [Булево](../../wiki/stdlib/boolean-ru-7823d4239bcc.md)
  
  ). Если DataType является, например, Структурой, все поля такого типа должны уметь отображаться в виде вышеописанных интерфейсных типах

---

### Строка

`Доступность: Клиент`

```
Строка: ТипДанных?
```

Созданная строка. На вход передается Неопределено. Ожидается, что на выходе будет передана созданная строка с типом DataType

---

### ТипСоздаваемойСтроки

`Доступность: Клиент` `ТолькоЧтение`

```
ТипСоздаваемойСтроки: Тип<ТипДанных>?
```

Тип создаваемой строки. Дает возможность понять тип ожидаемой строки типа DataType.
