Необязательный аргумент — это аргумент, которому соответствует параметр со значением по умолчанию.

В примере ниже описан метод `ВычислитьОбъем()` с параметрами `Длина`, `Ширина` и `Высота`. Для ширины и высоты заданы значения по умолчанию. Поэтому аргументы `10` и `150`, передаваемые в параметры `Ширина` и `Высота`, являются необязательным:

```xbsl
метод ВычислитьОбъем(Длина: Число, Ширина: Число = 80, Высота: Число = 120): Строка
    возврат "Объем равен ${Длина*Ширина*Высота}" 
;

метод Скрипт()
    ВычислитьОбъем(100, Высота = 150, Ширина = 10)
;
```
