Типы для работы с интеграционной шиной.

Пример схемы интеграционной шины между группами «Офис», «Магазины» и «Партнеры». Поток импорта витрины: Таймер → ОпросВитрины → ЕслиОшибкаHttp; успешные сообщения идут в ОтВитрины и далее в «Офис», ошибки — в ФормированиеПротокола → ПротоколОшибок. Поток отправки на WEB-витрину: «Офис» → НаВитрину → УпаковкаДляВитрины (ZIP) → ВызовВитрины → ЕслиОшибкаHttp2 → ФормированиеПротокола → ПротоколОшибок. Обмен с магазинами: «Офис» → ВМагазины → ВходящиеМагазина → «Магазины»; обратный поток «Магазины» → ВОфис → ВходящиеОфиса → «Офис». Сообщения партнёров формируются через ОтПартнеров (из HTTP-сервиса) либо ТаймерОпросаПартнеров → ОпросПартнеров (связан с группой «Партнеры»), затем оба источника идут в ПроверкаУпаковки. Оттуда сообщение поступает в ВходящиеОтПартнеров напрямую или через УпаковкаДляОфиса (ZIP), в зависимости от ContentType; канал передаёт сообщение группе «Офис». Сплошные стрелки обозначают маршруты узлов, голубые пунктирные — связи с группами участников. Это пример схемы, а не обязательная топология любой интеграции.
