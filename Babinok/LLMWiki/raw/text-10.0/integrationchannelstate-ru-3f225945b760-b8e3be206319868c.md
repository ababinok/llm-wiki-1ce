## Свойства

### ДинамикаКоличестваДоставленныхСообщений

`Доступность: Сервер` `ТолькоЧтение`

```
ДинамикаКоличестваДоставленныхСообщений: ДинамикаЗначенияИнтеграции
```

Динамика изменения количества сообщений, которые были получены участником интеграции. Сообщение считается доставленным после того, как система-получатель подтвердила доставку.

---

### ДинамикаКоличестваСообщенийВКанале

`Доступность: Сервер` `ТолькоЧтение`

```
ДинамикаКоличестваСообщенийВКанале: ДинамикаЗначенияИнтеграции
```

Динамика изменения количества сообщений, которые находятся в канале.

---

### КоличествоДоставленныхСообщений

`Доступность: Сервер` `ТолькоЧтение`

```
КоличествоДоставленныхСообщений: Число
```

Количество сообщений, доставленных участнику после запуска сервера. Сообщение считается доставленным после того, как система-получатель подтвердила доставку.

---

### КоличествоСообщенийВКанале

`Доступность: Сервер` `ТолькоЧтение`

```
КоличествоСообщенийВКанале: Число
```

Количество сообщений в канале, которые ожидают получения участником.

---

### ПодключениеАктивно

`Доступность: Сервер` `ТолькоЧтение`

```
ПодключениеАктивно: Булево
```

Признак, что пользователь участника канала подключен к брокеру шины в настоящий момент.

---

### ПоследнееПодключение

`Доступность: Сервер` `ТолькоЧтение`

```
ПоследнееПодключение: Момент?
```

Момент, когда пользователь участника канала подключался к брокеру шины последний раз. Если не подключался, то `Неопределено`.

---

### ПоследняяАктивность

`Доступность: Сервер` `ТолькоЧтение`

```
ПоследняяАктивность: Момент?
```

Момент, когда участник последний раз отправил в канал сообщение или подтвердил получение сообщения из канала. Если не отправлял и не подтверждал, то `Неопределено`.
