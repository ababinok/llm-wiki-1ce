## Свойства

### Заголовок

`Доступность: Клиент`

```
Заголовок: Авто|Строка
```

Заголовок пустого состояния. В заголовок помещаются 2 строки текста. Если задана пустая строка, заголовок отображаться не будет.

---

### Изображение

`Версия 9.0 и выше`

`Доступность: Клиент`

```
Изображение: Авто|Url|ДвоичныйОбъект.Ссылка|?
```

Изображение при пустом состоянии. Не рекомендуется использовать изображение, когда список расположен во всплывающем окне. При `Неопределено` изображение отображаться не будет.

---

### Изображение

`Версия 8.0 и ниже`

`Доступность: Клиент`

```
Изображение: Авто|ДвоичныйОбъект.Ссылка|?
```

Свойство заменено на [Изображение](../../wiki/interface/listemptystatepresentation-ru-5ecb2fd155ed.md).

---

### Команды

`Доступность: Клиент`

```
Команды: Авто|ФрагментКомандногоИнтерфейса|?
```

Команды, помогающие выйти из пустого состояния.

Отображение команд в пустом состоянии зависит от их количества:

- Если фрагмент командного интерфейса содержит не более 2х команд, то они отобразятся в виде кнопок.
- Если фрагмент содержит более 2х команд, то первая отобразится как кнопка, а остальные попадут в "Ещё". При
  
  `Неопределено`
  
  команды отображаться не будут.

---

### Пояснение

`Доступность: Клиент`

```
Пояснение: Авто|Строка
```

Поясняющий текст пустого состояния. В поясняющий текст помещаются 3 строки текста. Если задана пустая строка, поясняющий текст отображаться не будет.
