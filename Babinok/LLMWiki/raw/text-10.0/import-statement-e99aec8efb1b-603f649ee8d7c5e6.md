Первым блоком в модуле может быть блок импортов — записей вида:

```xbsl
импорт ПространствоИмен
```

В модуле, где объявлен импорт, можно использовать просто `ИмяТипа` без уточнения [пространства имен](../../wiki/language/namespaces-2e1d55efb91e.md).

Основное назначение блока импортов — сокращение наименований типов, объявленных в других модулях.

## Пример

```xbsl
импорт Общее
импорт Общее::Разделы::ИнструментыИнтеграции

метод ОписаниеПримера(): Пример.ОписаниеПримера
    возврат новый Пример.ОписаниеПримера(
        Название = "План обмена с конвертацией", 
        КраткоеОписание = "Обмен данными с использованием плана обмена и правил конвертации",
        Идентификатор = Ууид{dbc78308-2ee6-4d54-8bf6-0f6f84081459}
    )
;
```
