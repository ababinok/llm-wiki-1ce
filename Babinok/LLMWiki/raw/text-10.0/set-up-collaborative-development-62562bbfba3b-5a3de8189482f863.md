Чтобы настроить групповую разработку в проекте, выполните следующие действия:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. На вкладке **Проекты** щелкните на нужный проект.
3. В правом верхнем углу кликните на иконкуПиктограмма «Значок меню». [Описание иллюстрации](../figures/eeec48637e32c4f2ec0cc9ade2b45debe2df98791c721a93c2826cace650091a-7826430e32669bbb.md) и выберите **Настроить репозиторий**.
  
  
4. Выберите вариант размещения репозитория:
  
  - **Создать новый внутренний Git-репозиторий** — «1С:Предприятие.Элемент» создаст репозиторий в одном из подключенных хранилищ репозиториев GitLab. Если ни одно не подключено, этого пункта в диалоге не будет.
    
    [Как подключить к серверу систему управления репозиториями GitLab](../../wiki/project/connect-to-gitlab-daf8c8c732dc.md)
  - **Использовать существующий внешний Git-репозиторий** — если у вас уже есть Git-репозиторий, доступный по протоколам HTTP или SSH, вы можете использовать его.
    
    [Как подключить внешний Git-репозиторий](../../wiki/project/connect-git-repository-5006dd5715e6.md)
    
    [Как импортировать проект из Git-репозитория](../../wiki/project/import-project-from-git-repository-950a4a356ae6.md)
5. Укажите префикс, который будет добавляться перед номером задачи в проекте. По умолчанию «1С:Предприятие.Элемент» генерирует префикс задач на основе имени проекта.
  
  > [!NOTE] примечание
  > Обратите внимание, что для префикса допускается длина не более 10 символов и применяется транслитерация с использованием латинского алфавита.
  
  Диалог «Репозиторий» предлагает создать новый внутренний Git-репозиторий либо использовать существующий внешний. [Описание иллюстрации](../figures/0f3ea63594acee1d3097abeb92c84dbdfdecb1627ebba55a3bb131a0aaeb8c3b-9794b9705a7fa084.md)
  
  Префикс задач отображается в панели свойств проекта:
  
  В карточке проекта показан префикс задач DEMOCRM. Это пример значения префикса в свойствах проекта. [Описание иллюстрации](../figures/2e427637d6bfc1ef3b68714b26ab570b88bc9d7627df9389190b1eb370901a85-f52ce668dde3fac8.md)
  
  В соответствии с форматом наименования задач — **<Префикс>-<НомерЗадачи>** — задача в текущем проекте может называться, например, так: **DEMOCRM-123**.
  
  При необходимости префикс задачи можно изменить. Для этого:
  
  - В панели свойств проекта нажмите на значок меню в правом верхнем углу и выберите **Изменить префикс задач**:
    
    В меню карточки проекта выбран пункт «Изменить префикс задач». [Описание иллюстрации](../figures/3f0565f3d87519fe7a5f77df7fcf83610951690f40e54afd42b9b705c34b484a-efdd41fff50487ff.md)
  - В диалоговом окне введите новый префикс:
    
    Диалог изменения префикса задач содержит поле нового префикса и кнопку «Продолжить». [Описание иллюстрации](../figures/31f028ac6b270fda6b8ccf438a981fa88a4dcc9625e677a501ea7a7d44ca0815-a4da817232acec41.md)
6. «1С:Предприятие.Элемент» отобразит уведомления о создании репозитория:
  
  Уведомления настройки групповой разработки показывают два состояния: «Настройка репозитория проекта началась» с ожиданием доступности и «Репозиторий успешно создан для проекта» с разрешением начинать групповую разработку.. [Описание иллюстрации](../figures/18bd631ed6a1b3967e77a753ba816fd862a4ed5b25898ed4cbd48446f6401370-8259950c04798923.md)
7. После того как вы выполните все указанные выше шаги, на вкладках проекта **Задачи**, **Ветки** и **Разработчики** станут доступны соответствующие элементы групповой разработки:
  
  Список веток в панели «Ветки» [Описание иллюстрации](../figures/997b31623e79b2c2f5045a920a55e2b0bdcdfa2482a489e6d2f25c5359d9fdf5-c9c9bdd914b1eed3.md)

## Изменить настройки групповой разработки

Вы можете изменить настройки групповой разработки для репозитория следующим образом:

1. Нажмите на значок меню в правом верхнем углу карточки проекта и выберите **Репозиторий**.
  
  В меню карточки проекта выбран пункт «Репозиторий». [Описание иллюстрации](../figures/41d20559c0c4a9e2db7fa34ffd830255c189f60f5ede68e5da2bd550e5d51619-3dbc226026acf51c.md)
2. Появится окно, содержащее основные сведения о текущем репозитории. В правом верхнем углу этого окна нажмите на значокПиктограмма «Значок меню». [Описание иллюстрации](../figures/eeec48637e32c4f2ec0cc9ade2b45debe2df98791c721a93c2826cace650091a-7826430e32669bbb.md) и выберите пункт **Настройки**.
  
  Переход к настройкам репозитория [Описание иллюстрации](../figures/b3730027da0369a9bbc92e132dde4a376b0c33b71874395a3cf3fcfa16603b40-9349657827df5095.md)
3. В открывшемся окне включите или отключите нужные настройки и нажмите **Сохранить**.
  
  Включение проверки задач [Описание иллюстрации](../figures/8d5e6d2bcd4cd6b8fa702e699b67f8847595ee4c3181492b290510fc89bcd6b8-0bae40531b71c9d0.md)
