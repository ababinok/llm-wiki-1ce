Описывает элементы проекта, в которых будет осуществляться [регистрация изменения в данных](../../wiki/integration/data-exchange-385ce993615c.md), и участников обмена.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка
```

Реквизит плана обмена, значение которого «1С:Предприятие.Элемент» будет использовать в качестве [представления элемента плана обмена](../../wiki/integration/exchange-plan-project-element-c0fc3c4bb4ef.md).

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

##### Разрешения

Набор разрешений на выполнение основных операций с планом обмена.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Создание

Задает разрешение на создание нового узла плана обмена. Проверяется непосредственно перед записью изменения в базу данных.

Задает разрешение на чтение данных плана обмена из базы данных. Проверяется только в момент загрузки ссылки из базы данных.

Задает разрешение на изменение узла плана обмена, хранящегося в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

Задает разрешение на удаление узла плана обмена. Проверяется в момент вызова удаления.

</details>

Массив полей, по которым выполняется расчет разрешений доступа. Заполняется при выборе значения [РазрешенияВычисляютсяДляКаждогоОбъекта](../../wiki/project/accesscontrol-ru-c40ccedbcdb4.md).

#### ПередачаДанных

```yaml
ПередачаДанных: 
    Использовать: Булево
    ВидПакетаПередачиДанных: ВидПакетаПередачиДанных
    ИнтегрируемыеПриложения: 
        -
            Имя: Строка
            ИмяПланаОбменаВИнтегрируемомПриложении: Строка
```

Содержит настройки, которые позволяют организовать передачу сообщений обмена данными между приложениями.

<details>
<summary>**Свойства**</summary>

##### Использовать

Признак использования передачи данных. Значение по умолчанию — **Ложь**.

##### ВидПакетаПередачиДанных

Вид разбиения изменений данных на пакеты. Изменения в пакете обрабатываются либо все, либо ни одного. Задается значением перечисления [ВидПакетаПередачиДанных](../../wiki/project/datatransferbatchkind-ru-dade307e44fe.md). Значение по умолчанию — [ВсеИзменения](../../wiki/project/datatransferbatchkind-ru-dade307e44fe.md).

##### ИнтегрируемыеПриложения

Интегрируемые приложения, с которыми план обмена может выполнять обмен данными.

Конкретный экземпляр приложения для узла плана обмена выбирается в режиме выполнения. Группа может содержать несколько приложений и формирует список допустимых приложений для обмена данными с узлом плана обмена.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента проекта интегрируемого приложения, с которым план обмена может выполнять обмен данными. Допускается полное или короткое имя — аналогично именованию элементов проекта в составе плана обмена.

##### ИмяПланаОбменаВИнтегрируемомПриложении

Имя плана обмена во внешнем проекте, по которому устанавливается соответствие для обмена данными.

Если структура внешнего проекта отличается от текущего, то в нем может не быть плана обмена с тем же именем. В этом случае соответствие устанавливается по значению свойства **ИмяПланаОбменаВИнтегрируемомПриложении**.

Если **ИмяПланаОбменаВИнтегрируемомПриложении** не задано, поиск во внешнем проекте выполняется по имени текущего плана обмена: сначала по полному имени с пространством имен, при отсутствии — по короткому. Если найдено несколько элементов с одним коротким именем или ни одного, обмен данными прерывается.

Если **ИмяПланаОбменаВИнтегрируемомПриложении** задано, поиск выполняется по этому имени вместо имени текущего плана обмена. При использовании короткого имени поиск выполняется только по нему. Если найдено несколько элементов или ни одного, обмен данными прерывается.

Во внешнем проекте используется аналогичная настройка: соответствие устанавливается по совпадению значений **ИмяПланаОбменаВИнтегрируемомПриложении** в обоих проектах. Например, в текущем проекте есть план обмена **ПланОбмена1** со свойством **ИмяПланаОбменаВИнтегрируемомПриложении = ПО**, а во внешнем — **ПланОбмена2** с таким же значением свойства. Соответствие будет найдено по совпадению этих значений.

</details>

</details>

#### КонвертацияДанных

```yaml
КонвертацияДанных: 
    СхемаДанных: 
        ВидСхемыДанных: ВидСхемыДанных
    Элементы: 
        -
            Слева: Строка
            Справа: Строка
            Поля: 
                -
                    Слева: Строка
                    Справа: Строка
                    Действие: ДействиеЧастиЭлемента
                    ТипСправа: Тип[]
            ТабличныеЧасти: 
                -
                    Слева: Строка
                    Справа: Строка
                    Действие: ДействиеЧастиЭлемента
                    Поля: 
                        -
                            Слева: Строка
                            Справа: Строка
                            Действие: ДействиеЧастиЭлемента
                            ТипСправа: Тип[]
            Влево: 
                ПослеКонвертации: Строка
            Вправо: 
                ПослеКонвертации: Строка
```

Описывает правила конвертации, используемые при [чтении и записи данных сообщений обмена](../../wiki/integration/data-exchange-385ce993615c.md).

<details>
<summary>**Свойства**</summary>

##### СхемаДанных

Описание внешней системы, состава и структуры данных, участвующих в обмене.

Схема данных формируется автоматически по элементам проекта, входящим в состав плана обмена, с учетом заданных правил конвертации данных.

<details>
<summary>**Свойства**</summary>

##### ВидСхемыДанных

Определяет вид схемы данных. Может принимать следующие значения:

- `Проект1СПредприятияЭлемент` (значение по умолчанию)
  
  Внешняя система — «1С:Предприятие.Элемент». Обмен данными выполняется между приложениями «1С:Предприятие.Элемента» в формате XML, который используется для сериализации данных объектов, порождаемых элементами проекта «1С:Предприятие.Элемента».
- `Конфигурация1СПредприятия8`
  
  Внешняя система — «1С:Предприятие». Обмен данными выполняется между приложением «1С:Предприятие.Элемента» и информационной базой «1С:Предприятия» в формате XML, который используется механизмом обмена данными «1С:Предприятия».

</details>

##### Элементы

Описывает правила конвертации на уровне отдельных сущностей, их полей и табличных частей.

<details>
<summary>**Свойства**</summary>

##### Слева

Задает первого участника конвертации данных. Слева располагаются элементы проекта, входящие в состав плана обмена (внутренние данные).

##### Справа

Задает второго участника конвертации данных. Справа располагаются объекты внешней системы (внешние данные), для которых описывается взаимосвязь с элементами проекта **Слева**.

Если свойство **ВидСхемыДанных** имеет значение `Конфигурация1СПредприятия8`, то необходимо указывать полные имена объектов конфигурации «1С:Предприятия».

##### Поля

Описывает правила конвертации, применяемые к полям (реквизитам, измерениям и ресурсам). Позволяет переопределить правила по умолчанию.

<details>
<summary>**Свойства**</summary>

##### Слева

Имя поля элемента проекта, указанного в свойстве **Слева**.

##### Справа

Имя поля объекта внешней системы, указанного в свойстве **Справа**.

##### Действие

Действие, которое необходимо выполнить со значениями указанных полей при конвертации.

##### ТипСправа

Тип поля **Справа**. Позволяет переопределить тип поля при генерации объектов, описывающих внешние данные.

Можно указать следующие типы:

- примитивные типы (например,
  
  `Строка`
  
  ,
  
  `Число`
  
  и т. д.);
- типы, порожденные элементами проекта, которые входят в состав плана обмена (например,
  
  `<ИмяЭлементаПроектаВСоставеПланаОбмена>.Ссылка`
  
  ).

*Опциональное свойство*. Если не задано, то при генерации будет использоваться тип поля **Слева**.

</details>

##### ТабличныеЧасти

Описывает правила конвертации, применяемые к табличным частям. Позволяет переопределить правила по умолчанию.

<details>
<summary>**Свойства**</summary>

##### Слева

Имя поля элемента проекта, указанного в свойстве **Слева**.

##### Справа

Имя поля объекта внешней системы, указанного в свойстве **Справа**.

##### Действие

Действие, которое необходимо выполнить со значениями указанных полей при конвертации.

##### Поля

Описывает правила конвертации, применяемые к полям табличной части. Позволяет переопределить правила по умолчанию.

<details>
<summary>**Свойства**</summary>



</details>

#### ПараметрыЗаписи

```yaml
ПараметрыЗаписи: 
    -
        Имя: Строка
        Тип: Тип[]
```

Дает возможность параметризовать запись объекта. В обработчики `ПередЗаписью()`, `ПослеЗаписи()` и перегрузку метода `Записать()` добавляются соответствующие параметры. Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Множество типов, доступных для параметра.

</details>

Свойство является коллекцией элементов, определяющих имя параметра и «набор типов», задающий множество типов, доступных для параметра.

#### ПространстваБлокировок

```yaml
ПространстваБлокировок: 
    -
        Имя: Строка
        Ид: Ууид
        Поля: Строка[]
```

Одно или несколько дополнительных пространств управляемых блокировок.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Ид

Идентификатор элемента проекта. «1С:Предприятие.Элемент» создает этот идентификатор автоматически.

##### Поля

Последовательность имен реквизитов, которые входят в дополнительное пространство блокировок.

</details>

#### РежимУдаления

```yaml
РежимУдаления: РежимУдаления
```

[Режим удаления](../../wiki/project/data-deletion-141a62f69ff7.md) объекта:

- Немедленно
  
  — объект удаляется немедленно,
- ПометкаУдаления
  
  — объект помечается на удаление.
