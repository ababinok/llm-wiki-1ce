[Регистры сведений](../../wiki/data/information-register-project-element-8932693c91b1.md) используются для хранения произвольных данных в разрезе нескольких измерений, например цен товаров в разрезе номенклатуры и типа цен.

Информацию в регистре можно представить в виде таблицы, имеющей одну или несколько колонок. По своему назначению колонки делятся на три группы:

**Измерения** — это «координаты» или значения, для которых в регистре хранится некоторая информация. Например, в регистре **Цены товаров** измерениями будут товар и покупатель, для которого данный товар имеет некоторую цену. **Ресурсы** — это основная информация, хранимая в регистре. Например, в том же регистре это будет цена товара. **Реквизиты** — это вспомогательная информация, которая относится только к одной строке таблицы. Например, фамилия менеджера, который установил цену на товар.

Регистры могут быть [периодическими](../../wiki/data/periodic-information-register-2e754cdbda44.md) (хранят историю изменений данных) или непериодическими (хранят только актуальное состояние).

## Свойства

#### Имя

```yaml

```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

  `ДатаВремя`
  
  );
- [День](../../wiki/data/informationregisterperiodicity-ru-a47b12feaeb8.md)
  
  — раз в день (тип
  
  `Дата`
  
  );
- [Месяц](../../wiki/data/informationregisterperiodicity-ru-a47b12feaeb8.md)
  
  — раз в месяц (тип
  
  `Дата`

- [Квартал](../../wiki/data/informationregisterperiodicity-ru-a47b12feaeb8.md)

Содержит [настройки прав доступа](../../wiki/security/automatically-grant-permissions-to-user-groups-c39cf49a7075.md) к записям регистра накопления.

<details>
<summary>**Свойства**</summary>

##### Разрешения

Набор разрешений на выполнение основных операций с регистром сведений.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Чтение

Задает разрешение на чтение записи регистра сведений из базы данных. Проверяется только в момент загрузки ключа записи из базы данных.

##### Изменение

Задает разрешение на изменение записи регистра сведений, хранящейся в базе данных. Проверяется перед записью изменения в базу данных для старого и нового состояния элемента данных.

</details>

##### РасчетРазрешенийПо

Массив полей, по которым выполняется расчет разрешений доступа. Заполняется при выборе значения **РазрешенияВычисляютсяДляКаждогоОбъекта**.

</details>

## Дочерние элеметы

#### Ресурсы

```yaml
Ресурсы: РесурсРегистраСведений[]
```

Ресурсы регистра, используемые для хранения основной информации (цены, количества, значений и т. д.) в разрезе измерений.

---

#### Реквизиты

```yaml
Реквизиты: РеквизитРегистраСведений|Регистратор[]
```

Реквизиты для хранения вспомогательной (неключевой) информации о записях регистра.

---

#### Измерения

```yaml
Измерения: ИзмерениеРегистраСведений[]
```

Ключевые реквизиты, описывающие разрезы, в которых хранится информация. В качестве типов измерений нельзя использовать типы `Строка` и `Байты` неограниченной длины, а также тип `ДвоичныйОбъект.Ссылка`. Список измерений не может быть пустым.

Значения всех измерений записи образуют ключ этой записи: ключ записи должен быть уникален в пределах всего регистра. Таким образом, ключ однозначно идентифицирует запись регистра. Порядок измерений имеет значение — по ним в основной таблице регистра сведений создается индекс (измерения учитываются в том порядке, в котором они описаны).
