В данной статье перечислены свойства процесса интеграции, которые можно задать в режиме исполнения.

> [!WARNING] важно
> Процессы интеграции недоступны в облачной версии «1С:Предприятие.Элемента».

## Регистрировать доставку в журнале событий

Поставьте флажок в этом пункте, если хотите, чтобы факт доставки сообщений регистрировался и отображался в журнале событий. По умолчанию доставка сообщений не регистрируется в журнале.

## Максимальное количество повторных доставок

Следует указать целое неотрицательное число. Если доставка сообщения не удалась, «1С:Предприятие.Элемент» повторит отправку столько раз, сколько указано в данном поле. По умолчанию количество повторных доставок не задано, поэтому попытка доставить сообщение будет повторяться бесконечное число раз.

## Таймаут устаревания недоставленных сообщений в формате ДД.ЧЧ

Время, в течение которого недоставленные сообщения будут храниться в [канале недоставленных сообщений](../../wiki/project/undelivered-message-channel-54c826eff47a.md). Длительность указывается в формате ДД.ЧЧ. По умолчанию задано значение 07.00 (7 дней).

## Имя процесса для внешнего сервиса интеграции 1С:Предприятие

Определяет имя процесса в сервисе описания каналов, а также используется в имени канала внешнего сервиса интеграции. Для вновь созданных процессов интеграции значение свойства соответствует полному имени процесса (например, `e1c::ТестовыйПроект::Основной::ОбменССайтом`). Для существующих процессов при переходе на версию «Элемента» 5.2 или выше значение будет соответствовать полному имени процесса без поставщика и названия проекта (например, `Основной::ОбменССайтом`). Это сделано для сохранения совместимости с существующими сервисами интеграции «1С:Предприятия».

> [!WARNING] важно
> При изменении имени процесса обмен сообщениями с ранее настроенными каналами сервиса интеграции «1С:Предприятия» будет остановлен. Для восстановления обмена в конфигураторе системы «1С:Предприятие» требуется вручную обновить имя процесса в настройках имени канала сервиса интеграции. Для изменения имени процесса не рекомендуется выполнять повторный импорт из сервиса описания каналов, так как в этом случае недоставленные сообщения будут утеряны, а время простоя при восстановлении обмена может увеличиться.

## Задание свойств процесса интеграции

Чтобы задать свойства процесса интеграции, выполните следующие действия:

1. Откройте страницу приложения «1С:Предприятие.Элемента» и нажмите на карточку процесса интеграции:
  
  Карточка процесса интеграции [Описание иллюстрации](../figures/97a484b1d85cb9773d9f4fa0da8834e98e31c6362c7fc6d3dac852b9a4b4ac63-28a356dec11f2733.md)
2. Откроется схема процесса интеграции. На вкладке **Свойства** отображаются параметры и свойства процесса интеграции:
  
  Редактор процесса интеграции: схема находится слева, вкладка «Свойства» справа содержит параметры и свойства процесса. [Описание иллюстрации](../figures/2ed693b0a1c64e22e1156a1e21949b4d2b3e82a67678c1979d9b6e1befdc3cb1-33243421af2d9716.md)
3. Задайте необходимые значения свойств и нажмите **Применить**.

> [!NOTE] дополнительно
> Если вы изменяете значения свойств для запущенного процесса интеграции, применение параметров вызовет остановку и повторный запуск процесса. Это может занять значительное время.
