Чтобы найти измененные элементы проекта, перейдите в представление **1С**. Подсистемы, в которых есть изменения, будут выделены, а для измененных элементов проекта и модулей будут отображаться следующие индикаторы:

- Н
  
  — обозначает файлы, не добавленные в индекс;
- Д
  
  — обозначает файлы, добавленные в индекс;
- И
  
  — обозначает файлы, измененные по сравнению с репозиторием;
- У
  
  — обозначает удаленные файлы;
- П
  
  — обозначает переименованные файлы;
- С
  
  — обозначает скопированные файлы;
- К
  
  — обозначает конфликтующие файлы.

Индикаторы измененных файлов в навигаторе проекта [Описание иллюстрации](../figures/8cdd31536f02c45fb1f2149fa03531ec60133a2a0d6c12387ee367ada626f528-064c690d23a0cdf5.md)

Другой способ быстро найти измененные элементы проекта — перейти в представление **Система управления версиями**. Все измененные файлы будут отображаться в подгруппах **Промежуточные изменения** и **Изменения** группы **Коммит**.

Изменённые файлы в системе управления версиями разделены на «Промежуточные изменения» и «Изменения»; справа у каждого файла показан значок состояния изменения. [Описание иллюстрации](../figures/efba3944c25463ac9acdf0c039e81fb8eebf05cb820a7400a2a66bed32f5e572-7513593af8fa4309.md)

## Просмотр истории изменений

Чтобы посмотреть историю изменений для элемента проекта, выполните следующие действия:

1. В навигаторе проекта щелкните правой кнопкой мыши на нужный объект и выберите пункт **Открыть историю** в контекстном меню.
  
  Открыть историю [Описание иллюстрации](../figures/9ca4cea120c600ce5c533728d2e64fc849eed35980e9ab825aa16b5b6e7a2ef9-1a46788c855314a9.md)
2. Для выбранного объекта откроется представление **История**, содержащее список всех коммитов, в рамках которых данный объект был изменен. Для отображения подробной информации о коммите наведите на него мышку и нажмите на значокПиктограмма «Значок просмотра информации о коммите». [Описание иллюстрации](../figures/aaaef3260d5cc96c5a53f421a05d2a47e7713f3e737f90e50a0848a61a1049b0-3d7a5bfc7fb91631.md).
  
  Представление «История» [Описание иллюстрации](../figures/99f6209be99c666b418e6ed7b4a42455de2a2e00d9d1edd6083c53d385ffeef6-82e1be7a7afc5942.md)
3. Вы также можете посмотреть, какие изменения были внесены в файл объекта в рамках выбранного коммита. Для этого в разделе **Измененные файлы** нажмите на имя файла, чтобы открыть его в [панели diff](../../wiki/project/find-changed-lines-in-file-9435aa4a525c.md).
