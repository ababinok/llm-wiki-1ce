Чтобы узнать, запущен ли «Менеджер хостов внешних компонент», проверьте состояние его службы/демона.

- Windows
- Linux

1. В строке поиска Windows введите «Службы».
2. Запустите приложение
  
  Службы
  
  (
  
  Services
  
  ).
3. Найдите в списке службу
  
  `1c-enterprise-echostmanager`
  
  и посмотрите ее состояние.

В списке локальных служб выделена 1c-enterprise-echostmanager. [Описание иллюстрации](../figures/bf27ba8746c8d6a6d4c3c7a7ce631ea1984d1dc5501c3d157552ac2ea614d845-21d79cbfe42eaf97.md)
