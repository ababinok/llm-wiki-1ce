`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПроцессаИнтеграции}.СчетчикИзмененныхСообщенийТрансляторов` `Доступность: Сервер`

Предопределенная метрика-счетчик измененных сообщений в трансляторе. Содержит один параметр: имя узла, в котором увеличилась метрика.

При перезапуске процесса значение метрики НЕ обнуляется.

## Методы

### ПолучитьИсториюИзмерений

`Доступность: Сервер`

```
ПолучитьИсториюИзмерений(
  От: Момент,
  До: Момент
): ЧитаемыйМассив<ИзмерениеМетрикиИнтеграции>
```

Возвращает массив измерений счетчика измененных сообщений в трансляторе в указанном временном диапазоне. Элементы массива отсортированы по возрастанию значения момента измерения

[МоментИзмерения](../../wiki/integration/integrationmetricmeasurement-ru-5390dae879ab.md)

.

`Доступность: Сервер`

```

```

Возвращает текущие измерения счетчика измененных сообщений в трансляторе. Значение момента - значение на момент вызова.
