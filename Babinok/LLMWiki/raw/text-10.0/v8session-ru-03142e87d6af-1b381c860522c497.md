## Методы

### ЗавершитьСеанс

`Доступность: Сервер`

```
ЗавершитьСеанс(СообщениеОбОшибке: Строка = "")
```

Удаляет сеанс. При попытке обращения к кластеру серверов от имени удаленного сеанса будет выброшено исключение.

`СообщениеОбОшибке`

- сообщение для пользователя, которое содержит причину завершения сеанса.

---

### ПрерватьТекущийСерверныйВызов

`Доступность: Сервер`

```
ПрерватьТекущийСерверныйВызов(СообщениеОбОшибке: Строка = "")
```

Прерывает выполнение текущего серверного вызова.

`СообщениеОбОшибке`

- сообщение для пользователя, которое содержит причину прерывания выполнения текущей операции.
