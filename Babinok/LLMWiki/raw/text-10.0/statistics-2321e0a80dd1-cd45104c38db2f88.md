«1С:Предприятие.Элемент» позволяет интегрировать такие внешние сервисы для сбора статистических данных, как Яндекс Метрика, Google Analytics и ВК пиксель. Эти сервисы предоставляют инструменты для глубокого анализа данных, которые помогают продвигать и оптимизировать рекламные кампании целевого приложения на «1С:Предприятие.Элементе».

> [!WARNING] важно
> При использовании некоторых сервисов статистики требуется согласие конечного пользователя на сбор персональных данных. Это стоит учитывать, подключая сервис статистики «1С:Предприятие.Элемента». Необходимо проконсультироваться с юристом и сделать форму-соглашение (или аналогичный инструмент) для получения и хранения согласия пользователя на сбор персональных данных. Если пользователь отказывается предоставлять персональные данные, сервисы сбора статистики использовать не рекомендуется.

## Типы для работы с сервисом статистики

Сервис статистики реализован с помощью типа [`СтатистикаИспользованияПриложения`](../../wiki/interface/applicationusagestatistics-ru-83339db78941.md). Доступные сервисы сбора статистики описаны в перечислении [`СервисСтатистикиИспользованияПриложения`](../../wiki/interface/applicationusagestatisticsservice-ru-fa7beae9dc3f.md).

## Пример

Чтобы начать работу с сервисом статистики, например Яндекс Метрикой, сразу после открытия приложения, используйте метод [`НачатьСборСтатистикиЯндексМетрики()`](../../wiki/interface/applicationusagestatistics-ru-83339db78941.md), который запускает механизм сбора статистики использования приложения.

Модуль клиентского приложения

```xbsl
@Обработчик
метод ПослеСоздания()
    СтатистикаИспользованияПриложения.НачатьСборСтатистикиЯндексМетрики(
        ИдПриложения = "<код_приложения_Яндекс_Метрики>",
        Вебвизор = Истина,
        КартаНажатий = Истина,
        ОтслеживаниеСсылок = Истина,
        КодПодтвержденияВебмастера = "<ключ_Яндекс_Вебмастера>"
    )
;
```

После инициализации сервиса станут доступны вызовы его методов.

Например, пусть требуется отслеживать количество нажатий на кнопку **Нравится**. Тогда разработчику необходимо зарегистрировать цель при нажатии на эту кнопку с помощью метода [`СтатистикаИспользованияПриложения.ЗарегистрироватьЦель()`](../../wiki/interface/applicationusagestatistics-ru-83339db78941.md). В качестве параметра в метод можно передать данные в виде корректной JSON-строки, если такая возможность поддерживается сервисом статистики.

Тогда для обработчика `ПриНажатии` целевой кнопки, которая подтверждает выполнение условий для регистрации заданной цели (`button_clicked`), следует написать следующий код:

Обработчик нажатия на целевую кнопку

```xbsl
метод ЗафиксироватьЦельПриНажатииНаКнопкуНравится(Источник: Кнопка, Событие: СобытиеПриНажатии)
    // Строка JSON указана явно для упрощения
    СтатистикаИспользованияПриложения.ЗарегистрироватьЦель("button_clicked", "{\"count\": 1}")
;
```

По умолчанию при вызове метода [`СтатистикаИспользованияПриложения.ЗарегистрироватьЦель()`](../../wiki/interface/applicationusagestatistics-ru-83339db78941.md) данные отправляются во все сервисы. Если настройки сервисов отличаются, то в параметре **Сервисы** метода можно указать, в какой именно сервис необходимо отправить данные.
