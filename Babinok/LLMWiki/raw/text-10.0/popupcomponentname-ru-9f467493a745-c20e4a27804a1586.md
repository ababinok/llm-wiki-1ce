## Методы

### ОткрытьВоВсплывающемОкне

`Версия 10.0 и выше`

`Доступность: Клиент` `Статический`

```
@ИменованныеПараметры
ОткрытьВоВсплывающемОкне(
  РасположениеВсплывающегоОкна: Компонент|РасположениеВсплывающегоОкна = РасположениеВсплывающегоОкна.АктивныйКомпонент,
  ОжидатьЗакрытия: Булево = Истина,
  Свойство1Компонента: ТипСвойства1Компонента,
  Свойство2Компонента: ТипСвойства2Компонента,
  СвойствоNКомпонента: ТипСвойстваNКомпонента
): ResultType|Undefined
```

>

Вызов возможен только с именованными параметрами

Открывает всплывающий компонент данного типа во всплывающем окне. Допускает только именованную форму вызова.

Параметры:

- `РасположениеВсплывающегоОкна`
  
  - указывает местоположение открываемого всплывающего окна на экране: либо рядом с указазнным компонентом, либо согласно одному из значений перечисления
  
  [РасположениеВсплывающегоОкна](../../wiki/interface/popupwindowlocation-ru-e25539de959c.md)
  
  ,
- `ОжидатьЗакрытия`
  
  - если равен
  
  `Истина`
  
  , то метод не вернет управление, пока окно не закроется,
- `СвойстваКомпонента`
  
  - дополнительные свойства компонента, которые будут установлены при его открытии.

**Перегрузка** [ВсплывающийКомпонент::ОткрытьВоВсплывающемОкне(РасположениеВсплывающегоОкна: Компонент|РасположениеВсплывающегоОкна = РасположениеВсплывающегоОкна.АктивныйКомпонент, ОжидатьЗакрытия: Булево = Истина): ТипРезультата?](../../wiki/interface/popupcomponent-ru-260aa5761385.md)

#### Примеры

```xbsl
метод ОткрытьМойВсплывающийКомпонент()
    знч Результат = МойВсплывающийКомпонент.ОткрытьВоВсплывающемОкне(РасположениеВсплывающегоОкна = РасположениеВсплывающегоОкна.ПозицияКурсора, ОжидатьЗакрытия = Ложь)
;
```

Открывает компонент во всплывающем окне возле курсора мыши, без ожидания закрытия.

## Обработчики

### ПослеСоздания

```
ПослеСоздания()
```

Вызывается после создания UI-компонента системой:

- установлены значения свойств самого компонента, указанные в описании,
- созданы внутренние компоненты данного компонента, значения их свойств установлены из описаний их экземпляров,
- обработчики событий подписаны на события самого компонента и его внутренних компонентов. Предназначено для дополнительной инициализации свойств компонента на клиенте и вызова прикладной логики инициализации компонента.
