# Типы

## [ИсторияРаботыПользователя](../../wiki/interface/userworkhistory-ru-ad103b9e3c6d.md)

`Стд::Интерфейс::История::ИсторияРаботыПользователя` `Тип-одиночка` `Доступность: Клиент`

Позволяет записывать объекты в Историю работы Пользователя, а так же загружать историю для последующих взаимодействий. История Работы Пользователя ведется в разрезе конкретного клиентского приложения. Для клиентских приложений с режимом без аутентификации запись не производится, а загрузка всегда возвращает пустой массив.
