## Методы

### Повторить

`Доступность: КлиентИСервер`

```
Повторить(
  Строка: Строка,
  Количество: Число
): Строка
```

Возвращает результат конкатенации строки

`Строка`

указанное количество раз

`Количество`

.

---

### Соединить

`Доступность: КлиентИСервер`

```
Соединить(
  Части: Обходимое<Объект?>,
  Разделитель: Строка = ""
): Строка
```

Соединяет элементы

`Части`

в одну строку, состоящую из строковых представлений переданных объектов, с разделителем

`Разделитель`

. Преобразование к строке осуществляется через вызов

[ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)

---

### Шаблон

`Доступность: КлиентИСервер`

```
Шаблон(
  Шаблон: Строка,
  Параметры: Объект?
): Строка
```

Подставляет параметры

`Параметры`

в шаблонную строку

`Шаблон`

по индексу. Шаблонная строка может содержать маркеры подстановки вида:

`$0..$N`

,

`%0..%N`

. Нумерация маркеров начинается с 0. Маркеры могут повторяться. Подстановочные значения формируются как строковое представление переданного параметра. Если маркер имел вид %N, то преобразование к строке осуществляется через вызов

[ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)

Если маркер имел вид $N, то преобразование к строке осуществляется через вызов

[Представление](../../wiki/stdlib/object-ru-9e351f286699.md)

Если маркер имел вид $(N|Формат), то преобразование к строке осуществляется через вызов

[Представление](../../wiki/stdlib/formattable-ru-199658dd3e97.md)

Если параметр является массивом объектов, то каждый его элемент считается подстановочным значением. Если массив объектов пустой, то возвращается шаблонная строка без изменения. В случае, если за маркером следует число, то маркер должен указываться в виде

`$(i)`

, например

`"$(0)50руб"`

. Количество уникальных маркеров подстановки должно совпадать с количеством подстановочных значений.

#### Примеры

```xbsl
Строки.Шаблон("Copyright (C) $(0|гггг), $1", [Дата.Сейчас(), "1C"])  // "Copyright (C) 2023, 1C"
```
