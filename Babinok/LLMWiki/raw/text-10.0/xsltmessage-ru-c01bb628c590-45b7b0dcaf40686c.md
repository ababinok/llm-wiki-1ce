## Свойства

### КодОшибки

`Доступность: Сервер` `ТолькоЧтение`

```
КодОшибки: Строка?
```

Получить код ошибки (атрибут *error-code* в XSLT 3.0), если отсутствует - `Неопределено`.

---

### НомерКолонки

`Доступность: Сервер` `ТолькоЧтение`

```
НомерКолонки: Число
```

Получить номер колонки в таблице стилей XSLT, где была использована инструкция *xsl:message*.

---

### НомерСтроки

`Доступность: Сервер` `ТолькоЧтение`

```
НомерСтроки: Число
```

Получить номер строки в таблице стилей XSLT, где была использована инструкция *xsl:message*.

---

### СПрерыванием

`Доступность: Сервер` `ТолькоЧтение`

```
СПрерыванием: Булево
```

Получить признак прерывания обработки в *xsl:message*, если атрибут *terminate="yes"* - `Истина`, если *terminate="no"* или не используется - `Ложь`.

В случае использования сообщения с прерыванием (*terminate="yes"*) обработчик этого сообщения будет выполнен до выброса `ИсключениеПреобразованияXml`.

---

### Содержимое

`Доступность: Сервер` `ТолькоЧтение`

```
Содержимое: УзелXmlDom
```

Получить содержимое в виде узла XML (дочерний узел для *xsl:message* в XPath 1.0 или атрибут *select* в XSLT 2.0)
