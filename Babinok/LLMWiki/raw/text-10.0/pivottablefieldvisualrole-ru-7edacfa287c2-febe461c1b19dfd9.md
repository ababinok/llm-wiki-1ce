Определяет визуальные роли поля для сводной таблицы.

---

## Литералы

#### Строки

Может быть назначена только на размерность. Поле с этой ролью отображается в отдельной колонке.

---

#### КомпактныеСтроки

Может быть назначена только на размерность. Поле с этой ролью отображается в родительской колонке с внутренним левым отступом.

---

#### Иерархия

Может быть назначена только на иерархическую размерность. Ячейки размерности в этом случае раскрываются как уровни иерархии.

---

#### Колонки

Может быть назначена только на размерность. Поле с этой ролью отображается в отдельной строке.

---

#### ЗначенияКолонок

Может быть назначена только на факт. Поле с этой ролью отображается в отдельной строке.

---

#### ЗначенияСтрок

Может быть назначена только на факт. Поле с этой ролью отображается в отдельной колонке.

---

#### Итог

Может быть назначена только на размерность. Добавляет дополнительные ячейки с итогами.

---

#### КолонкиВЯчейках

Может быть назначена только на факт. Добавляет в каждую ячейку значения факта визуальный элемент — столбец, размер которого пропорционален значению факта.

---

#### Цвет

Может быть назначена только на факт. Раскрашивает ячейки в зависимости от настроек градиента и значения в ячейке.

---
