# Поиск элементов справочника при вводе по строке

Во время работы приложения, чтобы выбрать один из элементов справочника, пользователь может просто начать вводить в поле ввода известный ему фрагмент названия, кода, артикула или другого реквизита справочника. «1С:Предприятие.Элемент» автоматически подберет ему подходящие элементы.

Вы можете задать список тех реквизитов справочника, в которых «Элемент» будет искать текст, введенный пользователем. Для этого в проекте используйте свойство справочника [ВводПоСтроке](../../wiki/data/catalog-e0da7d4e8e72.md). В этом свойстве находится массив, содержащий имена реквизитов, в которых будет осуществляться поиск. По умолчанию в это свойство устанавливается реквизит, являющийся [представлением](../../wiki/data/element-view-cf34a8e796f4.md) элемента справочника (по умолчанию в качестве представления справочника используется стандартный реквизит [Наименование](../../wiki/data/name-ru-4602d20b0fc0.md)).

Вы можете переопределить стандартный алгоритм поиска, существующий в «Элементе». Для этого обрабатывайте событие [`ПолучитьЗначенияВыбора()`](../../wiki/data/catalogname-ru-691a065c1965.md) в модуле справочника ([подробнее](../../wiki/data/catalog-types-e0c7c64f0c49.md)).
