`Стд::Интерфейс::ГрафическиеСхемы::ДревовиднаяСхема` `Доступность: Клиент`

Абстрактный базовый тип для древовидных графических схем. Это схему, в которых у каждого элемента, кроме корневого, есть ровно один родитель, и какое-то (в том числе нулевое) количество дочерних элементов.

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [ГрафическаяСхема](../../wiki/interface/graphicalschema-ru-af7746d2c203.md), [Компонент](../../wiki/interface/component-ru-bad1c84be995.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

*Дочерние типы:* [Органиграмма](../../wiki/interface/organigram-ru-c0770ea503dd.md)

---

## Свойства

### ВидМакета

`Доступность: Клиент`

```
ВидМакета: Авто|ВидМакетаДревовиднойСхемы
```

Определяет вид макета древовидной графической схемы.

---

## Методы

### ПолучитьРодительскийЭлемент

`Доступность: Клиент`

```
ПолучитьРодительскийЭлемент(Элемент: ЭлементДревовиднойСхемы): ЭлементДревовиднойСхемы?
```

Возвращает родительский элемент.

---

### ПолучитьСоседниеЭлементы

`Доступность: Клиент`

```
ПолучитьСоседниеЭлементы(Элемент: ЭлементДревовиднойСхемы): Массив<ЭлементДревовиднойСхемы>
```

Возвращает соседние элементы - дочерние элементы родителя, за исключением самого элемента.

---

### ЦентрироватьПоЭлементу

`Доступность: Клиент`

```
ЦентрироватьПоЭлементу(
  Элемент: ЭлементДревовиднойСхемы,
  СброситьМасштабирование: Булево = Ложь)
```

Центрирует и масштабирует область просмотра на указанном элементе. Если параметр

`СброситьМасштабирование`

равен

`Истина`

, то масштабирование будет сброшено в 1 к 1.

**Перегрузка** [ГрафическаяСхема::ЦентрироватьПоЭлементу(Элемент: ЭлементГрафическойСхемы, СброситьМасштабирование: Булево = Ложь)](../../wiki/interface/graphicalschema-ru-af7746d2c203.md)
