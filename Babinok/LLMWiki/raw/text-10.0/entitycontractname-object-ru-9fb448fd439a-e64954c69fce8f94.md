## Обработчики

### ПередЗаписью

```
ПередЗаписью(
  До: {ИмяКонтрактаСущности}.Данные,
  ПараметрыЗаписи: {ИмяКонтрактаСущности}.ПараметрыЗаписи)
```

Вызывается при записи, после того как начата транзакция и захвачена блокировка. Для нового объекта параметр

`До`

соответствует текущему состоянию объекта. Параметр

`ПараметрыЗаписи`

содержит объявленные в объекте параметры записи (см. ИмяКонтрактаСущности.ПараметрыЗаписи).

---

### ПередУдалением

```
ПередУдалением(ПараметрыУдаления: {ИмяКонтрактаСущности}.ПараметрыУдаления)
```

Обработчик, вызываемый перед удалением объекта из базы данных.

Выполняется в транзакции.

Параметр `ПараметрыУдаления` содержит объявленные в объекте параметры удаления (см. ИмяКонтрактаСущности.ПараметрыУдаления).

---

### ПослеЗаписи

```
ПослеЗаписи(
  До: {ИмяКонтрактаСущности}.Данные,
  ПараметрыЗаписи: {ИмяКонтрактаСущности}.ПараметрыЗаписи)
```

Вызывается в транзакции при записи, после записи элемента в БД. Параметр

`ПараметрыЗаписи`

содержит объявленные в объекте параметры записи (см. ИмяРегистраНакопления.ПараметрыЗаписи).

---

### ПослеУдаления

```
ПослеУдаления(ПараметрыУдаления: {ИмяКонтрактаСущности}.ПараметрыУдаления)
```

Обработчик, вызываемый после удаления объекта в базе данных.

Выполняется в транзакции.

Параметр `ПараметрыУдаления` содержит объявленные в объекте параметры удаления (см. ИмяКонтрактаСущности.ПараметрыУдаления).
