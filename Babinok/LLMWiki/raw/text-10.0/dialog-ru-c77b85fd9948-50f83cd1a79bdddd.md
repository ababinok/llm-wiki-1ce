## Методы

### Вопрос

`Доступность: Клиент`

```
Вопрос(
  Текст: Строка,
  Кнопки: ЧитаемаяКоллекция<СтандартнаяКнопкаДиалога>,
  Пояснение: Строка = "",
  Иконка: Url|ДвоичныйОбъект.Ссылка|? = Неопределено
): СтандартнаяКнопкаДиалога
```

Отображает сообщение в предупреждающем окне и возвращает результат нажатия на кнопку. Возвращаемым значением является значение типа

[СтандартнаяКнопкаДиалога](../../wiki/interface/standarddialogbutton-ru-bf2aadb813bf.md)

Параметр `Кнопки` позволяет задать кнопки предупреждающего окна из заранее предопределённого набора стандартных кнопок.

- Если кнопок две и каждая из них занимает не более 50% от предупреждающего окна, то они располагаются горизонтально
- Иначе они располагаются друг под другом.

Параметр `Иконка` позволяет задать иконку предупреждающему окну.

`Пояснение` позволяет указать дополнительный поясняющий текст.

**Перегрузка** [Вопрос<ТипЗначения>(Текст: Строка, Кнопки: ЧитаемаяКоллекция<СтандартнаяКнопкаДиалога|КнопкаДиалога<ТипЗначения>>, Пояснение: Строка = "", Иконка: Url|ДвоичныйОбъект.Ссылка|? = Неопределено): СтандартнаяКнопкаДиалога|ТипЗначения](../../wiki/interface/dialog-ru-c77b85fd9948.md)

### Вопрос

`Доступность: Клиент`

```
Вопрос<ТипЗначения>(
  Текст: Строка,
  Кнопки: ЧитаемаяКоллекция<СтандартнаяКнопкаДиалога|КнопкаДиалога<ТипЗначения>>, Пояснение: Строка = "", Иконка: Url|ДвоичныйОбъект.Ссылка|? = Неопределено
): СтандартнаяКнопкаДиалога|ТипЗначения
```

ТипЗначения: Тип результата. Параметр типа должен иметь значение по умолчанию или

`Неопределено`

в составе типов.

Отображает сообщение в предупреждающем окне и возвращает результат нажатия на кнопку. Возвращаемым значением является либо тип [СтандартнаяКнопкаДиалога](../../wiki/interface/standarddialogbutton-ru-bf2aadb813bf.md), либо тип свойства [Значение](../../wiki/interface/dialogbutton-ru-c1e27b012450.md).

Параметр `Кнопки` позволяет задать кнопки предупреждающего окна. Можно выбрать как кнопки из предопределённого набора, так и указать свои при помощи типа [КнопкаДиалога](../../wiki/interface/dialogbutton-ru-c1e27b012450.md)

- Если кнопок две и каждая из них занимает не более 50% от предупреждающего окна, то они располагаются горизонтально
- Иначе они располагаются друг под другом.

Если одним из элементов коллекции кнопок является [КнопкаДиалога](../../wiki/interface/dialogbutton-ru-c1e27b012450.md), то заголовок этого элемента будет являться заголовком кнопки. При этом возвращаемое значение метода будет равно значению свойства [Значение](../../wiki/interface/dialogbutton-ru-c1e27b012450.md) этого элемента.

Параметр `Иконка` позволяет задать иконку предупреждающему окну.

`Пояснение` позволяет указать дополнительный поясняющий текст.
