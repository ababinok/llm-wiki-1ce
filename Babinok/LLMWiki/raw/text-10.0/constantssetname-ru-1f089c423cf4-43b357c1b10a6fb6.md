`Версия 9.0 и выше`

Таблица содержит записи набора констант.

---

## Примеры

В примере ниже показано, как выбрать все данные организации за все периоды из набора констант **ДанныеОрганизации**:

```xbql
ВЫБРАТЬ
    ДО.ИмяОрганизации,
    ДО.Адрес,
    ДО.Телефон,
    ДО.Факс,
    ДО.ЭлектроннаяПочта,
    ДО.Сайт,
    ДО.ИНН
ИЗ
    ДанныеОрганизации КАК ДО
```

---

## Поля

### {ИмяКонстанты}

```
{ИмяКонстанты}: ТипКонстанты
```

Значение константы набора констант.

---

### Период

`Ключевое поле`

```
Период: Дата
```

Дата периода. Поле доступно при включенной периодичности.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяНабораКонстант.КлючЗаписи
```

Содержит ключ записи набора констант. Используется для указания на конкретную запись. Имеет тип `имя-набора-констант.КлючЗаписи`.

#### Примеры

В примере ниже показано, как выбрать данные конкретной записи из набора констант **ДанныеОрганизации** по её ключу (значение поля **КлючЗаписи** равно параметру `%КлючОрганизации`):

```xbql
ВЫБРАТЬ
    Период,
    ИмяОрганизации,
    Адрес
ИЗ
    ДанныеОрганизации
ГДЕ
    КлючЗаписи == %КлючОрганизации
```
