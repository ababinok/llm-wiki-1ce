По умолчанию «Менеджер хостов внешних компонент» не устанавливается вместе с «1С:Предприятие.Элементом».

Вы можете установить его следующим образом:

1. Перед установкой «1С:Предприятие.Элемента» в окне [установщика](../../wiki/project/server-installer-d7f9b9f75941.md) нажмите на значок шестеренки, чтобы выбрать компоненты для установки.
  
  Выбор компонентов для установки [Описание иллюстрации](../figures/bae977f1960198b913a4901a06a1d49ccddf4ae2d851dd8260ac274ff7b90ab8-e67dbac2c8b7f9b9.md)
  
  Если «1С:Предприятие.Элемент» уже установлен, откройте [установщик](../../wiki/project/server-installer-d7f9b9f75941.md) и нажмите **Действие** ⟶ **Изменить**, чтобы открыть окно выбора компонентов.
  
  Изменение установленных компонентов [Описание иллюстрации](../figures/af8fcb07cadfc530fdbc8a098cdd6c0892d5ba2e9597cfe5239b555120a1167f-db8e6006e7e8ea49.md)
2. Поставьте галочку для компонента «1С:Предприятие.Элемент Менеджер Хостов Внешних Компонент» и нажмите **Установить**.
  
  Установщик на шаге выбора компонентов: установлен флажок «1С:Предприятие.Элемент Менеджер Хостов Внешних Компонент», справа дано описание выбранного компонента. [Описание иллюстрации](../figures/f37e5abcce4d1025caa566c3d46864bd19ca7d3d4c7dd01ebb130454b13b524f-aab66aed4a1ee4e6.md)

После установки вам необходимо создать и настроить конфигурационный файл сервера [management-echostmanager.yml](../../wiki/project/server-management-echostmanager-file-a73cbc74bac4.md), чтобы включить использование «Менеджера хостов внешних компонент» в «1С:Предприятие.Элементе».

## Результат установки

В результате установки на компьютере будут созданы два каталога:

- каталог исполняемых файлов «Менеджера хостов внешних компонент»,
- каталог экземпляра «Менеджера хостов внешних компонент», который содержит всю информацию об исполняющемся экземпляре менеджера.

Кроме этих каталогов будет создана и запущена служба (демон) для исполнения менеджера. Запуск осуществляется от имени пользователя USR1CE (usr1ce).

Ниже приведены имена каталогов и службы в разных операционных системах.

- Windows
- Linux

Каталог исполняемых файлов менеджера (указанная ниже версия может отличаться от установленной у вас версии):

```text
C:\Program Files\1C\1CE\components\1c-enterprise-echostmanager-9.1.9+17-x86_64
```

Каталог экземпляра менеджера:

```text
C:\ProgramData\1C\1CE\instances\1c-enterprise-echostmanager
```

Служба менеджера:

```text
1c-enterprise-echostmanager
```
