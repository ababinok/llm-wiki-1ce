`Стд::Интерфейс::Диаграммы::ЛинейнаяСерияДиаграммы` `Доступность: КлиентИСервер`

Описывает серию данных XY-диаграммы, которая визуализируется в виде линии.

### ЛинейнаяСерияДиаграммы

`Доступность: КлиентИСервер`

```

```

## Свойства

### Интерполяция

`Доступность: КлиентИСервер`

```
Интерполяция: Авто|Булево
```

Флаг, определяющий сглаживание линии.

### Цвет

`Доступность: КлиентИСервер`

```
Цвет: Авто|Цвет
```

Цвет, в который раскрашивается линия.
