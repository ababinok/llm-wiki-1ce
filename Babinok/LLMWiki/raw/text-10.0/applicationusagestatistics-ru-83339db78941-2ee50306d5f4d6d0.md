`Стд::Интерфейс::КлиентскоеПриложение::СтатистикаИспользованияПриложения` `Тип-одиночка` `Доступность: Клиент`

Содержит методы для работы со сбором статистики использования приложения.

**Важно!**

При использовании некоторых сервисов статистики часто требуется согласие от конечного пользователя для сбора персональных данных. Это следует учитывать перед тем, как использовать сервис. Следует проконсультироваться с компетентными специалистами в юридических вопросах и сделать форму-соглашение (или аналогичный инструмент) для получения и хранения согласия пользователя со сбором данных использования. Если пользователь отказывается предоставлять данные, настоятельно рекомендуется избегать использования сервисов сбора статистики в части сбора персональных данных.

## Методы

### ЗарегистрироватьПросмотр

`Доступность: Клиент`

```
ЗарегистрироватьПросмотр(
  Параметры: Строка = "",
  Сервисы: ЧитаемаяКоллекция<СервисСтатистикиИспользованияПриложения>? = Неопределено)
```

Параметры:

- `Параметры`
  
  - произвольный набор параметров вызова регистрации просмотра. Ожидается валидная JSON-строка,
- `Сервисы`
  
  - список сервисов статистики использования приложения, для которых будет вызван метод. Если не указаны – метод вызывается для всех инициализированных сервисов.

Регистрирует факт просмотра страницы.

### ЗарегистрироватьЦель

`Доступность: Клиент`

```
ЗарегистрироватьЦель(
  ИдЦели: Строка,
  Параметры: Строка = "",
  Сервисы: ЧитаемаяКоллекция<СервисСтатистикиИспользованияПриложения>? = Неопределено)
```

Параметры:

- `ИдЦели`
  
  - идентификатор достигнутой пользователем цели,
- `Параметры`
  
  - произвольный набор параметров вызова регистрации цели. Ожидается валидная JSON-строка,
- `Сервисы`
  
  - список сервисов статистики использования приложения, для которых будет вызван метод. Если не указаны – метод вызывается для всех инициализированных сервисов.

Регистрирует факт достижения цели пользователем. Цель должна быть описана предварительно разработчиком приложения в используемом сервисе статистики. Повторный вызов метода с тем же идентификатором цели зарегистрирует еще один факт ее достижения.

### ЗарегистрироватьЦельОднократно

`Доступность: Клиент`

```
ЗарегистрироватьЦельОднократно(
  ИдЦели: Строка,
  Компонент: Компонент,
  Параметры: Строка = "",
  Сервисы: ЧитаемаяКоллекция<СервисСтатистикиИспользованияПриложения>? = Неопределено)
```

Параметры:

- `ИдЦели`
  
  - идентификатор достигнутой пользователем цели,
- `Компонент`
  
  - компонент, с которым связана достигнутая пользователем цель,
- `Параметры`
  
  - произвольный набор параметров вызова регистрации цели. Ожидается валидная JSON-строка,
- `Сервисы`
  
  - список сервисов статистики использования приложения, для которых будет вызван метод. Если не указаны – метод вызывается для всех инициализированных сервисов.

Регистрирует факт достижения цели пользователем. Цель должна быть описана предварительно разработчиком приложения в используемом сервисе статистики. Данный метод регистрирует достижение цели однократно для указанного компонента. Если для данного компонента достижение цели уже было зарегистрировано ранее, то метод ничего не делает.

Прошлые имена: ЗарегистрироватьЦельОднократно

### НачатьСборСтатистики

`Доступность: Клиент`

```
НачатьСборСтатистики(
  СервисСтатистики: СервисСтатистикиИспользованияПриложения,
  ИдПриложения: Строка,
  ПараметрыИнициализации: Строка = "")
```

Параметры:

- `СервисСтатистики`
  
  - указывает вид используемого сервиса статистики,
- `ИдПриложения`
  
  - идентификатор приложения в указанном сервисе сбора статистики,
- `ПараметрыИнициализации`
  
  - произвольный набор параметров инициализации сервиса сбора статистики приложения. Ожидается валидная JSON-строка.

Инициализирует и запускает механизм сбора статистики использования приложения. Данный метод должен быть вызван до вызовов методов регистрации целей. Если методы регистрации целей будут вызваны до инициализации механизма сбора статистики, то при их вызове никаких действий выполнено не будет. Допускается неоднократный вызов данного метода для одновременного использования нескольких сервисов сбора статистики.

### НачатьСборСтатистикиGoogleAnalytics

`Доступность: Клиент`

```
@ИменованныеПараметры
НачатьСборСтатистикиGoogleAnalytics(
  ИдПриложения: Строка,
  РазрешитьGoogleSignals: Булево = Ложь,
  РазрешитьСборДанныхДляПерсонализацииРекламы: Булево = Ложь,
  ОтслеживаниеСсылок: Булево = Ложь,
  Язык: Строка = "",
  ИдПользователя: Строка = "",
  ПользовательскиеПараметры: Строка = "")
```

>

Вызов возможен только с именованными параметрами

Инициализирует и запускает механизм сбора статистики использования приложения Google Analytics. Данный метод должен быть вызван до вызовов методов регистрации целей. Если методы регистрации целей будут вызваны до инициализации механизма сбора статистики, то при их вызове никаких действий выполнено не будет.

Описание параметров:

- `РазрешитьGoogleSignals`
  
  : включает или отключает "Google Signals" — функцию, которая позволяет Google объединять данные из разных источников (поиск, реклама, YouTube) для:
  
  - кросс-устройственного отслеживания (если пользователь заходит с телефона и компьютера);
  - демографических отчетов (возраст, пол, интересы);
  - рекламных аудиторий в Google Ads.

Собирает персональные данные.

- `РазрешитьСборДанныхДляПерсонализацииРекламы`
  
  : управляет сбором данных для персонализации рекламы (например, в Google Ads).

Собирает персональные данные.

- `ОтслеживаниеСсылок`
  
  : включение отслеживания внешних ссылок, файлов и переходов
- `Язык`
  
  : язык пользователя. По умолчанию применяется пользовательское значение navigator.language
- `ЗаголовокСтраницы`
  
  : заголовок страницы или документа. По умолчанию применяется пользовательское значение document.title. Ограничение: 300 символов
- `ИдПользователя`
  
  : известный идентификатор, присваиваемый пользователю владельцем сайта. Он должен быть анонимным, т.е. не связанным с информацией, позволяющей идентифицировать личность, а его значение не должно сохраняться с помощью файлов cookie или каких-либо других средств хранения данных в Google Аналитике. Ограничение – 256 символов
- `ПользовательскиеПараметры`
  
  : атрибуты, описывающие сегменты пользовательской базы (язык, географическое местоположение и др.). Для каждого проекта можно добавить до 25 свойств пользователей. Ограничения:
  
  - название параметра – 24 символа;
  - значение параметра – 36 символов

Параметры передаются в виде валидной JSON-строки.

Соотношение параметров метода с АПИ Google Analytics:

- `РазрешитьGoogleSignals`
  
  – allow_google_signals
- `РазрешитьСборДанныхДляПерсонализацииРекламы`
  
  –allow_ad_personalization_signals
- `ОтслеживаниеСсылок`
  
  – ignore_referer
- `Язык`
  
  – language
- `ЗаголовокСтраницы`
  
  – page_title
- `ИдПользователя`
  
  – user_id
- `ПользовательскиеПараметры`
  
  – user_properties

### НачатьСборСтатистикиЯндексМетрики

`Доступность: Клиент`

```
@ИменованныеПараметры
НачатьСборСтатистикиЯндексМетрики(
  ИдПриложения: Строка,
  КартаНажатий: Булево = Ложь,
  ОтслеживаниеСсылок: Булево = Ложь,
  ДлительностьОтслеживанияОтказов: Длительность? = 15с,
  Вебвизор: Булево = Ложь,
  ПараметрыСессии: Строка = "",
  ПараметрыСессииПользователя: Строка = "",
  ОтправлятьЗаголовок: Булево = Истина,
  КодПодтвержденияВебмастера: Строка = "")
```

>

Вызов возможен только с именованными параметрами

Инициализирует и запускает механизм сбора статистики использования приложения Яндекс.Метрики. Данный метод должен быть вызван до вызовов методов регистрации целей. Если методы регистрации целей будут вызваны до инициализации механизма сбора статистики, то при их вызове никаких действий выполнено не будет.

Описание параметров:

- `КартаНажатий`
  
  : включение карты кликов (запись кликов пользователей по странице). Собирает персональные данные
- `ОтслеживаниеСсылок`
  
  : включение отслеживания внешних ссылок, файлов и переходов
- `ДлительностьОтслеживанияОтказов`
  
  : включает точный расчет отказов. По умолчанию, 15с. Если
  
  [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md)
  
  – параметр не используется
- `Вебвизор`
  
  : включение вебвизора (запись действий пользователей, включая движения курсора, скроллинг и ввод данных). Собирает персональные данные
- `ПараметрыСессии`
  
  : параметры визита, передаваемые во время инициализации счетчика. Ожидается валидная JSON-строка
- `ПараметрыСессииПользователя`
  
  : Параметры посетителей сайта, передаваемые во время инициализации счетчика. Ожидается валидная JSON-строка
- `ОтправлятьЗаголовок`
  
  : Запись заголовков (тег title). Потенциально может отправлять персональные данные, если они там прописаны
- `КодПодтвержденияВебмастера`
  
  : включение Яндекс.Вебмастера. В параметре передается код подтверждения

Соотношение параметров метода с АПИ Яндекс.Метрики:

- `КартаНажатий`
  
  – clickmap
- `ОтслеживаниеСсылок`
  
  – trackLinks
- `ДлительностьОтслеживанияОтказов`
  
  – accurateTrackBounce
- `Вебвизор`
  
  – webvisor
- `ПараметрыСессии`
  
  – params
- `ПараметрыСессииПользователя`
  
  – userParams
- `ОтправлятьЗаголовок`
  
  – sendTitle
