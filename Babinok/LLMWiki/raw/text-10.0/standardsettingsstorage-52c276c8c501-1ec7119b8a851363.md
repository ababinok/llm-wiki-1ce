## [СтандартноеХранилищеНастроек](../../wiki/queries/standardsettingsstorage-ru-4b4663bda589.md)

Таблица содержит данные, соответствующие элементам стандартного хранилища настроек. Одна запись таблицы — один элемент хранилища настроек. Таблица является ссылочной — к ее полям можно обращаться по их именам через точку от выражений, имеющих тип `СтандартноеХранилищеНастроек.Ссылка`.

---

## [СтандартноеХранилищеНастроек.Изменения](../../wiki/queries/standardsettingsstorage-changes-ru-db39bcb99d7d.md)

Таблица регистрации изменений создается, только если стандартное хранилище настроек включено в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению элемента хранилища настроек, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице хранилища настроек. Одна запись таблицы — изменения в одном элементе хранилища настроек, зарегистрированные для одного узла.
