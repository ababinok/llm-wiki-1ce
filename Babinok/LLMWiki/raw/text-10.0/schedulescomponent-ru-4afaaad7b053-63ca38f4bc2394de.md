## Примеры

**Общие примеры**

В примере компонент `КомпонентРасписаний` встраивается в форму планирования задания с возможностью настройки массива расписаний. В обработчике создания формы вызовом метода [УстановитьРасписания](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) устанавливается начальное значение редактируемого массива расписаний, вызовом метода [УстановитьРазрешениеИзменения](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) устанавливается, что задания разрешено изменять. В обработчиках событий [ПриДобавлении](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md), [ПриИзменении](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md), [ПриУдалении](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) выполняется добавление, изменение и удаление элемента расписания соответственно (изменяется значение свойства `РасписаниеЗапуска` формы), а вызовом метода [УстановитьРасписания](../../wiki/interface/schedulescomponent-ru-4afaaad7b053.md) выполняется установка обновленного массива расписаний в компоненте `КомпонентРасписаний` с именем `РедакторРасписания`. По команде формы выполняется планирование задания с использованием настроенного массива расписаний.

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: 9bff1e36-da47-4ad3-b2ef-64a31bf51b66
Имя: ФормаПланированияЗаданияСРасписаниями
ОбластьВидимости: ВПодсистеме
Свойства:
    -
        Тип: Массив<Расписание>
        Имя: РасписаниеЗапуска
Наследует:
    Тип: Форма
    ОсновнаяКоманда:
        Тип: ОбычнаяКоманда
        Обработчик: ОбработчикПланированияЗадания
        Представление: Запланировать
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: КомпонентРасписаний
            Имя: РедакторРасписания
            ПриДобавлении: ОбработчикДобавленияЭлементаРасписания
            ПриИзменении: ОбработчикИзмененияЭлементаРасписания
            ПриУдалении: ОбработчикУдаленияЭлементаРасписания
```

```xbsl
@Обработчик
метод ПослеСоздания()
    РасписаниеЗапуска.Добавить(Расписание.Ежедневно(Время{12:00}))
    Компоненты.РедакторРасписания.УстановитьРасписания(РасписаниеЗапуска)
    Компоненты.РедакторРасписания.УстановитьРазрешениеИзменения(Истина)
;

метод ОбработчикДобавленияЭлементаРасписания(Источник: КомпонентРасписаний, Событие: СобытиеСДанными<Расписание>)
    РасписаниеЗапуска.Добавить(Событие.Данные)
    Компоненты.РедакторРасписания.УстановитьРасписания(РасписаниеЗапуска)
;

метод ОбработчикИзмененияЭлементаРасписания(Источник: КомпонентРасписаний, Событие: СобытиеСДанными<КлючИЗначение<Число, Расписание>>)
    РасписаниеЗапуска[Событие.Данные.Ключ] = Событие.Данные.Значение
    Компоненты.РедакторРасписания.УстановитьРасписания(РасписаниеЗапуска)
;

метод ОбработчикУдаленияЭлементаРасписания(Источник: КомпонентРасписаний, Событие: СобытиеСДанными<КлючИЗначение<Число, Расписание>>)
    РасписаниеЗапуска.УдалитьПоИндексу(Событие.Данные.Ключ)
    Компоненты.РедакторРасписания.УстановитьРасписания(РасписаниеЗапуска)
;

метод ОбработчикПланированияЗадания(Команда: ОбычнаяКоманда)
    ЗапланироватьЗадание(РасписаниеЗапуска)
;

@НаСервере @ДоступноСКлиента
статический метод ЗапланироватьЗадание(Расписание: Массив<Расписание>)
    ЗапланированныеЗадания.Создать(&ОбработчикЗадания)
        .Настроить(Расписание = Расписание)
        .Запланировать()
;

@НаСервере
статический метод ОбработчикЗадания()
;
```

## События

### ПриДобавлении

`Доступность: Клиент`

```
ПриДобавлении: (
  КомпонентРасписаний,
  СобытиеСДанными<Расписание>)->ничто
```

Событие возникает, когда расписание было добавлено. В параметре события - новое расписание.

---

### ПриИзменении

`Доступность: Клиент`

```
ПриИзменении: (
  КомпонентРасписаний,
  СобытиеСДанными<КлючИЗначение<Число, Расписание>>)->ничто
```

Событие возникает, когда расписание было изменено. В параметре события ключ - индекс измененного расписания в массиве, значение - измененное расписание.

---

### ПриУдалении

`Доступность: Клиент`

```
ПриУдалении: (
  КомпонентРасписаний,
  СобытиеСДанными<КлючИЗначение<Число, Расписание>>)->ничто
```

Событие возникает, когда расписание было удалено. В параметре события ключ - индекс удаленного расписания в массиве, значение - удаленное расписание.

## Методы

### УстановитьРазрешениеИзменения

`Доступность: Клиент`

```
УстановитьРазрешениеИзменения(РазрешеноИзменение: Булево)
```

Устанавливает признак разрешения изменения расписаний.

#### Примеры

Установка разрешения редактировать расписание в компоненте `КомпонентРасписаний` с именем `РедакторРасписания`.

```xbsl
Компоненты.РедакторРасписания.УстановитьРазрешениеИзменения(Истина)
```

---

### УстановитьРасписания

`Доступность: Клиент`

```
УстановитьРасписания(Расписания: ЧитаемыйМассив<Расписание>)
```

Устанавливает расписания.

#### Примеры

Установка расписания компонента `КомпонентРасписаний` с именем `РедакторРасписания`.

```xbsl
Компоненты.РедакторРасписания.УстановитьРасписания([Расписание.Ежедневно(Время{12:00})])
```
