## Свойства

### ВесПриРастягивании

`Доступность: Клиент`

```
ВесПриРастягивании: Авто|Число
```

Свойство задает вес данного компонента при растягивании по сравнению с другими в той же группе. Т.е. если у одного компонента [ВесПриРастягивании](../../wiki/interface/component-ru-bad1c84be995.md) = 1, у другого 2, то второй компонент будет в 2 раза больше первого.

---

### Видимость

`Доступность: Клиент`

```
Видимость: Авто|Булево
```

Состояние видимости собственно самого компонента. При вычислении фактического состояния видимости также учитывается видимость родительских компонент.

---

### ВыравниваниеВГруппеПоВертикали

`Доступность: Клиент`

```
ВыравниваниеВГруппеПоВертикали: Авто|ВыравниваниеПоВертикали
```

Устанавливает вертикальное выравнивание дочерних компонентов. Для вертикальной группы имеет смысл только для крайних компонентов: если содержимое группы ориентировано в одну сторону, крайний с другой стороны компонент можно ориентировать в противоположную.

---

### ВыравниваниеВГруппеПоГоризонтали

`Доступность: Клиент`

```
ВыравниваниеВГруппеПоГоризонтали: Авто|ВыравниваниеПоГоризонтали
```

Устанавливает горизонтальное выравнивание компонента. Для горизонтальной группы имеет смысл только для крайних компонентов: если содержимое группы ориентировано в одну сторону, крайний с другой стороны компонент можно ориентировать в противоположную.

---

### Высота

`Доступность: Клиент`


Задает высоту компонента по умолчанию. Указывается в пикселах. [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) - рассчитывать автоматически.

---

### Доступность

`Доступность: Клиент`

```
Доступность: Авто|Булево
```

Состояние доступности данного компонента. Если компонент недоступен, то он не может принимать фокус и редактировать данные. Состояние доступности распространяется на все дочерние компоненты, пока не встретится переопределение свойства. Имеет приритет над свойством [ТолькоЧтение](../../wiki/interface/component-ru-bad1c84be995.md).

---

### ТолькоЧтение

`Доступность: Клиент`

```
ТолькоЧтение: Авто|Булево
```

Определяет возможность изменять данные внутри компонента. Если [ТолькоЧтение](../../wiki/interface/component-ru-bad1c84be995.md) установлено в `Истина`, то он все равно может принимать фокус, данные можно просматривать и копировать. Некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/component-ru-bad1c84be995.md) распространяется на все дочерние компоненты, пока не встретится переопределение свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/component-ru-bad1c84be995.md).

## События

### ПриПеретаскивании

`Доступность: Клиент`

```
ПриПеретаскивании: (
  Компонент,
  СобытиеПриПеретаскивании)->ничто
```

Вызывается по окончании перетаскивания объектов на область компонента. Если обработчик события не установил событию [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) = `Ложь` (или обработчик не был задан), происходит системная обработка события, после чего, если это не запрещено системной обработкой, событие вызывается у родительского компонента, вплоть до компонента [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На текущий момент поддерживается только перетаскивание файлов из операционной системы на область компонента.

## Методы

### Активировать

`Доступность: Клиент`

```
Активировать()
```

Активирует данный компонент:

- если это конечный компонент, то он сам получает фокус ввода
  
  - отображение фокусной рамки компонентов, не являющихся полями ввода, зависит от используемого пользователем способа навигации по приложению:
    
    - если с клавиатуры, то показывается
    - если мышью - то нет
- если это составной компонент или контейнер, то будет активирован автоматически найденный дочерний конечный компонент
  
  - либо тот, который активировался ранее
  - либо первый, который может быть активирован

### ОтключитьОбработчикТаймера

`Доступность: Клиент`

```
ОтключитьОбработчикТаймера(Обработчик: ()->ничто)
```

Отключает все подключенные к данному компоненту ожидания, обработчиком которых является указанная процедура текущего модуля.

`Обработчик` - Метод, выступающий обработчиком ожидания (ожиданий).

---

### ПодключитьОбработчикТаймера

`Доступность: Клиент`

```
ПодключитьОбработчикТаймера(
  Обработчик: ()->ничто,
  Интервал: Длительность,
  Однократно: Булево = Ложь)
```

Подключает указанный метод в качестве обработчика ожидания истечения указанного времени. При повторном вызове метода с таким же обработчиком процесс начинается заново. При уничтожении компонента автоматически уничтожаются все подключенные к нему обработчики ожидания.

`Обработчик` - Метод, выступающий обработчиком ожидания. `Интервал` - Интервал запуска обработчика. `Single` - Признак однократного выполнения процедуры-обработчика.

- `Истина`
  
  – процедура вызовется однократно по истечению
  
  `Интервал`
  
  времени.
- `Ложь`
  
  – процедура будет вызываться каждые
  
  `Интервал`
  
  времени.
