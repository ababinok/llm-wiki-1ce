Операции обработки — это методы, которые выполняет обработка. Наименование операций указывается в yaml-файле обработки, а их описание — в модуле объекта обработки. Методы, соответствующие операциям, помечаются аннотацией `@Обработчик`.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Представление

```yaml
Представление: Строка|СсылкаНаЛокализованнуюСтроку
```

Представление элемента.

---

#### КонтрольДоступа

`Версия 10.0 и выше`

```yaml
КонтрольДоступа: 
    Разрешения: 
        Вызов: КонтрольДоступа
    Обработчик: Строка
```

Содержит [настройки прав доступа](../../wiki/security/http-service-access-permissions-0998f45d9af8.md).

#### Основная

```yaml
Основная: Булево
```

Признак основной операции. Кнопка, соответствующая данной операции, становится [основной](../../wiki/project/primary-button-52e08ab36326.md). Если для обработки задана единственная операция, то она помечается как основная. Если несколько операций помечены как основные, то выводится сообщение об ошибке.
