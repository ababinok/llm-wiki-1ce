## Методы

### ВычислитьРазрешенияДоступа

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на интегрируемое приложение целиком.

---

### ВычислитьРазрешенияДоступаДляОбъектов

```
ВычислитьРазрешенияДоступаДляОбъектов(Элементы: ЧитаемыйМассив<ИмяИнтегрируемогоПриложения.ДанныеРасчетаРазрешений>): ЧитаемоеСоответствие<ИмяИнтегрируемогоПриложения.ДанныеРасчетаРазрешений,ЧитаемаяКоллекция<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на отдельные элементы интегрируемого приложения.

Принимает данные для расчета разрешений доступа объектов, для которых нужно вычислить права, и возвращает соответствие данных для расчета разрешений доступа объектов и установленных для них разрешений.

Используется только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение `РазрешенияВычисляютсяДляКаждогоОбъекта`

---

### НайтиПоКоду

`Доступность: Сервер`

```
НайтиПоКоду(Код: <ТипКода>): <{ИмяИнтегрируемогоПриложения}>
```

Метод поиска объектов по коду. Тип параметра зависит от типа кода, определенного для объекта.

Метод НайтиПоКоду выполняет только однозначный поиск ссылки по коду. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности.

#### Исключения

**[ИсключениеПоискаСущности](../../wiki/data/entitysearchexception-ru-ae3d905c5b5f.md)** - результат поиска неоднозначен. Найдено несколько ссылок с таким кодом.

---

### НайтиПоНаименованию

```
НайтиПоНаименованию(
  Наименование: Строка,
  ПроверятьУникальность: Булево = Истина
): <{ИмяИнтегрируемогоПриложения}>
```

Метод поиска объектов по наименованию.

Параметр `ПроверятьУникальность` отвечает за однозначный способ поиска. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности. Если нужно найти любой из имеющихся элементов, то можно передать значение `Ложь` в параметр `ПроверятьУникальность`

#### Исключения

**[ИсключениеПоискаСущности](../../wiki/data/entitysearchexception-ru-ae3d905c5b5f.md)** - результат поиска неоднозначен. Найдено несколько ссылок с таким наименованием.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<{ИмяИнтегрируемогоПриложения}.Ссылка>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа на отдельные объекты в интегрируемом приложении, выраженные ссылками.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяИнтегрируемогоПриложения.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

```
ПересчитатьРазрешенияДоступаДляОбъектов(
  <Параметр1>: <ТипПараметра1>,
  ....<ПараметрN>: <ТипПараметраN>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Вызов возможен только с именованными параметрами.

Пересчитывает разрешения доступа на отдельные объекты, значения реквизитов которых совпадают со значениями параметров, переданных в метод. В качестве параметров в метод могут быть переданы любые реквизиты, указанные в настройке `РасчетРазрешенийПо` элемента проекта.

### СоздатьФормуОбъекта

`Доступность: Клиент`

```
@ИменованныеПараметры
СоздатьФормуОбъекта(Ключ: {ИмяИнтегрируемогоПриложения}.Ссылка = Неопределено): ФормаОбъекта<{ИмяИнтегрируемогоПриложения}.Объект,неизвестно>
```

>

Вызов возможен только с именованными параметрами

Создает форму объекта интегрируемого приложения. Если интегрируемому приложению назначена форма объекта, то будет создана форма ровно этого типа. Иначе будет создана автоматическая форма типа [ИмяИнтегрируемогоПриложения.АвтоматическаяФормаОбъекта](../../wiki/stdlib/integrableapplicationname-automaticobjectform-ru-e3c6dc952ba2.md)

Параметр `Ключ` определяет, какой объект будет редактироваться в форме. Если в качестве значения ключа передано [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md), то будет открыта форма нового объекта.

**Перегрузка** [СоздатьФормуОбъекта(Ключ: ИмяИнтегрируемогоПриложения.Ссылка? = Неопределено): ФормаОбъекта<ИмяИнтегрируемогоПриложения.Объект, неизвестно>](../../wiki/stdlib/integrableapplicationname-ru-dded7fda26a0.md)

## Обработчики

### ПолучитьЗначенияВыбора

```
ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Событие вызываемое при попытке получить данные для выбора по введенной подстроке. В событие передается информация о набранной строке, и параметрах фильтра. Событие должно возвратить массив выбранных данных, или Неопределено если требуется выполнить стандартную обработку события.

### ВычислитьВнешнююНавигационнуюСсылку

```
ВычислитьВнешнююНавигационнуюСсылку(Ссылка: <{ИмяИнтегрируемогоПриложения}>): ВнешняяНавигационнаяСсылка?
```

Обработчик, который вычисляет навигационную ссылку внешней системы.

Параметры:

- `Ссылка`
  
  - ссылка на интегрируемое приложение, для которой нужно вычислить внешнюю навигационную ссылку.

Обработчик используется в контекстных обсуждениях системы взаимодействия.

---

### ВычислитьСсылкуПоВнешнейНавигационнойСсылке

```
ВычислитьСсылкуПоВнешнейНавигационнойСсылке(НавигационнаяСсылка: ВнешняяНавигационнаяСсылка): <{ИмяИнтегрируемогоПриложения}>
```

Обработчик, который вычисляет ссылку на интегрируемое приложение по внешней навигационной ссылке.

Параметры:

- `НавигационнаяСсылка`
  
  - внешняя навигационная ссылка.

Обработчик используется в контекстных обсуждениях системы взаимодействия и всегда используется в паре с обработчиком `ВычислитьВнешнююНавигационнуюСсылку`.
