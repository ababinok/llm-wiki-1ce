Макет отчета. Описание макета формируется автоматически при редактировании отчета в дизайнере «1С:Аналитики», встроенном в среду разработки.

---

## Свойства

#### ВидОтображения

```yaml
ВидОтображения: ВидОтображенияОтчета
```

Задает вид отображения отчета по умолчанию.

---

#### ВыбиратьРазрешенные

```yaml
ВыбиратьРазрешенные: Булево
```

Если значение свойства равно **Истина**, отчет формируется на основе доступных пользователю данных. Недоступные данные исключаются.

Если значение свойства равно **Ложь**, отчет формируется только при доступе ко всем необходимым данным. Если доступ ограничен, выводится сообщение об ошибке.

---

#### Выражения

```yaml
Выражения: 
    -
        Выражение: Строка
        ТипВыражения: Строка
        Имя: Строка
        Представление: Строка
        Вид: ВидПоляОтчета
```

Содержит описание выражений, используемых в отчете.

<details>
<summary>**Свойства**</summary>

##### Выражение

Задает вычисляемое выражение на основе реквизитов источника данных.

##### ТипВыражения

Задает тип значения, которое возвращает выражение.

##### Имя

Задает имя выражения, которое может использоваться в других выражениях.

##### Представление

Задает представление выражения, отображаемое пользователям.

##### Вид

Указывает, как может использоваться выражение.

</details>

#### Параметры

```yaml
Параметры: 
    -
        Имя: Строка
        Тип: Тип<Булево|Сущность.Ссылка|Перечисление|Число|Строка|ДатаВремя>
        Представление: Строка
        ЗначениеПоУмолчанию: Объект
        Обязательный: Булево
        Вид: ВидПараметраМакетаОтчета
        Значения: ЗначениеПараметраМакетаОтчета[]
```

Содержит описание параметров отчета.

<details>
<summary>**Свойства**</summary>

##### Имя

Имя элемента.

##### Тип

Тип параметра.

##### Представление

Имя параметра, отображаемое в отчете.

##### ЗначениеПоУмолчанию

Значение параметра по умолчанию. Если не указано, используется значение по умолчанию для типа параметра.

Если для параметра задан список значений, то значение свойства **ЗначениеПоУмолчанию** не указывается.

##### Обязательный

Указывает, является ли параметр обязательным. Если значение обязательного параметра не задано, отчет не будет построен.

##### Вид

Вид использования параметра: **Мера** или **Измерение**.

Значение **Мера** разрешено только для параметров типа `Число`.

##### Значения

Список допустимых значений. Если указаны, параметр может принимать только значения из списка.

Если список заполнен, создается перечисление `{ИмяОтчета}.Параметры.{ИмяПараметра}` с элементами, соответствующими указанным значениям.

</details>
