Для редактирования сообщений вы можете использовать метод [`РедактироватьСообщение()`](../../wiki/integration/collaborationsystem-ru-51561bd68a2c.md) типа [`СистемаВзаимодействия`](../../wiki/integration/collaborationsystem-ru-51561bd68a2c.md). Этот метод позволяет редактировать существующее сообщение по заданным параметрам, включая получателей, текст сообщения, вложения сообщения, а также данные и тип данных сообщения. При редактировании значения параметра **ТипДанных** оно не будет изменено, если при этом не были изменены **Данные**.

Пример редактирования сообщения

```xbsl
метод РедактироватьСообщениеВзаимодействия()
    знч ИдСообщения = Ууид{520a34cb-f8cb-4c79-ba78-45b7fdfb080d}
    знч Сообщение = СистемаВзаимодействия.НайтиСообщение(ИдСообщения)
    знч Таймаут = 5с

    попытка
        СистемаВзаимодействия.РедактироватьСообщение(
                                ИдСообщения = Сообщение.Ид,
                                ТекстСообщения = Сообщение.Текст + " Дополнительный текст",
                                Таймаут = Таймаут)
    поймать Исключение: ИсключениеСистемыВзаимодействия
    // Обработка исключения...
    ;
;
```
