Типы для работы с пользовательским интерфейсом приложения.

# Свойства

### ЗагрузкаФайлов

`Доступность: Клиент` `ТолькоЧтение`

```
ЗагрузкаФайлов: ЗагрузкаФайлов
```

Предоставляет доступ к глобальному менеджеру загрузки файлов, который является общим для всего приложения.

---

### КлиентскоеПриложение

`Доступность: Клиент` `ТолькоЧтение`

```
КлиентскоеПриложение: КлиентскоеПриложение
```

Указывает на компонент текущего клиентского приложения.

---

# Методы

### ПерейтиПоСсылке

`Доступность: Клиент`

```
ПерейтиПоСсылке(
  Ссылка: Строка,
  ОткрыватьВНовомОкне: Булево = Истина)
```

Осуществляет переход по указанной ссылке.

Параметры:

- `Ссылка`
  
  - ссылка для перехода,
- `ОткрыватьВНовомОкне`
  
  - если
  
  `Истина`
  
  , то ссылка откроется в новом окне браузера. Иначе - в текущем окне приложения.

---

### ПоказатьИнтерфейсОценкиПриложения

`Доступность: Клиент`

```
ПоказатьИнтерфейсОценкиПриложения()
```

Предлагает пользователю оценить приложение стандартными системными средствами. Пользователь может отказаться. Получить информацию о том оценил ли пользователь приложение и как оценил нельзя. Интерфейс будет отображаться только на платформах, на которых эта функциональность поддерживается в соответствии с правилами и ограничениями платформы (например в iOS не чаще 3-х раз в год). Т.е. нет гарантии, что интерфейс будет показан.

---

### Сообщить

`Доступность: Клиент`

```
Сообщить(Сообщение: Строка)
```

Показывает окно с указанным сообщением.
