## Методы

### НачатьЗагрузку

`Доступность: Клиент`

```
НачатьЗагрузку(
  Файл: ВыбранныйФайл,
  ТаймаутУстаревания: Длительность? = Неопределено,
  ТипСодержимого: Строка? = Неопределено
): ЗагрузкаФайла
```

Начинает загрузку файла на сервер.

`ТаймаутУстаревания` - время, через которое сборщик мусора сможет удалить объект, если на него не будет создано ссылок. Если не указано, используется время по умолчанию 24 часа. `ТипСодержимого` - тип содержимого. Если не указано, система пытается определить тип автоматически.

Для загрузки файлов анонимным пользователем требуется дополнительное разрешение, см. [УстановитьРазрешениеЗагрузкиАнонимнымПользователем](../../wiki/data/objectstorage-ru-2ba8627c997d.md).

---

### ОтменитьВсеЗагрузки

`Доступность: Клиент`

```
ОтменитьВсеЗагрузки()
```

Отменяет все текущие загрузки файлов, связанные с данным объектом.

---

### УдалитьЗагрузку

`Доступность: Клиент`

```
УдалитьЗагрузку(Загрузка: ЗагрузкаФайла)
```

Удаляет загрузку из списка загрузок. Если загрузка находилась в состоянии

[Активна](../../wiki/interface/fileuploadstate-ru-a7cbce297909.md)

, то происходит отмена загрузки.
