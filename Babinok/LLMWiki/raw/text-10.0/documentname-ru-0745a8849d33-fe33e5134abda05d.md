Таблица содержит записи, соответствующие элементам документа (одна запись таблицы — один элемент документа).

Таблица является ссылочной — к полям таблицы можно обращаться по их именам через точку от выражений, имеющих тип `ИмяДокумента.Ссылка`.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Ссылка** и **Контрагент** из документа **Накладная**:

```xbql
ВЫБРАТЬ 
   Накладная.Ссылка КАК Ссылка,
   Накладная.Контрагент КАК Контрагент 
ИЗ 
   Накладная КАК Накладная
```

---

## Поля

### {ИмяРеквизита}

```
{ИмяРеквизита}: ТипРеквизита
```

Значение реквизита документа.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяДокумента.Ссылка
```

Ссылка на экземпляр документа. Например, для документа **Накладная** это поле будет иметь тип `Накладная.Ссылка`.

---

### МеткаВерсии

```
МеткаВерсии: Ууид
```

Текущая версия данных экземпляра.

---

### МоментПометкиУдаления

```
МоментПометкиУдаления: Момент?
```

Момент пометки записи на удаление. Поле присутствует только у документов с режимом удаления `ПометкаУдаления`.

Поле имеет значение типа `Момент` для помеченных на удаление записей и значение `Неопределено`, если запись не помечена на удаление.

---

### ПометкаУдаления

`Вычисляемое поле`

```
ПометкаУдаления: Булево
```

Признак того, что запись помечена на удаление. Поле присутствует только у документов с режимом удаления `ПометкаУдаления`.

---

### Номер

```
Номер: Строка
```

Номер экземпляра документа

---

### Дата

```
Дата: ДатаВремя
```

Дата экземпляра документа.

---

### Представление

`Вычисляемое поле`

```
Представление: Строка
```

Строковое представление экземпляра документа.

---

## Индексы

### ПоляАвтонумерации

Индекс, используемый системным автонумератором. Может состоять из полей:

- Префикс (если нумерация идет в разрезе префикса)
- Постфикс (если нумерация идет в разрезе постфикса)
- Counter (системное поле, недоступное в языке запросов)

---

### Номер

Индекс по номеру и ссылке документа.

---

### ИндексДатаСсылка

Индекс по дате и ссылке документа.
