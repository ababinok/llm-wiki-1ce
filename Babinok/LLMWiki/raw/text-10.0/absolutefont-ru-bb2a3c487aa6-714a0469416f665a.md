## Конструкторы

### АбсолютныйШрифт

`Версия 8.0 и выше`

`Доступность: КлиентИСервер`

```
АбсолютныйШрифт(
  Имя: Строка = "",
  Размер: Число = 0,
  Полужирный: Булево = Ложь,
  Наклонный: Булево = Ложь,
  Подчеркивание: Булево = Ложь,
  Зачеркивание: Булево = Ложь)
```

Конструктор на основании всех свойств шрифта.

### АбсолютныйШрифт
