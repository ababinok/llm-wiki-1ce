#### Важность

```yaml
Важность: ВычисляемоеВыражение|Низкая|Обычная|Высокая
```

Определяет важность колонки. Влияет на отображение ячейки данной колонки.

При трансформации таблицы в мобильном окружении в список карточек, стандартные колонки с высокой важностью будут помещены выше остальных, остальные будут отсортированы по убыванию важности. В режиме иерархии, если нет колонок с важностью **Высокая**, наверх будет помещена первая по приоритету остаточной важности колонка.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Высота

```yaml
Высота: ВычисляемоеВыражение|Авто|Число
```

Высота компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение высоты применяется, только если оно отлично от 0 и [РастягиватьПоВертикали](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) равно **Ложь**.

---

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md).

#### РазрешитьСжатие

```yaml
РазрешитьСжатие: ВычисляемоеВыражение|Авто|Булево
```

Устанавливает поведение колонки при автоматическом расчете ширин колонок.

- Истина
  
  — содержимое будет вмещаться в ширину видимой области таблицы с учетом других колонок вплоть до минимально возможной ширины колонки.
- Ложь
  
  — ширина колонки будет подобрана так, чтобы вместить все свое содержимое.

#### Ссылка

```yaml
Ссылка: ВычисляемоеВыражение|Сущность.Ключ|Строка|?
```

Задает ссылку, при этом текст и картинка в ячейке отображаются как гиперссылка, нажатие на которую вызывает событие [ПриНажатии](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md).

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md).

---

#### ФигураКартинки

```yaml
ФигураКартинки: ВычисляемоеВыражение|Авто|Фигура
```

Фигура картинки. Принимает значения типа [Картинка](../../wiki/interface/picture-ru-efed61d49ad9.md): **Обычная**, **Закругленная**, **Круглая**.

---

#### Цвет

```yaml
Цвет: ВычисляемоеВыражение|Авто|Цвет
```

Задает основной цвет содержимого колонки таблицы. Используется для цвета текста или значка.

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md) равно **Ложь**.

---

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриНажатии

```yaml
ПриНажатии: Строка
```

Метод, обрабатывающий событие нажатия на ссылку (текст или картинку) в строке таблицы. Метод должен находиться в [модуле компонента](../../wiki/interface/interface-component-types-b9d0cf747ffb.md).

Если этот метод возвращает **Ложь**, то происходит стандартная обработка нажатия на ссылку — ссылка открывается.

Если гиперссылка выключена (свойство [ОбрабатыватьНажатие](../../wiki/interface/standardtablecolumn-ru-0b1e3e80ca73.md)), то событие вызывается.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
