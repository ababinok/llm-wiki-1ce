## Конструкторы

### ЭлементФильтраПоляКоллекция

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ЭлементФильтраПоляКоллекция(
  Поле: Строка,
  ВидСравненияПоляКоллекция: ВидСравненияПоляКоллекция,
  Значение: Объект?,
  Использовать: Булево,
  ОтображатьВНастройках: Авто|ВидОтображенияФильтра,
  Представление: Авто|Строка)
```

Создает элемент фильтра поля коллекции с указанными значениями полей.

---

### ЭлементФильтраПоляКоллекция

`Версия 9.0 и ниже`

`Доступность: КлиентИСервер`

```
ЭлементФильтраПоляКоллекция(
  Поле: Строка,
  ВидСравненияПоляКоллекция: ВидСравненияПоляКоллекция,
  Значение: Объект?,
  Использовать: Булево)
```

---

## Свойства

### ВидСравненияПоляКоллекция

`Доступность: КлиентИСервер`

```
ВидСравненияПоляКоллекция: ВидСравненияПоляКоллекция
```

Указывает вид сравнения.

---

### Значение

`Доступность: КлиентИСервер`

```
Значение: Объект?
```

Значение фильтра, с которым сравнивается значение поля выборки.

---

### Использовать

`Доступность: КлиентИСервер`

```
Использовать: Булево
```

Признак использования данного элемента фильтра для фильтрации выборки. Может использоваться для включения выключения отдельных элементов обора.

---

### ОтображатьВНастройках

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
ОтображатьВНастройках: Авто|ВидОтображенияФильтра
```

Включает отображение описанного фильтра в интерфейс настроек.

Такая настройка влияет на свойство [Использовать](../../wiki/interface/filteritemfieldcollection-ru-3284878e5b66.md), связанного с ней фильтра.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) – [ВидОтображенияФильтра](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).[НеОтображать](../../wiki/interface/filterdisplaykind-ru-6beb09b9b6be.md).

---

### Поле

`Доступность: КлиентИСервер`

```
Поле: Строка
```

Имя поля коллекции выборки, по которому будет осуществляться фильтр. Если в выборке больше одной таблицы, и имя поля неоднозначно, то требуется указать псевдоним таблицы.

---

### Представление

`Версия 10.0 и выше`

`Доступность: КлиентИСервер`

```
Представление: Авто|Строка
```

Задает представление фильтра в интерфейсе.
