## Методы

### ВСтроку

`Доступность: Сервер`

```
ВСтроку(): Строка
```

Возвращает строковое представление вложения.

**Переопределение** [Объект::ВСтроку](../../wiki/stdlib/object-ru-9e351f286699.md)

---

### ОткрытьПотокЧтения

`Доступность: Сервер`

```
ОткрытьПотокЧтения(
  Таймаут: Длительность = 1м,
  Прокси: ИнтернетПрокси? = Неопределено
): ПотокЧтения
```

Возвращает содержимое вложения как поток чтения.

- `Таймаут`
  
  - Таймаут, который определяет предельное время выполнения запроса к системе взаимодействия.
- `Прокси`
  
  - прокси для подключения к хранилищу сервера взаимодействия.

Будет выброшено исключение [ИсключениеОграниченияСистемыВзаимодействия](../../wiki/integration/collaborationsystemlimitexception-ru-0e9ec9960af1.md), если на сервере взаимодействия превышен лимит на получение файлов.
