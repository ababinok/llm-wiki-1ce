## Методы

### ПересчитатьКлючи

`Версия 7.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
ПересчитатьКлючи(
  Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>? = Неопределено,
  Владелец: Пользователи.Ссылка?)
```

>

Вызов возможен только с именованными параметрами

Пересчитывает ключи доступа, для указанного владельца (или для всех, если не указан) и для пользователей `Пользователи`. Если `Пользователи` = `Неопределено` - пересчитывает для всех пользователей.

**Перегрузка** [ВычисляемыйКлючДоступа::ПересчитатьКлючи(Пользователи: ЧитаемыйМассив<Пользователи.Ссылка>? = Неопределено)](../../wiki/security/computableaccesskey-ru-74362495699a.md)
