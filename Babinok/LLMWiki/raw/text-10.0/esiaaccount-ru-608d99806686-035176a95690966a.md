## Конструкторы

### УчетнаяЗаписьЕсиа

`Доступность: КлиентИСервер`

```
УчетнаяЗаписьЕсиа(Сервис: СервисУчетныхЗаписей)
```

Создает учетную запись ЕСИА в сервисе учетных записей

`Сервис`

## Свойства

### АдресПочты

`Доступность: КлиентИСервер`

```
АдресПочты: Строка
```

Адрес электронной почты пользователя, к которой привязана учетная запись в ЕСИА.

---

### ИдЕсиа

`Доступность: КлиентИСервер`

```
ИдЕсиа: Строка
```

Идентификатор пользователя в ЕСИА. Значение по-умолчанию `""`. При неправильном изменении вручную, возможность входа через ЕСИА для пользователя может быть нарушена.
