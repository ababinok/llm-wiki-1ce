## Методы

### Записать

`Доступность: Клиент`

```
Записать(
  Текст: Байты|Строка,
  Html: Байты|Строка|? = Неопределено,
  Svg: Байты|Строка|? = Неопределено,
  Изображение: Байты? = Неопределено)
```

Записывает в буфер обмена содержимое заданных видов.

---

### ЗаписатьHtml

`Доступность: Клиент`

```
ЗаписатьHtml(Html: Байты|Строка)
```

Записывает в буфер обмена данные разметки Html (MIME-тип "text/html").

---

### ЗаписатьSvg

`Доступность: Клиент`

```
ЗаписатьSvg(Svg: Байты|Строка)
```

Записывает в буфер обмена данные разметки Svg + Xml (MIME-тип "image/svg+xml").

---

### ЗаписатьИзображение

`Доступность: Клиент`

```
ЗаписатьИзображение(Изображение: Байты)
```

Записывает в буфер обмена данные изображения Png (MIME-тип "image/png").

---

### ЗаписатьТекст

`Доступность: Клиент`

```
ЗаписатьТекст(Текст: Байты|Строка)
```

Записывает в буфер обмена текстовые данные (MIME-тип "text/plain").

---

### ПолучитьВидыДанныхДляЧтения

`Доступность: Клиент`

```
ПолучитьВидыДанныхДляЧтения(): ЧитаемыйМассив<ВидДанныхБуфераОбмена>
```

Возвращает доступные для чтения виды данных содержимого буфера обмена.

#### Исключения

**[ИсключениеБуфераОбмена](../../wiki/interface/clipboardexception-ru-60397212f434.md)** - когда буфер обмена недоступен (не поддерживается браузером или функция вызвана на неактивной вкладке) или произошло обращение к недопустимому виду содержимого (например, запись Svg в браузере Firefox).

---
