`Стд::ЖурналСобытий::РезультатПоискаСобытийЖурналаСобытий` `Доступность: Сервер`

Результат поиска событий в журнале событий. После достижения конца автоматически освобождает внутренние ресурсы и не требует явного закрытия.

Ссылочное

*Базовые типы:* [Закрываемое](../../wiki/stdlib/closeable-ru-67cd73fca69d.md), [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

## Свойства

### Событие

`Доступность: Сервер` `ТолькоЧтение`

```
Событие: СобытиеЖурналаСобытий?
```

Текущее событие или `Неопределено`, если все события прочитаны.

#### Примеры

```xbsl
@НаСервере
метод ПолучитьВсеСобытияЗаСутки(): Массив<СобытиеЖурналаСобытий>
    знч От = Момент.Сейчас() - 1д
    знч До = Момент.Сейчас()
    
    пер События = новый Массив<СобытиеЖурналаСобытий>()
    
    исп РезультатПоиска = ЖурналСобытий.Найти(ДатаНачала=От, ДатаОкончания=До)
    пока РезультатПоиска.Следующий()
        События.Добавить(РезультатПоиска.Событие)
    ;
    
    // Закрывать явно необязательно, РезультатПоиска в любом случае будет закрыт после выхода из контекста метода
    РезультатПоиска.Закрыть()
    
    возврат События
;
```

```
Следующий(): Булево
```

[Событие](../../wiki/stdlib/eventlogeventsearchresult-ru-2dbf991487f4.md)
