### Код

`Доступность: Сервер` `ТолькоЧтение`

```
Код: Строка
```

Код участника интеграции. Не более 36 символов, строка должна состоять только из букв, цифр, подчеркивания, первый символ - не цифра. При попытке сохранить элемент справочника со значением кода, не удовлетворяющим требованиям, выбрасывается исключение [ИсключениеНедопустимыйФормат](../../wiki/stdlib/illegalformatexception-ru-8ff587175d1a.md).
