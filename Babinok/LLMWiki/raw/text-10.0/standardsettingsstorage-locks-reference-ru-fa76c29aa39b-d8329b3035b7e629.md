`Стд::ХранилищаНастроек::СтандартноеХранилищеНастроек.Блокировки.Ссылка` `Доступность: Сервер`

Блокировка для пространства блокировок `Ссылка` стандартного хранилища настроек [СтандартноеХранилищеНастроек](../../wiki/data/standardsettingsstorage-ru-45df1deaf228.md). Пространство используется для блокировки объектов хранилища настроек по значению поля `Ссылка`.

## Примеры

**Общие примеры**

```xbsl
метод УстановитьБлокировку(СсылкаНаНастройку: СтандартноеХранилищеНастроек.Ссылка)
    Блокировки.Заблокировать(новый СтандартноеХранилищеНастроек.Блокировки.Ссылка(Ссылка = СсылкаНаНастройку))
;
```

## Конструкторы

### СтандартноеХранилищеНастроек.Блокировки.Ссылка

`Доступность: Сервер`

```
@ИменованныеПараметры
СтандартноеХранилищеНастроек.Блокировки.Ссылка(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  Ссылка: СтандартноеХранилищеНастроек.Ссылка)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры не обязательные. Если значение параметра соответствующего полю блокировки не задано - значение этого поля в блокировке не указано (блокируются все значения).
