## Свойства

### ВРабочейОбласти

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВРабочейОбласти
```

Форма открывается в рабочей области приложения. В основной рабочей области может быть открыта только одна форма: если открывается новая, то текущая закрывается. *Рекомендация: данный вид открытия стоит использовать для списков, навигационных форм и форм сущностей.*

---

### ВДиалоговомОкне

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВДиалоговомОкне
```

Форма открывается в диалоговом окне. Такое окно открывается в новой плоскости, блокируя всю основную рабочую область. Диалоговое окно можно откладывать и возвращаться к нему с помощью панели отложенных, что позволяет выполнять параллельные сценарии. Окно автоматически откладывается в панель при переходе на другие диалоговые окна, если работа в нем не завершена. *Рекомендация: данный вид открытия стоит использовать для форм сущностей.*

---

### ВМодальномОкне

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВМодальномОкне
```

Форма открывается в модальном окне. Такое окно блокирует родителя: другое окно, либо приложение, если родительского окна нет. С помощью модального окна можно запрашивать у пользователя данные, требуемые для выполнения дальнейшей бизнес-логики. *Рекомендация: данный вид открытия стоит использовать для случаев, когда нужно получить от пользователя данные, необходимые для продолжения бизнес-логики. Лучше не использовать для форм сущностей.*

---

### ВоВсплывающемОкне

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВоВсплывающемОкне
```

Форма открывается во всплывающем окне. Такое окно открывается около активного компонента, а закрывается нажатием по области вне окна. *Рекомендация: данный вид открытия стоит использовать для форм выбора. Лучше не использовать для форм сущностей.*
