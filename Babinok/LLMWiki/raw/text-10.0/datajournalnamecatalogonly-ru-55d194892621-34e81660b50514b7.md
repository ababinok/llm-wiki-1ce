`Версия 10.0 и выше`

Таблица [журнала данных](../../wiki/project/data-journal-project-element-7531ea42bb4a.md), в состав которого входят только справочники. Таблица содержит записи, соответствующие данным справочников, входящим в состав журнала. Одна запись таблицы — один элемент справочника.

---

## Примеры

Пример запроса к таблице журнала данных **ЖурналКонтрагентов**:

```xbql
ВЫБРАТЬ
    Журнал.КлючЗаписи КАК КлючЗаписи,
    Журнал.Тип КАК Тип,
    Журнал.ФизЛица КАК ФизЛица,
    Журнал.ЮрЛица КАК ЮрЛица,
    Журнал.Код КАК Код
ИЗ
    ЖурналКонтрагентов КАК Журнал
```

---

## Поля

### {ИмяКолонки}

```
{ИмяКолонки}: ТипКолонки
```

Значение реквизита справочника, соответствующего колонке журнала.

Может принимать значение `Неопределено`, если для справочника, входящего в журнал, не указан соответствующий колонке реквизит.

---

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяСправочника.Ссылка
```

Ссылка на справочник, входящий в журнал.

---

### ПометкаУдаления

```
ПометкаУдаления: Булево
```

Пометка удаления справочника, входящего в журнал.

---

### Наименование

```
Наименование: Строка
```

Наименование элемента справочника. Необязательное поле.

В журнале поле **Наименование** будет существовать по умолчанию, только если хотя бы у одного из справочников есть реквизит **Наименование**. Наименование может быть строкой или отсутствовать. Наименование может быть разной длины, поэтому длина наименования в журнале — это максимальная длина среди всех наименований.

---

### Код

```
Код: Строка
```

Код элемента справочника. Необязательное поле.

В журнале поле **Код** будет существовать по умолчанию, только если хотя бы у одного из справочников есть реквизит **Код**. Код может быть числом, строкой или отсутствовать. Длина числа выбирается как максимальная из входящих (число может быть только целым положительным). Длина строки выбирается как максимальная из входящих.

---

### Тип

`Вычисляемое поле`

```
Тип: Тип
```

Тип ссылки на справочник, входящий в журнал.

---

### КлючЗаписи

`Вычисляемое поле`

```
КлючЗаписи: ИмяЖурналаСправочников.КлючЗаписи
```

Структура с одним полем **Ссылка**, которое содержит ссылку на справочник, входящий в журнал.
