Фрагмент командного интерфейса объединяет несколько команд и групп команд для того, чтобы показать их в интерфейсе. В отличие от [группы командного интерфейса](../../wiki/interface/command-interface-group-52b75d5d03e9.md), используется только как контейнер для компонентов командного интерфейса и не позволяет задать какие-либо настройки отображения в пользовательском интерфейсе. Если является элементом другого компонента, то отображается в соответствии с его настройками. Удобен для переиспользования в различных компонентах пользовательского интерфейса.

Все команды и группы команд внутри фрагмента должны иметь имена, уникальные в рамках одного элемента.

Может задаваться как самостоятельный элемент проекта. В таком виде используется, например, в свойствах компонента [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md):

- [КомандныйИнтерфейсПанелиНавигации](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md)
  
  ,
- [КомандныйИнтерфейсПанелиДействий](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md)
  
  ,
- [ДополнительныйКомандныйИнтерфейс](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md)
  
  .

Фрагмент командного интерфейса на форме содержит кнопки «Подсказать», «Справочники» и «В избранное». [Описание иллюстрации](../figures/5c0211ad9f50dfe3fab02a8a52cd8dab8460a69b94b4a3070b5b0264c297e9da-8f0fd7ffeed34477.md)

А это пример фрагмента командного интерфейса в панели навигации демонстрационного приложения:

В панели навигации демоприложения раскрыта группа «Активности» с командами «Задачи» и «События»; открыта форма списка задач. [Описание иллюстрации](../figures/e13b95512ef252cfdb521c7a155c1ed366562ee11ab32b6e7e2091dd28b302c2-bc74b9990cf7cb90.md)

В то время как в этом примере сама панель навигации является фрагментом командного интерфейса, каждый ее пункт является заголовком команды или группы команд. Так, **Активности** — это группа команд, каждая из которых открывает одну из двух форм: **Задачи** или **События**.

## Тип <ИмяФрагментаКомандногоИнтерфейса>

После того как вы добавили в проект фрагмент командного интерфейса, «1С:Предприятие.Элемент» создаст тип с тем же именем, что и имя вашего фрагмента командного интерфейса.

Например, если в проекте есть фрагмент командного интерфейса **ПанельНавигации**, то будет создан тип `ПанельНавигации`. В общем случае имя этого типа будет выглядеть следующим образом: `<ИмяФрагментаКомандногоИнтерфейса>`.

Этот тип доступен на клиенте.

Он не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Получить фрагмент командного интерфейса «ПанельНавигации»
пер Навигация = ПанельНавигации
```

## Модуль фрагмента командного интерфейса

В проекте модуль, расширяющий тип `<ИмяФрагментаКомандногоИнтерфейса>`, называется **модулем фрагмента командного интерфейса**. Он исполняется на клиенте.

В навигаторе показан модуль фрагмента командного интерфейса как составная часть соответствующего элемента проекта. [Описание иллюстрации](../figures/340f9b5f305f83ff237e5c7ccc65fb1133c3da0d57864010a49b019b3319e3a3-da2f9440697afdeb.md)

В этом модуле вы можете обработать события нажатия на команды, которые описаны в свойстве [`Элементы`](../../wiki/interface/command-interface-fragment-f742e5d6797f.md) этого фрагмента.

## Свойства элемента проекта

### ВидЭлемента

Вид элемента проекта ([подробнее](../../wiki/interface/all-project-elements-5977d6a645f5.md)).

### Ид

Идентификатор элемента проекта. «1С:Предприятие.Элемент» создает этот идентификатор автоматически.

### Импорт

Список импортированных пространств имен ([подробнее](../../wiki/language/modular-development-80166cfecf93.md)).

### Имя

Имя элемента проекта.

### ОбластьВидимости

Видимость элемента проекта ([подробнее](../../wiki/language/modular-development-80166cfecf93.md)):

- ВПодсистеме
  
  — элемент виден внутри одной подсистемы во всех пакетах.
  
  Значение по умолчанию
  
  .
- ВПроекте
  
  — элемент виден во всех подсистемах одного проекта.
- Глобально
  
  — элемент виден во всех подсистемах всех проектов.

### Элементы

Команда или список команд, которые будут содержаться во фрагменте. Массив следующих типов:

- [<ТипКоманды>](../../wiki/interface/command-interface-9e5d023134de.md)
  
  ,
- [ГруппаКомандногоИнтерфейса<ТипКоманды>](../../wiki/interface/command-interface-group-52b75d5d03e9.md)
  
  ,
- [ФрагментКомандногоИнтерфейса<ТипКоманды>](../../wiki/interface/command-interface-fragment-f742e5d6797f.md)
  
  .

## Пример

Пример YAML-файла, в котором используются различные способы формирования фрагмента командного интерфейса:

```yaml
ВидЭлемента: ФрагментКомандногоИнтерфейса
ОбластьВидимости: ВПодсистеме
Ид: 58e451d8-20ff-4ba8-8b92-d8dacae520cc
Имя: ФрагментИнтерфейса
Элементы:
    - # --- Вызов собственных команд, добавленных в проект
        =МояОбычнаяКоманда
    -
        =МояПереключаемаяКоманда
    -
        =ПанельНавигации

    - # --- Использование группы командного интерфейса      
        Тип: ГруппаКомандногоИнтерфейса<Команда>
        Представление: Стандартные команды элементов проекта
        Имя: СтандартныеКоманды
        Изображение: icon-desc.svg
        Элементы:
            - # --- Вызов стандартных команд элементов проекта: открытие форм справочников
                =Сотрудники.ОткрытьСписок
            - 
                =Организации.СоздатьОбъект

    - # --- Навигационная команда, описанная внутри фрагмента                   
        Тип: НавигационнаяКоманда
        Представление: Пример
        Имя: Пример
        ТипФормы: ПримерФормы

    - # --- Обычная команда, описанная внутри фрагмента      
        Тип: ОбычнаяКоманда
        Представление: Подсказать
        Имя: Подсказать
        Изображение: icon-q.svg
        Обработчик: ОбработчикКомандыПодсказать 

    - # --- Переключаемая команда, описанная внутри фрагмента
        Тип: ПереключаемаяКоманда
        ПредставлениеАктивного: Избранное
        Имя: Избранное
        ПредставлениеНеактивного: В избранное
        Обработчик: ОбработчикПереключаемойКоманды

    - # --- Фрагмент интерфейса, описанный внутри фрагмента    
        Тип: ФрагментКомандногоИнтерфейса<Команда>
        Имя: ФрагментКомандногоИнтерфейса
        Элементы:
            -
                Тип: ОбычнаяКоманда
                Представление: Настройки
                Имя: Настройки
                Изображение: РазделНастройки.svg
                Обработчик: ОбработчикКомандыНастройки
            -
                Тип: ОбычнаяКоманда
                Представление: Сервис
                Имя: Сервис
                Изображение: РазделСервис.svg
                Обработчик: ОбработчикКомандыСервис
```
