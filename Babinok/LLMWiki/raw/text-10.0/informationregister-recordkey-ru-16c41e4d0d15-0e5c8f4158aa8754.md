## Свойства

### КлючОсновногоФильтра

`Версия 9.0 и ниже`

`Доступность: Сервер` `ТолькоЧтение`

```
КлючОсновногоФильтра: РегистрСведений.КлючОсновногоФильтра
```

Свойство **КлючОсновногоФильтра** удалено из `Стд::РегистрыСведений::РегистрСведений.КлючЗаписи`. Вместо него можно использовать [КлючОсновногоФильтра](../../wiki/data/informationregistername-recordkey-ru-2cfab865dace.md), но только для независимого регистра сведений.

## Методы

### ЗагрузитьЗапись

`Доступность: Сервер`

```
ЗагрузитьЗапись(): РегистрСведений.Запись?
```

Считывает из базы данных запись, соответствующую ключу. Если запись не существует в базе данных, возвращается

`Неопределено`

.

#### Примеры

```xbsl
метод ЗагрузитьЗапись(ПользовательСсылка: Пользователи.Ссылка): ЦеныТоваров.Запись 
    возврат новый ЦеныТоваров.КлючЗаписи(Пользователь = ПользовательСсылка).ЗагрузитьЗапись() 
;
```
