`Версия 10.0 и выше`

`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяПодчиненногоРегистраСведений}.Блокировки.Регистратор` `Доступность: Сервер`

Блокировка для пространства блокировок `Регистратор` регистра сведений `ИмяПодчиненногоРегистраСведений`. Пространство используется для блокировки записей регистра сведений с указанными значениями стандартного реквизита `Регистратор`. При записи набора записей на это пространство платформой устанавливается исключительная блокировка со значениями регистратора, соответствующими фильтру набора записей.

### {ИмяПодчиненногоРегистраСведений}.Блокировки.Регистратор

`Доступность: Сервер`

```
ИмяПодчиненногоРегистраСведений.Блокировки.Регистратор(
  РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный,
  <Регистратор>: {ИмяДокумента}.Ссылка)
```

Конструирует блокировку данных в пространства блокировок соответствующему имени типа, с заданными в аргументах режимом и значениями полей блокировки. Все параметры необязательные. Если значение параметра, соответствующего полю блокировки, не задано, значение этого поля в блокировке не указано (блокируются все значения).
