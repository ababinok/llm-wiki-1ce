# Уникальность кодов элементов справочника

Код — это идентификатор элемента справочника, понятный для человека. Он может быть уникальным или неуникальным.

Если код уникальный, то во время работы приложения «1С:Предприятие.Элемент» не даст создать два элемента справочника с одинаковыми кодами, это стандартное поведение. В проекте за это отвечает свойство стандартного реквизита справочника **Код** — [Уникальность](../../wiki/data/code-ru-a7de32ab02b6.md).
