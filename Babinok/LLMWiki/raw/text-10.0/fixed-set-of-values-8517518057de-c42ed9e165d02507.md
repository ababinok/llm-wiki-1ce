# Фиксированный набор значений

При разработке приложения часто возникает необходимость иметь фиксированные наборы значений, например, состояния заказов (**Открыт**, **В работе**, **Выполнен**) или виды цен (**Оптовые**, **Розничные** и т. д.). Эти значения создаете вы и используете их в определенных местах приложения, например, в списке заказов или в прайс-листе. Пользователи не создают и не изменяют эти значения, но они могут выбирать их при редактировании прайс-листа или для того, чтобы учесть изменение состояния заказа.

В «Элементе» для решения этих задач существует вид элементов проекта **Перечисление**. Перечисление содержит элементы, каждый из которых и является некоторым значением, которое вам необходимо.

Элемент перечисления имеет имя и представление. По имени вы можете обращаться к этому элементу в коде и использовать его в проекте. Представление элемента «Элемент» покажет пользователю в интерфейсе во время работы приложения. Если вы не зададите представление, то «Элемент» будет использовать в интерфейсе приложения имя этого элемента перечисления.

Добавив в проект перечисление вы можете сразу же задать все его элементы. Один из элементов перечисления может быть элементом по умолчанию. Этот элемент «Элемент» использует следующим образом. Если в форме есть поле, имеющее тип этого перечисления и для этого поля не задано значение по-умолчанию, то «Элемент» подставит в это поле тот элемент перечисления, который указан как элемент по умолчанию в проекте.

Также элемент по умолчанию будет использован для инициализации переменной с типом этого перечисления. Например, есть перечисление **СостояниеЗаказов**, которое имеет элемент по умолчанию **Открыт**. Тогда:

```xbsl
пер Статус: СостояниеЗаказов
// здесь переменная Статус будет иметь значение СостояниеЗаказов.Открыт
```

Элемент проекта вида `Перечисление` порождает один тип, который вы можете использовать для обращения к элементам перечисления в коде ([подробнее](../../wiki/language/enumeration-name-type-f44bc1348f6f.md)).

Свойства элемента проекта вида **Перечисление** вы можете посмотреть [здесь](../../wiki/project/enumeration-92c2ac59457e.md).

Кроме создания перечислений в проекте (в виде элементов) вы можете описывать перечисления в коде модулей ([подробнее](../../wiki/language/enumeration-type-5311bbd23ddf.md)). Разница будет заключаться в том, что типы таких перечислений вы не сможете использовать для указания типа у реквизитов элементов проекта.
