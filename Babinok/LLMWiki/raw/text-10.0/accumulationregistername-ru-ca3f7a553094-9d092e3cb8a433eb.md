`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}` `Тип-одиночка` `Доступность: КлиентИСервер`

Менеджер регистра накопления. Содержит методы для работы с конкретным регистром накопления.

Для регистра накопления вызов [ПересчитатьРазрешенияДоступаДляОбъектов](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) приводит к инициации вычисления разрешений как на чтение, так и на изменение (вызываются обработчики [ВычислитьКлючиДоступаДляЧтения](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) и [ВычислитьКлючиДоступаДляИзменения](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md), а тривиальные разрешения из ключей создаются автоматически).

**Сравнение**

Ссылочное

## Методы

### Заблокировать

`Доступность: Сервер`

```
Заблокировать(Фильтр: {ИмяРегистраНакопления}.НаборЗаписей.Фильтр)
```

Устанавливает исключительную блокировку на набор записей определяемый фильтром до конца транзакции. Если транзакция не активна - выбрасывается исключение

[ИсключениеНетАктивнойТранзакции](../../wiki/data/noactivetransactionexception-ru-6e837ee18f97.md)

.

#### Примеры

```xbsl
метод ЗаблокироватьПоФильтру(НаборЗаписей: ЗаказыКлиентов.НаборЗаписей)
  ЗаказыКлиентов.Заблокировать(НаборЗаписей.Фильтр)
;
```

### ОптимизироватьПериодическиеИтоги

`Версия 8.0 и выше`

`Доступность: Сервер`

```
ОптимизироватьПериодическиеИтоги()
```

Метод доступен как для регистра остатков, так и для регистра оборотов, если свойство регистра ХранитьТекущиеИтоги = Истина.

Выполняет оптимизацию хранения периодических итогов регистра накопления в базе данных. Для вызова метода требуются права администратора. Метод может применяться для технического обслуживания системы.

В процессе работы регистра накопления в служебной таблице итогов могут накапливаться записи, которые увеличивают время доступа при запросах. Запуск метода может улучшить производительность запросов к виртуальным таблицам регистра накопления.

В процессе работы регистра накопления в служебной таблице итогов могут накапливаться записи, которые увеличивают время доступа при запросах. Запуск метода может улучшить производительность запросов к виртуальной таблице "Остатки".

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 7.0 и выше`

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<{ИмяРегистраНакопления}.КлючЗаписи>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчет разрешений на указанные записи регистра, выраженные ключами.

**Перегрузка** [ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяРегистраНакопления.КлючЗаписи>)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) [ПересчитатьРазрешенияДоступаДляОбъектов(ИмяИзмерения: ИмяСправочника.Ссылка?)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md)

#### Примеры

```xbsl
метод ПересчитатьПоНаборуКлючейЗаписи(НаборКлючейЗаписей: Обходимое<ЗаказыКлиентов.КлючЗаписи>)
    ЗаказыКлиентов.ПересчитатьРазрешенияДоступаДляОбъектов(НаборКлючейЗаписей)
;
```

### ПересчитатьРазрешенияДоступаДляОбъектов

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

**Перегрузка** [ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяРегистраНакопления.КлючЗаписи>)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) [ПересчитатьРазрешенияДоступаДляОбъектов(ИмяИзмерения: ИмяСправочника.Ссылка?)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md)

#### Примеры

```xbsl
метод ПересчитатьПоНаборуДанныхДляРасчетаРазрешений(НаборДанныхДляРасчетаРазрешений: Обходимое<ЗаказыКлиентов.ДанныеРасчетаРазрешений>)
    ЗаказыКлиентов.ПересчитатьРазрешенияДоступаДляОбъектов(НаборДанныхДляРасчетаРазрешений)
;
```

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступаДляОбъектов(
  <Параметр1>: <ТипПараметра1>,
  ....<ПараметрN>: <ТипПараметраN>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Вызов возможен только с именованными параметрами.

Пересчитывает разрешения доступа на отдельные объекты, значения реквизитов которых совпадают со значениями реквизитов, переданных в метод. В качестве реквизитов в метод могут быть переданы любые реквизиты, указанные в настройке `РасчетРазрешенийПо` элемента проекта.

**Перегрузка** [ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяРегистраНакопления.КлючЗаписи>)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md) [ПересчитатьРазрешенияДоступаДляОбъектов(ИмяИзмерения: ИмяСправочника.Ссылка?)](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md)

```xbsl
метод ПересчитатьПоЗначениямДляРасчетаРазрешений(ПользовательДляПересчета: Пользователи.Ссылка)
    ЗаказыКлиентов.ПересчитатьРазрешенияДоступаДляОбъектов(Пользователь = ПользовательДляПересчета)
```

## Обработчики

### ВычислитьРазрешенияДоступа

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на регистр накопления целиком.

#### Примеры

В данном примере мы выдаем всем аутентифицированным пользователям право только на чтение.

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
    возврат [
        новый РазрешениеДоступа([новый КлючДоступаДляАутентифицированных.Объект()], [Сущность.Право.Чтение])
    ]
;
```

---

### ВычислитьКлючиДоступаДляЧтения

`Версия 10.0 и выше`

```
ВычислитьКлючиДоступаДляЧтения(Ключи: ЧитаемыйМассив<{ИмяРегистраНакопления}.КлючРазрешенийИзмерений>): ЧитаемоеСоответствие<{ИмяРегистраНакопления}.КлючРазрешенийИзмерений,ЧитаемыйМассив<КлючДоступа.Объект>
```

Вызывается при необходимости рассчитать ключи доступа для чтения записей регистра накопления.

#### Примеры

Пример настройки прав, когда право есть только у пользователя, который указан в измерении Пользователь.

```xbsl
@Обработчик
метод ВычислитьКлючиДоступаДляЧтения(
    Ключи: ЧитаемыйМассив<ЗаказыКлиентов.КлючРазрешенийИзмерений>
): ЧитаемоеСоответствие<ЗаказыКлиентов.КлючРазрешенийИзмерений, ЧитаемыйМассив<КлючДоступа.Объект>>

    знч КлючиНаЧтение = <ЗаказыКлиентов.КлючРазрешенийИзмерений, ЧитаемыйМассив<КлючДоступа.Объект>>{:}

    для Ключ из Ключи
        КлючиНаЧтение.Вставить(Ключ, [
            новый КлючДоступаПользователя.Объект(Ключ.Пользователь)
        ])
    ;

    возврат КлючиНаЧтение
;
```

---

### ВычислитьКлючиДоступаДляИзменения

`Версия 10.0 и выше`

```
ВычислитьКлючиДоступаДляИзменения(Записи: ЧитаемыйМассив<{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений>): ЧитаемоеСоответствие<{ИмяРегистраНакопления}.ДанныеРасчетаРазрешений,ЧитаемыйМассив<КлючДоступа.Объект>
```

Вызывается при необходимости рассчитать ключи доступа для изменения записей регистра накопления.

#### Примеры

```xbsl
@Обработчик

    знч КлючиНаИзменение = <ЗаказыКлиентов.ДанныеРасчетаРазрешений, ЧитаемыйМассив<КлючДоступа.Объект>>{:}

    для Запись из Записи
        КлючиНаИзменение.Вставить(Запись, [
            новый КлючДоступаПользователя.Объект(Запись.Пользователь)
```
