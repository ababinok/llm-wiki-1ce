## Свойства

### Значение

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Значение: неизвестно
```

Содержит перетаскиваемое значение. Конкретное значение зависит от источника перетаскивания. В случае перетаскивания файлов из операционной системы, в этом свойстве содержится массив объектов типа [Файл](../../wiki/stdlib/file-ru-a4070bcf9efb.md).Ссылка.

---

### СтандартнаяОбработка

`Доступность: КлиентИСервер`

```
СтандартнаяОбработка: Булево
```

Признак выполнения стандартной (системной) обработки события. Если установить данному свойству значение `Ложь`, то стандартная обработка события производиться не будет. Отказ от стандартной обработки не отменяет действие. Всплытие события к родительским компонентам происходит только если [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) равна `Истина`.
