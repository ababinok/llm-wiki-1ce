## Методы

### Начать

`Доступность: Клиент`

```
Начать(
  ВидКонтакта: ВидКонтактаПользователя,
  Значение: Строка
): СтатусПодтверждаемойОперацииСамообслуживания
```

Начать операцию добавления контакта с указанием вида контакта. Если контакт уже добавлен, вернется неуспешный статус операции с соответствующем сообщением.

---

### ПовторитьОтправкуКодаПодтверждения

`Доступность: Клиент`

```
ПовторитьОтправкуКодаПодтверждения(): СтатусПодтверждаемойОперацииСамообслуживания
```

Повторить отправку кода подтверждения. Если превышено количество попыток отправить код подтверждения, то будет возвращена неуспешный статус операции.

---

### Подтвердить

`Доступность: Клиент`

```
Подтвердить(Код: Строка): СтатусПодтверждаемойОперацииСамообслуживания
```

Подтвердить добавление контакта кодом.
