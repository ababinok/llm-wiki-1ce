`Стд::ОбъектноеХранилище::ДвоичныйОбъект.HttpСсылка` `Доступность: КлиентИСервер`

Http ссылка на двоичный объект. Позволяет сформировать ссылку на объект в виде строки для загрузки объект из хранилища по протоколу HTTP. Ссылка поддерживает запросы типа GET и HEAD. Возвращает заголовки:

- `Content-Disposition`
  
  - содержит имя файла
- `Content-Length`
  
  - размер объекта в байтах
- `Content-Type`
  
  - MIME тип объекта
- `Content-Digest`
  
  - SHA-256 хеш объекта
- `Accept-Ranges: bytes`
  
  - доступно получение части объекта по ссылке через стандартный заголовок Range. Поддерживается возврат только одного диапазона, если в заголовке Range указано несколько диапазонов, сервер вернёт ошибку 416 Range Not Satisfiable.

## Методы

### Абсолютная

`Доступность: Клиент`

```
Абсолютная(): Строка
```

Возвращает абсолютную ссылку на загрузку объекта из хранилища. Доступен только на клиенте, использует текущий адрес приложения.

---

### Абсолютная

`Доступность: КлиентИСервер`

```
Абсолютная(СсылкаНаПриложение: Строка): Строка
```

Возвращает абсолютную ссылку на загрузку объекта из хранилища.

---

### Относительная

`Доступность: КлиентИСервер`

```
Относительная(): Строка
```

Возвращает относительную ссылку на загрузку объекта из хранилища.
