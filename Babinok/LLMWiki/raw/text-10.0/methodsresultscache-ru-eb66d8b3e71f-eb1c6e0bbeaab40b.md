`Стд::Кеширование::КешРезультатовМетодов` `Тип-одиночка` `Доступность: Клиент`

Позволяет сбросить кеш результатов методов, помеченных аннотацией [ДоступноСКлиента](../../wiki/stdlib/availablefromclient-ru-e1a5a666d615.md) с параметром `КешированиеРезультата` = `Истина`.

Ссылочное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md), [Одиночка](../../wiki/stdlib/singleton-ru-cb90fb36f1e3.md)

---

## Методы

### Сбросить

`Доступность: Клиент`

```
Сбросить(Метод: Объект)
```

Сбрасывает кеш результатов указанного метода.

`Метод`

- ссылка на метод, кеш которого надо сбросить.

#### Исключения

**null** - если передана не ссылка на метод или на метод без кеширования результата, то выбрасывается исключение.

---

### СброситьВсе

`Доступность: Клиент`

```
СброситьВсе()
```

Сбрасывает кеш результатов всех методов.
