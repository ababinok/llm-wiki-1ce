`Стд::ПобитовыеОперации` `Тип-одиночка` `Доступность: КлиентИСервер`

Набор методов для выполнения побитовых операций над типами Число и Байты. Побитовые операции реализованы для типов Байты и целых чисел (тип Число). Экземпляр типа Число преобразуется в битовую последовательность в дополнительном коде. Если в методе допускается передавать отрицательное Число, то оно логически представляется в дополнительном коде бесконечной длины.

Индексация битов начинается с 0. Если в побитовой операции используется экземпляр типа Байты, то байт с индексом `0` содержит самые младшие биты в двоичном представлении. Внутри байта младшим считается самый правый бит двоичного представления.

## Методы

### АрифметическийСдвигВправо

`Доступность: КлиентИСервер`

```
АрифметическийСдвигВправо<ТипИсточника>(
  Источник: ТипИсточника,
  Смещение: Число
): ТипИсточника
```

ТипИсточника: Тип экземпляра-источника. Допустимые типы: Число, Байты. Ограничения параметра типа: Стд::Байты, Стд::Число.

Выполняет арифметический сдвиг вправо на заданное количество битов. Для Источника типа Число допускаются как неотрицательные, так и отрицательные целые числа. Для Источника типа Байты освобождающиеся старшие биты получают значение старшего бита исходного байтового представления, а длина результата в байтах сохраняется. Возвращает новый экземпляр типа ТипИсточника.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Смещение < 0.

#### Примеры

```xbsl
метод ПримерАрифметическогоСдвигаВправо(): Число
  возврат ПобитовыеОперации.АрифметическийСдвигВправо(-0b100, 1) // знак сохраняется
;
```

Результат:

```text
-2
```

### БитоваяДлина

`Доступность: КлиентИСервер`

```
БитоваяДлина(Источник: Байты|Число): Число
```

Возвращает минимальное количество битов, необходимое для двоичного представления Источника без ведущих сброшенных битов. Для Числа метод принимает только целые неотрицательные значения.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Источник имеет тип Число и является отрицательным.

#### Примеры

```xbsl
метод ПримерБитовойДлины(): Число
  возврат ПобитовыеОперации.БитоваяДлина(0b101011)
;
```

Результат:

```text
6
```

### И

`Доступность: КлиентИСервер`

```
И<ТипИсточника>(
  Источник1: ТипИсточника,
  Источник2: МассивБитов|Байты|Число
): ТипИсточника
```

ТипИсточника: Тип экземпляра-источника. Допустимые типы: Число, Байты. Ограничения параметра типа: Стд::Байты, Стд::Число.

Выполняет побитовую операцию `И`. Второй аргумент преобразуется к представлению первого, поэтому при разных длинах более короткое представление дополняется сброшенными старшими битами. Для числовых аргументов допускаются только целые неотрицательные значения. Возвращает новый экземпляр типа ТипИсточника.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если в числовой аргумент передано отрицательное Число.

#### Примеры

```xbsl
метод ПримерПобитовогоИ(): Число
  возврат ПобитовыеОперации.И(0b11110000, 0b00111100)
;
```

Результат:

```text
0b00110000
```

Инвертирует значение бита по индексу. Для Источника типа Число допускаются как неотрицательные, так и отрицательные целые числа. Для Байтов при инверсии бита за пределами текущей длины результат расширяется до необходимого количества байтов. Возвращает новый экземпляр типа ТипИсточника.

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Источник имеет тип Число и не является целым. **[ИсключениеИндексВнеГраниц](../../wiki/stdlib/indexoutofboundsexception-ru-2b34a623369c.md)** - если Индекс < 0.

#### Примеры


### ЛогическийСдвигВправо

`Доступность: КлиентИСервер`

```
ЛогическийСдвигВправо(
  Источник: Байты,
  Смещение: Число
): Байты
```

Выполняет логический сдвиг вправо на заданное количество битов. Освободившиеся старшие биты становятся сброшенными. Метод поддерживается только для типа Байты. Длина результата в байтах сохраняется. Возвращает новый экземпляр типа ТипИсточника.

#### Исключения

**[ИсключениеНедопустимыйАргумент](../../wiki/stdlib/illegalargumentexception-ru-fc532bf88932.md)** - если Смещение < 0.

#### Примеры

```xbsl
метод ПримерЛогическогоСдвигаВправо(): Число
  знч Байты = МассивБитов.ИзЧисла(0b10110000, 8).ВБайты()
  знч Результат = ПобитовыеОперации.ЛогическийСдвигВправо(Байты, 3) // освободившиеся старшие биты становятся 0
  возврат МассивБитов.ИзБайтов(Результат, 8).ВЧисло()
;
```

Результат:

```text
0b00010110
```
