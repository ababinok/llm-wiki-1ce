`Версия 8.0 и выше`

`Стд::ИнтеграционнаяШина::СправочникИнформационныхСистем` `Доступность: КлиентИСервер`

Контракт справочника информационных систем - участников интеграции.

В качестве кода участника должна использоваться строка не более 36 символов, состоящая только из букв, цифр, подчеркивания, первый символ - не цифра. При попытке сохранить элемент справочника, реализующего данный контракт, со значением кода, не удовлетворяющим требованиям, выбрасывается исключение [ИсключениеНедопустимыйФормат](../../wiki/stdlib/illegalformatexception-ru-8ff587175d1a.md).

Нельзя изменять определенное значение ссылки на пользователя участника интеграции, при попытке сохранить такой элемент справочника, реализующего данный контракт, выбрасывается исключение [ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md).

## Методы

### ПолучитьОдиночку

`Доступность: КлиентИСервер` `Статический`

```
ПолучитьОдиночку(Источник: СправочникИнформационныхСистем.Объект|СправочникИнформационныхСистем.Ссылка|Тип<СправочникИнформационныхСистем.Объект>|Тип<СправочникИнформационныхСистем.Ссылка>): СправочникИнформационныхСистем
```

Получить экземпляр типа-одиночки, который реализует реализуют данный контракт сущности. Возвращается одиночка, соответствующий типу переданного источника, например, если передать ссылку на справочник, который реализует данный контракт, то возвращается экземпляр типа-одиночки этого справочника.
