## Методы

### Выполнить

`Доступность: Клиент`

```
Выполнить(): СтатусОперацииСамообслуживания
```

Выполнить операцию добавления биометрии для доверенного устройства для текущего пользователя. Если устройство не входит в множество доверенных, вернется неуспешный статус операции с соответствующем сообщением. Если устройство не поддерживает биометрию, вернется неуспешный статус операции с соответствующем сообщением.
