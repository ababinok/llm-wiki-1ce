[HTTP-сервис](../../wiki/integration/http-service-element-20a693318e85.md) позволяет «1С:Предприятие.Элементу» обрабатывать входящие HTTP-запросы, поступающие от внешних информационных систем. Например, процесс интеграции может быть настроен следующим образом: внешняя система отправляет сообщение по протоколу HTTP в «1С:Предприятие.Элемент», после чего в HTTP-сервисе вызывается [обработчик](../../wiki/integration/http-service-element-20a693318e85.md), который данное сообщение обрабатывает и передает дальше в программный источник. Сама схема процесса интеграции может выглядеть следующим образом:

Схема процесса интеграции [Описание иллюстрации](../figures/c9d1178b4c75b91d15e79d2682704907dee50fd8a61bc57714f17e40acc4c039-e59ff1e00bb556a2.md)

Чтобы создать новый HTTP-сервис, нажмите на значок плюса напротив нужной подсистемы и выберите **HTTP-сервис**:

Добавление нового элемента проекта [Описание иллюстрации](../figures/aec09558717e0cf74cdeef6fc39e33045c948457d372a8b74052458c9887271f-6133d2f8dc4d88d7.md)

В окне добавления элемента проекта выбран вид «HTTP-сервис». [Описание иллюстрации](../figures/f99883e2310a7e974744afec4dea180cd69f0f1e6a2657a43f9809efa4d04d33-0673765d7a7b415f.md)

Задайте имя HTTP-сервиса и нажмите **Ввод**. В структуре проекта отобразится новый HTTP-сервис:

Новый HTTP-сервис в структуре проекта [Описание иллюстрации](../figures/ac298de0d9a41580d8b308576bb7384af295430bb7254eb7396b8fbdcc50b8cc-808d9058b606e4b0.md)

В **Свойствах** HTTP-сервиса следует задать [**Корневой URL**](../../wiki/integration/http-service-element-20a693318e85.md):

В панели свойств HTTP-сервиса выделено поле «КорневойUrl» со значением «esb». [Описание иллюстрации](../figures/031e3b4130f8ecb9561306bbd47d3dcdb633a759e7f94f670fc5dc9ab2f3a0ec-637c74dd63e0b801.md)

Затем следует создать [шаблон URL](../../wiki/project/url-template-selection-4bfb8d21eb1e.md). Для этого нажмите на значок плюса рядом с пунктом **Шаблоны** HTTP-сервиса:

В дереве HTTP-сервиса выделена кнопка плюса рядом с «Шаблоны HTTP-сервиса», добавляющая шаблон URL. [Описание иллюстрации](../figures/3d776b46183023d3df4dfc43021aab6f029f238049815d549c8692bbc3e31046-441fecd2ea9c8f95.md)

Задайте имя шаблона и нажмите **Ввод**. Созданный вами шаблон отобразится во вкладке **Шаблоны**:



Следующим шагом следует создать HTTP-метод, который будет использоваться при обращении к HTTP-шаблону. Для этого нажмите на значок плюса напротив шаблона и выберите **Метод**:



Так как для передачи сообщения в «1С:Предприятие.Элемент» будет использоваться метод POST, назовите его **POST** и нажмите **Ввод**:

В дереве HTTP-сервиса внутри шаблона создан метод с именем POST для передачи сообщения в Элемент. [Описание иллюстрации](../figures/391e24ee05e098b911afe136cd084108a986850ae4c3f35dd8305861b2665980-20085ca1cefd304c.md)

При POST-запросе по URL-шаблону **messages** будет выполняться специальный метод, прописанный в [обработчике метода](../../wiki/project/url-handler-selection-a2c99bbe42d4.md) **POST**. В данном примере рассмотрим код, который будет принимать на вход сообщение из запроса, отправленного в HTTP-сервис «1С:Предприятие.Элемента», и затем отправлять его в следующий узел — **Программный Источник**.

Чтобы добавить обработчик, в свойствах метода шаблона в поле **Обработчик** нажмите на значок плюса:

В свойствах метода HTTP-шаблона POST рядом с полем «Обработчик» выделена кнопка плюса; ниже сообщение «Не задан обработчик». [Описание иллюстрации](../figures/f217d0d69806f158772638e430ceeb974bcc6a691a9f50f6413b2a05e4023760-607914867310fbb4.md)

Откроется модуль HTTP-сервиса, в котором автоматически будет создан метод с нужной сигнатурой. Данный метод будет автоматически назначен в качестве обработчика события. Впишите в тело метода следующий код:

```xbsl
метод messagesPOSTОбработкаЗапроса(Запрос: HttpСервисЗапрос)
    знч ЯвляетсяАрхивом = Запрос.Заголовки.ПолучитьПервый("content-type") == "application/zip"
    знч Сообщение = новый СообщениеИнтеграции({"IsArchive":ЯвляетсяАрхивом}, Запрос.Тело)
    ОбменТиповой.ОтправитьСообщениеВУзлы(Сообщение, ОбменТиповой.Схема.Узлы.ПрограммныйИсточник)
;
```

Имя для созданного системой обработчика также генерируется автоматически. Так, в примере выше, обработчику было присвоено имя **messagesPOSTОбработкаЗапроса**, которое состоит из следующих частей:

- `messages + POST + ОбработкаЗапроса`

Для автоматической генерации имени использовалась следующая схема:

- `ИмяШаблона + ИмяМетода + «ОбработкаЗапроса»`

Для генерации других типов обработчиков запросов используются следующие схемы:

- [Любой метод](../../wiki/integration/urltemplate-d1624a2e37c0.md):
  
  - `ИмяШаблона + «ЛюбойМетод» + «ОбработкаЗапроса»`
- [Контроль доступа](../../wiki/integration/urltemplate-d1624a2e37c0.md) к методам шаблона:
  
  - `ИмяШаблона + «КонтрольДоступа»`
- [Контроль доступа](../../wiki/integration/method-ru-44c98737758b.md) HTTP-метода:
  
  - `ИмяШаблона + ИмяМетода + «КонтрольДоступаОбработчика»`

В **Свойствах** HTTP-сервиса, в поле **Контроль доступа**, также есть возможность настроить пользователей, для которых будет доступен вызов этого сервиса:

В свойствах HTTP-сервиса раскрыта группа «КонтрольДоступа»: отдельные разрешения получения и вызова сервиса; в примере выбрано разрешение администратора. [Описание иллюстрации](../figures/efbe6cd03e01b32e5663018a1b70f9b53bce2298680aab7427eb426b2f2848ea-10b6b3132b32a45a.md)

Чтобы отправить запрос к HTTP-сервису, следует использовать следующий шаблон:

`{адрес-сервера-шины}/applications/{имя-приложения}/api/{корневой-url}/{url-шаблон}`

К HTTP-сервису, созданному в примере, можно обратиться следующим способом:

`http://127.0.0.1:9090/applications/PrimerIntegratsiiSistem-dev/api/esb/messages`

Пример POST-запроса для [авторизованной](../../wiki/security/external-program-authentication-af85e93b18a7.md) информационной системы с сообщением в теле запроса:

```text
curl -X POST 
      http://127.0.0.1:9090/applications/PrimerIntegratsiiSistem-dev/api/esb/messages \
     -H "authorization: Bearer БИЛЕТ" \
     -H "Content-Type: application/json" \
     -d "{'Тема сообщения': 'Тело сообщения'}"
```
