## Свойства

### НеИспользовать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеИспользовать
```

Список выбора не используется.

---

### Использовать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Использовать
```

Поле использует список выбора, но допускает также ввод значений, отсутствующих в списке.

---

### ТолькоЗначенияИзСпискаВыбора

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ТолькоЗначенияИзСпискаВыбора
```

В поле будет можно интерактивно ввести только те значения, которые присутствуют в списке выбора. Если в таком режиме пользователь вводит значение, а его нет в списке выбора, значение поля ввода не меняется. При этом в поле ввода можно установить любое значение программно.
