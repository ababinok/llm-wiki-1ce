`Стд::Интерфейс::Списки::ПроизвольныйСписок<ТипИсточника>` `Доступность: Клиент`

ТипИсточника: Тип источника данных списка. Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ИсточникДанных<неизвестно,неизвестно,неизвестно>.

Компонент списка, который использует [ПроизвольнаяСтрокаСписка](../../wiki/interface/customlistrow-ru-a113b0497543.md) для вывода его записей. При наличии обработчика [ПриНажатииСтроки](../../wiki/interface/list-ru-58c40755a735.md) список устанавливает обработчик события `ПриНажатии` у [Содержимое](../../wiki/interface/customlistrow-ru-a113b0497543.md) каждой строки списка, если обработчик не был установлен разработчиком.

**Сравнение**

Ссылочное

## Свойства

### КонтейнерСтрок

`Доступность: Клиент`

```
КонтейнерСтрок: Авто|Группа
```

Задает контейнер, в котором список размещает свои элементы.

#### Примеры

Например, можно указать матричную группу с шириной колонок от 100 до 200 пикселей

```yaml
Тип: Список<ИсточникДанныхМассив<Строка>>
ТипКомпонентаСтроки: СтрокаСписка
КонтейнерСтрок:
    Тип: Группа
    Компоновка: Матричная
    НастройкиМатричнойКомпоновки:
        ОписаниеАвтоматическихКолонок:
            Ширина: 200
            МинимальнаяШирина: 100
        АвтоЗаполнение: ДобавлятьКолонкиИСтроки
```

Или горизонтальную группу вместо вертикальной:

```yaml
Тип: Список<ИсточникДанныхМассив<Строка>>
ТипКомпонентаСтроки: СтрокаСписка
КонтейнерСтрок:
    Тип: Группа
    Компоновка: Горизонтальная
```

Если указано [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), то используется вертикальная [Группа](../../wiki/interface/group-ru-9e7fcb6be273.md).

`Доступность: Клиент`

Тип пользовательского компонента, наследующего компонент [ПроизвольнаяСтрокаСписка](../../wiki/interface/customlistrow-ru-a113b0497543.md), который будет использоваться для вывода элемента списка.
