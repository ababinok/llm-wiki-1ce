## Свойства

### РассчитаннаяМодифицированность

`Доступность: Клиент` `ТолькоЧтение`

```
РассчитаннаяМодифицированность: Булево
```

Устанавливается в `Истина` при выполнении любого из следующих условий:

- свойство
  
  [СобственнаяМодифицированность](../../wiki/interface/componentname-ru-ca3fcf138ae8.md)
  
  равно
  
  `Истина`
  
  ,
- свойство
  
  [РассчитаннаяМодифицированность](../../wiki/interface/componentname-ru-ca3fcf138ae8.md)
  
  у дочернего компонента, помеченного флагом
  
  `ОтслеживатьИзменениеДанных`
  
  , равно
  
  `Истина`
  
  ,
- только для
  
  [ФормаОбъекта](../../wiki/interface/objectform-ru-b5cec9fb1ea3.md)
  
  : модифицированы данные объекта.

### СобственнаяМодифицированность

`Доступность: Клиент`

```
СобственнаяМодифицированность: Булево
```

Автоматически устанавливается в `Истина`, когда изменяются отслеживаемые свойства самого компонента, у которых стоит признак `СохраняемыеДанные`.

## Методы

### ОтслеживатьИзменениеДанных

`Доступность: Клиент`

```
ОтслеживатьИзменениеДанных(
  Компонент: unknown,
  ОтслеживатьИзменениеДанных: Булево)
```

Включает или выключает отслеживание изменения данных компонента, переданного первым параметром. Если отслеживание включено, то изменение свойства

[РассчитаннаяМодифицированность](../../wiki/interface/componentname-ru-ca3fcf138ae8.md)

указанного компонента влияет на свойство

[РассчитаннаяМодифицированность](../../wiki/interface/componentname-ru-ca3fcf138ae8.md)

данного компонента.

Параметры:

- `Компонент`
  
  - Компонент, изменения данных которого требуется отслеживать или прекратить отслеживать,
- `ОтслеживатьИзменениеДанных`
  
  - Признак необходимости отслеживания изменения данных в указанном компоненте.

## Обработчики

### ПослеСоздания

```
ПослеСоздания()
```

Вызывается после создания UI-компонента системой:

- установлены значения свойств самого компонента, указанные в описании,
- созданы внутренние компоненты данного компонента, значения их свойств установлены из описаний их экземпляров,
- обработчики событий подписаны на события самого компонента и его внутренних компонентов. Предназначено для дополнительной инициализации свойств компонента на клиенте и вызова прикладной логики инициализации компонента.
