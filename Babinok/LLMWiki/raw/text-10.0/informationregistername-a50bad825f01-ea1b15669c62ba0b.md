Таблица содержит записи регистра сведений.

---

## [{ИмяРегистраСведений}.Изменения](../../wiki/queries/informationregistername-changes-ru-cbd76a6d1e7a.md)

Таблица регистрации изменений создается, только если регистр сведений включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению набора записей регистра сведений, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице регистра сведений.

---

## [{ИмяРегистраСведений}.СрезПоследних](../../wiki/queries/informationregistername-slicelast-ru-c86fed38a8d0.md)

Виртуальная таблица, которая возвращает последние внесенные в регистр сведений записи для каждой комбинации измерений. Существует только для периодических регистров сведений.
