[КлючДоступа](../../wiki/security/access-key-c2c3323f14bd.md) предназначен для того, чтобы вы могли описать в приложении собственные аспекты контроля прав доступа. Каждый элемент этого вида описывает в проекте один тип. Вы создаете экземпляры ключа (экземпляры этого типа). Они не хранятся в базе данных, хранится только их хеш-сумма.

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

#### РучнаяВыдача

`Версия 8.0 и выше`

```yaml
РучнаяВыдача: Булево
```

*Обязательное свойство*. Признак того, что экземпляры ключа доступа [выдаются/отзываются вручную](../../wiki/security/access-key-c2c3323f14bd.md). Значение по умолчанию — **Ложь**.

Для ключей доступа, выдаваемых вручную, отсутствует обработчик [ПроверитьНаличиеКлючейДоступа](../../wiki/security/computableaccesskeyname-ru-ab6483a7029c.md), становятся недоступны методы пересчета и отключаются системные вызовы пересчетов. Вы сами определяете, какие ключи доступа должны быть у пользователей и в каких случаях их необходимо отозвать.

---

#### ОтключитьСистемныеПересчеты

`Версия 8.0 и выше`

```yaml
ОтключитьСистемныеПересчеты: Булево
```

Позволяет отключить системные вызовы пересчетов [вычисляемых ключей доступа](../../wiki/security/access-key-c2c3323f14bd.md). Данная настройка применима, только если значение свойства [РучнаяВыдача](../../wiki/security/accesskey-f0f49d691d78.md) равно **Ложь**.

Системные пересчеты ключей доступа выполняются в следующих случаях:

- запись ключа доступа, экземпляра которого еще нет в системе (выполняется пересчет экземпляра ключа доступа для всех пользователей);
- создание нового пользователя в системе c непустым списком
  
  [утверждений](../../wiki/data/store-user-information-2cfd29ad3602.md)
  
  (выполняется пересчет всех экземпляров ключей доступа для данного пользователя);
- изменение
  
  [утверждений](../../wiki/data/store-user-information-2cfd29ad3602.md)
  
  пользователя (выполняется пересчет всех экземпляров ключей доступа для данного пользователя);
- изменение признака
  
  Администратор
  
  у пользователя:
  
  Истина
  
  →
  
  Ложь
  
  (выполняется пересчет всех экземпляров ключей доступа для данного пользователя).
