Предупреждающие окна ― это модальные окна, которые позволяют выводить предупреждающие сообщения для пользователей перед выполнением каких-либо действий. Окно не может быть закрыто, пока пользователь не нажмет одну из кнопок внутри окна.

Модальный диалог имеет заголовок «Удалить задачу?», сообщение «Это действие является необратимым. [Описание иллюстрации](../figures/76b6854d9eab256877b41a9b1f33043102f84cb0516d6e4654a81f2ae35b21f9-8c5f9c071dcaf409.md)

Для создания предупреждающего окна вызовите метод [`Вопрос`](../../wiki/interface/dialog-ru-c77b85fd9948.md) типа [`Диалог`](../../wiki/interface/dialog-ru-c77b85fd9948.md) и передайте следующие параметры:

- основное сообщение, которое будет отображаться в окне;
- массив кнопок. Вы можете использовать предопределенные кнопки, задаваемые элементами перечисления
  
  [`СтандартнаяКнопкаДиалога`](../../wiki/interface/standarddialogbutton-ru-bf2aadb813bf.md)
  
  , или создать свои с помощью типа
  
  [`КнопкаДиалога`](../../wiki/interface/dialogbutton-ru-c1e27b012450.md)
  
  ;
- дополнительный поясняющий текст (по умолчанию пустая строка);
- иконку окна (опционально).

Метод возвращает либо тип [`СтандартнаяКнопкаДиалога`](../../wiki/interface/standarddialogbutton-ru-bf2aadb813bf.md), либо тип свойства [`КнопкаДиалога.Значение`](../../wiki/interface/dialogbutton-ru-c1e27b012450.md), если окно содержит произвольные кнопки. Используйте возвращаемое значение, чтобы проанализировать, какую кнопку нажал пользователь, и выполнить необходимые действия.

Примеры ниже показывают, как отобразить предупреждающие окна для подтверждения удаления задачи в интерфейсе приложения.

**Пример 1**. Создание окна со стандартными кнопками:

```xbsl
знч Ответ = Диалог.Вопрос(
    "Удалить задачу?",
    [СтандартнаяКнопкаДиалога.Да, СтандартнаяКнопкаДиалога.Нет],
    "Это действие является необратимым. Продолжить?")

если Ответ == СтандартнаяКнопкаДиалога.Да
    // Код удаления задачи...
    // УдалитьЗадачу(Задачи.Ссылка)
;
```

**Пример 2**. Создание окна с произвольными кнопками:

```xbsl
// Создание кнопок предупреждающего окна.
знч КнопкаУдалить = новый КнопкаДиалога(Значение=Истина, Заголовок="Удалить",
                                        ОпасностьДействия=ОпасностьДействия.Высокая)
знч КнопкаОтменить = новый КнопкаДиалога(Значение=Ложь, Заголовок="Отменить")

знч Ответ = Диалог.Вопрос(
    "Удалить задачу?",
    [КнопкаУдалить, КнопкаОтменить],
    "Это действие является необратимым. Продолжить?")

если Ответ == КнопкаУдалить.Значение
    // Код удаления задачи...
    // УдалитьЗадачу(Задачи.Ссылка)
;
```
