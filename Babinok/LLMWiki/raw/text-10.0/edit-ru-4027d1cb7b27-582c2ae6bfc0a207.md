Поле для ввода и редактирования данных разных типов.

Поле ввода компонента: заголовок «Комментарий», подсказка «Введите произвольный комментарий», пиктограмма внутри поля и значок справки возле заголовка. [Описание иллюстрации](../figures/5723abd7437d400fb1b12b7dc657f5e53bba27f052691e6f42a17b1b1119b61e-7798c0769c48dc9b.md)

Вы можете добавить в поле ввода связанные действия:

- с помощью команды **ОткрытьЗначение** открывать ссылочное значение поля ввода в отдельном окне;
  
  open-value-of-edit-component [Описание иллюстрации](../figures/aa9a7459cfdb60e15d27d5446100da0dde2d62ebe82f4d05ef610887c2146a2c-c03520c9d69b38e4.md)
- добавить фрагмент командного интерфейса, в котором задать команды, доступные для поля ввода.
  
  У поля ввода «Значение» справа есть меню дополнительных команд. [Описание иллюстрации](../figures/811398e458ef1d3eee2059d09b03ba4fedb4ff65fc7a7f0ba1e4af655fa1f864-59cc3ef52be20860.md)

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Значение

```yaml
Значение: ВычисляемоеВыражение|неизвестно
```

Значение поля ввода. Изменяется при переходе на другой компонент интерфейса. Свойство требует двунаправленной связи с данными.

---

#### Заголовок

```yaml
Заголовок: Авто|Строка
```

Заголовок поля ввода.

---

#### Обязательное

```yaml
Обязательное: ВычисляемоеВыражение|Авто|Булево
```

Признак того, что в поле должно быть введено значение. Выглядит как красная звездочка перед заголовком. Установка этого признака имеет только визуальное значение и не оказывает никакого влияния на функционирование поля ввода.

---

#### ЗамещающийТекст

```yaml
ЗамещающийТекст: Авто|Строка
```

Замещающий текст, который отображается внутри поля ввода.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/edit-ru-4027d1cb7b27.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/edit-ru-4027d1cb7b27.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

---

#### ВидОтображенияКнопкиОчистки

```yaml
ВидОтображенияКнопкиОчистки: ВычисляемоеВыражение|Авто|ВидОтображения
```

Определяет вид отображения кнопки очистки содержимого:

В поле ввода «Наименование» формы валюты справа видна кнопка очистки «×»; на неё наведён курсор. [Описание иллюстрации](../figures/563abf40d23c85f603bcfcc38f2690f5cb53a2995ebccbd42cce72608a3b3a3f-86962ea8918d5140.md)

Очистка выполняется по следующим правилам:

- если тип поля ввода не имеет в своем составе тип
  
  `Неопределено`
  
  , то при очистке устанавливается значение по умолчанию;
- если тип поля ввода имеет в своем составе тип
  
  `Неопределено`
  
  , то при очистке устанавливается значение
  
  `Неопределено`
  
  .

Значение `Авто` интерпретируется как [Всегда](../../wiki/interface/displaykind-ru-8242ea93699b.md) в следующих случаях:

- если это мобильный интерфейс и задано значение по умолчанию;
- если это мобильный интерфейс и тип поля имеет в своем составе тип
  
  `Неопределено`
  
  ;
- если поле ввода имеет составной тип и подразумевает возврат к выбору типа перед вводом значения.

В остальных случаях `Авто` интерпретируется как [НеОтображать](../../wiki/interface/displaykind-ru-8242ea93699b.md).

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

#### Высота

```yaml

```

#### ДопустимыеТипы

```yaml
ДопустимыеТипы: ВычисляемоеВыражение|Множество<Тип>
```

Дополнительно ограничивает тип значения поля ввода на этапе исполнения кода. Используется только тогда, когда тип параметра нельзя задать с помощью обобщенного типа. Например, если тип задается динамически с помощью вычисляемого выражения.

---

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](../../wiki/interface/edit-ru-4027d1cb7b27.md).

##### Многострочная

Минимальное количество строк по вертикали

Устанавливает маску ввода строкового значения типа [Образец](../../wiki/stdlib/pattern-ru-4e0ef31a791c.md). Вводимое значение должно соответствовать указанному образцу.

Для фиксированных масок (имеющих определенную длину строки, которые могут быть однозначно разделены на символы) по умолчанию устанавливает символ подчеркивания `_`. Для динамических масок (длина строки не определена) замещающий символ не устанавливается.

### События

#### ПриАвтоПодборе

```yaml
ПриАвтоПодборе: Строка
```

«Элемент» вызывает это событие:

- Во время ввода текста, с некоторым интервалом. Значение
  
  [Текст](../../wiki/interface/onautocompleteevent-ru-f78771091970.md)
  
  может быть пустым, если пользователь стер текст в поле ввода.
- При нажатии клавиши «Стрелка вниз», кнопки открытия списка выбора или при активизации поля ввода мышью. Значение
  
  [Текст](../../wiki/interface/onautocompleteevent-ru-f78771091970.md)
  
  может быть пустым, если событие вызывается, когда пользователь еще не начал редактировать текст в поле. Если пользователь находится в процессе редактирования текста, в событии находится этот редактируемый текст.

В этом событии вы можете сформировать собственный список подобранных значений и поместить его в [ЗначенияАвтоПодбора](../../wiki/interface/onautocompleteevent-ru-f78771091970.md).

```yaml
ПриНажатииВвода: Строка
```

«Элемент» вызывает это событие при нажатии пользователем клавиши **Ввод**. Перед вызовом события введенные данные записываются в поле данных, связанное со свойством [Значение](../../wiki/interface/edit-ru-4027d1cb7b27.md). Если запись данных невозможна по причине их некорректности (например, несоответствия маске или доступному значению из списка), то запись не происходит и событие не вызывается.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

## Дочерние элеметы

#### Команды

```yaml
Команды: Авто|Команда|ФрагментКомандногоИнтерфейса
```

Набор связанных действий поля ввода, отображаемых рядом с ним. Для ссылочных полей ввода значение `Авто` преобразуется во фрагмент командного интерфейса с командой открытия сущности данного поля в отдельном диалоговом окне.

---

#### Картинка

```yaml
Картинка: Картинка
```

Картинка, которую использует поле ввода.
