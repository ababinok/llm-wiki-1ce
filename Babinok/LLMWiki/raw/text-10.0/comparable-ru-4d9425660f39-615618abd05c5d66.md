`Стд::Сравнимое<Тип>` `Доступность: КлиентИСервер`

Тип: тип, с которым сравним данный (обычно сам тип).

Базовый тип объектов, для которых определены операции сравнения (операции `<`, `>`, `>=`, `<=`).

## Методы

### Сравнить

`Доступность: КлиентИСервер`

```
Сравнить(Значение: Тип): Число
```

Сравнивает текущее значение с переданным

`Значение`

и возвращает результат в виде числа:

- Значение больше нуля - если текущее значение больше переданного
- 0 - если равны
- Значение меньше нуля - если текущее значение меньше переданного

#### Примеры

```xbsl
(1).Сравнить(2) // -1
(2).Сравнить(2) // 0
(3).Сравнить(2) // 1
```
