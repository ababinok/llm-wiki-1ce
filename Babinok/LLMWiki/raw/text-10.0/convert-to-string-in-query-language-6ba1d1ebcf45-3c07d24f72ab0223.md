В языке запросов доступны функции для конвертации значений различных типов в тип `Строка`. Значения, приведенные к типу `Строка`, затем можно использовать в выражениях внутри самого запроса.

Список методов, которые можно использовать для представления различных типов в виде строки:

- `ВСтроку()`
  
  ,
- `Представление()`
  
  ,
- `Представление(Формат: Строка)`
  
  (если тип, к которому применяется метод, является наследником типа
  
  [`Форматируемое`](../../wiki/language/formattable-type-72d4ecea32a4.md)
  
  ).

Это те же самые методы, что используются для [представления экземпляров в виде строки в языке «1С:Элемент»](../../wiki/project/represent-instances-as-string-cacec3d442ab.md). Следовательно, результат, который будет получен после применения данных методов к значениям различных типов, совпадет с результатом, который будет получен при применении данных методов к экземплярам соответствующих типов в языке «1С:Элемент».

Список типов, к которым можно применять методы конвертации в строку:

- `Null`
  
  (при попытке представить в виде строки будет возвращено
  
  [Null](../../wiki/queries/types-available-in-query-language-d6d174808211.md)
  
  ),
- `Неопределено`
  
  ,
- `Булево`
  
  ,
- `Число`
  
  ,
- `Длительность`
  
  ,
- `Дата`
  
  ,
- `Время`
  
  ,
- `ДатаВремя`
  
  ,
- `Момент`
  
  ,
- `Строка`
  
  ,
- `Байты`
  
  ,
- `Ууид`
  
  .

Чтобы преобразовать в строку примитивный тип [`Тип`](../../wiki/stdlib/type-ru-d603a6747a42.md), применяется метод `ВСтроку()`.

## Пример

Имеется [документ](../../wiki/data/document-element-0c6b898a8b13.md) «Накладная». Элементы документа хранятся в виде записей в одноименной [таблице](../../wiki/queries/documentname-ru-0745a8849d33.md) языка запросов. Нас интересуют три поля данной таблицы: **Номер**, **Дата** и **ИтоговаяСумма**:

- Поле
  
  Номер
  
  имеет тип
  
  `Строка`
  
  ;
- Поле
  
  Дата
  
  имеет тип
  
  `ДатаВремя`
  
  ;
- Поле
  
  ИтоговаяСумма
  
  имеет тип
  
  `Число`
  
  .

Задача состоит в том, чтобы в результате запроса получить поле следующего вида:

| Накладные |
| --- |
| "Накладная № **Номер** от **Дата** на сумму **ИтоговаяСумма** рублей" |
| ... |

Для этого следует выполнить следующий запрос:

```xbql
ВЫБРАТЬ
    "Накладная № " + 
    Накладная.Номер + " от " + 
    Накладная.Дата.Представление("дд.ММ.гг") + " на сумму " +
    Накладная.ИтоговаяСумма.ВСтроку() + " рублей " КАК Накладные
ИЗ
    Накладная КАК Накладная
```

Результат:

| Накладные |
| --- |
| "Накладная № 34ВА456 от 17.01.21 на сумму 25000 рублей" |
| "Накладная № 34ВА457 от 17.01.21 на сумму 32000 рублей" |
| ... |
| "Накладная № 34ВА463 от 18.01.21 на сумму 17000 рублей" |
