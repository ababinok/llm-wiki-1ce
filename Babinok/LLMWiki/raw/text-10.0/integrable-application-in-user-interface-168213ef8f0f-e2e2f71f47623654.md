Во время работы приложения «1С:Предприятие.Элемент» автоматически генерирует все команды и формы, которые требуются для работы с экземплярами интегрируемого приложения. Вы не можете изменить внешний вид или логику работы автоматически сгенерированных форм.

Форма объекта интегрируемого приложения **ПриложениеСклад**:

Форма объекта интегрируемого приложения «Приложение склад» содержит поля «Адрес», «Ид клиента», «Секрет клиента» и обязательное «Наименование», а внизу — «Готово» и «Сохранить изменения». [Описание иллюстрации](../figures/75f32409149d835be437134660e2dc177b4d345d863a5117243ebb0c325a6a3e-6a8d4b6bf6303579.md)

> [!NOTE] примечание
> В автоматически сгенерированной форме объекта интегрируемого приложения отображаются поля ввода системного реквизита **НастройкиПрямогоПодключения**, недоступного в среде разработки. Этот реквизит содержит параметры подключения текущего приложения к внешнему приложению — адрес, идентификатор клиента и секрет клиента.

Форма списка интегрируемого приложения **ПриложениеСклад**:

В форме списка «Приложение склад» колонки «Адрес», «Ид клиента», «Секрет клиента», «Наименование». [Описание иллюстрации](../figures/692aff9986cbd8b62b1f13429425a4a98049ccea6f517119382fb607270f5e3c-a54f26a9cc8b842d.md)

## Создание собственных форм

Вы можете создать собственные формы, а затем указать, что интегрируемое приложение должно использовать именно их, с помощью свойств **Интерфейс.Список.Форма** и **Интерфейс.Объект.Форма**.

Чтобы создать формы в коде, используйте методы [`СоздатьФормуОбъекта()`](../../wiki/stdlib/integrableapplicationname-ru-dded7fda26a0.md) и [`СоздатьФормуСписка()`](../../wiki/stdlib/integrableapplicationname-ru-dded7fda26a0.md) типа [`{ИмяИнтегрируемогоПриложения}`](../../wiki/stdlib/integrableapplication-ru-5607393f6b9e.md).

Например:

```xbsl
ПриложениеСклад.СоздатьФормуОбъекта()
```

Если интегрируемому приложению назначена соответствующая форма, то создается форма этого типа. Иначе создается автоматическая форма типа [`{ИмяИнтегрируемогоПриложения}.АвтоматическаяФормаОбъекта`](../../wiki/stdlib/integrableapplicationname-automaticobjectform-ru-e3c6dc952ba2.md) или [`{ИмяИнтегрируемогоПриложения}.АвтоматическаяФормаСписка`](../../wiki/stdlib/integrableapplicationname-automaticlistform-ru-5b3cecc7e37f.md).

## Команды открытия форм

При добавлении элемента проекта **ИнтегрируемоеПриложение** «1С:Предприятие.Элемент» добавляет в [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md) приложения команды открытия списка экземпляров интегрируемого приложения и создания нового экземпляра (например, для интегрируемого приложения **ПриложениеСклад**):

- `ПриложениеСклад.ОткрытьСписок()`
  
  ,
- `ПриложениеСклад.СоздатьОбъект()`
  
  .

Добавление форм в автоматический интерфейс приложения настраивается в группе свойств **Интерфейс**. Чтобы отключить добавление этих команд в автоматический интерфейс, используйте свойство **ВключатьВАвтоИнтерфейс**. По умолчанию команды, которые «1С:Предприятие.Элемент» добавляет в интерфейс приложения, в качестве своего представления используют имя интегрируемого приложения в проекте. Например, для интегрируемого приложения **ПриложениеСклад** в интерфейсе приложения будет две команды:

- ПриложениеСклад
  
  — команда перехода к списку экземпляров интегрируемого приложения.
- ПриложениеСклад
  
  — команда открытия формы нового экземпляра.

Вы можете изменить представление команд с помощью свойств **Интерфейс.Список.Представление** и **Интерфейс.Объект.Представление**. Указанное представление будет также использоваться в качестве представления команд `ИмяПриложения.ОткрытьСписок()` и `ИмяПриложения.СоздатьОбъект()`. Например, если для команды открытия формы нового экземпляра задать представление **Склад**, то в интерфейсе команда будет отображаться в единственном числе — **Склад**.
