Некоторые типы, поддерживаемые в языке запросов, позволяют обращаться к свойствам, вызывать методы и выполнять выражения, которые определены для этих типов в [языке «1С:Элемент»](../../wiki/language/1c-element-language-overview-59fed6458966.md). Далее перечислены типы и та функциональность, которая доступна для них в языке запросов.

## Null

Тип `Null` имеет единственное значение: `Null`.

> [!NOTE] примечание
> В языке «1С:Элемент» для работы со значениями `Null`, получаемыми из языка запросов или внешних баз данных, используется тип [`Null`](../../wiki/data/null-ru-0059ad0ae7ba.md) пространства имен [`Стд::БазаДанных`](../../wiki/data/database-c7a95b8f6198.md).

В языке запросов значение `Null` обозначает отсутствие данных. Например, когда при соединении таблиц для поля первой таблицы невозможно подобрать ни одной записи из второй таблицы, которая удовлетворяла бы условию связи. В этом случае поле второй таблицы будет иметь значение `Null`.

Если не сказано иного, в языке запросов любое выражение с участием `NULL` возвращает `NULL`:

- `2 + NULL`
  
  дает
  
  `NULL`
- `Контрагент == NULL`
  
  дает
  
  `NULL`

Есть две операции, которые позволяют определить, является ли указанное значение значением `Null`:

- [Операция ЕСТЬ NULL — сравнение с Null](../../wiki/project/is-null-expression-70c78665b1f8.md)
- [Операция ОТЛИЧАЕТСЯ ОТ](../../wiki/project/is-distinct-from-expression-86df4534b06c.md)

При сортировке по возрастанию `Null` всегда идет первым на всех СУБД.

[Булевы операции](../../wiki/queries/logical-and-boolean-operations-in-query-language-9dc1f24038ae.md) со значением `Null`:

- `Null или Ложь` дает `Null`
- `Null или Истина` дает `Истина`
- `Null и Ложь` дает `Ложь`
- `Null и Истина` дает `Null`
- `не Null` дает `Null`

При использовании в агрегатных функциях значения `Null` игнорируются, кроме функции `Количество(*)`.

## Байты

Используется для работы с двоичными данными (байтовыми строками).

### Литерал

Соответствует литералу типа [`Байты`](../../wiki/language/bytes-type-ad403f0fbd73.md). Пример:

```xbql
Байты{DEADBEEF}
```

Для записи шестнадцатеричного числа допускается использование как нижнего, так и верхнего регистра.

## Булево

Поддерживаются все свойства и методы типа [`Булево`](../../wiki/language/boolean-type-31a48b0a6803.md).

### Литерал

Соответствует литералу типа [`Булево`](../../wiki/language/boolean-type-31a48b0a6803.md). Пример:

```xbql
Сообщения.Доставлено == Ложь
```

## Время

Поддерживаются все свойства и методы типа [`Время`](../../wiki/language/time-type-0dd2a356632b.md).

Реализовано вычитание и сложение:

- `Время`
  
  -
  
  `Время`
  
  =
  
  `Длительность`
- `Время`
  
  +
  
  `Длительность`
  
  =
  
  `Время`

### Литерал

Соответствует литералу типа [`Время`](../../wiki/language/time-type-0dd2a356632b.md). Пример:

```xbsl
Время{00:00:00}
Время{12:34:56.789}
```

Ограничения:

- Минимальное допустимое значение времени —
  
  `00:00:00.000`
  
  .
- Максимальное допустимое значение времени —
  
  `23:59:59.999`
  
  .

## ДатаВремя

Поддерживаются все свойства и методы типа [`ДатаВремя`](../../wiki/language/datetime-type-d35f61464c24.md).

> [!NOTE] дополнительно
> При выполнении метода `ВМомент()` смещение часового пояса будет вычтено из значения `ДатаВремя`. Запросы с использованием этого метода могут работать гораздо медленнее.

Реализовано вычитание и сложение:

- `ДатаВремя`
  
  -
  
  `ДатаВремя`
  
  =
  
  `Длительность`
- `ДатаВремя`
  
  +
  
  `Длительность`
  
  =
  
  `ДатаВремя`

Реализован конструктор:

```xbql
ДатаВремя(дата)
ДатаВремя(дата, время)
```

### Литерал

Соответствует литералу типа [`ДатаВремя`](../../wiki/language/datetime-type-d35f61464c24.md). Пример:

```xbql
ДатаВремя{2024-01-01 00:00:00}
```

Ограничения:

- Минимальное допустимое значение даты —
  
  `01.01.0001 00:00`
  
  .
- Максимальное допустимое значение даты —
  
  `31.12.9999 23:59:59.999`
  
  .

## Момент

Реализован метод `ВДатаВремя()`

> [!NOTE] дополнительно
> При выполнении метода `ВДатаВремя()` смещение часового пояса будет прибавлено к значению `Момент`. Запросы с использованием этого метода могут работать гораздо медленнее

### Литерал

Соответствует литералу типа [`Момент`](../../wiki/language/instant-type-7c8265ee310d.md). Пример:

```xbql
Момент{2024-01-01T00:00:00Z}
```

Ограничения:

- Минимальное допустимое значение момента —
  
  `01.01.0001 00:00 UTC`
  
  .
- Максимальное допустимое значение момента —
  
  `31.12.3999 23:59 UTC`
  
  .

## Ссылочный тип

Используется для работы со ссылками на записи ссылочных таблиц. Определяется именем и типом идентификатора ссылки. Например, [`имя-плана-обмена.Ссылка`](../../wiki/integration/exchangeplanname-reference-ru-ea9b8c731c88.md).

Реализован конструктор `имя-плана-обмена.Ссылка()`, который позволяет создать новую ссылку по `Ууид`:

```xbql
Товары.Поставщик == Контрагенты.Ссылка(Ууид{fec3140a-5f2b-11e8-9c2d-fa7ae01bbebc})
```

### Литерал

Литерала нет. Вместо литерала следует использовать конструирование ссылки как структуры (см. пример выше).

## Строка

Значения типа `Строка` в языке запросов [сравниваются](../../wiki/queries/logical-and-boolean-operations-in-query-language-9dc1f24038ae.md) без учета регистра букв (т. е. **е** и **Е** будут считаться равными), но с учетом акцентов (т. е. **е** и **ё** будут считаться различными)

### Литерал

Соответствует литералу типа [`Строка`](../../wiki/language/string-type-e8ad86f5efd8.md). Поддерживаются [управляющие последовательности](../../wiki/project/escape-sequence-c843c60a53d9.md). Пример:

```xbql
Товары.Наименование == "Валенки"
```

## Тип

Используется для оперирования значениями типа, например для проверки типа значения.

### Литерал

Соответствует литералу типа [`Тип`](../../wiki/stdlib/type-ru-d603a6747a42.md). Пример:

```xbql
Тип<ФизическиеЛица.Ссылка> == Товары.Поставщик.ПолучитьТип()
```

## Тип перечисления

Используется для работы с [перечислениями](../../wiki/language/enumeration-name-type-f44bc1348f6f.md).

### Литерал

Синтаксис:

```xbql
<ИмяТипаПеречисления>.<ИмяЗначенияПеречисления>
```

Поддерживаются все доступные на сервере перечисления: системные, объявленные в проекте, объявленные в серверных модулях. Имя типа перечисления, объявленного в модуле, задается следующим образом: `Подсистема::Модуль.Перечисление`. Пример:

```xbql
ОстаткиТоваров.ВидДвижения == ВидДвиженияНакопления.Приход
```
