Компонент для отображения картинок разных форматов. Картинка может иметь всплывающую подсказку или служить гиперссылкой.

picture [Описание иллюстрации](../figures/b9ca2dfddd63434e992f6e7b1dbdd4fc57c1096d662c546c3b34586b1db11354-a9f052e2c9541e38.md)

---

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Изображение

`Версия 9.0 и ниже`

```yaml
Изображение: ВычисляемоеВыражение|ДвоичныйОбъект.Ссылка?
```

Свойство заменено на [Изображение](../../wiki/interface/picture-ru-b53534fbcf55.md).

---

#### Изображение

`Версия 9.0 и выше`

```yaml
Изображение: ВычисляемоеВыражение|Url|ДвоичныйОбъект.Ссылка|?
```

Ссылка на изображение.

---

#### Фигура

```yaml
Фигура: ВычисляемоеВыражение|Авто|Фигура
```

Фигура картинки: **Обычная**, **Закругленная**, **Круглая**.

---

#### Цвет

```yaml
Цвет: ВычисляемоеВыражение|Авто|Цвет
```

Цвет отображения картинки.

Применяется только для поддерживаемых картинок: правильно оформленных изображений в формате SVG.

---

#### АдаптацияКЦветуКонтейнера

```yaml
АдаптацияКЦветуКонтейнера: ВычисляемоеВыражение|Авто|Булево
```

Определяет, будет ли цвет иконки адаптироваться к цвету контейнера:

- Авто
  
  — подстраивать цвет иконки под цвет контейнера, только если иконка одноцветная;
- Истина
  
  — всегда подстраивать цвет иконки под цвет контейнера;
- Ложь
  
  — не менять цвет иконки.

---

#### АльтернативныйТекст

```yaml
АльтернативныйТекст: Авто|Строка
```

Задает текстовое описание изображения. Альтернативный текст используется для [оптимизации поисковой выдачи](../../wiki/project/seo-optimization-27876869518e.md) и является вспомогательным инструментом для людей с нарушениями зрения.

При **Авто** используется текст, указанный в свойстве [Подсказка](../../wiki/interface/picture-ru-b53534fbcf55.md). Если значение этого свойства не задано, свойству **АльтернативныйТекст** присваивается пустая строка.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/picture-ru-b53534fbcf55.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/picture-ru-b53534fbcf55.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

Позволяет управлять индивидуальным положением компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри горизонтальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены в начале, то последний компонент можно расположить в конце.

Пример горизонтального выравнивания: первые два компонента расположены в начале горизонтальной группы, последний — у противоположного края. [Описание иллюстрации](../figures/847e0f298697131e0fbd9b50b89d51e41a8dfd698a7ee3cc05b3b09baa35ad3c-8b1963441d35a227.md)

Пример конфликта горизонтального выравнивания: у второго компонента задано «Конец», у третьего — «Начало». [Описание иллюстрации](../figures/b99103f735cf8368faa3abd48f5cc63c3afc8224aa3de6451a1d06812af2d2ba-56a203a23c12d5d9.md)

#### Высота

```yaml
Высота: ВычисляемоеВыражение|Авто|Число
```

Высота компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение высоты применяется, только если оно отлично от 0 и [РастягиватьПоВертикали](../../wiki/interface/picture-ru-b53534fbcf55.md) равно **Ложь**.

Задает дополнительное значение, отображаемое в виде значка.

---

#### Доступность

```yaml
Доступность: ВычисляемоеВыражение|Авто|Булево
```

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством [ТолькоЧтение](../../wiki/interface/picture-ru-b53534fbcf55.md).

#### Масштабирование

```yaml
Масштабирование: ВычисляемоеВыражение|Авто|МасштабированиеИзображения
```

Определяет, как будет масштабироваться картинка при несовпадении ее реального размера и размера, указанного разработчиком.

- Авто
  
  — если
  
  Высота
  
  /
  
  Ширина
  
  больше реальных размеров картинки, то
  
  «Элемент»
  
  использует вариант
  
  РеальныйРазмер
  
  , иначе — вариант
  
  Пропорционально
  
  .
- Растянуть
  
  — картинка будет иметь размеры, указанные в свойствах
  
  Высота
  
  и
  
  Ширина
  
  . Если эти размеры не соотносятся с размерами картинки, то картинка будет искажена.
- РеальныйРазмер
  
  —
  
  «Элемент»
  
  отображает картинку в ее реальном размере. Если размер картинки больше чем
  
  Высота
  
  /
  
  Ширина
  
  , то края картинки будут обрезаны.
- Пропорционально
  
  —
  
  «Элемент»
  
  растягивает и сжимает картинку таким образом, чтобы занять всю указанную ширину или высоту (
  
  Высота
  
  /
  
  Ширина
  
  ).
- Заполнить
  
  — аналогично варианту
  
  Пропорционально
  
  , но
  
  «Элемент»
  
  может обрезать края картинки, если пропорции размеров
  
  Высота
  
  /
  
  Ширина
  
  не соответствуют пропорциям картинки.

#### ОбрабатыватьНажатие

```yaml
ОбрабатыватьНажатие: ВычисляемоеВыражение|Авто|Булево
```

Определяет, как обрабатывать нажатие на картинку:

- Авто
  
  — эквивалентно значению
  
  Истина
  
  , если для картинки заполнено свойство
  
  [Ссылка](../../wiki/interface/picture-ru-b53534fbcf55.md)
  
  и задан обработчик события
  
  [ПриНажатии](../../wiki/interface/picture-ru-b53534fbcf55.md)
  
  ;
- Истина
  
  — картинка обрабатывает нажатие (вызывается событие
  
  [ПриНажатии](../../wiki/interface/picture-ru-b53534fbcf55.md)
  
  ), может принимать фокус;
- Ложь
  
  — картинка не обрабатывает нажатие, не принимает фокус. Нажатие обрабатывают родительские компоненты.

    Истина

    Истина
    
    , иначе —
    
    Ложь
    
    .
  - Матричная группа
    
    ,
    
    СтрокаМатричнойГруппы

    Истина

#### Ссылка

```yaml
Ссылка: ВычисляемоеВыражение|Сущность.Ключ|Строка|?
```

Ссылка, которая будет открываться при нажатии на картинку.

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/picture-ru-b53534fbcf55.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/picture-ru-b53534fbcf55.md).

---

#### Ширина

```yaml
Ширина: ВычисляемоеВыражение|Авто|Число
```

Ширина компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если **Авто**, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](../../wiki/interface/picture-ru-b53534fbcf55.md) равно **Ложь**.

---

#### ШиринаВКолонках

```yaml
ШиринаВКолонках: ВычисляемоеВыражение|Авто|ШиринаВКолонках
```

Ширина компонента в колонках. Если **Авто**, то рассчитывается автоматически.

### События

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриНажатии

```yaml
ПриНажатии: Строка
```

Вызывается при нажатии на картинку, если свойство [ОбрабатыватьНажатие](../../wiki/interface/picture-ru-b53534fbcf55.md) равно **Истина**. Стандартная обработка события **ПриНажатии** выполняется, только если для свойства `СтандартнаяОбработка` установлено значение `Истина`.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
