## Конструкторы

### НастройкиАвтоматическогоФильтраПоляКоллекцииДинамическогоСписка

`Доступность: КлиентИСервер`

```
НастройкиАвтоматическогоФильтраПоляКоллекцииДинамическогоСписка(
  НастройкиВводаСсылок: Авто|НастройкиВводаСсылок,
  ЗначениеФильтраПоУмолчанию: Массив<Объект?>)
```

Создает настройки по умолчанию.

---

## Свойства

### ЗначениеФильтраПоУмолчанию

`Доступность: КлиентИСервер`

```
ЗначениеФильтраПоУмолчанию: Массив<Объект?>
```

Задает значение по умолчанию для автоматического фильтра. Такое значение будет подставлено в фильтр сразу после создания компонента [Список](../../wiki/interface/list-ru-58c40755a735.md), если ему не задано ранее сохраненное значение (см. [Список](../../wiki/interface/list-ru-58c40755a735.md).[ПриЧтенииНастроек](../../wiki/interface/list-ru-58c40755a735.md)).

---

### НастройкиВводаСсылок

`Доступность: КлиентИСервер`

```
НастройкиВводаСсылок: Авто|НастройкиВводаСсылок
```

Определяет настройки ввода ссылок для автоматического фильтра.
