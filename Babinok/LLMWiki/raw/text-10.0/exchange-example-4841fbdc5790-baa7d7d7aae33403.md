В этой статье показан пример организации обмена данными между двумя приложениями «1С:Предприятие.Элемента» — **ЦентральныйОфис** и **ОптовыйСклад**. Между ними синхронизируются изменения номенклатуры товаров и изменения остатков. Обмен можно инициировать только из офиса: приложение **ЦентральныйОфис** выступает в роли инициатора, **ОптовыйСклад** — в роли последователя.

## Настройка проекта в среде разработки

Для организации обмена сначала настройте проекты обоих приложений в среде разработки. Элемент проекта **ИнтегрируемоеПриложение** и план обмена с настроенной передачей данных добавляются в проект **ЦентральныйОфис**. В проекте **ОптовыйСклад** добавляется только план обмена с тем же именем и составом, без настройки передачи данных — все параметры подключения задаются на стороне проекта **ЦентральныйОфис**.

### Настройка приложения «ЦентральныйОфис»

1. В навигаторе проекта среды разработки добавьте элемент проекта **ИнтегрируемоеПриложение** с именем **ПриложениеСклад**. Это приложение будет использоваться для подключения к приложению **ОптовыйСклад**.
  
  <details>
  <summary>Пример YAML-файла интегрируемого приложения «ПриложениеСклад»</summary>
  
  ```yaml
  ВидЭлемента: ИнтегрируемоеПриложение
  Ид: 6df27393-34c1-41d3-b1f5-68fe82e1e329
  Имя: ПриложениеСклад
  ОбластьВидимости: ВПроекте
  РежимУдаления: Немедленно
  Реквизиты:
      -
          Имя: Наименование
  ```
  
  </details>
2. Добавьте план обмена **УдаленныйСклад**. В свойстве [Cостав](../../wiki/integration/exchangeplan-47d882fe414b.md) плана обмена укажите элементы проекта, участвующие в обмене данных, и настройте [передачу данных](../../wiki/integration/exchangeplan-47d882fe414b.md) через созданное интегрируемое приложение:
  
  <details>
  <summary>Пример YAML-файла плана обмена «УдаленныйСклад»</summary>
  
  ```yaml
  ВидЭлемента: ПланОбмена
  Ид: dc5c1eae-e90c-495b-80ea-ad7340917384
  Имя: УдаленныйСклад
  ОбластьВидимости: ВПроекте
  РежимУдаления: Немедленно
  Состав:
      - Элемент: Товары
      - Элемент: Остатки
  ПередачаДанных:
      Использовать: Истина
      ИнтегрируемыеПриложения:
          - Имя: ПриложениеСклад
  ```
  
  </details>

### Настройка приложения «ОптовыйСклад»

В проекте приложения **ОптовыйСклад** добавьте план обмена с тем же именем **УдаленныйСклад** и тем же составом элементов. План обмена в этом проекте не настраивается на передачу данных — настройки подключения задаются только в приложении **ЦентральныйОфис**.

<details>
<summary>Пример YAML-файла плана обмена «УдаленныйСклад»</summary>

```yaml
ВидЭлемента: ПланОбмена
Ид: 5a8c1d2e-3b4f-4956-9c8a-7d6e5f4a3b2c
Имя: УдаленныйСклад
ОбластьВидимости: ВПроекте
РежимУдаления: Немедленно
Состав:
    - Элемент: Товары
    - Элемент: Остатки
```

</details>

> [!NOTE] примечание
> Имена планов обмена в обоих проектах должны совпадать. Если в одном из проектов план обмена называется иначе, укажите в настройке передачи данных свойство **ИмяПланаОбменаВИнтегрируемомПриложении** — в нем задается имя плана обмена во внешнем проекте, которое будет использоваться при сопоставлении.

## Настройка запущенного приложения

После настройки проектов в среде разработки выполните настройку в запущенных приложениях и в панели управления.

### Настройка приложения «ОптовыйСклад»

1. Настройте узлы для плана обмена **УдаленныйСклад**:
  
  - Измените код узла
    
    ЭтотУзел
    
    на
    
    ОптовыйСклад
    
    . Код узла используется для идентификации участника обмена в протоколе сообщений.
  - Добавьте узел
    
    ЦентральныйОфис
    
    с кодом
    
    ЦентральныйОфис
    
    . Этот узел представляет приложение
    
    ЦентральныйОфис
    
    в базе данных
    
    ОптовыйСклад
    
    .
  
  Настройки узлов плана обмена [Описание иллюстрации](../figures/b89a262ffe022c9d224f955fd140091e000f2a7e1b925b43ffd2052c3fd91104-a3b7e1ed5634b96e.md)
2. В панели управления [создайте пользователя](https://1cmycloud.com/console/help/element/10.0/docs/topics/create-user/) с именем **ЦентральныйОфис** и получите для него [ключ доступа](../../wiki/security/get-user-key-9b77ae83ecbb.md). Идентификатор клиента и секрет клиента этого пользователя нужно будет передать администратору приложения **ЦентральныйОфис** — они используются для аутентификации при установке соединения между приложениями.
  
  

### Настройка приложения «ЦентральныйОфис»

1. В форме объекта интегрируемого приложения создайте экземпляр **ОптовыйСклад** и заполните параметры подключения, полученные от администратора приложения **ОптовыйСклад**:
  
  - Адрес
    
    — адрес приложения, по которому пользователи работают в браузере.
  - ИдКлиента
    
    — идентификатор клиента, выданный администратором приложения
    
    ОптовыйСклад
    
    .
  - СекретКлиента
    
    — секрет, выданный администратором приложения
    
    ОптовыйСклад
    
    .
  
  Карточка интегрируемого приложения склада содержит поля «Адрес», «Ид клиента», «Секрет клиента» и обязательное «Наименование». [Описание иллюстрации](../figures/5a4828ea7b894ae922316bf0a497bdbbc75e1cd2bb8e4b23733f18161423acd5-1cdb6f991ab9fc93.md)
2. Настройте узлы для плана обмена **УдаленныйСклад**:
  
  - Измените код узла
    
    ЭтотУзел
    
    на
    
    ЦентральныйОфис
    
    .
  - Добавьте узел
    
    ОптовыйСклад
    
    с кодом
    
    ОптовыйСклад
    
    и установленным флагом
    
    Активность
    
    . В настройках передачи данных этого узла выберите созданный экземпляр интегрируемого приложения
    
    ОптовыйСклад
    
    :
  
  Настройки узлов плана обмена [Описание иллюстрации](../figures/aa430ad1ad38b6161b7373ada3ba63b01de7e88169a15385888e1b2d200c50f4-d69c19315fbb9f65.md)

## Выполнение обмена

После записи узла плана обмена с активированной передачей данных в приложении **ЦентральныйОфис** «1С:Предприятие.Элемент» автоматически создает запланированное задание, выполняющее обмен данными для этого узла. Расписание по умолчанию — один раз в минуту, при необходимости администратор может его изменить.

Согласно расписанию запланированное задание выполняет обмен данными в потоковом режиме:

1. Устанавливает соединение с приложением
  
  ОптовыйСклад
  
  по настройкам подключения экземпляра интегрируемого приложения
  
  ОптовыйСклад
  
  : получает токен, запрашивает метаданные и открывает долговременное соединение.
2. Выгружает сообщение обмена данными для узла
  
  ОптовыйСклад
  
  и передает его получателю. Изменения номенклатуры товаров, зарегистрированные в приложении
  
  ЦентральныйОфис
  
  , передаются в
  
  ОптовыйСклад
  
  .
3. Инициирует в приложении
  
  ОптовыйСклад
  
  выгрузку сообщения обмена данными для узла
  
  ЦентральныйОфис
  
  , получает это сообщение и загружает его в свою базу данных. Изменения остатков, зарегистрированные в приложении
  
  ОптовыйСклад
  
  , передаются в
  
  ЦентральныйОфис
  
  .

Пока соединение с приложением **ОптовыйСклад** активно и запланированное задание выполняется по расписанию, все изменения сущностей, включенных в состав плана обмена **УдаленныйСклад**, автоматически синхронизируются между приложениями в обе стороны: каждое изменение номенклатуры в приложении **ЦентральныйОфис** отражается в приложении **ОптовыйСклад**, и наоборот. «1С:Предприятие.Элемент» самостоятельно обеспечивает установку соединения, передачу изменений по расписанию и фиксацию транзакций, поэтому для синхронизации данных между приложениями не требуется писать прикладной код.
