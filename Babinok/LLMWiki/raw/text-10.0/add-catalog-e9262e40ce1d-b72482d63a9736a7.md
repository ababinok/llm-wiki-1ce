> [!NOTE] примечание
> Этот пример использует [приложение «Демо CRM»](../../wiki/project/demo-app-3768685a4428.md).

В данном примере вы создадите новый [элемент проекта](../../wiki/project/project-element-e0f54b4a4951.md) вида [Справочник](../../wiki/data/catalog-project-element-b6ca52d114d4.md) и добавите команду открытия этого справочника в раздел **Активности** демонстрационного приложения.

Справочник «Проекты» в демо-приложении [Описание иллюстрации](../figures/9ad7390e6ebb7a77c7c1e1788408418f3675679e8487482a08524c67aa2f0dbd-5830d5873bf23261.md)

[Откройте](../../wiki/project/open-app-in-ide-2c0162ac1160.md) демо-приложение в среде разработки и выполните следующие действия:

1. Добавьте новый справочник в [подсистему](../../wiki/project/hierarchical-project-structure-397ba5e7f9df.md) **Активности**. Для этого наведите мышку на имя подсистемы и нажмите на знак плюса.
2. В открывшемся окне выберите элемент проекта **Справочник**.
  
  
3. Задайте имя справочника — **Проекты**. По умолчанию справочник будет иметь один реквизит — **Наименование**.
4. Выделите справочник в дереве объектов и в панели свойств задайте для него представления списка и объекта.
  
  В свойствах справочника «Проекты» указаны представления списка и объекта, используемые в интерфейсе приложения. [Описание иллюстрации](../figures/36d8b9858c2c7ceb33c7ac309efbd4e92e5a9f44f5908b9612710aa53b10b9c9-07a7ed1b93b85596.md)
  
  > [!NOTE] примечание
  > Подробнее о выборе представлений для элементов проекта см. в стандарте [«Имена элементов проекта»](../../wiki/project/project-element-names-standard-f12f4bc2a448.md).
5. Добавьте к справочнику стандартный реквизит **Код**. В навигаторе проекта разверните структуру справочника и нажмите на знак плюса в разделе **Реквизиты**. В открывшемся окне выберите **Код**.
  
  Добавление реквизита «Код» [Описание иллюстрации](../figures/8c1101542a0f094cd1115a96fa6e05f271dbc4823ea6166e0ee12bdfa2d43582-1991453276f7abc4.md)
6. Выделите реквизит **Код** и в панели **Свойства** укажите для свойства **Длина** значение **2**. Для каждого проекта будет автоматически генерироваться уникальный код в диапазоне от 1 до 99.
  
  Задание свойств реквизита «Код» [Описание иллюстрации](../figures/a9a1589428a0430298a85d64eefcaf639638f23c41ccc64e27e524ec9fa7511e-01fe4c47429f7207.md)
7. Добавьте реквизит **Описание**, в котором будет храниться описание проекта:
  
  - В разделе
    
    Реквизиты
    
    нажмите на знак плюса и выберите пункт
    
    Реквизит
    
    в открывшемся окне.
  - Введите имя реквизита.
  - В панели свойств реквизита укажите его тип —
    
    `Строка`
    
    . Установите значение свойства
    
    Многострочная
    
    как
    
    Истина
    
    .
  
  
8. «1С:Предприятие.Элемент» умеет формировать [автоматический интерфейс](../../wiki/interface/auto-generated-ui-7150689c0714.md) для элементов проекта. Поэтому вы можете не создавать формы для своего справочника, а сразу включить его в интерфейс.
  
  Из предыдущих примеров вы уже знаете, [где находится командный интерфейс приложения](../../wiki/interface/locate-command-interface-7543048d998d.md). Чтобы изменить его, выполните следующие действия:
  
  - В навигаторе проекта перейдите к элементу **НавигацияАктивности** и раскройте его содержимое.
  - Выделите компонент [ГруппаКомандногоИнтерфейса](../../wiki/interface/command-interface-group-52b75d5d03e9.md). Нажмите на знак плюса, чтобы добавить к нему новую команду, и выберите пункт **Вычисляемое выражение** в открывшемся окне.
    
    В дереве командного интерфейса выбрана «ГруппаКомандногоИнтерфейса» внутри «НавигацияАктивности». [Описание иллюстрации](../figures/5e3eda76ddab023955b2b22e891e26bd10b227b6bba93ec5cad87b095d13e638-7ef9272c44e78d68.md)
  - В панели свойств выражения выберите команду `Проекты.ОткрытьСписок`.
    
    
  
  Новая команда появится в конце раздела **Активности**.
  
  <details>
  <summary>Пример YAML-файла элемента проекта «НавигацияАктивности»</summary>
  
  ```yaml
  Ид: fe84665d-1862-4dc7-8966-227787333823
  Имя: НавигацияАктивности
  ОбластьВидимости: ВПроекте
  Элементы:
      -
          Тип: ГруппаКомандногоИнтерфейса
          Важность: Обычная
          Видимость: Истина
          Доступность: Истина
          Изображение: Активности.svg
          Представление: $АктивностиЛокализация.Активности
          Элементы:
              - =Задачи.ОткрытьСписок
              - =События.ОткрытьСписок
              - =Проекты.ОткрытьСписок
  ```
  
  </details>
9. [Опубликуйте](../../wiki/project/publish-project-on-server-dade1898bf5e.md) проект на сервере и перезапустите приложение. Нажмите **Активности** ⟶ **Проекты**, и вы увидите автоматическую форму списка.
  
  Вы можете создать несколько элементов справочника, при этом будет использоваться автоматическая форма объекта.
  
  Пример автоматической формы объекта справочника Проекты: заголовок «Проект», ссылка возврата к списку «Проекты», поля Наименование, Код и многострочное Описание. [Описание иллюстрации](../figures/226a513c0f33cecb4111240e3fa54e848a0a77182e63d816adbdd2a84ab7064e-cc5c9ece5be022b2.md)
10. [В следующем примере](../../wiki/interface/add-project-element-forms-2ae9079946eb.md) вы добавите к этому справочнику собственные формы.
