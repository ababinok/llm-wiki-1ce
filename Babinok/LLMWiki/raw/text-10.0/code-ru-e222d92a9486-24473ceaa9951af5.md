Стандартный реквизит, который содержит уникальный идентификатор элемента проекта или обеспечивает последовательную нумерацию элементов.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Тип

```yaml
Тип: Тип[]
```

Тип свойства контракта сущности.

---

#### ДлинаЦелойЧасти

```yaml
ДлинаЦелойЧасти: Число
```

Максимально допустимая длина целой части числа.

---

#### МаксимальнаяДлина

```yaml
МаксимальнаяДлина: Число
```

Максимально допустимая длина строки.

---

#### ДлинаДробнойЧасти

```yaml
ДлинаДробнойЧасти: Число
```

Максимально допустимая длина дробной части числа.

---

#### МаксимальноеЗначение

```yaml
МаксимальноеЗначение: Число
```

Максимально допустимое значение числа.

---

#### МинимальноеЗначение

```yaml
МинимальноеЗначение: Число
```

Минимально допустимое значение числа.

---

#### КонтрольУникальности

`Версия 9.0 и выше`

```yaml
КонтрольУникальности: КонтрольУникальности
```

Признак уникальности кодов элементов проекта. Значение по умолчанию — **Истина**.

---

#### ОграниченияЭлементов

```yaml
ОграниченияЭлементов: 
    ДлинаЦелойЧасти: Число
    ДлинаДробнойЧасти: Число
    МаксимальноеЗначение: Число
    МинимальноеЗначение: Число
    МаксимальнаяДлина: Число
```

Задает ограничения, применимые к элементам.

#### ПриУдаленииОбъектаПоСсылке

```yaml
ПриУдаленииОбъектаПоСсылке: ДействиеПриУдаленииОбъектаПоСсылке
```

Определяет поведение при удалении элемента, указанного в качестве реквизита ([подробнее](../../wiki/project/data-deletion-141a62f69ff7.md)).

---

#### ТолькоЧтение

```yaml
ТолькоЧтение: Булево
```

Определяет доступность свойства для чтения. Значение по умолчанию — **Ложь**.
