`Стд::Интерфейс::ОбщиеКомпоненты::ВыборЗначения<ТипДанных>` `Доступность: Клиент`

ТипДанных: тип значения компонента выбора значений. Если это [Массив](../../wiki/stdlib/array-ru-f0659b9628e1.md), компонент будет принимать вид группы флажков, иначе - группы радиокнопок или сегментов. Параметр типа должен иметь значение по умолчанию или `Неопределено` в составе типов.

Компонент, позволяющий выбрать один или несколько вариантов из заданного списка.

Компонент выбора значений. Может представлять собой переключатель, группу радиокнопок или группу флажков (для множественного выбора). Подстраивается под переданный параметр типа данных.

**Сравнение**

Ссылочное

## Свойства

### ВидОтображенияПереключателя

`Доступность: Клиент`

```
ВидОтображенияПереключателя: Авто|ВидОтображенияПереключателя
```

Определяет внешний вид одного элемента выбора, если ТипДанных определился, как выбор одного значения

---

### Заголовок

`Доступность: Клиент`

```
Заголовок: Строка
```

Заголовок, отображаемый над группой выбора значений.

Не учитывается для свойства [ВидОтображенияПереключателя](../../wiki/interface/valuechoice-ru-b6140ef5eb57.md) равного [Переключатель](../../wiki/interface/switcherdisplaykind-ru-22c480e72b3e.md).

---

### Значение

`Доступность: Клиент`

```
Значение: ТипДанных
```

Текущее значение выбора.

Если ТипДанных определился, как выбор одного значения – это ТипДанных, иначе [Массив](../../wiki/stdlib/array-ru-f0659b9628e1.md)<ТипДанных>.

---

### Ориентация

`Доступность: Клиент`

```
Ориентация: Авто|ОриентацияСодержимого
```

Указывает ориентацию элементов в группе выбора – по горизонтали или вертикали.

Не учитывается для свойства [ВидОтображенияПереключателя](../../wiki/interface/valuechoice-ru-b6140ef5eb57.md) равного [Переключатель](../../wiki/interface/switcherdisplaykind-ru-22c480e72b3e.md).

---

### СписокВыбора

`Доступность: Клиент`

```
СписокВыбора: Авто|Массив<(ТипДанных это Массив<неизвестно> ? ТипДанных.ItemType : ТипДанных)|ЭлементСпискаЗначений<ТипДанных это Массив<неизвестно> ? ТипДанных.ItemType : ТипДанных>>
```

Устанавливает определенный список выбора.

При Авто для параметра ТипДанных, наследуемого от типа [Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md) или являющимся [Массив](../../wiki/stdlib/array-ru-f0659b9628e1.md)<[Перечисление](../../wiki/stdlib/enum-ru-a7a357b96b4c.md)>, список выбора указывать необязательно. Система сама построит интерфейс на основании элементов переданного перечисления.

В качестве списка можно использовать массив с типом [ЭлементСпискаЗначений](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md), где в качестве представления элементов используется соответствующее свойство [Представление](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md). Если оно не задано и не задана картинка, то используется строковое представление свойства [Значение](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md).

В простых случаях, в качестве списка, можно использовать массив элементов конкретного типа, переданного в параметре ТипДанных.

---

### ЭлементыПереключателяОднойШирины

`Доступность: Клиент`

```
ЭлементыПереключателяОднойШирины: Авто|Булево
```

Указывает, должны ли элементы иметь одинаковую ширину вне зависимости от содержимого при значении свойства [ВидОтображенияПереключателя](../../wiki/interface/valuechoice-ru-b6140ef5eb57.md) равного [Переключатель](../../wiki/interface/switcherdisplaykind-ru-22c480e72b3e.md).
