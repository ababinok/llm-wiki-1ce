Показывает календарь и элемент выбора времени, с помощью которых пользователь может ввести дату, время и интервал.

date-time-picker [Описание иллюстрации](../figures/a17cf80aeb4227f68e707fc49beac7be0a28f126a3e9c412963c15232de8c784-cf1cdba72f3c2b0b.md)

## Иерархия наследования

## Свойства

### Значение

Отображаемое и редактируемое значение. Может принимать значение одного из следующих типов: `Неопределено`, `Момент`, `Дата`, `ДатаВремя`, `Время`, `ЗакрытыйДиапазон<Дата>`, `ЗакрытыйДиапазон<Время>`, `ЗакрытыйДиапазон<ДатаВремя>`, `ЗакрытыйДиапазон<Момент>`. Свойство требует двунаправленной связи с данными.

### ССекундами

`Авто|Булево`. Признак того, что можно редактировать секунды. В этом режиме компонент показывает дополнительный элемент для выбора секунд.

ССекундами [Описание иллюстрации](../figures/a757be0ace960bac7787c780e3f673e78e28cdb9b7abe3abab1ae94fcb3f7652-cca03ce147d36bf6.md)

### ТипРедактирования

Тип редактируемого значения. Внешний вид компонента зависит от типа редактируемого значения.

Если тип редактируемого значения — `ДатаВремя`, то в компоненте будут показаны элементы выбора и даты, и времени.

Пример выбора значения ДатаВремя: рядом показаны два календарных месяца, а справа — прокручиваемые колонки часов и минут. [Описание иллюстрации](../figures/1d001a26a3bf9fc5f5ae97815e05df1bcb00950c76f2cd0ca97e1dbad0ad5561-3527b47e5c46b26d.md)

Если тип редактируемого значения — `Дата`, то в компоненте будут показан только элемент выбора даты.

Компонент выбора даты показывает календарь двух соседних месяцев и выделение отдельной даты; элементов выбора времени или диапазона в этом примере нет. [Описание иллюстрации](../figures/dd7f251a4f503fe381414e33b58afc2168bba1a103814020e008233f3dd10bd0-bae1879913282c92.md)

Если тип редактируемого значения — `Время`, то в компоненте будут показан только элемент выбора времени.

Для значения типа Время показан только выбор времени: два вертикальных прокручиваемых столбца часов и минут, разделённые двоеточием. Выбрано 0:0; рядом видны часы 23 и 1, минуты 55 и 5, стрелки прокрутки вверх и вниз. Календарь на этом снимке отсутствует. [Описание иллюстрации](../figures/c41ce22cb3da474b49e14519e697d8ed13e0165d70ab12b6caa43550231e0da4-3391f94468d0a98a.md)

Если тип редактируемого значения — `ЗакрытыйДиапазон<Дата>`, то в компоненте будет возможность выбора периода дат.

Компонент выбора периода: рядом показаны два месяца, начальная и конечная даты выделены цветом, промежуток между ними закрашен. Это пример редактирования ЗакрытыйДиапазон<Дата>. [Описание иллюстрации](../figures/43af185bbe6a967bbd498a60ba46c847bef651c9d12b269055fb2a8e13226497-1c99ff7a2ed1a4fb.md)

Если тип редактируемого значения — `ЗакрытыйДиапазон<Время>`, то в компоненте будут показаны два элемента выбора времени — для начала и конца интервала.

Выбор периода времени содержит две пары колес часов/минут: начало 9:0 и конец 18:0. [Описание иллюстрации](../figures/70d36c6cabf3e0ad3bf78bda956d01a60fc92d0cb17aeebeb0ff4771fe2c6114-1a5b663acbf4bcfb.md)

Например, если у данного компонента `ВесПриРастягивании` = 1, а у другого `ВесПриРастягивании` = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

- `Авто`

  `ВыравниваниеПоВертикали.ПоБазовойЛинии`
  
  ;
- элементы перечисления
  
  `ВыравниваниеПоВертикали`
  
  —
  
  `Верх`
  
  ,
  
  `Центр`
  
  ,
  
  `Низ`
  
  ,
  
  `ПоБазовойЛинии`

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение `Низ`, а у второго — `Верх`, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)

### Высота

`Авто|Число`. Высота компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если `Авто`, то рассчитывается автоматически. Явно заданное значение высоты применяется, только если оно отлично от 0 и [РастягиватьПоВертикали](../../wiki/interface/date-time-choice-component-6b891eec73f9.md) равно `Ложь`.

### Доступность

Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. Состояние доступности распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет приоритет над свойством `ТолькоЧтение`.

### ТолькоЧтение

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние `ТолькоЧтение` распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство `Доступность`.

### Ширина

`Авто|Число`. Ширина компонента в пикселях ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

Если `Авто`, то рассчитывается автоматически. Явно заданное значение ширины применяется, только если оно отлично от 0 и [РастягиватьПоГоризонтали](../../wiki/interface/date-time-choice-component-6b891eec73f9.md) равно `Ложь`.

### <Свойство разработчика>

Собственное свойство компонента, добавленное разработчиком. Описывается следующими свойствами:

#### ЗначениеПоУмолчанию

Стандартное значение свойства. Значение можно не указывать, если у его типа/типов есть значение по умолчанию (в частности, если его тип включает `Неопределено` или `Null`). Если тип свойства составной (включает несколько типов), необходимо указать тип значения. Иначе просто само значение.

В [описании экземпляра](../../wiki/interface/system-and-interface-components-18287074edda.md) этого компонента вы можете установить другое значение этому свойству.

#### Имя

Имя свойства.

#### Контекстное

`Булево`. Признак доступности значения свойства на клиенте и сервере. Значение по умолчанию — `Ложь`. Если `Истина`, то поле **Тип** свойства должно содержать тип, доступный на клиенте и сервере.

«1С:Предприятие.Элемент» генерирует структурный тип [`{ИмяКомпонента}.Контекст`](../../wiki/interface/componentname-context-ru-e40a3f370a75.md), который содержит как собственные контекстные свойства, так и контекстные свойства, наследуемые от базовых системных типов. Этот тип генерируется всегда, даже если контекстные свойства отсутствуют.

Пример:

```yaml
Имя: МойКомпонент
Свойства:
    -
        Имя: КонтекстноеСвойство
        Тип: Строка
        Контекстное: Истина
```

Для работы с контекстными свойствами на сервере вы можете использовать *контекстные серверные методы*. Эти методы должны располагаться в модуле компонента интерфейса и содержать аннотации [`@Контекстный`](../../wiki/stdlib/contextual-ru-468258bf9c74.md) и [`@НаСервере`](../../wiki/stdlib/onserver-ru-ff4072dae1ed.md). В теле метода тип объекта `этот` заменяется на [`{ИмяКомпонента}.Контекст`](../../wiki/interface/componentname-context-ru-e40a3f370a75.md). Состояние этого объекта передается с клиента на сервер при каждом вызове метода. На сервере в теле метода вы можете изменить состояние объекта. Измененное состояние будет автоматически передано на клиент, и компонент будет инициализирован заново с учетом внесенных изменений.

Пример изменения значения контекстного свойства на сервере:

```xbsl
@НаСервере @ДоступноСКлиента
@Контекстный
метод КонтекстныйМетод()
    этот.ПолучитьТип() // Вернет "ИмяКомпонента.Контекст"
    // Задание значения контекстного свойства на сервере
    КонтекстноеСвойство = "Значение"
;
```

#### СохраняемыеДанные

`Истина` — при изменении значения этого свойства «Элемент» установит свойство `СобственнаяМодифицированность` компонента в значение `Истина`. После записи данных вы должны самостоятельно присвоить свойству `СобственнаяМодифицированность` значение `Ложь`.

#### Тип

Тип свойства.

### <Событие разработчика>

Собственное событие компонента, добавленное разработчиком. Здесь вы описываете только само событие, обработчик этого события необходимо назначить при [описании экземпляра](../../wiki/interface/system-and-interface-components-18287074edda.md) этого компонента. О вызове и назначении обработчиков собственных событий компонента можно прочитать [здесь](../../wiki/interface/component-example-077c0c8b7fb0.md). Каждое событие описывается следующими свойствами:

- Имя
  
  — имя события.
- Тип
  
  — тип объекта события:
  
  - тип должен быть наследником типа
    
    `СобытиеКомпонента`
    
    ;
  - если значение не указано, то тип события —
    
    `СобытиеКомпонента`
    
    .

## События

### ПриИзменении

«Элемент» вызывает это событие после установки нового значения в свойство [Значение](../../wiki/interface/date-time-choice-component-6b891eec73f9.md).

Пример YAML-файла:

```yaml
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: ВПодсистеме
Ид: a75d7a04-99ee-4432-ad3e-5bbdae5d3b51
Имя: МойВыборДатыВремени
Наследует:
    Тип: ВыборДатыВремени
    ПриИзменении: ОбработчикПриИзменении
```

Сигнатура обработчика события:

```xbsl
метод ОбработчикПриИзменении(Источник: ВыборДатыВремени, 
                            Событие: СобытиеПриИзменении<Объект>)
    // Обработка события...
;
```

### ПослеСоздания

Переопределяемый обработчик. Предназначен для дополнительной инициализации свойств экземпляра компонента на клиенте и вызова прикладной логики инициализации экземпляра компонента. Выполняется после полного конструирования экземпляра компонента, т. е. когда:

- установлены значения свойств экземпляра компонента, указанные при
  
  [описании экземпляра](../../wiki/interface/system-and-interface-components-18287074edda.md)
  
  ;
- созданы свои компоненты данного экземпляра;
- значения свойств своих компонентов установлены из описаний их экземпляров;
- подключены обработчики событий в экземпляре компонента и в экземплярах его внутренних компонентов.

Сигнатура обработчика:

```xbsl
@Обработчик
метод ПослеСоздания()
// Обработка события...
;
```

### ПриНаведении

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

Когда указатель мыши покидает область компонента, вызывается событие **ПриПотереНаведения**.

### ПриПеретаскивании

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство `СобытиеПриПеретаскивании.СтандартнаяОбработка` не равно `Ложь`, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от `КлиентскоеПриложение`. На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

### ПриПотереНаведения

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.

При наведении указателя мыши на область компонента вызывается событие **ПриНаведении**.
