## Методы

### ВычислитьРазрешенияДоступа

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на вид документа целиком.

---

### ВычислитьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступаДляОбъектов(Элементы: ЧитаемыйМассив<ИмяДокумента.ДанныеРасчетаРазрешений>): ЧитаемоеСоответствие<ИмяДокумента.ДанныеРасчетаРазрешений,ЧитаемаяКоллекция<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на отдельные экземпляры документа.

Принимает данные для расчета разрешений доступа объектов, для которых нужно вычислить права, и возвращает соответствие данных для расчета разрешений доступа объектов и установленных для них разрешений.

Используется только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение `РазрешенияВычисляютсяДляКаждогоОбъекта`

---

### НайтиПоНомеру

`Версия 10.0 и выше`

`Доступность: Сервер`

```
НайтиПоНомеру(Номер: <ТипНомера>): <{ИмяДокумента}>
```

Метод поиска документов по номеру. Тип параметра зависит от типа номера, определенного для объекта.

Метод НайтиПоНомеру выполняет только однозначный поиск ссылки. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности.

#### Исключения

**[ИсключениеПоискаСущности](../../wiki/data/entitysearchexception-ru-ae3d905c5b5f.md)** - результат поиска неоднозначен. Найдено несколько ссылок с таким номером.

---

### НайтиПоНомеру

`Версия 10.0 и выше`

`Доступность: Сервер`

```
НайтиПоНомеру(
  Номер: <ТипНомера>,
  Period: Date = '00010101'
): <{ИмяДокумента}>
```

Метод поиска документов по номеру. Тип параметра зависит от типа номера, определенного для объекта.

Необязательный параметр "Период" присутствует только у документов, имеющих периодическую нумерацию. Если параметр указан, выполняется поиск только в периоде, включающем в себя эту дату. Если параметр опущен - поиск выполняется во всем списке документов.

Метод НайтиПоНомеру выполняет только однозначный поиск ссылки. Если по указанным условиям поиска будет найдено несколько записей, метод выдает исключение ИсключениеПоискаСущности.

#### Исключения

**[ИсключениеПоискаСущности](../../wiki/data/entitysearchexception-ru-ae3d905c5b5f.md)** - результат поиска неоднозначен. Найдено несколько ссылок с таким кодом.

#### Примеры

```xbsl
// Поиск по номеру в пределах текущего года для документа с нумерацией в пределах года
метод НайтиЗаказ()
    знч Договор = ЗаказКлиента.НайтиПоНомеру("МА-18347/2023", Дата.Сейчас())
;
```

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<{ИмяДокумента}.Ссылка>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

Пересчитывает разрешения доступа на отдельные экземпляры документов, выраженные ссылками.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ПересчитатьРазрешенияДоступаДляОбъектов(Объекты: Обходимое<ИмяДокумента.ДанныеРасчетаРазрешений>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Пересчитывает разрешения доступа по списку данных для расчета разрешений. Разрешения пересчитаются у всех объектов, данные для расчета разрешений которых совпадают с одними из переданных в метод.

---

### ПересчитатьРазрешенияДоступаДляОбъектов

`Версия 10.0 и выше`

```
ПересчитатьРазрешенияДоступаДляОбъектов(
  <Параметр1>: <ТипПараметра1>,
  ....<ПараметрN>: <ТипПараметраN>)
```

Метод доступен только если включено управление доступом для отдельных объектов в элементе проекта, то есть для какого-то права указано значение

`РазрешенияВычисляютсяДляКаждогоОбъекта`

.

Вызов возможен только с именованными параметрами.

Пересчитывает разрешения доступа на отдельные объекты, значения реквизитов которых совпадают со значениями параметров, переданных в метод. В качестве параметров в метод могут быть переданы любые реквизиты, указанные в настройке `РасчетРазрешенийПо` элемента проекта.

### СоздатьНаОсновании

`Версия 10.0 и выше`

```
СоздатьНаОсновании(Основание: <Типыисточниковсозданиянаосновании>): <{ИмяДокумента}>
```

Метод создания нового объекта на основании другого.

Параметр `Основание` служит для указания основания при создании объекта. Значение этого параметра передастся в обработчик события `ПриСозданииНаОсновании`.

#### Примеры

Ввод накладной на основании ранее выписанного счета на оплату.

У документа "Накладные" свойство `СозданиеНаОсновании` заполнено следующим образом:

```yaml
СозданиеНаОсновании: [СчетНаОплату.Ссылка, ЗаказКлиента.Ссылка]
```

Для создания на основании можно использовать следующий код:

```xbsl
@НаСервере
метод СоздатьНакладную(Основание: ЗаказКлиента.Ссылка): Накладная.Ссылка
    знч НоваяНакладная = Накладная.СоздатьНаОсновании(Основание)
    НоваяНакладная.Записать()

    возврат НоваяНакладная.Ссылка
;
```

### СоздатьФормуОбъекта

`Версия 10.0 и выше`

`Доступность: Клиент`

```
@ИменованныеПараметры
СоздатьФормуОбъекта(Ключ: <{ИмяДокумента}>): ФормаОбъекта
```

>

Вызов возможен только с именованными параметрами

Создает форму объекта документа. Если документу назначена форма объекта, то будет создана форма ровно этого типа. Иначе будет создана автоматическая форма типа [ИмяДокумента.АвтоматическаяФормаОбъекта](../../wiki/data/documentname-automaticobjectform-ru-babf844e5502.md)

Параметр `Ключ` определяет, какой объект будет редактироваться в форме. Если в качестве значения ключа передано [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md), то будет открыта форма нового объекта.

**Перегрузка** [СоздатьФормуОбъекта(Ключ: ИмяДокумента.Ссылка? = Неопределено): ФормаОбъекта<ИмяДокумента.Объект, неизвестно>](../../wiki/data/documentname-ru-a385526b4a75.md)

## Обработчики

### ПолучитьЗначенияВыбора

`Версия 10.0 и выше`

```
ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Событие вызываемое при попытке получить данные для выбора по введенной подстроке. В событие передается информация о набранной строке, и параметрах фильтра. Событие должно возвратить массив выбранных данных, или Неопределено если требуется выполнить стандартную обработку события.

#### Примеры

Отфильтровать возможные значения статуса сделки для выбранного бизнес-проекта

```xbsl
@Обработчик
метод ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемаяКоллекция<ЭлементСпискаВыбора>?
       
    знч Фильтр = Параметры.Фильтр
    
    пер ЕстьПроект = Ложь
    пер ЗначениеФильтраПроект: Объект? = Неопределено
    
    для Элемент из Фильтр.Элементы
        знч ЭлементФильтра = Элемент как ЭлементФильтра
        
        если ЭлементФильтра.Поле == "Проект"
            ЕстьПроект = Истина
            ЗначениеФильтраПроект = ЭлементФильтра.Значение
            прервать
        ;
    ;
    
    если ЕстьПроект
        возврат Проекты.ПолучитьВозможныеСтатусыСделок(ЗначениеФильтраПроект)
    ;
    
    возврат Неопределено
;
```

### ВычислитьВнешнююНавигационнуюСсылку

`Версия 10.0 и выше`

```
ВычислитьВнешнююНавигационнуюСсылку(Ссылка: <{ИмяДокумента}>): ВнешняяНавигационнаяСсылка?
```

Обработчик, который вычисляет навигационную ссылку внешней системы.

Параметры:

- `Ссылка`
  
  - ссылка на документ, для которой нужно вычислить внешнюю навигационную ссылку.

Обработчик используется в контекстных обсуждениях системы взаимодействия.

---


Обработчик, который вычисляет ссылку на документ по внешней навигационной ссылке.

Параметры:
