`Стд::Аннотации::Проект::НастройкаПриложения` `Доступность: КлиентИСервер`

`Места применения:` Статический метод, Метод

Используется для пометки методов, выполняющих логику первоначальной настройки приложения. Параметры аннотации - идентификатор обновления и порядковый номер выполнения.

Проверяется уникальность идентификатора и номера в рамках приложения. Разрешается использовать только в модуле проекта. Разрешается использовать только на методах без параметров или с единственным параметром типа [Версия](../../wiki/stdlib/version-ru-29e92504e99e.md)

```xbsl
@НастройкаПриложения(Ид = "СозданияБота", Номер = 5)
```

## Параметры

### ВызватьПриОбновлении

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ВызватьПриОбновлении
```

Вызывать ли обработчик при следующем обновлении приложения (однократно):

- Истина - обработчик будет однократно вызван при следующем обновлении приложения (под "однократно" подразумевается, что при обновлениях приложения после следующего обработчик вызываться не будет).
- Ложь - обработчик не будет вызван при обновлениях приложения.

---

### Ид

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Ид
```

Уникальный идентификатор обновления.

Идентификатор не может повторяться с идентификаторами, используемыми в аннотации [ОбновлениеПроекта](../../wiki/stdlib/projectupdate-ru-af3dc1103215.md)

---

### Номер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Номер
```

Порядковый номер обновления.
