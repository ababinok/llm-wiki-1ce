В данной статье рассматривается создание отчета для отображения актуальных остатков товаров на складах. Пользователь может выбрать дату, на которую требуется показать данные.

Отчет строится на основе регистра накопления **ОстаткиНоменклатуры**, созданного в статье [Пример проектирования регистра накопления](../../wiki/data/accumulation-register-example-08cac330ee7d.md).

> [!NOTE] примечание
> Полный код данного примера доступен на сайте [Практические примеры разработки на «1С:Предприятие.Элементе»](https://hub.1cmycloud.com/?state=examples/balance-accumulation-register).

## Добавление отчета к проекту

1. Добавьте к проекту новый элемент вида **Отчет**. Введите имя отчета — **ОстаткиТоваров**.
  
  В окне добавления элемента проекта выбран «Отчёт» для создания отчёта «ОстаткиТоваров». [Описание иллюстрации](../figures/de8eda6c70e4f2b75593351ec2d038dfc6b8d0122a790113fe3bc5e8f6ec230a-fb7b0cfc2090d032.md)
2. Для свойства **ВидИсточникаДанных** выберите значение **Запрос**. Свойство **ИсточникДанных** оставьте пустым.
  
  В свойствах отчёта «ОстаткиТоваров» для ВидИсточникаДанных выбрано «Запрос», ИсточникДанных оставлен пустым. [Описание иллюстрации](../figures/ff79c432f0a66c65479261afc78fface49fcee190f73a45e064d394b98f9a7f6-fea4c0f044be017c.md)
3. «1С:Предприятие.Элемент» сгенерирует пустой файл **ОстаткиТоваров.xbql**. Откройте данный файл и добавьте в него запрос к [виртуальной таблице остатков](../../wiki/queries/accumulationregistername-balance-ru-cdd8ad42e449.md).
  
  ```xbql
  ВЫБРАТЬ
      ОстаткиНоменклатурыОстатки.Номенклатура КАК Номенклатура,
      ОстаткиНоменклатурыОстатки.Склад КАК Склад,
      ОстаткиНоменклатурыОстатки.КоличествоОстаток КАК КоличествоОстаток,
      ОстаткиНоменклатурыОстатки.СуммаОстаток КАК СуммаОстаток
  ИЗ
      ОстаткиНоменклатуры.Остатки(&ДатаОтчета) КАК ОстаткиНоменклатурыОстатки
  ```
4. Так как запрос содержит параметр **ДатаОтчета**, для него необходимо создать соответствующий параметр отчета. Для этого в навигаторе проекта разверните структуру отчета и в разделе **Параметры запроса** создайте новый параметр со следующими свойствами:
  
  - Имя
    
    — ДатаОтчета;
  - Тип
    
    —
    
    `ДатаВремя | Неопределено`
    
    .

## Проектирование отчета

1. Перейдите в дизайнер отчета. Добавьте к отчету поле **Номенклатура**. Для этого щелкните по полю в панели слева, и оно отобразится на панели отчета справа.
2. Аналогичным образом добавьте к отчету поле **Склад**. Нажмите на имя поля в панели состава отчета и выберите пункт **Колонки** в выпадающем меню, чтобы отобразить значения поля (названия складов) в заголовках колонок.
  
  Выбор опции «Колонки» для поля «Склад» [Описание иллюстрации](../figures/d3fabebb1c8615a3e34e50143c21507895b6b0b0821bcbe2c66787a0c0637fb4-ae5baeca5ec41e6e.md)
3. Добавьте к отчету поле **Количество остаток** как факт. Функция **СУММА** будет автоматически выбрана для агрегации факта по измерениям.
  
  Добавление поля «Количество остаток» [Описание иллюстрации](../figures/a40ea2954255b4f38982a3a27eb82015c550c550d21870afc8379307418fb89c-a9dca812183b83a9.md)
4. Переименуйте поле. Для этого нажмите на имя поля в панели состава отчета и выберите пункт **Редактировать** в выпадающем меню.
  
  Редактирование поля «Количество остаток» [Описание иллюстрации](../figures/cfe57385bf9b714a2f57776f94240b71e20c87071c06577b6e619e8ef2d2b19b-9b8a4326f7dcb0aa.md)
5. Нажмите на стрелку рядом с заголовком **Без названия** и выберите **Переименовать**. Введите новое имя поля — **Количество**.
  
  В редакторе поля отчёта меню возле заголовка «Без названия» содержит «Переименовать»; поле «Количество остаток» переименовывается в «Количество». [Описание иллюстрации](../figures/da123d2578f5146746ebebe180939c6c0e519adae8a3950ab9e029cb965100f7-b1c957729e1fbaf8.md)
6. Добавьте к отчету поле **Сумма остаток** как факт. Для агрегации факта по измерениям будет также выбрана функция **СУММА**.
  
  
7. Повторите шаги 4 и 5, чтобы переименовать добавленное поле. Укажите имя **Сумма**.
  
  В редакторе поля отчёта заголовок переименован в «Сумма»; выражение вычисляет сумму остатков. [Описание иллюстрации](../figures/e8139a0d399050d3f61ef4f5c5159d8ce08e46bc508a45062f226d35a5fc5804-c8a071215e5a7089.md)
8. Добавьте отображение итоговых значений. Для этого в панели состава отчета нажмите на поле **Склад** и выберите пункт **Итого** в выпадающем меню.
  
  Включение отображения итогов [Описание иллюстрации](../figures/9b3a6bdee5a0de8b47d6ee9f3f7b1c9dc36e414135fc7b843564db49fbe9dc7d-52f178bd74be2b85.md)
9. По умолчанию колонка с итоговыми значениями отображается в начале отчета. Вы можете изменить ее положение, включив переключатель **Отображать итоги в конце** в дизайнере отчета.
  
  

В результате макет отчета будет выглядеть следующим образом:

Макет отчета «Остатки товаров на складах»: строки — номенклатура, группы столбцов — склады; внутри каждого склада выводятся «Количество» и «Сумма». [Описание иллюстрации](../figures/5d0f37a78a4bfe2d801f5b10313bf448d085cdedece3b15b6baf43b72f05c48c-34de8e39a3d2e6d3.md)

## Добавление компонента выбора даты для параметра отчета

Добавьте в отчет поле для выбора даты, на которую требуется показать данные:

1. Создайте форму отчета с именем **ОстаткиТоваровФормаОтчета**.
  
  В дереве проекта выбран отчёт ОстаткиТоваров. При добавлении дочернего элемента открыта группа «Для "ОстаткиТоваров"»; доступны Параметр и ФормаОтчета, выбирается ФормаОтчета. В соседнем шаге имя новой формы задано как ОстаткиТоваровФормаОтчета. [Описание иллюстрации](../figures/c5457c42e882ead9bdabdac4823d29f09ffdf542b3c68c7be180797ca6d729cf-225a33608eba769d.md)
2. Добавьте к форме компонент [ПолеВвода](../../wiki/interface/edit-component-a54ad83ade7f.md) с именем **ДатаОтчета**. В качестве типа поля ввода укажите [`ДатаВремя`](../../wiki/language/datetime-157ea1c55e4f.md). В свойстве **Значение** настройте привязку к значениям параметра отчета.
  
  Макет формы отчета [Описание иллюстрации](../figures/9afa1de8bcd65adf3700838965f3d5d77dbbc94454e376fbd5b12e22161217fc-066af1c85759d618.md)
  
  <details>
  <summary>Пример YAML-файла формы отчета</summary>
  
  ```yaml
  ВидЭлемента: КомпонентИнтерфейса
  Ид: 490c6485-09fb-4397-a385-69a57979a349
  Имя: ОстаткиТоваровФормаОтчета
  ОбластьВидимости: ВПодсистеме
  Наследует:

      ВключатьВАвтоИнтерфейс: Ложь

                      Тип: ПолеВвода<ДатаВремя>

  ```
  
  </details>

## Добавление отчета в интерфейс приложения

Добавьте в ваше приложение стандартную команду для открытия отчета: `ОстаткиТоваров.Открыть`.

В данном примере команда добавляется в командный интерфейс панели навигации компонента **Приложение**, унаследованного от [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standard-client-application-with-sections-component-49da52beb720.md):

Команда открытия отчета [Описание иллюстрации](../figures/d35a33ee9e3b2d418604f4f42af14fbe7435713052121e78233bababe49da3a6-dc95f22fe00c0cf4.md)

[Запустите приложение](../../wiki/project/open-or-restart-application-2d42f8a2392d.md) и откройте созданный отчет.

Отчёт «Остатки товаров на складах»: сверху дата отчёта и команды, в таблице строки номенклатуры, колонки складов с количеством и суммой, итоговые колонки справа. [Описание иллюстрации](../figures/550cc680f429f605498b0a97c84b6c00633058efd218ed3af901ffdbdbf84773-a3dd3345dfbf7e61.md)
