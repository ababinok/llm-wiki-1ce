## Свойства

### ПерекрыватьСоседниеЯчейки

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ПерекрыватьСоседниеЯчейки
```

Не помещающийся по ширине текст будет перекрывать соседние ячейки по горизонтали, если в них нет текста. Если соседние ячейки заполнены, то текст будет обрезан.

---

### ЗаменятьНаМаркер

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
ЗаменятьНаМаркер
```

Видимая часть текста будет ограничена левой и правой границами ячейки. Если текст не помещается полностью, то все символы видимой части будут отображаться как символ "#".

---

### Переносить

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Переносить
```

Не помещающийся по ширине текст будет переноситься на следующие строки ячейки.

---

### Обрезать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Обрезать
```

Видимая часть текста будет ограничена левой и правой границами ячейки.
