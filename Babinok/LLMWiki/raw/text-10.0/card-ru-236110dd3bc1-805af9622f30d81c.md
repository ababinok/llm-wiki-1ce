`Стд::Интерфейс::ОбщиеКомпоненты::Карточка` `Доступность: Клиент`

Базовый абстрактный компонент карточки. Предназначен в основном для вывода списков, где каждый элемент должен быть представлен как карточка (мини-форма).

## Свойства

### Групповая

`Доступность: Клиент`

```
Групповая: Авто|Булево
```

Если свойство равно `Истина`, то карточка отображается в виде группы карточек. Влияет только на внешний вид.

---

### ОбрабатыватьНажатие

`Доступность: Клиент`

```
ОбрабатыватьНажатие: Авто|Булево
```

Определяет - является ли карточка нажимаемой: Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) - разыменуется в `Истина`, если задан обработчик события [ПриНажатии](../../wiki/interface/card-ru-236110dd3bc1.md) Если `Истина`:

- Компонент принимает внешний вид нажимаемой кнопки.
- Обрабатывает нажатие (позволяет вызывать событие
  
  [ПриНажатии](../../wiki/interface/card-ru-236110dd3bc1.md)
  
  ), может принимать фокус. Если
  
  `Ложь`
  
  :
- Обычная карточка.
- Не обрабатывает нажатие, не принимает фокус.

---

### ОценкаИнформации

`Доступность: Клиент`

```
ОценкаИнформации: Авто|ОценкаИнформации
```

Оценка информации карточки

---

## События

### ПриНажатии

`Доступность: Клиент`

```
ПриНажатии: (
  Карточка,
  СобытиеПриНажатии)->ничто
```

Вызывается при нажатии на карточку, если свойство [ОбрабатыватьНажатие](../../wiki/interface/card-ru-236110dd3bc1.md) установлено.
