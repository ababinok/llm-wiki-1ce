Таблица регистрации изменений создается, только если хранилище настроек включено в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению элемента хранилища настроек, входящего в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице хранилища настроек. Одна запись таблицы — изменения в одном элементе хранилища настроек, зарегистрированные для одного узла.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел** и **Ссылка** из таблицы регистрации изменений хранилища настроек **МоеХранилищеНастроек.Изменения**:

```xbql
ВЫБРАТЬ
    МоеХранилищеНастроек.Узел КАК Узел,
    МоеХранилищеНастроек.Ссылка КАК Ссылка
ИЗ
    МоеХранилищеНастроек.Изменения КАК МоеХранилищеНастроек
```

---

## Поля

### Ссылка

`Ключевое поле`

```
Ссылка: ИмяХранилищаНастроек.Ссылка
```

Ссылка на элемент хранилища настроек, в котором были зарегистрированы изменения.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Если изменение не включено в сообщение, то значение `Неопределено`.
