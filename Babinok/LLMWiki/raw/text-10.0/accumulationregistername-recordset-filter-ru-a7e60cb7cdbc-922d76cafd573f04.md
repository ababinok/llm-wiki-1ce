`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраНакопления}.НаборЗаписей.Фильтр` `Доступность: Сервер`

Объект предназначен для задания значений полей, по которым отбираются записи попадающие в набор записей. Является составной частью объектов типа [ИмяРегистраНакопления.НаборЗаписей](../../wiki/data/accumulationregistername-recordset-ru-b4bf21480f3e.md) (см. свойство `Фильтр`). Содержит единственный элемент фильтра [Сущность.НаборЗаписей.Фильтр.Элемент](../../wiki/data/entity-recordset-filter-item-ru-881dec7d18c2.md) для стандартного поля `Регистратор`.

## Примеры

**Общие примеры**

```xbsl
метод ОчиститьПоРегистратору(Регистратор: ЗаказКлиента.Ссылка)
    пер НаборЗаписей = новый ЗаказыКлиентов.НаборЗаписей()
    НаборЗаписей.Фильтр.Установить(Регистратор = Регистратор) 
    НаборЗаписей.Записать()
;
```

## Свойства

### КлючОсновногоФильтра

`Доступность: Сервер` `ТолькоЧтение`

```
КлючОсновногоФильтра: {ИмяРегистраНакопления}.КлючОсновногоФильтра
```

Структура содержащая единственное свойство `Регистратор`. Используется для регистрации изменений механизмом обмена данными.

Переопределение: [КлючОсновногоФильтра](../../wiki/data/accumulationregistername-recordset-filter-ru-a7e60cb7cdbc.md)

---

### Регистратор

`Доступность: Сервер` `ТолькоЧтение`

```
Регистратор: Сущность.НаборЗаписей.Фильтр.Элемент<{ИмяДокумента}.Ссылка?>
```

Элемент фильтра соответствующий стандартному полю `Регистратор`, содержащий ссылку на документ-регистратор по которому выполняется отбор записей.

## Методы

### Установить

`Версия 10.0 и выше`

`Доступность: Сервер`

```
Установить(Регистратор: ТипРегистратора)
```

Устанавливает указанное значение документа-регистратора в фильтр.
