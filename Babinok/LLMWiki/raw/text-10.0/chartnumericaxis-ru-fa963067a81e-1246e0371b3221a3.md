Описывает модель числовой оси для XY-диаграмм.

Ссылочное

---

## Конструкторы

### ЧисловаяОсьДиаграммы

`Доступность: КлиентИСервер`

```
ЧисловаяОсьДиаграммы()
```

Создает компонент числовой оси.

---

## Свойства

### Максимум

`Доступность: КлиентИСервер`

```
Максимум: Авто|Число
```

Максимальное значение числовой оси.

---

### Минимум

`Доступность: КлиентИСервер`

```
Минимум: Авто|Число
```

Минимальное значение числовой оси.

---

### Целочисленная

`Доступность: КлиентИСервер`

```
Целочисленная: Авто|Булево
```

Флаг отображения только целочисленных подписей. Если `Истина`, подписи дробных чисел на оси отображаться не будут.
