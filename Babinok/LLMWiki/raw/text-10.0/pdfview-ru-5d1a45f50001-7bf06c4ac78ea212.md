## Свойства

### Данные

`Доступность: Клиент`

```
Данные: ДвоичныйОбъект.Ссылка?
```

Ссылка на двоичные данные просматриваемого pdf-документа. Если `Неопределено`, то документ не отображается.

---

### ИмяФайла

`Доступность: Клиент`

```
ИмяФайла: Авто|Строка
```

Имя скачиваемого документа при нажатии на иконку загрузки файла
