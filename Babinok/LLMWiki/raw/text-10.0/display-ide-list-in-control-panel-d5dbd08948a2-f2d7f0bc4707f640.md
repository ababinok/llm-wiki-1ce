Открыть список сред разработки внутри конкретного пространства можно со страницы этого пространства (вкладка **Администрирование и пространства** ⟶ **«НужноеПространство»** ⟶ **Разработка**). Однако вы также можете открыть сквозной список сред разработки по всем пространствам. Для этого:

1. [Откройте](https://1cmycloud.com/console/help/element/10.0/docs/topics/open-control-panel/) панель управления.
2. Наведите курсор на вкладку **Разработка** и в выпадающем списке выберите **Среды разработки**:
  
  В панели управления раскрыто меню «Разработка» и выбран пункт «Среды разработки». [Описание иллюстрации](../figures/46df88be28ac067e802e6f222fe35e6f028c076abdd746cc7df752fdf2a4bd1f-8cbf083aa4b5469a.md)

У вас откроется сквозной список сред разработки по всем пространствам. Чтобы их отфильтровать, в правой верхней части экрана кликните на **Фильтры**, введите необходимые условия и нажмите **Применить**:

В списке сред разработки раскрыта панель «Фильтры»: поля условий по состоянию, задачам, приложению, пользователю и времени; выбранные условия применяются кнопкой «Применить». [Описание иллюстрации](../figures/f8146c92b45580dc6de891b96422f60dd63f9206142555853a336c37cc7be5a8-d160c59090e11278.md)

Чтобы задать настройки администрирования сред разработки, в правой верхней части экрана нажмите **Настройки**:

Переход к настройкам администрирования [Описание иллюстрации](../figures/95a055b3861c0be07c7288234b3bb3ac07fe78531b26a7593f56b61b575eb3b5-1e7fc0a9ab230db9.md)

Откроется окно настроек администрирования сред разработки. Задайте необходимые параметры (или оставьте уже установленные по умолчанию, где есть) и нажмите **Сохранить**:

Окно администрирования сред разработки содержит поля параметров подключения и числовых ограничений, внизу кнопку «Сохранить» для применения настроек. [Описание иллюстрации](../figures/f8612054f4352b87bf3e64e0425ff97673b264b6b957f26c2f3ee8014b710722-f4600f824565a463.md)

Чтобы вернуть значения по умолчанию, выберите **Вернуть значения по умолчанию**.
