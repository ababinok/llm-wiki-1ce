Центральным и главным компонентом системы является сервер. На нем хранятся проекты приложений в виде одной или нескольких своих версий.

Сервер исполняет приложения, которые реализуют всю прикладную функциональность. Приложение состоит из:

- версии проекта;
- [СУБД](https://1cmycloud.com/console/help/element/10.0/docs/topics/database-management-system/)
  
  , в которой приложение хранит пользовательские данные;
- [хранилища двоичных данных](https://1cmycloud.com/console/help/element/10.0/docs/topics/binary-data-storage/)
  
  , в котором приложение хранит файлы документов, изображения, видео или другие ресурсы.

Как правило пользователи находятся во внешней сети и подключаются к серверу через Интернет. Чтобы такое подключение было безопасным, рекомендуется использовать [обратный прокси-сервер](https://1cmycloud.com/console/help/element/10.0/docs/topics/reverse-proxy-server/), который транслирует запросы пользователей серверу и наоборот. Для подключения нужно использовать протокол безопасной передачи данных HTTPS.

Пользователи взаимодействуют с приложениями с помощью веб-клиента (на настольных компьютерах) или мобильного клиента (на мобильных устройствах).

Администраторы используют [панель управления](https://1cmycloud.com/console/help/element/10.0/docs/topics/control-panel/). С ее помощью они настраивают и обслуживают сервер, создают и обслуживают приложения, загружают проекты, управляют пользователями.

Разработчики используют среду разработки. С ее помощью они создают, изменяют и отлаживают проекты, которые хранятся на сервере. Для [групповой разработки](../../wiki/project/connect-to-gitlab-daf8c8c732dc.md) можно использовать систему управления репозиториями GitLab. Кроме того, можно использовать систему контроля версий Git, но в этом случае будут доступны только основные функции групповой разработки.
