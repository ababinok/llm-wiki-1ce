## Конструкторы

### ИнтервалДиаграммыГанта

`Доступность: КлиентИСервер`

```
ИнтервалДиаграммыГанта(
  Ид: Ууид,
  Наименование: Строка,
  Цвет: Авто|Цвет,
  Данные: ТипДанныхИнтервала?,
  Диапазон: ЗакрытыйДиапазон<Момент>?,
  Зависимости: Массив<Ууид>)
```

## Свойства

### Данные

`Доступность: КлиентИСервер`

```
Данные: ТипДанныхИнтервала?
```

Произвольные данные, связанные с интервалом. Не используются при отображении, но могут использоваться при обработке событий.

---

### Диапазон

`Доступность: КлиентИСервер`

```
Диапазон: ЗакрытыйДиапазон<Момент>?
```

---

### Зависимости

`Доступность: КлиентИСервер`

```
Зависимости: Массив<Ууид>
```

Массив идентификаторов зависимостей интервала. От каждой зависимости будет отображена стрелка к зависимому элементу.

---

`Доступность: КлиентИСервер`

```
Ид: Ууид
```

Идентификатор элемента. Используется для указания зависимостей между элементами.
