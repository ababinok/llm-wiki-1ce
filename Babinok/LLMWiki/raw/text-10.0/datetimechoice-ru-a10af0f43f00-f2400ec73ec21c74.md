Компонент ввода даты и времени. Содержит календарь и/или элемент выбора времени.

date-time-picker [Описание иллюстрации](../figures/a17cf80aeb4227f68e707fc49beac7be0a28f126a3e9c412963c15232de8c784-cf1cdba72f3c2b0b.md)

---

## Свойства

### Стандартные

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### Значение

```yaml
Значение: ВычисляемоеВыражение|Дата|ДатаВремя|Момент|Время|ЗакрытыйДиапазон<Дата>|ЗакрытыйДиапазон<ДатаВремя>|ЗакрытыйДиапазон<Момент>|ЗакрытыйДиапазон<Время>|?
```

Отображаемое и редактируемое значение. Может принимать значение одного из следующих типов: `Неопределено`, `Момент`, `Дата`, `ДатаВремя`, `Время`, `ЗакрытыйДиапазон<Дата>`, `ЗакрытыйДиапазон<Время>`, `ЗакрытыйДиапазон<ДатаВремя>`, `ЗакрытыйДиапазон<Момент>`. Свойство требует двунаправленной связи с данными.

---

#### ТипРедактирования

```yaml
ТипРедактирования: ВычисляемоеВыражение|Авто|Тип<Дата|ДатаВремя|Момент|Время|ЗакрытыйДиапазон<Дата>|ЗакрытыйДиапазон<ДатаВремя>|ЗакрытыйДиапазон<Момент>|ЗакрытыйДиапазон<Время>>
```

Тип редактируемого значения. Внешний вид компонента зависит от типа редактируемого значения.

Если тип редактируемого значения — `ДатаВремя`, то в компоненте будут показаны элементы выбора даты и времени.

date-time-picker [Описание иллюстрации](../figures/a17cf80aeb4227f68e707fc49beac7be0a28f126a3e9c412963c15232de8c784-cf1cdba72f3c2b0b.md)

Если тип редактируемого значения — `Дата`, то в компоненте будут показан только элемент выбора даты.

date-picker [Описание иллюстрации](../figures/90a2bfb090b6cff7b67e7a189ef21e7340a439f08eaa3e8fddea9f6e626c3425-eb1408bd2f249a81.md)

Если тип редактируемого значения — `Время`, то в компоненте будут показан только элемент выбора времени.

time-picker [Описание иллюстрации](../figures/d1fde4b82cd0a8903476f7925009cf940d27f8d0e8d45ecfee12cf995757a040-d06adc193c1a4754.md)

Если тип редактируемого значения — `ЗакрытыйДиапазон<Дата>`, то в компоненте будет возможность выбора периода дат.

date-period-picker [Описание иллюстрации](../figures/ada77544efd41a77274d93acbf20731d4b6de130e63a43d1f9fc32d68fbc4d2e-94f3ce902919984e.md)

Если тип редактируемого значения — `ЗакрытыйДиапазон<Время>`, то в компоненте будут показаны два элемента выбора времени — для начала и конца интервала.

time-period-picker [Описание иллюстрации](../figures/8caa5fe6266aa31c09a7c0c9d3bc1129e7b83da4eb1f75e2f368449e83621909-15ee409556f4b261.md)

#### ССекундами

```yaml
ССекундами: ВычисляемоеВыражение|Авто|Булево
```

Включает элемент ввода секунд при вводе времени.

---

#### ВесПриРастягивании

```yaml
ВесПриРастягивании: ВычисляемоеВыражение|Авто|Число
```

Значимость данного компонента по сравнению с другими растягиваемыми компонентами. Например, если у данного компонента [ВесПриРастягивании](../../wiki/interface/datetimechoice-ru-a10af0f43f00.md) = 1, а у другого [ВесПриРастягивании](../../wiki/interface/datetimechoice-ru-a10af0f43f00.md) = 2, то другой компонент будет в 2 раза больше данного ([подробнее](../../wiki/interface/arrange-components-on-screen-ebea0719d919.md)).

---

#### Видимость

```yaml
Видимость: ВычисляемоеВыражение|Авто|Булево
```

Показать или скрыть компонент. Фактическая видимость компонента зависит от видимости его родительских компонентов.

#### ВыравниваниеВГруппеПоВертикали

```yaml
ВыравниваниеВГруппеПоВертикали: ВычисляемоеВыражение|Авто|ВыравниваниеПоВертикали
```

Способ вертикального выравнивания этого компонента внутри родительской группы:

- Авто
  
  — значение
  
  [ПоБазовойЛинии](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  ;
- элементы перечисления
  
  [ВыравниваниеПоВертикали](../../wiki/interface/verticalalign-ru-79ebde0886d6.md)
  
  —
  
  Верх
  
  ,
  
  Центр
  
  ,
  
  Низ
  
  ,
  
  ПоБазовойЛинии
  
  .

Позволяет управлять индивидуальным положением этого компонента в группе, если размер группы больше размера, требуемого всем ее компонентам. Например, если «Элемент» растягивает группу, а компоненты в ней не растягивает.

Для компонента, расположенного внутри вертикальной группы, это свойство имеет смысл только в том случае, если этот компонент крайний. Например, если компоненты группы расположены вверху, то последний компонент можно расположить внизу.

Пример вертикального выравнивания: первые два компонента расположены у верхнего края вертикальной группы, последний — у нижнего. [Описание иллюстрации](../figures/c9b6e381c8c97fa30e6432d1701f80e520b7716fc134a499fc30ec1b46936b80-d1cae524ff431c82.md)

Если у компонентов внутри группы указаны разные способы вертикального положения, которые входят в конфликт друг с другом, то «Элемент» будет использовать для всех конфликтных компонентов тот способ, который указан у первого из них. Например, если у первого конфликтного компонента в группе указано положение **Низ**, а у второго — **Верх**, то оба компонента окажутся внизу.

Пример конфликта вертикального выравнивания: у второго компонента задано «Низ», у третьего — «Верх». [Описание иллюстрации](../figures/3ff4b64f82a737d0c02aeba39b29550b97f42ffe1d03d2eb5be1c50cc604b5f2-0bfb279a636f5778.md)


Состояние доступности компонента. Если компонент недоступен, то он не может принимать фокус и не позволяет редактировать данные. #### ТолькоЧтение

```yaml
ТолькоЧтение: ВычисляемоеВыражение|Авто|Булево
```

Запрет редактирования данных компонента. Если флажок установлен, то компонент может принимать фокус, его данные можно просматривать и копировать. В этом состоянии некоторые компоненты могут сохранять свою интерактивность, которая не влечет за собой изменение каких-либо данных. Состояние [ТолькоЧтение](../../wiki/interface/datetimechoice-ru-a10af0f43f00.md) распространяется на все компоненты содержимого, пока не встретится переопределение этого свойства. Имеет более низкий приоритет, чем свойство [Доступность](../../wiki/interface/datetimechoice-ru-a10af0f43f00.md).

### События

#### ПриИзменении

```yaml
ПриИзменении: Строка
```

Вызывается после установки нового значения в свойство [Значение](../../wiki/interface/datetimechoice-ru-a10af0f43f00.md).

---

#### ПриНаведении

```yaml
ПриНаведении: Строка
```

Назначаемое событие. Вызывается при наведении указателя мыши на область компонента. Особенности вызова события:

- При наведении указателя мыши на вложенные элементы событие
  
  ПриНаведении
  
  сначала вызывается для родительского элемента, а затем для дочернего.
- Событие не поддерживается на мобильных устройствах.

---

#### ПриПеретаскивании

```yaml
ПриПеретаскивании: Строка
```

Назначаемое событие. Возникает по окончании перетаскивания на область компонента. Если в обработчике события свойство [СтандартнаяОбработка](../../wiki/interface/ondropevent-ru-9660b8f6239f.md) не равно **Ложь**, то происходит системная обработка события, после чего «Элемент» вызывает событие у родительского компонента, вплоть до компонента, унаследованного от [КлиентскоеПриложение](../../wiki/interface/clientapplication-ru-b046bbeb06bc.md). На данный момент поддерживается только перетаскивание файлов из проводника на область компонента.

---

#### ПриПотереНаведения

```yaml
ПриПотереНаведения: Строка
```

Назначаемое событие. Вызывается, когда указатель мыши покидает область компонента. Особенности вызова события:

- Если событие срабатывает для вложенных элементов (курсор смещается за пределы родительского элемента), то сначала оно вызывается для дочернего элемента, а затем для родительского.
- Событие не вызывается при удалении компонента, изменении его видимости или размера (если в результате указатель мыши больше не находится над областью компонента).
- Событие не поддерживается на мобильных устройствах.
