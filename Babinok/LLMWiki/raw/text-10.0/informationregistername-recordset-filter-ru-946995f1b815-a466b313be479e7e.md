`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяРегистраСведений}.НаборЗаписей.Фильтр` `Доступность: Сервер`

Объект предназначен для задания значений ключевых полей, по которым отбираются записи, попадающие в набор записей. Является составной частью объектов типа [ИмяРегистраСведений.НаборЗаписей](../../wiki/data/informationregistername-recordset-ru-ff0cb8e8f1d1.md) (см. свойство `Фильтр`). Элементы фильтра [Сущность.НаборЗаписей.Фильтр.Элемент](../../wiki/data/entity-recordset-filter-item-ru-881dec7d18c2.md) конструируются платформой для каждого измерения регистра сведений, а также для стандартного поля `Период` (для периодических регистров).

## Свойства

### КлючОсновногоФильтра

`Доступность: Сервер` `ТолькоЧтение`

```

Содержит измерения, которые включены в основной фильтр, и период для периодического регистра сведений, если период включен в основной фильтр.

### Период

`Доступность: Сервер` `ТолькоЧтение`

```
Период: Сущность.НаборЗаписей.Фильтр.Элемент<Дата>

Элемент фильтра, соответствующий стандартному полю `Период` записи. Существует только для периодического регистра сведений.

## Методы

### Установить

`Версия 10.0 и выше`

`Доступность: Сервер`

```
@ИменованныеПараметры
Установить(
  <Поле1>: <ТипПоля1>,
  ....<ПолеN>: <ТипПоляN>)
```

>

Вызов возможен только с именованными параметрами

Все параметры необязательные. Устанавливает указанные значения в фильтр. Для полей с указанными значениями (параметр с указанным именем установлен) устанавливает переданное значение и устанавливает использование в `Истина`. Для полей с неуказанными значениями (параметр с указанным именем не установлен) устанавливает использование в `Ложь`.

Доступна только форма вызова с указанием имен параметров.
