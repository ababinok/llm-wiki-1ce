## [СтрокаДинамическогоСписка](../../wiki/interface/dynamiclistrow-ru-f0049a8b2f38.md)

`Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::СтрокаДинамическогоСписка<ТипДанныхСтроки>` `Доступность: КлиентИСервер`

ТипДанныхСтроки: тип данных строки динамического списка. По умолчанию [ПроизвольныеДанныеСтрокиДинамическогоСписка](../../wiki/interface/customdynamiclistrowdata-ru-4053fd705a34.md). Ограничения параметра типа: Стд::Интерфейс::ИсточникиДанных::ДинамическийСписок::ДанныеСтрокиДинамическогоСписка<неизвестно>.

Содержит ключ и значения полей одной записи динамического списка. Состав полей задается свойством [Поля](../../wiki/interface/dynamiclist-ru-ab61b0be4de4.md). Данный объект создается системой автоматически для каждой записи динамического списка, полученной с сервера.

---
