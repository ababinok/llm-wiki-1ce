`Версия 9.0 и выше`

Таблица регистрации изменений создается, только если набор констант включен в план обмена. Таблица содержит записи, соответствующие зарегистрированному для конкретного узла плана обмена изменению значений констант, входящих в состав плана обмена. Доступ предоставляется аналогично доступу к основной таблице набора констант.

---

## Примеры

В примере ниже показано, как выбрать записи с полями **Узел**, **НомерСообщения** и **КлючЗаписи** из таблицы регистрации изменений **ДанныеОрганизации.Изменения**:

```xbql
ВЫБРАТЬ
    ДанныеОрганизации.КлючЗаписи КАК КлючЗаписи,
    ДанныеОрганизации.НомерСообщения КАК НомерСообщения,
    ДанныеОрганизации.Узел КАК Узел
ИЗ
    ДанныеОрганизации.Изменения КАК ДанныеОрганизации
```

---

## Поля

### КлючЗаписи

`Ключевое поле`

```
КлючЗаписи: ИмяНабораКонстант.КлючЗаписи
```

Содержит ключ записи набора констант. Используется для указания на конкретную запись. Имеет тип `имя-набора-констант.КлючЗаписи`.

---

### Узел

`Ключевое поле`

```
Узел: ИмяПланаОбмена.Ссылка
```

Ссылка на узел плана обмена, для которого зарегистрированы изменения. Имеет тип `имя-плана-обмена.Ссылка`.

---

### НомерСообщения

```
НомерСообщения: Null|Число
```

Содержит номер первого сообщения, в которое включено изменение. Имеет тип `Число`. Если изменение не включено в сообщение, то значение `Неопределено`.
