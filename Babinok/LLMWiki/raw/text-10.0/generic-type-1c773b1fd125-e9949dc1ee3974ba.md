# Обобщенный тип

Обобщенный тип — это коллекция, параметризуемая типом. Этот тип определяет тип элементов коллекции.

Например, можно использовать обобщенный тип — массив, состоящий из строк: `Массив<Строка>`.

Пример:

```xbsl
// Значение типа «Массив». 
// Элементами этого массива могут быть только значения типа «Строка». 
пер МассивИзСтрок = новый Массив<Строка>() 

// Значение типа «Массив», заданное литералом.
// Элементами этого массива могут быть и числа, и строки. 
// В данный момент это числа 1 и 2. 
пер МассивИзЧиселИСтрок = <Число|Строка>[1, 2]
```
