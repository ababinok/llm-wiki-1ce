Элемент проекта вида «Обработка» — это объект конфигурации, предназначенный для обработки данных на стороне сервера. Он позволяет автоматизировать работу с данными: удалять, сохранять и создавать данные по заданному алгоритму ([подробнее](../../wiki/project/processing-project-element-acb124c72bfa.md)).

Обработка может содержать [Реквизиты](../../wiki/project/processing-3a8538244521.md) и [Операции](../../wiki/project/processing-3a8538244521.md), а также **форму обработки**, с помощью которой можно вводить параметры, влияющие на ход алгоритма обработки, и отображать результаты. Сам алгоритм обработки задается в модуле объекта обработки.

---

## Свойства

#### Имя

```yaml
Имя: Строка
```

Имя элемента.

---

#### ОбластьВидимости

```yaml
ОбластьВидимости: ОбластьВидимости
```

[Видимость](../../wiki/language/modular-development-80166cfecf93.md) элемента проекта:

- [ВПодсистеме](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден внутри одной подсистемы во всех пакетах (значение по умолчанию);
- [ВПроекте](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах одного проекта;
- [Глобально](../../wiki/project/visibilityscope-ru-d8260ddb99a7.md)
  
  — элемент виден во всех подсистемах всех проектов.

---

#### Импорт

```yaml
Импорт: ПространствоИмен[]
```

Список [импортированных пространств имен](../../wiki/language/modular-development-80166cfecf93.md).

#### КонтрольДоступа

`Версия 10.0 и выше`

```yaml
КонтрольДоступа: 
    Разрешения: 
        ПоУмолчанию: КонтрольДоступа
        Вызов: КонтрольДоступа
```

Содержит [настройки прав доступа](../../wiki/security/http-service-access-permissions-0998f45d9af8.md).

<details>
<summary>**Свойства**</summary>

##### Разрешения

Коллекция описания разрешений.

<details>
<summary>**Свойства**</summary>

##### ПоУмолчанию

Задает все разрешения элемента проекта, которые не указаны явно.

##### Вызов

Режим контроля доступа для обработки.

</details>

</details>

#### Интерфейс

```yaml
Интерфейс: 
    Представление: Строка|СсылкаНаЛокализованнуюСтроку
    ВключатьВАвтоИнтерфейс: Булево
    Изображение: ДвоичныйОбъект.Ссылка?
    Форма: Строка
```

Группа свойств, которые описывают пользовательский интерфейс обработки.

<details>
<summary>**Свойства**</summary>

##### Представление

Заголовок кнопки, соответствующей данной операции. Если не указано, то используется свойство операции **Имя**.

##### ВключатьВАвтоИнтерфейс

Признак включения формы в [автоматический интерфейс](../../wiki/interface/automatic-interface-df2ea881a675.md).

##### Изображение

Ссылка на картинку, отображаемую на кнопке.

##### Форма

Форма обработки.

</details>
