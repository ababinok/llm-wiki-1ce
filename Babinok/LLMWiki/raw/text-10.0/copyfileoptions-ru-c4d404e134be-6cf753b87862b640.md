## Конструкторы

### НастройкиКопированияФайлов

`Доступность: Сервер`

```
НастройкиКопированияФайлов()
```

Создает настройки, в которых все флаги установлены в значение

`Ложь`

. По умолчанию копирование будет произведено:

- с перезаписью файла, если файл существует,
- для символической ссылки - будет скопирована сама ссылка, а не объект, который расположен по адресу ссылки,
- без атрибутов копируемого файла,
- для всех дочерних файлов, если такие существуют.

## Методы

### КопироватьАтрибуты

`Доступность: Сервер`

```
КопироватьАтрибуты(Значение: Булево = Истина): НастройкиКопированияФайлов
```

Устанавливает признак

`Значение`

копирования атрибутов в новый файл. Возвращает текущий экземпляр.

---

### ПропускатьДочерние

`Доступность: Сервер`

```
ПропускатьДочерние(Значение: Булево = Истина): НастройкиКопированияФайлов
```

Устанавливает признак

`Значение`

пропуска дочерних файлов. Если

`Истина`

- дочерние файлы при копировании пропускаются. Возвращает текущий экземпляр.

---

### ПропускатьСуществующие

`Доступность: Сервер`

```
ПропускатьСуществующие(Значение: Булево = Истина): НастройкиКопированияФайлов
```

Устанавливает признак

`Значение`

пропуска существующего файла. Если

`Истина`

- существующие файлы не будут перезаписаны. Возвращает текущий экземпляр.

---

### СледоватьСсылкам

`Доступность: Сервер`

```
СледоватьСсылкам(Значение: Булево = Истина): НастройкиКопированияФайлов
```

Устанавливает признак

`Значение`

вычисления символических ссылок. Если

`Ложь`

, то копируется именно ссылка, а не объект, на который она ссылается. Возвращает текущий экземпляр.
