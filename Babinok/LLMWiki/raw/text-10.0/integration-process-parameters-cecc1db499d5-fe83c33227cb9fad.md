> [!WARNING] важно
> Процессы интеграции недоступны в облачной версии «1С:Предприятие.Элемента».

В среде разработки «1С:Предприятие.Элемента» у процесса интеграции можно создать один или несколько параметров. Каждый из них имеет имя. Это имя можно использовать в выражениях, использующихся для вычисления значений свойств узлов процесса интеграции. Значения параметров можно [задать в панели управления](../../wiki/integration/specify-integration-process-properties-eac1f57c7e07.md) приложением во время исполнения.

Рассмотрим процесс интеграции [«ОбменССайтом»](../../wiki/integration/esb-demo-example-1-023afe2b56d5.md), в ходе которого выполняется синхронизация изменений по товарным позициям между информационной базой «1С:Предприятие» и сайтом, т.е. при создании или изменении товара в базе, эти изменения автоматически отражаются на сайте. Схема такого процесса выглядит следующим образом:

Схема ОбменССайтом имеет цепочку сверху вниз: группа участников Офис → (пунктирная бирюзовая связь) ИзОфиса → (сплошной чёрный маршрут) HTTP-узел ОбменССайтом. [Описание иллюстрации](../figures/797c3d0c2d8c10a8fa6d79b808fdb319e7c57c62a10ae046bea2652805deb4e2-6109f66bb3a7b82e.md)

В данном примере мы создадим четыре параметра, которые впоследствии используем для вычисления свойств узла [**Http**](../../wiki/integration/http-integration-scheme-node-d9bde3031004.md) («ОбменССайтом»):

- URL

- API

Чтобы создать параметры процесса интеграции, нажмите на значок плюса напротив пункта **Параметры** процесса интеграции:

У процесса «ОбменССайтом» раскрыт раздел «Параметры»; кнопка плюса справа добавляет параметр процесса интеграции. [Описание иллюстрации](../figures/4ea52e8af9950c2f7fdc593810ef8e1a3de86eebe4027f8257a4804c47d4ce12-f5d8c7713b1afbf3.md)

Назовите параметр **URL**. Затем нажмите **Ввод**.

По аналогии создайте еще три параметра: **API**, **Login**, **Password**. Созданные параметры отобразятся слева в панели навигатора:



Кликните на узел **ОбменССайтом**. В панели **Свойства** заполните свойство **URI**. Для этого нажмите на кнопку, раскрывающую параметры процесса. В открывшемся списке выберите созданный ранее параметр **URL**:

В свойствах узла «ОбменССайтом» раскрыт выбор параметров процесса для URI и выбран параметр URL. [Описание иллюстрации](../figures/de3dc2276c9d8230c0f8cd6ee1f54f3f64e2cd04ff8af98b5a7dd5da8f233fdf-1949ced5779731ad.md)

Далее добавьте к параметру **URL** еще один параметр — **API**. Для этого повторно нажмите на кнопку, раскрывающую параметры процесса, и выберите созданный ранее параметр **API**:

В списке параметров процесса к параметру URL добавляется созданный ранее параметр API. [Описание иллюстрации](../figures/2eed20b846317e71de60a2df6b4deec773c2aa7264c5de8c0da12ea1c75ecc84-00312bd7eb2d61d9.md)

Аналогично заполните остальные параметры: имя пользователя как **Login**, пароль как **Password**:

Выбор метода [Описание иллюстрации](../figures/ab8a2d985904683e82b284977c4d8cea1779bb7ad1340db5fb76a40ca32c58d4-9921d8169b887314.md)

Теперь, после публикации проекта, в панели управления приложением, в карточке процесса интеграции, у вас будет возможность [задать значения](../../wiki/integration/specify-integration-process-properties-eac1f57c7e07.md) этих параметров. На основе этих значений будут вычислены значения свойств узла [**Http**](../../wiki/integration/http-integration-scheme-node-d9bde3031004.md).
