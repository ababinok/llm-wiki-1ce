`{ИмяРазработчика}::{ИмяПроекта}::{ИмяПодсистемы}::{ИмяОтчета}` `Доступность: КлиентИСервер`

Объект, с помощью которого можно отобразить отчет или панель отчетов.

Если отчет содержит параметры, или источником данных отчета является запрос или виртуальная таблица с параметрами, установить их значения можно в конструкторе или через специальное свойство [ИмяОтчета.Параметры](../../wiki/stdlib/reportname-parameters-ru-2d42387feb19.md).

## Примеры

**Общие примеры**

Установка значений параметров через конструктор:

```xbsl
знч Отчет = новый ОтчетПоВиртуальнойТаблице(Код = "А00001", Номер = 100)
```

Значения параметров можно получить или изменить через свойства:

```xbsl
знч Отчет = новый ОтчетПоВиртуальнойТаблице()
Отчет.Параметры.Код = "А00001"
Отчет.Параметры.Номер = 100
```

## Конструкторы

### {ИмяОтчета}

`Доступность: КлиентИСервер`

```
@ИменованныеПараметры
{ИмяОтчета}(
  <Параметр1>: <ТипПараметра1> = <ЗначениеПоУмолчаниюПараметра1>,
  ....<ПараметрN>: <ТипПараметраN> = <ЗначениеПоУмолчаниюПараметраN>)
```

Создает новый экземпляр отчета или панели отчетов.

Если отчет или его источник данных содержат параметры, они могут быть заданы через конструктор. Значения по умолчанию соответствуют значениям по умолчанию указанным в описании параметра. Виртуальные таблицы, у которых для параметра не указано значение по умолчанию, не могут быть использованы в отчетах.

Допускает только именованную форму вызова.

## Свойства

### Параметры

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Параметры: {ИмяОтчета}.Параметры
```

Свойство специального типа, которое позволяет получать и изменять значения параметров отчета.
