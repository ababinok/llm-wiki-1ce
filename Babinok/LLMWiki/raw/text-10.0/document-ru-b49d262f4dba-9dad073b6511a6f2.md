## Методы

### ПересчитатьРазрешенияДоступа

`Доступность: Сервер`

```
ПересчитатьРазрешенияДоступа()
```

Пересчитывает разрешения доступа на весь список документов целиком.

### ПолучитьСтандартныеЗначенияВыбора

`Доступность: Сервер`

```
ПолучитьСтандартныеЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемыйМассив<ЭлементСпискаВыбора>
```

Выполняет стандартный поиск значений по подстроке, предназначен для вызова из обработчика

[ПолучитьЗначенияВыбора](../../wiki/data/documentname-ru-a385526b4a75.md)

, имеет те же самые параметры типа

[ПараметрыПолученияЗначенийВыбора](../../wiki/interface/choicevaluesgettingparameters-ru-d09cd7fb3fef.md)

.

#### Примеры

В данном примере мы не изменяем стандартную логику поиска, а только добавляем в представление почтовый адрес.

```xbsl
@Обработчик
метод ПолучитьЗначенияВыбора(Параметры: ПараметрыПолученияЗначенийВыбора): ЧитаемаяКоллекция<ЭлементСпискаВыбора>?
    знч РезультатПоиска = ПолучитьСтандартныеЗначенияВыбора(Параметры) 
	для СтрокаРезультата из РезультатПоиска
        знч АдресПочты = ПолучитьАдресПочты(СтрокаРезультата.Значение как Контрагенты.Ссылка)
        СтрокаРезультата.Представление += " " + АдресПочты
    ;
	возврат РезультатПоиска
;

метод ПолучитьАдресПочты(Значение: неизвестно) : Строка
    пер АдресПочты = ""
    //  получаем адрес почты из значения выбора и устанавливаем в переменную АдресПочты
    возврат АдресПочты
;
```
