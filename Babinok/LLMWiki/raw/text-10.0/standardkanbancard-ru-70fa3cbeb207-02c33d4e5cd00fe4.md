### Исполнитель

`Доступность: Клиент`

```
Исполнитель: ЭлементСпискаЗначений<Строка>?
```

Аватар исполнителя. Используется только одно изображение: приоритет отдается [ИзображениеНеактивного](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md). При наведении курсора мыши на элемент появляется подсказка, описанная в [Представление](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md) или, если оно не задано, то [Значение](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md).

---

`Доступность: Клиент`

```
Код: Строка
```

Код карточки

---

### Счетчики

`Доступность: Клиент`

```
Счетчики: Массив<ЭлементСпискаЗначений<Строка>>
```

Массив счетчиков (не больше трех). На карточке отображается [Представление](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md) или, если оно не задано, то [Значение](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md). При наведении курсора мыши на элемент появляется подсказка, описанная в [Описание](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md). Используется только одно изображение: приоритет отдается [ИзображениеНеактивного](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md).

---

### Теги

`Доступность: Клиент`

```
Теги: ЧитаемыйМассив<Объект>
```

Список тегов. В качестве элементов можно использовать [ЭлементСпискаЗначений](../../wiki/interface/valuelistitem-ru-c68a213e54f6.md) с указанием цвета.
