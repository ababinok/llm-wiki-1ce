`Стд::ПолнотекстовыйПоиск::ФрагментыПолнотекстовогоПоискаПоСвойству` `Доступность: Сервер`

Структура описывает несколько фрагментов по одному свойству.

**Сравнение**

Структурное

Два экземпляра равны, если попарно равны все свойства.

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Свойства

### ИмеетВхождения

`Доступность: Сервер` `ТолькоЧтение`

```
ИмеетВхождения: Булево
```

Истина, если в представленном массиве фрагментов есть вхождения соответствующие поисковому запросу. Если ложь, значит свойство найдено по его представлению, а в значении свойства ничего не найдено или если свойство является дополнительным для расширения контекста или если запись найдена в результате поиска не по основному тексту, а по тегам или по нетекстовым свойствам.

---

### Свойство

`Доступность: Сервер` `ТолькоЧтение`

```
Свойство: ОтражениеХранимогоСвойства
```

Метаданные свойства.

---

### Фрагменты

`Доступность: Сервер` `ТолькоЧтение`

```
Фрагменты: ЧитаемыйМассив<ФрагментПолнотекстовогоПоиска>
```

Фрагменты текста, найденные в значении этого свойства. Первый и последний фрагмент может быть, соответственно, началом и концом значения свойства.
