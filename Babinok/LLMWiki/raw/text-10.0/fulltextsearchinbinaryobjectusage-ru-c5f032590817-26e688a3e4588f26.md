## Свойства

### Авто

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Авто
```

Автоматическое определение. Значение используется по умолчанию. Объект будет использоваться в полнотекстовом поиске при условии, что пройдены все прочие проверки по таким критериям как: размер файла, тип файла, персональность, конфиденциальность, временность и т.п. Если у двоичных данных вообще отсутствуют прикладные свойства тогда считается, что задано значение [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md).

---

### Использовать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
Использовать
```

Да, обязательно использовать в полнотекстовом поиске. Это категоричное требование позволяет пропустить проверку по всем прочим критериям, таким как: размер файла, тип файла, персональность, конфиденциальность, временность. Другими словами, требование позволяет сделать исключение для конкретного двоичного файла, если он не проходит обор по стандартным критериям, заданным по умолчанию.

---

### НеИспользовать

`Доступность: КлиентИСервер` `ТолькоЧтение`

```
НеИспользовать
```

Нет, не использовать.
