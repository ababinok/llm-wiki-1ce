`Стд::Http::КонтекстHttp` `Доступность: Сервер`

Состояние между выполнениями различных запросов к одному серверу.

**Сравнение**

Ссылочное

## Иерархия типа

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

---

## Примеры

**Общие примеры**

```xbsl
знч Аутентификация = новый АутентификацияHttp("пользователь", "пароль")
знч Контекст = новый КонтекстHttp(Аутентификация)
исп Ответ = КлиентHttp.ЗапросGet("адрес").Выполнить(Контекст)  
```

---

## Конструкторы

### КонтекстHttp

`Доступность: Сервер`

```
КонтекстHttp()
```

Создает новый контекст HTTP.

**Перегрузка** [КонтекстHttp(Аутентификация: АутентификацияHttp)](../../wiki/integration/httpcontext-ru-6de81d9dbfc4.md)

---

### КонтекстHttp

`Доступность: Сервер`

```
КонтекстHttp(Аутентификация: АутентификацияHttp)
```

Создает новый контекст HTTP с аутентификацией

`Аутентификация`

.

**Перегрузка** [КонтекстHttp()](../../wiki/integration/httpcontext-ru-6de81d9dbfc4.md)

---

## Свойства

### Аутентификация

`Доступность: Сервер` `ТолькоЧтение`

```
Аутентификация: АутентификацияHttp?
```

Данные аутентификации, которые будут использованы при выполнении запросов.

---

## Методы

### УстановитьАутентификацию

`Доступность: Сервер`

```
УстановитьАутентификацию(Аутентификация: АутентификацияHttp?): КонтекстHttp
```

Устанавливает данные аутентификации

`Аутентификация`

, которые будут использоваться при выполнении запросов. Если

`Неопределено`

, то не используется.
