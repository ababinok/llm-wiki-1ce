## Примеры

**Общие примеры**

В примере компонент `КомпонентРасписания` встраивается в форму планирования задания с возможностью настройки расписания. В обработчике создания формы вызовом метода [УстановитьРасписание](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) устанавливается начальное значение редактируемого расписания, вызовом метода [УстановитьРазрешениеИзменения](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) устанавливается, что задание разрешено изменять. По команде формы вызовом метода [ПолучитьВалидноеРасписание](../../wiki/interface/schedulecomponent-ru-05667e71e788.md) выполняется получение настроенного расписания, и, если его данные валидны, планирование задания с этим расписанием.

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: 7eaaa8c9-c615-4b96-9c4b-c22301079211
Имя: ФормаПланированияЗадания
ОбластьВидимости: ВПодсистеме
Наследует:
  Тип: Форма
  ОсновнаяКоманда:
    Тип: ОбычнаяКоманда
    Обработчик: ОбработчикПланированияЗадания
    Представление: Запланировать
  Содержимое:
    Тип: ПроизвольныйШаблонФормы
    Содержимое:
      Тип: КомпонентРасписания
      Имя: РедакторРасписания
```

```xbsl
@Обработчик
метод ПослеСоздания()
    Компоненты.РедакторРасписания.УстановитьРасписание(Расписание.Ежедневно(Время{12:00}))
    Компоненты.РедакторРасписания.УстановитьРазрешениеИзменения(Истина)
;

метод ОбработчикПланированияЗадания(Команда: ОбычнаяКоманда)
    знч Расписание = Компоненты.РедакторРасписания.ПолучитьВалидноеРасписание()
    если Расписание != Неопределено
        ЗапланироватьЗадание(Расписание)
    ;
;

@НаСервере @ДоступноСКлиента
статический метод ЗапланироватьЗадание(Расписание: Расписание)
    ЗапланированныеЗадания.Создать(&ОбработчикЗадания)
        .Настроить(Расписание = [Расписание])
        .Запланировать()
;

@НаСервере
статический метод ОбработчикЗадания()
;
```

## Методы

### ПолучитьВалидноеРасписание

`Доступность: Клиент`

```
ПолучитьВалидноеРасписание(): Расписание?
```

Возвращает валидное расписание. Если данные в компоненте невалидны (например, дата конца раньше даты начала), вернет

`Неопределено`

.

#### Примеры

Получение валидного расписания из компонента с именем `РедакторРасписания`, проверка валидности данных и планирование задания с этим расписанием. Код метода `ЗапланироватьЗадание` опущен для простоты примера.

```xbsl
знч Расписание = Компоненты.РедакторРасписания.ПолучитьВалидноеРасписание()
если Расписание != Неопределено
    ЗапланироватьЗадание(Расписание)
;
```

---

### РасписаниеВалидно

`Доступность: Клиент`

```
РасписаниеВалидно(): Булево
```

Проверяет, что данные расписания, отображаемые в компоненте, валидны. Если пользователь ввел невалидные данные (например, дата конца раньше даты начала), вернет

`Ложь`

. Если данные расписания валидны, вернет

`Истина`

.

---

### УстановитьРазрешениеИзменения

`Доступность: Клиент`

```
УстановитьРазрешениеИзменения(РазрешеноИзменение: Булево)
```

Устанавливает признак разрешения изменения расписания.

#### Примеры

Установка разрешения редактировать расписание в компоненте `КомпонентРасписания` с именем `РедакторРасписания`.

```xbsl
Компоненты.РедакторРасписания.УстановитьРазрешениеИзменения(Истина)
```

---

### УстановитьРасписание

`Доступность: Клиент`

```
УстановитьРасписание(Расписание: Расписание)
```

Устанавливает расписание.

#### Примеры

Установка расписания компонента `КомпонентРасписания` с именем `РедакторРасписания`.

```xbsl
Компоненты.РедакторРасписания.УстановитьРасписание(Расписание.Ежедневно(Время{12:00}))
```
