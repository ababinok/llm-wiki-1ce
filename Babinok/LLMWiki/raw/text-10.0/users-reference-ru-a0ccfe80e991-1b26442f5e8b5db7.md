### ЗагрузитьОбъект

`Доступность: Сервер`

```
ЗагрузитьОбъект(Заблокировать: Булево = Ложь): Пользователи.Объект?
```

Загружает объект пользователя по текущей ссылке.

`Заблокировать`

- признак необходимости установить блокировку на загружаемый объект до окончания текущей транзакции. Если объекта по ссылке не существует, возвращает

`Неопределено`

. Необходимы права администратора для загрузки пользователя, отличного от текущего.

#### Исключения

**[ИсключениеТаймаутаБлокировки](../../wiki/stdlib/locktimeoutexception-ru-944ade356519.md)** - если не удалось установить блокировку по таймауту. **[ИсключениеНетАктивнойТранзакции](../../wiki/data/noactivetransactionexception-ru-6e837ee18f97.md)** - при попытке заблокировать элемент вне транзакции. **[ИсключениеДоступЗапрещен](../../wiki/stdlib/accessdeniedexception-ru-f679f509f3e4.md)** - при отсутствии прав на загрузку объекта.
