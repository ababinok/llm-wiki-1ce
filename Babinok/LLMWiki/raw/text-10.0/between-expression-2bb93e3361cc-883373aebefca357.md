# Выражение МЕЖДУ — проверка вхождения значения в диапазон

Выражение `МЕЖДУ` имеет следующий синтаксис:

```xbql
проверяемое-значение МЕЖДУ нижняя-граница И верхняя-граница
```

Проверяет, что ***проверяемое-значение*** входит в диапазон от ***нижняя-граница*** (включительно) до ***верхняя-граница*** (включительно). Это выражение эквивалентно следующему логическому выражению:

```xbql
проверяемое-значение >= нижняя-граница И проверяемое-значение <= верхняя-граница
```
