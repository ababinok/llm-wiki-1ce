Для работы с датой и временем в языке запросов используйте свойства и методы следующих типов:

- [`Время`](../../wiki/language/time-type-0dd2a356632b.md)
  
  — предназначен для работы исключительно со временем, без учета даты;
- [`Дата`](../../wiki/language/date-type-ce16dd7b132b.md)
  
  — предназначен для работы исключительно с датой, без учета времени;
- [`ДатаВремя`](../../wiki/language/datetime-type-d35f61464c24.md)
  
  — дает возможность использовать одновременно и дату, и время;
- [`Длительность`](../../wiki/language/duration-type-9b74e1c1188b.md)
  
  — описывает временную продолжительность.

Доступны также тип [`Момент`](../../wiki/language/instant-type-7c8265ee310d.md) с реализацией метода `ВДатаВремя()` и тип [`ЧасовойПояс`](../../wiki/project/time-zone-eb74f3879e8f.md) с реализацией свойства `Имя`.

> [!NOTE] дополнительно
> При выполнении метода `ВМомент()` смещение часового пояса будет вычтено из значения `ДатаВремя`, а при выполнении метода `ВДатаВремя()` — прибавлено к значению `Момент`. Запросы с использованием этих методов могут работать гораздо медленнее.

Литералы типов для работы с датой и временем соответствуют литералам [языка «1С:Элемент»](../../wiki/language/1c-element-language-overview-59fed6458966.md).
