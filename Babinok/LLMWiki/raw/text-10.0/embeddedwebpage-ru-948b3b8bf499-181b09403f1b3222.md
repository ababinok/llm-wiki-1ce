`Стд::Интерфейс::КлиентскоеПриложение::ВстроеннаяВебСтраница` `Доступность: Клиент`

Осуществляет взаимодействие с встроенной веб-страницей внутри приложения типа [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standardclientapplicationwithsections-ru-2bf3e285c484.md).

*Базовые типы:* [Объект](../../wiki/stdlib/object-ru-9e351f286699.md)

*Дочерние типы:* [ВстроеннаяВебСтраница1СПредприятие](../../wiki/interface/embedded1centerprisewebpage-ru-beb590d93db9.md), [ПроизвольнаяВстроеннаяВебСтраница](../../wiki/interface/customembeddedwebpage-ru-5c207144daf0.md)

## Свойства

### Url

`Доступность: Клиент`

```
Url: Строка
```

Адрес встроенной веб-страницы, с которой осуществляется взаимодействие.

---

### Активно

`Доступность: Клиент`

```
Активно: Булево
```

Состояние активности встроенной веб-страницы. Для [СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standardclientapplicationwithsections-ru-2bf3e285c484.md) может быть только одна активная встроенная веб-страница.

---

### Данные

`Доступность: Клиент`

```
Данные: Объект?
```

Дополнительная информация о встроенной веб-странице.

---

### Запущено

`Доступность: Клиент`

```
Запущено: Булево
```

Проверяет, что встроенная веб-страница запущена и с ней можно взаимодействовать.

---

### Ид

`Доступность: Клиент`

```
Ид: Строка
```

Уникальный идентификатор встроенной веб-страницы. Назначается разработчиком.

---

### Изображение

`Доступность: Клиент`

```
Изображение: Url|ДвоичныйОбъект.Ссылка|?
```

Иконка встроенной веб-страницы.

---

### КомпонентСостоянияЗагрузки

`Доступность: Клиент`

```
КомпонентСостоянияЗагрузки: Компонент?
```

Устанавливает экран загрузки для встроенной веб-страницы.

---

### Представление

`Доступность: Клиент`

```
Представление: Строка
```

Текстовое представление встроенной веб-страницы в интерфейсе.

---

Подключает обработчик, вызываемый при начале загрузки встроенной веб-страницы.

---

### ПриОткрытии

`Доступность: Клиент`

```
ПриОткрытии: (
```

## Методы

### Активировать

`Доступность: Клиент`

```
Активировать(): Булево
```

Активирует встроенную веб-страницу в рабочей области

[СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standardclientapplicationwithsections-ru-2bf3e285c484.md)

.

---

### Остановить

`Доступность: Клиент`

```
Остановить(): Булево
```

Останавливает встроенную веб-страницу, удаляет её из панели запущенных веб-страниц и из рабочей области

[СтандартноеКлиентскоеПриложениеСРазделами](../../wiki/interface/standardclientapplicationwithsections-ru-2bf3e285c484.md)

.

---

### ОтправитьСообщение

`Доступность: Клиент`

```
ОтправитьСообщение(Сообщение: СообщениеВстроеннойВебСтраницы)
```

Пересылает сообщение встроенной веб-странице. Сообщение может пересылаться как есть, в виде строки или в виде объекта

[СообщениеВстроеннойВебСтраницы](../../wiki/interface/embeddedwebpagemessage-ru-22daadca3533.md)

. Первый вариант применяется для передачи сообщения обычной веб-странице, не являющейся приложением 1С:Предприятие и не знакомой с его форматом.

---

### ПоказатьСостояниеЗагрузки

`Доступность: Клиент`

```
ПоказатьСостояниеЗагрузки()
```

Включает экран загрузки для встроенной веб-страницы.

---

### СкрытьСостояниеЗагрузки

`Доступность: Клиент`

```
СкрытьСостояниеЗагрузки()
```

Выключает экран загрузки для встроенной веб-страницы.
