**Аннотация** — специальная синтаксическая конструкция, которая позволяет добавить метаданные в программный код. Добавленные метаданные могут использоваться компилятором/интерпретатором и другими механизмами при работе с исходным кодом. Аннотации могут размещаться на объявлениях структур, исключений, перечислений, констант, свойств, методов, параметров и конструкторов — в зависимости от применимости конкретной аннотации.

В программном коде аннотации отмечаются специальным символом `@` и указываются перед аннотируемым объектом:

```xbsl
@ИмяАннотации
объект
```

Например:

```xbsl
@ИменованныеПараметры(КромеПервого = Истина)
метод Пример(П1: Число = 22, П2: Число, П3 = 44)
;
```

В примере выше аннотация `@ИменованныеПараметры` дает возможность указать, что в методе/конструкторе допускаются только именованные аргументы для всех параметров, кроме первого. При попытке вызвать такой метод с позиционной формой параметров будет ошибка:

```xbsl
метод ВызватьМетод()
  Пример(П2 = 22)     // Ошибки нет
  Пример(0, П2 = 22)  // Ошибки нет, т. к. задан параметр КромеПервого = Истина
  Пример(0, 22)       // Ошибка. Допустим вызов только с именованной формой параметров
;
```

Аннотации могут иметь параметры. Параметры могут быть как обязательными, так и необязательными (иметь значение по умолчанию).

На типы параметров аннотаций и их значения ([выражения инициализации](../../wiki/language/variable-declaration-statement-defd1798c9ff.md)) накладываются следующие ограничения:

- Выражение, которое присваивается в качестве значения параметра, должно быть вычислимо во время компиляции. Выражение является вычислимым на этапе компиляции, если оно удовлетворяет следующим критериям:
  
  - Литералы (включая литералы коллекций) являются вычислимыми.
  - Обращения к константам модулей являются вычислимыми.
  - Операции над вычислимыми являются вычислимыми, кроме следующих исключений:
    
    - Вызовы методов и обращения к свойствам.
    - Вызовы конструкторов.
    - Операции сложения значения типа
      
      `Строка`
      
      со значением другого типа.

> [!NOTE] примечание
> Если выражение инициализации не указано, то в параметр присваивается значение по умолчанию. Если для выбранного параметра аннотации нет значения по умолчанию, то во время компиляции возникает ошибка.

Дополнительно разрешается использовать аннотации как параметры других аннотаций:

```xbsl
@Аннотация1(Параметр11 = @Аннотация2(Параметр21 = "ЗначениеПараметра"))
```

## Синтаксис аннотаций с параметрами

- Именованная форма:
  
  ```xbsl
  @Аннотация(Параметр1 = Значение1, ... , ПараметрN = ЗначениеN)
  ```
- Позиционная форма: допускается использовать позиционную форму только для первого параметра, если аннотация имеет соответствующий признак.
  
  Правильно. [Описание иллюстрации](../figures/e84cee6e0d7036af176153092a96bb7ffe5f858bf23d616f7cfc983a97a2de5f-ba77891b83aec8c5.md)
  
  ```xbsl
  @Аннотация(Значение1, Параметр2 = Значение2, ... , ПараметрN = ЗначениеN)
  ```
  
  ```xbsl
  @Аннотация(Параметр1 = Значение1, ... , ПараметрN = ЗначениеN)
  ```
  
  Неправильно. [Описание иллюстрации](../figures/603d54fd2915a5d2131847b25291afd1287a94423523671c5d183e102fd7c34e-e876f584ea679688.md)
  
  ```xbsl
  @Аннотация(Значение1, Значение2, ...)
  ```
  
  ```xbsl
  @Аннотация(Параметр1 = Значение1, Значение2, ...)
  ```

## Типы аннотаций

- `@ИменованныеПараметры` — запрещает вызывать метод с позиционными аргументами (допускаются только именованные аргументы). Имеет параметр `КромеПервого: Булево`, который указывает, что первый параметр можно использовать в позиционной форме.
- `@Контекстный` — помечает контекстные серверные нестатические методы, доступные в модулях компонентов интерфейса ([подробнее](../../wiki/stdlib/contextual-ru-468258bf9c74.md)).
- `@Обработчик` — помечает методы-обработчики.
- `@Подписка` — используется для объявления подписки на события ([подробнее](../../wiki/project/event-subscriptions-8a4718cb813e.md)).
- `@Реализация` — помечает методы, которые являются реализацией абстрактного метода контракта ([подробнее](../../wiki/project/contract-implementation-28307948da85.md)).
- Аннотации **ОбластиВидимости** — определяют область видимость элемента (подробнее):
  
  - `@ВПодсистеме`,
  - `@ВПроекте`,
  - `@ВТипе`,
  - `@Глобально`,
  - `@Локально`.
- Аннотации **Окружения** — определяют окружение элемента (подробнее):
  
  - `@ДоступноСКлиента`;
    
    > [!NOTE] примечание
    > Можно использовать с параметром **КешироватьРезультат** типа `Булево`. Значение по умолчанию — `Ложь`. Если значение параметра `Истина`, то результат первого вызова метода сохраняется в кеше на клиенте, а последующие вызовы, осуществляемые в течение данного сеанса пользователя, используют прошлый результат, не выполняя реального обращения к серверу.
  - `@НаКлиенте`;
  - `@НаСервере`.
- Аннотации **Проверки** — определяют необходимость проверки элемента:
  
  - `@ПроверятьИспользованиеЗначения`
    
    (
    
    [подробнее](../../wiki/language/methods-in-built-in-script-language-3c568746fa15.md)
    
    ).
- Аннотации **Проект** — используются для настройки и обновления приложений ([подробнее](../../wiki/project/update-app-data-356eca7811d0.md)):
  
  - `@НастройкаПриложения`,
  - `@ОбновлениеПроекта`.
- `@Устарело` — помечает некоторую функциональность как устаревшую ([подробнее](../../wiki/stdlib/deprecated-ru-ac9527c3202f.md)). Аннотация может применяться к следующим элементам языка «1С:Элемент»:
  
  - элементы перечислений,
    
    ```xbsl
    перечисление ОперационныеСистемы
      @Устарело(Сообщение = "Больше не поддерживаем Linux!")
      Linux,
      macOS,
      Windows умолчание
    ;
    ```
  - методы,
    
    ```xbsl
    @Устарело(Сообщение = "Устаревшая функциональность!")
    метод ПолучитьДанные()
    ;
    ```
  - конструкторы,
    
    ```xbsl
    структура БухгалтерскийДокумент
    @Устарело(Сообщение = "Устаревший конструктор для старого формата")
    конструктор
    ;
    ```
  - параметры методов и конструкторов,
    
    ```xbsl
    метод ДесериализоватьСтруктуруУстаревший(@Устарело СтрокаJSON: Строка)
    ;
    ```
  - свойства.
    
    ```xbsl
    структура БухгалтерскийДокумент
    @Устарело(Сообщение = "Устаревшее свойство")
    пер Сумма: Число
    ;
    ```

Информация об устаревшей функциональности отображается в панели [Проблемы](../../wiki/interface/ide-overview-and-basic-actions-969a6e6501a6.md) и во всплывающей подсказке:

Ссылка на элемент Linux демонстрационного перечисления ОперационныеСистемы подчёркнута как устаревшая. Подсказка и панель «Проблемы» показывают сообщение аннотации «Больше не поддерживаем Linux!». Это текст аннотации в пользовательском примере, а не сообщение о поддержке платформой операционной системы Linux. [Описание иллюстрации](../figures/df487789e4960185c1cc3786b3eb03ae21be9df768eaa7ddb4ea1a9b9f3f7fe8-bef18e598f6671f9.md)

В редакторе вызов ОбъектноеХранилище.Загрузить помечен как устаревший. Серверная подсказка рекомендует актуальный вариант с параметром ИмяФайла, входным потоком, размером, типом содержимого, свойствами и таймаутом устаревания; это сообщение о конкретной устаревшей перегрузке.
