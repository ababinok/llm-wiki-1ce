`Стд::Интерфейс::Группы::ГруппаСПлавающимКомпонентом` `Доступность: Клиент`

Группа, которая располагает плавающий компонент над содержимым. Плавающий компонент располагается в правом нижнем углу группы. На текущий момент в качестве плавающего компонента может использоваться только [ПлавающаяКнопка](../../wiki/interface/floatingbutton-ru-2c8293fa4a3b.md).

**Сравнение**

Ссылочное

## Свойства

### ПлавающийКомпонент

`Доступность: Клиент`

```
ПлавающийКомпонент: ПлавающаяКнопка
```

Плавающая кнопка, отображаемая поверх основного компонента.

---

### Содержимое

`Доступность: Клиент`

```
Содержимое: Компонент
```

Основной компонент, поверх которого будет отображаться всплывающий компонент.
