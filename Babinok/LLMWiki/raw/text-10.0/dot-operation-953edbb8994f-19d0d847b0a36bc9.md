## Обращение к свойствам экземпляра

Операция `.` (обращение «через точку») используется для доступа к свойствам экземпляра типа. Она отделяет имя переменной от имени свойства, к которому необходимо обратиться. Такое обращение может использоваться как для чтения, так и для установки значения свойства (если свойство допускает изменение).

Так, для обращения к свойству [`Имя`](../../wiki/stdlib/file-ru-a4070bcf9efb.md) экземпляра `Отчет` типа [`Файл`](../../wiki/stdlib/file-ru-a4070bcf9efb.md) следует использовать выражение вида:

```xbsl
знч Отчет = новый Файл("C:\\Documents\\Report.xml")
знч Имя = Отчет.Имя
```

Допускается последовательное использование операций обращения, если получаемое значение свойства также имеет свои свойства. Например:

```xbsl
знч Каталог = новый Файл("C:\\Documents")
знч ИмяФайла = Каталог.Дочерние[0].Имя
```

В этом примере:

- Первая точка (
  
  `Каталог.Дочерние`
  
  ) используется для доступа к свойству
  
  [`Дочерние`](../../wiki/stdlib/file-ru-a4070bcf9efb.md)
  
  экземпляра типа
  
  [`Файл`](../../wiki/stdlib/file-ru-a4070bcf9efb.md)
  
  . Это свойство возвращает массив файлов в каталоге.
- [Операция доступа по индексу](../../wiki/language/indexer-operator-6461034aa5ad.md)
  
  `[]`
  
  используется для доступа к первому элементу массива — экземпляру типа
  
  [`Файл`](../../wiki/stdlib/file-ru-a4070bcf9efb.md)
  
  .
- Последняя точка (
  
  `[0].Имя`
  
  ) позволяет получить доступ к свойству
  
  [`Имя`](../../wiki/stdlib/file-ru-a4070bcf9efb.md)
  
  полученного экземпляра типа
  
  [`Файл`](../../wiki/stdlib/file-ru-a4070bcf9efb.md)
  
  .

Последовательное использование операций обращения может приводить к различным ошибкам во время исполнения, поэтому такие сложные конструкции следует использовать только в случае полной уверенности, что написанное выражение не приведет к ошибке.

## Вызов методов экземпляра

Обращение к методам экземпляров также выполняется с помощью операции `.`. Вызов метода может использоваться в качестве участника выражения, если у метода есть возвращаемое значение подходящего типа. Использование вызова метода в левой части [инструкции присваивания](../../wiki/language/assignment-statement-d8e86eb2d5a3.md) не допускается.

Поддерживается каскадный вызов методов экземпляров:

```xbsl
знч ПримерСтроки = "Это пример строки"
знч ДлинаПодстроки = ПримерСтроки.Подстрока(4, 10).Длина()
```

В этом примере:

- Для переменной
  
  `ПримерСтроки`
  
  типа
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  вызывается метод
  
  [`Подстрока()`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  , который возвращает значение типа
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  .
- Для полученного значения вызывается метод
  
  [`Длина()`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  типа
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  .

> [!TIP] совет
> Если вы не уверены, метод какого экземпляра будет вызван, используйте круглые скобки для явного определения экземпляров.
