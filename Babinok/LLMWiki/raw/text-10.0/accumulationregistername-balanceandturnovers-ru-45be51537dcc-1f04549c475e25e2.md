`Версия 9.0 и выше`

Данные таблицы представляют собой итоги ресурсов (остатки и обороты) в разрезе измерений за определенный промежуток времени (период). Итоговые значения могут быть получены в разрезе комбинаций значений измерений и/или в развороте дополнительной периодичности.

Виртуальная таблица остатков и оборотов не хранится в базе данных, а строится в момент обращения к ней. Для построения виртуальной таблицы могут использоваться данные таблиц итогов (если значения свойств регистра `ХранитьТекущиеИтоги` и `ХранитьПериодическиеИтоги` равны `Истина`) и таблицы движений регистра (из базы данных). При этом учитывается значение параметра виртуальной таблицы. Итоги ресурсов собираются только по активным записям.

Таблица существует только для регистра накопления вида **Остатки**.

**Параметры:**

- НачалоПериода: [ДатаВремя](../../wiki/stdlib/datetime-ru-b9ec40d17fe0.md)? Позволяет указать начало периода расчета итогов. Если параметр не задан, итоги рассчитываются с самой первой записи.
- КонецПериода: [ДатаВремя](../../wiki/stdlib/datetime-ru-b9ec40d17fe0.md)? Позволяет указать конец периода расчета итогов. Если параметр не задан, итоги рассчитываются по самую последнюю запись.
- Периодичность: [ПериодичностьИтоговРегистраНакопления](../../wiki/data/accumulationregistertotalsperiodicity-ru-3bb775cf3108.md) Позволяет задать дополнительную группировку данных по стандартным периодам. Принимает значения перечисления `ПериодичностьИтоговРегистраНакопления`: `Авто`, `Период` (значение по умолчанию), `Год`, `Полугодие`, `Квартал`, `Месяц`, `Декада`, `Неделя`, `День`, `Час`, `Минута`, `Секунда`, `Регистратор`, `Запись`. Если значение параметра равно `Период`, итоги предоставляются за весь период (с **НачалоПериода** по **КонецПериода**) без дополнительных разворотов. При `Авто` периодичность определяется по используемым в запросе полям.
- СпособДополнения: [СпособДополненияПериодовРегистраНакопления](../../wiki/data/accumulationregisterperiodcomplementmethod-ru-37400c50a80f.md) Способ дополнения периодов. Используется для включения граничных периодов в состав выдаваемых виртуальной таблицей записей. Принимает значения перечисления `СпособДополненияПериодовРегистраНакопления`:
  
  - `ЗаписиИГраницыПериода`
    
    (значение по умолчанию) — граничные периоды включаются независимо от наличия или отсутствия записей движений в рамках интервала между
    
    НачалоПериода
    
    и
    
    КонецПериода
    
    .
  - `Записи`
    
    — граничные периоды не включаются: будут выданы записи только за те периоды, когда имели место движения.
- Фильтр Выражение языка запросов типа `Булево`. В выражении доступны поля измерений регистра накопления, а также применимые к этим полям выражения (например, операция обращения через точку или вызов функций, кроме агрегатных). Данный параметр позволяет ограничить состав исходных записей, по которым будут собираться итоги при построении виртуальной таблицы. Если параметр не указан, для сбора итогов будут анализироваться все активные записи регистра, что в большинстве случаев менее эффективно.

## Примеры

Пример запроса к таблице остатков и оборотов регистра накопления **ОстаткиНоменклатуры**:

```xbql
    ОстаткиНоменклатурыОстаткиИОбороты.Склад КАК Склад,
    ОстаткиНоменклатурыОстаткиИОбороты.КоличествоНачальныйОстаток КАК КоличествоНачальныйОстаток,
    ОстаткиНоменклатурыОстаткиИОбороты.КоличествоОборот КАК КоличествоОборот,
    ОстаткиНоменклатурыОстаткиИОбороты.КоличествоПриход КАК КоличествоПриход,
    ОстаткиНоменклатурыОстаткиИОбороты.КоличествоРасход КАК КоличествоРасход,
    ОстаткиНоменклатурыОстаткиИОбороты.КоличествоКонечныйОстаток КАК КоличествоКонечныйОстаток
ИЗ
    ОстаткиНоменклатуры.ОстаткиИОбороты(%НачалоПериода, %КонецПериода, ПериодичностьИтоговРегистраНакопления.Месяц) КАК ОстаткиНоменклатурыОстаткиИОбороты

    ОстаткиНоменклатурыОстаткиИОбороты.Склад
```

## Поля

### {ИмяИзмерения}

```
{ИмяИзмерения}: ТипИзмерения
```

Значение измерения регистра накопления.

---

### {ИмяРесурсаОборот}

```
{ИмяРесурса}Оборот: Число
```

Оборот ресурса. Сумма всех движений вида **Приход** со знаком «+» (плюс) и вида **Расход** со знаком «-» (минус).

---

### {ИмяРесурсаПриход}

```
{ИмяРесурса}Приход: Число
```

Содержит сумму всех движений вида **Приход** по ресурсу регистра.

---

### {ИмяРесурсаРасход}

```
{ИмяРесурса}Расход: Число
```

Содержит сумму всех движений вида **Расход** по ресурсу регистра.

---

### {ИмяРесурсаНачальныйОстаток}

```
{ИмяРесурса}НачальныйОстаток: Число
```

Содержит значение остатка ресурса на начало соответствующего периода.

---

### {ИмяРесурсаНачальныйОстатокПоложительный}

```
{ИмяРесурса}НачальныйОстатокПоложительный: Число
```

Содержит значение положительного остатка ресурса на начало соответствующего периода. Имеет значение 0, если начальный остаток ресурса отрицательный.

---

### {ИмяРесурсаНачальныйОстатокОтрицательный}

```
{ИмяРесурса}НачальныйОстатокОтрицательный: Число
```

Содержит абсолютное значение отрицательного остатка ресурса на начало соответствующего периода. Имеет значение 0, если начальный остаток ресурса положительный.

---

### {ИмяРесурсаКонечныйОстаток}

```
{ИмяРесурса}КонечныйОстаток: Число
```

Содержит значение остатка ресурса на конец соответствующего периода.

---

### {ИмяРесурсаКонечныйОстатокПоложительный}

```
{ИмяРесурса}КонечныйОстатокПоложительный: Число
```

Содержит значение положительного остатка ресурса на конец соответствующего периода. Имеет значение 0, если конечный остаток ресурса отрицательный.

---

### {ИмяРесурсаКонечныйОстатокОтрицательный}

```
{ИмяРесурса}КонечныйОстатокОтрицательный: Число
```

Содержит абсолютное значение отрицательного остатка ресурса на конец соответствующего периода. Имеет значение 0, если конечный остаток ресурса положительный.

---

### Период

```
Период: ДатаВремя
```

Содержит начальную дату периода, к которому относятся итоги регистра. Поле существует только в случае, если указано значение параметра **Периодичность**: `Год`, `Полугодие`, `Квартал`, `Месяц`, `Декада`, `Неделя`, `День`, `Час`, `Минута`, `Секунда`, `Регистратор` или `Запись`. В случае использования дополнительного разворота итогов по записям в поле **Период** содержится значение поля **Период** записи регистра или дата границы периода с точностью до миллисекунд (для дополнения периода).

---

```
ПериодГод: ДатаВремя
```

Начало периода с периодичностью до года. Поле существует, если значение параметра **Периодичность** равно `Авто`.

### ПериодЗаписи

```
ПериодЗаписи: ДатаВремя
```

Содержит значение поля **Период** записи регистра накопления. В случае дополнения периода содержит дату границы периода с точностью до миллисекунд. Поле существует, если значение параметра **Периодичность** равно `Авто`.

---

### Регистратор

```
Регистратор: ИмяДокумента.Ссылка?
```

Содержит ссылку на документ-регистратор, к которому относятся итоги регистра. В случае дополнения периода принимает значение `Неопределено`. Поле существует, если значение параметра **Периодичность** равно `Авто`, `Регистратор` или `Запись`.

---

### Индекс

```
Индекс: Число?
```

Содержит значение поля **Индекс** записи движения регистра накопления. В случае дополнения периода принимает значение `Неопределено`. Поле существует, если значение параметра **Периодичность** равно `Авто` или `Запись`.

---

### НомерСтроки

```
НомерСтроки: Число?
```

Содержит значение поля **НомерСтроки** записи движения регистра накопления. В случае дополнения периода принимает значение `Неопределено`. Поле существует, если значение параметра **Периодичность** равно `Авто` или `Запись`.
