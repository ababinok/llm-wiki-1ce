Выражение `В ИЕРАРХИИ` используется, чтобы проверить, входит ли объект в [иерархию](../../wiki/data/hierarchical-catalog-80c1ad8e7082.md).

Получение всех дочерних элементов

```xbql
ВЫБРАТЬ
    Ссылка,
    Код,
    Наименование
ИЗ
    Подразделения
ГДЕ
    Ссылка В ИЕРАРХИИ (%Родитель)
```

## Синтаксис

Синтаксис выражения `В ИЕРАРХИИ`:

```xbql
проверяемое-выражение [НЕ] В ИЕРАРХИИ [имя-таблицы-иерархии] (список-выражений-родителей)
```

Если `имя-таблицы-иерархии` не указано, то используется [иерархия по умолчанию](../../wiki/project/in-hierarchy-expression-e8dc73bcd687.md) для объекта.

Выражение `В ИЕРАРХИИ` принимает значения:

- `Null`
  
  , если проверяемое значение —
  
  `Null`
  
  .
- `Истина`
  
  , если проверяемое выражение или один из его родителей входят в список выражений родителей.
- `Ложь`
  
  в остальных случаях.

Выражение `НЕ В ИЕРАРХИИ` принимает значения:

- `Null`
  
  , если проверяемое значение —
  
  `Null`
  
  .
- `Ложь`
  
  , если проверяемое выражение или один из его родителей входят в список выражений родителей.
- `Истина`
  
  в остальных случаях.

## Определение таблицы иерархии, заданной по умолчанию

Если таблица иерархии по умолчанию не задана, «1С:Предприятие.Элемент» пытается определить ее по проверяемому выражению — такая таблица должна включать все ссылочные типы проверяемого выражения. Если определить ее не получается, то «1С:Предприятие.Элемент» ищет такую таблицу для каждого ссылочного типа из множества `проверяемое-выражение`:

- если для типа удалось определить таблицу иерархии, то для него выполняется поиск родителей по этой таблице;
- если для типа не удалось определить таблицу иерархии, то выражение
  
  `В ИЕРАРХИИ`
  
  проверяет, входит ли сам этот тип в список выражений родителей.

Для основного справочника, в котором описываются иерархии, можно задать иерархию по умолчанию с помощью свойства [ИерархияПоУмолчанию](../../wiki/data/catalog-e0da7d4e8e72.md).
