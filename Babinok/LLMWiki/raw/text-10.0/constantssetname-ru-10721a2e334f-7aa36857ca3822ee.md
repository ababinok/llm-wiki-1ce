## Методы

### ВычислитьРазрешенияДоступа

`Версия 10.0 и выше`

```
ВычислитьРазрешенияДоступа(): Массив<РазрешениеДоступа>
```

Обработчик, предназначенный для задания прав доступа на набор констант целиком.

#### Примеры

В данном примере мы выдаем всем аутентифицированным пользователям право на чтение и обновление набора констант.

```xbsl
@Обработчик
метод ВычислитьРазрешенияДоступа(): ЧитаемыйМассив<РазрешениеДоступа>
    возврат [
            новый РазрешениеДоступа([новый ПолныйКлючДоступа.Объект()],
                [НаборКонстантПраво.Изменение, НаборКонстантПраво.Чтение])
        ]
;
```

### Заблокировать

`Доступность: Сервер`

```
Заблокировать(РежимБлокировки: РежимБлокировки = РежимБлокировки.Исключительный)
```

Устанавливает заданный тип блокировки на весь набор констант до конца транзакции.

Если транзакция не активна — выбрасывается исключение `ИсключениеНетАктивнойТранзакции`.

#### Примеры

```xbsl
метод ЗаблокироватьНаборКонстант()
    ИмяНабораКонстант.Заблокировать()
;
```

---

### Получить

`Версия 10.0 и выше`

`Доступность: Сервер`

```
Получить(Заблокировать: Булево = Ложь): {ИмяНабораКонстант}.Запись
```

Получить набор констант

Подразумевается, что при выключенной периодичности единственная запись набора констант всегда присутствует в базе данных

Заблокировать = Истина - устанавливает исключительный режим блокировки для всего набора констант, если транзакция не активна - выбрасывается исключение `ИсключениеНетАктивнойТранзакции`

Метод доступен при выключенной периодичности.

#### Примеры

```xbsl
метод ПолучитьДанныеОрганизации(): ДанныеОрганизации.Запись
    возврат ДанныеОрганизации.Получить()
;
```

### Получить

`Доступность: Сервер`

```
Получить(
  Период: Дата,
  Заблокировать: Булево = Ложь
): {ИмяНабораКонстант}.Запись?
```

Получить набор констант в заданный период

Если сохраненного набора констант нет в заданном периоде, то вернет `Неопределено`

Заблокировать = Истина - устанавливает исключительный режим блокировки для всего набора констант, если транзакция не активна - выбрасывается исключение `ИсключениеНетАктивнойТранзакции`

Метод доступен при включенной периодичности.

#### Примеры

```xbsl
метод ПолучитьДанные(): ИмяНабораКонстант.Запись
    возврат ИмяНабораКонстант.Получить(Дата.Сейчас())
;
```

### ПолучитьСрезПоследних

`Версия 10.0 и выше`

`Доступность: Сервер`

```
ПолучитьСрезПоследних(
  Период: Дата = умолчание,
  Заблокировать: Булево = Ложь
): {ИмяНабораКонстант}.Запись
```

Получить набор констант с наибольшим значением поля Период, которое <= заданного периода

Всегда возвращает запись (даже если нет данных для указанного периода, возвращает запись по умолчанию с минимальной датой).

Метод не использует кэширование

Метод доступен при включенной периодичности.

#### Примеры

```xbsl
метод ПолучитьСрезПоследних(): ИмяНабораКонстант.Запись
    возврат ИмяНабораКонстант.ПолучитьСрезПоследних(Дата.Сейчас())
;
```

### СоздатьФормуЗаписи

`Версия 10.0 и выше`

`Доступность: Клиент`

```
СоздатьФормуЗаписи(Период: Дата): ФормаЗаписиПериодическогоНабораКонстант
```

Создает форму записи периодического набора констант. Если набору констант назначена форма записи, то будет создана форма ровно этого типа. Иначе будет создана автоматическая форма типа

[ИмяНабораКонстант.АвтоматическаяФормаЗаписи](../../wiki/stdlib/constantssetname-automaticrecordform-ru-61f6e8bd7e14.md)

Параметр `Период` определяет, какая запись набора констант будет редактироваться в форме. Если в качестве значения ключа передано [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md), то будет открыта форма новой записи. Метод доступен при включенной периодичности.
