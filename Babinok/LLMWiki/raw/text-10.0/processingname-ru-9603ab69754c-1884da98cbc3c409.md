## Методы

### {МетодВычисленияДоступаДляОперации}

```
{МетодВычисленияДоступаДляОперации}(): ЧитаемаяКоллекция<КлючДоступа.Объект>
```

Обработчик, предназначенный для установки прав доступа на отдельные операции обработки.

#### Примеры

```yaml
ВидЭлемента: Обработка
Ид: e66a74c2-e577-41b5-96da-cb274a8f6547
Имя: РасчетСтоимостиДоставки
ОбластьВидимости: ВПодсистеме
Операции:
  -
    Имя: РассчитатьАвиатранспортом
    КонтрольДоступа:
      Разрешения:
        Вызов: РазрешенияВычисляются
      Обработчик: ВычислитьРазрешенияОперацииРассчитатьАвиатранспортом
# Прочие поля опущены для краткости
#...
```

Предполагаем, что в проекте описан ключ доступа КлючДоступаДляМенеджеров. В данном примере мы выдаем менеджерам право выполнять операцию "РассчитатьАвиатранспортом".

```xbsl
метод ВычислитьРазрешенияОперацииРассчитатьАвиатранспортом(): ЧитаемаяКоллекция<КлючДоступа.Объект>
    возврат [новый КлючДоступаДляМенеджеров.Объект()]
;
```

---

### СоздатьФорму

`Версия 10.0 и выше`

`Доступность: Клиент`

```
СоздатьФорму(Объект: <{ИмяОбработки}>): ФормаОбработки
```

Создает форму обработки. Если обработке назначена форма обработки, то будет создана форма ровно этого типа. Иначе будет создана автоматическая форма типа

[ИмяОбработки.АвтоматическаяФорма](../../wiki/interface/processingname-automaticform-ru-40572408be14.md)

.

Параметр `Объект` определяет, какой объект будет редактироваться в форме. Если передано [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md), то будет открыта форма нового объекта.

---

```
СоздатьФорму(Объект: {ИмяОбработки}.Объект? = Неопределено): ФормаОбработки<{ИмяОбработки}.Объект>
```
