`Стд::Пользователи::Самообслуживание::ОперацияПошаговойРегистрацииСВнешнейУчетнойЗаписью` `Доступность: Клиент`

Операция самостоятельной регистрации с помощью внешней учетной записи.

Операция выполняется пошагово (шаги 2 и 3 могут вызываться в любом порядке):

1. [Начать](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md)
  
  — начать операцию,
2. [Аутентифицироваться](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md)
  
  — выполнить аутентификацию во внешнем сервисе,
3. [УстановитьПараметр](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md)
  
  — установить пользовательский параметр,
4. [Завершить](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md)
  
  — завершить операцию.

## Методы

### Аутентифицироваться

`Доступность: Клиент`

```
Аутентифицироваться(ПоставщикАутентификации: ПоставщикАутентификации): СтатусОперацииПошаговойРегистрацииСВнешнейУчетнойЗаписью
```

Выполнить вход во внешнюю систему.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [Начать](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md).

---

### Завершить

`Доступность: Клиент`

```
Завершить(СсылкаПослеРегистрации: Строка? = Неопределено): СтатусОперацииПошаговойРегистрацииСВнешнейУчетнойЗаписью
```

Завершить регистрацию. Пользователь создается и подключается к приложению.

Если задан параметр самостоятельной регистрации пользователя, то у него вызываются следующие обработчики:

- необязательный обработчик
  
  `ПриПроверкеПараметра`
  
  (при наличии);
- обязательный обработчик
  
  `ПослеПодключения`
  
  .

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - операция не готова к завершению (см. [ОжидаемыеДанные](../../wiki/stdlib/selfservicestepwiseoperationstatus-ru-0eedb2374a3e.md)).

---

### Начать

`Доступность: Клиент`

```
@ИменованныеПараметры
Начать(УстановкаПараметраОбязательна: Булево): СтатусОперацииПошаговойРегистрацииСВнешнейУчетнойЗаписью
```

>

Вызов возможен только с именованными параметрами

Начать операцию. Разрешен только именованный вызов.

Если обязательный параметр `УстановкаПараметраОбязательна` принимает значение `Истина`, то в ходе операции нужно указать параметр самостоятельной регистрации пользователя. Если значение параметра равно `Ложь`, то при установке параметра самостоятельной регистрации возникнет ошибка.

---

### УстановитьПараметр

`Доступность: Клиент`

```
УстановитьПараметр(Параметр: ПараметрСамостоятельнойРегистрацииПользователя): СтатусОперацииПошаговойРегистрацииСВнешнейУчетнойЗаписью
```

Установить пользовательский параметр регистрации. Обработчик

`ПриПроверкеПараметра`

будет вызван во время завершения операции.

Если операция начата с параметром `УстановкаПараметраОбязательна`, равным `Истина`, то вызов данного метода обязателен до завершения операции.

#### Исключения

**[ИсключениеНедопустимоеСостояние](../../wiki/stdlib/illegalstateexception-ru-4c1cc853b874.md)** - метод вызван до метода [Начать](../../wiki/data/stepwiseregistrationwithexternalaccountoperation-ru-57b2cf8bc16a.md) или операция начата с параметром `УстановкаПараметраОбязательна`, равным `Ложь`.
