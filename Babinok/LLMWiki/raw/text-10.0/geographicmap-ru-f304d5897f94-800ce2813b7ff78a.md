## Свойства

### КоординатыЦентра

`Доступность: Клиент`

```
КоординатыЦентра: Авто|ГеографическиеКоординаты
```

Географические координаты начального центра карты: широта и долгота.

Если [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md), пытается получить координаты местоположения пользователя. В случае неуспешного определения местоположения (например, отсутствует разрешение в браузере) равно координатам (0, 0).

---

### МаксимальнаяОбластьПросмотра

`Доступность: Клиент`

```
МаксимальнаяОбластьПросмотра: Авто|ОбластьПросмотраГеографическойКарты|?
```

Границы прямоугольной области, доступной для просмотра на карте.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) разрешается:

- Если
  
  [НастройкиБазовогоСлоя](../../wiki/interface/geographicmap-ru-f304d5897f94.md)
  
  заданы структурой
  
  [НастройкиСтатичногоИзображенияГеографическойКарты](../../wiki/stdlib/geographicmapstaticimagesettings-ru-df095dbeee59.md)
  
  , то свойства
  
  [КоординатыЛевогоНижнегоУгла](../../wiki/stdlib/geographicmapviewarea-ru-c3cd2f2742dd.md)
  
  и
  
  [КоординатыПравогоВерхнегоУгла](../../wiki/stdlib/geographicmapviewarea-ru-c3cd2f2742dd.md)
  
  совпадают с одноименными свойствами
  
  [НастройкиСтатичногоИзображенияГеографическойКарты](../../wiki/stdlib/geographicmapstaticimagesettings-ru-df095dbeee59.md)
  
  ,
- `ОбластьПросмотраГеографическойКарты(КоординатыЛевогоНижнегоУгла = ГеографическиеКоординаты(Широта = -85.06, Долгота = -180, КоординатыПравогоВерхнегоУгла = ГеографическиеКоординаты(Широта = 85.06, Долгота = 180))`
  
  , если задана
  
  [СферическаяМеркатора](../../wiki/stdlib/coordinatesystem-ru-c32f79727e08.md)
  
  ,
- `ОбластьПросмотраГеографическойКарты(КоординатыЛевогоНижнегоУгла = ГеографическиеКоординаты(Широта = -80, Долгота = -180, КоординатыПравогоВерхнегоУгла = ГеографическиеКоординаты(Широта = 84, Долгота = 180))`
  
  , если задана
  
  [ЭллиптическаяМеркатора](../../wiki/stdlib/coordinatesystem-ru-c32f79727e08.md)
  
  ,
- [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md)
  
  в остальных случаях.

Значения широт по умолчанию соответствуют ограничениям сферической проекции Меркатора EPSG:3857 ([https://epsg.io/3857](https://epsg.io/3857)) или эллиптической проекции Меркатора EPSG:3395 ([https://epsg.io/3395](https://epsg.io/3395))

### МаксимальныйМасштаб

`Доступность: Клиент`

```
МаксимальныйМасштаб: Авто|Число
```

Максимальное значение, которое может принимать коэффициент масштабирования карты. Может принимать значения от 0 до 18, но не должен быть меньше, чем [МинимальныйМасштаб](../../wiki/interface/geographicmap-ru-f304d5897f94.md).

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) разрешается, как 18.

---

### Масштаб

`Доступность: Клиент`

```
Масштаб: Авто|Число
```

Начальный коэффициент масштабирования карты. Может принимать целые значения от 0 до 18 или меньшего числа, в зависимости от поставщика тайлов. Не должен принимать значения вне пределов, заданных в свойствах [МаксимальныйМасштаб](../../wiki/interface/geographicmap-ru-f304d5897f94.md) и [МинимальныйМасштаб](../../wiki/interface/geographicmap-ru-f304d5897f94.md). Чем больше значение, тем ближе приближение.

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) разрешается, как 10 или 2, в случае, когда [КоординатыЦентра](../../wiki/interface/geographicmap-ru-f304d5897f94.md) = [Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) и не удалось определить местоположение пользователя.

---

### МинимальныйМасштаб

`Доступность: Клиент`

```
МинимальныйМасштаб: Авто|Число
```

Минимальное значение, которое может принимать коэффициент масштабирования карты. Может принимать значения от 0 до 18, но не должен быть больше, чем [МаксимальныйМасштаб](../../wiki/interface/geographicmap-ru-f304d5897f94.md).

[Авто](../../wiki/stdlib/auto-ru-1b14ed166f8e.md) разрешается, как 0, если свойство [МаксимальнаяОбластьПросмотра](../../wiki/interface/geographicmap-ru-f304d5897f94.md) разрешается как [Неопределено](../../wiki/stdlib/undefined-ru-bad7e9ef4c2b.md), иначе вычисляется автоматически, так чтобы просматриваемая область на карте не выходила за границы, определяемые в свойстве [МаксимальнаяОбластьПросмотра](../../wiki/interface/geographicmap-ru-f304d5897f94.md).

## Методы

### ОтобразитьМаршрут

`Доступность: Клиент`

```
ОтобразитьМаршрут(
  Маршрут: ГеографическийМаршрут,
  Маркеры: ЧитаемыйМассив<МаркерГеографическойКарты<ТипДанныхМаркера>>? = Неопределено, ЦветЛинии: Цвет? = Неопределено)
```

Отображает на карте указанный маршрут с возможностью переопределения его оформления.

- `Маршрут`
  
  — маршрут для отображения.
- `Маркеры`
  
  — список маркеров, отображаемых на маршруте. По умолчанию
  
  `Неопределено`
  
  , отображаются дефолтные маркеры начала, конца и промежуточных точек остановки. Если список задан, то дефолтные маркеры не отображаются.
- `ЦветЛинии`
  
  — цвет линии маршрута. По умолчанию
  
  `Неопределено`
  
  и используется цвет, заданный в
  
  [НастройкиОформления](../../wiki/interface/geographicmap-ru-f304d5897f94.md)
  
  карты. Если и в
  
  [НастройкиОформления](../../wiki/interface/geographicmap-ru-f304d5897f94.md)
  
  цвет не задан, то используется (
  
  [Красный](../../wiki/stdlib/colors-ru-a841affb57c9.md)
  
  ).
