## Свойства

### Активен

`Доступность: Сервер` `ТолькоЧтение`

```
Активен: Булево
```

Активность рабочего процесса:

- `Ложь`
  
  – процесс неактивен (либо не загружен в память, либо не может выполнять клиентские запросы);
- `Истина`
  
  – процесс активен (работает).

---

### Включен

`Доступность: Сервер` `ТолькоЧтение`

```
Включен: Булево
```

Устанавливается кластером при необходимости запустить или остановить рабочий процесс:

- `Истина`
  
  - процесс должен быть запущен и будет запущен при возможности.
- `Ложь`
  
  - процесс должен быть остановлен и будет остановлен после отсоединения всех пользователей или после истечения времени, заданного свойством
  
  [ВремяПринудительногоЗавершения](../../wiki/stdlib/v8cluster-ru-85b8e7d3013e.md)
  
  .

---

### ВремяЗапуска

`Доступность: Сервер` `ТолькоЧтение`

```
ВремяЗапуска: Момент
```

Момент запуска рабочего процесса. Если процесс не запущен, то содержит нулевую дату.

---

### ВремяПревышенияПоПамяти

`Доступность: Сервер` `ТолькоЧтение`

```
ВремяПревышенияПоПамяти: Длительность
```

Время, в течение которого объем виртуальной памяти рабочего процесса превышает критическое значение, установленное для кластера.

---

### ДоступнаяПроизводительность

`Доступность: Сервер` `ТолькоЧтение`

```
ДоступнаяПроизводительность: Число
```

Средняя за последние 5 минут доступная производительность. Определяется по времени реакции рабочего процесса на эталонный запрос. В соответствии с доступной производительностью кластер серверов принимает решение о распределении клиентов между рабочими процессами.

---

### ОтносительнаяПроизводительность

`Доступность: Сервер` `ТолькоЧтение`

```
ОтносительнаяПроизводительность: Число
```

Относительная производительность процесса. Может находиться в диапазоне от 1 до 1000. Используется в процессе выбора рабочего процесса, к которому будет подсоединен очередной клиент. Клиенты распределяются между рабочими процессами пропорционально производительности рабочих процессов.
