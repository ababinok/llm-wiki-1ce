После того как вы добавили в проект план обмена, «1С:Предприятие.Элемент» создаст несколько типов, имена которых в общем случае выглядят следующим образом:

- [`{ИмяПланаОбмена}`](../../wiki/integration/exchangeplanname-ru-5de5900381b1.md)
  
  ,
- [`{ИмяПланаОбмена}.Ссылка`](../../wiki/integration/exchangeplanname-reference-ru-ea9b8c731c88.md)
  
  ,
- [`{ИмяПланаОбмена}.Объект`](../../wiki/integration/exchangeplanname-object-ru-2882849e24b4.md)
  
  ,
- [`{ИмяПланаОбмена}.Данные`](../../wiki/integration/exchangeplanname-data-ru-d55d2649c218.md)
  
  .

Например, если в проекте есть план обмена **Склады**, то будут созданы следующие типы:

- `Склады`
  
  ,
- `Склады.Ссылка`
  
  ,
- `Склады.Объект`
  
  ,
- `Склады.Данные`
  
  .

## Тип «ИмяПланаОбмена»

Это тип-одиночка.

Тип [`{ИмяПланаОбмена}`](../../wiki/integration/exchangeplanname-ru-5de5900381b1.md) содержит методы для работы с узлами плана обмена и ссылками на них. Например, `НайтиПоКоду()`, `ПолучитьСсылку()`.

Также он позволяет пересчитать разрешения доступа: `ПересчитатьРазрешенияДоступа()`, `ПересчитатьРазрешенияДоступаДляОбъектов()` ([подробнее](../../wiki/security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md)).

Этот тип не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа:

```xbsl
// Получить менеджера плана обмена «Склады»
пер МенеджерПланаОбмена = Склады

// Пересчитать разрешения доступа плана обмена «Склады»
Склады.ПересчитатьРазрешенияДоступа()
```

### Модуль плана обмена

В проекте модуль, расширяющий тип [`{ИмяПланаОбмена}`](../../wiki/integration/exchangeplanname-ru-5de5900381b1.md), называется **модулем плана обмена** и имеет имя `ИмяПланаОбмена.xbsl`.

В дереве проекта показан модуль плана обмена вместе с его параметрами; модуль расширяет тип соответствующего плана обмена. [Описание иллюстрации](../figures/2ff9cb8980e43b9b385f5b09d62cf6f682c48971ee02b3d959640e9b53392a68-000c211e0e616d4f.md)

В этом модуле вы можете обработать событие `ПолучитьЗначенияВыбора()` для того, чтобы изменить стандартный алгоритм подбора узлов плана обмена при вводе по строке.

Также в модуле плана обмена можно обработать события вычисления разрешений доступа: `ВычислитьРазрешенияДоступа()`, `ВычислитьРазрешенияДоступаДляОбъектов()` ([подробнее](../../wiki/security/manage-access-control-2ec0764ce511.md)).

Вы можете расширить тип `{ИмяПланаОбмена}`, добавив в модуль плана обмена собственные публичные методы. Например, метод для создания элементов определенного вида:

```xbsl
// Создает узел в плане обмена «Склады»
@ВПроекте
метод СоздатьСкладМосква(Наименование: Строка): Склады.Ссылка

    пер Склад = новый Склады.Объект()
    Склад.Наименование = Наименование
    Склад.Регион = Регионы.Москва
    Склад.Записать()

    возврат Склад.Ссылка
;
```

Этот метод будет доступен в других модулях:

```xbsl
// Вызов метода разработчика у менеджера справочника «Сотрудники»
пер НовыйСкладМосква = Склады.СоздатьСкладМосква("Север")
```

> [!TIP] совет
> В модуле плана обмена может находиться реализация [контракта сервиса](../../wiki/project/service-contract-5b8423b5cca0.md).

## Тип «ИмяПланаОбмена.Объект»

Тип [`{ИмяПланаОбмена}.Объект`](../../wiki/integration/exchangeplanname-object-ru-2882849e24b4.md) доступен в окружении **КлиентИСервер**.

Экземпляр этого типа содержит данные одного узла плана обмена и предназначен для создания, изменения или удаления узла плана обмена.

Этот тип имеет конструкторы, которые позволяют создать новый узел плана обмена. Заполнив этот экземпляр данными, вы можете затем сохранить его в базе данных.

### Модуль объекта плана обмена

В проекте модуль, расширяющий тип [`{ИмяПланаОбмена}.Объект`](../../wiki/integration/exchangeplanname-object-ru-2882849e24b4.md), называется **модулем объекта плана обмена** или **модулем узла**. Он доступен в окружении **Сервер**.

В дереве плана обмена «Склады» выделен модуль «Склады.Объект», расположенный рядом с реквизитами и модулем плана; это модуль объекта узла плана обмена. [Описание иллюстрации](../figures/d8c9771e8589b65decb28e861ce3aae62435a03db2a3ac43173536a6b3befd1a-109fcf5a84ad15e1.md)

В нем вы можете обработать такие события, как:

- `ПриЗаполнении()`
  
  ,
- `ПередЗаписью()`
  
  ,
- `ПослеЗаписи()`
  
  ,
- `ПередУдалением()`
  
  .

Например:

```xbsl
@Обработчик
метод ПередУдалением(ПараметрыУдаления: Склады.ПараметрыУдаления)
    // Действия, которые выполняются перед удалением плана обмена
;
```

Во время записи узла плана обмена «Элемент» открывает в базе данных транзакцию записи и вызывает следующие события:

Транзакция записи [Описание иллюстрации](../figures/ec539f819e6ee01d2d6b3bb8b48db3181272c1d777412f667baf6697be1bc180-cac8878202623b73.md)

Вы можете расширить тип [`{ИмяПланаОбмена}.Объект`](../../wiki/integration/exchangeplanname-object-ru-2882849e24b4.md), добавив в модуль объекта собственные публичные методы. Например, метод для пересчета данных узла плана обмена, которые зависят от внешних данных, хранящихся вне плана обмена:

```xbsl
@ВПроекте
метод ПересчитатьДанные()
    // Алгоритм пересчета данных
    // ...
;
```

Этот метод будет доступен в других модулях:

```xbsl
// Вызов собственного метода объекта плана обмена «Склады»
// В переменной Склад находится значение типа Склады.Объект
пер Склад: Склады.Объект
Склад.ПересчитатьДанные()
Склад.Записать()
```

> [!TIP] совет
> В модуле объекта плана обмена может находиться реализация методов [контракта типа](../../wiki/language/type-contract-ab9f0932850d.md) и [контракта сущности](../../wiki/data/entity-contract-079bb6be0d9a.md).

## Тип «ИмяПланаОбмена.Ссылка»

Тип [`{ИмяПланаОбмена}.Ссылка`](../../wiki/integration/exchangeplanname-reference-ru-ea9b8c731c88.md) доступен в окружении **КлиентИСервер**.

Он предназначен для описания ссылки на один узел плана обмена.

Он имеет конструктор `новый ИмяПланаОбмена.Ссылка(Ид: Ууид)`, который позволяет создать новую ссылку по `Ууид`, и серверный метод `ЗагрузитьОбъект()`, который позволяет получить экземпляр (`{ИмяПланаОбмена}.Объект`) из ссылки (`{ИмяПланаОбмена}.Ссылка`).

Чтобы узнать, является ли какое-либо значение ссылкой на элемент плана обмена, можно использовать операцию [это](../../wiki/language/is-e12cbcb44c3d.md), например:

```xbsl
метод ЯвляетсяСсылкойНаПланОбмена(Элемент: Объект): Булево
    возврат Элемент это ПланОбмена.Ссылка
;
```

## Тип «ИмяПланаОбмена.Данные»

Тип структуры с реквизитами, соответствующими реквизитам плана обмена. Тип [`{ИмяПланаОбмена}.Данные`](../../wiki/integration/exchangeplanname-data-ru-d55d2649c218.md) доступен в окружении **Сервер**.

Используется только в обработчиках событий `{ИмяПланаОбмена}.Объект.ПередЗаписью` и `{ИмяПланаОбмена}.Объект.ПослеЗаписи`.

Не имеет конструктора. «Элемент» сам создает экземпляр этого типа при наступлении упомянутого события. Он передает в обработчик события экземпляр этого типа, наполненный «старыми» значениями.

## Тип «ИмяПланаОбмена.НастройкиПередачиДанных»

Тип [`{ИмяПланаОбмена}.НастройкиПередачиДанных`](../../wiki/integration/exchangeplanname-datatransfersettings-ru-c6f454de020a.md) описывает настройки передачи данных узла плана обмена и доступен в окружении **КлиентИСервер**. Позволяет организовать обмен данными текущего приложения с внешним приложением. Тип порождается для каждого плана обмена, в котором значение свойства [ПередачаДанных.Использовать](../../wiki/integration/exchangeplan-47d882fe414b.md) равно `Истина`.

При установке `Активность = Истина` создается запланированное задание, выполняющее обмен данными, а в свойстве `КлючЗапланированногоЗадания` сохраняется его ключ.

Если передача данных активирована, соответствующее интегрируемое приложение нельзя удалить — проверка выполняется при записи узла плана обмена.

```xbsl
метод АктивироватьПередачуДанных(Узел: Склады.Ссылка, Приложение: ПриложениеСклад.Ссылка): Строка?
    пер Настройки = Узел.ЗагрузитьОбъект().ПередачаДанных
    Настройки.Активность = Истина
    Настройки.ИнтегрируемоеПриложение = Приложение
    возврат Настройки.КлючЗапланированногоЗадания
;
```

## Тип «ПланыОбмена»

Это тип-одиночка.

Тип [`ПланыОбмена`](../../wiki/integration/exchangeplans-ru-655d42bfe00f.md) доступен в окружении **Сервер**.

Тип `ПланыОбмена` существует независимо от того, есть в проекте планы обмена или нет. Этот тип позволяет обойти все планы обмена и пересчитать разрешения доступа.

Тип `ПланыОбмена` не имеет конструктора и имеет единственный экземпляр, обращение к которому выполняется по имени типа.

```xbsl
// Получить менеджера всех планов обмена
пер МенеджерВсехПлановОбмена = ПланыОбмена
```

Экземпляр типа `ПланыОбмена` является коллекцией элементов типа `{ИмяПланаОбмена}`. Поэтому, чтобы пересчитать разрешения доступа, достаточно обойти эту коллекцию и у каждого менеджера вызвать пересчет разрешений ([подробнее](../../wiki/security/recalculate-access-permissions-and-keys-8fbd0f5252bf.md)).

```xbsl
для ПланОбмена из ПланыОбмена
    ПланОбмена.ПересчитатьРазрешенияДоступа()
;
```

Однако при этом нужно учитывать, что состав коллекции элементов экземпляра типа `ПланОбмена` зависит от того, какой подсистеме принадлежит модуль, в котором был получен этот экземпляр. В его составе будут только те планы обмена, которые принадлежат данной подсистеме и тем подсистемам, которые импортирует данная подсистема.

## Типы, порождаемые механизмом обмена данными

Для каждого элемента проекта, входящего в [состав плана обмена](../../wiki/integration/exchangeplan-47d882fe414b.md), «1С:Предприятие.Элемент» формирует типы [языка «1С:Элемент»](../../wiki/language/1c-element-language-overview-59fed6458966.md). Состав и структура типов зависит от [вида внешней системы](../../wiki/integration/exchangeplan-47d882fe414b.md).

Так, если выполняется обмен данными между приложениями «1С:Предприятие.Элемента», имя типа формируется по следующему шаблону: `<ИмяПланаОбмена>.СхемаДанных.<ИмяЭлементаПроектаВСоставеПланаОбмена><ИндексПриКонфликтеИмен>.(<ИмяТипа>|<ИмяТабличнойЧасти>)`.

Здесь:

- `ИмяПланаОбмена`
  
  — имя плана обмена, в котором описываются правила
  
  [конвертации данных](../../wiki/integration/exchangeplan-47d882fe414b.md)
  
  .
- `ИмяЭлементаПроектаВСоставеПланаОбмена`
  
  — имя элемента проекта, входящего в состав плана обмена. Если выполнена настройка
  
  [правил конвертации](../../wiki/integration/exchangeplan-47d882fe414b.md)
  
  и в свойстве
  
  [Справа](../../wiki/integration/exchangeplan-47d882fe414b.md)
  
  указано другое имя, то используется оно.
- `ИндексПриКонфликтеИмен`
  
  — число, добавляемое к конфликтующим именам. Так как при формировании имени типа пространство имен не используется, это может привести к конфликту имен. Например, если состав плана обмена включает два элемента —
  
  `Учет::Заказы`
  
  и
  
  `Продажи::Заказы`
  
  , то будут сгенерированы одинаковые имена
  
  Заказы
  
  и возникнет конфликт. Чтобы этого не произошло,
  
  «1С:Предприятие.Элемент»
  
  сформирует два имени —
  
  Заказы1
  
  и
  
  Заказы2
  
  .
- `ИмяТипа`
  
  — имя типа, порожденного по элементу проекта, который передается при обмене данными.
- `ИмяТабличнойЧасти`
  
  — имя табличной части, данные которой передаются при обмене данными.

Типы порождаются для элементов проекта, которые можно включить в состав плана обмена: справочника, документа, хранилища настроек, набора констант, регистра сведений и регистра накопления. Для объектных типов **Справочник**, **Документ** и **ХранилищеНастроек** порождаются типы `Объект`, `Ссылка` и `ИмяТабличнойЧасти` (при наличии). Для типа **НаборКонстант** порождаются объекты `Запись` и `КлючЗаписи`, а для типов **РегистрСведений** и **РегистрНакопления** порождаются объекты `Запись`, `НаборЗаписей`, `КлючЗаписи` и `КлючОсновногоФильтра`.

Например, для справочника **Заказы**, включенного в состав плана обмена **УдаленныеСклады**, будут сформированы три типа:

- `УдаленныеСклады.СхемаДанных.Заказы.Объект`
  
  — передает данные элемента справочника,
- `УдаленныеСклады.СхемаДанных.Заказы.Ссылка`
  
  — передает ссылку на элемент справочника,
- `УдаленныеСклады.СхемаДанных.Заказы.ПозицииЗаказа`
  
  — передает данные табличной части
  
  ПозицииЗаказа
  
  .

Поля элементов проекта, включенных в состав плана обмена, могут иметь только следующие типы:

- примитивные типы (
  
  [`Строка`](../../wiki/stdlib/string-ru-1bac645acacf.md)
  
  ,
  
  [`Число`](../../wiki/stdlib/number-ru-dd4b54993c86.md)
  
  и т. д.),
- перечисления,
- [`Сущность.Ссылка`](../../wiki/data/entity-reference-ru-d0485ecb981e.md)
  
  ,
- [`ДвоичныйОбъект.Ссылка`](../../wiki/data/binaryobject-reference-ru-295ba5edda1a.md)
  
  ,
- [`{ИмяСправочника}.Ссылка`](../../wiki/data/catalogname-reference-ru-27f8093271c9.md)
  
  ,
- [`{ИмяДокумента}.Ссылка`](../../wiki/data/documentname-reference-ru-0832916d1814.md)
  
  ,
- [`{ИмяНабораКонстант}.КлючЗаписи`](../../wiki/stdlib/constantssetname-recordkey-ru-561ab53f9174.md)
  
  ,
- [`{ИмяРегистраСведений}.КлючЗаписи`](../../wiki/data/informationregistername-recordkey-ru-2cfab865dace.md)
  
  ,
- [`{ИмяРегистраНакопления}.КлючЗаписи`](../../wiki/data/accumulationregistername-recordkey-ru-9247d6fd0ee5.md)
  
  .

Если используется недопустимый тип, то при применении изменений проекта появится сообщение об ошибке. Вы можете добавить правило конвертации, проигнорировать поле или изменить его тип на поддерживаемый (в этом случае для обработки значений поля необходимо реализовать обработчики событий `ПослеКонвертации` — [пример](../../wiki/integration/data-exchange-with-1c-enterprise-d09e80bf9aea.md)).
