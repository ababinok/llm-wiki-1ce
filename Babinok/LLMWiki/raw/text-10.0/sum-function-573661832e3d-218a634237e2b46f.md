Функция вычисляет арифметическую сумму всех попавших в выборку значений поля. Она имеет следующий синтаксис:

```xbql
СУММА([РАЗЛИЧНЫЕ] операнд)
```

Операнд должен иметь тип `Число`. Если выборка, по которой рассчитывается ***операнд***, пустая, то результатом функции будет `Null`.

Пример:

```xbql
ВЫБРАТЬ
    СУММА(Сотрудники.Возраст) КАК ОбщийВозраст
ИЗ
    Сотрудники КАК Сотрудники
```
