[Регистры накопления](../../wiki/data/accumulation-register-overview-699bd9df5dda.md) используются для хранения информации о наличии и движении средств, например финансов, товаров, материалов и т. д. Они позволяют «накапливать» числовые данные в разрезе нескольких измерений. Например, в регистре можно накапливать данные об остатках товаров на складах или информацию об объемах продаж в подразделениях компании.

Информация в регистре накопления хранится в виде записей, каждая из которых содержит значения **измерений** и соответствующие им значения **ресурсов**. Измерения описывают разрезы, в которых хранится информация, а в ресурсах регистра накапливаются нужные числовые данные.

Вместе с каждой записью в регистре накопления можно хранить дополнительную информацию. Для этого используются **реквизиты** регистра накопления.

#### ВидРегистра

```yaml
ВидРегистра: ВидРегистраНакопления
```

Вид регистра накопления. Возможные значения:

- [Остатки](../../wiki/data/accumulationregisterkind-ru-9a7712ae9ad3.md)
  
  (значение по умолчанию) — регистр хранит как итоговые значения ресурсов (остатки), так и их обороты;
- [Обороты](../../wiki/data/accumulationregisterkind-ru-9a7712ae9ad3.md)
  
  — регистр хранит только изменения ресурсов (обороты).

Задает все разрешения элемента проекта, которые не указаны явно.

#### ХранитьПериодическиеИтоги

`Версия 8.0 и выше`

```yaml
ХранитьПериодическиеИтоги: Булево
```

Включает/отключает хранение периодических итогов в базе данных.

Если **Истина** (значение по умолчанию), для регистра накопления создается служебная системная таблица периодических итогов. Она используется для вычисления результатов виртуальных таблиц [ИмяРегистраНакопления.Остатки](../../wiki/queries/accumulationregistername-balance-ru-cdd8ad42e449.md), [ИмяРегистраНакопления.Обороты](../../wiki/queries/accumulationregistername-turnovers-ru-3d6b38eee7dc.md), [ИмяРегистраНакопления.ОстаткиИОбороты](../../wiki/queries/accumulationregistername-balanceandturnovers-ru-45be51537dcc.md). Вы не можете получить доступ к таблице итогов с помощью языка запросов.

В процессе работы регистра накопления в служебной таблице итогов могут накапливаться записи, увеличивающие время доступа к виртуальным таблицам при выполнении запросов. Чтобы улучшить производительность запросов, используйте метод [ОптимизироватьПериодическиеИтоги](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md). Для вызова этого метода требуются права администратора.

#### ХранитьТекущиеИтоги

```yaml
ХранитьТекущиеИтоги: Булево
```

Включает/отключает хранение текущих итогов в базе данных.

Если **Истина** (значение по умолчанию), то для регистра накопления вида **Остатки** создается служебная системная таблица, в которой хранятся актуальные остатки ресурсов в разрезе измерений. Она используется для вычисления результатов виртуальных таблиц [ИмяРегистраНакопления.Остатки](../../wiki/queries/accumulationregistername-balance-ru-cdd8ad42e449.md) и [ИмяРегистраНакопления.ОстаткиИОбороты](../../wiki/queries/accumulationregistername-balanceandturnovers-ru-45be51537dcc.md). Вы не можете получить доступ к таблице итогов с помощью языка запросов.

В процессе работы регистра накопления в служебной таблице итогов могут накапливаться записи, увеличивающие время доступа к виртуальным таблицам при выполнении запросов. Чтобы улучшить производительность запросов, используйте метод [ОптимизироватьТекущиеИтоги](../../wiki/data/accumulationregistername-ru-ca3f7a553094.md). Для вызова этого метода требуются права администратора.

## Дочерние элеметы

#### Ресурсы

```yaml
Ресурсы: РесурсРегистраНакопления[]
```

Числовые показатели накопления, хранимые в регистре. Список ресурсов не может быть пустым.

---

#### Реквизиты

```yaml
Реквизиты: РеквизитРегистраНакопления|Регистратор[]
```

Реквизиты регистра накопления. Используются для хранения вспомогательной информации, относящейся к отдельным записям регистра.

Регистр накопления должен содержать обязательный стандартный реквизит **Регистратор**. В этом реквизите указываются ссылки на элементы проекта вида [Документ](../../wiki/data/document-element-0c6b898a8b13.md), которые являются регистраторами для регистра накопления.

---

#### Измерения

```yaml
Измерения: ИзмерениеРегистраНакопления[]
```

Значения, в разрезе которых в регистре хранятся показатели накопления. В качестве типов измерений нельзя использовать типы `Строка` и `Байты` неограниченной длины, а также тип `ДвоичныйОбъект.Ссылка`.
