`Стд::Интерфейс::ОбщиеКомпоненты::РедакторHtml` `Доступность: Клиент`

Компонент, позволяющий отображать и редактировать html-содержимое в виде WYSIWYG. Предназначен для редактирования html-содержимого (например, электронных писем).

Текущие возможности редактора:

- Форматирование текста: жирный, курсив, подчеркивание, зачеркивание
- Установка шрифта: вид и размер (предопределены)
- Установка цвета текста (предопределенная палитра)
- Создание списков (в т.ч. вложенных через команды отступа)
- Имитация нажатия клавиши Tab (отступы)
- Выравнивание текста: по левому, по центру, по правому краю
- Цитирование
- Вставка ссылок из буфера обмена (автоматическое преобразование)
- Вставка ссылок через всплывающее окно ввода адреса и представления (поддерживается вставка e-mail)
- Вставка изображений из буфера обмена и проводника
- Динамическое изменение размера изображений с сохранением пропорций
- Очистка формата
- Поддержка вставки из офисных программ, таких как MS Excel, MS Word и аналогов с сохранением стилей

## Свойства

### Значение

`Доступность: Клиент`

```
Значение: Строка
```

Содержимое редактора в виде html-разметки.

Значение изменяется динамически в обоих направлениях, как со стороны XBSL, так и со стороны клиента. Если пользователь ввел что-то в редакторе - значение будет изменено на новый ввод при сходе с него. Если значение было изменено программно - оно изменится в редакторе.

Если значением является некорректная html-строка - редактор преобразует содержимое в html-документ, но возможна потеря части содержимого, либо это содержимое отобразится не так как ожидалось.
